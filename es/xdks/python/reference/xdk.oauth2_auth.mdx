Este módulo proporciona funcionalidad de autenticación OAuth2 con PKCE (Proof Key for Code Exchange)
para flujos de autorización seguros. Incluye la generación de verificadores de código,
la gestión de tokens y la actualización automática de tokens.

<div id="class-xdkoauth2_authoauth2pkceauth">
  ### `class xdk.oauth2_auth.OAuth2PKCEAuth`
</div>

Autenticación OAuth2 PKCE para la X API.
