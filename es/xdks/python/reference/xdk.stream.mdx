<div id="labels_compliance">
  ### `labels_compliance`
</div>

Flujo de etiquetas de Publicaciones (streaming)
Transmite todos los eventos de etiquetado aplicados a las Publicaciones.
Este es un endpoint de streaming que emite datos en tiempo real a medida que están disponibles.
Cada elemento emitido representa un único dato del stream.
La conexión se gestiona automáticamente con lógica de reintento con backoff exponencial.
Si el stream se desconecta, el SDK se volverá a conectar automáticamente sin intervención del Cliente.

<div id="parameters">
  #### Parámetros
</div>

<ParamField path="path.backfill_minutes" type="int or None" default="None">
  El número de minutos de backfill solicitados.
</ParamField>

<ParamField path="path.start_time" type="str or None" default="None">
  YYYY-MM-DDTHH:mm:ssZ. El timestamp UTC más antiguo a partir del cual se proporcionarán las etiquetas de la publicación.
</ParamField>

<ParamField path="path.end_time" type="str or None" default="None">
  YYYY-MM-DDTHH:mm:ssZ. El timestamp UTC más reciente a partir del cual se proporcionarán las etiquetas de la publicación.
</ParamField>

<ParamField path="path.stream_config" type="StreamConfig">
  StreamConfig opcional para personalizar el comportamiento de reintento, los tiempos de espera y los callbacks.
</ParamField>
