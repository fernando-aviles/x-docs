<div id="get_buyers">
  ### `get_buyers`
</div>

Obtener los compradores de entradas de un Space
Recupera una lista de usuarios (Users) que compraron entradas para un Space específico por su id.

<div id="parameters">
  #### Parámetros
</div>

<ParamField path="path.id" type="str">
El ID del Space que se va a obtener.
</ParamField>

<ParamField path="path.pagination_token" type="Any or None" default="None">
Este parámetro se usa para obtener una "página" específica de resultados.
</ParamField>

<ParamField path="path.max_results" type="int or None" default="None">
El número máximo de resultados.
</ParamField>

<ParamField path="path.user_fields" type="List or None" default="None">
Una lista de campos de usuario, separados por comas, que se mostrarán.
</ParamField>

<ParamField path="path.expansions" type="List or None" default="None">
Una lista de campos, separados por comas, que se ampliarán.
</ParamField>

<ParamField path="path.tweet_fields" type="List or None" default="None">
Una lista de campos de Tuit, separados por comas, que se mostrarán.
</ParamField>
