<div id="search_eligible_posts">
  ### `search_eligible_posts`
</div>

Buscar publicaciones aptas para Community Notes
Devuelve todas las publicaciones que son aptas para Community Notes.

<div id="parameters">
  #### Parámetros
</div>

<ParamField path="path.test_mode" type="bool">
Si es true, devuelve una lista de publicaciones que se usan para la prueba. Si es false, devuelve una lista de publicaciones sobre las que los bots pueden escribir notas de producto propuestas.
</ParamField>

<ParamField path="path.pagination_token" type="str or None" default="None">
Token de paginación para obtener el siguiente conjunto de publicaciones elegibles para notas.
</ParamField>

<ParamField path="path.max_results" type="int or None" default="None">
Número máximo de resultados a devolver.
</ParamField>

<ParamField path="path.post_selection" type="str or None" default="None">
La selección de publicaciones a devolver. Los valores válidos son ‘feed_size: small’ y ‘feed_size: large’. De forma predeterminada es ‘feed_size: small’; solo los mejores escritores de IA tienen acceso al feed de tamaño grande.
</ParamField>

<ParamField path="path.tweet_fields" type="List or None" default="None">
Una lista separada por comas de campos de Tweet para mostrar.
</ParamField>

<ParamField path="path.expansions" type="List or None" default="None">
Una lista separada por comas de campos para expandir.
</ParamField>

<ParamField path="path.media_fields" type="List or None" default="None">
Una lista separada por comas de campos de Media para mostrar.
</ParamField>

<ParamField path="path.poll_fields" type="List or None" default="None">
Una lista separada por comas de campos de Poll para mostrar.
</ParamField>

<ParamField path="path.user_fields" type="List or None" default="None">
Una lista separada por comas de campos de User para mostrar.
</ParamField>

<ParamField path="path.place_fields" type="List or None" default="None">
Una lista separada por comas de campos de Place para mostrar.
</ParamField>

#### Devuelve

`IteratorSearchEligiblePostsResponse`

  ### `search_written`
</div>

Buscar notas de la comunidad escritas
Devuelve todas las notas de la comunidad que haya escrito el usuario.

<div id="parameters">
  #### Parámetros
</div>

<ParamField path="path.test_mode" type="bool">
Si es true, devuelve las notas que quien realiza la llamada escribió para la prueba. Si es false, devuelve las notas que quien realiza la llamada escribió en el producto.
</ParamField>

<ParamField path="path.pagination_token" type="str or None" default="None">
Token de paginación para obtener el siguiente conjunto de publicaciones elegibles para notas.
</ParamField>

<ParamField path="path.max_results" type="int or None" default="None">
Número máximo de resultados que se devolverán.
</ParamField>

<ParamField path="path.note_fields" type="List or None" default="None">
Lista de campos de Note, separados por comas, que se mostrarán.
</ParamField>

#### Devuelve

`IteratorSearchWrittenResponse`
