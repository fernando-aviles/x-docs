---
title: "StreamClient"
sidebarTitle: "StreamClient"

Este módulo proporciona un cliente para interactuar con los endpoints de streaming de la X API.
Las operaciones de transmisión en tiempo real devuelven generadores que emiten data a medida que llega.
Las conexiones de streaming se gestionan automáticamente con lógica de reintentos con backoff exponencial para una gestión sólida.
