Este módulo proporciona funcionalidad de autenticación OAuth1.0a para flujos de
autorización seguros. Incluye la generación de tokens de solicitud, la generación de URL
de autorización, el intercambio de tokens de acceso y la generación de firmas OAuth1.0a.
