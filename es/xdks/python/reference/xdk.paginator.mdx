Utilidades de paginación basada en cursores para el SDK de X API.

Este módulo proporciona una clase Cursor para ofrecer paginación de forma elegante en
todos los clientes de la API. Cursor permite iterar fácilmente sobre resultados paginados
utilizando tanto los métodos .pages() como .items(), con la seguridad de tipos adecuada.

<div id="xdkpaginatorcursor">
  ### `xdk.paginator.cursor`
</div>

Crea un cursor con la inferencia y validación de tipos adecuadas.
Esta función de fábrica ayuda con la inferencia de tipos para que obtengas
sugerencias de tipo correctas para la respuesta y valida que el método
admita paginación tanto en el análisis estático como en tiempo de ejecución.
