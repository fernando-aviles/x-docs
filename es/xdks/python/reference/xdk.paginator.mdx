Utilidades de paginación basadas en cursor para el SDK de X API.

Este módulo proporciona una clase Cursor para ofrecer un soporte de paginación elegante en todos los clientes de la API. Cursor permite iterar fácilmente sobre resultados paginados mediante los métodos .pages() y .items() con la seguridad de tipos adecuada.

<div id="xdkpaginatorcursor">
  ### `xdk.paginator.cursor`
</div>

Crea un cursor con una inferencia de tipos y una validación adecuadas.
Esta función de fábrica ayuda con la inferencia de tipos para que obtengas
sugerencias de tipos correctas para el tipo de respuesta y valida que el método
admita la paginación tanto en el análisis estático como en tiempo de ejecución.

</ParamField>
