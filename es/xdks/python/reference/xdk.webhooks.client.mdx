Crear enlace de transmisión
Crea un enlace para entregar eventos de `FilteredStream` al webhook especificado.

<div id="parameters">
  #### Parámetros
</div>

<ParamField path="path.webhook_id" type="Any">
El identificador de webhook que se vinculará a tu conjunto de reglas de FilteredStream.
</ParamField>

<ParamField path="path.tweet_fields" type="str or None" default="None">
Una lista de campos de Tweet separados por comas para mostrar.
</ParamField>

<ParamField path="path.expansions" type="str or None" default="None">
Una lista de campos a expandir, separados por comas.
</ParamField>

<ParamField path="path.media_fields" type="str or None" default="None">
Una lista de campos de medios separados por comas para mostrar.
</ParamField>

<ParamField path="path.poll_fields" type="str or None" default="None">
Una lista de campos de encuesta separados por comas para mostrar.
</ParamField>

<ParamField path="path.user_fields" type="str or None" default="None">
Una lista de campos de usuario separados por comas para mostrar.
</ParamField>

<ParamField path="path.place_fields" type="str or None" default="None">
Una lista de campos de lugar separados por comas para mostrar.
</ParamField>
