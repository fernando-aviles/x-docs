<div id="block_dms">
  ### `block_dms`
</div>

Bloquear mensajes directos
Bloquea, para el usuario autenticado, los mensajes directos enviados a o recibidos de un usuario específico por su id.

<div id="parameters">
  #### Parámetros
</div>

<ParamField path="path.id" type="Any">
  El id del usuario de destino para el cual el usuario autenticado solicita bloquear los mensajes directos.
</ParamField>

`BlockDmsResponse` - datos de la respuesta
