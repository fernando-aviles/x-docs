El XDK de Python (X Developer Kit) es nuestra biblioteca cliente oficial para interactuar con la X API v2 con Python. Permite a los desarrolladores comenzar a usar nuestra API rápidamente y crear aplicaciones que la utilicen. Se genera a partir de nuestra [especificación OpenAPI oficial](https://api.x.com/2/openapi.json). Abstrae los detalles HTTP de bajo nivel y, al mismo tiempo, proporciona un control granular cuando es necesario.

<div id="key-features">
  ## Funcionalidades clave
</div>

- 🔐 **Compatibilidad con OAuth**: Compatibilidad total con autenticación mediante Bearer Token (solo App), OAuth 2.0 con PKCE (contexto de usuario) y OAuth 1.0.
- 🔄 **Paginación**: Pagina automáticamente grandes volúmenes de resultados. El XDK se encarga de la paginación sin que tengas que hacer múltiples llamadas a la API usando el `next_token`.
- 📡 **Streaming**: Compatible con transmisión de datos en tiempo real para endpoints como filtered stream, que requieren una conexión HTTP persistente.
- 🎯 **Cobertura integral**: Compatible con todos los endpoints de X API v2, incluidos search, timelines, filtered-stream y más.
**Compatibilidad de versiones**: Python 3.8+. Probado en CPython y PyPy.
