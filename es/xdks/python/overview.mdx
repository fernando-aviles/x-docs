El XDK de Python (X Developer Kit) es nuestra biblioteca de cliente oficial para interactuar con X API v2 en Python. Permite que los desarrolladores comiencen rápidamente a usar nuestra API y desarrollen aplicaciones con ella. Se genera a partir de nuestra [especificación OpenAPI oficial](https://api.x.com/2/openapi.json). Abstrae los detalles HTTP de bajo nivel y, al mismo tiempo, ofrece un control detallado cuando es necesario.

<div id="key-features">
  ## Características clave
</div>

- 🔐 **Compatibilidad con OAuth**: Compatibilidad completa con autenticación Bearer Token (solo aplicación), OAuth 2.0 con PKCE (contexto de usuario) y OAuth 1.0.
- 🔄 **Paginación**: Realiza automáticamente la paginación sobre grandes volúmenes de resultados. El XDK se encarga de la paginación sin que tengas que hacer múltiples llamadas a la API usando `next_token`.
- 📡 **Streaming**: Admite transmisión de datos en tiempo real para endpoints como filtered stream que requieren una conexión HTTP persistente.
- 🎯 **Cobertura integral**: Admite todos los endpoints de X API v2, incluidos search, timelines, filtered-stream y más.
**Compatibilidad de versiones**: Python 3.8+. Probado en CPython y PyPy.
