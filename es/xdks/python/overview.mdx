El XDK de Python (X Developer Kit) es nuestra biblioteca cliente oficial para interactuar con la X API v2 usando Python. Permite a los desarrolladores empezar a trabajar rápidamente con nuestra API y crear aplicaciones con ella. Se genera a partir de nuestra [especificación OpenAPI oficial](https://api.x.com/2/openapi.json). Abstrae los detalles de HTTP de bajo nivel y, al mismo tiempo, proporciona un control detallado cuando es necesario.

<div id="key-features">
  ## Funciones clave
</div>

- 🔐 **Compatibilidad con OAuth**: Compatibilidad total con autenticación con Bearer Token (solo aplicación), OAuth 2.0 con PKCE (contexto de usuario) y OAuth 1.0.
- 🔄 **Paginación**: Realiza la paginación automáticamente en conjuntos de resultados grandes. El XDK se encarga de la paginación sin que tengas que realizar múltiples llamadas a la API usando el `next_token`.
- 📡 **Streaming**: Ofrece streaming de datos en tiempo real para endpoints como filtered stream que requieren una conexión HTTP persistente.
- 🎯 **Cobertura integral**: Compatible con todos los endpoints de X API v2, incluidos search, timelines, filtered stream y más.
**Compatibilidad de versiones**: Python 3.8+. Probado en CPython y PyPy.
