Este ejemplo muestra cómo buscar publicaciones de forma rápida con xdk utilizando autenticación con Bearer Token.

<div id="step-1-install-the-sdk">
  ## Paso 1: Instala el SDK
</div>

```bash
pip install xdk
```

<div id="step-2-get-your-bearer-token">
  ## Paso 2: Obtén tu Bearer Token
</div>

1. Inicia sesión en la [Consola de Desarrollador de X](https://developer.x.com/en/portal/dashboard).
2. Crea o selecciona una aplicación.
3. En «Keys and Tokens», genera un Bearer Token (autenticación solo de la aplicación).

<div id="step-3-write-and-run-your-first-script">
  ## Paso 3: Escribe y ejecuta tu primer script
</div>

Crea un archivo `quickstart.py`:

```python
# Import the client
from xdk import Client
# Replace with your actual Bearer Token
client = Client(bearer_token="YOUR_BEARER_TOKEN_HERE")
# Fetch recent Posts mentioning "api"
# search_recent returns an Iterator, so iterate over it
for page in client.posts.search_recent(query="api", max_results=10):
    if page.data and len(page.data) > 0:
        # Acceder a la primera Publicación - los modelos Pydantic soportan acceso por atributo y por diccionario
        first_post = page.data[0]
        post_text = first_post.text if hasattr(first_post, 'text') else first_post.get('text', '')
        print(f"Latest Post: {post_text}")
        break
    else:
        print("No Posts found.")
        break
```

Ejecútalo:

```bash
python quickstart.py
```

**Salida esperada**:

```
Latest Post: Exciting updates on XDK Python SDK!
```

**Solución de problemas**: Si recibes un error 401, vuelve a verificar tu Bearer Token. En caso de límites de uso (429), espera y vuelve a intentarlo.
