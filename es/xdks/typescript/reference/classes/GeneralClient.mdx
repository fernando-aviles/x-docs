Cliente para operaciones generales

Este cliente proporciona métodos para interactuar con los endpoints generales
de la X API. Se encarga de la autenticación, el formato de las solicitudes y el análisis
de las respuestas para todas las operaciones generales.

▸ **getOpenApiSpec**(`options`): `Promise`&lt;`Response`&gt;

Obtiene la especificación OpenAPI.
Devuelve la especificación completa de OpenAPI en formato JSON. (Consulta https://github.com/OAI/OpenAPI-Specification/blob/master/README.md)

<div id="parameters">
