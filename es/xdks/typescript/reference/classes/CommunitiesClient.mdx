Cliente para operaciones con comunidades

Este cliente proporciona métodos para interactuar con los endpoints de comunidades
de X API. Se encarga de la autenticación, el formato de las solicitudes y el procesamiento de las respuestas
para todas las operaciones relacionadas con comunidades.
