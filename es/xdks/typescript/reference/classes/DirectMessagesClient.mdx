Cliente para operaciones con mensajes directos

Este cliente proporciona métodos para interactuar con los endpoints de mensajes directos
de la X API. Se encarga de la autenticación, el formato de las solicitudes y el análisis de las respuestas
para todas las operaciones relacionadas con mensajes directos.
