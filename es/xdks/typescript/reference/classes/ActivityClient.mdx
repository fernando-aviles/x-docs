Cliente para operaciones de actividad

Este cliente proporciona métodos para interactuar con los endpoints de actividad
de la X API. Se encarga de la autenticación, el formateo de las solicitudes y el procesamiento de las respuestas
para todas las operaciones relacionadas con la actividad.
