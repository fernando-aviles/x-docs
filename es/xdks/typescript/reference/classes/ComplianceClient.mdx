Cliente para operaciones de cumplimiento

Este cliente proporciona métodos para interactuar con los endpoints de cumplimiento
de la X API. Se encarga de la autenticación, el formato de las solicitudes y el análisis de las respuestas
para todas las operaciones relacionadas con el cumplimiento.
