Cliente para operaciones con notas de la comunidad

Este cliente proporciona métodos para interactuar con los endpoints de notas de la comunidad
de la X API. Gestiona la autenticación, el formateo de las solicitudes y el análisis de las respuestas
para todas las operaciones relacionadas con las notas de la comunidad.
