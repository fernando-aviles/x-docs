Cliente para operaciones de tendencias

Este cliente proporciona métodos para interactuar con los endpoints de tendencias
de la X API. Se encarga de la autenticación, el formateo de las solicitudes y el análisis de las respuestas
para todas las operaciones relacionadas con las tendencias.
