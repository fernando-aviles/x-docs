Cliente para operaciones de noticias

Este cliente proporciona métodos para interactuar con los endpoints
de noticias de la X API. Se encarga de la autenticación, el formato de las solicitudes y el análisis
de las respuestas para todas las operaciones relacionadas con noticias.
