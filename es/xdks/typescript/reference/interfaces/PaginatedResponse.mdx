Interfaz de respuesta paginada

Representa la estructura de una respuesta de API paginada de la X API.

<div id="type-parameters">
  ## Parámetros de type
</div>

| Nombre | Descripción |
| :------ | :------ |
| `T` | El type de los elementos en la respuesta |

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="data" type="T[]" required>
Array de elementos de la página actual

</ResponseField>

<ResponseField name="meta" type="Object">
Metadatos de la paginación

<Expandable title="propiedades">
<ResponseField name="Name" type="Tipo | Descripción" required>
</ResponseField>

<ResponseField name="resultCount" type="number | Número de resultados en la página actual">
</ResponseField>

<ResponseField name="nextToken" type="string | Token para recuperar la página siguiente">
</ResponseField>

<ResponseField name="previousToken" type="string | Token para recuperar la página anterior">
</ResponseField>
</Expandable>
</ResponseField>

<ResponseField name="includes" type="Record&lt;string, any&gt;">
Objetos adicionales incluidos (usuarios, Tweets, etc.)

</ResponseField>

<ResponseField name="errors" type="any[]">
Errores presentes en la respuesta

</ResponseField>
