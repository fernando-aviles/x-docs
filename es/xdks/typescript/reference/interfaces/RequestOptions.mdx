Opciones de solicitud para llamadas a la API

<div id="properties">
  ## Propiedades
</div>

<ParamField name="timeout" type="number">
Tiempo de espera de la solicitud en milisegundos

</ParamField>

<ParamField name="headers" type="Record&lt;string, string&gt;">
Encabezados adicionales

</ParamField>

<ParamField name="signal" type="AbortSignal">
Señal de la solicitud para cancelarla

</ParamField>

<ParamField name="body" type="string">
Cuerpo de la solicitud

</ParamField>

<ParamField name="raw" type="boolean">
Devolver el wrapper HTTP sin procesar en lugar del cuerpo procesado

</ParamField>

<ParamField name="security" type="Record&lt;string, string[]&gt;[]">
Requisitos de seguridad para el endpoint (de la especificación OpenAPI), que se usan para la selección inteligente de autenticación

</ParamField>
