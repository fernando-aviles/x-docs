Opciones de la solicitud para llamadas a la API

<div id="properties">
  ## Propiedades
</div>

<ParamField name="timeout" type="number">
Tiempo de espera de la solicitud en milisegundos

</ParamField>

<ParamField name="headers" type="Record&lt;string, string&gt;">
Cabeceras adicionales

</ParamField>

<ParamField name="signal" type="AbortSignal">
Señal de la solicitud para cancelar la operación

</ParamField>

<ParamField name="body" type="string">
Cuerpo de la solicitud

</ParamField>

<ParamField name="raw" type="boolean">
Devuelve el contenedor HTTP sin procesar en lugar del cuerpo analizado

</ParamField>

<ParamField name="security" type="Record&lt;string, string[]&gt;[]">
Requisitos de seguridad del endpoint (según la especificación OpenAPI), usados para la selección automática de autenticación

</ParamField>
