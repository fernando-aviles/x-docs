Empieza a utilizar el SDK de TypeScript para la X API en tu proyecto.

<div id="install">
  ## Instalación
</div>

<CodeGroup>
  ```bash npm theme={null}
  npm install @xdevplatform/xdk
  ```

  ```bash yarn theme={null}
  yarn add @xdevplatform/xdk
  ```

  ```bash pnpm theme={null}
  pnpm add @xdevplatform/xdk
  ```
</CodeGroup>

<div id="typescript-support">
  ## Compatibilidad con TypeScript
</div>

El SDK está implementado en TypeScript e incluye definiciones de type completas. No se necesitan paquetes de type adicionales.

<div id="requirements">
  ## Requisitos
</div>

* Node.js 16+
* TypeScript 4.5+ (si utilizas TypeScript)
