<div id="x-developers">
  ## X + Desarrolladores
</div>

X valora a los desarrolladores. Nos entusiasman y sorprenden las herramientas y servicios que esta comunidad crea aprovechando la potencia de los datos de X. Como parte de nuestro compromiso con esta comunidad, nuestro objetivo es proporcionar un acceso a los datos que sea abierto y justo para los desarrolladores, seguro para las personas en X y beneficioso para la plataforma de X en su conjunto. Para promover estos objetivos, hemos elaborado la Política para Desarrolladores como una guía para ayudar a las personas a comprender nuestras reglas y expectativas sobre el uso adecuado de la X API y del Contenido de X.

Esta Política para Desarrolladores (“**Política**”) establece reglas y directrices para los desarrolladores que interactúan con el ecosistema de aplicaciones, servicios, sitio web, páginas web y contenido de X. Forma parte de tu contrato con X que rige el acceso a y el uso de la X API y del Contenido de X (ya sea como parte del Acuerdo para Desarrolladores u otro acuerdo por escrito con X). Las infracciones de esta Política se consideran infracciones de tu acuerdo. Esta Política puede modificarse de vez en cuando sin previo aviso. Los términos en mayúsculas utilizados en esta Política que no se definan en la misma tendrán los significados respectivos que se les atribuyen en el [Acuerdo para Desarrolladores](/es/developer-terms/agreement) o en el Acuerdo Marco de Licencia.

<div id="using-this-policy">
  ## Uso de esta política
</div>

Hemos estructurado esta política para que sea lo más fácil de seguir posible. Ten presentes en todo momento la información de las siguientes secciones de la política mientras utilizas la X API y X Content:

1. **Prepárate para el éxito** - Eres responsable de cumplir todas las políticas de X. Es importante que revises y entiendas esta Política, así como las políticas a las que enlazamos en este documento, antes de acceder a la X API y a X Content. El tiempo que dediques a revisar nuestras políticas puede ahorrarte horas de trabajo adicional más adelante.

2. **La privacidad y el control son esenciales** - Proteger y defender la privacidad de las personas en X forma parte del ADN central de nuestra empresa. Por ello, prohibimos el uso de los datos de X de cualquier forma que sea incompatible con las expectativas razonables de privacidad de las personas. Al crear con la X API o acceder a X Content, desempeñas un papel especial en salvaguardar este compromiso, principalmente respetando la privacidad de las personas y proporcionándoles transparencia y control sobre cómo se utilizan sus datos.

3. **Sigue las Directrices de Uso de la Plataforma** - Obtener la aprobación para acceder a la X API y a X Content es solo el primer paso. Nuestras Directrices de Uso de la Plataforma deberían ser tu primera referencia siempre que tengas preguntas sobre cómo garantizar el cumplimiento de las políticas para tu uso previsto de la plataforma de X.

A continuación, proporcionamos mucha más información sobre lo que significa cada una de estas tres secciones clave. Revísalas detenidamente para garantizar que tu uso de la X API y X Content sea coherente con nuestras políticas.

Si consideramos que estás infringiendo esta Política (o cualquier otra política de X), podemos suspender o revocar de forma permanente tu acceso a la X API y a X Content.

Por último, ten en cuenta que X puede supervisar tu uso de la X API para mejorar las aplicaciones de X, examinar cualquier uso comercial y garantizar que cumples con tu caso de uso aprobado y con esta Política.

Gracias por leer y gracias por desarrollar con nosotros. ¡Estamos deseando ver lo que creas!

<div id="set-yourself-up-for-success">
  ## Prepárate para el éxito
</div>

Puedes evitar muchos posibles inconvenientes al usar la X API si te aseguras de que tu servicio se haya creado de la forma correcta desde el primer día. Esta sección de la Política para Desarrolladores contiene reglas que todos los desarrolladores deben seguir antes de usar la X API o el Contenido de X.

Los planes Free, Basic y Pro (tal como se describen en [developer.x.com/en](http://developer.x.com/en)) están diseñados para aficionados, creación de prototipos comerciales, integraciones de productos X en etapas iniciales y para aplicaciones que dan soporte a un número limitado de usuarios finales. Si usas la X API y el Contenido de X más allá de este alcance, entonces debes solicitar (o ya estar suscrito a) un plan Enterprise (tal como se describe en [developer.x.com/en](http://developer.x.com/en)).

**Revisamos todos los usos propuestos de la plataforma para desarrolladores de X para verificar el cumplimiento de las políticas, por lo que estás obligado a revelar (y actualizar, según corresponda) tu uso previsto de la X API y el Contenido de X para que se te otorgue y mantengas el acceso.** Todos los desarrolladores nuevos deben [solicitar una cuenta de desarrollador](https://developer.x.com/portal/petition/essential/basic-info) para acceder a la X API. Los desarrolladores actuales sin una cuenta de desarrollador aprobada deben solicitar una, según se les indique por parte de X. Como parte de este proceso, deberás proporcionarnos una descripción por escrito de los usos que pretendes hacer de la X API y el Contenido de X.

La descripción de tu caso de uso es vinculante para ti, y cualquier desviación sustancial de esta puede constituir una infracción de nuestras reglas y dar lugar a medidas de cumplimiento. Debes notificarnos cualquier modificación sustancial de tu caso de uso y recibir aprobación antes de comenzar a usar Contenido de X para ese nuevo fin. Si no lo haces, esto puede dar lugar a la suspensión y la cancelación de tu acceso a la API y a los datos.

**Al crear sobre la X API o acceder al Contenido de X, debes cumplir con TODAS las políticas de X.** Estas incluyen esta [Política para Desarrolladores](/es/developer-terms/policy), las [Reglas de Automatización](https://help.x.com/rules-and-policies/x-automation), los [Requisitos de Visualización](https://developer.x.com/developer-terms/display-requirements.html), las [Reglas de Usos Restringidos de la API](/es/developer-terms/restricted-use-cases), las [Reglas de X](https://help.x.com/rules-and-policies/x-rules) y los [Recursos de Marca de X](https://about.x.com/who-we-are/brand-toolkit), así como cualquier otro acuerdo que celebres con X relacionado con tu uso de la X API o el Contenido de X, incluidos, entre otros, el [Acuerdo para Desarrolladores](/es/developer-terms/agreement) o un Acuerdo de Licencia Principal o una Orden (según corresponda). También debes cumplir con cualquier modificación de estas políticas y con cualquier política nueva que X lance. Es tu responsabilidad supervisar el uso de tu servicio y diseñar tu servicio para evitar infracciones de las políticas de X por parte de las personas que lo usan. Si no lo haces, esto puede resultar en la suspensión o la cancelación de tu acceso a la API y al Contenido de X.

**No puedes registrar múltiples aplicaciones para un único caso de uso ni para casos de uso sustancialmente similares o superpuestos.** En este contexto, un “caso de uso” es un conjunto coherente de análisis, visualizaciones o acciones realizadas mediante una aplicación. Las versiones de una herramienta o servicio de tipo &quot;white label&quot; no están permitidas. Si planeas crear versiones &quot;white label&quot; de tu aplicación, debes notificárnoslo y recibir una aprobación por separado de nuestra parte.

*Como única excepción a estas reglas,* puedes crear y usar un máximo de 3 aplicaciones para las instancias de desarrollo, staging y producción del mismo servicio. Estas aplicaciones deben estar registradas en una sola cuenta y deben estar claramente identificadas (en el nombre y la descripción) como instancias de desarrollo, staging y producción de un único servicio. **No puedes usar aplicaciones de desarrollo o staging con fines de producción.**

**Debes mantener en privado todas las claves de API u otras credenciales de acceso.** No puedes usar, ni fomentar o facilitar que otros usen, claves de API u otras credenciales de acceso que pertenezcan a terceros.

**Tu acuerdo de licencia con X limita tu uso de la X API y el Contenido de X. Entre otras cosas, la X API tiene límites de frecuencia que ayudan a garantizar un uso justo de los datos y a combatir el spam en la plataforma.** No puedes exceder ni eludir los límites de frecuencia, ni ninguna otra limitación o restricción descrita en esta Política o en tu acuerdo con X, enumeradas en el [sitio para desarrolladores](https://developer.x.com/) o que X te haya comunicado.

**No puedes eliminar ni modificar ningún aviso o marca de propiedad sobre el Contenido de X recibido a través de la X API.** Esto ayuda a garantizar que las personas sepan de dónde proviene el Contenido de X y a quién pertenece.

**Por motivos de integridad de los datos y del buen funcionamiento de la plataforma, no puedes interferir, interceptar, interrumpir ni deshabilitar ninguna de las funciones de la X API o del servicio de X.** En otras palabras, usa las APIs tal como se pretende y según lo documentado en [developer.x.com](https://developer.x.com/). Consulta nuestras [directrices de HackerOne](https://hackerone.com/x) para obtener más detalles sobre el uso aceptable.

<div id="privacy-and-control-are-essential">
  ## La privacidad y el control son esenciales
</div>

X se toma la privacidad en serio y esperamos que todas las personas que usan Contenido de X y la X API hagan lo mismo. Cualquier uso de la plataforma para desarrolladores de X, la X API o el Contenido de X de un modo que no sea coherente con las expectativas razonables de privacidad de las personas puede estar sujeto a medidas de cumplimiento, que pueden incluir la suspensión y la revocación del acceso a la API y al Contenido de X.

Tu compromiso con la privacidad y el control debe abarcar todos los usos del Contenido de X y todos los aspectos del servicio que desarrolles utilizando nuestra API. Para ello, las personas que usan tu servicio deben comprender y aceptar cómo usas sus datos y cómo accedes a X en su nombre. Esto se puede lograr proporcionando a las personas una política de privacidad clara, completa y transparente, así como garantizando que obtengas el consentimiento expreso e informado de cada persona que use tu servicio antes de realizar cualquier acción en su nombre. **Ten en cuenta que el hecho de que una persona se autentique en tu servicio no constituye consentimiento por sí solo.**

<div id="consent-permissions">
  ## Consentimiento y permisos
</div>

**En particular, debes obtener el consentimiento expreso e informado de las personas antes de realizar cualquiera de las siguientes acciones:**

* Realizar *cualquier* acción en su nombre. Esto incluye (entre otras cosas):
  * Publicar contenido en X
  * Seguir/dejar de seguir cuentas
  * Modificar la información del perfil o de la cuenta
  * Agregar hashtags o cualquier otro contenido a las Publicaciones

* Volver a publicar contenido al que se acceda por medios distintos de la X API u otras herramientas de X

* Usar el Contenido de X de otra persona para promocionar un producto o servicio

* Almacenar contenido no público como Mensajes Directos (DM), o cualquier otra información privada o confidencial

* Compartir o publicar contenido protegido, o cualquier otra información privada o confidencial

**Si tu servicio permite que las personas publiquen contenido en X, debes hacer lo siguiente antes de la publicación:**

* Mostrar exactamente qué se publicará
* Dejar claro a las personas que usan tu servicio qué información geográfica (si la hay) se agregará al contenido

**Si tu servicio permite que las personas publiquen contenido tanto en tu servicio como en X, debes hacer lo siguiente antes de la publicación:**

* Obtener permiso para publicar el contenido
* Explicar dónde publicarás el contenido

**Debes respetar el estado protegido y bloqueado de todo el Contenido de X. No puedes mostrar contenido obtenido mediante el token de autenticación de una persona a otra persona que no esté autorizada a ver ese contenido.**

* **Cuentas protegidas:** El contenido de una [cuenta protegida](https://help.x.com/safety-and-security/public-and-protected-posts) solo está disponible para las personas que el propietario haya aprobado para seguir esa cuenta. Por lo tanto, si administras un servicio que accede a cuentas protegidas, solo puedes hacerlo para mostrar dicho contenido a las personas específicas que tengan permiso para verlo.
* **Cuentas bloqueadas:** Las personas en X pueden [bloquear](https://help.x.com/using-x/blocking-and-unblocking-accounts) el acceso a sus cuentas por cualquier motivo que elijan. No se permite combinar información obtenida de tokens (o mediante cualquier otra acción basada en la API) para eludir esta elección.

**Dado que los Mensajes Directos (DM) son de naturaleza no pública, los servicios que proporcionan funciones de DM deben tomar medidas adicionales para proteger la privacidad personal. No puedes mostrar contenido de DM a personas que no estén autorizadas a ver ese contenido. Si tu servicio ofrece funcionalidad de DM, también debes:**

* Notificar a las personas si envías eventos de confirmación de lectura para DMs. Puedes hacer esto proporcionando un aviso directamente en tu servicio o mostrando las confirmaciones de lectura de otros participantes en una conversación.
* Obtener consentimiento antes de configurar contenido multimedia para que se envíe en un DM como &quot;compartido&quot; (es decir, reutilizable en varios DMs). Si permites que el contenido multimedia en un DM se &quot;comparta&quot;, debes proporcionar un aviso claro de que este contenido será accesible para cualquier persona que tenga la URL del contenido multimedia.

<div id="content-compliance">
  ## Cumplimiento de contenido
</div>

**Si almacenas Contenido de X de forma offline, debes mantenerlo actualizado con el estado actual de ese contenido en X.** En concreto, debes eliminar o modificar cualquier contenido que tengas si se elimina o modifica en X. Esto debe hacerse tan pronto como sea razonablemente posible, o dentro de las 24 horas siguientes a la recepción de una solicitud para hacerlo, ya sea por parte de X o del titular de la cuenta de X correspondiente, o según lo exija tu acuerdo con X o la legislación aplicable. Esto debe hacerse salvo que la ley lo prohíba, y solo en ese caso con el permiso expreso y por escrito de X.

El contenido modificado puede adoptar diversas formas. Esto incluye (entre otras cosas):

* Contenido que se ha hecho privado o que ha adquirido estatus de protegido
* Contenido que ha sido suspendido de la plataforma
* Contenido del que se han eliminado las etiquetas geográficas
* Contenido que se ha retenido o eliminado de X

<div id="off-x-matching">
  ## Emparejamiento fuera de X
</div>

**Limitamos las circunstancias en las que puedes hacer coincidir a una persona en X con información obtenida o almacenada fuera de X.** El emparejamiento fuera de X implica asociar Contenido de X, incluido un @handle de X o un id de usuario, con una persona, un hogar, un dispositivo, un navegador u otro identificador fuera de X. Solo puedes hacer esto si cuentas con el consentimiento expreso previo (opt‑in) de la persona antes de realizar la asociación, o según se describe a continuación.

En situaciones en las que no tengas el consentimiento expreso previo de una persona para vincular su identidad en X a un identificador fuera de X, exigimos que cualquier conexión que establezcas se base únicamente en información que alguien razonablemente esperaría que se utilizara para ese propósito. Además, si no cuentas con el consentimiento expreso previo de una persona, solo puedes intentar hacer coincidir tus registros sobre alguien con una identidad en X basándote en:

* **Información proporcionada directamente a ti por la persona.** Ten en cuenta que los registros sobre personas con las que no tienes una relación previa, incluidos los datos sobre personas obtenidos de terceros, no cumplen este estándar; y/o
* **Datos públicos.** En este contexto, “datos públicos” se refiere a:
  * Información sobre una persona que obtuviste de un recurso público y generalmente accesible (como un directorio de miembros de una asociación profesional)
  * Información en X sobre una persona que es de acceso público, incluyendo:
    * Publicaciones
    * Información de perfil, incluida la biografía de la cuenta y la ubicación declarada públicamente
    * Nombre para mostrar y @handle

<div id="your-privacy-policy">
  ## Tu política de privacidad
</div>

**Debes mostrar la política de privacidad de tu servicio a las personas antes de que se les permita descargar, instalar o registrarse en tu servicio.** Debe incluir como mínimo la siguiente información:

* La información que recopilas de las personas que usan tu servicio
* Cómo utilizas y compartes esa información (incluida su compartición con X)
* Cómo las personas pueden ponerse en contacto contigo para consultas y solicitudes relacionadas con su información

Tu política de privacidad debe ser coherente con todas las leyes aplicables y no debe proporcionar a las personas un nivel de protección inferior al de la [Política de Privacidad de X](https://x.com/privacy) y la [política de privacidad de nuestros otros servicios y empresas afiliadas](https://help.x.com/rules-and-policies/x-services-and-corporate-affiliates). Debes cesar tu acceso a la X API y el uso de todo Contenido de X si no puedes cumplir con tu Política de Privacidad y/o la de X.

<div id="using-geo-data">
  ## Uso de datos geográficos
</div>

**El uso de datos geográficos conlleva restricciones adicionales debido a la naturaleza sensible de esta información.** Si tu servicio añade información de ubicación a las Publicaciones, debes informar a las personas:

* Cuándo añades información de ubicación
* Si añades información de ubicación como una etiqueta geográfica (geotag) o como datos de anotación
* Si tu información de ubicación se muestra como un lugar o como coordenadas geográficas

Si tu aplicación permite que las personas publiquen con su ubicación, debes cumplir por completo con las [pautas de geolocalización](/es/developer-terms/geo-guidelines) de X.

**Cualquier uso de datos de ubicación o información geográfica de forma independiente está prohibido.** No puedes (ni puedes permitir que otros lo hagan) almacenar, agregar o almacenar en caché datos de ubicación y otra información geográfica contenida en Contenido de X, excepto como parte de una Publicación. Por ejemplo, no puedes separar datos de ubicación o información geográfica de las Publicaciones para mostrar dónde han estado las personas a lo largo del tiempo. Los mapas de calor y las herramientas relacionadas que muestran actividad geográfica agregada (por ejemplo, la cantidad de personas en una ciudad que utilizan un hashtag) están permitidos.

<div id="x-passwords">
  ## Contraseñas de X
</div>

**No puedes almacenar contraseñas de X ni pedir a las personas que te faciliten directamente su contraseña de X, credenciales de cuenta o información de su App de desarrollador (incluida la consumer key).** Sugerimos usar [Sign-in with X](/es/fundamentals/authentication/guides/log-in-with-x) como herramienta de autenticación para vincular tu servicio con las personas en X.

<div id="platform-usage-guidelines">
  ## Pautas de uso de la plataforma
</div>

¿Te has tomado el tiempo de revisar las políticas de X y de configurar correctamente tu acceso a la API? ¿Tu servicio sigue las pautas de privacidad y control de X? Si puedes responder que sí a estas dos preguntas, entonces estás listo para empezar a usar X API y el Contenido de X. Las Pautas de uso de la plataforma de X proporcionan la asistencia necesaria para garantizar que tu uso del Contenido de X cumpla con las normas desde el primer día y a lo largo de todo el ciclo de vida de tu servicio. Te recomendamos revisar estas reglas periódicamente para asegurarte de que tu integración opera de forma segura y beneficiosa para las personas en X y para la plataforma de X en su conjunto.

<div id="spam-bots-and-automation">
  ## Spam, bots y automatización
</div>

**Está prohibido utilizar la X API y los productos para desarrolladores para crear spam o participar en cualquier forma de manipulación de la plataforma.** Debes revisar las Reglas de X sobre [manipulación de la plataforma y spam](https://help.x.com/rules-and-policies/platform-manipulation) y asegurarte de que tu servicio no infrinja nuestras políticas ni permita que otras personas lo hagan.

**Los servicios que realizan acciones de escritura, incluidas la publicación de Publicaciones, seguir cuentas o enviar Mensajes Directos, deben cumplir con las [Automation Rules](https://help.x.com/rules-and-policies/x-automation).** En particular, debes:

* Obtener siempre el consentimiento explícito antes de enviar a las personas [respuestas automatizadas o Mensajes Directos](https://twittercommunity.com/t/policy-clarification-automated-replies-and-mentions/94444)
* Respetar de inmediato las solicitudes para dejar de recibir comunicaciones tuyas
* Nunca realizar acciones masivas, agresivas o consideradas spam, incluido el [seguimiento masivo](https://twittercommunity.com/t/policy-clarification-aggressive-following-and-inorganic-following-behavior/92769)
* Nunca publicar contenido idéntico o sustancialmente similar en [múltiples cuentas](https://blog.twitter.com/developer/en_us/topics/tips/2018/automation-and-the-use-of-multiple-accounts.html)

**Si administras una cuenta de bot basada en API, debes indicar claramente en qué consiste la cuenta y quién es responsable de ella.** Nunca debes engañar ni confundir a las personas sobre si tu cuenta es o no un bot. Una buena forma de hacerlo es incluir en la biografía del perfil una declaración de que la cuenta es un bot.

<div id="x-performance-benchmarking">
  ## Evaluación comparativa del rendimiento de X
</div>

**No puedes usar la X API para medir la disponibilidad, el rendimiento, la funcionalidad o el uso de X con fines de evaluación comparativa, competitivos o comerciales.** Por ejemplo, nunca debes usar la X API para:

* Calcular métricas agregadas de X, como el número total de usuarios activos mensuales (MA) o usuarios activos diarios (DA)
* Calcular métricas agregadas de Publicaciones de X, como el número total de Publicaciones realizadas por día o el número de interacciones con cuentas
* Medir o analizar la capacidad de respuesta de X
* Medir o analizar el spam o la seguridad en X, salvo lo permitido a continuación

**Apoyamos la investigación que ayuda a mejorar la salud de la conversación en X.** No puedes divulgar públicamente ninguna investigación o resultado relacionado con el uso de la X API o el Contenido de X, ni desarrollar, crear u ofrecer servicios que usen la X API o el Contenido de X para medir, analizar o intentar identificar comportamientos o contenido que infrinjan las políticas de X sin el permiso expreso por escrito de X.

**Investigadores DSA:** Si necesitas contactar con X en relación con el acceso en virtud del art. 40 del Digital Services Act, comunícate escribiendo a [**EU-Questions@X.com**](mailto:EU-Questions@X.com). Si deseas solicitar acceso como investigador, envía una [solicitud](https://forms.gle/btDwenPF7M3hgSvw7).

<div id="public-display-of-posts">
  ## Exhibición pública de Publicaciones
</div>

**Debe mantener la integridad de todo el Contenido de X que muestre públicamente o a las personas que usan su servicio.** Si no usa [X for Websites](https://developer.x.com/docs/twitter-for-websites/overview) para mostrar contenido, entonces debe usar la X API para recuperar la versión más reciente disponible para su exhibición. Si el contenido mostrado deja de estar disponible a través de la X API, entonces debe retirarlo de su servicio tan pronto como sea razonablemente posible, o dentro de las 24 horas posteriores a la recepción de una solicitud de retiro de X, del titular de la cuenta de X correspondiente, o según lo exija la legislación aplicable.

**Existen reglas específicas que debe seguir si muestra Contenido de X sin conexión.** Siga las [directrices](https://developer.x.com/developer-terms/display-requirements) para el uso de Publicaciones en transmisiones si muestra Publicaciones sin conexión.

**Si inserta o muestra Publicaciones, debe ponerse en contacto con nosotros acerca de su acceso a la X API si su sitio supera los 10 millones de impresiones diarias.** X se reserva el derecho de exigir términos adicionales como condición para su uso de la X API. Las restricciones adicionales sobre el uso de X for Websites por parte de desarrolladores incluyen:

* **Publicaciones incrustadas y/o cronologías incrustadas**
  * Debe proporcionar a las personas un aviso legalmente suficiente que revele plenamente la recopilación y el uso por parte de X de datos sobre las actividades de navegación en su sitio web, incluso para publicidad basada en intereses y personalización. También debe obtener el consentimiento legalmente suficiente de las personas para dicha recopilación y uso
  * Debe proporcionar instrucciones legalmente suficientes sobre cómo las personas pueden inhabilitar la publicidad basada en intereses y la personalización de X, según se describe [aquí](https://help.x.com/x-for-websites-ads-info-and-privacy)

* **Widgets de X for Websites**
  * Debe asegurarse de que se proporcione a las personas información clara y completa sobre el almacenamiento y acceso a cookies u otra información en sus dispositivos y que presten su consentimiento para ello, según se describe en el documento de X sobre [uso de cookies](https://help.x.com/rules-and-policies/x-cookies), cuando la ley exija proporcionar dicha información y obtener dicho consentimiento

* **Servicios dirigidos a niños menores de 13 años**
  * Los servicios dirigidos a niños menores de 13 años deben inhabilitar la personalización de X en cualquier Publicación incrustada y/o cronologías incrustadas estableciendo el parámetro de exclusión en `true`, según se describe [aquí](https://developer.x.com/docs/twitter-for-websites/privacy)

<div id="content-redistribution">
  ## Redistribución de contenido

**El mejor lugar para obtener Contenido de X es directamente de X.
