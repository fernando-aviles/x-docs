Las publicaciones en X pueden contener hasta **280 caracteres**. Sin embargo, no todos los caracteres cuentan por igual: los emojis, las URLs y ciertos rangos de Unicode se rigen por reglas de conteo especiales.

---

<div id="character-weights">
  ## Pesos de caracteres
</div>

X utiliza un sistema ponderado para el conteo de caracteres. La mayoría de los caracteres cuentan como 1, pero algunos cuentan como 2:

| Tipo de carácter | Peso | Máx. de caracteres |
|:---------------|:-------|:---------------|
| Caracteres latinos, puntuación y símbolos comunes | 1 | 280 |
| Emojis | 2 | 140 emojis |
| CJK (chino, japonés, coreano) | 2 | 140 caracteres |
| Otros caracteres Unicode | 2 (predeterminado) | Varía |

<Tip>
Utiliza la biblioteca de código abierto [twitter-text](https://github.com/twitter/twitter-text) para contar caracteres con precisión en tu aplicación.
</Tip>

<div id="emoji-counting">
  ## Recuento de emojis
</div>

Todos los emojis cuentan como **2 caracteres**, independientemente de su complejidad:

| Emoji | Representación | Recuento de caracteres | Unicode |
|:------|:--------|:----------------|:--------|
| 👾 | Emoji individual | 2 | U+1F47E |
| 🙋🏽 | Con tono de piel | 2 | 🙋 + modificador 🏽 |
| 👨‍🎤 | Combinado con ZWJ | 2 | 👨 + ZWJ + 🎤 |
| 👨‍👩‍👧‍👦 | Secuencia de familia | 2 | 4 emojis + 3 ZWJ |

Los zero-width joiners (ZWJ) combinan visualmente los emojis, pero no aumentan el recuento.

<div id="url-handling">
  ## Gestión de URL
</div>

Todas las URL se acortan con el servicio `t.co` y cuentan como **23 caracteres**, independientemente de su longitud original:

```
https://example.com                    → 23 caracteres
https://example.com/very/long/path     → 23 caracteres
```

<Note>
  Esto se aplica a cualquier URL válida que se detecte en el texto de la publicación.
</Note>

***


<div id="special-cases">
  ## Casos especiales
</div>

| Contenido | Regla de contabilización |
|:--------|:--------------|
| **@mentions en respuestas** | Las @mentions que se rellenan automáticamente al inicio de las respuestas no cuentan |
| **Nuevas @mentions** | Las @mentions que agregas manualmente sí se cuentan con normalidad |
| **Media** | El contenido multimedia adjunto (a través de clientes oficiales) cuenta como 0 caracteres |
| **Hashtags** | Se cuentan con normalidad (# + texto de la etiqueta) |

---

<div id="text-encoding">
  ## Codificación de texto
</div>

La X API requiere la codificación **UTF-8**. La longitud de los caracteres se calcula utilizando la Forma de Normalización Unicode C (NFC).

Ejemplo con `café`:

| Forma | Bytes | Caracteres |
|:------|:------|:-----------|
| NFC (compuesta) | `c a f é` | 4 |
| NFD (descompuesta) | `c a f e ́` | 5 |

X normaliza a NFC, por lo que ambas se contabilizan como 4 caracteres.

<div id="implementation">
  ## Implementación
</div>

Utiliza la biblioteca oficial [twitter-text](https://github.com/twitter/twitter-text) para contar caracteres con precisión:

<Tabs>
  <Tab title="JavaScript">
```javascript
import { parseTweet } from 'twitter-text';

const result = parseTweet('Hello, world! 👋');
console.log(result.weightedLength); // 16
console.log(result.valid);          // true
```
  </Tab>
  <Tab title="Python">
```python
from twitter_text import parse_tweet

result = parse_tweet('Hello, world! 👋')
print(result.weightedLength)  # 16
print(result.valid)           # True
```
  </Tab>
</Tabs>

La biblioteca maneja todos los casos límite, incluidas las secuencias de emoji, la detección de URL y la normalización de Unicode.
