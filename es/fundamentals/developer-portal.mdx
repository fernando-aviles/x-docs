La [Consola de Desarrollador](https://console.x.com) es tu punto central para administrar el acceso a X API. Crea aplicaciones, genera credenciales, supervisa el uso y gestiona la facturación, todo en un solo lugar.

<Button href="https://console.x.com">Abrir la Consola de Desarrollador</Button>

***

<div id="what-you-can-do">
  ## Lo que puedes hacer
</div>

<CardGroup cols={2}>
  <Card title="Crear y gestionar apps" icon="grid-2">
    Configura apps para obtener credenciales de API. Define la autenticación, los permisos y las URL de devolución de llamada.
  </Card>

  <Card title="Supervisar uso y costos" icon="chart-line">
    Haz un seguimiento del uso de la API en tiempo real. Consulta los costos por endpoint y gestiona tu saldo de créditos.
  </Card>

  <Card title="Generar credenciales" icon="key">
    Crea claves de API, tokens de acceso y credenciales OAuth para tus apps.
  </Card>

  <Card title="Comprar créditos" icon="credit-card">
    Compra créditos para la facturación por uso. No se requieren suscripciones ni compromisos.
  </Card>
</CardGroup>

<div id="getting-started">
  ## Primeros pasos
</div>

<Steps>
  <Step title="Regístrate para obtener una cuenta de desarrollador">
    Ve a [console.x.com](https://console.x.com) e inicia sesión con tu cuenta de X. Acepta el Acuerdo para Desarrolladores.
  </Step>

  <Step title="Crea tu primera app">
    Haz clic en **New App** y proporciona un nombre y una descripción. Esto generará tus credenciales de API.
  </Step>

  <Step title="Guarda tus credenciales">
    Copia y almacena de forma segura tu API Key, API Secret y Access Tokens. No se volverán a mostrar.
  </Step>

  <Step title="Comienza a desarrollar">
    Usa tus credenciales para autenticar solicitudes a la API. Consulta la [guía de inicio rápido](/es/x-api/getting-started/make-your-first-request).
  </Step>
</Steps>

<Warning>
  **Almacena las credenciales de forma segura.** Las claves de API y los tokens solo se muestran una vez, en el momento de generarlas. Usa un gestor de contraseñas o un almacén seguro. Si las pierdes, tendrás que regenerarlas, lo que invalidará las credenciales anteriores.
</Warning>

<div id="billing-credits">
  ## Facturación y créditos
</div>

La X API utiliza un modelo de pago por uso con un sistema basado en créditos:

| Función | Descripción |
|:--------|:------------|
| **Sin tarifas mensuales** | Paga solo por lo que usas, sin suscripciones |
| **Basado en créditos** | Compra créditos por adelantado, que se irán descontando a medida que uses la API |
| **Seguimiento en tiempo real** | Supervisa el uso y los costos en el panel de la Consola de Desarrollador |
| **Precios por endpoint** | Distintos endpoints tienen costos diferentes |
| **Desduplicación** | Si se solicita el mismo recurso dos veces en 24 horas, solo se cobra una vez |

Consulta los precios actuales y compra créditos en la [Consola de Desarrollador](https://console.x.com).

[Más información sobre precios →](/es/x-api/getting-started/pricing)

<div id="team-management">
  ## Gestión de equipos
</div>

<Note>
  La gestión de equipos está disponible solo para **cuentas Enterprise**.
</Note>

Las cuentas Enterprise pueden invitar a miembros del equipo para colaborar:

| Rol | Permisos |
|:-----|:-------------|
| **Administrador** | Acceso completo: administrar aplicaciones, facturación, miembros del equipo y roles |
| **Desarrollador** | Administrar sus propias aplicaciones, acceso de solo lectura a las aplicaciones del equipo |

Para invitar a un miembro del equipo, ve a la página Team en tu consola e ingresa su nombre de usuario de X.
