La [Consola de desarrollador](https://console.x.com) es tu panel central para gestionar el acceso a X API. Crea apps, genera credenciales, supervisa el uso y gestiona la facturación, todo desde un mismo lugar.

<Button href="https://console.x.com">Abrir Consola de desarrollador</Button>

***

<div id="what-you-can-do">
  ## Qué puedes hacer
</div>

<CardGroup cols={2}>
  <Card title="Crear y administrar aplicaciones" icon="grid-2">
    Configura aplicaciones para obtener credenciales de API. Configura la autenticación, los permisos y las URL de callback.
  </Card>

  <Card title="Supervisar uso y costos" icon="chart-line">
    Supervisa el uso de la API en tiempo real. Consulta los costos por endpoint y administra tu saldo de créditos.
  </Card>

  <Card title="Generar credenciales" icon="key">
    Crea claves de API, tokens de acceso y credenciales OAuth para tus aplicaciones.
  </Card>

  <Card title="Comprar créditos" icon="credit-card">
    Compra créditos para facturación de pago por uso. No necesitas suscripciones ni compromisos.
  </Card>
</CardGroup>

<div id="getting-started">
  ## Primeros pasos
</div>

<Steps>
  <Step title="Regístrate para obtener una cuenta de desarrollador">
    Ve a [console.x.com](https://console.x.com) e inicia sesión con tu cuenta de X. Acepta el Acuerdo de Desarrollador.
  </Step>

  <Step title="Crea tu primera App">
    Haz clic en **New App** y proporciona un nombre y una descripción. Esto genera tus credenciales de API.
  </Step>

  <Step title="Guarda tus credenciales">
    Copia y almacena de forma segura tu API Key, API Secret y Access Tokens. No se volverán a mostrar.
  </Step>

  <Step title="Comienza a desarrollar">
    Usa tus credenciales para autenticar solicitudes a la API. Consulta la [guía de inicio rápido](/es/x-api/getting-started/make-your-first-request).
  </Step>
</Steps>

<Warning>
  **Almacena las credenciales de forma segura.** Las claves y tokens de API solo se muestran una vez cuando se generan. Usa un gestor de contraseñas o un almacén seguro. Si se pierden, tendrás que regenerarlos, lo que invalida las credenciales anteriores.
</Warning>

<div id="billing-credits">
  ## Facturación y créditos
</div>

La X API usa precios de pago por uso con un sistema basado en créditos:

| Característica | Descripción |
|:--------|:------------|
| **Sin tarifas mensuales** | Paga solo por lo que usas, sin suscripciones |
| **Basado en créditos** | Compra créditos por adelantado, que se descuentan a medida que usas la API |
| **Seguimiento en tiempo real** | Supervisa el uso y los costos en el panel de la consola |
| **Precios por endpoint** | Distintos endpoints tienen costos diferentes |
| **Eliminación de duplicados** | El mismo recurso solicitado dos veces en 24 horas solo se cobra una vez |

Consulta los precios actuales y compra créditos en la [Consola de desarrollador](https://console.x.com).

[Más información sobre precios →](/es/x-api/getting-started/pricing)

<div id="team-management">
  ## Gestión de equipos
</div>

<Note>
  La gestión de equipos está disponible solo para **cuentas Enterprise**.
</Note>

Las cuentas Enterprise pueden invitar a miembros del equipo a colaborar:

| Role | Capabilities |
|:-----|:-------------|
| **Administrator** | Acceso completo: administrar apps, facturación, miembros del equipo y roles |
| **Developer** | Administrar sus propias apps, acceso de solo lectura a las apps del equipo |

Para invitar a un miembro del equipo, ve a la página Team en tu consola e introduce su handle de X.
