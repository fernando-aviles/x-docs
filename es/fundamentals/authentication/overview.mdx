Las X API manejan grandes volúmenes de datos. La manera en que garantizamos que estos datos estén protegidos tanto para desarrolladores como para usuarios es mediante la autenticación. Hay varios métodos de autenticación, que se enumeran a continuación.

La mayoría de los desarrolladores no necesitarán lidiar con las complejidades relacionadas con la autenticación, ya que las bibliotecas cliente manejan automáticamente estas dificultades.

Puedes encontrar una lista de las bibliotecas cliente disponibles en nuestra página de [Herramientas y bibliotecas](/es/resources/tools-and-libraries).

  <Card title="Autenticación básica" href="/es/resources/fundamentals/authentication/basic-auth">
    Muchas de las APIs empresariales de X requieren el uso de HTTP Basic Authentication.

    <br />

    [**Más información**](/es/resources/fundamentals/authentication/basic-auth)
  </Card>

  <Card title="Flujo de código de autorización OAuth 2.0 con PKCE" href="/es/resources/fundamentals/authentication/oauth-2-0/authorization-code">

    <br />

    [**Más información**](/es/resources/fundamentals/authentication/oauth-2-0/authorization-code)

<Note>
  **Nota:**
  Las claves de API de tu App y el App only Access Token, así como tu Access Token personal y el Access Token Secret, se pueden obtener en la sección [X developer Apps](/es/resources/fundamentals/developer-apps) que se encuentra en la [Consola de desarrollador](/es/resources/fundamentals/developer-portal).

  **Si deseas hacer solicitudes en nombre de otro usuario**, tendrás que generar un conjunto independiente de Access Tokens para ese usuario usando el [flujo OAuth de 3 patas](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens), y pasar los tokens de ese usuario con tus solicitudes de contexto de usuario OAuth 1.0a o contexto de usuario OAuth 2.0.
</Note>
