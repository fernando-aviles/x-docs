Las X APIs manejan enormes cantidades de datos. La forma en que garantizamos la seguridad de estos datos tanto para desarrolladores como para usuarios es mediante la autenticación. Existen varios métodos de autenticación, que se enumeran a continuación.

La mayoría de los desarrolladores no necesitarán lidiar con las complejidades relacionadas con la autenticación, ya que las bibliotecas cliente manejan automáticamente estas dificultades.

Puedes encontrar una lista de las bibliotecas cliente disponibles en nuestra página de [Herramientas y bibliotecas](/es/resources/tools-and-libraries).

<Note>
  **Nota:**
  Las API Keys de tu App y el App only Access Token, así como tu Access Token personal y tu Access Token Secret, se pueden obtener en la sección [X developer Apps](/es/resources/fundamentals/developer-apps) que se encuentra en la [Developer Console](/es/resources/fundamentals/developer-portal).

  **Si deseas realizar solicitudes en nombre de otro usuario**, deberás generar un conjunto independiente de Access Tokens para ese usuario utilizando el [3-legged OAuth flow](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens), y pasar los tokens de ese usuario con tus solicitudes de OAuth 1.0a User Context o de OAuth 2.0 User Context.
</Note>
