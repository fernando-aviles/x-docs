Las API de X manejan enormes cantidades de datos. La forma en que garantizamos que estos datos estén protegidos tanto para desarrolladores como para usuarios es mediante la autenticación. A continuación se enumeran varios métodos de autenticación.

La mayoría de los desarrolladores no necesitarán lidiar con las complejidades relacionadas con la autenticación, ya que las bibliotecas cliente manejan automáticamente estas dificultades.

Puedes encontrar una lista de las bibliotecas cliente disponibles en nuestra página de [Herramientas y bibliotecas](/es/resources/tools-and-libraries).

<Note>
  **Nota:**
  Las claves de API de tu App de desarrollador y el token de acceso de solo App, así como tu token de acceso personal y el secreto del token de acceso, se pueden obtener en la sección [X developer Apps](/es/resources/fundamentals/developer-apps), que se encuentra en la [Consola de Desarrollador](/es/resources/fundamentals/developer-portal).

  **Si quieres realizar solicitudes en nombre de otro usuario**, tendrás que generar un conjunto separado de tokens de acceso para ese usuario utilizando el [flujo OAuth de 3 partes](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens) y pasar los tokens de ese usuario en tus solicitudes de OAuth 1.0a User Context o de OAuth 2.0 User Context.
</Note>
