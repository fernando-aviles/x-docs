<div id="post-oauthrequest_token">
  ### POST oauth/request_token
</div>

Permite que una aplicación Consumer obtenga un OAuth Request Token para solicitar la autorización del usuario. Este método cumple con la [Sección 6.1](https://oauth.net/core/1.0/#auth_step1) del [flujo de autenticación OAuth 1.0](http://oauth.net/core/1.0/#anchor9).

**Es obligatorio usar HTTPS para todos los pasos de autorización OAuth.**

**Nota de uso:** Solo se aceptan valores ASCII para `oauth_nonce`.

**Resource URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/request_token`

**Resource Information[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| Formatos de respuesta | JSON |
| ¿Requiere autenticación? | No  |
| ¿Tiene límite de frecuencia? | Sí |

**Parameters[](#parameters "Permalink to this headline")**

| Nombre | Obligatorio | Descripción | Ejemplo |
| :--- | :--- | :--- | :--- |
| oauth&#95;callback | obligatorio | Para el cumplimiento de OAuth 1.0a este parámetro es **obligatorio**. El valor que especifiques aquí se utilizará como la URL a la que se redirige a un usuario en caso de que apruebe el acceso de tu aplicación a su cuenta. Configura esto como `oob` para el modo de PIN fuera de banda. Esta es también la forma en que especificas callbacks personalizados para usar en aplicaciones de escritorio/móviles. Envía siempre un `oauth_callback` en este paso, independientemente de que exista un callback preregistrado.<br /><br />Es obligatorio que cualquier URL de callback utilizada con este endpoint esté configurada en los ajustes de la app en developer.x.com* | `http://themattharris.local/auth.php` `twitterclient://callback` |
| x&#95;auth&#95;access&#95;type | opcional | Anula el nivel de acceso que una aplicación solicita a la cuenta de un usuario. Los valores admitidos son `read` o `write`. Este parámetro está pensado para permitir que un desarrollador registre una aplicación de lectura/escritura pero también solicite acceso de solo lectura cuando sea apropiado. |     |

Obtén más información sobre cómo aprobar tus URLs de callback en [esta página](/es/resources/fundamentals/developer-apps#callback-urls).

**Ten en cuenta** - Puedes ver y editar tus [apps de X](/es/resources/fundamentals/developer-apps) existentes a través del [panel de aplicaciones de X](https://developer.x.com/en/apps) si has iniciado sesión en tu cuenta de X en developer.x.com.

**Example request[](#example-request "Permalink to this headline")**

Request URL: `POST https://api.x.com/oauth/request_token`

Request POST Body: *N/A*

Authorization Header: `OAuth oauth_nonce="K7ny27JTpKVsTgdyLdDfmQQWVLERj2zAK5BslRsqyw", oauth_callback="http%3A%2F%2Fmyapp.com%3A3005%2Ftwitter%2Fprocess_callback", oauth_signature_method="HMAC-SHA1", oauth_timestamp="1300228849", oauth_consumer_key="OqEqJeafRSF11jBMStrZz", oauth_signature="Pc%2BMLdv028fxCErFyi8KXFM%2BddU%3D", oauth_version="1.0"`

Response: `oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik&oauth_token_secret=Kd75W4OQfb2oJTV0vzGzeXftVAwgMnEK9MumzYcM&oauth_callback_confirmed=true`

<div id="get-oauthauthorize">
  ### GET oauth/authorize
</div>

Permite que una aplicación cliente (Consumer) utilice un OAuth Request Token para solicitar la autorización del usuario. Este método cumple con la [Sección 6.2](http://oauth.net/core/1.0/#auth_step2) del [flujo de autenticación OAuth 1.0](http://oauth.net/core/1.0/#anchor9). Las aplicaciones de escritorio deben utilizar este método (y no pueden usar [GET oauth / authenticate](/es/resources/fundamentals/authentication/api-reference#get-oauth-authenticate)).

**Nota de uso:** Nunca se envía un `oauth_callback` a este método; en su lugar, proporciónalo a [POST oauth / request&#95;token](/es/resources/fundamentals/authentication/api-reference#post-oauth-request-token).

**URL del recurso[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/authorize`

**Información del recurso[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| Formatos de Respuesta | JSON |
| ¿Requiere autenticación? | Sí |
| ¿Tiene límite de frecuencia? | Sí |

**Parámetros[](#parameters "Permalink to this headline")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| Nombre | Obligatorio | Descripción | Valor predeterminado | Ejemplo |
| force&#95;login | opcional | Obliga al usuario a introducir sus credenciales para asegurarse de que se autoriza la cuenta de usuario correcta. |     |     |
| screen&#95;name | opcional | Rellena previamente el campo de nombre de usuario de la pantalla de inicio de sesión de OAuth con el valor proporcionado. |     |     |

**Ejemplo de solicitud[](#example-request "Permalink to this headline")**

Envía al usuario al paso `oauth/authorize` en un navegador web, incluyendo un parámetro oauth&#95;token:
`https://api.x.com/oauth/authorize?oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik`

<div id="get-oauthauthenticate">
  ### GET oauth/authenticate
</div>

Permite que una aplicación Consumer use un `request_token` de OAuth para solicitar la autorización de un usuario.

Este método reemplaza la [Sección 6.2](http://oauth.net/core/1.0/#auth_step2) del [flujo de autenticación OAuth 1.0](http://oauth.net/core/1.0/#anchor9) para aplicaciones que usan el flujo de autenticación con callback. El método utilizará al usuario que haya iniciado sesión actualmente como la cuenta para la autorización de acceso, a menos que el parámetro `force_login` se establezca en `true`.

Este método difiere de [GET oauth / authorize](/es/resources/fundamentals/authentication/api-reference#get-oauth-authorize) en que, si el usuario ya ha otorgado permiso a la aplicación, la redirección se producirá sin que el usuario tenga que volver a aprobarla. Para conseguir este comportamiento, debes habilitar la opción *Use Sign in with X* en el [registro de tu aplicación](https://developer.x.com/apps).

**Resource URL[](#resource-url "Enlace permanente a este encabezado")**

`https://api.x.com/oauth/authenticate`

**Resource Information[](#resource-information "Enlace permanente a este encabezado")**

|     |     |
| :--- | :--- |
| Response formats | JSON |
| Requires authentication? | Sí |
| Rate limited? | Sí |

**Parameters[](#parameters "Enlace permanente a este encabezado")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| Name | Required | Description | Default Value | Example |
| force&#95;login | optional | Obliga al usuario a introducir sus credenciales para garantizar que se autoriza la cuenta de usuario correcta. |     | *true* |
| screen&#95;name | optional | Precompleta el campo de nombre de usuario de la pantalla de inicio de sesión de OAuth con el valor proporcionado. |     |     |

**Example request[](#example-request "Enlace permanente a este encabezado")**

Redirige al usuario al paso `oauth/authenticate` en un navegador web, incluyendo un parámetro oauth&#95;token:
`https://api.x.com/oauth/authenticate?oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik`

<div id="post-oauthaccess_token">
  ### POST oauth/access_token
</div>

Permite que una aplicación Consumer intercambie el OAuth Request Token por un OAuth Access Token. Este método cumple con la [Sección 6.3](http://oauth.net/core/1.0/#auth_step3) del [flujo de autenticación OAuth 1.0](http://oauth.net/core/1.0/#anchor9).

**URL del recurso[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/access_token`

**Información del recurso[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| Formatos de respuesta | JSON |
| ¿Requiere autenticación? | Sí |
| ¿Con límite de frecuencia? | Sí |

**Parámetros[](#parameters "Permalink to this headline")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| Nombre | Obligatorio | Descripción | Valor predeterminado | Ejemplo |
| oauth&#95;token | obligatorio | El `oauth_token` aquí debe ser el mismo que el `oauth_token` devuelto en el paso `request_token`. |     |     |
| oauth&#95;verifier | obligatorio | Si utilizas el flujo web de OAuth, establece este parámetro en el valor de *oauth&#95;verifier* devuelto en la URL de callback. Si estás utilizando OAuth fuera de banda, establece este valor en el código PIN. Para cumplir con OAuth 1.0a, este parámetro es **obligatorio**. OAuth 1.0a se aplica de forma estricta y las aplicaciones que no utilicen *oauth&#95;verifier* no podrán completar el flujo de OAuth. |     |     |

**Ejemplo de solicitud[](#example-request "Permalink to this headline")**

`POST https://api.x.com/oauth/access_token?oauth_token=qLBVyoAAAAAAx72QAAATZxQWU6P&oauth_verifier=ghLM8lYmAxDbaqL912RZSRjCCEXKDIzx`

Desde una solicitud basada en PIN: `POST https://api.x.com/oauth/access_token?oauth_token=9Npq8AAAAAAAx72QBRABZ4DAfY9&oauth_verifier=4868795`

**Ejemplo de respuesta[](#example-response "Permalink to this headline")**

`oauth_token=6253282-eWudHldSbIaelX7swmsiHImEL4KinwaGloHANdrY&oauth_token_secret=2EEfA6BG5ly3sR3XjE0IBSnlQu4ZrUzPiYTmrkVU&user_id=6253282&screen_name=xapi`

<div id="post-oauthinvalidate_token">
  ### POST oauth/invalidate_token
</div>

Permite que una aplicación registrada revoque un OAuth access&#95;token emitido presentando sus credenciales de cliente. Una vez que un access&#95;token se ha invalidado, cualquier nuevo intento de creación generará un token de acceso diferente y ya no se permitirá usar el token invalidado.

**URL del recurso[](#resource-url "Permalink to this headline")**

`https://api.x.com/1.1/oauth/invalidate_token`

**Información del recurso[](#resource-information "Permalink to this headline")**

|                                       |                                                                      |
| :------------------------------------ | :------------------------------------------------------------------- |
| Formatos de respuesta                 | JSON                                                                 |
| ¿Requiere autenticación?              | Sí: contexto de usuario con los tokens de acceso que desea invalidar |
| ¿Está sujeto a límites de frecuencia? | Sí                                                                   |

**Ejemplo de solicitud[](#example-request "Permalink to this headline")**

```bash
        curl --request POST
          --url 'https://api.x.com/1.1/oauth/invalidate_token.json'
          --header 'authorization: OAuth oauth_consumer_key="CLIENT_KEY",
         oauth_nonce="AUTO_GENERATED_NONCE", oauth_signature="AUTO_GENERATED_SIGNATURE",
         oauth_signature_method="HMAC-SHA1", oauth_timestamp="AUTO_GENERATED_TIMESTAMP",
         oauth_token="ACCESS_TOKEN", oauth_version="1.0"'
```

**Ejemplo de respuesta[](#example-response "Enlace permanente a este encabezado")**

```bash
        HTTP/1.1 200 OK
        Content-Type: application/json; charset=utf-8
        Content-Length: 127
        ...

        {"access_token":"ACCESS_TOKEN"}
```

**Ejemplo de respuesta de error después de invalidar el token[](#example-error-response-after-token-has-been-invalidated "Enlace permanente a este título")**

```bash
        HTTP/1.1 401 Authorization Required
        ...

        {"errors": [{
          "code": 89,
          "message": "Invalid or expired token."}
        ]}
```

<div id="post-oauth2token">
  ### POST oauth2/token
</div>

Permite que una aplicación registrada obtenga un Bearer Token OAuth 2, que puede usarse para realizar solicitudes de API en nombre de la propia aplicación, sin un contexto de usuario. Esto se denomina [autenticación solo de aplicación](/es/resources/fundamentals/authentication/oauth-2-0/application-only).

Un Bearer Token puede invalidarse usando oauth2/invalidate&#95;token. Una vez que se ha invalidado un Bearer Token, los nuevos intentos de creación generarán un Bearer Token diferente y el uso del token anterior ya no estará permitido.

Solo puede existir un Bearer Token activo para una aplicación, y las solicitudes repetidas a este método generarán el mismo token ya existente hasta que haya sido invalidado.

Las respuestas satisfactorias incluyen una estructura JSON que describe el Bearer Token otorgado.

Los tokens recibidos mediante este método deben almacenarse en caché. Si se intenta hacerlo con demasiada frecuencia, las solicitudes serán rechazadas con un HTTP 403 y el código 99.

**URL del recurso[](#resource-url "Enlace permanente a este encabezado")**

`https://api.x.com/oauth2/token`

**Información del recurso[](#resource-information "Enlace permanente a este encabezado")**

|                              |                                                                                                           |
| :--------------------------- | :-------------------------------------------------------------------------------------------------------- |
| Formatos de respuesta        | JSON                                                                                                      |
| ¿Requiere autenticación?     | Sí: autenticación básica con tu API key como nombre de usuario y el secreto de tu API key como contraseña |
| ¿Tiene límite de frecuencia? | Sí                                                                                                        |

**Parámetros[](#parameters "Enlace permanente a este encabezado")**

|                |             |                                                                                                                                                                                                                                                                         | Valor predeterminado | Ejemplo                  |
| :------------- | :---------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------- | :----------------------- |
| Nombre         | obligatorio | Descripción                                                                                                                                                                                                                                                             | Valor predeterminado | Ejemplo                  |
| grant&#95;type | obligatorio | Especifica el tipo de grant que está solicitando la aplicación. En este momento, solo se permite *client&#95;credentials*. Consulta [autenticación solo de aplicación](/es/resources/fundamentals/authentication/oauth-2-0/application-only) para obtener más información. |                      | *client&#95;credentials* |

**Ejemplo de solicitud[](#example-request "Enlace permanente a este encabezado")**

```bash
    POST /oauth2/token HTTP/1.1
    Host: api.x.com
    User-Agent: My X App v1.0.23
    Authorization: Basic eHZ6MWV2R ... o4OERSZHlPZw==
    Content-Type: application/x-www-form-urlencoded;charset=UTF-8
    Content-Length: 29
    Accept-Encoding: gzip

    grant_type=client_credentials
```

**Ejemplo de respuesta:**

```bash
    HTTP/1.1 200 OK
    Status: 200 OK
    Content-Type: application/json; charset=utf-8
    ...
    Content-Encoding: gzip
    Content-Length: 140

    {"token_type":"bearer","access_token":"AAAA%2FAAA%3DAAAAAAAA"}
```

<div id="post-oauth2invalidate_token">
  ### POST oauth2/invalidate_token
</div>

Permite que una aplicación registrada revoque un Bearer Token de oAuth 2.0 emitido proporcionando sus credenciales de cliente. Una vez que un Bearer Token ha sido invalidado, los nuevos intentos de creación producirán un Bearer Token diferente y el uso del token invalidado ya no estará permitido.

Las respuestas satisfactorias incluyen una estructura JSON que describe el Bearer Token revocado.

**URL del recurso[](#resource-url "Enlace permanente a este encabezado")**

`https://api.x.com/oauth2/invalidate_token`

**Información del recurso[](#resource-information "Enlace permanente a este encabezado")**

|                              |                                                                                                                                                                                                   |
| :--------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Formatos de respuesta        | JSON                                                                                                                                                                                              |
| ¿Requiere autenticación?     | Sí: [oAuth 1.0a](/es/resources/fundamentals/authentication/oauth-1-0a) con las claves de API de consumidor de la aplicación y el access token y access token secret del propietario de la aplicación |
| ¿Tiene límite de frecuencia? | Sí                                                                                                                                                                                                |

**Parámetros[](#parameters "Enlace permanente a este encabezado")**

| Nombre           | Obligatorio | Descripción                                    |
| :--------------- | :---------- | :--------------------------------------------- |
| access&#95;token | obligatorio | El valor del Bearer Token que deseas invalidar |

**Ejemplo de solicitud[](#example-request "Enlace permanente a este encabezado")**

```
        curl --request POST
          --url 'https://api.x.com/oauth2/invalidate_token?access_token=AAAA%2FAAA%3DAAAAAAAA'
          --header 'authorization: OAuth oauth_consumer_key="CLIENT_KEY",
         oauth_nonce="AUTO_GENERATED_NONCE", oauth_signature="AUTO_GENERATED_SIGNATURE",
         oauth_signature_method="HMAC-SHA1", oauth_timestamp="AUTO_GENERATED_TIMESTAMP",
         oauth_token="ACCESS_TOKEN", oauth_version="1.0"'
```

**Ejemplo de respuesta[](#example-response "Permalink to this headline")**

```
         Status: 200 OK
         Content-Type: application/json; charset=utf-8
         Content-Length: 135
         ...
       {
        "access_token": "AAAA%2FAAA%3DAAAAAAAA"
        }
```
