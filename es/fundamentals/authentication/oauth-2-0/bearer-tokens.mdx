<div id="using-and-generating-an-app-only-bearer-token">
  ### Uso y generación de un Bearer Token de solo aplicación
</div>

Un Bearer Token permite a los desarrolladores contar con un punto de entrada más seguro para usar la X API y es una de las características principales de OAuth 2.0. 

La autenticación que usa un Bearer Token también se conoce como autenticación de solo aplicación. Un Bearer Token es un array de bytes de formato no especificado que generas usando un script, como por ejemplo un comando curl. También puedes obtener un Bearer Token en la Consola de Desarrollador, dentro de la sección de claves y tokens en la configuración de tu App. Puedes encontrar más información sobre esta característica en la [documentación oficial de OAuth](https://oauth.net/2/bearer-tokens/).

<div id="when-are-they-used">
  #### ¿Cuándo se usan?
</div>

Los productos que requieren el uso de un Bearer Token son los siguientes:

* [Engagement API](/es/x-api/enterprise-gnip-2.0/fundamentals/engagement-api)
* [Account Activity API](/es/x-api/enterprise-gnip-2.0/fundamentals/account-activity)
* Otras API que utilizan autenticación mediante OAuth 2.0 Bearer Token, como los endpoints de v2 y de Labs.

<div id="prerequisites">
  #### Requisitos previos
</div>

Necesitarás [registrarte para obtener una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) y haber creado una [X App](/es/resources/fundamentals/developer-apps). Una vez que tengas ambos, también necesitarás obtener las claves de API que se encuentran en la [Consola de Desarrollador](/es/resources/fundamentals/developer-portal). Sigue estos pasos:

1. Inicia sesión en tu cuenta de X en developer.x.com.
2. Ve al [panel de X App](https://developer.x.com/content/developer-twitter/en/apps) y abre la X App para la cual deseas generar tokens de acceso.
3. Ve a la página &quot;keys and tokens&quot;.
4. Encontrarás las claves de API, los Access Tokens de usuario y el Bearer Token en esta página.

<div id="how-to-generate-a-bearer-token">
  ### Cómo generar un Bearer Token
</div>

Puedes encontrar el Bearer Token de tu App junto con el resto de tus &quot;Keys and Tokens&quot;.

Copia el siguiente comando cURL en tu línea de comandos después de reemplazar las siguientes claves de API de consumidor obtenidas previamente de tu [X App](/es/resources/fundamentals/developer-apps). Ten en cuenta que las claves de API de consumidor utilizadas en esta página han sido desactivadas y no funcionarán para solicitudes reales.

* **API key** `<API key>` por ejemplo `xvz1evFS4wEEPTGEFPHBog`
* **API secret key** `<API secret key>` por ejemplo `L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg`

  ```bash
  curl -u "$API_KEY:$API_SECRET_KEY" \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
  ```

A continuación se muestra un ejemplo de cómo debería verse el comando cURL con tus claves de API incluidas:

```bash
   curl -u 'xvz1evFS4wEEPTGEFPHBog:L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg' \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
```

Así es como se vería la respuesta. Ten en cuenta que este es un Bearer Token desactivado:

`{"token_type":"bearer","access_token":"AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F"}`

Nuestro Bearer Token usado para autenticarse en los recursos con OAuth 2.0 sería:

`AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F`
