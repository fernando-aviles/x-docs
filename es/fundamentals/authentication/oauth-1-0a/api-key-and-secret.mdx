<div id="api-key-and-secret">
  ### API Key and Secret
</div>

La API Key y el Secret (también conocidos como Consumer Key y Secret) son las credenciales más fundamentales para acceder a X API. Estas credenciales actúan como el nombre de usuario y la contraseña de tu X App, y son utilizadas por X API para identificar de qué App provienen las solicitudes. 

Estas credenciales pueden ser utilizadas por los [authentication endpoints](/es/resources/fundamentals/authentication/api-reference) para generar credenciales adicionales, como [user Access Tokens and Secrets](/es/resources/fundamentals/authentication/oauth-1-0a/api-key-and-secret) y [Bearer Tokens](/es/resources/fundamentals/authentication/oauth-2-0/bearer-tokens). También debes usar estas credenciales junto con Access Tokens y otros parámetros de autorización para [autorizar solicitudes](/es/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request) que requieren autenticación mediante OAuth 1.0a User Context. 

<div id="how-to-acquire-an-api-key-and-secret">
  #### Cómo obtener una clave y un secreto de API (API Key and Secret)
</div>

Para obtener una X API Key and Secret, sigue estos pasos:

1. [Regístrate para obtener una cuenta de desarrollador de X](https://developer.x.com/en/apply-for-access)
2. Crea una [X App](/es/resources/fundamentals/developer-apps) dentro de la [Consola de Desarrollador](/es/resources/fundamentals/developer-portal). Ten en cuenta que, si deseas usar [X API v2](/es/x-api/introduction), debes utilizar claves y tokens de una App de desarrollador.
    

Cuando crees tu X App, se te mostrarán tu API Key and Secret, junto con un Bearer Token. Ten en cuenta que solo mostramos estas credenciales una vez, así que asegúrate de guardarlas en tu gestor de contraseñas o en algún lugar seguro.

Tenemos más recomendaciones sobre cómo manejar tus claves y tokens en nuestra página de [mejores prácticas de autenticación](/es/resources/fundamentals/authentication/guides/authentication-best-practices), donde se incluyen detalles sobre qué debes hacer si tus credenciales se han visto comprometidas.
 

<div id="how-to-find-and-regenerate-your-api-key-and-secret-after-app-creation">
  #### Cómo encontrar y regenerar tu clave y secreto de API después de crear la App
</div>

Si ya has creado una App y necesitas encontrar o regenerar tu clave y secreto de API, sigue estos pasos:

1. Ve a la Consola de Desarrollador
2. Expande el menú desplegable &#39;Apps&#39; en la barra lateral de navegación
3. Abre la App asociada con la clave y el secreto de API que quieres encontrar o regenerar
4. Ve a la pestaña Keys and tokens

Ahí encontrarás todas las credenciales asociadas con tu App. 
 

<div id="how-to-use-your-api-key-and-secret">
  #### Cómo usar tu API Key y Secret
</div>

Si solo estás explorando la X Developer Platform, te recomendamos que uses una [herramienta o biblioteca](/es/resources/tools-and-libraries) para ver qué está disponible en la plataforma. Estas herramientas gestionan la autenticación de forma sencilla y pueden ahorrarte mucho tiempo y frustración. Te recomendamos específicamente [empezar con Postman](/es/tutorials/postman-getting-started) o [Insomnia](https://insomnia.rest/) si eres un desarrollador principiante. 

Si estás interesado en crear una solicitud desde cero, lee nuestra guía sobre [autorizar una solicitud OAuth 1.0a](/es/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request).
