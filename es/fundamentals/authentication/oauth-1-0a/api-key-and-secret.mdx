<div id="api-key-and-secret">
  ### API Key and Secret
</div>

La API Key y Secret (también conocidas como Consumer Key y Secret) son las credenciales más fundamentales necesarias para acceder a X API. Estas credenciales actúan como el nombre de usuario y la contraseña de tu App de X y son utilizadas por X API para identificar de qué App provienen las solicitudes. 

Estas credenciales pueden ser utilizadas por los [endpoints de autenticación](/es/resources/fundamentals/authentication/api-reference) para generar credenciales adicionales, como [user Access Tokens and Secrets](/es/resources/fundamentals/authentication/oauth-1-0a/api-key-and-secret) y [Bearer Tokens](/es/resources/fundamentals/authentication/oauth-2-0/bearer-tokens). También debes usar estas credenciales junto con Access Tokens y otros parámetros de autorización para [autorizar solicitudes](/es/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request) que requieren autenticación OAuth 1.0a con contexto de usuario. 

<div id="how-to-acquire-an-api-key-and-secret">
  #### Cómo obtener una API Key y Secret
</div>

Para obtener una X API Key y Secret, sigue estos pasos:

1. [Crea una cuenta de desarrollador de X](https://developer.x.com/en/apply-for-access)
2. Crea una [X App](/es/resources/fundamentals/developer-apps) dentro de la [Consola de desarrollador](/es/resources/fundamentals/developer-portal). Ten en cuenta que, si deseas usar [X API v2](/es/x-api/introduction), debes usar las claves y tokens de una App de desarrollador.
    

Cuando crees tu X App, se te mostrarán tu API Key y Secret, junto con un Bearer Token. Ten en cuenta que solo mostramos estas credenciales una vez, así que asegúrate de guardarlas en tu gestor de contraseñas o en un lugar seguro.

Tenemos más recomendaciones sobre cómo manejar tus claves y tokens en nuestra página de [mejores prácticas de autenticación](/es/resources/fundamentals/authentication/guides/authentication-best-practices), incluidos detalles sobre qué debes hacer si tus credenciales se han visto comprometidas.
 

<div id="how-to-find-and-regenerate-your-api-key-and-secret-after-app-creation">
  #### Cómo encontrar y regenerar tu API Key y Secret después de crear la App
</div>

Si ya creaste una App y necesitas encontrar o regenerar tu API Key y Secret, sigue estos pasos:

1. Ve a la Consola de desarrollador
2. Despliega el menú &quot;Apps&quot; en la barra lateral
3. Abre la App que está asociada con la API Key y Secret que deseas encontrar o regenerar
4. Ve a la pestaña Keys and tokens

Desde ahí verás todas las credenciales asociadas a tu App. 
 

<div id="how-to-use-your-api-key-and-secret">
  #### Cómo usar tu API Key y Secret
</div>

Si solo estás explorando la X Developer Platform, te recomendamos que uses una [herramienta o biblioteca](/es/resources/tools-and-libraries) para ver todo lo que ofrece la plataforma. Estas herramientas se encargan de la autenticación de forma transparente y pueden ahorrarte mucho tiempo y frustración. Recomendamos específicamente [comenzar con Postman](/es/tutorials/postman-getting-started) o [Insomnia](https://insomnia.rest/) para desarrolladores principiantes. 

Si estás interesado en crear una solicitud desde cero, lee nuestra guía sobre cómo [autorizar una solicitud con OAuth 1.0a](/es/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request).
