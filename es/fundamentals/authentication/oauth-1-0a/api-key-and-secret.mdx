<div id="api-key-and-secret">
  ### Clave de API y secreto
</div>

La clave de API y el secreto (también conocidos como Consumer Key y Secret) son las credenciales fundamentales obligatorias para acceder a X API. Estas credenciales actúan como el nombre de usuario y la contraseña de tu aplicación de X, y son utilizadas por X API para identificar de qué aplicación provienen las solicitudes. 

Estas credenciales pueden ser utilizadas por los [endpoints de autenticación](/es/resources/fundamentals/authentication/api-reference) para generar credenciales adicionales, como [user Access Tokens and Secrets](/es/resources/fundamentals/authentication/oauth-1-0a/api-key-and-secret) y [Bearer Tokens](/es/resources/fundamentals/authentication/oauth-2-0/bearer-tokens). También necesitas usar estas credenciales junto con Access Tokens y otros parámetros de autorización para [autorizar solicitudes](/es/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request) que requieren autenticación OAuth 1.0a User Context. 

<div id="how-to-acquire-an-api-key-and-secret">
  #### Cómo obtener una API Key y Secret
</div>

Para obtener una API Key y Secret de X API, sigue estos pasos:

1. [Regístrate para obtener una cuenta de desarrollador en X](https://developer.x.com/en/apply-for-access)
2. Crea una [X App](/es/resources/fundamentals/developer-apps) dentro de la [Developer Console](/es/resources/fundamentals/developer-portal). Ten en cuenta que, si quieres utilizar [X API v2](/es/x-api/introduction), debes usar las keys y tokens de una App de desarrollador.
    

Cuando crees tu X App, verás tu API Key y Secret, junto con un Bearer Token. Ten en cuenta que solo mostramos estas credenciales una vez, así que asegúrate de guardarlas en tu gestor de contraseñas o en algún lugar seguro.

Tenemos más recomendaciones sobre cómo manejar tus keys y tokens en nuestra página de [mejores prácticas de autenticación](/es/resources/fundamentals/authentication/guides/authentication-best-practices), incluidos detalles sobre qué debes hacer si tus credenciales se han visto comprometidas.
 

<div id="how-to-find-and-regenerate-your-api-key-and-secret-after-app-creation">
  #### Cómo encontrar y regenerar tu API Key y Secret después de crear una App
</div>

Si ya has creado una App y necesitas encontrar o regenerar tu API Key y Secret, sigue estos pasos:

1. Accede a la Developer Console
2. Despliega el menú desplegable &quot;Apps&quot; en la barra lateral de navegación
3. Abre la App que está asociada con la API Key y Secret que quieres encontrar o regenerar
4. Ve a la pestaña &quot;Keys and tokens&quot;

Ahí encontrarás todas las credenciales asociadas con tu App. 
 

<div id="how-to-use-your-api-key-and-secret">
  #### Cómo usar tu API Key y Secret
</div>

Si solo estás explorando la X Developer Platform, te recomendamos que utilices una [herramienta o biblioteca](/es/resources/tools-and-libraries) para ver qué hay disponible en la plataforma. Estas herramientas gestionan la autenticación de forma transparente y pueden ahorrarte mucho tiempo y frustración. En particular, recomendamos [comenzar con Postman](/es/tutorials/postman-getting-started) o [Insomnia](https://insomnia.rest/) para desarrolladores principiantes.

Si te interesa crear una solicitud desde cero, lee nuestra guía sobre cómo [autorizar una solicitud OAuth 1.0a](/es/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request).
