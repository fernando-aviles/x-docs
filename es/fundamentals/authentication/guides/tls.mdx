Las conexiones TLS son obligatorias para acceder a los endpoints de X API. La comunicación mediante TLS preserva la privacidad y la seguridad del usuario al proteger la información entre el usuario y X API mientras viaja por la Internet pública. Las conexiones a X API requieren la versión 1.2 de TLS.


<div id="verification">
  ## Verificación
</div>

<div id="use-an-up-to-date-root-store">
  ### Usa un almacén de certificados raíz actualizado
</div>

Es importante que tu aplicación o biblioteca use un almacén de certificados raíz fiable y actualizado al verificar el certificado de X. Cuando sea posible, usar el almacén de certificados raíz proporcionado por tu sistema operativo puede ser la opción más sencilla. Como alternativa, el [almacén de certificados raíz de Mozilla (NSS)](https://www.mozilla.org/en-US/about/governance/policies/security-group/certs/) se mantiene de forma pública y transparente. cURL también proporciona [una versión de este almacén en formato PEM](https://curl.haxx.se/docs/caextract.html).

Actualmente, X emite la mayor parte de nuestros certificados desde [DigiCert High Assurance EV Root CA](https://www.digicert.com/digicert-root-certificates.htm), pero esto no es así para el 100% de los certificados relacionados con X y puede que no siga siendo así para siempre, por lo que confiar únicamente en los certificados raíz actualmente utilizados de DigiCert podría causar problemas con tu aplicación en el futuro.

<div id="check-crls-and-the-ocsp-status">
  ### Comprobar las CRL y el estado OCSP[](#check-crls-and-the-ocsp-status "Permalink to this headline")
</div>

Muchas aplicaciones no comprueban la lista de revocación de certificados (CRL) para los certificados que reciben o dependen del sistema operativo para hacerlo. Asegúrate de que tu aplicación o biblioteca TLS esté configurada para forzar la verificación de CRL y OCSP (Online Certificate Status Protocol) antes de aceptar el certificado de X.

<div id="cdns">
  ### CDNs[](#cdns "Enlace permanente a este encabezado")
</div>

Al mostrar Tuits que contienen contenido multimedia, usa el atributo `media_url_https` para las URL HTTPS que se utilizarán al mostrar imágenes. En el futuro, todas las URL servidas desde endpoints de la API proporcionarán rutas HTTPS.

<div id="provide-an-indication-of-security-status">
  ## Proporciona una indicación del estado de seguridad
</div>

Si es posible, debes mostrar una indicación del estado actual entre tu aplicación y X. Algunos navegadores web indican esto mostrando un icono de candado, mientras que otros muestran el estado actual de la conexión mediante mensajes descriptivos.
