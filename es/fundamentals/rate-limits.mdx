Los límites de frecuencia controlan cuántas solicitudes a la API puedes realizar en un período de tiempo determinado. Garantizan un uso equitativo y la estabilidad del sistema en toda la plataforma.

***

<div id="how-rate-limits-work">
  ## Cómo funcionan los límites de frecuencia
</div>

| Concepto | Descripción |
|:--------|:------------|
| **Ventana temporal** | La mayoría de los límites se restablecen cada 15 minutos |
| **Límites por usuario** | Se aplican cuando se usan tokens de usuario OAuth 1.0a u OAuth 2.0 |
| **Límites por aplicación** | Se aplican cuando se usa autenticación con Bearer Token (solo aplicación) |
| **Específicos por endpoint** | Cada endpoint tiene su propio límite |

***

<div id="checking-your-limits">
  ## Comprobar tus límites
</div>

Cada respuesta de la API incluye encabezados que muestran el estado actual de tu límite de solicitudes:

```
x-rate-limit-limit: 900
x-rate-limit-remaining: 847
x-rate-limit-reset: 1705420800
```

| Encabezado               | Descripción                                                  |
| :----------------------- | :----------------------------------------------------------- |
| `x-rate-limit-limit`     | Número máximo de solicitudes permitidas en la ventana actual |
| `x-rate-limit-remaining` | Solicitudes restantes en la ventana actual                   |
| `x-rate-limit-reset`     | Marca de tiempo Unix en la que se restablece el límite       |

***

<div id="rate-limit-errors">
  ## Errores de límite de frecuencia
</div>

Cuando superes el límite de frecuencia, recibirás una respuesta **429 Too Many Requests**:

```json
{
  "errors": [{
    "code": 88,
    "message": "Rate limit exceeded"
  }]
}
```

<div id="best-practices">
  ## Mejores prácticas
</div>

<CardGroup cols={2}>
  <Card title="Almacena respuestas en caché" icon="database">
    Almacena en caché las respuestas de la API localmente para reducir las solicitudes repetidas de los mismos datos.
  </Card>

  <Card title="Usa backoff exponencial" icon="clock-rotate-left">
    Cuando estés sujeto a límites de frecuencia, espera antes de reintentar. Duplica el tiempo de espera con cada reintento.
  </Card>

  <Card title="Revisa los encabezados" icon="list-check">
    Supervisa los encabezados de límite de frecuencia para evitar alcanzar los límites de forma proactiva.
  </Card>

  <Card title="Usa streaming" icon="signal-stream">
    Para datos en tiempo real, usa el stream filtrado en lugar de consultar repetidamente los endpoints de búsqueda.
  </Card>
</CardGroup>
