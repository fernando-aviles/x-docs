Los límites de tasa controlan cuántas solicitudes a la API puedes realizar en un período de tiempo determinado. Garantizan un uso justo y la estabilidad del sistema en toda la plataforma.

***

<div id="how-rate-limits-work">
  ## Cómo funcionan los límites de tasa
</div>

| Concepto | Descripción |
|:--------|:------------|
| **Ventana temporal** | La mayoría de los límites se restablecen cada 15 minutos |
| **Límites por usuario** | Se aplican cuando se utilizan tokens de usuario de OAuth 1.0a u OAuth 2.0 |
| **Límites por aplicación** | Se aplican cuando se usa autenticación con Bearer Token (solo App) |
| **Específicos por endpoint** | Cada endpoint tiene su propio límite |

***

<div id="checking-your-limits">
  ## Comprobar tus límites de uso
</div>

Cada respuesta de la API incluye encabezados que muestran el estado actual de tu límite de solicitudes:

```
x-rate-limit-limit: 900
x-rate-limit-remaining: 847
x-rate-limit-reset: 1705420800
```

| Header                   | Description                                                  |
| :----------------------- | :----------------------------------------------------------- |
| `x-rate-limit-limit`     | Número máximo de solicitudes permitidas en la ventana actual |
| `x-rate-limit-remaining` | Solicitudes restantes en la ventana actual                   |
| `x-rate-limit-reset`     | Marca de tiempo Unix en la que se restablece el límite       |

***

<div id="rate-limit-errors">
  ## Errores de límite de frecuencia
</div>

Cuando excedas un límite de frecuencia, recibirás una respuesta **429 Too Many Requests**:

```json
{
  "errors": [{
    "code": 88,
    "message": "Rate limit exceeded"
  }]
}
```

<div id="best-practices">
  ## Mejores prácticas
</div>

<CardGroup cols={2}>
  <Card title="Almacenar respuestas en caché" icon="database">
    Almacena las respuestas de la API localmente para reducir solicitudes repetidas de los mismos datos.
  </Card>

  <Card title="Usar backoff exponencial" icon="clock-rotate-left">
    Cuando alcances el límite de tasa, espera antes de reintentar. Duplica el tiempo de espera con cada reintento.
  </Card>

  <Card title="Revisar encabezados" icon="list-check">
    Supervisa los encabezados de límite de tasa para evitar alcanzar los límites de forma proactiva.
  </Card>

  <Card title="Usar streaming" icon="signal-stream">
    Para datos en tiempo real, usa una transmisión filtrada en lugar de hacer polling a los endpoints de búsqueda.
  </Card>
</CardGroup>
