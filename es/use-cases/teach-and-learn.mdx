<div id="educators">
  ## Educadores
</div>

Lleva la API a tu aula para enseñar a los estudiantes fundamentos de programación y
valiosas habilidades de procesamiento de datos.

**Recursos:**

¿Eres educador y quieres usar la X API en tu curso? Esta
[guía para enseñar con la X API](https://dev.to/suhemparack/a-guide-to-teaching-with-the-twitter-api-v2-3n08)
te ayudará a entender la X API, por qué la usan los educadores, qué tipo de
clases se imparten con la API y todo lo demás que necesitas saber para
empezar.

**Destacados:**

Los siguientes planes de estudio se han diseñado e implementado utilizando la X API v2:

- [Social Media Data Mining and Analysis](https://canvas.uw.edu/courses/1434897)
  por la Dra. Tanu Mitra

- [Data Science & Society](https://dssoc.github.io/) por el Dr. Chris Bail

- [Introduction to Cultural Analytics & Python](https://melaniewalsh.github.io/Intro-Cultural-Analytics/welcome.html)
  por la Dra. Melanie Walsh

- [Oxford Spring School in Advanced Research Methods, Analysing X Data](https://github.com/cjbarrie/oxspsch)
  por el Dr. Chris Barrie
