<div id="official-sdks">
  ## SDKs oficiales
</div>

X ofrece SDKs oficiales para TypeScript y Python con soporte completo para X API v2:

<CardGroup cols={2}>
  <Card title="SDK de Python" icon="python" href="/es/xdks/python/overview">
    Soporte para async, anotaciones de tipos y actualización automática de tokens. Perfecto para el análisis de datos y la automatización.
  </Card>

  <Card title="SDK de TypeScript" icon="js" href="/es/xdks/typescript/overview">
    Seguridad de tipos completa y compatibilidad con ESM. Funciona en Node.js y con empaquetadores modernos.
  </Card>
</CardGroup>

<div id="building-a-library">
  ## ¿Estás desarrollando una biblioteca?
</div>

Si has creado una biblioteca de X API, compártela con la comunidad:

1. Publica en el [foro de Libraries &amp; SDKs](https://devcommunity.x.com/c/libraries-and-sdks/63)
2. ¡Podríamos incluirla en esta página!

Usa nuestras [insignias de versión](https://twbadges.glitch.me/) en tu README para mostrar la compatibilidad con X API.
