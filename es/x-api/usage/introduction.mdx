El endpoint Usage te permite monitorizar el uso de tu API, incluido el número de Publicaciones consumidas. Haz un seguimiento de tu uso de forma programática para gestionar los costes y mantenerte dentro de los límites.

<div id="endpoint">
  ## Endpoint
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/usage/tweets`](/es/x-api/usage/get-usage) | Obtener datos de uso de publicaciones |

***

<div id="response-data">
  ## Datos de la respuesta
</div>

La respuesta incluye recuentos diarios del consumo de Publicaciones:

```json
{
  "data": {
    "daily_project_usage": [
      {
        "date": "2024-01-15",
        "usage": [
          {
            "app_id": "12345678",
            "tweets_consumed": 15420
          }
        ]
      }
    ],
    "project_id": "1234567890",
    "project_cap": 10000000
  }
}
```

<div id="fields">
  ### Campos
</div>

| Campo | Descripción |
|:------|:------------|
| `daily_project_usage` | Array de datos de uso diario |
| `date` | Fecha en formato YYYY-MM-DD |
| `app_id` | El ID de tu aplicación |
| `tweets_consumed` | Publicaciones consumidas ese día |
| `project_cap` | Tu límite mensual de publicaciones |

***

<div id="example-request">
  ## Ejemplo de solicitud
</div>

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

***

<div id="use-cases">
  ## Casos de uso
</div>

* **Supervisión de costos** — Realiza un seguimiento del consumo en relación con los límites de tu plan
* **Alertas** — Configura alertas cuando te acerques a los límites
* **Optimización** — Identifica endpoints con alto consumo
* **Informes** — Genera informes de uso

<Tip>
  Los recursos se desduplican dentro de una ventana de 24 horas UTC, por lo que solicitar el mismo recurso varias veces en un día solo cuenta como un único cargo. [Más información sobre precios →](/es/x-api/getting-started/pricing)
</Tip>
