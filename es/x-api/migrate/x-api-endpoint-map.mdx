La siguiente tabla relaciona los endpoints de X API v2 con los endpoints correspondientes de la versión estándar v1.1 y de Enterprise. Para obtener más información sobre cada una de estas versiones y niveles, visita nuestra [guía de introducción a X API](/es/x-api/getting-started/about-x-api).

Verás que aún tenemos varios elementos marcados como **[Próximamente]**. Si ves algo en esta tabla que esté marcado como **[Reemplazo en evaluación]** o **[Sin reemplazo previsto]**, y te gustaría que publiquemos una versión v2 de ese endpoint, háznoslo saber a través de nuestro [foro de la comunidad](https://devcommunity.x.com/) o de tu account manager de Enterprise.
