La siguiente tabla relaciona los endpoints de la X API v2 con los endpoints estándar v1.1 y enterprise correspondientes. Para obtener más información sobre cada una de estas versiones y niveles, visita nuestra [guía de introducción a la X API](/es/x-api/getting-started/about-x-api).

Notarás que aún tenemos varios elementos marcados como **[Próximamente]**. Si ves algo en esta tabla que esté marcado como **[Reemplazo en consideración]** o **[Sin reemplazo planificado]**, y te gustaría que publiquemos una versión v2 de ese endpoint, háznoslo saber a través de nuestro [foro de la comunidad](https://devcommunity.x.com/) o de tu gestor de cuenta de enterprise.
