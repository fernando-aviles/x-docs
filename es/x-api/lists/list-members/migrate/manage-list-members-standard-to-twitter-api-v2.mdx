<div id="manage-list-members-standard-v11-compared-to-x-api-v2">
  ### Gestionar miembros de Listas: estándar v1.1 en comparación con X API v2
</div>

Si has estado trabajando con los endpoints estándar v1.1 [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) y [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy), el objetivo de esta guía es ayudarte a entender las similitudes y diferencias entre los endpoints estándar v1.1 y X API v2 para gestionar los miembros de Listas.

* **Similitudes**
  * Autenticación
* **Diferencias**
  * URLs de los endpoints
  * Requisitos de la aplicación y del Project
  * Métodos HTTP
  * Límites de frecuencia
  * Parámetros de la solicitud

<div id="similarities">
  #### Similitudes
</div>

**Autenticación**

Ambas versiones del endpoint son compatibles con [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication). Por lo tanto, si antes utilizabas uno de los endpoints estándar v1.1 para gestionar miembros de List, puedes seguir usando el mismo método de autenticación si migras a la versión de X API v2.

<div id="differences">
  #### Diferencias
</div>

**URLs de endpoints**

* Endpoints estándar v1.1:
  * POST https://api.x.com/1.1/lists/members/create.json
    (Agrega un miembro a una lista especificada)
  * POST https://api.x.com/1.1/lists/members/destroy.json
    (Elimina un miembro de una lista especificada)
* Endpoint de X API v2:
  * POST https://api.x.com/2/lists/:id/members
    (Agrega un miembro a una lista especificada)

  * DELETE https://api.x.com/2/lists/:id/members/:user&#95;id
    (Elimina un miembro de una lista especificada)

**Límites de frecuencia**

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| /1.1/lists/members/create.json<br /><br />none | /2/lists/:id/members<br /><br />300 solicitudes por ventana de 15 minutos con OAuth 1.0a User Context<br /><br />300 solicitudes por ventana de 15 minutos con OAuth 2.0 Authorization Code with PKCE |
| /1.1/lists/members/destroy.json<br /><br />none | /2/lists/:id/members/:user&#95;id<br /><br />300 solicitudes por ventana de 15 minutos con OAuth 1.0a User Context<br /><br />300 solicitudes por ventana de 15 minutos con OAuth 2.0 Authorization Code with PKCE |

**Requisitos de App y Project**

Los endpoints de X API v2 requieren que uses credenciales de una [developer App](/es/resources/fundamentals/developer-apps) que esté asociada con un [Project](/es/resources/fundamentals/developer-apps) al autenticar tus solicitudes. Todos los endpoints de X API v1.1 pueden usar credenciales de Apps o Apps asociadas a un Project.

**Parámetros de solicitud**

Los siguientes parámetros de solicitud estándar v1.1 tienen equivalentes en X API v2:

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| list&#95;id | id  |
| slug | Sin equivalente |
| screen&#95;name | Sin equivalente |
| owner&#95;screen&#95;name | Sin equivalente |
| owner&#95;id | Sin equivalente |
