<div id="manage-list-members-standard-v11-compared-to-x-api-v2">
  ### Administrar miembros de Listas: estándar v1.1 en comparación con X API v2
</div>

Si has estado trabajando con los endpoints estándar v1.1 [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) y [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy), el objetivo de esta guía es ayudarte a comprender las similitudes y diferencias entre los endpoints estándar v1.1 y X API v2 para administrar miembros de Listas.

* **Similitudes**
  * Autenticación
* **Diferencias**
  * URLs de los endpoints
  * Requisitos de la App y el Project
  * Métodos HTTP
  * Límites de frecuencia
  * Parámetros de solicitud

<div id="similarities">
  #### Similitudes
</div>

**Autenticación**

Ambas versiones del endpoint son compatibles con [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication). Por lo tanto, si antes utilizabas uno de los endpoints estándar de v1.1 para administrar miembros de Listas, puedes seguir usando el mismo método de autenticación si migras a la versión de X API v2.

<div id="differences">
  #### Diferencias
</div>

**URLs de endpoint**

* Endpoints estándar v1.1:
  * POST https://api.x.com/1.1/lists/members/create.json
    (Agrega un miembro a una Lista especificada)
  * POST https://api.x.com/1.1/lists/members/destroy.json
    (Elimina un miembro de una Lista especificada)
* Endpoint de X API v2:
  * POST https://api.x.com/2/lists/:id/members
    (Agrega un miembro a una Lista especificada)

  * DELETE https://api.x.com/2/lists/:id/members/:user&#95;id
    (Elimina un miembro de una Lista especificada)

**Límites de frecuencia**

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| /1.1/lists/members/create.json<br /><br />ninguno | /2/lists/:id/members<br /><br />300 solicitudes por ventana de 15 minutos con OAuth 1.0a User Context<br /><br />300 solicitudes por ventana de 15 minutos con OAuth 2.0 Authorization Code con PKCE |
| /1.1/lists/members/destroy.json<br /><br />ninguno | /2/lists/:id/members/:user&#95;id<br /><br />300 solicitudes por ventana de 15 minutos con OAuth 1.0a User Context<br /><br />300 solicitudes por ventana de 15 minutos con OAuth 2.0 Authorization Code con PKCE |

**Requisitos de App y Project**

Los endpoints de X API v2 requieren que uses credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que esté asociada con un [Project](/es/resources/fundamentals/developer-apps) para autenticar tus solicitudes. Todos los endpoints de X API v1.1 pueden usar credenciales de Apps o de Apps relacionadas con un Project.

**Parámetros de solicitud**

Los siguientes parámetros de solicitud de Standard v1.1 tienen equivalentes en X API v2:

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| list&#95;id | id  |
| slug | Sin equivalente |
| screen&#95;name | Sin equivalente |
| owner&#95;screen&#95;name | Sin equivalente |
| owner&#95;id | Sin equivalente |
