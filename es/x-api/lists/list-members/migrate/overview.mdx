<div id="comparing-x-apis-list-members-endpoints">
  ## Comparación de los endpoints de miembros de Listas de la X API
</div>

El grupo de endpoints de miembros de Listas de la X API v2 sustituirá a los endpoints estándar de v1.1 [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members), [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships), [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) y [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy). Si cuentas con código, aplicaciones o herramientas que utilizan alguna de estas versiones de los endpoints de miembros de Lista y estás considerando migrar al endpoint más reciente de X API v2, entonces este conjunto de guías es para ti. 

<div id="list-members-lookup">
  ### Búsqueda de miembros de la Lista
</div>

Los endpoints v2 de búsqueda de miembros de Listas reemplazarán los endpoints estándar [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members), [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships).

Las siguientes tablas comparan los endpoints estándar de Listas de v1.1 y de X API v2:

**Búsqueda de miembros de la Lista**

|     |     |     |
| :--- | :--- | :--- |
| Descripción | v1.1 estándar | X API v2 |
| Métodos HTTP compatibles | `GET` | `GET` |
| Dominio del host | `https://api.x.com` | `https://api.x.com` |
| Ruta del endpoint | `/1.1/lists/members.json` | `/2/lists/:id/members` |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App only | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />App only |
| Límite de [límites de tasa](/es/resources/fundamentals/rate-limits) de solicitud predeterminado | 900 solicitudes cada 15 min con OAuth 1.0a<br /><br />75 solicitudes cada 15 min con App only | 900 solicitudes cada 15 min con OAuth 1.0a<br /><br />900 solicitudes cada 15 min con OAuth 2.0<br /><br />900 solicitudes cada 15 min con App only |

**Búsqueda de pertenencias a Listas**

|     |     |     |
| :--- | :--- | :--- |
| Descripción | v1.1 estándar | X API v2 |
| Métodos HTTP compatibles | `GET` | `GET` |
| Dominio del host | `https://api.x.com` | `https://api.x.com` |
| Ruta del endpoint | `/1.1/lists/memberships.json` | `/2/users/:id/list_memberships` |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App only | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />App only |
| Límite de [límites de tasa](/es/resources/fundamentals/rate-limits) de solicitud predeterminado | 75 solicitudes cada 15 min con OAuth 1.0a<br /><br />75 solicitudes cada 15 min con App only | 75 solicitudes cada 15 min con OAuth 1.0a<br /><br />75 solicitudes cada 15 min con OAuth 2.0<br /><br />75 solicitudes cada 15 min con App only |

<div id="manage-list-members">
  ### Administrar miembros de la Lista
</div>

Los endpoints de v2 para administrar miembros de la Lista reemplazarán los endpoints estándar [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create), [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy).

Las siguientes tablas comparan los endpoints estándar de v1.1 y de X API v2 para Listas:

**Agregar miembro**

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | POST |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/lists/members/create.json | /2/lists/:id/members |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a contexto de usuario | OAuth 1.0a contexto de usuario<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Límites de tasa](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | Ninguno | 300 solicitudes por 15 min (por usuario) |

**Eliminar miembro**

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | DELETE |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/lists/members/destroy.json | /2/lists/:id/:user&#95;id |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a contexto de usuario | OAuth 1.0a contexto de usuario<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Límites de tasa](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | Ninguno | 300 solicitudes por 15 min (por usuario) |

Para acceder a los endpoints de X API v2, debes [registrarte para obtener una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info). Al autenticarte, debes usar claves y tokens de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que se encuentre dentro de un [Proyecto](/es/resources/fundamentals/developer-apps).

Obtén más información sobre cómo obtener acceso a los endpoints de X API v2 en nuestra página de [introducción](/es/x-api/getting-started/getting-access).
