Los endpoints de miembros de List te permiten consultar los miembros de una List y administrar su membresía.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * El Bearer Token de tu App (para consultas)
  * El User Access Token (para administrar miembros)
</Note>

<div id="authentication">
  ## Autenticación
</div>

| Operación | Autenticación |
|:----------|:---------------|
| Consultar miembros | Bearer Token, OAuth 1.0a o OAuth 2.0 PKCE |
| Añadir o eliminar miembros | OAuth 1.0a o OAuth 2.0 PKCE |

<div id="quick-example">
  ## Ejemplo rápido
</div>

<CodeGroup dropdown>
  ```bash cURL
  # Obtener miembros de la lista
  curl "https://api.x.com/2/lists/84839422/members" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python SDK de Python
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener miembros de la lista
  for page in client.lists.get_members("84839422"):
      for user in page.data:
          print(f"{user.username}")
  ```

  ```javascript SDK de JavaScript
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtener miembros de la lista
  const paginator = client.lists.getMembers("84839422");

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(user.username);
    });
  }
  ```
</CodeGroup>
