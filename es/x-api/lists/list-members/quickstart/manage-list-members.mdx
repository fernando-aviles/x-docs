Esta guía te muestra cómo agregar y eliminar miembros de una Lista.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * Un token de acceso de usuario (OAuth 1.0a o OAuth 2.0 PKCE)
  * Una Lista que sea de tu propiedad
</Note>

***

<div id="add-a-member-to-a-list">
  ## Agregar un miembro a una Lista
</div>

<Steps>
  <Step title="Obtener el ID de la Lista y el ID de usuario">
    Necesitas el ID de tu Lista y el ID de usuario de la persona que quieres agregar. Puedes encontrar los ID de usuario usando el [endpoint de búsqueda de usuarios](/es/x-api/users/lookup/introduction).
  </Step>

  <Step title="Agregar el miembro">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/lists/1441162269824405510/members" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"user_id": "2244994945"}'
      ```

      ```python Python SDK
      from xdk import Client
      from xdk.oauth1_auth import OAuth1

      oauth1 = OAuth1(
          api_key="YOUR_API_KEY",
          api_secret="YOUR_API_SECRET",
          access_token="YOUR_ACCESS_TOKEN",
          access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
      )

      client = Client(auth=oauth1)

      # Agregar un miembro a una Lista
      response = client.lists.add_member(
          list_id="1441162269824405510",
          user_id="2244994945"
      )

      print(f"Is member: {response.data.is_member}")
      ```

      ```javascript JavaScript SDK
      import { Client, OAuth1 } from "@xdevplatform/xdk";

      const oauth1 = new OAuth1({
        apiKey: "YOUR_API_KEY",
        apiSecret: "YOUR_API_SECRET",
        accessToken: "YOUR_ACCESS_TOKEN",
        accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
      });

      const client = new Client({ oauth1 });

      // Agregar un miembro a una Lista
      const response = await client.lists.addMember("1441162269824405510", {
        userId: "2244994945",
      });

      console.log(`Is member: ${response.data?.is_member}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Revisar la respuesta">
    ```json
    {
      "data": {
        "is_member": true
      }
    }
    ```
  </Step>
</Steps>

<div id="remove-a-member-from-a-list">
  ## Quitar un miembro de una Lista
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/lists/1441162269824405510/members/2244994945" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Quitar un miembro de una Lista
  response = client.lists.remove_member(
      list_id="1441162269824405510",
      user_id="2244994945"
  )

  print(f"Is member: {response.data.is_member}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Quitar un miembro de una Lista
  const response = await client.lists.removeMember(
    "1441162269824405510",
    "2244994945"
  );

  console.log(`Is member: ${response.data?.is_member}`);
  ```
</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "is_member": false
  }
}
```

<div id="important-notes">
  ## Notas importantes
</div>

<Note>
  * Solo puedes administrar miembros de Listas que te pertenecen
  * Agregar a un usuario a una Lista no requiere su permiso
  * Los usuarios pueden ver en qué Listas públicas han sido incluidos
</Note>
