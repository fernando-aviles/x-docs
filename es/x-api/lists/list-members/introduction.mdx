Los endpoints de miembros de Lista te permiten ver los miembros de una Lista, añadir miembros a tus Listas y eliminarlos. También puedes ver de qué Listas es miembro un usuario.

<div id="endpoints">
  ## Puntos de conexión
</div>

<div id="list-members-lookup">
  ### Consulta de miembros de listas
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/members`](/es/x-api/lists/get-list-members) | Obtener los miembros de una lista |
| GET | [`/2/users/:id/list_memberships`](/es/x-api/users/get-list-memberships) | Obtener las listas a las que pertenece un usuario |

<div id="manage-list-members">
  ### Administrar miembros de la Lista
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | [`/2/lists/:id/members`](/es/x-api/lists/add-list-member) | Agregar un miembro |
| DELETE | [`/2/lists/:id/members/:user_id`](/es/x-api/lists/remove-list-member) | Eliminar un miembro |

***

<div id="example-get-list-members">
  ## Ejemplo: Obtener miembros de una lista
</div>

```bash
curl "https://api.x.com/2/lists/1234567890/members?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-add-a-member">
  ## Ejemplo: Agregar un miembro
</div>

```bash
curl -X POST "https://api.x.com/2/lists/1234567890/members" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "9876543210"}'
```
