Esta guía te explica cómo consultar información de List usando los endpoints de consulta de List.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * El Bearer Token de tu App
</Note>

<div id="get-a-list-by-id">
  ## Obtener una Lista por ID
</div>

Recupera los detalles de una Lista específica:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/1234567890?\
  list.fields=description,owner_id,member_count,follower_count,private,created_at" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener una Lista por ID
  response = client.lists.get(
      "1234567890",
      list_fields=["description", "owner_id", "member_count", "follower_count", "private", "created_at"]
  )

  print(f"Lista: {response.data.name}")
  print(f"Miembros: {response.data.member_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtener una Lista por ID
  const response = await client.lists.get("1234567890", {
    listFields: ["description", "owner_id", "member_count", "follower_count", "private", "created_at"],
  });

  console.log(`Lista: ${response.data?.name}`);
  console.log(`Miembros: ${response.data?.member_count}`);
  ```
</CodeGroup>

<div id="get-lists-owned-by-a-user">
  ## Obtener las Listas que pertenecen a un usuario
</div>

Recupera todas las Listas que pertenecen a un usuario específico:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/2244994945/owned_lists?\
  list.fields=description,member_count,follower_count&\
  max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener las Listas que pertenecen a un usuario con paginación
  for page in client.lists.get_owned_lists(
      "2244994945",
      list_fields=["description", "member_count", "follower_count"],
      max_results=100
  ):
      for lst in page.data:
          print(f"{lst.name} - {lst.member_count} members")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtener las Listas que pertenecen a un usuario con paginación
  const paginator = client.lists.getOwnedLists("2244994945", {
    listFields: ["description", "member_count", "follower_count"],
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((lst) => {
      console.log(`${lst.name} - ${lst.member_count} members`);
    });
  }
  ```
</CodeGroup>

<div id="include-owner-information">
  ## Incluir información del propietario
</div>

Amplía los datos de usuario del propietario:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/1234567890?\
  list.fields=description,owner_id&\
  expansions=owner_id&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener lista con información del propietario
  response = client.lists.get(
      "1234567890",
      list_fields=["description", "owner_id"],
      expansions=["owner_id"],
      user_fields=["username", "verified"]
  )

  print(f"List: {response.data.name}")
  # La información del propietario está en response.includes.users
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtener lista con información del propietario
  const response = await client.lists.get("1234567890", {
    listFields: ["description", "owner_id"],
    expansions: ["owner_id"],
    userFields: ["username", "verified"],
  });

  console.log(`List: ${response.data?.name}`);
  // La información del propietario está en response.includes?.users
  ```
</CodeGroup>

<div id="response-with-expansion">
  ### Respuesta con expansión
</div>

```json
{
  "data": {
    "id": "1234567890",
    "name": "Tech News",
    "description": "Top tech journalists",
    "owner_id": "2244994945"
  },
  "includes": {
    "users": [
      {
        "id": "2244994945",
        "username": "XDevelopers",
        "verified": true
      }
    ]
  }
}
```

<div id="available-fields">
  ## Campos disponibles
</div>

| Campo | Descripción |
|:------|:------------|
| `description` | Descripción de la lista |
| `owner_id` | ID de usuario del propietario |
| `private` | Indica si la lista es privada |
| `member_count` | Número de miembros |
| `follower_count` | Número de seguidores |
| `created_at` | Fecha de creación de la lista |
