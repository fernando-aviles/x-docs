Los endpoints de consulta de Listas te permiten obtener información sobre listas. Consulta una lista específica por ID u obtén todas las listas de un usuario.

<div id="overview">
  ## Descripción general
</div>

<CardGroup cols={2}>
  <Card title="Por ID" icon="list">
    Obtén los detalles de una lista específica
  </Card>

  <Card title="Por propietario" icon="user">
    Obtén todas las listas que pertenecen a un usuario
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id`](/es/x-api/lists/get-list-by-id) | Obtener la lista por id |
| GET | [`/2/users/:id/owned_lists`](/es/x-api/users/get-owned-lists) | Obtener las listas que pertenecen a un usuario |

***

<div id="response-fields">
  ## Campos de la respuesta
</div>

De forma predeterminada, la respuesta incluye `id` y `name`. Puedes solicitar campos adicionales:

| Campo | Descripción |
|:------|:------------|
| `description` | Descripción de la Lista |
| `owner_id` | Identificador de usuario del propietario |
| `private` | Indica si la Lista es privada |
| `follower_count` | Número de seguidores |
| `member_count` | Número de miembros |
| `created_at` | Fecha de creación de la Lista |

<div id="example-request">
  ### Ejemplo de solicitud
</div>

```bash
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id,member_count,follower_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
