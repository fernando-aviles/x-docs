<div id="authentication">
  ## Autenticación
</div>

Los endpoints de consulta de Listas admiten varios métodos de autenticación:

| Método | Ideal para | ¿Acceso a Listas privadas? |
|:-------|:-----------|:---------------------------|
| [OAuth 2.0 App-Only](/es/resources/fundamentals/authentication#oauth-2-0) | Datos de Listas públicas | No |
| [OAuth 2.0 Authorization Code with PKCE](/es/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Aplicaciones de cara al usuario | Sí (propias/seguidas) |
| [OAuth 1.0a User Context](/es/resources/fundamentals/authentication) | Integraciones heredadas | Sí (propias/seguidas) |

<div id="example-request">
  ### Ejemplo de solicitud
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/84839422?\
  list.fields=description,member_count,follower_count,private" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener una lista por ID
  response = client.lists.get(
      list_id="84839422",
      list_fields=["description", "member_count", "follower_count", "private"]
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  const response = await client.lists.get("84839422", {
    listFields: ["description", "member_count", "follower_count", "private"],
  });
  console.log(response.data);
  ```
</CodeGroup>

</div>

| Método | Endpoint | Descripción |

<div id="available-fields">
  ### Campos disponibles
</div>

<Accordion title="list.fields">
  | Campo | Descripción |
  |:------|:------------|
  | `created_at` | Marca de tiempo de creación de la lista |
  | `description` | Descripción de la lista |
  | `follower_count` | Número de seguidores |
  | `member_count` | Número de miembros |
  | `owner_id` | id de usuario del propietario |
  | `private` | Indica si la lista es privada |
</Accordion>

<Accordion title="user.fields (requires owner_id expansion)">
  | Campo | Descripción |
  |:------|:------------|
  | `username` | Handle @ del propietario |
  | `name` | Nombre visible del propietario |
  | `verified` | Estado de verificación del propietario |
  | `profile_image_url` | URL del avatar del propietario |
</Accordion>

<div id="example-with-expansions">
  ### Ejemplo con expansions
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/84839422?\
  list.fields=description,member_count,follower_count,owner_id&\
  expansions=owner_id&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener una lista con la expansión del propietario
  response = client.lists.get(
      list_id="84839422",
      list_fields=["description", "member_count", "follower_count", "owner_id"],
      expansions=["owner_id"],
      user_fields=["username", "verified"]
  )

  print(response.data)
  print(response.includes)  # Contiene el objeto de usuario del propietario
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  const response = await client.lists.get("84839422", {
    listFields: ["description", "member_count", "follower_count", "owner_id"],
    expansions: ["owner_id"],
    userFields: ["username", "verified"],
  });

  console.log(response.data);
  console.log(response.includes); // Contiene el objeto de usuario del propietario
  ```
</CodeGroup>

<div id="pagination">
  ## Paginación
</div>

Al recuperar listas propiedad del usuario, los resultados se paginan:

<CodeGroup dropdown>
  ```bash cURL
  # Primera solicitud
  curl "https://api.x.com/2/users/123/owned_lists?max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"

  # Solicitud posterior con token de paginación
  curl "https://api.x.com/2/users/123/owned_lists?max_results=100&pagination_token=NEXT_TOKEN" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # El SDK gestiona la paginación automáticamente
  all_lists = []

  for page in client.lists.get_user_owned_lists(user_id="123", max_results=100):
      if page.data:
          all_lists.extend(page.data)

  print(f"Se encontraron {len(all_lists)} listas")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  async function getAllOwnedLists(userId) {
    const allLists = [];

    // El SDK gestiona la paginación automáticamente
    const paginator = client.lists.getUserOwnedLists(userId, { maxResults: 100 });

    for await (const page of paginator) {
      if (page.data) {
        allLists.push(...page.data);
      }
    }

    return allLists;
  }

  // Uso
  const lists = await getAllOwnedLists("123");
  console.log(`Se encontraron ${lists.length} listas`);
  ```
</CodeGroup>

<div id="private-lists">
  ## Listas privadas
</div>

* Las listas privadas solo son visibles para el propietario
* Debes autenticarte como propietario para obtener los detalles de una lista privada
* El campo `private` indica si una lista es privada

<div id="error-handling">
  ## Manejo de errores
</div>

| Estado | Error | Solución |
|:-------|:------|:---------|
| 400 | Solicitud no válida | Comprueba el formato del id de la lista |
| 401 | No autorizado | Verifica la autenticación |
| 403 | Acceso denegado | Es posible que la lista sea privada |
| 404 | No encontrado | La lista no existe |
| 429 | Demasiadas solicitudes | Espera y vuelve a intentarlo |
