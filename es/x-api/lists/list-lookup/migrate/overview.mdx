<div id="comparing-x-apis-list-lookup-endpoints">
  ## Comparación de los endpoints de búsqueda de Listas de X API
</div>

El grupo de endpoints de búsqueda de Listas de v2 reemplazará los endpoints estándar de v1.1 [GET lists/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-show) y [GET lists/ownership](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-ownerships). Si tienes código, apps o herramientas que usan una de estas versiones de los endpoints de búsqueda de Listas y estás considerando migrar al nuevo endpoint de X API v2, entonces este conjunto de guías es para ti.

Las siguientes tablas comparan los endpoints estándar de Listas de v1.1 y de X API v2:

**Búsqueda de Lista por ID**

|     |     |     |
| :--- | :--- | :--- |
| Descripción | v1.1 estándar | X API v2 |
| Métodos HTTP compatibles | `GET` | `GET` |
| Dominio del host | `https://api.x.com` | `https://api.x.com` |
| Ruta del endpoint | `/1.1/lists/show.json` | `/2/lists/:id` |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />Solo App | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />Solo App |
| [Límites de frecuencia](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | 75 solicitudes por 15 min con OAuth 1.0a<br /><br />75 solicitudes por 15 min con OAuth 2.0<br /><br />75 solicitudes por 15 min con Solo App | 75 solicitudes por 15 min con OAuth 1.0a<br /><br />75 solicitudes por 15 min con OAuth 2.0<br /><br />75 solicitudes por 15 min con Solo App |

**Búsqueda de Lista propiedad del usuario**

|     |     |     |
| :--- | :--- | :--- |
| Descripción | v1.1 estándar | X API v2 |
| Métodos HTTP compatibles | `GET` | `GET` |
| Dominio del host | `https://api.x.com` | `https://api.x.com` |
| Ruta del endpoint | `/1.1/lists/ownerships.json` | `/2/users/:id/owned_lists` |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />Solo App | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />Solo App |
| [Límites de frecuencia](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | 15 solicitudes por 15 min con OAuth 1.0a<br /><br />15 solicitudes por 15 min con Solo App | 15 solicitudes por 15 min con OAuth 1.0a<br /><br />15 solicitudes por 15 min con OAuth 2.0<br /><br />15 solicitudes por 15 min con Solo App |

Para acceder a los endpoints de X API v2, debes [registrarte para obtener una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info). Al autenticarte, debes usar claves y tokens de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que se encuentra dentro de un [Project](/es/resources/fundamentals/developer-apps).

Obtén más información sobre cómo acceder a los endpoints de X API v2 en nuestra página de [primeros pasos](/es/x-api/getting-started/getting-access).
