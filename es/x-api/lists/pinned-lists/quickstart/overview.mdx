Los endpoints de Listas fijadas te permiten consultar las Listas fijadas de un usuario y administrar qué Listas están fijadas.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una aplicación aprobada
  * Un token de acceso de usuario (OAuth 1.0a o OAuth 2.0 PKCE)
</Note>

<div id="authentication">
  ## Autenticación
</div>

| Operación | Autenticación |
|:----------|:---------------|
| Consultar listas fijadas | OAuth 1.0a o OAuth 2.0 PKCE |
| Fijar/desfijar listas | OAuth 1.0a o OAuth 2.0 PKCE |

<Warning>
  Tanto las operaciones de consulta como de gestión requieren autenticación con contexto de usuario. La autenticación solo de aplicación (Bearer Token) no se admite.
</Warning>

<div id="quick-example">
  ## Ejemplo rápido
</div>

<CodeGroup dropdown>
  ```bash cURL
  # Obtener listas fijadas
  curl "https://api.x.com/2/users/2244994945/pinned_lists" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Obtener listas fijadas
  response = client.lists.get_pinned("2244994945")

  for lst in response.data:
      print(f"{lst.name}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Obtener listas fijadas
  const response = await client.lists.getPinned("2244994945");

  response.data?.forEach((lst) => {
    console.log(lst.name);
  });
  ```
</CodeGroup>
