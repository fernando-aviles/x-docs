Esta guía te muestra cómo obtener las Listas fijadas de un usuario.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una aplicación aprobada
  * Un token de acceso de usuario (OAuth 1.0a o OAuth 2.0 PKCE)
</Note>

***

<div id="get-pinned-lists">
  ## Obtener listas fijadas
</div>

<Steps>
  <Step title="Obtener tu ID de usuario">
    Necesitas el ID de tu usuario autenticado. Puedes encontrarlo usando el [endpoint de búsqueda de usuarios](/es/x-api/users/lookup/introduction) o a partir de tu token de acceso (la parte numérica es tu ID de usuario).
  </Step>

  <Step title="Solicitar listas fijadas">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/users/2244994945/pinned_lists?\
      list.fields=follower_count,member_count,owner_id&\
      expansions=owner_id&\
      user.fields=created_at,username" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Obtener listas fijadas
      response = client.lists.get_pinned(
          "2244994945",
          list_fields=["follower_count", "member_count", "owner_id"],
          expansions=["owner_id"],
          user_fields=["created_at", "username"]
      )

      for lst in response.data:
          print(f"{lst.name} - {lst.follower_count} followers")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Obtener listas fijadas
      const response = await client.lists.getPinned("2244994945", {
        listFields: ["follower_count", "member_count", "owner_id"],
        expansions: ["owner_id"],
        userFields: ["created_at", "username"],
      });

      response.data?.forEach((lst) => {
        console.log(`${lst.name} - ${lst.follower_count} followers`);
      });
      ```
    </CodeGroup>
  </Step>

  <Step title="Revisar la respuesta">

  </Step>
</Steps>

<div id="available-list-fields">
  ## Campos disponibles de listas
</div>

| Campo | Descripción |
|:------|:------------|
| `description` | Descripción de la lista |
| `owner_id` | ID de usuario del propietario |
| `private` | Indica si la lista es privada |
| `member_count` | Número de miembros |
| `follower_count` | Número de seguidores |
| `created_at` | Fecha de creación de la lista |
