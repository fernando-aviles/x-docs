Los endpoints de Pinned Lists te permiten ver, anclar y desanclar listas para el usuario autenticado. Las Pinned Lists se muestran de forma destacada en la interfaz de X del usuario.

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/pinned_lists`](/es/x-api/users/get-pinned-lists) | Obtener listas fijadas |
| POST | [`/2/users/:id/pinned_lists`](/es/x-api/users/pin-list) | Fijar una lista |
| DELETE | [`/2/users/:id/pinned_lists/:list_id`](/es/x-api/users/unpin-list) | Desfijar una lista |

***

<div id="example-get-pinned-lists">
  ## Ejemplo: Obtener listas fijadas
</div>

```bash
curl "https://api.x.com/2/users/123456789/pinned_lists?\
list.fields=name,description,member_count" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-pin-a-list">
  ## Ejemplo: Fijar una lista
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"list_id": "9876543210"}'
```
