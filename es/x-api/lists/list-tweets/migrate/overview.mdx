  ## Comparación de los endpoints de consulta de Publicaciones de listas de X API
</div>

El endpoint de consulta de Publicaciones de listas de la v2 reemplazará el endpoint estándar v1.1 [GET lists/statuses](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-statuses). Si tiene código, aplicaciones o herramientas que usan esta versión del endpoint y está considerando migrar al endpoint más reciente de X API v2, entonces este conjunto de guías es para usted.

Las siguientes tablas comparan los endpoints estándar de listas de v1.1 y de X API v2:

**Consulta de lista por ID**

|     |     |     |
| :--- | :--- | :--- |
| Descripción | v1.1 estándar | X API v2 |
| Métodos HTTP compatibles | `GET` | `GET` |
| Dominio de host | `https://api.x.com` | `https://api.x.com` |
| Ruta del endpoint | `/1.1/lists/statuses.json` | `/2/lists/:id/tweets` |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />Solo App | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />Solo App |
| [Límites de frecuencia](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | 900 solicitudes cada 15 min con OAuth 1.0a<br /><br />900 solicitudes cada 15 min con Solo App | 900 solicitudes cada 15 min con OAuth 1.0a<br /><br />900 solicitudes cada 15 min con OAuth 2.0<br /><br />900 solicitudes cada 15 min con Solo App |

Para acceder a los endpoints de X API v2, debe [registrarse para obtener una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info). Al autenticarse, debe usar las claves y los tokens de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que se encuentre dentro de un [Project](/es/resources/fundamentals/developer-apps). 

Obtenga más información sobre cómo obtener acceso a los endpoints de X API v2 en nuestra página de [introducción](/es/x-api/getting-started/getting-access).
