  ## Comparación de los endpoints de consulta de Publicaciones de listas de X API
</div>

El endpoint de consulta de Publicaciones de listas de v2 reemplazará el endpoint estándar v1.1 [GET lists/statuses](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-statuses). Si tienes código, apps o herramientas que usan esta versión del endpoint y estás considerando migrar al nuevo endpoint de X API v2, entonces esta serie de guías es para ti.

Las siguientes tablas comparan los endpoints estándar de listas de v1.1 y X API v2:

**Búsqueda de lista por ID**

|     |     |     |
| :--- | :--- | :--- |
| Descripción | Estándar v1.1 | X API v2 |
| Métodos HTTP admitidos | `GET` | `GET` |
| Dominio del host | `https://api.x.com` | `https://api.x.com` |
| Ruta del endpoint | `/1.1/lists/statuses.json` | `/2/lists/:id/tweets` |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />Solo App | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />Solo App |
| Límites de frecuencia de solicitudes predeterminados ([rate limits](/es/resources/fundamentals/rate-limits)) | 900 solicitudes por 15 min con OAuth 1.0a<br /><br />900 solicitudes por 15 min con Solo App | 900 solicitudes por 15 min con OAuth 1.0a<br /><br />900 solicitudes por 15 min con OAuth 2.0<br /><br />900 solicitudes por 15 min con Solo App |

Para acceder a los endpoints de X API v2, debes [registrarte para obtener una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info). Al autenticarte, debes usar las claves y los tokens de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que esté ubicada dentro de un [Project](/es/resources/fundamentals/developer-apps). 

Obtén más información sobre cómo obtener acceso a los endpoints de X API v2 en nuestra página de [primeros pasos](/es/x-api/getting-started/getting-access).
