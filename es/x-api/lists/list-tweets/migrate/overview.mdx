  ## Comparación de los endpoints de consulta de Publicaciones de Listas de X API
</div>

El endpoint de consulta de Publicaciones de Listas de la v2 reemplazará el endpoint estándar de la v1.1 [GET lists/statuses](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-statuses). Si tienes código, apps o herramientas que usan esta versión del endpoint y estás considerando migrar al endpoint más reciente de X API v2, entonces este conjunto de guías es para ti.

Las siguientes tablas comparan los endpoints estándar de la v1.1 y de X API v2 para Listas:

**Búsqueda de Lista por ID**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| HTTP methods supported | `GET` | `GET` |
| Host domain | `https://api.x.com` | `https://api.x.com` |
| Endpoint path | `/1.1/lists/statuses.json` | `/2/lists/:id/tweets` |
| [Authentication](/es/resources/fundamentals/authentication) | OAuth 1.0a contexto de usuario<br /><br />Solo App | OAuth 1.0a contexto de usuario<br /><br />OAuth 2.0 Authorization Code con PKCE<br /><br />Solo App |
| Default request [rate limits](/es/resources/fundamentals/rate-limits) | 900 solicitudes cada 15 min con OAuth 1.0a<br /><br />900 solicitudes cada 15 min con Solo App | 900 solicitudes cada 15 min con OAuth 1.0a<br /><br />900 solicitudes cada 15 min con OAuth 2.0<br /><br />900 solicitudes cada 15 min con Solo App |

Para acceder a los endpoints de X API v2, debes [registrarte para obtener una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info). Al autenticarte, debes usar las claves y tokens de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que se encuentra dentro de un [Proyecto](/es/resources/fundamentals/developer-apps).

Obtén más información sobre cómo conseguir acceso a los endpoints de X API v2 en nuestra página de [primeros pasos](/es/x-api/getting-started/getting-access).
