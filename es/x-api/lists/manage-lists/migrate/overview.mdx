<div id="comparing-x-apis-lists-endpoints">
  ## Comparación de los endpoints de Listas de X API
</div>

Los endpoints de administración de Listas de la v2 acabarán reemplazando [POST lists/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-create), [POST lists/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-destroy) y [POST lists/update](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-update). Si tienes código, aplicaciones o herramientas que usan una versión anterior de estos endpoints y estás considerando migrar a la nueva X API v2, esta guía es para ti.

Las siguientes tablas comparan los endpoints de List de la v1.1 estándar y de X API v2:

**Crear una Lista**

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP compatibles | POST | POST |
| Dominio host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/lists/create.json | /2/lists |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Límites de frecuencia](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | Ninguno | 300 solicitudes por 15 min (por usuario) |

**Eliminar una Lista**

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP compatibles | POST | DELETE |
| Dominio host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/lists/destroy.json | /2/lists/:id |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Límites de frecuencia](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | Ninguno | 300 solicitudes por 15 min (por usuario) |

**Actualizar una Lista**

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP compatibles | POST | PUT |
| Dominio host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/lists/update.json | /2/lists/:id |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Límites de frecuencia](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | Ninguno | 300 solicitudes por 15 min (por usuario) |

Para acceder a los endpoints de X API v2, debes [registrarte para obtener una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info). Al autenticarte, debes usar claves y tokens de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que se encuentra dentro de un [Project](/es/resources/fundamentals/developer-apps).

Obtén más información sobre cómo acceder a los endpoints de X API v2 en nuestra página de [primeros pasos](/es/x-api/getting-started/getting-access).
