Los endpoints de administración de listas te permiten crear, actualizar y eliminar listas en nombre de los usuarios autenticados.

<div id="overview">
  ## Descripción general
</div>

<CardGroup cols={2}>
  <Card title="Crear" icon="plus">
    Crea una nueva Lista
  </Card>

  <Card title="Actualizar" icon="pen">
    Actualiza el nombre y la descripción de la Lista
  </Card>

  <Card title="Eliminar" icon="trash">
    Elimina una Lista
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | [`/2/lists`](/es/x-api/lists/create-list) | Crear una lista nueva |
| PUT | [`/2/lists/:id`](/es/x-api/lists/update-list) | Actualizar una lista |
| DELETE | [`/2/lists/:id`](/es/x-api/lists/delete-list) | Eliminar una lista |

***

<div id="example-create-a-list">
  ## Ejemplo: Crear una lista
</div>

```bash
curl -X POST "https://api.x.com/2/lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech News",
    "description": "My favorite tech journalists",
    "private": false
  }'
```

<div id="example-response">
  ## Ejemplo de respuesta
</div>

```json
{
  "data": {
    "id": "1234567890",
    "name": "Tech News"
  }
}
```
