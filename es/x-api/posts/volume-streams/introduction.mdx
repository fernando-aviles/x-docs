* Flujo muestreado al 1%.
* Flujo muestreado al 10%. Comúnmente denominado &quot;Decahose&quot;.

Se denominan &quot;flujos de volumen&quot; porque ambos entregan grandes volúmenes de datos. Incluso el flujo del 1% puede emitir muchas docenas de Publicaciones cada segundo. Con estos flujos puedes identificar y hacer seguimiento de tendencias, monitorear el sentimiento general, monitorear eventos globales y mucho más. 

Estos endpoints de streaming entregan [objetos de Publicación](/es/x-api/fundamentals/data-dictionary#tweet) mediante una conexión HTTP GET persistente y usan autenticación [OAuth 2.0 App-Only](/es/resources/fundamentals/authentication#oauth-2-0). Con acceso Essential, puedes tener una conexión a la vez. Con todos los niveles de acceso, se pueden realizar solicitudes de conexión hasta 50 veces por ventana de 15 minutos.

Estos endpoints de flujos de volumen admiten Publicaciones editadas. Estos endpoints entregarán Publicaciones editadas, junto con su historial de ediciones, incluido un array de IDs de Publicación. Para las Publicaciones sin historial de ediciones, este array contendrá un solo ID. Para las Publicaciones que se han editado, este array contiene múltiples IDs, ordenados en forma ascendente que refleja el orden de las ediciones, con la versión más reciente en la última posición del array. Para obtener más información sobre cómo funcionan las ediciones de Publicaciones, consulta la página de [fundamentos de las ediciones de Publicaciones](/es/x-api/fundamentals/edit-posts). 

*Para usar estas APIs, primero debes configurar una cuenta con nuestro equipo de ventas para empresas.*

<Note>
  **Configuración de la cuenta**

  Para acceder a estos endpoints, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) aprobada.
  * Autenticarte usando las claves y tokens de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que se encuentre dentro de un [Project](/es/resources/fundamentals/developer-apps). 

  Obtén más información sobre cómo obtener acceso a los endpoints de X API v2 en nuestra [guía de introducción](/es/x-api/getting-started/getting-access).
</Note>
