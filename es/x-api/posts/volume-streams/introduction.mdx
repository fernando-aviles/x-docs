* Flujo muestreado del 1%.
* Flujo muestreado del 10%. Comúnmente denominado «Decahose».

A estos se les conoce como «flujos de volumen» porque ambos entregan grandes volúmenes de datos. Incluso el flujo del 1% puede emitir muchas docenas de Publicaciones cada segundo. Con estos flujos, puedes identificar y seguir tendencias, monitorear el sentimiento general, supervisar eventos globales y mucho más. 

Estos endpoints de streaming entregan [objetos Post](/es/x-api/fundamentals/data-dictionary#tweet) a través de una conexión HTTP GET persistente y usan autenticación [OAuth 2.0 App-Only](/es/resources/fundamentals/authentication#oauth-2-0). Con acceso Essential, puedes tener una conexión a la vez. Con todos los niveles de acceso, puedes realizar solicitudes de conexión hasta 50 veces por ventana de 15 minutos.

Estos endpoints de flujos de volumen admiten Publicaciones editadas. Estos endpoints entregarán Publicaciones editadas junto con su historial de ediciones, incluido un array de ids de Publicación. Para Publicaciones sin historial de ediciones, este array contendrá un único id. Para Publicaciones que han sido editadas, este array contiene varios ids, ordenados en forma ascendente que refleja el orden de las ediciones, con la versión más reciente en la última posición del array. Para obtener más información sobre cómo funcionan las ediciones de Publicaciones, consulta la página [Fundamentos de las ediciones de Publicaciones](/es/x-api/fundamentals/edit-posts). 

*Para usar estas API, primero debes configurar una cuenta con nuestro equipo de ventas para empresas.*

<Note>
  **Configuración de la cuenta**

  Para acceder a estos endpoints, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) aprobada.
  * Autenticarte usando las claves y tokens de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que se encuentre dentro de un [Project](/es/resources/fundamentals/developer-apps). 

  Obtén más información sobre cómo acceder a los endpoints de X API v2 en nuestra [guía de primeros pasos](/es/x-api/getting-started/getting-access).
</Note>
