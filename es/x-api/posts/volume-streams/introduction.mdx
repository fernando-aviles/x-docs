* Flujo muestreado del 1%.
* Flujo muestreado del 10%. Comúnmente conocido como el «Decahose».

Se conocen como «flujos de volumen» porque ambos entregan grandes volúmenes de datos. Incluso el flujo del 1% puede emitir muchas docenas de Publicaciones cada segundo. Con estos flujos, puedes identificar y seguir tendencias, monitorear el sentimiento general, monitorear eventos globales y mucho más. 

Estos endpoints de streaming entregan [objetos Post](/es/x-api/fundamentals/data-dictionary#tweet) a través de una conexión HTTP GET persistente y usan autenticación [OAuth 2.0 App-Only](/es/resources/fundamentals/authentication#oauth-2-0). Con el acceso Essential, puedes tener una conexión a la vez. Con todos los niveles de acceso, se pueden realizar solicitudes de conexión hasta 50 veces por intervalos de 15 minutos.

Estos endpoints de flujos de volumen son compatibles con Publicaciones editadas. Estos endpoints entregarán Publicaciones editadas, junto con su historial de ediciones, incluido un array de IDs de Publicación. Para Publicaciones sin historial de ediciones, este array contendrá una sola ID. Para Publicaciones que se han editado, este array contiene múltiples IDs, ordenadas de forma ascendente que refleja el orden de las ediciones, con la versión más reciente en la última posición del array. Para obtener más información sobre cómo funcionan las ediciones de Publicaciones, consulta la página [Fundamentos de las ediciones de Publicaciones](/es/x-api/fundamentals/edit-posts). 

*Para usar estas APIs, primero debes configurar una cuenta con nuestro equipo de ventas para empresas.*

<Note>
  **Configuración de la cuenta**

  Para acceder a estos endpoints, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) aprobada.
  * Autenticarte usando las claves y los tokens de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que se encuentra dentro de un [Project](/es/resources/fundamentals/developer-apps). 

  Obtén más información sobre cómo obtener acceso a los endpoints de X API v2 en nuestra [guía de primeros pasos](/es/x-api/getting-started/getting-access).
</Note>
