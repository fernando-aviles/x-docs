Esta guía te explica cómo agregar y eliminar marcadores con la X API.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * Un token de acceso de usuario con el alcance `bookmark.write` (OAuth 2.0 PKCE)
</Note>

***

<div id="add-a-bookmark">
  ## Añadir un marcador
</div>

<Steps>
  <Step title="Obtén tu id de usuario">
    Necesitas el id de tu usuario autenticado. Puedes encontrarlo usando el endpoint `/2/users/me` o el [endpoint de consulta de usuarios](/es/x-api/users/lookup/introduction).
  </Step>

  <Step title="Obtén el id de la Publicación">
    Encuentra el id de la Publicación en la URL cuando estés viendo una Publicación:

    ```
    https://x.com/XDevelopers/status/1460323737035677698
                                    └── Este es el id de la Publicación
    ```
  </Step>

  <Step title="Añade el marcador">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/users/2244994945/bookmarks" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"tweet_id": "1460323737035677698"}'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Añadir un marcador
      response = client.bookmarks.create(
          user_id="2244994945",
          tweet_id="1460323737035677698"
      )

      print(f"Bookmarked: {response.data.bookmarked}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Añadir un marcador
      const response = await client.bookmarks.create("2244994945", {
        tweetId: "1460323737035677698",
      });

      console.log(`Bookmarked: ${response.data?.bookmarked}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Revisa la respuesta">
    ```json
    {
      "data": {
        "bookmarked": true
      }
    }
    ```
  </Step>
</Steps>

***

<div id="remove-a-bookmark">
  ## Eliminar un marcador
</div>

Elimina una Publicación de tus marcadores:

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/2244994945/bookmarks/1460323737035677698" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Eliminar un marcador
  response = client.bookmarks.delete(
      user_id="2244994945",
      tweet_id="1460323737035677698"
  )

  print(f"Marcado: {response.data.bookmarked}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Eliminar un marcador
  const response = await client.bookmarks.delete("2244994945", "1460323737035677698");

  console.log(`Marcado: ${response.data?.bookmarked}`);
  ```
</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "bookmarked": false
  }
}
```

***

<div id="required-scopes">
  ## Ámbitos requeridos
</div>

Cuando uses OAuth 2.0 PKCE, tu token de acceso debe tener estos ámbitos:

| Ámbito | Descripción |
|:------|:------------|
| `bookmark.write` | Agregar y eliminar marcadores |
| `tweet.read` | Leer datos de Publicaciones |
| `users.read` | Leer datos de usuario |
