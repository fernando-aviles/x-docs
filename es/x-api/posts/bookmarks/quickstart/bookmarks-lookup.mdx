Esta guía te muestra cómo recuperar las Publicaciones que has guardado en marcadores mediante X API.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * Un token de acceso de usuario con el alcance `bookmark.read` (OAuth 2.0 PKCE)
</Note>

***

<div id="get-your-bookmarks">
  ## Obtén tus marcadores
</div>

<Steps>
  <Step title="Obtén tu id de usuario">
    Necesitas el id de tu usuario autenticado. Puedes obtenerlo usando el endpoint `/2/users/me` o desde el [endpoint de búsqueda de usuarios](/es/x-api/users/lookup/introduction).
  </Step>

  <Step title="Solicita tus marcadores">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/users/2244994945/bookmarks?\
      tweet.fields=created_at,public_metrics,author_id&\
      max_results=10" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Obtén publicaciones guardadas en marcadores con paginación
      for page in client.bookmarks.get(
          "2244994945",
          tweet_fields=["created_at", "public_metrics", "author_id"],
          max_results=10
      ):
          for post in page.data:
              print(f"{post.text[:50]}... - Likes: {post.public_metrics.like_count}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Obtén publicaciones guardadas en marcadores con paginación
      const paginator = client.bookmarks.get("2244994945", {
        tweetFields: ["created_at", "public_metrics", "author_id"],
        maxResults: 10,
      });

      for await (const page of paginator) {
        page.data?.forEach((post) => {
          console.log(`${post.text?.slice(0, 50)}... - Likes: ${post.public_metrics?.like_count}`);
        });
      }
      ```
    </CodeGroup>
  </Step>

<div id="include-author-information">
  ## Incluir información del autor
</div>

Usa el parámetro expansions para obtener datos sobre los autores de las publicaciones:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/2244994945/bookmarks?\
  tweet.fields=created_at,author_id&\
  expansions=author_id&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Obtener marcadores con información del autor
  for page in client.bookmarks.get(
      "2244994945",
      tweet_fields=["created_at", "author_id"],
      expansions=["author_id"],
      user_fields=["username", "verified"]
  ):
      for post in page.data:
          print(f"{post.text[:50]}...")
      # La información del autor está en page.includes.users
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Obtener marcadores con información del autor
  const paginator = client.bookmarks.get("2244994945", {
    tweetFields: ["created_at", "author_id"],
    expansions: ["author_id"],
    userFields: ["username", "verified"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text?.slice(0, 50)}...`);
    });
    // La información del autor está en page.includes?.users
  }
  ```
</CodeGroup>

<div id="required-scopes">
  ## Scopes obligatorios
</div>

Cuando uses OAuth 2.0 PKCE, tu token de acceso debe tener estos scopes:

| Scope | Descripción |
|:------|:------------|
| `bookmark.read` | Leer marcadores |
| `tweet.read` | Leer datos de publicaciones |
| `users.read` | Leer datos de usuarios (para expansions) |
