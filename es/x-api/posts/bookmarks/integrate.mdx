<div id="authentication">
  #### Autenticación
</div>

Todos los endpoints de X API v2 requieren que autentiques tus solicitudes con un conjunto de credenciales, también conocidas como claves y tokens.

Estos endpoints en particular requieren el uso de [OAuth 2.0 Authorization Code Flow with PKCE](/es/resources/fundamentals/authentication/oauth-2-0/authorization-code), lo que significa que debes usar un conjunto de claves y Access Tokens de usuario para realizar una solicitud exitosa. Los Access Tokens deben estar asociados con el usuario en cuyo nombre estás realizando la solicitud. Si quieres generar un conjunto de Access Tokens para otro usuario, esa persona debe autorizar tu App o autenticarse en ella utilizando una [Authorize URL](/es/resources/fundamentals/authentication#authorize-url).

Ten en cuenta que OAuth 2.0 puede ser complicado de usar. Si no estás familiarizado con este método de autenticación, te recomendamos usar una [librería](/es/x-api/tools-and-libraries/overview) o una herramienta como Postman para autenticar tus solicitudes correctamente.

<div id="developer-console-projects-and-developer-apps">
  #### Consola de desarrollador, Proyectos y Apps de desarrollador
</div>

Para obtener un conjunto de credenciales de autenticación que funcionen con los endpoints de X API v2, debes tener una [cuenta de desarrollador](/es/resources/fundamentals/developer-portal), haber configurado un [Proyecto](/es/resources/fundamentals/developer-apps) dentro de esa cuenta y haber creado una [App de desarrollador](/es/resources/fundamentals/developer-apps) dentro de ese Proyecto. Luego podrás encontrar tus claves y tokens dentro de tu App de desarrollador.

<div id="rate-limits">
  #### Límites de tasa
</div>

Cada día, muchos miles de desarrolladores realizan solicitudes a la X API. Para ayudar a gestionar el enorme volumen de estas solicitudes, se aplican [límites de tasa](/es/resources/fundamentals/rate-limits) a cada endpoint, que limitan la cantidad de solicitudes que puedes hacer en nombre de tu App o en nombre de un usuario autenticado.

Estos endpoints tienen límites de tasa a nivel de usuario, lo que significa que el usuario autenticado en cuyo nombre estás realizando la solicitud solo puede llamar al endpoint un número determinado de veces desde cualquier App de desarrollador. Existe un límite de tasa por usuario de 180 solicitudes por ventana de 15 minutos para el método GET. Con el método GET del endpoint Bookmarks lookup obtendrás 800 de tus Publicaciones más recientes en Marcadores. Además, existe un límite de tasa por usuario de 50 solicitudes por ventana de 15 minutos para los métodos POST y DELETE.

<div id="get-bookmarks">
  #### Obtener marcadores
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123/bookmarks?tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Obtener los marcadores del usuario
  for page in client.bookmarks.get(user_id="123", tweet_fields=["created_at", "public_metrics"]):
      for post in page.data:
          print(f"{post.text} - Likes: {post.public_metrics.like_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Obtener los marcadores del usuario
  const paginator = client.bookmarks.get("123", {
    tweetFields: ["created_at", "public_metrics"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text} - Likes: ${post.public_metrics?.like_count}`);
    });
  }
  ```
</CodeGroup>

<div id="create-a-bookmark">
  #### Crear un marcador
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/bookmarks" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Guardar una Publicación en marcadores
  response = client.bookmarks.create(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Guardar una Publicación en marcadores
  const response = await client.bookmarks.create("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
