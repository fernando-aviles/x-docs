Los endpoints de Bookmarks te permiten ver, añadir y eliminar las Publicaciones marcadas del usuario autenticado. Los marcadores son privados y solo son visibles para el usuario que los creó.

<div id="endpoints">
  ## Endpoints
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/bookmarks`](/es/x-api/users/get-bookmarks) | Obtener los marcadores de un usuario |
| POST | [`/2/users/:id/bookmarks`](/es/x-api/users/create-bookmark) | Añadir una Publicación a marcadores |
| DELETE | [`/2/users/:id/bookmarks/:tweet_id`](/es/x-api/users/delete-bookmark) | Eliminar un marcador |
| GET | [`/2/users/:id/bookmarks/folders`](/es/x-api/users/get-bookmark-folders) | Obtener las carpetas de marcadores |
| GET | [`/2/users/:id/bookmarks/folders/:folder_id`](/es/x-api/users/get-bookmarks-by-folder-id) | Obtener las Publicaciones de una carpeta |

***

<div id="example-get-bookmarks">
  ## Ejemplo: obtener marcadores
</div>

```bash
curl "https://api.x.com/2/users/123456789/bookmarks?\
tweet.fields=created_at,author_id,public_metrics" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-add-bookmark">
  ## Ejemplo: Añadir marcador
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
