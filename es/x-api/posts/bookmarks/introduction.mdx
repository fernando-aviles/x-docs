Los endpoints de Bookmarks te permiten ver, agregar y eliminar Publicaciones marcadas para el usuario autenticado. Los Bookmarks son privados y solo los puede ver el usuario que los creó.

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/bookmarks`](/es/x-api/users/get-bookmarks) | Obtener los marcadores del usuario |
| POST | [`/2/users/:id/bookmarks`](/es/x-api/users/create-bookmark) | Marcar una Publicación |
| DELETE | [`/2/users/:id/bookmarks/:tweet_id`](/es/x-api/users/delete-bookmark) | Eliminar un marcador |
| GET | [`/2/users/:id/bookmarks/folders`](/es/x-api/users/get-bookmark-folders) | Obtener carpetas de marcadores |
| GET | [`/2/users/:id/bookmarks/folders/:folder_id`](/es/x-api/users/get-bookmarks-by-folder-id) | Obtener las Publicaciones de una carpeta |

***

<div id="example-get-bookmarks">
  ## Ejemplo: Obtener marcadores
</div>

```bash
curl "https://api.x.com/2/users/123456789/bookmarks?\
tweet.fields=created_at,author_id,public_metrics" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-add-bookmark">
  ## Ejemplo: Añadir marcador
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
