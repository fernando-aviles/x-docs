<div id="comparing-x-apis-timelines-endpoints">
  ## Comparación de los endpoints de cronologías de X API
</div>

Los endpoints de cronología en orden cronológico inverso de v2, cronología de Publicaciones de usuario y cronología de menciones de usuario reemplazan respectivamente los endpoints [v1.1 statuses/home&#95;timeine,](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-home_timeline) [v1.1 statuses/user&#95;timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-user_timeline.html) y [v1.1 statuses/mentions&#95;timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-mentions_timeline.html). Si tienes código, aplicaciones o herramientas que usan una versión anterior de este endpoint y estás considerando migrar al nuevo endpoint de X API v2, esta guía es para ti. Para una guía de migración más detallada, consulta [Migración de Standard v1.1 a X API v2](/es/x-api/posts/timelines/migrate/standard-to-twitter-api-v2).

Esta página contiene tres tablas comparativas:

* Cronología de inicio en orden cronológico inverso
* Cronología de Publicaciones de usuario
* Cronología de menciones de usuario
