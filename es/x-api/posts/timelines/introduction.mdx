<div id="endpoints">
  ## Endpoints
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/es/x-api/users/get-posts) | Obtener las Publicaciones de un usuario |
| GET | [`/2/users/:id/mentions`](/es/x-api/users/get-mentions) | Obtener las Publicaciones que mencionan a un usuario |

<div id="reverse-chronological-home-timeline">
  ## Cronología de inicio en orden cronológico inverso
</div>

Recupera la cronología de inicio del usuario autenticado en orden cronológico inverso.

### Características

* Publicaciones de cuentas seguidas
* 3.200 publicaciones más recientes (o 7 días)
* Excluye la clasificación algorítmica
* Requiere autenticación de usuario

<Note>
  Este endpoint requiere [OAuth 1.0a User Context](/es/resources/fundamentals/authentication) o [OAuth 2.0 Authorization Code with PKCE](/es/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2).
</Note>

<div id="filtering-options">
  ## Opciones de filtrado
</div>

<div id="exclude-parameter">
  ### Parámetro exclude
</div>

Filtra tipos específicos de Publicaciones:

| Value      | Effect             |
| :--------- | :----------------- |
| `retweets` | Excluir retweets   |
| `replies`  | Excluir respuestas |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="time-based-filtering">
  ### Filtrado por tiempo
</div>

| Parámetro | Descripción |
|:----------|:------------|
| `start_time` | Marca de tiempo de la Publicación más antigua (ISO 8601) |
| `end_time` | Marca de tiempo de la Publicación más reciente (ISO 8601) |
| `since_id` | Devuelve Publicaciones posteriores a este id |
| `until_id` | Devuelve Publicaciones anteriores a este id |
