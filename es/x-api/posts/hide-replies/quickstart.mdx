Esta guía te muestra cómo ocultar y volver a mostrar respuestas a Publicaciones en conversaciones que iniciaste.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * Un token de acceso de usuario (OAuth 1.0a o OAuth 2.0 PKCE)
</Note>

***

<div id="hide-a-reply">
  ## Ocultar una respuesta
</div>

<Steps>
  <Step title="Busca el ID de la Publicación de la respuesta" icon="message">
    Obtén el ID de la respuesta que quieres ocultar. Solo puedes ocultar respuestas a conversaciones iniciadas por el usuario autenticado.

    ```
    https://x.com/user/status/1232720193182412800
                              └── Este es el ID de la Publicación
    ```
  </Step>

  <Step title="Envía la solicitud para ocultar la respuesta" icon="eye-slash">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X PUT "https://api.x.com/2/tweets/1232720193182412800/hidden" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"hidden": true}'
      ```

      ```python Python SDK
      from xdk import Client
      from xdk.oauth1_auth import OAuth1

      oauth1 = OAuth1(
          api_key="YOUR_API_KEY",
          api_secret="YOUR_API_SECRET",
          access_token="YOUR_ACCESS_TOKEN",
          access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
      )

      client = Client(auth=oauth1)

      # Ocultar una respuesta
      response = client.posts.hide_reply("1232720193182412800", hidden=True)
      print(f"Hidden: {response.data.hidden}")
      ```

      ```javascript JavaScript SDK
      import { Client, OAuth1 } from "@xdevplatform/xdk";

      const oauth1 = new OAuth1({
        apiKey: "YOUR_API_KEY",
        apiSecret: "YOUR_API_SECRET",
        accessToken: "YOUR_ACCESS_TOKEN",
        accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
      });

      const client = new Client({ oauth1 });

      // Ocultar una respuesta
      const response = await client.posts.hideReply("1232720193182412800", {
        hidden: true,
      });
      console.log(`Hidden: ${response.data?.hidden}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Confirma que la respuesta está oculta" icon="check">
    ```json
    {
      "data": {
        "hidden": true
      }
    }
    ```

    La respuesta ahora está oculta en la vista principal de la conversación. Los usuarios todavía pueden verla haciendo clic en &quot;Ver respuestas ocultas&quot;.
  </Step>
</Steps>

***

<div id="unhide-a-reply">
  ## Volver a mostrar una respuesta
</div>

Para que una respuesta oculta vuelva a ser visible:

<CodeGroup dropdown>
  ```bash cURL
  curl -X PUT "https://api.x.com/2/tweets/1232720193182412800/hidden" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"hidden": false}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Volver a mostrar una respuesta
  response = client.posts.hide_reply("1232720193182412800", hidden=False)
  print(f"Hidden: {response.data.hidden}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Volver a mostrar una respuesta
  const response = await client.posts.hideReply("1232720193182412800", {
    hidden: false,
  });
  console.log(`Hidden: ${response.data?.hidden}`);
  ```
</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "hidden": false
  }
}
```

***

<div id="important-notes">
  ## Notas importantes
</div>

<Note>
  * Solo puedes ocultar respuestas a conversaciones **que tú iniciaste**
  * Las respuestas ocultas siguen siendo visibles a través de &quot;Ver respuestas ocultas&quot;
  * El autor de la respuesta no recibe ninguna notificación cuando se oculta su respuesta
</Note>
