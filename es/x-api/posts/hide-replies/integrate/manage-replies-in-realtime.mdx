<div id="manage-replies-in-realtime">
  ### Gestionar las respuestas en tiempo real
</div>

Con el endpoint hide replies, puedes crear un flujo de trabajo que ayude a tus usuarios a ocultar respuestas que tengan una probabilidad muy alta de ser irrelevantes.

Las aplicaciones útiles suelen combinar tecnologías para aportar valor a sus usuarios. Esta página muestra cómo ocultar respuestas usando la [Perspective API](https://www.perspectiveapi.com/). Esta API es una inteligencia artificial entrenada por [Jigsaw](https://jigsaw.google.com/), una unidad de Google, para detectar comentarios tóxicos. La lógica de la aplicación funcionará de la siguiente manera:

1.  Pide permiso al usuario para leer sus Publicaciones y ocultar o dejar de ocultar sus respuestas.
2.  Utiliza la [Account Activity API](https://developer.x.com/en/docs/x-api/v1/accounts-and-users/subscribe-account-activity/overview) para detectar las respuestas entrantes.
3.  Pide a la Perspective API que proporcione una “puntuación” (un número entre 0 y 1) que indique el grado de confianza de su algoritmo en que un comentario es similar a comentarios tóxicos que ha visto en el pasado. (Perspective no almacena el texto enviado al servicio).
4.  Invoca hide replies si la puntuación del algoritmo es muy alta.

<div id="strive-for-transparency">
  #### Procura la transparencia
</div>

Debido a que Perspective no está entrenado con Publicaciones reales, ciertos matices del lenguaje pueden hacer que esta app oculte una respuesta que la persona usuaria quiere mantener visible. Independientemente de la tecnología o el enfoque que uses al diseñar tu app, haz siempre todo lo posible para asegurarte de que tus usuarios entienden qué ha ocultado tu app y que pueden hacer cambios.

* La mejor opción es confiar siempre en la persona usuaria y darle control total sobre sus decisiones. Esto significa que tu experiencia de usuario debe incluir controles para deshacer cualquier acción que tu app lleve a cabo en nombre del usuario.
* Cuando uses una inteligencia artificial, tu app debe utilizar un umbral de confianza muy alto para detectar y ocultar Publicaciones.
* No todo el mundo usa las mismas palabras, y tu app debe estar diseñada para evitar cualquier sesgo. Ten en cuenta las palabras reapropiadas y la jerga que pueden provocar falsos positivos.
* Si estás entrenando una inteligencia artificial, considera adoptar un modelo que refleje de forma cercana el lenguaje que se usa con frecuencia en X.
