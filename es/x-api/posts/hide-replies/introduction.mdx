El endpoint Hide Replies te permite ocultar o volver a mostrar las respuestas a Publicaciones creadas por el usuario autenticado. Las respuestas ocultas siguen siendo accesibles, pero requieren un clic adicional para poder verse.

<div id="endpoint">
  ## Endpoint
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| PUT | [`/2/tweets/:tweet_id/hidden`](/es/x-api/posts/hide-reply) | Ocultar o dejar de ocultar una respuesta |

***

<div id="how-it-works">
  ## Cómo funciona
</div>

Envía una solicitud PUT con `hidden: true` para ocultar una respuesta, o `hidden: false` para mostrarla de nuevo:

```json
{
  "hidden": true
}
```

***

<div id="example-hide-a-reply">
  ## Ejemplo: Ocultar una respuesta
</div>

```bash
curl -X PUT "https://api.x.com/2/tweets/1234567890/hidden" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"hidden": true}'
```

<div id="example-response">
  ## Ejemplo de respuesta
</div>

```json
{
  "data": {
    "hidden": true
  }
}
```
