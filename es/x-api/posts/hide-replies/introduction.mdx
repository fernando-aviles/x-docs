El endpoint Hide Replies permite ocultar o volver a mostrar respuestas a Publicaciones del usuario autenticado. Las respuestas ocultas siguen siendo accesibles, pero requieren un clic adicional para poder verlas.

<div id="endpoint">
  ## Endpoint
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| PUT | [`/2/tweets/:tweet_id/hidden`](/es/x-api/posts/hide-reply) | Ocultar o dejar de ocultar una respuesta |

***

<div id="how-it-works">
  ## Cómo funciona
</div>

Envía una solicitud PUT con `hidden: true` para ocultar una respuesta, o `hidden: false` para volver a mostrarla:

```json
{
  "hidden": true
}
```

***

<div id="example-hide-a-reply">
  ## Ejemplo: ocultar una respuesta
</div>

```bash
curl -X PUT "https://api.x.com/2/tweets/1234567890/hidden" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"hidden": true}'
```

<div id="example-response">
  ## Ejemplo de respuesta
</div>

```json
{
  "data": {
    "hidden": true
  }
}
```
