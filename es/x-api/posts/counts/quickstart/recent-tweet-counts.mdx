Esta guía te muestra cómo obtener los recuentos de Publicaciones (volumen) de los últimos 7 días.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * El Bearer Token de tu App
</Note>

<div id="get-recent-post-counts">
  ## Obtener recuentos recientes de Publicaciones
</div>

<Steps>
  <Step title="Crear una consulta">
    Usa la misma sintaxis de consulta que la búsqueda reciente. Por ejemplo, para contar publicaciones de @XDevelopers:

    ```
    from:XDevelopers
    ```
  </Step>

  <Step title="Realizar la solicitud">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/tweets/counts/recent?\
      query=from%3AXDevelopers&\
      granularity=day" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Obtener recuentos recientes de publicaciones
      response = client.posts.count_recent(
          query="from:XDevelopers",
          granularity="day"
      )

      for bucket in response.data:
          print(f"{bucket.start}: {bucket.tweet_count} Publicaciones")

      print(f"Total: {response.meta.total_tweet_count} Publicaciones")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Obtener recuentos recientes de publicaciones
      const response = await client.posts.countRecent({
        query: "from:XDevelopers",
        granularity: "day",
      });

      response.data?.forEach((bucket) => {
        console.log(`${bucket.start}: ${bucket.tweet_count} Publicaciones`);
      });

      console.log(`Total: ${response.meta?.total_tweet_count} Publicaciones`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Revisar la respuesta">
    ```json
    {
      "data": [
        {
          "end": "2024-01-16T00:00:00.000Z",
          "start": "2024-01-15T00:00:00.000Z",
          "tweet_count": 5
        },
        {
          "end": "2024-01-17T00:00:00.000Z",
          "start": "2024-01-16T00:00:00.000Z",
          "tweet_count": 3
        },
        {
          "end": "2024-01-18T00:00:00.000Z",
          "start": "2024-01-17T00:00:00.000Z",
          "tweet_count": 8
        }
      ],
      "meta": {
        "total_tweet_count": 16
      }
    }
    ```
  </Step>
</Steps>

<div id="granularity-options">
  ## Opciones de granularidad
</div>

Controla cómo se agrupan los recuentos:

| Granularidad | Descripción |
|:------------|:------------|
| `minute` | Recuentos por minuto |
| `hour` | Recuentos por hora (predeterminado) |
| `day` | Recuentos por día |

<CodeGroup dropdown>
  ```bash cURL
  # Obtener recuentos por hora
  curl "https://api.x.com/2/tweets/counts/recent?\
  query=python%20lang%3Aen&\
  granularity=hour" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener recuentos por hora
  response = client.posts.count_recent(
      query="python lang:en",
      granularity="hour"
  )

  for bucket in response.data:
      print(f"{bucket.start}: {bucket.tweet_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtener recuentos por hora
  const response = await client.posts.countRecent({
    query: "python lang:en",
    granularity: "hour",
  });

  response.data?.forEach((bucket) => {
    console.log(`${bucket.start}: ${bucket.tweet_count}`);
  });
  ```
</CodeGroup>

<div id="filter-by-time-range">
  ## Filtrar por intervalo de tiempo
</div>

Limita los recuentos a un período de tiempo específico:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/counts/recent?\
  query=from%3AXDevelopers&\
  start_time=2024-01-10T00%3A00%3A00Z&\
  end_time=2024-01-15T00%3A00%3A00Z&\
  granularity=day" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener recuentos para un intervalo de tiempo específico
  response = client.posts.count_recent(
      query="from:XDevelopers",
      start_time="2024-01-10T00:00:00Z",
      end_time="2024-01-15T00:00:00Z",
      granularity="day"
  )

  print(f"Publicaciones totales: {response.meta.total_tweet_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtener recuentos para un intervalo de tiempo específico
  const response = await client.posts.countRecent({
    query: "from:XDevelopers",
    startTime: "2024-01-10T00:00:00Z",
    endTime: "2024-01-15T00:00:00Z",
    granularity: "day",
  });

  console.log(`Publicaciones totales: ${response.meta?.total_tweet_count}`);
  ```
</CodeGroup>

<div id="common-parameters">
  ## Parámetros comunes
</div>

| Parámetro | Descripción | Valor predeterminado |
|:----------|:------------|:---------------------|
| `query` | Consulta de búsqueda (obligatorio) | — |
| `granularity` | Tamaño del intervalo de tiempo | `hour` |
| `start_time` | Marca de tiempo más antigua (ISO 8601) | Hace 7 días |
| `end_time` | Marca de tiempo más reciente (ISO 8601) | Ahora |
