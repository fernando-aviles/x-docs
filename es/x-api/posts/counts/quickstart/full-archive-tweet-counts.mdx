Esta guía te explica cómo obtener recuentos históricos de Publicaciones hasta marzo de 2006.

<Warning>
  Los recuentos de Publicaciones de archivo completo requieren acceso [Self-serve](/es/x-api/getting-started/about-x-api) o [Enterprise](/es/x-api/getting-started/about-x-api).
</Warning>

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitas:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con acceso Self-serve o Enterprise
  * El Bearer Token de tu app
</Note>

***

<div id="get-full-archive-post-counts">
  ## Obtener recuentos de Publicaciones del archivo completo
</div>

<Steps>
  <Step title="Crea una consulta">
    Usa la misma sintaxis de consulta que en la búsqueda de archivo completo. Por ejemplo, para contar Publicaciones de @XDevelopers:

    ```
    from:XDevelopers
    ```
  </Step>

  <Step title="Define un intervalo de tiempo">
    Especifica `start_time` y `end_time` para buscar períodos históricos específicos:

    | Parámetro | Formato | Ejemplo |
    |:----------|:--------|:--------|
    | `start_time` | ISO 8601 | `2020-01-01T00:00:00Z` |
    | `end_time` | ISO 8601 | `2020-12-31T23:59:59Z` |
  </Step>

  <Step title="Realiza la solicitud">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/tweets/counts/all?\
      query=from%3AXDevelopers&\
      start_time=2020-01-01T00%3A00%3A00Z&\
      end_time=2020-12-31T23%3A59%3A59Z&\
      granularity=day" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Obtener recuentos de Publicaciones del archivo completo
      response = client.posts.count_all(
          query="from:XDevelopers",
          start_time="2020-01-01T00:00:00Z",
          end_time="2020-12-31T23:59:59Z",
          granularity="day"
      )

      for bucket in response.data:
          print(f"{bucket.start}: {bucket.tweet_count} Publicaciones")

      print(f"Total: {response.meta.total_tweet_count} Publicaciones")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Obtener recuentos de Publicaciones del archivo completo
      const response = await client.posts.countAll({
        query: "from:XDevelopers",
        startTime: "2020-01-01T00:00:00Z",
        endTime: "2020-12-31T23:59:59Z",
        granularity: "day",
      });

      response.data?.forEach((bucket) => {
        console.log(`${bucket.start}: ${bucket.tweet_count} Publicaciones`);
      });

      console.log(`Total: ${response.meta?.total_tweet_count} Publicaciones`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Revisa la respuesta">
    ```json
    {
      "data": [
        {
          "end": "2020-01-02T00:00:00.000Z",
          "start": "2020-01-01T00:00:00.000Z",
          "tweet_count": 3
        },
        {
          "end": "2020-01-03T00:00:00.000Z",
          "start": "2020-01-02T00:00:00.000Z",
          "tweet_count": 5
        }
      ],
      "meta": {
        "total_tweet_count": 8
      }
    }
    ```
  </Step>
</Steps>

<div id="granularity-options">
  ## Opciones de granularidad
</div>

Controla cómo se agrupan los recuentos:

| Granularidad | Descripción |
|:------------|:------------|
| `minute` | Recuentos por minuto |
| `hour` | Recuentos por hora (predeterminado) |
| `day` | Recuentos por día |

***

<div id="paginate-through-results">
  ## Paginar resultados
</div>

Para rangos de tiempo amplios, usa el `next_token` de la respuesta:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/counts/all?\
  query=from%3AXDevelopers&\
  start_time=2015-01-01T00%3A00%3A00Z&\
  end_time=2020-12-31T23%3A59%3A59Z&\
  granularity=day&\
  next_token=abc123" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener recuentos con paginación
  next_token = None

  while True:
      response = client.posts.count_all(
          query="from:XDevelopers",
          start_time="2015-01-01T00:00:00Z",
          end_time="2020-12-31T23:59:59Z",
          granularity="day",
          next_token=next_token
      )
      
      for bucket in response.data:
          print(f"{bucket.start}: {bucket.tweet_count}")
      
      next_token = response.meta.next_token
      if not next_token:
          break
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtener recuentos con paginación
  let nextToken = undefined;

  do {
    const response = await client.posts.countAll({
      query: "from:XDevelopers",
      startTime: "2015-01-01T00:00:00Z",
      endTime: "2020-12-31T23:59:59Z",
      granularity: "day",
      nextToken,
    });

    response.data?.forEach((bucket) => {
      console.log(`${bucket.start}: ${bucket.tweet_count}`);
    });

    nextToken = response.meta?.next_token;
  } while (nextToken);
  ```
</CodeGroup>

<div id="key-differences-from-recent-counts">
  ## Diferencias clave respecto a los conteos recientes
</div>

| Funcionalidad | Conteos recientes | Conteos de archivo completo |
|:--------------|:-----------------|:----------------------------|
| Intervalo de tiempo | Últimos 7 días | Desde marzo de 2006 hasta la actualidad |
| Acceso obligatorio | Todos los desarrolladores | Pago por uso, Enterprise |
| Intervalo de tiempo predeterminado | Últimos 7 días | Últimos 30 días |

***

<div id="common-parameters">
  ## Parámetros comunes
</div>

| Parámetro | Descripción | Valor predeterminado |
|:----------|:------------|:---------------------|
| `query` | Consulta de búsqueda (obligatorio) | — |
| `granularity` | Tamaño del intervalo de tiempo | `hour` |
| `start_time` | Marca de tiempo más antigua (ISO 8601) | Hace 30 días |
| `end_time` | Marca de tiempo más reciente (ISO 8601) | Ahora |
| `next_token` | Token de paginación | — |
