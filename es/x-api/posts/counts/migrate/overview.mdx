<div id="comparing-x-apis-post-counts-endpoints">
  ## Comparación de los endpoints de recuento de Publicaciones de X API
</div>

El endpoint de recuento de Publicaciones de X API v2 sustituirá eventualmente al [endpoint de recuento de enterprise Search API](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api#counts-requests-post-count). Si tienes código, aplicaciones o herramientas que usan una versión anterior de un endpoint de recuento de Publicaciones y estás considerando migrar a los endpoints más recientes de X API v2, esta guía es para ti.

***

<div id="recent-post-counts-comparison">
  ## Comparación de recuentos de Publicaciones recientes
</div>

La versión Enterprise de los endpoints de recuento de Publicaciones permite obtener recuentos para 30 días o desde el archivo completo. Por lo tanto, el endpoint de recuento de Publicaciones recientes de v2, que analiza un período de 7 días, no es un reemplazo directo de ninguno de los endpoints mencionados anteriormente.

Sin embargo, para facilitar las comparaciones, analizaremos cómo se compara el endpoint de recuento de Publicaciones recientes de v2 con el endpoint Enterprise de 30 días.

La siguiente tabla compara los distintos tipos de endpoints de recuento de Publicaciones recientes:

| **Description** | **Enterprise** | **X API v2** |
| :--- | :--- | :--- |
| Host domain | https://gnip-api.x.com | https://api.x.com |
| Endpoint path | /search/30day/accounts/:account&#95;name/:label/counts.json | /2/tweets/counts/recent |
| [Authentication](/es/resources/fundamentals/authentication) | Autenticación básica | OAuth 2.0 Bearer Token |
| Timestamp format | YYYYMMDDhhmm | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |
| Returns counts of Posts that are no older than | 31 días | 7 días |
| HTTP methods supported | GET | GET |
| Default request rate limits | 20 solicitudes por 1 s, agregadas entre solicitudes de search data y de counts  <br />El límite de solicitudes por minuto variará según el socio, según se especifique en su contrato. | 180 solicitudes por 15 min por usuario  <br />450 solicitudes por 15 min por App |
| Supports filtering using [annotations](/es/x-api/fundamentals/post-annotations) |     | ✔   |
| Supports filtering using [conversation&#95;id](/es/x-api/fundamentals/conversation-id) |     | ✔   |
| JSON key name for Post data array | results | data |
| Time granularity | Día, hora o minuto | Día, hora o minuto |
| Timezone | UTC | UTC |
| Request parameters for selecting time period | fromDate  <br />toDate | start&#95;time  <br />end&#95;time |
| Request parameters for navigating by Post ID |     | since&#95;id  <br />until&#95;id |
| Requires the use of credentials from a [developer App](/es/resources/fundamentals/developer-apps) associated with a [project](/es/resources/fundamentals/developer-apps) |     | ✔   |

<div id="filtering-operator-comparison">
  ### Comparación de operadores de filtrado
</div>

Las dos versiones diferentes (Enterprise y v2) de recuentos de Publicaciones difieren en qué operadores están disponibles y también presentan distintos niveles de disponibilidad de operadores en cada versión, lo cual se explica a continuación.

Enterprise

* No hay subniveles de operadores de Enterprise. Todos los operadores de Enterprise están disponibles para todos los usuarios de Enterprise.

X API v2

* **Básico:** Estos operadores están disponibles para cualquier usuario de v2.
* **Avanzado:** Estos operadores solo están disponibles para usuarios que hayan sido aprobados para acceso a Academic Research.

Puedes obtener más información sobre cada uno de estos conjuntos de operadores en sus respectivas guías:

* [Operadores de Enterprise](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api#building-search-queries)
* [Operadores de X API v2](/es/x-api/posts/search/integrate/build-a-query)
