<div id="comparing-x-apis-post-counts-endpoints">
  ## Comparación de los endpoints de conteo de Publicaciones de la X API
</div>

El endpoint de conteo de Publicaciones de X API v2 acabará reemplazando al [endpoint de conteo de Enterprise Search API](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api#counts-requests-post-count). Si tienes código, aplicaciones o herramientas que utilizan una versión anterior de un endpoint de conteo de Publicaciones y estás considerando migrar a los endpoints más recientes de X API v2, entonces esta guía es para ti.

***

<div id="recent-post-counts-comparison">
  ## Comparación de conteos de Publicaciones recientes
</div>

La versión empresarial de los endpoints de conteo de Publicaciones permite obtener conteos ya sea de 30 días o del archivo completo. Por lo tanto, el endpoint de conteos de Publicaciones recientes de v2, que analiza un período de 7 días, no es un reemplazo directo de ninguno de los endpoints anteriormente mencionados.

Sin embargo, para facilitar las comparaciones, veremos cómo se compara el endpoint de conteos de Publicaciones recientes de v2 con el endpoint empresarial de 30 días.

La siguiente tabla compara los distintos tipos de endpoints de conteos de Publicaciones recientes:

| **Descripción** | **Enterprise** | **X API v2** |
| :--- | :--- | :--- |
| Dominio del host | https://gnip-api.x.com | https://api.x.com |
| Ruta del endpoint | /search/30day/accounts/:account&#95;name/:label/counts.json | /2/tweets/counts/recent |
| [Autenticación](/es/resources/fundamentals/authentication) | Autenticación básica | OAuth 2.0 Bearer Token |
| Formato de marca de tiempo | YYYYMMDDhhmm | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |
| Devuelve conteos de Publicaciones que no tienen más de | 31 días | 7 días |
| Métodos HTTP admitidos | GET | GET |
| Límites de tasa de solicitudes predeterminados | 20 solicitudes por 1 s, agregadas entre solicitudes de search data y de conteos  <br />El límite de tasa por minuto variará según el partner, tal como se especifica en el contrato. | 180 solicitudes por 15 min por usuario  <br />450 solicitudes por 15 min por App |
| Permite filtrado usando [annotations](/es/x-api/fundamentals/post-annotations) |     | ✔   |
| Permite filtrado usando [conversation&#95;id](/es/x-api/fundamentals/conversation-id) |     | ✔   |
| Nombre de la clave JSON para el arreglo de data de Publicaciones | results | data |
| Granularidad temporal | Día, hora o minuto | Día, hora o minuto |
| Zona horaria | UTC | UTC |
| Parámetros de la solicitud para seleccionar el período de tiempo | fromDate  <br />toDate | start&#95;time  <br />end&#95;time |
| Parámetros de la solicitud para navegar por ID de Publicación |     | since&#95;id  <br />until&#95;id |
| Requiere el uso de credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) asociada con un [Project](/es/resources/fundamentals/developer-apps) |     | ✔   |

<div id="filtering-operator-comparison">
  ### Comparación de operadores de filtrado
</div>

Las dos versiones diferentes (Enterprise y v2) de recuentos de publicaciones difieren en qué operadores están disponibles y también tienen distintos niveles de disponibilidad de operadores dentro de cada versión, lo cual se explica a continuación.

Enterprise

* No hay subniveles de operadores de Enterprise. Todos los operadores de Enterprise están disponibles para todos los usuarios de Enterprise.

X API v2

* **Core:** Estos operadores están disponibles para cualquier usuario de v2.
* **Advanced:** Estos operadores solo están disponibles para usuarios que hayan sido aprobados para acceso a Academic Research.

Puedes obtener más información sobre cada uno de estos conjuntos de operadores en sus respectivas guías:

* [Operadores de Enterprise](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api#building-search-queries)
* [Operadores de X API v2](/es/x-api/posts/search/integrate/build-a-query)
