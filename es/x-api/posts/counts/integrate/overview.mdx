Esta página presenta las herramientas y los conceptos clave para integrar los endpoints de recuento de publicaciones.

***

<div id="helpful-tools">
  ## Herramientas útiles
</div>

Antes de comenzar a explorar algunos conceptos clave, te recomendamos usar una de las siguientes herramientas o fragmentos de código para empezar a probar la funcionalidad de estos endpoints.

<div id="code-samples">
  ### Ejemplos de código
</div>

Si quieres configurar estos endpoints con código en tu lenguaje de programación preferido, ponemos a tu disposición varios ejemplos de código que puedes usar como punto de partida en nuestra [página de GitHub](https://github.com/xdevplatform/Twitter-API-v2-sample-code), incluido un [cliente de Python](https://github.com/xdevplatform/search-tweets-python).

<div id="libraries">
  ### Bibliotecas
</div>

Aprovecha una de nuestras muchas [bibliotecas de terceros creadas por la comunidad](/es/x-api/tools-and-libraries/overview) para ayudarte a empezar. Puedes encontrar una biblioteca que funcione con los endpoints de la v2 buscando la etiqueta de versión correspondiente.

<div id="postman">
  ### Postman
</div>

Postman es una excelente herramienta que puedes usar para probar estos endpoints. Cada solicitud de Postman incluye todos los parámetros del endpoint correspondiente para ayudarte a comprender rápidamente qué tienes disponible. Para obtener más información sobre nuestras colecciones de Postman, visita nuestra página [Usar Postman](/es/tutorials/postman-getting-started).

<div id="key-concepts">
  ## Conceptos clave
</div>

<div id="authentication">
  ### Autenticación
</div>

Todos los endpoints de X API v2 requieren que las solicitudes estén [autenticadas](/es/resources/fundamentals/authentication) con un conjunto de credenciales, también conocido como claves y tokens. Este endpoint específico requiere el uso de [OAuth 2.0 Bearer Token](/es/resources/fundamentals/authentication#oauth-2-0), lo que significa que debes pasar un [Bearer Token](/es/resources/fundamentals/authentication#bearer-token-also-known-as-app-only) para realizar una solicitud exitosa. Puedes generar un Bearer Token directamente desde una App de desarrollador o generar uno usando el endpoint [POST oauth2/token](/es/resources/fundamentals/authentication#post-oauth2-token).

<div id="developer-console-projects-and-developer-apps">
  ### Developer Console, Projects y Apps de desarrollador
</div>

Para trabajar con cualquier endpoint de X API v2, debes tener una [cuenta de desarrollador](/es/resources/fundamentals/developer-portal), configurar un [Project](/es/resources/fundamentals/developer-apps) dentro de esa cuenta y crear una [App de desarrollador](/es/resources/fundamentals/developer-apps) dentro de ese Project. Tus claves y tokens dentro de esa App de desarrollador funcionarán para los endpoints de recuento de Publicaciones recientes. Si deseas usar el endpoint de recuento de Publicaciones del archivo completo o utilizar los operadores avanzados y consultas más largas, deberás haber sido aprobado para el acceso empresarial.

Visita nuestra sección sobre acceso empresarial para obtener más información.

<div id="rate-limits">
  ### Límites de frecuencia
</div>

Cada día, muchos miles de desarrolladores realizan solicitudes a la X API. Para ayudar a gestionar el volumen, se aplican [límites de frecuencia](/es/x-api/fundamentals/rate-limits) a cada endpoint, que restringen la cantidad de solicitudes que cada desarrollador puede hacer en nombre de una app o de un usuario autenticado.

Este endpoint tiene límites de frecuencia a nivel de App, lo que significa que tú, como desarrollador, solo puedes realizar una cierta cantidad de solicitudes a este endpoint durante un período de tiempo determinado desde cualquier App (según las credenciales que estés usando).

<div id="building-queries">
  ### Creación de consultas
</div>

La característica central de estos endpoints es su uso de una única consulta para filtrar las Publicaciones en los recuentos que se te devuelven. Estas consultas están formadas por operadores que se aplican a atributos de las Publicaciones y de los usuarios, como palabras clave del mensaje, hashtags y URL. Los operadores se pueden combinar en consultas con lógica booleana y paréntesis para ayudar a refinar el comportamiento de coincidencia de la consulta.

Puedes usar nuestra guía sobre [cómo crear una consulta](/es/x-api/posts/counts/integrate/build-a-query) para obtener más información.

<div id="pagination">
  ### Paginación
</div>

Para los recuentos recientes de Publicaciones, no se devuelve ningún next&#95;token, lo que significa que, independientemente de la granularidad, obtendrás el volumen de Publicaciones de los últimos 7 días en una sola llamada a la API.

Para los recuentos de Publicaciones de archivo completo, obtendrás data de los últimos 30 días. Para data de hace más de 30 días, recibirás un next&#95;token que luego puedes usar para paginar y obtener la data adicional.
