Los endpoints de Search Posts te permiten encontrar Publicaciones que cumplan con criterios específicos mediante potentes operadores de consulta. Busca palabras clave, hashtags, menciones, URLs y más.

<div id="overview">
  ## Descripción general
</div>

X ofrece dos endpoints de búsqueda con distintos rangos de tiempo y requisitos de acceso:

<CardGroup cols={2}>
  <Card title="Búsqueda reciente" icon="clock">
    Busca Publicaciones de los **últimos 7 días**. Disponible para todos los desarrolladores.
  </Card>

  <Card title="Búsqueda de archivo completo" icon="vault">
    Busca en el **archivo completo** desde 2006. Disponible para clientes de pago por uso y clientes Enterprise.
  </Card>
</CardGroup>

***

<div id="use-cases">
  ## Casos de uso
</div>

* **Monitoreo de marca** — Haz un seguimiento de las menciones de tu marca o productos
* **Análisis de tendencias** — Analiza las conversaciones sobre temas o eventos
* **Investigación** — Recopila datos para investigaciones académicas o de mercado
* **Escucha en tiempo real** — Crea aplicaciones que reaccionen ante nuevas Publicaciones

***

<div id="endpoints">
  ## Endpoints
</div>

| Method | Endpoint | Description | Access |
|:-------|:---------|:------------|:-------|
| GET | [`/2/tweets/search/recent`](/es/x-api/posts/search-recent-posts) | Buscar publicaciones de los últimos 7 días | Todos los desarrolladores |
| GET | [`/2/tweets/search/all`](/es/x-api/posts/search-all-posts) | Buscar en el archivo completo de publicaciones | Pago por uso, Enterprise |

<div id="query-operators">
  ## Operadores de consulta
</div>

Crea consultas utilizando operadores que coincidan con los atributos de las Publicaciones:

```
(AI OR "artificial intelligence") lang:en -is:retweet has:links
```

<AccordionGroup>
  <Accordion title="Operadores de palabras clave">
    | Operador | Ejemplo              | Descripción                                           |
    | :------- | :------------------- | :---------------------------------------------------- |
    | Keyword  | `python`             | Coincide con Publicaciones que contienen la palabra   |
    | Phrase   | `"machine learning"` | Coincide con la frase exacta                          |
    | Hashtag  | `#AI`                | Coincide con Publicaciones con el hashtag             |
    | Mention  | `@XDevelopers`       | Coincide con Publicaciones que mencionan a un usuario |
  </Accordion>

  <Accordion title="Operadores de usuario">
    | Operador       | Ejemplo          | Descripción                                 |
    | :------------- | :--------------- | :------------------------------------------ |
    | `from:`        | `from:elonmusk`  | Publicaciones de un usuario                 |
    | `to:`          | `to:XDevelopers` | Respuestas dirigidas a un usuario           |
    | `retweets_of:` | `retweets_of:X`  | Retweets de las Publicaciones de un usuario |
  </Accordion>

  <Accordion title="Operadores de contenido">
    | Operador       | Ejemplo          | Descripción                          |
    | :------------- | :--------------- | :----------------------------------- |
    | `has:images`   | `cat has:images` | Publicaciones con imágenes           |
    | `has:videos`   | `has:videos`     | Publicaciones con videos             |
    | `has:links`    | `has:links`      | Publicaciones con enlaces            |
    | `has:mentions` | `has:mentions`   | Publicaciones con menciones          |
    | `url:`         | `url:github.com` | Publicaciones con una URL específica |
  </Accordion>

  <Accordion title="Operadores de filtro">
    | Operador      | Ejemplo       | Descripción                           |
    | :------------ | :------------ | :------------------------------------ |
    | `lang:`       | `lang:en`     | Publicaciones en un idioma            |
    | `-is:retweet` | `-is:retweet` | Excluir retweets                      |
    | `-is:reply`   | `-is:reply`   | Excluir respuestas                    |
    | `is:verified` | `is:verified` | Publicaciones de usuarios verificados |
  </Accordion>
</AccordionGroup>

<div id="recent-search">
  ## Búsqueda reciente
</div>

Permite buscar Publicaciones de los **últimos 7 días**. Disponible para todos los desarrolladores.

<div id="features">
  ### Características
</div>

* Hasta 100 Publicaciones por solicitud
* Paginación para conjuntos de resultados grandes
* Todos los operadores de consulta principales
* Longitud máxima de la consulta de 512 caracteres (4.096 para Enterprise)

<div id="full-archive-search">
  ## Búsqueda en el archivo completo
</div>

Busca en el **archivo completo de Publicaciones** desde marzo de 2006.

<Note>
  La búsqueda en el archivo completo está disponible para clientes de pago por uso y Enterprise.
</Note>

<div id="features">
  ### Características
</div>

* Hasta 500 Publicaciones por solicitud
* Acceso al historial completo de Publicaciones
* Todos los operadores de consulta disponibles
* Longitud de consulta de 1.024 caracteres (4.096 para Enterprise)
