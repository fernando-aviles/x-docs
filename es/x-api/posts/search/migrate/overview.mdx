<div id="comparing-x-apis-search-posts-endpoints">
  ## Comparación de los endpoints Search Posts de X API
</div>

El endpoint v2 Search Tweets sustituirá eventualmente al endpoint [estándar v1.1 search/posts](/es/x-api/posts/search/introduction) y a la [Enterprise Search API](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api). Si tienes código, aplicaciones o herramientas que utilizan una versión anterior de un endpoint de búsqueda de X y estás considerando migrar a los nuevos endpoints de X API v2, esta guía es para ti.

***

**Comparación de operadores de filtrado**

Las cuatro versiones diferentes (Standard, Enterprise y v2) de búsqueda de Publicaciones difieren en qué operadores están disponibles y también presentan distintos niveles de disponibilidad de operadores dentro de cada versión, que se explican a continuación.

Enterprise

* No existen subniveles de operadores Enterprise

X API v2

* **Self-serve:** Disponible cuando se utiliza cualquier Project
* **Enterprise:** Disponible cuando se utiliza un Project

Puede obtener más información sobre cada uno de estos conjuntos de operadores en sus respectivas guías:

* [Enterprise operators](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [X API v2 operators](/es/x-api/posts/search/integrate/build-a-query#operators)
