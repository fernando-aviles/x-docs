<div id="comparing-x-apis-search-posts-endpoints">
  ## Comparación de los endpoints de búsqueda de Publicaciones de X API
</div>

El endpoint v2 Search Tweets acabará reemplazando el endpoint [estándar v1.1 search/posts](/es/x-api/posts/search/introduction) y la [Enterprise Search API](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api). Si dispones de código, aplicaciones o herramientas que usan una versión anterior de un endpoint de búsqueda de X y estás considerando migrar a los nuevos endpoints de X API v2, entonces esta guía es para ti.

***

**Comparación de operadores de filtrado**

Las cuatro versiones diferentes (estándar, Enterprise y v2) de búsqueda de Publicaciones difieren en qué operadores están disponibles y también tienen distintos niveles de disponibilidad de operadores dentro de cada versión, los cuales se explican a continuación.

Enterprise

* No hay subniveles de operadores de Enterprise

X API v2

* **Self-serve:** Disponible cuando se utiliza cualquier Project
* **Enterprise:** Disponible cuando se utiliza un Project

Puedes obtener más información sobre cada uno de estos conjuntos de operadores en sus respectivas guías:

* [Operadores de Enterprise](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [Operadores de X API v2](/es/x-api/posts/search/integrate/build-a-query#operators)
