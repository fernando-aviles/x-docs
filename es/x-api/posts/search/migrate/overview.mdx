<div id="comparing-x-apis-search-posts-endpoints">
  ## Comparación de los endpoints de búsqueda de Publicaciones de la X API
</div>

El endpoint v2 Search Tweets sustituirá eventualmente al endpoint de [búsqueda de publicaciones estándar v1.1](/es/x-api/posts/search/introduction) y a la [Enterprise Search API](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api). Si tienes código, aplicaciones o herramientas que usan una versión anterior de un endpoint de búsqueda de X y estás considerando migrar a los endpoints más recientes de X API v2, esta guía es para ti.

***

**Comparación de operadores de filtrado**

Las cuatro versiones diferentes (estándar, Enterprise y v2) de búsqueda de Publicaciones difieren en qué operadores están disponibles y también tienen distintos niveles de disponibilidad de operadores dentro de cada versión, lo cual se explica a continuación.

Enterprise

* No hay subniveles de operadores de Enterprise

X API v2

* **Self-serve:** Disponible cuando se usa cualquier Project
* **Enterprise:** Disponible cuando se usa un Project

Puedes obtener más información sobre cada uno de estos conjuntos de operadores en sus respectivas guías:

* [Enterprise operators](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [X API v2 operators](/es/x-api/posts/search/integrate/build-a-query#operators)
