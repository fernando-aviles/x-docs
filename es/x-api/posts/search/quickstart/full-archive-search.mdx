Esta guía te acompaña en la creación de tu primera solicitud de búsqueda en el archivo completo para encontrar Publicaciones del archivo de X, desde marzo de 2006.

<Warning>
  La búsqueda en el archivo completo requiere acceso [Self-serve](/es/x-api/getting-started/about-x-api) o [Enterprise](/es/x-api/getting-started/about-x-api). [Actualiza tu nivel de acceso](https://developer.x.com/en/portal/products) para poder usar este endpoint.
</Warning>

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info)
  * El Bearer Token de tu App (se encuentra en la Developer Console en &quot;Keys and tokens&quot;)
</Note>

***

<div id="step-1-build-a-query">
  ## Paso 1: Crea una consulta
</div>

La búsqueda en el archivo completo admite todos los operadores de consulta. Crea las consultas de la misma forma que en la búsqueda reciente:

```
from:XDevelopers lang:en
```

<Tip>
  La búsqueda en todo el archivo admite consultas de hasta 1.024 caracteres (4.096 para Enterprise).
</Tip>

***

<div id="step-2-set-a-time-range">
  ## Paso 2: Configura un intervalo de tiempo
</div>

De forma predeterminada, los resultados incluyen publicaciones de los últimos 30 días. Usa `start_time` y `end_time` para buscar períodos específicos:

| Parámetro | Formato | Ejemplo |
|:----------|:--------|:--------|
| `start_time` | ISO 8601 | `2020-01-01T00:00:00Z` |
| `end_time` | ISO 8601 | `2020-12-31T23:59:59Z` |

***

<div id="step-3-make-a-request">
  ## Paso 3: Realizar una solicitud
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/search/all?\
  query=from%3AXDevelopers&\
  start_time=2020-01-01T00%3A00%3A00Z&\
  end_time=2020-12-31T23%3A59%3A59Z&\
  max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Búsqueda en el archivo completo con paginación
  for page in client.posts.search_all(
      query="from:XDevelopers",
      start_time="2020-01-01T00:00:00Z",
      end_time="2020-12-31T23:59:59Z",
      max_results=100
  ):
      for post in page.data:
          print(post.text)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Búsqueda en el archivo completo con paginación
  const paginator = client.posts.searchAll({
    query: "from:XDevelopers",
    startTime: "2020-01-01T00:00:00Z",
    endTime: "2020-12-31T23:59:59Z",
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(post.text);
    });
  }
  ```
</CodeGroup>

<div id="step-5-add-fields-and-expansions">
  ## Paso 5: Añade campos y expansions
</div>

Solicita datos adicionales mediante parámetros de consulta:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/search/all?\
  query=from%3AXDevelopers&\
  start_time=2020-01-01T00%3A00%3A00Z&\
  end_time=2020-12-31T23%3A59%3A59Z&\
  tweet.fields=created_at,public_metrics,author_id&\
  expansions=author_id&\
  user.fields=username,description&\
  max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Búsqueda con campos y expansions
  for page in client.posts.search_all(
      query="from:XDevelopers",
      start_time="2020-01-01T00:00:00Z",
      end_time="2020-12-31T23:59:59Z",
      tweet_fields=["created_at", "public_metrics", "author_id"],
      expansions=["author_id"],
      user_fields=["username", "description"],
      max_results=100
  ):
      for post in page.data:
          print(f"{post.created_at}: {post.text[:50]}...")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Búsqueda con campos y expansions
  const paginator = client.posts.searchAll({
    query: "from:XDevelopers",
    startTime: "2020-01-01T00:00:00Z",
    endTime: "2020-12-31T23:59:59Z",
    tweetFields: ["created_at", "public_metrics", "author_id"],
    expansions: ["author_id"],
    userFields: ["username", "description"],
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.created_at}: ${post.text?.slice(0, 50)}...`);
    });
  }
  ```
</CodeGroup>

<div id="step-6-paginate-through-results">
  ## Paso 6: Paginar los resultados
</div>

Los SDK gestionan la paginación automáticamente. Para cURL, usa el `next_token` de la respuesta:

```bash
curl "https://api.x.com/2/tweets/search/all?\
query=from%3AXDevelopers&\
max_results=500&\
next_token=b26v89c19zqg8o3fo7gesq314yb9l2l4ptqy" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="key-differences-from-recent-search">
  ## Principales diferencias con la búsqueda reciente
</div>

| Característica | Búsqueda reciente | Búsqueda en todo el archivo |
|:--------|:--------------|:--------------------|
| Intervalo de tiempo | Últimos 7 días | Desde marzo de 2006 hasta ahora |
| Acceso requerido | Todos los desarrolladores | Pago por uso, Enterprise |
| Máximo de resultados por solicitud | 100 | 500 |
| Longitud de la consulta | 512 caracteres | 1,024 caracteres |
| Límite de frecuencia | 450 / 15 min | 300 / 15 min, 1 / segundo |
| Autenticación | App-Only, contexto de usuario | Solo App-Only |

***

<div id="common-parameters">
  ## Parámetros comunes
</div>

| Parámetro | Descripción | Valor predeterminado |
|:----------|:------------|:---------------------|
| `query` | Consulta de búsqueda (obligatorio) | — |
| `max_results` | Publicaciones por página (10-500) | 10 |
| `start_time` | Marca de tiempo de la publicación más antigua | Hace 30 días |
| `end_time` | Marca de tiempo de la publicación más reciente | Ahora |
| `next_token` | Token de paginación | — |
| `tweet.fields` | Campos adicionales de la publicación | `id`, `text` |
| `expansions` | Objetos relacionados para incluir | — |
