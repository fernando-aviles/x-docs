<div id="manage-likes-standard-v11-compared-to-x-api-v2">
  ### Administrar Me gusta: estándar v1.1 en comparación con X API v2
</div>

Si has estado trabajando con los endpoints estándar de v1.1 [POST favorites/create](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-create) y [POST favorites/destroy](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-destroy), el objetivo de esta guía es ayudarte a entender las similitudes y diferencias entre los endpoints estándar de v1.1 y X API v2 para administrar Me gusta.

* **Similitudes**
  * OAuth 1.0a User Context
* **Diferencias**
  * URLs de endpoints y métodos HTTP
  * Requisitos de App y Project
  * Parámetros de solicitud

<div id="similarities">
  #### Similitudes
</div>

**Método de autenticación OAuth 1.0a User Context**

Ambas versiones del endpoint admiten [OAuth 1.0a User Context](/es/resources/fundamentals/authentication#oauth-1-0a-2). Por lo tanto, si antes usabas uno de los endpoints estándar de v1.1 para administrar Me gusta, puedes seguir usando el mismo método de autenticación si migras a la versión de X API v2.

<div id="differences">
  #### Diferencias
</div>

**URLs de endpoints y métodos HTTP**

* Endpoints estándar de v1.1:
  * POST https://api.x.com/1.1/favorites/create.json
    (marcar una Publicación con Me gusta)
  * POST https://api.x.com/1.1/favorites/destroy.json
    (quitar el Me gusta de una Publicación)
* Endpoint de X API v2:
  * POST https://api.x.com/2/tweets/:id/likes
    (marcar una Publicación con Me gusta)
  * DELETE https://api.x.com/2/tweets/:id/likes/:tweet&#95;id
    (quitar el Me gusta de una Publicación) 

**Requisitos de App y Project**

Los endpoints de X API v2 requieren que utilices credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que esté asociada a un [Project](/es/resources/fundamentals/developer-apps) al autenticar tus solicitudes. Todos los endpoints de X API v1.1 pueden usar credenciales de Apps o de Apps asociadas a un Project.

**Parámetros de la solicitud**

Los siguientes parámetros estándar de solicitud de v1.1 tienen equivalentes en X API v2:

| Estándar v1.1 | X API v2 |
| :--- | :--- |
| id  | id  |
| includes&#95;entities | Sin equivalente |

Ten en cuenta que los parámetros estándar de v1.1 se envían como parámetros de consulta (query parameters), mientras que los parámetros de X API v2 se envían como parámetros en el cuerpo para el endpoint POST o parámetros de ruta para el endpoint DELETE.

Además, no es obligatorio indicar el id del usuario que marca con Me gusta una Publicación cuando se utilizan los endpoints estándar de v1.1, ya que los [tokens de acceso](/es/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) enviados con [OAuth 1.0a User Context](/es/resources/fundamentals/authentication) determinan qué usuario inicia la acción de marcar o quitar el Me gusta.

  ## Ejemplos de código

<div id="like-a-post-v2">
  ### Marcar una Publicación con Me gusta (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/likes" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python
  # Requiere autenticación OAuth 1.0a User Context
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/likes"
  response = requests.post(url, auth=auth, json={"tweet_id": "1234567890"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Marcar una Publicación con Me gusta
  response = client.posts.like(user_id="123456789", tweet_id="1234567890")
  print(f"Liked: {response.data.liked}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Marcar una Publicación con Me gusta
  const response = await client.posts.like("123456789", { tweetId: "1234567890" });
  console.log(`Liked: ${response.data?.liked}`);
  ```
</CodeGroup>

<div id="unlike-a-post-v2">
  ### Quitar un Me gusta de una publicación (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/123456789/likes/1234567890" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  # Requiere autenticación con OAuth 1.0a User Context
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/likes/1234567890"
  response = requests.delete(url, auth=auth)
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Quitar un Me gusta de una publicación
  response = client.posts.unlike(user_id="123456789", tweet_id="1234567890")
  print(f"Liked: {response.data.liked}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
  ```
