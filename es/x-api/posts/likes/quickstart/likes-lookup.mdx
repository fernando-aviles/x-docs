Esta guía te explica cómo recuperar datos de Me gusta usando la X API.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitas:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * El Bearer Token de tu App (para datos públicos) o el User Access Token (para métricas privadas)
</Note>

<div id="get-users-who-liked-a-post">
  ## Obtener usuarios que marcaron con Me gusta una Publicación
</div>

Obtén la lista de usuarios que marcaron con Me gusta una Publicación específica:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/1354143047324299264/liking_users?\
  user.fields=created_at,username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener usuarios que marcaron con Me gusta una Publicación con paginación
  for page in client.posts.get_liking_users(
      "1354143047324299264",
      user_fields=["created_at", "username", "verified"]
  ):
      for user in page.data:
          print(f"{user.username} - Se unió: {user.created_at}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtener usuarios que marcaron con Me gusta una Publicación con paginación
  const paginator = client.posts.getLikingUsers("1354143047324299264", {
    userFields: ["created_at", "username", "verified"],
  });

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(`${user.username} - Se unió: ${user.created_at}`);
    });
  }
  ```
</CodeGroup>

<div id="get-a-users-liked-posts">
  ## Obtener las Publicaciones que le han gustado a un usuario
</div>

Recupera las Publicaciones que le han gustado a un usuario específico:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/2244994945/liked_tweets?\
  tweet.fields=created_at,public_metrics&\
  max_results=10" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener las Publicaciones que le han gustado a un usuario con paginación
  for page in client.users.get_liked_tweets(
      "2244994945",
      tweet_fields=["created_at", "public_metrics"],
      max_results=10
  ):
      for post in page.data:
          print(f"{post.text[:50]}... - Likes: {post.public_metrics.like_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtener las Publicaciones que le han gustado a un usuario con paginación
  const paginator = client.users.getLikedTweets("2244994945", {
    tweetFields: ["created_at", "public_metrics"],
    maxResults: 10,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text?.slice(0, 50)}... - Likes: ${post.public_metrics?.like_count}`);
    });
  }
  ```
</CodeGroup>

<div id="include-additional-data">
  ## Incluir datos adicionales
</div>

Usa expansions para obtener datos relacionados, como las Publicaciones fijadas:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/1354143047324299264/liking_users?\
  user.fields=created_at&\
  expansions=pinned_tweet_id&\
  tweet.fields=created_at" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtén los usuarios que indicaron que les gusta, con la expansión de Publicación fijada
  for page in client.posts.get_liking_users(
      "1354143047324299264",
      user_fields=["created_at"],
      expansions=["pinned_tweet_id"],
      tweet_fields=["created_at"]
  ):
      for user in page.data:
          print(f"{user.username}")
      # Las Publicaciones fijadas están en page.includes.tweets
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtén los usuarios que indicaron que les gusta, con la expansión de Publicación fijada
  const paginator = client.posts.getLikingUsers("1354143047324299264", {
    userFields: ["created_at"],
    expansions: ["pinned_tweet_id"],
    tweetFields: ["created_at"],
  });

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(user.username);
    });
    // Las Publicaciones fijadas están en page.includes?.tweets
  }
  ```
</CodeGroup>
