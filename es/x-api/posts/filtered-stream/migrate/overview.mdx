<div id="comparing-x-apis-filtered-stream-endpoints">
  ## Comparación de los endpoints de flujo filtrado de X API
</div>

El conjunto de endpoints de flujo filtrado de v2 sustituye a [standard v1.1 statuses/filter](https://developer.x.com/en/docs/x-api/v1/tweets/filter-realtime/api-reference/post-statuses-filter) y a [PowerTrack API](/es/x-api/enterprise-gnip-2.0/powertrack-api). Si dispones de código, aplicaciones o herramientas que usan una versión anterior del endpoint de flujo filtrado y estás considerando migrar al nuevo endpoint de X API v2, esta comparación puede ayudarte a empezar.

Consulta nuestras guías de migración más detalladas para:

[Migración desde Standard v1.1 en comparación con X API v2](x-api/posts/filtered-stream#standard-v1-1-compared-to-x-api-v2)

[Migración desde PowerTrack API a X API v2](/es/x-api/enterprise-gnip-2.0/powertrack-api#powertrack-operators)
