Esta guía te explica cómo conectarte al flujo filtrado para recibir Publicaciones en tiempo real que coincidan con tus reglas de filtrado.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info)
  * El Bearer Token de tu App (se encuentra en la Developer Console, en «Keys and tokens»)
</Note>

***

<Steps>
  <Step title="Crear una regla de filtrado" icon="filter">
    Las reglas definen qué Publicaciones recibirás. Usa operadores para hacer coincidir palabras clave, hashtags, usuarios y más.

    **Ejemplo de regla:** Coincidir Publicaciones que contengan &quot;cat&quot; y tengan imágenes:

    ```
    cat has:images
    ```

    <Card title="Crear una regla" icon="filter" href="/es/x-api/posts/filtered-stream/integrate/build-a-rule">
      Aprende la sintaxis y los operadores de las reglas
    </Card>
  </Step>

  <Step title="Añade la regla a tu flujo" icon="plus">
    Añade una regla usando el endpoint de reglas. Incluye una `tag` para identificar qué regla coincidió con cada Publicación:

    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
        -H "Authorization: Bearer $BEARER_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{
          "add": [
            {"value": "cat has:images", "tag": "cats with images"}
          ]
        }'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Añade una regla al flujo filtrado
      response = client.filtered_stream.add_rules(
          add=[{"value": "cat has:images", "tag": "cats with images"}]
      )

      for rule in response.data:
          print(f"Rule added: {rule.id} - {rule.value}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Añade una regla al flujo filtrado
      const response = await client.filteredStream.addRules({
        add: [{ value: "cat has:images", tag: "cats with images" }],
      });

      response.data?.forEach((rule) => {
        console.log(`Rule added: ${rule.id} - ${rule.value}`);
      });
      ```
    </CodeGroup>

    **Respuesta:**

    ```json
    {
      "data": [
        {
          "id": "1273026480692322304",
          "value": "cat has:images",
          "tag": "gatos con imágenes"
        }
      ],
      "meta": {
        "sent": "2024-01-15T10:30:00.000Z",
        "summary": {
          "created": 1,
          "not_created": 0,
          "valid": 1,
          "invalid": 0
        }
      }
    }
    ```
  </Step>

  <Step title="Verifica tus reglas" icon="check">
    Enumera todas las reglas activas para confirmar que se agregó tu regla:

    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/tweets/search/stream/rules" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Obtener todas las reglas activas
      response = client.filtered_stream.get_rules()

      for rule in response.data:
          print(f"Regla activa: {rule.id} - {rule.value}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Obtener todas las reglas activas
      const response = await client.filteredStream.getRules();

      response.data?.forEach((rule) => {
        console.log(`Regla activa: ${rule.id} - ${rule.value}`);
      });
      ```
    </CodeGroup>
  </Step>

  <Step title="Conectarse al stream" icon="plug">
    Abre una conexión persistente para recibir Publicaciones coincidentes:

    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/tweets/search/stream?\
      tweet.fields=created_at,author_id&\
      expansions=author_id&\
      user.fields=username" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Conéctate al stream filtrado
      for post in client.filtered_stream.stream(
          tweet_fields=["created_at", "author_id"],
          expansions=["author_id"],
          user_fields=["username"]
      ):
          print(f"New post: {post.data.text}")
          print(f"Matching rules: {post.matching_rules}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Conéctate al stream filtrado
      const stream = client.filteredStream.stream({
        tweetFields: ["created_at", "author_id"],
        expansions: ["author_id"],
        userFields: ["username"],
      });

      for await (const post of stream) {
        console.log(`New post: ${post.data?.text}`);
        console.log(`Matching rules: ${post.matching_rules}`);
      }
      ```
    </CodeGroup>
  </Step>

  <Step title="Procesar publicaciones entrantes" icon="message">
    Flujo de publicaciones coincidentes en forma de objetos JSON:

    ```json
    {
      "data": {
        "id": "1234567890",
        "text": "Look at this cute cat! 🐱",
        "author_id": "9876543210",
        "created_at": "2024-01-15T10:35:00.000Z",
        "edit_history_tweet_ids": ["1234567890"]
      },
      "includes": {
        "users": [
          {
            "id": "9876543210",
            "username": "catperson"
          }
        ]
      },
      "matching_rules": [
        {
          "id": "1273026480692322304",
          "tag": "cats with images"
        }
      ]
    }
    ```

    <Tip>
      La matriz `matching_rules` muestra qué reglas se aplicaron a la Publicación, utilizando las etiquetas que definiste.
    </Tip>
  </Step>

  <Step title="Eliminar reglas (opcional)" icon="trash">
    Eliminar reglas por su ID:

    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
        -H "Authorization: Bearer $BEARER_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{
          "delete": {
            "ids": ["1273026480692322304"]
          }
        }'
      ```

      ```python SDK de Python
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Eliminar reglas por ID
      response = client.filtered_stream.delete_rules(
          delete={"ids": ["1273026480692322304"]}
      )
      print(f"Deleted: {response.meta.summary.deleted}")
      ```

      ```javascript SDK de JavaScript
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Eliminar reglas por ID
      const response = await client.filteredStream.deleteRules({
        delete: { ids: ["1273026480692322304"] },
      });
      console.log(`Deleted: ${response.meta?.summary?.deleted}`);
      ```
    </CodeGroup>
  </Step>
</Steps>

<div id="managing-your-connection">
  ## Gestión de tu conexión
</div>

<AccordionGroup>
  <Accordion title="Señales de keep-alive">
    La transmisión envía líneas en blanco (`\r\n`) cada 20 segundos. Si no recibes datos ni una señal de keep-alive durante 20 segundos, vuelve a conectarte.
  </Accordion>

  <Accordion title="Desconexión">
    Pulsa `Ctrl+C` para cerrar la conexión o cierra la ventana de tu terminal.
  </Accordion>

  <Accordion title="Límites de conexión">
    Solo se permite una conexión por App. Abrir una nueva conexión cerrará cualquier conexión existente.
  </Accordion>
</AccordionGroup>
