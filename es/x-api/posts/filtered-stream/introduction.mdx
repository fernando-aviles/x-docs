<div id="how-it-works">
  ## Cómo funciona
</div>

1. **Crea reglas** — Define reglas de filtrado mediante operadores
2. **Conéctate al stream** — Establece una conexión HTTP persistente
3. **Recibe publicaciones** — Obtén publicaciones coincidentes en tiempo real

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│ Crear/      │      │ Conectar al │      │ Recibir     │
│ gestionar   │  →   │ endpoint de │  →   │ Publicacio- │
│ reglas      │      │ streaming   │      │ nes coin.   │
└─────────────┘      └─────────────┘      └─────────────┘
```

<div id="building-rules">
  ## Definición de reglas
</div>

Las reglas utilizan los mismos operadores que las consultas de búsqueda:

```
(AI OR "machine learning") lang:en -is:retweet
```

<div id="example-rules">
  ### Ejemplos de reglas
</div>

| Regla | Coincidencias |
|:-----|:--------|
| `#python` | Publicaciones con el hashtag #python |
| `from:elonmusk` | Publicaciones de @elonmusk |
| `"breaking news" has:images` | Publicaciones con la frase e imágenes |
| `(@XDevelopers OR @X) -is:retweet` | Menciones, excluyendo los retuits |

<div id="connecting-to-the-stream">
  ## Conexión al stream
</div>

Establece una conexión HTTP persistente para recibir publicaciones:

```python
import requests

def stream_posts(bearer_token):
    url = "https://api.x.com/2/tweets/search/stream"
    headers = {"Authorization": f"Bearer {bearer_token}"}
    
    response = requests.get(url, headers=headers, stream=True)
    
    for line in response.iter_lines():
        if line:
            print(line.decode("utf-8"))
```

<div id="keep-alive-signals">
  ### Señales de keep-alive
</div>

El stream envía líneas en blanco (`\r\n`) cada 20 segundos para mantener activa la conexión. Si no recibes datos ni una señal de keep-alive durante 20 segundos, vuelve a conectarte.

<div id="post-edits">
  ## Ediciones de publicaciones
</div>

El stream entrega publicaciones editadas junto con su historial de ediciones. Cada edición crea un nuevo id de la publicación:

```json
{
  "data": {
    "id": "1234567893",
    "text": "Hello world! (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891", "1234567893"]
  }
}
```
