<div id="comparing-x-apis-manage-posts-endpoints">
  ## Comparación de los endpoints de administración de Publicaciones de X API
</div>

Los endpoints de administración de Publicaciones de X API v2 reemplazarán los endpoints estándar de v1.1 [POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) y [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id). Si tienes código, apps o herramientas que usan la versión v1.1 de los endpoints de administración de Publicaciones y estás considerando migrar al endpoint más reciente de X API v2, este conjunto de guías es para ti.

Las siguientes tablas comparan los endpoints estándar de administración de Publicaciones de v1.1 y de X API v2:

<div id="create-a-post">
  ### Crear una Publicación
</div>

| Descripción | Estándar v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP compatibles | POST | POST |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/statuses/update.json | /2/tweets |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Límites de tasa](/es/x-api/fundamentals/rate-limits) de solicitud predeterminados | Ninguno<br /><br />300 solicitudes por ventana de 3 horas por usuario y por App. Compartido con el endpoint POST Retweets de v1.1. | 200 solicitudes por 15 minutos por usuario<br /><br />300 solicitudes por ventana de 3 horas por usuario y por App. Compartido con el endpoint POST Retweets de v2. |
| Requiere el uso de credenciales de una [developer App](/es/resources/fundamentals/developer-apps) asociada con un [Project](/es/resources/fundamentals/developer-apps) |     | ✔   |

<div id="delete-a-post">
  ### Eliminar una Publicación
</div>

| Descripción | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | DELETE |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/statuses/destroy/:id.json | /2/tweets/:id |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Límites de tasa](/es/x-api/fundamentals/rate-limits) de solicitud predeterminados | Ninguno | 50 solicitudes por usuario cada 15 min |
| Requiere usar credenciales de una [App para desarrolladores](/es/resources/fundamentals/developer-apps) asociada con un [Project](/es/resources/fundamentals/developer-apps) |     | ✔   |
