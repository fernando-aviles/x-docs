<div id="comparing-x-apis-manage-posts-endpoints">
  ## Comparación de los endpoints para gestionar Publicaciones de X API
</div>

Los endpoints para gestionar Publicaciones de X API v2 reemplazarán los endpoints estándar de v1.1 [POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) y [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id). Si tienes código, aplicaciones o herramientas que utilizan la versión v1.1 de estos endpoints para gestionar Publicaciones y estás considerando migrar a los endpoints más recientes de X API v2, entonces este conjunto de guías es para ti.

Las siguientes tablas comparan los endpoints estándar de v1.1 y de X API v2 para gestionar Publicaciones:

<div id="create-a-post">
  ### Crear una Publicación
</div>

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP compatibles | POST | POST |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/statuses/update.json | /2/tweets |
| [Authentication](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Límites de frecuencia](/es/x-api/fundamentals/rate-limits) de solicitudes predeterminados | Ninguno<br /><br />300 solicitudes por ventana de 3 horas por usuario y por app. Compartido con el endpoint v1.1 POST Retweets. | 200 solicitudes por 15 minutos por usuario<br /><br />300 solicitudes por ventana de 3 horas por usuario y por app. Compartido con el endpoint v2 POST Retweets. |
| Requiere el uso de credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) asociada con un [Project](/es/resources/fundamentals/developer-apps) |     | ✔   |

<div id="delete-a-post">
  ### Eliminar una Publicación
</div>

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | DELETE |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/statuses/destroy/:id.json | /2/tweets/:id |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Límites de frecuencia de solicitudes](/es/x-api/fundamentals/rate-limits) predeterminados | Ninguno | 50 solicitudes por 15 min por usuario |
| Requiere el uso de credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) asociada con un [Project](/es/resources/fundamentals/developer-apps) |     | ✔   |
