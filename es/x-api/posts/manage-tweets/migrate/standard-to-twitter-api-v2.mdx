<div id="standard-v11-compared-to-x-api-v2">
  ## Comparación entre la versión estándar v1.1 y X API v2
</div>

Si has estado trabajando con los endpoints estándar v1.1 [POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) y [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id), el objetivo de esta guía es ayudarte a comprender las similitudes y diferencias entre los endpoints estándar y los endpoints de X API v2 para gestionar Publicaciones.

* **Similitudes**
  * Autenticación
* **Diferencias**
  * URL de los endpoints

  * Requisitos de la aplicación y del Project

  * Parámetros de la solicitud

<div id="similarities">
  ### Similitudes
</div>

**Autenticación**

Tanto los endpoints estándar de v1.1 para Publicaciones ([POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) y [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id)) como sus equivalentes en X API v2 utilizan [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication). Por lo tanto, si anteriormente utilizabas uno de los endpoints estándar de v1.1, puedes seguir utilizando el mismo método de autenticación si migras a la versión de X API v2.

<div id="differences">
  ### Diferencias
</div>

**URLs de endpoints**

* Endpoints estándar de la v1.1:
  * https://api.x.com/1.1/statuses/update.json
    (Crea una Publicación)
  * `https://api.x.com/1.1/statuses/destroy/:id.json`
    (Elimina una Publicación)
* Endpoint de X API v2:
  * https://api.x.com/2/tweets
    (Crea una Publicación)
  * https://api.x.com/2/tweets/:id
    (Elimina la Publicación especificada)

<div id="app-and-project-requirements">
  ### Requisitos de la App y del Project
</div>

Los endpoints de X API v2 requieren que utilices credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que esté asociada con un [Project](/es/resources/fundamentals/developer-apps) al autenticar tus solicitudes. Todos los endpoints de X API v1.1 pueden usar credenciales de Apps independientes o de Apps asociadas a un proyecto.

<div id="request-parameters">
  ### Parámetros de la solicitud
</div>

Los siguientes parámetros estándar de solicitud de la v1.1 aceptaban dos parámetros de consulta (user&#95;id o screen&#95;name). La X API v2 solo acepta el id numérico de la Publicación para el endpoint DELETE, y debe pasarse como parte de la ruta del endpoint.

Para el endpoint POST, se deben incluir parámetros adicionales en el cuerpo de la solicitud en formato JSON. Puedes obtener más información sobre qué parámetros están disponibles en la [guía de referencia de la API](/es/x-api/posts/manage-tweets/introduction).

  ## Ejemplos de código

<div id="create-a-post-v2">
  ### Crear una publicación (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/tweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"text": "¡Hola mundo!"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Crear una publicación
  response = client.posts.create(text="¡Hola mundo!")
  print(f"Publicación creada: {response.data.id}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Crear una publicación
  const response = await client.posts.create({ text: "¡Hola mundo!" });
  console.log(`Publicación creada: ${response.data?.id}`);
  ```
</CodeGroup>

  ### Eliminar una publicación (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/tweets/1234567890" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

      api_key="YOUR_API_KEY",
  ```
