Los endpoints de Manage Posts te permiten crear y eliminar publicaciones en nombre de usuarios autenticados. Crea aplicaciones para publicar contenido, crear hilos o administrar las publicaciones de los usuarios.

<div id="creating-posts">
  ## Crear publicaciones
</div>

<div id="basic-post">
  ### Publicación básica
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from the API!"}'
```

<div id="reply-to-a-post">
  ### Responder a una publicación
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "This is a reply!",
    "reply": {
      "in_reply_to_tweet_id": "1234567890"
    }
  }'
```

<div id="quote-a-post">
  ### Citar una publicación
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Check this out!",
    "quote_tweet_id": "1234567890"
  }'
```

<div id="post-with-media">
  ### Publicación con contenido multimedia
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Photo of the day",
    "media": {
      "media_ids": ["1234567890123456789"]
    }
  }'
```

<Note>
  Primero carga el contenido multimedia mediante el [endpoint Media Upload](/es/x-api/media/quickstart/media-upload-chunked), luego referencia el `media_id` en tu Publicación.
</Note>

<div id="post-with-poll">
  ### Publicación con encuesta
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "What is your favorite color?",
    "poll": {
      "options": ["Red", "Blue", "Green", "Yellow"],
      "duration_minutes": 1440
    }
  }'
```

***

<div id="deleting-posts">
  ## Eliminar publicaciones
</div>

```bash
curl -X DELETE "https://api.x.com/2/tweets/1234567890" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<Warning>
  Solo puedes eliminar Publicaciones del usuario autenticado.
</Warning>
