Esta guía te explica cómo retuitear y deshacer retuits con la X API.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una aplicación aprobada
  * Un token de acceso de usuario (OAuth 1.0a o OAuth 2.0 PKCE)
</Note>

***

<div id="retweet-a-post">
  ## Hacer repost de una Publicación
</div>

<Steps>
  <Step title="Obtén tu ID de usuario">
    Necesitas el ID de tu usuario autenticado. Puedes encontrarlo usando el [endpoint de búsqueda de usuarios](/es/x-api/users/lookup/introduction) o en tu Access Token (la parte numérica es tu ID de usuario).
  </Step>

  <Step title="Obtén el ID de la Publicación">
    Encuentra el ID de la Publicación en la URL al ver una Publicación:

    ```
    https://x.com/XDevelopers/status/1228393702244134912
                                    └── Este es el ID de la Publicación
    ```
  </Step>

  <Step title="Envía la solicitud de repost">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/users/123456789/retweets" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"tweet_id": "1228393702244134912"}'
      ```

      ```python Python SDK
      from xdk import Client
      from xdk.oauth1_auth import OAuth1

      oauth1 = OAuth1(
          api_key="YOUR_API_KEY",
          api_secret="YOUR_API_SECRET",
          access_token="YOUR_ACCESS_TOKEN",
          access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
      )

      client = Client(auth=oauth1)

      # Hacer repost de una Publicación
      response = client.posts.retweet(
          user_id="123456789",
          tweet_id="1228393702244134912"
      )

      print(f"Repost realizado: {response.data.retweeted}")
      ```

      ```javascript JavaScript SDK
      import { Client, OAuth1 } from "@xdevplatform/xdk";

      const oauth1 = new OAuth1({
        apiKey: "YOUR_API_KEY",
        apiSecret: "YOUR_API_SECRET",
        accessToken: "YOUR_ACCESS_TOKEN",
        accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
      });

      const client = new Client({ oauth1 });

      // Hacer repost de una Publicación
      const response = await client.posts.retweet("123456789", {
        tweetId: "1228393702244134912",
      });

      console.log(`Repost realizado: ${response.data?.retweeted}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Revisa la respuesta">
    ```json
    {
      "data": {
        "retweeted": true
      }
    }
    ```
  </Step>
</Steps>

<div id="undo-a-retweet">
  ## Deshacer un retuit
</div>

Quitar un retuit:

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/123456789/retweets/1228393702244134912" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Deshacer un retuit
  response = client.posts.unretweet(
      user_id="123456789",
      tweet_id="1228393702244134912"
  )

  print(f"Retweeted: {response.data.retweeted}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Deshacer un retuit
  const response = await client.posts.unretweet("123456789", "1228393702244134912");

  console.log(`Retweeted: ${response.data?.retweeted}`);
  ```
</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "retweeted": false
  }
}
```
