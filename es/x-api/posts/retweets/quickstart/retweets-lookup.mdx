Esta guía te explica paso a paso cómo obtener los usuarios que hicieron Retweet de una Publicación específica.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitas:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * El Bearer Token de tu App (para datos públicos) o el User Access Token (para métricas privadas)
</Note>

***

<div id="get-users-who-retweeted-a-post">
  ## Obtener usuarios que hicieron Retweet de una Publicación
</div>

<Steps>
  <Step title="Buscar el ID de la Publicación">
    Obtén el ID de la Publicación para la que quieres consultar los Retweets:

    ```
    https://x.com/XDevelopers/status/1354143047324299264
                                    └── Este es el ID de la Publicación
    ```
  </Step>

  <Step title="Realizar la solicitud">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/tweets/1354143047324299264/retweeted_by?\
      user.fields=created_at,username,verified" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Obtener usuarios que hicieron Retweet de una Publicación con paginación
      for page in client.posts.get_retweeted_by(
          "1354143047324299264",
          user_fields=["created_at", "username", "verified"]
      ):
          for user in page.data:
              print(f"{user.username} - Se unió: {user.created_at}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Obtener usuarios que hicieron Retweet de una Publicación con paginación
      const paginator = client.posts.getRetweetedBy("1354143047324299264", {
        userFields: ["created_at", "username", "verified"],
      });

      for await (const page of paginator) {
        page.data?.forEach((user) => {
          console.log(`${user.username} - Se unió: ${user.created_at}`);
        });
      }
      ```
    </CodeGroup>
  </Step>

  <Step title="Revisar la respuesta">

<div id="include-additional-data">
  ## Incluye datos adicionales
</div>

Usa el parámetro expansions para obtener datos relacionados, como Publicaciones fijadas:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/1354143047324299264/retweeted_by?\
  user.fields=created_at&\
  expansions=pinned_tweet_id&\
  tweet.fields=created_at" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtén los usuarios que hicieron Retweet con expansions
  for page in client.posts.get_retweeted_by(
      "1354143047324299264",
      user_fields=["created_at"],
      expansions=["pinned_tweet_id"],
      tweet_fields=["created_at"]
  ):
      for user in page.data:
          print(f"{user.username}")
      # Las Publicaciones fijadas están en page.includes.tweets
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtén los usuarios que hicieron Retweet con expansions
  const paginator = client.posts.getRetweetedBy("1354143047324299264", {
    userFields: ["created_at"],
    expansions: ["pinned_tweet_id"],
    tweetFields: ["created_at"],
  });

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(user.username);
    });
    // Las Publicaciones fijadas están en page.includes?.tweets
  }
  ```
</CodeGroup>
