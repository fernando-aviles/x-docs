<div id="comparing-x-apis-retweets-endpoints">
  ## Comparación de los endpoints de retuits de X API
</div>

**Consulta de retuits**

El endpoint de consulta de retuits de v2 reemplazará los endpoints estándar [v1.1 GET statuses/retweets/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweets-id) y [v1.1 GET statuses/retweets/:ids](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweeters-ids).

Las siguientes tablas comparan los endpoints estándar de retuits de v1.1 y X API v2:

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | GET | GET |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/retweeters/id.json<br /><br />`/1.1/retweets/ids.json` | /2/users/:id/retweeted&#95;by |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a User Context |
| [Límites de frecuencia](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | 75 solicitudes por 15 min | 75 solicitudes por 15 min (por App)<br /><br />75 solicitudes por 15 min (por usuario) |
| Formato de datos | Formato estándar v1.1 | [Formato de X API v2](/es/x-api/fundamentals/data-dictionary) (determinado por los parámetros de solicitud fields y expansions; no es retrocompatible con los formatos de v1.1)<br /><br />Para obtener más información sobre cómo migrar del formato estándar v1.1 al formato de X API v2, consulta nuestra [guía de migración de formatos de datos](/es/x-api/migrate/data-format-migration). |
| Requiere el uso de credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que esté asociada con un [Project](/es/resources/fundamentals/developer-apps) |     | ✔️  |

<div id="manage-retweets">
  ### Gestionar Retuits
</div>

Las siguientes tablas comparan el endpoint de deshacer Retuit de la v1.1 estándar y de X API v2:

**Retuitear una Publicación**

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | POST |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/statuses/retweet/:id.json | /2/users/:id/retweets |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Límites de frecuencia](/es/resources/fundamentals/rate-limits) predeterminados para las solicitudes | Ninguno<br /><br />300 solicitudes por ventana de 3 horas (por usuario, por aplicación). Se comparte con el endpoint POST Tweet | 50 solicitudes por 15 minutos (por usuario)<br /><br />300 solicitudes por ventana de 3 horas (por usuario, por aplicación). Se comparte con el endpoint POST Tweet para gestionar Publicaciones. |
| Requiere el uso de credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) asociada a un [Project](/es/resources/fundamentals/developer-apps) |     | ✔️  |
