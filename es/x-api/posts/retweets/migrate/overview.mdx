<div id="comparing-x-apis-retweets-endpoints">
  ## Comparación de los endpoints de Retweets de X API
</div>

**Consulta de Retweets**

El endpoint v2 de consulta de Retweets reemplazará los endpoints estándar [v1.1 GET statuses/retweets/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweets-id) y [v1.1 GET statuses/retweets/:ids](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweeters-ids).

Las siguientes tablas comparan los endpoints de Retweets estándar v1.1 y X API v2:

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | GET | GET |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/retweeters/id.json<br /><br />`/1.1/retweets/ids.json` | /2/users/:id/retweeted&#95;by |
| [Autenticación](/es/resources/fundamentals/authentication) | Contexto de usuario de OAuth 1.0a | Bearer Token de OAuth 2.0<br /><br />Contexto de usuario de OAuth 1.0a |
| [Límites de tasa](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | 75 solicitudes por 15 min | 75 solicitudes por 15 min (por App)<br /><br />75 solicitudes por 15 min (por usuario) |
| Formato de datos | Formato estándar v1.1 | [Formato de X API v2](/es/x-api/fundamentals/data-dictionary) (determinado por los parámetros de solicitud fields y expansions, no es retrocompatible con los formatos v1.1)<br /><br />Para obtener más información sobre cómo migrar del formato estándar v1.1 al formato de X API v2, consulta nuestra [guía de migración de formatos de datos](/es/x-api/migrate/data-format-migration). |
| Requiere el uso de credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que esté asociada con un [Proyecto](/es/resources/fundamentals/developer-apps) |     | ✔️  |

<div id="manage-retweets">
  ### Gestionar Retweets
</div>

Las siguientes tablas comparan el endpoint estándar v1.1 y el de X API v2 para deshacer un Retweet:

**Hacer Retweet de una Publicación**

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP compatibles | POST | POST |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/statuses/retweet/:id.json | /2/users/:id/retweets |
| [Authentication](/es/resources/fundamentals/authentication) | Contexto de usuario de OAuth 1.0a | Contexto de usuario de OAuth 1.0a |
| [Límites de tasa](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | Ninguno<br /><br />300 solicitudes por ventana de 3 horas (por usuario, por App). Se comparte con el endpoint POST Tweet | 50 solicitudes por 15 minutos (por usuario)<br /><br />300 solicitudes por ventana de 3 horas (por usuario, por App). Se comparte con el endpoint POST Tweet para gestionar Publicaciones. |
| Requiere el uso de credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que esté asociada con un [Proyecto](/es/resources/fundamentals/developer-apps) |     | ✔️  |
