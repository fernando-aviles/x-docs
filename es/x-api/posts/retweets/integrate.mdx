  ### Conceptos clave
</div>

<div id="authentication">
  #### Autenticación
</div>

Todos los endpoints de X API v2 requieren que autentiques tus solicitudes con un conjunto de credenciales, también conocidas como claves y tokens.

Puedes usar OAuth 1.0a User Context o OAuth 2.0 Bearer Token para autenticar tus solicitudes al endpoint de búsqueda de Retuits.

Los endpoints para gestionar Retuits requieren el uso de OAuth 1.0a User Context, lo que significa que debes usar un conjunto de claves de API y tokens de acceso de usuario para realizar una solicitud satisfactoria. Los tokens de acceso deben estar asociados con el usuario en cuyo nombre estás realizando la solicitud. Si quieres generar un conjunto de tokens de acceso para otro usuario, ese usuario debe autorizar o autenticar tu App usando el flujo OAuth de 3 pasos (3-legged OAuth).

Ten en cuenta que OAuth 1.0a puede ser complicado de usar. Si no estás familiarizado con este método de autenticación, te recomendamos que uses una [biblioteca](/es/x-api/tools-and-libraries/overview) para autenticar correctamente tus solicitudes.

**Ten en cuenta**

Si estás solicitando los siguientes campos, OAuth 1.0a User Context es obligatorio:

* tweet.fields.non&#95;public&#95;metrics
* tweet.fields.promoted&#95;metrics
* tweet.fields.organic&#95;metrics
* media.fields.non&#95;public&#95;metrics
* media.fields.promoted&#95;metrics
* media.fields.organic&#95;metrics

<div id="developer-console-projects-and-developer-apps">
  #### Developer Console, Projects y Apps de desarrollador
</div>

Para obtener un conjunto de credenciales de autenticación que funcionen con los endpoints de X API v2, debes [registrarte para obtener una cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info), configurar un [Project](/es/resources/fundamentals/developer-apps) dentro de esa cuenta y crear una [App de desarrollador](/es/resources/fundamentals/developer-apps) dentro de ese Project. Luego podrás encontrar tus claves y tokens dentro de tu App de desarrollador.

<div id="rate-limits">
  #### Límites de frecuencia
</div>

Cada día, muchos miles de desarrolladores realizan solicitudes a la X API. Para ayudar a gestionar el enorme volumen de estas solicitudes, se aplican [límites de frecuencia](/es/x-api/fundamentals/rate-limits) a cada endpoint, que restringen la cantidad de solicitudes que puedes hacer en nombre de tu aplicación o de un usuario autenticado.

Los endpoints para administrar Retweets están limitados a 50 solicitudes por intervalo de 15 minutos (por usuario). Además, para el endpoint POST, el límite es de 300 solicitudes por ventana de 3 horas (por usuario y por aplicación).

Con el endpoint de búsqueda de Retweets, el límite es de 75 solicitudes por ventana de 15 minutos. Además, este endpoint solo devolverá a los 100 usuarios que hayan hecho Retweet más recientemente.

<div id="fields-and-expansions">
  #### Campos y expansions
</div>

X API v2 permite a los usuarios seleccionar exactamente qué data quieren que la API devuelva utilizando un conjunto de herramientas llamadas campos y expansions. El parámetro expansions te permite expandir los objetos referenciados en el payload. Por ejemplo, este endpoint te permite obtener las siguientes [expansions](/es/x-api/fundamentals/expansions):

* attachments.poll&#95;ids
* attachments.media&#95;keys
* author&#95;id, entities.mentions.username
* geo.place&#95;id
* in&#95;reply&#95;to&#95;user&#95;id,
* referenced&#95;tweets.id,
* referenced&#95;tweets.id.author&#95;id

El parámetro fields te permite seleccionar exactamente qué [campos](/es/x-api/fundamentals/fields) dentro de los diferentes objetos de data quieres recibir. Estos endpoints devuelven principalmente objetos de Publicación. De forma predeterminada, el objeto de Publicación devuelve los campos id y text. Para recibir campos adicionales como tweet.created&#95;at o tweet.entities, tendrás que solicitarlos específicamente usando un parámetro fields. Algunos campos importantes que podrías considerar usar en tu integración son nuestros datos de encuestas (poll data), métricas, anotaciones de la Publicación y campos de id de conversación.

Hemos añadido una guía sobre cómo [usar campos y expansions](/es/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions) juntos en nuestro [diccionario de datos de X API v2](/es/x-api/fundamentals/data-dictionary).

<div id="get-users-who-retweeted-a-post">
  #### Obtener usuarios que retuitearon una Publicación
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/1234567890/retweeted_by?user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtener usuarios que retuitearon una Publicación
  response = client.posts.get_retweeted_by(
      "1234567890",
      user_fields=["username", "verified"]
  )
  for user in response.data:
      print(f"{user.username} - Verified: {user.verified}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtener usuarios que retuitearon una Publicación
  const response = await client.posts.getRetweetedBy("1234567890", {
    userFields: ["username", "verified"],
  });

  response.data?.forEach((user) => {
    console.log(`${user.username} - Verified: ${user.verified}`);
  });
  ```
</CodeGroup>

<div id="retweet-a-post">
  #### Retuitear una publicación
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/retweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Retuitear una publicación
  response = client.posts.retweet(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Retuitear una publicación
  const response = await client.posts.retweet("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
