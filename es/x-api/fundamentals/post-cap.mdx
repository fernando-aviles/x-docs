X API v2 utiliza un modelo de precios **por uso**. Se cobra en función del consumo real de la API, que se realiza un seguimiento a nivel de la aplicación.

***

<div id="how-billing-works">
  ## Cómo funciona la facturación
</div>

| Concepto | Descripción |
|:--------|:------------|
| **Basado en créditos** | Adquiere créditos por adelantado, que se descuentan a medida que usas la API |
| **Precios por solicitud** | Diferentes endpoints tienen costos diferentes |
| **Seguimiento en tiempo real** | Supervisa el uso en la Consola de Desarrollador |
| **Sin límites** | Úsalo tanto como necesites: no hay límites mensuales |

<div id="deduplication">
  ## Deduplicación
</div>

<Note>
  **Deduplicación diaria**: Si la misma publicación se devuelve en varias consultas dentro de un mismo día, solo se contabiliza una vez para la facturación.
</Note>

Esto significa:

* Recuperar la misma publicación varias veces en un día = 1 cargo
* Recuperar una publicación nuevamente al día siguiente = 1 cargo adicional
* Publicaciones diferentes en la misma solicitud = cada una se contabiliza por separado

<div id="pricing-details">
  ## Detalles de precios
</div>

Para conocer los precios actuales por endpoint y operación, consulta la [Consola de Desarrollador](https://console.x.com).

Los precios pueden variar según:

* Tipo de endpoint (búsqueda vs. consulta vs. transmisión)
* Operación (lectura vs. escritura)
* Alcance de los datos (reciente vs. archivo completo)

<div id="faqs">
  ## Preguntas frecuentes
</div>

<Accordion title="¿Qué sucede si me quedo sin créditos?">
  Las solicitudes de API fallarán hasta que compres más créditos. Configura alertas de saldo para evitar interrupciones.
</Accordion>

<Accordion title="¿Hay mínimos mensuales?">
  No. Paga solo por lo que uses. Puedes tener meses con uso cero y costo cero.
</Accordion>

<Accordion title="¿Cómo se factura el streaming?">
  Cada publicación única entregada a través de filtered stream cuenta para el uso, con una deduplicación diaria.
</Accordion>

<Accordion title="¿Las solicitudes fallidas cuentan?">
  No. Solo se facturan las respuestas exitosas que devuelven datos.
</Accordion>
