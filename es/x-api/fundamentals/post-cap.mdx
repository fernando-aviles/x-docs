X API v2 utiliza un modelo de precios de **pago por uso**. Se te cobra en función del consumo real de la API, cuyo seguimiento se realiza a nivel de aplicación.

***

<div id="how-billing-works">
  ## Cómo funciona la facturación
</div>

| Concepto | Descripción |
|:--------|:------------|
| **Basado en créditos** | Adquiere créditos por adelantado, que se descuentan a medida que usas la API |
| **Precios por solicitud** | Distintos endpoints tienen costos diferentes |
| **Seguimiento en tiempo real** | Supervisa el uso en la Developer Console |
| **Sin límites** | Usa tanto como necesites: no hay límites mensuales |

<div id="deduplication">
  ## Eliminación de duplicados
</div>

<Note>
  **Eliminación diaria de duplicados**: Si la misma publicación se devuelve en varias consultas durante un mismo día, solo cuenta una vez para la facturación.
</Note>

Esto significa:

* Recuperar la misma publicación varias veces en un día = 1 cargo
* Recuperar una publicación de nuevo al día siguiente = 1 cargo adicional
* Publicaciones diferentes en la misma solicitud = cada una cuenta por separado

<div id="pricing-details">
  ## Detalles de precios
</div>

Para ver los precios vigentes por endpoint y operación, visita el [Developer Console](https://console.x.com).

Los precios pueden variar según:

* Tipo de endpoint (búsqueda vs. consulta vs. stream)
* Operación (lectura vs. escritura)
* Alcance de los datos (recientes vs. archivo completo)

<div id="faqs">
  ## Preguntas frecuentes
</div>

<Accordion title="¿Qué sucede si me quedo sin créditos?">
  Las solicitudes a la API fallarán hasta que compres más créditos. Configura alertas de saldo para evitar interrupciones.
</Accordion>

<Accordion title="¿Hay mínimos mensuales?">
  No. Pagas solo por lo que usas. Puedes tener meses con uso cero y costo cero.
</Accordion>

<Accordion title="¿Cómo se factura el streaming?">
  Cada Publicación única entregada a través del stream filtrado cuenta para el uso, con una desduplicación diaria.
</Accordion>

<Accordion title="¿Las solicitudes fallidas cuentan?">
  No. Solo se facturan las respuestas satisfactorias que devuelven data.
</Accordion>
