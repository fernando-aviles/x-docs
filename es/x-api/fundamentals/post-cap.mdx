X API v2 utiliza un modelo de precios de **pago por uso**. La facturación se basa en el consumo real de la API, medido a nivel de App.

***

<div id="how-billing-works">
  ## Cómo funciona la facturación
</div>

| Concepto | Descripción |
|:--------|:------------|
| **Basado en créditos** | Compra créditos por adelantado; se descuentan a medida que usas la API |
| **Precios por solicitud** | Distintos endpoints tienen costos diferentes |
| **Seguimiento en tiempo real** | Monitorea el uso en la Consola de desarrollador |
| **Sin límites** | Usa tanto como necesites; no hay límites mensuales |

<div id="deduplication">
  ## Eliminación de duplicados
</div>

<Note>
  **Eliminación diaria de duplicados**: Si la misma publicación se devuelve a partir de varias consultas dentro de un mismo día, solo se cuenta una vez para la facturación.
</Note>

Esto significa:

* Obtener la misma publicación varias veces en un día = 1 cargo
* Obtener una publicación nuevamente al día siguiente = 1 cargo adicional
* Publicaciones diferentes en la misma solicitud = cada una se cuenta por separado

<div id="pricing-details">
  ## Detalles de precios
</div>

Para conocer los precios actuales por endpoint y operación, visita la [Consola de desarrollador](https://console.x.com).

Los precios pueden variar según:

* Tipo de endpoint (búsqueda vs. consulta vs. streaming)
* Operación (lectura vs. escritura)
* Alcance de los datos (reciente vs. archivo completo)

<div id="faqs">
  ## Preguntas frecuentes
</div>

<Accordion title="¿Qué sucede si me quedo sin créditos?">
  Las solicitudes a la API fallarán hasta que compres más créditos. Configura alertas de saldo para evitar interrupciones.
</Accordion>

<Accordion title="¿Hay mínimos mensuales?">
  No. Paga solo por lo que uses. Puedes tener meses sin uso y sin costo.
</Accordion>

<Accordion title="¿Cómo se factura el streaming?">
  Cada Publicación única entregada a través del stream filtrado se contabiliza en el uso, con deduplicación diaria.
</Accordion>

<Accordion title="¿Las solicitudes fallidas cuentan?">
  No. Solo se facturan las respuestas exitosas que devuelven datos.
</Accordion>
