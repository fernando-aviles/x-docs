Cada respuesta en X pertenece a un hilo de conversación. El campo `conversation_id` te permite identificar, hacer seguimiento y reconstruir árboles de conversación completos.

***

<div id="how-it-works">
  ## Cómo funciona
</div>

Cuando alguien publica y otras personas responden, todas las respuestas comparten el mismo `conversation_id`, el identificador de la publicación original que inició la conversación.

```
Original post (ID: 1234567890)  ← conversation_id for all replies
├── Reply 1 (ID: 1234567891)    → conversation_id: 1234567890
│   └── Reply to Reply 1        → conversation_id: 1234567890
└── Reply 2 (ID: 1234567892)    → conversation_id: 1234567890
    └── Reply to Reply 2        → conversation_id: 1234567890
```

No importa cuán profundo sea el hilo, todas las publicaciones comparten el mismo `conversation_id`.

***

<div id="requesting-conversation_id">
  ## Solicitar conversation_id
</div>

Agrega `conversation_id` a `tweet.fields`:

```bash
curl "https://api.x.com/2/tweets/1234567891?tweet.fields=conversation_id,in_reply_to_user_id,referenced_tweets" \
  -H "Authorization: Bearer $TOKEN"
```

Respuesta:

```json
{
  "data": {
    "id": "1234567891",
    "text": "@user Great point!",
    "conversation_id": "1234567890",
    "in_reply_to_user_id": "2244994945",
    "referenced_tweets": [{
      "type": "replied_to",
      "id": "1234567890"
    }]
  }
}
```

***

<div id="getting-a-full-conversation">
  ## Obtener una conversación completa
</div>

Usa `conversation_id` como operador de búsqueda para obtener todas las publicaciones de un hilo:

```bash
curl "https://api.x.com/2/tweets/search/recent?\
query=conversation_id:1234567890&\
tweet.fields=author_id,created_at,in_reply_to_user_id&\
expansions=author_id" \
  -H "Authorization: Bearer $TOKEN"
```

Devuelve todas las respuestas a la publicación original, ordenadas en orden cronológico inverso.

***

<div id="use-cases">
  ## Casos de uso
</div>

<Tabs>
  <Tab title="Reconstrucción de hilos">
    Reconstruye el árbol completo de la conversación:

    ```python
    import requests

    conversation_id = "1234567890"
    url = f"https://api.x.com/2/tweets/search/recent"
    params = {
        "query": f"conversation_id:{conversation_id}",
        "tweet.fields": "author_id,in_reply_to_user_id,referenced_tweets,created_at",
        "max_results": 100
    }

    response = requests.get(url, headers=headers, params=params)
    replies = response.json()["data"]

    # Ordena por created_at para obtener el orden cronológico
    replies.sort(key=lambda x: x["created_at"])
    ```
  </Tab>

  <Tab title="Supervisión de conversaciones">
    Transmite en tiempo real las respuestas a conversaciones específicas:

    ```bash
    # Añade una regla de flujo filtrado para una conversación
    curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{"add": [{"value": "conversation_id:1234567890"}]}'
    ```
  </Tab>

  <Tab title="Análisis de conversaciones">
    Cuenta las respuestas en una conversación:

    ```bash
    curl "https://api.x.com/2/tweets/counts/recent?\
    query=conversation_id:1234567890" \
      -H "Authorization: Bearer $TOKEN"
    ```
  </Tab>
</Tabs>

***

<div id="related-fields">
  ## Campos relacionados
</div>

| Campo | Descripción |
|:------|:------------|
| `conversation_id` | ID de la publicación original que inició el hilo |
| `in_reply_to_user_id` | ID del usuario de la publicación a la que se responde |
| `referenced_tweets` | Array con `type: "replied_to"` y el ID de la publicación principal |

<div id="notes">
  ## Notas
</div>

* El `conversation_id` de la publicación original es igual a su propio `id`
* `conversation_id` está disponible en todos los endpoints v2 que devuelven publicaciones
* Úsalo con [filtered stream](/es/x-api/posts/filtered-stream/introduction) para supervisar conversaciones en tiempo real
* Combínalo con [pagination](/es/x-api/fundamentals/pagination) para hilos de gran tamaño
