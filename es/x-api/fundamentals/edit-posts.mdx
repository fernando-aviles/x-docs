Las publicaciones en X pueden editarse en un plazo de 30 minutos tras su publicación, hasta 5 veces. La X API proporciona acceso completo al historial de ediciones y a los metadatos.

***

<div id="edit-rules">
  ## Reglas de edición
</div>

| Regla | Detalles |
|:-----|:--------|
| **Ventana de tiempo** | 30 minutos desde la publicación original |
| **Límite de ediciones** | 5 ediciones como máximo |
| **Comportamiento del id** | Cada edición crea un nuevo id de publicación |
| **Eliminación** | Al eliminar cualquier versión se elimina toda la cadena |

***

<div id="what-cant-be-edited">
  ## Qué no se puede editar
</div>

Algunos tipos de publicaciones no se pueden editar:

* Publicaciones promocionadas (anuncios)
* Publicaciones con encuestas
* Respuestas a otros (que no forman parte de tus propios hilos)
* Reposts (las publicaciones con cita *sí* se pueden editar)
* Publicaciones de comunidades
* Publicaciones colaborativas
* Publicaciones programadas

***

<div id="edit-data-in-responses">
  ## Editar el campo data en las respuestas
</div>

<div id="default-fields">
  ### Campos predeterminados
</div>

Todas las respuestas de publicaciones incluyen `edit_history_tweet_ids` de manera predeterminada:

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"]
  }
}
```

* Una sola id = nunca editado
* Varias id = historial de edición (de la más antigua a la más reciente)

<div id="edit-controls">
  ### Controles de edición
</div>

Solicita `edit_controls` para obtener el estado de la edición:

```bash
curl "https://api.x.com/2/tweets/1234567891?tweet.fields=edit_controls" \
  -H "Authorization: Bearer $TOKEN"
```

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"],
    "edit_controls": {
      "is_edit_eligible": true,
      "editable_until": "2024-01-15T12:30:00.000Z",
      "edits_remaining": 3
    }
  }
}
```

| Field              | Description                                               |
| :----------------- | :-------------------------------------------------------- |
| `is_edit_eligible` | Indica si la publicación se puede editar                  |
| `editable_until`   | Marca de tiempo en la que se cierra la ventana de edición |
| `edits_remaining`  | Número de ediciones restantes (0-5)                       |

***

<div id="getting-edit-history">
  ## Obtener el historial de ediciones
</div>

Utiliza la expansión `edit_history_tweet_ids` para obtener los objetos de Publicación completos de todas las versiones:

```bash
curl "https://api.x.com/2/tweets/1234567891?\
tweet.fields=edit_controls&\
expansions=edit_history_tweet_ids" \
  -H "Authorization: Bearer $TOKEN"
```

```json
{
  "data": {
    "id": "1234567891",
    "text": "Texto actualizado (editado)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"],
    "edit_controls": {
      "is_edit_eligible": true,
      "editable_until": "2024-01-15T12:30:00.000Z",
      "edits_remaining": 3
    }
  },
  "includes": {
    "tweets": [{
      "id": "1234567890",
      "text": "Texto original (con error)",
      "edit_history_tweet_ids": ["1234567890", "1234567891"],
      "edit_controls": {
        "is_edit_eligible": true,
        "editable_until": "2024-01-15T12:30:00.000Z",
        "edits_remaining": 3
      }
    }]
  }
}
```

***

<div id="which-version-is-returned">
  ## ¿Qué versión se devuelve?
</div>

De forma predeterminada, la API devuelve la **versión más reciente** de una publicación editada.

Para obtener una versión específica, solicítala directamente mediante el id de la publicación:

```bash
# Obtener versión original
curl "https://api.x.com/2/tweets/1234567890" -H "Authorization: Bearer $TOKEN"

# Get edited version  
curl "https://api.x.com/2/tweets/1234567891" -H "Authorization: Bearer $TOKEN"
```

***

<div id="metrics-for-edited-posts">
  ## Métricas de publicaciones editadas
</div>

Cada versión de una publicación editada tiene sus propias métricas de interacción. Estas métricas se atribuyen a la versión que estaba visible en el momento en que se produjo la interacción.

***

<div id="availability">
  ## Disponibilidad
</div>

Los metadatos de edición están disponibles:

* Para todas las publicaciones creadas desde el 29 de septiembre de 2022
* En todos los endpoints v2 que devuelven publicaciones
* Incluyendo búsqueda, líneas de tiempo, stream y consultas

Las publicaciones creadas antes de esta fecha no tienen metadatos de edición.

<div id="use-cases">
  ## Casos de uso
</div>

<Tabs>
  <Tab title="Rastrear cambios">
    Supervisa las publicaciones para detectar ediciones y registrar las diferencias:

    ```python
    def check_for_edits(post):
        history = post.get("edit_history_tweet_ids", [])
        if len(history) > 1:
            print(f"La publicación {post['id']} se ha editado {len(history) - 1} veces")
    ```
  </Tab>

  <Tab title="Mostrar indicador de edición">
    Muestra una insignia &quot;editado&quot; en tu interfaz de usuario:

    ```javascript
    const isEdited = post.edit_history_tweet_ids?.length > 1;
    if (isEdited) {
      showEditedBadge();
    }
    ```
  </Tab>

  <Tab title="Obtener contenido original">
    Recupera la versión original de una publicación editada:

    ```python
    original_id = post["edit_history_tweet_ids"][0]
    original = api.get_tweet(original_id)
    ```
  </Tab>
</Tabs>
