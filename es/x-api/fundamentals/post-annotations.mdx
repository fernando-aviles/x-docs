Las anotaciones proporcionan metadatos semánticos sobre el contenido de las publicaciones. X analiza las publicaciones para identificar entidades (personas, lugares, productos) y contexto (temas, dominios) para ayudarte a comprender y filtrar el contenido.

---

<div id="annotation-types">
  ## Tipos de anotaciones
</div>

<div id="entity-annotations">
  ### Anotaciones de entidades
</div>

El reconocimiento de entidades nombradas (NER) identifica menciones específicas en el texto de la Publicación:

| Tipo | Ejemplos |
|:-----|:---------|
| **Persona** | Barack Obama, Elon Musk |
| **Lugar** | San Francisco, Japón |
| **Producto** | iPhone, ChatGPT |
| **Organización** | NASA, Google |
| **Otro** | Super Bowl, Diabetes |

Las anotaciones de entidades incluyen un puntaje de confianza y su posición en el texto.

<div id="context-annotations">
  ### Anotaciones de contexto
</div>

Análisis semántico que clasifica las publicaciones por tema y dominio:

- **Dominio**: Categoría amplia (Deportes, Entretenimiento, Tecnología)
- **Entidad**: Tema específico dentro del dominio (NBA, Películas de Marvel, IA)

Las anotaciones de contexto ayudan a filtrar y categorizar publicaciones sin depender de palabras clave.

---

<div id="requesting-annotations">
  ## Solicitud de anotaciones
</div>

Agrega `context_annotations` y `entities` a tus `tweet.fields`:

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=context_annotations,entities" \
  -H "Authorization: Bearer $TOKEN"
```

***


<div id="response-structure">
  ## Estructura de la respuesta
</div>

```json
{
  "data": {
    "id": "1234567890",
    "text": "Just saw the new Marvel movie - it was amazing!",
    "entities": {
      "annotations": [
        {
          "start": 17,
          "end": 22,
          "probability": 0.9234,
          "type": "Organization",
          "normalized_text": "Marvel"
        }
      ]
    },
    "context_annotations": [
      {
        "domain": {
          "id": "86",
          "name": "Movie",
          "description": "Una película"
        },
        "entity": {
          "id": "1234567890",
          "name": "Marvel Cinematic Universe"
        }
      },
      {
        "domain": {
          "id": "65",
          "name": "Interests and Hobbies Vertical"
        },
        "entity": {
          "id": "781974596752842752",
          "name": "Entertainment"
        }
      }
    ]
  }
}
```

***


<div id="entity-annotation-fields">
  ## Campos de anotación de entidades
</div>

| Campo | Descripción |
|:------|:------------|
| `start` | Posición inicial en el texto |
| `end` | Posición final en el texto |
| `probability` | Índice de confianza (0-1) |
| `type` | Tipo de entidad (persona, lugar, etc.) |
| `normalized_text` | Nombre de la entidad normalizado |

<div id="using-annotations-in-filters">
  ## Uso de anotaciones en los filtros
</div>

<div id="search-and-filtered-stream">
  ### Búsqueda y stream filtrado
</div>

Filtra publicaciones por el ID de entidad de `context annotation`:

```bash
# Publicaciones sobre una entidad específica
context:86.1234567890

# Publicaciones en un dominio específico
context:86.*
```


<div id="practical-examples">
  ### Ejemplos prácticos
</div>

```bash
# Posts about the NBA
query=context:26.852137520

# Publicaciones sobre productos de Apple
query=context:47.10026792024

# Posts about movies
query=context:86.*
```

---

<div id="important-notes">
  ## Notas importantes
</div>

<Warning>
**No todas las publicaciones están anotadas.** La cobertura de anotaciones depende de:
- Soporte de idiomas
- Cobertura de temas en la taxonomía de X
- Riqueza semántica del texto de la publicación
</Warning>

- Las anotaciones no son retroactivas—solo se aplican cuando las entidades están siendo rastreadas
- La misma entidad puede aparecer en múltiples dominios (por ejemplo, una celebridad es tanto Persona como Actor)
- Los id de entidad son estables en todos los dominios
