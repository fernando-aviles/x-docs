X API usa números de versión en las rutas de los endpoints para proporcionar estabilidad mientras permite la evolución. Comprender nuestra estrategia de control de versiones te ayuda a planificar integraciones y mantenerte al día.

***

<div id="current-versions">
  ## Versiones actuales
</div>

| Versión | Estado | Descripción |
|:--------|:-------|:------------|
| **v2** | Actual | Endpoints modernos, precios flexibles, todas las funciones nuevas |
| **v1.1** | Heredada | Soporte limitado, actualizaciones mínimas |
| **Enterprise** | Disponible | Acceso de alto volumen con soporte dedicado |

<Tip>
  Utiliza **X API v2** para todos los proyectos nuevos. Aquí es donde se publican todas las funciones nuevas.
</Tip>

***

<div id="version-in-urls">
  ## Versión en las URL
</div>

El número de versión aparece en la ruta del endpoint:

```
https://api.x.com/2/tweets
                   ^
                   version
```

<div id="breaking-vs-non-breaking-changes">
  ## Cambios incompatibles y compatibles
</div>

<div id="breaking-changes-require-code-updates">
  ### Cambios incompatibles (requieren actualizaciones de código)
</div>

Estos cambios solo se dan en cambios de versión mayor:

* Eliminar un endpoint
* Eliminar un campo de respuesta
* Eliminar un parámetro de consulta
* Agregar un nuevo parámetro obligatorio
* Cambiar el tipo de datos de un campo
* Cambiar el nombre de un campo o recurso
* Cambiar códigos de respuesta o tipos de error
* Modificar los ámbitos de autorización

<div id="non-breaking-changes-additive">
  ### Cambios no incompatibles (aditivos)
</div>

Estos pueden ocurrir en cualquier momento sin cambios de versión:

* Agregar un nuevo endpoint
* Agregar un nuevo parámetro opcional
* Agregar un nuevo campo de respuesta
* Agregar nuevos ámbitos de OAuth
* Cambiar el texto del mensaje de error
* Establecer campos en null por motivos de privacidad o seguridad

<div id="deprecation-policy">
  ## Política de obsolescencia
</div>

Cuando lanzamos una nueva versión mayor:

1. **Obsolescencia**: La versión anterior se declara obsoleta
2. **Período de soporte**: La versión obsoleta sigue funcionando durante un período determinado
3. **Retirada**: La versión obsoleta se elimina

<div id="definitions">
  ### Definiciones
</div>

| Estado | Significado |
|:-------|:------------|
| **Active** | Totalmente admitido, con nuevas funciones y correcciones de errores |
| **Deprecated** | Sin nuevas funciones; solo corrección de errores críticos; se desaconseja su uso |
| **Retired** | Ya no está disponible |
