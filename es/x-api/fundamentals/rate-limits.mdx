Los límites de uso controlan la cantidad de solicitudes que puedes hacer a cada endpoint. Si superas estos límites, recibirás un error 429 hasta que se restablezca la ventana de tiempo.

***

<div id="how-rate-limits-work">
  ## Cómo funcionan los límites de uso
</div>

| Concepto | Descripción |
|:--------|:------------|
| **Ventana de tiempo** | Normalmente 15 minutos o 24 horas |
| **Límites por usuario** | Se aplican con OAuth 1.0a o tokens de usuario de OAuth 2.0 |
| **Límites por aplicación** | Se aplican con Bearer Token (solo para la aplicación) |
| **Límites por endpoint** | Cada endpoint tiene sus propios límites |

***

<div id="checking-your-limits">
  ## Comprobar tus límites
</div>

Los encabezados de la respuesta muestran el estado actual de tus límites de frecuencia:

```
x-rate-limit-limit: 900
x-rate-limit-remaining: 847
x-rate-limit-reset: 1705420800
```

| Encabezado               | Descripción                                          |
| :----------------------- | :--------------------------------------------------- |
| `x-rate-limit-limit`     | Límite máximo de solicitudes permitidas              |
| `x-rate-limit-remaining` | Solicitudes restantes en la ventana de tiempo        |
| `x-rate-limit-reset`     | Marca de tiempo Unix en que se restablece la ventana |

<div id="handling-rate-limits">
  ## Gestión de límites de frecuencia
</div>

Cuando superes un límite de frecuencia, recibirás una respuesta 429:

```json
{
  "errors": [{
    "code": 88,
    "message": "Rate limit exceeded"
  }]
}
```

<div id="recovery-strategy">
  ### Estrategia de recuperación
</div>

1. Consulta `x-rate-limit-reset` para saber cuándo se reinicia la ventana
2. Espera hasta ese momento antes de reintentar
3. Usa backoff exponencial si es necesario

```python
import time

def make_request_with_backoff(url, headers):
    response = requests.get(url, headers=headers)
    
    if response.status_code == 429:
        reset_time = int(response.headers.get('x-rate-limit-reset', 0))
        wait_time = max(reset_time - time.time(), 60)
        time.sleep(wait_time)
        return make_request_with_backoff(url, headers)
    
    return response
```

<div id="rate-limits-vs-billing">
  ## Límites de frecuencia vs. facturación
</div>

Los límites de frecuencia y la facturación son independientes:

| Concepto | Propósito |
|:--------|:--------|
| **Límites de frecuencia** | Controlan la frecuencia de las solicitudes para la estabilidad del sistema |
| **Facturación por uso** | Cobran por los datos recuperados (pago por uso) |

Puedes estar dentro de los límites de frecuencia pero aun así incurrir en costos de uso, o alcanzar los límites de frecuencia sin costo adicional.
