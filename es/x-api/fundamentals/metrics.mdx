La X API ofrece métricas de interacción para publicaciones y contenido multimedia. Puedes acceder a métricas públicas con cualquier método de autenticación o a métricas privadas de tu propio contenido con autenticación de usuario.

***

<div id="metric-types">
  ## Tipos de métricas
</div>

| Tipo | Autenticación | Descripción |
|:-----|:---------------|:------------|
| **Públicas** | Bearer Token | Visibles para cualquier persona (me gusta, reposts y respuestas) |
| **No públicas** | Contexto de usuario | Métricas privadas (impresiones, clics) |
| **Orgánicas** | Contexto de usuario | Métricas de vistas no promocionadas |
| **Promocionadas** | Contexto de usuario | Métricas de vistas de anuncios |

<Note>
  **Límite de 30 días**: las métricas no públicas, orgánicas y promocionadas solo están disponibles para publicaciones creadas en los últimos 30 días.
</Note>

***

<div id="available-metrics">
  ## Métricas disponibles
</div>

<div id="post-metrics">
  ### Métricas de publicaciones
</div>

| Métrica | Tipo | Ruta de campo |
|:-------|:-----|:-----------|
| Reposts | Público | `public_metrics.retweet_count` |
| Citas | Público | `public_metrics.quote_count` |
| Me gusta | Público | `public_metrics.like_count` |
| Respuestas | Público | `public_metrics.reply_count` |
| Impresiones | No público | `non_public_metrics.impression_count` |
| Clics en URL | No público | `non_public_metrics.url_link_clicks` |
| Clics en el perfil | No público | `non_public_metrics.user_profile_clicks` |

<div id="media-metrics-videos">
  ### Métricas de medios (videos)
</div>

| Métrica | Tipo | Ruta del campo |
|:-------|:-----|:-----------|
| Visualizaciones | Públicas | `public_metrics.view_count` |
| Reproducción al 0 % | No públicas | `non_public_metrics.playback_0_count` |
| Reproducción al 25 % | No públicas | `non_public_metrics.playback_25_count` |
| Reproducción al 50 % | No públicas | `non_public_metrics.playback_50_count` |
| Reproducción al 75 % | No públicas | `non_public_metrics.playback_75_count` |
| Reproducción al 100 % | No públicas | `non_public_metrics.playback_100_count` |

<div id="requesting-metrics">
  ## Solicitud de métricas
</div>

<div id="public-metrics-any-auth">
  ### Métricas públicas (con cualquier tipo de autenticación)
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

Respuesta:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "public_metrics": {
      "retweet_count": 50,
      "reply_count": 12,
      "like_count": 234,
      "quote_count": 5
    }
  }
}
```

<div id="private-metrics-user-context">
  ### Métricas privadas (contexto de usuario)
</div>

Requiere OAuth 1.0a u OAuth 2.0 con contexto de usuario para las publicaciones que te pertenecen:

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=non_public_metrics,organic_metrics" \
  -H "Authorization: OAuth oauth_consumer_key=...,oauth_token=..."
```

Respuesta:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "non_public_metrics": {
      "impression_count": 5432,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    },
    "organic_metrics": {
      "impression_count": 5432,
      "like_count": 234,
      "reply_count": 12,
      "retweet_count": 50,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    }
  }
}
```

<div id="video-metrics">
  ## Métricas de video
</div>

Para las métricas de reproducción de video, usa la expansión `media`:

```bash
curl "https://api.x.com/2/tweets/1234567890?\
tweet.fields=attachments&\
expansions=attachments.media_keys&\
media.fields=public_metrics,non_public_metrics" \
  -H "Authorization: OAuth ..."
```

Respuesta:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Check out this video!",
    "attachments": {
      "media_keys": ["13_9876543210"]
    }
  },
  "includes": {
    "media": [{
      "media_key": "13_9876543210",
      "type": "video",
      "public_metrics": {
        "view_count": 12543
      },
      "non_public_metrics": {
        "playback_0_count": 12543,
        "playback_25_count": 9876,
        "playback_50_count": 7654,
        "playback_75_count": 5432,
        "playback_100_count": 3210
      }
    }]
  }
}
```

<div id="organic-vs-promoted-metrics">
  ## Métricas orgánicas vs. promocionadas
</div>

Si una publicación se promocionó como un anuncio, las métricas se dividen entre vistas orgánicas y promocionadas:

| Contexto         | Descripción                                  |
| :--------------- | :------------------------------------------- |
| **Orgánico**     | Métricas de vistas normales en la cronología |
| **Promocionado** | Métricas de impresiones de anuncios pagados  |
| **Público**      | Total combinado (orgánico + promocionado)    |

Solicita ambas para ver el desglose:

```bash
tweet.fields=public_metrics,organic_metrics,promoted_metrics
```

<div id="metric-definitions">
  ## Definiciones de métricas
</div>

<Accordion title="Impresiones">
  Cantidad de veces que la publicación apareció en la pantalla de un usuario. No es única: el mismo usuario que la ve dos veces cuenta como dos impresiones.
</Accordion>

<Accordion title="Cantidad de reposts">
  Número de reposts (retuits). No incluye publicaciones con cita.
</Accordion>

<Accordion title="Cantidad de citas">
  Número de publicaciones con cita (reposts con comentario). Estas siempre son orgánicas.
</Accordion>

<Accordion title="Reproducciones de video">
  Agregado en todas las publicaciones que contienen el video. Un video reposteado en varias publicaciones tiene solo un conteo total de visualizaciones.
</Accordion>

<Accordion title="Cuartiles de reproducción">
  Número de usuarios únicos que reprodujeron el video hasta cada porcentaje. Útil para entender las tasas de abandono.
</Accordion>

<div id="requirements-summary">
  ## Resumen de requisitos
</div>

| Campo de métricas | Autenticación requerida |
|:------------------|:------------------------|
| `public_metrics` | Bearer Token (cualquiera) |
| `non_public_metrics` | Contexto de usuario (solo publicaciones propias) |
| `organic_metrics` | Contexto de usuario (solo publicaciones propias) |
| `promoted_metrics` | Contexto de usuario (solo publicaciones promocionadas) |
