Los endpoints de consulta de mensajes directos te permiten obtener eventos de DM del usuario autenticado, incluidos mensajes de conversaciones individuales y de grupo.

<div id="overview">
  ## Descripción general
</div>

<CardGroup cols={2}>
  <Card title="Todos los eventos de DM" icon="messages">
    Obtén todos los eventos de DM de un usuario
  </Card>

  <Card title="Uno a uno" icon="message">
    Obtén eventos de una conversación específica
  </Card>

  <Card title="Por ID de conversación" icon="comments">
    Obtén eventos por ID de conversación
  </Card>

  <Card title="Tipos de eventos" icon="bell">
    Mensajes, incorporaciones y salidas
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/dm_events`](/es/x-api/direct-messages/get-dm-events) | Obtener todos los eventos de DM para el usuario |
| GET | [`/2/dm_conversations/with/:participant_id/dm_events`](/es/x-api/direct-messages/get-dm-events-for-a-dm-conversation) | Obtener eventos de una conversación individual |
| GET | [`/2/dm_conversations/:dm_conversation_id/dm_events`](/es/x-api/direct-messages/get-dm-events-for-a-dm-conversation-1) | Obtener eventos por id de la conversación |

***

<div id="event-types">
  ## Tipos de eventos
</div>

| Evento | Descripción |
|:------|:------------|
| `MessageCreate` | Se envió un mensaje en la conversación |
| `ParticipantsJoin` | Un usuario se unió a la conversación |
| `ParticipantsLeave` | Un usuario abandonó la conversación |

***

<div id="data-retention">
  ## Retención de datos
</div>

<Note>
  Los eventos de los últimos **30 días** están disponibles a través de estos endpoints.
</Note>
