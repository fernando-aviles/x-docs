Los endpoints de Manage Direct Messages permiten enviar y eliminar mensajes directos en nombre de usuarios autenticados.

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | `/2/dm_conversations` | Crear una nueva conversación |
| POST | `/2/dm_conversations/with/:participant_id/messages` | Enviar un mensaje a una conversación individual |
| POST | `/2/dm_conversations/:dm_conversation_id/messages` | Enviar un mensaje a una conversación existente |
| DELETE | `/2/dm_events/:id` | Eliminar un evento de MD |

***

<div id="example-send-a-message">
  ## Ejemplo: enviar un mensaje
</div>

```bash
curl -X POST "https://api.x.com/2/dm_conversations/with/1234567890/messages" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello! How are you?"}'
```

<div id="example-response">
  ## Ejemplo de respuesta
</div>

```json
{
  "data": {
    "dm_conversation_id": "1234567890-0987654321",
    "dm_event_id": "1122334455667788990"
  }
}
```

<div id="message-types">
  ## Tipos de mensajes
</div>

Puedes enviar mensajes de texto y adjuntar archivos multimedia:

```json
{
  "text": "¡Mira esta foto!",
  "attachments": [{
    "media_id": "1234567890123456789"
  }]
}
```
