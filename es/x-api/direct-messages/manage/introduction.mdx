Los endpoints de administración de Mensajes Directos te permiten enviar y eliminar Mensajes Directos en nombre de usuarios autenticados.

<div id="overview">
  ## Descripción general
</div>

<CardGroup cols={2}>
  <Card title="Enviar mensaje" icon="paper-plane">

  <Card title="Eliminar mensaje" icon="trash">

  <Card title="Mensajes de grupo" icon="users">

***

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | `/2/dm_conversations` | Crear una nueva conversación |
| POST | `/2/dm_conversations/with/:participant_id/messages` | Enviar a una conversación individual |
| POST | `/2/dm_conversations/:dm_conversation_id/messages` | Enviar a una conversación existente |
| DELETE | `/2/dm_events/:id` | Eliminar un evento de DM |
----------------------------------------------------------

<div id="example-response">
  ## Ejemplo: Enviar un mensaje
</div>

```bash
curl -X POST "https://api.x.com/2/dm_conversations/with/1234567890/messages" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello! How are you?"}'
```

<div id="message-types">
  ## Ejemplo de respuesta
</div>

```json
{
  "data": {
    "dm_conversation_id": "1234567890-0987654321",
    "dm_event_id": "1122334455667788990"
  }
}
```

<div id="getting-started">
  ## Tipos de mensajes
</div>

Puedes enviar mensajes de texto y adjuntar medios:

```json
{
  "text": "¡Mira esta foto!",
  "attachments": [{
    "media_id": "1234567890123456789"
  }]
}
```
