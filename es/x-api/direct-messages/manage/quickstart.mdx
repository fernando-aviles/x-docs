Esta guía te mostrará cómo enviar Mensajes Directos y crear conversaciones de grupo.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * Un User Access Token (OAuth 2.0 PKCE con los ámbitos `dm.write` y `dm.read`)
</Note>

***

<div id="send-a-one-to-one-message">
  ## Enviar un mensaje individual
</div>

<Steps>
  <Step title="Obtener el ID de usuario del destinatario">
    Necesitas el ID de usuario de la persona a la que quieres enviar un mensaje. Puedes obtenerlo mediante el [endpoint de búsqueda de usuarios](/es/x-api/users/lookup/introduction).
  </Step>

  <Step title="Enviar el mensaje">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/dm_conversations/with/9876543210/messages" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"text": "¡Hola! Este es un mensaje desde la API."}'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Enviar un mensaje individual
      response = client.dm.send_message(
          participant_id="9876543210",
          text="¡Hola! Este es un mensaje desde la API."
      )

      print(f"Mensaje enviado: {response.data.dm_event_id}")
      print(f"Conversación: {response.data.dm_conversation_id}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Enviar un mensaje individual
      const response = await client.dm.sendMessage({
        participantId: "9876543210",
        text: "¡Hola! Este es un mensaje desde la API.",
      });

      console.log(`Mensaje enviado: ${response.data?.dm_event_id}`);
      console.log(`Conversación: ${response.data?.dm_conversation_id}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Revisa la respuesta">
    ```json
    {
      "data": {
        "dm_conversation_id": "1234567890-9876543210",
        "dm_event_id": "1582103724607971332"
      }
    }
    ```
  </Step>
</Steps>

<div id="create-a-group-conversation">
  ## Crear una conversación de grupo
</div>

<Steps>
  <Step title="Definir participantes">
    Reúne los identificadores de usuario de todas las personas que quieres incluir en el grupo (sin incluirte a ti).
  </Step>

  <Step title="Crear el grupo con el primer mensaje">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/dm_conversations" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{
          "conversation_type": "Group",
          "participant_ids": ["944480690", "906948460078698496"],
          "message": {"text": "¡Bienvenidos a nuestro nuevo grupo!"}
        }'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Crear una conversación de grupo
      response = client.dm.create_conversation(
          conversation_type="Group",
          participant_ids=["944480690", "906948460078698496"],
          message={"text": "¡Bienvenidos a nuestro nuevo grupo!"}
      )

      print(f"Grupo creado: {response.data.dm_conversation_id}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Crear una conversación de grupo
      const response = await client.dm.createConversation({
        conversationType: "Group",
        participantIds: ["944480690", "906948460078698496"],
        message: { text: "¡Bienvenidos a nuestro nuevo grupo!" },
      });

      console.log(`Grupo creado: ${response.data?.dm_conversation_id}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Recibir el identificador de la conversación">
    ```json
    {
      "data": {
        "dm_conversation_id": "1582103724607971328",
        "dm_event_id": "1582103724607971332"
      }
    }
    ```

    Guarda el `dm_conversation_id` para añadir más mensajes más adelante.
  </Step>
</Steps>

<div id="add-a-message-to-an-existing-conversation">
  ## Agregar un mensaje a una conversación existente
</div>

Envía un mensaje a una conversación de la que ya formas parte:

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/dm_conversations/1582103724607971328/messages" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"text": "Agregando otro mensaje a la conversación."}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Agregar un mensaje a una conversación existente
  response = client.dm.send_message_to_conversation(
      dm_conversation_id="1582103724607971328",
      text="Agregando otro mensaje a la conversación."
  )

  print(f"Mensaje enviado: {response.data.dm_event_id}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Agregar un mensaje a una conversación existente
  const response = await client.dm.sendMessageToConversation(
    "1582103724607971328",
    { text: "Agregando otro mensaje a la conversación." }
  );

  console.log(`Mensaje enviado: ${response.data?.dm_event_id}`);
  ```
</CodeGroup>

<div id="send-a-message-with-media">
  ## Enviar un mensaje con contenido multimedia
</div>

<Steps>
  <Step title="Subir el contenido multimedia">
    Primero, sube tu contenido multimedia utilizando el [endpoint Media Upload](/es/x-api/media/quickstart/media-upload-chunked).
  </Step>

  <Step title="Enviar con contenido multimedia adjunto">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/dm_conversations/with/9876543210/messages" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{
          "text": "Check out this image!",
          "attachments": [{"media_id": "1234567890123456789"}]
        }'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Enviar un mensaje con contenido multimedia
      response = client.dm.send_message(
          participant_id="9876543210",
          text="Check out this image!",
          attachments=[{"media_id": "1234567890123456789"}]
      )

      print(f"Mensaje con contenido multimedia enviado: {response.data.dm_event_id}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Enviar un mensaje con contenido multimedia
      const response = await client.dm.sendMessage({
        participantId: "9876543210",
        text: "Check out this image!",
        attachments: [{ mediaId: "1234567890123456789" }],
      });

      console.log(`Mensaje con contenido multimedia enviado: ${response.data?.dm_event_id}`);
      ```
    </CodeGroup>
  </Step>
</Steps>

<div id="delete-a-message">
  ## Eliminar un mensaje
</div>

Elimina un mensaje que enviaste:

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/dm_events/1582103724607971332" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Eliminar un mensaje
  response = client.dm.delete_message("1582103724607971332")
  print(f"Eliminado: {response.data.deleted}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Eliminar un mensaje
  const response = await client.dm.deleteMessage("1582103724607971332");
  console.log(`Eliminado: ${response.data?.deleted}`);
  ```
</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "deleted": true
  }
}
```

<Warning>
  Solo puedes eliminar los mensajes que tú enviaste; no puedes eliminar los mensajes de otros participantes.
</Warning>

<div id="required-scopes">
  ## Permisos requeridos
</div>

Cuando uses OAuth 2.0 PKCE, tu token de acceso debe tener estos permisos:

| Scope | Descripción |
|:------|:------------|
| `dm.write` | Enviar y eliminar mensajes |
| `dm.read` | Leer conversaciones (requerido con dm.write) |
| `tweet.read` | Requerido para algunas expansions |
| `users.read` | Requerido para expansions de usuario |
