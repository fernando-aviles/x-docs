Esta guía explica cómo enviar Mensajes Directos y crear conversaciones grupales.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una aplicación aprobada
  * Un token de acceso de usuario (OAuth 2.0 PKCE con los permisos `dm.write` y `dm.read`)
</Note>

***

<div id="send-a-one-to-one-message">
  ## Enviar un mensaje uno a uno
</div>

<Steps>
  <Step title="Obtén el id de usuario del destinatario">
    Necesitas el id de usuario de la persona a la que quieres enviar el mensaje. Puedes obtenerlo en el [endpoint de búsqueda de usuarios](/es/x-api/users/lookup/introduction).
  </Step>

  <Step title="Envía el mensaje">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/dm_conversations/with/9876543210/messages" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"text": "Hello! This is a message from the API."}'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Send a one-to-one message
      response = client.dm.send_message(
          participant_id="9876543210",
          text="Hello! This is a message from the API."
      )

      print(f"Message sent: {response.data.dm_event_id}")
      print(f"Conversation: {response.data.dm_conversation_id}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Send a one-to-one message
      const response = await client.dm.sendMessage({
        participantId: "9876543210",
        text: "Hello! This is a message from the API.",
      });

      console.log(`Message sent: ${response.data?.dm_event_id}`);
      console.log(`Conversation: ${response.data?.dm_conversation_id}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Revisa la respuesta">
    ```json
    {
      "data": {
        "dm_conversation_id": "1234567890-9876543210",
        "dm_event_id": "1582103724607971332"
      }
    }
    ```
  </Step>
</Steps>

<div id="create-a-group-conversation">
  ## Crear una conversación de grupo
</div>

<Steps>
  <Step title="Definir participantes">
    Recopila los ID de usuario de todos los que quieras en el grupo (excluyéndote a ti mismo).
  </Step>

  <Step title="Crear el grupo con el primer mensaje">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/dm_conversations" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{
          "conversation_type": "Group",
          "participant_ids": ["944480690", "906948460078698496"],
          "message": {"text": "Welcome to our new group!"}
        }'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Crear una conversación de grupo
      response = client.dm.create_conversation(
          conversation_type="Group",
          participant_ids=["944480690", "906948460078698496"],
          message={"text": "Welcome to our new group!"}
      )

      print(f"Grupo creado: {response.data.dm_conversation_id}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Crear una conversación de grupo
      const response = await client.dm.createConversation({
        conversationType: "Group",
        participantIds: ["944480690", "906948460078698496"],
        message: { text: "Welcome to our new group!" },
      });

      console.log(`Grupo creado: ${response.data?.dm_conversation_id}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Obtener el ID de la conversación">
    ```json
    {
      "data": {
        "dm_conversation_id": "1582103724607971328",
        "dm_event_id": "1582103724607971332"
      }
    }
    ```

    Guarda el `dm_conversation_id` para poder agregar más mensajes más adelante.
  </Step>
</Steps>

<div id="add-a-message-to-an-existing-conversation">
  ## Añadir un mensaje a una conversación existente
</div>

Envía un mensaje a una conversación en la que ya participas:

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/dm_conversations/1582103724607971328/messages" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"text": "Adding another message to the conversation."}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Añadir un mensaje a una conversación existente
  response = client.dm.send_message_to_conversation(
      dm_conversation_id="1582103724607971328",
      text="Adding another message to the conversation."
  )

  print(f"Message sent: {response.data.dm_event_id}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Añadir un mensaje a una conversación existente
  const response = await client.dm.sendMessageToConversation(
    "1582103724607971328",
    { text: "Adding another message to the conversation." }
  );

  console.log(`Message sent: ${response.data?.dm_event_id}`);
  ```
</CodeGroup>

<div id="send-a-message-with-media">
  ## Enviar un mensaje con contenido multimedia
</div>

<Steps>
  <Step title="Subir el contenido multimedia">
    Primero, sube el contenido multimedia usando el [endpoint Media Upload](/es/x-api/media/quickstart/media-upload-chunked).
  </Step>

  <Step title="Enviar con contenido multimedia adjunto">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/dm_conversations/with/9876543210/messages" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{
          "text": "Check out this image!",
          "attachments": [{"media_id": "1234567890123456789"}]
        }'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Enviar mensaje con contenido multimedia
      response = client.dm.send_message(
          participant_id="9876543210",
          text="Check out this image!",
          attachments=[{"media_id": "1234567890123456789"}]
      )

      print(f"Mensaje con contenido multimedia enviado: {response.data.dm_event_id}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Enviar mensaje con contenido multimedia
      const response = await client.dm.sendMessage({
        participantId: "9876543210",
        text: "Check out this image!",
        attachments: [{ mediaId: "1234567890123456789" }],
      });

      console.log(`Mensaje con contenido multimedia enviado: ${response.data?.dm_event_id}`);
      ```
    </CodeGroup>
  </Step>
</Steps>

<div id="delete-a-message">
  ## Eliminar un mensaje
</div>

Elimina un mensaje que has enviado:

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/dm_events/1582103724607971332" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Eliminar un mensaje
  response = client.dm.delete_message("1582103724607971332")
  print(f"Deleted: {response.data.deleted}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Eliminar un mensaje
  const response = await client.dm.deleteMessage("1582103724607971332");
  console.log(`Deleted: ${response.data?.deleted}`);
  ```
</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "deleted": true
  }
}
```

<Warning>
  Solo puedes eliminar los mensajes que enviaste; no puedes eliminar los mensajes de otros participantes.
</Warning>

<div id="required-scopes">
  ## Alcances obligatorios
</div>

Cuando utilices OAuth 2.0 PKCE, tu token de acceso debe tener estos alcances:

| Alcance | Descripción |
|:--------|:------------|
| `dm.write` | Enviar y eliminar mensajes |
| `dm.read` | Leer conversaciones (obligatorio junto con dm.write) |
| `tweet.read` | Obligatorio para algunas expansions |
| `users.read` | Obligatorio para expansions de usuarios |
