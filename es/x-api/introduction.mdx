<div id="key-features">
  ## Funciones clave
</div>

<Tabs>
  <Tab title="Acceso a datos">
    ### Objetos de datos enriquecidos

    Accede a datos detallados y estructurados de publicaciones, usuarios, contenido multimedia y más:

    * **Publicaciones**: Texto completo, métricas, entidades, anotaciones, hilos de conversación
    * **Usuarios**: Perfiles, recuentos de seguidores, estado de verificación
    * **Contenido multimedia**: Imágenes, videos, GIFs con metadatos
    * **Encuestas**: Opciones y recuentos de votos

    Personaliza las respuestas con [fields](/es/x-api/fundamentals/fields) y [expansions](/es/x-api/fundamentals/expansions) para obtener exactamente los datos que necesitas.
  </Tab>

  <Tab title="Streaming en tiempo real">
    ### Flujo filtrado

    Recibe publicaciones en tiempo real en cuanto se publican. Define hasta 1.000 reglas de filtrado para recibir solo las publicaciones que coincidan.

    ```bash
    # Agregar una regla
    curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{"add": [{"value": "from:xdevelopers"}]}'

    # Conectarse al flujo
    curl "https://api.x.com/2/tweets/search/stream" \
      -H "Authorization: Bearer $TOKEN"
    ```

    [Más información sobre el flujo filtrado →](/es/x-api/posts/filtered-stream/introduction)
  </Tab>

  <Tab title="Búsqueda y análisis">
    ### Búsqueda en todo el archivo

    Busca en todo el historial de publicaciones públicas, desde 2006. Crea consultas con operadores para usuarios, palabras clave, fechas y más.

    ```bash
    curl "https://api.x.com/2/tweets/search/all?query=AI%20lang:en" \
      -H "Authorization: Bearer $TOKEN"
    ```

    ### Métricas

    Accede a métricas de interacción, incluidas impresiones, Me gusta, republicaciones, respuestas y reproducciones de video.

    [Más información sobre la búsqueda →](/es/x-api/posts/search/introduction)
  </Tab>
</Tabs>

<div id="quick-start">
  ## Inicio rápido
</div>

<Steps>
  <Step title="Crea una cuenta de desarrollador">
    Regístrate en [console.x.com](https://console.x.com) y crea una app.
  </Step>

  <Step title="Obtén tus credenciales">
    Genera tu Bearer Token para solicitudes solo de la aplicación.
  </Step>

  <Step title="Haz una solicitud">
    Prueba a buscar un usuario:

    ```bash
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>
</Steps>
