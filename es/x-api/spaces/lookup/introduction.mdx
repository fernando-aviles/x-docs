<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/spaces/:id`](/es/x-api/spaces/get-space-by-id) | Obtener un Espacio por ID |
| GET | [`/2/spaces`](/es/x-api/spaces/get-spaces-by-ids) | Obtener Espacios por IDs |
| GET | [`/2/spaces/by/creator_ids`](/es/x-api/spaces/get-spaces-by-creator-ids) | Obtener Espacios por IDs de usuarios creadores |
| GET | [`/2/spaces/:id/buyers`](/es/x-api/spaces/get-space-ticket-buyers) | Obtener los compradores de entradas de un Espacio |
| GET | [`/2/spaces/:id/tweets`](/es/x-api/spaces/get-space-posts) | Obtener Publicaciones compartidas en un Espacio |

***

<div id="response-fields">
  ## Campos de respuesta
</div>

De forma predeterminada, la respuesta incluye `id` y `state`. Solicita campos adicionales:

| Campo | Descripción |
|:------|:------------|
| `title` | Título del Space |
| `host_ids` | IDs de usuarios anfitriones |
| `speaker_ids` | IDs de usuarios oradores |
| `participant_count` | Número de participantes |
| `scheduled_start` | Hora de inicio programada |
| `started_at` | Hora de inicio real |
| `ended_at` | Hora de finalización |
| `is_ticketed` | Indica si el Space tiene entradas |

<div id="space-states">
  ### Estados de un Space
</div>

| Estado | Descripción |
|:------|:------------|
| `live` | Actualmente activo |
| `scheduled` | Programado para el futuro |
| `ended` | Ha finalizado |

***

<div id="example-request">
  ## Ejemplo de solicitud
</div>

```bash
curl "https://api.x.com/2/spaces/1DXxyRYNejbKM?\
space.fields=title,host_ids,participant_count,scheduled_start,state" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
