El endpoint Spaces Search te permite buscar Spaces en vivo o programados por palabra clave. Encuentra Spaces sobre temas que te interesen.

<div id="endpoint">
  ## Endpoint
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/spaces/search`](/es/x-api/spaces/search-spaces) | Buscar Spaces |

***

<div id="parameters">
  ## Parámetros
</div>

| Parámetro | Descripción |
|:----------|:------------|
| `query` | Consulta de búsqueda (obligatoria) |
| `state` | Filtrar por `live` o `scheduled` |
| `space.fields` | Campos adicionales de Space |
| `expansions` | Objetos relacionados que se incluirán |

***

<div id="example-request">
  ## Ejemplo de solicitud
</div>

```bash
curl "https://api.x.com/2/spaces/search?\
query=AI&\
state=live&\
space.fields=title,host_ids,participant_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## Ejemplo de respuesta
</div>

```json
{
  "data": [

```
