Esta guía te enseñará a buscar Spaces por palabra clave.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una App aprobada
  * El Bearer Token de tu App
</Note>

<div id="search-for-spaces">
  ## Buscar Spaces
</div>

Busca Spaces que coincidan con una palabra clave determinada:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/spaces/search?\
  query=AI&\
  space.fields=title,host_ids,participant_count,state&\
  state=live" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Buscar Spaces
  response = client.spaces.search(
      query="AI",
      space_fields=["title", "host_ids", "participant_count", "state"],
      state="live"
  )

  for space in response.data:
      print(f"{space.title} - {space.participant_count} participants")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Buscar Spaces
  const response = await client.spaces.search({
    query: "AI",
    spaceFields: ["title", "host_ids", "participant_count", "state"],
    state: "live",
  });

  response.data?.forEach((space) => {
    console.log(`${space.title} - ${space.participant_count} participants`);
  });
  ```
</CodeGroup>

<div id="include-host-information">
  ## Incluir información del anfitrión
</div>

Amplía los datos del usuario anfitrión:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/spaces/search?\
  query=AI&\
  space.fields=title,host_ids,state&\
  expansions=host_ids&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Buscar espacios con información del anfitrión
  response = client.spaces.search(
      query="AI",
      space_fields=["title", "host_ids", "state"],
      expansions=["host_ids"],
      user_fields=["username", "verified"]
  )

  for space in response.data:
      print(f"{space.title}")
  # La información del anfitrión está en response.includes.users
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Buscar espacios con información del anfitrión
  const response = await client.spaces.search({
    query: "AI",
    spaceFields: ["title", "host_ids", "state"],
    expansions: ["host_ids"],
    userFields: ["username", "verified"],
  });

  response.data?.forEach((space) => {
    console.log(space.title);
  });
  // La información del anfitrión está en response.includes?.users
  ```
</CodeGroup>

<div id="common-parameters">
  ## Parámetros comunes
</div>

| Parámetro | Descripción |
|:----------|:------------|
| `query` | Consulta de búsqueda (requerida) |
| `state` | Filtro: `live`, `scheduled` o `all` |
| `max_results` | Resultados que se devolverán (1-100) |
| `space.fields` | Campos de Space a incluir |
| `expansions` | Objetos relacionados a incluir |
| `user.fields` | Campos de usuario a incluir |
