Un objeto multimedia representa una única foto, vídeo o GIF animado. Los objetos multimedia se utilizan en muchos endpoints dentro de la X API y pueden incluirse en Publicaciones, Mensajes Directos, perfiles de usuario, creatividades publicitarias y otros contextos. Cada objeto multimedia puede tener múltiples variantes de visualización o reproducción, con diferentes resoluciones o formatos.

<div id="media-types-size-restrictions">
  ## Tipos de medios y restricciones de tamaño
</div>

Restricciones de tamaño para carga mediante la API

* **Imagen**: `5 MB`
* **GIF**: `15 MB`
* **Vídeo**: `512 MB` (cuando se usa `media_category=amplify_video`)

<div id="creation">
  ## Creación
</div>

Objetos como Publicaciones, Mensajes Directos, fotos de perfil de usuario, tarjetas de Ads alojadas, etc. pueden contener uno o más objetos multimedia. Estos objetos de nivel superior se conocen colectivamente como entidades. A la API de creación de entidades correspondiente (por ejemplo, [`POST /2/tweets`](/es/x-api/posts/creation-of-a-post)) se le pueden pasar uno o más objetos multimedia usando un `media_id` único.

Se puede crear una entidad que contiene uno o varios objetos multimedia siguiendo estos pasos:

1. Sube los archivos multimedia usando la carga [fragmentada](/es/x-api-/media/quickstart/media-upload-chunked) recomendada (imágenes/GIF/video) o la carga [simple](/es/x-api/media-upload/media-upload) anterior (solo imágenes).
2. Obtén un `media_id` del paso 1. Este paso se puede repetir varias veces con contenido multimedia diferente si la entidad permite pasar varios parámetros `media_id`.
3. Crea la entidad llamando al endpoint correspondiente, incluyendo el `media_id` y otros parámetros obligatorios. Por ejemplo, adjunta un `media_id` a una Publicación usando el endpoint [`POST /2/tweets`](/es/x-api/posts/creation-of-a-post).
