<div id="overview">
  ## Descripción general
</div>

Un objeto multimedia representa una única foto, un video o un GIF animado. Los objetos multimedia se utilizan en muchos endpoints dentro de la API de Twitter y pueden incluirse en Tuits, mensajes directos, perfiles de usuario, creativos publicitarios y en otros lugares. Cada objeto multimedia puede tener múltiples variantes de visualización o reproducción, con diferentes resoluciones o formatos.

<div id="media-types-size-restrictions">
  ## Tipos de medios y restricciones de tamaño
</div>

Restricciones de tamaño para subir a través de la API 

- Imagen 5 MB
- GIF 15 MB
- Vídeo 512 MB (cuando se usa media_category=amplify)

<div id="creation">
  ## Creación
</div>

Objetos como Tuits, Mensajes Directos, fotos de perfil de usuario, tarjetas de anuncios alojadas, etc. pueden contener uno o más objetos multimedia. Estos objetos de nivel superior se conocen colectivamente como entidades. A la API de creación de entidades correspondiente (por ejemplo, POST statuses/update) se le pueden pasar uno o más objetos multimedia usando un media_id único.

Una entidad que contenga uno o varios objetos multimedia se puede crear siguiendo estos pasos:

1. Carga el/los archivo(s) multimedia usando la carga segmentada recomendada (imágenes/GIF/video) o la carga simple anterior (solo imágenes).
2. Recibe un media_id del paso 1. Este paso se puede repetir varias veces con contenido multimedia diferente si la entidad permite que se pasen varios parámetros media_id.
3. Crea la entidad llamando al endpoint correspondiente, incluyendo el media_id y otros parámetros obligatorios. Por ejemplo, adjunta un media_id a un Tuit usando el endpoint POST statuses/update.
