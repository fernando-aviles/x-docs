<div id="overview">
  ## Descripción general
</div>

Un objeto multimedia representa una única foto, vídeo o GIF animado. Los objetos multimedia se utilizan en muchos endpoints de la Twitter API y pueden incluirse en Tweets, Mensajes Directos, perfiles de usuario, creativos publicitarios y otros contextos. Cada objeto multimedia puede tener múltiples variantes de visualización o reproducción, con distintas resoluciones o formatos.

<div id="media-types-size-restrictions">
  ## Tipos de medios y restricciones de tamaño
</div>

Restricciones de tamaño para cargar mediante la API 

- Imagen 5 MB
- GIF 15 MB
- Video 512 MB (cuando se usa media_category=amplify)

<div id="creation">
  ## Creación
</div>

Objetos como Tweets, Mensajes Directos, fotos de perfil de usuario, tarjetas de Ads alojadas, etc. pueden contener uno o varios objetos multimedia. A la API de creación de entidades correspondiente (por ejemplo, POST statuses/update) se le pueden pasar uno o varios objetos multimedia mediante un media_id único.

Puedes crear una entidad que contenga uno o varios objetos multimedia siguiendo estos pasos:

1. Sube el/los archivo(s) multimedia usando la carga segmentada recomendada (imágenes/GIF/vídeo) o la carga simple anterior (solo imágenes).
2. Obtén un media_id del paso 1. Este paso se puede repetir varias veces con diferentes archivos multimedia si la entidad permite que se pasen varios parámetros media_id.
3. Crea la entidad llamando al endpoint correspondiente e incluyendo el media_id y los demás parámetros obligatorios. Por ejemplo, adjunta un media_id a un Tweet usando el endpoint POST statuses/update.

<div id="retrieving">
  ## Recuperación
</div>

Consulte el objeto Media en el diccionario de datos de Tweet.
