<div id="overview">
  ## Descripción general
</div>

Un objeto multimedia representa una única foto, video o GIF animado. Los objetos multimedia son utilizados por muchos endpoints dentro de la Twitter API y pueden incluirse en Tuits, Mensajes Directos, perfiles de usuario, piezas creativas publicitarias y otros lugares. Cada objeto multimedia puede tener múltiples variantes de visualización o reproducción, con diferentes resoluciones o formatos.

<div id="media-types-size-restrictions">
  ## Tipos de medios y restricciones de tamaño
</div>

Restricciones de tamaño para subir mediante la API 

- Imagen 5 MB
- GIF 15 MB
- Vídeo 512 MB (cuando se usa media_category=amplify)

<div id="creation">
  ## Creación
</div>

Objetos como Tuits, Mensajes Directos, fotos de perfil de usuario, tarjetas de Ads alojadas, etc. pueden contener uno o más objetos multimedia. Estos objetos de nivel superior se conocen colectivamente como entidades. A la API de creación de entidades correspondiente (por ejemplo, POST statuses/update) se le puede pasar uno o más objetos multimedia usando un media_id único.

Puedes crear una entidad que contenga uno o más objetos multimedia siguiendo estos pasos:

1. Sube los archivos multimedia utilizando la carga segmentada recomendada (imágenes/GIF/video) o la carga simple anterior (solo imágenes).
2. Obtén un media_id en el paso 1. Este paso se puede repetir varias veces con multimedia diferente si la entidad permite que se pasen varios parámetros media_id.
3. Crea la entidad llamando al endpoint correspondiente, incluyendo el media_id y otros parámetros obligatorios. Por ejemplo, adjunta un media_id a un Tuit utilizando el endpoint POST statuses/update.

  ## Recuperar
