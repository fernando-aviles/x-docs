Esta guía describe el proceso de carga de videos y archivos multimedia grandes mediante el flujo de trabajo de carga en fragmentos.

Para cargar videos o medios de gran tamaño, debes:

1. **INIT** — Inicializar la carga y obtener un `media_id`
2. **APPEND** — Cargar cada fragmento del archivo
3. **FINALIZE** — Completar la carga
4. **STATUS** — (Si es necesario) Esperar a que finalice el procesamiento

<Note>
  Consulta [este código de ejemplo](https://github.com/xdevplatform/large-video-upload-python) para ver un ejemplo completo en Python.
</Note>

***

<div id="step-1-initialize-upload-init">
  ## Paso 1: Iniciar la carga (INIT)
</div>

Inicia la sesión de subida para obtener un `media_id`:

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/media/upload" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: multipart/form-data" \
    -F "command=INIT" \
    -F "media_type=video/mp4" \
    -F "total_bytes=1048576" \
    -F "media_category=amplify_video"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Inicializar la subida segmentada
  response = client.media.init_upload(
      media_type="video/mp4",
      total_bytes=1048576,
      media_category="amplify_video"
  )

  media_id = response.data.id
  print(f"Media ID: {media_id}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Inicializar la subida segmentada
  const response = await client.media.initUpload({
    mediaType: "video/mp4",
    totalBytes: 1048576,
    mediaCategory: "amplify_video",
  });

  const mediaId = response.data?.id;
  console.log(`Media ID: ${mediaId}`);
  ```
</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "id": "1880028106020515840",
    "media_key": "13_1880028106020515840",
    "expires_after_secs": 1295999
  }
}
```

***

<div id="step-2-upload-chunks-append">
  ## Paso 2: Subir fragmentos (APPEND)
</div>

Sube cada fragmento del archivo. Por ejemplo, divide un archivo de 3 MB en 3 fragmentos:

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/media/upload" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: multipart/form-data" \
    -F "command=APPEND" \
    -F "media_id=1880028106020515840" \
    -F "segment_index=0" \
    -F "media=@/path/to/chunk1.mp4"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Subir fragmentos
  chunk_size = 1024 * 1024  # fragmentos de 1 MB

  with open("video.mp4", "rb") as f:
      segment_index = 0
      while True:
          chunk = f.read(chunk_size)
          if not chunk:
              break
          
          client.media.append_upload(
              media_id=media_id,
              segment_index=segment_index,
              media=chunk
          )
          segment_index += 1
          print(f"Fragmento {segment_index} subido")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";
  import fs from "fs";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Subir fragmentos
  const chunkSize = 1024 * 1024; // fragmentos de 1 MB
  const fileBuffer = fs.readFileSync("video.mp4");

  let segmentIndex = 0;
  for (let offset = 0; offset < fileBuffer.length; offset += chunkSize) {
    const chunk = fileBuffer.slice(offset, offset + chunkSize);
    
    await client.media.appendUpload({
      mediaId,
      segmentIndex,
      media: chunk,
    });
    
    console.log(`Fragmento ${segmentIndex + 1} subido`);
    segmentIndex++;
  }
  ```
</CodeGroup>

<Info>
  **Ventajas de usar fragmentos:**

  * Mayor fiabilidad en redes lentas
  * Las subidas se pueden pausar y reanudar
  * Los fragmentos con errores se pueden reintentar de forma individual
</Info>

***

<div id="step-3-finalize-upload-finalize">
  ## Paso 3: Finalizar la carga (FINALIZE)
</div>

Finaliza la carga una vez que se hayan enviado todos los fragmentos:

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/media/upload" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: multipart/form-data" \
    -F "command=FINALIZE" \
    -F "media_id=1880028106020515840"
  ```

  ```python SDK de Python
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Finalizar la carga
  response = client.media.finalize_upload(media_id=media_id)

  print(f"Processing state: {response.data.processing_info.state}")
  ```

  ```javascript SDK de JavaScript
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Finalizar la carga
  const response = await client.media.finalizeUpload({ mediaId });

  console.log(`Processing state: ${response.data?.processing_info?.state}`);
  ```
</CodeGroup>

**Respuesta:**

```json
{
  "data": {
    "id": "1880028106020515840",
    "media_key": "13_1880028106020515840",
    "size": 1048576,
    "expires_after_secs": 86400,
    "processing_info": {
      "state": "pending",
      "check_after_secs": 1
    }
  }
}
```

<Note>
  Si se devuelve `processing_info`, ve al Paso 4 para esperar a que finalice el procesamiento. De lo contrario, el contenido multimedia ya está listo para usarse.
</Note>

***

<div id="step-4-check-status-status">
  ## Paso 4: Comprobar el estado (STATUS)
</div>

Si se devolvió `processing_info`, consulta periódicamente hasta que se complete el procesamiento:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/media/upload?command=STATUS&media_id=1880028106020515840" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client
  import time

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Espera a que se complete el procesamiento
  while True:
      response = client.media.get_status(media_id=media_id)
      state = response.data.processing_info.state
      
      if state == "succeeded":
          print("¡Contenido multimedia listo!")
          break
      elif state == "failed":
          print("El procesamiento falló")
          break
      else:
          check_after = response.data.processing_info.check_after_secs
          print(f"Procesando... se volverá a comprobar en {check_after}s")
          time.sleep(check_after)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Espera a que se complete el procesamiento
  while (true) {
    const response = await client.media.getStatus({ mediaId });
    const state = response.data?.processing_info?.state;
    
    if (state === "succeeded") {
      console.log("¡Contenido multimedia listo!");
      break;
    } else if (state === "failed") {
      console.log("El procesamiento falló");
      break;
    } else {
      const checkAfter = response.data?.processing_info?.check_after_secs ?? 1;
      console.log(`Procesando... se volverá a comprobar en ${checkAfter}s`);
      await new Promise((r) => setTimeout(r, checkAfter * 1000));
    }
  }
  ```
</CodeGroup>

**Estados de procesamiento:** `pending` → `in_progress` → `succeeded` o `failed`

<div id="step-5-create-post-with-media">
  ## Paso 5: Crear una Publicación con contenido multimedia
</div>

Cuando haya finalizado el procesamiento, crea una Publicación con contenido multimedia:

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/tweets" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "text": "Check out this video!",
      "media": {
        "media_ids": ["1880028106020515840"]
      }
    }'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Crear una Publicación con contenido multimedia
  response = client.posts.create(
      text="Check out this video!",
      media={"media_ids": [media_id]}
  )

  print(f"Posted: {response.data.id}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Crear una Publicación con contenido multimedia
  const response = await client.posts.create({
    text: "Check out this video!",
    media: { mediaIds: [mediaId] },
  });

  console.log(`Posted: ${response.data?.id}`);
  ```
</CodeGroup>
