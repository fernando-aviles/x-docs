<div id="overview">
  ## Descripción general
</div>

El grupo de endpoints de flujo filtrado permite a los desarrolladores filtrar un flujo de Publicaciones públicas. La funcionalidad de este grupo de endpoints incluye varios endpoints que te permiten crear y administrar reglas, y aplicar esas reglas para filtrar un flujo de Publicaciones que devolverá Publicaciones públicas coincidentes. Este grupo de endpoints permite a los usuarios escuchar temas y eventos específicos, monitorear la conversación en torno a competiciones, entender cómo se desarrollan las tendencias y mucho más.

Los desarrolladores pueden usar el [endpoint de reglas](/es/x-api/posts/filtered-stream#post-2-tweets-search-stream-rules) REST para agregar y eliminar reglas con las que filtrar Publicaciones que coincidan con un criterio definido. Estas [reglas](/es/x-api/posts/filtered-stream#building-rules-for-filtered-stream) se pueden crear con operadores que coinciden con atributos de la Publicación, como palabras clave del mensaje, hashtags y URL. Los operadores y las cláusulas de reglas se pueden combinar con lógica booleana y paréntesis para ayudar a refinar el comportamiento de coincidencia del filtro. 

Una vez que hayas agregado un conjunto de reglas, puedes registrar tu webhook, donde X comenzará a entregar [objetos de Publicación](/es/x-api/fundamentals/data-dictionary#tweet) en formato JSON. Solo recibirás en tu webhook contenido que coincida con tus reglas.

Este endpoint admite Publicaciones editadas. Tu webhook recibirá Publicaciones editadas que coincidan con uno o más de tus filtros, junto con su historial de edición, incluido un arreglo de ID de Publicación. Para Publicaciones sin historial de edición, este arreglo contendrá un solo ID. Para Publicaciones que se hayan editado, este arreglo contiene múltiples ID, ordenados de forma ascendente según el orden de las ediciones, con la versión más reciente en la última posición del arreglo. Para obtener más información sobre cómo funcionan las ediciones de Publicaciones, consulta la página [Fundamentos de ediciones de Publicaciones](/es/x-api/fundamentals/edit-posts). 

**Nota:** Este grupo de endpoints es similar al [endpoint de flujo filtrado v2](/es/x-api/posts/filtered-stream/introduction) para configurar tus reglas. La única diferencia son los mecanismos de entrega de las Publicaciones que coinciden con tus reglas.

* En el caso del endpoint de flujo filtrado v2, debes establecer una conexión persistente y escuchar las Publicaciones que coincidan con tus reglas.
* En el caso de este endpoint de webhook de flujo filtrado, registras tu webhook y X entrega las Publicaciones que coinciden con tus reglas a tu webhook.

Esto elimina la necesidad de manejar desconexiones derivadas de caídas del cliente o caídas del lado del servidor por reinicios normales de nuestro servicio. Dado que probablemente estaremos entregando cientos de eventos por segundo, es necesario que tu servidor de webhook pueda manejar estos intentos de conexión simultáneos.

Actualmente, este endpoint está disponible para desarrolladores Enterprise y admite la siguiente configuración:

* Más de 25.000 reglas por proyecto
* Se pueden usar todos los operadores al crear tu regla
* Se pueden crear reglas de hasta 2048 caracteres de longitud
* Solicita acceso [aquí](https://developer.x.com/en/products/x-api/enterprise/enterprise-api-interest-form) para obtener acceso Enterprise

Las Publicaciones devueltas del flujo filtrado cuentan para el [límite mensual de Publicaciones](/es/x-api/fundamentals/post-cap).
