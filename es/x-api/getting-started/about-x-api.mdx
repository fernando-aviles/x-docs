X API proporciona acceso programático a la conversación pública de X. Obtén Publicaciones, analiza tendencias, crea integraciones y desarrolla nuevas experiencias en la plataforma.

***

<div id="what-you-can-do">
  ## Lo que puedes hacer
</div>

| Funcionalidad | Descripción |
|:-----------|:------------|
| **Leer publicaciones** | Buscar, consultar y recibir publicaciones en tiempo real mediante streaming |
| **Publicar contenido** | Crear publicaciones, respuestas e hilos |
| **Administrar usuarios** | Consultar usuarios y administrar seguimientos, bloqueos y silenciamientos |
| **Analizar datos** | Acceder a métricas, tendencias y análisis de interacción |
| **Crear integraciones** | Enviar mensajes directos (MD), administrar Listas e interactuar con Spaces |

***

<div id="api-versions">
  ## Versiones de la API
</div>

<Tabs>
  <Tab title="X API v2 (Recomendada)">
    La versión actual de la X API con funcionalidades modernas y precios flexibles.

    **Por qué usar v2:**

    * Precio según el uso, sin límites mensuales
    * Formato de respuesta JSON moderno
    * [fields](/es/x-api/fundamentals/fields) y [expansions](/es/x-api/fundamentals/expansions) flexibles
    * Funcionalidades avanzadas: anotaciones, seguimiento de conversaciones, historial de ediciones
    * Todos los endpoints y funcionalidades nuevas

    **Primeros pasos:**

    1. Regístrate en [console.x.com](https://console.x.com)
    2. Crea una aplicación y obtén las credenciales
    3. [Haz tu primera solicitud](/es/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1 (versión heredada)">
    La versión anterior de la X API. Soporte limitado; utiliza v2 para proyectos nuevos.

    **Aún disponible:**

    * Algunos endpoints de carga de medios
    * Streaming heredado (obsoleto)
    * Algunos endpoints especializados

    **Migrar a v2:**
    Consulta la [guía de migración](/es/x-api/migrate/overview) para el mapeo de endpoints y los cambios en el formato de datos.
  </Tab>

  <Tab title="Enterprise">
    Acceso de alto volumen para empresas con necesidades avanzadas.

    **Características:**

    * Acceso completo al firehose
    * Recuperación de datos históricos
    * Soporte dedicado
    * Límites de tasa personalizados
    * Flujos de cumplimiento normativo

    [Contacta con el equipo de ventas para Enterprise →](/es/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

<div id="v2-highlights">
  ## Aspectos destacados de v2
</div>

<Accordion title="Campos y expansions">
  Solicita solo los datos que necesitas. Usa los parámetros `fields` para seleccionar atributos específicos y `expansions` para incluir objetos relacionados.

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [Más información sobre campos →](/es/x-api/fundamentals/fields)
</Accordion>

<Accordion title="Anotaciones de publicaciones">
  Las publicaciones incluyen anotaciones semánticas que identifican personas, lugares, productos y temas. Filtra streams y búsquedas por tema.

  [Más información sobre anotaciones →](/es/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="Métricas de interacción">
  Accede a métricas públicas (likes, reposts, respuestas) y métricas privadas (impresiones, clics) para tus propias publicaciones.

  [Más información sobre métricas →](/es/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="Seguimiento de conversaciones">
  Reconstruye hilos de conversación completos usando `conversation_id`. Haz seguimiento de las respuestas a lo largo de todo el hilo.

  [Más información sobre el seguimiento de conversaciones →](/es/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="Historial de ediciones">
  Accede al historial de ediciones de las publicaciones, incluidas todas las versiones anteriores y los metadatos de edición.

  [Más información sobre la edición de publicaciones →](/es/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## Precios
</div>

X API v2 usa un modelo de precios de **pago por uso**:

| Beneficio | Descripción |
|:--------|:------------|
| **Sin suscripciones** | Paga solo por lo que usas |
| **Sin límites** | Usa tanto como necesites |
| **Basado en créditos** | Compra créditos, que se descuentan por cada solicitud |
| **Seguimiento en tiempo real** | Supervisa el uso en la Consola de desarrollador |
| **Desduplicación** | El mismo recurso solicitado dos veces dentro de 24 horas solo se cobra una vez |

[Ver detalles de precios →](/es/x-api/getting-started/pricing)
