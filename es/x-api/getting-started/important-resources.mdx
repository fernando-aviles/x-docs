  ## Referencia rápida
</div>

<div id="response-structure">
  ### Estructura de la respuesta
</div>

Todas las respuestas de v2 siguen esta estructura:

```json
{
  "data": { ... },      // Objeto(s) principal(es)
  "includes": { ... },  // Objetos expandidos (si se solicitan)
  "meta": { ... },      // Información de paginación
  "errors": [ ... ]     // Errores parciales (si los hay)
}
```

<div id="common-parameters">
  ### Parámetros comunes
</div>

| Parámetro | Uso |
|:----------|:----|
| `tweet.fields` | Solicitar campos específicos de la publicación |
| `user.fields` | Solicitar campos específicos del usuario |
| `expansions` | Incluir objetos relacionados |
| `max_results` | Limitar resultados por página |
| `pagination_token` | Obtener la página siguiente o anterior |

<div id="authentication-methods">
  ### Métodos de autenticación
</div>

| Método | Caso de uso |
|:-------|:------------|
| Bearer Token | Datos públicos de solo lectura |
| OAuth 2.0 | Acciones de usuario con ámbitos granulares |
| OAuth 1.0a | Acciones de usuario (legado, permisos completos) |

[Guía completa de autenticación →](/es/resources/fundamentals/authentication/overview)
