Esta guía te explica cómo hacer tu primera solicitud a la X API. Necesitarás una [cuenta de desarrollador con credenciales de aplicación](/es/x-api/getting-started/getting-access) antes de empezar.

***

<div id="quick-start-with-curl">
  ## Inicio rápido con cURL
</div>

La manera más rápida de probar la API es usar cURL. Veamos cómo buscar un usuario:

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

Reemplaza `$BEARER_TOKEN` por tu Bearer Token real. Obtendrás una respuesta como:

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers"
  }
}
```

***

<div id="step-by-step-guide">
  ## Guía paso a paso
</div>

<Steps>
  <Step title="Obtén tu Bearer Token">
    En la [Developer Console](https://console.x.com), ve a tu app y copia el Bearer Token.
  </Step>

  <Step title="Elige un endpoint">
    Comienza con uno de estos endpoints aptos para principiantes:

    | Endpoint | Qué hace |
    |:---------|:-------------|
    | [User lookup](/es/x-api/users/lookup/introduction) | Obtiene el perfil de usuario por nombre de usuario o ID |
    | [Post lookup](/es/x-api/posts/lookup/introduction) | Obtiene una publicación por ID |
    | [Recent search](/es/x-api/posts/search/introduction) | Busca publicaciones de los últimos 7 días |
  </Step>

  <Step title="Realiza la solicitud">
    Usa cURL, Postman o tu cliente HTTP preferido:

    ```bash
    # Buscar un usuario por nombre de usuario
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>

  <Step title="Analiza la respuesta">
    Las respuestas están en formato JSON. Los datos principales se encuentran en el campo `data`:

    ```json
    {
      "data": {
        "id": "2244994945",
        "name": "X Developers",
        "username": "xdevelopers"
      }
    }
    ```
  </Step>
</Steps>

***

<div id="request-more-data-with-fields">
  ## Solicita más data con campos
</div>

De forma predeterminada, los endpoints devuelven un conjunto mínimo de campos. Utiliza el parámetro `fields` para solicitar data adicional:

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers?user.fields=created_at,description,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

Respuesta:

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "The voice of the X Developer Platform",
    "public_metrics": {
      "followers_count": 570842,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```

[Más información sobre los campos →](/es/x-api/fundamentals/fields)

<div id="using-code-instead-of-curl">
  ## Uso de código en lugar de cURL
</div>

<Tabs>
  <Tab title="Python">
    ```python
    import requests

    bearer_token = "YOUR_BEARER_TOKEN"
    url = "https://api.x.com/2/users/by/username/xdevelopers"

    headers = {"Authorization": f"Bearer {bearer_token}"}
    response = requests.get(url, headers=headers)

    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    ```javascript
    const bearerToken = "YOUR_BEARER_TOKEN";
    const url = "https://api.x.com/2/users/by/username/xdevelopers";

    fetch(url, {
      headers: { Authorization: `Bearer ${bearerToken}` }
    })
      .then(res => res.json())
      .then(data => console.log(data));
    ```
  </Tab>

  <Tab title="SDKs oficiales">
    Para uso en producción, recomendamos los SDK oficiales:

    * [SDK de Python](/es/xdks/python/overview)
    * [SDK de TypeScript](/es/xdks/typescript/overview)

    Se encargan automáticamente de la autenticación, la paginación y la limitación de tasa de solicitudes.
  </Tab>
</Tabs>

<div id="troubleshooting">
  ## Solución de problemas
</div>

<Accordion title="401 No autorizado">
  * Verifica que tu Bearer Token sea correcto
  * Asegúrate de que el token no se haya regenerado
  * Verifica el formato del encabezado `Authorization`: `Bearer YOUR_TOKEN`
</Accordion>

<Accordion title="403 Prohibido">
  * Es posible que tu aplicación no tenga acceso a este endpoint
  * Algunos endpoints requieren autenticación con contexto de usuario (OAuth 1.0a o 2.0)
  * Revisa los permisos de tu aplicación en la Developer Console
</Accordion>

<Accordion title="429 Demasiadas solicitudes">
  * Has alcanzado un límite de solicitudes
  * Revisa el encabezado `x-rate-limit-reset` para saber cuándo reintentar
  * Implementa un backoff exponencial en tu código
</Accordion>

[Referencia completa de errores →](/es/x-api/fundamentals/response-codes-and-errors)
