<div id="deduplication">
  ## Desduplicación
</div>

Todos los recursos se desduplican dentro de una **ventana de 24 horas en UTC**. Si solicitas y se te cobra por un recurso (como una Publicación), solicitar el mismo recurso de nuevo dentro de esa ventana no generará cargos adicionales.

Esto significa:

* Solicitar la misma Publicación varias veces en un día cuenta como un solo cargo
* La ventana de desduplicación se restablece a la medianoche UTC
* Esto se aplica a todos los recursos facturables (Publicaciones, usuarios, etc.)

<Note>
  La desduplicación es una **garantía no estricta**. Aunque se produce en la gran mayoría de los casos, puede haber casos límite específicos, como interrupciones del servicio, que provoquen que algunos recursos no se desdupliquen.
</Note>

<div id="credit-balance">
  ## Saldo de créditos
</div>

Tu saldo de créditos se muestra en la Developer Console. Los créditos se descuentan en tiempo real a medida que realizas solicitudes a la API.

<Warning>
  Supervisa tu saldo de créditos con regularidad para evitar interrupciones del servicio. Añade créditos antes de que tu saldo llegue a cero para garantizar un acceso ininterrumpido a la API.

  ***Nota:** Es posible que el saldo de créditos de una cuenta quede ligeramente en negativo. En este caso, las solicitudes a la API se bloquearán hasta que añadas créditos para cubrir el saldo negativo.*
</Warning>

<div id="auto-recharge">
  ### Recarga automática
</div>

Activa la recarga automática para añadir crédito automáticamente a tu saldo y evitar interrupciones del servicio. Configura esto en la Developer Console:

| Configuración | Descripción |
|:--------|:------------|
| **Recharge amount** | Importe que se añadirá cuando se active la recarga automática (por ejemplo, 25 USD) |
| **Trigger threshold** | La recarga automática se activa cuando tu saldo cae por debajo de este importe (por ejemplo, 5 USD) |

<Note>
  La recarga automática requiere un método de pago guardado establecido como predeterminado. Puedes cancelarla en cualquier momento en la Developer Console o poniéndote en contacto con el equipo de soporte.
</Note>

***

<div id="spending-limits">
  ### Límites de gasto
</div>

Establece un importe máximo que puedes gastar por ciclo de facturación para controlar los costos. Cuando se alcance el límite, las solicitudes a la API se bloquearán hasta el siguiente ciclo de facturación.

| Opción | Descripción |
|:-------|:------------|
| **Límite de gasto** | Establece un importe específico en dólares como tu gasto máximo por ciclo de facturación |

<Tip>
  Usa límites de gasto para evitar cargos inesperados, especialmente durante el desarrollo y las pruebas.
</Tip>

<div id="monitoring-usage">
  ## Supervisar el uso
</div>

Supervisa el uso de la API de forma programática con el [endpoint de uso](/es/x-api/usage/introduction):

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

Esto devuelve los recuentos diarios de consumo de Publicaciones, lo que te ayuda a:

* Hacer un seguimiento del consumo con respecto a tu presupuesto
* Configurar alertas cuando te acerques a los límites
* Identificar endpoints de alto consumo
* Generar informes de uso
