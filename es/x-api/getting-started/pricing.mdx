<div id="deduplication">
  ## Deduplicación
</div>

Todos los recursos se someten a deduplicación dentro de una **ventana correspondiente a un día de 24 horas en UTC**. Si solicitas y se te cobra por un recurso (como una Publicación), solicitar el mismo recurso nuevamente dentro de esa ventana no generará un cargo adicional.

Esto significa:

* Solicitar la misma Publicación varias veces en un día cuenta como un solo cargo
* La ventana de deduplicación se restablece a la medianoche UTC
* Esto se aplica a todos los recursos facturables (Publicaciones, usuarios, etc.)

<Note>
  La deduplicación es una **garantía no estricta**. Aunque se aplica en la gran mayoría de los casos, puede haber casos extremos específicos, como interrupciones del servicio, que hagan que la deduplicación no se aplique a algunos recursos.
</Note>

<div id="credit-balance">
  ## Saldo de créditos
</div>

Tu saldo de créditos se muestra en la Consola de Desarrollador. Los créditos se descuentan en tiempo real a medida que realizas solicitudes a la API.

<Warning>
  Supervisa tu saldo de créditos con regularidad para evitar interrupciones del servicio. Agrega créditos antes de que tu saldo llegue a cero para garantizar un acceso ininterrumpido a la API.

  ***Nota:** Es posible que el saldo de créditos de una cuenta quede ligeramente en negativo. En este caso, las solicitudes a la API se bloquearán hasta que agregues créditos para cubrir el saldo negativo.*
</Warning>

<div id="auto-recharge">
  ### Recarga automática
</div>

Habilita la recarga automática para añadir saldo automáticamente a tu saldo de crédito y evitar interrupciones del servicio. Configúralo en la Consola de Desarrollador:

| Configuración | Descripción |
|:--------|:------------|
| **Recharge amount** | Importe que se añadirá cuando se active la recarga automática (por ejemplo, 25 USD) |
| **Trigger threshold** | La recarga automática se activa cuando tu saldo cae por debajo de este importe (por ejemplo, 5 USD) |

<Note>
  La recarga automática requiere un método de pago guardado establecido como predeterminado. Puedes cancelarla en cualquier momento en la Consola de Desarrollador o poniéndote en contacto con el equipo de soporte.
</Note>

<div id="spending-limits">
  ### Límites de gasto
</div>

Establece una cantidad máxima que puedes gastar en cada ciclo de facturación para controlar los costos. Cuando se alcance el límite, las solicitudes a la API se bloquearán hasta el siguiente ciclo de facturación.

| Opción | Descripción |
|:-------|:------------|
| **Límite de gasto** | Establece un importe específico en dólares como tu gasto máximo por ciclo de facturación |

<Tip>
  Usa los límites de gasto para evitar cargos inesperados, especialmente durante el desarrollo y las pruebas.
</Tip>

<div id="monitoring-usage">
  ## Supervisar el uso
</div>

Supervisa el uso de la API de forma programática con el [endpoint Usage](/es/x-api/usage/introduction):

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

Esto devuelve recuentos diarios de consumo de Publicaciones, lo que te ayuda a:

* Hacer un seguimiento del consumo respecto a tu presupuesto
* Configurar alertas al acercarte a los límites
* Identificar endpoints de alto consumo
* Generar informes de uso
