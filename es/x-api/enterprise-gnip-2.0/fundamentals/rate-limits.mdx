<div id="overview">
  ## Descripción general
</div>

Cada día, muchos miles de desarrolladores realizan solicitudes a la X API. Para ayudar a gestionar el enorme volumen de estas solicitudes, se establecen límites en la cantidad de solicitudes que se pueden realizar. Estos límites nos ayudan a ofrecer la API confiable y escalable en la que nuestra comunidad de desarrolladores confía. 

El número máximo de solicitudes permitidas depende de un intervalo de tiempo, es decir, de un período o ventana de tiempo específicos. Si un endpoint tiene un límite de 900 solicitudes por cada 15 minutos, entonces se permiten hasta 900 solicitudes en cualquier intervalo de 15 minutos.
