<div id="overview">
  ## Descripción general
</div>

Cada día, miles de desarrolladores realizan solicitudes a la X API. Para ayudar a gestionar el gran volumen de estas solicitudes, se establecen límites en la cantidad de solicitudes que se pueden hacer. Estos límites nos ayudan a proporcionar la API confiable y escalable en la que nuestra comunidad de desarrolladores confía. 

El número máximo de solicitudes permitidas se determina en función de un intervalo de tiempo, es decir, un período o ventana de tiempo específicos. Si un endpoint tiene un límite de frecuencia de 900 solicitudes/15 minutos, entonces se permiten hasta 900 solicitudes en cualquier intervalo de 15 minutos.
