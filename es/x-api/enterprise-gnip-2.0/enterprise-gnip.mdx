Nuestras APIs empresariales ofrecen el máximo nivel de acceso y fiabilidad para quienes dependen de los datos de X. Son ideales a medida que superas el nivel Premium y necesitas un acceso más confiable, paquetes personalizados o contratos a más largo plazo. El acceso a la Enterprise API incluye administradores de cuentas dedicados y soporte técnico personalizado.

Si has determinado que las soluciones Basic y Pro no son suficientes para cubrir tus necesidades, puedes solicitar acceso a los productos Enterprise en el siguiente enlace:

<Button href="https://developer.x.com/en/products/twitter-api/enterprise/enterprise-api-interest-form">
  Solicitar acceso
</Button>

<div id="available-endpoints">
  ## Endpoints disponibles
</div>

| En tiempo real | [PowerTrack API](/es/x-api/enterprise-gnip-2.0/powertrack-api) | Proporciona cobertura completa de las Publicaciones públicas a medida que se producen, filtrables mediante una amplia gama de operadores y reglas. |
| :--- | :--- | :--- |
| [Decahose API](/es/x-api/enterprise-gnip-2.0/fundamentals/decahose-api) | Permite transmitir una muestra aleatoria del 10% de todas las Publicaciones públicas y sus Me gusta. |
| :--- | :--- | :--- |
| [Account Activity API](/es/x-api/enterprise-gnip-2.0/fundamentals/account-activity) | Permite suscribirse a usuarios y recibir una variedad de actividades diferentes, incluidas Publicaciones, Mensajes Directos, Me gusta, seguimientos y más. |
| :--- | :--- | :--- |
| Histórico | [Search API](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api) | Permite buscar en los últimos 30 días o en el archivo completo de Publicaciones públicas utilizando herramientas de filtrado avanzadas. |
| [Historical PowerTrack API](/es/x-api/enterprise-gnip-2.0/powertrack-api) | Permite filtrar el archivo completo de Publicaciones públicas mediante un proceso económico de acceso por lotes. |
| Insights | [Engagement API](/es/x-api/enterprise-gnip-2.0/fundamentals/engagement-api) | Mide el volumen de impresiones e interacciones de las Publicaciones públicas. |
| Cumplimiento | [Compliance Firehose API](/es/x-api/enterprise-gnip-2.0/fundamentals/firehouse) | Permite transmitir todos los eventos de cumplimiento. |
| Uso | [Usage API](/es/x-api/enterprise-gnip-2.0/fundamentals/usage) | Proporciona acceso programático al consumo de actividad en todos los productos empresariales. |

<div id="enrichments">
  ### Enriquecimientos de datos
</div>

Hemos añadido metadatos al cuerpo de la respuesta de las API premium para desarrolladores que utilizan un plan de pago. Obtén más información sobre URL expandidas, datos de encuestas y geolocalización de perfil visitando nuestra [sección de enriquecimientos de datos](/es/x-api/enterprise-gnip-2.0/fundamentals/data-enrichments).
 

<div id="advanced-filtering-tools">
  ### Herramientas avanzadas de filtrado
</div>

La Premium Search API pone a tu disposición un conjunto avanzado de operadores que no están disponibles en el endpoint de búsqueda estándar. Muchos de estos operadores están disponibles para los usuarios del sandbox gratuito, pero tendrás acceso a un conjunto más completo de operadores si utilizas un plan de pago. Obtén más información visitando nuestra [sección de reglas y filtros](/es/x-api/enterprise-gnip-2.0/fundamentals/rules-filtering#getting-started-with-enterprise-rules-and-queries).
