Nuestras APIs empresariales ofrecen el nivel más alto de acceso y fiabilidad para quienes dependen de los datos de X. Son ideales a medida que tu integración escala más allá de Premium y necesitas un acceso más fiable, paquetes personalizados a medida o contratos de mayor duración. El acceso a la Enterprise API incluye responsables de cuenta dedicados y soporte técnico personalizado.

Si has identificado que las soluciones Basic y Pro no son suficientes para cubrir tus necesidades, puedes solicitar acceso a los productos empresariales en el siguiente enlace:

  Solicitar acceso
</Button>

<div id="available-endpoints">
  ## Endpoints disponibles
</div>

| En tiempo real | [PowerTrack API](/es/x-api/enterprise-gnip-2.0/powertrack-api) | Proporciona una cobertura completa de las publicaciones públicas a medida que ocurren, filtrables mediante una amplia gama de operadores y reglas. |
| :--- | :--- | :--- |
| [Decahose API](/es/x-api/enterprise-gnip-2.0/fundamentals/decahose-api) | Transmite una muestra aleatoria del 10% de todas las publicaciones públicas y sus Me gusta. |
| :--- | :--- | :--- |
| [Account Activity API](/es/x-api/enterprise-gnip-2.0/fundamentals/account-activity) | Suscríbete a usuarios y recibe una variedad de actividades diferentes, incluidas publicaciones, Mensajes Directos, Me gusta, seguimientos y más. |
| :--- | :--- | :--- |
| Histórico | [Search API](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api) | Busca en los últimos 30 días o en el archivo completo de publicaciones públicas utilizando herramientas de filtrado avanzadas. |
| [Historical PowerTrack API](/es/x-api/enterprise-gnip-2.0/powertrack-api) | Filtra el archivo completo de publicaciones públicas utilizando un proceso económico de acceso por lotes. |
| Información analítica | [Engagement API](/es/x-api/enterprise-gnip-2.0/fundamentals/engagement-api) | Mide el volumen de impresiones e interacciones de las publicaciones públicas. |
| Cumplimiento | [Compliance Firehose API](/es/x-api/enterprise-gnip-2.0/fundamentals/firehouse) | Transmite todos los eventos de cumplimiento. |
| Uso | [Usage API](/es/x-api/enterprise-gnip-2.0/fundamentals/usage) | Proporciona acceso programático al consumo de actividad en todos los productos empresariales. |

<div id="advanced-filtering-tools">
  ### Herramientas de filtrado avanzadas
</div>

La Premium Search API ofrece un conjunto avanzado de operadores que no están disponibles en el endpoint de búsqueda estándar. Muchos de estos operadores están disponibles para los usuarios gratuitos del entorno de prueba (sandbox), pero se obtiene un conjunto más completo de operadores si se utiliza un plan de pago. Obtén más información visitando nuestra [sección de reglas y filtros](/es/x-api/enterprise-gnip-2.0/fundamentals/rules-filtering#getting-started-with-enterprise-rules-and-queries).
