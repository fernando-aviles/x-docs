Nuestras APIs empresariales ofrecen el nivel más alto de acceso y fiabilidad para quienes dependen de los datos de X. Son la opción ideal cuando necesitas escalar más allá de la oferta Premium y requieres un acceso más fiable, paquetes personalizados o contratos de mayor duración. El acceso a las APIs empresariales incluye gestores de cuenta dedicados y soporte técnico personalizado.

Si has determinado que las soluciones Basic y Pro no son suficientes para cubrir tus necesidades, puedes solicitar acceso a los productos empresariales en el siguiente enlace:

  Solicitar acceso
</Button>

<div id="available-endpoints">
  ## Endpoints disponibles
</div>

| En tiempo real | [PowerTrack API](/es/x-api/enterprise-gnip-2.0/powertrack-api) | Proporciona una cobertura completa de las publicaciones públicas a medida que ocurren, filtrable mediante una amplia variedad de operadores y reglas. |
| :--- | :--- | :--- |
| [Decahose API](/es/x-api/enterprise-gnip-2.0/fundamentals/decahose-api) | Transmite una muestra aleatoria del 10 % de todas las publicaciones públicas y sus me gusta. |
| :--- | :--- | :--- |
| [Account Activity API](/es/x-api/enterprise-gnip-2.0/fundamentals/account-activity) | Permite suscribirte a usuarios y recibir una variedad de actividades diferentes, incluidas publicaciones, mensajes directos, me gusta, seguimientos y más. |
| :--- | :--- | :--- |
| Histórico | [Search API](/es/x-api/enterprise-gnip-2.0/fundamentals/search-api) | Busca en los últimos 30 días o en el archivo completo de publicaciones públicas mediante herramientas avanzadas de filtrado. |
| [Historical PowerTrack API](/es/x-api/enterprise-gnip-2.0/powertrack-api) | Filtra todo el archivo de publicaciones públicas mediante un proceso económico de acceso por lotes. |
| Análisis | [Engagement API](/es/x-api/enterprise-gnip-2.0/fundamentals/engagement-api) | Mide el volumen de impresiones e interacciones de las publicaciones públicas. |
| Cumplimiento | [Compliance Firehose API](/es/x-api/enterprise-gnip-2.0/fundamentals/firehouse) | Transmite todos los eventos de cumplimiento. |
| Uso | [Usage API](/es/x-api/enterprise-gnip-2.0/fundamentals/usage) | Proporciona acceso programático al consumo de actividad en todos los productos empresariales. |

<div id="enrichments">
  ### Enriquecimientos
</div>

Hemos añadido metadatos a la carga útil de la respuesta de las API premium para desarrolladores que utilizan un nivel de suscripción de pago. Obtén más información sobre URL ampliadas, datos de encuestas y geolocalización del perfil visitando nuestra [sección de enriquecimientos](/es/x-api/enterprise-gnip-2.0/fundamentals/data-enrichments).
 

<div id="advanced-filtering-tools">
  ### Herramientas avanzadas de filtrado
</div>

La Premium Search API ofrece un conjunto avanzado de operadores que no están disponibles con el endpoint estándar de búsqueda. Muchos de estos operadores están disponibles para los usuarios del sandbox gratuito, pero obtendrás un conjunto más sólido de operadores si utilizas un plan de pago. Para obtener más información, visita nuestra [sección de reglas y filtros](/es/x-api/enterprise-gnip-2.0/fundamentals/rules-filtering#getting-started-with-enterprise-rules-and-queries).
