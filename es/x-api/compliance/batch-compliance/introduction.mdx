Los endpoints de Batch Compliance te permiten cargar conjuntos de IDs de Publicación o de usuario y recibir su estado de cumplimiento actual. Úsalos para identificar Publicaciones eliminadas, cuentas suspendidas y otros eventos de cumplimiento.

<div id="how-it-works">
  ## Cómo funciona
</div>

1. **Crear un trabajo** — Especifica el tipo (Publicaciones o usuarios) y la URL de carga
2. **Subir ID** — Sube tu conjunto de datos a la URL proporcionada
3. **Esperar el procesamiento** — El trabajo se procesa de manera asíncrona
4. **Descargar resultados** — Obtén el estado de cumplimiento para cada ID

***

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | [`/2/compliance/jobs`](/es/x-api/compliance/create-compliance-job) | Crear un nuevo trabajo de cumplimiento |
| GET | [`/2/compliance/jobs/:id`](/es/x-api/compliance/get-compliance-job-by-id) | Obtener el estado del trabajo |
| GET | [`/2/compliance/jobs`](/es/x-api/compliance/get-compliance-jobs) | Listar todos los trabajos |

***

<div id="job-types">
  ## Tipos de trabajos
</div>

| Tipo | Descripción |
|:-----|:------------|
| `tweets` | Comprobar el estado de cumplimiento de publicaciones |
| `users` | Comprobar el estado de cumplimiento de usuarios |

***

<div id="compliance-events">
  ## Eventos de cumplimiento
</div>

<div id="post-events">
  ### Eventos de publicaciones
</div>

| Evento | Descripción |
|:------|:------------|
| `deleted` | La publicación fue eliminada por el usuario |
| `bounced` | La publicación no superó la verificación de cumplimiento |
| `protected` | La cuenta pasó a estar protegida |
| `suspended` | La cuenta fue suspendida |
| `scrub_geo` | Se eliminaron los datos de ubicación |

<div id="user-events">
  ### Eventos de usuario
</div>

| Evento | Descripción |
|:------|:------------|
| `deleted` | La cuenta fue eliminada |
| `suspended` | La cuenta fue suspendida |
| `protected` | La cuenta pasó a ser protegida |
| `deactivated` | La cuenta fue desactivada |

***

<div id="example-create-a-job">
  ## Ejemplo: crear un trabajo
</div>

```bash
curl -X POST "https://api.x.com/2/compliance/jobs" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "tweets",
    "name": "my-compliance-job"
  }'
```
