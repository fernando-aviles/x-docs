Los endpoints de Batch Compliance te permiten cargar conjuntos de datos de IDs de Publicación o IDs de usuario y recibir su estado de cumplimiento actual. Utiliza esto para identificar Publicaciones eliminadas, cuentas suspendidas y otros eventos de cumplimiento.

<div id="how-it-works">
  ## Cómo funciona
</div>

1. **Crea un trabajo** — Especifica el tipo (Publicaciones o usuarios) y la URL de carga
2. **Carga las id** — Carga tu conjunto de datos en la URL proporcionada
3. **Espera a que se procese** — El trabajo se procesa de forma asíncrona
4. **Descarga los resultados** — Obtén el estado de cumplimiento de cada id

***

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| POST | [`/2/compliance/jobs`](/es/x-api/compliance/create-compliance-job) | Crear un nuevo job de cumplimiento |
| GET | [`/2/compliance/jobs/:id`](/es/x-api/compliance/get-compliance-job-by-id) | Obtener el estado del job |
| GET | [`/2/compliance/jobs`](/es/x-api/compliance/get-compliance-jobs) | Listar todos los jobs |

***

<div id="job-types">
  ## Tipos de trabajos
</div>

| Tipo | Descripción |
|:-----|:------------|
| `tweets` | Verificar el estado de cumplimiento de las publicaciones |
| `users` | Verificar el estado de cumplimiento de los usuarios |

***

<div id="compliance-events">
  ## Eventos de cumplimiento
</div>

<div id="post-events">
  ### Eventos de publicaciones
</div>

| Evento | Descripción |
|:------|:------------|
| `deleted` | Publicación eliminada por el usuario |
| `bounced` | Publicación falló la verificación de cumplimiento |
| `protected` | La cuenta pasó a ser protegida |
| `suspended` | La cuenta fue suspendida |
| `scrub_geo` | Se eliminaron los datos geográficos |

<div id="user-events">
  ### Eventos de usuario
</div>

| Evento | Descripción |
|:------|:------------|
| `deleted` | La cuenta fue eliminada |
| `suspended` | La cuenta fue suspendida |
| `protected` | La cuenta pasó a ser protegida |
| `deactivated` | La cuenta fue desactivada |

***

<div id="example-create-a-job">
  ## Ejemplo: Crear un trabajo
</div>

```bash
curl -X POST "https://api.x.com/2/compliance/jobs" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "tweets",
    "name": "my-compliance-job"
  }'
```
