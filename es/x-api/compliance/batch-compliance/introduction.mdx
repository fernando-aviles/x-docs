Los endpoints de Batch Compliance te permiten cargar conjuntos de datos de id de Publicaciones o id de usuarios y recibir su estado de cumplimiento actual. Úsalos para identificar Publicaciones eliminadas, cuentas suspendidas y otros eventos de cumplimiento.

<div id="how-it-works">
  ## Cómo funciona
</div>

1. **Crear una tarea** — Especifica el tipo (Publicaciones o usuarios) y la URL de carga
2. **Cargar los ID** — Carga tu conjunto de datos en la URL proporcionada
3. **Esperar el procesamiento** — La tarea se procesa de forma asíncrona
4. **Descargar resultados** — Obtén el estado de cumplimiento para cada ID

***

<div id="endpoints">
  ## Endpoints
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/compliance/jobs`](/es/x-api/compliance/create-compliance-job) | Crear una nueva tarea de cumplimiento |
| GET | [`/2/compliance/jobs/:id`](/es/x-api/compliance/get-compliance-job-by-id) | Obtener el estado de la tarea |
| GET | [`/2/compliance/jobs`](/es/x-api/compliance/get-compliance-jobs) | Listar todas las tareas |

***

<div id="job-types">
  ## Tipos de tareas
</div>

| Tipo | Descripción |
|:-----|:------------|
| `tweets` | Comprobar el estado de cumplimiento de las Publicaciones |
| `users` | Comprobar el estado de cumplimiento de los usuarios |

***

<div id="compliance-events">
  ## Eventos de cumplimiento normativo
</div>

<div id="post-events">
  ### Eventos de Publicaciones
</div>

| Evento | Descripción |
|:------|:------------|
| `deleted` | La Publicación fue eliminada por el usuario |
| `bounced` | La Publicación no superó la comprobación de cumplimiento |
| `protected` | La cuenta pasó a estar protegida |
| `suspended` | La cuenta fue suspendida |
| `scrub_geo` | Los datos de geolocalización se eliminaron |

<div id="user-events">
  ### Eventos de usuario
</div>

| Evento | Descripción |
|:------|:------------|
| `deleted` | La cuenta se eliminó |
| `suspended` | La cuenta se suspendió |
| `protected` | La cuenta pasó a estar protegida |
| `deactivated` | La cuenta se desactivó |

***

<div id="example-create-a-job">
  ## Ejemplo: crear un trabajo
</div>

```bash
curl -X POST "https://api.x.com/2/compliance/jobs" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "tweets",
    "name": "my-compliance-job"
  }'
```
