El endpoint de búsqueda de usuarios permite buscar usuarios por palabra clave. Busca usuarios por nombre, nombre de usuario o por el contenido de su biografía.

<div id="overview">
  ## Descripción general
</div>

<CardGroup cols={2}>
  <Card title="Búsqueda por palabra clave" icon="magnifying-glass">
    Busca por nombre, nombre de usuario o biografía
  </Card>

  <Card title="Descubre usuarios" icon="user-plus">
    Encuentra cuentas relevantes
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## Endpoint
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/users/search`](/es/x-api/users/search-users) | Buscar usuarios |

***

<div id="example-request">
  ## Ejemplo de solicitud
</div>

```bash
curl "https://api.x.com/2/users/search?\
query=python%20developer&\
user.fields=description,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## Ejemplo de respuesta
