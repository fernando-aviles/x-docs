  ## Comparación de los endpoints de búsqueda de usuarios de X API
</div>

Los endpoints de búsqueda de usuarios de la v2 sustituirán a los endpoints estándar de v1.1 [GET users/lookup](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-lookup.html) y [GET users/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-show.html). Si tienes código, apps o herramientas que usan alguna de estas versiones de los endpoints de búsqueda de usuarios y estás considerando migrar al endpoint más reciente de X API v2, esta serie de guías es para ti. 
 

Las tablas siguientes comparan los distintos tipos de endpoints de búsqueda de usuarios:
 

|     |     |     |
| :--- | :--- | :--- |
| **Descripción** | **Standard v1.1** | **X API v2** |
| Métodos HTTP compatibles | `GET` | `GET` |
| Dominio de host | `https://api.x.com` | `https://api.x.com` |
| Ruta del endpoint | `/1.1/users/show.json` `/1.1/users/lookup.json` | `/2/users`<br /><br />`/2/users/:id`<br /><br />`/2/users/by`<br /><br />`/2/users/by/:username` |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />Solo App<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Límites de frecuencia](/es/resources/fundamentals/rate-limits) de solicitud predeterminados | 900 solicitudes por 15 min (por usuario)<br /><br />/show - 900 solicitudes por 15 min (por app)  <br />/lookup - 300 solicitudes por 15 min (por app) | 900 solicitudes por 15 min (por usuario)<br /><br />300 solicitudes por 15 min (por app) |
| Número máximo de usuarios por respuesta | /show -  1<br /><br />/lookup - 100 | 100 |
| Formato del objeto JSON de respuesta | Formato Standard v1.1 | [Formato de X API v2](/es/x-api/fundamentals/data-dictionary) (determinado por los parámetros de solicitud fields y expansions, no es compatible con versiones anteriores de los formatos v1.1)<br /><br />Para obtener más información sobre cómo migrar del formato Standard v1.1 al formato de X API v2, visita nuestra [guía de migración de formatos de datos](/es/x-api/migrate/data-format-migration). |
| Permite seleccionar qué [fields](/es/x-api/fundamentals/data-dictionary) se devuelven en el payload |     | ✔   |
| Permite usar los campos de [annotations](/es/x-api/fundamentals/post-annotations) (en la Publicación fijada) |     | ✔   |
| Permite solicitar nuevos campos de [metrics](/es/x-api/fundamentals/metrics) (en la Publicación fijada) |     | ✔   |
| Permite usar el campo [conversation&#95;id](/es/x-api/fundamentals/conversation-id) (en la Publicación fijada) |     | ✔   |
| Requiere el uso de credenciales de una [developer App](/es/resources/fundamentals/developer-apps) asociada con un [Project](/es/resources/fundamentals/developer-apps) |     | ✔   |
