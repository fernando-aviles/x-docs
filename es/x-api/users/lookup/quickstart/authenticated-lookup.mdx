En esta guía se explica cómo recuperar el perfil del usuario autenticado actual mediante el endpoint `/me`.

<Note>
  **Requisitos previos**

  Antes de comenzar, necesitarás lo siguiente:

  * Una [cuenta de desarrollador](https://developer.x.com/en/portal/petition/essential/basic-info) con una aplicación aprobada
  * Un token de acceso de usuario (OAuth 1.0a o OAuth 2.0 PKCE)
</Note>

***

<div id="get-the-authenticated-user">
  ## Obtener el usuario autenticado
</div>

Realiza una solicitud al endpoint `/me` con un token de acceso de usuario (User Access Token):

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/me?\
  user.fields=created_at,description,verified,public_metrics,profile_image_url" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Obtener el usuario autenticado
  response = client.users.get_me(
      user_fields=["created_at", "description", "verified", "public_metrics", "profile_image_url"]
  )

  print(f"Username: {response.data.username}")
  print(f"ID: {response.data.id}")
  print(f"Followers: {response.data.public_metrics.followers_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Obtener el usuario autenticado
  const response = await client.users.getMe({
    userFields: ["created_at", "description", "verified", "public_metrics", "profile_image_url"],
  });

  console.log(`Username: ${response.data?.username}`);
  console.log(`ID: ${response.data?.id}`);
  console.log(`Followers: ${response.data?.public_metrics?.followers_count}`);
  ```
</CodeGroup>

<div id="use-case">
  ## Caso de uso
</div>

El endpoint `/me` es esencial cuando:

* **Verificar la autenticación** — Confirmar que el usuario está correctamente autenticado
* **Obtener el id de usuario** — Recuperar el id del usuario autenticado para otras llamadas a la API
* **Personalizar experiencias** — Mostrar el perfil del usuario en tu aplicación
* **Solicitudes en nombre de** — Saber en nombre de quién estás realizando solicitudes

<div id="include-pinned-post">
  ## Incluir la publicación fijada
</div>

Solicita la publicación fijada del usuario:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/me?\
  user.fields=pinned_tweet_id&\
  expansions=pinned_tweet_id&\
  tweet.fields=created_at,text" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Obtén el usuario autenticado con la publicación fijada
  response = client.users.get_me(
      user_fields=["pinned_tweet_id"],
      expansions=["pinned_tweet_id"],
      tweet_fields=["created_at", "text"]
  )

  print(f"Username: {response.data.username}")
  # La publicación fijada está en response.includes.tweets
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Obtén el usuario autenticado con la publicación fijada
  const response = await client.users.getMe({
    userFields: ["pinned_tweet_id"],
    expansions: ["pinned_tweet_id"],
    tweetFields: ["created_at", "text"],
  });

  console.log(`Username: ${response.data?.username}`);
  // La publicación fijada está en response.includes?.tweets
  ```
</CodeGroup>

<div id="available-fields">
  ## Campos disponibles
</div>

| Campo | Descripción |
|:------|:------------|
| `created_at` | Fecha de creación de la cuenta |
| `description` | Biografía del usuario |
| `profile_image_url` | URL del avatar |
| `verified` | Estado de verificación |
| `public_metrics` | Número de seguidores/seguidos |
| `location` | Ubicación definida por el usuario |
| `url` | Sitio web del usuario |
| `protected` | Estado de la cuenta protegida |
| `pinned_tweet_id` | ID de la Publicación fijada |

***

<div id="authentication-requirement">
  ## Requisito de autenticación
</div>

<Warning>
  El endpoint `/me` requiere autenticación con User Context. La autenticación solo de aplicación (Bearer Token) no es compatible.
</Warning>

Utiliza uno de los siguientes métodos:

* [OAuth 1.0a User Context](/es/resources/fundamentals/authentication)
* [OAuth 2.0 Authorization Code with PKCE](/es/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)
