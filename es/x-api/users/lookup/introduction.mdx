Los endpoints de consulta de usuarios te permiten obtener información de perfil de uno o más usuarios. Puedes buscar usuarios por su id o su nombre de usuario, u obtener detalles del usuario autenticado actualmente.

  ## Descripción general
</div>

<CardGroup cols={2}>
  <Card title="Por ID" icon="fingerprint">

  </Card>

  <Card title="Por nombre de usuario" icon="at">

***

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/users/:id`](/es/x-api/users/get-user-by-id) | Obtener usuario por ID |
| GET | [`/2/users`](/es/x-api/users/get-users-by-ids) | Obtener usuarios por IDs (hasta 100) |
| GET | [`/2/users/by/username/:username`](/es/x-api/users/get-user-by-username) | Obtener usuario por nombre de usuario |
| GET | [`/2/users/by`](/es/x-api/users/get-users-by-usernames) | Obtener usuarios por nombres de usuario (hasta 100) |
| GET | [`/2/users/me`](/es/x-api/users/get-my-user) | Obtener usuario autenticado |

***

<div id="example-request">
  ## Ejemplo de solicitud
</div>

```bash
curl "https://api.x.com/2/users/by/username/XDevelopers?\
user.fields=created_at,description,public_metrics,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## Ejemplo de respuesta
</div>

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",

      "followers_count": 583423,
      "following_count": 2048,
      "tweet_count": 14052,

  }
}
```
