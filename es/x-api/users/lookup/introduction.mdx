Los endpoints de búsqueda de usuarios te permiten obtener información de perfil de uno o más usuarios. Busca usuarios por su id, nombre de usuario o obtén detalles del usuario autenticado actual.

<div id="overview">
  ## Descripción general
</div>

<CardGroup cols={2}>
  <Card title="Por ID" icon="fingerprint">
    Busca usuarios por su id de usuario único
  </Card>

  <Card title="Por nombre de usuario" icon="at">
    Busca usuarios por su @handle
  </Card>

  <Card title="Varios usuarios" icon="users">
    Recupera hasta 100 usuarios por solicitud
  </Card>

  <Card title="Usuario autenticado" icon="user-check">
    Obtén detalles del usuario actual
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## Endpoints
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id`](/es/x-api/users/get-user-by-id) | Obtener el usuario por id |
| GET | [`/2/users`](/es/x-api/users/get-users-by-ids) | Obtener los usuarios por sus ids (hasta 100) |
| GET | [`/2/users/by/username/:username`](/es/x-api/users/get-user-by-username) | Obtener el usuario por nombre de usuario |
| GET | [`/2/users/by`](/es/x-api/users/get-users-by-usernames) | Obtener los usuarios por nombres de usuario (hasta 100) |
| GET | [`/2/users/me`](/es/x-api/users/get-my-user) | Obtener el usuario autenticado |

***

<div id="example-request">
  ## Ejemplo de solicitud
</div>

```bash
curl "https://api.x.com/2/users/by/username/XDevelopers?\
user.fields=created_at,description,public_metrics,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## Ejemplo de respuesta
</div>

```json
{
  "data": {
    "id": "2244994945",

  }
}
```
