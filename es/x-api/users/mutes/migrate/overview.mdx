<div id="comparing-x-apis-mutes-endpoints">
  ## Comparación de los endpoints de silenciamiento de X API
</div>

<div id="mutes-lookup">
  #### Consulta de silenciados
</div>

El endpoint de consulta de silenciados de v2 reemplazará los endpoints estándar [v1.1 GET mutes/users/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-ids) y [GET mutes/users/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-list).

Las siguientes tablas comparan los endpoints de silenciados estándar de v1.1 y de X API v2:
 

| Descripción | v1.1 estándar | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP permitidos | ******GET****** | ******GET****** |
| Dominio del host | ******https://api.x.com****** | ******https://api.x.com****** |
| Ruta del endpoint | ******/1.1/mutes/users/ids.json******<br /><br />/1.1/mutes/users/list.json | ******/2/users/:id/muting****** |
| [Autenticación](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Límites de frecuencia](/es/resources/fundamentals/rate-limits) de solicitudes predeterminados | 15 solicitudes por 15 min (por usuario) | 15 solicitudes por 15 min (por usuario) |
| Formatos de datos | Formato estándar v1.1 | [Formato de X API v2](/es/x-api/fundamentals/data-dictionary) (determinado por los parámetros de consulta fields y expansions; no es compatible con versiones anteriores de los formatos v1.1)<br /><br />Para obtener más información sobre cómo migrar del formato estándar v1.1 al formato de X API v2, consulta nuestra [guía de migración de formatos de datos](/es/x-api/migrate/data-format-migration). |
| Requiere el uso de credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que esté asociada con un [Project](/es/resources/fundamentals/developer-apps) |     | ✔️  |

<div id="manage-mutes">
  #### Administrar silenciados
</div>

Los endpoints v2 para administrar silenciados reemplazarán los endpoints estándar de v1.1 [POST mutes/users/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-create) y [POST mutes/users/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-destroy).

Las siguientes tablas comparan los endpoints de silenciamiento estándar de v1.1 y de X API v2:

**Silenciar a un usuario**

| Descripción | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | POST |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/mutes/users/create.json | /2/users/:id/muting |
| [Authentication](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Rate limits](/es/resources/fundamentals/rate-limits) de solicitud predeterminados | 50 solicitudes cada 15 min | 50 solicitudes cada 15 min |
| Requiere usar credenciales de una [developer App](/es/resources/fundamentals/developer-apps) que está asociada con un [Project](/es/resources/fundamentals/developer-apps) |     | ✔️  |

**Dejar de silenciar a un usuario**

Las siguientes tablas comparan los endpoints estándar de v1.1 y de X API v2 para dejar de silenciar:

| Descripción | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Métodos HTTP admitidos | POST | DELETE |
| Dominio del host | https://api.x.com | https://api.x.com |
| Ruta del endpoint | /1.1/mutes/users/destroy.json | /2/users/:source&#95;user&#95;id/muting/:target&#95;user&#95;id |
| [Authentication](/es/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Rate limits](/es/resources/fundamentals/rate-limits) de solicitud predeterminados | 50 solicitudes cada 15 min | 50 solicitudes cada 15 min |
| Requiere usar credenciales de una [developer App](/es/resources/fundamentals/developer-apps) que está asociada con un [Project](/es/resources/fundamentals/developer-apps) |     | ✔️  |
