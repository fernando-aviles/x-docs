<div id="manage-mutes-standard-v11-compared-to-x-api-v2">
  ### Administrar silencios: Standard v1.1 en comparación con X API v2
</div>

Si has estado utilizando los endpoints estándar de v1.1 [POST mutes/users/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-create) y [POST mutes/users/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-destroy), el objetivo de esta guía es ayudarte a comprender las similitudes y diferencias entre los endpoints para administrar silencios en Standard v1.1 y X API v2.

* **Similitudes**
  * OAuth 1.0a User Context
* **Diferencias**
  * URLs de los endpoints
  * Requisitos de App y Project
  * Métodos HTTP
  * Parámetros de la solicitud

<div id="similarities">
  #### Similitudes
</div>

**Método de autenticación OAuth 1.0a User Context**

Ambas versiones del endpoint son compatibles con [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication). Por lo tanto, si anteriormente utilizabas uno de los endpoints estándar de v1.1 para administrar silenciamientos, puedes seguir usando el mismo método de autenticación si migras a la versión de X API v2.

<div id="differences">
  #### Diferencias
</div>

**URLs de endpoints**

* Endpoints estándar v1.1:
  * POST https://api.x.com/1.1/mutes/users/create.json
    (silenciar a un usuario)
  * POST https://api.x.com/1.1/mutes/users/destroy.json
    (dejar de silenciar a un usuario)
* Endpoint de X API v2:
  * POST https://api.x.com/2/users/:id/muting
    (silenciar a un usuario)
  * DELETE https://api.x.com/2/users/:source&#95;user&#95;id/muting/:target&#95;user&#95;id
    (dejar de silenciar a un usuario)

**Requisitos de App y Project**

Los endpoints de X API v2 requieren que uses credenciales de una [App de desarrollador](/es/resources/fundamentals/developer-apps) que esté asociada con un [Project](/es/resources/fundamentals/developer-apps) al autenticar tus solicitudes. Todos los endpoints de X API v1.1 pueden usar credenciales de Apps o de Apps asociadas con un Project.

**Parámetros de la solicitud**

Los siguientes parámetros de solicitud estándar v1.1 tienen equivalentes en X API v2:

| Estándar v1.1 | X API v2 |
| :--- | :--- |
| user&#95;id | target&#95;user&#95;id |
| screen&#95;name | Sin equivalente |

Ten en cuenta que los parámetros estándar v1.1 se envían como parámetros de consulta, mientras que los parámetros de X API v2 se envían como parámetros del cuerpo (para el endpoint POST) o parámetros de ruta (para el endpoint DELETE).

Además, no se requiere el id del usuario que silencia al usuario de destino cuando se usan los endpoints estándar v1.1, ya que los tokens de acceso enviados con [OAuth 1.0a User Context](/es/resources/fundamentals/authentication) permitían determinar qué usuario estaba iniciando la acción de silenciar o de dejar de silenciar.

<div id="mute-a-user-v2">
  ### Silenciar a un usuario (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/muting" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"target_user_id": "2244994945"}'
  ```

  ```python Python
  # Requiere autenticación OAuth 1.0a User Context
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/muting"
  response = requests.post(url, auth=auth, json={"target_user_id": "2244994945"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Silenciar a un usuario
  response = client.users.mute(
      source_user_id="123456789",
      target_user_id="2244994945"
  )
  print(f"Muting: {response.data.muting}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Silenciar a un usuario
  const response = await client.users.mute("123456789", {
    targetUserId: "2244994945",
  });
  console.log(`Muting: ${response.data?.muting}`);
  ```
</CodeGroup>

<div id="unmute-a-user-v2">
  ### Dejar de silenciar a un usuario (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/123456789/muting/2244994945" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  # Requiere autenticación con OAuth 1.0a User Context
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/muting/2244994945"
  response = requests.delete(url, auth=auth)
  print(response.json())
  ```

