Los endpoints de Mutes te permiten silenciar y quitar el silencio a usuarios, y obtener la lista de usuarios silenciados por el usuario autenticado.

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/muting`](/es/x-api/users/get-muting) | Obtener los usuarios silenciados |
| POST | [`/2/users/:id/muting`](/es/x-api/users/mute-user) | Silenciar a un usuario |
| DELETE | [`/2/users/:source_user_id/muting/:target_user_id`](/es/x-api/users/unmute-user) | Dejar de silenciar a un usuario |

***

<div id="example-get-muted-users">
  ## Ejemplo: Obtener usuarios silenciados
</div>

```bash
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-mute-a-user">
  ## Ejemplo: Silenciar a un usuario
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/muting" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
