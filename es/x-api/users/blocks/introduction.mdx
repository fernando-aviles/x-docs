Los endpoints de bloqueo permiten bloquear y desbloquear usuarios, y obtener la lista de usuarios bloqueados por el usuario autenticado.

<div id="overview">
  ## Descripción general
</div>

<CardGroup cols={2}>
  <Card title="Bloquear" icon="ban">
    Bloquear a un usuario
  </Card>

  <Card title="Desbloquear" icon="circle-check">
    Desbloquear a un usuario
  </Card>

  <Card title="Usuarios bloqueados" icon="list">
    Obtener la lista de tus usuarios bloqueados
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## Endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/blocking`](/es/x-api/users/get-blocking) | Obtener usuarios bloqueados |
| POST | [`/2/users/:id/blocking`](/es/x-api/users/block-dms) | Bloquear a un usuario |
| DELETE | `/2/users/:source_user_id/blocking/:target_user_id` | Desbloquear a un usuario |

***

<div id="example-get-blocked-users">
  ## Ejemplo: Obtener la lista de usuarios bloqueados
</div>

```bash
curl "https://api.x.com/2/users/123456789/blocking?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-block-a-user">
  ## Ejemplo: bloquear a un usuario
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/blocking" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
