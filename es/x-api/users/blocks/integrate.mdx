Esta guía describe los conceptos clave que necesitas conocer para integrar los endpoints de bloqueos en tu aplicación.

***

<div id="authentication">
  ## Autenticación
</div>

Los endpoints de bloqueos requieren autenticación de usuario:

| Método | Descripción |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/es/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Recomendado para aplicaciones nuevas |
| [OAuth 1.0a User Context](/es/resources/fundamentals/authentication) | Compatibilidad heredada |

<Warning>
  No se admite la autenticación de solo aplicación (App-Only). Debes autenticarte en nombre de un usuario.
</Warning>

<div id="required-scopes-oauth-20">
  ### Scopes obligatorios (OAuth 2.0)
</div>

| Scope | Obligatorio para |
|:------|:-----------------|
| `block.read` | Obtener cuentas bloqueadas |
| `block.write` | Bloquear y desbloquear cuentas |
| `users.read` | Obligatorio junto con los scopes de bloqueo |

***

<div id="endpoints-overview">
  ## Descripción general de los endpoints
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | `/2/users/:id/blocking` | Obtener la lista de cuentas bloqueadas |
| POST | `/2/users/:id/blocking` | Bloquear una cuenta |
| DELETE | `/2/users/:source_user_id/blocking/:target_user_id` | Desbloquear una cuenta |

<div id="pagination">
  ## Paginación
</div>

Para usuarios con listas de bloqueo muy extensas, los resultados se paginan:

<CodeGroup dropdown>
  ```bash cURL
  # Primera solicitud
  curl "https://api.x.com/2/users/123/blocking?max_results=100" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"

  # Solicitud posterior con token de paginación
  curl "https://api.x.com/2/users/123/blocking?max_results=100&pagination_token=NEXT_TOKEN" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  # Usa un token de acceso de usuario OAuth 2.0
  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # El SDK maneja la paginación automáticamente
  all_blocked = []

  for page in client.users.get_blocking(user_id="123", max_results=100):
      if page.data:
          all_blocked.extend(page.data)

  print(f"Se bloquearon {len(all_blocked)} usuarios")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  async function getAllBlockedUsers(userId) {
    const allBlocked = [];

    // El SDK maneja la paginación automáticamente
    const paginator = client.users.getBlocking(userId, { maxResults: 100 });

    for await (const page of paginator) {
      if (page.data) {
        allBlocked.push(...page.data);
      }
    }

    return allBlocked;
  }

  // Uso
  const blocked = await getAllBlockedUsers("123");
  console.log(`Se bloquearon ${blocked.length} usuarios`);
  ```
</CodeGroup>

<div id="error-handling">
  ## Gestión de errores
</div>

| Estado | Error | Solución |
|:-------|:------|:---------|
| 400 | Solicitud inválida | Comprueba el formato del id de usuario |
| 401 | No autorizado | Comprueba el token de acceso |
| 403 | Prohibido | Comprueba los scopes y los permisos |
| 404 | No encontrado | El usuario no existe |
| 429 | Demasiadas solicitudes | Espera y vuelve a intentarlo |
