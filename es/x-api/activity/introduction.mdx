El endpoint Activity Stream proporciona la entrega en tiempo real de eventos de actividad de la cuenta para usuarios suscritos. Recibe eventos cuando los usuarios crean Publicaciones, indican que les gustan, siguen a otros usuarios, reciben mensajes directos (MD) y más.

<div id="event-types">
  ## Tipos de eventos
</div>

| Evento | Descripción |
|:------|:------------|
| `tweet_create_events` | Un usuario publica una nueva Publicación |
| `favorite_events` | Un usuario indica que le gusta una Publicación |
| `follow_events` | Un usuario sigue a otro usuario o es seguido |
| `direct_message_events` | Un usuario envía o recibe un mensaje directo (MD) |
| `block_events` | Un usuario bloquea o desbloquea a otro usuario |
| `mute_events` | Un usuario silencia o deja de silenciar a otro usuario |

<div id="how-it-works">
  ## Cómo funciona
</div>

1. **Crear una suscripción** — Suscribirte a la actividad de un usuario
2. **Conectarte al stream** — Establecer una conexión persistente
3. **Recibir eventos** — Recibir eventos de actividad en tiempo real
4. **Procesar eventos** — Procesar eventos en tu aplicación

***

<div id="example-connect-to-stream">
  ## Ejemplo: Conectarse al stream
</div>

```python
import requests

def stream_activity(bearer_token):
    url = "https://api.x.com/2/activity/stream"
    headers = {"Authorization": f"Bearer {bearer_token}"}
    
    response = requests.get(url, headers=headers, stream=True)
    
    for line in response.iter_lines():
        if line:
            print(line.decode("utf-8"))
```
