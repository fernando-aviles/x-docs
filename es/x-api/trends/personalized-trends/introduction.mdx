El endpoint Personalized Trends devuelve temas en tendencia personalizados para el usuario autenticado, según su ubicación e intereses.

<div id="overview">
  ## Descripción general
</div>

<CardGroup cols={2}>
  <Card title="Personalizadas" icon="user">
    Tendencias adaptadas al usuario
  </Card>

  <Card title="Según ubicación" icon="location-dot">
    Basadas en la ubicación del usuario
  </Card>

  <Card title="En tiempo real" icon="bolt">
    Temas en tendencia actuales
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## Endpoint
</div>

| Método | Endpoint | Descripción |
|:-------|:---------|:------------|
| GET | `/2/users/personalized_trends` | Obtener tendencias personalizadas |

***

<div id="example-request">
  ## Ejemplo de solicitud
</div>

```bash
curl "https://api.x.com/2/users/personalized_trends" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-response">
  ## Ejemplo de respuesta
</div>

```json
{
  "data": [
    {
      "trend_name": "#AI",
      "tweet_count": 125000
    },
    {
      "trend_name": "Machine Learning",
      "tweet_count": 85000
    }
  ]
}
```
