Puedes usar la API oEmbed para obtener de forma programática contenido incrustado, como [Tuits](https://developer.x.com/en/docs/twitter-for-websites/embedded-tweets/overview) y [cronologías](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview). 

La respuesta de la API oEmbed devolverá un fragmento de HTML que se reconocerá automáticamente cuando se [incluya el JavaScript de widgets de X en la página](https://developer.x.com/web/javascript/loading).

Ten en cuenta que se recomienda usar la API para realizar tareas por lotes, y aconsejamos utilizar nuestra potente herramienta [publish.x.com](https://publish.x.com/#) para incrustar contenido.

<Tabs>
  <Tab title="Líneas de tiempo incrustadas">
    El fragmento de HTML devuelto se reconocerá automáticamente como una [cronología incrustada](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview) cuando [el JavaScript de widgets de X esté incluido en la página](https://developer.x.com/web/javascript/loading).

    El endpoint oEmbed permite personalizar la apariencia final de una cronología incrustada configurando las propiedades correspondientes en el marcado HTML para que sean interpretadas por el JavaScript de X incluido de forma predeterminada con la respuesta HTML. El formato del marcado devuelto puede cambiar con el tiempo a medida que X agrega nuevas funciones o ajusta su representación de la cronología.

    Devuelve, para una cronología de X especificada por la URL de la cronología, un formato JSON compatible con [oEmbed](https://oembed.com/). Se admiten cronologías de usuario y de listas. El marcado de la cronología está pensado para almacenarse en caché en tus servidores hasta el tiempo de vida de caché sugerido especificado por la propiedad `cache_age`.

    ## URL del recurso

    *https://publish.x.com/oembed*

    ## Información del recurso

    |                          |      |
    | :----------------------- | :--- |
    | Formatos de respuesta    | JSON |
    | ¿Requiere autenticación? | No   |
    | Límite de frecuencia     | No   |

    ## Ejemplos de solicitudes

    ```bash
    curl --request GET --url 'https://publish.x.com/oembed?url=https%3A%2F%2Ftwitter.com%2FInterior%2Fstatus%2F507185938620219395'
    twurl -H publish.x.com "/oembed?url=https://x.com/Interior/status/463440424141459456"
    ```

    ```json
      "url": "https://x.com/TwitterDev",
      "title": "",
      "html": "<a class=\"twitter-timeline\" href=\"https://x.com/TwitterDev\">Tuits de TwitterDev</a>\n<script async src=\"//platform.x.com/widgets.js\" charset=\"utf-8\"></script>",

      "cache_age": "3153600000",
      "provider_name": "Twitter",
      "provider_url": "https://x.com",
      "version": "1.0"
    }
    ```

  <Tab title="Tuits incrustados">
    El fragmento HTML devuelto se reconocerá automáticamente como un [Tuit incrustado](https://developer.x.com/web/embedded-tweets) cuando [se incluya el JavaScript del widget de X en la página](https://developer.x.com/web/javascript/loading).

    El endpoint oEmbed permite personalizar la apariencia final de un Tuit Incrustado estableciendo las propiedades correspondientes en el marcado HTML para que sean interpretadas por el JavaScript de X incluido con la respuesta HTML de forma predeterminada. El formato del marcado devuelto puede cambiar con el tiempo a medida que X añade nuevas funcionalidades o ajusta su representación de Tuits.

    El marcado de respaldo del Tuit debe almacenarse en caché en sus servidores durante el tiempo de vida de caché sugerido especificado por la propiedad `cache_age`.

    *https://publish.x.com/oembed*

    | `maxwidth`  <br />Int `[220..550]`                                                                                                   | `325`                | El ancho máximo de un Tuit renderizado en píxeles enteros. Un valor proporcionado por debajo o por encima del rango permitido se devolverá como el ancho mínimo o máximo admitido, respectivamente; el valor de ancho ajustado se reflejará en la propiedad `width` de la respuesta. Ten en cuenta que X no admite el parámetro `maxheight` de oEmbed. Los Tuits son fundamentalmente texto y, por lo tanto, tienen una altura impredecible que no puede escalarse como una imagen o un video. Asimismo, la respuesta oEmbed no proporcionará ningún valor para `height`. Las implementaciones que necesiten alturas consistentes para los Tuits deben consultar los parámetros `hide_thread` y `hide_media` que se indican a continuación. |
    | `hide_media`  <br />Boolean, cadena de texto o Int                                                                                   | `false`              | Cuando se establece en `true`, `"t"` o `1`, los enlaces de un Tuit no se expanden en previsualizaciones de fotos, vídeos ni enlaces.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
    | `hide_thread`  <br />Booleano, cadena de texto o entero                                                                              | `false`              | Cuando se establece en `true`, `"t"` o `1`, no se mostrará una versión contraída del Tuit anterior en un hilo de conversación cuando el Tuit solicitado sea una respuesta a otro Tuit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

    | `align`  <br />Enum `{left,right,center,none}`                                                                                       | `none`               | Especifica si el Tuit incrustado debe alinearse a la izquierda, a la derecha o al centro de la página con respecto al elemento principal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
    | `lang`  <br />Enum([Idioma](https://developer.x.com/en/docs/twitter-for-websites/twitter-for-websites-supported-languages/overview)) | `en`                 | Devuelve HTML y un Tuit renderizado en el [idioma de X compatible con Tuits incrustados](https://developer.x.com/web/overview/languages) especificado.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
    | `theme`  <br />Enum `{light, dark}`                                                                                                  | `light`              | Cuando se establece en `dark`, el Tuit se muestra con texto claro sobre un fondo oscuro.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
