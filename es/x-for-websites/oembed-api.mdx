Puedes usar la API oEmbed para devolver de forma programática contenido incrustado, como [Tuits](https://developer.x.com/en/docs/twitter-for-websites/embedded-tweets/overview) y [cronologías](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview).

La Respuesta de la API oEmbed devolverá un fragmento de HTML que se reconocerá automáticamente cuando se [incluya el JavaScript de widgets de X en la página](https://developer.x.com/web/javascript/loading).

Ten en cuenta que se recomienda usar la API para realizar tareas de forma masiva, y aconsejamos utilizar nuestra sólida herramienta [publish.x.com](https://publish.x.com/#) para incrustar contenido.

<Tabs>
  <Tab title="Cronologías incrustadas">
    El fragmento de HTML devuelto se reconocerá automáticamente como una [cronología incrustada](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview) cuando [el JavaScript de widgets de X se incluya en la página](https://developer.x.com/web/javascript/loading).

    El endpoint oEmbed permite personalizar la apariencia final de una cronología incrustada estableciendo las propiedades correspondientes en el marcado HTML, que será interpretado por el JavaScript de X incluido con la respuesta HTML de forma predeterminada. El formato del marcado devuelto puede cambiar con el tiempo a medida que X incorpora nuevas funciones o ajusta su representación de cronologías.

    Para una cronología de X especificada por la URL de la cronología, en un formato JSON compatible con [oEmbed](https://oembed.com/). Se admiten cronologías de usuario y de listas. El marcado de la cronología está pensado para almacenarse en caché en tus servidores hasta el tiempo de vida de caché sugerido especificado por la propiedad cache&#95;age.

    ## Resource URL

    *https://publish.x.com/oembed*

    | Rate limited             | No   |

    ## Example Requests

    ```bash
    curl --request GET --url 'https://publish.x.com/oembed?url=https%3A%2F%2Ftwitter.com%2FInterior%2Fstatus%2F507185938620219395'
    twurl -H publish.x.com "/oembed?url=https://x.com/Interior/status/463440424141459456"
    ```

  <Tab title="Tuits incrustados">
    El fragmento HTML devuelto se reconocerá automáticamente como un [Tuit incrustado](https://developer.x.com/web/embedded-tweets) cuando [se incluya el JavaScript del widget de X en la página](https://developer.x.com/web/javascript/loading).

    El endpoint oEmbed permite personalizar la apariencia final de un Tuit Incrustado mediante el establecimiento de las propiedades correspondientes en el marcado HTML que será interpretado por el JavaScript de X incluido con la respuesta HTML de forma predeterminada. El formato del marcado devuelto puede cambiar con el tiempo a medida que X añade nuevas funcionalidades o ajusta su representación de Tuits.

    El marcado de respaldo del Tuit debe almacenarse en caché en sus servidores durante el tiempo de vida de caché sugerido especificado por la propiedad `cache_age`.

    ## URL del recurso

    *https://publish.x.com/oembed*

    | Nombre                                                                                                                               | Valor predeterminado | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
    | :----------------------------------------------------------------------------------------------------------------------------------- | :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
    | `url` obligatorio  <br />cadena de texto                                                                                             |                      | La URL del Tuit que se va a incrustar                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
    | `maxwidth`  <br />Int `[220..550]`                                                                                                   | `325`                | El ancho máximo de un Tuit renderizado en píxeles enteros. Un valor proporcionado por debajo o por encima del rango permitido se devolverá como el ancho mínimo o máximo admitido, respectivamente; el valor de ancho restablecido se reflejará en la propiedad `width` devuelta. Ten en cuenta que X no admite el parámetro oEmbed `maxheight`. Los Tuits son fundamentalmente texto y, por lo tanto, tienen una altura impredecible que no puede escalarse como una imagen o un vídeo. En consecuencia, la respuesta de oEmbed no proporcionará un valor para `height`. Las implementaciones que necesiten alturas consistentes para los Tuits deben consultar los parámetros `hide_thread` y `hide_media` que se indican a continuación. |
    | `hide_media`  <br />Booleano, cadena de texto o entero                                                                               | `false`              | Cuando se establece en `true`, `"t"` o `1`, los enlaces de un Tuit no se expanden a vistas previas de fotos, videos ni enlaces.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
    | `hide_thread`  <br />Booleano, cadena de texto o entero                                                                              | `false`              | Cuando se establece en `true`, `"t"` o `1`, no se mostrará una versión contraída del Tuit anterior en el hilo de conversación si el Tuit solicitado es una respuesta a otro Tuit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
    | `omit_script`  <br />Booleano, cadena de texto o Int                                                                                 | `false`              | Cuando se establece en `true`, `"t"` o `1`, el `<script>` responsable de cargar `widgets.js` no se incluirá.     | `align`  <br />Enum `{left,right,center,none}`                                                                                       | `none`               | Especifica si el Tuit incrustado debe alinearse a la izquierda, a la derecha o al centro de la página con respecto a su elemento padre.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
    | `lang`  <br />Enum([Idioma](https://developer.x.com/en/docs/twitter-for-websites/twitter-for-websites-supported-languages/overview)) | `en`                 | La solicitud devuelve HTML y un Tuit renderizado en el [idioma de X compatible con Tuits incrustados](https://developer.x.com/web/overview/languages) especificado.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
    | `theme`  <br />Enumeración `{light, dark}`                                                                                           | `light`              | Cuando se configura en `dark`, el Tuit se muestra con texto claro sobre un fondo oscuro.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
    | `dnt`  <br />Boolean                                                                                                                 | `false`              | Cuando se establece en `true`, el Tuit y la página en la que está incrustado en tu sitio no se utilizan con fines que incluyen [sugerencias personalizadas](https://support.x.com/articles/20169421) y [anuncios personalizados](https://support.x.com/articles/20170405).                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
