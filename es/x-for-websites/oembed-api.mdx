Puedes usar la API de oEmbed para recuperar de forma programática contenido incrustado, como [Tweets](https://developer.x.com/en/docs/twitter-for-websites/embedded-tweets/overview) y [cronologías](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview). 

La respuesta de la API de oEmbed será un fragmento de HTML que se reconocerá automáticamente cuando se [incluya el JavaScript de widgets de X en la página](https://developer.x.com/web/javascript/loading).

Ten en cuenta que se recomienda usar la API para realizar tareas en lote, y te aconsejamos utilizar nuestra potente herramienta [publish.x.com](https://publish.x.com/#) para incrustar contenido.

<Tabs>
  <Tab title="Cronologías incrustadas">
    El fragmento de HTML devuelto se reconocerá automáticamente como una [cronología incrustada](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview) cuando [se incluya el JavaScript de widgets de X en la página](https://developer.x.com/web/javascript/loading).

    El endpoint oEmbed permite personalizar la apariencia final de una cronología incrustada estableciendo las propiedades correspondientes en el marcado HTML, que serán interpretadas por el JavaScript de X incluido de forma predeterminada en la respuesta HTML. El formato del marcado devuelto puede cambiar con el tiempo a medida que X añade nuevas funciones o ajusta su representación de cronologías.

    Para una cronología de X especificada por la URL de la cronología, en un formato JSON compatible con [oEmbed](https://oembed.com/). Se admiten cronologías de usuario y de listas. El marcado de la cronología está pensado para almacenarse en caché en tus servidores hasta el tiempo de vida de caché sugerido especificado por la propiedad cache&#95;age.

    ## Resource URL

    *https://publish.x.com/oembed*

    ## Example Requests

    ```bash
    curl --request GET --url 'https://publish.x.com/oembed?url=https%3A%2F%2Ftwitter.com%2FInterior%2Fstatus%2F507185938620219395'
    twurl -H publish.x.com "/oembed?url=https://x.com/Interior/status/463440424141459456"
    ```

    }

  <Tab title="Tweets incrustados">
    El fragmento HTML devuelto se reconocerá automáticamente como un [Tweet incrustado](https://developer.x.com/web/embedded-tweets) cuando [se incluya el JavaScript del widget de X en la página](https://developer.x.com/web/javascript/loading).

    El endpoint oEmbed permite personalizar la apariencia final de un Tweet incrustado mediante la configuración de las propiedades correspondientes en el marcado HTML, que serán interpretadas por el JavaScript de X incluido por defecto en la respuesta HTML. El formato del marcado devuelto puede cambiar con el tiempo a medida que X añade nuevas funcionalidades o ajusta la representación de sus Tweets.

    El marcado de respaldo del Tweet debe almacenarse en caché en tus servidores durante el tiempo de vida de caché sugerido especificado por la propiedad `cache_age`.

    ## URL del recurso

    *https://publish.x.com/oembed*

    ## Parámetros

    | Nombre                                                                                                                               | Predeterminado | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
    | :----------------------------------------------------------------------------------------------------------------------------------- | :------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
    | `url` obligatorio  <br />String                                                                                                      |                | La URL del Tweet que se va a incrustar                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
    | `maxwidth`  <br />Int `[220..550]`                                                                                                   | `325`          | El ancho máximo de un Tweet renderizado en píxeles enteros. Un valor proporcionado por debajo o por encima del rango permitido se devolverá como el ancho mínimo o máximo admitido, respectivamente; el valor de ancho ajustado se reflejará en la propiedad `width` devuelta. Ten en cuenta que X no admite el parámetro oEmbed `maxheight`. Los Tweets son fundamentalmente texto y, por lo tanto, tienen una altura impredecible que no se puede escalar como una imagen o un video. Del mismo modo, la respuesta de oEmbed no proporcionará un valor para `height`. Las implementaciones que necesiten alturas consistentes para los Tweets deben usar los parámetros `hide_thread` y `hide_media` que se indican a continuación. |
    | `hide_media`  <br />Boolean, String o Int                                                                                            | `false`        | Cuando se establece en `true`, `"t"` o `1`, los enlaces de un Tweet no se expanden a vistas previas de fotos, videos ni enlaces.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
    | `hide_thread`  <br />Boolean, String o Int                                                                                           | `false`        | Cuando se establece en `true`, `"t"` o `1`, no se mostrará una versión contraída del Tweet anterior en un hilo de conversación cuando el Tweet solicitado sea una respuesta a otro Tweet.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
    | `omit_script`  <br />Booleano, cadena o entero                                                                                       | `false`        | Cuando se establece en `true`, `"t"` o `1`, no se devolverá el `<script>` encargado de cargar `widgets.js`. Tus páginas web deben incluir su propia referencia a `widgets.js` para utilizarlo en todos los widgets de X, incluidos los [Tweets incrustados](https://developer.x.com/web/embedded-tweets).                                                                                                                                                                                                                                                                                                                                                                                                                             |
    | `align`  <br />Enum `{left,right,center,none}`                                                                                       | `none`         | Especifica si el Tweet incrustado debe alinearse a la izquierda, derecha o al centro de la página con respecto a su elemento padre.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
    | `lang`  <br />Enum([Idioma](https://developer.x.com/en/docs/twitter-for-websites/twitter-for-websites-supported-languages/overview)) | `en`           | La solicitud devuelve HTML y un Tweet renderizado en el [idioma de X especificado compatible con Tweets incrustados](https://developer.x.com/web/overview/languages).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
    | `theme`  <br />Enum `{light, dark}`                                                                                                  | `light`        | Cuando se configura en `dark`, el Tweet se muestra con texto claro sobre un fondo oscuro.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
    | `dnt`  <br />Booleano                                                                                                                | `false`        | Cuando se establece en `true`, el Tweet y su página incrustada en tu sitio no se utilizan con fines como las [sugerencias personalizadas](https://support.x.com/articles/20169421) y los [anuncios personalizados](https://support.x.com/articles/20170405).                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
