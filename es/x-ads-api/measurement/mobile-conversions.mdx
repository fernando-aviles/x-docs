<div id="mact-overview">
  ## Descripción general de MACT
</div>

La medición de [promoción de aplicaciones móviles](https://biz.x.com/mobile-app-promotion) en X permite a los anunciantes hacer un seguimiento del éxito de las campañas publicitarias en X diseñadas para impulsar instalaciones u otras conversiones dentro de la aplicación. Un socio de medición móvil de X ofrece a un anunciante la posibilidad de gestionar qué conversiones desea medir desde las aplicaciones que está promocionando en X. Una vez que el anunciante haya configurado el type y las ventanas temporales de los eventos que quiere medir, el socio de medición móvil enviará todos esos eventos a X y recibirá de inmediato datos de atribución que indican la campaña y la pieza creativa con las que interactuó el usuario y que generaron la conversión.

<div id="conversion-events">
  ### Eventos de conversión
</div>

Para poder reportar un [evento de conversión](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-event) a X y obtener datos de atribución, el partner debe enviar el ID de la app móvil, el tipo y la marca de tiempo de la conversión, así como un valor con hash del ID de publicidad/dispositivo. Proporcionar estos datos registrará el evento de conversión en la plataforma de X y devolverá la atribución cuando corresponda. Además, el anunciante puede elegir proporcionar metadatos adicionales sobre el evento de conversión, como el valor de una compra, el ID de un producto o un método de registro.

<div id="post-conversion_event">
  #### POST conversion_event
</div>

Registra un evento de conversión de medición móvil. La respuesta indicará la atribución de X o de X Audience Platform (TAP).

Este endpoint está relacionado con [GET conversion&#95;attribution](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-attribution#get-conversion-attribution).

En la respuesta se asignará atribución de X, de TAP o ninguna atribución. El nodo `twitter_attribution` siempre estará presente y tendrá un valor de `null` cuando no haya atribución de X (consulta el ejemplo de respuesta a continuación). Si se asigna atribución de TAP, estará presente un nodo `tpn_attribution` y se rellenará en consecuencia. Consulta la [descripción general de TAP](https://developer.x.com/en/docs/x-ads-api/measurement/overview/twitter-audience-platform) para obtener más información.

Hay varios parámetros opcionales disponibles para establecer metadatos asociados con cada evento de conversión. Estos metadatos no tienen ningún efecto en los cálculos de atribución.

<div id="resource-url">
  ##### URL del recurso
</div>

`https://ads-api.x.com/12/conversion_event`

<div id="parameters">
  ##### Parámetros
</div>

| Nombre | Descripción |
| :--- | :--- |
| app&#95;id  <br />*required* | El identificador único correspondiente en la tienda de aplicaciones.<br /><br />Tipo: int, string<br /><br />Ejemplo: `333903271`, `com.vine.android` |
| conversion&#95;time  <br />*required* | La hora del evento de conversión en formato de marca de tiempo ISO-8601, con milisegundos añadidos.<br /><br />Tipo: string<br /><br />Ejemplo: `2014-05-22T02:38:28.103Z` |
| conversion&#95;type  <br />*required* | El tipo de evento de conversión.<br /><br />Tipo: enum<br /><br />Valores posibles: `PURCHASE`, `SIGN_UP`, `INSTALL`, `RE_ENGAGE`, `UPDATE`, `TUTORIAL_COMPLETE`, `RESERVATION`, `ADD_TO_CART`, `ADD_TO_WISHLIST`, `LOGIN`, `CHECKOUT_INITIATED`, `SEARCH`, `LEVEL_ACHIEVED`, `ACHIEVEMENT_UNLOCKED`, `CONTENT_VIEW`, `SHARE`, `INVITE`, `ADDED_PAYMENT_INFO`, `SPENT_CREDITS`, `RATED` |
| hashed&#95;device&#95;id  <br />*required* | El IDFA o AdID con hash HMAC&#95;SHA-256.<br /><br />Tipo: string<br /><br />Ejemplo: `ABCD1234XYZ` |
| os&#95;type  <br />*required* | El tipo de sistema operativo (OS) para la aplicación.<br /><br />Tipo: enum<br /><br />Valores posibles: `IOS`, `ANDROID` |
| click&#95;window  <br />*optional* | La ventana de clic para este evento en días.<br /><br />Tipo: int<br /><br />**Nota**: `click_window` debe ser mayor o igual que view&#95;through&#95;window<br /><br />Predeterminado: `14`  <br />Valores posibles: `1`, `7`, `14`, `30` |
| device&#95;ip&#95;address  <br />*optional* | Dirección IPv4 o IPv6 del dispositivo cuando ocurrió el evento de conversión.<br /><br />Tipo: string<br /><br />Ejemplo: `192.133.78.1` |
| level  <br />*optional* | Un nivel asociado a este evento.<br /><br />Tipo: int<br /><br />Ejemplo: `2` |
| non&#95;twitter&#95;engagement&#95;time  <br />*optional* | La hora de la última interacción fuera de X antes de la conversión.<br /><br />Tipo: string<br /><br />Ejemplo: `2014-05-22T02:38:28.103Z` |
| non&#95;twitter&#95;engagement&#95;type  <br />*optional* | El tipo de interacción fuera de X previa al evento de conversión.<br /><br />Tipo: enum<br /><br />Valores posibles: `CLICK`, `VIEW` |
| number&#95;items  <br />*optional* | Número de elementos asociados a este evento.<br /><br />Tipo: int<br /><br />Ejemplo: `2` |
| price&#95;currency  <br />*optional* | Se espera que sea un código ISO 4217 que indique la moneda asociada con este evento.<br /><br />Tipo: string<br /><br />Ejemplos: `EUR`, `USD`, `JPY` |
| price&#95;micro  <br />*optional* | Un importe asociado a este evento en microunidades.<br /><br />Tipo: int<br /><br />Ejemplo: `123450000` |
| user&#95;payment&#95;info  <br />*optional* | Un valor booleano que indica si la información de pago del usuario está almacenada en la aplicación asociada con este evento.<br /><br />Tipo: bool<br /><br />Valores posibles: `true` o `false` |
| view&#95;through&#95;window  <br />*optional* | La ventana de visualización (view-through) para este evento en días.<br /><br />**Nota**:<br /><br />`click_window` debe ser mayor o igual que view&#95;through&#95;window.<br /><br />Tipo: int<br /><br />Predeterminado: `1`  <br />Valores posibles: `0`, `1`, `7`, `14`, `30` |

En la respuesta se indicará atribución de X, TAP o ninguna atribución.
