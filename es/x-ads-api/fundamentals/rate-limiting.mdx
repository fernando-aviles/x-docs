La Advertiser API tiene límites de tasa similares a los de la API REST v1.1, tal como se documenta aquí: [Limitación de tasa de la API REST en v1.1](https://developer.x.com/content/developer-twitter/en/docs/basics/rate-limits). A diferencia de la API REST v1.1, no existe un índice accesible mediante programación de los límites por endpoint. Los límites de tasa de los endpoints y las ventanas de restablecimiento se comunican mediante encabezados de respuesta HTTP. Toda la limitación de tasa en la Ads API utiliza OAuth 1.0a.

<div id="user-level-and-ad-account-level-limits">
  ## Límites a nivel de usuario y de cuenta publicitaria
</div>

Hay dos tipos de límites de frecuencia: a nivel de token de usuario y a nivel de cuenta publicitaria. Un subconjunto de endpoints tiene habilitada la limitación de frecuencia a nivel de cuenta publicitaria. Un token de usuario es el [token de acceso OAuth](/es/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) que utilizas para autenticarte y llamar a la Ads API. Cada token de usuario puede tener acceso a una o más cuentas publicitarias.

Los desarrolladores deben utilizar el límite de frecuencia a nivel de cuenta publicitaria cuando este se devuelva en los encabezados de la respuesta y utilizar únicamente el límite a nivel de usuario cuando no se encuentre el límite de cuenta publicitaria.

Los límites de frecuencia a nivel de usuario se expresan mediante estos encabezados: **x-rate-limit-limit**, **x-rate-limit-remaining** y **x-rate-limit-reset**.

Para los endpoints con limitación de frecuencia a nivel de cuenta publicitaria habilitada, los límites de frecuencia se expresan mediante estos encabezados: **x-account-rate-limit-limit**, **x-account-rate-limit-remaining** y **x-account-rate-limit-reset**.

Los límites de frecuencia a nivel de cuenta publicitaria se proporcionan solo para endpoints GET, para permitir que las aplicaciones sincronicen los datos de entidades (como objetos de campaña o de line item) desde un único token de usuario que accede a múltiples cuentas publicitarias. No se garantiza que las acciones de escritura usen los mismos límites de frecuencia a nivel de cuenta publicitaria.

Para los endpoints con límite de frecuencia a nivel de cuenta publicitaria, el límite de frecuencia a nivel de usuario se establece en un valor alto que representa una cuota global para toda tu aplicación. Cuando esté disponible, el límite de frecuencia a nivel de cuenta publicitaria debe tener prioridad para controlar tu volumen de solicitudes.

<div id="best-practices">
  ## Mejores prácticas
</div>

1. Guarda en tu base de datos una marca de tiempo con la última sincronización y, cuando solicites datos, si corresponde, pide los datos con la opción `sort_by=updated_at-desc` para poder detener tu proceso de sincronización cuando llegues a datos anteriores a tu última marca de tiempo sincronizada. Esto evitará sincronizar los mismos datos de forma redundante.

2. Solicita múltiples entidades en una sola petición: Algunos endpoints te permiten especificar una lista de valores separados por comas para recuperar múltiples datos similares. Esto puede reducir la cantidad total de llamadas que realizas y, por lo tanto, aprovechar el límite de frecuencia de la API de manera más eficiente.

3. Solicita el valor máximo de `count` en tus peticiones: Para algunos endpoints, como [GET accounts/:account&#95;id/targeting&#95;criteria](/es/x-ads-api/campaign-management#targeting-criteria), se recomienda encarecidamente llamarlos con el valor máximo de `count` para devolver 1000 objetos en lugar del valor predeterminado de 200.

<div id="faqs">
  ## Preguntas frecuentes
</div>

*¿Es posible aumentar los límites de frecuencia para una cuenta publicitaria en particular o para nuestra aplicación?*

Por lo general, no podemos aumentar los límites de frecuencia y están configurados para admitir las cuentas publicitarias más grandes. Implementa primero las prácticas recomendadas indicadas en este documento y, si los límites de frecuencia siguen afectando tu capacidad de escalar o de lograr tus objetivos comerciales, ponte en contacto con tus contactos de X Ads API y proporciónales información completa sobre el caso de uso y las solicitudes implicadas.
