La Advertiser API está sujeta a límites de frecuencia de forma similar a la REST API v1.1, como se documenta aquí: [Limitación de frecuencia de la API REST en v1.1](https://developer.x.com/content/developer-twitter/en/docs/basics/rate-limits). A diferencia de la REST API v1.1, no existe un índice programático de los límites por endpoint. Los límites de frecuencia por endpoint y las ventanas de restablecimiento se comunican mediante encabezados de Respuesta HTTP. Toda la limitación de frecuencia en la Ads API se realiza mediante OAuth 1.0a.

<div id="user-level-and-ad-account-level-limits">
  ## Límites a nivel de usuario y a nivel de cuenta publicitaria
</div>

Hay dos tipos de límites de frecuencia: a nivel de token de usuario y a nivel de cuenta publicitaria. Un subconjunto de endpoints está habilitado para usar límites de frecuencia a nivel de cuenta publicitaria. Un token de usuario es el [token de acceso OAuth](/es/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) que utilizas para autenticarte y llamar a la Ads API. Cada token de usuario puede tener acceso a una o más cuentas publicitarias.

Los desarrolladores deben utilizar el límite de frecuencia a nivel de cuenta publicitaria cuando se devuelva en los encabezados de respuesta y utilizar únicamente el límite a nivel de usuario cuando no se encuentre el límite de la cuenta publicitaria.

Los límites de frecuencia a nivel de usuario se expresan mediante estos encabezados: **x-rate-limit-limit**, **x-rate-limit-remaining** y **x-rate-limit-reset**

Para los endpoints con limitación de frecuencia a nivel de cuenta publicitaria habilitada, los límites de frecuencia se expresan mediante estos encabezados: **x-account-rate-limit-limit**, **x-account-rate-limit-remaining** y **x-account-rate-limit-reset**.

Los límites de frecuencia a nivel de cuenta publicitaria se proporcionan solo para endpoints de tipo GET para permitir que las aplicaciones sincronicen los datos de entidades (como objetos de campañas o line items) desde un único token de usuario que accede a varias cuentas publicitarias. No se garantiza que las acciones de escritura utilicen los mismos límites de frecuencia a nivel de cuenta publicitaria.

Para los endpoints con límites de frecuencia a nivel de cuenta publicitaria, el límite de frecuencia a nivel de usuario se establece en un valor alto que representa una cuota global para toda tu aplicación. Cuando esté disponible, el límite de frecuencia a nivel de cuenta publicitaria debe tener prioridad al controlar tu volumen de solicitudes.

<div id="best-practices">
  ## Mejores prácticas
</div>

1. Guarda una marca de tiempo en tu base de datos correspondiente a la última sincronización y, al solicitar datos cuando corresponda, pide los datos con la opción `sort_by=updated_at-desc` para poder detener tu proceso de sincronización después de llegar a datos anteriores a tu última marca de tiempo sincronizada. Esto evitará sincronizar los mismos datos de forma redundante.

2. Solicita múltiples entidades en una sola solicitud: algunos endpoints te permiten especificar una lista de valores separados por comas para recuperar múltiples fragmentos de datos similares. Esto puede reducir el número total de llamadas que realizas y, por lo tanto, aprovechar el rate limit de forma más eficiente.

3. Solicita el valor máximo de “count” en tus solicitudes: para algunos endpoints, como [GET accounts/:account&#95;id/targeting&#95;criteria](/es/x-ads-api/campaign-management#targeting-criteria), se recomienda encarecidamente invocarlos con el valor máximo de `count` para devolver 1000 objetos en lugar del valor predeterminado de 200.

<div id="faqs">
  ## Preguntas frecuentes
</div>

*¿Es posible aumentar los límites de tasa para una cuenta publicitaria en particular o para nuestra aplicación?*

Por lo general, no podemos aumentar los límites de tasa y están configurados para admitir incluso las cuentas publicitarias más grandes. Implementa primero las prácticas recomendadas indicadas en este documento y, si los límites de tasa siguen afectando tu capacidad para escalar o lograr tus objetivos de negocio, comunícate con tus contactos de X Ads API proporcionando todos los detalles sobre el caso de uso y las solicitudes relacionadas.
