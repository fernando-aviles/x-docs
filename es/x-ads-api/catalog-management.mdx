<div id="overview">
  ## Descripción general
</div>

La Catalog API es una solución de comercio que da a los anunciantes la capacidad de configurar feeds de productos, agrupar productos en conjuntos y gestionar de forma integral los productos del catálogo. La Catalog API será una herramienta central que permite la gestión programática de catálogos y otorga a los anunciantes más control sobre cómo se incorporan y actualizan sus catálogos.

Un catálogo contiene todo lo relacionado con el producto y el conjunto de productos del usuario y está asociado al handle del usuario. Actualmente, **un usuario solo puede crear un catálogo**. 

La Catalog API admite 2 formas de incorporar productos:

1.  Scheduled Feed: el usuario puede añadir una URL de feed (CSV, TSV y XML) que se recuperará periódicamente (X admite actualmente un archivo de hasta 8 GB)

2.  Batch Products API: el usuario puede ver, crear, actualizar y eliminar atributos de productos con solicitudes por lotes (JSON)

Los comercios de X pueden crear conjuntos de productos basados en reglas de filtrado. Al hacerlo, podrán adjuntar metadatos adicionales a sus productos y crear conjuntos de productos especiales para mostrar estos productos mediante funciones de comercio orgánico o anuncios dinámicos de productos. La Catalog API y X Shopping Manager admiten dos tipos de conjuntos de productos. 

1.  Manual: el usuario puede seleccionar hasta 50 productos y establecer un nombre y una descripción

2.  Filtro: el usuario puede añadir hasta 30 filtros para generar automáticamente conjuntos con productos que cumplan estos filtros. Los tipos de filtros incluyen precio, categoría de producto de Google, tipo de producto, inventario, precio de oferta y campos personalizados.

La Catalog API incluye 4 endpoints para gestionar catálogos:

* [Product Catalogs](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-catalogs) \- Creación de un contenedor para la información de productos
* [Products](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/products) -  Adición síncrona, actualización, visualización y eliminación de productos de los catálogos
* [Product Sets](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-sets) -  Clasificación de productos en grupos basados en la información de productos
* [Schedule Feeds](https://developer.x.com/en/docs/twitter-ads-api/catalog-management/api-reference/scheduled-feeds) \- Configuración de la incorporación asíncrona de datos de productos desde archivos en los catálogos

<div id="prerequisites-for-the-catalog-api">
  ### Requisitos previos para Catalog API
</div>

Los endpoints de Catalog API están disponibles actualmente únicamente mediante acceso anticipado. Para solicitar acceso, ponte en contacto con tu representante de X. 

Debes aceptar los términos del servicio a través de [X Shopping Manager](https://ads.x.com/shopping_manager).

Para obtener más información sobre Shopping Manager y las especificaciones de productos, consulta la [guía de especificaciones de productos](https://business.x.com/en/help/shopping-specs.html).
