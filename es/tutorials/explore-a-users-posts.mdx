<div id="introduction">
  ## Introducción
</div>

Aunque el [endpoint de búsqueda reciente](/es/x-api/posts/search/introduction) solo te permite obtener publicaciones realizadas en los últimos 7 días, los endpoints de cronología de publicaciones de usuario y de cronología de menciones de usuario te permiten recuperar publicaciones y menciones con más de 7 días de antigüedad, para un usuario autorizado (utilizando el id de usuario). Los desarrolladores pueden usar estos endpoints para estudiar temas, entidades y el sentimiento de las publicaciones de la cronología de un usuario o de sus menciones. En este tutorial, te mostraremos cómo explorar las publicaciones y menciones de un usuario utilizando los endpoints de cronología de Tweet de usuario y de cronología de menciones de usuario.
 

<div id="prerequisites">
  ## Requisitos previos
</div>

* Para poder usar los endpoints de cronología de Tuits de usuario y de cronología de menciones de usuario, necesitarás tener una cuenta de desarrollador válida. 
* También necesitarás tener un [Project](/es/resources/fundamentals/developer-apps) creado.
* Debes haberte [registrado](https://developer.x.com/en/portal/petition/essential/basic-info) para obtener una cuenta de desarrollador y haber activado la [nueva experiencia de la Developer Console](https://developer.x.com/en/portal/opt-in.html). 
* El acceso está disponible con claves y tokens activos de una App de desarrollador asociada a un [Project](/es/resources/fundamentals/developer-apps) creado en la [Developer Console](/es/resources/fundamentals/developer-portal).
* Un Bearer Token de tu App en la [X Developer Console](/es/resources/fundamentals/developer-portal).
* Si no tienes una cuenta de desarrollador aprobada, puedes [solicitar una](https://developer.x.com/en/apply-for-access).

  ## Cuenta de desarrollador aprobada
</div>

Si aún no tienes una, puedes [solicitarla](https://developer.x.com/en/apply-for-access).

A continuación, puedes crear una nueva App o conectar una [App](/es/resources/fundamentals/developer-apps) existente (una App es un contenedor para tus claves de API que necesitas para hacer una solicitud HTTP a la X API).

<Frame>
  <img src="/images/add-your-app.png.twimg.1920.png" />

Haz clic en **Create a new App instead** y asigna un nombre a tu App para crear una App nueva.

  <img src="/images/last-step-name-your-app.png.twimg.1920.png" />

Una vez que hagas clic en **Complete**, obtendrás tus claves de API y el Bearer Token, que podrás usar para conectarte a los nuevos endpoints de la X API v2.

<div id="how-to-get-the-user-id-for-a-user-to-use-in-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## Cómo obtener el id de usuario para usarlo en los endpoints de timeline de Tuits de usuario y de menciones de usuario
</div>

Los endpoints de timeline de Tuits de usuario y de menciones de usuario permiten obtener Publicaciones usando el id de usuario. Para obtener el id de usuario a partir de un nombre de usuario, puedes usar el nuevo [endpoint de búsqueda de usuarios v2](/es/x-api/users/lookup/quickstart/user-lookup). Reemplaza USER&#95;NAME con el nombre de usuario que desees y XXXX con tu propio Bearer Token que obtuviste anteriormente

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

Verás el ID de usuario en la respuesta, como se muestra a continuación:

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```

<div id="connecting-to-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## Conectarse a los endpoints de la cronología de Tuits del usuario y de la cronología de menciones del usuario
</div>

Para obtener la cronología de Tuits de un usuario, ejecuta el siguiente comando curl en tu terminal (asegúrate de reemplazar USER&#95;ID con el id de usuario que desees y XXXX con tu propio Bearer Token que obtuviste anteriormente)

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```

Verás que la respuesta JSON de estas solicitudes incluye, de forma predeterminada, el id y el texto de las publicaciones (ejemplo a continuación).

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 If you are new to the X API v2, check out this step-by-step guide to making your first request https://t.co/4rZqThpSbp"
}
```

Si quieres que se devuelvan campos adicionales como parte de la respuesta (como información del usuario, campos de Tuit adicionales como `context annotations`, etc.), deberás especificar esos campos explícitamente en tu respuesta. Aprende cómo hacerlo en la [guía sobre cómo usar campos y expansions](/es/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions).

También puedes obtener estas Publicaciones utilizando el lenguaje de programación que prefieras. Consulta nuestro código de ejemplo en Python, Node (JavaScript), Java y Ruby para los endpoints de la cronología de Tuits del usuario y de la cronología de menciones del usuario en nuestro [repositorio de GitHub](https://github.com/xdevplatform/Twitter-API-v2-sample-code).

<div id="exploring-the-users-posts">
  ## Exploración de las Publicaciones del usuario
</div>

Una vez que conozcas cómo obtener Publicaciones usando los endpoints de cronología de Tuits de usuario y de cronología de menciones de usuario, puedes empezar a explorar sus Publicaciones. Por ejemplo, si quisieras identificar entidades con nombre frecuentes presentes en las menciones de un usuario, puedes hacer lo siguiente:

En la solicitud de API, especifica que quieres que se devuelva el objeto context&#95;annotations en las respuestas de Tuits:

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

En la respuesta, verás si hay entidades con nombre en las menciones. Aquí tienes un ejemplo:

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "Marcas y empresas"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

Si desea ver qué entidades populares aparecen en sus menciones, puede llevar un recuento de entidades populares analizando cada Tuit en las menciones.

Si desea explorar la URL de la imagen de vista previa de todas las Publicaciones en su cronología que contienen medios, puede hacer lo siguiente:

En la solicitud de la API, especifique que desea el preview&#95;image&#95;url en los campos tweet.media y la expansión attachments.media&#95;keys

```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

En la respuesta, podrás ver el campo preview&#95;image&#95;url en el objeto includes, como se muestra a continuación:

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```
