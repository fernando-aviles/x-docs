<div id="introduction">
  ## Introducción
</div>

Aunque el [endpoint de búsqueda reciente](/es/x-api/posts/search/introduction) solo permite obtener Publicaciones de los últimos 7 días, los endpoints de cronología de Publicaciones de usuario y de cronología de menciones de usuario permiten recuperar Publicaciones y menciones anteriores a esos 7 días, para un usuario autorizado (usando el id de usuario). Los desarrolladores pueden usar estos endpoints para estudiar temas, entidades y el sentimiento de las Publicaciones en la cronología de un usuario o en sus menciones. En este tutorial, te mostraremos cómo explorar las Publicaciones y menciones de un usuario usando los endpoints de cronología de Tweets de usuario y de cronología de menciones de usuario.
 

<div id="prerequisites">
  ## Requisitos previos
</div>

* Para poder usar los endpoints de la cronología de Tweets de usuario y de menciones de usuario, necesitarás tener una cuenta de desarrollador válida. 
* También necesitarás tener creado un [Project](/es/resources/fundamentals/developer-apps).
* Debes haberte [registrado](https://developer.x.com/en/portal/petition/essential/basic-info) para obtener una cuenta de desarrollador y haber activado la [nueva experiencia de la Consola de desarrollador](https://developer.x.com/en/portal/opt-in.html). 
* El acceso está disponible con claves y tokens activos para una App de desarrollador que esté asociada a un [Project](/es/resources/fundamentals/developer-apps) creado en la [Consola de desarrollador](/es/resources/fundamentals/developer-portal).
* Necesitarás un Bearer Token de tu App en la [Consola de desarrollador de X](/es/resources/fundamentals/developer-portal).
* Si no tienes una cuenta de desarrollador aprobada, puedes [solicitar una](https://developer.x.com/en/apply-for-access).

<div id="how-to-get-the-user-id-for-a-user-to-use-in-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## Cómo obtener el id de usuario para usarlo en los endpoints de timeline de Tweets de usuario y timeline de menciones de usuario
</div>

Los endpoints de timeline de Tweets de usuario y timeline de menciones de usuario te permiten obtener Publicaciones usando el id de usuario. Para obtener el id de usuario a partir de un nombre de usuario, puedes usar el nuevo [user lookup endpoint v2](/es/x-api/users/lookup/quickstart/user-lookup). Sustituye USER&#95;NAME por el nombre de usuario que elijas y XXXX por tu propio Bearer Token que obtuviste anteriormente

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

Verás el id de usuario en la respuesta, como se muestra a continuación:

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```

<div id="connecting-to-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## Conectarse a los endpoints de timeline de Tweets de usuario y timeline de menciones de usuario
</div>

Para obtener el timeline de Tweets de un usuario, ejecuta el siguiente comando curl en tu terminal (asegúrate de reemplazar USER&#95;ID con el id del usuario que elijas y XXXX con tu propio Bearer Token que obtuviste anteriormente)

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```

Verás que la respuesta JSON de estas solicitudes incluye el id y el texto de las Publicaciones de forma predeterminada (ejemplo a continuación).

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 If you are new to the X API v2, check out this step-by-step guide to making your first request https://t.co/4rZqThpSbp"
}
```

Si deseas que se devuelvan campos adicionales como parte de la respuesta (como información del usuario, campos adicionales de Tweet como anotaciones de contexto, etc.), tendrás que especificar esos campos explícitamente en tu solicitud. Aprende cómo hacerlo en la [guía sobre el uso de campos y expansions](/es/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions).

También puedes obtener estas Publicaciones en el lenguaje de programación que prefieras. Consulta nuestro código de ejemplo en Python, Node (JavaScript), Java y Ruby para los endpoints user Tweet timeline y user mention timeline en nuestro [repositorio de GitHub](https://github.com/xdevplatform/Twitter-API-v2-sample-code).

<div id="exploring-the-users-posts">
  ## Exploración de las Publicaciones del usuario
</div>

Una vez que sepas cómo obtener Publicaciones usando los endpoints de cronología de Tweets del usuario y de cronología de menciones del usuario, puedes empezar a explorar sus Publicaciones. Por ejemplo, si quisieras identificar entidades con nombre comunes presentes en las menciones de un usuario, puedes hacer lo siguiente:

En la solicitud a la API, especifica que quieres que se incluya el objeto context&#95;annotations en las respuestas de Tweet:

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

En la respuesta, podrás ver si hay entidades nombradas en las menciones. Aquí tienes un ejemplo:

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "Marcas y compañías"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

Si quieres ver qué entidades populares aparecen en tus menciones, puedes llevar un recuento de entidades populares analizando cada Tweet de las menciones.

Si quieres explorar la URL de la imagen de vista previa de todas las Publicaciones de tu cronología que contienen contenido multimedia, puedes hacer lo siguiente:

En la solicitud de API, especifica que quieres el preview&#95;image&#95;url en los campos tweet.media y las expansions attachments.media&#95;keys

```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

En la respuesta verás `preview_image_url` dentro del objeto includes, como se muestra a continuación:

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```
