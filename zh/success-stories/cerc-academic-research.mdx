<div id="challenge">
  ## 挑战
</div>

对于 Stein Monteiro——加拿大瑞尔森大学加拿大移民与融合卓越研究主席（CERC）的研究员——来说，他的工作处在统计学、文化与时事的交汇处。虽然他的经济学专长为他在学术界的成功打下了基础，但真正点燃他对移民研究热情的，是他自己的亲身经历。

Stein 出生并成长于印度，高中时期曾在迪拜生活，之后前往加拿大攻读本科学位。对他而言，作为一个“新来者”融入一个国家的感受再熟悉不过。他对如何在新的社会体系、气候条件和生活方式中摸索前行并不陌生。适应新文化和新环境的过程激发了他对移民融入历程的兴趣。随着他继续学习经济学，这些更具个人色彩的体验依然对他有强烈的吸引力——于是他试图将二者结合起来。为了取得经济学博士学位，他将自己的论文重点放在移民研究相关文献上。

在撰写论文期间，Stein 自学了编程。后来在 Humber College 担任统计学家时，他就能将所学应用到实践中。编程让自动化成为可能——通过对数据进行整理和运算来简化他的工作。

通过将自己的工作流程用代码形式表达出来，Stein 能更容易识别问题，并以循序渐进的方式向他人解释自己的工作和思考过程。这为他打开了一种全新的视角，去审视问题并构建解决方案。他逐渐意识到这一技能组合所蕴含的巨大潜力，并将这份认识带到了加拿大移民与融合卓越研究主席（CERC）的岗位上。 

在 CERC 工作期间，Stein 被他在社交媒体各处看到的网络行动主义深深吸引，尤其是围绕印度农民抗议活动（由 2020 年 8 月推出的三项备受争议的法律引发）。他能看到这些抗议活动与自己研究工作之间的联系。这是一个重要时刻：正在实时发生的事件，能够揭示关于整体移民与侨民经历的重要信息。

随着周围相关讨论的激增，他开始思考，网络行动主义是如何影响生活在加拿大、英国、澳大利亚以及海湾国家的印度侨民群体的现实行动的。社交网络又是如何将移民与印度国内的对话连接在一起的？

是时候开始动手研究了。 

<div id="solution">
  ## 解决方案
</div>

为了更好地理解印度侨民与农民抗议活动之间的关系，Stein 知道他必须倾听线上对话——于是他把目光投向了 Twitter。

据 Stein 介绍，“这些本地事件之所以能够触达国际受众，不仅因为 Twitter 是一个全球现象，还因为人们——就是普通人——可以在网上彼此交谈，而且他们可以仅通过一个话题标签就相互联结起来。” 对他来说，有了 Twitter，“你可以参与发生在印度的农民抗议，而不一定是印度人，或者你是印度人但身在世界的另一端。”

在 Stein 看来，Twitter 是一个汇聚了抗议者、反抗议言论、亲政府实体，以及未经修饰的一线亲身经历的平台。而他也希望参与其中。

在吸收这些对话内容的同时，Stein 需要聚焦于几件事情：当有人在印度在线发帖时，这条推文是如何传播到世界其他地方的？信息是如何通过网络、话题标签等流动的？而侨民又是如何回应从印度发出的推文的？

在 Twitter API 的帮助下，Stein 得以获得更清晰的认识。Twitter API 推出了 Academic Research 产品路径，除了提供大量推文和作者信息以供进一步分析外，还允许访问历史数据。

对 Stein 来说，API 的强大之处在于它在较长时间范围内的可访问性，使他可以为这些对话构建一个时间维度——谁在转推什么，谁又在和谁对话。

掌握了所有这些信息后，他对自己的发现感到震惊：印度侨民对于印度局势的反应异常活跃。Stein 说：“这甚至不是什么滞后的活动，几乎是即时发生的。所以在一天之内，我就能看到有人在印度发帖后，来自世界其他地区的转推随之出现。”

数据非常清楚地表明：社交媒体让移民和散居群体得以与其祖国保持联结，并在重要的讨论中发挥积极作用。

<div id="impact">
  ## 影响
</div>

借助 Twitter 的开放 API，Stein 得以围绕一项具有时效性的事件开展研究，从而深入洞察更广泛的移民经历相关讨论。获取数据以及对这些数据进行筛选和排序的功能，对这个项目至关重要。 

更重要的是，Stein 认识到，Twitter 作为整体学术研究工具具有重要价值。对他来说，研究中的一大难题在于必须从全球各地收集数据。幸运的是，Twitter 在全球范围内的影响力提供了获取全球信息的途径，而无需在世界各地投入大量资金开展问卷调查和焦点小组。 

Stein 指出：“Twitter 让研究人员和学术界能够以一种全新的方式获取数据，用于自身的研究目的，从而开发新的研究方法，同时还能以一种具有成本效益的方式来实现。”他认为线上发生的对话之所以有用，是因为“它们几乎未加筛选，也不带偏见，是人们在没有研究者干预的情况下进行的自然对话。” 

Stein 的研究表明，Twitter 依然是一种连接全球的工具——而 Twitter 的 API 则可以帮助从这种连接中提炼出大规模洞察。
