<div id="situation">
  ## 情况
</div>

在新冠疫情爆发之后，针对亚裔美国人和太平洋岛裔（AAPI）的仇恨事件有所上升。虽然其中一些事件被新闻报道，但成千上万的人正向全国性举报中心 [Stop AAPI Hate](https://stopaapihate.org/) 提交报告，该中心通过研究、倡导和能力建设来回应和应对仇恨事件。在此期间，[The Asian American Foundation (TAAF)](https://www.taaf.org/) 成立。该组织成为团队背后的主要推动力量，这个团队决定利用 X，提供一个新的视角，展现这些事件如何在个人层面影响被针对的人群。

<div id="solution">
  ## 解决方案
</div>

由两名工程师组成的小团队将 X 作为他们的事件数据源。他们选择这个平台有两个原因：首先，它包含丰富多样的信息，例如新闻、人们的观点、想法、日常生活事件，以及社区中正在发生的事情。正因如此，X 能够提供来自不同人群的独特且贴近生活的样本。其次，X 也是唯一一个真正开放的 API 平台，使 TAAF 的开发者能够访问数据，并且提供强大的数据收集和分析工具。

利用 X API v2 的 search Tweets 和 Tweets lookup 端点，团队可以搜索帖子内容，识别出人们何时报告了仇恨事件（甚至还能识别他们使用了哪些话题标签）。这帮助团队设计了一个 1023 字符的搜索查询，将数十亿条帖子缩小到一个他们能够处理的规模。

接下来，他们要完成的任务是验证这些帖子是否确实与仇恨事件相关。团队开发了一款基于自然语言处理的工具，帮助从数千条帖子中筛选出与项目相关的内容。在应用经过训练的机器学习模型之后，这些帖子随后由人工进行复核，以进一步提高准确性。

在 2021 年，TAAF 还与 Stop AAPI Hate 联盟共同编写了 [Documenting Anti-AAPI Hate Codebook](https://stopaapihate.org/wp-content/uploads/2021/12/SAH-x-TAAF-Codebook-FINAL-2021-08-19.pdf)。这一资源包含以社区为基础的数据收集标准与实践草案，帮助团队对人们在 X 上分享的事件进行分类。

在此基础上，下一个挑战是以一种人们容易理解的方式呈现这些数据。TAAF 创建了一个数据可视化工具 [Decoding Hate](https://decodinghate.taaf.org/)，以交互的方式展示他们庞大的数据量。在一家数据可视化工作室的帮助下，他们将带标注的 X 数据转化为数千条帖子背后的深刻故事，从而揭示 AAPI 社群中正在发生事件的真相。

<div id="impact">
  ## 影响
</div>

Decoding Hate 项目帮助检测到了原本未被报告的数千起仇恨相关事件，并且直到今天仍在持续发挥这一作用。该项目已经成为一项长期运行的工具，用于提升人们对 AAPI 社群中个体亲身经历的认识和关注。

在下一阶段的工作中，TAAF 将与 Stop AAPI Hate 合作，在 X 上试点由真人为举报仇恨事件的个人提供一对一回应。在这一阶段，Stop AAPI Hate 将主动与许多发布帖子、分享自己遭遇仇恨经历的用户进行互动，并鼓励他们通过 [Stop AAPI Hate Reporting Center](https://stopaapihate.org/) 报告这些事件。向 Stop AAPI Hate 报告的人越多，该联盟及其合作伙伴就能越好地理解正在发生的仇恨事件的性质，并为最有效的政策解决方案进行倡导。 

除了揭示 AAPI 社群中正在发生的仇恨相关事件之外，该项目还凸显了 X 的 API 所具备的价值。这个案例向我们表明，通过将合适的数据与合适的工具结合起来，开发者可以利用 X 在公益领域进行创新。
