<div id="situation">
  ## 情况
</div>

在新冠疫情爆发之后，针对亚裔美国人和太平洋岛民群体（AAPI）的仇恨事件有所增加。虽然其中一些事件出现在新闻报道中，但仍有成千上万的人向全国举报中心 [Stop AAPI Hate](https://stopaapihate.org/) 提交报告，该中心通过研究、倡导和能力建设来回应和处理仇恨事件。在此期间，[The American Asian Foundation (TAAF)](https://www.taaf.org/) 成立。这个组织成为这一团队背后的推动力量，该团队决定利用 X 提供一个新的窗口，呈现这些事件如何在个人层面影响遭受针对的人们。

<div id="solution">
  ## 解决方案
</div>

由两名工程师组成的小团队将 X 作为事件数据的来源。他们选择这一平台有两个原因：首先，它包含丰富多样的信息，例如新闻、人们的想法、思考、日常生活事件以及他们所在社区正在发生的事情。正因如此，X 提供了一个独特且贴近生活的多元人群样本。X 也是唯一一个拥有真正开放 API、TAAF 的开发者可以在其中访问数据的平台，并且还提供了用于收集和分析这些数据的强大工具。 

通过使用 X API v2 的 search Tweets 和 Tweets lookup 端点，团队能够搜索帖子并识别出人们何时报告了仇恨事件（甚至包括他们会使用哪些标签）。这帮助团队设计出一个 1023 字符的搜索查询，将数十亿条帖子缩小到一个团队可以处理的数量。 

接下来要做的就是核实这些帖子是否确实与仇恨事件相关。团队开发了一款使用自然语言处理的工具，帮助从数千条帖子中筛选出与项目相关的内容。在应用他们训练好的机器学习模型之后，这些帖子再由人工进行核实，以进一步提升准确性。 

2021 年，TAAF 还与 Stop AAPI Hate 联盟共同撰写了《[Documenting Anti-AAPI Hate Codebook](https://stopaapihate.org/wp-content/uploads/2021/12/SAH-x-TAAF-Codebook-FINAL-2021-08-19.pdf)》。这一资源包含了面向社区的数据收集标准和实践草案，帮助团队对人们在 X 上分享的事件进行分类。 

之后，下一个挑战是以一种人们易于理解的方式呈现这些数据。TAAF 创建了一个数据可视化工具 [Decoding Hate](https://decodinghate.taaf.org/)，以交互形式展示其海量数据。在一家数据可视化工作室的帮助下，他们得以将带标注的 X 数据转化为成千上万则富有洞察力的故事，揭示 AAPI 社区中正在发生的真实情况。

<div id="impact">
  ## 影响
</div>

Decoding Hate 项目帮助发现了数以千计原本未被报告的仇恨相关事件，并且至今仍在持续发挥作用。这个项目已经成为一个长期使用的工具，用于提高人们对亚裔美国人和太平洋岛民（AAPI）群体中个体经历的认知。

在下一阶段的工作中，TAAF 将与 Stop AAPI Hate 合作，在 X 上试点为举报仇恨事件的个人提供一对一的人工响应。在此阶段，Stop AAPI Hate 将主动与许多发布帖子、讲述自己遭遇的仇恨经历的人互动，并鼓励他们通过 [Stop AAPI Hate Reporting Center](https://stopaapihate.org/) 报告这些事件。向 Stop AAPI Hate 报告的人越多，该联盟及其合作伙伴就能越深入地理解正在发生的仇恨事件的性质，并为最有效的政策解决方案进行倡导。 

除了揭示 AAPI 社群中正在发生的仇恨相关事件之外，该项目也凸显了 X 的 API 的价值。这个案例向我们展示，通过利用合适的数据和合适的工具，开发者可以使用 X 为公益进行创新。
