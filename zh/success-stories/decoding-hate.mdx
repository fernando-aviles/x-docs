<div id="situation">
  ## 情况
</div>

在新冠疫情爆发后，针对亚裔美国人和太平洋岛裔（AAPI）的仇恨事件不断增加。虽然其中一些事件被新闻报道，但成千上万的人则向全国举报中心 [Stop AAPI Hate](https://stopaapihate.org/) 提交报告，该中心通过研究、倡导和能力建设来回应和处理仇恨事件。就在这段时间，[亚裔美国人基金会（The Asian American Foundation，TAAF）](https://www.taaf.org/) 成立。该组织成为一个团队背后的推动力量，这个团队决定利用 X 提供一个全新的窗口，展现这些事件在个人层面如何影响被针对的人群。

<div id="solution">
  ## 解决方案
</div>

由两名工程师组成的小团队选择将 X 作为他们的事件数据来源。他们选择这个平台有两个原因：首先，它包含丰富而多样的信息，例如新闻、人们的想法、思考、日常生活事件以及发生在他们社区中的事情。正因如此，X 提供了来自各类人群的独特且贴近生活的样本。其次，X 也是唯一一个真正提供开放 API、使 TAAF 的开发者能够访问数据，并拥有深度工具来收集和分析这些数据的平台。

使用 X API v2 中的 search Tweets 和 Tweets lookup 端点，团队能够搜索帖子状态并识别出人们何时报告了仇恨事件（甚至还能识别他们会使用哪些标签（hashtag））。这帮助团队设计出一个长度为 1023 个字符的搜索查询，把数十亿条帖子缩小到一个团队可以处理的规模。

接下来的一项任务是验证这些帖子是否确实与仇恨事件相关。团队开发了一款使用自然语言处理的工具，帮助从数以千计的帖子中筛选出与该项目相关的内容。在应用他们训练好的机器学习模型之后，帖子还会再由人工审核，以进一步提高准确性。

在 2021 年，TAAF 还与 Stop AAPI Hate 联盟合作共同撰写了[《Documenting Anti-AAPI Hate Codebook》](https://stopaapihate.org/wp-content/uploads/2021/12/SAH-x-TAAF-Codebook-FINAL-2021-08-19.pdf)。这一资源包含了面向社区的数据收集草案标准和实践方法，帮助团队对人们在 X 上分享的事件进行分类。

在此基础上，下一个挑战是如何以一种人们易于理解的方式展示这些数据。TAAF 创建了一个数据可视化工具 [Decoding Hate](https://decodinghate.taaf.org/)，以交互方式展示他们庞大的数据量。在一家数据可视化工作室的帮助下，他们得以将带注释的 X 数据转化为数千条帖子背后具有洞察力的故事，从而揭示 AAPI 社群内部正在发生情况的真相。

<div id="impact">
  ## 影响
</div>

Decoding Hate 项目帮助检测到了数以千计原本未被上报的仇恨相关事件，并且直到今天仍在持续发挥这一作用。该项目已成为一项持续提升公众对 AAPI 社群中个体经历认知的重要工具。

在下一阶段工作中，TAAF 将与 Stop AAPI Hate 合作，在 X 上试点面向仇恨事件举报者的一对一人工回应机制。在此阶段，Stop AAPI Hate 将主动与许多发布帖子、讲述自身遭遇仇恨经历的人互动，并鼓励他们通过 [Stop AAPI Hate Reporting Center](https://stopaapihate.org/) 报告相关事件。向 Stop AAPI Hate 举报的人越多，该联盟及其合作伙伴就能越好地理解这些仇恨事件的性质，并为最有效的政策解决方案进行倡导。 

除了揭示在 AAPI 社群中发生的仇恨相关事件之外，该项目也凸显了 X 的 API 的价值。本案例向我们展示，通过将合适的数据与合适的工具相结合，开发者可以利用 X 为公益事业进行创新。
