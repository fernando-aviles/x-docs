<Note>
**要点速览（tl;dr）**

顺势走向成功：当 Red Cloud 金融服务公司受托帮助一家矿业公司推广其全新的绿色技术时，他们借助基于 X 分析打造的 Audiense 定向工具来“挖掘”数据并触达全新受众。
</Note>

<div id="situation">
  ## 情况
</div>

Red Cloud Financial Services 的任务是帮助其客户（一家上市矿业公司）在全新的受众群体中提升其新开发、正在申请专利的技术的知名度。 

该公司必须找到一种方式，使这款新产品取得成效，从而拓展到新的市场区域，并有效开展一场能够触达这些新客户的活动。 

这一需求带来了两大核心挑战： 

1. **触达新的受众**

    客户的新技术不再专注其现有的矿业客户，而是吸引了更广泛、关注绿色创新和社会责任的群体。对于 Red Cloud 来说，这是前所未有的领域，与其以往执行的任何活动都截然不同。

1. **提供可量化的投资回报率（ROI）**
    
    该客户并不习惯投放付费活动。要让 Red Cloud 清晰阐明以品牌认知为目标的活动的投资回报率（ROI），并在其缺乏第一手经验的新受众中交付成果，这是一项艰巨的任务。 
    
    Red Cloud 求助于 Audiense，以便在研究潜在新客户的同时触达现有客户。Audiense 的 X 营销产品专注于利用其强大的受众定向工具，开展高影响力的 X 活动。

<div id="solution">
  ## 解决方案
</div>

Red Cloud 首先着手设定预期。借助 Audiense 提供的洞察来创建活动效果预测，Red Cloud 得以就活动的最终目标及相关 KPI 与客户达成一致预期。 

在 Audiense 的帮助下，Red Cloud 将研究重点放在 X 上，用于挖掘公司新闻和相关股票信息。Audiense 的平台让 Red Cloud 能够轻松发现活动与兴趣提升之间的潜在关联，这些兴趣提升体现在视频观看量和网站流量增长上。

三层次的方法：

1. 构建全新受众。

    在客户的指导下，Red Cloud Financial 确定了两个主要受众作为活动的重点：第一类细分包括采矿和投资，第二类则涵盖清洁科技、电动汽车、ESG 和责任投资。X 的数据进一步帮助 Red Cloud 将这些受众与后续活动更好地匹配和对齐。

1. 细分新受众。 

    尽管新受众覆盖了广泛的行业，但它们之间仍然存在大量共性。Audiense 帮助 Red Cloud Financial 深入挖掘这些新细分群体，以识别关键影响者、内容消费习惯等信息。这些洞察也帮助他们确定应关注哪些账号，以期对方回关，从而扩大 Red Cloud 与其客户的受众群体。

1. 确定哪个最有价值。 
    
    确定哪个最有价值。使用 Audiense 的 [Targeting Pack 功能](https://help.audiense.com/knowledge/what-is-a-targeting-pack)，Red Cloud 创建了高度定向的付费 X 广告活动，同时利用为 X 细分受众积累的数据来开展自然投放活动。通过利用源自 Targeting Pack 功能的洞察，Audiense 和 Red Cloud 为这两类受众分别制作了两支独特视频。他们能够据此判断哪支视频在活动中始终表现最佳，从而在定向上始终保持精准。

<div id="impact">
  ## 影响
</div>

Audiense 的平台以及他们在 X 上的研究，帮助 Red Cloud 找到合适的目标受众，对其进行细分，并加以利用来扩大粉丝规模，同时为其在自然内容和付费内容方面的整体社交媒体策略提供支撑。

Red Cloud Financial 的表现超出了客户的预期。事实上，由于广告活动效果十分出色，客户决定继续推进并加大投入，启动新的活动。 

- 综合各个广告活动，共获得 350 万+ 次曝光和 280 万+ 次总观看量
- 与该客户正在申请专利的新技术相关的讨论量有所上升
- 他们注意到网站引荐流量有所提升，其中包括来自关于其新技术的推广文章和新闻稿的 7,000 名新访客

这是一个典型案例，展示了在 X 上利用受众分析与定向如何帮助你触达新受众、优化营销活动并带来实实在在的成果。这也可能成为帮助打造客户品牌并推动其业务增长的绝佳机会。
