<Note>
**要点如下**

引领成功趋势：当 Red Cloud Financial Services 受托帮助一家矿业公司推广其全新的绿色技术时，它借助基于 X 分析数据构建的 Audiense 定向工具来挖掘数据并触达新的受众。
</Note>

<div id="situation">
  ## 情况
</div>

Red Cloud Financial Services 的任务是帮助其客户——一家上市矿业公司——在全新的受众中提升其新开发的、正在申请专利的技术的知名度。 

为了拓展到新的市场领域，并有效地开展一场能够触达这些新客户的营销活动，该公司必须找到一种方式，为这一新产品带来实际成效。 

这一需求带来了两个关键挑战： 

1. **触达全新受众**

    与其继续专注于现有的矿业客户，这位客户的新技术更能吸引对绿色创新和社会责任感兴趣的更广泛人群。对于 Red Cloud 来说，这是前所未有的领域，与其之前所做的任何活动都截然不同。

1. **提供明确的投资回报率（ROI）**
    
    该客户并不习惯开展付费营销活动。要让 Red Cloud 清晰说明以品牌认知为目标的活动的投资回报率，并在其几乎没有直接经验的受众中产生效果，是一项艰巨的任务。 
    
    Red Cloud 求助于 Audiense，希望在触达现有客户的同时研究潜在新客户。Audiense 的 X 营销产品专注于利用其强大的受众定向工具，投放具有显著影响力的 X 活动。

<div id="solution">
  ## 解决方案
</div>

Red Cloud 首先进行了预期设定。借助 Audiense 提供的洞察创建广告活动效果预测，Red Cloud 得以就广告活动的最终目标及相关 KPI 与客户对齐预期。 

在 Audiense 的帮助下，Red Cloud 将研究重点放在 X 上，用于挖掘公司新闻及相关股票信息。Audiense 的平台使其能够轻松发现广告活动与兴趣提升之间的潜在相关性，这些兴趣提升体现在视频观看量的增加以及网站流量的增长上。

三层次方法：

1. 构建全新的受众群体。

    在客户的指导下，Red Cloud Financial 确定了两个主要受众群体来聚焦广告活动：第一类细分包括采矿与投资，第二类则涵盖清洁技术、电动车、ESG 和责任投资。X 的数据进一步帮助 Red Cloud 将这些受众与未来的后续活动进行匹配。

1. 细分新的受众群体。 

    尽管这些新受众覆盖了广泛的行业，但它们之间存在大量共通点。Audiense 帮助 Red Cloud Financial 深入挖掘这些新细分受众，以识别其中的影响者、内容消费习惯等信息。这些洞察也帮助他们确定应关注哪些账号，以期对方回粉，从而扩大 Red Cloud 和客户的受众群体。

1. 确定哪些受众价值最高。 
    
    确定哪些受众价值最高。借助 Audiense 的 [Targeting Pack 功能](https://help.audiense.com/knowledge/what-is-a-targeting-pack)，Red Cloud 创建了精准定向的 X 付费广告活动，同时使用为 X 细分受众累积的数据来运营自然投放活动。利用从 Targeting Pack 功能中获得的洞察，Audiense 和 Red Cloud 为这两个受众分别制作了两支独特的视频。他们能够判断哪支视频在广告活动中始终表现最佳，并据此保持精准投放方向。

<div id="impact">
  ## 影响
</div>

Audiense 的平台以及他们在 X 上的研究，帮助 Red Cloud 找到并细分了合适的受众，并利用这些受众来提升粉丝数量，同时为其有机与付费内容的整体社交媒体策略提供参考。

Red Cloud Financial 超出了其客户的预期。事实上，由于广告活动取得了非常出色的效果，客户决定继续推进并加大另一项活动的投入。 

- 这些整体广告活动共获得了超过 350 万次展示和 280 万次总观看量
- 与客户正在申请专利的新技术相关的讨论量有所提升 
- 他们注意到网站引荐流量明显提升，其中包括来自关于其新技术的推广文章和新闻稿的 7,000 名新访客

这是一个典型案例，展示了如何通过 X 上的受众分析和定向，帮助你触达新受众、优化营销活动并带来切实成效。这也可能是一个帮助塑造客户品牌并提升其业务的绝佳机会。
