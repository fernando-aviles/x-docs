<Note>
**简而言之**

成功势头逐渐显现：当 Red Cloud 金融服务公司受托帮助一家矿业公司推广其全新的绿色技术时，他们借助基于 X 分析构建的 Audiense 定向工具，深入挖掘数据并触达全新受众群体。
</Note>

<div id="situation">
  ## 情况
</div>

Red Cloud Financial Services 受托帮助其客户——一家上市矿业公司——在全新的受众群体中提升其新开发且正在申请专利的技术的知名度。 

该公司必须找到一种方式，为这款新产品带来实际效果，从而进入新的地区市场，并高效开展能够触达这些新客户的营销活动。 

这一需求带来了两个关键挑战： 

1. **触达全新受众**

    相较于继续聚焦现有的矿业客户群，这项新技术更能吸引对绿色创新和社会责任感兴趣的更广泛受众。对于 Red Cloud 来说，这是前所未涉足的领域，与其此前开展的任何活动都截然不同。

1. **提供可量化的投资回报率（ROI）**
    
    该客户并不习惯投放付费营销活动。对于以提升认知为主的活动，Red Cloud 既要清晰说明其投资回报率，又要在其几乎没有一手经验的受众群体中取得成效，这是一项艰巨的任务。 
    
    Red Cloud 因此求助于 Audiense，在研究潜在新客户的同时触达现有客户。Audiense 的 X 营销产品专注于借助其强大的受众定向工具，投放具有影响力的 X 营销活动。

<div id="solution">
  ## 解决方案
</div>

Red Cloud 首先从设定预期入手。借助 Audiense 提供的洞察来创建活动效果预测，Red Cloud 得以就活动的最终目标和相关 KPI 与客户对齐预期。 

在 Audiense 的帮助下，Red Cloud 将研究重点放在 X 上，用于挖掘公司新闻和相关股票信息。Audiense 的平台让他们更容易找到活动与兴趣提升（体现在视频观看次数增加和网站流量上升）之间的潜在关联。

三层策略：

1. 构建全新的受众群体。

    在客户的指导下，Red Cloud Financial 确定了两个主要受众群体作为活动的重点：第一类细分群体包括采矿和投资，第二类则包括清洁科技、电动汽车、ESG 和负责任投资。来自 X 的数据进一步帮助 Red Cloud 将这些受众与未来的活动规划相匹配。

1. 细分新受众。 

    尽管这些新受众涵盖的行业范围广泛，但其间仍然存在许多共性。Audiense 帮助 Red Cloud Financial 深入挖掘这些新细分群体，以识别关键影响者、内容消费习惯等信息。这些洞察也帮助他们确定应关注哪些账号，以期对方回关，从而扩大 Red Cloud 和其客户的受众群体。

1. 确定哪个最有价值。 
    
    确定哪个最有价值。借助 Audiense 的 [Targeting Pack 功能](https://help.audiense.com/knowledge/what-is-a-targeting-pack)，Red Cloud 创建了高度精准定向的 X 付费广告活动，同时将累积的 X 细分数据用于自然活动。利用从 Targeting Pack 功能中获得的洞察，Audiense 和 Red Cloud 针对这两个受众群体分别制作了两个独特的视频。他们由此能够确定哪个视频在活动中始终表现最佳，并在定向策略上保持正确方向。

<div id="impact">
  ## 影响
</div>

Audiense 的平台以及其基于 X 的研究，帮助 Red Cloud 找到合适的受众，对其进行细分，并有效利用这些受众来提升粉丝规模，同时为其在自然内容和付费内容上的整体社交媒体策略提供洞察。

Red Cloud Financial 超出了其客户的预期。事实上，活动的效果非常出色，客户决定继续推进并加大下一轮活动的投入。 

- 几轮活动合计获得 350 万次以上曝光和 280 万次总观看量
- 与客户新近申请专利的技术相关的讨论量有所提升
- 他们注意到网站引荐流量增加，其中包括来自关于其新技术的推广文章和新闻稿的 7,000 名新访客

这是一个有力例证，展示了在 X 上利用受众分析和定向投放，如何帮助你触达全新受众、优化营销活动并交付切实成果。这可以成为帮助塑造客户品牌、推动其业务增长的绝佳机会。
