<Note>
**以下是简要概述**

以下是开发者兼创作者 Aaron Ng 如何使用 X 的 API 构建 Flocknet——一个面向你在 X 上人脉网络的搜索引擎。人们正在使用 Flocknet 来拓展人脉、招募人才以及获取投资线索。Flocknet 最初是为他个人使用而构建，如今正在帮助人们在 X 上管理数百万联系人。
</Note>

<div id="challenge">
  ## 挑战
</div>

当 Aaron Ng 在纽约参加一场设计大会时，他希望能与业内其他人建立联系并见面。但这时他才意识到，即使是在 X 上与自己的设计师朋友交流，也比他想象的还要难。他的很多人脉圈都在 X 上，尤其是他在行业里的朋友。难道没有办法让他知道哪些朋友也会来这座城市吗？如果不知道谁会在附近，他又该如何与业内人脉叙旧、保持联系？

Aaron 立刻把这一挑战视作一个机会。也正是凭借他的创业精神，Flocknet 应运而生。 

<div id="solution">
  ## 解决方案
</div>

仅用一个周末时间，Aaron 就打造出了一款产品，用于在他的 X 网络中搜索、排序，以及跟进人脉、朋友和其他专业人士的动态，即使看不到他们的推文也没有问题。他选择在这个项目中使用 X 的 API，“因为知道有可以提问的人，而且知道 X 团队很在乎，这让整个体验好得多。” 他补充说，“促使我持续构建产品的社区有很大一部分就在 X 上——这就是为什么它对我来说如此重要，也为什么我想做一些工具来提升我对它的使用体验。”

凭借他自己的创造力、驱动力和经验，Flocknet 应运而生——一款用于在你的 X 网络中寻找他人的搜索引擎和联系人管理工具。借助 X 的关注相关端点和 Python，Flocknet 允许用户按职业、工作单位、地理位置以及众多其他属性来搜索自己的关注者。

虽然最初只是为他个人使用而开发的，但 Flocknet 很快引发了广泛关注，让他意识到应该将其分享出来。于是，他迅速转而投入精力，对 Flocknet 进行扩展，逐步打造成今天的样子。

<div id="impact">
  ## 影响
</div>

在短短几个月内，Flocknet 就已经代表用户管理了数百万个联系人。技术从业者发现它尤其有用，用它来完成从招聘到投资以及两者之间的各种用途。事实上，就连 Aaron 本人都通过 Flocknet 招聘过员工！

但 Aaron 还远未停下脚步。通过专注于不断涌入的功能需求，Aaron 持续思考如何拓展这个产品。

最终，Aaron 找到了一种方法，把 X 打造成一个元平台，为那些社区主要存在于 X 上的所有人提升体验。他说：“我就是做了很多东西，我喜欢做自己觉得有用、别人也觉得有用的东西。”而他确实也做到了这一点。
