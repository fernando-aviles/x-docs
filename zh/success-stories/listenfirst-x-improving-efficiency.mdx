<div id="situation">
  ## 情况
</div>

长期以来，数字营销人员一直缺乏对其数据的统一视图。自然数据可能在一个系统中，付费数据在另一个系统中，而对话内容则来自不同的渠道。但当客户和相关方提出类似“我昨天获得了多少展示次数？”接着又问“自然与付费的占比是多少？”这样的问题时，就比以往任何时候都更需要一种精简高效的方式来汇总和解读这些数据。

为了解决这些问题，ListenFirst——一个基于 X Developer Platform 构建、并已深度合作超过 10 年的社交分析平台——需要创建一款工具，从单一可信的数据源中收集自然和付费的 X 数据。过去，这些自然和付费数据分散在不同的平台、API 和端点中，彼此割裂；而且从来不是为了被汇总、求和和/或混合到一起而设计的。

<div id="solution">
  ## 解决方案
</div>

在探索更高效的方法为客户提供洞察的过程中，ListenFirst 采用了 X 的 v2 端点，将用户在 X 上讨论的内容更顺畅地转化并接入他们的平台。ListenFirst 团队带着一个明确的目标开始行动：打造更纯净的数据。

> *“对我们来说，使用 v2 是为了优化集成。如果我们在自己的网站上需要拼接的部分更少，就能让运营更简单，也让我们可以将产品扩展到更多品牌、更多内容，并提供更优质的洞察。”*
> 
> - Jonathan Farb，ListenFirst 首席产品官。

促使团队优先采用 X 的 v2 API，尤其是 Tweets lookup 端点的，是其在互动量和曝光量数据上的高准确性。通过使用这一端点，ListenFirst 能够生成更可靠的指标，并与其客户在其他 X 原生分析工具中看到的结果保持一致。

<div id="impact">
  ## 影响
</div>

尽管仍处于早期阶段，引入 v2 已经对 ListenFirst 的效率产生了显著影响。过去，ListenFirst 不得不从不同的 API 集合中拼凑数据，而这些数据与原生分析中看到的数字并不一致。如今，他们对 v2 的使用使 ListenFirst 的数字与 X 原生分析中的数字更加接近，实现了更高的对齐度，从而提升了准确性和客户信任。现在，ListenFirst 可以产出有理有据且更为精细的洞察，帮助品牌完善其在 X 上的营销策略。ListenFirst 认为，进一步采用 v2 将通过提升准确性和透明度，增强客户对相关指标的信心。
