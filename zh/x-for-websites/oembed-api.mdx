你可以使用 oEmbed API 以编程方式获取嵌入内容，例如 [推文](https://developer.x.com/en/docs/twitter-for-websites/embedded-tweets/overview) 和 [时间线](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview)。 

oEmbed API 的响应会返回一个 HTML 片段，当页面中[包含 X 的 widget JavaScript](https://developer.x.com/web/javascript/loading) 时，该片段会被自动识别。

请注意，该 API 更适合用于批量执行任务；在嵌入内容时，我们建议使用功能强大的 [publish.x.com](https://publish.x.com/#) 工具。

<Tabs>
  <Tab title="嵌入时间线">
    当页面中[包含 X 的小部件 JavaScript](https://developer.x.com/web/javascript/loading) 时，返回的 HTML 代码片段会自动被识别为[嵌入式时间线](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview)。

    oEmbed 端点允许通过在 HTML 标记中设置相应属性来自定义嵌入式时间线的最终外观，这些属性会由与 HTML 响应一起打包的 X JavaScript 默认解析。随着 X 添加新功能或调整其时间线呈现方式，返回标记的格式可能会随时间发生变化。

    对于通过时间线 URL 指定的 X 时间线，将以兼容 [oEmbed](https://oembed.com/) 的 JSON 格式返回。支持用户时间线和列表时间线。时间线标记应缓存在你的服务器上，缓存时间最长不应超过由 `cache_age` 属性指定的建议缓存生命周期。

    ## 示例请求

    ```bash
    curl --request GET --url 'https://publish.x.com/oembed?url=https%3A%2F%2Ftwitter.com%2FInterior%2Fstatus%2F507185938620219395'
    twurl -H publish.x.com "/oembed?url=https://x.com/Interior/status/463440424141459456"
    ```

    ```json
    {
      "url": "https://x.com/TwitterDev",
      "title": "",
      "html": "<a class=\"twitter-timeline\" href=\"https://x.com/TwitterDev\">Tweets by TwitterDev</a>\n<script async src=\"//platform.x.com/widgets.js\" charset=\"utf-8\"></script>",

      "cache_age": "3153600000",
      "provider_name": "Twitter",
      "provider_url": "https://x.com",
      "version": "1.0"
    }
    ```

  <Tab title="嵌入推文">
    当[页面中包含 X 的小部件 JavaScript](https://developer.x.com/web/javascript/loading) 时,返回的 HTML 代码段将自动识别为[嵌入式推文](https://developer.x.com/web/embedded-tweets)。

    oEmbed 端点允许通过在 HTML 标记中设置相应属性来自定义嵌入推文的最终外观,这些属性默认由与 HTML 响应捆绑的 X JavaScript 解析。随着 X 添加新功能或调整推文表示方式,返回标记的格式可能会随时间发生变化。

    推文回退标记应缓存在您的服务器上,缓存时长不超过 `cache_age` 属性所指定的建议缓存生命周期。

    ## 参数

    | 名称                                                                                                                               | 默认值     | 描述                                                                                                                                                                                                                                        |
    | :------------------------------------------------------------------------------------------------------------------------------- | :------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | `url`必需  <br />字符串                                                                                                               |         | 要嵌入的推文的 URL                                                                                                                                                                                                                               |
    | `maxwidth`  <br />Int `[220..550]`                                                                                               | `325`   | 以整像素表示的已渲染推文的最大宽度。如果提供的数值低于或高于允许范围，将分别被调整为所支持的最小或最大宽度；调整后的宽度值会体现在返回的 `width` 属性中。请注意，X 不支持 oEmbed 的 `maxheight` 参数。推文本质上是文本，因此其高度不可预测，无法像图像或视频那样按比例缩放。同样地，oEmbed 响应不会提供 `height` 的数值。需要推文具有统一高度的实现应参考下方的 `hide_thread` 和 `hide_media` 参数。 |
    | `hide_media`  <br />Boolean、String 或 Int                                                                                         | `false` | 当设置为 `true`、`"t"` 或 `1` 时，推文中的链接不会展开为图片、视频或链接预览。                                                                                                                                                                                          |
    | `hide_thread`  <br />布尔值、字符串或整数                                                                                                  | `false` | 当设置为 `true`、`"t"` 或 `1` 时，如果所请求的推文是对另一条推文的回复，将不会显示该对话线程中上一条推文的折叠版本。                                                                                                                                                                       |
    | `omit_script`  <br />Boolean、String 或 Int                                                                                        | `false` | 当设置为 `true`、`"t"` 或 `1` 时，负责加载 `widgets.js` 的 `<script>` 标签将不会被返回。你的网页应自行引用 `widgets.js`，以便在所有 X 组件中使用，包括[嵌入式推文](https://developer.x.com/web/embedded-tweets)。                                                                            |
    | `align`  <br />枚举 `{left,right,center,none}`                                                                                     | `none`  | 指定嵌入的推文在页面中相对于父元素是左浮动、右浮动还是居中对齐。                                                                                                                                                                                                          |
    | `lang`  <br />枚举类型（[语言](https://developer.x.com/en/docs/twitter-for-websites/twitter-for-websites-supported-languages/overview)） | `en`    | 请求会返回使用指定[嵌入式推文支持的 X 语言](https://developer.x.com/web/overview/languages)的 HTML 和渲染后的推文。                                                                                                                                                   |
    | `theme`  <br />枚举值 `{light, dark}`                                                                                               | `light` | 当设置为 `dark` 时，推文将以浅色文字显示在深色背景上。                                                                                                                                                                                                           |
    | `dnt`  <br />Boolean                                                                                                             | `false` | 当设置为 `true` 时，该推文及其在你的网站中的嵌入页面不会被用于[个性化推荐](https://support.x.com/articles/20169421)、[个性化广告](https://support.x.com/articles/20170405)等用途。                                                                                                  |
