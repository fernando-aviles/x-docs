你可以使用 oEmbed API 以编程方式获取嵌入内容，例如 [推文](https://developer.x.com/en/docs/twitter-for-websites/embedded-tweets/overview) 和 [时间线](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview)。 

来自 oEmbed API 的响应将返回一个 HTML 代码片段，当[在页面中引入 X 的 widget JavaScript 时](https://developer.x.com/web/javascript/loading)，该代码片段会被自动识别。

请注意，该 API 建议用于批量处理任务，我们建议使用功能强大的 [publish.x.com](https://publish.x.com/#) 工具来嵌入内容。

<Tabs>
  <Tab title="嵌入式时间线">
    返回的 HTML 代码片段在[页面中包含 X 的小部件 JavaScript 时](https://developer.x.com/web/javascript/loading)，会被自动识别为[嵌入式时间线](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview)。

    oEmbed 端点允许你通过在 HTML 标记中设置相应属性来自定义嵌入式时间线的最终外观，这些属性会由与 HTML 响应一起打包的 X JavaScript 默认进行解析。随着 X 添加新功能或调整其时间线呈现方式，返回标记的格式可能会随时间发生变化。

    对于由时间线 URL 指定的 X 时间线，将以 [oEmbed](https://oembed.com/) 兼容的 JSON 格式返回。支持用户时间线和列表时间线。时间线标记建议在你的服务器上缓存，最长不超过 `cache_age` 属性指定的缓存生命周期。

    ## 示例请求

    ```bash
    curl --request GET --url 'https://publish.x.com/oembed?url=https%3A%2F%2Ftwitter.com%2FInterior%2Fstatus%2F507185938620219395'
    twurl -H publish.x.com "/oembed?url=https://x.com/Interior/status/463440424141459456"
    ```

    ## 示例响应

    ```json

    {
      "url": "https://x.com/TwitterDev",
      "title": "",
      "html": "<a class=\"twitter-timeline\" href=\"https://x.com/TwitterDev\">TwitterDev 的推文</a>\n<script async src=\"//platform.x.com/widgets.js\" charset=\"utf-8\"></script>",

      "cache_age": "3153600000",
      "provider_name": "Twitter",
      "provider_url": "https://x.com",
      "version": "1.0"
    }
    ```

  <Tab title="嵌入推文">
    当[页面中包含 X 的小部件 JavaScript](https://developer.x.com/web/javascript/loading) 时,返回的 HTML 代码段将自动识别为[嵌入式推文](https://developer.x.com/web/embedded-tweets)。

    oEmbed 端点允许通过在 HTML 标记中设置相应属性来自定义嵌入推文的最终外观,这些属性默认由与 HTML 响应捆绑的 X JavaScript 解释。随着 X 添加新功能或调整推文表示方式,返回标记的格式可能会随时间发生变化。

    推文回退标记应缓存在您的服务器上,缓存时长不超过 `cache_age` 属性所指定的建议缓存生命周期。

    ## 参数

    | 名称                                                                                                                               | 默认值     | 说明                                                                                                                                                                                                                                   |
    | :------------------------------------------------------------------------------------------------------------------------------- | :------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | `url`必需  <br />字符串                                                                                                               |         | 将要嵌入的推文的 URL                                                                                                                                                                                                                         |
    | `maxwidth`  <br />整数 `[220..550]`                                                                                                | `325`   | 以整像素数表示的渲染推文的最大宽度。如果提供的值低于或高于允许范围，将被重置为支持的最小或最大宽度并返回；重置后的宽度值会体现在返回的 `width` 属性中。请注意，X 不支持 oEmbed 的 `maxheight` 参数。推文本质上是文本，因此其高度不可预测，无法像图像或视频那样缩放。相应地，oEmbed 响应不会提供 `height` 的值。需要推文具有统一高度的实现应参考下方的 `hide_thread` 和 `hide_media` 参数。 |
    | `hide_media`  <br />Boolean、字符串或 Int                                                                                             | `false` | 将其设置为 `true`、`"t"` 或 `1` 时，推文中的链接不会展开显示为照片、视频或链接预览。                                                                                                                                                                                  |
    | `hide_thread`  <br />布尔值、字符串或整数                                                                                                  | `false` | 当设置为 `true`、`"t"` 或 `1` 时，如果所请求的推文是对另一条推文的回复，则不会显示该对话串中上一条推文的折叠版本。                                                                                                                                                                   |
    | `omit_script`  <br />布尔值、字符串或整数                                                                                                  | `false` | 当设置为 `true`、`"t"` 或 `1` 时，用于加载 `widgets.js` 的 `<script>` 将不会被返回。你的网页应自行包含对 `widgets.js` 的引用，以便在所有 X 小部件（包括[嵌入式推文](https://developer.x.com/web/embedded-tweets)）中使用。                                                                  |
    | `align`  <br />枚举值 `{left,right,center,none}`                                                                                    | `none`  | 指定嵌入推文相对于父元素在页面中的对齐方式：左浮动、右浮动或居中。                                                                                                                                                                                                    |
    | `lang`  <br />枚举类型([语言](https://developer.x.com/en/docs/twitter-for-websites/twitter-for-websites-supported-languages/overview)) | `en`    | 请求将返回使用指定的、[X 支持的嵌入式推文语言](https://developer.x.com/web/overview/languages)的 HTML 和渲染后的推文。                                                                                                                                             |
    | `theme`  <br />枚举类型 `{light, dark}`                                                                                              | `light` | 当设置为 `dark` 时，推文会以浅色文字显示在深色背景上。                                                                                                                                                                                                      |
    | `dnt`  <br />Boolean                                                                                                             | `false` | 将其设置为 `true` 时，你的网站上的该推文及其嵌入的页面不会被用于包括[个性化推荐](https://support.x.com/articles/20169421)和[个性化广告](https://support.x.com/articles/20170405)在内的用途。                                                                                        |
