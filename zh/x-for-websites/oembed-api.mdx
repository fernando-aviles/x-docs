你可以使用 oEmbed API 以编程方式获取嵌入内容，例如 [推文](https://developer.x.com/en/docs/twitter-for-websites/embedded-tweets/overview) 和 [时间线](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview)。 

oEmbed API 的响应是一段 HTML 代码片段，当[在页面中包含 X 的 widget JavaScript](https://developer.x.com/web/javascript/loading) 时，该片段会被自动识别。

请注意，此 API 推荐用于批量执行任务，而在嵌入内容时，我们建议你使用功能强大的 [publish.x.com](https://publish.x.com/#) 工具。

  <Tab title="嵌入时间线">
    当在[页面中包含 X 的小部件 JavaScript 时](https://developer.x.com/web/javascript/loading)，返回的 HTML 代码片段会被自动识别为[嵌入式时间线](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview)。

    oEmbed 端点允许通过在 HTML 标记中设置相应的属性，来自定义嵌入式时间线的最终外观，这些属性将由与 HTML 响应一起打包的 X JavaScript 默认进行解析。随着 X 添加新功能或调整其时间线呈现方式，返回的标记格式可能会随时间变化。

    对于通过时间线 URL 指定的 X 时间线，本端点以[oEmbed](https://oembed.com/) 兼容的 JSON 格式返回。支持用户时间线和列表时间线。时间线标记应在你的服务器上缓存，最长不超过 `cache_age` 属性指定的建议缓存有效期。

    ## 示例请求

    ```bash
    curl --request GET --url 'https://publish.x.com/oembed?url=https%3A%2F%2Ftwitter.com%2FInterior%2Fstatus%2F507185938620219395'
    twurl -H publish.x.com "/oembed?url=https://x.com/Interior/status/463440424141459456"
    ```

  <Tab title="嵌入推文">
    当页面中[包含 X 的小部件 JavaScript](https://developer.x.com/web/javascript/loading) 时,返回的 HTML 代码段将自动识别为[嵌入式推文](https://developer.x.com/web/embedded-tweets)。

    oEmbed 端点允许通过在 HTML 标记中设置相应属性来自定义嵌入推文的最终外观,这些属性将由默认与 HTML 响应一起打包的 X JavaScript 进行解释。随着 X 添加新功能或调整其推文呈现方式,返回标记的格式可能会随时间发生变化。

    推文回退标记应缓存在您的服务器上,缓存时长不超过 `cache_age` 属性所指定的建议缓存生命周期。

    ## 参数

    | 名称                                                                                                                                         | 默认值     | 说明                                                                                                                                                                                                                                            |
    | :----------------------------------------------------------------------------------------------------------------------------------------- | :------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | `url` 必需  <br />字符串                                                                                                                        |         | 要嵌入的推文 URL                                                                                                                                                                                                                                    |
    | `maxwidth`  <br />Int `[220..550]`                                                                                                         | `325`   | 渲染后推文的最大宽度（单位为整像素）。当提供的值低于或高于允许范围时，将分别被调整为支持的最小或最大宽度；重置后的宽度值会反映在返回的 `width` 属性中。请注意，X 不支持 oEmbed 的 `maxheight` 参数。推文本质上是文本内容，因此其高度不可预期，无法像图像或视频那样按比例缩放。相应地，oEmbed 响应中不会提供 `height` 的数值。需要为推文保持一致高度的实现，应参考下文的 `hide_thread` 和 `hide_media` 参数。 |
    | `hide_media`  <br />布尔、字符串或整数                                                                                                              | `false` | 当设置为 `true`、`"t"` 或 `1` 时，推文中的链接不会被展开为照片、视频或链接预览。                                                                                                                                                                                             |
    | `hide_thread`  <br />布尔值、字符串或整数                                                                                                            | `false` | 当设置为 `true`、`"t"` 或 `1` 时，如果请求的推文是对另一条推文的回复，会话线程中上一条推文的折叠版本将不会显示。                                                                                                                                                                             |
    | `omit_script`  <br />布尔值、字符串或整数                                                                                                            | `false` | 当设置为 `true`、`"t"` 或 `1` 时，用于加载 `widgets.js` 的 `<script>` 将不会被返回。您的网页应自行引用 `widgets.js`，以便在包括[嵌入式推文](https://developer.x.com/web/embedded-tweets)在内的所有 X 小组件中使用。                                                                               |
    | `align`  <br />枚举类型 `{left,right,center,none}`                                                                                             | `none`  | 指定嵌入的推文相对于父元素在页面中应左对齐、右对齐还是居中显示。                                                                                                                                                                                                              |
    | `lang`  <br />Enum([Language（语言）](https://developer.x.com/en/docs/twitter-for-websites/twitter-for-websites-supported-languages/overview)) | `en`    | 请求返回使用指定的[嵌入式推文所支持的 X 语言](https://developer.x.com/web/overview/languages)编写的 HTML 和渲染后的推文。                                                                                                                                                    |
    | `theme`  <br />枚举类型 `{light, dark}`                                                                                                        | `light` | 当设置为 `dark` 时，推文将以浅色文字显示在深色背景上。                                                                                                                                                                                                               |
    | `dnt`  <br />布尔值                                                                                                                           | `false` | 当设置为 `true` 时，你网站上的该推文及其嵌入页面不会被用于包括[个性化推荐](https://support.x.com/articles/20169421)和[个性化广告](https://support.x.com/articles/20170405)在内的相关用途。                                                                                                  |
