<div id="introduction">
  ## 介绍
</div>

虽然 [recent search endpoint](/zh/x-api/posts/search/introduction) 只能获取过去 7 天内发布的帖子，但 user Post timeline 和 user mention timeline 端点允许你为已授权用户（使用用户 id）检索早于这 7 天的帖子和提及。开发者可以使用这些端点来研究某个用户时间线或提及中的主题、实体和情感倾向。在本教程中，我们将向你展示如何使用 user Tweet timeline 和 user mention timeline 端点来探索某个用户的帖子和提及。
 

<div id="prerequisites">
  ## 先决条件
</div>

* 要使用用户推文时间线和用户提及时间线端点，你需要拥有一个有效的开发者账号。 
* 你还需要已创建一个 [Project](/zh/resources/fundamentals/developer-apps)。
* 你必须已经[注册](https://developer.x.com/en/portal/petition/essential/basic-info)开发者账号，并激活[新的 Developer Console 体验](https://developer.x.com/en/portal/opt-in.html)。 
* 你需要为在 [Developer Console](/zh/resources/fundamentals/developer-portal) 中创建并附属于 [Project](/zh/resources/fundamentals/developer-apps) 的开发者 App 准备有效的密钥和令牌。
* 来自你在 [X Developer Console](/zh/resources/fundamentals/developer-portal) 中的 App 的 Bearer Token。
* 如果你还没有获批的开发者账号，可以[申请一个](https://developer.x.com/en/apply-for-access)。

<div id="approved-developer-account">
  ## 已获批准的开发者账号
</div>

如果你还没有开发者账号，可以[在此申请](https://developer.x.com/en/apply-for-access)。

<div id="how-to-get-the-user-id-for-a-user-to-use-in-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## 如何获取可用于用户推文时间线和用户提及时间线端点的用户 ID
</div>

用户推文时间线和用户提及时间线端点支持你通过用户 ID 获取帖子。要通过用户名获取用户 ID，你可以使用新的 [用户查询端点 v2](/zh/x-api/users/lookup/quickstart/user-lookup)。将 USER&#95;NAME 替换为你选择的用户名，将 XXXX 替换为你在上文获取的 Bearer Token。

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

您将在响应中看到用户 id，如下所示：

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```

<div id="connecting-to-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## 连接用户推文时间线和用户提及时间线端点
</div>

要获取某个用户的推文时间线，请在终端中运行以下 curl 命令（务必将 USER&#95;ID 替换为你选择的用户 ID，将 XXXX 替换为你在上面获得的 Bearer Token）。

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```

你会看到，这些请求的 JSON 响应默认会包含这些帖子的 ID 和文本（示例如下）。

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 如果您是 X API v2 的新用户,请查看这份分步指南来发出您的第一个请求 https://t.co/4rZqThpSbp"
}
```

如果你希望在响应中返回更多字段（例如用户信息、其他推文字段，如上下文注释等），那么你需要在请求中显式指定这些字段。你可以在[使用字段和扩展的指南](/zh/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)中了解具体操作方法。

你也可以使用任意你熟悉的编程语言来获取这些帖子。请在我们的 [GitHub 仓库](https://github.com/xdevplatform/Twitter-API-v2-sample-code)中查看针对用户推文时间线和用户提及时间线端点的 Python、Node（JavaScript）、Java 和 Ruby 示例代码。

<div id="exploring-the-users-posts">
  ## 探索用户的帖子
</div>

一旦你掌握了如何使用用户推文时间线和用户提及时间线端点来获取帖子，就可以开始探索他们的帖子。例如，如果你想识别某个用户被提及的帖子中出现的常见命名实体，可以执行以下操作：

在 API 请求中，指定你希望在推文响应中返回 `context_annotations` 对象：

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

在响应中，你可以看到提及中是否包含任何命名实体。示例如下：

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "品牌与公司"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

如果你想查看有哪些热门实体出现在你的提及（mentions）中，你可以通过解析提及中的每条推文来统计各热门实体的出现次数。

如果你想获取时间线中所有包含媒体的帖子对应的预览图片 URL，可以按以下方式操作：

在 API 请求中，指定你需要在 tweet.media 字段中返回 preview&#95;image&#95;url，并在 expansions 参数中请求 attachments.media&#95;keys。

```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

在响应中，您会在包含对象 `includes` 中看到 preview&#95;image&#95;url 字段，如下所示：

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```
