<div id="introduction">
  ## 介绍
</div>

[最近搜索端点](/zh/x-api/posts/search/introduction) 只能获取最近 7 天内发布的帖子，而用户帖子时间线和用户提及时间线端点则允许你针对已授权用户（使用用户 ID）检索早于最近 7 天的帖子和提及。开发者可以使用这些端点分析用户时间线或提及中的话题、实体和情感。在本教程中，我们将向你展示如何使用用户 Tweet 时间线和用户提及时间线端点来探索某个用户的帖子和提及。
 

<div id="prerequisites">
  ## 前提条件
</div>

* 若要使用用户推文时间线和用户提及时间线端点，你需要拥有一个有效的开发者账号。 
* 你还需要创建一个 [Project](/zh/resources/fundamentals/developer-apps)。
* 你必须已经[注册](https://developer.x.com/en/portal/petition/essential/basic-info)开发者账号，并已激活 [新的 Developer Console 体验](https://developer.x.com/en/portal/opt-in.html)。 
* 只要你拥有一个附属于在 [Developer Console](/zh/resources/fundamentals/developer-portal) 中创建的 [Project](/zh/resources/fundamentals/developer-apps) 的开发者 App 的有效密钥和令牌，即可获得访问权限。
* 你在 [X Developer Console](/zh/resources/fundamentals/developer-portal) 中 App 的 Bearer Token。
* 如果你还没有获批的开发者账号，可以[申请一个](https://developer.x.com/en/apply-for-access)。

<div id="approved-developer-account">
  ## 已获批准的开发者账号
</div>

如果你还没有开发者账号，可以[申请一个](https://developer.x.com/en/apply-for-access)。

<div id="how-to-get-the-user-id-for-a-user-to-use-in-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## 如何获取可用于用户推文时间线和用户提及时间线端点的用户 ID
</div>

用户推文时间线和用户提及时间线端点允许你使用用户 ID 来获取帖子。要从用户名获取用户 ID，你可以使用新的 [user lookup endpoint v2](/zh/x-api/users/lookup/quickstart/user-lookup)。将 USER&#95;NAME 替换为你选择的用户名，将 XXXX 替换为你在上文获取的 Bearer Token。

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

您将在响应中看到用户 id，如下所示：

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```

<div id="connecting-to-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## 连接用户推文时间线和用户提及时间线端点
</div>

为了获取某个用户的推文时间线，请在终端中执行以下 curl 命令（请确保将 USER&#95;ID 替换为你选择的用户 ID，并将 XXXX 替换为你在上文中获取的你自己的 Bearer Token）

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```

你会看到，这些请求的 JSON 响应默认会包含帖子的 id 和文本内容（示例如下）。

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 如果您是 X API v2 的新用户,请查看这份发送首个请求的分步指南 https://t.co/4rZqThpSbp"
}
```

如果你希望在响应中返回更多字段（例如用户信息、额外的推文字段，如上下文注释等），那么你需要在请求中明确指定这些字段，使其包含在响应中。请参阅[关于使用字段和扩展的指南](/zh/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)了解具体方法。

你也可以使用任意你偏好的编程语言来获取这些帖子。请查看我们在 Python、Node（JavaScript）、Java 和 Ruby 中为用户推文时间线和用户提及时间线端点提供的示例代码，这些代码托管在我们的 [GitHub 仓库](https://github.com/xdevplatform/Twitter-API-v2-sample-code)中。

<div id="exploring-the-users-posts">
  ## 探索用户的帖子
</div>

一旦你知道如何使用用户推文时间线和用户提及时间线端点来获取帖子，就可以开始探索这些帖子。例如，如果你想识别某个用户被提及内容中常见的命名实体，可以按如下方式操作：

在 API 请求中，指定你希望在 Tweet 响应中返回 `context_annotations` 对象：

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

在响应中，您可以看到提及中是否包含任何命名实体。以下是一个示例：

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "品牌与公司"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

如果你想查看在你的提及中出现了哪些热门实体，你可以通过解析提及中的每条推文来统计这些热门实体的出现次数。

如果你想查看时间线中所有包含媒体的帖子所对应的预览图片 URL，你可以执行以下操作：

在 API 请求中，指定你希望在 tweet.media 字段中返回 preview&#95;image&#95;url，并在 expansions 参数中指定 attachments.media&#95;keys。

```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

在响应的 includes 对象中，你会看到 preview&#95;image&#95;url，如下所示：

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```
