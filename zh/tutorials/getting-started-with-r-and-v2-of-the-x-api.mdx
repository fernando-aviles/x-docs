<div id="introduction">
  ## 介绍
</div>

本教程将逐步介绍你使用 R 编程语言和 X API v2 入门所需的内容。通过使用 R 连接到
[user lookup](/zh/x-api/users/lookup/introduction) 端点，我会演示如何处理
X API 返回的 JSON。user lookup 是一个 GET 方法，会根据指定的用户 ID 或
用户名，返回关于某个用户或一组用户的信息。

如果你还不太熟悉，R 是当前最流行的语言之一，常用于时间序列分析、建模、可视化以及其他
数据分析等常见数据科学任务，并且经常与 X API 搭配使用。借助 user lookup
端点，你可以使用
[user object](/zh/x-api/fundamentals/data-dictionary#user)
来确定某人拥有的关注者数量与其个人简介情感评分之间的相关性。user object
也可以用于基于账户在其个人资料中公开列出的位置信息，对一组账户进行归类或映射。

<div id="getting-started-with-the-x-api">
  ### 开始使用 X API
</div>

在使用 X API v2 之前，你需要先
[注册](https://developer.x.com/en/portal/petition/essential/basic-info)
一个开发者账号。

获得批准的开发者账号后，你需要先创建一个
[Project](/zh/resources/fundamentals/developer-apps)。Project 允许你根据自己计划如何使用 X API 来组织工作，从而有效管理
你对 API 的访问，并监控你的使用情况。

每个 Project 都包含一个 [App](/zh/resources/fundamentals/developer-apps)，你可以使用它
生成用于使用 X API 所必需的凭证。你可以在文档的
[入门](/zh/x-api/getting-started/about-x-api) 部分
了解更多关于如何开始使用 X API 的信息。

<div id="getting-your-r-environment-set-up">
  ### 设置你的 R 环境
</div>

首先，你需要先[下载 R](https://cloud.r-project.org/)，你可以在
[CRAN 网站](https://cran.r-project.org/)上完成这一步。

之后，为了搭建一个可以使用 R 的环境，你可以使用
[RStudio](https://www.rstudio.com/)、适用于

的 R 扩展包，或者
[Jupyter Notebook](https://docs.anaconda.com/anaconda/navigator/tutorials/r-lang/)，
如果你来自 Python 生态的话。

<div id="setting-up-your-environment-variable">
  ### 设置环境变量
</div>

在接下来要展示的代码示例中，你需要为你的 Bearer Token 创建一个环境变量。Bearer Token 用于对 X API 进行身份验证，并开始发起请求。首先，将 “your-bearer-token” 替换为你自己的 Bearer Token，你可以在 Developer Console 中你的 App 的密钥和令牌部分获取它。在开始编写脚本之前，你需要先在终端中运行这一行代码。

```r
Sys.setenv(BEARER_TOKEN = "your-bearer-token")
```

<div id="making-your-request">
  ### 发起请求
</div>

你可以使用
[httr](https://cran.r-project.org/web/packages/httr/index.html) 包向 X API 发起 HTTP
请求。如果你尚未安装，请在控制台中安装该包。你还需要安装
[jsonlite](https://cran.r-project.org/web/packages/jsonlite/index.html) 以处理我们的 JSON 对象，以及用于数据操作的 [dplyr](https://dplyr.tidyverse.org/)。

```r
install.packages("httr")
install.packages("jsonlite")
install.packages("dplyr")
```

现在可以开始编写一个用于连接到 API 的 R 脚本。在文件开头加载 httr、jsonlite 和 dplyr 包。

```r
require(httr)
require(jsonlite)
require(dplyr)
```

代码示例中的第一步，是完成用于连接到 X API 的身份验证配置。拿到你从 App 中获取的
[Bearer Token](/zh/resources/fundamentals/authentication#using-and-generating-an-app-only-bearer-token)，并将它传入请求头中用于身份验证。在下面的示例中，用你的 token 替换 $BEARER&#95;TOKEN。

```r
bearer_token <- Sys.getenv("$BEARER_TOKEN")
headers <- c(`Authorization` = sprintf('Bearer %s', bearer_token))
```

在完成身份验证配置之后，定义你的请求参数。
默认情况下，响应中会返回每个用户的 id、名称和用户名。
你可以通过添加额外的
[字段](/zh/x-api/fundamentals/fields) 和
[扩展](/zh/x-api/fundamentals/expansions) 来调整这个 JSON 数据。
在本示例中，你需要获取用户的个人简介信息，这是通过在请求中指定 `user.fields=description` 来实现的，
以及一个包含该用户置顶帖子（pinned Post）的扩展。

```r
params <- list(`user.fields` = 'description', `expansions` = 'pinned_tweet_id')
```

现在，你已经可以使用想要获取更多信息的 X handle（也称为账号）来格式化你的 URL。使用 `readline` 方法，使这个示例可以复用。输入你想要查询的 handle 之后，通过将 `$USERNAME` 替换为目标 X handle 来格式化你的 URL，使其中包含你指定的 handle。

```r
handle <- readline('$USERNAME')
url_handle <- sprintf('https://api.x.com/2/users/by?usernames=%s', handle)
```

此时，请使用 httr 包向你刚刚创建的 URL 发出一个 GET 请求，通过请求头传入我们的身份验证凭据，并传入你定义的参数。你可以将响应以文本对象的形式保存在变量 obj 中，并将其打印出来以查看你发出的请求的结果。

```r
response <-
  httr::GET(url = url_handle,
    httr::add_headers(.headers = headers),
    query = params)
obj <- httr::content(response, as = "text")
print(obj)
```

<div id="working-with-our-json-payload">
  ### 处理我们的 JSON 负载
</div>

我最喜欢处理 JSON 的方式之一是使用数据框（data frame），它可以让你轻松访问复杂的嵌套数据。为此，可以使用 jsonlite 包的 fromJSON 方法将文件展平，使所有字段都位于同一层级的对象中。然后，将该对象传入数据框中。现在你就可以查看这个数据框了。

```
json_data <- fromJSON(obj, flatten = TRUE) %>% as.data.frame View(json_data)
```

你可以从数据帧中访问 data 的字段，然后将这些字段值拼接成一个包含 handle、用户名和简介的字符串。

```r
final <-
  sprintf(
    "用户名: %s\n简介: %s\n置顶推文: %s",
    json_data$data.username,
    json_data$data.description,
    json_data$includes.tweets.text
  )
```

使用 `cat` 而不是 `print` 来查看对象，使你提取的每个字段之间以换行分隔。

```r
cat(final)
```

如果你对多个账号（handle）发起了请求，可以很方便地使用循环来访问数据框中的每个元素。
