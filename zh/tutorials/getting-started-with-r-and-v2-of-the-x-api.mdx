<div id="introduction">
  ## 介绍
</div>

本教程将逐步介绍你开始使用 R 编程语言和 X API v2 所需的准备工作。我们将使用 R 连接到
[user lookup](/zh/x-api/users/lookup/introduction) 端点，我会演示如何处理
X API 返回的 JSON。User lookup 是一个使用 GET 方法的端点，它会根据用户 ID 或
用户名返回有关单个用户或一组用户的信息。

如果你还不熟悉 R，R 是最流行的用于常见数据科学任务的语言之一，例如时间序列分析、
建模、可视化和其他数据分析，并且经常与 X API 结合使用。通过 user
lookup 端点，你可以使用
[user object](/zh/x-api/fundamentals/data-dictionary#user)
来确定某人拥有的关注者数量与其个人简介情感得分之间的相关性。User object 还可以用来基于用户在个人资料中公开列出的所在地，对一组账号进行映射。

<div id="getting-started-with-the-x-api">
  ### 开始使用 X API
</div>

在使用 X API v2 之前，你需要先
[注册](https://developer.x.com/en/portal/petition/essential/basic-info)
一个开发者账号。

开发者账号获批后，你需要先创建一个
[Project](/zh/resources/fundamentals/developer-apps)。Project 可以让你根据计划如何使用 X API 来组织你的工作，从而更有效地管理你对 API 的访问，并监控你的使用情况。

每个 Project 都包含一个 [App](/zh/resources/fundamentals/developer-apps)，你可以通过它生成使用 X API 所需的凭证。你可以在文档中的
[入门](/zh/x-api/getting-started/about-x-api)部分了解更多关于如何开始使用 X API 的信息。

<div id="getting-your-r-environment-set-up">
  ### 设置 R 开发环境
</div>

首先，你需要[下载 R](https://cloud.r-project.org/)，你可以在
[CRAN 网站](https://cran.r-project.org/)上完成下载。

然后，要搭建一个用于 R 的工作环境，你可以使用
[RStudio](https://www.rstudio.com/)、适用于
[Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=Ikuyadeu.r-pack)
的 R 扩展包，或者如果你主要使用 Python，也可以使用
[Jupyter Notebook](https://docs.anaconda.com/anaconda/navigator/tutorials/r-lang/)。

<div id="setting-up-your-environment-variable">
  ### 设置环境变量
</div>

在本节要演示的代码示例中，你需要先为你的 Bearer 令牌创建一个环境变量。Bearer 令牌是让你能够通过 X API 进行身份验证并开始发送请求的凭据。首先，将“your-bearer-token”替换为你自己的 Bearer 令牌，你可以在开发者控制台中 App 的 keys and tokens 部分获取它。在开始编写脚本之前，你需要先在终端/控制台中运行这一行代码。

```r
Sys.setenv(BEARER_TOKEN = "your-bearer-token")
```

<div id="making-your-request">
  ### 发出请求
</div>

你可以使用
[httr](https://cran.r-project.org/web/packages/httr/index.html) 包向 X API 发送 HTTP
请求。如果你尚未安装它，请在 R 控制台中安装该包。你还需要安装
[jsonlite](https://cran.r-project.org/web/packages/jsonlite/index.html) 来处理我们的 JSON 对象，以及用于数据操作的 [dplyr](https://dplyr.tidyverse.org/)。

```r
install.packages("httr")
install.packages("jsonlite")
install.packages("dplyr")
```

现在你可以开始编写 R 脚本来连接到 API。在文件顶部加载 httr、jsonlite 和 dplyr 这几个包。

```r
require(httr)
require(jsonlite)
require(dplyr)
```

在你的代码示例中，第一步是完成与 X API 通信所需的身份验证设置。获取你在
App 中生成的
[Bearer Token](/zh/resources/fundamentals/authentication#using-and-generating-an-app-only-bearer-token)，并将它传递到请求头中用于身份验证。在下面的示例中，将 $BEARER&#95;TOKEN 替换为你的 Bearer 令牌。

```r
bearer_token <- Sys.getenv("$BEARER_TOKEN")
headers <- c(`Authorization` = sprintf('Bearer %s', bearer_token))
```

在完成身份验证配置之后，先定义你的请求参数。
默认情况下，你会收到每个返回的用户的 id、name 和 username。
你可以通过添加额外的
[字段](/zh/x-api/fundamentals/fields) 和
[expansions](/zh/x-api/fundamentals/expansions) 来调整这个响应数据。
在本示例中，你需要用户的个人简介（profile bio），这是通过 user.fields=description 请求的，
以及一个包含该用户置顶帖子（pinned Post）的 expansion。

```r
params <- list(`user.fields` = 'description', `expansions` = 'pinned_tweet_id')
```

现在，你已经可以根据想要获取更多信息的 X handle（也称为账号）来构造你的 URL。使用 readline 方法，使此示例可以被重复使用。当你输入想要查看的 handle 后，通过将 $USERNAME 替换为目标 X handle 来构造你的 URL，使其包含你定义的 handle。

```r
handle <- readline('$USERNAME')
url_handle <- sprintf('https://api.x.com/2/users/by?usernames=%s', handle)
```

此时，使用 httr 包向你刚刚创建的 URL 发起一次 GET 请求，通过请求头（header）传入我们的认证凭据，并传入你定义的参数。你可以将响应结果作为文本对象保存在变量 obj 中，然后将其打印出来，以查看你发起的请求的结果。

```r
response <-
  httr::GET(url = url_handle,
    httr::add_headers(.headers = headers),
    query = params)
obj <- httr::content(response, as = "text")
print(obj)
```

<div id="working-with-our-json-payload">
  ### 使用我们的 JSON 负载
</div>

我最喜欢处理 JSON 的方式之一是使用数据框，它可以让你轻松访问复杂的嵌套数据。为此，可以使用 jsonlite 包的 fromJSON 方法将文件“展平”，使各字段处于同一对象层级。然后，将该对象转换为数据框。现在，你就可以查看这个数据框了。

```
json_data <- fromJSON(obj, flatten = TRUE) %>% as.data.frame View(json_data)
```

你可以从数据帧中访问数据的字段，并将它们传入一个字符串，该字符串包含 handle、username 和 bio。

```r
final <-
  sprintf(
    "Handle: %s\nBio: %s\nPinned Post: %s",
    json_data$data.username,
    json_data$data.description,
    json_data$includes.tweets.text
  )
```

使用 `cat` 而不是 `print` 来查看对象，这样你获取的每个字段之间都会以换行分隔。

```r
cat(final)
```

如果你需要为多个 handle 发起请求，可以使用循环来依次访问每个数据帧元素。
