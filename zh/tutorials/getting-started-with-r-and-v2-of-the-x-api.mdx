<div id="introduction">
  ## 介绍
</div>

本教程将逐步讲解开始使用 R 编程语言和 X API v2 所需了解的内容。我们将使用 R 连接到
[user lookup](/zh/x-api/users/lookup/introduction) 端点，我会演示如何处理
X API 返回的 JSON。user lookup 端点使用 GET 方法，根据用户 ID 或
用户名返回单个用户或一组用户的信息。

如果你对 R 不太熟悉，R 是在时间序列分析、建模、可视化以及其他数据分析等常见数据科学任务中
最流行的语言之一，并且经常与 X API 配合使用。通过 user lookup 端点，你可以使用
[user object](/zh/x-api/fundamentals/data-dictionary#user)
来分析某人的粉丝数量与其个人简介情感分数之间的相关性。user object 也可以用来根据
用户在其个人资料中公开列出的位置信息，对一组账号进行映射。

<div id="getting-started-with-the-x-api">
  ### 开始使用 X API
</div>

在使用 X API v2 之前，你需要先
[注册](https://developer.x.com/en/portal/petition/essential/basic-info)
一个开发者账号。

在你的开发者账号获批后，你需要先创建一个
[Project](/zh/resources/fundamentals/developer-apps)。Project 可让你根据你计划如何使用 X API 来组织工作，从而更有效地管理对 API 的访问并监控用量。

每个 Project 都包含一个 [App](/zh/resources/fundamentals/developer-apps)，你可以使用它生成使用 X API 所必需的凭证。你可以在文档中的
[入门](/zh/x-api/getting-started/about-x-api)
部分了解更多关于如何开始使用 X API 的信息。

<div id="getting-your-r-environment-set-up">
  ### 设置你的 R 环境
</div>

首先，你需要先[下载 R](https://cloud.r-project.org/)，可以在
[CRAN 官网](https://cran.r-project.org/)上完成这一步。

然后，为了搭建一个用于使用 R 的环境，你可以使用
[RStudio](https://www.rstudio.com/)、适用于
[Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=Ikuyadeu.r-pack)
的 R 扩展包，或者如果你来自 Python 生态，也可以使用
[Jupyter Notebook](https://docs.anaconda.com/anaconda/navigator/tutorials/r-lang/)。

<div id="setting-up-your-environment-variable">
  ### 设置环境变量
</div>

在今天要展示的代码示例中，你需要为自己的 Bearer Token 创建一个环境变量。Bearer Token 用于对 X API 进行身份验证，并开始发送请求。首先，将 “your-bearer-token” 替换为你自己的 Bearer Token，你可以在开发者控制台中 App 的 Keys and tokens 部分获取该值。在开始编写脚本之前，你需要先在控制台中运行这一行代码。

```r
Sys.setenv(BEARER_TOKEN = "your-bearer-token")
```

<div id="making-your-request">
  ### 发起请求
</div>

你可以使用
[httr](https://cran.r-project.org/web/packages/httr/index.html) 包来向 X API 发起 HTTP
请求。如果你尚未安装该包，请在控制台中先进行安装。你还需要安装
[jsonlite](https://cran.r-project.org/web/packages/jsonlite/index.html) 以处理我们的 JSON 对象，以及 [dplyr](https://dplyr.tidyverse.org/) 以进行数据处理。

```r
install.packages("httr")
install.packages("jsonlite")
install.packages("dplyr")
```

现在你可以开始编写用于连接 API 的 R 脚本。在文件开头加载 httr、jsonlite 和 dplyr 这几个包。

```r
require(httr)
require(jsonlite)
require(dplyr)
```

代码示例中的第一步是完成 X API 的认证设置。取出你在应用中获取的
[Bearer Token](/zh/resources/fundamentals/authentication#using-and-generating-an-app-only-bearer-token)，并将它作为认证信息传入请求头中。在下面的示例中，将 $BEARER&#95;TOKEN 替换为你的令牌。

```r
bearer_token <- Sys.getenv("$BEARER_TOKEN")
headers <- c(`Authorization` = sprintf('Bearer %s', bearer_token))
```

在完成身份验证配置后，定义你的请求参数。
默认情况下，你会在响应中获得每个用户的 id、名称和用户名。
你可以通过添加额外的
[字段](/zh/x-api/fundamentals/fields) 和
[扩展](/zh/x-api/fundamentals/expansions) 来调整返回的 JSON 负载。
在本示例中，你希望获取用户的个人简介，这是通过 `user.fields=description` 请求的，
以及一个包含该用户置顶帖子的扩展。

```r
params <- list(`user.fields` = 'description', `expansions` = 'pinned_tweet_id')
```

现在，你已经可以使用要查询的 X 用户名（也称为账号）来构造你的 URL。使用 `readline` 方法，使此示例可以复用。输入你想要查看的用户名后，通过将 `$USERNAME` 替换为目标 X 用户名来格式化你的 URL，使其包含你指定的用户名。

```r
handle <- readline('$USERNAME')
url_handle <- sprintf('https://api.x.com/2/users/by?usernames=%s', handle)
```

此时，请使用 httr 包向你刚刚创建的 URL 发出一个 GET 请求，在请求头中传入我们的身份验证凭证，并传入你定义的参数。你可以将响应作为文本对象保存在变量 obj 中，然后将其打印出来，以查看你发出的请求的结果。

```r
response <-
  httr::GET(url = url_handle,
    httr::add_headers(.headers = headers),
    query = params)
obj <- httr::content(response, as = "text")
print(obj)
```

<div id="working-with-our-json-payload">
  ### 使用我们的 JSON 负载
</div>

我最喜欢处理 JSON 的方式之一是使用数据框，这能让你轻松访问复杂的嵌套 data。要做到这一点，可以使用 jsonlite 包的 fromJSON 方法将文件展平成扁平结构，使字段处于同一对象中。然后，将该对象转换为一个数据框。现在你就可以开始查看这个数据框了。

```
json_data <- fromJSON(obj, flatten = TRUE) %>% as.data.frame View(json_data)
```

你可以从数据框中访问 data 的字段，并将它们传入一个包含 handle、用户名和个人简介的字符串中。

```r
final <-
  sprintf(
    "用户名: %s\n简介: %s\n置顶推文: %s",
    json_data$data.username,
    json_data$data.description,
    json_data$includes.tweets.text
  )
```

使用 `cat` 而不是 `print` 来查看对象，这样你获取的每个字段之间都会有换行。

```r
cat(final)
```

如果你针对多个 handle 发起了请求，可以很容易地用一个循环来访问每个数据框对象。
