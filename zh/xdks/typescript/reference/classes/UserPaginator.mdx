<div id="fetchnext">
  ### fetchNext
</div>

▸ **fetchNext**(): `Promise`&lt;`void`&gt;

获取下一页并将项目添加到当前实例中

此方法会获取下一页的数据，并将这些项目追加到当前分页器实例中。它会更新分页状态和元数据。

#### 返回

`Promise`&lt;`void`&gt;

**`示例`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // 获取第一页
console.log(followers.items.length); // 关注者数量

if (!followers.done) {
  await followers.fetchNext(); // 获取第二页
  console.log(followers.items.length); // 所有页面的关注者总数
}
```

**`Throws`**

在 API 请求失败时抛出异常

<div id="next">
  ### next
</div>

▸ **next**(): `Promise`&lt;[`Paginator`](/zh/xdks/typescript/reference/classes/Paginator)&lt;`any`&gt;&gt;

以新实例的方式获取下一页

此方法会创建一个从下一页开始的新 Paginator 实例，
而不会影响当前 Paginator 的状态。

<div id="returns">
  #### 返回值
</div>

`Promise`&lt;[`Paginator`](/zh/xdks/typescript/reference/classes/Paginator)&lt;`any`&gt;&gt;

用于获取下一页的新分页器实例

**`示例`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // Fetch first page

if (!followers.done) {
  const nextPage = await followers.next(); // 以新实例形式获取下一页
  console.log(followers.items.length); // Still first page
  console.log(nextPage.items.length); // Second page
}
```
