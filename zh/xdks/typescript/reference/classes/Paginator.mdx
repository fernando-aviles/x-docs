功能丰富的 X API 分页器

此类为 X API 提供了全面的分页支持，包括：

* 使用 `for await...of` 循环进行自动迭代
* 通过 `fetchNext()` 和 `fetchPrevious()` 手动控制分页
* 访问与分页令牌和计数相关的元数据
* 错误处理和限流（速率限制）检测
* 支持向前和向后分页

**`Example`**

```typescript
// 自动迭代
const followers = await client.users.getFollowers('783214');
for await (const follower of followers) {
  console.log(follower.username);
}

// 手动控制
const followers = await client.users.getFollowers('783214');
await followers.fetchNext();
console.log(followers.items.length); // 关注者数量
console.log(followers.meta.nextToken); // 下一页分页令牌

// 检查状态
if (!followers.done) {
  await followers.fetchNext();
}
```

<div id="fetchnext">
  ### fetchNext
</div>

▸ **fetchNext**(): `Promise`&lt;`void`&gt;

获取下一页并将项目添加到当前实例中

此方法会获取下一页的数据，并将其中的项目追加到当前分页实例。它会更新分页状态和元数据。

<div id="returns">
  #### 返回值
</div>

`Promise`&lt;`void`&gt;

**`示例`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // 获取第一页
console.log(followers.items.length); // 关注者数量

if (!followers.done) {
  await followers.fetchNext(); // 获取第二页
  console.log(followers.items.length); // 所有页面的关注者总数
}
```

**`Throws`**

<div id="next">
  ### next
</div>

▸ **next**(): `Promise`&lt;[`Paginator`](/zh/xdks/typescript/reference/classes/Paginator)&lt;`T`&gt;&gt;

以新实例的形式获取下一页

此方法会创建一个从下一页开始的新分页器实例，
且不会影响当前分页器的状态。

<div id="returns">
  #### 返回值
</div>

`Promise`&lt;[`Paginator`](/zh/xdks/typescript/reference/classes/Paginator)&lt;`T`&gt;&gt;

用于获取下一页的新分页器实例

**`示例`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // Fetch first page

if (!followers.done) {
  const nextPage = await followers.next(); // 以新实例形式获取下一页
  console.log(followers.items.length); // Still first page
  console.log(nextPage.items.length); // Second page
}
```
