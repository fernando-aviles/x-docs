Python XDK（X Developer Kit）是我们为使用 Python 与 X API v2 交互而提供的官方客户端库。它可以帮助开发者快速上手我们的 API，并基于此构建应用程序。该库是基于我们的官方 [OpenAPI 规范](https://api.x.com/2/openapi.json) 自动生成的。它在屏蔽底层 HTTP 细节的同时，也在需要时仍提供精细的控制能力。

<div id="key-features">
  ## 关键特性
</div>

- 🔐 **OAuth 支持**：完整支持 Bearer 令牌（仅 App）认证、带 PKCE 的 OAuth 2.0（用户上下文）以及 OAuth 1.0。
- 🔄 **分页**：自动分页获取大量结果。XDK 会处理分页逻辑，你无需手动使用 `next_token` 发起多次 API 调用。
- 📡 **流式传输**：为需要持久 HTTP 连接的端点（如 filtered stream）提供实时数据流支持。
- 🎯 **全面覆盖**：支持所有 X API v2 端点，包括搜索、时间线、filtered-stream 等。
**版本兼容性**：Python 3.8+。已在 CPython 和 PyPy 上测试。
