Python XDK（X Developer Kit，X 开发工具包）是我们面向 Python 的官方客户端库，用于与 X API v2 交互。它使开发者能够快速上手我们的 API 并基于此构建应用程序。它是基于我们的官方 [OpenAPI 规范](https://api.x.com/2/openapi.json) 自动生成的。在需要时，它在屏蔽底层 HTTP 细节的同时，仍然提供细粒度的控制能力。

<div id="key-features">
  ## 关键特性
</div>

- 🔐 **OAuth 支持**：完整支持 Bearer Token（仅应用 app-only）认证、带 PKCE 的 OAuth 2.0（用户上下文）以及 OAuth 1.0。
- 🔄 **分页**：自动分页处理大规模结果集。XDK 会负责处理分页逻辑，你无需为手动使用 `next_token` 发起多次 API 调用而操心。
- 📡 **流式传输**：支持需要持久 HTTP 连接的端点（如 filtered stream）的实时数据流式传输。
- 🎯 **全面覆盖**：支持包括搜索、时间线、filtered stream 等在内的所有 X API v2 端点。
**版本兼容性**：Python 3.8+。已在 CPython 和 PyPy 上测试。
