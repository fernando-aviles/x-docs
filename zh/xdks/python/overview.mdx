Python XDK（X Developer Kit）是我们面向 Python 的、用于与 X API v2 交互的官方客户端库。它可以帮助开发者快速上手我们的 API，并在此基础上构建应用程序。它基于我们的官方 [OpenAPI 规范](https://api.x.com/2/openapi.json) 自动生成。在屏蔽底层 HTTP 细节的同时，仍然可以在需要时进行精细化控制。

<div id="key-features">
  ## 关键特性
</div>

- 🔐 **OAuth 支持**：完整支持 Bearer Token（仅应用）认证、带 PKCE 的 OAuth 2.0（用户上下文）以及 OAuth 1.0。
- 🔄 **分页**：自动分页处理大型结果集。xdk 会负责处理分页逻辑，你无需手动结合 `next_token` 发起多次 API 调用。
- 📡 **流式传输**：为需要持久 HTTP 连接的端点（例如 filtered stream）提供实时数据流支持。
- 🎯 **全面覆盖**：支持所有 X API v2 端点，包括搜索、时间线、filtered stream 等。

**版本兼容性**：Python 3.8+。已在 CPython 和 PyPy 上测试。
