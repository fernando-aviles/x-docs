该模块提供一个用于与 X API 流式端点交互的客户端。
实时流式操作会返回生成器，在数据到达时依次产出 data。
流式连接会自动使用指数退避重试机制进行管理，以实现可靠的处理。

<div id="labels_compliance">
  ### `labels_compliance`
</div>

帖子标签流（Streaming）
对所有应用到帖子上的标签事件进行流式传输。
这是一个流式端点，会在 data 实时可用时将其输出。
每个输出项代表该流中的单个数据点。
