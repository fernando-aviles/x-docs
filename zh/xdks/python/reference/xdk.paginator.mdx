适用于 X API SDK 的基于游标的分页工具。

此模块提供一个 Cursor 类，为所有 API Client 提供优雅的分页支持。Cursor 允许你通过 .pages() 和 .items() 方法轻松遍历分页结果，并同时保证类型安全。

<div id="xdkpaginatorcursor">
  ### `xdk.paginator.cursor`
</div>

用于创建带有正确类型推断和校验的游标。
这个工厂函数有助于进行类型推断，使你能够为响应类型获得正确的
类型提示，并在静态分析阶段和运行时验证该方法
是否支持分页。
