<div id="create_replay_job">
  ### `create_replay_job`
</div>

创建回放任务
创建一个回放任务，用于为与指定 webhook 关联的所有订阅检索过去最多 5 天内的活动。

<div id="parameters">
  #### 参数
</div>

<ParamField path="path.webhook_id" type="Any">
Webhook 配置的唯一标识符。
</ParamField>

<ParamField path="path.from_date" type="str">
提供事件的最早（起始）UTC 时间戳（含），格式为 yyyymmddhhmm。
</ParamField>

<ParamField path="path.to_date" type="str">
提供事件的最晚（结束）UTC 时间戳（不含），格式为 yyyymmddhhmm。
</ParamField>

</div>

`CreateReplayJobResponse` - 响应数据
