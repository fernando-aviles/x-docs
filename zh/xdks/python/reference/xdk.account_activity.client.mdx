<div id="create_replay_job">
  ### `create_replay_job`
</div>

创建回放作业
创建一个回放作业，以检索与指定 webhook 关联的所有订阅在过去最多 5 天内的活动。

<div id="parameters">
  #### 参数
</div>

<ParamField path="path.webhook_id" type="Any">
webhook 配置的唯一标识符。
</ParamField>

<ParamField path="path.from_date" type="str">
事件提供的最早（起始）UTC 时间戳（含该时间），格式为 yyyymmddhhmm。
</ParamField>

<ParamField path="path.to_date" type="str">
事件提供的最晚（结束）UTC 时间戳（不含该时间），格式为 yyyymmddhhmm。
</ParamField>

#### 返回

`CreateReplayJobResponse` - 响应数据
