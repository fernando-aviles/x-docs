该模块提供 OAuth2 PKCE（Proof Key for Code Exchange，用于代码交换的证明密钥）身份验证功能，用于实现安全的授权流程。功能包括 code verifier 的生成、访问令牌（token）管理，以及自动刷新令牌的能力。

<div id="class-xdkoauth2_authoauth2pkceauth">
  ### `class xdk.oauth2_auth.OAuth2PKCEAuth`
</div>

用于 X API 的 OAuth2 PKCE 身份验证。
