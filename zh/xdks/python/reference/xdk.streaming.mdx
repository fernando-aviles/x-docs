为 X API SDK 提供健壮的流式传输实用工具。

该模块提供带有自动重连、指数退避以及完善错误处理的流式连接管理功能。Client 可以在无需关心连接管理的情况下使用流式端点——SDK 会自动处理所有恢复工作。

<div id="xdkstreamingstream_with_retry">
  ### `xdk.streaming.stream_with_retry`
</div>

从某个 endpoint 以流式方式获取数据，支持自动重连和指数退避。
此函数负责全部连接管理工作，包括：

- 断开连接时自动重连
- 对重试延迟使用带抖动（jitter）的指数退避
- 将 `errors` 分类为可重试错误与致命错误
- 用于监控连接状态的生命周期回调
