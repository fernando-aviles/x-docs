为 X API SDK 提供健壮的流式处理工具。

此模块提供流式连接处理功能，包括自动重连、
指数退避以及全面的错误处理。客户端可以使用
流式端点而无需关心连接管理——SDK 会自动处理所有恢复逻辑。

<div id="xdkstreamingstream_with_retry">
  ### `xdk.streaming.stream_with_retry`
</div>

从指定的 endpoint 以流式方式获取数据，并具备自动重连和指数退避机制。
此函数负责所有连接管理工作，包括：

- 断开连接时自动重连
- 带抖动的指数退避重试间隔
- 将错误分类为可重试错误与致命错误
- 用于监控连接状态的生命周期回调
