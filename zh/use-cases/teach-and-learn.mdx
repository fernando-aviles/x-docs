<div id="educators">
  ## 教育工作者
</div>

将 API 引入课堂，用于向学生讲授编程基础和实用的数据处理技能。

**资源：**

你是一名希望在课程中使用 X API 的教育工作者吗？这篇
[使用 X API 进行教学的指南](https://dev.to/suhemparack/a-guide-to-teaching-with-the-twitter-api-v2-3n08)
将帮助你了解 X API、教育工作者为何使用它、使用该 API 正在教授哪些
类型的课程，以及入门所需了解的其他所有内容。

**课程精选：**

以下课程体系是基于 X API v2 设计并开展的：

- [Social Media Data Mining and Analysis](https://canvas.uw.edu/courses/1434897)
  主讲人：Tanu Mitra 博士

- [Data Science & Society](https://dssoc.github.io/) 主讲人：Chris Bail 博士

- [Introduction to Cultural Analytics & Python](https://melaniewalsh.github.io/Intro-Cultural-Analytics/welcome.html)
  主讲人：Melanie Walsh 博士

- [Oxford Spring School in Advanced Research Methods, Analysing X Data](https://github.com/cjbarrie/oxspsch)
  主讲人：Chris Barrie 博士
