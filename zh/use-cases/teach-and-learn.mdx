  ## 教育工作者
</div>

将 API 引入课堂，向学生教授编程基础和实用的数据处理技能。

**资源：**

您是一位希望在课程中使用 X API 的教育工作者吗？这篇
[使用 X API 教学指南](https://dev.to/suhemparack/a-guide-to-teaching-with-the-twitter-api-v2-3n08)
将帮助您理解 X API、了解教育工作者为何使用它、正在通过该 API 开设哪些类型的课程，以及帮助您入门所需的一切信息。

**精选案例：**

下面的课程是基于 X API v2 设计和实施的：

  作者：Tanu Mitra 博士

- [Introduction to Cultural Analytics & Python](https://melaniewalsh.github.io/Intro-Cultural-Analytics/welcome.html)
  作者：Melanie Walsh 博士

  作者：Chris Barrie 博士
