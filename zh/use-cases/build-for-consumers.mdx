<div id="ways-to-build-for-people-on-x">
  ## 在 X 上为人们构建产品的方式
</div>

我们正在开放平台，鼓励你构建能够对公共对话产生积极影响并服务于 X 上用户的新工具和产品。具体来说，我们希望在以下领域鼓励新的创新和开发：

<CardGroup>
  <Card title="为健康和安全进行对话管理" icon="bullhorn" iconType="solid">
    通过构建内容审核工具和其他解决方案，帮助提升公共对话的健康和安全，使人们在 X 上参与对话时感到安全并乐在其中。构建互补或增强型技术，为人们提供更全面的工具选择，以便掌控他们在 X 上的互动体验。

    [**了解详情**](/zh/x-api/what-to-build#moderate-conversations-for-health-and-safety) <Icon icon="arrow-right" />
  </Card>

  <Card title="促进创作与个性表达" icon="bullhorn" iconType="solid">
    为创作者、品牌和个人构建工具，帮助他们扩展影响力、表达品牌并与拥有共同热情的人建立联系。也可以拓展人们在 X 上参与互动的方式，例如跨平台发布内容、游戏化机制或实用的机器人。

    [**了解详情**](/zh/x-api/what-to-build#enable-creation-and-personal-expression) <Icon icon="arrow-right" />
  </Card>

  <Card title="衡量和分析“正在发生的事”" icon="bullhorn" iconType="solid">
    帮助人们对公共对话或他们自己的内容进行衡量、分析并获取洞察。更好地了解你的受众，衡量内容的表现和影响力，从而做出更明智的决策，等等。

    [**了解详情**](/zh/x-api/what-to-build#measure-and-analyze-whats-happening) <Icon icon="arrow-right" />
  </Card>

  <Card title="改进社区体验 " icon="bullhorn" iconType="solid">
    X 面向所有人，我们希望鼓励并赋能你利用自己的专业能力，更好地服务 X 上不同社区的独特需求。无论你是在为新兴全球市场构建本地化解决方案，还是在为平台上不断壮大的社区（如游戏或金融）增强体验，我们都希望每个人都能在 X 上找到自己的归属。

    [**了解详情**](/zh/x-api/what-to-build#improve-community-experiences) <Icon icon="arrow-right" />
  </Card>

  <Card title="策划与推荐内容" icon="bullhorn" iconType="solid">
    构建 App、机器人或其他工具，帮助人们发现新内容或建立新的连接。也可以构建经过策划且可定制的体验，让人们看到更多自己最关心的内容。

    [**了解详情**](/zh/x-api/what-to-build#curate-and-recommend-content) <Icon icon="arrow-right" />
  </Card>

  <Card title="造福公共利益" icon="bullhorn" iconType="solid">
    开展突破性的研究，推动对公共健康和气候危机的认识进步，并以非商业方式开展构建，为公共利益服务。

    [**了解详情**](/zh/x-api/what-to-build#impact-the-greater-good) <Icon icon="arrow-right" />
  </Card>
</CardGroup>
