[开发者控制台](https://console.x.com) 是你管理 X API 访问的中心枢纽。你可以在一个地方完成创建 App、生成凭证、监控使用情况以及管理计费等操作。

<Button href="https://console.x.com">打开开发者控制台</Button>

<div id="getting-started">
  ## 入门
</div>

<Steps>
  <Step title="注册开发者账号">
    前往 [console.x.com](https://console.x.com)，使用你的 X 账号登录。阅读并接受《开发者协议》（Developer Agreement）。
  </Step>

  <Step title="创建你的第一个 App">
    点击 **New App**，填写名称和描述。这将生成你的 API 凭证。
  </Step>

  <Step title="保存你的凭证">
    复制并安全保存你的 API Key、API Secret 和 Access Tokens。它们之后将不会再次显示。
  </Step>

  <Step title="开始开发">
    使用你的凭证为 API 请求进行身份验证。参阅[快速入门指南](/zh/x-api/getting-started/make-your-first-request)。
  </Step>
</Steps>

<Warning>
  **请安全地存储凭证。** API keys 和 tokens 只会在生成时显示一次。请使用密码管理器或安全金库。如果遗失，你需要重新生成它们，旧凭证将会失效。
</Warning>

<div id="billing-credits">
  ## 计费与点数（Credits）
</div>

X API 采用按使用量计费的点数（credit）体系：

| 功能 | 说明 |
|:--------|:------------|
| **无月费** | 只为实际使用付费，无需订阅 |
| **基于点数** | 预先购买点数，调用 API 时按用量扣减 |
| **实时跟踪** | 在控制台仪表盘中监控用量和成本 |
| **按端点计费** | 不同端点对应不同费用 |
| **去重计费** | 同一资源在 24 小时内多次请求只计费一次 |

在 [开发者控制台](https://console.x.com) 查看当前定价并购买点数。

[了解更多定价信息 →](/zh/x-api/getting-started/pricing)

<div id="team-management">
  ## 团队管理
</div>

<Note>
  团队管理仅适用于**企业账户**。
</Note>

企业账户可以邀请团队成员进行协作：

| 角色 | 权限 |
|:-----|:-------------|
| **Administrator** | 完全访问权限：管理应用、账单和计费、团队成员及角色 |
| **Developer** | 管理自己的应用，对团队应用仅有只读访问权限 |

要邀请团队成员，请在控制台中进入 Team 页面并输入他们的 X 用户名。
