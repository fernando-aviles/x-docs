[Developer Console](https://console.x.com) 是您管理 X API 访问的统一入口。您可以在这里创建应用、生成凭据、监控用量并管理计费——全部在一个地方完成。

<Button href="https://console.x.com">打开 Developer Console</Button>

<div id="getting-started">
  ## 入门
</div>

<Steps>
  <Step title="注册开发者账号">
    前往 [console.x.com](https://console.x.com)，使用你的 X 账号登录，并接受《开发者协议》（Developer Agreement）。
  </Step>

  <Step title="创建你的第一个应用">
    点击 **New App**，并填写名称和描述。系统会为你生成 API 凭证。
  </Step>

  <Step title="保存你的凭证">
    复制并安全保存你的 API Key、API Secret 和 Access Tokens。它们之后将不会再次显示。
  </Step>

  <Step title="开始构建">
    使用你的凭证对 API 请求进行认证。参阅[快速入门指南](/zh/x-api/getting-started/make-your-first-request)。
  </Step>
</Steps>

<Warning>
  **安全地存储凭证。** API key 和 token 在生成时只会显示一次。请使用密码管理器或安全保管库。如果丢失，你需要重新生成它们，旧凭证将会失效。
</Warning>

<div id="billing-credits">
  ## 计费与额度
</div>

X API 采用按使用量计费的额度体系：

| 功能 | 说明 |
|:--------|:------------|
| **无月费** | 只为实际使用付费——无需订阅 |
| **基于额度** | 预先购买额度，调用 API 时按用量扣减 |
| **实时跟踪** | 在控制台仪表板中监控用量和成本 |
| **按端点定价** | 不同端点的费用不同 |
| **去重计费** | 同一资源在 24 小时内被请求两次，只计费一次 |

在 [Developer Console](https://console.x.com) 中查看当前定价并购买额度。

[了解更多定价信息 →](/zh/x-api/getting-started/pricing)

<div id="team-management">
  ## 团队管理
</div>

<Note>
  团队管理功能仅适用于 **企业账户（Enterprise accounts）**。
</Note>

企业账户可以邀请团队成员协同合作：

| 角色 | 权限 |
|:-----|:-------------|
| **Administrator（管理员）** | 完整访问权限：管理应用、账单、团队成员和角色 |
| **Developer（开发者）** | 管理自己的应用，对团队应用具有只读访问权限 |

要邀请团队成员，请在控制台中打开 Team 页面并输入他们的 X 账号（handle）。
