<div id="using-and-generating-an-app-only-bearer-token">
  ### 使用和生成仅 App 的 Bearer 令牌
</div>

Bearer 令牌为开发者提供了一种更安全的方式来使用 X API，并且是 OAuth 2.0 的核心特性之一。 

使用 Bearer 令牌的身份验证也被称为仅应用身份验证（application-only authentication）。Bearer 令牌是一个格式未指定的字节数组，你可以使用类似 `curl` 命令的脚本来生成它。你也可以在开发者控制台中，从你的 App 设置里的 Keys and tokens 部分获取 Bearer 令牌。关于此功能的更多信息可以在 [OAuth 的官方文档](https://oauth.net/2/bearer-tokens/) 中找到。

<div id="when-are-they-used">
  #### 它们在什么情况下使用？
</div>

需要使用 Bearer 令牌的产品包括：

* [Engagement API](/zh/x-api/enterprise-gnip-2.0/fundamentals/engagement-api)
* [Account Activity API](/zh/x-api/enterprise-gnip-2.0/fundamentals/account-activity)
* 其他使用 OAuth 2.0 Bearer 令牌认证的 API，例如 v2 和 Labs 端点。

<div id="prerequisites">
  #### 先决条件
</div>

你需要先[注册一个开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)，并创建一个 [X App](/zh/resources/fundamentals/developer-apps)。完成这些之后，你还需要在[开发者控制台](/zh/resources/fundamentals/developer-portal)中获取 API 密钥。请按照以下步骤操作：

1. 在 developer.x.com 登录你的 X 账号。
2. 进入 [X App dashboard](https://developer.x.com/content/developer-twitter/en/apps)，打开你希望为其生成访问令牌的 X App。
3. 前往 &quot;keys and tokens&quot; 页面。
4. 你可以在该页面找到 API 密钥、用户访问令牌（Access Token）和 Bearer 令牌。

<div id="how-to-generate-a-bearer-token">
  ### 如何生成 Bearer 令牌
</div>

你可以在 App 的“Keys and Tokens”部分找到该 App 的 Bearer 令牌。

在从你的 [X App](/zh/resources/fundamentals/developer-apps) 获取到以下消费者 API 密钥并按需替换后，将下面的 curl 请求复制到命令行中。请注意，本页面中使用的消费者 API 密钥已经停用，不能用于实际请求。

* **API key** `<API key>` 例如 `xvz1evFS4wEEPTGEFPHBog`
* **API secret key** `<API secret key>` 例如 `L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg`

  ```bash
  curl -u "$API_KEY:$API_SECRET_KEY" \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
  ```

下面是一个示例，展示了在填入你的 API 密钥后，该 curl 请求应当是什么样子：

```bash
   curl -u 'xvz1evFS4wEEPTGEFPHBog:L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg' \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
```

以下是响应的示例。请注意，这是一个已停用的 Bearer 令牌：

`{"token_type":"bearer","access_token":"AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F"}`
