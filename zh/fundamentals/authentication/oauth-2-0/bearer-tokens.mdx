<div id="using-and-generating-an-app-only-bearer-token">
  ### 使用和生成仅应用 Bearer Token
</div>

Bearer Token 允许开发者在使用 X API 时拥有更安全的访问入口，并且是 OAuth 2.0 的核心特性之一。 

使用 Bearer Token 的身份验证方式也称为仅应用身份验证（application-only authentication）。Bearer Token 是一种格式未指定的字节数组，你可以使用类似 `curl` 命令的脚本来生成它。你也可以在 Developer Console 的应用设置中，通过 “keys and tokens” 部分获取 Bearer Token。关于此功能的更多信息可以在 [OAuth 的官方文档](https://oauth.net/2/bearer-tokens/) 中找到。

<div id="when-are-they-used">
  #### 它们在什么情况下使用？
</div>

需要使用 Bearer Token 的产品包括：

* [Engagement API](/zh/x-api/enterprise-gnip-2.0/fundamentals/engagement-api)
* [Account Activity API](/zh/x-api/enterprise-gnip-2.0/fundamentals/account-activity)
* 其他使用 OAuth 2.0 Bearer Token 进行身份验证的 API，例如 v2 和 Labs 的端点。

<div id="prerequisites">
  #### 先决条件
</div>

你需要先[注册一个开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)，并创建一个 [X App](/zh/resources/fundamentals/developer-apps)。完成这些之后，你还需要在 [Developer Console](/zh/resources/fundamentals/developer-portal) 中获取 API key。请按照以下步骤操作：

1. 登录你的 X 账号并访问 developer.x.com。
2. 前往 [X App dashboard](https://developer.x.com/content/developer-twitter/en/apps)，打开你希望为其生成访问令牌的 X App。
3. 进入 “keys and tokens” 页面。
4. 你可以在此页面找到 API key、用户访问令牌（Access Tokens）以及 Bearer Token。

<div id="how-to-generate-a-bearer-token">
  ### 如何生成 Bearer Token
</div>

你可以在应用的“Keys and Tokens”部分，与其他密钥一起找到该应用的 Bearer Token。

在命令行中复制以下 cURL 请求，并将其中的 consumer API 密钥替换为你之前从 [X App](/zh/resources/fundamentals/developer-apps) 获取的值。请注意，本页面所使用的 consumer API 密钥已被停用，无法用于真实请求。

* **API key** `<API key>` 例如 `xvz1evFS4wEEPTGEFPHBog`
* **API secret key** `<API secret key>` 例如 `L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg`

  ```bash
  curl -u "$API_KEY:$API_SECRET_KEY" \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
  ```

下面是一个示例，展示在填入你的 API 密钥之后，cURL 请求应类似如下：

```bash
   curl -u 'xvz1evFS4wEEPTGEFPHBog:L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg' \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
```

以下是响应示例。请注意，这是一个已停用的 Bearer Token：

`{"token_type":"bearer","access_token":"AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F"}`

我们用于在 OAuth 2.0 中对资源进行身份验证的 Bearer Token 为：

`AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F`
