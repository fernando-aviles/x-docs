<div id="using-and-generating-an-app-only-bearer-token">
  ### 使用和生成应用级（app-only）Bearer Token
</div>

Bearer Token 为开发者提供了一种更安全的方式来使用 X API，并且是 OAuth 2.0 的核心特性之一。

使用 Bearer Token 的认证也被称为仅应用认证（application-only authentication）。Bearer Token 是一种未指定格式的字节数组，你可以使用类似 curl 命令的脚本来生成它。你也可以在开发者控制台中，通过 App 设置里的 “keys and tokens” 部分获取 Bearer Token。关于此特性的更多信息，请参阅 [OAuth 的官方文档](https://oauth.net/2/bearer-tokens/)。

<div id="when-are-they-used">
  #### 何时会用到它们？
</div>

需要使用 Bearer Token 的产品包括：

* [Engagement API](/zh/x-api/enterprise-gnip-2.0/fundamentals/engagement-api)
* [Account Activity API](/zh/x-api/enterprise-gnip-2.0/fundamentals/account-activity)
* 其他使用 OAuth 2.0 Bearer Token 进行认证的 API，例如 v2 和 Labs 端点。

<div id="prerequisites">
  #### 前提条件
</div>

你需要先[注册一个开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)，并创建一个 [X App](/zh/resources/fundamentals/developer-apps)。完成这些之后，你还需要在[开发者控制台](/zh/resources/fundamentals/developer-portal)中获取 API keys。请按照以下步骤操作：

1. 在 developer.x.com 上登录你的 X 账号。
2. 前往 [X App dashboard](https://developer.x.com/content/developer-twitter/en/apps)，打开你希望为其生成访问令牌的 X App。
3. 进入 “keys and tokens” 页面。
4. 你可以在该页面找到 API keys、用户访问令牌（Access Tokens）以及 Bearer Token。

<div id="how-to-generate-a-bearer-token">
  ### 如何生成 Bearer Token
</div>

你可以在你的应用的“Keys and Tokens”部分找到该应用的 Bearer Token。

将下面的 cURL 请求复制到命令行中，并将其中的 consumer API key 替换为你之前从 [X App](/zh/resources/fundamentals/developer-apps) 获取的值。请注意，本页中使用的 consumer API key 已被弃用，无法用于真实请求。

* **API key** `<API key>` 例如 `xvz1evFS4wEEPTGEFPHBog`
* **API secret key** `<API secret key>` 例如 `L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg`

  ```bash
  curl -u "$API_KEY:$API_SECRET_KEY" \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
  ```

下面是一个示例，展示填入 API key 后的 cURL 请求应如下所示：

```bash
   curl -u 'xvz1evFS4wEEPTGEFPHBog:L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg' \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
```

以下是响应的示例。请注意，这是一个已停用的 Bearer Token：

`{"token_type":"bearer","access_token":"AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F"}`

我们使用 OAuth 2.0 对资源进行认证的 Bearer Token 如下：

`AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F`
