<div id="post-oauthrequest_token">
  ### POST oauth/request_token
</div>

允许 Consumer 应用获取一个 OAuth Request Token 以请求用户授权。此方法对应 [OAuth 1.0 认证流程](http://oauth.net/core/1.0/#anchor9)的[第 6.1 节](https://oauth.net/core/1.0/#auth_step1)。

**所有 OAuth 授权步骤都必须使用 HTTPS。**

**使用说明：** `oauth_nonce` 只接受 ASCII 字符

**资源 URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/request_token`

**资源信息[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| 响应格式 | JSON |
| 是否需要认证？ | 否  |
| 是否有速率限制？ | 是 |

**参数[](#parameters "Permalink to this headline")**

| Name | Required | Description | Example |
| :--- | :--- | :--- | :--- |
| oauth&#95;callback | required | 为符合 OAuth 1.0a，此参数为**必需**。你在此处指定的值将作为用户在批准你的应用访问其账号后被重定向到的 URL。将其设为 `oob` 以启用带 PIN 的带外模式（out-of-band pin mode）。这也是你为桌面 / 移动应用指定自定义回调的方式。无论是否预先注册了回调，在此步骤始终发送一个 `oauth_callback`。<br /><br />我们要求在此端点中使用的任何回调 URL 必须先在 developer.x.com 上的应用设置中完成配置* | `http://themattharris.local/auth.php` `twitterclient://callback` |
| x&#95;auth&#95;access&#95;type | optional | 覆盖应用向用户账号请求的访问级别。支持的值为 `read` 或 `write`。此参数旨在允许开发者注册具备读/写权限的应用，但在合适的场景中仅请求只读访问。 |     |

在[此页面](/zh/resources/fundamentals/developer-apps#callback-urls)了解更多有关如何批准你的回调 URL 的信息。

**请注意** - 如果你已登录 developer.x.com 上的 X 账号，你可以通过 [X 应用仪表板](https://developer.x.com/en/apps)查看并编辑你现有的 [X 应用](/zh/resources/fundamentals/developer-apps)。

**示例请求[](#example-request "Permalink to this headline")**

请求 URL：`POST https://api.x.com/oauth/request_token`

请求 POST 正文：*N/A*

Authorization Header: `OAuth oauth_nonce="K7ny27JTpKVsTgdyLdDfmQQWVLERj2zAK5BslRsqyw", oauth_callback="http%3A%2F%2Fmyapp.com%3A3005%2Ftwitter%2Fprocess_callback", oauth_signature_method="HMAC-SHA1", oauth_timestamp="1300228849", oauth_consumer_key="OqEqJeafRSF11jBMStrZz", oauth_signature="Pc%2BMLdv028fxCErFyi8KXFM%2BddU%3D", oauth_version="1.0"`

响应：`oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik&oauth_token_secret=Kd75W4OQfb2oJTV0vzGzeXftVAwgMnEK9MumzYcM&oauth_callback_confirmed=true`

<div id="get-oauthauthorize">
  ### GET oauth/authorize
</div>

允许 Consumer 应用使用 OAuth Request Token 来请求用户授权。此方法满足 [OAuth 1.0 身份验证流程](http://oauth.net/core/1.0/#anchor9)的 [第 6.2 节](http://oauth.net/core/1.0/#auth_step2) 要求。桌面应用程序必须使用此方法（并且不能使用 [GET oauth / authenticate](/zh/resources/fundamentals/authentication/api-reference#get-oauth-authenticate)）。

**使用说明：** 此方法从不会接收 `oauth_callback`，请改为将其提供给 [POST oauth / request&#95;token](/zh/resources/fundamentals/authentication/api-reference#post-oauth-request-token)。

**资源 URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/authorize`

**资源信息[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| 响应格式 | JSON |
| 是否需要身份验证？ | 是 |
| 是否有速率限制？ | 是 |

**参数[](#parameters "Permalink to this headline")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| 名称 | 必需 | 描述 | 默认值 | 示例 |
| force&#95;login | 可选 | 强制用户输入其凭据，以确保授权的是正确的用户账号。 |     |     |
| screen&#95;name | 可选 | 使用给定值预填充 OAuth 登录界面的用户名输入框。 |     |     |

**示例请求[](#example-request "Permalink to this headline")**

在浏览器中将用户重定向到 `oauth/authorize` 步骤，并包含一个 oauth&#95;token 参数：
`https://api.x.com/oauth/authorize?oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik`

<div id="get-oauthauthenticate">
  ### GET oauth/authenticate
</div>

允许 Consumer 应用程序使用 OAuth `request_token` 来请求用户授权。

对于使用回调认证流程的应用，此方法可替代 [OAuth 1.0 认证流程](http://oauth.net/core/1.0/#anchor9)中的 [第 6.2 节](http://oauth.net/core/1.0/#auth_step2)。除非将 `force_login` 参数设置为 `true`，否则该方法会将当前已登录用户作为进行访问授权的账号。

此方法与 [GET oauth / authorize](/zh/resources/fundamentals/authentication/api-reference#get-oauth-authorize) 的不同之处在于，如果用户已授予应用权限，则会在无需用户重新批准应用的情况下直接重定向。要实现此行为，你必须在你的[应用记录](https://developer.x.com/apps)上启用 *Use Sign in with X* 设置。

**资源 URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/authenticate`

**资源信息[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| 响应格式 | JSON |
| 是否需要认证？ | 是 |
| 是否有速率限制？ | 是 |

**参数[](#parameters "Permalink to this headline")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| 名称 | 必需 | 描述 | 默认值 | 示例 |
| force&#95;login | optional | 强制用户输入其凭证，以确保授权的是正确的用户账号。 |     | *true* |
| screen&#95;name | optional | 预填充 OAuth 登录界面中用户名输入框的值。 |     |     |

**示例请求[](#example-request "Permalink to this headline")**

在浏览器中将用户引导至 `oauth/authenticate` 步骤，并包含 oauth&#95;token 参数：
`https://api.x.com/oauth/authenticate?oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik`

<div id="post-oauthaccess_token">
  ### POST oauth/access_token
</div>

允许一个 Consumer 应用将 OAuth Request Token 交换为 OAuth Access Token。此方法实现了 [第 6.3 节](http://oauth.net/core/1.0/#auth_step3) 中的 [OAuth 1.0 认证流程](http://oauth.net/core/1.0/#anchor9)。

**资源 URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/access_token`

**资源信息[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| 响应格式 | JSON |
| 是否需要身份验证？ | 是 |
| 是否有速率限制？ | 是 |

**参数[](#parameters "Permalink to this headline")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| 名称 | 必需 | 描述 | 默认值 | 示例 |
| oauth&#95;token | 必需 | 这里的 oauth&#95;token 必须与 request&#95;token 步骤中返回的 oauth&#95;token 相同。 |     |     |
| oauth&#95;verifier | 必需 | 如果使用 OAuth 网页流程（web-flow），请将该参数设置为回调 URL 中返回的 *oauth&#95;verifier* 的值。如果使用带外（out-of-band）OAuth，请将该值设置为 PIN 码。为了符合 OAuth 1.0a，此参数是**必需**的。OAuth 1.0a 会被严格执行，未使用 *oauth&#95;verifier* 的应用将无法完成 OAuth 流程。 |     |     |

**请求示例[](#example-request "Permalink to this headline")**

`POST https://api.x.com/oauth/access_token?oauth_token=qLBVyoAAAAAAx72QAAATZxQWU6P&oauth_verifier=ghLM8lYmAxDbaqL912RZSRjCCEXKDIzx`

基于 PIN 的：`POST https://api.x.com/oauth/access_token?oauth_token=9Npq8AAAAAAAx72QBRABZ4DAfY9&oauth_verifier=4868795`

**响应示例[](#example-response "Permalink to this headline")**

`oauth_token=6253282-eWudHldSbIaelX7swmsiHImEL4KinwaGloHANdrY&oauth_token_secret=2EEfA6BG5ly3sR3XjE0IBSnlQu4ZrUzPiYTmrkVU&user_id=6253282&screen_name=xapi`

<div id="post-oauthinvalidate_token">
  ### POST oauth/invalidate_token
</div>

允许已注册的应用通过提供其客户端凭证来撤销已签发的 OAuth `access_token`。一旦某个 `access_token` 被作废，后续新建访问令牌时将生成一个不同的访问令牌，并且已作废的令牌将无法再使用。

**资源 URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/1.1/oauth/invalidate_token`

**资源信息[](#resource-information "Permalink to this headline")**

|           |                            |
| :-------- | :------------------------- |
| 响应格式      | JSON                       |
| 是否需要身份验证？ | 是 - 使用包含你希望使其失效的访问令牌的用户上下文 |
| 是否受速率限制？  | 是                          |

**示例请求[](#example-request "Permalink to this headline")**

```bash
        curl --request POST
          --url 'https://api.x.com/1.1/oauth/invalidate_token.json'
          --header 'authorization: OAuth oauth_consumer_key="CLIENT_KEY",
         oauth_nonce="AUTO_GENERATED_NONCE", oauth_signature="AUTO_GENERATED_SIGNATURE",
         oauth_signature_method="HMAC-SHA1", oauth_timestamp="AUTO_GENERATED_TIMESTAMP",
         oauth_token="ACCESS_TOKEN", oauth_version="1.0"'
```

**示例响应[](#example-response "此标题的固定链接")**

```bash
        HTTP/1.1 200 OK
        Content-Type: application/json; charset=utf-8
        Content-Length: 127
        ...

        {"access_token":"ACCESS_TOKEN"}
```

**令牌失效后的示例错误响应[](#example-error-response-after-token-has-been-invalidated "指向此标题的固定链接")**

```bash
        HTTP/1.1 401 Authorization Required
        ...

        {"errors": [{
          "code": 89,
          "message": "Invalid or expired token."}
        ]}
```

<div id="post-oauth2token">
  ### POST oauth2/token
</div>

允许已注册的应用获取一个 OAuth 2 Bearer Token，它可用于以应用自身的身份在没有用户上下文的情况下发起 API 请求。这称为[仅应用身份验证](/zh/resources/fundamentals/authentication/oauth-2-0/application-only)。

可以使用 oauth2/invalidate&#95;token 使 Bearer Token 失效。一旦 Bearer Token 被失效处理，之后再次创建时将返回一个不同的 Bearer Token，而先前的令牌将不再被允许使用。

对于一个应用，只能存在一个处于有效状态的 Bearer Token，在该令牌被失效之前，对此方法的重复请求将返回同一个已存在的令牌。

成功的响应包含一个 JSON 结构，用于描述颁发的 Bearer Token。

通过此方法获得的令牌应当被缓存。如果尝试过于频繁，请求会被以 HTTP 403 和错误码 99 拒绝。

**资源 URL[](#resource-url "跳转到此标题的永久链接")**

`https://api.x.com/oauth2/token`

**资源信息[](#resource-information "跳转到此标题的永久链接")**

|                          |                                                                                         |
| :----------------------- | :-------------------------------------------------------------------------------------- |
| Response formats         | JSON                                                                                    |
| 响应格式                     | JSON                                                                                    |
| Requires authentication? | Yes - Basic auth with your API key as your username and API key secret as your password |
| 是否需要身份验证？                | 是 - 使用 Basic 身份验证，将你的 API key 作为用户名，将 API key secret 作为密码                               |
| Rate limited?            | Yes                                                                                     |
| 是否受速率限制？                 | 是                                                                                       |

**参数[](#parameters "跳转到此标题的永久链接")**

|      |          |                                                                                                                                 |               |                          |
| :--- | :------- | :------------------------------------------------------------------------------------------------------------------------------ | :------------ | :----------------------- |
| Name | Required | Description                                                                                                                     | Default Value | Example                  |
| Name | 必需       | 指定应用请求的授权类型。目前只允许 *client&#95;credentials*。更多信息请参阅[仅应用身份验证](/zh/resources/fundamentals/authentication/oauth-2-0/application-only)。 |               | *client&#95;credentials* |

**示例请求[](#example-request "跳转到此标题的永久链接")**

```bash
    POST /oauth2/token HTTP/1.1
    Host: api.x.com
    User-Agent: My X App v1.0.23
    Authorization: Basic eHZ6MWV2R ... o4OERSZHlPZw==
    Content-Type: application/x-www-form-urlencoded;charset=UTF-8
    Content-Length: 29
    Accept-Encoding: gzip

    grant_type=client_credentials
```

**示例响应：**

```bash
    HTTP/1.1 200 OK
    Status: 200 OK
    Content-Type: application/json; charset=utf-8
    ...
    Content-Encoding: gzip
    Content-Length: 140

    {"token_type":"bearer","access_token":"AAAA%2FAAA%3DAAAAAAAA"}
```

<div id="post-oauth2invalidate_token">
  ### POST oauth2/invalidate_token
</div>

允许已注册的应用通过提供其客户端凭证来撤销已签发的 OAuth 2.0 Bearer Token。一旦某个 Bearer Token 被作废，后续再次创建时将会得到一个不同的 Bearer Token，而被作废的令牌将不可再使用。

成功的响应会返回一个描述已撤销 Bearer Token 的 JSON 结构。

**资源 URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth2/invalidate_token`

**资源信息[](#resource-information "Permalink to this headline")**

|                          |                                                                                                                                                  |
| :----------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| Response formats         | JSON                                                                                                                                             |
| Requires authentication? | Yes - 使用应用的 consumer API key 以及应用所有者的 access token 和 access token secret，通过 [OAuth 1.0a](/zh/resources/fundamentals/authentication/oauth-1-0a) 进行认证 |
| Rate limited?            | Yes                                                                                                                                              |

**参数[](#parameters "Permalink to this headline")**

| Name             | Required | Description          |
| :--------------- | :------- | :------------------- |
| access&#95;token | 必需       | 要作废的 Bearer Token 的值 |

**示例请求[](#example-request "Permalink to this headline")**

```
        curl --request POST
          --url 'https://api.x.com/oauth2/invalidate_token?access_token=AAAA%2FAAA%3DAAAAAAAA'
          --header 'authorization: OAuth oauth_consumer_key="CLIENT_KEY",
         oauth_nonce="AUTO_GENERATED_NONCE", oauth_signature="AUTO_GENERATED_SIGNATURE",
         oauth_signature_method="HMAC-SHA1", oauth_timestamp="AUTO_GENERATED_TIMESTAMP",
         oauth_token="ACCESS_TOKEN", oauth_version="1.0"'
```

**示例响应[](#example-response "Permalink to this headline")**

```
         Status: 200 OK
         Content-Type: application/json; charset=utf-8
         Content-Length: 135
         ...
       {
        "access_token": "AAAA%2FAAA%3DAAAAAAAA"
        }
```
