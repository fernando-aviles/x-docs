访问 X API 端点必须使用 TLS 连接。通过 TLS 通信可以在数据通过公共互联网在用户与 X API 之间传输时加以保护，从而保障用户的隐私和安全。连接到 X API 必须使用 TLS 1.2 版本。


<div id="verification">
  ## 验证
</div>

<div id="use-an-up-to-date-root-store">
  ### 使用最新的根证书存储
</div>

在验证 X 证书时，让您的应用程序或库使用可信且最新的根证书存储非常重要。在可能的情况下，使用操作系统提供的根证书存储通常是最简单的做法。或者，[Mozilla (NSS) 根证书存储](https://www.mozilla.org/en-US/about/governance/policies/security-group/certs/)以公开透明的方式得到良好维护。cURL 也提供了[该证书存储的 PEM 格式版本](https://curl.haxx.se/docs/caextract.html)。

X 目前的大部分证书由 [DigiCert High Assurance EV Root CA](https://www.digicert.com/digicert-root-certificates.htm) 签发，但这并不适用于 100% 的 X 相关证书，将来也可能会发生变化，因此如果只信任当前正在使用的 DigiCert 根证书，将来可能会导致您的应用出现问题。

<div id="check-crls-and-the-ocsp-status">
  ### 检查 CRL 和 OCSP 状态[](#check-crls-and-the-ocsp-status "Permalink to this headline")
</div>

许多应用程序不会检查返回证书的证书吊销列表（CRL），或者依赖操作系统来执行此操作。请确保你的应用程序或 TLS 库配置为在接受 X 的证书之前，强制执行 CRL 和 OCSP（在线证书状态协议）验证。

<div id="cdns">
  ### CDNs[](#cdns "Permalink to this headline")
</div>

在展示包含媒体内容的推文时，请使用 `media_url_https` 属性来获取用于展示图片的 HTTPS URL。今后，通过 API 端点提供的所有 URL 都将使用 HTTPS 路径。

<div id="provide-an-indication-of-security-status">
  ## 提供安全状态指示
</div>

如果可能，您应当显示您的应用与 X 之间当前安全状态的指示。一些网页浏览器会通过显示锁形图标来体现这一点，而其他浏览器则通过描述性消息来指示当前连接状态。
