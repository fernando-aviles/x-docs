要访问 X API 端点，必须使用 TLS 加密连接。通过 TLS 通信可以在数据穿越公共互联网时保护用户与 X API 之间的信息，从而保障用户隐私和安全。与 X API 的连接需要使用 TLS 1.2 版本。


<div id="verification">
  ## 验证
</div>

<div id="use-an-up-to-date-root-store">
  ### 使用最新的根证书存储
</div>

在验证 X 证书时，确保你的应用或库使用可信且最新的根证书存储非常重要。在可能的情况下，使用操作系统提供的根证书存储通常是最简单的做法。或者，[Mozilla (NSS) 根证书存储](https://www.mozilla.org/en-US/about/governance/policies/security-group/certs/) 也以公开透明的方式进行良好维护。curl 还提供了[一个 PEM 格式的该证书存储版本](https://curl.haxx.se/docs/caextract.html)。

X 目前的大部分证书由 [DigiCert High Assurance EV Root CA](https://www.digicert.com/digicert-root-certificates.htm) 签发，但这并不适用于 100% 的 X 相关证书，且未来也不一定始终如此，因此如果只信任当前使用的 DigiCert 根证书，将来可能会导致你的应用出现问题。

<div id="check-crls-and-the-ocsp-status">
  ### 检查 CRL 和 OCSP 状态[](#check-crls-and-the-ocsp-status "Permalink to this headline")
</div>

许多应用程序不会检查所返回证书的证书吊销列表（CRL），或者依赖操作系统来执行此检查。请确保你的应用程序或 TLS 库已配置为在接受 X 的证书之前强制进行 CRL 和 OCSP（Online Certificate Status Protocol，在线证书状态协议）验证。

<div id="cdns">
  ### CDNs[](#cdns "此标题的永久链接")
</div>

当展示包含媒体的推文时，应使用 `media_url_https` 属性提供的 HTTPS URL 来显示图像。未来，通过 API 端点提供的所有 URL 都将支持 HTTPS 路径。

<div id="provide-an-indication-of-security-status">
  ## 提供安全状态指示
</div>

如果可能，你应当显示你的应用与 X 之间当前安全状态的指示。一些 Web 浏览器通过显示锁形图标来表示这一点，而其他浏览器则通过描述性消息来指示当前的连接状态。
