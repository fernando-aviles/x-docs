<div id="general">
  ## 常规
</div>

<AccordionGroup>
  <Accordion title="什么是 OAuth？">
    OAuth 是一种身份验证协议，允许用户在不共享密码的情况下授权应用代表其执行操作。更多信息请参见 [oauth.net](http://oauth.net/)。
  </Accordion>

  <Accordion title="我如何生成访问令牌？">
    要生成访问令牌，你必须拥有一个 [X app](/zh/resources/fundamentals/developer-apps)。关于访问令牌的更多信息，请参见[此处](/zh/resources/fundamentals/authentication#oauth-1-0a-2)。 
  </Accordion>

  <Accordion title="我如何创建一个 X app？">
    你必须拥有一个[开发者账号](/zh/resources/fundamentals/developer-portal) 才能创建 [X app](/zh/resources/fundamentals/developer-apps)。你可以在[此处](https://developer.x.com/en/portal/petition/essential/basic-info)注册。
  </Accordion>

  <Accordion title="如果我已经有一个 X app，该如何查看和编辑这个应用？">
    如果你已在 developer.x.com 登录你的 X 账号，可以在 [X app dashboard](https://developer.x.com/content/developer-twitter/en/apps) 查看和编辑你的应用。
  </Accordion>
</AccordionGroup>

<div id="technical">
  ## 技术
</div>

<AccordionGroup>
  <Accordion title="访问令牌的有效期是多长时间？">
    访问令牌没有明确的过期时间。如果用户在其 X 账户设置中明确撤销了某个应用，或者 X 暂停了某个应用，则该访问令牌将失效。如果某个应用被暂停，在 [X app](/zh/resources/fundamentals/developer-apps) 仪表板中会有一条说明，指出该应用已被暂停。
  </Accordion>

  <Accordion title="如果访问令牌变为无效怎么办？">
    你应当假设用户的访问令牌在任何时候都 *可能* 变为无效。如果发生这种情况，提示用户重新授权该应用。妥善处理这种情况对于提供良好的用户体验非常重要。
  </Accordion>

  <Accordion title="应用注册页面询问读/写访问权限。什么算作写入？">
    许多用户愿意信任应用读取他们的信息，但未必愿意让应用更改其用户资料信息或发布新的帖子。通过 X API 更新信息——无论是名称、位置还是添加新的帖子——都需要发起 HTTP POST 请求。任何需要 HTTP POST 的 API 方法都被视为写入方法，并且需要读写访问权限。
  </Accordion>
</AccordionGroup>
