<div id="basic-authentication">
  ## 基本身份验证
</div>

许多 X 的企业级 API 需要使用 HTTP Basic Authentication。要向需要 Basic Authentication 的 API 发出请求并获得成功响应，你必须在每个请求中通过授权头传入有效的电子邮箱地址和密码组合。该邮箱和密码组合与用于访问 [enterprise API console](https://console.gnip.com/) 时使用的相同，并且可以在该控制台中进行编辑。

在使用 Basic Authentication 构建请求时，确保通过 HTTPS 添加带有编码后凭证的 `Authentication: Basic` HTTP 头。

在下面的 cURL 请求示例中，你需要在发送请求之前，将 `<email_address>` 和 `<password>` 替换为你的凭证：

```bash
curl -v --compressed -u<email_address>:<password>
    "https://gnip-api.x.com/search/30day/accounts/<account-name>/prod/counts.json?query=from%3Axdevelopers"
```

**需要基本认证的 API：**

* [PowerTrack API](/zh/x-api/enterprise-gnip-2.0/powertrack-api) 企业版
* [Decahose stream API](http://localhost:3000/x-api/enterprise-gnip-2.0/fundamentals/decahose-api) 企业版
* [30-Day Search API](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api) 企业版
* [Full-Archive Search API](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api) 企业版
* [Usage API](/zh/x-api/enterprise-gnip-2.0/fundamentals/usage) 企业版
