<Update label="Aug 3, 2022" description="X API v2">
  ### 新增过滤运算符别名

  在企业版、专业版以及 v2 的搜索和 filtered stream 端点中，新增了过滤/查询运算符“别名”。在许多情况下，该运算符指代的是帖子而不是状态，例如，将 &quot;in&#95;reply&#95;to&#95;tweet&#95;id&quot; 作为 &quot;in&#95;reply&#95;to&#95;status&#95;id&quot; 的别名。在其他情况下，新的运算符别名可以让匹配行为更加清晰。例如，由于帖子只能包含一个视频附件，因此为 &quot;has:videos&quot; 新增了一个 &quot;has:video&#95;link&quot; 别名。查看 [v2 filtered stream 运算符表](https://developer.x.com/en/docs/twitter-api/tweets/filtered-stream/integrate/build-a-rule#list)以获取更多示例。
</Update>

<Update label="Dec 14, 2021" description="X API v2：身份验证">
  ### 支持 OAuth 2.0 身份验证

  从今天起，所有开发者都可以在 Developer Console 中选择 OAuth 2.0 作为身份验证方法来进行身份验证。我们在本次发布中新增了对机密客户端和公共客户端的支持，并为所有相关的 v2 端点提供了使用此身份验证方法的能力。

  OAuth 2.0 是行业标准的授权协议，可让开发者对应用的作用域拥有更多控制，并改进跨多设备的授权流程。换句话说，为 X 上的用户构建应用的开发者将对其 App 向用户请求的信息拥有更多控制权，因此你只需向终端用户请求你所需要的数据和信息。

  这一现代授权协议将使你能够为终端用户提供更精简的授权同意流程，用于授权你的应用，并且只展示你向他们请求的特定作用域。

  如需了解有关此次发布的更多信息，请访问我们的论坛公告。
</Update>

<Update label="Nov 15, 2021" description="X API v2：早期访问">
  ### X API v2 的重大平台更新

  **重大平台更新：X API v2 现已成为主要版本，新增 Essential 和 Elevated 访问级别，以及政策变更**

  今天，我们宣布 X API v2 现已成为 X API 的主要版本。我们已经在 X API v2 中发布了足够多的端点和功能，能够满足 90% 现有基于 X API 构建的 App 的需求。

  为了进一步改进 X API v2 的开发者体验，我们今天发布了以下变更：

  * 对 API 提供快速且免费的 Essential 访问，以及对使用场景已获批准的开发者提供免费的 Elevated 访问。关于这些访问级别，我们在 “About the X API” 页面上提供了更多详细信息。

  * 我们正在移除 Developer Policy 中限制你如何使用 X 的核心功能进行构建、以及限制你的应用可支持用户数量的相关措辞。

    * 我们正在开放平台，以鼓励你构建工具和产品，使 X 更加优秀、更健康，并扩展公共对话。[查看我们希望你构建的解决方案列表](https://developer.x.com/en/docs/twitter-api/what-to-build)。

    * 具体来说，我们移除了限制复刻 X 体验的条款，其中包括 X 的核心功能，以及要求获得许可才能拥有大量用户令牌的条款。

    * 我们知道，构建帮助 X 上人们的解决方案，往往意味着开发者必须构建（或复刻）X 上已经提供的一些功能。我们对 Developer Policy 所做的这些更改旨在为开发者生态提供更清晰的指引，并提供一个开放的 API 平台，使开发者更容易构建、创新，并对公共对话产生影响。

  在我们的[论坛帖子](https://devcommunity.x.com/t/ushering-in-a-new-era-for-the-twitter-developer-platform-with-the-twitter-api-v2/162087)中，我们对这次发布以及此前引领到这一时刻的 X API 发布做了更为详细的介绍。

  除了查看更早的更新日志条目之外，我们还整理了一些关键资源，供你审阅以了解迄今为止 X API v2 已发布的全部内容：

  * [X API 端点映射](/zh/x-api/migrate/x-api-endpoint-map)

  * [About the X API](/zh/x-api/getting-started/about-x-api)

  ### 流式端点的可靠性功能

  今天，我们为 X API v2 的过滤流和采样流发布了两个流式可靠性功能：回填（backfill）和冗余连接，这些功能现已在 Academic Research 产品线上提供。

<Update label="Dec 18, 2020" description="适用于 X API v2 的会话回复设置帖子字段">
  ### 新增回复设置字段

  今天，我们在帖子对象中新增了一个名为 `reply_settings` 的字段。该字段适用于所有返回帖子的 X API v2 端点，包括帖子查询、隐藏回复、最近搜索、采样流、过滤流、关注查找、用户帖子时间线和用户提及时间线端点，或通过在任意端点中[扩展](/zh/x-api/fundamentals/expansions)帖子对象获取。

  该字段表示帖子作者允许谁回复其帖子，可以是所有人、仅帖子中提及的人，或是其关注的人。`reply_settings` 字段返回的字段值包括 `everyone`、`mentionedUsers` 和 `following`。如果帖子未设置会话控制，该字段仍会出现在帖子对象中，其字段值为 `everyone`。
</Update>

<Update label="Jan 21, 2020" description="X API：标准版 v1.1">
  ### 对访问令牌管理的更改

  今天，我们对在 [developer.x.com 上的应用程序仪表板](https://developer.x.com/content/developer-twitter/en/apps)中展示和管理访问令牌（Access Tokens）与访问令牌密钥（Access Token Secrets）的方式进行了更改。

<Update label="Nov 14, 2017" description="X API: Premium v1.1">
  ### Premium API 上线

  发布了 Premium API。

  这些全新的 API 构建在我们企业级数据平台的高质量和高稳定性之上，并通过分级定价模式向更广泛的用户开放。你现在首次可以搜索最近 30 天的帖子（而不是标准端点上仅提供的 7 天数据），并且还可以选择访问我们的高级增强功能，如个人资料地理信息、URL 展开以及投票数据。以下是部分新功能：

  * 每个请求可获取更多帖子（Sandbox + Premium）

  * 更加丰富的查询语言，支持更复杂的查询（Sandbox + Premium）

  * 返回帖子时间序列计数的 counts 端点（Premium）

  * 元数据增强，例如展开后的 URL 和个人资料地理信息（Profile Geo）（Premium）

  在我们的[博客](https://blog.x.com/developer/en_us/topics/tools/2017/introducing-twitter-premium-apis.html)中了解此版本的更多信息。
</Update>
