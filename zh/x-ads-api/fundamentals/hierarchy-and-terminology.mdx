要在使用 Ads API 时取得良好效果，了解 X Ads 中各类实体之间的关系至关重要。本教程将介绍 X Ads 对象层级结构的基础知识。

![X Ads API 层级结构](/images/adsapi-heirarchy.png.twimg.1920.png)

<div id="ad-group-line-items">
  ## 广告组（line items）
</div>

广告组在 Ads API 中称为 [广告单元（line items）](https://developer.x.com/content/developer-twitter/en/docs/tutorials/ads-api-hierarchy-terminology#line-items)，隶属于广告活动，用于针对一组 X 用户进行定向投放和竞价。广告主通过将帖子或媒体（例如作为 In-stream 广告投放的视频）与广告单元关联来进行推广。另请参阅广告组。

<div id="account-media">
  ## 账户媒体
</div>

一组已作为[账户媒体](/zh/x-ads-api/creatives#account-media)上传到广告账户的创意素材集合，其中可以包括推广视频[前贴片资产](/zh/x-ads-api/campaign-management#video-views-preroll-objective)（也称为流内广告），以及可在 [X Audience Platform](https://developer.x.com/content/developer-twitter/en/docs/ads/measurement/overview/twitter-audience-platform) 上进行推广的图片。

<div id="ads-accounts">
  ## 广告账户
</div>

在 X Ads 的层级结构中，处于最顶层的是广告账户。一个广告账户可以由多个 X 用户管理。@Furni（我们的家具店演示账号）就是管理广告账户的一个示例用户。我们通过 account&#95;id 来标识广告账户，该字段是一个 [base36](https://en.wikipedia.org/wiki/Base36) 字母数字字符串。

在每个账户下，我们会存储若干可以在不同广告系列中复用的实体类型，例如可用于定向的定制受众、账户媒体（视频或图片），以及卡片（可以添加到帖子中的扩展创意素材）。

<div id="amplify-video">
  ## Amplify 视频
</div>

在上传视频资产时，上传方可以为视频指定一个类别（例如，推文视频、推文 Gif、推文图片以及 Amplify 视频）。当尝试上传将作为流内广告投放的视频时，必须使用 Amplify 视频类别。此类视频需要经过特殊处理以确保可以投放，因此媒体类别必须设置为 Amplify 视频。

<div id="analytics">
  ## Analytics
</div>

Analytics 指标可帮助合作伙伴和广告主了解他们在 X 上推广内容的效果。这包括展示次数、点击量、视频观看次数和广告支出等信息。此外，合作伙伴和广告主还能获取其触达受众中各细分群体的详细指标。

Ads API 支持两种获取详细广告系列效果指标的方式：同步和异步。

使用[同步 Analytics](/zh/x-ads-api/analytics#synchronous-analytics) 请求时，请求的指标会在响应中返回。同步端点支持较短的时间跨度，非常适合查询实时广告系列效果。

使用[异步 Analytics](/zh/x-ads-api/analytics#asynchronous-analytics) 端点时，请求的指标会在关联的 “job” 完成处理后，通过可下载的结果文件提供。异步端点支持在更长的时间跨度内请求指标，允许返回细分数据，并用于获取大规模数据——非常适合生成报表或进行历史数据回填。

<div id="campaigns">
  ## 广告活动
</div>

广告主投放的每个广告活动都必须在一个现有的资金工具下创建。通过广告活动，你可以定义广告活动的名称、投放日程和预算等内容。继续以 Furni 为例，我们可以创建一个名为 “Furni home decor” 的广告活动。

需要注意的是，一个广告帐户最多只能有 200 个处于活动状态的广告活动；该上限可以由广告主的客户经理提高。在到达结束时间或预算用尽之前，广告活动都被视为处于活动状态。已暂停的广告活动在广告活动数量限制的计算中仍然视为活动广告活动。

<div id="cards">
  ## 卡片
</div>

卡片提供了一种方式，可以以可视化形式扩展推文，使其包含图片、视频或 UI 元素。Ads API 支持多种可用于推文的卡片类型，这些推文随后可以在广告活动中投放推广。

<div id="creatives">
  ## 创意素材
</div>

广告主可以在包含创意素材（如图片、GIF 和视频）的广告活动中推广推文。这些创意素材可以与 X 卡片关联，使推文能够附加丰富的照片、视频和媒体体验。创意素材也可以直接附加到推文上。例如，你可以同时包含文本和视频（或最多 3 张图片），创建一条推广推文。

每个 line item（广告项目）至少需要关联一个创意素材才能投放。可用的创意素材选项包括：用于获取新关注者的 Promoted Accounts（推广帐号）、适用于 TX Audience Platform 上各类 line item 的媒体创意素材（例如图片或视频），以及 Promoted Posts（推广帖子）等。

<div id="funding-instruments">
  ## 资金工具
</div>

在广告账户下还有资金工具，即广告主为使用 X Ads 而配置的不同资金来源。这些资金来源可以是广告主与 X 签署的插单，也可以是绑定在账户上的信用卡等。

<div id="line-items">
  ## 广告组（Line Items）
</div>

在一个广告活动中，你可以有一个或多个广告组，在 Ads API 中也称为 line items。可以将 line items 理解为广告活动的不同细分部分，每个都有自己的一套定向设置和各自的创意素材。包含多个 line items 的广告活动通常被称为“广告组广告活动”（ad group campaigns）。

在单个广告活动中使用多个 line items 的一个好处是，你可以创建更加多样化的定向与创意组合。

在我们的“Furni home decor”广告活动下，我们可能想要创建两个 line items：一个可以是“Home buyers in San Francisco”，另一个可以是“Home buyers in London”。

每个广告活动最多允许包含 100 个 line items，而一个广告账户在所有广告活动中合计最多可以有 4,000 个处于活动状态的 line items。

<div id="mobile-app-promotion-map">
  ## 移动应用推广（MAP）
</div>

移动应用推广（Mobile App Promotion，简称 MAP）是一套产品组合，使广告主能够通过 X 推广移动应用，包括应用安装、转化和再互动。

<div id="mobile-app-conversion-tracking-mact">
  ## 移动应用转化跟踪（MACT）
</div>

X 移动应用推广成效衡量功能允许广告主跟踪在 X 上投放的、旨在推动应用安装或其他应用内转化的广告活动效果。X 的移动测量合作伙伴使广告主能够管理他们希望从在 X 上推广的应用中跟踪哪些转化。MACT 概览

<div id="media-library">
  ## 媒体库
</div>

Media Library 端点用于管理 X Ads 账户中的图片、GIF 和视频。库中的媒体素材可用于帖子和卡片创建，也可以在多个创意中重复使用，从而无需多次上传相同素材。

<div id="promoted-accounts">
  ## 推广账号
</div>

推广账号（粉丝广告活动）属于“推荐关注”功能的一部分，“推荐关注”会向用户推荐他们当前尚未关注但可能感兴趣的账号。推广账号可以向用户介绍更多他们可能喜欢的各类账号。

推广账号使广告主能够推广其账号，并在 X 上扩大受众群体。粉丝广告活动会在 X 平台的多个位置展示——包括主页时间线、“推荐关注”和搜索结果——这些推荐会标记为“推广”，以便与其他推荐账号区分开来。

<div id="promotable-users">
  ## 可推广用户
</div>

每个 X Ads 账号都可以拥有一个或多个可推广用户，即我们可以通过该广告账号进行推广的用户。Furni 的 @Furni 账号就是 Furni 广告账号下的一个 FULL 可推广用户示例，这意味着我们可以为 @Furni 及其推文投放所有类型的广告活动。一个广告账号只能有一个 FULL 可推广用户。

注意，一个广告账号下还可以有其他可推广用户。例如，如果我们想推广 @Jack 发布的关于 Furni 产品的推文，他将在该账号下成为仅限转推的可推广用户，并用 RETWEETS&#95;ONLY 标示。广告主应联系其 X 客户经理，了解将转推用户添加到其广告账号的相关信息。

<div id="promoted-video">
  ## 推广视频
</div>

推广视频是由广告主付费投放在推广推文中的视频。这类视频会出现在首页时间线、X 上搜索结果的顶部以及平台的其他位置，并且会被清晰地标记为“推广”。

<div id="publisher-network">
  ## 发布商网络
</div>

请参阅 [X Audience Platform](/zh/x-ads-api/audiences)。

<div id="scheduled-tweets">
  ## 预定推文
</div>

预定推文允许广告主或用户创建一条推文，并安排在稍后时间发布。除了能够创建和管理这些推文之外，API 还允许将这些推文与广告单元（line item）关联，以便在推文发布后进行推广。这使广告主可以提前创建原生推文，并在任何关键活动之前规划他们的广告素材。例如，可以预先创建一条推文创意，使其在新品发布公告发出的同时立即上线。

<div id="segmentation">
  ## 细分
</div>

细分功能允许合作伙伴和广告主按特定定向值（例如年龄、设备或语言）划分并获取指标数据，并且仅可通过我们的异步分析端点使用。要请求细分指标，请使用 `segmentation_type` 请求参数。有关细分选项的更多详细信息，请参阅 Metrics and Segmentation。

<div id="tailored-audience-list">
  ## Tailored Audience - 列表
</div>

基于列表的 Tailored Audience 是三种 Tailored Audience 之一，通过上传包含您自己的用户和客户 data 的文件创建。您的列表会与 X 上的用户进行匹配，使您可以在广告投放活动中直接定向触达这些用户。请查看这些限制条件。

<div id="tailored-audience-web">
  ## 定向受众 - Web
</div>

来自 Web 的定向受众是三种定向受众类型之一，由访问过你网站的 X 用户组成。要使用来自 Web 的定向受众，你必须在你的网站上安装我们的 X 像素代码，或使用我们认可的标签管理器合作伙伴之一。请查看相关限制条件。

<div id="targeting-criteria">
  ## 定向条件
</div>

如前所述，定向条件是与广告单元（line item）关联的。我们提供多种定向方式可供使用，从位置、关键词和性别到更精细的属性，例如用户行为和兴趣。对于“Home Buyers in San Francisco”这个广告单元，我们可能会将“home buying”行为与“San Francisco”位置一同作为定向条件。

如需了解可用的不同定向类型，请访问我们开发者网站上的 Targeting Overview 页面。

<div id="twitter-object-nest-ton">
  ## Twitter Object Nest (TON)
</div>

Twitter Object Nest (TON) 用于存储通过 Media Upload 端点上传的媒体及各类素材，以供用作创意内容（Creatives）。
