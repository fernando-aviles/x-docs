要在 Ads API 取得成功，了解 X Ads 中各个实体之间的关系非常重要。本教程将介绍 X Ads 对象层级结构的基础知识。

![X Ads API 层级结构](/images/adsapi-heirarchy.png.twimg.1920.png)

<div id="ad-group-line-items">
  ## 广告组（line items）
</div>

广告组（在 Ads API 中称为[line items](https://developer.x.com/content/developer-twitter/en/docs/tutorials/ads-api-hierarchy-terminology#line-items)）隶属于广告活动，用于针对一组 X 用户进行定向和出价。广告主通过将帖子或媒体内容（例如以 In-stream 广告形式投放的视频）与某个 line item 关联来进行推广。另见 Ad Group。

<div id="account-media">
  ## 账号媒体
</div>

一组已作为[账号媒体](/zh/x-ads-api/creatives#account-media)上传到某个广告账号的创意素材集合，其中可以包括推广视频[前贴片素材](/zh/x-ads-api/campaign-management#video-views-preroll-objective)（也称为流内广告），以及可在 [X Audience Platform](https://developer.x.com/content/developer-twitter/en/docs/ads/measurement/overview/twitter-audience-platform) 上进行推广的图片。

<div id="ads-accounts">
  ## 广告账户
</div>

位于 X Ads 层级结构最顶层的是广告账户。一个广告账户可以由多个 X 用户管理。@Furni，我们的家具店演示账号，就是一个管理广告账户的用户示例。我们通过 account&#95;id 来标识广告账户，它是一个由字母和数字组成的 [base36](https://en.wikipedia.org/wiki/Base36) 字符串。

在每个账户下，我们保存了一些可在多个广告系列之间复用的实体类型，例如可用于定向的定制受众、作为账户媒体的视频或图片，以及卡片，这是一种可以添加到帖子中的扩展创意素材。

<div id="amplify-video">
  ## Amplify 视频
</div>

在上传视频素材时，上传方可以为视频定义一个类别（例如，Tweet Video、Tweet Gif、Tweet Image 和 Amplify Video）。当你要上传用于流内广告投放的视频时，必须使用 Amplify 视频这一类别。这类视频需要特殊处理以确保可以被正常投放，因此媒体类别必须设置为 Amplify 视频。

<div id="analytics">
  ## Analytics
</div>

Analytics 指标可帮助合作伙伴和广告主了解他们在 X 上推广内容的表现。这其中包括展示次数、点击量、视频观看次数以及花费等信息。此外，合作伙伴和广告主还能获取其触达受众中各类细分群体的详细指标。

Ads API 支持两种获取详细广告活动表现指标的方式：同步和异步。

使用 [同步 analytics](/zh/x-ads-api/analytics#synchronous-analytics) 请求时，请求的指标会在响应中返回。同步端点支持较短的时间范围，非常适合用于查询广告活动的实时表现。

使用 [异步 analytics](/zh/x-ads-api/analytics#asynchronous-analytics) 端点时，请求的指标会在关联的 “job” 处理完成后，以可下载结果文件的形式提供。异步端点支持在更长的时间范围内请求指标，允许返回按细分维度划分的数据，并用于获取规模更大的数据——非常适合用于生成报表或进行历史数据回填。

<div id="campaigns">
  ## 广告系列
</div>

广告主投放的每个广告系列都必须在现有的资金工具下创建。通过广告系列，你可以定义广告系列的名称、投放时间和预算等内容。继续以 Furni 为例，我们可以创建一个名为 “Furni home decor” 的广告系列。

需要注意的是，一个广告账户最多只能拥有 200 个处于活动状态的广告系列；该上限可以由广告主的客户经理上调。广告系列在到达结束时间或其预算耗尽之前，都被视为处于活动状态。已暂停的广告系列在计算广告系列数量时仍然被视为活动广告系列。

<div id="cards">
  ## 卡片
</div>

卡片是一种可视化扩展推文的形式，可加入图片、视频或 UI 元素。Ads API 支持多种可用于推文的卡片类型，这些卡片随后可以在广告系列中进行推广。

<div id="creatives">
  ## 创意素材
</div>

广告主可以在包含创意素材（如图片、GIF 和视频）的广告活动中推广推文。这些创意素材可以与 X 卡片关联，为推文附加丰富的照片、视频和媒体体验。创意素材也可以直接附加到推文中。例如，你可以包含文本和视频（或最多 3 张图片），并创建一条推广推文。

每个广告项目都需要至少关联一个创意素材才能投放。可用的创意素材选项包括用于获取新粉丝的推广账号、适用于 TX Audience Platform 中各类广告项目的媒体创意素材（如图片或视频），或者推广帖子。

<div id="funding-instruments">
  ## 资金工具
</div>

在广告账户下还有资金工具，即广告主为在 X Ads 中使用而配置的不同资金来源。这些资金来源可以是他们与 X 签署的插播订单，也可以是绑定在账户上的信用卡等。

<div id="line-items">
  ## 广告组（Line Items）
</div>

在一个广告系列中，你可以拥有一个或多个广告组，在 Ads API 中也称为 line items。可以将广告组理解为广告系列中的不同细分单元，每个单元都有自己的一套定向设置和自己的创意素材。包含多个广告组的广告系列通常被称为“广告组广告系列”（ad group campaigns）。

在同一广告系列中包含多个广告组的好处之一，是你可以创建更多样化的定向与创意组合。

在我们的 “Furni 家居装饰” 广告系列下，我们可能想创建两个广告组：一个可以是“旧金山的购房者”，另一个可以是“伦敦的购房者”。

每个广告系列最多允许 100 个广告组，一个广告账户在所有广告系列中合计最多只能有 4,000 个处于启用状态的广告组。

<div id="mobile-app-promotion-map">
  ## 移动 App 推广（MAP）
</div>

Mobile App Promotion（移动 App 推广，简称 MAP）是一套产品组合，让广告主能够通过 X 平台推广移动 App，包括 App 安装、转化和重新触达。

</div>

<div id="media-library">
  ## 媒体库
</div>

媒体库端点支持管理 X Ads 帐户中的图片、GIF 和视频。库中的媒体素材可以用于帖子并用于创建卡片，也可以在多个创意中复用，从而无需重复上传同一素材。

<div id="promoted-accounts">
  ## 推广帐号
</div>

推广帐号（粉丝广告系列）是“可能感兴趣的人”功能的一部分，该功能会向用户推荐他们当前尚未关注但可能感兴趣的帐号。推广帐号有助于帮助用户发现更多他们可能喜欢的各类帐号。

推广帐号允许广告主推广自己的帐号并在 X 上扩大受众。粉丝广告系列会在 X 平台的多个位置展示——包括首页时间线、“可能感兴趣的人”和搜索结果——这些推荐会带有“推广”标识，以便与其他推荐帐号区分开来。

<div id="promotable-users">
  ## 可推广用户
</div>

每个 X Ads 账户都可以有一个或多个可推广用户，也就是我们可以通过该广告账户进行推广的用户。Furni 的 @Furni 账号就是 Furni 广告账户下 FULL 可推广用户的一个示例，这意味着我们可以为 @Furni 以及其推文投放所有类型的广告活动。一个广告账户只能有一个 FULL 可推广用户。

请注意，在一个广告账户下还可以有其他类型的可推广用户。比如，如果我们想要推广 @Jack 发布的关于 Furni 产品的推文，他将在该账户下成为仅限转推的可推广用户，用 `RETWEETS_ONLY` 表示。广告主应联系其 X 客户经理，了解向其广告账户添加转推用户的相关信息。

<div id="promoted-video">
  ## 推广视频
</div>

推广视频是指由广告主付费投放在推广推文中的视频。这些视频会出现在主页时间线、X 的搜索结果顶部以及平台上的其他位置，并会被清晰地标注为“Promoted”（推广）。

<div id="scheduled-tweets">
  ## 定时推文
</div>

定时推文允许广告主或用户创建一条推文，并安排其在未来某个时间发布。除了能够创建和管理这些推文之外，API 还允许将这些推文与某个 line item 关联，以便在推文发布后对其进行推广。这样一来，广告主就可以预先创建原生推文，并在任何关键活动之前提前规划其广告创意。例如，预先设置某条推文创意，使其在新产品发布公告的那一刻立即上线。

<div id="segmentation">
  ## 细分
</div>

细分功能允许合作伙伴和广告主按特定定向维度（例如年龄、设备或语言）拆分并获取指标数据，并且仅可通过我们的异步分析端点使用。要请求细分指标，请使用 `segmentation_type` 请求参数。有关细分选项的更多详细信息，请参阅“Metrics and Segmentation”。

<div id="tailored-audience-list">
  ## 定向受众 - 列表
</div>

来自列表的定向受众是三种定向受众类型之一，通过上传包含您拥有的用户和客户数据的文件创建。您的列表会与 X 上的用户进行匹配，从而使您可以在广告活动中直接定向触达这些用户。请查看这些限制条件。

<div id="tailored-audience-web">
  ## 定制受众 - Web
</div>

来自 Web 的定制受众（Tailored Audience from web）是三种定制受众类型之一，由访问过你网站的 X 用户构成。要使用来自 Web 的定制受众，你必须在你的网站上安装我们的 X pixel，或使用我们认可的标签管理合作伙伴之一。请查看相关限制。

<div id="targeting-criteria">
  ## 定向条件
</div>

如前文所述，定向条件是与广告单元（line item）关联的。我们提供多种不同的定向方式供你使用，从位置、关键词和性别，到更细粒度的属性，如用户行为和兴趣等。对于 “Home Buyers in San Francisco” 这一广告单元，我们可能会将 “home buying” 行为与 “San Francisco” 位置一起作为定向条件。

有关可用不同定向类型的详细信息，请访问我们开发者站点上的 Targeting Overview 页面。
