沙盒是一个用于测试和构建你的 Ads API 集成实现的环境。

通过沙盒创建的 Campaign 不会向用户投放，你也可以为 Funding Instruments 等对象动态创建测试记录。

使用沙盒就像调用 ads-api-sandbox.x.com 的相应主机名一样简单，但它还包含一些仅在沙盒中才有的独特功能。

首先向 [POST accounts](/zh/x-ads-api/campaign-management#post-accounts) 发起请求以创建新的广告主账号。此调用的响应将包含一个可用于后续请求的 `account_id`。这些端点使开发者可以创建多个广告主账号并针对其进行测试。

<div id="sandbox-only-endpoint-list">
  ### Sandbox 专用端点列表：
</div>

* [POST accounts](/zh/x-ads-api/campaign-management#post-accounts) 在 Sandbox 中创建账户
* [POST accounts/:account&#95;id/features](/zh/x-ads-api/campaign-management#post-accounts-account-id-features) 在 Sandbox 中为账户添加功能
* [POST accounts/:account&#95;id/funding&#95;instruments](/zh/x-ads-api/campaign-management#post-accounts-account-id-funding-instruments) 在 Sandbox 中为账户添加资金工具
* [DELETE accounts/:account&#95;id](/zh/x-ads-api/campaign-management#delete-accounts-account-id) 在 Sandbox 中删除账户
* [DELETE accounts/:account&#95;id/features](/zh/x-ads-api/campaign-management#delete-accounts-account-id-features) 在 Sandbox 中删除账户功能
* [DELETE accounts/:account&#95;id/funding&#95;instruments/:funding&#95;instrument&#95;id](/zh/x-ads-api/campaign-management#delete-accounts-account-id-funding-instruments-funding-instrument-id) 在 Sandbox 中删除账户资金工具
