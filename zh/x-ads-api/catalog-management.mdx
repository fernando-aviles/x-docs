<div id="overview">
  ## 概览
</div>

Catalog API 是一套电商解决方案，使广告主能够设置商品 feed，将商品分组为商品集，并对目录中的商品进行整体管理。Catalog API 将成为支持以编程方式管理目录的核心工具，让广告主对其目录的导入和更新拥有更高的控制权。

一个目录包含与用户商品及商品集相关的所有信息，并与该用户的账号 handle 关联。目前，**一个用户只能创建一个目录**。 

Catalog API 支持两种商品导入方式：

1.  定时 Feed：用户可以添加一个 feed URL（CSV、TSV 和 XML），系统会定期拉取（X 目前支持最大 8GB 的文件）

2.  Batch Products API：用户可以通过批量（JSON）请求查看、创建、更新和删除商品属性

X 商家可以根据筛选规则创建商品集。通过这种方式，他们可以为商品附加额外的元数据，并创建特殊商品集，通过自然电商功能或动态商品广告来展示这些商品。Catalog API 和 X Shopping Manager 支持两种类型的商品集。 

1.  手动：用户可以选择最多 50 个商品，并设置名称和描述

2.  筛选：用户可以添加最多 30 个筛选条件，自动生成满足这些筛选条件的商品集。筛选条件类型包括价格、Google 商品类别、商品类型、库存、促销价以及自定义字段。

Catalog API 提供 4 个用于管理目录的端点：

* [Product Catalogs](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-catalogs) \- 创建商品信息容器
* [Products](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/products) -  同步添加、更新、查看和移除目录中的商品
* [Product Sets](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-sets) -  根据商品信息将商品划分为不同分组
* [Schedule Feeds](https://developer.x.com/en/docs/twitter-ads-api/catalog-management/api-reference/scheduled-feeds) \- 配置将基于文件的商品数据异步导入目录

<div id="prerequisites-for-the-catalog-api">
  ### Catalog API 的先决条件
</div>

Catalog API 的端点目前仅通过早期访问提供。要申请访问权限，请联系你的 X 客户代表。 

你必须通过 [X Shopping Manager](https://ads.x.com/shopping_manager) 接受服务条款。

有关 Shopping Manager 和产品规范的详细信息，请参阅 [产品规范指南](https://business.x.com/en/help/shopping-specs.html)。

<div id="rate-limits">
  ### 速率限制
</div>

下表展示了每个端点的速率限制。

<div id="product-catalog">
  #### 产品目录
</div>

| HTTP 方法 | 速率限制 |
| :--- | :--- |
| GET /product_catalogs | 每 15 分钟 1,000 次 |
| POST /product_catalogs | 每 15 分钟 20 次 |
| PUT /product\_catalogs/:product\_catalog_id | 每 15 分钟 20 次 |
| DELETE /product\_catalogs/:product\_catalog_id | 每 15 分钟 20 次 |

<div id="batch-products-api">
