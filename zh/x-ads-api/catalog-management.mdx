<div id="overview">
  ## 概览
</div>

Catalog API 是一套电商解决方案，使广告主能够设置产品 feed，将产品分组到产品集，并以整体方式管理目录中的产品。Catalog API 将成为实现目录程序化管理的核心工具，为广告主在目录导入和更新方式上提供更高的控制力。

一个目录包含与用户产品和产品集相关的所有内容，并与该用户的 handle 关联。目前，**一个用户只能创建一个目录**。 

Catalog API 支持两种导入产品的方式：

1.  Scheduled Feed：用户可以添加一个 feed URL（CSV、TSV 和 XML），系统会按固定频率抓取该文件（X 目前支持最大 8GB 的文件）

2.  Batch Products API：用户可以通过批量（JSON）请求查看、创建、更新和删除产品属性

X 商家可以基于筛选规则创建产品集。通过这种方式，他们可以为产品附加额外的元数据，并创建特殊产品集，以通过自然电商功能或动态产品广告来展示这些产品。Catalog API 和 X Shopping Manager 支持两种类型的产品集。 

1.  Manual：用户最多可以选择 50 个产品，并设置名称和描述

2.  Filter：用户最多可以添加 30 个筛选条件，以自动生成包含满足这些条件的产品的产品集。筛选条件类型包括价格、Google 产品类别、产品类型、库存、促销价以及自定义字段。

Catalog API 提供 4 个用于管理目录的端点：

* [Product Catalogs](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-catalogs) \- 创建一个用于存放产品信息的容器
* [Products](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/products) -  同步地向目录中添加、更新、查看和移除产品
* [Product Sets](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-sets) -  基于产品信息将产品划分为不同分组
* [Schedule Feeds](https://developer.x.com/en/docs/twitter-ads-api/catalog-management/api-reference/scheduled-feeds) \- 设置将基于文件的产品数据异步导入目录

<div id="prerequisites-for-the-catalog-api">
  ### Catalog API 的先决条件
</div>

Catalog API 端点目前仅通过早期访问提供。若要申请访问权限，请联系你的 X 客户代表。

你必须通过 [X Shopping Manager](https://ads.x.com/shopping_manager) 接受服务条款。

有关 Shopping Manager 和产品规范的详细信息，请参阅[产品规范指南](https://business.x.com/en/help/shopping-specs.html)。

<div id="rate-limits">
  ### 速率限制
</div>

下表展示了各端点的速率限制。

<div id="product-catalog">
  #### 产品目录
</div>

| HTTP 方法 | 速率限制 |
| :--- | :--- |
| GET /product_catalogs | 每 15 分钟 1,000 次 |
| POST /product_catalogs | 每 15 分钟 20 次 |
| PUT /product\_catalogs/:product\_catalog_id | 每 15 分钟 20 次 |
| DELETE /product\_catalogs/:product\_catalog_id | 每 15 分钟 20 次 |

<div id="batch-products-api">
  #### 产品批量 API
</div>

| HTTP Method | 速率限制 |
| :--- | :--- |
| GET /product\_catalogs/:product\_catalog_id/products | 每 15 分钟 1,000 次 |
| PUT /product\_catalogs/:product\_catalog_id/products | 每 15 分钟 600 次 |
| DELETE /product\_catalogs/:product\_catalog_id/products | 每 15 分钟 150 次 |
