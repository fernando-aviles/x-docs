本指南将引导你完成设置活动流订阅，以接收实时账号活动事件的过程。

<Note>
  **先决条件**

  在开始之前，你需要：

  * 一个已获批准 App 的[开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)
  * 你的 App 的 Bearer 令牌
</Note>

***

<Steps>
  <Step title="创建订阅" icon="bell">
    订阅某个用户的活动事件：

    <Tabs>
      <Tab title="cURL">
        ```bash
        curl -X POST "https://api.x.com/2/activity/subscriptions" \
          -H "Authorization: Bearer $BEARER_TOKEN" \
          -H "Content-Type: application/json" \
          -d '{
            "user_id": "2244994945",
            "event_types": ["tweet_create_events", "favorite_events", "follow_events"]
          }'
        ```
      </Tab>

      <Tab title="Python">
        ```python
        import requests

        bearer_token = "YOUR_BEARER_TOKEN"

        url = "https://api.x.com/2/activity/subscriptions"
        headers = {
            "Authorization": f"Bearer {bearer_token}",
            "Content-Type": "application/json"
        }
        payload = {
            "user_id": "2244994945",
            "event_types": ["tweet_create_events", "favorite_events", "follow_events"]
        }

        response = requests.post(url, headers=headers, json=payload)
        print(response.json())
        ```
      </Tab>
    </Tabs>

    **响应：**

    ```json
    {
      "data": {
        "id": "1234567890",
        "user_id": "2244994945",
        "event_types": ["tweet_create_events", "favorite_events", "follow_events"],
        "created_at": "2024-01-15T10:00:00.000Z"
      }
    }
    ```
  </Step>

  <Step title="连接到流" icon="plug">
    打开一个持久连接以接收事件：

    <Tabs>
      <Tab title="cURL">
        ```bash
        curl "https://api.x.com/2/activity/stream" \
          -H "Authorization: Bearer $BEARER_TOKEN"
        ```
      </Tab>

      <Tab title="Python">
        ```python
        import requests

        bearer_token = "YOUR_BEARER_TOKEN"

        url = "https://api.x.com/2/activity/stream"
        headers = {"Authorization": f"Bearer {bearer_token}"}

        response = requests.get(url, headers=headers, stream=True)

        for line in response.iter_lines():
            if line:
                print(line.decode("utf-8"))
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="处理传入事件" icon="message">
    事件会以 JSON 对象的形式源源不断地流入：

    ```json
    {
      "for_user_id": "2244994945",
      "event_type": "tweet_create_events",
      "created_at": "2024-01-15T10:30:00.000Z",
      "tweet_create_events": [
        {
          "id": "1234567890",
          "text": "Hello from the stream!",
          "author_id": "2244994945"
        }
      ]
    }
    ```
  </Step>
</Steps>

<div id="available-event-types">
  ## 可用事件类型
</div>

| 事件 | 描述 |
|:------|:------------|
| `tweet_create_events` | 用户发布新的帖子 |
| `favorite_events` | 用户点赞帖子 |
| `follow_events` | 用户关注他人或被他人关注 |
| `direct_message_events` | 用户发送或接收私信 |
| `block_events` | 用户拉黑或取消拉黑他人 |
| `mute_events` | 用户将他人静音或取消静音 |

<div id="manage-subscriptions">
  ## 管理订阅
</div>

<AccordionGroup>
  <Accordion title="列出订阅">
    获取所有活动订阅：

    ```bash
    curl "https://api.x.com/2/activity/subscriptions" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Accordion>

  <Accordion title="更新订阅">
    修改某个订阅的事件类型：

    ```bash
    curl -X PUT "https://api.x.com/2/activity/subscriptions/1234567890" \
      -H "Authorization: Bearer $BEARER_TOKEN" \
      -H "Content-Type: application/json" \
      -d '{
        "event_types": ["tweet_create_events", "favorite_events"]
      }'
    ```
  </Accordion>

  <Accordion title="删除订阅">
    删除一个订阅：

    ```bash
    curl -X DELETE "https://api.x.com/2/activity/subscriptions/1234567890" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Accordion>
</AccordionGroup>
