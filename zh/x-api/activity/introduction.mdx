Activity Stream 端点为已订阅用户提供账号活动事件的实时推送。当用户发布帖子、点赞、关注、接收私信等操作时，你都可以接收到相应事件。

<div id="event-types">
  ## 事件类型
</div>

| 事件 | 描述 |
|:------|:------------|
| `tweet_create_events` | 用户发布新帖子 |
| `favorite_events` | 用户点赞帖子 |
| `follow_events` | 用户关注其他用户或被关注 |
| `direct_message_events` | 用户发送或接收私信 |
| `block_events` | 用户拉黑或取消拉黑 |
| `mute_events` | 用户静音或取消静音 |

<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/activity/stream`](/zh/x-api/activity/activity-stream) | 连接活动流 |

| DELETE | [`/2/activity/subscriptions/:id`](/zh/x-api/activity/deletes-x-activity-subscription) | 删除订阅 |

***

<div id="how-it-works">
  ## 工作原理
</div>

1. **创建订阅** — 订阅某个用户的活动
2. **连接到流** — 建立持久流式连接
3. **接收事件** — 获取实时活动事件
4. **处理事件** — 在你的应用程序中处理这些事件

***

<div id="example-connect-to-stream">
  ## 示例：连接到流式 API
</div>

```python
import requests

def stream_activity(bearer_token):
    url = "https://api.x.com/2/activity/stream"
    headers = {"Authorization": f"Bearer {bearer_token}"}
    
    response = requests.get(url, headers=headers, stream=True)
    
    for line in response.iter_lines():
        if line:
            print(line.decode("utf-8"))
```
