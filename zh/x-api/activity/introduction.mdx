Activity Stream 端点为订阅用户提供账号活动事件的实时推送。当用户发布帖子、点赞、关注、接收私信（DM）等操作时，你都可以接收相应事件。

<div id="event-types">
  ## 事件类型
</div>

| 事件 | 描述 |
|:------|:------------|
| `tweet_create_events` | 用户发布一条新帖子 |
| `favorite_events` | 用户点赞一条帖子 |
| `follow_events` | 用户关注他人或被他人关注 |
| `direct_message_events` | 用户发送或接收私信 |
| `block_events` | 用户屏蔽或取消屏蔽他人 |
| `mute_events` | 用户静音或取消静音他人 |

<div id="how-it-works">
  ## 工作原理
</div>

1. **创建订阅** — 订阅某个用户的活动
2. **连接到流式接口** — 建立持久连接
3. **接收事件** — 获取实时活动事件
4. **处理事件** — 在应用中处理这些事件

***

<div id="example-connect-to-stream">
  ## 示例：连接到流式数据
</div>

```python
import requests

def stream_activity(bearer_token):
    url = "https://api.x.com/2/activity/stream"
    headers = {"Authorization": f"Bearer {bearer_token}"}
    
    response = requests.get(url, headers=headers, stream=True)
    
    for line in response.iter_lines():
        if line:
            print(line.decode("utf-8"))
```
