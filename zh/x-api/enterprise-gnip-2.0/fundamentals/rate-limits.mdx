<div id="overview">
  ## 概览
</div>

每天都有成千上万的开发者向 X API 发起请求。为了管理如此巨大的请求量，我们对可发起的请求数设置了限制。通过这些限制，我们得以为开发者社区提供可靠且可扩展的 API。 

允许的最大请求数是基于一个时间间隔来设定的，即某个特定的时间段或时间窗口。例如，如果某个端点（endpoint）的速率限制为 900 次请求/15 分钟，那么在任意 15 分钟时间窗口内最多允许 900 次请求。
