<div id="overview">
  ## 概览
</div>

每天都有成千上万的开发者向 X API 发起请求。为了管理如此庞大的请求量，我们对可发起的请求数设置了限制。这些限制有助于我们为开发者社区提供可靠且可扩展的 API。 

允许的最大请求数是按时间间隔计算的，即某个指定的时间段或时间窗口。例如，如果某个端点的请求速率限制为 900 次请求/15 分钟，那么在任意 15 分钟时间段内最多允许 900 次请求。
