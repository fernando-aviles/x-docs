## 概述

> 企业控制台（位于 console.gnip.com）面向已签订企业 API 访问合同的企业数据客户开放。如果你目前还不是企业数据客户但希望了解更多信息，可以在此处了解更多关于[企业数据](https://developer.x.com/en/products/x-api/enterprise)的内容。

本文概述了 X 的企业控制台仪表板。以下各节分别介绍控制台中与产品详情、使用情况以及通用账户管理相关的具体区域。如果你对自己的账户有任何疑问，请联系你指定的客户经理，或查看我们的[企业产品技术文档](/zh/x-api/enterprise-gnip-2.0/enterprise-gnip)。

在你与客户经理进行企业试用和入门流程期间，你将获得 [console.gnip.com](http://console.gnip.com) 的登录账号。该站点是用于查看和配置企业产品访问权限的用户界面。客户管理员对控制台的初始访问由 X 在企业入门流程中完成配置，之后管理员可以添加更多用户。企业控制台可帮助你管理并访问与你的企业产品相关的更多详细信息。

<div id="products-tab">
  ## Products 选项卡
</div>

登录你的账户并进入 [console.gnip.com](http://console.gnip.com) 后，你会进入仪表板中的 Products 选项卡。此页面包含当前在你账户中可用的企业产品概览。

对于使用流式投递的产品（例如 PowerTrack 或 Decahose），此页面会列出产品名称和流标签、当前活动连接数、每个流当前生效的规则数量（如适用），以及最近 24 小时内投递的活动（例如帖子）的原始数量。

对于使用 REST 投递的产品（例如 Search API），此页面会列出产品名称、标签（也显示为“streams”）、通过这些端点返回的当前活动（例如帖子），以及每个端点的若干不同请求次数统计。

请注意，[Usage API](/zh/x-api/enterprise-gnip-2.0/fundamentals/usage) 会以编程方式提供上述大部分数据。

点击名称或设置按钮即可查看每个流的具体详细信息。

<div id="overview">
  ### 概览
</div>

在主仪表板中点击某个流会进入该流的概览页面。

对于流式投放产品，此页面包含以下内容：

1. 通过每个特定流连接向你投放的活动数量图表

2. 关于该流上当前活动连接的详细信息（连接 id 和 IP 地址）

3. 你所用流的最近连接、断开连接以及规则更新事件日志

请注意，可以使用右上角的链接调整图表的显示范围。你可以通过点击图表正下方图例中的相应项目来切换单个连接和断开连接的显示与隐藏。

<div id="connections">
  ### 连接
</div>

Connections 页面提供在你的流上发生的最近连接事件的详细信息。其中包括每次连接的开始和结束时间（24 小时制 UTC）、每次连接的持续时间、发起连接的服务器 IP、用于参考的唯一连接 ID，以及当前连接状态。该状态对应于指定连接最近发生的事件——例如 Client Connected，或一次断开连接（其中会指定断开连接的类型）。有关连接调试的更多信息，请访问[断开连接说明指南](/zh/x-api/enterprise-gnip-2.0/powertrack-api#integrating-with-powertrack)。

<div id="rules">
  ### 规则
</div>

“规则”选项卡适用于 PowerTrack 流，允许你通过用户界面手动输入纯文本规则，从而快速开始使用。请注意，该界面在这种手动方式下最多支持添加 1000 条规则，仅应用于初始测试。我们建议在任何生产环境中，通过 [Rules API](/zh/x-api/enterprise-gnip-2.0/powertrack-api#api-reference-index) 以编程方式管理你的规则。

<div id="settings">
  ### 设置
</div>

Settings 选项卡允许你切换流中数据的输出格式，支持多种格式选项。要切换格式，只需使用对应不同选项的单选按钮。更改会在重新连接到流时生效。请注意，更新此设置会在下一次请求或连接时立即生效，并且在使用新格式时可能会导致你现有的解析器出错。 

**请注意：** 若要获取尽可能多的数据，推荐的设置是 &quot;Leave data in the original format&quot;，它会以富化的原生格式返回 data，详见[此处](/zh/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#post-object)。Activity Streams 格式说明见[此处](/zh/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#activity-object)。

<div id="usage-tab">
  ## Usage 选项卡
</div>

Usage 选项卡可帮助你了解在不同时间段内对你的流的使用情况。若要以编程方式访问用量信息，请参阅 [Usage API](/zh/x-api/enterprise-gnip-2.0/fundamentals/usage)。

<div id="monthly">
  ### 每月
</div>

“每月用量”页面按产品细分展示你的流使用情况。比如，对于某个给定的数据源，覆盖类产品（例如 PowerTrack、Historical PowerTrack 和 PowerTrack Replay）会被归为一组，既提供各自独立的数据，也提供汇总计数。计数包括当前截至本月的用量、本月预计总用量（基于本月迄今的使用情况和本月剩余时间），以及前两个月的用量。

需要注意的是，这些计数会按产品和流分别去重。如果你通过多个与同一 PowerTrack 流的连接收到了同一条帖子，则在这些统计中，该帖子只会被计为一次。计数每 24 小时在 00:00 UTC 更新一次。

<div id="daily">
  ### 每日
</div>

“每日使用量”页面按产品划分，提供当月每天的去重统计计数。数据每 24 小时在 UTC 00:00 更新一次。

<div id="rules">
  ### 规则
</div>

规则数量限制基于你所签订的 PowerTrack 规则套餐，并适用于指定“类型”的所有流。每当添加或删除规则时，计数都会更新。

<div id="account-tab">
  ## 账户选项卡
</div>

<div id="my-profile">
  ### 我的个人资料
</div>

在这里查看你的个人资料详细信息并更改密码。此外，你还可以为自己的账户单独配置账户使用阈值通知。API 状态通知可在状态页面 https://api.twitterstat.us 查看。

<div id="account-settings">
  ### 账户设置
</div>

您可以添加、删除和编辑用户，并为各个用户以及使用量阈值警报配置电子邮件通知。

<Frame>
  <img src="/images/account-settings.png.twimg.1920.png" />
</Frame>

请注意，有三种类型的用户——Account Admin、User 和 Email Only。  

* Account Admin 可以创建、删除和编辑其他用户，并且可以使用用户名（电子邮件）和密码，通过基本身份验证连接到企业级 API

* User 不能创建或修改其他用户，但可以使用用户名（电子邮件）和密码，通过基本身份验证连接到企业级 API

* Email Only 用户无法访问控制面板，无权连接到企业级 API，并且只有在在 “Notifications” 部分被配置为接收通知时才会收到通知。

<div id="usage-thresholds">
  ### 用量阈值
</div>

为你的产品配置用量阈值。对于在个人资料中配置了相关通知的用户，当每个产品达到预警阈值或关键阈值时，系统都会发送电子邮件通知。

<Frame>
  <img src="/images/usage-thresholds.png.twimg.1920.png" />
</Frame>

请注意，这些阈值每天在协调世界时 (UTC) 19:30 评估一次，并非实时评估。
