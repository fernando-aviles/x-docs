## 概览

> 企业控制台（位于 console.gnip.com）面向已签约使用企业 API 的企业数据客户开放。如果你目前还不是企业数据客户但希望了解更多信息，可以在此处进一步了解[企业数据](https://developer.x.com/en/products/x-api/enterprise)。

本文概述 X 企业控制台仪表板。下面涵盖的各个部分对应控制台中的不同区域，用于查看产品详情、使用情况以及通用账户管理。如果你对自己的账户有任何疑问，请联系你指定的客户经理，或查阅我们的[企业产品技术文档](/zh/x-api/enterprise-gnip-2.0/enterprise-gnip)。

在与你的客户经理进行企业试用和接入流程期间，你将获得 [console.gnip.com](http://console.gnip.com) 的登录凭据。该站点是用于查看和配置企业产品访问权限的用户界面。X 会在企业接入过程中为客户管理员开通控制台的初始访问权限，之后管理员可以添加其他用户。企业控制台允许你管理并访问与你的企业产品相关的更多详细信息。

<div id="products-tab">
  ## 产品选项卡
</div>

登录你的账户并进入 [console.gnip.com](http://console.gnip.com) 后，你会首先看到仪表板中的“产品”选项卡。此页面包含当前在你的账户中可用的企业产品概览。

对于使用流式投递的产品（例如 PowerTrack 或 Decahose），此页面会列出产品名称和流标签、当前活动连接数、每个产品当前激活的规则数（如适用），以及最近 24 小时内投递的活动原始数量（例如帖子）。

对于使用 REST 投递的产品（例如 Search API），此页面会列出产品名称、标签（也显示为“streams”）、通过这些端点返回的当前活动数量（例如帖子），以及每个端点的若干不同请求计数指标。

请注意，[Usage API](/zh/x-api/enterprise-gnip-2.0/fundamentals/usage) 能通过编程方式提供其中大部分数据。

可以通过点击名称或设置按钮查看每个流的详细信息。

<div id="overview">
  ### 概览
</div>

在主控制面板中点击某个流，会进入该流的概览页面。

对于流式投递产品，此页面包含以下内容：

1. 通过每个具体流连接向你投递的活动数量的流量图表

2. 当前在该流上处于活动状态的连接详情（连接 ID 和 IP 地址）

3. 你的流最近发生的连接、断开连接以及规则更新事件日志

请注意，可以使用右上角的链接调整图表的显示范围。可以通过点击图表正下方图例中相应的条目来切换单个连接和断开连接的可见性。

<div id="connections">
  ### 连接
</div>

Connections 页面提供你流中最近连接事件的详细信息。这包括每次连接的开始和结束时间（24 小时制 UTC）、每次连接的持续时间、发起该连接的服务器 IP、用于引用的唯一连接 ID，以及当前连接状态。该状态对应指定连接的最新事件——即客户端已连接，或已断开连接，并标明断开连接的类型。有关连接调试的更多详细信息，请参阅[断开连接详解指南](/zh/x-api/enterprise-gnip-2.0/powertrack-api#integrating-with-powertrack)。

<div id="rules">
  ### 规则
</div>

“规则”选项卡适用于 PowerTrack 流，并提供一种通过用户界面手动输入纯文本规则的快速入门方式。请注意，该界面在此手动方式下最多仅支持添加 1000 条规则，因此应仅用于初始测试。我们建议在任何生产环境中，通过 [Rules API](/zh/x-api/enterprise-gnip-2.0/powertrack-api#api-reference-index) 以编程方式管理规则。

<div id="settings">
  ### 设置
</div>

“Settings” 选项卡允许你切换流中 data 的输出格式，支持多种格式选项。要切换格式，只需使用对应不同选项的单选按钮。更改会在你重新连接到流时生效。请注意，更新此设置将在下一次请求或连接时立即生效，并且可能会因为新格式而导致你的解析器出现问题。 

**请注意：** 为获取最多的 data，推荐使用的设置是 “Leave data in the original format”，该设置会以增强的原生格式返回 data，详情见[此处](/zh/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#post-object)。Activity Streams 格式说明见[此处](/zh/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#activity-object)。

<div id="usage-tab">
  ## Usage 选项卡
</div>

Usage 选项卡可帮助你了解在不同时间段内对数据流的使用情况。若要通过编程方式访问用量信息，请参阅 [Usage API](/zh/x-api/enterprise-gnip-2.0/fundamentals/usage)。

<div id="monthly">
  ### 每月
</div>

“每月使用情况”页面按产品展示你的流用量细分。例如，针对某一数据源的覆盖类产品（例如 PowerTrack、Historical PowerTrack 和 PowerTrack Replay）会被归为一组，既提供分别统计的数据，也提供合并汇总的总计数。这些计数包括：本月截至当前的累积用量、本月预计月末用量（基于目前本月使用情况和本月剩余时间推算），以及前两个月的用量计数。

需要特别注意的是，这些计数在每个产品和流维度上都进行了去重统计。如果你通过多个连接接收到了同一 PowerTrack 流中的同一条帖子，则该帖子在此处只会计数一次。计数将每 24 小时在世界协调时 (UTC) 00:00 更新一次。

<div id="daily">
  ### 每日
</div>

“每日使用量”页面提供当月中每一天按产品细分的每日去重计数。统计数据每 24 小时在 00:00 UTC 更新一次。

<div id="rules">
  ### 规则
</div>

规则限制取决于您合约中约定的 PowerTrack 规则包，并适用于某一“类型”的所有流。每当添加或删除规则时，数量都会更新。

<div id="account-tab">
  ## “账户” 选项卡
</div>

<div id="my-profile">
  ### 我的个人资料
</div>

在此查看你的个人资料详细信息，并更改密码。此外，你还可以为你的账号配置专属的使用阈值通知。API 状态通知可在状态页面 https://api.twitterstat.us 上查看。

<div id="account-settings">
  ### 账户设置
</div>

你可以添加、删除和编辑用户，并为各个用户以及用量阈值告警配置电子邮件通知。

<Frame>
  <img src="/images/account-settings.png.twimg.1920.png" />
</Frame>

请注意，用户分为三种类型——Account Admin、User 和 Email Only。

* Account admins 可以创建、删除和编辑其他用户，并且可以使用带有用户名（电子邮件地址）和密码的基本身份验证来连接到企业 API。

* Users 无法创建或修改其他用户，但可以使用带有用户名（电子邮件地址）和密码的基本身份验证来连接到企业 API。

* Email Only 用户无法访问仪表板，无权连接到企业 API，并且只有在 Notifications 部分中被配置为接收通知时，才会收到通知。

<div id="usage-thresholds">
  ### 用量阈值
</div>

为你的产品配置用量阈值。对于在个人资料中启用相关通知的用户，当每个产品达到预警阈值或严重阈值时，系统都会向他们发送电子邮件通知。

<Frame>
  <img src="/images/usage-thresholds.png.twimg.1920.png" />
</Frame>

请注意，这些阈值每天在 19:30（UTC）评估一次，并不会实时评估。
