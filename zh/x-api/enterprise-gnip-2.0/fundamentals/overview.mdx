## 概览

> 企业控制台（位于 console.gnip.com）面向已签订企业 API 访问合约的企业数据客户开放。若您目前还不是企业数据客户但希望了解更多信息，可以在[企业数据](https://developer.x.com/en/products/x-api/enterprise)页面获取详细说明。

本文概述了 X 的企业控制台仪表盘。下面将分别介绍控制台中各个与产品详情、使用情况以及通用账号管理相关的区域。如对您的具体账号有任何问题，请联系您指定的客户经理，或查阅我们的[企业产品技术文档](/zh/x-api/enterprise-gnip-2.0/enterprise-gnip)。

在与客户经理合作完成企业试用和接入流程时，企业客户会收到一个用于登录 [console.gnip.com](http://console.gnip.com) 的账号。该站点是用于查看和配置企业产品访问权限的用户界面。客户管理员对控制台的初始访问权限由 X 在企业接入流程中进行设置，之后管理员可以添加其他用户。通过企业控制台，您可以管理并访问与企业产品相关的更多详细信息。 

以下视频展示了 console.gnip.com 仪表盘各个部分的整体概览。

<div id="products-tab">
  ## 产品标签页
</div>

当你使用账号登录 [console.gnip.com](http://console.gnip.com) 后，将进入仪表板中的产品标签页。此页面包含你账号当前可用的企业产品概览。

对于使用流式传输（streaming delivery）的产品，例如 PowerTrack 或 Decahose，此页面会列出产品名称、流标签（stream label）、当前活动连接数量、每个流当前生效的规则数量（如适用），以及最近 24 小时内传送的活动原始计数（例如帖子数量）。

对于使用 REST 传输的产品，例如 Search API，此页面会列出产品名称、标签（在界面中也显示为 &quot;streams&quot;）、通过这些端点返回的当前活动（例如帖子），以及每个端点的若干不同请求计数。

请注意，[Usage API](/zh/x-api/enterprise-gnip-2.0/fundamentals/usage) 会以编程方式提供其中的大部分数据。

你可以通过点击名称或设置按钮来查看每个流的具体详细信息。

<div id="overview">
  ### 概览
</div>

在主仪表板中点击某个流，将进入该流的概览页面。

对于流式传输投递产品，此页面包括以下内容：

1. 显示通过每个特定流连接交付给你的活动数量的量级图表

2. 当前在该流上处于活动状态的连接的详细信息（连接 ID 和 IP 地址）

3. 你的流最近发生的连接、断开连接以及规则更新事件的日志

请注意，可以使用右上角的链接调整图表的刻度。你可以通过点击图表正下方图例中的相应项目，切换单个连接和断开事件的可见性。

<div id="connections">
  ### 连接
</div>

“Connections” 页面提供你的流中最近连接事件的详细信息。其中包括每次连接的开始和结束时间（UTC 24 小时制）、每次连接的持续时间、发起连接的服务器 IP、用于引用的唯一连接 ID，以及当前连接状态。该状态对应于指定连接的最近一次事件，即 `Client Connected`，或一次断开事件，并给出断开的类型。有关连接调试的更多详情，请访问[断开连接说明文档](/zh/x-api/enterprise-gnip-2.0/powertrack-api#integrating-with-powertrack)。

<div id="rules">
  ### 规则
</div>

Rules 选项卡适用于 PowerTrack 流，并提供了一种通过用户界面手动输入纯文本规则、快速上手的方式。请注意，该界面在此手动方式下最多只支持添加 1000 条规则，应仅用于初始测试阶段。在任何生产环境中，我们建议通过 [Rules API](/zh/x-api/enterprise-gnip-2.0/powertrack-api#api-reference-index) 以编程方式管理你的规则。

<div id="settings">
  ### 设置
</div>

Settings 选项卡允许你切换流中数据的输出格式，并支持多种格式选项。要切换格式，只需使用对应不同选项的单选按钮。更改会在重新连接到流时生效。请注意，更新此设置会在下一次请求或连接时立即生效，并且由于格式变更，可能会导致你现有的解析器无法兼容新格式。 

**请注意：** 为尽可能多地获取数据，推荐的设置是“保留数据的原始格式”，该设置会以富化的原生格式返回数据，详见[此处](/zh/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#post-object)。Activity Streams 格式的说明见[此处](/zh/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#activity-object)。

<div id="usage-tab">
  ## 使用选项卡
</div>

“Usage”（用量）选项卡可帮助你了解在不同时间段内的流使用情况。若要通过编程方式访问使用信息，请参阅 [Usage API](/zh/x-api/enterprise-gnip-2.0/fundamentals/usage)。

<div id="monthly">
  ### 每月
</div>

“每月使用情况”页面按产品展示你的流使用量明细。例如，对于某个数据源，覆盖类产品（例如 PowerTrack、Historical PowerTrack 和 PowerTrack Replay）会被归为一组，既提供各自独立的数据，也提供合并汇总计数。这些计数包括：本月至今的使用量、本月预计月末总量（基于目前为止的本月使用量以及本月剩余时间），以及前两个月的计数。

需要特别注意的是，这些计数会在产品和流维度上去重。如果你通过多个与同一 PowerTrack 流的连接接收到相同的帖子，则该帖子在此只会被计数一次。这些计数每 24 小时在 UTC 时间 00:00 更新一次。

<div id="daily">
  ### 每日
</div>

“每日使用量”页面按产品维度提供当月中每一天的去重计数。计数每 24 小时在 00:00 UTC（协调世界时）更新一次。

<div id="rules">
  ### 规则
</div>

规则限制取决于您合同约定的 PowerTrack 规则套餐，并适用于给定“type”的所有数据流。每当添加或删除规则时，规则计数都会更新。

<div id="account-tab">
  ## 账户标签页
</div>

<div id="my-profile">
  ### 我的个人资料
</div>

在此查看你的个人资料详情并修改密码。此外，你还可以为你的账号配置专属的账号使用量阈值通知。API 状态通知可通过状态页面 https://api.twitterstat.us 查看。

<div id="account-settings">
  ### 账户设置
</div>

您可以添加、删除和编辑用户，并为单个用户和用量阈值告警配置电子邮件通知。

<Frame>
  <img src="/images/account-settings.png.twimg.1920.png" />
</Frame>

请注意，有三种类型的用户——Account Admin、User 和 Email Only。  

* Account Admin 可以创建/删除/编辑其他用户，并且可以使用用户名（电子邮件）和密码进行基本身份验证以连接到企业级 API

* User 无法创建或修改其他用户，但可以使用用户名（电子邮件）和密码进行基本身份验证以连接到企业级 API

* Email Only 用户无法访问控制面板、无权连接企业级 API，仅在在“通知”部分被配置为接收通知时才会收到通知。

<div id="usage-thresholds">
  ### 使用阈值
</div>

为你的产品配置用量阈值。当使用量达到这些阈值时，如果用户在其个人资料中配置了相关通知，将会收到电子邮件提醒，涵盖每个产品的预警阈值和关键阈值。

<Frame>
  <img src="/images/usage-thresholds.png.twimg.1920.png" />
</Frame>

请注意，这些阈值每天在 19:30（UTC）评估一次，并不会实时评估。
