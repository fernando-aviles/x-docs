我们的企业版 API 为依赖 X 数据的用户提供最高级别的访问能力和可靠性。当你的使用规模超出高级版（Premium），并且需要更可靠的访问、自定义套餐或更长期的合同时，它将是理想选择。企业版 API 访问还配备专属客户经理和个性化技术支持。

如果你已经确定 Basic 和 Pro 方案不足以满足你的需求，可以通过以下链接申请企业版产品访问权限：

<div id="available-endpoints">
  ## 可用的端点
</div>

| 实时 | [PowerTrack API](/zh/x-api/enterprise-gnip-2.0/powertrack-api) | 对实时产生的所有公开帖子提供完整覆盖，并可使用多种运算符和规则进行筛选。 |
| :--- | :--- | :--- |
| [Decahose API](/zh/x-api/enterprise-gnip-2.0/fundamentals/decahose-api) | 流式传输所有公开帖子及其点赞的 10% 随机样本。 |
| :--- | :--- | :--- |
| [Account Activity API](/zh/x-api/enterprise-gnip-2.0/fundamentals/account-activity) | 订阅用户并接收其多种活动事件，包括帖子、私信、点赞、关注等。 |
| :--- | :--- | :--- |
| 历史 | [Search API](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api) | 使用高级筛选工具搜索过去 30 天或完整存档的公开帖子。 |
| [Historical PowerTrack API](/zh/x-api/enterprise-gnip-2.0/powertrack-api) | 通过经济高效的批量访问流程筛选完整存档的公开帖子。 |
| 洞察 | [Engagement API](/zh/x-api/enterprise-gnip-2.0/fundamentals/engagement-api) | 衡量公开帖子的曝光量和互动量。 |
| 合规 | [Compliance Firehose API](/zh/x-api/enterprise-gnip-2.0/fundamentals/firehouse) | 流式传输所有合规事件。 |
| 用量 | [Usage API](/zh/x-api/enterprise-gnip-2.0/fundamentals/usage) | 提供对各企业产品使用量的程序化访问。 |

<div id="important-concepts">
  ## 重要概念
</div>

<div id="gnip-console">
  ### Gnip 控制台
</div>

您可以通过 [Gnip 控制台](/zh/x-api/enterprise-gnip-2.0/fundamentals/overview) 管理企业产品和账户访问权限。 

<div id="enrichments">
  ### 富化数据
</div>

对于使用付费级别的开发者，我们在高级版 API 的响应载荷中添加了元数据。要了解有关扩展 URL、投票数据和个人资料地理位置的更多信息，请访问我们的[数据富化章节](/zh/x-api/enterprise-gnip-2.0/fundamentals/data-enrichments)。
 

<div id="advanced-filtering-tools">
  ### 高级过滤工具
</div>

Premium Search API 提供了一组标准搜索端点中不可用的高级运算符。许多运算符对免费沙箱用户也可使用，但如果你使用付费层级，将获得更全面、更强大的运算符集合。要了解更多，请访问我们的[规则与过滤章节](/zh/x-api/enterprise-gnip-2.0/fundamentals/rules-filtering#getting-started-with-enterprise-rules-and-queries)。
