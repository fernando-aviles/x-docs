我们的企业级 API 为依赖 X 数据的用户提供最高级别的访问权限和可靠性。非常适合在你超出高级版能力边界、需要更可靠的访问、自定义打包方案或更长期合同时使用。企业级 API 访问还配备专属客户经理和个性化技术支持。

如果你确定 Basic 和 Pro 方案不足以满足你的需求，你可以通过以下链接申请访问企业级产品：

<div id="available-endpoints">
  ## 可用端点
</div>

| 实时 | [PowerTrack API](/zh/x-api/enterprise-gnip-2.0/powertrack-api) | 提供对实时公开帖子的完整覆盖，并可使用多种运算符和规则进行过滤。 |
| :--- | :--- | :--- |
| [Decahose API](/zh/x-api/enterprise-gnip-2.0/fundamentals/decahose-api) | 流式传输所有公开帖子及其点赞中随机抽取的 10% 样本。 |
| :--- | :--- | :--- |
| [Account Activity API](/zh/x-api/enterprise-gnip-2.0/fundamentals/account-activity) | 订阅用户并接收多种不同的活动，包括帖子、私信、点赞、关注等。 |
| :--- | :--- | :--- |
| 历史 | [Search API](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api) | 使用高级过滤工具搜索过去 30 天或全部公开帖子的存档。 |
| [Historical PowerTrack API](/zh/x-api/enterprise-gnip-2.0/powertrack-api) | 使用经济高效的批量访问流程过滤全部公开帖子的存档。 |
| 洞察 | [Engagement API](/zh/x-api/enterprise-gnip-2.0/fundamentals/engagement-api) | 衡量公开帖子的曝光量和互动量。 |
| 合规 | [Compliance Firehose API](/zh/x-api/enterprise-gnip-2.0/fundamentals/firehouse) | 流式传输所有合规事件。 |
| 用量 | [Usage API](/zh/x-api/enterprise-gnip-2.0/fundamentals/usage) | 提供以编程方式访问各企业产品活动使用情况的能力。 |

<div id="important-concepts">
  ## 关键概念
</div>

<div id="gnip-console">
  ### Gnip 控制台
</div>

可以通过 [Gnip 控制台](/zh/x-api/enterprise-gnip-2.0/fundamentals/overview) 管理企业产品和账户访问权限。 

<div id="enrichments">
  ### 数据富化（Enrichments）
</div>

对于使用付费层级的开发者，我们在高级版 API 的响应负载中添加了元数据。要了解有关展开后的 URL、投票数据和个人资料地理位置信息的更多内容，请访问我们的[数据富化部分](/zh/x-api/enterprise-gnip-2.0/fundamentals/data-enrichments)。
 

<div id="advanced-filtering-tools">
  ### 高级过滤工具
</div>

Premium Search API 提供了一套标准搜索端点不支持的高级运算符。许多运算符同样对免费沙盒用户开放，但如果你使用付费级别，将能使用更完整、更强大的运算符集。要了解更多，请访问我们的[规则和过滤部分](/zh/x-api/enterprise-gnip-2.0/fundamentals/rules-filtering#getting-started-with-enterprise-rules-and-queries)。
