Spaces 查询端点可让你检索正在直播或已预定的 Spaces 的信息。你可以通过其 id 查询 Spaces，或查找由特定用户创建的 Spaces。

<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/spaces/:id`](/zh/x-api/spaces/get-space-by-id) | 根据 ID 获取 Space |
| GET | [`/2/spaces`](/zh/x-api/spaces/get-spaces-by-ids) | 根据多个 ID 获取 Spaces |
| GET | [`/2/spaces/by/creator_ids`](/zh/x-api/spaces/get-spaces-by-creator-ids) | 根据创建者用户 ID 获取 Spaces |
| GET | [`/2/spaces/:id/buyers`](/zh/x-api/spaces/get-space-ticket-buyers) | 获取某个 Space 的门票购买者 |
| GET | [`/2/spaces/:id/tweets`](/zh/x-api/spaces/get-space-posts) | 获取在某个 Space 中分享的帖子 |

***

<div id="response-fields">
  ## 响应字段
</div>

默认情况下，响应包含 `id` 和 `state`。如需更多字段，可请求以下字段：

| 字段 | 说明 |
|:------|:------------|
| `title` | Space 标题 |
| `host_ids` | 主持人用户 ID |
| `speaker_ids` | 发言人用户 ID |
| `participant_count` | 参与者数量 |
| `scheduled_start` | 计划开始时间 |
| `started_at` | 实际开始时间 |
| `ended_at` | 结束时间 |
| `is_ticketed` | Space 是否售票 |

<div id="space-states">
  ### Space 状态
</div>

| 状态 | 描述 |
|:------|:------------|
| `live` | 当前正在进行 |
| `scheduled` | 已排期，稍后开始 |
| `ended` | 已结束 |

***

<div id="example-request">
  ## 示例请求
</div>

```bash
curl "https://api.x.com/2/spaces/1DXxyRYNejbKM?\
space.fields=title,host_ids,participant_count,scheduled_start,state" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
