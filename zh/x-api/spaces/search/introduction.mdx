Spaces Search 端点可让你按关键字搜索正在进行或已排期的 Spaces。查找你感兴趣话题的 Spaces。

  ## 概览
</div>

  <Card title="发现 Spaces" icon="microphone">
    查找正在进行或即将开始的 Spaces
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/spaces/search`](/zh/x-api/spaces/search-spaces) | 搜索 Spaces |

***

<div id="parameters">
  ## 参数
</div>

| 参数 | 说明 |
|:----------|:------------|
| `query` | 搜索查询（必需） |
| `state` | 按 `live` 或 `scheduled` 进行筛选 |
| `space.fields` | 额外的 Space 字段 |
| `expansions` | 要包含的相关扩展对象 |

***

<div id="example-request">
  ## 示例请求
</div>

```bash
curl "https://api.x.com/2/spaces/search?\
query=AI&\
state=live&\
space.fields=title,host_ids,participant_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## 示例响应
