Spaces 搜索端点可让你按关键字搜索正在直播或已安排的 Spaces，查找你感兴趣话题的 Spaces。

<div id="endpoint">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/spaces/search`](/zh/x-api/spaces/search-spaces) | 搜索 Spaces |

***

<div id="parameters">
  ## 参数
</div>

| 参数 | 描述 |
|:----------|:------------|
| `query` | 搜索查询（必需） |
| `state` | 通过 `live` 或 `scheduled` 进行筛选 |
| `space.fields` | 额外的 Space 字段 |
| `expansions` | 要包含的相关对象 |

***

<div id="example-request">
  ## 请求示例
</div>

```bash
curl "https://api.x.com/2/spaces/search?\
query=AI&\
state=live&\
space.fields=title,host_ids,participant_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## 示例响应
</div>

```json
{
  "data": [
    {
      "id": "1DXxyRYNejbKM",

  }
}
```
