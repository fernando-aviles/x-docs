新闻查询端点允许开发者获取在 X 上发布的最新新闻和头条。

该端点支持 OAuth1 和 OAuth2 PKCE 的应用认证（app-auth）和用户认证（user-auth）。

<div id="getting-started">
  ## 入门
</div>

要使用该端点，你需要先在[开发者控制台](https://developer.x.com/en/portal/dashboard)获取一个[Bearer Token](/zh/fundamentals/authentication/oauth-2-0/application-only)。

获得 Bearer Token 之后，你就可以按如下方式调用新闻 API：

```bash
curl 'https://api.x.com/2/news/1989418137272422538?news.fields=contexts,cluster_posts_results' --header 'Authorization: Bearer XXXXX'
```
