`news lookup` 端点允许开发者获取在 X 上正在发生的新闻和突发头条。

此端点支持通过 OAuth1 和 OAuth2 PKCE 进行应用级鉴权（app-auth）和用户级鉴权（user-auth）。

<div id="getting-started">
  ## 入门
</div>

要使用该 endpoint，你需要在 [Developer Console](https://developer.x.com/en/portal/dashboard) 中获取一个 [bearer token](/zh/fundamentals/authentication/oauth-2-0/application-only)。

获取 bearer token 后，你就可以按如下方式调用新闻 API：

```bash
curl 'https://api.x.com/2/news/1989418137272422538?news.fields=contexts,cluster_posts_results' --header 'Authorization: Bearer XXXXX'
```
