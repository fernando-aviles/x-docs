  ## 比较 v1.1 和 v2 管理 Direct Message 端点
</div>

Direct Messages 端点的 v1.1 和 v2 版本都提供了创建 Direct Message 的方法。本指南旨在帮助你理解两者之间的差异，并为迁移到 v2 提供参考信息。 

两者之间的一个主要区别是：v1.1 仅支持一对一会话，而 v2 新增了对群组会话的支持。由此带来的一个结果是，v1.1 仅支持“消息创建”事件，而 v2 还支持与参与者加入和离开会话相关的事件。事实上，v2 的一个基础性更新是将 `dm_conversations` 建立为核心 API 对象。   

在 v1.1 中，有两个用于管理 Direct Messages 的端点：

* POST direct&#95;messages/events/new - 创建一条一对一 Direct Message。此 v1.1 端点只能创建一对一消息，不支持群组消息。  

* DELETE direct&#95;messages/events/destroy - 从认证用户的视图中删除一条一对一消息。 

在此 v2 版本中，有三个用于创建 Direct Messages 的 POST 方法： 

* **POST /2/dm&#95;conversations/with/:participant&#95;id/messages** - 创建一条一对一 Direct Message。该方法会将消息添加到现有的一对一会话中，或创建一个新的会话。`:participant_id` 路径参数是接收消息账号的用户 ID。 

* **POST /2/dm&#95;conversations** - 创建一个新的群组会话并向其中添加一条 Direct Message。这些请求需要提供会话参与者列表。请注意，你可以使用同一参与者列表创建多个会话。这些请求将始终返回新的会话 ID。 

* **POST /2/dm&#95;conversations/:dm&#95;conversation&#95;id/messages** - 创建一条 Direct Message 并将其添加到现有会话中。`:dm\_conversation\_id` 路径参数是要添加消息的会话 ID。 

一个重要细节是，会话和事件 ID 在 X 平台的 v1.1 和 v2 版本之间是共享的。这意味着这两个版本可以一起使用。例如，Direct Messages v1.1 端点提供了返回单个事件和删除事件的方法，而这些方法在 v2 中尚不可用。由于 ID 在 v1.1 和 v2 之间是通用的，你可以基于 v2 提供的 ID 发起 v1.1 请求，或者通过引用 X 应用中会话 URL 中显示的会话 ID 来发起请求。
