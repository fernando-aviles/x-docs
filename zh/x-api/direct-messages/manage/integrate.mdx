<div id="authentication">
  ## 身份验证
</div>

DM 端点需要用户身份验证：

| 方法 | 说明 |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/zh/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | 推荐使用 |
| [OAuth 1.0a User Context](/zh/resources/fundamentals/authentication) | 旧版兼容 |

<Warning>
  不支持仅应用（App-only）身份验证。所有私信（Direct Message）都是私密的。
</Warning>

<div id="required-scopes-oauth-20">
  ### 必需的 scope（OAuth 2.0）
</div>

| Scope | 用于 |
|:------|:-------------|
| `dm.write` | 发送和删除消息 |
| `dm.read` | 与 dm.write 一起使用时必需 |
| `tweet.read` | 在使用 dm 相关 scope 时必需 |
| `users.read` | 在使用 dm 相关 scope 时必需 |

***

<div id="endpoints-overview">
  ## 端点概览
</div>

| 方法 | 端点 | 说明 |
|:-------|:---------|:------------|
| POST | `/2/dm_conversations/with/:participant_id/messages` | 发送一对一私信 |
| POST | `/2/dm_conversations` | 创建群组会话 |
| POST | `/2/dm_conversations/:dm_conversation_id/messages` | 向会话添加消息 |
| DELETE | `/2/dm_events/:event_id` | 删除消息 |

<div id="sending-messages">
  ## 发送消息
</div>

<div id="one-to-one-message">
  ### 一对一私信
</div>

向特定用户发送私信。如果尚未存在会话，则会创建一个新会话：

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/dm_conversations/with/9876543210/messages" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"text": "Hello!"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 发送一条一对一私信
  response = client.dm_conversations.create_message(
      participant_id="9876543210",
      text="Hello!"
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 发送一条一对一私信
  const response = await client.dmConversations.createMessage({
    participantId: "9876543210",
    text: "Hello!",
  });
  console.log(response.data);
  ```
</CodeGroup>

<div id="group-conversation">
  ### 群组会话
</div>

创建一个新的群组会话并发送第一条消息：

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/dm_conversations" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "conversation_type": "Group",
      "participant_ids": ["944480690", "906948460078698496"],
      "message": {"text": "Welcome to our group!"}
    }'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 创建一个群组会话
  response = client.dm_conversations.create(
      conversation_type="Group",
      participant_ids=["944480690", "906948460078698496"],
      message={"text": "Welcome to our group!"}
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 创建一个群组会话
  const response = await client.dmConversations.create({
    conversationType: "Group",
    participantIds: ["944480690", "906948460078698496"],
    message: { text: "Welcome to our group!" },
  });
  console.log(response.data);
  ```
</CodeGroup>

<Note>
  `conversation_type` 字段必须设置为 `"Group"`（区分大小写）。
</Note>

<div id="add-to-existing-conversation">
  ### 添加到现有会话
</div>

向你参与的任何会话发送消息：

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/dm_conversations/1582103724607971328/messages" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"text": "Another message"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 将消息添加到现有会话
  response = client.dm_conversations.add_message(
      dm_conversation_id="1582103724607971328",
      text="Another message"
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 将消息添加到现有会话
  const response = await client.dmConversations.addMessage({
    dmConversationId: "1582103724607971328",
    text: "Another message",
  });
  console.log(response.data);
  ```
</CodeGroup>

<div id="media-attachments">
  ## 媒体附件
</div>

每条消息可附加一个媒体文件（照片、视频或 GIF）。

<Steps>
  <Step title="上传媒体">
    使用 [Media Upload endpoint](/zh/x-api/media/quickstart/media-upload-chunked) 上传你的文件并获取一个 `media_id`。
  </Step>

  <Step title="包含在消息中">
    ```json
    {
      "text": "来看看这张图片！",
      "attachments": [{"media_id": "1583157113245011970"}]
    }
    ```
  </Step>
</Steps>

<Note>
  * 已认证用户必须是该媒体的上传者
  * 上传后媒体在 24 小时内有效
  * 每条消息仅支持一个附件
</Note>

<div id="sharing-posts">
  ## 分享帖子
</div>

要在消息中包含帖子，只需在消息文本中添加该帖子的 URL：

```json
{
  "text": "Have you seen this? https://x.com/XDevelopers/status/1580559079470145536"
}
```

响应中将包含一个 `referenced_tweets` 字段，其中带有帖子 id。

***

<div id="message-requirements">
  ## 消息要求
</div>

| 字段 | 必需 | 备注 |
|:------|:---------|:------|
| `text` | 是* | 如果没有附件，则为必需字段 |
| `attachments` | 是* | 如果没有文本，则为必需字段 |

*必须至少提供 `text` 或 `attachments` 之一。

***

<div id="id-compatibility-with-v11">
  ## 与 v1.1 的 ID 兼容性
</div>

会话和事件 ID 在 v1.1 和 v2 端点之间是共享的，从而支持混合式工作流：

* 使用 v2 创建消息
* 使用 v1.1 删除消息（v2 中尚未提供）
* 从 x.com URL 中引用会话 ID

<div id="error-handling">
  ## 错误处理
</div>

| 状态码 | 错误 | 解决方案 |
|:-------|:------|:---------|
| 400 | 无效请求 | 检查请求体格式 |
| 401 | 未授权 | 验证访问令牌 |
| 403 | 无权限 | 检查权限范围（scopes）和用户权限 |
| 429 | 请求过多 | 等待并重试 |

<div id="common-issues">
  ### 常见问题
</div>

<AccordionGroup>
  <Accordion title="无法发送给该用户">
    收件人可能启用了只接收已知用户私信的设置，或者已将你拉黑。
  </Accordion>

  <Accordion title="媒体附件失败">
    请确保媒体由同一已认证用户上传，且上传时间少于 24 小时。
  </Accordion>

  <Accordion title="群组创建失败">
    请确认所有参与者 id 均有效，并且这些用户允许接收群组私信邀请。
  </Accordion>
</AccordionGroup>
