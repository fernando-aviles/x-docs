Manage Direct Messages 端点允许你代表已通过身份验证的用户发送和删除私信（Direct Messages）。

<div id="overview">
  ## 概览
</div>

<CardGroup cols={2}>
  <Card title="发送消息" icon="paper-plane">
    向其他用户发送一条私信（DM）
  </Card>

  <Card title="删除消息" icon="trash">
    从你的收件箱中删除一条私信（DM）
  </Card>

  <Card title="创建会话" icon="comments">
    开始一个新的会话
  </Card>

  <Card title="群组消息" icon="users">
    向群组会话发送消息
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| POST | `/2/dm_conversations` | 创建一个新的会话 |
| POST | `/2/dm_conversations/with/:participant_id/messages` | 向一对一会话发送消息 |
| POST | `/2/dm_conversations/:dm_conversation_id/messages` | 向已有会话发送消息 |
| DELETE | `/2/dm_events/:id` | 删除 DM 事件 |

***

<div id="example-send-a-message">
  ## 示例：发送消息
</div>

```bash
curl -X POST "https://api.x.com/2/dm_conversations/with/1234567890/messages" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello! How are you?"}'
```

<div id="example-response">
  ## 示例响应
</div>

```json
{
  "data": {
    "dm_conversation_id": "1234567890-0987654321",
    "dm_event_id": "1122334455667788990"
  }
}
```

***

<div id="message-types">
  ## 消息类型
</div>

你可以发送文本消息并附带媒体内容：

```json
{
  "text": "Check out this photo!",
  "attachments": [{
    "media_id": "1234567890123456789"
  }]
}
```
