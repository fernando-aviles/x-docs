Direct Messages 查询端点允许你检索已通过身份验证用户的私信事件，包括来自一对一和群组会话的消息。

<div id="overview">
  ## 概览
</div>

<CardGroup cols={2}>
  <Card title="所有 DM 事件" icon="messages">
    获取该用户的所有 DM 事件
  </Card>

  <Card title="一对一会话" icon="message">
    获取来自特定会话的事件
  </Card>

  <Card title="按会话 ID" icon="comments">
    按会话 ID 获取事件
  </Card>

  <Card title="事件类型" icon="bell">
    消息、加入和离开事件
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/dm_events`](/zh/x-api/direct-messages/get-dm-events) | 获取当前用户的全部 DM 事件 |
| GET | [`/2/dm_conversations/with/:participant_id/dm_events`](/zh/x-api/direct-messages/get-dm-events-for-a-dm-conversation) | 获取一对一 DM 会话中的事件 |
| GET | [`/2/dm_conversations/:dm_conversation_id/dm_events`](/zh/x-api/direct-messages/get-dm-events-for-a-dm-conversation-1) | 根据会话 ID 获取事件 |

***

<div id="event-types">
  ## 事件类型
</div>

| Event | Description |
|:------|:------------|
| `MessageCreate` | 在会话中发送了一条消息 |
| `ParticipantsJoin` | 有用户加入该会话 |
| `ParticipantsLeave` | 有用户离开该会话 |

***

<div id="data-retention">
  ## 数据保留
</div>

<Note>
  可通过这些端点访问**最多 30 天前**的事件。
</Note>
