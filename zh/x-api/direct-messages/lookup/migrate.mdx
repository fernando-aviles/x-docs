  ## 比较 v1.1 和 v2 私信事件查询端点
</div>

Direct Messages 端点在 v1.1 和 v2 版本中都提供了查询私信事件的方法。本指南旨在帮助你理解二者之间的差异，并为迁移到 v2 提供参考信息。 

两者之间的一个主要区别是，v1.1 只支持一对一会话，而 v2 引入了对群组会话的支持。由此带来的一个结果是，v1.1 仅支持“消息创建”事件，而 v2 还支持与参与者加入和离开会话相关的事件。实际上，v2 的一个基础性更新是将 `dm_conversations` 建立为核心 API 对象。   

在 v1.1 中，有两个用于检索私信的端点（同样地，v1.1 中仅支持新消息这一种事件类型）：

* GET direct&#95;messages/events/show - 根据 ID 检索单个事件。 

* GET direct&#95;messages/events/list - 检索已认证用户在过去最多 30 天内发送和接收的一对一私信。请注意，此方法无法检索群组会话中的消息。 

在此 v2 版本中，有三个用于检索私信会话事件的 GET 方法： 

* **GET /2/dm&#95;conversations/with/:participant&#95;id/dm&#95;events** - 检索与某个一对一会话相关的私信事件。`:participant_id` 路径参数是与发出该请求的已认证用户进行会话的账号的用户 id。 

* **GET /2/dm&#95;conversations/:dm&#95;conversation&#95;id/dm&#95;events** - 检索与特定会话 ID 相关的私信事件，由 `:dm_conversation_id` 路径参数指定。此方法同时支持一对一和群组会话。 

* **GET /2/dm&#95;events** - 检索与某个用户相关的私信事件，包括一对一和群组会话。可用的事件时间范围最长可追溯到 30 天前。  

一个重要细节是，会话和事件 ID 在 X 平台的 v1.1 和 v2 版本之间是共享的。这意味着可以同时使用这两个版本。例如，私信 v1.1 端点提供了返回单个事件和删除事件的方法，而这些方法在 v2 中尚不可用。由于 ID 在 v1.1 和 v2 之间是通用的，你可以基于 v2 提供的 ID 发起 v1.1 请求，或者使用 X 应用中会话 URL 显示的会话 ID。

下表比较了 v1.1 和 v2 私信事件查询端点的一些基本方面。此处列出的 X API v2 特性适用于所有私信查询端点。
