<div id="authentication">
  ## 认证
</div>

DM 端点需要用户身份验证才能访问私密会话：

| 方法 | 描述 |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/zh/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | 推荐 |
| [OAuth 1.0a User Context](/zh/resources/fundamentals/authentication) | 旧版兼容支持 |

<Warning>
  不支持 App-Only 身份验证。所有私信（Direct Messages）均为私密内容。
</Warning>

<div id="required-scopes-oauth-20">
  ### 所需权限范围（OAuth 2.0）
</div>

| Scope | 用途说明 |
|:------|:-------------|
| `dm.read` | 读取私信事件 |
| `tweet.read` | 与 dm.read 一同使用时必需 |
| `users.read` | 与 dm.read 一同使用时必需 |

<div id="conversation-types">
  ## 会话类型
</div>

<CardGroup cols={2}>
  <Card title="一对一" icon="message">
    始终为两名参与者。会话 ID 格式：`{smaller_user_id}-{larger_user_id}`
  </Card>

  <Card title="群组" icon="comments">

  </Card>

<div id="event-types">
  ## 事件类型
</div>

| Event | 描述 | 关键字段 |
|:------|:------------|:-----------|
| `MessageCreate` | 消息已发送 | `text`, `sender_id` |
| `ParticipantsJoin` | 用户加入群组 | `participant_ids`, `sender_id` |
| `ParticipantsLeave` | 用户离开群组 | `participant_ids` |

<div id="fields-and-expansions">
  ## 字段和 expansions
</div>

<div id="default-fields">
  ### 默认字段
</div>

| 事件类型 | 默认字段 |
|:-----------|:---------------|
| MessageCreate | `id`, `event_type`, `text` |
| ParticipantsJoin/Leave | `id`, `event_type`, `participant_ids` |

<div id="available-fields">
  ### 可用字段
</div>

| 字段 | 描述 | 事件 |
|:------|:------------|:-------|
| `dm_conversation_id` | 会话 ID | All |
| `created_at` | 事件时间戳 | All |
| `sender_id` | 发送/邀请方 | MessageCreate, Join |
| `attachments` | 媒体附件 | MessageCreate |
| `referenced_tweets` | 被分享的帖子 | MessageCreate |

<div id="available-expansions">
  ### 可用的 expansions
</div>

| Expansion | 返回内容 |
|:----------|:--------|
| `sender_id` | 发送方的用户对象 |
| `participant_ids` | 参与者的用户对象 |
| `attachments.media_keys` | 媒体对象 |
| `referenced_tweets.id` | 帖子对象 |

<div id="example-with-expansions">
  ### 使用 expansions 的示例
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/dm_events?\
  dm_event.fields=created_at,sender_id,attachments&\
  expansions=sender_id,attachments.media_keys&\
  user.fields=username,profile_image_url&\
  media.fields=url,type" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 使用 expansions 获取 DM 事件
  for page in client.dm_events.list(
      dm_event_fields=["created_at", "sender_id", "attachments"],
      expansions=["sender_id", "attachments.media_keys"],
      user_fields=["username", "profile_image_url"],
      media_fields=["url", "type"],
      max_results=100
  ):
      for event in page.data:
          print(f"Event: {event.event_type} - {event.text}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  const paginator = client.dmEvents.list({
    dmEventFields: ["created_at", "sender_id", "attachments"],
    expansions: ["sender_id", "attachments.media_keys"],
    userFields: ["username", "profile_image_url"],
    mediaFields: ["url", "type"],
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((event) => {
      console.log(`Event: ${event.event_type} - ${event.text}`);
    });
  }
  ```
</CodeGroup>

<div id="pagination">
  ## 分页
</div>

DM 事件按时间倒序返回（最新的在前）：

<CodeGroup dropdown>
  ```bash cURL
  # 第一次请求
  curl "https://api.x.com/2/dm_events?max_results=100" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"

  # 带有分页令牌的后续请求
  curl "https://api.x.com/2/dm_events?max_results=100&pagination_token=NEXT_TOKEN" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # SDK 会自动处理分页
  all_events = []

  for page in client.dm_events.list(max_results=100):
      if page.data:
          all_events.extend(page.data)

  print(f"Found {len(all_events)} DM events")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  async function getAllDMEvents() {
    const allEvents = [];

    // SDK 会自动处理分页
    const paginator = client.dmEvents.list({ maxResults: 100 });

    for await (const page of paginator) {
      if (page.data) {
        allEvents.push(...page.data);
      }
    }

    return allEvents;
  }

  // 用法
  const events = await getAllDMEvents();
  console.log(`Found ${events.length} DM events`);
  ```
</CodeGroup>

<Note>
  最多可获取过去 **30 天内** 的事件。
</Note>

<div id="id-compatibility-with-v11">
  ## 与 v1.1 的 ID 兼容性
</div>

会话和事件 ID 在 v1.1 和 v2 端点之间是共享的。这意味着你可以：

* 使用 v2 检索事件，然后使用 v1.1 删除特定消息
* 在 API 请求中引用来自 x.com URL 的会话 ID
