Trends by WOEID 端点会返回某一特定地理位置的热门话题，该位置通过 Yahoo! 的 Where On Earth ID（WOEID）来标识。

<div id="overview">
  ## 概览
</div>

<CardGroup cols={2}>
  <Card title="基于位置" icon="location-dot">
    查看任意受支持位置的趋势
  </Card>

  <Card title="全球覆盖" icon="globe">
    覆盖国家、城市和地区
  </Card>

  <Card title="实时" icon="bolt">
    当前趋势话题
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## Endpoint
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/trends/by/woeid/:id`](/zh/x-api/trends/get-trends-by-woeid) | 获取指定 WOEID 的趋势 |

***

<div id="common-woeids">
  ## 常见 WOEID
</div>

| 地点 | WOEID |
|:---------|:------|
| 全球 | 1 |
| 美国 | 23424977 |
| 英国 | 23424975 |
| 日本 | 23424856 |
| 纽约 | 2459115 |
| 洛杉矶 | 2442047 |
| 伦敦 | 44418 |
| 东京 | 1118370 |

***

<div id="example-request">
  ## 示例请求
</div>

```bash
curl "https://api.x.com/2/trends/by/woeid/1" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## 示例响应
</div>

```json
{
  "data": [
    {
      "trend_name": "#AI",
      "tweet_count": 250000
    },
    {
      "trend_name": "Breaking News",
      "tweet_count": 180000
    }
  ]
}
```
