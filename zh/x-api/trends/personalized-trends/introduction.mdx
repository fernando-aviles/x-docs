“个性化趋势”端点会基于已认证用户的位置和兴趣，为其返回个性化的热门话题。

  <Card title="实时" icon="bolt">

</CardGroup>

***

<div id="endpoint">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | `/2/users/personalized_trends` | 获取个性化趋势信息 |

***

<div id="example-request">
  ## 示例请求
</div>

```bash
curl "https://api.x.com/2/users/personalized_trends" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-response">
  ## 示例响应
</div>

```json
{
  "data": [
    {
      "trend_name": "#AI",
      "tweet_count": 125000
    },
    {
      "trend_name": "Machine Learning",
      "tweet_count": 85000
    }
  ]
}
```
