个性化趋势端点会根据已认证用户的位置和兴趣，返回为其定制的热门话题。

<div id="overview">
  ## 概览
</div>

<CardGroup cols={2}>
  <Card title="个性化" icon="user">
    为用户量身定制的趋势
  </Card>

  <Card title="位置感知" icon="location-dot">
    基于用户所在位置
  </Card>

  <Card title="实时" icon="bolt">
    当前热门话题
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | `/2/users/personalized_trends` | 获取个性化趋势数据 |

***

<div id="example-request">
  ## 请求示例
</div>

```bash
curl "https://api.x.com/2/users/personalized_trends" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-response">
  ## 示例响应
</div>

```json
{
  "data": [
    {
      "trend_name": "#AI",
      "tweet_count": 125000
    },
    {
      "trend_name": "Machine Learning",
      "tweet_count": 85000
    }
  ]
}
```
