<div id="key-features">
  ## 关键特性
</div>

<Tabs>
  <Tab title="数据访问">
    ### 丰富的数据对象

    获取帖子、用户、媒体等的详细结构化数据：

    * **帖子**：完整文本、指标、实体、注释、会话线程
    * **用户**：个人资料、关注者数量、认证状态
    * **媒体**：带有元数据的图片、视频、GIF
    * **投票**：选项和投票数量

    使用 [fields](/zh/x-api/fundamentals/fields) 和 [expansions](/zh/x-api/fundamentals/expansions) 自定义响应，以精确获取所需的数据。
  </Tab>

  <Tab title="实时流">
    ### 过滤流

    在帖子发布的同时实时接收。可定义最多 1,000 条过滤规则，只接收匹配的帖子。

    ```bash
    # 添加一条规则
    curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{"add": [{"value": "from:xdevelopers"}]}'

    # 连接到流
    curl "https://api.x.com/2/tweets/search/stream" \
      -H "Authorization: Bearer $TOKEN"
    ```

    [进一步了解过滤流 →](/zh/x-api/posts/filtered-stream/introduction)
  </Tab>

  <Tab title="搜索与分析">
    ### 全量归档搜索

    搜索自 2006 年以来的全部公开帖子历史记录。使用针对用户、关键词、日期等的运算符构建查询。

    ```bash
    curl "https://api.x.com/2/tweets/search/all?query=AI%20lang:en" \
      -H "Authorization: Bearer $TOKEN"
    ```

    ### 指标

    获取包括展示次数、点赞、转发、回复和视频播放量在内的互动指标。

    [进一步了解搜索 →](/zh/x-api/posts/search/introduction)
  </Tab>
</Tabs>

<div id="quick-start">
  ## 快速开始
</div>

<Steps>
  <Step title="创建开发者账号">
    在 [console.x.com](https://console.x.com) 注册并创建一个应用。
  </Step>

  <Step title="获取凭证">
    为仅应用（App-only）请求生成你的 Bearer Token。
  </Step>

  <Step title="发起请求">
    试着查找某个用户：

    ```bash
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>
</Steps>
