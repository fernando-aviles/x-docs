<div id="official-sdks">
  ## 官方 SDK
</div>

X 提供适用于 TypeScript 和 Python 的官方 SDK，完全支持 X API v2：

<CardGroup cols={2}>
  <Card title="Python SDK" icon="python" href="/zh/xdks/python/overview">
    提供异步支持、类型提示和自动令牌刷新功能，非常适合数据分析和自动化。
  </Card>

  <Card title="TypeScript SDK" icon="js" href="/zh/xdks/typescript/overview">
    具备完善的类型安全保障和 ESM 支持，可在 Node.js 和现代打包工具中使用。
  </Card>
</CardGroup>

<div id="official-tools">
  ## 官方工具
</div>

| 工具 | 描述 |
|:-----|:------------|
| [Postman Collection](https://app.getpostman.com/run-collection/9956214-784efcda-ed4c-4491-a4c0-a26470a67400) | 针对所有 X API v2 端点的交互式 API 测试 |
| [OpenAPI Spec](https://api.x.com/2/openapi.json) | 机器可读的 API 规范 |
| [twitter-text](https://github.com/twitter/twitter-text) | 解析和验证帖子文本并统计字符数 |

<div id="building-a-library">
  ## 正在开发库？
</div>

如果你正在构建 X API 库，欢迎与社区分享：

1. 在 [Libraries &amp; SDKs 论坛](https://devcommunity.x.com/c/libraries-and-sdks/63) 中发帖
2. 我们可能会把它添加到本页！

在你的 README 中使用我们的 [version badges](https://twbadges.glitch.me/) 来展示 API 兼容性。
