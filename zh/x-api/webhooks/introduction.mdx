<div id="how-webhooks-work">
  ## Webhook 工作原理
</div>

```
┌──────────┐      ┌──────────┐      ┌──────────┐
│ X Event  │  →   │ X Server │  →   │ Your     │
│ Occurs   │      │          │      │ Webhook  │
└──────────┘      └──────────┘      └──────────┘
```

1. **事件触发** — 用户发布帖子、发送私信等
2. **X 发起请求** — 向你的 webhook URL 发送 POST 请求
3. **你处理** — 你的服务器处理该事件
4. **返回 200** — 返回 200 OK 以确认接收

<div id="webhook-requirements">
  ## Webhook 要求
</div>

| 要求 | 描述 |
|:------------|:------------|
| **HTTPS** | Webhook URL 必须使用 HTTPS |
| **Public** | URL 必须对公网可访问 |
| **Fast response** | 必须在 10 秒内返回响应 |
| **200 OK** | 返回 200 状态码以确认 |

## 安全

<div id="signature-verification">
  ### 挑战-响应检查（CRC）
</div>

X 会通过发送 CRC 请求来验证你的 webhook。你需要返回一个使用 HMAC-SHA256 生成的哈希值：

```python
import hmac
import hashlib
import base64

def handle_crc(crc_token, consumer_secret):
    sha256_hash = hmac.new(
        consumer_secret.encode(),
        crc_token.encode(),
        hashlib.sha256
    ).digest()
    
    return {
        "response_token": "sha256=" + base64.b64encode(sha256_hash).decode()
    }
```

### 签名验证

使用 `x-twitter-webhooks-signature` HTTP 头来验证 webhook 请求的真实性。
