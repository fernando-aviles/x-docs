<div id="how-webhooks-work">
  ## Webhook 的工作原理
</div>

```
┌──────────┐      ┌──────────┐      ┌──────────┐
│ X Event  │  →   │ X Server │  →   │ Your     │
│ Occurs   │      │          │      │ Webhook  │
└──────────┘      └──────────┘      └──────────┘
```

1. **事件触发** — 用户发布帖子、发送私信等
2. **X 发送请求** — 向你的 webhook URL 发送 POST 请求
3. **你进行处理** — 你的服务器处理该事件
4. **返回 200** — 返回 200 OK 表示已收到

<div id="webhook-requirements">
  ## Webhook 要求
</div>

| Requirement | Description |
|:------------|:------------|
| **HTTPS** | Webhook URL 必须使用 HTTPS |
| **Public** | URL 必须可被公开访问 |
| **Fast response** | 在 10 秒内返回响应 |
| **200 OK** | 返回 200 状态码以表示确认 |

<div id="challenge-response-check-crc">
  ### Challenge-Response 检查（CRC）
</div>

X 会通过发送 CRC 请求来验证你的 webhook。请使用 HMAC-SHA256 哈希值进行响应：

```python
import hmac
import hashlib
import base64

def handle_crc(crc_token, consumer_secret):
    sha256_hash = hmac.new(
        consumer_secret.encode(),
        crc_token.encode(),
        hashlib.sha256
    ).digest()
    
    return {
        "response_token": "sha256=" + base64.b64encode(sha256_hash).decode()
    }
```
