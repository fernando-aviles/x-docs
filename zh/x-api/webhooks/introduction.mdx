<div id="how-webhooks-work">
  ## Webhook 的工作原理
</div>

```
┌──────────┐      ┌──────────┐      ┌──────────┐
│ X Event  │  →   │ X Server │  →   │ Your     │
│ Occurs   │      │          │      │ Webhook  │
└──────────┘      └──────────┘      └──────────┘
```

1. **事件发生** — 用户发布帖子、发送私信等
2. **X 发送请求** — 向你的 webhook URL 发起 POST 请求
3. **处理事件** — 你的服务器处理该事件
4. **响应 200** — 返回 200 OK 以确认已接收

***

<div id="webhook-requirements">
  ## Webhook 要求
</div>

| 要求 | 说明 |
|:------------|:------------|
| **HTTPS** | Webhook URL 必须使用 HTTPS 协议 |
| **Public** | URL 必须对外公开可访问 |
| **Fast response** | 必须在 10 秒内返回响应 |
| **200 OK** | 返回 200 OK 状态码以确认接收 |

<div id="challenge-response-check-crc">
  ### 质询-响应校验（CRC）
</div>

X 会通过发送 CRC 请求来验证你的 webhook。请返回一个 HMAC-SHA256 哈希值：

```python
import hmac
import hashlib
import base64

def handle_crc(crc_token, consumer_secret):
    sha256_hash = hmac.new(
        consumer_secret.encode(),
        crc_token.encode(),
        hashlib.sha256
    ).digest()
    
    return {
        "response_token": "sha256=" + base64.b64encode(sha256_hash).decode()
    }
```
