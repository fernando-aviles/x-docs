User Search 端点允许你通过关键词搜索用户。你可以根据用户的名称、用户名或个人简介中的内容来查找用户。

  ## 概览

  </Card>

  <Card title="发现用户" icon="user-plus">
    查找相关账号
  </Card>
</CardGroup>

<div id="endpoint">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/users/search`](/zh/x-api/users/search-users) | 搜索用户 |

***

<div id="example-request">
  ## 请求示例
</div>

```bash
curl "https://api.x.com/2/users/search?\
query=python%20developer&\
user.fields=description,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## 示例响应
</div>

```json
{
  "data": [
    {
      "id": "1234567890",
      "name": "Python Developer",

      "description": "Building cool things with Python",
      "verified": false,

        "followers_count": 5000,
        "following_count": 200,
        "tweet_count": 1500
      }
    }
  ],

```
