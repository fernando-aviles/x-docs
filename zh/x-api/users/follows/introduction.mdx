Follows 端点可用于关注和取消关注用户，并检索任意用户的粉丝列表和关注列表。

  ## 概览

<div id="endpoints">
  ## 端点
</div>

<div id="follows-lookup">
  ### 关注关系查询
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/followers`](/zh/x-api/users/get-followers) | 获取某个用户的关注者 |
| GET | [`/2/users/:id/following`](/zh/x-api/users/get-following) | 获取某个用户关注的账号 |

<div id="manage-follows">
  ### 管理关注关系
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/following`](/zh/x-api/users/follow-user) | 关注指定用户 |
| DELETE | [`/2/users/:source_user_id/following/:target_user_id`](/zh/x-api/users/unfollow-user) | 取消关注指定用户 |

***

<div id="example-get-followers">
  ## 示例：获取关注者
</div>

```bash
curl "https://api.x.com/2/users/2244994945/followers?\
user.fields=username,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-follow-a-user">
  ## 示例：关注某个用户
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/following" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "2244994945"}'
```
