Follows 端点允许你关注或取消关注用户，并获取任意用户的关注者和关注列表。

<div id="overview">
  ## 概览
</div>

<CardGroup cols={2}>
  <Card title="关注" icon="user-plus">
    代表经过身份验证的用户关注某个用户
  </Card>

  <Card title="取消关注" icon="user-minus">
    取消关注某个用户
  </Card>

  <Card title="关注者" icon="users">
    获取某个用户的关注者
  </Card>

  <Card title="正在关注" icon="user-group">
    获取某个用户正在关注的账号
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## 接口端点
</div>

<div id="follows-lookup">
  ### 关注关系查询
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/followers`](/zh/x-api/users/get-followers) | 获取某个用户的关注者 |
| GET | [`/2/users/:id/following`](/zh/x-api/users/get-following) | 获取某个用户正在关注的账号 |

<div id="manage-follows">
  ### 管理关注
</div>

| 方法 | 端点 | 说明 |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/following`](/zh/x-api/users/follow-user) | 关注用户 |
| DELETE | [`/2/users/:source_user_id/following/:target_user_id`](/zh/x-api/users/unfollow-user) | 取消关注用户 |

***

<div id="example-get-followers">
  ## 示例：获取关注者
</div>

```bash
curl "https://api.x.com/2/users/2244994945/followers?\
user.fields=username,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-follow-a-user">
  ## 示例：关注某个用户
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/following" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "2244994945"}'
```
