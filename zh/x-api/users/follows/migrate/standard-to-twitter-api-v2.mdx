<div id="manage-follows-standard-v11-compared-to-x-api-v2">
  #### 管理关注：标准版 v1.1 与 X API v2 对比
</div>

如果你一直在使用标准版 v1.1 中的 [POST friendships/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/post-friendships-create) 和 [POST friendships/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/post-friendships-destroy) 端点，本指南旨在帮助你了解这些标准端点与 X API v2 中管理关注的端点之间的相似点和差异。

* **相似点**
  * OAuth 1.0a 用户上下文
* **差异**
  * 端点 URL
  * App 和 Project 要求
  * HTTP 方法
  * 请求参数

<div id="similarities">
  #### 相似之处
</div>

**OAuth 1.0a 用户上下文认证方式**

这两个版本的端点都支持 [OAuth 1.0a 用户上下文](/zh/resources/fundamentals/authentication#oauth-1-0a-2)。因此，如果你之前使用的是某个标准的 v1.1 管理关注端点，在迁移到 X API v2 版本后，可以继续使用相同的认证方式。

<div id="differences">
  #### 差异
</div>

**端点 URL**

* 标准 v1.1 端点：
  * POST https://api.x.com/1.1/friendships/create.json
    （关注用户）
  * POST https://api.x.com/1.1/friendships/destroy.json
    （取消关注用户）
* X API v2 端点：
  * POST https://api.x.com/2/users/:id/following
    （关注用户）
  * DELETE https://api.x.com/2/users/:source&#95;user&#95;id/following/:target&#95;user&#95;id
    （取消关注用户）

**App 和 Project 要求**

在对请求进行身份验证时，X API v2 端点要求你使用与某个 [Project](/zh/resources/fundamentals/developer-apps) 关联的[开发者 App](/zh/resources/fundamentals/developer-apps) 的凭证。所有 X API v1.1 端点都可以使用来自 App 或与某个 Project 关联的 App 的凭证。

**请求参数**

以下标准 v1.1 请求参数在 X API v2 中有对应项：

| 标准 v1.1 | X API v2 |
| :--- | :--- |
| 无对应项 | id (POST), source&#95;user&#95;id (DELETE) |
| user&#95;id | target&#95;user&#95;id |
| screen&#95;name | 无对应项 |

请注意，标准 v1.1 参数作为查询参数传递，而 X API v2 参数则作为请求体参数（用于 POST 端点）或路径参数（用于 DELETE 端点）传递。

另外，在使用标准 v1.1 端点时，不需要提供 v2 的 id 和 source&#95;user&#95;id，因为通过 OAuth 1.0a 用户上下文传递的 Access Tokens 就可以推断出是哪位用户发起了关注/取消关注操作。

<div id="follow-a-user-v2">
  ### 关注用户（v2）
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/following" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"target_user_id": "2244994945"}'
  ```

  ```python Python
  # 需要使用 OAuth 1.0a 用户上下文进行身份验证
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/following"
  response = requests.post(url, auth=auth, json={"target_user_id": "2244994945"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 关注用户
  response = client.users.follow(
      source_user_id="123456789",
      target_user_id="2244994945"
  )
  print(f"Following: {response.data.following}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 关注用户
  const response = await client.users.follow("123456789", {
    targetUserId: "2244994945",
  });
  console.log(`Following: ${response.data?.following}`);
  ```
</CodeGroup>
