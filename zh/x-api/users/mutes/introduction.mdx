Mutes 端点使你可以对用户进行静音和取消静音，并获取经过身份验证的用户所静音的用户列表。

<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/muting`](/zh/x-api/users/get-muting) | 获取被静音的用户 |
| POST | [`/2/users/:id/muting`](/zh/x-api/users/mute-user) | 将用户静音 |
| DELETE | [`/2/users/:source_user_id/muting/:target_user_id`](/zh/x-api/users/unmute-user) | 取消对用户的静音 |

***

<div id="example-get-muted-users">
  ## 示例：获取已静音的用户
</div>

```bash
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-mute-a-user">
  ## 示例：将某个用户静音
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/muting" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
