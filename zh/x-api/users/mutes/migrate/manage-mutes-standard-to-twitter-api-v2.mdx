<div id="manage-mutes-standard-v11-compared-to-x-api-v2">
  ### 管理静音：标准版 v1.1 与 X API v2 的比较
</div>

如果你一直在使用标准版 v1.1 的 [POST mutes/users/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-create) 和 [POST mutes/users/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-destroy) 端点，本指南旨在帮助你了解标准版 v1.1 与 X API v2 中管理静音端点之间的相同点和不同点。

* **相似点**
  * OAuth 1.0a 用户上下文
* **差异**
  * 端点 URL
  * 应用和 Project 要求
  * HTTP 方法
  * 请求参数

<div id="similarities">
  #### 相似点
</div>

**OAuth 1.0a 用户上下文认证方式**

这两个端点版本都支持 [OAuth 1.0a 用户上下文](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication)。因此，如果你之前使用的是标准 v1.1 的某个管理静音（manage mutes）端点，那么在迁移到 X API v2 版本后，可以继续使用相同的认证方式。

<div id="differences">
  #### 差异
</div>

**端点 URL**

* 标准 v1.1 端点：
  * POST https://api.x.com/1.1/mutes/users/create.json
    （将用户静音）
  * POST https://api.x.com/1.1/mutes/users/destroy.json
    （取消对用户静音）
* X API v2 端点：
  * POST https://api.x.com/2/users/:id/muting
    （将用户静音）
  * DELETE https://api.x.com/2/users/:source&#95;user&#95;id/muting/:target&#95;user&#95;id
    （取消对用户静音）

**App 和 Project 要求**

在对请求进行身份验证时，X API v2 端点要求你使用与某个 [developer App](/zh/resources/fundamentals/developer-apps) 关联并属于某个 [Project](/zh/resources/fundamentals/developer-apps) 的凭证。所有 X API v1.1 端点都可以使用来自 App 或与某个 Project 关联的 App 的凭证。

**请求参数**

以下标准 v1.1 请求参数在 X API v2 中有对应项：

| 标准 v1.1 | X API v2 |
| :--- | :--- |
| user&#95;id | target&#95;user&#95;id |
| screen&#95;name | 无对应项 |

请注意，标准 v1.1 参数作为查询参数传递，而 X API v2 参数则作为请求体参数（用于 POST 端点）或路径参数（用于 DELETE 端点）传递。

另外，当使用标准 v1.1 端点时，不需要提供发起对目标用户静音的用户 id，因为随 [OAuth 1.0a User Context](/zh/resources/fundamentals/authentication) 传递的访问令牌可以推断出是哪位用户在发起静音/取消静音操作。

<div id="mute-a-user-v2">
  ### 静音用户（v2）
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/muting" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"target_user_id": "2244994945"}'
  ```

  ```python Python
  # 需要使用 OAuth 1.0a 用户上下文进行身份验证
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/muting"
  response = requests.post(url, auth=auth, json={"target_user_id": "2244994945"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 静音用户
  response = client.users.mute(
      source_user_id="123456789",
      target_user_id="2244994945"
  )
  print(f"Muting: {response.data.muting}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 静音用户
  const response = await client.users.mute("123456789", {
    targetUserId: "2244994945",
  });
  console.log(`Muting: ${response.data?.muting}`);
  ```
</CodeGroup>

<div id="unmute-a-user-v2">
  ### 取消静音某个用户 (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/123456789/muting/2244994945" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  # 需要使用 OAuth 1.0a 用户上下文认证
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"

  response = requests.delete(url, auth=auth)
  print(response.json())
  ```
