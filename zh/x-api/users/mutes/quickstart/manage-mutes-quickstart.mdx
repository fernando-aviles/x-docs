本指南将引导你使用 X API 将用户静音或取消静音。

<Note>
  **前提条件**

  在开始之前，你需要：

  * 一个拥有已批准 App 的 [开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)
  * 用户访问令牌（OAuth 1.0a 或 OAuth 2.0 PKCE）
</Note>

***

<div id="mute-a-user">
  ## 静音某个用户
</div>

<Steps>
  <Step title="获取你的用户 ID">
    你需要你经过身份验证的用户 ID。你可以使用 [用户查询端点](/zh/x-api/users/lookup/introduction) 查找它，或者从你的 Access Token 中获取（其中的数字部分就是你的用户 ID）。
  </Step>

  <Step title="获取目标用户 ID">
    使用 [用户查询端点](/zh/x-api/users/lookup/introduction) 查找你想要静音的账户的用户 ID。
  </Step>

  <Step title="发送静音请求">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/users/123456789/muting" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"target_user_id": "9876543210"}'
      ```

      ```python Python SDK
      from xdk import Client
      from xdk.oauth1_auth import OAuth1

      oauth1 = OAuth1(
          api_key="YOUR_API_KEY",
          api_secret="YOUR_API_SECRET",
          access_token="YOUR_ACCESS_TOKEN",
          access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
      )

      client = Client(auth=oauth1)

      # 静音某个用户
      response = client.users.mute(
          source_user_id="123456789",
          target_user_id="9876543210"
      )

      print(f"Muting: {response.data.muting}")
      ```

      ```javascript JavaScript SDK
      import { Client, OAuth1 } from "@xdevplatform/xdk";

      const oauth1 = new OAuth1({
        apiKey: "YOUR_API_KEY",
        apiSecret: "YOUR_API_SECRET",
        accessToken: "YOUR_ACCESS_TOKEN",
        accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
      });

      const client = new Client({ oauth1 });

      // 静音某个用户
      const response = await client.users.mute("123456789", {
        targetUserId: "9876543210",
      });

      console.log(`Muting: ${response.data?.muting}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="查看响应">
    ```json
    {
      "data": {
        "muting": true
      }
    }
    ```
  </Step>
</Steps>

<div id="unmute-a-user">
  ## 取消对用户的静音
</div>

将某个用户从静音列表中移除：

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/123456789/muting/9876543210" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 取消对用户的静音
  response = client.users.unmute(
      source_user_id="123456789",
      target_user_id="9876543210"
  )

  print(f"Muting: {response.data.muting}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 取消对用户的静音
  const response = await client.users.unmute("123456789", "9876543210");

  console.log(`Muting: ${response.data?.muting}`);
  ```
</CodeGroup>

**响应：**

```json
{
  "data": {
    "muting": false
  }
}
```

<div id="mute-vs-block">
  ## 静音 vs 屏蔽
</div>

| 功能 | 静音 | 屏蔽 |
|:--------|:-----|:------|
| 是否能看到他们的帖子 | 否 | 否 |
| 他们是否能看到你的帖子 | 是 | 否 |
| 他们是否可以关注你 | 是 | 否 |
| 他们是否可以向你发送私信 | 是 | 否 |
| 对方是否会知道 | 否 | 是 |
