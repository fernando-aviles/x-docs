<div id="authentication">
  ## 身份验证
</div>

Mute 相关端点需要用户身份验证才能访问私密静音列表：

| Method | Description |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/zh/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | 建议用于新应用 |
| [OAuth 1.0a User Context](/zh/resources/fundamentals/authentication) | 为旧版集成提供支持 |

<Warning>
  不支持仅应用程序身份验证（App-Only authentication）。你必须以用户身份进行身份验证。
</Warning>

<div id="required-scopes-oauth-20">
  ### 必需的 Scope（OAuth 2.0）
</div>

| Scope | 必需用于的操作 |
|:------|:-------------|
| `mute.read` | 获取已静音的账号 |
| `mute.write` | 对账号执行静音和取消静音操作 |
| `users.read` | 与静音相关的 scope 一起使用时为必需 |

<div id="endpoints-overview">
  ## 端点概览
</div>

| 方法 | 端点 | 说明 |
|:-------|:---------|:------------|
| GET | `/2/users/:id/muting` | 获取已静音的账号列表 |
| POST | `/2/users/:id/muting` | 将账号静音 |
| DELETE | `/2/users/:source_user_id/muting/:target_user_id` | 取消账号静音 |

### 包含字段参数的示例

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123456789/muting?\
  user.fields=username,verified,created_at&\
  max_results=100" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 获取包含附加字段的被静音用户
  for page in client.users.get_muting(
      user_id="123456789",
      user_fields=["username", "verified", "created_at"],
      max_results=100
  ):
      for user in page.data:
          print(f"{user.username} - Verified: {user.verified}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  const paginator = client.users.getMuting("123456789", {
    userFields: ["username", "verified", "created_at"],
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(`${user.username} - Verified: ${user.verified}`);
    });
  }
  ```
</CodeGroup>

<div id="behavior-differences">
  ## 分页
</div>

对于静音列表较大的用户，结果会进行分页：

<CodeGroup dropdown>
  ```bash cURL
  # 第一次请求
  curl "https://api.x.com/2/users/123/muting?max_results=100" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"

  # 携带分页令牌的后续请求
  curl "https://api.x.com/2/users/123/muting?max_results=100&pagination_token=NEXT_TOKEN" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # SDK 会自动处理分页
  all_muted = []

  for page in client.users.get_muting(user_id="123", max_results=100):
      if page.data:
          all_muted.extend(page.data)

  print(f"Muted {len(all_muted)} users")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  async function getAllMutedUsers(userId) {
    const allMuted = [];

    // SDK 会自动处理分页
    const paginator = client.users.getMuting(userId, { maxResults: 100 });

    for await (const page of paginator) {
      if (page.data) {
        allMuted.push(...page.data);
      }
    }

    return allMuted;
  }

  // 用法
  const muted = await getAllMutedUsers("123");
  console.log(`Muted ${muted.length} users`);
  ```
</CodeGroup>

## 行为差异

### 静音与拉黑

| 功能 | 静音 | 拉黑 |
|:--------|:-----|:------|
| 你能看到他们的帖子 | 否（已隐藏） | 否 |
| 他们能看到你的帖子 | 是 | 否 |
| 他们能关注你 | 是（可以关注） | 否（已取消关注） |
| 他们能向你发送私信 | 是 | 否 |
| 是否会发送通知 | 否 | 否 |

<Tip>
  静音是私密的——被静音的用户不会收到通知，也无法察觉自己已经被静音。
</Tip>

<div id="next-steps">
  ## 错误处理
</div>

| 状态码 | 错误 | 解决方案 |
|:-------|:------|:---------|
| 400 | 无效请求 | 检查用户 ID 格式是否正确 |
| 401 | 未授权 | 检查访问令牌 |
| 403 | 禁止访问 | 检查权限范围（scopes）和权限设置 |
| 404 | 未找到 | 用户不存在 |
| 429 | 请求过多 | 等待一段时间后重试 |
