Blocks 端点可用于屏蔽和取消屏蔽用户，并获取已认证用户所屏蔽用户的列表。

  ## 概览

***

<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/blocking`](/zh/x-api/users/get-blocking) | 获取已屏蔽的用户 |
| POST | [`/2/users/:id/blocking`](/zh/x-api/users/block-dms) | 屏蔽用户 |
| DELETE | `/2/users/:source_user_id/blocking/:target_user_id` | 取消屏蔽用户 |

***

<div id="example-get-blocked-users">
  ## 示例：获取被拉黑的用户
</div>

```bash
curl "https://api.x.com/2/users/123456789/blocking?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-block-a-user">
  ## 示例：屏蔽用户
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/blocking" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
