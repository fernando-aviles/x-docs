<div id="blocks-lookup-standard-v11-compared-to-x-api-v2">
  ### 屏蔽查询：标准版 v1.1 与 X API v2 的对比
</div>

如果你一直在使用标准版 v1.1 的 [GET blocks/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-blocks-ids) 和 [GET blocks/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-blocks-list) 端点，本指南的目标是帮助你理解标准版 v1.1 与 X API v2 屏蔽查询端点之间的相似之处和差异。

* **相似之处**
  * 身份验证
* **不同点**
  * 端点 URL

  * 每次请求的用户数量限制

  * App 和 Project 要求

  * 响应数据格式

  * 请求参数

<div id="similarities">
  #### 相似之处
</div>

**身份验证**

标准 v1.1 和 X API v2 的屏蔽查询（blocks lookup）端点都使用 [OAuth 1.0a 用户上下文](/zh/resources/fundamentals/authentication#oauth-1-0a-2)。因此，如果你之前使用的是标准 v1.1 的某个屏蔽查询端点，那么在迁移到 X API v2 版本时，可以继续使用相同的身份验证方法。 

<div id="differences">
  #### 差异
</div>

**Endpoint URLs**

* 标准 v1.1 endpoints：
  * GET https://api.x.com/1.1/blocks/ids.json
    （由指定用户屏蔽的用户 ID 列表）
  * GET https://api.x.com/1.1/blocks/lists.json
    （由指定用户屏蔽的用户列表）
* X API v2 endpoint：
  * GET https://api.x.com/2/users/:id/blocking
    （由指定用户 ID 屏蔽的用户列表）
     

**每次请求的用户数量限制**

标准 v1.1 endpoints 每次请求最多可返回 5000 个用户。新的 v2 endpoints 每次请求最多可返回 1000 个用户。要返回完整的 1000 个用户，你需要在查询参数中传入 max&#95;results=1000；然后可以将响应载荷中返回的 next&#95;token 作为下一次请求中 pagination&#95;token 查询参数的值。 

**App 和 Project 要求**

在为请求进行认证时，X API v2 endpoints 要求你使用与某个 [Project](/zh/resources/fundamentals/developer-apps) 关联的 [developer App](/zh/resources/fundamentals/developer-apps) 的凭证。所有 X API v1.1 endpoints 都可以使用来自独立 App 或与 Project 关联的 App 的凭证。

**响应数据格式**

标准 v1.1 与 X API v2 版本的 endpoints 之间最大的差异之一，是你如何选择要在载荷中返回哪些字段。

对于标准 endpoints，你默认会收到许多响应字段，然后可以选择使用参数来指定哪些字段或字段集合应在载荷中返回。

X API v2 版本默认只返回用户的 id、name 和 username 字段。若要请求任何额外的字段或对象，你需要使用 [fields](/zh/x-api/fundamentals/fields) 和 [expansions](/zh/x-api/fundamentals/expansions) 参数。你从此 endpoint 请求的任何用户字段都会返回在主 user 对象中。任何扩展的 Post 对象及其字段都会返回在响应中的 includes 对象内。然后，你可以通过匹配 user 对象与扩展 Post 对象中出现的 ID，将任何扩展对象匹配回 user 对象。 

我们建议你在各自的指南中进一步了解这些新参数，或者阅读我们的[如何使用 fields 和 expansions](/zh/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions) 指南。 

我们还整理了一份[数据格式迁移指南](/zh/x-api/migrate/data-format-migration#migrating-from-standard-v1-1s-data-format-to-v2)，帮助你将标准 v1.1 字段映射到较新的 v2 字段。该指南还会提供你在 v2 请求中为返回特定字段所需传入的具体 expansion 和 field 参数。 
 

除了你如何请求某些字段方面的更改之外，X API v2 还为 API 返回的对象引入了新的 JSON 设计，包括 [帖](/zh/x-api/fundamentals/data-dictionary#tweet)子和 [user](/zh/x-api/fundamentals/data-dictionary#user) 对象。

* 在 JSON 根级别，标准 endpoints 会在 statuses 数组中返回 Post 对象，而 X API v2 会返回 data 数组。 
* X API v2 JSON 不再引用被转发和被引用的 “statuses”，而是引用被转发和被引用的 Tweets。许多传统和已弃用字段（例如 contributors 和 user.translator&#95;type）正在被移除。 
* X API v2 使用术语 like，替代之前在 Post 对象中的 favorites 和在 user 对象中的 favourites。 
* X 采用的约定是：没有值的 JSON 字段（例如 null）不会写入载荷。Post 和 user 属性仅在具有非 null 值时才会被包含。 
   

我们还在 [Post 对象](/zh/x-api/fundamentals/data-dictionary#tweet)中引入了一组新字段，包括：

* 一个 [conversation&#95;id](/zh/x-api/fundamentals/conversation-id) 字段
* 两个新的 [annotations](/zh/x-api/fundamentals/post-annotations) 字段，包括 context 和 entities
* 若干新的 [metrics](/zh/x-api/fundamentals/metrics) 字段 
* 一个新的 reply&#95;setting 字段，用于指示哪些人可以回复指定的 Post

**请求参数**

以下标准 v1.1 请求接受两个查询参数（user&#95;id 或 screen&#95;name）。在 X API v2 中，则只接受数值型的用户 id，且必须作为端点路径的一部分传入。

<div id="get-blocked-users-v2">
  ### 获取当前用户屏蔽的用户 (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123456789/blocking?user.fields=username,verified&max_results=100" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  # 需要使用 OAuth 1.0a 用户上下文认证
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/blocking"
  params = {"user.fields": "username,verified", "max_results": 100}

  response = requests.get(url, auth=auth, params=params)
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 分页获取当前用户屏蔽的用户
  for page in client.users.get_blocking(
      "123456789",
      user_fields=["username", "verified"],
      max_results=100
  ):
      for user in page.data:
          print(f"{user.username} - Verified: {user.verified}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 分页获取当前用户屏蔽的用户
  const paginator = client.users.getBlocking("123456789", {
    userFields: ["username", "verified"],
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(`${user.username} - Verified: ${user.verified}`);
    });
  }
  ```

<div id="block-a-user-v2">
  ### 屏蔽用户 (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/blocking" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"target_user_id": "2244994945"}'
  ```

  ```python Python
  # 需要使用 OAuth 1.0a 用户上下文认证
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/blocking"
  response = requests.post(url, auth=auth, json={"target_user_id": "2244994945"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 屏蔽用户
  response = client.users.block(
      source_user_id="123456789",
      target_user_id="2244994945"
  )
  print(f"Blocking: {response.data.blocking}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 屏蔽用户
  const response = await client.users.block("123456789", {
    targetUserId: "2244994945",
  });
  console.log(`Blocking: ${response.data?.blocking}`);
  ```
