<div id="authentication">
  ## 身份验证
</div>

Block 端点需要用户身份验证：

| 方法 | 描述 |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/zh/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | 推荐用于新的应用 |
| [OAuth 1.0a User Context](/zh/resources/fundamentals/authentication) | 用于兼容旧版 |

<Warning>
  不支持仅 App 身份验证。你必须代表用户进行身份验证。
</Warning>

<div id="required-scopes-oauth-20">
  ### 所需权限范围（OAuth 2.0）
</div>

| Scope | 适用于 |
|:------|:-------------|
| `block.read` | 获取被屏蔽的账号 |
| `block.write` | 屏蔽和取消屏蔽账号 |
| `users.read` | 在使用屏蔽相关权限范围时必需 |

<div id="endpoints-overview">
  ## 端点概览
</div>

| 方法 | Endpoint | 说明 |
|:-------|:---------|:------------|
| GET | `/2/users/:id/blocking` | 获取被屏蔽账户列表 |
| POST | `/2/users/:id/blocking` | 屏蔽一个账户 |
| DELETE | `/2/users/:source_user_id/blocking/:target_user_id` | 取消屏蔽一个账户 |

<div id="pagination">
  ## 分页
</div>

对于屏蔽列表较大的用户，结果会进行分页：

<CodeGroup dropdown>
  ```bash cURL
  # 首个请求
  curl "https://api.x.com/2/users/123/blocking?max_results=100" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"

  # 带有分页令牌的后续请求
  curl "https://api.x.com/2/users/123/blocking?max_results=100&pagination_token=NEXT_TOKEN" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  # 使用 OAuth 2.0 用户访问令牌
  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # SDK 会自动处理分页
  all_blocked = []

  for page in client.users.get_blocking(user_id="123", max_results=100):
      if page.data:
          all_blocked.extend(page.data)

  print(f"Blocked {len(all_blocked)} users")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  async function getAllBlockedUsers(userId) {
    const allBlocked = [];

    // SDK 会自动处理分页
    const paginator = client.users.getBlocking(userId, { maxResults: 100 });

    for await (const page of paginator) {
      if (page.data) {
        allBlocked.push(...page.data);
      }
    }

    return allBlocked;
  }

  // 用法
  const blocked = await getAllBlockedUsers("123");
  console.log(`Blocked ${blocked.length} users`);
  ```
</CodeGroup>

<div id="error-handling">
  ## 错误处理
</div>

| 状态码 | 错误 | 解决方案 |
|:-------|:------|:---------|
| 400 | 无效请求 | 检查用户 ID 格式 |
| 401 | 未经授权 | 验证访问令牌 |
| 403 | 无权限访问 | 检查作用域（scopes）和权限 |
| 404 | 未找到 | 用户不存在 |
| 429 | 请求过于频繁 | 等待后重试 |
