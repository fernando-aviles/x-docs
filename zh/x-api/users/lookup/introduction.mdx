用户查询端点允许你检索一个或多个用户的个人资料信息。你可以通过他们的 id 或用户名来查询用户，或获取当前已认证用户的详细信息。

  ## 概览
</div>

<CardGroup cols={2}>
  <Card title="按 ID 查询" icon="fingerprint">
    通过用户的唯一 ID 查找用户
  </Card>

  <Card title="按用户名查询" icon="at">
    通过用户的 @用户名 查找用户
  </Card>

  <Card title="多个用户" icon="users">
    每次请求最多返回 100 个用户
  </Card>

  <Card title="已认证用户" icon="user-check">
    获取当前用户的详细信息
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/users/:id`](/zh/x-api/users/get-user-by-id) | 通过 ID 获取用户 |
| GET | [`/2/users`](/zh/x-api/users/get-users-by-ids) | 通过多个 ID 获取用户（最多 100 个） |
| GET | [`/2/users/by/username/:username`](/zh/x-api/users/get-user-by-username) | 通过用户名获取用户 |
| GET | [`/2/users/by`](/zh/x-api/users/get-users-by-usernames) | 通过多个用户名获取用户（最多 100 个） |
| GET | [`/2/users/me`](/zh/x-api/users/get-my-user) | 获取当前已认证用户 |

***

<div id="example-request">
  ## 请求示例
</div>

```bash
curl "https://api.x.com/2/users/by/username/XDevelopers?\
user.fields=created_at,description,public_metrics,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## 响应示例
</div>

```json
{
  "data": {
    "id": "2244994945",

      "followers_count": 583423,
      "following_count": 2048,

  }
}
```
