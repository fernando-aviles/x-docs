User 查询端点允许你获取一个或多个用户的个人资料信息。你可以通过用户的 id 或用户名来查询，或获取当前已认证用户的详细信息。

<div id="overview">
  ## 概览
</div>

<CardGroup cols={2}>
  <Card title="按 ID" icon="fingerprint">
    按唯一用户 ID 查找用户
  </Card>

  <Card title="按用户名" icon="at">
    按用户的 @handle（用户名）查找用户
  </Card>

  <Card title="多个用户" icon="users">
    每个请求最多可检索 100 名用户
  </Card>

  <Card title="已认证用户" icon="user-check">
    获取当前已认证用户的详细信息
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id`](/zh/x-api/users/get-user-by-id) | 根据 ID 获取用户 |
| GET | [`/2/users`](/zh/x-api/users/get-users-by-ids) | 根据多个 ID 批量获取用户（最多 100 个） |
| GET | [`/2/users/by/username/:username`](/zh/x-api/users/get-user-by-username) | 根据用户名获取用户 |
| GET | [`/2/users/by`](/zh/x-api/users/get-users-by-usernames) | 根据多个用户名批量获取用户（最多 100 个） |
| GET | [`/2/users/me`](/zh/x-api/users/get-my-user) | 获取当前已认证的用户 |

***

<div id="example-request">
  ## 示例请求
</div>

```bash
curl "https://api.x.com/2/users/by/username/XDevelopers?\
user.fields=created_at,description,public_metrics,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## 示例响应
</div>

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "XDevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "The voice of the X developer community",

    "public_metrics": {
      "followers_count": 583423,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```
