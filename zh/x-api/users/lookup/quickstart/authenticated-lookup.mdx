本指南将引导你通过 `/me` 端点获取当前已认证的用户资料。

<Note>
  **前提条件**

  在开始之前，你需要：

  * 一个具有已获批准 App 的[开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)
  * 用户访问令牌（OAuth 1.0a 或 OAuth 2.0 PKCE）
</Note>

***

<div id="get-the-authenticated-user">
  ## 获取已认证用户
</div>

使用用户访问令牌向 `/me` 端点发起请求：

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/me?\
  user.fields=created_at,description,verified,public_metrics,profile_image_url" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 获取已认证用户
  response = client.users.get_me(
      user_fields=["created_at", "description", "verified", "public_metrics", "profile_image_url"]
  )

  print(f"Username: {response.data.username}")
  print(f"ID: {response.data.id}")
  print(f"Followers: {response.data.public_metrics.followers_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 获取已认证用户
  const response = await client.users.getMe({
    userFields: ["created_at", "description", "verified", "public_metrics", "profile_image_url"],
  });

  console.log(`Username: ${response.data?.username}`);
  console.log(`ID: ${response.data?.id}`);
  console.log(`Followers: ${response.data?.public_metrics?.followers_count}`);
  ```
</CodeGroup>

<div id="use-case">
  ## 使用场景
</div>

在以下场景下，`/me` 端点至关重要：

* **验证身份** — 确认用户已正确通过身份验证
* **获取用户 ID** — 为后续 API 调用检索已认证用户的 ID
* **个性化体验** — 在你的应用中展示用户的个人资料
* **代表用户发起请求** — 明确你正在代表哪位用户发起请求

<div id="include-pinned-post">
  ## 包含置顶帖子
</div>

请求获取用户的置顶帖子：

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/me?\
  user.fields=pinned_tweet_id&\
  expansions=pinned_tweet_id&\
  tweet.fields=created_at,text" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 获取包含置顶帖子的已认证用户信息
  response = client.users.get_me(
      user_fields=["pinned_tweet_id"],
      expansions=["pinned_tweet_id"],
      tweet_fields=["created_at", "text"]
  )

  print(f"Username: {response.data.username}")
  # 置顶帖子位于 response.includes.tweets 中
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 获取包含置顶帖子的已认证用户信息
  const response = await client.users.getMe({
    userFields: ["pinned_tweet_id"],
    expansions: ["pinned_tweet_id"],
    tweetFields: ["created_at", "text"],
  });

  console.log(`Username: ${response.data?.username}`);
  // 置顶帖子位于 response.includes?.tweets 中
  ```
</CodeGroup>

<div id="available-fields">
  ## 可用字段
</div>

| 字段 | 描述 |
|:------|:------------|
| `created_at` | 账号创建日期 |
| `description` | 用户简介 |
| `profile_image_url` | 头像 URL |
| `verified` | 认证状态 |
| `public_metrics` | 粉丝数/关注数 |
| `location` | 用户自定义位置信息 |
| `url` | 用户网站 |
| `protected` | 受保护账号状态 |
| `pinned_tweet_id` | 置顶帖子 id |

<div id="authentication-requirement">
  ## 身份验证要求
</div>

<Warning>
  `/me` 端点需要使用用户上下文身份验证。不支持仅应用（Bearer Token）身份验证。
</Warning>

请选择以下任一方式：

* [OAuth 1.0a 用户上下文](/zh/resources/fundamentals/authentication)
* [OAuth 2.0 带 PKCE 的授权码模式](/zh/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)
