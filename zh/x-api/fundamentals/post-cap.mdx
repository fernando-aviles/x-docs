X API v2 采用**按使用量付费**的定价模式。您的费用会根据应用实际的 API 使用量进行统计和结算。

***

<div id="how-billing-works">
  ## 计费方式说明
</div>

| 概念 | 说明 |
|:--------|:------------|
| **基于额度** | 预先购买额度，在调用 API 时按使用量扣减 |
| **按请求计费** | 不同的接口费用不同 |
| **实时跟踪** | 在开发者控制台中监控使用情况 |
| **无上限** | 按需使用——没有每月用量上限 |

<div id="deduplication">
  ## 去重
</div>

<Note>
  **按日去重**：如果同一条帖子在一天内通过多个查询返回，在计费时只会被计算一次。
</Note>

这意味着：

* 在同一天内多次获取同一条帖子 = 收费 1 次
* 第二天再次获取同一条帖子 = 额外再收费 1 次
* 同一请求中包含多条不同帖子 = 每条分别计费

</div>

有关当前每个端点和操作的定价，请访问 [开发者控制台](https://console.x.com)。

<div id="faqs">
  ## 常见问题
</div>

<Accordion title="如果我的额度用完会发生什么？">
  在你购买更多额度之前，所有 API 请求都会失败。请设置余额提醒以避免服务中断。
</Accordion>

<Accordion title="是否有每月最低消费？">
  没有。只需为你的实际使用付费。你可以有零使用、零费用的月份。
</Accordion>

<Accordion title="流式传输如何计费？">
  通过过滤流传送的每条唯一帖子都会计入用量，并按日进行去重。
</Accordion>

<Accordion title="失败的请求会计入用量吗？">
  不会。只有返回 data 的成功响应才会产生计费。
</Accordion>
