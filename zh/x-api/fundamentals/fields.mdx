X API v2 默认仅返回最基本的数据。使用 **fields 参数** 请求每种对象类型的额外数据。

***

<div id="how-fields-work">
  ## 字段的工作方式
</div>

默认情况下，帖子查询只会返回 `id`、`text` 和 `edit_history_tweet_ids`。要获取更多数据，请在请求中添加字段参数：

```bash
# 默认响应 - 最少字段
curl "https://api.x.com/2/tweets/1234567890" \
  -H "Authorization: Bearer $TOKEN"

# With additional fields
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=created_at,public_metrics,author_id" \
  -H "Authorization: Bearer $TOKEN"
```

***

<div id="available-field-parameters">
  ## 可用字段参数
</div>

每种对象类型都有其对应的字段参数：

| 对象 | 参数 | 文档 |
|:-------|:----------|:--------------|
| 帖子（Tweet） | `tweet.fields` | [帖子字段](/zh/x-api/fundamentals/data-dictionary#tweet) |
| 用户 | `user.fields` | [用户字段](/zh/x-api/fundamentals/data-dictionary#user) |
| 媒体 | `media.fields` | [媒体字段](/zh/x-api/fundamentals/data-dictionary#media) |
| 投票 | `poll.fields` | [投票字段](/zh/x-api/fundamentals/data-dictionary#poll) |
| 地点 | `place.fields` | [地点字段](/zh/x-api/fundamentals/data-dictionary#place) |

<div id="example-post-fields">
  ## 示例：帖子字段
</div>

使用 `tweet.fields` 请求特定的帖子字段：

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=created_at,public_metrics,lang" \
  -H "Authorization: Bearer $TOKEN"
```

响应：

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "edit_history_tweet_ids": ["1234567890"],
    "created_at": "2024-01-15T12:00:00.000Z",
    "lang": "en",
    "public_metrics": {
      "retweet_count": 10,
      "reply_count": 5,
      "like_count": 100,
      "quote_count": 2
    }
  }
}
```

<div id="example-user-fields">
  ## 示例：用户字段
</div>

使用 `user.fields` 请求特定用户的字段：

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers?user.fields=created_at,description,public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

响应：

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "X 开发者平台的声音",
    "public_metrics": {
      "followers_count": 570842,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```

<div id="fields-for-related-objects">
  ## 关联对象的字段
</div>

要获取关联对象（例如帖子的作者）的字段，你需要满足两个条件：

1. 一个用于包含关联对象的**扩展（expansion）**
2. 该对象类型的**字段参数（fields 参数）**

```bash
# 获取帖子及作者详细信息
curl "https://api.x.com/2/tweets/1234567890?expansions=author_id&user.fields=description,public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

响应：

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "author_id": "2244994945"
  },
  "includes": {
    "users": [{
      "id": "2244994945",
      "name": "X Developers",
      "username": "xdevelopers",
      "description": "X 开发者平台的官方声音",
      "public_metrics": {
        "followers_count": 570842,
        "following_count": 2048
      }
    }]
  }
}
```

  ## 常用字段组合
</div>

<Tabs>
  <Tab title="帖子分析数据">

    ```
    tweet.fields=created_at,author_id,conversation_id,in_reply_to_user_id,referenced_tweets

    ```
  </Tab>

  <Tab title="媒体详细信息">
    ```
    tweet.fields=attachments
    expansions=attachments.media_keys
    media.fields=url,preview_image_url,alt_text,public_metrics
    ```
  </Tab>
</Tabs>

<div id="important-notes">
  ## 重要说明
</div>

<Warning>
  **你无法请求子字段。** 当你请求 `public_metrics` 时，你会获得所有指标（点赞、转发、回复、引用）。你不能只请求 `public_metrics.like_count`。
</Warning>

* 响应中的字段顺序可能与请求中的顺序不同
* 如果响应中缺少某个字段，表示其值为 `null` 或为空
* 某些字段需要特定的身份验证（例如，私有指标需要用户上下文）
* 查看每个端点的 API 参考以了解可用字段
