X API 返回结构化的 JSON 对象，表示帖子、用户、媒体等内容。本参考文档列出了每种对象类型可用的所有字段。

<div id="post-tweet">
  ## Post (Tweet)
</div>

帖子是 X 上的核心内容单元。每个 Post 对象都包含文本、元数据，以及对作者、媒体和投票等相关对象的引用。

**默认字段：** `id`, `text`, `edit_history_tweet_ids`

使用 `tweet.fields` 请求附加字段，并使用 `expansions` 包含相关对象。

<div id="all-post-fields">
  ### 所有帖子字段
</div>

| 字段                                         | 类型           | 描述                                                                                              | 用途                            |
| :----------------------------------------- | :----------- | :---------------------------------------------------------------------------------------------- | :---------------------------- |
| **id（默认）**                                 | string       | 所请求推文的唯一标识符。                                                                                    | 使用此字段以编程方式检索特定推文。             |
| **text（默认）**                               | string       | 推文的实际 UTF-8 文本内容。有关有效字符的详细信息，请参阅 [twitter-text](https://github.com/twitter/twitter-text/)。      | 用于关键词抽取以及情感分析/情感分类。           |
| **edit&#95;history&#95;tweet&#95;ids（默认）** | object       | 表示某条推文所有版本的唯一标识符。对于没有编辑记录的推文，只有一个 ID；对于存在编辑历史的推文，会有多个 ID。                                       | 使用此信息来查询某条推文的编辑历史。            |
| **article**                                | object       | 包含此推文中 Article 的元数据。                                                                            | 使用此字段获取 Article 的文本和实体信息。     |
| **attachments**                            | object       | 指定此推文中存在的附件类型（如果有）。                                                                             | 用于了解针对所请求的扩展所返回的对象。           |
| **author&#95;id**                          | string       | 发布此推文的用户（User）的唯一标识符。                                                                           | 用于填充 User 对象，以及在同行评审中共享数据集。   |
| **card&#95;uri**                           | string       | 此推文中 Card 的 URI。                                                                                |                               |
| **community&#95;id**                       | string       | 该帖子所属 Community 的唯一标识符。                                                                         |                               |
| **context&#95;annotations**                | array        | 包含该推文的上下文标注信息。                                                                                  | 用于实体识别/抽取和主题分析。               |
| **conversation&#95;id**                    | string       | 此会话中原始推文的推文 ID（包括直接回复和回复的回复）。                                                                   | 使用此字段从一条推文还原整段对话。             |
| **created&#95;at**                         | 日期（ISO 8601） | 该推文的创建时间。                                                                                       | 可用于时间序列分析以及了解其创建时间。           |
| **display&#95;text&#95;range**             | array        | 一个数组，包含要显示文本片段的起始和结束索引。                                                                         | 对于长帖子，可用于确定默认显示的文本部分。         |
| **edit&#95;controls**                      | object       | 指示该推文还能编辑多长时间以及剩余的可编辑次数。                                                                        | 使用此字段确定某条推文是否仍可编辑。            |
| **entities**                               | 对象           | 从帖子文本中解析出的实体。参见 Tweet 对象中的 entities 字段。                                                         | 提供关于主题标签、URL、提及等的附加信息。        |
| **geo**                                    | 对象           | 指示带地理标签的帖子的位置或地点。                                                                               | 使用此字段来确定带地理标签帖子的具体位置。         |
| **in&#95;reply&#95;to&#95;user&#95;id**    | 字符串          | 如果所表示的帖子是一条回复，此字段将包含原始帖子作者的 ID。                                                                 | 用于判断某条帖子是否是对另一条帖子的回复。         |
| **lang**                                   | 字符串          | 帖子的语言（如果已被 Twitter 检测到）。                                                                        | 根据自然语言对帖子进行分类。                |
| **non&#95;public&#95;metrics**             | 对象           | 请求时刻该帖子的非公开互动指标。需要用户上下文身份验证。                                                                    | 用于确定该帖子产生的总展示次数。              |
| **note&#95;tweet**                         | 对象           | 对于长文帖子（超过 280 个字符），包含该帖子的完整文本。                                                                  | 获取帖子的完整文本。                    |
| **organic&#95;metrics**                    | 对象           | 请求时刻该帖子在自然（非推广）场景下跟踪的互动指标。需要用户上下文身份验证。                                                          | 衡量该帖子的自然互动情况。                 |
| **possibly&#95;sensitive**                 | 布尔值          | 指示内容是否可能被识别为敏感内容。                                                                               | 用于研究某些类型内容的传播情况。              |
| **promoted&#95;metrics**                   | 对象           | 请求时刻该帖子在推广场景中跟踪的互动指标。需要用户上下文身份验证。                                                               | 衡量帖子在被推广时的互动情况。               |
| **public&#95;metrics**                     | 对象           | 请求时刻该帖子的公开互动指标。                                                                                 | 衡量帖子的整体互动情况。                  |
| **referenced&#95;tweets**                  | 数组           | 此帖子引用的帖子列表，例如转帖、引用帖子或回复。                                                                        | 用于理解转帖等在对话层面的关联关系。            |
| **reply&#95;settings**                     | 字符串          | 显示谁可以回复指定的帖子。可选值为 &quot;everyone&quot;、&quot;mentioned&#95;users&quot; 和 &quot;followers&quot;。 | 确定该帖子的会话回复设置。                 |
| **withheld**                               | 对象           | 包含[受限内容](https://help.x.com/en/rules-and-policies/tweet-withheld-by-country)的屏蔽详情。              |                               |
| **scopes**                                 | 对象           | 包含该帖子的可见性范围详细信息。                                                                                | 指示谁可以查看该帖子。仅对推广帖子返回。          |
| **media&#95;metadata**                     | 数组           | 推文中媒体附件的元数据。                                                                                    | 获取更多元数据，例如推文媒体附件的 `alt_text`。 |

**检索 Tweet 对象**

**示例请求**

在以下请求中，我们在 [Tweets lookup](/zh/resources/fundamentals/rate-limits) 端点中请求该推文的字段。请务必将 `$BEARER_TOKEN` 替换为你自己生成的 [Bearer Token](/zh/resources/fundamentals/authentication)。

```bash
curl --request GET 'https://api.x.com/2/tweets?ids=1212092628029698048&tweet.fields=attachments,author_id,context_annotations,created_at,entities,geo,id,in_reply_to_user_id,lang,possibly_sensitive,public_metrics,referenced_tweets,text,withheld&expansions=referenced_tweets.id' --header 'Authorization: Bearer $BEARER_TOKEN'
```

<div id="user">
  ### User
</div>

`user` 对象包含描述被引用用户的 Twitter 用户账户的元数据。`user` 对象是在 [users lookup](/zh/x-api/users/lookup/introduction) 端点中返回的主要对象。如果要在此端点请求额外的用户字段，只需使用字段参数 `user.fields`。

`user` 对象也可以作为子对象出现在推文（Tweet）对象中，并在其中被展开。可以通过 `?expansions=author_id` 或 `?expansions=in_reply_to_user_id` 对该对象进行扩展，以获取仅包含默认字段的精简对象。当你需要请求额外字段以补全该对象时，请将 `expansions` 查询参数与字段参数 `user.fields` 结合使用。

  ### Space

Spaces 通过实时音频对话支持表达与互动。Space 数据字典包含与 Space 相关的元数据；所有细节都会实时更新。

User 对象可以在 user 资源中找到并进行扩展。通过在 `expansions` 查询参数中添加至少一个 `host_ids`、`creator_id`、`speaker_ids`、`mentioned_user_ids`，即可返回这些可展开的对象。

<div id="direct-message-events">
  ### 私信事件
</div>

私信（DM）会话由一系列事件组成。X API v2 目前支持三种事件类型：MessageCreate、ParticipantsJoin 和 ParticipantsLeave。

DM 事件对象由 [Direct Message lookup](/zh/x-api/direct-messages/lookup/introduction) 端点返回，当使用 [Manage Direct Messages](/zh/x-api/direct-messages/lookup/introduction) 端点成功创建私信时，会生成一个 MessageCreate 事件。

在请求 DM 事件时，默认会包含三个事件对象属性（字段）：id、event&#95;type 和 text。若要接收额外的事件字段，请使用 [fields](/zh/x-api/fundamentals/fields) 参数 dm&#95;event.fields 来选择其他字段。其他可用的事件字段包括：dm&#95;conversation&#95;id、created&#95;at、sender&#95;id、attachments、participant&#95;ids 和 referenced&#95;tweets。

其中有几个字段会提供与私信事件相关的其他 X 对象的 ID：

* sender&#95;id - 发送消息的账号 ID，或邀请参与者加入群组会话的账号 ID
* partricipants&#95;ids - 账号 ID 的数组。对于 ParticipantsJoin 和 ParticipantsLeave 事件，此数组将只包含一个创建该事件的账号 ID
* attachments - 提供发送方在 X 上上传内容的媒体 ID
* referenced&#95;tweets - 如果在 text 字段中发现 Tweet URL，则该 Tweet 的 ID 会包含在响应中

可以使用 sender&#95;id、participant&#95;ids、referenced&#95;tweets.id 和 attachments.media&#95;keys 的 [expansions](/zh/x-api/fundamentals/expansions) 来扩展这些 X 对象 ID。

| id (default) | string | 事件的唯一标识符。<br /><br />&quot;id&quot;: &quot;1050118621198921728&quot; | 使用此字段以编程方式检索特定会话事件（适用于 v1.1 端点）。 |
| event&#95;type (default) | string | 描述事件的类型。目前支持三种类型：<br /><br />* MessageCreate<br />    <br />* ParticipantsJoin<br />    <br />* ParticipantsLeave<br />    <br /><br />&quot;event&#95;type&quot;: &quot;MessageCreate&quot; | 在检索会话历史时，用于了解消息的创建时间；对于群组会话，用于了解参与者加入和离开的时间。所有 GET 方法都支持使用 event&#95;type= 查询参数对特定事件类型进行过滤。 |

<div id="community">
  ### 社区
</div>

社区是 X 用户用于连接、分享，并更贴近他们最关心讨论内容的专属空间。

社区中的帖子在 X 上任何人都可以看到，但只有该社区内的其他成员才能参与互动和讨论。

Community 对象包含与某个社区相关的元数据。

| 字段值              | 类型            | 描述                                                 |    |
| :--------------- | :------------ | :------------------------------------------------- | :- |
| created&#95;at   | 日期 (ISO 8601) | 社区的创建时间。                                           |    |
| id               | 字符串           | 社区的唯一标识符。                                          |    |
| name             | 字符串           | 社区的名称。                                             |    |
| description      | 字符串           | 社区描述的文本内容（如果已提供）。                                  |    |
| access           | 字符串           | 社区的访问级别。<br /><br /> 可以是以下之一：                      |    |
|                  |               | - `Public`                                         |    |
|                  |               | - `Closed`                                         |    |
| join&#95;policy  | 字符串           | 社区的加入策略。<br /><br /> 可以是以下之一：                      |    |
|                  |               | - `Open`                                           |    |
|                  |               | - `RestrictedJoinRequestsDisabled`                 |    |
|                  |               | - `RestrictedJoinRequestsRequireAdminApproval`     |    |
|                  |               | - `RestrictedJoinRequestsRequireModeratorApproval` |    |
|                  |               | - `SuperFollowRequired`                            |    |
| member&#95;count | 整数            | 已加入该社区的成员数量。                                       |    |

**检索 Community 对象**

<div id="how-to-use-fields-and-expansions">
  ## 如何使用字段和扩展
</div>

默认情况下，如果在请求中未使用 [字段](/zh/x-api/fundamentals/fields) 或 [扩展](/zh/x-api/fundamentals/expansions) 参数，X API v2 数据对象只会包含少量默认字段。本指南将向你展示如何在请求中使用 `fields` 和 `expansions` 查询参数，从而在响应中获取更多对象和字段。

在本指南中，我们将以下方这条推文的截图为例，请求若干字段。
 

![此图像为一条由 @X 发布的推文截图。你可以看到推文文本、用户名、发布时间（日期和时间）、来源以及公开指标。它还包含一个视频。](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/ScreenShotDataDictionaryGuide.png.twimg.1920.png)

如你在截图中所见，与这条推文相关的可见信息有多项内容，包括推文作者、推文指标、创建时间戳、视频以及视频观看次数。还有一些数据在截图中不可见，但仍然可以通过请求获取。 

当向 API 发出请求时，默认响应非常简洁，只包含默认的推文字段（id 和 text）。你也只能接收所使用端点返回的主对象，而不会接收到与该主对象相关联的其他数据对象。

这种默认的简洁设计，加上 `fields` 和 `expansions` 参数，使你能够根据具体用例，只请求所需的字段。

curl --request GET --url 'https://api.x.com/2/tweets?ids=1260294888811347969' \
