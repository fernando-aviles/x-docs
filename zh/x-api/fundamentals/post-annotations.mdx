标注为帖子内容提供语义元数据。X 会分析帖子内容，以识别实体（人物、地点、产品）和上下文（主题、领域），从而帮助你理解和筛选内容。

---

<div id="annotation-types">
  ## 标注类型
</div>

<div id="entity-annotations">
  ### 实体标注
</div>

命名实体识别（NER）会识别帖子文本中的特定实体提及：

| 类型 | 示例 |
|:-----|:---------|
| **Person** | Barack Obama, Elon Musk |
| **Place** | San Francisco, Japan |
| **Product** | iPhone, ChatGPT |
| **Organization** | NASA, Google |
| **Other** | Super Bowl, Diabetes |

实体标注包括置信度评分以及在文本中的位置。

<div id="context-annotations">
  ### 上下文注解
</div>

通过语义分析按主题和领域对帖子进行分类：

- **Domain**：大类（体育、娱乐、科技）
- **Entity**：该领域内的具体主题（NBA、漫威电影、AI）

上下文注解有助于在不依赖关键词的情况下过滤和分类帖子。

---

<div id="requesting-annotations">
  ## 请求注解
</div>

将 `context_annotations` 和 `entities` 添加到 `tweet.fields` 中：

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=context_annotations,entities" \
  -H "Authorization: Bearer $TOKEN"
```

<div id="entity-annotation-fields">
  ## 实体标注字段
</div>

| 字段 | 描述 |
|:------|:------------|
| `start` | 在文本中的起始位置 |
| `end` | 在文本中的结束位置 |
| `probability` | 置信度评分（0-1） |
| `type` | 实体类型（Person、Place 等） |
| `normalized_text` | 规范化的实体名称 |

<div id="using-annotations-in-filters">
  ## 在过滤条件中使用注释
</div>

<div id="search-and-filtered-stream">
  ### 搜索与过滤流
</div>

根据上下文注解实体 ID 筛选帖子：

```bash
# 关于特定实体的帖子
context:86.1234567890

# 特定域中的帖子
context:86.*
```


<div id="practical-examples">
  ### 实用示例
</div>

```bash
# Posts about the NBA
query=context:26.852137520

# 关于 Apple 产品的帖子
query=context:47.10026792024

# Posts about movies
query=context:86.*
```

<div id="language-support">
  ## 语言支持
</div>

注释目前支持多种语言：

| 语言 | 覆盖范围 |
|:---------|:---------|
| English | 最高 |
| Japanese | 高 |
| Spanish | 高 |
| Portuguese | 中等 |
| French | 中等 |
| Hindi | 中等 |

覆盖范围会因领域和市场而异。

---

<div id="important-notes">
  ## 重要说明
</div>

<Warning>
**并非所有帖子都会带有标注。** 标注覆盖范围取决于：
- 语言支持情况
- X 分类体系中的主题覆盖范围
- 帖子文本的语义丰富程度
</Warning>

- 标注不会追溯补写——只会在实体开始被跟踪时才应用
- 同一个实体可以出现在多个领域中（例如，一位名人既属于 Person，也属于 Actor）
- 实体 id 在不同领域之间保持稳定不变
