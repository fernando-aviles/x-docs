标注为帖子内容提供语义元数据。X 会分析帖子，以识别人、地点、产品等实体以及主题、域等上下文，帮助你理解和过滤内容。

---

<div id="annotation-types">
  ## 标注类型
</div>

<div id="entity-annotations">
  ### 实体标注
</div>

命名实体识别（NER）会识别帖子文本中的特定实体：

| 类型 | 示例 |
|:-----|:---------|
| **Person** | Barack Obama, Elon Musk |
| **Place** | San Francisco, Japan |
| **Product** | iPhone, ChatGPT |
| **Organization** | NASA, Google |
| **Other** | Super Bowl, Diabetes |

实体标注包含置信度评分以及在文本中的位置。

<div id="context-annotations">
  ### 上下文注解
</div>

通过语义分析，根据主题和领域对帖子进行分类：

- **Domain**：广义类别（体育、娱乐、科技）
- **Entity**：该领域中的具体主题（NBA、漫威电影、AI）

上下文注解有助于在不依赖关键词的情况下对帖子进行筛选和分类。

---

<div id="requesting-annotations">
  ## 请求注解信息
</div>

在 `tweet.fields` 中添加 `context_annotations` 和 `entities`：

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=context_annotations,entities" \
  -H "Authorization: Bearer $TOKEN"
```

<div id="entity-annotation-fields">
  ## 实体标注字段
</div>

| 字段 | 描述 |
|:------|:------------|
| `start` | 文本中的起始位置 |
| `end` | 文本中的结束位置 |
| `probability` | 置信度分数（0-1） |
| `type` | 实体类型（人物、地点等） |
| `normalized_text` | 规范化的实体名称 |

<div id="using-annotations-in-filters">
  ## 在过滤条件中使用标注
</div>

<div id="search-and-filtered-stream">
  ### 搜索和过滤流
</div>

根据上下文注释实体 ID 筛选帖子：

```bash
# 关于特定实体的帖子
context:86.1234567890

# Posts in a specific domain
context:86.*
```


<div id="practical-examples">
  ### 实用示例
</div>

```bash
# Posts about the NBA
query=context:26.852137520

# 关于 Apple 产品的帖子
query=context:47.10026792024

# Posts about movies
query=context:86.*
```

<div id="language-support">
  ## 语言支持
</div>

以下语言提供标注：

| 语言 | 覆盖情况 |
|:---------|:---------|
| 英语 | 最高 |
| 日语 | 高 |
| 西班牙语 | 高 |
| 葡萄牙语 | 中等 |
| 法语 | 中等 |
| 印地语 | 中等 |

覆盖情况会因领域和市场而有所不同。

---

<div id="important-notes">
  ## 重要说明
</div>

<Warning>
**并非所有帖子都会被标注。** 标注覆盖范围取决于：
- 语言支持情况
- X 分类体系中的话题覆盖范围
- 帖子文本的语义丰富度
</Warning>

- 标注不具备追溯性——只会在实体被跟踪时应用
- 同一实体可以出现在多个领域中（例如，一位名人既是 Person 也是 Actor）
- 实体 id 在不同领域之间是稳定的
