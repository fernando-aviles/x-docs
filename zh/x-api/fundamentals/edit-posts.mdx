X 上的帖子在发布后的 30 分钟内可以编辑，最多可编辑 5 次。X API 提供对编辑历史和元数据的完全访问权限。

***

<div id="edit-rules">
  ## 编辑规则
</div>

| 规则 | 说明 |
|:-----|:--------|
| **时间窗口** | 自原始帖子发布起的 30 分钟内 |
| **编辑次数上限** | 最多可编辑 5 次 |
| **ID 行为** | 每次编辑都会创建一个新的帖子 ID |
| **删除** | 删除任意版本会删除整条编辑链 |
---------------------------

<div id="edit-data-in-responses">
  ## 哪些内容不可编辑
</div>

某些帖子类型无法编辑：

* 推广帖子（广告）
* 带有投票的帖子
* 对他人帖子发表的回复（非对自己帖子串联回复）
* 转帖（引用帖子*可以*编辑）
* 社群帖子
* 协作帖子
* 定时发布的帖子

***

## 响应中的编辑数据

<div id="edit-controls">
  ### 默认字段
</div>

所有帖子相关的响应默认都包含 `edit_history_tweet_ids`：

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"]
  }
}
```

* 单个 ID = 从未编辑
* 多个 ID = 编辑历史（按时间从早到晚）

### 编辑控制

请求 `edit_controls` 字段以获取编辑状态：

```bash
curl "https://api.x.com/2/tweets/1234567891?tweet.fields=edit_controls" \
  -H "Authorization: Bearer $TOKEN"
```

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"],
    "edit_controls": {
      "is_edit_eligible": true,
      "editable_until": "2024-01-15T12:30:00.000Z",
      "edits_remaining": 3
    }
  }
}
```

| 字段                 | 描述           |
| :----------------- | :----------- |
| `is_edit_eligible` | 帖子是否可编辑      |
| `editable_until`   | 编辑窗口关闭的时间戳   |
| `edits_remaining`  | 剩余可编辑次数（0-5） |

***

<div id="which-version-is-returned">
  ## 获取编辑历史
</div>

使用 `edit_history_tweet_ids` 扩展字段来获取所有版本对应的完整帖子对象：

```bash
curl "https://api.x.com/2/tweets/1234567891?\
tweet.fields=edit_controls&\
expansions=edit_history_tweet_ids" \
  -H "Authorization: Bearer $TOKEN"
```

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"],
    "edit_controls": {
      "is_edit_eligible": true,
      "editable_until": "2024-01-15T12:30:00.000Z",
      "edits_remaining": 3
    }
  },
  "includes": {
    "tweets": [{
      "id": "1234567890",
      "text": "Original text (with typo)",
      "edit_history_tweet_ids": ["1234567890", "1234567891"],
      "edit_controls": {
        "is_edit_eligible": true,
        "editable_until": "2024-01-15T12:30:00.000Z",
        "edits_remaining": 3
      }
    }]
  }
}
```

<div id="metrics-for-edited-posts">
  ## 会返回哪个版本？
</div>

默认情况下，API 会返回编辑后帖子中的**最新版本**。

要获取特定版本，请直接通过该帖子的 ID 发起请求：

```bash
# 获取原始版本
curl "https://api.x.com/2/tweets/1234567890" -H "Authorization: Bearer $TOKEN"

# Get edited version  
curl "https://api.x.com/2/tweets/1234567891" -H "Authorization: Bearer $TOKEN"
```

***

<div id="availability">
  ## 已编辑帖子指标
</div>

编辑后的帖子中的每个版本都有其各自的互动指标。这些指标会记在互动发生时对外可见的那个版本上。

***

<div id="use-cases">
  ## 可用性
</div>

编辑元数据适用于：

* 所有在 2022 年 9 月 29 日之后创建的帖子
* 所有会返回帖子的 v2 端点
* 包括搜索、时间线、流式接口和查找接口

在此日期之前创建的帖子不包含编辑元数据。

  <Tab title="跟踪更改">
    监控帖子编辑情况并记录变更内容：

    ```python
    def check_for_edits(post):
        history = post.get("edit_history_tweet_ids", [])
        if len(history) > 1:
            print(f"Post {post['id']} has been edited {len(history) - 1} times")
    ```
  </Tab>

  <Tab title="显示编辑标记">

    ```javascript
    if (isEdited) {
      showEditedBadge();
    }
    ```
  </Tab>

  <Tab title="获取原始内容">
    获取已编辑帖子的原始版本：

    ```python
    original_id = post["edit_history_tweet_ids"][0]
    original = api.get_tweet(original_id)
    ```
  </Tab>
