在 X 上发布的帖子可以在发布后 30 分钟内编辑，最多可编辑 5 次。X API 提供对编辑历史和元数据的完整访问。

***

<div id="edit-rules">
  ## 编辑规则
</div>

| 规则 | 详情 |
|:-----|:--------|
| **时间窗口** | 从原始帖子发布起的 30 分钟内 |
| **编辑次数限制** | 最多可编辑 5 次 |
| **ID 行为** | 每次编辑都会创建新的帖子 ID |
| **删除** | 删除任一版本会删除整个版本链 |

***

<div id="what-cant-be-edited">
  ## 无法编辑的内容
</div>

某些类型的帖子无法编辑：

* 推广帖子（广告）
* 含投票的帖子
* 回复他人的帖子（非你自己串联的帖子）
* 转帖（引用帖子*可以*编辑）
* 社群帖子
* 协作帖子
* 已排程的帖子

***

<div id="edit-data-in-responses">
  ## 修改响应中的数据
</div>

<div id="default-fields">
  ### 默认字段
</div>

所有帖子响应中默认都会包含 `edit_history_tweet_ids`：

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"]
  }
}
```

* 单个 id = 未曾编辑
* 多个 id = 编辑历史（按时间从早到晚，最早的在前）

<div id="edit-controls">
  ### 编辑控制信息
</div>

请求 `edit_controls` 来获取编辑状态：

```bash
curl "https://api.x.com/2/tweets/1234567891?tweet.fields=edit_controls" \
  -H "Authorization: Bearer $TOKEN"
```

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"],
    "edit_controls": {
      "is_edit_eligible": true,
      "editable_until": "2024-01-15T12:30:00.000Z",
      "edits_remaining": 3
    }
  }
}
```

| 字段                 | 描述           |
| :----------------- | :----------- |
| `is_edit_eligible` | 帖子是否可编辑      |
| `editable_until`   | 编辑时间窗口关闭的时间戳 |
| `edits_remaining`  | 剩余可编辑次数（0-5） |

***

<div id="getting-edit-history">
  ## 获取编辑历史
</div>

使用 `edit_history_tweet_ids` 扩展参数来获取所有版本的完整帖子对象：

```bash
curl "https://api.x.com/2/tweets/1234567891?\
tweet.fields=edit_controls&\
expansions=edit_history_tweet_ids" \
  -H "Authorization: Bearer $TOKEN"
```

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"],
    "edit_controls": {
      "is_edit_eligible": true,
      "editable_until": "2024-01-15T12:30:00.000Z",
      "edits_remaining": 3
    }
  },
  "includes": {
    "tweets": [{
      "id": "1234567890",
      "text": "Original text (with typo)",
      "edit_history_tweet_ids": ["1234567890", "1234567891"],
      "edit_controls": {
        "is_edit_eligible": true,
        "editable_until": "2024-01-15T12:30:00.000Z",
        "edits_remaining": 3
      }
    }]
  }
}
```

***

<div id="which-version-is-returned">
  ## 返回的是哪个版本？
</div>

默认情况下，API 会返回已编辑帖子的**最新版本**。

若要获取特定版本，请直接通过该帖子的 ID 请求：

```bash
# 获取原始版本
curl "https://api.x.com/2/tweets/1234567890" -H "Authorization: Bearer $TOKEN"

# Get edited version  
curl "https://api.x.com/2/tweets/1234567891" -H "Authorization: Bearer $TOKEN"
```

***

<div id="metrics-for-edited-posts">
  ## 已编辑帖子的指标
</div>

已编辑帖子的每个版本都有其各自的互动指标。指标会计入互动发生时对外可见的帖子版本。

***

<div id="availability">
  ## 适用范围
</div>

编辑元数据在以下情况下可用：

* 适用于 2022 年 9 月 29 日之后创建的所有帖子
* 适用于所有返回帖子的 v2 端点
* 包括搜索、时间线、流式和查找端点

在此日期之前创建的帖子不包含编辑元数据。

<div id="use-cases">
  ## 使用场景
</div>

<Tabs>
  <Tab title="跟踪变更">
    监控帖子是否被编辑并记录差异：

    ```python
    def check_for_edits(post):
        history = post.get("edit_history_tweet_ids", [])
        if len(history) > 1:
            print(f"Post {post['id']} has been edited {len(history) - 1} times")
    ```
  </Tab>

  <Tab title="显示编辑标识">
    在你的 UI 中显示“edited”徽章：

    ```javascript
    const isEdited = post.edit_history_tweet_ids?.length > 1;
    if (isEdited) {
      showEditedBadge();
    }
    ```
  </Tab>

  <Tab title="获取原始内容">
    获取已编辑帖子的原始版本：

    ```python
    original_id = post["edit_history_tweet_ids"][0]
    original = api.get_tweet(original_id)
    ```
  </Tab>
</Tabs>
