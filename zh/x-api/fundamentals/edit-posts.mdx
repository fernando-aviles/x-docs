在 X 上发布的帖子可以在发布后的 30 分钟内进行编辑，最多可编辑 5 次。X API 提供对编辑历史和元数据的完整访问权限。

***

<div id="edit-rules">
  ## 编辑规则
</div>

| 规则 | 详情 |
|:-----|:--------|
| **时间窗口** | 自原始帖子发布起 30 分钟内 |
| **编辑次数上限** | 最多编辑 5 次 |
| **ID 行为** | 每次编辑都会生成新的帖子 id |
| **删除** | 删除任意版本都会删除整个编辑链 |

***

<div id="what-cant-be-edited">
  ## 无法编辑的内容
</div>

某些帖子类型无法编辑：

* 推广帖子（广告）
* 含投票的帖子
* 回复他人的帖子（不包括自己的串帖）
* 转发帖子（引用帖子 *可以* 编辑）
* 社区帖子
* 协作帖子
* 已安排发送的帖子

***

<div id="edit-data-in-responses">
  ## 编辑响应中的 data 字段
</div>

<div id="default-fields">
  ### 默认字段
</div>

所有帖子响应默认都包含 `edit_history_tweet_ids`：

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"]
  }
}
```

* 单个 id = 从未编辑过
* 多个 id = 编辑历史（最早的在前）

<div id="edit-controls">
  ### 编辑控制
</div>

请求 `edit_controls` 字段以获取编辑状态：

```bash
curl "https://api.x.com/2/tweets/1234567891?tweet.fields=edit_controls" \
  -H "Authorization: Bearer $TOKEN"
```

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"],
    "edit_controls": {
      "is_edit_eligible": true,
      "editable_until": "2024-01-15T12:30:00.000Z",
      "edits_remaining": 3
    }
  }
}
```

| Field              | Description |
| :----------------- | :---------- |
| `is_edit_eligible` | 帖子是否可编辑     |
| `editable_until`   | 可编辑截止的时间戳   |
| `edits_remaining`  | 剩余编辑次数（0-5） |

***

<div id="getting-edit-history">
  ## 获取编辑历史
</div>

使用 `edit_history_tweet_ids` 扩展字段来获取所有版本对应的完整帖子对象：

```bash
curl "https://api.x.com/2/tweets/1234567891?\
tweet.fields=edit_controls&\
expansions=edit_history_tweet_ids" \
  -H "Authorization: Bearer $TOKEN"
```

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"],
    "edit_controls": {
      "is_edit_eligible": true,
      "editable_until": "2024-01-15T12:30:00.000Z",
      "edits_remaining": 3
    }
  },
  "includes": {
    "tweets": [{
      "id": "1234567890",
      "text": "Original text (with typo)",
      "edit_history_tweet_ids": ["1234567890", "1234567891"],
      "edit_controls": {
        "is_edit_eligible": true,
        "editable_until": "2024-01-15T12:30:00.000Z",
        "edits_remaining": 3
      }
    }]
  }
}
```

***

<div id="which-version-is-returned">
  ## 返回的是哪个版本？
</div>

默认情况下，API 会返回已编辑帖子中**最新版本**。

如果要获取指定版本，请直接通过该帖子的 id 发起请求：

```bash
# 获取原始版本
curl "https://api.x.com/2/tweets/1234567890" -H "Authorization: Bearer $TOKEN"

# Get edited version  
curl "https://api.x.com/2/tweets/1234567891" -H "Authorization: Bearer $TOKEN"
```

***

<div id="metrics-for-edited-posts">
  ## 已编辑帖子对应的指标
</div>

已编辑帖子的每个版本都有各自的互动指标。这些指标会归属于互动发生时对用户可见的那个版本。

***

<div id="availability">
  ## 可用范围
</div>

编辑元数据适用于：

* 所有自 2022 年 9 月 29 日起创建的帖子
* 所有返回帖子的 v2 端点
* 包括搜索、时间线、流式传输和查找

在此日期之前创建的帖子不包含编辑元数据。

<div id="use-cases">
  ## 使用场景
</div>

<Tabs>
  <Tab title="跟踪变更">
    监控帖子是否被编辑，并记录差异：

    ```python
    def check_for_edits(post):
        history = post.get("edit_history_tweet_ids", [])
        if len(history) > 1:
            print(f"帖子 {post['id']} 已被编辑 {len(history) - 1} 次")
    ```
  </Tab>

  <Tab title="显示编辑标记">
    在你的 UI 中显示“已编辑”徽章：

    ```javascript
    const isEdited = post.edit_history_tweet_ids?.length > 1;
    if (isEdited) {
      showEditedBadge();
    }
    ```
  </Tab>

  <Tab title="获取原始内容">
    获取已编辑帖子的原始版本：

    ```python
    original_id = post["edit_history_tweet_ids"][0]
    original = api.get_tweet(original_id)
    ```
  </Tab>
</Tabs>
