  ## 使用隐藏回复端点的应用
</div>

以下是一些值得关注的应用，这些应用由集成了隐藏回复端点的开发者构建。通过将他们的技术与 X API 相结合，他们打造了有助于所有用户提升公共对话质量的实用体验。

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge 集成了隐藏回复功能，使公司可以保持其 X 信息流整洁且有趣易读。回复可以手动隐藏，客服人员还可以使用 Clarabridge 的文本分析功能，自动检测脏话以及其他不符合品牌政策的用语。

[访问网站 ▸](https://www.clarabridge.com/ "Go to website ▸")

[Clarabridge 在 X 上](https://x.com/Clarabridge "Clarabridge on X")

![Perspective API template app](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Perspective API 模板应用**

Perspective 是由 Jigsaw（Alphabet 内部的一个部门）训练的人工智能，用于检测带有攻击性或有害内容的评论。此应用会检测某个用户收到的回复，并根据一个“评分”自动隐藏回复，该评分表示 Perspective 对某条评论与其过去所见有害评论相似程度的信心。这是由 X 开发的开源模板应用，我们鼓励你对其进行个性化定制，为你的用户构建工具。

[使用应用 ▸](https://quintessential-yoke.glitch.me "Use app ▸")

[Jigsaw 在 X 上](https://x.com/jigsaw "Jigsaw on X")

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle 是一个用于将业务应用与灵活脚本连接起来的平台。他们构建了一个集成脚本，用于检测并隐藏包含你所定义关键词的回复。要试用它，请确保你已为 Hide replies 功能启用了有效的应用，然后按照代码仓库中的说明进行操作。

[前往应用 ▸](https://github.com/reshufflehq/reshuffle "Go to app ▸")

[Reshuffle 在 X 上](https://x.com/reshufflehq "Reshuffle on X")

![Hide unwanted replies](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 396 397%22%3E%3C/svg%3E)

**Hide unwanted replies**

热门应用 QuotedReplies 背后的开发者 Dara Oladosu 构建了一款应用，可自动隐藏符合他所设定若干条件的回复，这些条件更有可能与辱骂性行为相关，包括包含他过去已静音的特定关键词的回复。

[前往应用 ▸](https://hideunwantedreplies.com/ "Go to app ▸")

[Dara Oladosu 在 X 上](https://x.com/dara_tobi "Dara Oladosu on X")

![Pandaflow](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 94 94%22%3E%3C/svg%3E)

**Pandaflow**

Pandaflow 是一个用于自动化工作流的无代码平台。他们集成了该端点，使用户可以根据自己定义的自定义流程，以编程方式隐藏回复。

[前往应用 ▸](https://pandaflow.io/ "Go to app ▸")

[Pandaflow 在 X 上](https://x.com/pandaflowio "Pandaflow on X")
