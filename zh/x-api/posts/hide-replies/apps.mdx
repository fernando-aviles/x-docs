<div id="apps-using-the-hide-replies-endpoint">
  ## 使用 Hide replies 端点的应用
</div>

以下是一些值得关注的应用，这些应用由集成了 Hide replies 端点的开发者构建。通过将其技术与 X API 相结合，他们为所有用户创造了有助于提升平台公共对话质量的实用体验。

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge 集成了 Hide replies 功能，使公司能够保持其 X 信息流的整洁且更有阅读价值。回复可以手动隐藏，客服人员也可以使用 Clarabridge 的文本分析功能，自动检测不雅用语以及其他不符合品牌政策的语言。

[前往网站 ▸](https://www.clarabridge.com/ "前往网站 ▸")

[Clarabridge 在 X 上](https://x.com/Clarabridge "Clarabridge 在 X 上")

![Perspective API 模板应用](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Perspective API 模板应用**

Perspective 是由 Jigsaw（Alphabet 旗下的一个部门）训练的人工智能，用于检测有害评论。此应用会检测某人收到的回复，并根据一个“评分”自动隐藏回复，该评分表明 Perspective 对该评论与其过去见过的有害评论的相似程度有多大信心。这是由 X 开发的开源模板应用。我们鼓励你根据自己的需求对其进行个性化定制，为你的用户构建工具。

[使用应用 ▸](https://quintessential-yoke.glitch.me "使用应用 ▸")

[Jigsaw 在 X 上](https://x.com/jigsaw "Jigsaw 在 X 上")

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle 是一个通过灵活脚本连接各类业务应用的平台。他们构建了一个集成脚本，用于检测并隐藏包含你定义的关键词的回复。若要试用，请确保你已启用了支持 Hide replies 功能的有效应用，然后按照代码仓库中的说明操作。

[前往应用 ▸](https://github.com/reshufflehq/reshuffle "前往应用 ▸")

[Reshuffle 在 X 上](https://x.com/reshufflehq "Reshuffle 在 X 上")

![Hide unwanted replies](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 396 397%22%3E%3C/svg%3E)

**Hide unwanted replies**

热门应用 QuotedReplies 背后的开发者 Dara Oladosu 构建了一个应用，可自动隐藏满足其设定的某些条件、且更可能表现出辱骂行为的回复，其中包括包含他过去已静音的特定关键词的回复。

[前往应用 ▸](https://hideunwantedreplies.com/ "前往应用 ▸")

[Dara Oladosu 在 X 上](https://x.com/dara_tobi "Dara Oladosu 在 X 上")

![Pandaflow](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 94 94%22%3E%3C/svg%3E)

**Pandaflow**

Pandaflow 是一个用于自动化工作流的零代码平台。他们集成了该端点，使用户可以根据自己定义的流程，通过编程方式隐藏回复。

[前往应用 ▸](https://pandaflow.io/ "前往应用 ▸")

[Pandaflow 在 X 上](https://x.com/pandaflowio "Pandaflow 在 X 上")
