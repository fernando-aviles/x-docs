Hide Replies 端点允许你隐藏或恢复显示由已通过身份验证的用户发布的帖子下的回复。被隐藏的回复仍然可以访问，但需要额外点击一次才能查看。

<div id="endpoint">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| PUT | [`/2/tweets/:tweet_id/hidden`](/zh/x-api/posts/hide-reply) | 隐藏或取消隐藏回复 |

***

<div id="how-it-works">
  ## 工作原理
</div>

发送 PUT 请求，将 `hidden` 设为 `true` 来隐藏回复，或设为 `false` 来取消隐藏：

```json
{
  "hidden": true
}
```

***

<div id="example-hide-a-reply">
  ## 示例：隐藏回复
</div>

```bash
curl -X PUT "https://api.x.com/2/tweets/1234567890/hidden" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"hidden": true}'
```

<div id="example-response">
  ## 示例响应
</div>

```json
{
  "data": {
    "hidden": true
  }
}
```
