Hide Replies 端点允许你隐藏或重新显示由经过身份验证的用户发布的帖子下的回复。被隐藏的回复仍然可以访问，但需要额外点击才能查看。

<div id="endpoint">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| PUT | [`/2/tweets/:tweet_id/hidden`](/zh/x-api/posts/hide-reply) | 隐藏或取消隐藏回复 |

***

<div id="how-it-works">
  ## 工作原理
</div>

发送一个带有 `hidden: true` 的 PUT 请求来隐藏回复，或发送一个带有 `hidden: false` 的 PUT 请求来取消隐藏该回复：

```json
{
  "hidden": true
}
```

***

<div id="example-hide-a-reply">
  ## 示例：隐藏某条回复
</div>

```bash
curl -X PUT "https://api.x.com/2/tweets/1234567890/hidden" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"hidden": true}'
```

<div id="example-response">
  ## 示例响应
</div>

```json
{
  "data": {
    "hidden": true
  }
}
```
