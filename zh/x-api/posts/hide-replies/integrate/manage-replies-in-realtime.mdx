<div id="manage-replies-in-realtime">
  ### 实时管理回复
</div>

借助 hide replies 端点，你可以构建一套工作流，帮助用户隐藏那些很可能与对话无关的回复。

实用的应用通常会结合多种技术，从而为用户提供更高价值。本页展示了如何使用 [Perspective API](https://www.perspectiveapi.com/) 来隐藏回复。该 API 是由 Google 旗下的 [Jigsaw](https://jigsaw.google.com/) 训练的人工智能，用于检测具有攻击性或有害的评论。应用逻辑的工作方式如下：

1.  向用户请求权限，以读取他们的帖子，并隐藏或取消隐藏他们的回复。
2.  使用 [Account Activity API](https://developer.x.com/en/docs/x-api/v1/accounts-and-users/subscribe-account-activity/overview) 检测收到的回复。
3.  请求 Perspective API 返回一个“评分”（介于 0 和 1 之间的数字），表示其算法对某个评论与其过去见过的有害评论相似程度的置信度。（Perspective 不会存储发送到其服务的文本）。
4.  如果算法的评分非常高，则调用 hide replies。

<div id="strive-for-transparency">
  #### 努力保持透明
</div>

由于 Perspective 并非使用真实帖子进行训练，某些语言细微差别可能会导致此应用隐藏用户本希望保持可见的回复。无论你在设计应用时使用何种技术或方法，都应尽最大努力确保用户了解你的应用隐藏了哪些内容，并能够进行更改。

* 最佳做法是始终信任用户，并让他们对自己的决策拥有完全的控制权。这意味着在你的用户体验中应提供功能，允许撤销你的应用代表用户执行的任何操作。
* 在使用人工智能时，你的应用在检测并隐藏帖子时应采用非常高的置信度阈值。
* 并非所有人使用相同的词语，你的应用在设计时应避免任何偏见。请注意那些被重新赋予积极含义的用语和俚语，它们可能导致误判。
* 如果你正在训练人工智能模型，请考虑采用能够紧密贴合 X 上常用语言的模型。
