<div id="manage-replies-in-realtime">
  ### 实时管理回复
</div>

借助 hide replies 端点，你可以构建一套流程，帮助你的用户隐藏那些高度可能不相关的回复。

实用的 App 往往会结合多种技术，以便为用户提供更大价值。本页展示如何使用 [Perspective API](https://www.perspectiveapi.com/) 来隐藏回复。该 API 背后是一套由 Google 内部部门 [Jigsaw](https://jigsaw.google.com/) 训练的人工智能模型，用于检测带有攻击性或有害的评论。应用程序逻辑将按以下方式工作：

1.  向用户请求权限，以读取他们的帖子并隐藏或取消隐藏其回复。
2.  使用 [Account Activity API](https://developer.x.com/en/docs/x-api/v1/accounts-and-users/subscribe-account-activity/overview) 来检测新收到的回复。
3.  请求 Perspective API 提供一个“评分”（介于 0 到 1 之间的数字），用来表示其算法有多大把握认为某条评论与其过去见过的恶意评论相似。（Perspective 不会存储发送到该服务的文本）。
4.  如果算法评分非常高，则调用 hide replies。

<div id="strive-for-transparency">
  #### 努力保持透明
</div>

由于 Perspective 并不是基于实际的帖子进行训练，某些语言上的细微差异可能会导致此 App 隐藏用户本希望保持可见的回复。无论你在设计 App 时使用何种技术或方法，都应尽最大努力确保用户了解你的 App 隐藏了哪些内容，并且能够进行调整。

* 最好的做法是始终信任用户，并将决定权完全交给他们。这意味着你的用户体验中应提供控制项，让用户可以撤销你的 App 代表他们所执行的任何操作。
* 当使用人工智能时，你的 App 在检测和隐藏帖子时应使用非常高的置信度阈值。
* 并不是所有人都使用相同的词汇，你的 App 设计应避免任何偏见。请注意那些被重新赋予意义的用语和俚语，它们可能会导致误报。
* 如果你正在训练人工智能，考虑采用一个与 X 上常用语言高度贴合的模型。
