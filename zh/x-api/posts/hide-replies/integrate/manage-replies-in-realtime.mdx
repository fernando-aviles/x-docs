<div id="manage-replies-in-realtime">
  ### 实时管理回复
</div>

借助 hide replies 端点，你可以构建一个流程，帮助用户隐藏那些极有可能与主题无关的回复。

实用的应用通常会结合多种技术，从而为用户提供更大价值。本页展示如何使用 [Perspective API](https://www.perspectiveapi.com/) 来隐藏回复。该 API 是由 [Jigsaw](https://jigsaw.google.com/)（Google 内部的一个部门）训练的人工智能，用于检测有害评论。应用逻辑将按如下方式运作：

1.  它会征求用户的许可，以读取他们的帖子并隐藏或取消隐藏其回复。
2.  它使用 [Account Activity API](https://developer.x.com/en/docs/x-api/v1/accounts-and-users/subscribe-account-activity/overview) 来检测新收到的回复。
3.  它请求 Perspective API 提供一个“评分”（介于 0 和 1 之间的数字），用于表示其算法对某条评论与其过去见过的有害评论相似程度的置信度。（Perspective 不会存储发送到该服务的文本）。
4.  如果算法评分非常高，它就会调用 hide replies 端点。

<div id="strive-for-transparency">
  #### 努力保持透明
</div>

由于 Perspective 并非基于实际帖子进行训练，某些语言细微差别可能会导致此应用隐藏用户原本希望保持可见的回复。无论你在设计应用时使用何种技术或方法，都应尽最大努力确保用户了解你的应用隐藏了哪些内容，并且可以自行进行更改。

* 最佳做法是始终信任用户，并赋予他们对自身决策的完全控制权。这意味着你的产品体验中应包含用于撤销应用代表用户所执行任何操作的控制选项。
* 在使用人工智能时，你的应用在检测和隐藏帖子时应使用非常高的置信度阈值。
* 并非所有人使用相同的词语，你的应用在设计时应尽量避免任何偏见。请留意被重新赋义的词语和俚语，它们可能会导致误报。
* 如果你在训练人工智能，考虑采用一种能够尽量贴近 X 上常用语言的模型。
