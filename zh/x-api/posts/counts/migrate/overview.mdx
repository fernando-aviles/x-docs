<div id="comparing-x-apis-post-counts-endpoints">
  ## 比较 X API 的帖子计数端点
</div>

v2 帖子计数端点最终会取代[企业版 Search API 的计数端点](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api#counts-requests-post-count)。如果您有使用旧版帖子计数端点的代码、App 或工具，并且正在考虑迁移到较新的 X API v2 端点，那么本指南适合您。

***

<div id="recent-post-counts-comparison">
  ## 最近帖子计数比较
</div>

企业版的帖子计数端点允许你获取最近 30 天或全量存档的计数。因此，v2 的最近帖子计数端点（查看 7 天时间范围）不能直接替代上述任一端点。

为便于比较，我们将看看 v2 最近帖子计数端点与企业版 30 天端点的对比情况。

下表对不同类型的最近帖子计数端点进行了比较：

| **说明** | **Enterprise** | **X API v2** |
| :--- | :--- | :--- |
| 主机域名 | https://gnip-api.x.com | https://api.x.com |
| 端点路径 | /search/30day/accounts/:account&#95;name/:label/counts.json | /2/tweets/counts/recent |
| [Authentication](/zh/resources/fundamentals/authentication) | 基本身份验证 | OAuth 2.0 Bearer Token |
| 时间戳格式 | YYYYMMDDhhmm | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |
| 返回的帖子最久可追溯至 | 31 天 | 7 天 |
| 支持的 HTTP 方法 | GET | GET |
| 默认请求速率限制 | 每 1 秒 20 个请求，在搜索数据和计数请求之间合并计算  <br />具体每分钟速率限制将根据与你签订合同中约定的合作方配置而有所不同。 | 每位用户每 15 分钟 180 个请求  <br />每个 App 每 15 分钟 450 个请求 |
| 支持使用 [annotations](/zh/x-api/fundamentals/post-annotations) 进行过滤 |     | ✔   |
| 支持使用 [conversation&#95;id](/zh/x-api/fundamentals/conversation-id) 进行过滤 |     | ✔   |
| 帖子数据数组的 JSON 键名 | results | data |
| 时间粒度 | 天、小时或分钟 | 天、小时或分钟 |
| 时区 | UTC | UTC |
| 用于选择时间范围的请求参数 | fromDate  <br />toDate | start&#95;time  <br />end&#95;time |
| 用于按帖子 ID 导航的请求参数 |     | since&#95;id  <br />until&#95;id |
| 是否需要使用与某个 [project](/zh/resources/fundamentals/developer-apps) 关联的 [developer App](/zh/resources/fundamentals/developer-apps) 的凭证 |     | ✔   |

<div id="filtering-operator-comparison">
  ### 过滤运算符对比
</div>

Enterprise 和 v2 这两个不同版本的帖子计数在可用运算符上存在差异，并且在每个版本内部，运算符的可用范围也不同，下面将对其进行说明。

Enterprise

* Enterprise 运算符没有子层级。所有 Enterprise 运算符对所有 Enterprise 用户均可用。

X API v2

* **Core：** 这些运算符对任何 v2 用户都可用。
* **Advanced：** 这些运算符仅对已获准 Academic Research 访问权限的用户可用。

你可以在各自的指南中进一步了解每一组运算符：

* [Enterprise 运算符](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api#building-search-queries)
* [X API v2 运算符](/zh/x-api/posts/search/integrate/build-a-query)
