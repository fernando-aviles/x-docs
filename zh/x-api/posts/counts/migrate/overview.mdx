<div id="comparing-x-apis-post-counts-endpoints">
  ## 比较 X API 的帖子计数端点
</div>

X API v2 的帖子计数端点最终将取代 [enterprise Search API 的计数端点](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api#counts-requests-post-count)。如果你在代码、应用或工具中使用旧版的帖子计数端点，并正在考虑迁移到更新的 X API v2 端点，那么本指南适合你。

***

<div id="recent-post-counts-comparison">
  ## 最近帖子计数比较
</div>

企业版的帖子计数端点允许你获取最近 30 天或全量存档中的计数。因此，v2 的最近帖子计数端点（只查看 7 天的时间范围）不能直接替代上述任一端点。

不过，为了便于比较，我们将查看 v2 最近帖子计数端点与企业 30 天端点之间的差异。

下表比较了各种类型的最近帖子计数端点：

| **Description** | **Enterprise** | **X API v2** |
| :--- | :--- | :--- |
| Host domain | https://gnip-api.x.com | https://api.x.com |
| Endpoint path | /search/30day/accounts/:account&#95;name/:label/counts.json | /2/tweets/counts/recent |
| [Authentication](/zh/resources/fundamentals/authentication) | 基本身份验证 | OAuth 2.0 Bearer Token |
| Timestamp format | YYYYMMDDhhmm | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |
| Returns counts of Posts that are no older than | 不超过 31 天的帖子计数 | 不超过 7 天的帖子计数 |
| HTTP methods supported | GET | GET |
| Default request rate limits | 每 1 秒 20 个请求，在搜索 data 和计数请求之间共享  <br />每分钟的速率限制会根据你的合同中约定的合作伙伴而变化。 | 每个用户每 15 分钟 180 个请求  <br />每个 App 每 15 分钟 450 个请求 |
| Supports filtering using [annotations](/zh/x-api/fundamentals/post-annotations) |     | ✔   |
| Supports filtering using [conversation&#95;id](/zh/x-api/fundamentals/conversation-id) |     | ✔   |
| JSON key name for Post data array | results | data |
| Time granularity | 天、小时或分钟 | 天、小时或分钟 |
| Timezone | UTC | UTC |
| Request parameters for selecting time period | fromDate  <br />toDate | start&#95;time  <br />end&#95;time |
| Request parameters for navigating by Post ID |     | since&#95;id  <br />until&#95;id |
| Requires the use of credentials from a [developer App](/zh/resources/fundamentals/developer-apps) associated with a [project](/zh/resources/fundamentals/developer-apps) |     | ✔   |

<div id="filtering-operator-comparison">
  ### 过滤运算符比较
</div>

Post 计数功能的两个不同版本（Enterprise 和 v2）在可用运算符上有所不同，并且每个版本内部的运算符可用级别也不同，具体说明如下。

Enterprise

* Enterprise 运算符没有子级别。所有 Enterprise 运算符对所有 Enterprise 用户均可用。

X API v2

* **Core：** 这些运算符对任何 X API v2 用户都可用。
* **Advanced：** 这些运算符仅对已获批学术研究访问权限的用户可用。

你可以在各自的指南中进一步了解这些运算符集合：

* [Enterprise 运算符](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api#building-search-queries)
* [X API v2 运算符](/zh/x-api/posts/search/integrate/build-a-query)

在了解了 X API v2 中这些不同运算符级别之后，下面的表格展示了 Post 计数的运算符可用性（注意：如果单元格为空，则表示该运算符不可用）：
