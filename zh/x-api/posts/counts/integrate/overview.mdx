本页介绍在集成帖子计数端点时涉及的工具和关键概念。

<div id="helpful-tools">
  ## 实用工具
</div>

在开始探索一些关键概念之前，我们建议你先使用下列工具或代码示例之一，对这些端点的功能进行测试。

<div id="code-samples">
  ### 代码示例
</div>

想用你偏好的编程语言，通过一些代码来开始使用这些端点吗？我们在 [GitHub 页面](https://github.com/xdevplatform/Twitter-API-v2-sample-code) 上提供了多种代码示例，可作为你的起点使用，其中包括一个 [Python 客户端](https://github.com/xdevplatform/search-tweets-python)。

<div id="libraries">
  ### 库
</div>

利用我们众多的[社区第三方库](/zh/x-api/tools-and-libraries/overview)来帮助你快速上手。你可以通过查找合适的版本标签，找到适用于 v2 端点的库。

<div id="postman">
  ### Postman
</div>

Postman 是一个非常适合用来测试这些端点的工具。每个 Postman 请求都包含相应端点的所有参数，帮助你快速了解有哪些可用内容。要进一步了解我们的 Postman 集合，请参阅我们的 [使用 Postman](/zh/tutorials/postman-getting-started) 页面。

<div id="key-concepts">
  ## 核心概念
</div>

<div id="authentication">
  ### 鉴权
</div>

所有 X API v2 端点都要求你使用一组凭证（也称为 keys 和 tokens）对请求进行[鉴权](/zh/resources/fundamentals/authentication)。本端点要求使用 [OAuth 2.0 Bearer Token](/zh/resources/fundamentals/authentication#oauth-2-0)，这意味着你必须在请求中携带一个 [Bearer Token](/zh/resources/fundamentals/authentication#bearer-token-also-known-as-app-only) 才能成功发起请求。你可以直接在开发者 App 中生成一个 Bearer Token，或者使用 [POST oauth2/token](/zh/resources/fundamentals/authentication#post-oauth2-token) 端点生成一个 Bearer Token。

<div id="developer-console-projects-and-developer-apps">
  ### 开发者控制台、Project 和开发者 App
</div>

要使用任何 X API v2 端点，你必须拥有一个[开发者账号](/zh/resources/fundamentals/developer-portal)，在该账号下设置一个 [Project](/zh/resources/fundamentals/developer-apps)，并在该 Project 中创建一个 [开发者 App](/zh/resources/fundamentals/developer-apps)。该开发者 App 中的密钥和令牌可用于近期帖子计数端点。如果你想使用全量归档帖子计数端点，或使用高级运算符和更长的查询字符串，你需要先获得企业访问权限批准。

请访问我们的企业访问权限部分以了解更多信息。

<div id="rate-limits">
  ### 速率限制
</div>

每天都有成千上万名开发者向 X API 发起请求。为了管理请求量，我们在每个 endpoint 上都设置了[速率限制](/zh/x-api/fundamentals/rate-limits)，限制每位开发者代表某个应用或已认证用户所能发起的请求次数。

此 endpoint 采用应用级（App-level）速率限制，这意味着作为开发者，你在任意给定的时间段内，从任意一个 App（由你所使用的凭证所标识）调用此 endpoint 时，只能发起有限数量的请求。

<div id="building-queries">
  ### 构建查询
</div>

这些端点的核心特性在于使用单个查询来对帖子进行筛选，并生成返回给你的计数结果。这些查询由一组运算符组成，用于匹配帖子和用户的属性，例如消息关键词、话题标签（hashtag）以及 URL。你可以使用布尔逻辑和括号将运算符组合成查询，以帮助细化查询的匹配行为。

你可以参考我们的[如何构建查询](/zh/x-api/posts/counts/integrate/build-a-query)指南来了解更多信息。

<div id="pagination">
  ### 分页
</div>

对于最近的帖子计数，请求不会返回 next&#95;token，这意味着无论统计粒度如何，你都可以通过一次 API 调用获取过去 7 天的帖子数量。

对于全量归档的帖子计数，你将获得最近 30 天的 data。对于早于 30 天的 data，你会收到一个 next&#95;token，然后可以使用它进行分页以获取更多的 data。
