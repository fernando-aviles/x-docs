在开始探索关键概念之前，我们建议你使用下列任一工具或代码示例来开始测试这些端点的功能。

<div id="key-concepts">
  ## 核心概念
</div>

<div id="authentication">
  ### 认证
</div>

所有 X API v2 端点都要求使用一组凭证（也称为密钥和令牌）对请求进行[认证](/zh/resources/fundamentals/authentication)。此端点要求使用 [OAuth 2.0 Bearer Token](/zh/resources/fundamentals/authentication#oauth-2-0)，这意味着你必须在请求中携带一个 [Bearer Token](/zh/resources/fundamentals/authentication#bearer-token-also-known-as-app-only) 才能成功发起请求。你可以直接在开发者 App 中生成一个 Bearer Token，或者使用 [POST oauth2/token](/zh/resources/fundamentals/authentication#post-oauth2-token) 端点来生成。

<div id="developer-console-projects-and-developer-apps">
  ### 开发者控制台、项目和开发者 App
</div>

要使用任何 X API v2 端点，你必须拥有一个[开发者账号](/zh/resources/fundamentals/developer-portal)，在该账号下设置一个[项目](/zh/resources/fundamentals/developer-apps)，并在该项目中创建一个[开发者 App](/zh/resources/fundamentals/developer-apps)。你在该开发者 App 中的密钥和令牌可以用于最近帖子计数端点。如果你想使用全量归档帖子计数端点，或使用高级运算符和更长的查询字符串，则需要获得企业级访问权限的批准。

请访问我们的企业级访问部分以了解更多信息。

<div id="rate-limits">
  ### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为了控制请求量，我们在每个端点上都设置了[速率限制](/zh/x-api/fundamentals/rate-limits)，以限制每位开发者代表某个 App 或代表已认证用户所能发起的请求次数。

此端点在 App 级别进行速率限制，这意味着你作为开发者，在任意给定的时间段内，从任意给定的 App（由你所使用的凭证所对应）调用该端点时，只能发起有限次数的请求。

<div id="building-queries">
  ### 构建查询
</div>

这些端点的核心特性是使用单个查询对帖子进行过滤，以生成返回给你的计数结果。这些查询由运算符组成，用于匹配帖子和用户属性，例如消息关键词、话题标签（hashtags）和 URL。运算符可以通过布尔逻辑和括号组合成查询，以帮助精细控制查询的匹配行为。

你可以参考我们的[如何构建查询](/zh/x-api/posts/counts/integrate/build-a-query)指南，以了解更多信息。

<div id="pagination">
  ### 分页
</div>

对于最近的帖子计数，不会返回 next&#95;token，这意味着无论粒度如何，你都可以在一次 API 调用中获取过去 7 天的帖子数量。

对于全量存档的帖子计数，你将获得过去 30 天的数据。对于 30 天以前的数据，你会得到一个 next&#95;token，之后你可以使用它进行分页以获取更多数据。
