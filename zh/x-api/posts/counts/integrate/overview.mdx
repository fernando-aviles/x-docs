<div id="key-concepts">
  ## 关键概念
</div>

<div id="authentication">
  ### 身份验证
</div>

所有 X API v2 端点都要求使用一组凭证（也称为密钥和令牌）对请求进行[身份验证](/zh/resources/fundamentals/authentication)。该端点要求使用 [OAuth 2.0 Bearer Token](/zh/resources/fundamentals/authentication#oauth-2-0)，也就是说，你必须在请求中携带 [Bearer Token](/zh/resources/fundamentals/authentication#bearer-token-also-known-as-app-only) 才能成功发起调用。你可以直接在开发者 App 中生成 Bearer Token，或者使用 [POST oauth2/token](/zh/resources/fundamentals/authentication#post-oauth2-token) 端点生成。

<div id="developer-console-projects-and-developer-apps">
  ### Developer Console、Project 和开发者 App
</div>

若要使用任何 X API v2 端点，你必须先拥有一个[开发者账号](/zh/resources/fundamentals/developer-portal)，在该账号下创建一个 [Project](/zh/resources/fundamentals/developer-apps)，并在该 Project 中创建一个[开发者 App](/zh/resources/fundamentals/developer-apps)。该开发者 App 中的密钥和令牌可用于近期帖子计数相关端点。如果你希望使用全量归档帖子计数端点，或使用高级运算符和更长的查询字符串，则需要先获批企业级访问权限。

请访问我们的企业级访问相关内容以了解更多信息。

<div id="rate-limits">
  ### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为了帮助管理请求量，我们在每个 endpoint 上都设置了[速率限制](/zh/x-api/fundamentals/rate-limits)，以限制每位开发者代表某个 App 或代表已认证用户所能发起的请求次数。

此 endpoint 采用 App 级别的速率限制，这意味着你作为开发者，在指定时间段内，从任意特定的 App（由你所使用的凭证所标识）向该 endpoint 发起的请求次数是有限制的。

<div id="building-queries">
  ### 构建查询
</div>

这些端点的核心特性在于，它们使用单个查询来过滤帖子，并将计数结果返回给你。这些查询由运算符组成，用于基于帖子和用户属性进行匹配，例如消息关键词、话题标签（hashtags）和 URL。你可以使用布尔逻辑和括号将运算符组合成查询，以便进一步细化查询的匹配行为。

你可以参考我们的指南[如何构建查询](/zh/x-api/posts/counts/integrate/build-a-query)了解更多信息。

<div id="pagination">
  ### 分页
</div>

对于最近的帖子计数，不会返回 next&#95;token，这意味着无论粒度如何，你都可以通过一次 API 调用获取过去 7 天的帖子量。

对于全量归档帖子计数，你将获得最近 30 天的 data。对于早于 30 天之前的 data，你会得到一个 next&#95;token，然后可以使用它进行分页以获取更多的 data。
