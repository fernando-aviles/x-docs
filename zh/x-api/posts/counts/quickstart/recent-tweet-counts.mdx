本指南将引导你获取过去 7 天的帖子量（volume）。

<Note>
  **先决条件**

  在开始之前，你需要：

  * 一个拥有已获批准 App 的[开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)
  * 你的 App 的 Bearer 令牌
</Note>

<div id="get-recent-post-counts">
  ## 获取最近帖子数量
</div>

<Steps>
  <Step title="构建查询">
    使用与最近搜索相同的查询语法。例如，要统计来自 @XDevelopers 的帖子数量：

    ```
    from:XDevelopers
    ```
  </Step>

  <Step title="发起请求">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/tweets/counts/recent?\
      query=from%3AXDevelopers&\
      granularity=day" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # 获取最近帖子数量
      response = client.posts.count_recent(
          query="from:XDevelopers",
          granularity="day"
      )

      for bucket in response.data:
          print(f"{bucket.start}: {bucket.tweet_count} Posts")

      print(f"Total: {response.meta.total_tweet_count}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // 获取最近帖子数量
      const response = await client.posts.countRecent({
        query: "from:XDevelopers",
        granularity: "day",
      });

      response.data?.forEach((bucket) => {
        console.log(`${bucket.start}: ${bucket.tweet_count} Posts`);
      });

      console.log(`Total: ${response.meta?.total_tweet_count}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="查看响应">
    ```json
    {
      "data": [
        {
          "end": "2024-01-16T00:00:00.000Z",
          "start": "2024-01-15T00:00:00.000Z",
          "tweet_count": 5
        },
        {
          "end": "2024-01-17T00:00:00.000Z",
          "start": "2024-01-16T00:00:00.000Z",
          "tweet_count": 3
        },
        {
          "end": "2024-01-18T00:00:00.000Z",
          "start": "2024-01-17T00:00:00.000Z",
          "tweet_count": 8
        }
      ],
      "meta": {
        "total_tweet_count": 16
      }
    }
    ```
  </Step>
</Steps>

<div id="granularity-options">
  ## 粒度选项
</div>

控制按何种粒度对计数进行分组：

| 粒度 | 描述 |
|:------------|:------------|
| `minute` | 每分钟的计数 |
| `hour` | 每小时的计数（默认） |
| `day` | 每天的计数 |

<CodeGroup dropdown>
  ```bash cURL
  # 获取每小时计数
  curl "https://api.x.com/2/tweets/counts/recent?\
  query=python%20lang%3Aen&\
  granularity=hour" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 获取每小时计数
  response = client.posts.count_recent(
      query="python lang:en",
      granularity="hour"
  )

  for bucket in response.data:
      print(f"{bucket.start}: {bucket.tweet_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 获取每小时计数
  const response = await client.posts.countRecent({
    query: "python lang:en",
    granularity: "hour",
  });

  response.data?.forEach((bucket) => {
    console.log(`${bucket.start}: ${bucket.tweet_count}`);
  });
  ```
</CodeGroup>

<div id="filter-by-time-range">
  ## 按时间范围筛选
</div>

将统计结果限定在特定时间段：

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/counts/recent?\
  query=from%3AXDevelopers&\
  start_time=2024-01-10T00%3A00%3A00Z&\
  end_time=2024-01-15T00%3A00%3A00Z&\
  granularity=day" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 获取特定时间范围内的计数
  response = client.posts.count_recent(
      query="from:XDevelopers",
      start_time="2024-01-10T00:00:00Z",
      end_time="2024-01-15T00:00:00Z",
      granularity="day"
  )

  print(f"帖子总数: {response.meta.total_tweet_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 获取特定时间范围内的计数
  const response = await client.posts.countRecent({
    query: "from:XDevelopers",
    startTime: "2024-01-10T00:00:00Z",
    endTime: "2024-01-15T00:00:00Z",
    granularity: "day",
  });

  console.log(`帖子总数: ${response.meta?.total_tweet_count}`);
  ```
</CodeGroup>

<div id="common-parameters">
  ## 常用参数
</div>

| 参数 | 说明 | 默认值 |
|:----------|:------------|:--------|
| `query` | 搜索查询（必填） | — |
| `granularity` | 时间粒度 | `hour` |
| `start_time` | 最早时间戳（ISO 8601） | 7 天前 |
| `end_time` | 最新时间戳（ISO 8601） | 当前时间 |
