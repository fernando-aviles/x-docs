本指南将引导你获取可追溯至 2006 年 3 月的历史帖子数量。

<Warning>
  获取完整归档的帖子计数需要具备 [Self-serve](/zh/x-api/getting-started/about-x-api) 或 [Enterprise](/zh/x-api/getting-started/about-x-api) 访问权限。
</Warning>

<Note>
  **先决条件**

  在开始之前，你需要：

  * 一个具备 Self-serve 或 Enterprise 访问权限的 [开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)
  * 你的应用的 Bearer Token
</Note>

***

<div id="get-full-archive-post-counts">
  ## 获取全归档帖子计数
</div>

<Steps>
  <Step title="构建查询">
    使用与全归档搜索相同的查询语法。例如，要统计来自 @XDevelopers 的帖子数量：

    ```
    from:XDevelopers
    ```
  </Step>

  <Step title="设置时间范围">
    指定 `start_time` 和 `end_time` 以搜索特定的历史时间段：

    | 参数 | 格式 | 示例 |
    |:----------|:-------|:--------|
    | `start_time` | ISO 8601 | `2020-01-01T00:00:00Z` |
    | `end_time` | ISO 8601 | `2020-12-31T23:59:59Z` |
  </Step>

  <Step title="发起请求">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/tweets/counts/all?\
      query=from%3AXDevelopers&\
      start_time=2020-01-01T00%3A00%3A00Z&\
      end_time=2020-12-31T23%3A59%3A59Z&\
      granularity=day" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # 获取全归档帖子计数
      response = client.posts.count_all(
          query="from:XDevelopers",
          start_time="2020-01-01T00:00:00Z",
          end_time="2020-12-31T23:59:59Z",
          granularity="day"
      )

      for bucket in response.data:
          print(f"{bucket.start}: {bucket.tweet_count} Posts")

      print(f"Total: {response.meta.total_tweet_count}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // 获取全归档帖子计数
      const response = await client.posts.countAll({
        query: "from:XDevelopers",
        startTime: "2020-01-01T00:00:00Z",
        endTime: "2020-12-31T23:59:59Z",
        granularity: "day",
      });

      response.data?.forEach((bucket) => {
        console.log(`${bucket.start}: ${bucket.tweet_count} Posts`);
      });

      console.log(`Total: ${response.meta?.total_tweet_count}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="查看响应">
    ```json
    {
      "data": [
        {
          "end": "2020-01-02T00:00:00.000Z",
          "start": "2020-01-01T00:00:00.000Z",
          "tweet_count": 3
        },
        {
          "end": "2020-01-03T00:00:00.000Z",
          "start": "2020-01-02T00:00:00.000Z",
          "tweet_count": 5
        }
      ],
      "meta": {
        "total_tweet_count": 8
      }
    }
    ```
  </Step>
</Steps>

<div id="granularity-options">
  ## 粒度选项
</div>

控制计数的分组方式：

| 粒度 | 描述 |
|:------------|:------------|
| `minute` | 按分钟统计 |
| `hour` | 按小时统计（默认） |
| `day` | 按天统计 |

***

<div id="paginate-through-results">
  ## 对结果进行分页
</div>

在时间范围较大时，请使用响应中的 `next_token`：

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/counts/all?\
  query=from%3AXDevelopers&\
  start_time=2015-01-01T00%3A00%3A00Z&\
  end_time=2020-12-31T23%3A59%3A59Z&\
  granularity=day&\
  next_token=abc123" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 通过分页获取计数
  next_token = None

  while True:
      response = client.posts.count_all(
          query="from:XDevelopers",
          start_time="2015-01-01T00:00:00Z",
          end_time="2020-12-31T23:59:59Z",
          granularity="day",
          next_token=next_token
      )
      
      for bucket in response.data:
          print(f"{bucket.start}: {bucket.tweet_count}")
      
      next_token = response.meta.next_token
      if not next_token:
          break
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 通过分页获取计数
  let nextToken = undefined;

  do {
    const response = await client.posts.countAll({
      query: "from:XDevelopers",
      startTime: "2015-01-01T00:00:00Z",
      endTime: "2020-12-31T23:59:59Z",
      granularity: "day",
      nextToken,
    });

    response.data?.forEach((bucket) => {
      console.log(`${bucket.start}: ${bucket.tweet_count}`);
    });

    nextToken = response.meta?.next_token;
  } while (nextToken);
  ```
</CodeGroup>

<div id="key-differences-from-recent-counts">
  ## 与最近计数的主要区别
</div>

| 功能 | 最近计数 | 全量存档计数 |
|:--------|:--------------|:--------------------|
| 时间范围 | 过去 7 天 | 2006 年 3 月至今 |
| 访问要求 | 所有开发者 | 按次计费，Enterprise |
| 默认时间范围 | 过去 7 天 | 过去 30 天 |

***

<div id="common-parameters">
  ## 常用参数
</div>

| 参数 | 描述 | 默认值 |
|:----------|:------------|:--------|
| `query` | 搜索查询（必需） | — |
| `granularity` | 时间粒度 | `hour` |
| `start_time` | 最早时间戳（ISO 8601） | 30 天前 |
| `end_time` | 最新时间戳（ISO 8601） | 当前时间 |
| `next_token` | 分页令牌 | — |
