  ### 核心概念
</div>

<div id="authentication">
  #### 身份验证
</div>

所有 X API v2 端点都要求你使用一组凭证（也称为密钥和令牌）对请求进行身份验证。

你可以使用 OAuth 1.0a User Context 或 OAuth 2.0 Bearer Token 来对发送到 Retweets 查询端点的请求进行身份验证。

管理 Retweets 的端点需要使用 OAuth 1.0a User Context，这意味着你必须使用一组 API 密钥和用户访问令牌才能成功发起请求。访问令牌必须与由你代为发起请求的用户关联。如果你想为另一位用户生成一组访问令牌，对方必须通过三方（3-legged）OAuth 流程授权或认证你的应用。

请注意，OAuth 1.0a 的使用可能比较复杂。如果你不熟悉这种身份验证方法，建议你使用一个[库](/zh/x-api/tools-and-libraries/overview)来正确地对你的请求进行身份验证。

**请注意**

如果你请求以下字段，则必须使用 OAuth 1.0a User Context：

* tweet.fields.non&#95;public&#95;metrics
* tweet.fields.promoted&#95;metrics
* tweet.fields.organic&#95;metrics
* media.fields.non&#95;public&#95;metrics
* media.fields.promoted&#95;metrics
* media.fields.organic&#95;metrics

<div id="developer-console-projects-and-developer-apps">
  #### Developer Console、Project 和开发者 App
</div>

要获取一组可用于 X API v2 端点的身份验证凭证，你必须先[注册开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)，在该账号下创建一个 [Project](/zh/resources/fundamentals/developer-apps)，然后在该 Project 内创建一个[开发者 App](/zh/resources/fundamentals/developer-apps)。之后，你可以在自己的开发者 App 中找到密钥和令牌。

<div id="rate-limits">
  #### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为了管理如此庞大的请求量，[速率限制](/zh/x-api/fundamentals/rate-limits) 会针对每个 endpoint 设置调用上限，用于限制代表应用或已认证用户发起的请求次数。

用于管理 Retweets 的 endpoints 限制为每位用户每 15 分钟最多 50 次请求。此外，对于 POST endpoint，每位用户在每个应用下的每 3 小时窗口内最多可发起 300 次请求。

使用 Retweets lookup endpoint 时，每个 15 分钟窗口内最多可发起 75 次请求。此外，该 endpoint 只会返回最近的 100 个执行 Retweet 的用户。

<div id="fields-and-expansions">
  #### 字段和扩展
</div>

X API v2 允许用户使用一组称为字段和扩展的工具，精确选择他们希望从 API 返回的 data。`expansions` 参数允许你展开在响应有效负载中通过 id 引用的对象。例如，此端点允许你获取以下[扩展](/zh/x-api/fundamentals/expansions)：

* attachments.poll&#95;ids
* attachments.media&#95;keys
* author&#95;id, entities.mentions.username
* geo.place&#95;id
* in&#95;reply&#95;to&#95;user&#95;id,
* referenced&#95;tweets.id,
* referenced&#95;tweets.id.author&#95;id

`fields` 参数允许你精确选择在不同 data 对象中你希望接收哪些[字段](/zh/x-api/fundamentals/fields)。这些端点主要返回帖子对象（Post 对象）。默认情况下，Post 对象只返回 `id` 和 `text` 字段。若要接收额外字段（例如 `tweet.created_at` 或 `tweet.entities`），你必须通过 `fields` 参数显式请求这些字段。在你的集成中，你可能希望考虑使用的一些重要字段包括投票数据、指标（metrics）、帖子注释以及会话 ID 字段。

我们在 [X API v2 数据字典](/zh/x-api/fundamentals/data-dictionary)中增加了一篇指南，介绍如何结合[使用字段和扩展](/zh/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)。

<div id="get-users-who-retweeted-a-post">
  #### 获取转发该帖子的用户
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/1234567890/retweeted_by?user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 获取转发该帖子的用户
  response = client.posts.get_retweeted_by(
      "1234567890",
      user_fields=["username", "verified"]
  )
  for user in response.data:
      print(f"{user.username} - Verified: {user.verified}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 获取转发该帖子的用户
  const response = await client.posts.getRetweetedBy("1234567890", {
    userFields: ["username", "verified"],
  });

  response.data?.forEach((user) => {
    console.log(`${user.username} - Verified: ${user.verified}`);
  });
  ```
</CodeGroup>

<div id="retweet-a-post">
  #### 转发帖子
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/retweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 转发帖子
  response = client.posts.retweet(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 转发帖子
  const response = await client.posts.retweet("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
