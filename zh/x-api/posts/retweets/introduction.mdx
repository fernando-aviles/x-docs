Retweets 端点可以用于转发和撤销转发、查看是谁转发了某条帖子，以及获取你自己帖子的转发列表。

<div id="endpoints">
  ## 端点
</div>

<div id="retweets-lookup">
  ### 转发查询
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/retweeted_by`](/zh/x-api/posts/get-reposted-by) | 获取转发某条帖子的用户 |
| GET | [`/2/tweets/:id/quote_tweets`](/zh/x-api/posts/get-quoted-posts) | 获取引用某条帖子的帖子 |
| GET | [`/2/users/reposts_of_me`](/zh/x-api/users/get-reposts-of-me) | 获取转发已认证用户帖子的帖子 |

<div id="manage-retweets">
  ### 管理转发
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/retweets`](/zh/x-api/users/repost-post) | 转发一条帖子 |
| DELETE | [`/2/users/:id/retweets/:tweet_id`](/zh/x-api/users/unrepost-post) | 撤销转发 |

***

<div id="example-get-retweeting-users">
  ## 示例：获取转发该帖子的用户
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890/retweeted_by?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-retweet-a-post">
  ## 示例：转发帖子
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/retweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
