<div id="manage-likes-standard-v11-compared-to-x-api-v2">
  ### 管理点赞：标准版 v1.1 与 X API v2 的比较
</div>

如果你一直在使用标准版 v1.1 的 [POST favorites/create](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-create) 和 [POST favorites/destroy](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-destroy) 端点，本指南旨在帮助你理解标准版 v1.1 与 X API v2 之间用于管理点赞的端点有何异同。

* **相同点**
  * OAuth 1.0a 用户上下文
* **不同点**
  * 端点 URL 和 HTTP 方法
  * App 和 Project 要求
  * 请求参数

<div id="similarities">
  #### 相似之处
</div>

**OAuth 1.0a 用户上下文身份验证方式**

这两个版本的 endpoint 都支持 [OAuth 1.0a User Context](/zh/resources/fundamentals/authentication#oauth-1-0a-2)。因此，如果你之前使用的是某个标准 v1.1 的管理收藏（favorites）endpoint，那么在迁移到 X API v2 版本时，仍可继续使用相同的身份验证方式。

<div id="differences">
  #### 差异
</div>

**端点 URL 和 HTTP 方法**

* 标准 v1.1 端点：
  * POST https://api.x.com/1.1/favorites/create.json
    （为一个帖子点赞）
  * POST https://api.x.com/1.1/favorites/destroy.json
    （为一个帖子取消点赞）
* X API v2 端点：
  * POST https://api.x.com/2/tweets/:id/likes
    （为一个帖子点赞）
  * DELETE https://api.x.com/2/tweets/:id/likes/:tweet&#95;id
    （为一个帖子取消点赞） 

**App 和 Project 要求**

在对请求进行认证时，X API v2 端点要求你使用某个与 [developer App](/zh/resources/fundamentals/developer-apps) 关联并归属到某个 [Project](/zh/resources/fundamentals/developer-apps) 的凭证。所有 X API v1.1 端点则可以使用来自 App 的凭证，或者来自与 App 关联的 App 的凭证。

**请求参数**

以下标准 v1.1 请求参数在 X API v2 中有对应项：

| 标准 v1.1 | X API v2 |
| :--- | :--- |
| id  | id  |
| includes&#95;entities | 无对应项 |

请注意，标准 v1.1 参数是作为查询参数传递的，而 X API v2 参数则在 POST 端点中作为请求体参数传递，或在 DELETE 端点中作为路径参数传递。

另外，在使用标准 v1.1 端点时，不需要提供为帖子点赞的用户的 id，因为随 [OAuth 1.0a User Context](/zh/resources/fundamentals/authentication) 一同传递的 [Access Tokens](/zh/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) 会推断出是哪位用户发起了点赞或取消点赞操作。

<div id="like-a-post-v2">
  ### 为帖子点赞 (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/likes" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python
  # 需要使用 OAuth 1.0a 用户上下文进行认证
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/likes"
  response = requests.post(url, auth=auth, json={"tweet_id": "1234567890"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 为帖子点赞
  response = client.posts.like(user_id="123456789", tweet_id="1234567890")
  print(f"Liked: {response.data.liked}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 为帖子点赞
  const response = await client.posts.like("123456789", { tweetId: "1234567890" });
  console.log(`Liked: ${response.data?.liked}`);
  ```
</CodeGroup>

  ### 取消对帖子点赞（v2）
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/123456789/likes/1234567890" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  # 使用 OAuth 1.0a 用户上下文进行认证
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
  ```
