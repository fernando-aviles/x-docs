Likes 端点使你能够对帖子点赞或取消点赞、查看点赞某个帖子的用户，以及获取某个用户点赞过的帖子。

<div id="endpoints">
  ## 接口
</div>

<div id="likes-lookup">
  ### 点赞查找
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/liking_users`](/zh/x-api/posts/get-liking-users) | 获取对某条帖子点过赞的用户 |
| GET | [`/2/users/:id/liked_tweets`](/zh/x-api/users/get-liked-posts) | 获取某个用户点过赞的帖子 |

<div id="manage-likes">
  ### 管理点赞
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/likes`](/zh/x-api/users/like-post) | 点赞帖子 |
| DELETE | [`/2/users/:id/likes/:tweet_id`](/zh/x-api/users/unlike-post) | 取消点赞帖子 |

***

<div id="important-notes">
  ## 重要说明
</div>

<Note>
  无论实际点赞总数是多少，liking users 端点在任意时间范围内对每个帖子最多只返回 **100 个用户**。
</Note>

***

<div id="example-get-liking-users">
  ## 示例：获取点赞用户
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890/liking_users?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-like-a-post">
  ## 示例：给帖子点赞
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
