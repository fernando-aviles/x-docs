Likes 端点允许你给帖子点赞或取消点赞、查看哪些用户点赞了某条帖子，以及获取某个用户点赞过的帖子。

<div id="endpoints">
  ## 端点
</div>

<div id="likes-lookup">
  ### 点赞查询
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/liking_users`](/zh/x-api/posts/get-liking-users) | 获取点赞某条帖子的用户 |
| GET | [`/2/users/:id/liked_tweets`](/zh/x-api/users/get-liked-posts) | 获取某用户点赞过的帖子 |

<div id="manage-likes">
  ### 管理点赞
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/likes`](/zh/x-api/users/like-post) | 为帖子点赞 |
| DELETE | [`/2/users/:id/likes/:tweet_id`](/zh/x-api/users/unlike-post) | 取消对帖子点赞 |

***

<div id="important-notes">
  ## 重要说明
</div>

<Note>
  无论实际点赞数量是多少，liking users 端点在每个帖子整个生命周期内最多只返回 **100 名用户**。
</Note>

***

<div id="example-get-liking-users">
  ## 示例：获取点赞该帖的用户
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890/liking_users?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-like-a-post">
  ## 示例：点赞帖子
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
