Timelines 端点允许你从用户时间线、提及信息流和主页信息流中检索帖子。你可以获取某个用户发布的内容、查看提到他们的帖子，或查看他们个性化的主页时间线。

<div id="endpoints">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/zh/x-api/users/get-posts) | 获取某用户发布的帖子 |
| GET | [`/2/users/:id/mentions`](/zh/x-api/users/get-mentions) | 获取提及某用户的帖子 |
| GET | [`/2/users/:id/timelines/reverse_chronological`](/zh/x-api/users/get-timeline) | 获取主页时间线 |

</div>

* 可过滤掉回复和转发
* 支持分页
* 支持基于时间筛选的历史数据访问

<div id="reverse-chronological-home-timeline">
  ## 按时间倒序排列的主页时间线
</div>

以时间倒序获取经过身份验证用户的主页时间线。

<div id="features">
  ### 功能
</div>

* 来自已关注账号的帖子
* 最近的 3,200 条帖子（或最近 7 天内的帖子）
* 不包含算法推荐排序
* 需要用户身份验证

<Note>
  此 endpoint 需要使用 [OAuth 1.0a User Context](/zh/resources/fundamentals/authentication) 或 [OAuth 2.0 Authorization Code with PKCE](/zh/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)。
</Note>

<div id="filtering-options">
  ## 过滤选项
</div>

<div id="exclude-parameter">
  ### exclude 参数
</div>

过滤特定类型的帖子：

| Value      | Effect |
| :--------- | :----- |
| `retweets` | 排除转发   |
| `replies`  | 排除回复   |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="time-based-filtering">
  ### 基于时间的过滤
</div>

| 参数 | 说明 |
|:----------|:------------|
| `start_time` | 最早的帖子时间戳（ISO 8601） |
| `end_time` | 最新的帖子时间戳（ISO 8601） |
| `since_id` | 返回此 id 之后的帖子 |
| `until_id` | 返回此 id 之前的帖子 |
