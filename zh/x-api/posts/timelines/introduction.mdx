<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/zh/x-api/users/get-posts) | 获取指定用户的帖子 |

<div id="user-posts-timeline">
  ## 用户帖子时间线
</div>

获取由特定用户发布的最新帖子。

<div id="features">

* 可过滤掉回复和转发
* 支持分页
* 支持按时间过滤访问历史数据

<div id="reverse-chronological-home-timeline">
  ## 按时间倒序排列的首页时间线
</div>

按时间倒序获取已认证用户的首页时间线。

<div id="features">
  ### 功能
</div>

* 来自已关注账号的帖子
* 最近的 3,200 条帖子（或最近 7 天内的帖子）
* 不经过算法排序
* 需要用户身份验证

<Note>
  此端点需要使用 [OAuth 1.0a User Context](/zh/resources/fundamentals/authentication) 或 [OAuth 2.0 Authorization Code with PKCE](/zh/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)。
</Note>

<div id="filtering-options">
  ## 筛选选项
</div>

<div id="exclude-parameter">
  ### exclude 参数
</div>

过滤掉特定的帖子类型：

| 值          | 作用   |
| :--------- | :--- |
| `retweets` | 排除转发 |
| `replies`  | 排除回复 |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="time-based-filtering">
  ### 基于时间的过滤
</div>

| 参数 | 说明 |
|:----------|:------------|
| `start_time` | 最早的帖子时间戳（ISO 8601） |
| `end_time` | 最新的帖子时间戳（ISO 8601） |
| `since_id` | 返回 id 大于该值的帖子 |
| `until_id` | 返回 id 小于该值的帖子 |
