<div id="authentication">
  ## 身份验证
</div>

<div id="endpoint-requirements">
  ### 端点要求
</div>

| 端点 | 仅限 App | 用户上下文 |
|:---------|:---------|:-------------|
| 用户帖子时间线 | ✓ | ✓ |
| 用户被提及时间线 | ✓ | ✓ |
| 主页时间线 | — | ✓（必需） |

<div id="private-metrics">
  ### 私有指标
</div>

要访问私有指标，你必须以帖子作者的身份进行身份验证：

<Warning>
  这些字段需要使用 User Context 身份验证：

  * `tweet.fields.non_public_metrics`
  * `tweet.fields.promoted_metrics`
  * `tweet.fields.organic_metrics`
  * `media.fields.non_public_metrics`
  * `media.fields.promoted_metrics`
  * `media.fields.organic_metrics`
</Warning>

***

<div id="fields-and-expansions">
  ## 字段和 expansions
</div>

默认情况下，响应只包含 `id`、`text` 和 `edit_history_tweet_ids`。要请求更多数据：

<div id="example-request">
  ### 示例请求
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123/tweets?\
  tweet.fields=created_at,public_metrics,author_id&\
  expansions=author_id,attachments.media_keys&\
  user.fields=username,verified&\
  media.fields=url,type" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 获取用户帖子时间线
  for page in client.posts.get_user_posts(
      user_id="123",
      tweet_fields=["created_at", "public_metrics", "author_id"],
      expansions=["author_id", "attachments.media_keys"],
      user_fields=["username", "verified"],
      media_fields=["url", "type"],
      max_results=100
  ):
      for post in page.data:
          print(f"{post.text} - {post.public_metrics}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 通过分页获取用户帖子时间线
  const paginator = client.posts.getUserPosts("123", {
    tweetFields: ["created_at", "public_metrics", "author_id"],
    expansions: ["author_id", "attachments.media_keys"],
    userFields: ["username", "verified"],
    mediaFields: ["url", "type"],
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text} - ${JSON.stringify(post.public_metrics)}`);
    });
  }
  ```
</CodeGroup>

| Field | Description |

| `created_at` | 帖子创建时间戳 |

| `conversation_id` | 会话标识符 |

<div id="pagination">
  ## 分页
</div>

时间线每次请求最多返回 100 条帖子。对于更大的结果集，请使用分页功能。

<div id="how-it-works">
  ### 工作原理
</div>

1. 使用带有 `max_results` 参数的初始请求
2. 从 `meta` 对象中获取 `next_token`
3. 在下一次请求中包含 `pagination_token`
4. 重复上述步骤，直到不再返回 `next_token`

<div id="example">
  ### 示例
</div>

<CodeGroup dropdown>
  ```bash cURL
  # 第一次请求
  curl "https://api.x.com/2/users/123/tweets?max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"

  # 带分页令牌的后续请求
  curl "https://api.x.com/2/users/123/tweets?max_results=100&pagination_token=NEXT_TOKEN" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # SDK 会自动处理分页
  all_posts = []

  for page in client.posts.get_user_posts(user_id="123", max_results=100):
      if page.data:
          all_posts.extend(page.data)

  print(f"Found {len(all_posts)} posts")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  async function getAllTimelinePosts(userId) {
    const allPosts = [];

    // SDK 通过异步迭代自动处理分页
    const paginator = client.posts.getUserPosts(userId, { maxResults: 100 });

    for await (const page of paginator) {
      if (page.data) {
        allPosts.push(...page.data);
      }
    }

    return allPosts;
  }

  // 用法
  const posts = await getAllTimelinePosts("123");
  console.log(`Found ${posts.length} posts`);
  ```
</CodeGroup>

<div id="filtering-results">
  ## 筛选结果
</div>

<div id="time-based-filtering">
  ### 基于时间的过滤
</div>

| 参数 | 描述 |
|:----------|:------------|
| `start_time` | 最早的帖子时间戳（ISO 8601） |
| `end_time` | 最新的帖子时间戳（ISO 8601） |
| `since_id` | 返回该 ID 之后的帖子 |
| `until_id` | 返回该 ID 之前的帖子 |

<div id="exclude-parameter">
  ### exclude 参数
</div>

将特定类型的帖子从结果中排除：

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 排除转发和回复
  for page in client.posts.get_user_posts(
      user_id="123",
      exclude=["retweets", "replies"]
  ):
      for post in page.data:
          print(post.text)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 排除转发和回复
  const paginator = client.posts.getUserPosts("123", {
    exclude: ["retweets", "replies"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => console.log(post.text));
  }
  ```
</CodeGroup>

| 值 | 作用 |
|:------|:-------|
| `retweets` | 排除转发 |
| `replies` | 排除回复 |

<div id="volume-limits">
  ## 数量限制
</div>

每个时间线都有最大可检索数量：

| Endpoint | 最大帖子数量 |
|:---------|:--------------|
| 用户帖子时间线 | 最近 3,200 条 |
| 用户帖子（exclude=replies） | 最近 800 条 |
| 用户提及时间线 | 最近 800 条 |
| 主页时间线 | 最多 3,200 条或最近 7 天的内容 |

<Note>
  请求超出这些限制范围的帖子会返回成功响应，但不包含数据。
</Note>

<div id="post-edits">
  ## 帖子编辑
</div>

帖子最多可在 30 分钟内编辑 5 次。时间线相关接口始终返回最新版本。

<div id="considerations">
  ### 注意事项
</div>

* 超过 30 分钟的帖子将被视为其最终版本
* 准实时场景应考虑可能发生的编辑
* 如有需要，可使用帖子查找来验证最终状态

<div id="post-metrics">
  ## 帖子指标
</div>

<div id="public-metrics">
  ### 公开指标
</div>

适用于所有使用 App-only 或用户上下文身份验证的帖子：

```json
{
  "public_metrics": {
    "retweet_count": 156,
    "reply_count": 23,
    "like_count": 892,
    "quote_count": 12
  }
}
```

### 私密指标

需要使用帖子作者的用户上下文进行认证：

* 仅适用于过去 30 天内的帖子
* 仅返回由已认证用户创作的帖子
* 对其他用户的帖子会返回错误

***

<div id="edge-cases">
  ## 特殊情况
</div>

<Accordion title="非公开指标与分页">
  当请求发布时间早于 30 天前的帖子非公开指标时，您可能会收到带有 `result_count: 0` 的 `next_token`。为避免这种情况：

  * 将请求限定在最近 30 天内
  * 将 `max_results` 设置为至少 10
</Accordion>

<Accordion title="未推广帖子的推广指标">
  为未推广的帖子请求推广指标会返回空响应。这是一个已知问题。
</Accordion>

<Accordion title="被截断的转推文本">
  对于文本超过 140 个字符的转推，`text` 字段会被截断。使用 `referenced_tweets.id` 扩展以获取完整文本。
</Accordion>
