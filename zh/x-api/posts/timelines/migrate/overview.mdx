<div id="comparing-x-apis-timelines-endpoints">
  ## X API 时间线端点对比
</div>

X API v2 中的倒序时间线、用户帖子时间线和用户提及时间线端点分别替代了 [v1.1 statuses/home&#95;timeine](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-home_timeline)、[v1.1 statuses/user&#95;timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-user_timeline.html) 和 [v1.1 statuses/mentions&#95;timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-mentions_timeline.html) 端点。如果你有使用这些旧版端点的代码、App 或工具，并正在考虑迁移到新的 X API v2 端点，那么本指南适合你。要查看更详细的迁移说明，请参阅 [Standard v1.1 迁移至 X API v2](/zh/x-api/posts/timelines/migrate/standard-to-twitter-api-v2)。

本页包含三个对比表：

* 倒序主页时间线
* 用户帖子时间线
* 用户提及时间线

<div id="reverse-chronological-home-timeline">
  ### 按时间倒序的主页时间线
</div>

下表对比了标准 v1.1 与 X API v2 的主页时间线端点：

|                                                                                                                     |                                                                                                                                                        |                                                                                                                                                                                                                                                                                                                                            |
| :------------------------------------------------------------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **说明**                                                                                                              | **Standard v1.1**                                                                                                                                      | **X API v2**                                                                                                                                                                                                                                                                                                                               |
| 文档                                                                                                                  | [API 参考](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-home_timeline)                                     | [API 参考](https://developer.x.com/x-api/posts/timelines#user-mention-timeline-3)                                                                                                                                                                                                                                                            |
| 支持的 HTTP 方法                                                                                                         | `GET`                                                                                                                                                  | `GET`                                                                                                                                                                                                                                                                                                                                      |
| 主机域名                                                                                                                | `https://api.x.com`                                                                                                                                    | `https://api.x.com`                                                                                                                                                                                                                                                                                                                        |
| 端点路径                                                                                                                | `/1.1/statuses/home_timeline.json`                                                                                                                     | `/2/users/:id/timelines/reverse_chronological`                                                                                                                                                                                                                                                                                             |
| 必需的参数                                                                                                               | `user_id` or `screen_name`                                                                                                                             | 将用户 ID 设置为路径参数 :id                                                                                                                                                                                                                                                                                                                         |
| 身份验证                                                                                                                | OAuth 1.0a 用户上下文                                                                                                                                       | OAuth 1.0a 用户上下文<br /><br />[带 PKCE 的 OAuth 2.0 授权码流程](/zh/resources/fundamentals/authenticationoauth-2-0/authorization-code)                                                                                                                                                                                                                 |
| 请求速率限制                                                                                                              | 每 15 分钟最多 15 次请求，使用 OAuth 1.0a User Context<br /><br />请求上限：24 小时内最多 100,000 次。                                                                        | 每 15 分钟 180 个请求                                                                                                                                                                                                                                                                                                                            |
| 每个响应中返回的默认帖子数量                                                                                                      | 15                                                                                                                                                     | 100                                                                                                                                                                                                                                                                                                                                        |
| 每个响应中返回的最大帖子数量                                                                                                      | 800                                                                                                                                                    | 此端点将返回时间线中过去 7 天内创建的所有帖子，以及无论创建日期的最近 800 条帖子。                                                                                                                                                                                                                                                                                              |
| 提供帖子编辑历史记录                                                                                                          | ✔                                                                                                                                                      | ✔                                                                                                                                                                                                                                                                                                                                          |
| 可用的历史帖子                                                                                                             | 最近的 800 条帖子，包括转推                                                                                                                                       | 最近的 3,200 条帖子，包括转推                                                                                                                                                                                                                                                                                                                         |
| 时间线导航选项                                                                                                             | since&#95;id（不包含该 id）用于增量轮询<br /><br />`max_id`（包含该 id）                                                                                                | `start_time`<br /><br />end&#95;time<br /><br />`since_id`（不包含该 id）用于更新轮询 <br /><br />`until_id`（不包含该 id）                                                                                                                                                                                                                                  |
| 用于优化结果的可选参数                                                                                                         | `count`<br /><br />`exclude_replies`<br /><br />`include_rts`<br /><br />`trim_user`<br /><br />`tweet_mode`<br /><br />`since_id`<br /><br />`max_id` | `max_results`<br /><br />`exclude`(转推、回复)<br /><br />`tweet.fields`<br /><br />`user.fields`<br /><br />`place.fields`<br /><br />`media.fields`<br /><br />`poll.fields`<br /><br />`expansions`<br /><br />`start_time`<br /><br />`end_time`<br /><br />`since_id`<br /><br />`until_id`                                                |
| 支持请求并接收[标注](/zh/x-api/fundamentals/post-annotations)                                                                   | 不适用                                                                                                                                                    | 如果在 tweet.fields 中包含注解，结果将附带基于帖子文本推断出的注解数据，例如“Music Genre”和“Folk Music”，或“Musician”和“Dolly Parton”。                                                                                                                                                                                                                                        |
| 支持请求并接收特定帖子的[指标](/zh/x-api/fundamentals/metrics)                                                                       | 不适用                                                                                                                                                    | 如果在 `tweet.fields` 中包含注解，结果中每条帖子都会附带 public&#95;metrics 注解，包括 `retweet_count`、`reply_count`、`quote_count` 和 `like_count`，以及 `non_public_metrics`，包括 `impression_count`、`user_profile_clicks`、`url_link_clicks`。<br /><br />其他媒体指标，例如 view&#95;count 和视频播放相关指标。<br /><br />在用户上下文下，对推广帖子还可获取额外的 organic&#95;metrics 和 promoted&#95;metrics。 |
| 支持请求并接收 [conversation&#95;id](/zh/x-api/fundamentals/conversation-id)                                                  | 不适用                                                                                                                                                    | 返回 conversation&#95;id 字段，其值标识回复线程中首条已发布的帖子，帮助你跟踪会话。                                                                                                                                                                                                                                                                                       |
| 帖子 JSON 格式                                                                                                          | [标准 v1.1 数据格式](https://developer.x.com/en/docs/twitter-api/v1/data-dictionary/overview.html)                                                           | [X API v2](/zh/x-api/fundamentals/data-dictionary) 格式（由 fields 和 expansions 请求参数决定，与 v1.1 格式不兼容）<br /><br />要详细了解如何从 Standard v1.1 格式迁移到 X API v2 格式，请参阅我们的[数据格式迁移指南](/zh/x-api/migrate/data-format-migration)。                                                                                                                                  |
| 结果顺序                                                                                                                | 按时间逆序                                                                                                                                                  | 按时间逆序                                                                                                                                                                                                                                                                                                                                      |
| 结果分页                                                                                                                | 不适用；必须通过帖子 ID 进行导航                                                                                                                                     | 可以使用 pagination&#95;token 向前或向后查看结果                                                                                                                                                                                                                                                                                                        |
| 需要使用隶属于某个 [Project](/zh/resources/fundamentals/developer-apps) 的 [开发者 App](/zh/resources/fundamentals/developer-apps) 的凭证 |                                                                                                                                                        | ✔                                                                                                                                                                                                                                                                                                                                          |

<div id="user-post-timeline">
  ### 用户帖子时间线
</div>

下表对比了标准 v1.1 和 X API v2 的用户帖子时间线端点：

|     |     |     |
| :--- | :--- | :--- |
| **Description** | **Standard v1.1** | **X API v2** |
| Documentation | [API 参考](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-user_timeline.html) | [API 参考](/zh/x-api/posts/user-posts-timeline-by-user-id) |
| HTTP methods supported | GET | GET |
| Host domain | https://api.x.com | https://api.x.com |
| Endpoint paths | /1.1/statuses/user&#95;timeline.json | /2/users/:id/tweets |
| Required parameters | user&#95;id 或 screen&#95;name | 用户 ID，作为路径参数 :id |
| Authentication | OAuth 1.0a User Context<br /><br />OAuth 2.0 App-Only | OAuth 1.0a User Context<br /><br />OAuth 2.0 App-Only<br /><br />OAuth 2.0 Authorization Code with PKCE |
| Request rate limits | 使用 OAuth 1.0a User Context 时，每个 15 分钟时间窗口内 900 个请求<br /><br />使用 OAuth 2.0 App-Only 时，每个 15 分钟时间窗口内 1500 个请求<br /><br />请求总量上限：24 小时内 100,000 个。 | 使用 OAuth 1.0a User Context 时，每个 15 分钟时间窗口内 900 个请求<br /><br />使用 OAuth 2.0 App-Only 时，每个 15 分钟时间窗口内 1500 个请求 |
| Default Posts per response | 每个响应默认返回 15 条帖子 | 每个响应默认返回 10 条帖子 |
| Maximum Posts per response | 每个响应最多返回 200 条帖子 | 每个响应最多返回 100 条帖子 |
| Historical Posts available | 最近的 3,200 条帖子，包括转发（Retweets） | 最近的 3,200 条帖子，包括转发（Retweets） |
| Timeline navigation options | 使用 since&#95;id（不包含该 id）进行更新轮询<br /><br />max&#95;id（包含该 id） | start&#95;time<br /><br />end&#95;time<br /><br />使用 since&#95;id（不包含该 id）进行更新轮询<br /><br />until&#95;id（不包含该 id） |
| Optional parameters for results refinement | count  <br />exclude&#95;replies  <br />include&#95;rts  <br />trim&#95;user  <br />tweet&#95;mode  <br />since&#95;id  <br />max&#95;id | max&#95;results  <br />exclude(retweets,replies)  <br />tweet.fields  <br />user.fields  <br />place.fields  <br />media.fields  <br />poll.fields  <br />expansions  <br />start&#95;time  <br />end&#95;time  <br />since&#95;id  <br />until&#95;id |
| Supports requesting and receiving [annotations](/zh/x-api/fundamentals/post-annotations) | 不适用 | 返回的帖子结果中包含基于帖子文本推断的注解数据，例如 “Music Genre” 和 “Folk Music”，或 “Musician” 和 “Dolly Parton” |
| Supports requesting and receiving specific Post [metrics](/zh/x-api/fundamentals/metrics) | 不适用 | 返回的帖子结果中包含每条帖子可用的 public&#95;metrics，例如 retweet&#95;count、reply&#95;count、quote&#95;count 和 like&#95;count。  <br />  <br />在 OAuth 1.0a User Context 下可用：<br />额外的 non&#95;public&#95;metrics，包括 impression&#95;count、user&#95;profile&#95;clicks、url&#95;link&#95;clicks。<br /><br />额外的媒体指标，例如 view&#95;count 以及视频播放相关指标。<br /><br />对于推广帖子，在 OAuth 1.0a User Context 下还可获得额外的 organic&#95;metrics 和 promoted&#95;metrics。 |
| Supports requesting and receiving [conversation&#95;id](/zh/x-api/fundamentals/conversation-id) | 不适用 | 返回一个 conversation&#95;id 字段，其值表示回复线程中最先发布的帖子，以帮助你追踪会话。 |
| Post JSON format | [Standard v1.1 数据格式](/zh/x-api/fundamentals/data-dictionary) | [X API v2](/zh/x-api/fundamentals/data-dictionary) 格式（由 fields 和 expansions 请求参数决定，与 v1.1 格式不向后兼容）<br /><br />要了解如何从 Standard v1.1 格式迁移到 X API v2 格式，请访问我们的[数据格式迁移指南](/zh/x-api/migrate/data-format-migration)。 |
| Results order | 按时间倒序 | 按时间倒序 |
| Results pagination | 不适用，必须通过帖子 ID 进行导航 | 可以使用 pagination&#95;token 向前或向后查看结果 |
| Requires the use of credentials from a [developer App](/zh/resources/fundamentals/developer-apps) associated with a [Project](/zh/resources/fundamentals/developer-apps) |     | ✔   |
| Provides Post edit history | ✔   | ✔   |

| 支持请求和接收 [annotations](/zh/x-api/fundamentals/post-annotations) | 不适用 | 返回的帖子结果包含基于帖子文本推断的注释数据，例如 “Music Genre” 和 “Folk Music”，或 “Musician” 和 “Dolly Parton” |
