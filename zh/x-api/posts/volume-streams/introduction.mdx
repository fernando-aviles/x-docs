* 1% 抽样流。
* 10% 抽样流，通常称为 “Decahose”。

这些被称为 “volume streams”（大流量流），因为它们都会传递大量数据。即使是 1% 抽样流，每秒也可以传输数十条帖子。使用这些流，你可以识别和跟踪趋势、监控总体情绪、监控全球事件等等。 

这些流式端点通过持续的 HTTP GET 连接传递 [Post 对象](/zh/x-api/fundamentals/data-dictionary#tweet)，并使用 [OAuth 2.0 App-Only](/zh/resources/fundamentals/authentication#oauth-2-0) 认证。使用 Essential 级别访问时，你一次只能有一个连接。在所有访问级别下，每 15 分钟窗口内最多可以发起 50 次连接请求。

这些大流量流端点支持已编辑的帖子。这些端点会返回已编辑的帖子及其编辑历史记录，其中包含一个帖子 ID 数组。对于没有编辑历史的帖子，此数组仅包含一个 ID。对于已被编辑的帖子，此数组包含多个 ID，按升序排列，反映编辑顺序，数组最后一个元素为最新版本。要进一步了解帖子编辑的工作方式，请参阅 [帖子编辑基础](/zh/x-api/fundamentals/edit-posts) 页面。 

*要使用这些 API，你必须先联系我们的企业销售团队开通账号。*

<Note>
  **账号设置**

  若要访问这些端点，你需要：

  * 一个已获批准的 [开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)。
  * 使用来自位于某个 [Project](/zh/resources/fundamentals/developer-apps) 中的 [developer App](/zh/resources/fundamentals/developer-apps) 的密钥和令牌进行认证。 

  在我们的 [入门指南](/zh/x-api/getting-started/getting-access) 中进一步了解如何获取 X API v2 端点的访问权限。
</Note>
