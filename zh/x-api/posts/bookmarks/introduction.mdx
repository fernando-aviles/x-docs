Bookmarks 端点允许你为经过身份验证的用户查看、添加和移除已加书签的帖子。Bookmarks 是私密的，仅对创建它们的用户可见。

<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/bookmarks`](/zh/x-api/users/get-bookmarks) | 获取用户书签 |
| POST | [`/2/users/:id/bookmarks`](/zh/x-api/users/create-bookmark) | 将帖子加入书签 |
| DELETE | [`/2/users/:id/bookmarks/:tweet_id`](/zh/x-api/users/delete-bookmark) | 移除书签 |
| GET | [`/2/users/:id/bookmarks/folders`](/zh/x-api/users/get-bookmark-folders) | 获取书签文件夹 |
| GET | [`/2/users/:id/bookmarks/folders/:folder_id`](/zh/x-api/users/get-bookmarks-by-folder-id) | 获取文件夹中的帖子 |

***

<div id="example-get-bookmarks">
  ## 示例：获取书签
</div>

```bash
curl "https://api.x.com/2/users/123456789/bookmarks?\
tweet.fields=created_at,author_id,public_metrics" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-add-bookmark">
  ## 示例：添加书签
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
