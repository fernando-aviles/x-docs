<div id="authentication">
  #### 身份验证
</div>

所有 X API v2 端点都要求你使用一组凭证（也称为密钥和令牌）来对请求进行身份验证。

这些特定端点要求使用 [带 PKCE 的 OAuth 2.0 授权码流程](/zh/resources/fundamentals/authentication/oauth-2-0/authorization-code)，这意味着你必须使用一组密钥和用户访问令牌（Access Tokens）才能成功发起请求。访问令牌必须与你代表其发起请求的用户关联。如果你想为另一位用户生成一组访问令牌，他们必须通过一个 [Authorize URL](/zh/resources/fundamentals/authentication#authorize-url) 来授权或验证你的 App。

请注意，OAuth 2.0 的使用可能比较复杂。如果你对这种身份验证方法不熟悉，我们建议使用一个 [library](/zh/x-api/tools-and-libraries/overview) 或者像 Postman 这样的工具来正确地为你的请求进行身份验证。

<div id="developer-console-projects-and-developer-apps">
  #### 开发者控制台、Project 和开发者 App
</div>

要获取一组可用于 X API v2 各端点的身份验证凭证，你必须先拥有一个[开发者账号](/zh/resources/fundamentals/developer-portal)，在该账号下创建一个 [Project](/zh/resources/fundamentals/developer-apps)，并在该 Project 中创建一个[开发者 App](/zh/resources/fundamentals/developer-apps)。然后，你可以在自己的开发者 App 中找到相应的密钥和令牌。

<div id="rate-limits">
  #### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为了帮助管理如此庞大的请求量，[速率限制](/zh/resources/fundamentals/rate-limits) 会被应用到每个端点上，从而限制你代表自己的应用或代表已认证用户所能发起的请求次数。

这些端点是按用户维度进行速率限制的，这意味着，你代表某个已认证用户发起的请求，在所有开发者 App 中合计只能在一定次数内调用该端点。对于 GET 方法，用户速率限制为每 15 分钟时间窗口 180 次请求。使用 Bookmarks 查询端点的 GET 方法时，你将会获得你最近收藏的最多 800 条帖子。此外，对于 POST 和 DELETE 方法，用户速率限制为每 15 分钟 50 次请求。

<div id="get-bookmarks">
  #### 获取书签
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123/bookmarks?tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 获取用户书签
  for page in client.bookmarks.get(user_id="123", tweet_fields=["created_at", "public_metrics"]):
      for post in page.data:
          print(f"{post.text} - Likes: {post.public_metrics.like_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 获取用户书签
  const paginator = client.bookmarks.get("123", {
    tweetFields: ["created_at", "public_metrics"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text} - Likes: ${post.public_metrics?.like_count}`);
    });
  }
  ```
</CodeGroup>

<div id="create-a-bookmark">
  #### 创建书签
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/bookmarks" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 为帖子添加书签
  response = client.bookmarks.create(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 为帖子添加书签
  const response = await client.bookmarks.create("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
