  ### 核心概念
</div>

<div id="authentication">
  #### 认证
</div>

所有 X API v2 端点都要求你使用一组凭证（也称为 keys 和 tokens）来对请求进行身份验证。

这些特定端点要求使用 [OAuth 2.0 Authorization Code Flow with PKCE](/zh/resources/fundamentals/authentication/oauth-2-0/authorization-code)，这意味着你必须使用一组 keys 和用户 Access Tokens 才能成功发起请求。Access Tokens 必须与你代表其发起请求的用户关联。如果你想为另一位用户生成一组 Access Tokens，他们必须通过 [Authorize URL](/zh/resources/fundamentals/authentication#authorize-url) 授权或验证你的 App。

请注意，OAuth 2.0 的使用可能比较棘手。如果你不熟悉这种认证方式，我们建议使用一个 [library](/zh/x-api/tools-and-libraries/overview) 或 Postman 之类的工具来正确地为你的请求执行认证。

<div id="developer-console-projects-and-developer-apps">
  #### 开发者控制台、Project 和开发者 App
</div>

要获取一组可用于 X API v2 端点的身份验证凭据，你必须拥有一个[开发者账号](/zh/resources/fundamentals/developer-portal)，在该账号下设置一个 [Project](/zh/resources/fundamentals/developer-apps)，并在该 Project 中创建一个[开发者 App](/zh/resources/fundamentals/developer-apps)。然后，你可以在该开发者 App 中找到你的密钥和令牌。

<div id="rate-limits">
  #### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为了管理如此巨大的请求量，[速率限制](/zh/resources/fundamentals/rate-limits) 会应用到每个端点上，用来限制你代表 App 或代表已认证用户所能发起的请求数量。

这些端点采用用户级别的速率限制，这意味着你代表其发起请求的已认证用户，在任何开发者 App 中调用该端点的次数都是有限的。对于 GET 方法，用户级别的速率限制为每 15 分钟窗口 180 次请求。使用 Bookmarks 查询端点的 GET 方法时，你将会获得最近被加为书签的 800 条帖子。此外，对于 POST 和 DELETE 方法，用户级别的速率限制为每 15 分钟 50 次请求。

<div id="get-bookmarks">
  #### 获取书签
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123/bookmarks?tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 获取用户的书签
  for page in client.bookmarks.get(user_id="123", tweet_fields=["created_at", "public_metrics"]):
      for post in page.data:
          print(f"{post.text} - Likes: {post.public_metrics.like_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 获取用户的书签
  const paginator = client.bookmarks.get("123", {
    tweetFields: ["created_at", "public_metrics"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text} - Likes: ${post.public_metrics?.like_count}`);
    });
  }
  ```
</CodeGroup>

<div id="create-a-bookmark">
  #### 创建书签
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/bookmarks" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 将帖子添加到书签
  response = client.bookmarks.create(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 将帖子添加到书签
  const response = await client.bookmarks.create("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
