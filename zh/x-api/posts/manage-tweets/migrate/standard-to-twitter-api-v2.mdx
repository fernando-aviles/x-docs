<div id="standard-v11-compared-to-x-api-v2">
  ## 标准版 v1.1 与 X API v2 的比较
</div>

如果你一直在使用标准版 v1.1 的 [POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) 和 [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id) 端点，本指南的目标是帮助你理解标准版与 X API v2 中用于管理帖子的端点之间的相似点和差异。

* **相似之处**
  * 认证方式
* **差异之处**
  * 端点 URL

  * 应用（App）和 Project 要求

  * 请求参数

<div id="similarities">
  ### 相似之处
</div>

**身份验证**

标准 v1.1 和 X API v2 中用于处理帖子（[POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) 和 [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id)）的端点都使用 [OAuth 1.0a 用户上下文](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication)。因此，如果你之前使用的是标准 v1.1 的某个端点，在迁移到 X API v2 时，可以继续使用相同的身份验证方式。

<div id="differences">
  ### 差异
</div>

**端点 URL**

* 标准 v1.1 端点：
  * https://api.x.com/1.1/statuses/update.json
    （创建帖子）
  * `https://api.x.com/1.1/statuses/destroy/:id.json`
    （删除帖子）
* X API v2 端点：
  * https://api.x.com/2/tweets
    （创建帖子）
  * https://api.x.com/2/tweets/:id
    （删除指定的帖子）

<div id="app-and-project-requirements">
  ### App 和 Project 要求
</div>

在对请求进行身份验证时，X API v2 的端点要求你必须使用来自与 [Project](/zh/resources/fundamentals/developer-apps) 关联的 [developer App](/zh/resources/fundamentals/developer-apps) 的凭证。所有 X API v1.1 端点都可以使用来自独立 App 或与 Project 关联的 App 的凭证。

<div id="request-parameters">
  ### 请求参数
</div>

以下标准 v1.1 请求参数曾接受两个查询参数（user&#95;id 或 screen&#95;name）。X API v2 的 DELETE 端点只接受数值型的帖子 ID，并且必须作为端点路径的一部分传入。

对于 POST 端点，额外的参数需要通过请求的 JSON 请求体传入。可在 [API 参考指南](/zh/x-api/posts/manage-tweets/introduction) 中了解可用的参数。

<div id="code-examples">
  ## 代码示例
</div>

<div id="create-a-post-v2">
  ### 创建帖子 (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/tweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"text": "Hello world!"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 创建帖子
  response = client.posts.create(text="Hello world!")
  print(f"Created Post: {response.data.id}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 创建帖子
  const response = await client.posts.create({ text: "Hello world!" });
  console.log(`Created Post: ${response.data?.id}`);
  ```
</CodeGroup>

<div id="delete-a-post-v2">
  ### 删除帖子（v2）
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/tweets/1234567890" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",

  client = Client(auth=oauth1)

  # 删除帖子
  response = client.posts.delete("1234567890")
  print(f"Deleted: {response.data.deleted}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";
  ```
