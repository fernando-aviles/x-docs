<div id="authentication">
  ### 认证
</div>

所有 X API v2 端点都要求你使用一组凭证（也称为 keys 和 tokens）来对请求进行认证。

这些特定端点需要使用 [OAuth 1.0a 用户上下文](/zh/resources/fundamentals/authentication)，这意味着你必须使用一组 API keys 和用户 Access Tokens 才能成功发起请求。Access Tokens 必须与你代表其发起请求的用户相关联。如果你想为另一位用户生成一组 Access Tokens，则该用户必须通过 [三方（3-legged）OAuth 流程](/zh/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow)来授权或认证你的 App。

请注意，OAuth 1.0a 的使用可能相对复杂。如果你不熟悉这种认证方式，我们建议你使用某个 [library](/zh/x-api/tools-and-libraries/overview)、使用类似 Postman 的工具，或使用 OAuth 2.0 来为你的请求进行认证。

[OAuth 2.0 Authorization Code with PKCE](/zh/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) 允许你对应用的 scope 进行更精细的控制，并支持跨多个设备的授权流程。OAuth 2.0 允许你选择特定的细粒度 scope，从而代表用户获取相应的特定权限。

要在你的 App 中启用 OAuth 2.0，你必须在 Developer Console 的 App settings 部分中，在该 App 的 authentication 设置里启用它。

<div id="developer-console-projects-and-developer-apps">
  ### Developer Console、Project 和开发者 App
</div>

要获取一组适用于 X API v2 端点的认证凭证，你必须拥有一个 [开发者账号]/resources/fundamentals/developer-portal)，在该账号下设置一个 [Project](/zh/resources/fundamentals/developer-apps)，并在该 Project 中创建一个 [开发者 App](/zh/resources/fundamentals/developer-apps)。然后，你可以在自己的开发者 App 中找到密钥和令牌。

<div id="rate-limits">
  ### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为了管理如此庞大的请求量，我们对每个 endpoint 都设置了[速率限制](https://developer.x.com/x-api/fundamentals/rate-limits)，以限制你代表你的应用或已认证用户所能发起的请求次数。

这些 endpoint 采用用户级速率限制，这意味着，你代表其发起请求的已认证用户，在任意开发者 App 中对该 endpoint 的调用次数都有上限。对于 POST 方法，用户的速率限制是每 15 分钟 200 次请求。对于 DELETE 方法，速率限制是每 15 分钟 50 次请求。此外，还存在[每 3 小时 300 次请求](https://blog.x.com/developer/en_us/topics/tools/2018/new-developer-requirements-to-protect-our-platform)的上限，其中包括通过 manage Posts 或 manage Retweets 权限创建的帖子。

<div id="source-labels">
  ### 来源标签
</div>

你的应用名称和网站 URL 会作为[来源标签](https://help.x.com/en/using-twitter/how-to-tweet#source-labels)显示在由你的应用程序以程序化方式创建的任何帖子元数据中。如果你更改了某个 X 应用的使用场景，请务必在这些设置中更新该使用场景，以确保符合[开发者条款](https://developer.x.com/content/developer-twitter/en/developer-terms/agreement-and-policy)的要求。

<div id="profile-settings">
  ### 个人资料设置
</div>

只有在你的个人资料设置中启用了地理位置功能（geo）时，才能为帖子添加位置。如果你没有启用地理位置，你仍然可以在请求体中添加位置参数，但该位置不会关联到你的帖子。对于在图片中标记用户也是同样的规则。如果你标记的用户没有启用照片标记功能，即使帖子已成功创建，他们的名称也不会出现在已标记用户列表中。

<div id="adding-media-to-a-post">
  ### 向帖子添加媒体
</div>

目前，还无法通过 X API v2 完成媒体上传。不过，你可以将之前已上传的媒体附加到帖子中。你可以使用已经通过 [v1 媒体端点上传](https://developer.x.com/en/docs/twitter-api/v1/media/upload-media/api-reference/post-media-upload) 或 [X Media Studio](https://media.x.com/en/articles/products/2018/media-studio) 上传的媒体 id。这些媒体 id 必须属于你自己，或属于当前已通过身份验证的用户。

<div id="create-a-post">
  ### 创建帖子
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/tweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"text": "Hello world!"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Create a Post
  response = client.posts.create(text="Hello world!")
  print(f"Created Post: {response.data.id}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Create a Post
  const response = await client.posts.create({ text: "Hello world!" });
  console.log(`Created Post: ${response.data?.id}`);
  ```
</CodeGroup>

</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/tweets" \

    -H "Content-Type: application/json" \
  ```

  ```python Python SDK
  from xdk import Client

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",

  client = Client(auth=oauth1)

  )

  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
  ```
