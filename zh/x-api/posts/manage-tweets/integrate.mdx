<div id="authentication">
  ### 认证
</div>

所有 X API v2 端点都要求你使用一组凭证来对请求进行身份验证，这些凭证也被称为密钥和令牌。

这些特定端点需要使用 [OAuth 1.0a 用户上下文](/zh/resources/fundamentals/authentication)，这意味着你必须使用一组 API 密钥和用户访问令牌（Access Token）才能成功发起请求。访问令牌必须与你代表其发起请求的用户关联。如果你想为另一位用户生成一组访问令牌，他们必须通过使用 [三方 OAuth 授权流程](/zh/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow)来授权或验证你的 App。

请注意，OAuth 1.0a 可能比较难用。如果你不熟悉这种身份验证方式，我们建议你使用一个[库](/zh/x-api/tools-and-libraries/overview)、使用 Postman 等工具，或者使用 OAuth 2.0 来对你的请求进行身份验证。

[带 PKCE 的 OAuth 2.0 授权码模式](/zh/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)可以在应用的权限范围以及跨多设备的授权流程上提供更强的控制能力。OAuth 2.0 允许你选择特定的细粒度 scope，从而代表用户获得对应的具体权限。

要在你的 App 中启用 OAuth 2.0，你必须在开发者控制台中该 App 设置部分的身份验证设置里将其启用。

<div id="developer-console-projects-and-developer-apps">
  ### 开发者控制台、Project 和开发者 App
</div>

要获取一组适用于 X API v2 端点的身份验证凭据，你必须先拥有一个 [开发者账号](/zh/resources/fundamentals/developer-portal)，在该账号下设置一个 [Project](/zh/resources/fundamentals/developer-apps)，并在该 Project 中创建一个 [开发者 App](/zh/resources/fundamentals/developer-apps)。然后，你可以在你的开发者 App 中找到相应的密钥和令牌。

<div id="rate-limits">
  ### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为了管理如此巨大的请求量，我们在每个端点上都设置了[速率限制](https://developer.x.com/x-api/fundamentals/rate-limits)，以限制你代表应用或已认证用户所能发起的请求数量。

这些端点在用户级别上受到速率限制，这意味着，你代表其发起请求的已认证用户，在任何开发者 App 上调用该端点的次数都有上限。对于 POST 方法，用户级速率限制为每 15 分钟最多 200 次请求。DELETE 方法的速率限制为每 15 分钟最多 50 次请求。此外，还有一个[每 3 小时 300 次请求](https://blog.x.com/developer/en_us/topics/tools/2018/new-developer-requirements-to-protect-our-platform)的上限，其中包括通过 manage Posts 或 manage Retweets 创建的帖子。

<div id="source-labels">
  ### 来源标签
</div>

你的 App 名称和网站 URL 会作为[来源标签](https://help.x.com/en/using-twitter/how-to-tweet#source-labels)显示在由你的应用以编程方式创建的任何帖子元数据中。如果你更改了某个 X App 的使用场景，请务必在这些设置中同步更新该使用场景，以确保你遵守[开发者条款](https://developer.x.com/content/developer-twitter/en/developer-terms/agreement-and-policy)。

<div id="profile-settings">
  ### 个人资料设置
</div>

只有在你的个人资料设置中启用了地理位置（geo）功能时，你才能在帖子中添加位置。如果你没有启用地理位置，你仍然可以在请求体中添加位置参数，但该位置不会与帖子关联。对在图片中标记用户也是如此。如果你标记的用户没有启用照片标记功能，即使帖子已成功创建，他们的用户名也不会显示在已标记用户列表中。

<div id="adding-media-to-a-post">
  ### 将媒体添加到帖子中
</div>

目前，还无法通过 X API v2 完整上传媒体。不过，你可以将之前已上传的媒体附加到帖子中。你可以使用已经通过 [v1 媒体端点上传](https://developer.x.com/en/docs/twitter-api/v1/media/upload-media/api-reference/post-media-upload) 或 [X Media Studio](https://media.x.com/en/articles/products/2018/media-studio) 上传的媒体 ID。这些媒体 ID 必须属于你自己或当前已认证用户。

<div id="create-a-post">
  ### 创建帖子
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/tweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"text": "Hello world!"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 创建帖子
  response = client.posts.create(text="Hello world!")
  print(f"Created Post: {response.data.id}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 创建帖子
  const response = await client.posts.create({ text: "Hello world!" });
  console.log(`Created Post: ${response.data?.id}`);
  ```
</CodeGroup>
