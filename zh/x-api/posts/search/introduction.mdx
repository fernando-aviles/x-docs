Search Posts 端点允许你使用强大的查询运算符，查找符合特定条件的帖子。你可以搜索关键词、话题标签、提及、URL 等内容。

<div id="overview">
  ## 概览
</div>

X 提供两个搜索端点，具有不同的时间范围和访问要求：

<CardGroup cols={2}>
  <Card title="最近搜索" icon="clock">
    搜索**最近 7 天**的帖子。对所有开发者开放。
  </Card>

  <Card title="全量归档搜索" icon="vault">
    搜索自 2006 年起的**完整归档**。向按次付费和企业客户开放。
  </Card>
</CardGroup>

***

<div id="use-cases">
  ## 使用场景
</div>

* **品牌监测** — 跟踪品牌或产品被提及的情况
* **趋势分析** — 分析围绕特定话题或事件的讨论
* **研究** — 为学术或市场研究收集数据
* **实时监听** — 构建能够对新帖子实时响应的应用程序

<div id="endpoints">

</div>

| Method | Endpoint | Description | Access |
|:-------|:---------|:------------|:-------|
| GET | [`/2/tweets/search/recent`](/zh/x-api/posts/search-recent-posts) | 搜索最近 7 天的帖子 | 所有开发者 |
| GET | [`/2/tweets/search/all`](/zh/x-api/posts/search-all-posts) | 搜索完整的帖子存档 | 按使用量计费，企业版 |

<div id="query-operators">
  ## 查询运算符
</div>

使用运算符根据帖子属性构建查询：

```
(AI OR "artificial intelligence") lang:en -is:retweet has:links
```

<AccordionGroup>
  <Accordion title="关键词运算符">
    | Operator | Example              | Description  |
    | :------- | :------------------- | :----------- |
    | Keyword  | `python`             | 匹配包含该单词的帖子   |
    | Phrase   | `"machine learning"` | 匹配完全相同的短语    |
    | Hashtag  | `#AI`                | 匹配带有该话题标签的帖子 |
    | Mention  | `@XDevelopers`       | 匹配提及该用户的帖子   |
  </Accordion>

  <Accordion title="用户运算符">
    | Operator       | Example          | Description |
    | :------------- | :--------------- | :---------- |
    | `from:`        | `from:elonmusk`  | 某用户发布的帖子    |
    | `to:`          | `to:XDevelopers` | 回复某个用户的帖子   |
    | `retweets_of:` | `retweets_of:X`  | 对某用户帖子所做的转发 |
  </Accordion>

  <Accordion title="内容运算符">
    | Operator       | Example          | Description  |
    | :------------- | :--------------- | :----------- |
    | `has:images`   | `cat has:images` | 带有图片的帖子      |
    | `has:videos`   | `has:videos`     | 带有视频的帖子      |
    | `has:links`    | `has:links`      | 带有链接的帖子      |
    | `has:mentions` | `has:mentions`   | 带有提及的帖子      |
    | `url:`         | `url:github.com` | 带有特定 URL 的帖子 |
  </Accordion>

  <Accordion title="过滤运算符">
    | Operator      | Example       | Description  |
    | :------------ | :------------ | :----------- |
    | `lang:`       | `lang:en`     | 使用特定语言的帖子    |
    | `-is:retweet` | `-is:retweet` | 排除转发         |
    | `-is:reply`   | `-is:reply`   | 排除回复         |
    | `is:verified` | `is:verified` | 已通过认证用户发布的帖子 |
  </Accordion>
</AccordionGroup>

<div id="recent-search">
  ## 最近搜索
</div>

搜索最近 7 天内的帖子。适用于所有开发者。

<div id="features">
  ### 功能
</div>

* 每个请求最多 100 条帖子
* 支持对大型结果集进行分页
* 支持所有核心查询运算符
* 查询字符串长度为 512 个字符（企业版为 4,096 个字符）

<div id="full-archive-search">
  ## 全量归档搜索
</div>

搜索自 2006 年 3 月以来的**完整帖子归档**。

<Note>
  全量归档搜索适用于按量计费和企业级客户。
</Note>

<div id="features">
  ### 功能
</div>

* 每次请求最多 500 条帖子
* 访问完整的帖子历史
* 支持所有查询运算符
* 查询长度为 1,024 个字符（Enterprise 版本为 4,096）
