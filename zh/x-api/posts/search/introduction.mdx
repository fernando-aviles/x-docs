Search Posts 端点允许你使用强大的查询运算符查找符合特定条件的帖子。支持按关键词、话题标签、提及、URL 等进行搜索。

<div id="overview">
  ## 概览
</div>

X 提供了两个搜索端点，它们具有不同的可用时间范围和访问权限要求：

<CardGroup cols={2}>
  <Card title="Recent Search" icon="clock">
    搜索**最近 7 天内发布的帖子**。对所有开发者开放。
  </Card>

  <Card title="Full-Archive Search" icon="vault">
    搜索自 2006 年以来的**完整存档**。对按使用量计费和企业客户开放。
  </Card>
</CardGroup>

***

<div id="use-cases">
  ## 使用场景
</div>

* **品牌监测** — 跟踪品牌或产品被提及的情况
* **趋势分析** — 分析围绕特定话题或事件的讨论
* **研究** — 为学术或市场研究收集数据
* **实时监听** — 构建能够对新帖子做出响应的应用程序

***

<div id="endpoints">
  ## 端点
</div>

| 方法 | 端点 | 描述 | 访问权限 |
|:-------|:---------|:------------|:-------|
| GET | [`/2/tweets/search/recent`](/zh/x-api/posts/search-recent-posts) | 搜索最近 7 天内的帖子 | 所有开发者 |
| GET | [`/2/tweets/search/all`](/zh/x-api/posts/search-all-posts) | 搜索完整的帖子存档 | 按使用量计费，企业版 |

<div id="query-operators">
  ## 查询运算符
</div>

使用可根据帖子属性进行匹配的运算符来构建查询：

```
(AI OR "artificial intelligence") lang:en -is:retweet has:links
```

<AccordionGroup>
  <Accordion title="关键词运算符">
    | Operator | Example              | Description  |
    | :------- | :------------------- | :----------- |
    | Keyword  | `python`             | 匹配包含该词的帖子    |
    | Phrase   | `"machine learning"` | 匹配完全相同的短语    |
    | Hashtag  | `#AI`                | 匹配带有该话题标签的帖子 |
    | Mention  | `@XDevelopers`       | 匹配提及该用户的帖子   |
  </Accordion>

  <Accordion title="用户运算符">
    | Operator       | Example          | Description  |
    | :------------- | :--------------- | :----------- |
    | `from:`        | `from:elonmusk`  | 某个用户发布的帖子    |
    | `to:`          | `to:XDevelopers` | 回复给某个用户的帖子   |
    | `retweets_of:` | `retweets_of:X`  | 某个用户帖子被转发的内容 |
  </Accordion>

  <Accordion title="内容运算符">
    | Operator       | Example          | Description  |
    | :------------- | :--------------- | :----------- |
    | `has:images`   | `cat has:images` | 包含图片的帖子      |
    | `has:videos`   | `has:videos`     | 包含视频的帖子      |
    | `has:links`    | `has:links`      | 包含链接的帖子      |
    | `has:mentions` | `has:mentions`   | 包含提及的帖子      |
    | `url:`         | `url:github.com` | 包含特定 URL 的帖子 |
  </Accordion>

  <Accordion title="过滤运算符">
    | Operator      | Example       | Description |
    | :------------ | :------------ | :---------- |
    | `lang:`       | `lang:en`     | 使用指定语言的帖子   |
    | `-is:retweet` | `-is:retweet` | 排除转发        |
    | `-is:reply`   | `-is:reply`   | 排除回复        |
    | `is:verified` | `is:verified` | 来自已认证用户的帖子  |
  </Accordion>
</AccordionGroup>

<div id="recent-search">
  ## 最近搜索
</div>

搜索**最近 7 天内**的帖子。对所有开发者开放。

<div id="features">
  ### 功能
</div>

* 每个请求最多 100 条帖子
* 针对大型结果集的分页
* 所有核心查询运算符
* 查询长度为 512 个字符（企业版为 4,096 个字符）

<div id="full-archive-search">
  ## 全量归档搜索
</div>

搜索自 2006 年 3 月以来的**全部帖子存档**。

<Note>
  全量归档搜索对按次计费和企业客户开放。
</Note>

<div id="features">
  ### 功能
</div>

* 每次请求最多 500 条帖子
* 访问完整的帖子历史记录
* 可使用所有查询运算符
* 查询长度为 1,024 个字符（企业版为 4,096 个字符）
