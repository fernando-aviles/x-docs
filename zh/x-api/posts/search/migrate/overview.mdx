<div id="comparing-x-apis-search-posts-endpoints">
  ## X API 搜索帖子端点对比
</div>

v2 Search Tweets 端点最终会取代 [标准 v1.1 search/posts](/zh/x-api/posts/search/introduction) 端点和 [enterprise Search API](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api)。如果你在代码、应用或工具中使用的是旧版 X 搜索端点，并且正在考虑迁移到更新的 X API v2 端点，那么本指南适合你。

***

<div id="recent-search-comparison">
  ## 最近搜索比较
</div>

下表比较了各种类型的最近搜索端点：

| **说明** | **Standard v1.1** | **X API v2** |
| :--- | :--- | :--- |
| 主机域名 | https://api.x.com | https://api.x.com |
| 端点路径 | /1.1/search/tweets.json | /2/tweets/search/recent |
| [Authentication](/zh/resources/fundamentals/authentication) | OAuth 1.0a 用户上下文  <br />OAuth 2.0 仅限 App | OAuth 1.0a 用户上下文<br /><br />OAuth 2.0 授权码模式（带 PKCE）<br /><br />OAuth 2.0 仅限 App |
| 时间戳格式 | YYYYMMDD | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |
| 返回的帖子距今不超过 | 7 天 | 7 天 |
| 支持的 HTTP 方法 | GET | GET |
| 默认请求速率限制 | 使用 OAuth 1.0a 用户上下文时每 15 分钟 180 个请求<br /><br />使用 OAuth 2.0 仅限 App 时每 15 分钟 450 个请求 | **自助：**<br /><br />使用 OAuth 2.0 仅限 App 时每 15 分钟 60 个请求<br /><br />使用 OAuth 1.0a 用户上下文时每 15 分钟 60 个请求<br /><br />使用 OAuth 2.0 授权码模式（带 PKCE）时每 15 分钟 60 个请求 |
| 提供完全展开的 URL |     | ✔   |
| 每个响应中的最大帖子数（默认） | 100 (15) | 100 (10) |
| 帖子 JSON 格式 | Standard v1.1 格式 | [X API v2 格式](/zh/x-api/fundamentals/data-dictionary)（由 fields 和 expansions 请求参数决定，与 v1.1 格式不向后兼容）<br /><br />要详细了解如何从 Standard v1.1 格式迁移到 X API v2 格式，请访问我们的[数据格式迁移指南](/zh/x-api/migrate/data-format-migration)。 |
| 支持选择在有效负载中返回哪些[字段](/zh/x-api/fundamentals/fields) |     | ✔   |
| 支持请求和接收[注解](/zh/x-api/fundamentals/post-annotations) |     | ✔   |
| 支持在帖子对象中请求特定的[指标](/zh/x-api/fundamentals/metrics) |     | ✔   |
| 支持 [conversation&#95;id](/zh/x-api/fundamentals/conversation-id) 运算符和字段 |     | ✔   |
| 提供帖子编辑历史 | ✔   | ✔   |
| 帖子 data 数组的 JSON 键名 | statuses | data |
| 分页的 JSON 键名 | search&#95;metadata.next&#95;results | meta.next&#95;token |
| 支持按时间范围浏览存档 | ✔   | ✔   |
| 基于时间请求的时间分辨率 | 天 | 秒 |
| 时区 | UTC | UTC |
| 按时间浏览的请求参数 | until | start&#95;time  <br />end&#95;time |
| 按帖子 ID 浏览的请求参数 | since&#95;id   <br />max&#95;id | since&#95;id   <br />until&#95;id |
| 用于分页的请求参数 | 提供 URL 编码的查询字符串 | next&#95;token |
| 需要使用与某个 [Project](/zh/resources/fundamentals/developer-apps) 关联的 [开发者 App](/zh/resources/fundamentals/developer-apps) 的凭证 |     | ✔   |

**过滤运算符比较**

搜索帖子有四种不同版本（standard、enterprise 和 v2），它们在可用运算符方面有所不同，并且每个版本内部的运算符可用级别也不一样，具体如下所述。

Enterprise

* 不存在 enterprise 运算符的子级别

X API v2

* **Self-serve：** 使用任意 Project 时可用
* **Enterprise：** 使用 Project 时可用

您可以在各自的指南中进一步了解这些运算符集：

* [Enterprise 运算符](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [X API v2 运算符](/zh/x-api/posts/search/integrate/build-a-query#operators)
