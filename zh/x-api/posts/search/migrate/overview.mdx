<div id="comparing-x-apis-search-posts-endpoints">
  ## 对比 X API 的搜索帖子端点
</div>

v2 Search Tweets 端点最终会替代 [标准版 v1.1 search/posts](/zh/x-api/posts/search/introduction) 端点和 [企业版 Search API](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api)。如果你现有的代码、App 或工具使用的是旧版 X 搜索端点，并且正在考虑迁移到较新的 X API v2 端点，那么本指南适合你。

***

<div id="recent-search-comparison">
  ## 最近搜索对比
</div>

下表比较了不同类型的最近搜索端点：

| **说明** | **Standard v1.1** | **X API v2** |
| :--- | :--- | :--- |

| 提供完全解开的 URL |     | ✔   |

**过滤运算符对比**

搜索帖子功能有四种不同版本（standard、enterprise 和 v2），它们在可用运算符方面有所不同，并且每个版本内部也存在不同级别的运算符可用性，下面将对其进行说明。

Enterprise

* 不存在 enterprise 运算符的子级别划分

X API v2

* **Self-serve：** 使用任何 Project 时可用
* **Enterprise：** 使用 Project 时可用

你可以在各自的指南中了解更多关于这些运算符集合的信息：

* [Enterprise operators](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [X API v2 operators](/zh/x-api/posts/search/integrate/build-a-query#operators)
