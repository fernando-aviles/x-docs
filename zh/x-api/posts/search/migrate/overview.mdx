<div id="comparing-x-apis-search-posts-endpoints">
  ## 比较 X API 的搜索帖子端点
</div>

v2 Search Tweets 端点最终将取代 [标准版 v1.1 search/posts](/zh/x-api/posts/search/introduction) 端点和 [企业版 Search API](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api)。如果你有使用旧版 X 搜索端点的代码、应用或工具，并且正在考虑迁移到新版 X API v2 端点，那么本指南适合你。

***

<div id="recent-search-comparison">
  ## 近期搜索对比
</div>

下表比较了各种类型的近期搜索端点：

| **Description** | **Standard v1.1** | **X API v2** |
| :--- | :--- | :--- |
| Host domain | https://api.x.com | https://api.x.com |
| Endpoint path | /1.1/search/tweets.json | /2/tweets/search/recent |
| [Authentication](/zh/resources/fundamentals/authentication) | OAuth 1.0a 用户上下文  <br />OAuth 2.0 仅限 App | OAuth 1.0a 用户上下文<br /><br />OAuth 2.0 授权码（带 PKCE）<br /><br />OAuth 2.0 仅限 App |
| Timestamp format | YYYYMMDD | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |
| Returns Posts that are no older than | 返回不早于 7 天前的帖子 | 返回不早于 7 天前的帖子 |
| HTTP methods supported | GET | GET |
| Default request rate limits | 使用 OAuth 1.0a 用户上下文时，每 15 分钟 180 个请求<br /><br />使用 OAuth 2.0 仅限 App 时，每 15 分钟 450 个请求 | **自助：**<br /><br />使用 OAuth 2.0 仅限 App 时，每 15 分钟 60 个请求<br /><br />使用 OAuth 1.0a 用户上下文时，每 15 分钟 60 个请求<br /><br />使用 OAuth 2.0 授权码（带 PKCE）时，每 15 分钟 60 个请求 |
| Offers fully unwound URLs |     | ✔   |
| Maximum Posts per response (default) | 每个响应的最大帖子数（默认）为 100（15） | 每个响应的最大帖子数（默认）为 100（10） |
| Post JSON format | Standard v1.1 格式 | [X API v2 格式](/zh/x-api/fundamentals/data-dictionary)（由 fields 和 expansions 请求参数决定，与 v1.1 格式不向后兼容）<br /><br />要了解如何从 Standard v1.1 格式迁移到 X API v2 格式，请参阅我们的[数据格式迁移指南](/zh/x-api/migrate/data-format-migration)。 |
| Supports selecting which [fields](/zh/x-api/fundamentals/fields) return in the payload |     | ✔   |
| Supports requesting and receiving [annotations](/zh/x-api/fundamentals/post-annotations) |     | ✔   |
| Supports requesting specific [metrics](/zh/x-api/fundamentals/metrics) within Post object |     | ✔   |
| Supports the [conversation&#95;id](/zh/x-api/fundamentals/conversation-id) operator and field |     | ✔   |
| Provides Post edit history | ✔   | ✔   |
| JSON key name for Post data array | statuses | data |
| JSON key name for pagination | search&#95;metadata.next&#95;results | meta.next&#95;token |
| Supports navigating archive by time range | ✔   | ✔   |
| Time resolution of time-based requests | 基于时间请求的时间粒度为天 | 基于时间请求的时间粒度为秒 |
| Timezone | UTC | UTC |
| Request parameters for navigating by time | 用于按时间导航的请求参数为 until | 用于按时间导航的请求参数为 start&#95;time  <br />end&#95;time |
| Request parameters for navigating by Post ID | 用于按帖子 ID 导航的请求参数为 since&#95;id   <br />max&#95;id | 用于按帖子 ID 导航的请求参数为 since&#95;id   <br />until&#95;id |
| Request parameter for pagination | 用于分页的请求参数为提供 URL 编码的查询字符串 | 用于分页的请求参数为 next&#95;token |
| Requires the use of credentials from a [developer App](/zh/resources/fundamentals/developer-apps) associated with a [Project](/zh/resources/fundamentals/developer-apps) |     | ✔   |

**过滤运算符比较**

帖子搜索的四个不同版本（standard、enterprise 和 v2）在可用运算符方面有所不同，并且每个版本内部的运算符可用性级别也不同，具体说明如下。

Enterprise

* enterprise 运算符没有子层级划分

X API v2

* **Self-serve：** 使用任何 Project 时可用
* **Enterprise：** 使用 Project 时可用

您可以在各自的指南中进一步了解这些运算符集合：

* [Enterprise 运算符](/zh/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [X API v2 运算符](/zh/x-api/posts/search/integrate/build-a-query#operators)
