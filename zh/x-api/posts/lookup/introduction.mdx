帖子查询端点允许你通过帖子 ID 检索一个或多个帖子。使用这些端点可获取最新的帖子详细信息、检查帖子是否可用，或查看编辑历史。

<div id="overview">
  ## 概览
</div>

帖子是 X 上的核心内容。每条帖子可以包含：

* 最多 280 个字符的文本
* 附带媒体（图片、视频、GIF）
* 投票、地点和 URL
* 回复、引用和提及

帖子在创建后的 30 分钟内最多可以编辑 5 次。每次编辑都会生成一个新的帖子 ID，并保留完整的编辑历史。

<div id="use-cases">
  ## 使用场景
</div>

* **显示帖子内容** — 在你的应用程序中展示帖子详情
* **验证可用性** — 检查帖子是否仍然存在或已被删除
* **合规管理** — 跟踪帖子的变更以满足合规要求
* **分析** — 获取特定帖子的互动指标数据

<div id="endpoints">
  ## 端点
</div>

| 方法 | 端点 | 说明 |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id`](/zh/x-api/posts/get-post-by-id) | 通过 ID 获取单个帖子 |
| GET | [`/2/tweets`](/zh/x-api/posts/get-posts-by-ids) | 通过多个 ID 获取帖子（最多 100 条） |
