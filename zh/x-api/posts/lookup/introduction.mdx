帖子查询端点允许你通过帖子 ID 检索一条或多条帖子。使用这些端点可以获取最新的帖子详情、验证帖子是否可用，或查看编辑历史记录。

<div id="overview">
  ## 概览
</div>

帖子是 X 上的核心内容。每条帖子可以包含：

* 最多 280 个字符的文本
* 媒体附件（图片、视频、GIF）
* 投票、地点和 URL
* 回复、引用和提及

帖子在创建后的 30 分钟内最多可编辑 5 次。每次编辑都会生成一个新的帖子 ID，并保留完整的编辑历史记录。

<div id="use-cases">
  ## 使用场景
</div>

* **展示帖子内容** — 在你的应用中显示帖子的详细信息
* **验证可用性** — 检查某条帖子是否仍然存在或已被删除
* **合规管理** — 跟踪帖子变更以满足合规事件要求
* **分析** — 获取特定帖子的互动指标
