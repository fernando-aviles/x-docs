Communities 查询端点可让你通过 ID 检索 X Communities 社区的信息。

<div id="overview">
  ## 概览
</div>

Community 是 X 上的公开或私密社区/群组，成员可以在其中分享帖子、讨论话题，并围绕共同兴趣进行交流。

<CardGroup cols={2}>
  <Card title="按 ID" icon="users-rectangle">
    获取指定 Community 的详细信息
  </Card>

  <Card title="搜索" icon="magnifying-glass">
    按关键词搜索 Community
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/communities/:id`](/zh/x-api/communities/get-community-by-id) | 按 ID 获取社区 |

***

<div id="response-fields">
  ## 响应字段
</div>

| 字段 | 描述 |
|:------|:------------|
| `id` | 社区 ID |
| `name` | 社区名称 |
| `description` | 社区描述 |
| `created_at` | 创建日期 |
| `member_count` | 成员数量 |
| `is_private` | 社区是否为私密 |

***

<div id="example-request">
  ## 示例请求
</div>

```bash
curl "https://api.x.com/2/communities/1234567890?\
community.fields=name,description,member_count,created_at" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
