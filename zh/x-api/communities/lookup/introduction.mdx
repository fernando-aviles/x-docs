Communities 查找端点可让你根据 id 检索 X 社群的信息。

<div id="overview">
  ## 概览
</div>

Community 是 X 上的公开或私密社群，成员可以在其中分享帖子、讨论话题，并围绕共同兴趣进行交流。

***

<div id="endpoint">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/communities/:id`](/zh/x-api/communities/get-community-by-id) | 根据 ID 获取社群 |

***

<div id="response-fields">
  ## 响应字段
</div>

| 字段 | 描述 |
|:------|:------------|
| `id` | 社区 ID |
| `name` | 社区名称 |
| `description` | 社区描述 |
| `created_at` | 创建时间 |
| `member_count` | 成员数量 |
| `is_private` | 社区是否为私密 |
--------------------------

<div id="getting-started">
  ## 示例请求
</div>

```bash
curl "https://api.x.com/2/communities/1234567890?\
community.fields=name,description,member_count,created_at" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
