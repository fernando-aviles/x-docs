Communities 搜索端点允许你根据关键字搜索 Communities。发现围绕你感兴趣主题的 Communities。

  ## 概览

<div id="endpoint">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/communities/search`](/zh/x-api/communities/search-communities) | 搜索社区 |

***

<div id="parameters">
  ## 参数
</div>

| 参数名 | 描述 |
|:----------|:------------|
| `query` | 搜索查询条件（必需） |
| `max_results` | 每页返回的结果数（最大为 100） |
| `community.fields` | 附加的 Community 字段 |

***

<div id="example-request">
  ## 示例请求
</div>

```bash
curl "https://api.x.com/2/communities/search?\
query=Python&\
max_results=10&\
community.fields=name,description,member_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
