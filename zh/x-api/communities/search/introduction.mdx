`Communities Search` 端点允许你通过关键词搜索 `Communities`。发现与你兴趣相关的话题 `Communities`。

<div id="overview">
  ## 概览
</div>

<CardGroup cols={2}>
  <Card title="关键词搜索" icon="magnifying-glass">
    按名称和描述搜索社区
  </Card>

  <Card title="发现" icon="users-rectangle">
    查找可加入的社区
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/communities/search`](/zh/x-api/communities/search-communities) | 搜索社区 |

***

<div id="parameters">
  ## 参数
</div>

| 参数 | 说明 |
|:----------|:------------|
| `query` | 搜索查询（必需） |
| `max_results` | 每页结果数（最多 100） |
| `community.fields` | 附加的 Community 字段 |

***

<div id="example-request">
  ## 示例请求
</div>

```bash
curl "https://api.x.com/2/communities/search?\
query=Python&\
max_results=10&\
community.fields=name,description,member_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
