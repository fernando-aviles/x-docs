Usage 端点可让你监控 API 使用情况，包括已使用的帖子数量。以编程方式跟踪你的使用量，从而管理成本并保持在配额范围内。

<div id="endpoint">
  ## Endpoint
</div>

| 方法 | Endpoint | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/usage/tweets`](/zh/x-api/usage/get-usage) | 获取帖子使用情况数据 |

***

<div id="response-data">
  ## 响应数据
</div>

该响应包含按天统计的帖子消费计数：

```json
{
  "data": {
    "daily_project_usage": [
      {
        "date": "2024-01-15",
        "usage": [
          {
            "app_id": "12345678",
            "tweets_consumed": 15420
          }
        ]
      }
    ],
    "project_id": "1234567890",
    "project_cap": 10000000
  }
}
```

<div id="fields">
  ### 字段
</div>

| 字段 | 描述 |
|:------|:------------|
| `daily_project_usage` | 按日统计的使用数据数组 |
| `date` | YYYY-MM-DD 格式的日期 |
| `app_id` | 应用的 id |
| `tweets_consumed` | 当天消耗的帖子数量 |
| `project_cap` | 每月帖子配额上限 |

***

<div id="example-request">
  ## 请求示例
</div>

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

***

<div id="use-cases">
  ## 使用场景
</div>

* **成本监控** — 跟踪与你套餐限额对应的使用量
* **告警** — 在接近限额时设置告警
* **优化** — 识别高消耗的 API 端点
* **报告** — 生成使用情况报告

<Tip>
  资源会在 24 小时的 UTC 窗口内进行去重，因此在同一窗口内多次请求相同资源只计为一次收费。[了解更多定价信息 →](/zh/x-api/getting-started/pricing)
</Tip>
