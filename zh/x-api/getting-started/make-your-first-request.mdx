本指南将指导你发出第一个 X API 请求。开始之前，你需要先拥有一个[包含应用凭证的开发者账号](/zh/x-api/getting-started/getting-access)。

***

<div id="quick-start-with-curl">
  ## 使用 cURL 快速开始
</div>

测试 API 的最快方式是使用 cURL。让我们来查找一个用户：

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

将 `$BEARER_TOKEN` 替换为你的 Bearer Token 实际值。你会收到类似这样的响应：

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers"
  }
}
```

***

<div id="step-by-step-guide">
  ## 分步指南
</div>

<Steps>
  <Step title="获取 Bearer Token">
    在 [Developer Console](https://console.x.com) 中进入你的应用页面，并复制 Bearer Token。
  </Step>

  <Step title="选择一个端点">
    从以下这些适合入门的 endpoint 开始：

    | Endpoint | 功能说明 |
    |:---------|:-------------|
    | [User lookup](/zh/x-api/users/lookup/introduction) | 通过用户名或 ID 获取用户资料 |
    | [Post lookup](/zh/x-api/posts/lookup/introduction) | 通过 ID 获取帖子 |
    | [Recent search](/zh/x-api/posts/search/introduction) | 搜索最近 7 天内的帖子 |
  </Step>

  <Step title="发起请求">
    使用 cURL、Postman 或你常用的 HTTP 客户端：

    ```bash
    # 通过用户名查找用户
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>

  <Step title="解析响应">
    响应是 JSON 格式。主要数据位于 `data` 字段中：

    ```json
    {
      "data": {
        "id": "2244994945",
        "name": "X Developers",
        "username": "xdevelopers"
      }
    }
    ```
  </Step>
</Steps>

***

<div id="request-more-data-with-fields">
  ## 使用字段请求更多数据
</div>

默认情况下，端点只返回最基本的字段。使用 `fields` 参数来请求更多数据：

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers?user.fields=created_at,description,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

响应：

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "X 开发者平台的声音",
    "public_metrics": {
      "followers_count": 570842,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```

<div id="using-code-instead-of-curl">
  ## 使用代码而非 cURL
</div>

<Tabs>
  <Tab title="Python">
    ```python
    import requests

    bearer_token = "YOUR_BEARER_TOKEN"
    url = "https://api.x.com/2/users/by/username/xdevelopers"

    headers = {"Authorization": f"Bearer {bearer_token}"}
    response = requests.get(url, headers=headers)

    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    ```javascript
    const bearerToken = "YOUR_BEARER_TOKEN";
    const url = "https://api.x.com/2/users/by/username/xdevelopers";

    fetch(url, {
      headers: { Authorization: `Bearer ${bearerToken}` }
    })
      .then(res => res.json())
      .then(data => console.log(data));
    ```
  </Tab>

  <Tab title="官方 SDKs">
    在生产环境中，我们建议使用官方 SDK：

    * [Python SDK](/zh/xdks/python/overview)
    * [TypeScript SDK](/zh/xdks/typescript/overview)

    它们会自动处理身份验证、分页和速率限制。
  </Tab>
</Tabs>

<div id="troubleshooting">
  ## 故障排查
</div>

<Accordion title="401 未授权">
  * 检查你的 Bearer Token 是否正确
  * 确保该令牌没有被重新生成或轮换
  * 核对 `Authorization` 请求头的格式：`Bearer YOUR_TOKEN`
</Accordion>

<Accordion title="403 禁止访问">
  * 你的应用可能无权访问此端点
  * 某些端点需要用户上下文身份验证（OAuth 1.0a 或 2.0）
  * 在 Developer Console 中检查你的应用权限
</Accordion>

<Accordion title="429 请求过多">
  * 你已达到速率限制
  * 检查 `x-rate-limit-reset` 响应头以了解何时重试
  * 在代码中实现指数退避机制
</Accordion>
