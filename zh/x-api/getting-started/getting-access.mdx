通过三个步骤即可开始使用 X API：注册、创建 App，并保存你的凭证。

<Button href="https://console.x.com">立即注册</Button>

***

<div id="step-1-create-a-developer-account">
  ## 步骤 1：创建开发者账号
</div>

<Steps>
  <Step title="前往开发者控制台">
    访问 [console.x.com](https://console.x.com) 并使用你的 X 账号登录。
  </Step>

  <Step title="接受开发者协议">
    阅读并接受开发者协议与政策。
  </Step>

  <Step title="完善你的个人资料">
    提供一些关于你计划如何使用 API 的基本信息。
  </Step>
</Steps>

***

<div id="step-2-create-an-app">
  ## 步骤 2：创建一个 App
</div>

注册完成后，创建一个 App 以获取你的 API 凭证：

<Steps>
  <Step title="点击 'New App'">
    在开发者控制台的仪表板中创建一个新的 App。
  </Step>

  <Step title="输入 App 详细信息">
    为你的 App 提供名称、描述和用例。
  </Step>

  <Step title="生成凭证">
    开发者控制台会为你生成 API 密钥和令牌。
  </Step>
</Steps>

***

<div id="step-3-save-your-credentials">
  ## 步骤 3：保存你的凭证
</div>

根据你的认证需求，你会收到若干不同的凭证：

| 凭证 | 用途 |
|:-----------|:--------|
| **API Key 和 Secret** | 标识你的 App。用于生成令牌并签署 OAuth 1.0a 请求。 |
| **Bearer 令牌** | 仅 App 级认证，用于读取公开数据。 |
| **Access Token 和 Secret** | 代表你自己的账号发起请求（OAuth 1.0a）。 |
| **Client ID 和 Secret** | 用于用户上下文请求的 OAuth 2.0 认证。 |

<Warning>
  **请立即保存。** 凭证只会显示一次。请将它们存储在密码管理器或安全密钥库中。如果丢失，你需要重新生成（这会使旧凭证失效）。
</Warning>

***

<div id="which-credentials-do-you-need">
  ## 你需要哪些凭证？
</div>

<Tabs>
  <Tab title="读取公共数据">
    对于简单的、只读访问公共数据的场景，请使用 **Bearer 令牌**。

    ```bash
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```

    最适用于：搜索帖子、查询用户、读取趋势数据。
  </Tab>

  <Tab title="以用户身份操作">
    若要代表用户执行操作，请使用 **OAuth 2.0**（推荐）或 **OAuth 1.0a**。

    OAuth 2.0 提供细粒度的权限范围，只请求你所需的权限。

    最适用于：发帖、点赞、关注、访问私信（DM）。

    [OAuth 2.0 指南 →](/zh/resources/fundamentals/authentication/oauth-2-0/overview)
  </Tab>

  <Tab title="以你自己的身份操作">
    使用你的 **Access Token &amp; Secret** 以你自己的账号发起请求。

    这些 token 代表的是拥有该 App 的账号。

    最适用于：测试、个人机器人、自用自动化任务。
  </Tab>
</Tabs>

<div id="credential-security-best-practices">
  ## 凭证安全最佳实践
</div>

<CardGroup cols={2}>
  <Card title="使用环境变量" icon="terminal">
    切勿在源代码中硬编码凭证。
  </Card>

  <Card title="不要提交到 Git" icon="code-branch">
    将凭证文件添加到 `.gitignore` 中。
  </Card>

  <Card title="定期轮换" icon="arrows-rotate">
    定期重新生成凭证，作为一项安全措施。
  </Card>

  <Card title="使用最小必要权限" icon="shield-check">
    只请求你的 App 所需的 OAuth 权限。
  </Card>
</CardGroup>
