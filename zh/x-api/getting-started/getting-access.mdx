开始使用 X API 只需三步：注册、创建应用并保存凭证。

<Button href="https://console.x.com">立即注册</Button>

***

<div id="step-1-create-a-developer-account">
  ## 步骤 1：创建开发者账号
</div>

<Steps>
  <Step title="前往开发者控制台">
    访问 [console.x.com](https://console.x.com)，并使用你的 X 账号登录。
  </Step>

  <Step title="接受开发者协议">
    阅读并接受开发者协议和政策。
  </Step>

  <Step title="完善个人资料">
    提供关于你将如何使用该 API 的基本信息。
  </Step>
</Steps>

***

<div id="step-2-create-an-app">
  ## 步骤 2：创建应用
</div>

注册完成后，创建一个应用以获取你的 API 凭证：

<Steps>
  <Step title="点击 “New App”">
    在开发者控制台的仪表板中创建一个新应用。
  </Step>

  <Step title="输入应用详细信息">
    为你的应用填写名称、描述和使用场景。
  </Step>

  <Step title="生成凭证">
    控制台会为你生成 API 密钥和访问令牌。
  </Step>
</Steps>

***

<div id="step-3-save-your-credentials">
  ## 步骤 3：保存你的凭证
</div>

你将根据所需的身份验证方式获得多种凭证：

| Credential | Purpose |
|:-----------|:--------|
| **API Key &amp; Secret** | 用于标识你的应用。用于生成令牌并为 OAuth 1.0a 请求签名。 |
| **Bearer Token** | 仅应用级认证，用于读取公开数据。 |
| **Access Token &amp; Secret** | 代表你自己的账号发起请求（OAuth 1.0a）。 |
| **Client ID &amp; Secret** | 用于 OAuth 2.0 用户上下文请求的认证。 |

<Warning>
  **请立即保存。** 凭证只会显示一次。将它们存储在密码管理器或安全金库中。如果丢失，你需要重新生成（这会使旧凭证失效）。
</Warning>

***

<div id="which-credentials-do-you-need">
  ## 你需要哪些凭证？
</div>

<Tabs>
  <Tab title="读取公开数据">
    使用 **Bearer Token** 即可对公开数据进行简单的只读访问。

    ```bash
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```

    最适合用于：搜索帖子、查找用户、查看趋势。
  </Tab>

  <Tab title="以用户身份操作">
    使用 **OAuth 2.0**（推荐）或 **OAuth 1.0a** 代表用户执行操作。

    OAuth 2.0 提供细粒度的权限范围（scope）——只请求你所需的权限。

    最适合用于：发帖、点赞、关注、访问私信（DM）。

    [OAuth 2.0 指南 →](/zh/resources/fundamentals/authentication/oauth-2-0/overview)
  </Tab>

  <Tab title="以你自己的身份操作">
    使用你的 **Access Token &amp; Secret** 以你自己的账号发起请求。

    这些令牌代表的是拥有该应用的账号。

    最适合用于：测试、个人机器人、自用自动化。
  </Tab>
</Tabs>

<div id="credential-security-best-practices">
  ## 凭证安全最佳实践
</div>

<CardGroup cols={2}>
  <Card title="使用环境变量" icon="terminal">
    切勿在源代码中硬编码凭证。
  </Card>

  <Card title="不要提交到 Git 仓库" icon="code-branch">
    将凭证文件添加到 `.gitignore` 中。
  </Card>

  <Card title="定期轮换" icon="arrows-rotate">
    定期重新生成凭证，作为安全防护措施。
  </Card>

  <Card title="使用最小必要的权限范围" icon="shield-check">
    只请求你的应用所需的 OAuth 权限。
  </Card>
</CardGroup>
