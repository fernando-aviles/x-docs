X API 让你可以以编程方式访问 X 上的公开对话。你可以检索帖子、分析趋势、构建集成应用，并在平台之上打造全新的体验。

***

<div id="what-you-can-do">
  ## 你可以做什么
</div>

| 功能 | 说明 |
|:-----------|:------------|
| **读取帖子** | 实时搜索、检索和流式获取帖子 |
| **发布内容** | 创建帖子、回复和帖子串 |
| **管理用户** | 查询用户，管理关注、屏蔽和静音 |
| **分析数据** | 访问指标、趋势和互动数据分析 |
| **构建集成** | 发送私信、管理列表，并与 Spaces 交互 |

***

<div id="api-versions">
  ## API 版本
</div>

<Tabs>
  <Tab title="X API v2（推荐）">
    当前版本的 X API，提供现代化功能和灵活定价。

    **为什么选择 v2：**

    * 按使用量计费——无月度上限
    * 现代化的 JSON 响应格式
    * 灵活的 [fields](/zh/x-api/fundamentals/fields) 和 [expansions](/zh/x-api/fundamentals/expansions)
    * 高级功能：标注、会话追踪、编辑历史
    * 所有最新端点和功能

    **快速开始：**

    1. 在 [console.x.com](https://console.x.com) 注册
    2. 创建一个 App 并获取凭证
    3. [发送你的第一个请求](/zh/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1（旧版）">
    上一代 X API 版本，仅提供有限支持；新项目请使用 v2。

    **仍然可用的内容：**

    * 部分媒体上传端点
    * 旧版流式接口（已弃用）
    * 部分专用端点

    **迁移到 v2：**
    有关端点映射和数据格式变更，请参见[迁移指南](/zh/x-api/migrate/overview)。
  </Tab>

  <Tab title="企业版">
    为具有高级需求的企业提供大规模访问能力。

    **功能：**

    * 完整 firehose 数据流访问
    * 历史数据回填
    * 专属支持
    * 自定义速率限制
    * 合规数据流

    [联系企业销售 →](/zh/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

<div id="v2-highlights">
  ## v2 亮点
</div>

<Accordion title="字段和 expansions">
  只请求你需要的数据。使用 `fields` 参数选择特定属性，使用 `expansions` 来包含关联对象。

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [详细了解字段 →](/zh/x-api/fundamentals/fields)
</Accordion>

<Accordion title="帖子标注">
  帖子包含语义标注，用于标识人物、地点、产品和主题。可以按主题过滤流和搜索结果。

  [详细了解标注 →](/zh/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="互动指标">
  获取公开指标（点赞、转发、回复）以及你自己帖子对应的私有指标（展示次数、点击量）。

  [详细了解指标 →](/zh/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="会话追踪">
  使用 `conversation_id` 重建完整会话线程，跟踪整个线程中的所有回复。

  [详细了解会话追踪 →](/zh/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="编辑历史">
  访问帖子的编辑历史，包括所有先前版本和编辑元数据。

  [详细了解编辑帖子 →](/zh/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## 价格
</div>

X API v2 采用**按使用量计费**模式：

| 优势 | 说明 |
|:--------|:------------|
| **无需订阅** | 只为实际使用付费 |
| **无用量上限** | 按需无限使用 |
| **基于额度** | 购买额度，每个请求会扣减相应额度 |
| **实时跟踪** | 在开发者控制台中实时监控用量 |
| **去重计费** | 同一资源在 24 小时内重复请求只计费一次 |

[查看定价详情 →](/zh/x-api/getting-started/pricing)
