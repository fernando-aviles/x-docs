X API 提供对 X 上公开对话的程序化访问能力。你可以检索帖子、分析趋势、构建集成方案，并在平台上创造全新的体验。

***

<div id="what-you-can-do">
  ## 你可以实现的功能
</div>

| 功能 | 说明 |
|:-----------|:------------|
| **阅读帖子** | 实时搜索、查询和流式获取帖子 |
| **发布内容** | 创建帖子、回复和帖子串 |
| **管理用户** | 查询用户，管理关注、屏蔽和静音 |
| **分析数据** | 获取指标、趋势和互动分析 |
| **构建集成** | 发送私信、管理列表并与 Spaces 交互 |

***

<div id="api-versions">
  ## API 版本
</div>

<Tabs>
  <Tab title="X API v2（推荐）">
    当前版本的 X API，具备现代化特性和灵活的定价模式。

    **为什么使用 v2：**

    * 按使用量计费——无月度上限
    * 现代化的 JSON 响应格式
    * 灵活的 [字段](/zh/x-api/fundamentals/fields) 和 [扩展](/zh/x-api/fundamentals/expansions)
    * 高级功能：注释、会话跟踪、编辑历史
    * 所有新增端点和功能

    **快速开始：**

    1. 在 [console.x.com](https://console.x.com) 注册
    2. 创建应用并获取凭证信息
    3. [发送首个请求](/zh/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1（旧版）">
    上一版本的 X API。仅提供有限支持；新项目请使用 v2。

    **仍可用的功能：**

    * 部分媒体上传端点
    * 旧版流式接口（已弃用）
    * 部分专用端点

    **迁移到 v2：**
    请参阅[迁移指南](/zh/x-api/migrate/overview)，了解端点映射和数据格式更改。
  </Tab>

  <Tab title="企业版">
    为具有高级需求的企业提供的大批量访问方案。

    **功能：**

    * 完整 Firehose（全量数据流）访问
    * 历史数据回填
    * 专属支持
    * 自定义速率限制
    * 合规数据流

    [联系企业销售 →](/zh/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

<div id="v2-highlights">
  ## v2 亮点
</div>

<Accordion title="字段和扩展">
  只请求你所需的数据。使用 `fields` 参数选择特定属性，使用 `expansions` 包含关联对象。

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [进一步了解字段 →](/zh/x-api/fundamentals/fields)
</Accordion>

<Accordion title="帖子标注">
  帖子包含语义标注，用于标识人物、地点、产品和主题。可以按主题过滤流和搜索结果。

  [进一步了解标注 →](/zh/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="互动指标">
  访问公开指标（点赞、转发、回复）以及你自己帖子对应的私有指标（展示次数、点击次数）。

  [进一步了解指标 →](/zh/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="会话追踪">
  使用 `conversation_id` 重建完整会话线程，并在整个线程范围内跟踪回复。

  [进一步了解会话追踪 →](/zh/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="编辑历史">
  访问帖子的编辑历史，包括所有先前版本和编辑元数据。

  [进一步了解编辑帖子 →](/zh/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## 价格
</div>

X API v2 采用**按使用量计费**的定价模式：

| 优势 | 说明 |
|:--------|:------------|
| **无订阅** | 只为你的实际使用量付费 |
| **无上限** | 按需使用，无总量上限 |
| **基于额度** | 购买额度，按请求扣减 |
| **实时跟踪** | 在 Developer Console 中监控使用情况 |
| **去重计费** | 同一资源在 24 小时内重复请求仅收取一次费用 |

[查看详细定价信息 →](/zh/x-api/getting-started/pricing)
