X API 提供对 X 公开讨论的编程访问能力，可用于检索帖子、分析趋势、构建集成，并在平台上打造全新的体验。

***

<div id="what-you-can-do">
  ## 你可以做什么
</div>

| 功能 | 描述 |
|:-----------|:------------|
| **阅读帖子** | 搜索、查询，并实时流式接收帖子 |
| **发布内容** | 创建帖子、回复和讨论串 |
| **管理用户** | 查询用户，管理关注、屏蔽和静音 |
| **分析数据** | 获取指标、趋势和互动分析 |
| **构建集成** | 发送私信（DM），管理列表，并与 Spaces 互动 |

***

<div id="api-versions">
  ## API 版本
</div>

<Tabs>
  <Tab title="X API v2（推荐）">
    当前的 X API 版本，具备现代特性和灵活的计费方案。

    **为什么使用 v2：**

    * 按使用量计费——无月度上限
    * 现代化的 JSON 响应格式
    * 灵活的 [fields（字段）](/zh/x-api/fundamentals/fields) 和 [expansions（扩展）](/zh/x-api/fundamentals/expansions)
    * 高级功能：注释、会话追踪、编辑历史
    * 所有新端点和新功能

    **开始使用：**

    1. 在 [console.x.com](https://console.x.com) 注册
    2. 创建应用并获取凭证
    3. [发出你的第一个请求](/zh/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1（旧版）">
    之前的 X API 版本。仅提供有限支持；新项目请使用 v2。

    **仍可使用的内容：**

    * 部分媒体上传端点
    * 旧版流式接口（已弃用）
    * 一些专用端点

    **迁移到 v2：**
    有关端点映射和数据格式更改，请参阅[迁移指南](/zh/x-api/migrate/overview)。
  </Tab>

  <Tab title="Enterprise">
    面向具有高级需求企业的大规模访问方案。

    **功能：**

    * 完整 firehose 访问
    * 历史数据回填
    * 专属支持
    * 自定义速率限制
    * 合规性数据流

    [联系企业销售 →](/zh/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

<div id="v2-highlights">
  ## v2 重点功能
</div>

<Accordion title="字段和扩展">
  只请求你需要的数据。使用 `fields` 参数选择特定属性，并使用 `expansions` 包含相关对象。

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [进一步了解字段 →](/zh/x-api/fundamentals/fields)
</Accordion>

<Accordion title="帖子标注">
  帖子包含用于标识人物、地点、产品和主题的语义标注。可以按主题过滤流和搜索结果。

  [进一步了解标注 →](/zh/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="互动指标">
  获取公开指标（点赞、转发、回复）以及你自己帖子对应的私有指标（展示次数、点击次数）。

  [进一步了解指标 →](/zh/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="会话跟踪">
  使用 `conversation_id` 还原完整会话线程。在整个线程中跟踪回复。

  [进一步了解会话跟踪 →](/zh/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="编辑历史">
  访问帖子的编辑历史，包括所有历史版本和编辑相关的元数据。

  [进一步了解编辑帖子 →](/zh/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## 价格
</div>

X API v2 采用 **按使用量付费** 的计费模式：

| 优势 | 说明 |
|:--------|:------------|
| **无订阅** | 只为实际使用量付费 |
| **无上限** | 可按需任意使用 |
| **基于额度** | 购买额度，每次请求会扣减相应额度 |
| **实时跟踪** | 在开发者控制台中监控使用情况 |
| **去重计费** | 同一资源在 24 小时内被请求两次，仅收取一次费用 |

[查看价格详情 →](/zh/x-api/getting-started/pricing)
