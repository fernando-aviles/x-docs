  ## 快速参考
</div>

<div id="response-structure">
  ### 响应结构
</div>

所有 v2 的响应都遵循以下结构：

```json
{
  "data": { ... },      // 主要对象
  "includes": { ... },  // 扩展对象(如已请求)
  "meta": { ... },      // 分页信息
  "errors": [ ... ]     // 部分错误(如有)
}
```

<div id="common-parameters">
  ### 常用参数
</div>

| 参数 | 用途 |
|:----------|:----|
| `tweet.fields` | 请求特定帖子字段 |
| `user.fields` | 请求特定用户字段 |
| `expansions` | 包含关联对象 |
| `max_results` | 限制每页结果数量 |
| `pagination_token` | 获取下一页/上一页 |

<div id="authentication-methods">
  ### 身份验证方式
</div>

| 方式 | 使用场景 |
|:-------|:---------|
| Bearer 令牌 | 读取公共数据（只读） |
| OAuth 2.0 | 用户操作（细粒度权限范围） |
| OAuth 1.0a | 用户操作（旧版，完整权限） |

[完整身份验证指南 →](/zh/resources/fundamentals/authentication/overview)
