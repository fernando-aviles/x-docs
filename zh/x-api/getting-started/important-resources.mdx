  ## 快速参考

<div id="response-structure">
  ### 响应结构
</div>

所有 v2 响应都采用如下结构：

```json
{
  "data": { ... },      // 主要对象
  "includes": { ... },  // 扩展对象(如有请求)
  "meta": { ... },      // 分页信息
  "errors": [ ... ]     // 部分错误(如有)
}
```

<div id="common-parameters">
  ### 常用参数
</div>

| 参数 | 用途 |
|:----------|:----|
| `tweet.fields` | 请求特定帖子字段 |
| `user.fields` | 请求特定用户字段 |
| `expansions` | 包含关联对象 |
| `max_results` | 限制每页结果数量 |
| `pagination_token` | 获取上一页或下一页 |

<div id="authentication-methods">
  ### 认证方法
</div>

| 方法 | 使用场景 |
|:-------|:---------|
| Bearer Token | 只读访问公共数据 |
| OAuth 2.0 | 具备细粒度权限范围的用户操作 |
| OAuth 1.0a | 用户操作（旧版，具备完整权限） |

[完整认证指南 →](/zh/resources/fundamentals/authentication/overview)
