<div id="what-is-the-x-api-v2">
  ## 什么是 X API v2？
</div>

X API v2 现在是主要的 X API，也是我们产品投资和创新的重点所在。我们与开发者合作，构建了新一代的 X API，以更好地服务多元化的开发者社区。基于开发者的反馈，我们重新构建了该 API，以更好地满足更广泛的需求，引入新的功能和端点，并改进开发者体验。

X API v2 现在是主要的 X API，也是我们产品投资和创新的重点所在。在过去几年中，我们与开发者合作，重新构建了该 API，以更好地满足更广泛的需求，引入新的功能和端点，并改进开发者体验。我们致力于持续构建一个开放的开发者平台，并期待看到你使用 X API v2 构建出怎样的产品。

<div id="why-migrate">
  ## 为什么要迁移？
</div>

X API v2 构建在更加现代且更可持续的基础之上，既为标准版 v1.1 和企业级产品提供了改进后的替代端点，也引入了全新的功能。我们强烈建议使用旧版 API（v1.1 和企业版）的客户开始迁移到 v2，因为我们最终确实计划弃用这些旧版本。使用 X API 来监测和分析公开讨论，与 X 上的用户互动，并不断创新。

在本节中，我们将介绍这些端点及其功能。

<div id="discover-new-and-updated-response-objects">
  ### 发现新的和更新的响应对象
</div>

以下六种数据对象可通过 v2 端点获取：

| Object | Description |
|:--------|:-------------|
| [Tweet](/zh/x-api/fundamentals/data-dictionary#tweet) | Tweet 对象包含大量根级字段，例如 `id`、`text` 和 `created_at`。Tweet 对象也是多个子对象的父对象，包括 `user`、`media`、`poll` 和 `place`。 |
| [User](/zh/x-api/fundamentals/data-dictionary#user) | User 对象包含用于描述被引用用户的 X 用户账号元数据。 |
| [Spaces](/zh/x-api/fundamentals/data-dictionary#space) | Space 对象由诸如 `state`、`host_id`、`is_ticketed`，甚至 `lang` 等字段组成。 |
| [Lists](/zh/x-api/fundamentals/data-dictionary#list) | List 对象包含有关所请求列表的基本信息，包括 `description`、`member_count` 和 `owner_id`。 |
| [Media](/zh/x-api/fundamentals/data-dictionary#media) | 如果一条推文包含媒体（例如图片），则可以使用 `media.fields` 参数请求 Media 对象，其中包含诸如 `media_key`、`type`、`url`、`preview_image_url` 等字段。 |
| [Poll](/zh/x-api/fundamentals/data-dictionary#poll) | 包含在推文中的投票在任何端点中都不是主对象，但可以在 Tweet 对象中找到并进行展开。 |
| [Place](/zh/x-api/fundamentals/data-dictionary#place) | Place 对象由诸如 `place_id`、`geo` 对象、`country_code` 等字段组成。可以使用这些信息来识别推文并基于地理位置分析推文。 |

详细了解[如何使用字段和 expansions](/zh/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)。

<div id="flexibility-to-choose-which-objects-and-fields-you-receive">
  ### 灵活选择要接收的对象和字段
</div>

当你向某个 GET 端点发出请求时，你会收到与该端点关联的主要数据对象，其中会包含一组默认字段。例如，Tweet 对象默认返回 `id` 和 `text` 字段。

如果你希望在请求中获取额外字段，则需要使用 [fields](/zh/x-api/fundamentals/fields) 和 [expansions](/zh/x-api/fundamentals/expansions) 参数。`expansions` 参数可以让你获取相关的数据对象，例如某个用户置顶的推文或媒体对象，而 fields 参数可以让你在默认字段之外，请求返回对象中的特定字段。

下面是你可以在不同 X API v2 端点中请求的可用 expansions 的完整列表：

| 对象 / 资源 | 可用的 Expansions |
|:-------------------|:----------------------|
| Tweets            | `author_id`, `edit_history_tweet_ids`, `entities.mentions.username`, `in_reply_to_user_id`, `referenced_tweets.id`, `referenced_tweets.id.author_id`, `attachments.poll_ids`, `attachments.media_keys`, `geo.place_id` |
| Users             | `pinned_tweet_id` |
| Spaces            | `invited_user_ids`, `speaker_ids`, `creator_id`, `host_ids`, `topic_ids` |

在[如何使用 fields 和 expansions](/zh/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)中了解更多信息。

<div id="edit-tweets">
  ## 编辑推文
</div>

X API v2 端点会提供与已编辑推文相关的元数据。*Edit Tweet*（编辑推文）功能最初于 2022 年 9 月 1 日面向 X 员工开启测试。从该日期开始，符合条件的推文可在 30 分钟内编辑，且最多可编辑 5 次。详细了解[编辑推文](/zh/x-api/fundamentals/edit-posts)。
使用 X API v2，开发者可以了解：

* 某条推文在创建时是否符合可编辑条件。有些推文（例如带投票的推文或已定时发布的推文）无法编辑。
* 推文在 30 分钟内可编辑，且最多可编辑 5 次。对于可编辑的推文，你可以查看剩余可编辑时间以及还可以编辑的次数。
* 你当前查看的是否是某条推文的已编辑版本（在大多数情况下，API 会返回该推文的最新版本，除非通过推文 ID 请求了特定的历史版本）。
* 该推文的完整编辑历史。
* 归属于该推文每个版本的互动量。

<div id="track-threaded-conversations">
  ## 跟踪线程化会话
</div>

一个新的推文字段可以帮助你识别某条推文属于哪个会话线程。会话 ID 对应的是发起该会话的那条推文的 Tweet ID。请在[会话跟踪](/zh/x-api/fundamentals/conversation-id)中了解更多信息。

<div id="ready-to-migrate">
  ## 准备迁移
</div>

为了使用 v2 端点，你需要具备以下内容：

* [一个开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)
* 在某个 [Project](resources/fundamentals/projects) 中创建的 [开发者 App](https://developer.x.com/en/apps)
* 来自该 Project 中开发者 App 的 [密钥和令牌](resources/fundamentals/authentication)

请注意，务必使用属于某个 Project 中 App 的密钥和令牌。如果你使用的是不在任何 Project 中的 App 的密钥和令牌，将无法向 v2 端点发起请求。

一旦你拥有了开发者账号，就可以在 [开发者控制台](https://developer.x.com/en/portal/petition/essential/basic-info) 中完成上述所有设置。

<div id="authentication">
  ### 身份验证
</div>

在新的 Twitter API 中，你将使用两种不同的身份验证方式：OAuth 1.0a User Context 和 OAuth 2.0 Bearer 令牌，来访问不同的端点。在向端点发出请求时，它们分别用于不同的场景：

当你代表某个 Twitter 用户发出请求时，需要使用 OAuth 1.0a User Context\
当你代表你的开发者 App 发出请求时，需要使用 OAuth 2.0 Bearer 令牌
