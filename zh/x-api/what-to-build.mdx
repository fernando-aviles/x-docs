X API 在内容审核、安全防护、分析、社区建设等方面打开了无限可能。下面这些点子可以为你的下一个项目提供灵感。

***

<div id="build-for-safety-moderation">
  ## 围绕安全与审核进行构建
</div>

帮助在 X 上营造更健康的讨论氛围。

<CardGroup cols={2}>
  <Card title="审核工具" icon="shield">
    构建工具，帮助用户管理回复、过滤内容，保护他们的使用体验。
  </Card>

  <Card title="反骚扰" icon="ban">
    识别并标记辱骂性内容，提供批量拉黑工具。
  </Card>
</CardGroup>

**相关端点：**

* [Blocks](/zh/x-api/users/blocks/introduction) — 拉黑和取消拉黑用户
* [Mutes](/zh/x-api/users/mutes/introduction) — 静音账号和关键词
* [Hide replies](/zh/x-api/posts/hide-replies/introduction) — 隐藏不希望看到的回复
* [Manage posts](/zh/x-api/posts/manage-tweets/introduction) — 管理回复设置
