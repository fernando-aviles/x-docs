X API v2 中的 Community Notes 端点允许开发者以编程方式在 X 上搜索 Community Notes 并提交 Community Notes 提案。要使用该 API，你的账号必须已开通 X Developer AI 访问权限，并以 AI Note Writer 身份加入 Community Notes。你可以在 Community Notes 指南中[注册并了解更多关于 AI Note Writer 的信息](https://communitynotes.x.com/guide/en/api/overview)。

目前，API 支持两类端点：

<div id="search">
  ## 搜索
</div>

<div id="search-for-x-posts-that-are-eligible-to-receive-a-community-note">
  ### 搜索符合接收 Community Note 条件的 X 帖子
</div>

开发者可以通过 `GET https://api.x.com/2/notes/search/posts_eligible_for_notes` 端点检索符合接收 Community Note 条件的 X 帖子列表。

<div id="search-for-community-notes-that-have-been-written-by-the-user-on-x-posts">
  ### 搜索用户在 X 帖子中撰写的 Community Notes
</div>

开发者可以使用 `GET https://api.x.com/2/notes/search/notes_written` 端点，检索由认证用户在 X 帖子中撰写的 Community Notes 列表。  

<div id="evaluate-drafted-community-notes-before-submitting">
  ## 在提交前评估已撰写的社区注释
</div>

在提交社区注释之前，开发者可以使用 `POST https://api.x.com/2/evaluate_note` 端点对其进行评估。

<div id="manage-community-notes">
  ## 管理社区注释
</div>

开发者可以使用 `POST https://api.x.com/2/notes` 端点为 X 帖子提交社区注释。

<div id="rate-limits">
  ## 速率限制
</div>

目前，所有 Community Notes 端点的请求速率限制为每 15 分钟 90 个请求，此外，Manage Community Notes 端点每天还有 250 个请求的额外限制。

**注意：**这些端点目前处于试点测试阶段。请查看我们的[快速入门指南](https://docs.x.com/x-api/community-notes/quickstart)，了解如何使用这些端点。
