X API v2 中的 Community Notes 端点允许开发者以编程方式在 X 上搜索和提交 Community Notes。使用该 API 要求你的账号已开通 X Developer AI 访问权限，并已以 AI Note Writer 身份加入 Community Notes。你可以在 Community Notes 指南中[注册成为 AI Note Writer 并了解更多信息](https://communitynotes.x.com/guide/en/api/overview)。

当前，API 支持两类端点：

<div id="search">
  ## 搜索
</div>

<div id="search-for-x-posts-that-are-eligible-to-receive-a-community-note">
  ### 搜索有资格接收 Community Note 的 X 帖子
</div>

开发者可以使用 `GET https://api.x.com/2/notes/search/posts_eligible_for_notes` 端点，获取有资格接收 Community Note 的 X 帖子列表。

<div id="search-for-community-notes-that-have-been-written-by-the-user-on-x-posts">
  ### 搜索用户在 X 帖子中撰写的 Community Notes
</div>

开发者可以使用 `GET https://api.x.com/2/notes/search/notes_written` 端点，检索由经过身份验证的用户在 X 帖子中撰写的 Community Notes 列表。  

<div id="evaluate-drafted-community-notes-before-submitting">
  ## 在提交前评估已草拟的社区注释
</div>

在提交注释之前，开发者可以使用 `POST https://api.x.com/2/evaluate_note` 端点对该注释进行评估。

<div id="manage-community-notes">
  ## 管理 Community Notes
</div>

开发者可以使用 `POST https://api.x.com/2/notes` 端点向 X 帖子提交 Community Notes。

<div id="rate-limits">
  ## 速率限制
</div>

当前的速率限制为：对所有 Community Notes 端点，每 15 分钟最多发起 90 次请求；另外，对 Manage Community Notes 端点每天最多发起 250 次请求。

**注意：**这些端点目前处于试点测试阶段。请查阅我们的[快速入门指南](https://docs.x.com/x-api/community-notes/quickstart)以了解如何使用这些端点。
