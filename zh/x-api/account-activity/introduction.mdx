Account Activity API 会将实时账户活动事件发送到你的 webhook。你可以订阅用户账户，并在他们发布帖子、收到私信、被关注等时收到通知。

<div id="how-it-works">
  ## 工作原理
</div>

1. **注册 webhook** — 注册你的 webhook URL
2. **订阅用户** — 添加用户订阅
3. **接收事件** — 通过 POST 请求接收活动事件
4. **处理事件** — 在你的应用程序中处理事件

***

<div id="event-types">
  ## 事件类型
</div>

| 类别 | 事件 |
|:---------|:-------|
| **帖子** | 创建、删除、点赞、取消点赞 |
| **私信** | 接收、发送、输入状态指示 |
| **关注** | 关注、取消关注 |
| **屏蔽** | 屏蔽、取消屏蔽 |
| **静音** | 静音、取消静音 |

***

<div id="webhook-security">
  ## Webhook 安全
</div>

所有 webhook 请求都包含：

* **CRC 校验** — 用于验证 webhook 的真实性
* **签名头部** — `x-twitter-webhooks-signature`
* **必须使用 HTTPS** — 所有 webhook URL 必须使用 HTTPS

***

<div id="example-register-a-webhook">
  ## 示例：注册 Webhook
</div>

```bash
curl -X POST "https://api.x.com/1.1/account_activity/all/env-name/webhooks.json?\
url=https%3A%2F%2Fyour-server.com%2Fwebhook" \
  -H "Authorization: OAuth oauth_consumer_key=..."
```
