  ## 比较 X API 的列表帖子查询端点
</div>

v2 列表帖子查询端点将取代标准 v1.1 的 [GET lists/statuses](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-statuses)。如果你已有使用该版本端点的代码、App 或工具，并考虑迁移到较新的 X API v2 端点，那么本系列指南适合你。

下表比较了标准 v1.1 与 X API v2 的列表端点：

**通过 ID 查询列表**

|     |     |     |
| :--- | :--- | :--- |
| 描述 | 标准 v1.1 | X API v2 |
| 支持的 HTTP 方法 | `GET` | `GET` |
| 主机域名 | `https://api.x.com` | `https://api.x.com` |
| 端点路径 | `/1.1/lists/statuses.json` | `/2/lists/:id/tweets` |
| [Authentication](/zh/resources/fundamentals/authentication) | OAuth 1.0a 用户上下文<br /><br />仅限 App | OAuth 1.0a 用户上下文<br /><br />OAuth 2.0 带 PKCE 的授权码模式<br /><br />仅限 App |
| 默认请求[速率限制](/zh/resources/fundamentals/rate-limits) | 使用 OAuth 1.0a 时每 15 分钟 900 次请求<br /><br />仅限 App 时每 15 分钟 900 次请求 | 使用 OAuth 1.0a 时每 15 分钟 900 次请求<br /><br />使用 OAuth 2.0 时每 15 分钟 900 次请求<br /><br />仅限 App 时每 15 分钟 900 次请求 |

要访问 X API v2 端点，你必须先[注册开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)。在进行认证时，你必须使用位于某个 [Project](/zh/resources/fundamentals/developer-apps) 中的[开发者 App](/zh/resources/fundamentals/developer-apps)所对应的密钥和 token。

在我们的[入门](/zh/x-api/getting-started/getting-access)页面了解更多关于如何获取 X API v2 端点访问权限的信息。
