<div id="comparing-x-apis-list-members-endpoints">
  ## 比较 X API 的列表成员端点
</div>

v2 列表成员端点组将取代标准的 v1.1 [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members)、[GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships)、[POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) 和 [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) 端点。如果你有使用上述任一列表成员端点的代码、应用或工具，并正在考虑迁移到较新的 X API v2 端点，那么本系列指南就是为你准备的。 

<div id="list-members-lookup">
  ### 列表成员查询
</div>

X API v2 中的列表成员查询端点将取代标准的 [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members)、[GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships) 端点。

下表对比了标准 v1.1 和 X API v2 的列表端点：

**列表成员查询**

|     |     |     |
| :--- | :--- | :--- |
| 说明 | 标准 v1.1 | X API v2 |
| 支持的 HTTP 方法 | `GET` | `GET` |
| 主机域名 | `https://api.x.com` | `https://api.x.com` |
| 端点路径 | `/1.1/lists/members.json` | `/2/lists/:id/members` |
| [Authentication](/zh/resources/fundamentals/authentication) | OAuth 1.0a 用户上下文<br /><br />仅限 App | OAuth 1.0a 用户上下文<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />仅限 App |
| 默认请求[速率限制](/zh/resources/fundamentals/rate-limits) | 使用 OAuth 1.0a 时，每 15 分钟 900 个请求<br /><br />仅限 App 时，每 15 分钟 75 个请求 | 使用 OAuth 1.0a 时，每 15 分钟 900 个请求<br /><br />使用 OAuth 2.0 时，每 15 分钟 900 个请求<br /><br />仅限 App 时，每 15 分钟 900 个请求 |

**列表成员关系查询**

|     |     |     |
| :--- | :--- | :--- |
| 说明 | 标准 v1.1 | X API v2 |
| 支持的 HTTP 方法 | `GET` | `GET` |
| 主机域名 | `https://api.x.com` | `https://api.x.com` |
| 端点路径 | `/1.1/lists/memberships.json` | `/2/users/:id/list_memberships` |
| [Authentication](/zh/resources/fundamentals/authentication) | OAuth 1.0a 用户上下文<br /><br />仅限 App | OAuth 1.0a 用户上下文<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />仅限 App |
| 默认请求[速率限制](/zh/resources/fundamentals/rate-limits) | 使用 OAuth 1.0a 时，每 15 分钟 75 个请求<br /><br />仅限 App 时，每 15 分钟 75 个请求 | 使用 OAuth 1.0a 时，每 15 分钟 75 个请求<br /><br />使用 OAuth 2.0 时，每 15 分钟 75 个请求<br /><br />仅限 App 时，每 15 分钟 75 个请求 |

<div id="manage-list-members">
  ### 管理 List 成员
</div>

用于在 v2 中管理 List 成员的端点将取代标准的 [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create)、[POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) 端点。

下表比较了标准 v1.1 和 X API v2 的 List 端点：

**添加成员**

| 描述 | 标准 v1.1 | X API v2 |
| :--- | :--- | :--- |
| 支持的 HTTP 方法 | POST | POST |
| 主机域名 | https://api.x.com | https://api.x.com |
| 端点路径 | /1.1/lists/members/create.json | /2/lists/:id/members |
| [Authentication](/zh/resources/fundamentals/authentication) | OAuth 1.0a 用户上下文 | OAuth 1.0a 用户上下文<br /><br />OAuth 2.0 Authorization Code with PKCE |
| 默认请求[速率限制](/zh/resources/fundamentals/rate-limits) | 无 | 每 15 分钟 300 次请求（每个用户） |

**移除成员**

| 描述 | 标准 v1.1 | X API v2 |
| :--- | :--- | :--- |
| 支持的 HTTP 方法 | POST | DELETE |
| 主机域名 | https://api.x.com | https://api.x.com |
| 端点路径 | /1.1/lists/members/destroy.json | /2/lists/:id/:user&#95;id |
| [Authentication](/zh/resources/fundamentals/authentication) | OAuth 1.0a 用户上下文 | OAuth 1.0a 用户上下文<br /><br />OAuth 2.0 Authorization Code with PKCE |
| 默认请求[速率限制](/zh/resources/fundamentals/rate-limits) | 无 | 每 15 分钟 300 次请求（每个用户） |

要访问 X API v2 端点，您必须先[注册开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)。在进行认证时，您必须使用位于某个 [Project](/zh/resources/fundamentals/developer-apps) 中的[开发者 App](/zh/resources/fundamentals/developer-apps) 的密钥和令牌。

在我们的[入门](/zh/x-api/getting-started/getting-access)页面了解更多关于如何获得 X API v2 端点访问权限的信息。
