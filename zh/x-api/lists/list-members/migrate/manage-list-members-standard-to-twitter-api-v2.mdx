<div id="manage-list-members-standard-v11-compared-to-x-api-v2">
  ### 管理列表成员：Standard v1.1 与 X API v2 对比
</div>

如果您一直在使用 Standard v1.1 的 [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) 和 [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) 端点，本指南旨在帮助您理解 Standard v1.1 与 X API v2 管理列表成员端点之间的相似之处和差异。

* **相似点**
  * 身份验证
* **不同点**
  * 端点 URL
  * App 和 Project 要求
  * HTTP 方法
  * 速率限制
  * 请求参数

<div id="similarities">
  #### 相似点
</div>

**身份验证**

这两个端点版本都支持 [OAuth 1.0a 用户上下文](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication)。因此，如果你之前使用的是某个标准 v1.1 管理列表成员的端点，那么在迁移到 X API v2 版本时，可以继续使用同样的身份验证方式。

<div id="differences">
  #### 差异
</div>

**端点 URL**

* 标准 v1.1 端点：
  * POST https://api.x.com/1.1/lists/members/create.json
    （将成员添加到指定的列表）
  * POST https://api.x.com/1.1/lists/members/destroy.json
    （从指定的列表中移除成员）
* X API v2 端点：
  * POST https://api.x.com/2/lists/:id/members
    （将成员添加到指定的列表）

  * DELETE https://api.x.com/2/lists/:id/members/:user&#95;id
    （从指定的列表中移除成员）

**速率限制**

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| /1.1/lists/members/create.json<br /><br />none | /2/lists/:id/members<br /><br />在 OAuth 1.0a 用户上下文下，每 15 分钟 300 次请求<br /><br />在 OAuth 2.0 Authorization Code with PKCE 模式下，每 15 分钟 300 次请求 |
| /1.1/lists/members/destroy.json<br /><br />none | /2/lists/:id/members/:user&#95;id<br /><br />在 OAuth 1.0a 用户上下文下，每 15 分钟 300 次请求<br /><br />在 OAuth 2.0 Authorization Code with PKCE 模式下，每 15 分钟 300 次请求 |

**App 和 Project 要求**

在对请求进行认证时，X API v2 端点要求你使用隶属于某个 [Project](/zh/resources/fundamentals/developer-apps) 的 [developer App](/zh/resources/fundamentals/developer-apps) 的凭证。所有 X API v1.1 端点都可以使用任意 App 的凭证，或隶属于某个 Project 的 App 的凭证。

**请求参数**

以下 Standard v1.1 请求参数在 X API v2 中有对应项：

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| list&#95;id | id  |
| slug | 无对应项 |
| screen&#95;name | 无对应项 |
| owner&#95;screen&#95;name | 无对应项 |
| owner&#95;id | 无对应项 |
