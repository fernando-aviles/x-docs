列表成员端点可用于查看列表成员、向列表添加成员以及将成员移除。你还可以查看某个用户是哪些列表的成员。

<div id="endpoints">
  ## 端点
</div>

<div id="list-members-lookup">
  ### 查找列表成员
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/members`](/zh/x-api/lists/get-list-members) | 获取列表成员 |
| GET | [`/2/users/:id/list_memberships`](/zh/x-api/users/get-list-memberships) | 获取用户所在的列表 |

<div id="manage-list-members">
  ### 管理列表成员
</div>

| 方法 | Endpoint | 描述 |
|:-------|:---------|:------------|
| POST | [`/2/lists/:id/members`](/zh/x-api/lists/add-list-member) | 添加成员 |
| DELETE | [`/2/lists/:id/members/:user_id`](/zh/x-api/lists/remove-list-member) | 移除成员 |

***

<div id="example-get-list-members">
  ## 示例：获取列表成员
</div>

```bash
curl "https://api.x.com/2/lists/1234567890/members?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-add-a-member">
  ## 示例：添加成员
</div>

```bash
curl -X POST "https://api.x.com/2/lists/1234567890/members" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "9876543210"}'
```
