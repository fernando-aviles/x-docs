固定列表端点使你能够为经过身份验证的用户查看、固定和取消固定列表。固定列表会在用户的 X 界面中显著显示。

<div id="endpoints">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/pinned_lists`](/zh/x-api/users/get-pinned-lists) | 获取已置顶的列表 |
| POST | [`/2/users/:id/pinned_lists`](/zh/x-api/users/pin-list) | 置顶一个列表 |
| DELETE | [`/2/users/:id/pinned_lists/:list_id`](/zh/x-api/users/unpin-list) | 取消列表置顶 |

***

<div id="example-get-pinned-lists">
  ## 示例：获取置顶列表
</div>

```bash
curl "https://api.x.com/2/users/123456789/pinned_lists?\
list.fields=name,description,member_count" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-pin-a-list">
  ## 示例：置顶列表
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"list_id": "9876543210"}'
```
