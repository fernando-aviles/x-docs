  ## 关键概念

<div id="authentication">
  ### 身份验证
</div>

所有 X API v2 端点都要求你使用一组凭据（也称为密钥和令牌）对请求进行身份验证。你可以使用 OAuth 1.0a 用户上下文来对发送到该端点的请求进行身份验证。

在使用 [OAuth 1.0a 用户上下文](/zh/resources/fundamentals/authentication) 时，你必须使用一组 API 密钥和用户访问令牌才能成功发出请求。访问令牌必须与由你代表其发出请求的用户关联。如果你想为其他用户生成一组访问令牌，他们必须通过 [3-legged OAuth flow](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens) 授权你的应用。

请注意，OAuth 1.0a 可能比较难用。如果你不熟悉这种身份验证方式，建议你使用某个 [library](/zh/x-api/tools-and-libraries/overview)，或者使用 Postman 等工具。

<div id="developer-console-projects-and-developer-apps">
  ### Developer Console、Project 和开发者 App
</div>

要获取一组可用于 X API v2 端点的身份验证凭证，你必须先[注册开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)、在该账号下创建一个 [Project](/zh/resources/fundamentals/developer-apps)，并在该 Project 中创建一个 [开发者 App](/zh/resources/fundamentals/developer-apps)。然后你可以在自己的开发者 App 中找到密钥和令牌。

<div id="rate-limits">
  ### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为了管理如此巨大的请求量，[速率限制](/zh/x-api/fundamentals/rate-limits) 会应用到每个端点，用于限制你代表应用或代表已认证用户所能发起的请求次数。

这些端点在用户级别进行速率限制，这意味着你代表其发起请求的已认证用户，在任意开发者 App 中调用该端点的次数都有上限。

下表展示了每个端点的速率限制。

| Endpoint | HTTP method | Rate limit |
| :--- | :--- | :--- |
| /2/users/:id/pinned&#95;lists | POST | 每 15 分钟 50 次请求 |
| /2/users/:id/pinned&#95;lists/:list&#95;id | DELETE | 每 15 分钟 50 次请求 |
| /2/users/:id/pinned&#95;lists | GET | 每 15 分钟 15 次请求 |

<div id="fields-and-expansions">
  ### 字段和扩展
</div>

X API v2 的 GET 端点允许用户使用一组称为 `fields` 和 `expansions` 的工具，精确选择希望从 API 返回的哪些数据。`expansions` 参数允许你展开在响应负载中被引用的对象。比如，查询置顶的列表（pinned Lists）时，你可以获取以下[扩展](/zh/x-api/fundamentals/expansions)：

* `owner_id`

`fields` 参数允许你精确选择希望在不同数据对象中接收哪些[字段](/zh/x-api/fundamentals/fields)。此端点主要返回用户对象。默认情况下，List 对象只返回 `id` 和 `name` 字段。要接收例如 `list.created_at` 或 `list.description` 等附加字段，你必须通过 `fields` 参数显式请求这些字段。

我们在 [X API v2 数据字典](/zh/x-api/fundamentals/data-dictionary)中新增了一篇关于如何同时使用[字段和扩展](/zh/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)的指南。

下表展示了在该查找端点可用的字段和扩展：

| Endpoint | Fields | Expansions |
| :--- | :--- | :--- |
| /2/users/:id/pinned&#95;lists | `list.fields`, `user.fields` | `owner_id` |
