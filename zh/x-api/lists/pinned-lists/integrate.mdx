  ## 关键概念
</div>

<div id="authentication">
  ### 鉴权
</div>

所有 X API v2 端点都要求你使用一组凭证（也称为 keys 和 tokens）对请求进行鉴权。你可以使用 OAuth 1.0a 用户上下文来对发往此端点的请求进行鉴权。

[OAuth 1.0a 用户上下文](/zh/resources/fundamentals/authentication)，这意味着你必须使用一组 API Keys 和用户 Access Tokens 才能成功发起请求。Access Tokens 必须与你代表其发起请求的用户相关联。如果你希望为另一位用户生成一组 Access Tokens，则该用户必须通过 [3-legged OAuth 流程](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens)授权你的 App。

请注意，OAuth 1.0a 相对较难使用。如果你不熟悉这种鉴权方式，我们建议你使用一个 [库](/zh/x-api/tools-and-libraries/overview)，或使用 Postman 之类的工具。

<div id="developer-console-projects-and-developer-apps">
  ### 开发者控制台、Project 和开发者 App
</div>

要获取一组可用于 X API v2 端点的认证凭据，你必须先[注册开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)，在该账号下创建一个 [Project](/zh/resources/fundamentals/developer-apps)，并在该 Project 中创建一个[开发者 App](/zh/resources/fundamentals/developer-apps)。然后你可以在你的开发者 App 中找到你的密钥和令牌。

<div id="rate-limits">
  ### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为了管理如此巨大的请求量，[速率限制](/zh/x-api/fundamentals/rate-limits) 会应用到每个端点上，用于限制你代表你的应用或已认证用户所能发起的请求次数。

这些端点是按用户级别进行速率限制的，这意味着你代表其发起请求的已认证用户，在任意开发者 App 中对该端点的调用次数都有上限。

下表展示了每个端点的速率限制。

| 端点 | HTTP 方法 | 速率限制 |
| :--- | :--- | :--- |
| /2/users/:id/pinned&#95;lists | POST | 每 15 分钟 50 次请求 |
| /2/users/:id/pinned&#95;lists/:list&#95;id | DELETE | 每 15 分钟 50 次请求 |
| /2/users/:id/pinned&#95;lists | GET | 每 15 分钟 15 次请求 |

<div id="fields-and-expansions">
  ### 字段和扩展
</div>

X API v2 的 GET 端点允许用户使用一组称为 `fields` 和 `expansions` 的工具，精确选择他们希望从 API 返回的 data。`expansions` 参数允许你展开在负载中被引用的对象。例如，查询置顶的 List 可以让你获取以下[扩展](/zh/x-api/fundamentals/expansions)：

* `owner_id`

`fields` 参数允许你精确选择不同 data 对象中你希望接收的哪些[字段](/zh/x-api/fundamentals/fields)。此端点主要返回用户对象。默认情况下，List 对象会返回 `id` 和 `name` 字段。若要接收额外字段，例如 `list.created_at` 或 `list.description`，你必须通过 fields 参数显式请求这些字段。

我们在 [X API v2 数据字典](/zh/x-api/fundamentals/data-dictionary)中新增了一篇关于如何同时使用[字段和扩展](/zh/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)的指南。

下表展示了查找（lookup）端点可用的字段和扩展：

| Endpoint | Fields | Expansions |
| :--- | :--- | :--- |
| /2/users/:id/pinned&#95;lists | `list.fields`, `user.fields` | `owner_id` |
