置顶列表端点可用于查询用户的置顶列表，并管理哪些列表被置顶。

<Note>
  **先决条件**

  在开始之前，你需要：

  * 一个已获批准 App 的[开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)
  * 用户访问令牌（OAuth 1.0a 或 OAuth 2.0 PKCE）
</Note>

<div id="authentication">
  ## 身份验证
</div>

| 操作 | 身份验证 |
|:----------|:---------------|
| 查找已置顶的列表 | OAuth 1.0a 或 OAuth 2.0 PKCE |
| 置顶/取消置顶列表 | OAuth 1.0a 或 OAuth 2.0 PKCE |

<Warning>
  查找和管理操作都需要使用用户上下文的身份验证。不支持仅应用级（Bearer Token）身份验证。
</Warning>

<div id="quick-example">
  ## 快速示例
</div>

<CodeGroup dropdown>
  ```bash cURL
  # 获取置顶列表
  curl "https://api.x.com/2/users/2244994945/pinned_lists" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 获取置顶列表
  response = client.lists.get_pinned("2244994945")

  for lst in response.data:
      print(f"{lst.name}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 获取置顶列表
  const response = await client.lists.getPinned("2244994945");

  response.data?.forEach((lst) => {
    console.log(lst.name);
  });
  ```
</CodeGroup>
