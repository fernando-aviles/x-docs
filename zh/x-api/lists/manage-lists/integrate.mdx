<div id="authentication">
  #### 身份验证
</div>

所有 X API v2 端点都要求您使用一组凭证（也称为密钥和令牌）对请求进行身份验证。

这些特定的端点需要使用 [OAuth 1.0a 用户上下文](/zh/resources/fundamentals/authentication)，这意味着您必须使用一组 API key 和用户 Access Token 才能成功发出请求。Access Token 必须与您代表其发起请求的用户相关联。如果您想为另一位用户生成一组 Access Token，该用户必须通过 [三方 OAuth 流程](/zh/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow)授权或验证您的应用。

请注意，OAuth 1.0a 的使用可能比较复杂。如果您不熟悉这种身份验证方法，建议您使用某个[库](/zh/x-api/tools-and-libraries/overview)或 Postman 等工具来正确地为您的请求进行身份验证。

<div id="developer-console-projects-and-developer-apps">
  #### 开发者控制台、Project 与开发者 App
</div>

要获取可用于 X API v2 端点的一组身份验证凭证，你必须先[注册一个开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)、在该账号下创建一个 [Project](/zh/resources/fundamentals/developer-apps)，并在该 Project 中创建一个[开发者 App](/zh/resources/fundamentals/developer-apps)。然后你可以在你的开发者 App 中找到相应的密钥和令牌。

<div id="rate-limits">
  #### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为了管理如此巨大的请求量，[速率限制](/zh/x-api/fundamentals/rate-limits) 会应用到每个端点（endpoint），用于限制你代表应用或代表已通过身份验证的用户所能发起的请求次数。

这些端点在用户级别上实施速率限制，这意味着，你代表其发起请求的已验证用户，在任何开发者 App 中调用该端点的次数都有上限。

下表显示了每个端点的速率限制。

|     |     |     |
| :--- | :--- | :--- |
| **Endpoint** | **HTTP method** | **Rate limit** |
| /2/lists | POST | 每 15 分钟 300 个请求 |
| /2/lists/:id | DELETE / PUT | 每 15 分钟 300 个请求 |

<div id="create-a-list">
  #### 创建列表
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/lists" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"name": "My List", "description": "A list of interesting accounts"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 创建新列表
  response = client.lists.create(
      name="My List",
      description="A list of interesting accounts"
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 创建新列表
  const response = await client.lists.create({
    name: "My List",
    description: "A list of interesting accounts",
  });
  console.log(response.data);
  ```
</CodeGroup>
