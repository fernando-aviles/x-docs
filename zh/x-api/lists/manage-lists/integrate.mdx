  ### 核心概念
</div>

<div id="authentication">
  #### 身份验证
</div>

所有 X API v2 端点都要求你使用一组凭证对请求进行身份验证，也称为密钥和令牌。

这些特定的端点需要使用 [OAuth 1.0a 用户上下文](/zh/resources/fundamentals/authentication)，这意味着你必须使用一组 API 密钥和用户访问令牌（Access Tokens）才能成功发出请求。访问令牌必须与你代表其发出请求的用户关联。如果你想为另一位用户生成一组访问令牌，他们必须使用 [三方（3-legged）OAuth 流程](/zh/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow)对你的 App 进行授权或认证。

请注意，OAuth 1.0a 使用起来可能比较棘手。如果你不熟悉这种身份验证方法，我们建议你使用一个[库](/zh/x-api/tools-and-libraries/overview)或类似 Postman 的工具来正确地为你的请求进行身份验证。

<div id="developer-console-projects-and-developer-apps">
  #### 开发者控制台、Project 和开发者 App
</div>

要获取一套可用于 X API v2 端点的认证凭据，你必须先[注册开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)，在该账号下创建一个 [Project](/zh/resources/fundamentals/developer-apps)，并在该 Project 中创建一个 [开发者 App](/zh/resources/fundamentals/developer-apps)。然后，你可以在自己的开发者 App 中找到对应的密钥和令牌。

<div id="rate-limits">
  #### 速率限制
</div>

每天都有成千上万的开发者向 X API 发起请求。为帮助管理如此巨大的请求量，我们在每个端点上设置了[速率限制](/zh/x-api/fundamentals/rate-limits)，用于限制你代表你的 App 或代表经过身份验证的用户所能发起的请求数量。

这些端点的速率限制是按用户级别设置的，这意味着你代表其发起请求的经过身份验证的用户，在任何开发者 App 中对该端点的调用次数都有上限。

下表显示了各端点的速率限制。

|     |     |     |
| :--- | :--- | :--- |
| **端点** | **HTTP 方法** | **速率限制** |
| /2/lists | POST | 每 15 分钟 300 次请求 |
| /2/lists/:id | DELETE / PUT | 每 15 分钟 300 次请求 |

<div id="create-a-list">
  #### 创建列表
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/lists" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"name": "My List", "description": "A list of interesting accounts"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 创建一个新的列表
  response = client.lists.create(
      name="My List",
      description="A list of interesting accounts"
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 创建一个新的列表
  const response = await client.lists.create({
    name: "My List",
    description: "A list of interesting accounts",
  });
  console.log(response.data);
  ```
</CodeGroup>

<div id="update-a-list">
  #### 更新列表
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X PUT "https://api.x.com/2/lists/123456789" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"name": "Updated List Name"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 更新列表
  response = client.lists.update(
      list_id="123456789",
      name="Updated List Name"
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",

  const client = new Client({ oauth1 });

  // 更新列表
  const response = await client.lists.update("123456789", {
  ```
