<div id="manage-lists-standard-v11-compared-to-x-api-v2">
  ### 管理列表：标准 v1.1 与 X API v2 的比较
</div>

如果你一直在使用标准 v1.1 的 [POST lists/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-create)、[POST lists/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-destroy) 和 [POST lists/update](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-update) 端点，本指南旨在帮助你了解标准 v1.1 与 X API v2 管理列表端点之间的相似点和差异。

* **相似之处**
  * 身份验证
* **差异**
  * 端点 URL
  * App 和 Project 要求
  * HTTP 方法
  * 速率限制
  * 请求参数

<div id="similarities">
  #### 相似点
</div>

**身份验证**

这两个版本的端点都支持 [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication)。因此，如果你之前使用的是标准 v1.1 中的某个管理列表端点，在迁移到 X API v2 版本时，可以继续使用相同的身份验证方式。

<div id="differences">
  #### 差异
</div>

**端点 URL**

* 标准 v1.1 端点：
  * POST https://api.x.com/1.1/lists/create.json\
    （创建列表）
  * POST https://api.x.com/1.1/lists/destroy.json\
    （删除列表）
  * POST https://api.x.com/1.1/lists/update.json\
    （更新列表）
* X API v2 端点：
  * POST https://api.x.com/2/lists\
    （创建列表）

  * DELETE https://api.x.com/2/lists/:id\
    （删除列表）

  * PUT https://api.x.com/2/lists/:id\
    （更新列表）

**速率限制**

| **标准 v1.1** | **X API v2** |
| :--- | :--- |
| /1.1/lists/create.json<br /><br />无 | /2/lists<br /><br />在 OAuth 1.0a 用户上下文下，每 15 分钟窗口内最多 300 次请求 |
| /1.1/lists/destroy.json<br /><br />无 | /2/lists/:id<br /><br />在 OAuth 1.0a 用户上下文下，每 15 分钟窗口内最多 300 次请求 |
| /1.1/lists/update.json<br /><br />无 | /2/lists/:id<br /><br />在 OAuth 1.0a 用户上下文下，每 15 分钟窗口内最多 300 次请求 |

**App 和 Project 要求**

在对请求进行认证时，X API v2 端点要求你使用与某个 [Project](/zh/resources/fundamentals/developer-apps) 关联的 [developer App](/zh/resources/fundamentals/developer-apps) 的凭证。所有 X API v1.1 端点都可以使用来自 App 或来自与 Project 关联的 App 的凭证。

**请求参数**

以下标准 v1.1 请求参数在 X API v2 中有对应项：

**创建列表**

| **标准** | **X API v2** |
| :--- | :--- |
| name | name |
| mode | private |
| description | description |

**删除/更新列表**

| **标准** | **X API v2** |
| :--- | :--- |
| owner&#95;screen&#95;name | 无对应项 |
| owner&#95;id | 无对应项 |
| list&#95;id | id  |
| slug | 无对应项 |

<Note>
  **请注意：** 标准 v1.1 参数作为查询参数传递，而 X API v2 参数则作为请求体参数（用于 POST 端点）或路径参数（用于 DELETE 和 PUT 端点）传递。
</Note>

<div id="create-a-list-v2">
  ### 创建列表 (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/lists" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"name": "My List", "description": "A great list"}'
  ```

  ```python Python
  # 需要 OAuth 1.0a 用户上下文身份验证
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/lists"
  data = {"name": "My List", "description": "A great list"}

  response = requests.post(url, auth=auth, json=data)
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 创建列表
  response = client.lists.create(name="My List", description="A great list")
  print(f"Created List: {response.data.id}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 创建列表
  const response = await client.lists.create({
    name: "My List",
    description: "A great list",
  });
  console.log(`Created List: ${response.data?.id}`);
  ```
</CodeGroup>

  ### 删除列表 (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/lists/123456789" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/lists/123456789"
  response = requests.delete(url, auth=auth)
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  ```
