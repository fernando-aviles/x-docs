“Manage Lists” 端点可让你代表已通过身份验证的用户创建、更新和删除列表。

<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/lists`](/zh/x-api/lists/create-list) | 创建新的列表 |
| PUT | [`/2/lists/:id`](/zh/x-api/lists/update-list) | 更新列表 |
| DELETE | [`/2/lists/:id`](/zh/x-api/lists/delete-list) | 删除列表 |

***

<div id="example-create-a-list">
  ## 示例：创建一个列表
</div>

```bash
curl -X POST "https://api.x.com/2/lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech News",
    "description": "My favorite tech journalists",
    "private": false
  }'
```

<div id="example-response">
  ## 示例响应
</div>

```json
{
  "data": {
    "id": "1234567890",
    "name": "Tech News"
  }
}
```
