列表查询端点允许你检索列表相关信息。你可以通过 id 查询特定列表，或获取某个用户拥有的所有列表。

<div id="overview">
  ## 概览
</div>

<CardGroup cols={2}>
  <Card title="按 id" icon="list">
    获取指定列表的详细信息
  </Card>

  <Card title="按所有者" icon="user">
    获取某个用户拥有的所有列表
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id`](/zh/x-api/lists/get-list-by-id) | 根据 ID 获取列表 |
| GET | [`/2/users/:id/owned_lists`](/zh/x-api/users/get-owned-lists) | 获取用户拥有的列表 |

***

<div id="response-fields">
  ## 响应字段
</div>

默认情况下，响应中包含 `id` 和 `name`。你可以请求额外字段：

| 字段 | 说明 |
|:------|:------------|
| `description` | 列表描述 |
| `owner_id` | 所有者的用户 ID |
| `private` | 列表是否为私密 |
| `follower_count` | 关注者数量 |
| `member_count` | 成员数量 |
| `created_at` | 列表创建时间 |

<div id="example-request">
  ### 示例请求
</div>

```bash
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id,member_count,follower_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
