List 查询端点可让你检索列表（List）的相关信息。你可以通过 id 查找特定的 List，或获取某个用户拥有的所有 List。

<div id="overview">
  ## 概览
</div>

<CardGroup cols={2}>
  <Card title="按 id" icon="list">
    获取指定列表的详细信息
  </Card>

  <Card title="按拥有者" icon="user">
    获取某用户拥有的所有列表
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## 端点
</div>

| 方法 | 端点 | 描述 |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id`](/zh/x-api/lists/get-list-by-id) | 根据 ID 获取列表 |
| GET | [`/2/users/:id/owned_lists`](/zh/x-api/users/get-owned-lists) | 获取指定用户拥有的列表 |

***

<div id="response-fields">
  ## 响应字段
</div>

默认情况下，响应包含 `id` 和 `name`。若需更多字段，请求以下附加字段：

| 字段 | 描述 |
|:------|:------------|
| `description` | 列表描述 |
| `owner_id` | 所有者的用户 id |
| `private` | 列表是否为私密 |
| `follower_count` | 关注者数量 |
| `member_count` | 成员数量 |
| `created_at` | 列表创建时间 |

<div id="example-request">
  ### 示例请求
</div>

```bash
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id,member_count,follower_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
