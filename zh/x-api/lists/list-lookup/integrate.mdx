<div id="authentication">
  ## 认证
</div>

列表查询端点支持多种身份验证方法：

| 方法 | 最适用场景 | 是否可访问私有列表？ |
|:-------|:---------|:-------------------------|
| [OAuth 2.0 App-Only](/zh/resources/fundamentals/authentication#oauth-2-0) | 公共列表数据 | 否 |
| [OAuth 2.0 Authorization Code with PKCE](/zh/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | 面向用户的应用 | 是（拥有/关注） |
| [OAuth 1.0a User Context](/zh/resources/fundamentals/authentication) | 遗留集成 | 是（拥有/关注） |

<div id="example-request">
  ### 示例请求
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/84839422?\
  list.fields=description,member_count,follower_count,private" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 通过 ID 获取列表
  response = client.lists.get(
      list_id="84839422",
      list_fields=["description", "member_count", "follower_count", "private"]
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  const response = await client.lists.get("84839422", {
    listFields: ["description", "member_count", "follower_count", "private"],
  });
  console.log(response.data);
  ```
</CodeGroup>

| Method | Endpoint | Description |

<div id="available-fields">
  ### 可用字段
</div>

<Accordion title="list.fields">
  | 字段 | 描述 |
  |:------|:------------|
  | `created_at` | 列表创建时间戳 |
  | `description` | 列表描述 |
  | `follower_count` | 关注者数量 |
  | `member_count` | 成员数量 |
  | `owner_id` | 所有者的用户 ID |
  | `private` | 列表是否为私密 |
</Accordion>

<Accordion title="user.fields（需要展开 owner_id）">
  | 字段 | 描述 |
  |:------|:------------|
  | `username` | 所有者的 @handle |
  | `name` | 所有者的显示名称 |
  | `verified` | 所有者的认证状态 |
  | `profile_image_url` | 所有者的头像 URL |
</Accordion>

<div id="example-with-expansions">
  ### 包含 expansions 的示例
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/84839422?\
  list.fields=description,member_count,follower_count,owner_id&\
  expansions=owner_id&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 获取带有所有者扩展的列表
  response = client.lists.get(
      list_id="84839422",
      list_fields=["description", "member_count", "follower_count", "owner_id"],
      expansions=["owner_id"],
      user_fields=["username", "verified"]
  )

  print(response.data)
  print(response.includes)  # 包含所有者用户对象
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  const response = await client.lists.get("84839422", {
    listFields: ["description", "member_count", "follower_count", "owner_id"],
    expansions: ["owner_id"],
    userFields: ["username", "verified"],
  });

  console.log(response.data);
  console.log(response.includes); // 包含所有者用户对象
  ```
</CodeGroup>

<div id="pagination">
  ## 分页
</div>

在检索自己拥有的列表时，结果将以分页形式返回：

<CodeGroup dropdown>
  ```bash cURL
  # 第一次请求
  curl "https://api.x.com/2/users/123/owned_lists?max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"

  # 携带分页令牌的后续请求
  curl "https://api.x.com/2/users/123/owned_lists?max_results=100&pagination_token=NEXT_TOKEN" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # SDK 会自动处理分页
  all_lists = []

  for page in client.lists.get_user_owned_lists(user_id="123", max_results=100):
      if page.data:
          all_lists.extend(page.data)

  print(f"Found {len(all_lists)} lists")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  async function getAllOwnedLists(userId) {
    const allLists = [];

    // SDK 会自动处理分页
    const paginator = client.lists.getUserOwnedLists(userId, { maxResults: 100 });

    for await (const page of paginator) {
      if (page.data) {
        allLists.push(...page.data);
      }
    }

    return allLists;
  }

  // 用法
  const lists = await getAllOwnedLists("123");
  console.log(`Found ${lists.length} lists`);
  ```
</CodeGroup>

<div id="private-lists">
  ## 私密列表
</div>

* 私密列表仅对列表所有者可见
* 你必须以列表所有者身份进行认证才能获取私密列表详情
* `private` 字段表示列表是否为私密列表

***

<div id="error-handling">
  ## 错误处理
</div>

| 状态码 | 错误 | 解决方案 |
|:-------|:------|:---------|
| 400 | 无效请求 | 检查列表 ID 格式 |
| 401 | 未授权 | 检查认证信息 |
| 403 | 禁止访问 | 列表可能是私有的 |
| 404 | 未找到 | 列表不存在 |
| 429 | 请求过多 | 等待后重试 |
