<div id="overview">
  ## 概览
</div>

媒体对象代表一张照片、一个视频或一个动态 GIF。媒体对象被 Twitter API 中的许多端点使用，并且可以包含在推文、私信、用户个人资料、广告素材等内容中。每个媒体对象都可以有多个用于展示或播放的变体，这些变体具有不同的分辨率或格式。

<div id="media-types-size-restrictions">
  ## 媒体类型和大小限制
</div>

通过 API 上传的媒体大小限制 

- 图像 5 MB
- GIF 15 MB
- 视频 512 MB（使用 media_category=amplify 时）

<div id="creation">
  ## 创建
</div>

诸如推文、私信、用户头像、托管 Ads 卡片等对象可以包含一个或多个媒体对象。这些顶级对象统称为实体（entity）。用于创建这些实体的相关 API（例如 `POST statuses/update`）可以通过唯一的 `media_id` 关联一个或多个媒体对象。

包含媒体对象的实体可以按以下步骤创建：

1. 使用推荐的分块上传（图像/GIF/视频）或较早的简单上传（仅图像）来上传媒体文件。
2. 从步骤 1 中获取一个 `media_id`。如果该实体允许在参数中传入多个 `media_id`，则可以针对不同的媒体多次重复此步骤。
3. 调用相应的 endpoint 创建实体，并包含 `media_id` 和其他必需参数。例如，使用 `POST statuses/update` endpoint 将一个 `media_id` 附加到一条推文。
