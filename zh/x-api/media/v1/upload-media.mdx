<div id="overview">
  ## 概览
</div>

媒体对象表示单张照片、视频或动态 GIF 图像。媒体对象在 Twitter API 中的许多端点中都会使用，并且可以包含在推文、私信、用户资料、广告素材等位置。每个媒体对象可以具有多个用于展示或播放的变体，具有不同的分辨率或格式。

<div id="media-types-size-restrictions">
  ## 媒体类型和大小限制
</div>

通过 API 上传的媒体文件大小限制

- 图片：最大 5 MB
- GIF：最大 15 MB
- 视频：最大 512 MB（当使用 media_category=amplify 时）

<div id="creation">
  ## 创建
</div>

推文、私信、用户头像、托管广告卡片等对象可以包含一个或多个媒体对象。这些顶级对象统称为实体（entity）。相关的实体创建 API（例如 POST statuses/update）可以通过唯一的 media_id 传入一个或多个媒体对象。

包含一个或多个媒体对象的实体可以通过以下步骤创建：

1. 使用推荐的分块上传（图像/GIF/视频）或较早的简单上传（仅图像）上传媒体文件。
2. 从第 1 步中获取一个 media_id。如果该实体允许传入多个 media_id 参数，则可以使用不同的媒体多次重复此步骤。
3. 通过调用相应的 endpoint 创建实体，并包含 media_id 和其他必需参数。例如，通过 POST statuses/update 端点将 media_id 附加到一条推文上。
