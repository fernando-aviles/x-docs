<div id="overview">
  ## 概览
</div>

媒体对象表示一张照片、一个视频或一个动画 GIF。媒体对象被 Twitter API 中的许多端点使用，并可出现在推文、私信、用户资料、广告素材等位置。每个媒体对象可能具有多个用于展示或播放的版本，采用不同的分辨率或格式。

<div id="media-types-size-restrictions">
  ## 媒体类型和大小限制
</div>

通过 API 上传时的大小限制 

- 图片 5 MB
- GIF 15 MB
- 视频 512 MB（使用 media_category=amplify 时）

<div id="creation">
  ## 创建
</div>

推文、私信、用户个人资料图片、托管 Ads 卡片等对象可以包含一个或多个媒体对象。这些顶层对象统称为实体（entities）。相关的实体创建 API（例如 POST statuses/update）可以使用唯一的 media_id 传入一个或多个媒体对象。

包含媒体对象的实体可以通过以下步骤创建：

1. 使用推荐的分块上传（图像/GIF/视频）或较早的简单上传方式（仅图像）来上传媒体文件。
2. 从步骤 1 中获取一个 media_id。如果该实体允许传入多个 media_id 参数，则可以使用不同的媒体多次重复此步骤。
3. 调用相应的端点创建该实体，并包含 media_id 以及其他必需参数。例如，使用 POST statuses/update 端点将 media_id 附加到一条推文上。
