X 致力于支持使用 X API 构建产品的开发者社区。作为这一承诺的一部分，我们的目标是让我们的 API 对开发者保持开放与公平，对 X 上的用户安全，并整体上有利于整个 X 平台。任何将 X 内容进行离线存储的开发者，都必须确保这些数据能够反映用户意图以及 X 上内容的当前状态。例如，当 X 上的某个人删除了一条帖子或其账号、将其帖子设为受保护状态，或编辑了一条帖子时，X 和我们的开发者都必须尊重该用户的期望和意图，这一点至关重要。

实时合规事件流为开发者提供工具，以便依据 [X Developer Agreement and Policy](https://developer.x.com/en/developer-terms/policy) 维护符合要求的 X 数据。 

合规事件流有两种：一种用于帖子合规事件，另一种用于 *用户合规* 事件。这些流在具有 Enterprise 访问权限的情况下可用，旨在帮助摄取高容量数据的合作伙伴“监听”合规事件，例如帖子编辑事件。

这些流提供以下事件： 

**帖子合规流： **

* delete - 表示该帖子已被删除。

* tweet&#95;edit - 表示某条帖子已被编辑，并提供更新后帖子的 ID。 

* withheld - 表示该帖子在一个或多个国家/地区被屏蔽。 

* drop - 表示该帖子应从公开视图中移除。

* undrop - 表示该帖子可以再次展示并视为公开内容。

**用户合规流： **

* **user&#95;delete** - 表示该用户账号已被删除

* **user&#95;undelete** - 表示该用户账号已被恢复

* **user&#95;protect** - 表示该用户账号已变为私密

* **user&#95;unprotect** - 表示该用户账号已变为公开

* **user&#95;withheld** - 表示该用户账号在一个或多个国家/地区被屏蔽。 

* **user&#95;suspend** - 表示该用户账号已被暂停

* **user&#95;unsuspend** - 表示该用户账号的暂停状态已被解除

* **user&#95;profile&#95;modification** - 表示该用户资料已更新。这包括更新后的简介、名称、位置和 URL。

**账号设置**

要访问这些端点，你需要：

* 一个已获批准的 [开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)。
* 使用来自 [developer App](/zh/resources/fundamentals/developer-apps)（位于某个 [Project](/zh/resources/fundamentals/developer-apps) 中）的密钥和令牌进行认证。 

在我们的 [入门指南](/zh/x-api/getting-started/getting-access) 中了解有关获取 X API v2 端点访问权限的更多信息。
