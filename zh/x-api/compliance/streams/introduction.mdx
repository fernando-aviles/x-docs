X 致力于支持使用 X API 构建产品的开发者社区。作为这一承诺的一部分，我们的目标是让 API 对开发者保持开放和公平，对 X 上的用户安全，并整体上有利于 X 平台。任何将 X 内容离线存储的开发者，都必须确保这些数据能够体现用户意图以及 X 上内容的当前状态。例如，当某人在 X 上删除帖子或其账号、保护其帖子或编辑帖子时，X 和我们的开发者都必须尊重该用户的期望和意图。

实时的合规事件流为开发者提供工具，以便其维护的 X 数据符合 [X Developer Agreement and Policy](https://developer.x.com/en/developer-terms/policy) 的要求。 

有两个合规事件流，一个用于帖子合规事件，一个用于 *用户合规* 事件。这些流在 Enterprise 级别访问权限下可用，旨在帮助摄入大量数据的合作伙伴“监听”诸如帖子编辑事件等合规事件。

这些流会提供以下事件： 

**帖子合规流： **

* delete - 表示该帖子已被删除。

* tweet&#95;edit - 表示某条帖子已被编辑，并提供更新后帖子的 ID。 

* withheld - 表示该帖子已在一个或多个国家/地区被屏蔽。 

* drop - 表示该帖子应从公共视图中移除。

* undrop - 表示该帖子可以再次展示并视为公开内容。

**用户合规流： **

* **user&#95;delete** - 表示该用户账号已被删除

* **user&#95;undelete** - 表示该用户账号被恢复

* **user&#95;protect** - 表示该用户账号变为私密

* **user&#95;unprotect** - 表示该用户账号变为公开

* **user&#95;withheld** - 表示该用户账号已在一个或多个国家/地区被屏蔽。 

* **user&#95;suspend** - 表示该用户账号已被暂停

* **user&#95;unsuspend** - 表示该用户账号已被解除暂停

* **user&#95;profile&#95;modification** - 表示该用户资料已被更新。这包括更新后的简介、名称、位置和 URL。

**账号设置**

要访问这些端点，你需要：

* 一个已获批准的 [开发者账号](https://developer.x.com/en/portal/petition/essential/basic-info)。
* 使用来自 [developer App](/zh/resources/fundamentals/developer-apps) 的密钥和令牌进行认证，该 App 位于某个 [Project](/zh/resources/fundamentals/developer-apps) 中。 

在我们的 [入门指南](/zh/x-api/getting-started/getting-access) 中了解更多关于如何获取 X API v2 端点访问权限的信息。
