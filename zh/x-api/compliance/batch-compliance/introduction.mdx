Batch Compliance 端点允许你上传包含帖子 ID 或用户 ID 的数据集，并获取其当前的合规状态。你可以用它来识别已删除的帖子、已封禁的账号，以及其他合规事件。

<div id="how-it-works">
  ## 工作原理
</div>

1. **创建作业** — 指定类型（帖子或用户）和上传 URL 地址
2. **上传 ID** — 将你的数据集上传到提供的 URL
3. **等待处理** — 作业会异步处理
4. **下载结果** — 获取每个 ID 的合规状态

***

<div id="endpoints">
  ## 端点
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/compliance/jobs`](/zh/x-api/compliance/create-compliance-job) | 创建新的合规任务 |
| GET | [`/2/compliance/jobs/:id`](/zh/x-api/compliance/get-compliance-job-by-id) | 获取任务状态 |
| GET | [`/2/compliance/jobs`](/zh/x-api/compliance/get-compliance-jobs) | 列出所有任务 |

***

<div id="job-types">
  ## 作业类型
</div>

| 类型 | 描述 |
|:-----|:------------|
| `tweets` | 检查帖子合规状态 |
| `users` | 检查用户合规状态 |

***

<div id="compliance-events">
  ## 合规事件
</div>

<div id="post-events">
  ### 帖子事件
</div>

| 事件 | 描述 |
|:------|:------------|
| `deleted` | 帖子被用户删除 |
| `bounced` | 帖子未通过合规性检查 |
| `protected` | 账号变为受保护状态 |
| `suspended` | 账号被暂停使用 |
| `scrub_geo` | 地理位置信息被移除 |

<div id="user-events">
  ### 用户事件
</div>

| Event | Description |
|:------|:------------|
| `deleted` | 账户已被删除 |
| `suspended` | 账户已被封禁 |
| `protected` | 账户已被设为受保护 |
| `deactivated` | 账户已被停用 |

***

<div id="example-create-a-job">
  ## 示例：创建作业
</div>

```bash
curl -X POST "https://api.x.com/2/compliance/jobs" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "tweets",
    "name": "my-compliance-job"
  }'
```
