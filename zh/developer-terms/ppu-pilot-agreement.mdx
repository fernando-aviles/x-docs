I. **定义**。

在本协议中，以下定义适用：

1. **“点数（Credits）”**是指你购买的虚拟单位，用于使用付费服务；每次 API 调用或操作将根据价格表扣减相应数量的点数。除法律要求外，点数不可退款、不可转让，且除非另有说明，否则不会过期。

2\. **“开发者网站（Developer Site）”**是指位于 [**https://developer.x.com**](https://developer.x.com/) 的 X 开发者网站。

3\. **“私信（Direct Message）”**是指用户通过 X 的私信功能，在 X 应用程序上由一名用户发送给一名或多名特定其他用户的私密消息。

4\. **“知识产权（Intellectual Property Rights）”**是指在全球范围内的所有著作权、精神权利、专利权、商标权以及任何其他知识产权或类似权利（无论已注册或未注册）。

5\. **“许可材料（Licensed Material）”**是指单独或统称的 X API 和 X 内容（X Content）。

6\. **“付费服务（Paid Service(s)）”**是指许可材料中，你通过扣减从 X 购买的点数而访问的功能或特性，并根据你对调用和功能的使用情况从你的账户中扣减，具体如我们的定价页面所述。除非本协议另有规定，对“许可材料”的所有提及均意在包含付费服务。

7\. **“支付门户（Payment Portal）”**是指向你提供的在线门户，用于选择使用许可材料、管理用于付费服务的点数购买、管理付费服务的付款方式、启用“自动充值”（参见第 VII.F 节）并更新账户信息。

8\. **“服务（Services）”**是指你的服务、网站、应用程序和其他产品（包括研究），这些产品展示 X 内容或以其他方式使用许可材料。

9\. **“帖子（Post）”**是指通过 X 应用程序分发的短文本和多媒体消息。

10\. **“价格表（Pricing Schedule）”**是指每次 API 调用或操作的当前价格列表，可在 [https://console.x.com/pricing](https://console.x.com/pricing) 获取，X 可在通知后对其进行更新。

11\. **“X”** 指以下主体：(a) 如果你的主要营业地点不在欧盟、欧洲自由贸易联盟（EFTA）国家和英国，则为 X Corp.（865 FM 1209, Building 2, Bastrop, TX 78602, USA）；或 (b) 如果你的主要营业地点在欧盟、欧洲自由贸易联盟（EFTA）国家或英国，则为 X Internet Unlimited Company（One Cumberland Place, Fenian Street, Dublin 2, D02 AX07, Ireland）。

12\. **“X API”** 指 X 应用程序编程接口（每一项为 “API”）、软件开发工具包（每一项为 “SDK”），以及 X 通过 Developer Site 向你提供的相关工具、文档、数据、技术、代码和其他材料。

13\. **“X Applications”** 指 X 的实时信息服务，通常称为 “X”，包括 X 目前通过其网站以及 X 所有、运营或控制的移动应用程序、社交插件和应用程序编程接口所提供的相关服务。

14\. **“X Content”** 指帖子、为每个帖子生成的唯一标识号码、X 终端用户档案信息，以及通过 X API 或经 X 授权的任何其他方式向你提供的任何其他数据和信息，以及上述内容的任何副本和衍生作品。

15\. **“X Marks”** 指 X 向你提供的、包括通过 Developer Site 向你提供的 X 名称、商标和徽标，仅供你按照本协议使用以表明来源。

16\. **“Users”** 指你的 Services 的访问者、用户或客户。
