**一、定义**

在本协议中，适用以下定义：

1. “**Developer Site**” 指位于 [**https://developer.x.com/**](https://developer.x.com/) 的 X 开发者站点。

2. “**Direct Message**” 指通过 X Applications 的私信功能，由一名用户向一个或多个其他特定用户发送的私密消息。

3. “**Intellectual Property Rights**” 指全球范围内的所有版权、精神权利、专利权、商标权，以及任何其他知识产权或类似权利（无论是否注册）。

4. “**Licensed Material**” 单独或合称指 X API 和 X Content。

5. “**Paid Service(s)**” 指你通过支付周期性费用以获取访问权限的 Licensed Material 的功能或特性，具体适用于相关功能或特性以及本协议的规定。除非本协议另有规定，所有对 “Licensed Material” 的引用均应视为包括 Paid Service(s)。

6. “**Payment Portal**” 指提供给你使用的在线门户，用于选择使用 Licensed Material、管理 Paid Services 的订阅、管理 Paid Services 的付款方式，以及更新账户信息。

7. “**Services**” 指你的服务、网站、应用程序以及其他产品和服务（包括研究），这些产品和服务展示 X Content 或以其他方式使用 Licensed Material。

8. “**Post**” 指通过 X Applications 分发的短文本和多媒体构成的消息。

9. “**X**” 指：(a) 如果你的主要营业地点不在欧盟、EFTA 国家和英国，则指 X Corp.（865 FM 1209, Building 2, Bastrop, TX 78602, USA）；或 (b) 如果你的主要营业地点在欧盟、EFTA 国家或英国，则指 X Internet Unlimited Company（One Cumberland Place, Fenian Street, Dublin 2, D02 AX07, Ireland）。

10. “**X API**” 指 X 应用程序编程接口（每一个为 **“API”**）、软件开发工具包（每一个为 **“SDK”**），以及 X 通过 Developer Site 向你提供的相关工具、文档、数据、技术、代码和其他材料。

11. “**X Applications**” 指 X 的实时信息服务，通常称为 “X”，包括 X 当前通过其网站以及 X 所拥有、运营或控制的移动应用、社交插件和应用程序编程接口所提供的服务。

12. “**X Content**” 指帖子、为每条帖子生成的唯一识别号码、X 终端用户的个人资料信息，以及通过 X API 或由 X 授权的任何其他方式向你提供的任何其他数据和信息，以及其任何副本和衍生作品。

14. “**Users**” 指你的 Services 的访问者、用户或客户。
