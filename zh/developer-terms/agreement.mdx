**I. 定义**

在本协议中，适用以下定义：

1. “**Developer Site**” 是指位于 [**https://developer.x.com/**](https://developer.x.com/) 的 X 开发者网站。

2. “**Direct Message**” 是指一名用户通过 X 的私信功能在 X Applications 上发送给一个或多个其他特定用户的私密消息。

3. “**Intellectual Property Rights**” 是指在全球范围内的所有版权、精神权利、专利权、商标权，以及任何其他知识产权或类似权利（无论是否注册）。

4. “**Licensed Material**” 是指单独或合称的 X API 和 X Content。

5. “**Paid Service(s)**” 是指你为获取访问权限而按期支付费用的 Licensed Material 的相关功能或特性（具体视相关功能或特性以及本协议的规定而定）。除非本协议另有规定，对 “Licensed Material” 的所有提及均应包括 Paid Service(s)。

6. “**Payment Portal**” 是指提供给你使用的在线门户，用于选择使用 Licensed Material、管理 Paid Service(s) 的订阅、管理 Paid Service(s) 的付款方式，以及更新账户信息。

7. “**Services**” 是指你的服务、网站、应用程序和其他产品（包括研究），这些服务、网站、应用程序和其他产品展示 X Content 或以其他方式使用 Licensed Material。

8. “**Post**” 是指通过 X Applications 分发的短文本和多媒体形式的帖子。

9. “**X**” 是指：(a) 如果你的主要营业地位于欧盟、EFTA 国家和英国之外，则为 X Corp.（865 FM 1209, Building 2, Bastrop, TX 78602, USA）；或 (b) 如果你的主要营业地位于欧盟、EFTA 国家或英国，则为 X Internet Unlimited Company（One Cumberland Place, Fenian Street, Dublin 2, D02 AX07, Ireland）。

10. “**X API**” 是指 X Application Programming Interfaces（每一个为 **“API”**）、Software Development Kits（每一个为 **“SDK”**），以及 X 通过 Developer Site 向你提供的相关工具、文档、数据、技术、代码和其他材料。

11. “**X Applications**” 是指 X 的实时信息服务，通常称为 “X”，其中包括当前由 X 通过其网站以及 X 拥有、运营或控制的移动应用程序、社交插件和应用程序编程接口所提供的服务。

12. “**X Content**” 是指帖子、为每条帖子生成的唯一标识号码、X 终端用户的个人资料信息，以及通过 X API 或由 X 授权的任何其他方式向你提供的任何其他数据和信息，以及上述任何内容的任何副本和衍生作品。

13. “**X Marks**” 是指 X 向你提供的 X 名称、商标和标识（包括通过 Developer Site 提供），且仅可按照本协议使用。

14. “**Users**” 是指你的 Services 的访问者、用户或客户。
