  ### 1. 引言；适用范围；各项产品条款。
</div>

**1.1 引言。** X 维护、运营并提供一系列产品和服务，使 X 的广告合作伙伴能够实现多种功能。用于实现或与这些功能相关的具体产品、服务和项目（各称为“**单项产品（Individual Product）**”）包括：(i) X Ads API Program（详见[附件 A](#Exhibit-A)）；以及 (ii) X 的 Custom Audiences Program（详见[附件 B](#Exhibit-B)）。上述单项产品在本协议中统称为“**广告产品（Ads Products）**”。本协议规范对广告产品整体以及各单项产品分别的使用和/或访问。此外，在公司就本协议项下所涵盖的某一广告产品参与 X Marketing Partner（“**TMP**”）项目的范围内，[附件 C](#Exhibit-C) 中载明的条款和条件应适用于公司。

**1.2 适用范围。** 在遵守本协议的前提下，在本协议期限内，公司可以访问和使用 X 已授予或向公司提供访问权限的特定单项产品。公司没有义务使用 X 已授予或向公司提供访问权限的任何或全部单项产品，且 X 亦无义务向公司提供（或继续提供）对任何特定单项产品或广告产品任何功能的使用和/或访问。X 可在其全权酌情决定的任何时间，授予或拒绝对任何特定单项产品或其任何功能的使用和/或访问。在公司访问或使用广告产品任何功能的范围内，本协议的条款将规范该等访问或使用。为免生疑义，本协议仅规范公司对本协议所述广告产品的使用。公司根据一份单独协议和/或在一项单独 X 项目项下，由 X 直接或间接向公司提供的任何数据、内容或其他材料的访问和使用，应完全受该等单独协议和/或项目的条款与条件（而非本协议的条款与条件）所规范，除非 X 与公司另行书面共同约定。

**1.3 各项产品条款。** 每一单项产品可能包含特定条款与条件，在不限制本协议条款且作为对本协议条款补充的前提下，只要公司访问或使用该单项产品，该等特定条款与条件即适用。公司访问任何特定单项产品和/或相关 X Materials（如下所定义）的前提，是公司接受并遵守各项产品条款，以及与访问、调用次数和单项产品使用相关的任何技术限制。各项产品条款作为[附件 A](#Exhibit-A)和[附件 B](#Exhibit-B)附于本协议。X 可依其全权酌情决定，按照下文第 15.15 条之规定，制定并修改该等单项产品相关政策或条款。

<div id="2-definitions">
  ### 2. 定义。
</div>

**2.1** “**Campaign**” 指桌面端、移动网站或移动应用程序的广告活动，或其任何部分。

**2.2** “**Client**” 指使用一项（1）或多项 Ads Products，并在每种情形下均经 X 批准的 X 广告主（同时也是 Company 的客户）。

**2.3** “**Company Marks**” 指 Company 的名称，以及 Company 向 X 提供以供在本协议项下使用的任何 Company 标志、商标和/或服务标记（或以其他方式授权 X 在本协议项下使用的此类标志、商标和/或服务标记）。

**2.4** “**Company Materials**” 指 Company 通过 Ads Products 向 X 提供的任何 Company 数据、交付成果或用户内容。

**2.5** “**Company Service**” 指展示或以其他方式使用 X Materials 或其任何方面的 Company 网站、应用程序及其他产品或服务。

**2.6** “**Data**” 指 X 向 Company 提供的指标、数据以及任何其他信息和/或内容，包括通过分析或使用上述任何一项（汇总或其他形式）而得出的任何结果、使用统计数据、数据或其他信息。

**2.7** “**End Users**” 指代表该 Client 使用 Ads Products 的该 Client 的员工或授权代理人。

**2.8** “**Marks**” 指 X Marks 和/或 Company Marks，视具体情况而定（基于上下文）。

**2.9** “**Materials**” 指 X Materials 和/或 Company Materials，视具体情况而定（基于上下文）。

**2.10** “**Personal Data**” 指与在世自然人有关的、该自然人已被识别或可被识别的数据，该等识别可单独通过数据本身，或将该数据与由数据控制者持有或可能取得的其他信息相结合而实现。

**2.11** “**X Ads**” 指 X 的广告产品和服务，包括在 X Network 上投放广告。

**2.12** “**X Code**” 指由 X 开发并提供给 Company 的、至少会调用 X 服务器的计算机代码。

**2.13** “**X Marks**” 指 X 的名称，以及 X 向 Company 提供以供在本协议项下使用的任何 X 标志、商标和/或服务标记（或以其他方式授权 Company 在本协议项下使用的此类标志、商标和/或服务标记）。

**2.14** “**X Materials**” 指由 X 生成的任何 X 数据、交付成果或用户内容（包括其衍生物），以及任何由 X 生成、收集或开发的 X 数据、交付成果或用户内容（包括其衍生物），或 X 根据本协议向 Company 提供或向其提供或开放使用的此类内容，包括任何源自于、基于或因 Company 与 X 的合作伙伴关系而产生的任何数据，或任何设备级数据，或 Company 或任何经 X 批准的第三方从 Company 的 X 广告活动中或与其相关而收集、推断、衍生或获得的任何转化、互动、跟踪或定向数据。为避免疑义且不作任何限制，“X Materials” 包括 `X Ads API`（定义见[附件 A](#Exhibit-A)）、X Code、Data、Ads Products，以及用于创建 Custom Audience（定义见下文）的任何 X 用户 ID。

**2.15** “**X Network**” 指 X 可以通过其分发广告的广告渠道网络，包括所有形式的媒体、应用程序和设备，不论是当前已知的媒介，还是将来开发的媒介。

**2.16** “**X Marketing Partners Program**” 指由 X 提供的合作与品牌计划，如[附件 C](#Exhibit-C)中作进一步描述。

**2.17** “**X Service**” 指：（i）由 X 运营的实时内容和信息服务；（ii）支持此类服务的技术和系统，其包括（统称）X 当前在其网站上提供的面向消费者和广告客户的产品和服务，以及 X 拥有、运营和/或控制的移动应用程序、社交插件和 API，包括但不限于 Measurement Code、任何 HTML 标签或其他代码、互联网门户、仪表板、系统和分析工具及相关服务；以及（iii）由 X 及其 Affiliates 提供的所有其他产品或服务，包括（但不限于且仅为示例）X Audience Platform 和 Data &amp; Enterprise Solutions。
