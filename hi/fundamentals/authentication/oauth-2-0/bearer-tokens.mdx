<div id="using-and-generating-an-app-only-bearer-token">
  ### ऐप-ओनली बेयरर टोकन का उपयोग और जनरेट करना
</div>

बेयरर टोकन डेवलपरों को X API का उपयोग करने के लिए एक अधिक सुरक्षित एंट्री पॉइंट देता है, और यह OAuth 2.0 की मुख्य सुविधाओं में से एक है। 

बेयरर टोकन का उपयोग करने वाले प्रमाणीकरण को application-only authentication भी कहा जाता है। बेयरर टोकन अनिर्दिष्ट फ़ॉर्मैट का एक बाइट ऐरे होता है, जिसे आप `curl` कमांड जैसी किसी स्क्रिप्ट से जनरेट करते हैं। आप अपने ऐप की settings के keys and tokens section में, डेवलपर कंसोल से भी बेयरर टोकन प्राप्त कर सकते हैं। इस सुविधा के बारे में अधिक जानकारी [OAuth के आधिकारिक दस्तावेज़](https://oauth.net/2/bearer-tokens/) में मिल सकती है।

<div id="when-are-they-used">
  #### इनका उपयोग कब किया जाता है?
</div>

जिन उत्पादों के लिए बेयरर टोकन का उपयोग आवश्यक है, वे निम्नलिखित हैं:

* [Engagement API](/hi/x-api/enterprise-gnip-2.0/fundamentals/engagement-api)
* [Account Activity API](/hi/x-api/enterprise-gnip-2.0/fundamentals/account-activity)
* अन्य API जो OAuth 2.0 बेयरर टोकन प्रमाणीकरण का उपयोग करते हैं, जैसे v2 और Labs endpoint.

<div id="prerequisites">
  #### पूर्वापेक्षाएँ
</div>

आपको एक [डेवलपर खाता](https://developer.x.com/en/portal/petition/essential/basic-info) के लिए साइन अप करना होगा और एक [X ऐप](/hi/resources/fundamentals/developer-apps) बनाना होगा। इसके बाद, आपको [डेवलपर कंसोल](/hi/resources/fundamentals/developer-portal) में उपलब्ध API keys भी प्राप्त करनी होंगी। नीचे दिए गए चरणों का पालन करें:

1. developer.x.com पर अपने X खाते में लॉग इन करें।
2. [X App dashboard](https://developer.x.com/content/developer-twitter/en/apps) पर जाएँ और वह X ऐप खोलें, जिसके लिए आप access tokens जनरेट करना चाहते हैं।
3. &quot;keys and tokens&quot; पेज पर जाएँ।
4. इस पेज पर आपको API keys, user Access Tokens, और बेयरर टोकन मिलेंगे।

<div id="how-to-generate-a-bearer-token">
  ### बेयरर टोकन जनरेट करने का तरीका
</div>

आप अपने ऐप का बेयरर टोकन अपनी बाकी &quot;Keys and Tokens&quot; के साथ पा सकते हैं।

पहले से प्राप्त अपने [X ऐप](/hi/resources/fundamentals/developer-apps) की निम्न consumer API keys में बदलाव करने के बाद, नीचे दिया गया cURL अनुरोध अपनी कमांड लाइन में कॉपी करें। ध्यान दें कि इस पेज पर इस्तेमाल की गई consumer API keys को निष्क्रिय कर दिया गया है और वे वास्तविक अनुरोधों के लिए काम नहीं करेंगी।

* **API key** `<API key>` उदाहरण: `xvz1evFS4wEEPTGEFPHBog`
* **API secret key** `<API secret key>` उदाहरण: `L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg`

  ```bash
  curl -u "$API_KEY:$API_SECRET_KEY" \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
  ```

यहाँ एक उदाहरण दिया गया है कि आपकी API keys दर्ज करने के बाद curl अनुरोध कैसा दिखना चाहिए:

```bash
   curl -u 'xvz1evFS4wEEPTGEFPHBog:L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg' \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
```

रिस्पॉन्स कुछ ऐसा दिखाई देगा। ध्यान दें कि यह एक निष्क्रिय किया गया बेयरर टोकन है:

`{"token_type":"bearer","access_token":"AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F"}`

OAuth 2.0 का उपयोग करके रिसोर्सेस के लिए प्रमाणीकृत करने हेतु हमारा बेयरर टोकन यह होगा:

`AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F`
