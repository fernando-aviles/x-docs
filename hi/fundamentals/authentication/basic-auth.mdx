<div id="basic-authentication">
  ## बेसिक प्रमाणीकरण
</div>

X के कई enterprise APIs में HTTP बेसिक प्रमाणीकरण का उपयोग आवश्यक है। किसी ऐसे API को सफलतापूर्वक अनुरोध भेजने के लिए, जिसमें बेसिक प्रमाणीकरण आवश्यक हो, आपको हर अनुरोध के लिए authorization header में एक मान्य ईमेल पता और पासवर्ड का संयोजन भेजना होगा। ईमेल और पासवर्ड का यह संयोजन वही होता है जिसका उपयोग आप [enterprise API console](https://console.gnip.com/) तक पहुंचने के लिए करते हैं, और इसे इसी console के भीतर से संपादित किया जा सकता है। 

बेसिक प्रमाणीकरण का उपयोग करके अनुरोध बनाते समय, सुनिश्चित करें कि आप HTTPS पर encoded credentials के साथ Authentication: Basic HTTP header जोड़ें।

नीचे दिए गए cURL अनुरोध उदाहरण में, अनुरोध भेजने से पहले आपको `<email_address>` और `<password>` को अपने credentials से बदलना होगा:

```bash
curl -v --compressed -u<email_address>:<password>
    "https://gnip-api.x.com/search/30day/accounts/<account-name>/prod/counts.json?query=from%3Axdevelopers"
```
