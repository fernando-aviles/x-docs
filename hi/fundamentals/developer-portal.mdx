[डेवलपर कंसोल](https://console.x.com) X API ऐक्सेस प्रबंधित करने के लिए आपका केंद्रीय हब है। ऐप्स बनाएं, क्रेडेंशियल जनरेट करें, उपयोग की निगरानी करें, और बिलिंग प्रबंधित करें—सब कुछ एक ही जगह पर।

<div id="getting-started">
  ## शुरुआत करें
</div>

<Steps>
  <Step title="डेवलपर खाते के लिए साइन अप करें">
    [console.x.com](https://console.x.com) पर जाएँ और अपने X खाते से साइन इन करें। Developer Agreement स्वीकार करें।
  </Step>

  <Step title="अपना पहला ऐप बनाएँ">
    **New App** पर क्लिक करें और एक नाम व विवरण दें। इससे आपके API क्रेडेंशियल जनरेट हो जाते हैं।
  </Step>

  <Step title="अपने क्रेडेंशियल्स सहेजें">
    अपनी API Key, API Secret और Access Tokens को कॉपी करें और सुरक्षित रूप से सहेजें। इन्हें दोबारा नहीं दिखाया जाएगा।
  </Step>

  <Step title="बनाना शुरू करें">
    API अनुरोधों का प्रमाणीकरण करने के लिए अपने क्रेडेंशियल्स का उपयोग करें। [त्वरित शुरुआत मार्गदर्शिका](/hi/x-api/getting-started/make-your-first-request) देखें।
  </Step>
</Steps>

<Warning>
  **क्रेडेंशियल्स को सुरक्षित रूप से सहेजें।** API keys और tokens जनरेट होने पर केवल एक बार दिखाए जाते हैं। किसी password manager या सुरक्षित vault का उपयोग करें। अगर ये खो जाएँ, तो आपको इन्हें फिर से जनरेट करना होगा, जिससे पुराने क्रेडेंशियल्स अमान्य हो जाएँगे।
</Warning>

<div id="billing-credits">
  ## बिलिंग और क्रेडिट
</div>

X API क्रेडिट-आधारित सिस्टम के साथ उपयोग के अनुसार मूल्य निर्धारण मॉडल का उपयोग करता है:

| सुविधा                            | विवरण                                                                                |
| :-------------------------------- | :----------------------------------------------------------------------------------- |
| **कोई मासिक शुल्क नहीं**          | सिर्फ़ उतने का भुगतान करें, जितना आप इस्तेमाल करते हैं—कोई सदस्यता नहीं              |
| **क्रेडिट-आधारित**                | पहले से क्रेडिट खरीदें; API इस्तेमाल करने पर उनसे कटौती होती जाती है                 |
| **रीयल-टाइम ट्रैकिंग**            | कंसोल डैशबोर्ड में उपयोग और लागत की निगरानी करें                                     |
| **प्रति-एंडपॉइंट मूल्य निर्धारण** | अलग-अलग एंडपॉइंट की लागत अलग-अलग होती है                                             |
| **डिडुप्लिकेशन**                  | 24 घंटे के भीतर एक ही संसाधन का दो बार अनुरोध करने पर केवल एक बार शुल्क लिया जाता है |

वर्तमान मूल्य देखें और [डेवलपर कंसोल](https://console.x.com) में क्रेडिट खरीदें।

[मूल्य निर्धारण के बारे में और जानें →](/hi/x-api/getting-started/pricing)

<div id="team-management">
  ## टीम प्रबंधन
</div>

<Note>
  टीम प्रबंधन केवल **Enterprise खातों** के लिए उपलब्ध है।
</Note>

Enterprise खाते सहयोग के लिए टीम सदस्यों को आमंत्रित कर सकते हैं:

| Role              | Capabilities                                                   |
| :---------------- | :------------------------------------------------------------- |
| **Administrator** | पूर्ण एक्सेस: ऐप्स, बिलिंग, टीम सदस्यों और भूमिकाओं का प्रबंधन |
| **Developer**     | अपने ऐप्स का प्रबंधन, टीम ऐप्स के लिए केवल-पढ़ने की एक्सेस     |

किसी टीम सदस्य को आमंत्रित करने के लिए, अपने कंसोल में Team पेज पर जाएँ और उनका X हैंडल दर्ज करें।
