रेट लिमिट्स यह निर्धारित करती हैं कि आप किसी निश्चित समयावधि में कितने API अनुरोध कर सकते हैं। ये पूरे प्लेटफ़ॉर्म पर निष्पक्ष उपयोग और सिस्टम की स्थिरता सुनिश्चित करती हैं।

***

</div>

हर X API उत्पाद के लिए रेट लिमिटिंग का अपना तरीका होता है:

  <Card title="X API v2" icon="square-x-twitter" href="/hi/x-api/fundamentals/rate-limits">

  </Card>
</CardGroup>

<div id="how-rate-limits-work">
  ## रेट लिमिट्स कैसे काम करती हैं
</div>

| अवधारणा                      | विवरण                                                             |
| :--------------------------- | :---------------------------------------------------------------- |
| **समय विंडो**                | अधिकांश लिमिट्स हर 15 मिनट में रीसेट हो जाती हैं                  |
| **प्रति-उपयोगकर्ता लिमिट्स** | OAuth 1.0a या OAuth 2.0 यूज़र टोकन का उपयोग करने पर लागू होती हैं |
| **प्रति-ऐप लिमिट्स**         | बेयरर टोकन (केवल-ऐप) प्रमाणीकरण का उपयोग करने पर लागू होती हैं    |
| **एंडपॉइंट-विशिष्ट**         | हर एंडपॉइंट की अपनी लिमिट होती है                                 |

<div id="checking-your-limits">
  ## अपनी रेट लिमिट जाँचें
</div>

हर API रिस्पॉन्स में ऐसे हेडर होते हैं, जो आपकी मौजूदा रेट लिमिट स्थिति दिखाते हैं:

```
x-rate-limit-limit: 900
x-rate-limit-remaining: 847
x-rate-limit-reset: 1705420800
```

| हेडर                    | विवरण                                             |
| :----------------------- | :------------------------------------------------ |
| `x-rate-limit-limit`     | वर्तमान विंडो में अनुमत अनुरोधों की अधिकतम संख्या |
| `x-rate-limit-remaining` | वर्तमान विंडो में बचे हुए अनुरोध                  |
| `x-rate-limit-reset`     | सीमा रीसेट होने का Unix timestamp                 |

***

<div id="rate-limit-errors">
  ## रेट लिमिट त्रुटियाँ
</div>

जब आप रेट लिमिट पार कर जाते हैं, तो आपको **429 Too Many Requests** रिस्पॉन्स मिलेगा:

```json
{
  "errors": [{
    "code": 88,
    "message": "Rate limit exceeded"
  }]
}
```
