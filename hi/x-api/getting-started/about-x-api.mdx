X API, X पर होने वाली सार्वजनिक बातचीत तक प्रोग्रामेटिक एक्सेस प्रदान करता है। पोस्ट्स प्राप्त करें, ट्रेंड्स का विश्लेषण करें, इंटीग्रेशन बनाएँ, और प्लेटफ़ॉर्म पर नए अनुभव बनाएँ।

***

<div id="what-you-can-do">
  ## आप क्या कर सकते हैं
</div>

| क्षमता                            | विवरण                                                            |
| :-------------------------------- | :--------------------------------------------------------------- |
| **पोस्ट्स पढ़ें**                 | पोस्ट्स को खोजें, प्राप्त करें, और रीयल-टाइम में स्ट्रीम करें    |
| **सामग्री प्रकाशित करें**         | पोस्ट्स, जवाब, और थ्रेड्स बनाएँ                                  |
| **उपयोगकर्ताओं को प्रबंधित करें** | उपयोगकर्ताओं को खोजें, और फ़ॉलो, ब्लॉक, व म्यूट प्रबंधित करें    |
| **डेटा का विश्लेषण करें**         | मेट्रिक्स, ट्रेंड्स, और एंगेजमेंट एनालिटिक्स तक पहुँचें          |
| **इंटीग्रेशन बनाएँ**              | DMs भेजें, सूचियाँ प्रबंधित करें, और Spaces के साथ इंटरैक्ट करें |

***

<div id="api-versions">
  ## API संस्करण
</div>

<Tabs>
  <Tab title="X API v2 (अनुशंसित)">
    आधुनिक सुविधाओं और लचीले मूल्य निर्धारण के साथ X API का वर्तमान संस्करण।

    **v2 का उपयोग क्यों करें:**

    * उपयोग के आधार पर मूल्य निर्धारण—कोई मासिक सीमा नहीं
    * आधुनिक JSON रिस्पॉन्स फ़ॉर्मैट
    * लचीले [फ़ील्ड्स](/hi/x-api/fundamentals/fields) और [expansions](/hi/x-api/fundamentals/expansions)
    * उन्नत सुविधाएँ: annotations, conversation tracking, edit history
    * सभी नए एंडपॉइंट्स और सुविधाएँ

    **शुरू करने का तरीका:**

    1. [console.x.com](https://console.x.com) पर साइन अप करें
    2. एक ऐप बनाएँ और क्रेडेंशियल्स प्राप्त करें
    3. [अपना पहला अनुरोध करें](/hi/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1 (लीगेसी)">
    X API का पिछला संस्करण। सीमित समर्थन उपलब्ध है; नई परियोजनाओं के लिए v2 का उपयोग करें।

    **अब भी उपलब्ध:**

    * कुछ मीडिया अपलोड एंडपॉइंट्स
    * लीगेसी स्ट्रीमिंग (deprecated)
    * कुछ विशेष एंडपॉइंट्स

    **v2 पर माइग्रेट करना:**
    एंडपॉइंट मैपिंग और डेटा फ़ॉर्मैट में बदलावों के लिए [migration guide](/hi/x-api/migrate/overview) देखें।
  </Tab>

  <Tab title="Enterprise">
    उन्नत आवश्यकताओं वाले व्यवसायों के लिए उच्च-वॉल्यूम एक्सेस।

    **सुविधाएँ:**

    * पूर्ण firehose एक्सेस
    * ऐतिहासिक डेटा बैकफिल
    * समर्पित सहायता
    * कस्टम रेट लिमिट्स
    * compliance streams

    [Enterprise सेल्स से संपर्क करें →](/hi/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

<div id="v2-highlights">
  ## v2 की मुख्य विशेषताएं
</div>

<Accordion title="फ़ील्ड्स और expansions">
  केवल उतना ही डेटा अनुरोध करें, जितनी आपको आवश्यकता है। खास एट्रिब्यूट चुनने के लिए `fields` पैरामीटर का उपयोग करें और संबंधित ऑब्जेक्ट्स शामिल करने के लिए `expansions` का उपयोग करें।

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [फ़ील्ड्स के बारे में और जानें →](/hi/x-api/fundamentals/fields)
</Accordion>

<Accordion title="पोस्ट एनोटेशंस">
  पोस्ट्स में लोगों, स्थानों, उत्पादों और विषयों की पहचान करने वाले सिमैंटिक एनोटेशंस शामिल होते हैं। विषय के आधार पर स्ट्रीम्स और खोज को फ़िल्टर करें।

  [एनोटेशंस के बारे में और जानें →](/hi/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="एंगेजमेंट मेट्रिक्स">
  अपनी पोस्ट्स के लिए सार्वजनिक मेट्रिक्स (लाइक्स, रीपोस्ट्स, रिप्लाई) और निजी मेट्रिक्स (इम्प्रेशंस, क्लिक) ऐक्सेस करें।

  [मेट्रिक्स के बारे में और जानें →](/hi/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="वार्तालाप ट्रैकिंग">
  `conversation_id` का उपयोग करके पूरे वार्तालाप थ्रेड को पुनर्निर्मित करें। पूरे थ्रेड में रिप्लाई को ट्रैक करें।

  [वार्तालाप ट्रैकिंग के बारे में और जानें →](/hi/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="संपादन इतिहास">
  पोस्ट्स के संपादन इतिहास को ऐक्सेस करें, जिसमें सभी पिछले वर्शन और संपादन मेटाडेटा शामिल हैं।

  [पोस्ट्स को संपादित करने के बारे में और जानें →](/hi/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## मूल्य निर्धारण
</div>

X API v2 में **पे-पर-यूज़** मूल्य निर्धारण का उपयोग होता है:

| लाभ                    | विवरण                                                                                 |
| :--------------------- | :------------------------------------------------------------------------------------ |
| **कोई सदस्यता नहीं**   | केवल जितना उपयोग करें, उतना ही भुगतान करें                                            |
| **कोई सीमा नहीं**      | जितनी ज़रूरत हो, उतना उपयोग करें                                                      |
| **क्रेडिट-आधारित**     | क्रेडिट खरीदें; प्रत्येक अनुरोध पर क्रेडिट काटे जाते हैं                              |
| **रीयल-टाइम ट्रैकिंग** | डेवलपर कंसोल में उपयोग की निगरानी करें                                                |
| **डिडुप्लिकेशन**       | 24 घंटों के भीतर एक ही संसाधन का दो बार अनुरोध करने पर केवल एक बार शुल्क लिया जाता है |

[मूल्य निर्धारण का विवरण देखें →](/hi/x-api/getting-started/pricing)
