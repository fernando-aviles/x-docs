<div id="deduplication">
  ## डिडुप्लिकेशन
</div>

सभी संसाधनों का डिडुप्लिकेशन **UTC के 24-घंटे के दिन की विंडो** के भीतर किया जाता है। यदि आप किसी संसाधन (जैसे किसी पोस्ट) का अनुरोध करते हैं और उसके लिए आपसे शुल्क लिया जाता है, तो उस विंडो के भीतर उसी संसाधन का दोबारा अनुरोध करने पर अतिरिक्त शुल्क नहीं लगेगा।

इसका मतलब है:

* एक ही पोस्ट का एक दिन में कई बार अनुरोध करना केवल एक शुल्क के रूप में गिना जाता है
* डिडुप्लिकेशन विंडो UTC में मध्यरात्रि पर रीसेट हो जाती है
* यह सभी बिल योग्य संसाधनों (पोस्ट्स, उपयोगकर्ताओं आदि) पर लागू होता है

<Note>
  डिडुप्लिकेशन एक **सॉफ्ट गारंटी** है। हालांकि, यह अधिकांश मामलों में लागू होता है, लेकिन सेवा बाधाओं जैसे कुछ विशेष एज केस में संसाधनों का डिडुप्लिकेशन नहीं हो सकता।
</Note>

<div id="credit-balance">
  ## क्रेडिट बैलेंस
</div>

आपका क्रेडिट बैलेंस डेवलपर कंसोल में दिखाया जाता है। API अनुरोध करने पर क्रेडिट रीयल-टाइम में कटते हैं।

<Warning>
  सेवा में रुकावट से बचने के लिए अपने क्रेडिट बैलेंस की नियमित रूप से निगरानी करें। निर्बाध API एक्सेस सुनिश्चित करने के लिए बैलेंस शून्य होने से पहले क्रेडिट जोड़ें।

  ***नोट:** किसी खाते का क्रेडिट बैलेंस थोड़ा नकारात्मक हो सकता है। ऐसी स्थिति में, नकारात्मक बैलेंस की भरपाई के लिए क्रेडिट जोड़ने तक API अनुरोध ब्लॉक रहेंगे।*
</Warning>

<div id="auto-recharge">
  ### ऑटो-रीचार्ज
</div>

अपने क्रेडिट बैलेंस को अपने-आप रिचार्ज करने और सेवा में रुकावटों से बचने के लिए ऑटो-रीचार्ज सक्षम करें। इसे डेवलपर कंसोल में कॉन्फ़िगर करें:

| Setting               | Description                                                                           |
| :-------------------- | :------------------------------------------------------------------------------------ |
| **रीचार्ज राशि**      | ऑटो-रीचार्ज ट्रिगर होने पर जोड़ी जाने वाली राशि (उदा., $25)                           |
| **ट्रिगर थ्रेशहोल्ड** | जब आपका बैलेंस इस राशि से नीचे आ जाता है, तो ऑटो-रीचार्ज सक्रिय हो जाता है (उदा., $5) |

<Note>
  ऑटो-रीचार्ज के लिए डिफ़ॉल्ट के रूप में सेट की गई सहेजी हुई भुगतान विधि आवश्यक है। आप इसे कभी भी डेवलपर कंसोल में या सहायता टीम से संपर्क करके रद्द कर सकते हैं।
</Note>

<div id="spending-limits">
  ### खर्च सीमा
</div>

लागत नियंत्रित करने के लिए प्रति बिलिंग चक्र अपनी अधिकतम खर्च राशि तय करें। यह सीमा पूरी होते ही, अगले बिलिंग चक्र तक API अनुरोध ब्लॉक कर दिए जाएँगे।

| विकल्प        | विवरण                                                                  |
| :------------ | :--------------------------------------------------------------------- |
| **खर्च सीमा** | प्रति बिलिंग चक्र अपने अधिकतम खर्च के लिए एक निश्चित डॉलर राशि तय करें |

<Tip>
  अनपेक्षित शुल्कों से बचने के लिए खर्च सीमा का उपयोग करें, खासकर डेवलपमेंट और टेस्टिंग के दौरान।
</Tip>

<div id="monitoring-usage">
  ## उपयोग की निगरानी
</div>

[Usage endpoint](/hi/x-api/usage/introduction) के साथ अपने API उपयोग को प्रोग्रामेटिक रूप से ट्रैक करें:

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

यह दैनिक पोस्ट खपत की संख्या दिखाता है, जिससे आप यह कर सकते हैं:

* अपने बजट के मुकाबले खपत को ट्रैक करें
* सीमाओं के करीब पहुँचने पर अलर्ट सेट करें
* अधिक खपत वाले एंडपॉइंट्स की पहचान करें
* उपयोग रिपोर्ट तैयार करें
