<div id="response-structure">
  ### रिस्पॉन्स की संरचना
</div>

सभी v2 रिस्पॉन्स इसी संरचना का पालन करते हैं:

```json
{
  "data": { ... },      // प्राथमिक ऑब्जेक्ट(s)
  "includes": { ... },  // विस्तारित ऑब्जेक्ट (यदि अनुरोध किया गया हो)
  "meta": { ... },      // पेजिनेशन जानकारी
  "errors": [ ... ]     // आंशिक त्रुटियाँ (यदि कोई हों)
}
```

<div id="common-parameters">
  ### सामान्य पैरामीटर
</div>

| पैरामीटर           | उपयोग                                      |
| :----------------- | :----------------------------------------- |
| `tweet.fields`     | विशिष्ट पोस्ट फ़ील्ड्स का अनुरोध करें      |
| `user.fields`      | विशिष्ट उपयोगकर्ता फ़ील्ड्स का अनुरोध करें |
| `expansions`       | संबंधित ऑब्जेक्ट्स शामिल करें              |
| `max_results`      | प्रति पृष्ठ परिणामों की सीमा तय करें       |
| `pagination_token` | अगला/पिछला पृष्ठ प्राप्त करें              |

<div id="authentication-methods">
  ### प्रमाणीकरण के तरीके
</div>

| तरीका      | उपयोग                                              |
| :--------- | :------------------------------------------------- |
| बेयरर टोकन | सिर्फ़-पढ़ने योग्य सार्वजनिक डेटा                  |
| OAuth 2.0  | सूक्ष्म-स्तरीय स्कोप के साथ उपयोगकर्ता कार्रवाइयाँ |
| OAuth 1.0a | उपयोगकर्ता कार्रवाइयाँ (लीगेसी, पूर्ण अनुमतियाँ)   |
