<div id="comparing-x-apis-list-members-endpoints">
  ## X API के सूची सदस्य एंडपॉइंट्स की तुलना
</div>

v2 सूची सदस्य एंडपॉइंट्स का समूह, मानक v1.1 [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members), [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships), [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) और [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) एंडपॉइंट्स का स्थान लेगा। यदि आपके पास ऐसा कोड, ऐप्स या टूल हैं जो इन सूची सदस्य एंडपॉइंट्स के किसी एक संस्करण का उपयोग करते हैं और आप नए X API v2 एंडपॉइंट पर माइग्रेट करने पर विचार कर रहे हैं, तो यह गाइड्स का सेट आपके लिए है। 

<div id="list-members-lookup">
  ### सूची सदस्यों का लुकअप
</div>

v2 के सूची सदस्य लुकअप एंडपॉइंट्स, मानक  [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members), [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships) एंडपॉइंट्स का स्थान लेंगे।

निम्न तालिकाएं मानक v1.1 और X API v2 सूची एंडपॉइंट्स की तुलना करती हैं:

**सूची सदस्य लुकअप**

|                                                                    |                                                                                          |                                                                                                                                              |
| :----------------------------------------------------------------- | :--------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| विवरण                                                              | मानक v1.1                                                                                | X API v2                                                                                                                                     |
| समर्थित HTTP मेथड्स                                                | `GET`                                                                                    | `GET`                                                                                                                                        |
| होस्ट डोमेन                                                        | `https://api.x.com`                                                                      | `https://api.x.com`                                                                                                                          |
| एंडपॉइंट पाथ                                                       | `/1.1/lists/members.json`                                                                | `/2/lists/:id/members`                                                                                                                       |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)               | OAuth 1.0a User Context<br /><br />केवल ऐप                                               | OAuth 1.0a User Context<br /><br />PKCE के साथ OAuth 2.0 Authorization Code<br /><br />केवल ऐप                                               |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits) | OAuth 1.0a के साथ 15 मिनट में 900 अनुरोध<br /><br />केवल ऐप के साथ 15 मिनट में 75 अनुरोध | OAuth 1.0a के साथ 15 मिनट में 900 अनुरोध<br /><br />OAuth 2.0 के साथ 15 मिनट में 900 अनुरोध<br /><br />केवल ऐप के साथ 15 मिनट में 900 अनुरोध |

**सूची सदस्यता लुकअप**

|                                                                    |                                                                                         |                                                                                                                                           |
| :----------------------------------------------------------------- | :-------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------- |
| विवरण                                                              | मानक v1.1                                                                               | X API v2                                                                                                                                  |
| समर्थित HTTP मेथड्स                                                | `GET`                                                                                   | `GET`                                                                                                                                     |
| होस्ट डोमेन                                                        | `https://api.x.com`                                                                     | `https://api.x.com`                                                                                                                       |
| एंडपॉइंट पाथ                                                       | `/1.1/lists/memberships.json`                                                           | `/2/users/:id/list_memberships`                                                                                                           |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)               | OAuth 1.0a User Context<br /><br />केवल ऐप                                              | OAuth 1.0a User Context<br /><br />PKCE के साथ OAuth 2.0 Authorization Code<br /><br />केवल ऐप                                            |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits) | OAuth 1.0a के साथ 15 मिनट में 75 अनुरोध<br /><br />केवल ऐप के साथ 15 मिनट में 75 अनुरोध | OAuth 1.0a के साथ 15 मिनट में 75 अनुरोध<br /><br />OAuth 2.0 के साथ 15 मिनट में 75 अनुरोध<br /><br />केवल ऐप के साथ 15 मिनट में 75 अनुरोध |

<div id="manage-list-members">
  ### सूची सदस्यों को प्रबंधित करना
</div>

v2 के सूची सदस्य प्रबंधन एंडपॉइंट्स, मानक [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) और [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) एंडपॉइंट्स का स्थान लेंगे।

निम्न तालिकाएँ मानक v1.1 और X API v2 सूची एंडपॉइंट्स की तुलना करती हैं:

**सदस्य जोड़ें**

| विवरण                                                              | मानक v1.1                      | X API v2                                                                  |
| :----------------------------------------------------------------- | :----------------------------- | :------------------------------------------------------------------------ |
| समर्थित HTTP मेथड                                                  | POST                           | POST                                                                      |
| होस्ट डोमेन                                                        | https://api.x.com              | https://api.x.com                                                         |
| एंडपॉइंट पाथ                                                       | /1.1/lists/members/create.json | /2/lists/:id/members                                                      |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)               | OAuth 1.0a User Context        | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits) | कोई नहीं                       | प्रति 15 मिनट 300 अनुरोध (प्रति उपयोगकर्ता)                               |

**सदस्य हटाएँ**

| विवरण                                                              | मानक v1.1                       | X API v2                                                                  |
| :----------------------------------------------------------------- | :------------------------------ | :------------------------------------------------------------------------ |
| समर्थित HTTP मेथड                                                  | POST                            | DELETE                                                                    |
| होस्ट डोमेन                                                        | https://api.x.com               | https://api.x.com                                                         |
| एंडपॉइंट पाथ                                                       | /1.1/lists/members/destroy.json | /2/lists/:id/:user&#95;id                                                 |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)               | OAuth 1.0a User Context         | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits) | कोई नहीं                        | प्रति 15 मिनट 300 अनुरोध (प्रति उपयोगकर्ता)                               |

X API v2 एंडपॉइंट्स तक पहुँचने के लिए, आपको [डेवलपर खाते के लिए साइन अप करना](https://developer.x.com/en/portal/petition/essential/basic-info) होगा। प्रमाणीकरण करते समय, आपको एक [डेवलपर ऐप](/hi/resources/fundamentals/developer-apps) से keys और tokens का उपयोग करना होगा, जो किसी [प्रोजेक्ट](/hi/resources/fundamentals/developer-apps) के भीतर स्थित हो। 

X API v2 एंडपॉइंट्स का एक्सेस पाने के बारे में अधिक जानने के लिए हमारा [शुरुआत करना](/hi/x-api/getting-started/getting-access) पेज देखें।
