<div id="manage-list-members-standard-v11-compared-to-x-api-v2">
  ### सूची सदस्यों का प्रबंधन: Standard v1.1 की X API v2 से तुलना
</div>

यदि आप standard v1.1 के [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) और [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) एंडपॉइंट्स का उपयोग कर रहे हैं, तो इस गाइड का उद्देश्य standard v1.1 और X API v2 के सूची सदस्यों को प्रबंधित करने वाले एंडपॉइंट्स के बीच की समानताओं और अंतरों को समझने में आपकी मदद करना है।

* **समानताएँ**
  * प्रमाणीकरण
* **अंतर**
  * एंडपॉइंट URLs
  * ऐप और प्रोजेक्ट आवश्यकताएँ
  * HTTP मेथड्स
  * रेट लिमिट्स
  * अनुरोध पैरामीटर

<div id="similarities">
  #### समानताएँ
</div>

**प्रमाणीकरण**

दोनों एंडपॉइंट संस्करण [OAuth 1.0a उपयोगकर्ता संदर्भ](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication) का समर्थन करते हैं। इसलिए, यदि आप पहले मानक v1.1 सूची सदस्य प्रबंधन एंडपॉइंट में से किसी एक का उपयोग कर रहे थे, तो X API v2 संस्करण पर migrate करने के बाद भी आप उसी प्रमाणीकरण विधि का उपयोग जारी रख सकते हैं।

<div id="differences">
  #### अंतर
</div>

**एंडपॉइंट URL**

* Standard v1.1 एंडपॉइंट:
  * POST https://api.x.com/1.1/lists/members/create.json
    (निर्दिष्ट सूची में एक सदस्य जोड़ता है)
  * POST https://api.x.com/1.1/lists/members/destroy.json
    (निर्दिष्ट सूची से एक सदस्य हटाता है)
* X API v2 एंडपॉइंट:
  * POST https://api.x.com/2/lists/:id/members
    (निर्दिष्ट सूची में एक सदस्य जोड़ता है)

  * DELETE https://api.x.com/2/lists/:id/members/:user&#95;id
    (निर्दिष्ट सूची से एक सदस्य हटाता है)

**रेट लिमिट्स**

| **Standard v1.1**                                   | **X API v2**                                                                                                                                                                                               |
| :-------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| /1.1/lists/members/create.json<br /><br />कोई नहीं  | /2/lists/:id/members<br /><br />OAuth 1.0a उपयोगकर्ता संदर्भ के साथ हर 15-मिनट की विंडो में 300 अनुरोध<br /><br />OAuth 2.0 Authorization Code with PKCE के साथ हर 15-मिनट की विंडो में 300 अनुरोध              |
| /1.1/lists/members/destroy.json<br /><br />कोई नहीं | /2/lists/:id/members/:user&#95;id<br /><br />OAuth 1.0a उपयोगकर्ता संदर्भ के साथ हर 15-मिनट की विंडो में 300 अनुरोध<br /><br />OAuth 2.0 Authorization Code with PKCE के साथ हर 15-मिनट की विंडो में 300 अनुरोध |

**ऐप और प्रोजेक्ट आवश्यकताएँ**

X API v2 एंडपॉइंट्स के लिए यह आवश्यक है कि आप अपने अनुरोधों को प्रमाणित करते समय ऐसे [developer ऐप](/hi/resources/fundamentals/developer-apps) के क्रेडेंशियल्स का उपयोग करें, जो किसी [प्रोजेक्ट](/hi/resources/fundamentals/developer-apps) से संबद्ध हो। सभी X API v1.1 एंडपॉइंट्स, ऐप्स या किसी प्रोजेक्ट से संबंधित ऐप्स के क्रेडेंशियल्स का उपयोग कर सकते हैं।

**अनुरोध पैरामीटर**

निम्नलिखित Standard v1.1 अनुरोध पैरामीटर के X API v2 में समकक्ष हैं:

| **Standard v1.1**         | **X API v2**    |
| :------------------------ | :-------------- |
| list&#95;id               | id              |
| slug                      | कोई समकक्ष नहीं |
| screen&#95;name           | कोई समकक्ष नहीं |
| owner&#95;screen&#95;name | कोई समकक्ष नहीं |
| owner&#95;id              | कोई समकक्ष नहीं |
