इस पेज में सूची एंडपॉइंट्स को इंटीग्रेट करने के लिए उपयोगी टूल और मुख्य अवधारणाओं के बारे में बताया गया है।

***

<div id="helpful-tools">
  ## उपयोगी टूल
</div>

इस एंडपॉइंट को इंटीग्रेट करने में मदद करने वाली कुछ प्रमुख अवधारणाओं पर जाने से पहले, हमारा सुझाव है कि आप इनसे परिचित हो जाएँ:

<div id="postman">
  #### Postman
</div>

Postman एक बेहतरीन टूल है, जिसका उपयोग आप किसी एंडपॉइंट को टेस्ट करने के लिए कर सकते हैं। हर Postman अनुरोध में सभी path और body पैरामीटर शामिल होते हैं, ताकि आप जल्दी से समझ सकें कि आपके लिए क्या उपलब्ध है। हमारी Postman collections के बारे में अधिक जानने के लिए, कृपया हमारा [&quot;Postman का उपयोग करना&quot;](/hi/tutorials/postman-getting-started) पेज देखें।

<div id="code-samples">
  #### कोड नमूने
</div>

क्या आप अपनी पसंदीदा कोडिंग भाषा में कुछ कोड के साथ इस एंडपॉइंट को सेट अप करना चाहते हैं? हमारे [Github page](https://github.com/xdevplatform/Twitter-API-v2-sample-code) पर कई अलग-अलग कोड नमूने उपलब्ध हैं, जिन्हें आप शुरुआती बिंदु के रूप में इस्तेमाल कर सकते हैं।

<div id="third-party-libraries">
  #### तृतीय-पक्ष लाइब्रेरी
</div>

शुरुआत करने में मदद के लिए हमारे समुदाय की [तृतीय-पक्ष लाइब्रेरी](/hi/x-api/tools-and-libraries/overview) में से किसी एक का उपयोग करें। सही version tag देखकर आप ऐसी लाइब्रेरी ढूँढ़ सकते हैं जो v2 एंडपॉइंट्स के साथ काम करती हो।

<div id="key-concepts">
  ### मुख्य अवधारणाएँ
</div>

<div id="authentication">
  #### प्रमाणीकरण
</div>

सभी X API v2 एंडपॉइंट के लिए यह आवश्यक है कि आप अपने अनुरोधों को क्रेडेंशियल्स के एक सेट से प्रमाणित करें, जिन्हें keys और tokens भी कहा जाता है।

इन विशेष एंडपॉइंट के लिए [OAuth 1.0a User Context](/hi/resources/fundamentals/authentication) का उपयोग आवश्यक है, यानी सफल अनुरोध करने के लिए आपको API keys और उपयोगकर्ता एक्सेस टोकन के एक सेट का उपयोग करना होगा। Access Tokens उस उपयोगकर्ता से संबद्ध होने चाहिए, जिसकी ओर से आप अनुरोध कर रहे हैं। अगर आप किसी दूसरे उपयोगकर्ता के लिए Access Tokens का एक सेट जनरेट करना चाहते हैं, तो उसे [3-legged OAuth flow](/hi/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) का उपयोग करके आपके ऐप को अधिकृत या प्रमाणित करना होगा।

कृपया ध्यान दें कि OAuth 1.0a का उपयोग करना थोड़ा जटिल हो सकता है। अगर आप इस प्रमाणीकरण विधि से परिचित नहीं हैं, तो हम सलाह देते हैं कि अपने अनुरोधों को सही तरीके से प्रमाणित करने के लिए आप किसी [लाइब्रेरी](/hi/x-api/tools-and-libraries/overview) या Postman जैसे टूल का उपयोग करें।

<div id="developer-console-projects-and-developer-apps">
  #### डेवलपर कंसोल, प्रोजेक्ट, और डेवलपर ऐप्स
</div>

X API v2 एंडपॉइंट्स के साथ काम करने वाले प्रमाणीकरण क्रेडेंशियल्स का एक सेट प्राप्त करने के लिए, आपको [डेवलपर खाते के लिए साइन अप](https://developer.x.com/en/portal/petition/essential/basic-info) करना होगा, उस खाते के भीतर एक [प्रोजेक्ट](/hi/resources/fundamentals/developer-apps) सेट अप करना होगा, और उस प्रोजेक्ट के भीतर एक [डेवलपर ऐप](/hi/resources/fundamentals/developer-apps) बनाना होगा। इसके बाद, आप अपने डेवलपर ऐप में अपनी कुंजियाँ और टोकन पा सकते हैं।

<div id="rate-limits">
  #### रेट लिमिट्स
</div>

हर दिन, हज़ारों डेवलपर X API को अनुरोध भेजते हैं। इन अनुरोधों की बहुत अधिक संख्या को प्रबंधित करने में मदद के लिए, प्रत्येक एंडपॉइंट पर [रेट लिमिट्स](/hi/x-api/fundamentals/rate-limits) लागू की जाती हैं, जो उन अनुरोधों की संख्या सीमित करती हैं जिन्हें आप अपने ऐप की ओर से या किसी प्रमाणीकृत उपयोगकर्ता की ओर से कर सकते हैं।

इन एंडपॉइंट्स पर उपयोगकर्ता-स्तर की रेट लिमिट्स लागू होती हैं। इसका मतलब है कि जिस प्रमाणीकृत उपयोगकर्ता की ओर से आप अनुरोध कर रहे हैं, वह किसी भी डेवलपर ऐप में इस एंडपॉइंट को केवल एक निश्चित संख्या में ही कॉल कर सकता है।

नीचे दी गई तालिका प्रत्येक एंडपॉइंट के लिए रेट लिमिट्स दिखाती है।

|              |               |                        |
| :----------- | :------------ | :--------------------- |
| **एंडपॉइंट** | **HTTP विधि** | **रेट लिमिट**          |
| /2/lists     | POST          | 15 मिनट में 300 अनुरोध |
| /2/lists/:id | DELETE / PUT  | 15 मिनट में 300 अनुरोध |

<div id="create-a-list">
  #### सूची बनाएँ
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/lists" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"name": "My List", "description": "A list of interesting accounts"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # नई सूची बनाएँ
  response = client.lists.create(
      name="My List",
      description="A list of interesting accounts"
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // नई सूची बनाएँ
  const response = await client.lists.create({
    name: "My List",
    description: "A list of interesting accounts",
  });
  console.log(response.data);
  ```
</CodeGroup>
