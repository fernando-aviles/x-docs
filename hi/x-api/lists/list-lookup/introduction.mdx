सूची खोज एंडपॉइंट आपको सूचियों के बारे में जानकारी प्राप्त करने की सुविधा देते हैं। id द्वारा किसी विशिष्ट सूची को खोजें या किसी उपयोगकर्ता के स्वामित्व वाली सभी सूचियाँ प्राप्त करें।

<div id="endpoints">
  ## एंडपॉइंट
</div>

| Method | Endpoint                                                   | Description                                       |
| :----- | :--------------------------------------------------------- | :------------------------------------------------ |
| GET    | [`/2/lists/:id`](/hi/x-api/lists/get-list-by-id)              | id द्वारा सूची प्राप्त करें                       |
| GET    | [`/2/users/:id/owned_lists`](/hi/x-api/users/get-owned-lists) | उपयोगकर्ता के स्वामित्व वाली सूचियाँ प्राप्त करें |

***

<div id="response-fields">
  ## रिस्पॉन्स फ़ील्ड्स
</div>

डिफ़ॉल्ट रूप से, रिस्पॉन्स में `id` और `name` शामिल होते हैं। अतिरिक्त फ़ील्ड्स का अनुरोध करें:

| फ़ील्ड           | विवरण                   |
| :--------------- | :---------------------- |
| `description`    | सूची का विवरण           |
| `owner_id`       | स्वामी की उपयोगकर्ता ID |
| `private`        | क्या सूची निजी है       |
| `follower_count` | फ़ॉलोअर्स की संख्या     |
| `member_count`   | सदस्यों की संख्या       |
| `created_at`     | सूची बनने की तारीख      |

<div id="example-request">
  ### उदाहरण अनुरोध
</div>

```bash
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id,member_count,follower_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
