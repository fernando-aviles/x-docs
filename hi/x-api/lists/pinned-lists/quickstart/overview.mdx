पिन की गई सूचियों के एंडपॉइंट आपको किसी उपयोगकर्ता की पिन की गई सूचियां देखने और यह प्रबंधित करने की सुविधा देते हैं कि कौन-सी सूचियां पिन की गई हैं।

<Note>
  **पूर्वापेक्षाएँ**

  शुरू करने से पहले, आपको इनकी आवश्यकता होगी:

  * स्वीकृत ऐप वाला एक [डेवलपर खाता](https://developer.x.com/en/portal/petition/essential/basic-info)
  * उपयोगकर्ता एक्सेस टोकन (OAuth 1.0a या OAuth 2.0 PKCE)
</Note>

<div id="authentication">
  ## प्रमाणीकरण
</div>

| Operation                 | Authentication               |
| :------------------------ | :--------------------------- |
| पिन की गई सूचियाँ देखें   | OAuth 1.0a or OAuth 2.0 PKCE |
| सूचियों को पिन/अनपिन करें | OAuth 1.0a or OAuth 2.0 PKCE |

<Warning>
  लुकअप और प्रबंधन, दोनों कार्रवाइयों के लिए उपयोगकर्ता संदर्भ प्रमाणीकरण आवश्यक है। केवल-ऐप (बेयरर टोकन) प्रमाणीकरण समर्थित नहीं है।
</Warning>

<div id="quick-example">
  ## त्वरित उदाहरण
</div>

<CodeGroup dropdown>
  ```bash cURL
  # पिन की गई सूचियाँ प्राप्त करें
  curl "https://api.x.com/2/users/2244994945/pinned_lists" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # पिन की गई सूचियाँ प्राप्त करें
  response = client.lists.get_pinned("2244994945")

  for lst in response.data:
      print(f"{lst.name}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // पिन की गई सूचियाँ प्राप्त करें
  const response = await client.lists.getPinned("2244994945");

  response.data?.forEach((lst) => {
    console.log(lst.name);
  });
  ```
</CodeGroup>
