<div id="endpoint">
  ## एंडपॉइंट
</div>

| विधि | एंडपॉइंट                       | विवरण                            |
| :--- | :----------------------------- | :------------------------------- |
| GET  | `/2/users/personalized_trends` | वैयक्तिकृत ट्रेंड्स प्राप्त करें |

***

<div id="example-request">
  ## उदाहरण अनुरोध
</div>

```bash
curl "https://api.x.com/2/users/personalized_trends" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-response">
  ## रिस्पॉन्स का उदाहरण

```json
    {

      "tweet_count": 85000
    }
  ]
}
```
