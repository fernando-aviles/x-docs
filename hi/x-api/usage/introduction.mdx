Usage endpoint आपको अपने API उपयोग की निगरानी करने देता है, जिसमें उपभोग किए गए पोस्ट्स की संख्या भी शामिल है। लागत प्रबंधित करने और सीमाओं के भीतर रहने के लिए अपने उपयोग को प्रोग्रामेटिक तरीके से ट्रैक करें।

<div id="endpoint">
  ## एंडपॉइंट
</div>

| विधि | एंडपॉइंट                                    | विवरण                         |
| :--- | :------------------------------------------ | :---------------------------- |
| GET  | [`/2/usage/tweets`](/hi/x-api/usage/get-usage) | पोस्ट उपयोग डेटा प्राप्त करें |

***

<div id="response-data">
  ## प्रतिक्रिया डेटा
</div>

रिस्पॉन्स में प्रतिदिन की पोस्ट खपत की संख्याएँ शामिल हैं:

```json
{
  "data": {
    "daily_project_usage": [
      {
        "date": "2024-01-15",
        "usage": [
          {
            "app_id": "12345678",
            "tweets_consumed": 15420
          }
        ]
      }
    ],
    "project_id": "1234567890",
    "project_cap": 10000000
  }
}
```

<div id="fields">
  ### फ़ील्ड्स
</div>

| फ़ील्ड                | विवरण                        |
| :-------------------- | :--------------------------- |
| `daily_project_usage` | दैनिक उपयोग डेटा की सूची     |
| `date`                | YYYY-MM-DD प्रारूप में तारीख |
| `app_id`              | आपके ऐप का ID                |
| `tweets_consumed`     | उस दिन उपभोग किए गए पोस्ट्स  |
| `project_cap`         | आपकी मासिक पोस्ट सीमा        |

***

<div id="example-request">
  ## उदाहरण अनुरोध
</div>

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="use-cases">
  ## उपयोग परिदृश्य
</div>

* **लागत निगरानी** — अपनी योजना की सीमाओं के अनुरूप खपत पर नज़र रखें
* **अलर्ट** — सीमाओं के करीब पहुँचने पर अलर्ट सेट करें
* **अनुकूलन** — अधिक खपत वाले एंडपॉइंट की पहचान करें
* **रिपोर्टिंग** — उपयोग रिपोर्ट तैयार करें

<Tip>
  24-घंटे की UTC विंडो के भीतर संसाधनों को डुप्लिकेट नहीं गिना जाता, इसलिए दिन में एक ही संसाधन के लिए कई बार अनुरोध करने पर भी केवल एक ही शुल्क लगता है। [कीमत के बारे में और जानें →](/hi/x-api/getting-started/pricing)
</Tip>
