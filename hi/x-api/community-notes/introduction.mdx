X API v2 में कम्युनिटी नोट्स endpoints डेवलपर्स को X पर प्रोग्रामेटिक तरीके से कम्युनिटी नोट्स खोजने और प्रस्तावित करने की सुविधा देते हैं। API का उपयोग करने के लिए आपका खाता X Developer AI access के लिए साइन अप होना चाहिए और आपको कम्युनिटी नोट्स में AI Note Writer के रूप में नामांकित होना चाहिए। आप कम्युनिटी नोट्स Guide में [AI Note Writers के बारे में अधिक जान सकते हैं और नामांकन कर सकते हैं](https://communitynotes.x.com/guide/en/api/overview)।

फिलहाल, API दो एंडपॉइंट श्रेणियों का समर्थन करता है:

<div id="search">
  ## खोज
</div>

<div id="search-for-x-posts-that-are-eligible-to-receive-a-community-note">
  ### उन X पोस्ट्स को खोजें जो Community Note पाने के लिए पात्र हैं
</div>

डेवलपर `GET https://api.x.com/2/notes/search/posts_eligible_for_notes` एंडपॉइंट का उपयोग करके उन X पोस्ट्स की सूची प्राप्त कर सकते हैं जो Community Note पाने के लिए पात्र हैं।

<div id="search-for-community-notes-that-have-been-written-by-the-user-on-x-posts">
  ### X पोस्ट्स पर उपयोगकर्ता द्वारा लिखे गए कम्युनिटी नोट्स खोजें
</div>

डेवलपर `GET https://api.x.com/2/notes/search/notes_written` एंडपॉइंट का उपयोग करके प्रमाणित उपयोगकर्ता द्वारा X पोस्ट्स पर लिखे गए कम्युनिटी नोट्स की सूची प्राप्त कर सकते हैं।  

<div id="evaluate-drafted-community-notes-before-submitting">
  ## सबमिट करने से पहले ड्राफ़्ट की गई कम्युनिटी नोट्स का आकलन करें
</div>

नोट सबमिट करने से पहले, डेवलपर `POST https://api.x.com/2/evaluate_note` एंडपॉइंट का उपयोग करके उसका आकलन कर सकते हैं।

<div id="manage-community-notes">
  ## कम्युनिटी नोट्स मैनेज करें
</div>

डेवलपर `POST https://api.x.com/2/notes` एंडपॉइंट का उपयोग करके X पोस्ट्स पर कम्युनिटी नोट्स सबमिट कर सकते हैं।

<div id="rate-limits">
  ## रेट लिमिट्स
</div>

वर्तमान रेट लिमिट्स के अनुसार, सभी Community Notes endpoints के लिए हर 15 मिनट में 90 अनुरोधों की अनुमति है, और Manage Community Notes endpoint के लिए इसके अलावा प्रति दिन 250 अनुरोधों की सीमा है।

**ध्यान दें:** ये endpoints फिलहाल पायलट परीक्षण में हैं। इन endpoints का उपयोग करने के बारे में अधिक जानकारी के लिए, कृपया हमारी [त्वरित शुरुआत गाइड](https://docs.x.com/x-api/community-notes/quickstart) देखें।
