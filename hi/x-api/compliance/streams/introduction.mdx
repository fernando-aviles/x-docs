X, डेवलपर्स के हमारे उस समुदाय के प्रति प्रतिबद्ध है जो X API के साथ निर्माण करता है। इस प्रतिबद्धता के तहत, हमारा लक्ष्य अपने API को डेवलपर्स के लिए खुला और निष्पक्ष, X पर लोगों के लिए सुरक्षित, और समग्र रूप से X प्लेटफ़ॉर्म के लिए लाभकारी बनाना है। यह बेहद ज़रूरी है कि X सामग्री को ऑफ़लाइन संग्रहीत करने वाला कोई भी डेवलपर यह सुनिश्चित करे कि डेटा, उपयोगकर्ता की मंशा और X पर सामग्री की मौजूदा स्थिति को सही रूप से दर्शाए। उदाहरण के लिए, जब X पर कोई व्यक्ति कोई पोस्ट हटाता है, अपना खाता हटाता है, अपनी पोस्ट्स को सुरक्षित करता है, या किसी पोस्ट को संपादित करता है, तो उस व्यक्ति की अपेक्षाओं और मंशा का सम्मान करना X और हमारे डेवलपर्स—दोनों के लिए बेहद महत्वपूर्ण है।

अनुपालन इवेंट्स की रीयल-टाइम स्ट्रीम्स डेवलपर्स को ऐसे टूल्स देती हैं, जिनकी मदद से वे X डेटा को [X Developer Agreement and Policy](https://developer.x.com/en/developer-terms/policy) के अनुरूप बनाए रख सकते हैं. 

दो c&#95;ompliance event&#95; streams हैं, एक Post&#95; compliance&#95; events के लिए, और एक *User compliance* events के लिए। ये streams Enterprise access के साथ उपलब्ध हैं और उन पार्टनर्स की मदद के लिए बनाई गई हैं जो बड़ी मात्रा में डेटा इनजेस्ट करते हैं, ताकि वे पोस्ट संपादन इवेंट्स जैसे अनुपालन इवेंट्स के लिए &#39;सुन&#39; सकें।

ये streams निम्नलिखित इवेंट्स प्रदान करती हैं: 

**पोस्ट अनुपालन स्ट्रीम: **

* delete - यह दर्शाता है कि पोस्ट हटा दी गई थी।

* tweet&#95;edit - यह दर्शाता है कि किसी पोस्ट को संपादित किया गया है और अपडेट की गई पोस्ट की ID प्रदान करता है। 

* withheld - यह दर्शाता है कि पोस्ट को एक या अधिक देशों में रोक दिया गया है। 

* drop - यह दर्शाता है कि पोस्ट को सार्वजनिक दृश्य से हटा दिया जाना चाहिए।

* undrop - यह दर्शाता है कि पोस्ट को फिर से दिखाया जा सकता है और उसे सार्वजनिक माना जा सकता है।

**उपयोगकर्ता अनुपालन स्ट्रीम: **

* **user&#95;delete** - यह दर्शाता है कि उपयोगकर्ता खाता हटा दिया गया था

* **user&#95;undelete** - यह दर्शाता है कि उपयोगकर्ता खाते को फिर से बहाल किया गया था

* **user&#95;protect** - यह दर्शाता है कि उपयोगकर्ता खाता निजी हो गया

* **user&#95;unprotect** - यह दर्शाता है कि उपयोगकर्ता खाता सार्वजनिक हो गया

* **user&#95;withheld** - यह दर्शाता है कि उपयोगकर्ता खाते को एक या अधिक देशों में रोक दिया गया है। 

* **user&#95;suspend** - यह दर्शाता है कि उपयोगकर्ता खाता निलंबित कर दिया गया था

* **user&#95;unsuspend** - यह दर्शाता है कि उपयोगकर्ता खाते से निलंबन हटा दिया गया था

* **user&#95;profile&#95;modification** - यह दर्शाता है कि उपयोगकर्ता प्रोफ़ाइल अपडेट की गई है। इसमें अपडेट किया गया विवरण, नाम, स्थान, और URL शामिल हैं।

**खाता सेटअप**

इन endpoints तक पहुँचने के लिए, आपको इनकी आवश्यकता होगी:

* एक स्वीकृत [डेवलपर खाता](https://developer.x.com/en/portal/petition/essential/basic-info)।
* एक [डेवलपर ऐप](/hi/resources/fundamentals/developer-apps) से प्राप्त keys और tokens का उपयोग करके प्रमाणित करना, जो एक [Project](/hi/resources/fundamentals/developer-apps) के भीतर स्थित हो। 

X API v2 endpoints तक पहुँच पाने के बारे में अधिक जानने के लिए हमारी [getting started guide](/hi/x-api/getting-started/getting-access) देखें।
