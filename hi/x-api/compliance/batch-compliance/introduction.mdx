बैच अनुपालन एंडपॉइंट्स आपको पोस्ट IDs या यूज़र IDs के डेटासेट अपलोड करने और उनकी वर्तमान अनुपालन स्थिति प्राप्त करने की सुविधा देते हैं। हटाई गई पोस्ट्स, निलंबित खातों और अन्य अनुपालन घटनाओं की पहचान करने के लिए इसका उपयोग करें।

<div id="how-it-works">
  ## यह कैसे काम करता है
</div>

1. **एक जॉब बनाएं** — type (पोस्ट्स या उपयोगकर्ता) और अपलोड URL निर्दिष्ट करें
2. **IDs अपलोड करें** — अपने डेटासेट को दिए गए URL पर अपलोड करें
3. **प्रोसेसिंग की प्रतीक्षा करें** — जॉब असिंक्रोनस रूप से प्रोसेस होती है
4. **परिणाम डाउनलोड करें** — प्रत्येक ID की अनुपालन स्थिति प्राप्त करें

***

<div id="endpoints">
  ## एंडपॉइंट्स
</div>

| Method | Endpoint                                                               | Description                    |
| :----- | :--------------------------------------------------------------------- | :----------------------------- |
| POST   | [`/2/compliance/jobs`](/hi/x-api/compliance/create-compliance-job)        | नई अनुपालन जॉब बनाएँ         |
| GET    | [`/2/compliance/jobs/:id`](/hi/x-api/compliance/get-compliance-job-by-id) | जॉब की स्थिति प्राप्त करें     |
| GET    | [`/2/compliance/jobs`](/hi/x-api/compliance/get-compliance-jobs)          | सभी जॉब्स की सूची प्राप्त करें |

<div id="job-types">
  ## जॉब के प्रकार
</div>

| प्रकार   | विवरण                               |
| :------- | :---------------------------------- |
| `tweets` | पोस्ट की अनुपालन स्थिति जाँचें      |
| `users`  | उपयोगकर्ता की अनुपालन स्थिति जाँचें |

***

<div id="compliance-events">
  ## अनुपालन इवेंट्स
</div>

<div id="post-events">
  ### पोस्ट इवेंट्स
</div>

| इवेंट       | विवरण                           |
| :---------- | :------------------------------ |
| `deleted`   | पोस्ट को उपयोगकर्ता ने हटा दिया |
| `bounced`   | पोस्ट अनुपालन जांच में विफल रही |
| `protected` | खाता सुरक्षित हो गया            |
| `suspended` | खाते को निलंबित कर दिया गया     |
| `scrub_geo` | भौगोलिक डेटा हटा दिया गया       |

<div id="user-events">
  ### उपयोगकर्ता इवेंट्स
</div>

| इवेंट         | विवरण                      |
| :------------ | :------------------------- |
| `deleted`     | खाता हटा दिया गया          |
| `suspended`   | खाता निलंबित कर दिया गया   |
| `protected`   | खाता संरक्षित हो गया       |
| `deactivated` | खाता निष्क्रिय कर दिया गया |

***

<div id="example-create-a-job">
  ## उदाहरण: जॉब बनाना
</div>

```bash
curl -X POST "https://api.x.com/2/compliance/jobs" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "tweets",
    "name": "my-compliance-job"
  }'
```
