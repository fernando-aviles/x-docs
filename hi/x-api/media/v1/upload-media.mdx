<div id="overview">
  ## अवलोकन
</div>

एक मीडिया ऑब्जेक्ट एकल फ़ोटो, वीडियो या एनिमेटेड GIF को दर्शाता है। मीडिया ऑब्जेक्ट का उपयोग Twitter API के कई endpoints में किया जाता है, और इन्हें Tweets, Direct Messages, उपयोगकर्ता प्रोफ़ाइल, विज्ञापन creatives तथा अन्य स्थानों में शामिल किया जा सकता है। प्रत्येक मीडिया ऑब्जेक्ट के प्रदर्शन या playback के कई variants हो सकते हैं, जिनमें अलग-अलग resolutions या formats होते हैं।

<div id="media-types-size-restrictions">
  ## मीडिया प्रकार और आकार संबंधी सीमाएं
</div>

API के माध्यम से अपलोड करने के लिए आकार संबंधी सीमाएं

* इमेज 5 MB
* GIF 15 MB
* वीडियो 512 MB (media&#95;category=amplify का उपयोग करने पर)

<div id="creation">
  ## निर्माण
</div>

Tweet, Direct Messages, उपयोगकर्ता प्रोफ़ाइल चित्र, होस्ट किए गए Ads कार्ड आदि जैसे ऑब्जेक्ट में एक या अधिक मीडिया ऑब्जेक्ट हो सकते हैं। इन शीर्ष-स्तरीय ऑब्जेक्ट को सामूहिक रूप से entities कहा जाता है। संबंधित entity creation API (उदा. POST statuses/update) को एक अद्वितीय media&#95;id का उपयोग करके एक या अधिक मीडिया ऑब्जेक्ट दिए जा सकते हैं।

मीडिया ऑब्जेक्ट(s) वाली कोई entity निम्न चरणों का पालन करके बनाई जा सकती है:

1. अनुशंसित chunked upload (images/GIF/video) या पुराने simple upload (केवल images) में से किसी एक का उपयोग करके मीडिया फ़ाइल(फ़ाइलें) अपलोड करें।
2. चरण 1 से एक media&#95;id प्राप्त करें। यदि entity में एक से अधिक media&#95;id पैरामीटर भेजने की अनुमति है, तो अलग-अलग मीडिया के साथ यह चरण कई बार दोहराया जा सकता है।
3. media&#95;id और अन्य आवश्यक पैरामीटर शामिल करते हुए, उपयुक्त endpoint को कॉल करके entity बनाएँ। उदाहरण के लिए, POST statuses/update endpoint का उपयोग करके किसी Tweet के साथ media&#95;id संलग्न करें।
