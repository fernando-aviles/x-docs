समाचार लुकअप एंडपॉइंट डेवलपरों को X पर ताज़ा समाचार और सुर्खियाँ प्राप्त करने की सुविधा देता है।

यह एंडपॉइंट OAuth1 और OAuth2 PKCE, दोनों के लिए ऐप-प्रमाणीकरण और उपयोगकर्ता-प्रमाणीकरण का समर्थन करता है।

<div id="getting-started">
  ## शुरुआत करें
</div>

एंडपॉइंट का उपयोग करने के लिए, आपको [बेयरर टोकन](/hi/fundamentals/authentication/oauth-2-0/application-only) की आवश्यकता होगी, जो [डेवलपर कंसोल](https://developer.x.com/en/portal/dashboard) से प्राप्त होता है।

बेयरर टोकन मिल जाने के बाद, आप नीचे दिखाए गए अनुसार news API को कॉल कर सकते हैं:

```bash
curl 'https://api.x.com/2/news/1989418137272422538?news.fields=contexts,cluster_posts_results' --header 'Authorization: Bearer XXXXX'
```
