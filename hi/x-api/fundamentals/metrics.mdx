X API पोस्ट्स और मीडिया के लिए एंगेजमेंट मेट्रिक्स उपलब्ध कराता है। किसी भी ऑथेंटिकेशन के साथ सार्वजनिक मेट्रिक्स ऐक्सेस करें, या यूज़र ऑथेंटिकेशन के साथ अपनी सामग्री के लिए निजी मेट्रिक्स ऐक्सेस करें।

***

<div id="metric-types">
  ## मेट्रिक के प्रकार
</div>

| type              | प्रमाणीकरण        | विवरण                                            |
| :---------------- | :---------------- | :----------------------------------------------- |
| **सार्वजनिक**     | बेयरर टोकन        | किसी को भी दिखाई देने वाले (लाइक, रीपोस्ट, जवाब) |
| **गैर-सार्वजनिक** | उपयोगकर्ता संदर्भ | निजी मेट्रिक्स (इम्प्रेशन, क्लिक)                |
| **ऑर्गैनिक**      | उपयोगकर्ता संदर्भ | गैर-प्रमोटेड व्यूज़ से मिलने वाले मेट्रिक्स      |
| **प्रमोटेड**      | उपयोगकर्ता संदर्भ | विज्ञापन व्यूज़ से मिलने वाले मेट्रिक्स          |

<Note>
  **30-दिन की सीमा**: गैर-सार्वजनिक, ऑर्गैनिक और प्रमोटेड मेट्रिक्स केवल पिछले 30 दिनों के भीतर बनाई गई पोस्ट्स के लिए उपलब्ध हैं।
</Note>

<div id="post-metrics">
  ### पोस्ट मेट्रिक्स
</div>

| मेट्रिक           | type          | फ़ील्ड पथ                                |
| :---------------- | :------------ | :--------------------------------------- |
| रीपोस्ट्स         | सार्वजनिक     | `public_metrics.retweet_count`           |
| कोट्स             | सार्वजनिक     | `public_metrics.quote_count`             |
| लाइक्स            | सार्वजनिक     | `public_metrics.like_count`              |
| रिप्लाईज़         | सार्वजनिक     | `public_metrics.reply_count`             |
| इम्प्रेशन्स       | गैर-सार्वजनिक | `non_public_metrics.impression_count`    |
| URL क्लिक्स       | गैर-सार्वजनिक | `non_public_metrics.url_link_clicks`     |
| प्रोफ़ाइल क्लिक्स | गैर-सार्वजनिक | `non_public_metrics.user_profile_clicks` |

<div id="requesting-metrics">
  ## मेट्रिक्स का अनुरोध
</div>

<div id="public-metrics-any-auth">
  ### सार्वजनिक मेट्रिक्स (किसी भी auth के साथ)
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

रिस्पॉन्स:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "public_metrics": {
      "retweet_count": 50,
      "reply_count": 12,
      "like_count": 234,
      "quote_count": 5
    }
  }
}
```

<div id="private-metrics-user-context">
  ### निजी मेट्रिक्स (उपयोगकर्ता संदर्भ)
</div>

आपकी स्वामित्व वाली पोस्ट्स के लिए OAuth 1.0a या उपयोगकर्ता संदर्भ के साथ OAuth 2.0 आवश्यक है:

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=non_public_metrics,organic_metrics" \
  -H "Authorization: OAuth oauth_consumer_key=...,oauth_token=..."
```

रिस्पॉन्स:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "non_public_metrics": {
      "impression_count": 5432,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    },
    "organic_metrics": {
      "impression_count": 5432,
      "like_count": 234,
      "reply_count": 12,
      "retweet_count": 50,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    }
  }
}
```

<div id="video-metrics">
  ## वीडियो मेट्रिक्स
</div>

वीडियो प्लेबैक मेट्रिक्स के लिए media expansion का उपयोग करें:

```bash
curl "https://api.x.com/2/tweets/1234567890?\
tweet.fields=attachments&\
expansions=attachments.media_keys&\
media.fields=public_metrics,non_public_metrics" \
  -H "Authorization: OAuth ..."
```

रिस्पॉन्स:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Check out this video!",
    "attachments": {
      "media_keys": ["13_9876543210"]
    }
  },
  "includes": {
    "media": [{
      "media_key": "13_9876543210",
      "type": "video",
      "public_metrics": {
        "view_count": 12543
      },
      "non_public_metrics": {
        "playback_0_count": 12543,
        "playback_25_count": 9876,
        "playback_50_count": 7654,
        "playback_75_count": 5432,
        "playback_100_count": 3210
      }
    }]
  }
}
```

<div id="organic-vs-promoted-metrics">
  ## ऑर्गैनिक बनाम प्रमोटेड मेट्रिक्स
</div>

अगर किसी पोस्ट को विज्ञापन के रूप में प्रमोट किया गया हो, तो मेट्रिक्स ऑर्गैनिक और प्रमोटेड व्यूज़ में अलग-अलग विभाजित हो जाते हैं:

| Context       | Description                                      |
| :------------ | :----------------------------------------------- |
| **ऑर्गैनिक**  | सामान्य टाइमलाइन व्यूज़ से मिलने वाले मेट्रिक्स  |
| **प्रमोटेड**  | पेड विज्ञापन इम्प्रेशन्स से मिलने वाले मेट्रिक्स |
| **सार्वजनिक** | कुल संयुक्त संख्या (ऑर्गैनिक + प्रमोटेड)         |

विभाजन देखने के लिए दोनों का अनुरोध करें:

```bash
tweet.fields=public_metrics,organic_metrics,promoted_metrics
```

<div id="metric-definitions">
  ## मेट्रिक परिभाषाएँ
</div>

<Accordion title="इम्प्रेशन">
  पोस्ट उपयोगकर्ता की स्क्रीन पर जितनी बार दिखाई दी, उसकी संख्या। यह यूनीक नहीं है—अगर वही उपयोगकर्ता इसे दो बार देखता है, तो उसे दो इम्प्रेशन माना जाएगा।
</Accordion>

<Accordion title="रीपोस्ट की संख्या">
  रीपोस्ट्स (रीट्वीट्स) की संख्या। इसमें कोट पोस्ट्स शामिल नहीं हैं।
</Accordion>

<Accordion title="कोट की संख्या">
  कोट पोस्ट्स (टिप्पणी के साथ रीपोस्ट) की संख्या। ये हमेशा ऑर्गैनिक होते हैं।
</Accordion>

<Accordion title="वीडियो व्यूज़">
  वीडियो वाले सभी पोस्ट्स में कुल मिलाकर जोड़ा गया। अगर किसी वीडियो को कई पोस्ट्स में रीपोस्ट किया गया है, तो उसका कुल व्यू काउंट एक ही होता है।
</Accordion>

<Accordion title="प्लेबैक क्वार्टाइल्स">
  उन यूनीक उपयोगकर्ताओं की संख्या जिन्होंने वीडियो के हर प्रतिशत स्तर तक चलाकर देखा। ड्रॉप-ऑफ रेट समझने में उपयोगी।
</Accordion>

<div id="requirements-summary">
  ## आवश्यकताओं का सारांश
</div>

| मेट्रिक फ़ील्ड       | आवश्यक प्रमाणीकरण                             |
| :------------------- | :-------------------------------------------- |
| `public_metrics`     | बेयरर टोकन (कोई भी)                           |
| `non_public_metrics` | उपयोगकर्ता संदर्भ (केवल अपनी पोस्ट्स)         |
| `organic_metrics`    | उपयोगकर्ता संदर्भ (केवल अपनी पोस्ट्स)         |
| `promoted_metrics`   | उपयोगकर्ता संदर्भ (केवल प्रमोट की गई पोस्ट्स) |
