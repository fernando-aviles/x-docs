X API v2 में **प्रति-उपयोग** मूल्य निर्धारण लागू होता है। आपसे वास्तविक API उपयोग के आधार पर शुल्क लिया जाता है, जिसे ऐप स्तर पर ट्रैक किया जाता है।

***

<div id="how-billing-works">
  ## बिलिंग कैसे काम करती है
</div>

| अवधारणा                         | विवरण                                                         |
| :------------------------------ | :------------------------------------------------------------ |
| **क्रेडिट-आधारित**              | पहले से क्रेडिट खरीदें; API का उपयोग करने पर वे कटते जाते हैं |
| **प्रति-अनुरोध मूल्य निर्धारण** | अलग-अलग एंडपॉइंट की लागत अलग-अलग होती है                      |
| **रीयल-टाइम ट्रैकिंग**          | डेवलपर कंसोल में उपयोग पर नज़र रखें                           |
| **कोई सीमा नहीं**               | जितनी ज़रूरत हो, उतना उपयोग करें—कोई मासिक सीमा नहीं          |

<div id="deduplication">
  ## डीडुप्लिकेशन
</div>

<Note>
  **दैनिक डीडुप्लिकेशन**: अगर एक ही पोस्ट एक दिन के भीतर कई क्वेरी से लौटती है, तो बिलिंग के लिए उसे केवल एक बार गिना जाता है।
</Note>

इसका मतलब है:

* एक ही पोस्ट को एक दिन में कई बार प्राप्त करना = 1 शुल्क
* अगले दिन उसी पोस्ट को फिर से प्राप्त करना = 1 अतिरिक्त शुल्क
* एक ही अनुरोध में अलग-अलग पोस्ट्स = प्रत्येक को अलग से गिना जाता है

| **लागत ट्रैकिंग**      | रीयल-टाइम लागत गणनाएँ           |
| **क्रेडिट शेष**        | शेष प्रीपेड क्रेडिट             |

<div id="pricing-details">
  ## मूल्य निर्धारण का विवरण
</div>

हर endpoint और operation के लिए मौजूदा मूल्य निर्धारण देखने हेतु [डेवलपर कंसोल](https://console.x.com) पर जाएँ।

मूल्य निर्धारण इनमें से इन कारकों के अनुसार भिन्न हो सकता है:

* Endpoint type (`search` बनाम `lookup` बनाम `stream`)
* Operation (`read` बनाम `write`)
* डेटा का दायरा (हाल का बनाम पूर्ण आर्काइव)

<div id="faqs">
  ## अक्सर पूछे जाने वाले सवाल
</div>

<Accordion title="अगर मेरे क्रेडिट खत्म हो जाएं, तो क्या होगा?">
  जब तक आप और क्रेडिट नहीं खरीदते, API अनुरोध विफल रहेंगे। रुकावट से बचने के लिए बैलेंस अलर्ट सेट करें।
</Accordion>

<Accordion title="क्या कोई मासिक न्यूनतम राशि है?">
  नहीं। आप सिर्फ़ उतने का भुगतान करते हैं, जितना आप इस्तेमाल करते हैं। ऐसे महीने भी हो सकते हैं जिनमें न कोई उपयोग हो, न कोई लागत।
</Accordion>

<Accordion title="स्ट्रीमिंग का बिल कैसे लिया जाता है?">
  फ़िल्टर की गई स्ट्रीम के ज़रिए डिलीवर की गई हर यूनीक पोस्ट उपयोग में गिनी जाती है, जिस पर रोज़ाना डीडुप्लिकेशन लागू होता है।
</Accordion>

<Accordion title="क्या विफल अनुरोध भी गिने जाते हैं?">
  नहीं। केवल वे सफल रिस्पॉन्स, जिनमें डेटा लौटता है, बिल किए जाते हैं।
</Accordion>
