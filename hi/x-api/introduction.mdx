<div id="key-features">
  ## प्रमुख विशेषताएँ
</div>

<Tabs>
  <Tab title="डेटा एक्सेस">
    ### समृद्ध डेटा ऑब्जेक्ट्स

    पोस्ट्स, उपयोगकर्ताओं, मीडिया व अन्य के लिए विस्तृत और संरचित डेटा एक्सेस करें:

    * **पोस्ट्स**: पूरा टेक्स्ट, मेट्रिक्स, एंटिटीज़, एनोटेशंस, बातचीत के थ्रेड्स
    * **Users**: प्रोफ़ाइल, फ़ॉलोअर संख्या, सत्यापन स्थिति
    * **Media**: मेटाडेटा के साथ इमेज, वीडियो, GIFs
    * **Polls**: विकल्प और वोटों की संख्या

    [fields](/hi/x-api/fundamentals/fields) और [expansions](/hi/x-api/fundamentals/expansions) की मदद से responses को अपनी ज़रूरत के मुताबिक़ अनुकूलित करें, ताकि आपको ठीक वही डेटा मिले जिसकी आपको आवश्यकता है।
  </Tab>

  <Tab title="रियल-टाइम स्ट्रीमिंग">
    ### फ़िल्टर्ड स्ट्रीम

    पोस्ट्स को प्रकाशित होते ही रियल-टाइम में पाएं। सिर्फ़ मेल खाने वाले पोस्ट्स पाने के लिए अधिकतम 1,000 फ़िल्टरिंग नियम तय करें।

    ```bash
    # एक नियम जोड़ें
    curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{"add": [{"value": "from:xdevelopers"}]}'

    # स्ट्रीम से कनेक्ट करें
    curl "https://api.x.com/2/tweets/search/stream" \
      -H "Authorization: Bearer $TOKEN"
    ```

    [फ़िल्टर्ड स्ट्रीम के बारे में और जानें →](/hi/x-api/posts/filtered-stream/introduction)
  </Tab>

  <Tab title="खोज और विश्लेषण">
    ### पूर्ण-आर्काइव खोज

    सार्वजनिक पोस्ट्स के पूरे इतिहास में खोजें—2006 तक। उपयोगकर्ताओं, कीवर्ड्स, तारीखों व अन्य के लिए operators के साथ queries बनाएं।

    ```bash
    curl "https://api.x.com/2/tweets/search/all?query=AI%20lang:en" \
      -H "Authorization: Bearer $TOKEN"
    ```

    ### मेट्रिक्स

    impressions, likes, reposts, replies और video views सहित एंगेजमेंट मेट्रिक्स एक्सेस करें।

    [खोज के बारे में और जानें →](/hi/x-api/posts/search/introduction)
  </Tab>
</Tabs>

<div id="api-versions">
  ## API संस्करण
</div>

| संस्करण        | स्थिति  | विवरण                                          |
| :------------- | :------ | :--------------------------------------------- |
| **v2**         | वर्तमान | आधुनिक endpoints, लचीली कीमतें, सभी नई सुविधाएँ |
| **Enterprise** | उपलब्ध  | समर्पित सहायता के साथ उच्च-मात्रा एक्सेस       |

<Tip>
  सभी नई परियोजनाओं के लिए **X API v2** का उपयोग करें। सभी नई सुविधाएँ और सुधार इसी में जारी किए जाते हैं।
</Tip>
