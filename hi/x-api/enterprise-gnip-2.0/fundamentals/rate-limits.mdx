<div id="overview">
  ## अवलोकन
</div>

हर दिन कई हज़ार डेवलपर X API को अनुरोध भेजते हैं। इन अनुरोधों की बहुत अधिक संख्या को प्रबंधित करने के लिए, किए जा सकने वाले अनुरोधों की संख्या पर सीमाएँ लगाई जाती हैं। ये सीमाएँ हमें वह विश्वसनीय और स्केलेबल API उपलब्ध कराने में मदद करती हैं, जिस पर हमारा डेवलपर समुदाय निर्भर करता है। 

अनुमत अनुरोधों की अधिकतम संख्या एक समय अंतराल, यानी किसी निर्दिष्ट अवधि या समय-विंडो, के आधार पर तय होती है। यदि किसी एंडपॉइंट की रेट लिमिट 900 requests/15-minutes है, तो किसी भी 15-मिनट के अंतराल में अधिकतम 900 अनुरोधों की अनुमति होती है।
