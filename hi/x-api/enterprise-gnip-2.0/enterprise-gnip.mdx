हमारे एंटरप्राइज़ APIs, X डेटा पर निर्भर लोगों को पहुँच और विश्वसनीयता का सर्वोच्च स्तर प्रदान करते हैं। यह तब आदर्श है, जब आप premium से आगे बढ़ रहे हों और आपको अधिक विश्वसनीय पहुँच, आपकी ज़रूरतों के अनुरूप पैकेज, या दीर्घकालिक अनुबंधों की आवश्यकता हो। एंटरप्राइज़ API access के साथ समर्पित account managers और व्यक्तिगत तकनीकी सहायता भी मिलती है।

यदि आपने तय कर लिया है कि Basic और Pro समाधान आपकी आवश्यकताओं के लिए पर्याप्त नहीं हैं, तो आप नीचे दिए गए लिंक पर एंटरप्राइज़ products की पहुँच के लिए आवेदन कर सकते हैं:

<div id="important-concepts">
  ## महत्वपूर्ण अवधारणाएँ
</div>

<div id="gnip-console">
  ### Gnip Console
</div>

आप [Gnip Console](/hi/x-api/enterprise-gnip-2.0/fundamentals/overview) के माध्यम से अपने एंटरप्राइज़ प्रोडक्ट्स और अकाउंट ऐक्सेस का प्रबंधन कर सकते हैं। 

<div id="enrichments">
  ### संवर्धन
</div>

हमने सशुल्क टियर का उपयोग करने वाले डेवलपरों के लिए premium APIs के रिस्पॉन्स पेलोड में मेटाडेटा जोड़ा है। expanded URLs, poll data, और profile geo के बारे में अधिक जानने के लिए हमारा [संवर्धन अनुभाग](/hi/x-api/enterprise-gnip-2.0/fundamentals/data-enrichments) देखें।
 

<div id="advanced-filtering-tools">
  ### उन्नत फ़िल्टरिंग टूल
</div>

Premium Search API ऑपरेटरों का एक उन्नत सेट उपलब्ध कराता है, जो मानक search endpoint पर उपलब्ध नहीं है। इनमें से कई ऑपरेटर निःशुल्क sandbox उपयोगकर्ताओं के लिए उपलब्ध हैं, लेकिन यदि आप किसी सशुल्क tier का उपयोग कर रहे हैं, तो आपको ऑपरेटरों का अधिक व्यापक सेट मिलेगा। अधिक जानने के लिए हमारा [rules and filters section](/hi/x-api/enterprise-gnip-2.0/fundamentals/rules-filtering#getting-started-with-enterprise-rules-and-queries) देखें।

<div id="explore-x-api-v2">
  ## X API v2 के बारे में जानें

क्या आप जानना चाहते हैं कि v2 में अभी क्या उपलब्ध है? क्या नया है, यह देखने के लिए हमारा दस्तावेज़ देखें, और उन संसाधनों के लिए migration hub पर जाएँ जो आपको आगे चलकर X API v2 पर माइग्रेट करने में मदद करेंगे। आप नए v2 endpoint अनुभागों में सूचीबद्ध हर endpoint के लिए migration guide भी देख सकते हैं।
