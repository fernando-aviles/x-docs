<div id="search-for-spaces">
  ## Spaces खोजें
</div>

किसी कीवर्ड से मेल खाने वाले Spaces खोजें:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/spaces/search?\
  query=AI&\
  space.fields=title,host_ids,participant_count,state&\
  state=live" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Spaces खोजें
  response = client.spaces.search(
      query="AI",
      space_fields=["title", "host_ids", "participant_count", "state"],
      state="live"
  )

  for space in response.data:
      print(f"{space.title} - {space.participant_count} प्रतिभागी")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Spaces खोजें
  const response = await client.spaces.search({
    query: "AI",
    spaceFields: ["title", "host_ids", "participant_count", "state"],
    state: "live",
  });

  response.data?.forEach((space) => {
    console.log(`${space.title} - ${space.participant_count} प्रतिभागी`);
  });
  ```
</CodeGroup>

<div id="include-host-information">
  ## होस्ट की जानकारी शामिल करें
</div>

होस्ट उपयोगकर्ता डेटा का विस्तार करें:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/spaces/search?\
  query=AI&\
  space.fields=title,host_ids,state&\
  expansions=host_ids&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # होस्ट जानकारी के साथ खोजें
  response = client.spaces.search(
      query="AI",
      space_fields=["title", "host_ids", "state"],
      expansions=["host_ids"],
      user_fields=["username", "verified"]
  )

  for space in response.data:
      print(f"{space.title}")
  # होस्ट जानकारी response.includes.users में है
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // होस्ट जानकारी के साथ खोजें
  const response = await client.spaces.search({
    query: "AI",
    spaceFields: ["title", "host_ids", "state"],
    expansions: ["host_ids"],
    userFields: ["username", "verified"],
  });

  response.data?.forEach((space) => {
    console.log(space.title);
  });
  // होस्ट जानकारी response.includes?.users में है
  ```
</CodeGroup>

<div id="common-parameters">
  ## सामान्य पैरामीटर
</div>

| पैरामीटर       | विवरण                                   |
| :------------- | :-------------------------------------- |
| `query`        | खोज क्वेरी (आवश्यक)                     |
| `state`        | फ़िल्टर: `live`, `scheduled`, या `all`  |
| `max_results`  | लौटाए जाने वाले परिणाम (1-100)          |
| `space.fields` | शामिल किए जाने वाले Space फ़ील्ड्स      |
| `expansions`   | शामिल किए जाने वाले संबंधित ऑब्जेक्ट    |
| `user.fields`  | शामिल किए जाने वाले उपयोगकर्ता फ़ील्ड्स |
