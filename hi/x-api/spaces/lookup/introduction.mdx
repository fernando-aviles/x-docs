<div id="endpoints">
  ## एंडपॉइंट्स
</div>

| विधि | एंडपॉइंट                                                              | विवरण                                           |
| :--- | :-------------------------------------------------------------------- | :---------------------------------------------- |
| GET  | [`/2/spaces/:id`](/hi/x-api/spaces/get-space-by-id)                      | ID से Space प्राप्त करें                        |
| GET  | [`/2/spaces`](/hi/x-api/spaces/get-spaces-by-ids)                        | IDs से Spaces प्राप्त करें                      |
| GET  | [`/2/spaces/by/creator_ids`](/hi/x-api/spaces/get-spaces-by-creator-ids) | क्रिएटर उपयोगकर्ता IDs से Spaces प्राप्त करें   |
| GET  | [`/2/spaces/:id/buyers`](/hi/x-api/spaces/get-space-ticket-buyers)       | किसी Space के टिकट खरीदार प्राप्त करें          |
| GET  | [`/2/spaces/:id/tweets`](/hi/x-api/spaces/get-space-posts)               | किसी Space में साझा किए गए पोस्ट्स प्राप्त करें |

<div id="response-fields">
  ## प्रतिक्रिया फ़ील्ड्स
</div>

डिफ़ॉल्ट रूप से, प्रतिक्रिया में `id` और `state` शामिल होते हैं। अतिरिक्त फ़ील्ड्स का अनुरोध करें:

| फ़ील्ड              | विवरण                      |
| :------------------ | :------------------------- |
| `title`             | Space का शीर्षक            |
| `host_ids`          | होस्ट उपयोगकर्ता ID        |
| `speaker_ids`       | वक्ता उपयोगकर्ता ID        |
| `participant_count` | प्रतिभागियों की संख्या     |
| `scheduled_start`   | निर्धारित शुरू होने का समय |
| `started_at`        | वास्तविक शुरू होने का समय  |
| `ended_at`          | समाप्ति समय                |
| `is_ticketed`       | क्या Space टिकट-आधारित है  |

<div id="space-states">
  ### Space की स्थितियाँ
</div>

| स्थिति      | विवरण                   |
| :---------- | :---------------------- |
| `live`      | वर्तमान में सक्रिय      |
| `scheduled` | भविष्य के लिए निर्धारित |
| `ended`     | समाप्त हो चुका है       |

<div id="example-request">
  ## उदाहरण अनुरोध
</div>

```bash
curl "https://api.x.com/2/spaces/1DXxyRYNejbKM?\
space.fields=title,host_ids,participant_count,scheduled_start,state" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
