  ## v1.1 और v2 Manage Direct Message एंडपॉइंट्स की तुलना
</div>

Direct Messages एंडपॉइंट्स के v1.1 और v2, दोनों संस्करण Direct Message संदेश बनाने के तरीके उपलब्ध कराते हैं। यह गाइड इन अंतरों को समझने और v2 पर माइग्रेट करने के लिए जानकारी देने के उद्देश्य से है। 

दोनों संस्करणों के बीच एक बड़ा अंतर यह है कि v1.1 केवल one-to-one बातचीतों का समर्थन करता है, जबकि v2 group बातचीतों के लिए भी समर्थन जोड़ता है। इसका एक परिणाम यह है कि v1.1 केवल &quot;message created&quot; events का समर्थन करता है, जबकि v2 उन events का भी समर्थन करता है जो participants के बातचीत में शामिल होने और उससे बाहर जाने से संबंधित हैं। वास्तव में, v2 का एक मूलभूत अपडेट dm&#95;conversations को एक मुख्य API object के रूप में स्थापित करना है।   

v1.1 में Direct Messages को प्रबंधित करने के लिए दो एंडपॉइंट्स हैं:

* POST direct&#95;messages/events/new - एक one-to-one Direct Message बनाता है। यह v1.1 एंडपॉइंट केवल one-to-one messages बना सकता है और group messages का समर्थन नहीं करता।  

* DELETE direct&#95;messages/events/destroy - authenticating user के view से एक one-to-one message हटाता है। 

इस v2 release में, Direct Messages बनाने के लिए तीन POST methods हैं: 

* **POST /2/dm&#95;conversations/with/:participant&#95;id/messages** - एक one-to-one Direct Message बनाता है। यह method या तो message को किसी मौजूदा one-to-one बातचीत में जोड़ता है या एक नई बातचीत बनाता है। :participant&#95;id path parameter उस account का User ID है जो message प्राप्त कर रहा है। 

* **POST /2/dm&#95;conversations** - एक नई group बातचीत बनाता है और उसमें एक Direct Message जोड़ता है। इन requests के लिए बातचीत participants की एक सूची आवश्यक होती है। ध्यान दें कि आप एक ही participant list के साथ कई बातचीतें बना सकते हैं। ये requests हमेशा एक नया बातचीत ID लौटाएँगी। 

* **POST /2/dm&#95;conversations/:dm&#95;conversation&#95;id/messages** - एक Direct Message बनाता है और उसे किसी मौजूदा बातचीत में जोड़ता है। :dm&#95;conversation&#95;id path parameter उस बातचीत की ID है, जिसमें message जोड़ा जाएगा। 

एक महत्वपूर्ण बात यह है कि बातचीत और event IDs, X Platform के v1.1 और v2 संस्करणों में साझा होती हैं। इसका मतलब है कि दोनों संस्करणों का साथ में उपयोग किया जा सकता है। उदाहरण के लिए, Direct Messages v1.1 एंडपॉइंट्स किसी single event को लौटाने और events को हटाने के तरीके उपलब्ध कराते हैं, जो v2 में अभी उपलब्ध नहीं हैं। चूँकि IDs, v1.1 और v2 में समान हैं, आप v2 द्वारा दी गई IDs के आधार पर v1.1 requests कर सकते हैं, या X application में बातचीत URLs में दिखाई देने वाली बातचीत IDs का संदर्भ ले सकते हैं।

नीचे दी गई तालिका v1.1 और v2 manage Direct Messages एंडपॉइंट्स के मूलभूत पहलुओं की तुलना करती है। यहाँ साझा की गई X API v2 की विशेषताएँ सभी Direct Message lookup एंडपॉइंट्स में सामान्य हैं।
