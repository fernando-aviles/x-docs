निम्न तालिका X API v2 एंडपॉइंट्स का संबंधित standard v1.1 और enterprise एंडपॉइंट्स से मिलान दिखाती है। इन संस्करणों और tiers के बारे में अधिक जानने के लिए, कृपया हमारी [X API शुरू करने की गाइड](/hi/x-api/getting-started/about-x-api) देखें।

आप देखेंगे कि अभी भी कई आइटम **[जल्द आ रहा है]** के रूप में चिह्नित हैं। यदि आपको इस तालिका में कोई भी प्रविष्टि **[प्रतिस्थापन विचाराधीन है]** या **[किसी प्रतिस्थापन की योजना नहीं है]** के रूप में चिह्नित दिखे, और आप उस एंडपॉइंट का v2 संस्करण जारी होते देखना चाहते हों, तो कृपया हमें हमारे [community forum](https://devcommunity.x.com/) या अपने enterprise account manager के माध्यम से बताएं।
