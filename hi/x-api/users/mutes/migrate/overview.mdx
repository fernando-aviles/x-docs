  ## X API के म्यूट्स एंडपॉइंट्स की तुलना
</div>

<div id="mutes-lookup">
  #### म्यूट्स लुकअप
</div>

v2 म्यूट्स लुकअप एंडपॉइंट, मानक [v1.1 GET mutes/users/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-ids) और [GET mutes/users/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-list) एंडपॉइंट्स की जगह लेगा।

निम्न तालिकाएँ मानक v1.1 और X API v2 म्यूट एंडपॉइंट्स की तुलना करती हैं:
 

| विवरण                                                                                                                                                                      | मानक v1.1                                                                   | X API v2                                                                                                                                                                                                                                                                                                                                                                    |
| :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| समर्थित HTTP मेथड                                                                                                                                                          | ******GET******                                                             | ******GET******                                                                                                                                                                                                                                                                                                                                                             |
| होस्ट डोमेन                                                                                                                                                                | ******https://api.x.com******                                               | ******https://api.x.com******                                                                                                                                                                                                                                                                                                                                               |
| एंडपॉइंट पाथ                                                                                                                                                               | ******/1.1/mutes/users/ids.json******<br /><br />/1.1/mutes/users/list.json | ******/2/users/:id/muting******                                                                                                                                                                                                                                                                                                                                             |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)                                                                                                                       | OAuth 1.0a उपयोगकर्ता संदर्भ                                                | OAuth 1.0a उपयोगकर्ता संदर्भ<br /><br />PKCE के साथ OAuth 2.0 ऑथराइज़ेशन कोड                                                                                                                                                                                                                                                                                                |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits)                                                                                                         | प्रति 15 मिनट 15 अनुरोध (प्रति उपयोगकर्ता)                                  | प्रति 15 मिनट 15 अनुरोध (प्रति उपयोगकर्ता)                                                                                                                                                                                                                                                                                                                                  |
| डेटा फ़ॉर्मैट                                                                                                                                                              | मानक v1.1 फ़ॉर्मैट                                                          | [X API v2 फ़ॉर्मैट](/hi/x-api/fundamentals/data-dictionary) (यह fields और expansions अनुरोध पैरामीटर से निर्धारित होता है और v1.1 फ़ॉर्मैट्स के साथ backward-compatible नहीं है)<br /><br />मानक v1.1 फ़ॉर्मैट से X API v2 फ़ॉर्मैट में माइग्रेट करने के बारे में अधिक जानने के लिए, कृपया हमारी [डेटा फ़ॉर्मैट्स माइग्रेशन गाइड](/hi/x-api/migrate/data-format-migration) देखें। |
| किसी [डेवलपर ऐप](/hi/resources/fundamentals/developer-apps) से जुड़े और किसी [प्रोजेक्ट](/hi/resources/fundamentals/developer-apps) से संबद्ध क्रेडेंशियल्स के उपयोग की आवश्यकता |                                                                             | ✔️                                                                                                                                                                                                                                                                                                                                                                          |

<div id="manage-mutes">
  #### म्यूट्स प्रबंधित करें
</div>

v2 के म्यूट्स प्रबंधन एंडपॉइंट्स, मानक v1.1 [POST mutes/users/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-create) और [POST mutes/users/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-destroy) एंडपॉइंट्स की जगह लेंगे।

निम्न तालिकाएँ मानक v1.1 और X API v2 के म्यूट्स एंडपॉइंट्स की तुलना करती हैं:

**किसी उपयोगकर्ता को म्यूट करें**

| विवरण                                                                                                                                                                      | मानक v1.1                    | X API v2                                                                  |
| :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------- | :------------------------------------------------------------------------ |
| समर्थित HTTP मेथड्स                                                                                                                                                        | POST                         | POST                                                                      |
| होस्ट डोमेन                                                                                                                                                                | https://api.x.com            | https://api.x.com                                                         |
| एंडपॉइंट पाथ                                                                                                                                                               | /1.1/mutes/users/create.json | /2/users/:id/muting                                                       |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)                                                                                                                       | OAuth 1.0a उपयोगकर्ता संदर्भ      | OAuth 1.0a उपयोगकर्ता संदर्भ<br /><br />OAuth 2.0 ऑथराइज़ेशन कोड with PKCE |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits)                                                                                                         | 15 मिनट में 50 अनुरोध        | 15 मिनट में 50 अनुरोध                                                     |
| किसी [डेवलपर ऐप](/hi/resources/fundamentals/developer-apps) के ऐसे क्रेडेंशियल्स का उपयोग आवश्यक है, जो किसी [प्रोजेक्ट](/hi/resources/fundamentals/developer-apps) से संबद्ध हो |                              | ✔️                                                                        |

**किसी उपयोगकर्ता का म्यूट हटाएँ**

निम्न तालिकाएँ मानक v1.1 और X API v2 के म्यूट हटाने वाले एंडपॉइंट्स की तुलना करती हैं:

| एंडपॉइंट पाथ                                                                                                                                                               | /1.1/mutes/users/destroy.json | /2/users/:source&#95;user&#95;id/muting/:target&#95;user&#95;id           |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)                                                                                                                       | OAuth 1.0a उपयोगकर्ता संदर्भ       | OAuth 1.0a उपयोगकर्ता संदर्भ<br /><br />OAuth 2.0 ऑथराइज़ेशन कोड with PKCE |
