उपयोगकर्ता खोज endpoints आपको एक या अधिक उपयोगकर्ताओं की प्रोफ़ाइल जानकारी प्राप्त करने की सुविधा देते हैं। उपयोगकर्ताओं को उनके ID या उपयोगकर्ता नाम के आधार पर खोजें, या वर्तमान में प्रमाणीकृत उपयोगकर्ता का विवरण प्राप्त करें।

<div id="endpoints">
  ## एंडपॉइंट्स
</div>

| विधि | एंडपॉइंट                                                              | विवरण                                             |
| :--- | :-------------------------------------------------------------------- | :------------------------------------------------ |
| GET  | [`/2/users/:id`](/hi/x-api/users/get-user-by-id)                         | ID से उपयोगकर्ता प्राप्त करें                     |
| GET  | [`/2/users`](/hi/x-api/users/get-users-by-ids)                           | IDs से उपयोगकर्ता प्राप्त करें (अधिकतम 100)       |
| GET  | [`/2/users/by/username/:username`](/hi/x-api/users/get-user-by-username) | उपयोगकर्ता नाम से उपयोगकर्ता प्राप्त करें               |
| GET  | [`/2/users/by`](/hi/x-api/users/get-users-by-usernames)                  | उपयोगकर्ता नामों से उपयोगकर्ता प्राप्त करें (अधिकतम 100) |
| GET  | [`/2/users/me`](/hi/x-api/users/get-my-user)                             | प्रमाणीकृत उपयोगकर्ता प्राप्त करें                |

***

<div id="example-request">
  ## अनुरोध का उदाहरण
</div>

```bash
curl "https://api.x.com/2/users/by/username/XDevelopers?\
user.fields=created_at,description,public_metrics,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
