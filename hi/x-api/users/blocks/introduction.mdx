<div id="endpoints">
  ## एंडपॉइंट्स
</div>

| Method | Endpoint                                             | Description                               |
| :----- | :--------------------------------------------------- | :---------------------------------------- |
| GET    | [`/2/users/:id/blocking`](/hi/x-api/users/get-blocking) | ब्लॉक किए गए उपयोगकर्ताओं को प्राप्त करें |
| POST   | [`/2/users/:id/blocking`](/hi/x-api/users/block-dms)    | किसी उपयोगकर्ता को ब्लॉक करें             |
| DELETE | `/2/users/:source_user_id/blocking/:target_user_id`  | किसी उपयोगकर्ता को अनब्लॉक करें           |

***

<div id="example-get-blocked-users">
  ## उदाहरण: ब्लॉक किए गए उपयोगकर्ताओं को प्राप्त करें
</div>

```bash
curl "https://api.x.com/2/users/123456789/blocking?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-block-a-user">
  ## उदाहरण: किसी उपयोगकर्ता को ब्लॉक करें
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/blocking" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
