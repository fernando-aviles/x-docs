<div id="comparing-x-apis-timelines-endpoints">
  ## X API के टाइमलाइन एंडपॉइंट की तुलना
</div>

v2 reverse chronological टाइमलाइन, user पोस्ट्स टाइमलाइन, और user mention टाइमलाइन एंडपॉइंट क्रमशः [v1.1 statuses/home&#95;timeine,](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-home_timeline) [v1.1 statuses/user&#95;timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-user_timeline.html), और [v1.1 statuses/mentions&#95;timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-mentions_timeline.html) एंडपॉइंट की जगह लेते हैं। अगर आपके पास ऐसा code, ऐप्स, या tools हैं जो इस एंडपॉइंट के पुराने version का इस्तेमाल करते हैं और आप नए X API v2 एंडपॉइंट पर migrate करने की सोच रहे हैं, तो यह guide आपके लिए है। अधिक विस्तृत migration guide के लिए [Standard v1.1 migration to X API v2](/hi/x-api/posts/timelines/migrate/standard-to-twitter-api-v2) देखें।

इस page में तीन comparison tables हैं:

* Reverse chronological home टाइमलाइन
* User पोस्ट टाइमलाइन
* User mention टाइमलाइन
