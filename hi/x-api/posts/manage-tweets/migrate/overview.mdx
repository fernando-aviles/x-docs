<div id="comparing-x-apis-manage-posts-endpoints">
  ## X API के पोस्ट्स प्रबंधित करने वाले एंडपॉइंट्स की तुलना
</div>

v2 के पोस्ट्स प्रबंधित करने वाले एंडपॉइंट्स, मानक v1.1 [POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) और [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id) एंडपॉइंट्स की जगह लेंगे। यदि आपके पास ऐसा कोड, ऐप्स या टूल हैं जो पोस्ट्स प्रबंधित करने वाले एंडपॉइंट्स के v1.1 संस्करण का उपयोग करते हैं और आप नए X API v2 एंडपॉइंट पर माइग्रेट करने पर विचार कर रहे हैं, तो गाइडों का यह सेट आपके लिए है।

निम्न तालिकाएँ मानक v1.1 और X API v2 के पोस्ट्स प्रबंधित करने वाले एंडपॉइंट्स की तुलना करती हैं:
