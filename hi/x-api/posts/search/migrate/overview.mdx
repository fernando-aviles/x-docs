<div id="comparing-x-apis-search-posts-endpoints">
  ## X API के Search पोस्ट्स एंडपॉइंट्स की तुलना
</div>

v2 Search Tweets endpoint अंततः [standard v1.1 search/posts](/hi/x-api/posts/search/introduction) endpoint और [enterprise Search API](/hi/x-api/enterprise-gnip-2.0/fundamentals/search-api) की जगह ले लेगा। यदि आपके पास ऐसा कोड, ऐप्स या टूल हैं जो X search endpoint के किसी पुराने संस्करण का उपयोग करते हैं और आप नए X API v2 एंडपॉइंट्स पर माइग्रेट करने पर विचार कर रहे हैं, तो यह मार्गदर्शिका आपके लिए है।

***

**फ़िल्टरिंग ऑपरेटर तुलना**

सर्च पोस्ट्स के चार अलग-अलग संस्करणों (standard, enterprise, और v2) में उपलब्ध ऑपरेटर अलग-अलग हैं। साथ ही, प्रत्येक संस्करण के भीतर भी ऑपरेटर उपलब्धता के स्तर भिन्न हैं, जिनकी व्याख्या नीचे दी गई है।

Enterprise

* enterprise ऑपरेटरों के कोई उप-स्तर नहीं हैं

X API v2

* **Self-serve:** किसी भी Project का उपयोग करने पर उपलब्ध
* **Enterprise:** किसी Project का उपयोग करने पर उपलब्ध

आप इन सभी ऑपरेटर सेट्स के बारे में उनकी संबंधित गाइड्स में अधिक जान सकते हैं:

* [Enterprise operators](/hi/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [X API v2 operators](/hi/x-api/posts/search/integrate/build-a-query#operators)

अब जब हम X API v2 के भीतर अलग-अलग ऑपरेटर स्तरों को समझ चुके हैं, तो यहाँ वह तालिका है जो सर्च पोस्ट्स के लिए ऑपरेटर उपलब्धता दिखाती है (ध्यान दें कि यदि कोई सेल खाली छोड़ा गया है, तो वह ऑपरेटर उपलब्ध नहीं है):
