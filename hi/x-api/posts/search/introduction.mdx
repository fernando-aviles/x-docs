<div id="use-cases">
  ## उपयोग के परिदृश्य
</div>

* **ब्रांड मॉनिटरिंग** — अपने ब्रांड या उत्पादों के उल्लेखों पर नज़र रखें
* **रुझान विश्लेषण** — विषयों या घटनाओं से जुड़ी बातचीत का विश्लेषण करें
* **अनुसंधान** — शैक्षणिक या बाज़ार शोध के लिए डेटा एकत्र करें
* **रीयल-टाइम लिसनिंग** — ऐसे अनुप्रयोग बनाएँ जो नई पोस्ट्स पर प्रतिक्रिया दें

<div id="query-operators">
  ## क्वेरी ऑपरेटर
</div>

पोस्ट विशेषताओं से मेल खाने वाले ऑपरेटरों का उपयोग करके क्वेरी बनाएं:

```
(AI OR "artificial intelligence") lang:en -is:retweet has:links
```

<AccordionGroup>
  <Accordion title="कीवर्ड ऑपरेटर">
    | Operator | Example              | Description                            |
    | :------- | :------------------- | :------------------------------------- |
    | Keyword  | `python`             | शब्द वाले पोस्ट्स                      |
    | Phrase   | `"machine learning"` | सटीक वाक्यांश वाले पोस्ट्स             |
    | Hashtag  | `#AI`                | हैशटैग वाले पोस्ट्स                    |
    | Mention  | `@XDevelopers`       | उपयोगकर्ता का उल्लेख करने वाले पोस्ट्स |
  </Accordion>

  <Accordion title="उपयोगकर्ता ऑपरेटर">
    | Operator       | Example          | Description                           |
    | :------------- | :--------------- | :------------------------------------ |
    | `from:`        | `from:elonmusk`  | किसी उपयोगकर्ता के पोस्ट्स            |
    | `to:`          | `to:XDevelopers` | किसी उपयोगकर्ता को दिए गए जवाब        |
    | `retweets_of:` | `retweets_of:X`  | किसी उपयोगकर्ता के पोस्ट्स के रीट्वीट |
  </Accordion>

  <Accordion title="कॉन्टेंट ऑपरेटर">
    | Operator       | Example          | Description               |
    | :------------- | :--------------- | :------------------------ |
    | `has:images`   | `cat has:images` | इमेज वाले पोस्ट्स         |
    | `has:videos`   | `has:videos`     | वीडियो वाले पोस्ट्स       |
    | `has:links`    | `has:links`      | लिंक वाले पोस्ट्स         |
    | `has:mentions` | `has:mentions`   | मेंशन वाले पोस्ट्स        |
    | `url:`         | `url:github.com` | किसी खास URL वाले पोस्ट्स |
  </Accordion>

  <Accordion title="फ़िल्टर ऑपरेटर">
    | Operator      | Example       | Description                      |
    | :------------ | :------------ | :------------------------------- |
    | `lang:`       | `lang:en`     | किसी भाषा के पोस्ट्स             |
    | `-is:retweet` | `-is:retweet` | रीट्वीट्स को छोड़कर              |
    | `-is:reply`   | `-is:reply`   | जवाबों को छोड़कर                 |
    | `is:verified` | `is:verified` | सत्यापित उपयोगकर्ताओं के पोस्ट्स |
  </Accordion>
</AccordionGroup>

<div id="recent-search">
  ## हालिया खोज
</div>

**पिछले 7 दिनों** की पोस्ट्स खोजें। यह सभी डेवलपर्स के लिए उपलब्ध है।

### सुविधाएँ

* प्रति अनुरोध अधिकतम 100 पोस्ट्स
* बड़े परिणाम सेट के लिए पेजिनेशन
* सभी मुख्य क्वेरी ऑपरेटर
* 512-वर्ण की क्वेरी लंबाई (Enterprise के लिए 4,096)
