<div id="comparing-x-apis-likes-endpoints">
  ## X API के Likes endpoints की तुलना
</div>

ये गाइड निम्नलिखित क्षेत्रों पर केंद्रित होंगी:

* **API अनुरोध पैरामीटर** - X API v2 endpoint अनुरोध पैरामीटरों का एक नया सेट पेश करता है। हालांकि कुछ पैरामीटर परिचित लगेंगे, खासकर उन लोगों के लिए जो Labs के साथ इंटीग्रेट कर रहे हैं, फिर भी कई महत्वपूर्ण अंतर हैं, जैसे [फ़ील्ड्स](/hi/x-api/fundamentals/fields) और [expansions](/hi/x-api/fundamentals/expansions) पैरामीटरों की शुरुआत।

* **ऐप और Project आवश्यकताएँ** - X API v2 तक पहुँचने के लिए, आपको ऐसे [developer App](/hi/resources/fundamentals/developer-apps) के क्रेडेंशियल्स का उपयोग करना होगा, जो किसी [Project](/hi/resources/fundamentals/developer-apps) से जुड़ा हो

<div id="likes-lookup">
  #### लाइक्स लुकअप
</div>

**वे उपयोगकर्ता जिन्होंने किसी पोस्ट को लाइक किया है**

liked users endpoint, v2 की एक नई सुविधा है, जो आपको किसी पोस्ट को लाइक करने वाले उपयोगकर्ताओं के बारे में जानकारी प्राप्त करने देती है।

| विवरण                                                              | X API v2                                                                                 |
| :----------------------------------------------------------------- | :--------------------------------------------------------------------------------------- |
| समर्थित HTTP मेथड                                                  | GET                                                                                      |
| होस्ट डोमेन                                                        | https://api.x.com                                                                        |
| एंडपॉइंट पाथ                                                       | /2/tweets/:id/liking&#95;users                                                           |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)               | OAuth 2.0 बेयरर टोकन<br /><br />OAuth 1.0a यूज़र कॉन्टेक्स्ट                             |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits) | प्रति 15 मिनट 75 अनुरोध (प्रति ऐप)<br /><br />प्रति 15 मिनट 75 अनुरोध (प्रति उपयोगकर्ता) |

**किसी उपयोगकर्ता द्वारा लाइक की गई पोस्ट्स**

निम्न तालिकाएँ Standard v1.1 [GET favorites/list](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-favorites-list) एंडपॉइंट और X API v2 liked पोस्ट्स एंडपॉइंट्स की तुलना करती हैं:

| विवरण                                                              | Standard v1.1                | X API v2                                                                                                                                                                                                                                                                                                                                                                              |
| :----------------------------------------------------------------- | :--------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| समर्थित HTTP मेथड                                                  | GET                          | GET                                                                                                                                                                                                                                                                                                                                                                                   |
| होस्ट डोमेन                                                        | https://api.x.com            | https://api.x.com                                                                                                                                                                                                                                                                                                                                                                     |
| एंडपॉइंट पाथ                                                       | /1.1/favorites/list.json     | /2/users/:id/liked&#95;tweets                                                                                                                                                                                                                                                                                                                                                         |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)               | OAuth 1.0a यूज़र कॉन्टेक्स्ट | OAuth 2.0 बेयरर टोकन<br /><br />OAuth 1.0a यूज़र कॉन्टेक्स्ट                                                                                                                                                                                                                                                                                                                          |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits) | प्रति 15 मिनट 75 अनुरोध      | प्रति 15 मिनट 75 अनुरोध (प्रति ऐप)<br /><br />प्रति 15 मिनट 75 अनुरोध (प्रति उपयोगकर्ता)                                                                                                                                                                                                                                                                                              |
| डेटा फ़ॉर्मैट                                                      | Standard v1.1 फ़ॉर्मैट       | [X API v2 फ़ॉर्मैट](/hi/x-api/fundamentals/data-dictionary) (इसका निर्धारण फ़ील्ड्स और expansions अनुरोध पैरामीटर द्वारा होता है, और यह v1.1 फ़ॉर्मैट्स के साथ backward-compatible नहीं है)<br /><br />Standard v1.1 फ़ॉर्मैट से X API v2 फ़ॉर्मैट में migrate करने के बारे में अधिक जानने के लिए, कृपया हमारी [data formats migration guide](/hi/x-api/migrate/data-format-migration) देखें। |

<div id="manage-likes">
  #### लाइक प्रबंधित करें
</div>

v2 के लाइक प्रबंधन एंडपॉइंट, v1.1 के [POST favorites/create](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-create) और [POST favorites/destroy](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-destroy) एंडपॉइंट्स का स्थान लेते हैं।

निम्न तालिकाएँ, मानक v1.1 और X API v2 के लाइक प्रबंधन एंडपॉइंट्स की तुलना करती हैं:

<div id="like-a-post">
  #### किसी पोस्ट को लाइक करें
</div>

| विवरण                                                              | मानक v1.1                                                                                    | X API v2                                                                                                               |
| :----------------------------------------------------------------- | :------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------- |
| समर्थित HTTP मेथड्स                                                | POST                                                                                         | POST                                                                                                                   |
| होस्ट डोमेन                                                        | https://api.x.com                                                                            | https://api.x.com                                                                                                      |
| एंडपॉइंट पाथ                                                       | /1.1/favorites/create.json                                                                   | /2/users/:id/likes                                                                                                     |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)               | OAuth 1.0a यूज़र कॉन्टेक्स्ट                                                                 | OAuth 1.0a यूज़र कॉन्टेक्स्ट                                                                                            |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits) | प्रति 24 घंटे 1000 अनुरोध (प्रति उपयोगकर्ता)<br /><br />प्रति 24 घंटे 1000 अनुरोध (प्रति ऐप) | प्रति 15 मिनट 50 अनुरोध (प्रति उपयोगकर्ता)<br /><br />प्रति 24 घंटे 1000 अनुरोध (प्रति उपयोगकर्ता, DELETE के साथ साझा) |
