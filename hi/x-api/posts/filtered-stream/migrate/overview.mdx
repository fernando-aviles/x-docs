  ## X API के फ़िल्टर्ड स्ट्रीम एंडपॉइंट्स की तुलना
</div>

v2 फ़िल्टर्ड स्ट्रीम एंडपॉइंट्स का समूह, [standard v1.1 statuses/filter](https://developer.x.com/en/docs/x-api/v1/tweets/filter-realtime/api-reference/post-statuses-filter) और [PowerTrack API](/hi/x-api/enterprise-gnip-2.0/powertrack-api) की जगह ले रहा है। यदि आपके पास ऐसा कोड, ऐप्स, या टूल हैं जो फ़िल्टर्ड स्ट्रीम एंडपॉइंट के पुराने वर्शन का उपयोग करते हैं, और आप नए X API v2 एंडपॉइंट पर माइग्रेट करने पर विचार कर रहे हैं, तो यह तुलना आपको शुरुआत करने में मदद कर सकती है।

इनके लिए हमारी अधिक विस्तृत माइग्रेशन गाइड्स देखें:

[Standard v1.1 से X API v2 पर माइग्रेट करना](x-api/posts/filtered-stream#standard-v1-1-compared-to-x-api-v2)

[PowerTrack API से X API v2 पर माइग्रेट करना](/hi/x-api/enterprise-gnip-2.0/powertrack-api#powertrack-operators)
