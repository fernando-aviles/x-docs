बुकमार्क्स एंडपॉइंट आपको प्रमाणीकृत उपयोगकर्ता के लिए बुकमार्क की गई पोस्ट्स को देखने, जोड़ने और हटाने की सुविधा देते हैं। बुकमार्क्स निजी होते हैं और केवल उन्हें बनाने वाले उपयोगकर्ता को ही दिखाई देते हैं।

<div id="endpoints">
  ## एंडपॉइंट्स
</div>

| Method | Endpoint                                                                               | Description                           |
| :----- | :------------------------------------------------------------------------------------- | :------------------------------------ |
| GET    | [`/2/users/:id/bookmarks`](/hi/x-api/users/get-bookmarks)                                 | उपयोगकर्ता के बुकमार्क प्राप्त करें   |
| POST   | [`/2/users/:id/bookmarks`](/hi/x-api/users/create-bookmark)                               | किसी पोस्ट को बुकमार्क करें           |
| DELETE | [`/2/users/:id/bookmarks/:tweet_id`](/hi/x-api/users/delete-bookmark)                     | बुकमार्क हटाएँ                        |
| GET    | [`/2/users/:id/bookmarks/folders`](/hi/x-api/users/get-bookmark-folders)                  | बुकमार्क फ़ोल्डर्स प्राप्त करें       |
| GET    | [`/2/users/:id/bookmarks/folders/:folder_id`](/hi/x-api/users/get-bookmarks-by-folder-id) | किसी फ़ोल्डर में पोस्ट्स प्राप्त करें |

***

<div id="example-get-bookmarks">
  ## उदाहरण: बुकमार्क पाएं
</div>

```bash
curl "https://api.x.com/2/users/123456789/bookmarks?\
tweet.fields=created_at,author_id,public_metrics" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-add-bookmark">
  ## उदाहरण: बुकमार्क जोड़ना
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
