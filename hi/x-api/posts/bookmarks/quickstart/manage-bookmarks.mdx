यह मार्गदर्शिका आपको X API का उपयोग करके बुकमार्क जोड़ने और हटाने के तरीके के बारे में बताती है।

<Note>
  **पूर्वापेक्षाएँ**

  शुरू करने से पहले, आपको इनकी आवश्यकता होगी:

  * स्वीकृत App के साथ एक [डेवलपर खाता](https://developer.x.com/en/portal/petition/essential/basic-info)
  * `bookmark.write` स्कोप वाला User Access Token (OAuth 2.0 PKCE)
</Note>

***

<div id="add-a-bookmark">
  ## बुकमार्क जोड़ें
</div>

<Steps>
  <Step title="अपनी यूज़र ID प्राप्त करें">
    आपको अपने प्रमाणीकृत यूज़र की ID चाहिए। आप इसे `/2/users/me` endpoint या [user lookup endpoint](/hi/x-api/users/lookup/introduction) का इस्तेमाल करके प्राप्त कर सकते हैं।
  </Step>

  <Step title="पोस्ट ID प्राप्त करें">
    किसी पोस्ट को देखते समय URL में पोस्ट ID ढूंढें:

    ```
    https://x.com/XDevelopers/status/1460323737035677698
                                    └── यह पोस्ट ID है
    ```
  </Step>

  <Step title="बुकमार्क जोड़ें">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/users/2244994945/bookmarks" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"tweet_id": "1460323737035677698"}'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # बुकमार्क जोड़ें
      response = client.bookmarks.create(
          user_id="2244994945",
          tweet_id="1460323737035677698"
      )

      print(f"Bookmarked: {response.data.bookmarked}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // बुकमार्क जोड़ें
      const response = await client.bookmarks.create("2244994945", {
        tweetId: "1460323737035677698",
      });

      console.log(`Bookmarked: ${response.data?.bookmarked}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="रिस्पॉन्स की समीक्षा करें">
    ```json
    {
      "data": {
        "bookmarked": true
      }
    }
    ```
  </Step>
</Steps>

<div id="remove-a-bookmark">
  ## एक बुकमार्क हटाएँ
</div>

अपने बुकमार्क से एक पोस्ट हटाएँ:

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/2244994945/bookmarks/1460323737035677698" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # एक बुकमार्क हटाएँ
  response = client.bookmarks.delete(
      user_id="2244994945",
      tweet_id="1460323737035677698"
  )

  print(f"Bookmarked: {response.data.bookmarked}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // एक बुकमार्क हटाएँ
  const response = await client.bookmarks.delete("2244994945", "1460323737035677698");

  console.log(`Bookmarked: ${response.data?.bookmarked}`);
  ```
</CodeGroup>

**प्रतिक्रिया:**

```json
{
  "data": {
    "bookmarked": false
  }
}
```

<div id="required-scopes">
  ## आवश्यक स्कोप
</div>

OAuth 2.0 PKCE का उपयोग करते समय, आपके access token में ये स्कोप होने चाहिए:

| स्कोप            | विवरण                    |
| :--------------- | :----------------------- |
| `bookmark.write` | बुकमार्क जोड़ना और हटाना |
| `tweet.read`     | पोस्ट डेटा पढ़ना         |
| `users.read`     | उपयोगकर्ता डेटा पढ़ना    |
