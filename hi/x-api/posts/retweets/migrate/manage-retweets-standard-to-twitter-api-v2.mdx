<div id="manage-retweets-standard-v11-compared-to-x-api-v2">
  ### रीट्वीट प्रबंधित करना: Standard v1.1 की X API v2 से तुलना
</div>

यदि आपने standard v1.1 [POST statuses/retweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-retweet-id) और [POST statuses/unretweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-unretweet-id) एंडपॉइंट्स के साथ काम किया है, तो इस गाइड का उद्देश्य standard और X API v2 के रीट्वीट एंडपॉइंट्स के बीच समानताओं और अंतरों को समझने में आपकी मदद करना है।

* **समानताएँ**
  * प्रमाणीकरण
* **अंतर**
  * एंडपॉइंट URL और HTTP मेथड
  * अनुरोध सीमाएँ
  * ऐप और प्रोजेक्ट आवश्यकताएँ
  * अनुरोध पैरामीटर

<div id="similarities">
  #### समानताएँ
</div>

**प्रमाणीकरण**

मानक v1.1 और X API v2, दोनों में रीट्वीट प्रबंधित करने वाले एंडपॉइंट्स ([POST statuses/retweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-retweet-id) और [POST statuses/unretweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-unretweet-id)) [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication) का उपयोग करते हैं। इसलिए, यदि आप पहले मानक v1.1 के रीट्वीट lookup एंडपॉइंट्स में से किसी एक का उपयोग कर रहे थे, तो X API v2 संस्करण पर माइग्रेट करने के बाद भी आप वही प्रमाणीकरण विधि इस्तेमाल करना जारी रख सकते हैं। 

<div id="differences">
  #### अंतर
</div>

**एंडपॉइंट URL और HTTP मेथड**

* मानक v1.1 एंडपॉइंट:
  * https://api.x.com/1.1/statuses/retweet/:id.json
    (किसी पोस्ट को रीट्वीट करता है। मूल पोस्ट को एम्बेड किए गए रीट्वीट विवरणों के साथ लौटाता है)
  * https://api.x.com/1.1/statuses/unretweet/:id.json
    (रीट्वीट को पूर्ववत करता है। मूल पोस्ट को एम्बेड किए गए रीट्वीट विवरणों के साथ लौटाता है)
* X API v2 एंडपॉइंट:
  * https://api.x.com/2/tweets/:id/retweets
    (किसी दिए गए पोस्ट को रीट्वीट करता है)
  * https://api.x.com/2/users/:id/retweets/:source&#95;tweet&#95;id
    (किसी दिए गए पोस्ट के रीट्वीट को पूर्ववत करता है) 

**ऐप और प्रोजेक्ट आवश्यकताएँ**

X API v2 एंडपॉइंट के लिए यह आवश्यक है कि आप अपने अनुरोधों को प्रमाणित करते समय ऐसे [developer ऐप](/hi/resources/fundamentals/developer-apps) की credentials का उपयोग करें, जो किसी [Project](/hi/resources/fundamentals/developer-apps) से संबद्ध हो। सभी X API v1.1 एंडपॉइंट, ऐप्स या किसी ऐप से संबद्ध ऐप्स की credentials का उपयोग कर सकते हैं।

**अनुरोध पैरामीटर**

निम्नलिखित मानक v1.1 अनुरोध पैरामीटर, दो request query parameters (user&#95;id या screen&#95;name) स्वीकार करते थे। X API v2 केवल संख्यात्मक user ID स्वीकार करता है, और इसे एंडपॉइंट पाथ के हिस्से के रूप में पास किया जाना चाहिए।

| Standard v1.1             | X API v2        |
| :------------------------ | :-------------- |
| **id**                    | **id**          |
| **includes&#95;entities** | कोई समकक्ष नहीं |

कृपया ध्यान दें कि Standard v1.1 पैरामीटर query parameters के रूप में पास किए जाते हैं, जबकि X API v2 पैरामीटर, POST एंडपॉइंट के लिए body parameters के रूप में या DELETE एंडपॉइंट के for path parameters के रूप में पास किए जाते हैं।

साथ ही, मानक v1.1 एंडपॉइंट का उपयोग करते समय किसी पोस्ट को रीट्वीट करने वाले उपयोगकर्ता की id आवश्यक नहीं होती, क्योंकि [OAuth 1.0a User Context](/hi/resources/fundamentals/authentication) के साथ पास किए गए [Access Tokens](/hi/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) से यह पता चल जाता है कि कौन-सा उपयोगकर्ता रीट्वीट शुरू कर रहा है या रीट्वीट को पूर्ववत कर रहा है।

<div id="retweet-a-post-v2">
  ### पोस्ट को रीट्वीट करें (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/retweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python
  # OAuth 1.0a User Context प्रमाणीकरण आवश्यक है
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/retweets"
  response = requests.post(url, auth=auth, json={"tweet_id": "1234567890"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # पोस्ट को रीट्वीट करें
  response = client.posts.retweet(user_id="123456789", tweet_id="1234567890")
  print(f"Retweeted: {response.data.retweeted}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // पोस्ट को रीट्वीट करें
  const response = await client.posts.retweet("123456789", { tweetId: "1234567890" });
  console.log(`Retweeted: ${response.data?.retweeted}`);
  ```

  ### रीट्वीट को पूर्ववत करें (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/123456789/retweets/1234567890" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  # OAuth 1.0a User Context प्रमाणीकरण आवश्यक है
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",

  url = "https://api.x.com/2/users/123456789/retweets/1234567890"
  response = requests.delete(url, auth=auth)
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  ```
