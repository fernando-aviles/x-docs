<div id="comparing-x-apis-retweets-endpoints">
  ## X API के Retweets एंडपॉइंट्स की तुलना
</div>

**Retweets लुकअप**

v2 Retweets लुकअप एंडपॉइंट, मानक [v1.1 GET statuses/retweets/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweets-id) और [v1.1 GET statuses/retweets/:ids](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweeters-ids) एंडपॉइंट्स की जगह लेगा।

निम्न तालिकाएँ मानक v1.1 और X API v2 Retweets एंडपॉइंट्स की तुलना करती हैं:

| विवरण                                                                                                                                                                            | मानक v1.1                                                   | X API v2                                                                                                                                                                                                                                                                                                                                               |
| :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| समर्थित HTTP मेथड                                                                                                                                                                | GET                                                         | GET                                                                                                                                                                                                                                                                                                                                                    |
| होस्ट डोमेन                                                                                                                                                                      | https://api.x.com                                           | https://api.x.com                                                                                                                                                                                                                                                                                                                                      |
| एंडपॉइंट पाथ                                                                                                                                                                     | /1.1/retweeters/id.json<br /><br />`/1.1/retweets/ids.json` | /2/users/:id/retweeted&#95;by                                                                                                                                                                                                                                                                                                                          |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)                                                                                                                             | OAuth 1.0a User Context                                     | OAuth 2.0 बेयरर टोकन<br /><br />OAuth 1.0a User Context                                                                                                                                                                                                                                                                                                |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits)                                                                                                               | प्रति 15 मिनट 75 अनुरोध                                     | प्रति 15 मिनट 75 अनुरोध (प्रति ऐप)<br /><br />प्रति 15 मिनट 75 अनुरोध (प्रति उपयोगकर्ता)                                                                                                                                                                                                                                                               |
| डेटा प्रारूप                                                                                                                                                                     | मानक v1.1 प्रारूप                                           | [X API v2 प्रारूप](/hi/x-api/fundamentals/data-dictionary) (यह fields और expansions अनुरोध पैरामीटर से निर्धारित होता है, और v1.1 प्रारूपों के साथ संगत नहीं है)<br /><br />मानक v1.1 प्रारूप से X API v2 प्रारूप में माइग्रेट करने के बारे में अधिक जानने के लिए, कृपया हमारी [डेटा प्रारूप माइग्रेशन गाइड](/hi/x-api/migrate/data-format-migration) देखें। |
| किसी [डेवलपर ऐप](/hi/resources/fundamentals/developer-apps) से जुड़े ऐसे क्रेडेंशियल्स के उपयोग की आवश्यकता, जो किसी [Project](/hi/resources/fundamentals/developer-apps) से संबद्ध हो |                                                             | ✔️                                                                                                                                                                                                                                                                                                                                                     |

<div id="manage-retweets">
  ### Retweets प्रबंधित करें
</div>

निम्न तालिकाएँ standard v1.1 और X API v2 के Retweet वापस लेने वाले endpoint की तुलना करती हैं:

**किसी पोस्ट को Retweet करें**

| विवरण                                                                                                                                                           | Standard v1.1                                                                                                                    | X API v2                                                                                                                                                                                           |
| :-------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| समर्थित HTTP मेथड                                                                                                                                               | POST                                                                                                                             | POST                                                                                                                                                                                               |
| होस्ट डोमेन                                                                                                                                                     | https://api.x.com                                                                                                                | https://api.x.com                                                                                                                                                                                  |
| एंडपॉइंट पाथ                                                                                                                                                    | /1.1/statuses/retweet/:id.json                                                                                                   | /2/users/:id/retweets                                                                                                                                                                              |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)                                                                                                            | OAuth 1.0a User Context                                                                                                          | OAuth 1.0a User Context                                                                                                                                                                            |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits)                                                                                              | कोई नहीं<br /><br />3 घंटे की विंडो में 300 अनुरोध (प्रति उपयोगकर्ता, प्रति ऐप)। यह POST Tweet endpoint के साथ साझा किया जाता है | 15 मिनट में 50 अनुरोध (प्रति उपयोगकर्ता)<br /><br />3 घंटे की विंडो में 300 अनुरोध (प्रति उपयोगकर्ता, प्रति ऐप)। यह पोस्ट्स को प्रबंधित करने के लिए POST Tweet endpoint के with साझा किया जाता है। |
| ऐसे [डेवलपर ऐप](/hi/resources/fundamentals/developer-apps) के credentials का उपयोग आवश्यक है, जो [Project](/hi/resources/fundamentals/developer-apps) से संबद्ध हो |                                                                                                                                  | ✔️                                                                                                                                                                                                 |

<div id="undo-a-retweet">
  #### रीट्वीट पूर्ववत करें
</div>

निम्न तालिकाएँ Standard v1.1 और X API v2 के रीट्वीट पूर्ववत करने वाले एंडपॉइंट की तुलना करती हैं:

| विवरण                                                                                                                                                                          | Standard v1.1                    | X API v2                                       |
| :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------- | :--------------------------------------------- |
| समर्थित HTTP मेथड्स                                                                                                                                                            | POST                             | DELETE                                         |
| होस्ट डोमेन                                                                                                                                                                    | https://api.x.com                | https://api.x.com                              |
| एंडपॉइंट पाथ                                                                                                                                                                   | /1.1/statuses/unretweet/:id.json | /2/users/:id/retweets/:source&#95;tweet&#95;id |
| [प्रमाणीकरण](/hi/resources/fundamentals/authentication)                                                                                                                           | OAuth 1.0a User Context          | OAuth 1.0a User Context                        |
| डिफ़ॉल्ट अनुरोध [रेट लिमिट्स](/hi/resources/fundamentals/rate-limits)                                                                                                             | कोई नहीं                         | प्रति 15 मिनट 50 अनुरोध (प्रति उपयोगकर्ता)     |
| किसी [डेवलपर ऐप](/hi/resources/fundamentals/developer-apps) के उन क्रेडेंशियल्स के उपयोग की आवश्यकता है, जो किसी [Project](/hi/resources/fundamentals/developer-apps) से संबद्ध हो |                                  | ✔️                                             |
