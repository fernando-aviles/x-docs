  ## hide replies endpoint का इस्तेमाल करने वाले ऐप्स
</div>

यह उन उल्लेखनीय ऐप्स का संग्रह है जिन्हें उन डेवलपरों ने बनाया है जिन्होंने hide replies endpoint को इंटिग्रेट किया। अपनी तकनीक को X API के साथ जोड़कर, उन्होंने ऐसे उपयोगी अनुभव बनाए जो सभी उपयोगकर्ताओं को सार्वजनिक बातचीत बेहतर बनाने में मदद करते हैं।

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge, hide replies को इंटिग्रेट करता है ताकि कंपनियाँ अपनी X फ़ीड को साफ़-सुथरा और पढ़ने में दिलचस्प बनाए रख सकें। रिप्लाई को मैन्युअल रूप से छिपाया जा सकता है, और एजेंट Clarabridge के text analytics का इस्तेमाल करके अश्लील भाषा और ऐसी अन्य भाषा का अपने-आप पता भी लगा सकते हैं जो ब्रांड नीति के अनुरूप नहीं है।

![Perspective API template app](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Perspective API template app**

Perspective एक कृत्रिम बुद्धिमत्ता है, जिसे Jigsaw (Alphabet की एक इकाई) ने विषाक्त टिप्पणियों का पता लगाने के लिए प्रशिक्षित किया है। यह ऐप किसी व्यक्ति को मिलने वाले रिप्लाई का पता लगाता है और “score” के आधार पर किसी रिप्लाई को अपने-आप छिपा देता है। यह score दर्शाता है कि Perspective को कितना भरोसा है कि कोई टिप्पणी उन विषाक्त टिप्पणियों जैसी है जिन्हें उसने पहले देखा है। यह X द्वारा विकसित एक open source template app है। हम आपको प्रोत्साहित करते हैं कि आप अपने उपयोगकर्ताओं के लिए टूल बनाने हेतु इसे अपनी ज़रूरत के मुताबिक अनुकूलित करें।

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle लचीली scripts के साथ बिज़नेस ऐप्लिकेशन को जोड़ने का एक प्लेटफ़ॉर्म है। उन्होंने एक integration script बनाई है, जो आपके द्वारा तय किए गए keywords वाले रिप्लाई का पता लगाकर उन्हें छिपाती है। इसे आज़माने के लिए, सुनिश्चित करें कि आपके पास Hide replies के लिए सक्षम एक मान्य ऐप है, फिर repo में दिए गए निर्देशों का पालन करें।

**Hide unwanted replies**

लोकप्रिय ऐप QuotedReplies के डेवलपर Dara Oladosu ने एक ऐसा ऐप बनाया है जो उन रिप्लाई को अपने-आप छिपा देता है जो कुछ ऐसे मानदंडों पर खरे उतरते हैं, जिनके बारे में उनका मानना है कि उनमें अपमानजनक व्यवहार होने की संभावना अधिक होती है। इनमें वे रिप्लाई भी शामिल हैं जिनमें ऐसे कुछ keywords होते हैं जिन्हें उन्होंने पहले mute किया है।
