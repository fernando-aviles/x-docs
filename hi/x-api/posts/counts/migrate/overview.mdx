<div id="comparing-x-apis-post-counts-endpoints">
  ## X API के पोस्ट काउंट्स एंडपॉइंट्स की तुलना
</div>

v2 पोस्ट काउंट्स एंडपॉइंट अंततः [enterprise Search API के counts एंडपॉइंट](/hi/x-api/enterprise-gnip-2.0/fundamentals/search-api#counts-requests-post-count) की जगह ले लेगा। यदि आपके पास ऐसा कोड, ऐप्स या टूल हैं जो पोस्ट काउंट्स एंडपॉइंट के किसी पुराने संस्करण का उपयोग करते हैं और आप नए X API v2 एंडपॉइंट्स पर माइग्रेट करने पर विचार कर रहे हैं, तो यह गाइड आपके लिए है।

***

<div id="recent-post-counts-comparison">
  ## हाल के पोस्ट काउंट्स की तुलना
</div>

पोस्ट काउंट्स एंडपॉइंट्स का enterprise संस्करण आपको 30 दिनों के लिए या पूर्ण-आर्काइव से काउंट्स प्राप्त करने की अनुमति देता है। इसलिए, v2 का recent पोस्ट काउंट्स एंडपॉइंट, जो 7 दिनों की समयावधि को देखता है, ऊपर बताए गए किसी भी एंडपॉइंट का सीधा प्रतिस्थापन नहीं है।

हालाँकि, तुलना में सहायता के लिए, हम देखेंगे कि v2 recent पोस्ट काउंट्स एंडपॉइंट की तुलना enterprise 30-day एंडपॉइंट से कैसे की जा सकती है।

निम्न तालिका recent पोस्ट काउंट्स एंडपॉइंट्स के विभिन्न प्रकारों की तुलना करती है:

<div id="filtering-operator-comparison">
  ### फ़िल्टरिंग ऑपरेटर तुलना
</div>

पोस्ट काउंट्स के दो अलग-अलग संस्करणों (enterprise और v2) में उपलब्ध ऑपरेटर अलग हैं। साथ ही, हर संस्करण के भीतर भी ऑपरेटर उपलब्धता के स्तर अलग-अलग हैं, जिन्हें नीचे समझाया गया है।

Enterprise

* enterprise ऑपरेटरों के कोई उप-स्तर नहीं हैं। सभी enterprise ऑपरेटर, सभी enterprise उपयोगकर्ताओं के लिए उपलब्ध हैं।

X API v2

* **Core:** ये ऑपरेटर किसी भी v2 उपयोगकर्ता के लिए उपलब्ध हैं।
* **Advanced:** ये ऑपरेटर केवल उन उपयोगकर्ताओं के लिए उपलब्ध हैं जिन्हें Academic Research ऐक्सेस के लिए स्वीकृति मिली है।

आप इन ऑपरेटर समूहों में से प्रत्येक के बारे में उनकी संबंधित गाइड में अधिक जान सकते हैं:

* [Enterprise operators](/hi/x-api/enterprise-gnip-2.0/fundamentals/search-api#building-search-queries)
* [X API v2 operators](/hi/x-api/posts/search/integrate/build-a-query)

अब जब हम X API v2 के भीतर इन अलग-अलग ऑपरेटर स्तरों को समझ चुके हैं, तो यहाँ वह तालिका दी गई है जो पोस्ट काउंट्स के लिए ऑपरेटर उपलब्धता दिखाती है (ध्यान दें, यदि कोई सेल खाली है, तो वह ऑपरेटर उपलब्ध नहीं है):
