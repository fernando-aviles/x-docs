XDK Python SDK सीधे GitHub रिपॉज़िटरी से उपलब्ध है और इसे `pip` के जरिए इंस्टॉल किया जा सकता है।

<div id="prerequisites">
  ## पूर्वापेक्षाएँ
</div>

* Python 3.8 या उससे नया संस्करण।
* वर्चुअल एनवायरनमेंट के लिए `pip` और `venv` (अनुशंसित)।

<div id="quick-install">
  ## त्वरित इंस्टॉलेशन
</div>

GitHub की उपनिर्देशिका से XDK इंस्टॉल करें:

```bash
pip install xdk
```

यह `main` ब्रांच से जनरेट किए गए नवीनतम संस्करण को प्राप्त करता है।


<div id="development-install">
  ## डेवलपमेंट इंस्टॉल
</div>

डेवलपमेंट या योगदान के लिए:

1. रिपॉज़िटरी क्लोन करें:
   ```bash
   git clone https://github.com/xdevplatform/xdk.git
   cd xdk/python
   ```
2. डिपेंडेंसीज़ को editable मोड में इंस्टॉल करें:
   ```bash
   pip install -e .
   ```
   इससे SDK और उसकी रनटाइम डिपेंडेंसीज़ इंस्टॉल हो जाती हैं।
3. (वैकल्पिक) टेस्टिंग/linting के लिए dev डिपेंडेंसीज़ इंस्टॉल करें:
   ```bash
   pip install -e .[dev]
   ```

<div id="verification">
  ## सत्यापन
</div>

इंस्टॉलेशन की जाँच करें:

```python
import xdk
print(xdk.__version__)  # XDK संस्करण प्रिंट होना चाहिए
```

**नोट:** चूँकि XDK, OpenAPI spec का उपयोग करके जनरेट किया जाता है, इसलिए किसी भी बदलाव के लिए हमेशा [X API changelog](https://docs.x.com/changelog) और repo में मौजूद XDK release notes देखें।
Python XDK का उपयोग करने वाले विस्तृत code examples के लिए, हमारा [code samples GitHub repo](https://github.com/xdevplatform/samples/tree/main/python) देखें।
