Python XDK (X Developer Kit), Python का उपयोग करके X API v2 के साथ इंटरैक्ट करने के लिए हमारी आधिकारिक Client लाइब्रेरी है। यह डेवलपर्स को हमारे API के साथ तेज़ी से शुरुआत करने और उस पर ऐप्लिकेशन बनाने में मदद करता है। इसे हमारे आधिकारिक [OpenAPI specification](https://api.x.com/2/openapi.json) के आधार पर जनरेट किया गया है। यह निम्न-स्तरीय HTTP विवरणों को छिपा देता है, साथ ही ज़रूरत पड़ने पर बारीक नियंत्रण भी प्रदान करता है।

<div id="key-features">
  ## मुख्य विशेषताएँ
</div>

* 🔐 **OAuth समर्थन**: बेयरर टोकन (केवल-ऐप) ऑथ, PKCE के साथ OAuth 2.0 (उपयोगकर्ता कॉन्टेक्स्ट), और OAuth 1.0 के लिए पूर्ण समर्थन।
* 🔄 **पेजिनेशन**: बड़े परिणामों के पेज अपने-आप प्राप्त करें। `next_token` का उपयोग करके कई API कॉल करने की ज़रूरत पड़े बिना, XDK पेजिनेशन संभाल लेता है।
* 📡 **स्ट्रीमिंग**: filtered stream जैसे एंडपॉइंट्स के लिए रीयल-टाइम डेटा स्ट्रीमिंग का समर्थन करता है, जिनके लिए स्थायी HTTP कनेक्शन की आवश्यकता होती है।
* 🎯 **व्यापक कवरेज**: search, timelines, filtered-stream आदि सहित सभी X API v2 एंडपॉइंट्स का समर्थन करता है।
  **संस्करण संगतता**: Python 3.8+। CPython और PyPy पर परीक्षण किया गया है।
