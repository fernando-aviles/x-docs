यह मॉड्यूल X API के साथ इंटरैक्ट करने के लिए मुख्य Client क्लास उपलब्ध कराता है।
यह सभी उप-क्लाइंट का समन्वय करता है और प्रमाणीकरण, सत्र प्रबंधन,
और OAuth2 PKCE फ़्लो को संभालता है। सभी कार्यक्षमता OpenAPI विनिर्देशन से जनरेट की जाती है।

<div id="parameters">
  #### पैरामीटर
</div>

<ParamField path="path.base_url" type="str" default="'https://api.x.com'">
  X API के लिए बेस URL ([https://api.x.com](https://api.x.com) डिफ़ॉल्ट रूप से सेट है)।
</ParamField>

<ParamField path="path.bearer_token" type="str or None" default="None">
  X API के लिए बेयरर टोकन (केवल-ऐप प्रमाणीकरण)।
</ParamField>

<ParamField path="path.access_token" type="str or None" default="None">
  उपयोगकर्ता संदर्भ के लिए OAuth2 access token (इसे सीधे bearer token के रूप में इस्तेमाल किया जा सकता है)।
</ParamField>

<ParamField path="path.client_id" type="str or None" default="None">
  X API के लिए client ID (OAuth2 PKCE flow के लिए आवश्यक)।
</ParamField>

<ParamField path="path.client_secret" type="str or None" default="None">
  X API के लिए client secret।
</ParamField>

<ParamField path="path.redirect_uri" type="str or None" default="None">
  OAuth2 ऑथराइज़ेशन के लिए redirect URI।
</ParamField>

<ParamField path="path.token" type="Dict[str, Any] or None" default="None">
  मौजूदा OAuth2 token dictionary (यदि उपलब्ध हो)। अगर यह दी गई है, तो access&#95;token निकाला जाएगा।
</ParamField>

<ParamField path="path.scope" type="str or List[str] or None" default="None">
  OAuth2 ऑथराइज़ेशन scopes के लिए स्पेस से अलग की गई स्ट्रिंग, या स्ट्रिंग्स की सूची।
</ParamField>

<ParamField path="path.authorization_base_url" type="str" default="'https://x.com/i'">
  OAuth2 ऑथराइज़ेशन के लिए बेस URL ([https://x.com/i](https://x.com/i) डिफ़ॉल्ट रूप से सेट है)।
</ParamField>

<ParamField path="path.auth" type="OAuth1">
  OAuth1.0a प्रमाणीकरण के लिए OAuth1 instance।
</ParamField>

  ### `exchange_code`
</div>

टोकन के लिए ऑथराइज़ेशन कोड का विनिमय करें (TypeScript API से मेल खाता है)।

  #### पैरामीटर

  कॉलबैक से मिला ऑथराइज़ेशन कोड।

  वैकल्पिक कोड सत्यापक (यदि प्रदान नहीं किया गया है, तो संग्रहीत सत्यापक का उपयोग किया जाता है)।
</ParamField>

  ### `fetch_token`
</div>

</ParamField>
