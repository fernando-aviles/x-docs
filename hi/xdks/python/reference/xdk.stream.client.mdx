यह मॉड्यूल X API के stream endpoints के साथ इंटरैक्ट करने के लिए एक क्लाइंट उपलब्ध कराता है।
रीयल-टाइम स्ट्रीमिंग ऑपरेशन ऐसे generators लौटाते हैं जो डेटा आते ही उसे प्रदान करते हैं।
स्ट्रीमिंग कनेक्शन का प्रबंधन, भरोसेमंद संचालन के लिए exponential backoff retry logic के साथ, अपने-आप किया जाता है।
