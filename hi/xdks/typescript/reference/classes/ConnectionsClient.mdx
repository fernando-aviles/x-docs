connections ऑपरेशनों के लिए Client

यह Client, X API के connections endpoints के साथ इंटरैक्ट करने के लिए मेथड उपलब्ध कराता है।
यह authentication, request formatting और connections से संबंधित सभी ऑपरेशनों के लिए
रिस्पॉन्स parsing को संभालता है।
