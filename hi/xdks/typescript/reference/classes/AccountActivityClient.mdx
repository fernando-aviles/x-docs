अकाउंट गतिविधि संचालन के लिए Client

यह Client, X API के account activity endpoints के साथ इंटरैक्ट करने के लिए methods प्रदान करता है।
यह authentication, request formatting, और account activity से संबंधित सभी operations के लिए रिस्पॉन्स
parsing को संभालता है।
