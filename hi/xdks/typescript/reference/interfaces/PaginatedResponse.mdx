पेजिनेटेड रिस्पॉन्स इंटरफ़ेस

X API से प्राप्त पेजिनेटेड API रिस्पॉन्स की संरचना को दर्शाता है।

<div id="type-parameters">
  ## type पैरामीटर
</div>

| नाम | विवरण                     |
| :-- | :------------------------ |
| `T` | रिस्पॉन्स में आइटम का type |

<div id="properties">
  ## गुण
</div>

<ResponseField name="data" type="T[]" required>
  वर्तमान पृष्ठ के आइटमों की सरणी
</ResponseField>

<ResponseField name="meta" type="Object">
  पृष्ठांकन मेटाडेटा

  <Expandable title="गुण">
    <ResponseField name="नाम" type="प्रकार | विवरण" required />

    <ResponseField name="resultCount" type="number | वर्तमान पृष्ठ में परिणामों की संख्या" />

    <ResponseField name="nextToken" type="string | अगला पृष्ठ प्राप्त करने का टोकन" />

    <ResponseField name="previousToken" type="string | पिछला पृष्ठ प्राप्त करने का टोकन" />
  </Expandable>
</ResponseField>

<ResponseField name="includes" type="Record<string, any>">
  शामिल किए गए अतिरिक्त ऑब्जेक्ट (users, tweets, आदि)
</ResponseField>

<ResponseField name="errors" type="any[]">
  रिस्पॉन्स में मौजूद कोई भी त्रुटियाँ
</ResponseField>
