अपने प्रोजेक्ट में X API के लिए TypeScript SDK का इस्तेमाल शुरू करें।

<div id="install">
  ## इंस्टॉल करें
</div>

<CodeGroup>
  ```bash npm theme={null}
  npm install @xdevplatform/xdk
  ```

  ```bash yarn theme={null}
  yarn add @xdevplatform/xdk
  ```

  ```bash pnpm theme={null}
  pnpm add @xdevplatform/xdk
  ```
</CodeGroup>

<div id="typescript-support">
  ## TypeScript समर्थन
</div>

यह SDK TypeScript में लिखा गया है और इसमें पूर्ण type डेफ़िनिशन शामिल हैं। किसी अतिरिक्त type पैकेज की आवश्यकता नहीं है।

<div id="requirements">
  ## आवश्यकताएँ
</div>

* Node.js 16+
* TypeScript 4.5+ (अगर आप TypeScript का उपयोग कर रहे हैं)
