<div id="how-to-get-access-to-the-ads-api">
  ## Ads API का एक्सेस कैसे प्राप्त करें
</div>

1. [डेवलपर खाता](https://developer.x.com/en/apply-for-access) के लिए साइन अप करें।
2. एक [डेवलपर ऐप](https://developer.x.com/app) बनाएं और अपने टोकन को सुरक्षित रखें।
3. अपने प्रत्येक डेवलपर ऐप के लिए Ads API पहुँच का अनुरोध भेजने हेतु [ads.x.com/help](https://ads.x.com/help) पर जाएं।

<Note>**नोट:** अगर आप पहले से ही X Developer Platform पर काम कर रहे हैं और आपके पास डेवलपर खाता है, तो सीधे तीसरे चरण पर जाएं।</Note>

<div id="step-one-signup-for-a-developer-account">
  ### चरण एक: डेवलपर खाते के लिए साइन अप करें
</div>

X के किसी भी API उत्पाद को अनुरोध भेजने के लिए, आपको पहले एक डेवलपर खाते के लिए साइन अप करना होगा। डेवलपर कंसोल में एक ऐप और डेवलपर ऐप बनाएं। इससे आपको क्रेडेंशियल्स का एक सेट मिलेगा, जिसका उपयोग आप API को भेजे जाने वाले सभी अनुरोधों को प्रमाणित करने के लिए करेंगे।

<Button href="https://developer.x.com/en/apply-for-access">
  डेवलपर खाते के लिए साइन अप करें
</Button>

<div id="step-two-save-your-apps-key-and-tokens-and-keep-them-secure">
  ### चरण दो: अपने ऐप की keys और tokens सहेजें और उन्हें सुरक्षित रखें
</div>

अपने डेवलपर ऐप में आपको API Keys (जिन्हें Consumer Keys भी कहा जाता है) का एक सेट दिया जाएगा। आपको Access Tokens का एक सेट जनरेट करने का विकल्प भी मिलेगा, जिनका उपयोग आपके व्यक्तिगत X खाते की ओर से अनुरोध करने के लिए किया जा सकता है। साथ ही, आपको एक बेयरर टोकन भी मिलेगा, जिसका उपयोग उन endpoints को प्रमाणित करने के लिए किया जा सकता है जिनके लिए OAuth 2.0 Bearer Token आवश्यक है। चूंकि ये keys और tokens दोबारा जनरेट किए जाने तक समाप्त नहीं होते, इसलिए हम सलाह देते हैं कि आप environment variables बनाएं या किसी सुरक्षित password manager का उपयोग करें।

कृपया अपने ऐप ID को भी नोट कर लें, जो आपके ऐप के details की URL में मिल सकती है। इससे अगले चरण में Ads API का access अनुरोध करना आसान हो जाएगा।

<Note>
  **नोट:** आपकी keys और tokens डेवलपर कंसोल में केवल एक बार दिखाई देंगी, इसलिए यह ज़रूरी है कि आप इन्हें जनरेट करते ही अपने password management system में सुरक्षित रूप से सहेज लें।

  यदि आपकी keys और tokens खो जाएं या आप उन्हें भूल जाएं, तो आपको उन्हें फिर से जनरेट करना होगा। इससे नई keys और tokens बनेंगे और पुराने अमान्य हो जाएंगे। इसका मतलब है कि आपको उन सभी integrations को अपडेट करना होगा जिन्हें आपने अपने पुराने credentials के साथ सेट अप किया है।

  हमारी [authentication best practices](https://developer.x.com/en/docs/authentication/guides/authentication-best-practices) के बारे में और जानें।
</Note>

<div id="step-three-apply-for-access-to-the-ads-api">
  ### चरण तीन: Ads API तक पहुँच के लिए आवेदन करें
</div>

इस चरण पर आपके पास [X API की बुनियादी पहुँच](https://developer.x.com/en/docs/twitter-api/v1) होगी, लेकिन X Ads API की विशिष्ट सुविधाएँ उपलब्ध नहीं होंगी। इसके बाद, आपको पहुँच का अनुरोध करना होगा और Ads API पहुँच के लिए स्वीकृति लेनी होगी। अपने प्रत्येक डेवलपर ऐप के लिए Ads API पहुँच का अनुरोध सबमिट करने हेतु [ads.x.com/help](https://ads.x.com/help) पर जाएँ।

<div id="access-tiers">
  ### एक्सेस स्तर
</div>

आवेदन प्रक्रिया के तहत, आपको यह बताना होगा कि आपको किस स्तर की एक्सेस चाहिए। [ऐप-स्तरीय और Ad Account-स्तरीय अनुमतियों](https://developer.x.com/en/docs/twitter-ads-api/obtaining-ads-account-access#levels-of-access) के बारे में अधिक जानें।

<div id="conversion-only">
  #### केवल Conversion
</div>

Mobile और Web Conversion endpoints के लिए read &amp; write access.

<div id="standard-access">
  #### मानक एक्सेस
</div>

Analytics, Campaign Management, Creatives, Custom Audiences, और Conversion endpoints के लिए पढ़ने और लिखने की अनुमति के साथ एक्सेस।

<Note>**नोट:** Ads API पहुँच के लिए आपके ऐप के स्वीकृत होने के बाद, ठीक तरह से [authenticated Ads API requests](https://developer.x.com/en/docs/twitter-ads-api/making-authenticated-requests) करने के लिए आपको [किसी भी user access tokens को फिर से जनरेट](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens) करना होगा।</Note>

<Note>**नोट:** जिन Ads API developers ने जुलाई 2023 से पहले एक्सेस का अनुरोध किया था, उनके एक्सेस और permissions के स्तर अलग हो सकते हैं, और वे पाँच OAuth tokens तक सीमित हो सकते हैं। अतिरिक्त endpoints का एक्सेस पाने या मौजूदा applications के लिए token limits हटाने के लिए [एक्सेस बढ़ाने](https://developer.x.com/en/docs/twitter-ads-api/increasing-access) पर हमारी गाइड देखें।</Note>

<div id="make-your-first-request">
  ## अपना पहला अनुरोध करें
</div>

Ads API तक अपनी पहुँच जाँचने के लिए [GET accounts](https://developer.x.com/en/docs/twitter-ads-api/campaign-management/api-reference/accounts) endpoint पर एक अनुरोध करें। यह endpoint उन ad accounts को लौटाता है, जिन तक वर्तमान में अधिकृत उपयोगकर्ता की पहुँच है। किसी खास ad account के लिए डेटा पढ़ने और लिखने हेतु, बाद के API अनुरोधों में इस अनुरोध से प्राप्त ad account IDs का उपयोग करें। कमांड लाइन पर [Twurl](https://developer.x.com/en/docs/tutorials/using-twurl) का उपयोग करने पर यह अनुरोध कुछ इस तरह दिखाई देगा।

**उदाहरण अनुरोध**

```bash
twurl -H ads-api.x.com "/11/accounts"
```
