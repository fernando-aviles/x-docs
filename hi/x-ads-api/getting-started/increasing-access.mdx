<div id="requesting-additional-app-level-permissions">
  ### अतिरिक्त ऐप-स्तरीय अनुमतियों का अनुरोध
</div>

यदि आपका ऐप्लिकेशन नीचे दी गई किसी भी ऐप-स्तरीय अनुमति तक सीमित है और आप अतिरिक्त एंडपॉइंट्स का ऐक्सेस चाहते हैं, तो **Standard Access** के लिए आवेदन करने हेतु कृपया अपने X प्रतिनिधि से संपर्क करें।

जिन डेवलपर्स ने जुलाई 2023 से पहले Ads API ऐक्सेस का अनुरोध किया था, उन्होंने निम्न में से किसी ऐप-स्तरीय अनुमति का अनुरोध किया हो सकता है, जो अब
Standard Access स्तर में शामिल हैं:

* **Analytics** (केवल-पठन): उपयोगकर्ता को [Analytics](https://developer.x.com/en/docs/twitter-ads-api/analytics/overview) एंडपॉइंट्स का [केवल-पठन](https://developer.x.com/en/docs/apps/app-permissions) ऐक्सेस प्राप्त है। उपयोगकर्ता Campaign Management, Creative या Custom Audiences एंडपॉइंट्स का ऐक्सेस नहीं कर सकता, लेकिन Analytics एंडपॉइंट्स के request parameters में creative entities पास करके metrics प्राप्त कर सकता है। media&#95;id या media&#95;name स्तर की granularity प्राप्त करने के लिए, उपयोगकर्ता के ऐप्लिकेशन के पास Ads API write access होना आवश्यक है।

* **Campaign Management &amp; Creative** (पठन और लेखन): उपयोगकर्ता को [Campaign Management](https://developer.x.com/en/docs/twitter-ads-api/campaign-management/overview) और [Creative](https://developer.x.com/en/docs/twitter-ads-api/creatives/overview) एंडपॉइंट्स का [पठन और लेखन](https://developer.x.com/en/docs/apps/app-permissions) ऐक्सेस प्राप्त है। उपयोगकर्ता को Analytics एंडपॉइंट्स का ऐक्सेस भी प्राप्त है।

* **Custom Audiences** (पठन और लेखन): उपयोगकर्ता को [Custom Audiences](https://developer.x.com/en/docs/twitter-ads-api/audiences/overview) एंडपॉइंट्स
  का [पठन और लेखन](https://developer.x.com/en/docs/apps/app-permissions) ऐक्सेस प्राप्त है। उपयोगकर्ता को Campaign Management, Creative और Analytics एंडपॉइंट्स का ऐक्सेस भी प्राप्त है।

* **Conversion** (पठन और लेखन): उपयोगकर्ता को [Mobile](https://developer.x.com/en/docs/twitter-ads-api/measurement/mobile-conversions/overview) और [Web Conversion](https://developer.x.com/en/docs/twitter-ads-api/measurement/web-conversions/overview) एंडपॉइंट्स का [पठन और लेखन](https://developer.x.com/en/docs/apps/app-permissions) ऐक्सेस प्राप्त है। उपयोगकर्ता को अन्य Ads API एंडपॉइंट्स का ऐक्सेस हो भी सकता है और नहीं भी। 

<div id="requesting-an-increase-to-user-oauth-token-limits">
  ### उपयोगकर्ता OAuth टोकन सीमा बढ़ाने का अनुरोध
</div>

जिन डेवलपर्स ने जुलाई 2023 से पहले Ads API ऐक्सेस का अनुरोध किया था, उनकी एप्लिकेशन पर 5 उपयोगकर्ता OAuth टोकन की सीमा हो सकती है। अगर आपको अपने डेवलपर ऐप की टोकन सीमा बढ़ानी है, तो कृपया अपने X प्रतिनिधि से संपर्क करें।

<Note>**नोट:** हम किसी भी Ads API एंडपॉइंट के लिए [रेट लिमिट्स](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting) नहीं बढ़ाते। रेट लिमिट्स के भीतर बने रहने का तरीका जानने के लिए हमारी [सर्वोत्तम प्रक्रियाएँ](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting) देखें।</Note>
