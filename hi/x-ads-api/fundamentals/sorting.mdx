ज़्यादातर Ads API collection endpoints (जो ऑब्जेक्ट्स की सूची लौटाते हैं) के लिए सॉर्टिंग उपलब्ध है। endpoint के आधार पर, आपको सॉर्टिंग के लिए सक्षम अलग-अलग पैरामीटर मिलेंगे। इन पैरामीटरों से लौटाए गए ज़्यादातर फ़ील्ड्स (IDs और ENUMs को छोड़कर) सॉर्ट किए जा सकते हैं।

| API कलेक्शन                                                                               | सॉर्ट किए जा सकने वाले पैरामीटर                                                                                                                                    |
| :---------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [अकाउंट्स](/hi/x-ads-api/campaign-management#accounts)                                       | `created_at`, `updated_at`, `deleted`, `name`                                                                                                                      |
| [फंडिंग इंस्ट्रूमेंट्स](/hi/x-ads-api/campaign-management#funding-instruments)               | `created_at`, `updated_at`, `deleted`, `funded_amount_local_micro`, `start_time`, `end_time`                                                                       |
| [कैंपेन](/hi/x-ads-api/campaign-management#campaigns)                                        | `created_at`, `updated_at`, `deleted`, `name`, `start_time`, `end_time`, `daily_budget_amount_local_micro`, `total_budget_amount_local_micro`, `standard_delivery` |
| [लाइन आइटम](/hi/x-ads-api/campaign-management#line-items)                                    | `created_at`, `updated_at`, `deleted`, `bid_amount_local_micro`                                                                                                    |
| [कार्ड्स](https://developer.x.com/en/docs/ads/creatives/api-reference/image-app-download) | `created_at`, `updated_at`, `deleted`, `name`                                                                                                                      |
| [प्रमोटेड अकाउंट्स](/hi/x-ads-api/campaign-management#advertiser-api)                        | `created_at`, `updated_at`, `deleted`, `paused`                                                                                                                    |
| [प्रमोटेड Tweets](/hi/x-ads-api/campaign-management#promoted-tweets)                         | `created_at`, `updated_at`, `deleted`, `paused`                                                                                                                    |
| [ऐप इवेंट टैग्स](/hi/x-ads-api/measurement/mobile-conversions#app-event-tags)                | `created_at`, `updated_at`, `deleted`, `post_view_attribution_window`, `post_engagement_attribution_window`, `assisted_conversion`, `provider_app_event_name`      |

<div id="getting-started">
  ## शुरुआत करें
</div>

अपने API अनुरोध में बस `sort_by=[attribute name]-[asc/desc]` जोड़ें, जहाँ attribute ऐसा मान्य attribute हो जो आपके GET अनुरोध के JSON में लौटाया जाता है।

उदाहरण के लिए, नाम के अनुसार वर्णक्रम में क्रमबद्ध करने के लिए आप `?name-asc` का उपयोग कर सकते हैं, या उल्टे क्रम में क्रमबद्ध करने के लिए `?name-desc` का उपयोग कर सकते हैं।
