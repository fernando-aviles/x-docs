<div id="mact-overview">
  ## MACT अवलोकन
</div>

X [मोबाइल ऐप प्रचार](https://biz.x.com/mobile-app-promotion) मापन विज्ञापनदाताओं को X पर उन विज्ञापन अभियानों की सफलता ट्रैक करने की सुविधा देता है, जिन्हें इंस्टॉल या अन्य इन-ऐप रूपांतरण बढ़ाने के लिए डिज़ाइन किया गया है। X का एक मोबाइल मापन पार्टनर विज्ञापनदाता को यह प्रबंधित करने की क्षमता देता है कि वह X पर प्रमोट किए जा रहे अपने ऐप्स से किन रूपांतरणों को ट्रैक करना चाहता है। एक बार विज्ञापनदाता उन इवेंट्स के type और समय-सीमाएं सेट कर देता है जिन्हें वह ट्रैक करना चाहता है, तो मोबाइल मापन पार्टनर उन सभी इवेंट्स को X को भेजता है और तुरंत एट्रिब्यूशन डेटा प्राप्त करता है, जो उस अभियान और क्रिएटिव की जानकारी देता है जिनके साथ उपयोगकर्ता ने रूपांतरण कराने के लिए इंटरैक्ट किया था।

<div id="conversion-events">
  ### कन्वर्ज़न इवेंट
</div>

X को [कन्वर्ज़न इवेंट](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-event) रिपोर्ट करने और एट्रिब्यूशन डेटा प्राप्त करने के लिए, पार्टनर को मोबाइल ऐप ID, रूपांतरण का type और timestamp, साथ ही advertising/device ID का एक hashed मान भेजना होगा। यह डेटा देने पर X के प्लेटफ़ॉर्म पर कन्वर्ज़न इवेंट दर्ज हो जाएगा और जहाँ उपयुक्त हो, वहाँ एट्रिब्यूशन भी लौटाया जाएगा। इसके अलावा, विज्ञापनदाता कन्वर्ज़न इवेंट के बारे में अतिरिक्त metadata देना चुन सकता है, जैसे खरीदारी का मान, किसी उत्पाद की ID, या पंजीकरण का तरीका।

<div id="post-conversion_event">
  #### POST conversion_event
</div>

मोबाइल मापन कन्वर्ज़न इवेंट रिकॉर्ड करें। रिस्पॉन्स यह बताएगा कि एट्रिब्यूशन X का है या X Audience Platform (TAP) का।

यह [GET conversion&#95;attribution](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-attribution#get-conversion-attribution) endpoint से संबंधित है।

रिस्पॉन्स में X, TAP, या कोई एट्रिब्यूशन नहीं दिखाया जाएगा। `twitter_attribution` node हमेशा मौजूद रहेगा, और जब X एट्रिब्यूशन नहीं होगा तब उसका मान `null` होगा (नीचे दिया गया उदाहरण रिस्पॉन्स देखें)। अगर TAP एट्रिब्यूशन क्लेम किया जाता है, तो `tpn_attribution` node मौजूद रहेगा और उसी के अनुसार भरा जाएगा। अधिक जानकारी के लिए कृपया [TAP overview](https://developer.x.com/en/docs/x-ads-api/measurement/overview/twitter-audience-platform) देखें।

हर कन्वर्ज़न इवेंट से जुड़े metadata को सेट करने के लिए कई वैकल्पिक parameters उपलब्ध हैं। इस metadata का एट्रिब्यूशन कैलकुलेशन पर कोई प्रभाव नहीं पड़ता।
