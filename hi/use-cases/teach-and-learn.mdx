<div id="educators">
  ## शिक्षकों
</div>

अपनी कक्षा में API को शामिल करें, ताकि छात्र प्रोग्रामिंग की बुनियादी बातें और
डेटा प्रोसेसिंग के उपयोगी कौशल सीख सकें।

**संसाधन:**

क्या आप ऐसे शिक्षक हैं जो अपने पाठ्यक्रम में X API का उपयोग करना चाहते हैं? यह
[X API के साथ शिक्षण की मार्गदर्शिका](https://dev.to/suhemparack/a-guide-to-teaching-with-the-twitter-api-v2-3n08)
आपको X API को समझने, यह जानने में कि शिक्षक इसका उपयोग क्यों करते हैं, X API की मदद से किस तरह की
कक्षाएँ पढ़ाई जा रही हैं, और शुरुआत करने के लिए ज़रूरी अन्य सभी बातों को समझने में मदद करेगी।

**मुख्य आकर्षण:**

नीचे दिए गए पाठ्यक्रम X API v2 का उपयोग करके तैयार और संचालित किए जाते हैं:

* [Social Media Data Mining and Analysis](https://canvas.uw.edu/courses/1434897)
  डॉ. Tanu Mitra द्वारा

* [Data Science &amp; Society](https://dssoc.github.io/) डॉ. Chris Bail द्वारा

* [Introduction to Cultural Analytics &amp; Python](https://melaniewalsh.github.io/Intro-Cultural-Analytics/welcome.html)
  डॉ. Melanie Walsh द्वारा

* [Oxford Spring School in Advanced Research Methods, Analysing X Data](https://github.com/cjbarrie/oxspsch)
  डॉ. Chris Barrie द्वारा
