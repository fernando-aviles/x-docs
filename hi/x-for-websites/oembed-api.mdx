आप oEmbed API का उपयोग प्रोग्रामेटिक रूप से एम्बेड किया गया कॉन्टेंट लौटाने के लिए कर सकते हैं, जैसे [Tweets](https://developer.x.com/en/docs/twitter-for-websites/embedded-tweets/overview) और [timelines](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview)। 

oEmbed API का रिस्पॉन्स एक HTML स्निपेट लौटाता है, जिसे [पेज में X का widget JavaScript शामिल होने पर](https://developer.x.com/web/javascript/loading) स्वचालित रूप से पहचान लिया जाता है।

कृपया ध्यान दें कि API का उपयोग बड़े पैमाने पर कार्य करने के लिए सुझाया जाता है, और कॉन्टेंट एम्बेड करने के लिए हम अपने सशक्त [publish.x.com](https://publish.x.com/#) टूल का उपयोग करने की सलाह देते हैं।

  <Tab title="एम्बेड की गई टाइमलाइनें">
    लौटाया गया HTML स्निपेट अपने-आप एक [एम्बेडेड टाइमलाइन](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview) के रूप में पहचाना जाएगा, जब [पेज में X का widget JavaScript शामिल हो](https://developer.x.com/web/javascript/loading).

    oEmbed endpoint, HTML markup में संबंधित गुण सेट करके, एम्बेडेड टाइमलाइन के अंतिम रूप को अनुकूलित करने की सुविधा देता है। इन गुणों की व्याख्या डिफ़ॉल्ट रूप से HTML रिस्पॉन्स के साथ बंडल किए गए X के JavaScript द्वारा की जाती है। लौटाए गए markup का प्रारूप समय के साथ बदल सकता है, क्योंकि X नई सुविधाएँ जोड़ता है या अपनी टाइमलाइन प्रस्तुति को समायोजित करता है।

    टाइमलाइन URL द्वारा निर्दिष्ट X टाइमलाइन के लिए, [oEmbed](https://oembed.com/)-संगत JSON प्रारूप में। उपयोगकर्ता और सूची टाइमलाइन समर्थित हैं। टाइमलाइन markup को आपके सर्वरों पर cache&#95;age गुण द्वारा निर्दिष्ट सुझाई गई cache lifetime तक कैश किया जाना चाहिए।

    ## उदाहरण अनुरोध

    ```bash
    curl --request GET --url 'https://publish.x.com/oembed?url=https%3A%2F%2Ftwitter.com%2FInterior%2Fstatus%2F507185938620219395'
    twurl -H publish.x.com "/oembed?url=https://x.com/Interior/status/463440424141459456"
    ```

  <Tab title="एम्बेड किए गए Tweet">
    लौटाया गया HTML स्निपेट स्वचालित रूप से एक [embedded Tweet](https://developer.x.com/web/embedded-tweets) के रूप में पहचाना जाएगा, जब [X का widget JavaScript पेज पर include किया गया हो](https://developer.x.com/web/javascript/loading)।

    oEmbed एंडपॉइंट, Embedded Tweet के अंतिम स्वरूप को कस्टमाइज़ करने की सुविधा देता है — इसके लिए HTML मार्कअप में संबंधित गुण सेट किए जाते हैं, जिन्हें डिफ़ॉल्ट रूप से HTML रिस्पॉन्स के साथ बंडल किए गए X के JavaScript द्वारा interpret किया जाता है। लौटाए गए मार्कअप का फ़ॉर्मेट समय के साथ बदल सकता है, क्योंकि X नई सुविधाएँ जोड़ता रहता है या अपने Tweet representation में बदलाव करता है।

    Tweet फ़ॉलबैक मार्कअप को आपके सर्वर पर `cache_age` प्रॉपर्टी में निर्दिष्ट सुझाई गई कैश अवधि तक कैश किया जाना चाहिए।
