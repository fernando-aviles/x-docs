<div id="educators">
  ## 教育者のみなさまへ
</div>

プログラミングの基礎や有用なデータ処理スキルを教えるために、API を授業に取り入れてください。

**リソース：**

授業で X API を使いたい教育者の方は、こちらの
[X API を使った授業のためのガイド](https://dev.to/suhemparack/a-guide-to-teaching-with-the-twitter-api-v2-3n08)
を参照してください。X API とは何か、なぜ教育現場で使われているのか、どのような授業が API を使って行われているのか、そして導入を始めるために知っておくべきことを理解するのに役立ちます。

**スポットライト：**

以下のカリキュラムは、X API v2 を用いて構築および実施されています。

- [Social Media Data Mining and Analysis](https://canvas.uw.edu/courses/1434897)
  （Dr. Tanu Mitra）

- [Data Science & Society](https://dssoc.github.io/) （Dr. Chris Bail）

- [Introduction to Cultural Analytics & Python](https://melaniewalsh.github.io/Intro-Cultural-Analytics/welcome.html)
  （Dr. Melanie Walsh）

- [Oxford Spring School in Advanced Research Methods, Analysing X Data](https://github.com/cjbarrie/oxspsch)
  （Dr. Chris Barrie）
