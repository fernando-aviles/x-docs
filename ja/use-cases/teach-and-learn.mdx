<div id="educators">
  ## 教育者の方へ
</div>

学生にプログラミングの基礎と、実践的なデータ処理スキルを教えるために、API を授業に取り入れましょう。

**リソース:**

授業で X API を活用したい教育者の方は、この
[「X API を用いた授業設計ガイド」](https://dev.to/suhemparack/a-guide-to-teaching-with-the-twitter-api-v2-3n08)
を参照してください。X API とは何か、教育現場でなぜ利用されているのか、どのような
授業で API が活用されているのか、そして導入を始めるにあたって知っておくべきことを理解するのに役立ちます。

**事例紹介:**

以下のカリキュラムは、X API v2 を用いて構築・実施されています。

- [Social Media Data Mining and Analysis](https://canvas.uw.edu/courses/1434897)
  （Dr. Tanu Mitra）

- [Data Science & Society](https://dssoc.github.io/)（Dr. Chris Bail）

- [Introduction to Cultural Analytics & Python](https://melaniewalsh.github.io/Intro-Cultural-Analytics/welcome.html)
  （Dr. Melanie Walsh）

- [Oxford Spring School in Advanced Research Methods, Analysing X Data](https://github.com/cjbarrie/oxspsch)
  （Dr. Chris Barrie）
