<div id="ways-to-build-for-people-on-x">
  ## X 上の人々のために構築する方法
</div>

私たちは、公共の会話に良い影響を与え、X 上の人々に役立つ新しいツールやプロダクトを構築していただくために、プラットフォームを開放しています。とりわけ、次の領域での新たなイノベーションと開発を奨励しています。

<CardGroup>
  <Card title="健全性と安全性のために会話をモデレートする" icon="bullhorn" iconType="solid">
    コンテンツモデレーションツールや、X 上の会話に安心して、そして前向きな気持ちで参加できるようにするその他のソリューションを構築し、公共の会話の健全性と安全性の向上に貢献してください。人々が自分の体験や会話のコントロール方法について、より幅広いツールから包括的に選べるようにする補完的／付加的なテクノロジーを構築してください。

    [**詳細はこちら**](/ja/x-api/what-to-build#moderate-conversations-for-health-and-safety) <Icon icon="arrow-right" />
  </Card>

  <Card title="創作と個人表現を可能にする" icon="bullhorn" iconType="solid">
    リーチを広げたいクリエイター、ブランド、個人、ブランドを表現したい人、自分の情熱を共有する人々とつながりたい人のためのツールを構築してください。または、クロスポストされたコンテンツ、ゲーミフィケーション、役立つボットなどを通じて、人々が X 上で関わることのできる方法を広げてください。

    [**詳細はこちら**](/ja/x-api/what-to-build#enable-creation-and-personal-expression) <Icon icon="arrow-right" />
  </Card>

  <Card title="「いま起きていること」を測定・分析する" icon="bullhorn" iconType="solid">
    公共の会話や自分自身のコンテンツを測定・分析し、インサイトを得られるよう、人々を支援してください。オーディエンスをより深く理解し、コンテンツの成果や影響を測定し、より十分な情報に基づいた意思決定を行うなど、多くのことが可能になります。

    [**詳細はこちら**](/ja/x-api/what-to-build#measure-and-analyze-whats-happening) <Icon icon="arrow-right" />
  </Card>

  <Card title="コミュニティ体験を向上させる" icon="bullhorn" iconType="solid">
    X はすべての人のためのものであり、X 上の多様なコミュニティそれぞれの固有のニーズに、皆さんの専門性を活かしてより良く応えられるよう、私たちは後押ししたいと考えています。新興グローバル市場向けのローカライズされたソリューションを構築する場合でも、ゲームや金融といったプラットフォーム上で成長するコミュニティ向けの体験を強化する場合でも、X 上の誰もが自分の居場所を見つけられるようにしたいと考えています。

    [**詳細はこちら**](/ja/x-api/what-to-build#improve-community-experiences) <Icon icon="arrow-right" />
  </Card>

  <Card title="コンテンツをキュレーションしておすすめする" icon="bullhorn" iconType="solid">
    人々が新しいコンテンツを発見したり、新しいつながりを得たりするのに役立つアプリやボット、その他のツールを構築してください。または、キュレーションされ、カスタマイズ可能な体験を提供し、人々が最も関心のあるコンテンツをより多く見られるようにしてください。

    [**詳細はこちら**](/ja/x-api/what-to-build#curate-and-recommend-content) <Icon icon="arrow-right" />
  </Card>

  <Card title="社会全体の利益に貢献する" icon="bullhorn" iconType="solid">
    画期的な研究を行い、公衆衛生や気候危機に関する知見の進展に貢献し、非商用の取り組みを通じて社会全体の利益のために構築してください。

    [**詳細はこちら**](/ja/x-api/what-to-build#impact-the-greater-good) <Icon icon="arrow-right" />
  </Card>
</CardGroup>
