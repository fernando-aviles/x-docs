<div id="ways-to-build-for-people-on-x">
  ## X 上の人々のために構築する方法
</div>

私たちは、公共の会話にポジティブな影響を与え、X 上の人々に役立つ新しいツールやプロダクトを皆さんに構築していただけるよう、プラットフォームを開放しています。具体的には、次の分野での新たなイノベーションと開発を推進したいと考えています。

<CardGroup>
  <Card title="会話をモデレートして健全性と安全性を高める" icon="bullhorn" iconType="solid">
    X 上の会話に人々が安心して意欲的に参加できるようにするコンテンツモデレーションツールやその他のソリューションを構築することで、公共の会話の健全性と安全性の向上に貢献してください。補完的または付加的なテクノロジーを構築し、人々が自身のやり取りをコントロールできるよう、幅広いツールの選択肢を提供しましょう。

    [**詳細はこちら**](/ja/x-api/what-to-build#moderate-conversations-for-health-and-safety) <Icon icon="arrow-right" />
  </Card>

  <Card title="創造と自己表現を可能にする" icon="bullhorn" iconType="solid">
    クリエイター、ブランド、そして自分のリーチを広げ、ブランドを表現し、自分の情熱を共有する人々とつながりたい個人のためのツールを構築してください。あるいは、クロス投稿コンテンツ、ゲーミフィケーション、便利なボットなどを通じて、人々が X 上で関わり合う方法の幅を広げてください。

    [**詳細はこちら**](/ja/x-api/what-to-build#enable-creation-and-personal-expression) <Icon icon="arrow-right" />
  </Card>

  <Card title="「いま起きていること」を計測・分析する" icon="bullhorn" iconType="solid">
    公共の会話や自分自身のコンテンツを計測・分析し、インサイトを得られるよう人々を支援してください。オーディエンスをより深く理解し、コンテンツのパフォーマンスとインパクトを測定し、より情報に基づいた意思決定を行えるようにします。

    [**詳細はこちら**](/ja/x-api/what-to-build#measure-and-analyze-whats-happening) <Icon icon="arrow-right" />
  </Card>

  <Card title="コミュニティ体験を向上させる" icon="bullhorn" iconType="solid">
    X はすべての人のための場であり、X 上のさまざまなコミュニティの固有ニーズによりよく応えるために、皆さんの専門性を活かしていただきたいと考えています。新興グローバル市場向けのローカライズされたソリューションを構築する場合でも、ゲームや金融などプラットフォーム上で成長しているコミュニティの体験を強化する場合でも、誰もが X 上で自分の居場所を見つけられるようにしたいと考えています。

    [**詳細はこちら**](/ja/x-api/what-to-build#improve-community-experiences) <Icon icon="arrow-right" />
  </Card>

  <Card title="コンテンツをキュレーションし、レコメンドする" icon="bullhorn" iconType="solid">
    人々が新しいコンテンツを発見したり、新しいつながりを見つけたりするのに役立つ App、ボット、その他のツールを構築してください。あるいは、キュレーションされカスタマイズ可能なエクスペリエンスを構築し、人々が最も関心のあるコンテンツをより多く見られるようにしてください。

    [**詳細はこちら**](/ja/x-api/what-to-build#curate-and-recommend-content) <Icon icon="arrow-right" />
  </Card>

  <Card title="より大きな公益に貢献する" icon="bullhorn" iconType="solid">
    画期的な研究を行い、公衆衛生や気候危機に関する知見の発展に貢献し、より大きな公益を目的とした非商業的なプロジェクトを構築してください。

    [**詳細はこちら**](/ja/x-api/what-to-build#impact-the-greater-good) <Icon icon="arrow-right" />
  </Card>
</CardGroup>
