<div id="ways-to-build-for-people-on-x">
  ## X 上の人々のために開発する方法
</div>

私たちはプラットフォームを開放し、公共の会話に良い影響を与え、X 上の人々に役立つ新しいツールやプロダクトを開発していただくことを奨励しています。特に、次の分野での新たなイノベーションと開発を推進したいと考えています。

<CardGroup>
  <Card title="会話をモデレートして健全性と安全性を守る" icon="bullhorn" iconType="solid">
    X 上の会話に安心してワクワクしながら参加できるようにするコンテンツモデレーションツールやその他のソリューションを構築することで、公共の会話の健全性と安全性の向上に貢献してください。補完的または付加的なテクノロジーを構築し、人々が自分の利用体験ややり取りをコントロールするための多様なツールから包括的に選択できるようにしましょう。

    [**詳細を見る**](/ja/x-api/what-to-build#moderate-conversations-for-health-and-safety) <Icon icon="arrow-right" />
  </Card>

  <Card title="創造と自己表現を可能にする" icon="bullhorn" iconType="solid">
    リーチを拡大し、自身のブランドを表現し、自分の情熱を共有する人々とつながりたいクリエイター、ブランド、個人のためのツールを構築してください。あるいは、クロスポストされたコンテンツ、ゲーミフィケーション、便利なボットなどを通じて、X 上で人々が関わる方法の幅を広げてください。

    [**詳細を見る**](/ja/x-api/what-to-build#enable-creation-and-personal-expression) <Icon icon="arrow-right" />
  </Card>

  <Card title="「今起きていること」を計測し分析する" icon="bullhorn" iconType="solid">
    公共の会話や自分自身のコンテンツを計測・分析し、そこからインサイトを引き出せるよう人々を支援してください。オーディエンスをより深く理解し、コンテンツのパフォーマンスと影響を測定し、十分な情報に基づいた意思決定を行うなど、さまざまなことが可能になります。

    [**詳細を見る**](/ja/x-api/what-to-build#measure-and-analyze-whats-happening) <Icon icon="arrow-right" />
  </Card>

  <Card title="コミュニティ体験を向上させる" icon="bullhorn" iconType="solid">
    X はすべての人のためのものであり、X 上のさまざまなコミュニティの固有のニーズによりよく応えるために、皆さんの専門性を生かしていただきたいと考えています。新興グローバル市場向けのローカライズされたソリューションを構築する場合でも、ゲームやファイナンスのようにプラットフォーム上で成長しているコミュニティの体験を強化する場合でも、X 上で誰もが自分の居場所を見つけられるようにしたいと考えています。

    [**詳細を見る**](/ja/x-api/what-to-build#improve-community-experiences) <Icon icon="arrow-right" />
  </Card>

  <Card title="コンテンツをキュレーションしレコメンドする" icon="bullhorn" iconType="solid">
    人々が新しいコンテンツを発見したり、新たなつながりを見つけたりできるようにするアプリ、ボット、その他のツールを構築してください。また、人々が最も関心のあるコンテンツをより多く目にできるよう、キュレーションされ、カスタマイズ可能な体験を構築してください。

    [**詳細を見る**](/ja/x-api/what-to-build#curate-and-recommend-content) <Icon icon="arrow-right" />
  </Card>

  <Card title="より大きな公益に貢献する" icon="bullhorn" iconType="solid">
    先駆的な研究を実施し、公衆衛生や気候危機に関する知識の発展に貢献し、より大きな公益のために非営利のプロジェクトを構築してください。

    [**詳細を見る**](/ja/x-api/what-to-build#impact-the-greater-good) <Icon icon="arrow-right" />
  </Card>
</CardGroup>
