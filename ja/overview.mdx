<div id="pricing">
  ## 料金
</div>

X API は **従量課金** の料金体系を採用しています。月額サブスクリプションはなく、使った分だけ支払います。

<CardGroup cols={2}>
  <Card title="柔軟" icon="sliders">
    利用ニーズに応じてスケールを柔軟に調整できます。コストは利用量に応じて増加します。
  </Card>

  <Card title="利用しやすい" icon="door-open">
    小規模な Project でも始めやすくなります。料金プランの段階的な引き上げや長期契約は不要です。
  </Card>
</CardGroup>
