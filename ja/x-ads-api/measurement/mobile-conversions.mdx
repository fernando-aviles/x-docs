<div id="mact-overview">
  ## MACT の概要
</div>

X の[モバイルアプリプロモーション](https://biz.x.com/mobile-app-promotion)の計測機能により、広告主は、アプリのインストールやその他のアプリ内コンバージョンの促進を目的として X 上で実施する広告キャンペーンの成果をトラッキングできます。X のモバイル計測パートナーは、広告主が X 上でプロモーションするアプリからどのコンバージョンを計測対象とするかを管理できるようにします。広告主がトラッキングしたいイベントのタイプおよび時間ウィンドウを設定すると、モバイル計測パートナーはそれらすべてのイベントを X に送信し、コンバージョンに至るまでユーザーがどのキャンペーンやクリエイティブに接触したかを示すアトリビューションデータを即座に受信します。

<div id="conversion-events">
  ### コンバージョンイベント
</div>

[コンバージョンイベント](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-event) を X に報告してアトリビューションデータを取得するには、パートナーはモバイルアプリ ID、コンバージョンのタイプとタイムスタンプに加えて、広告 ID やデバイス ID のハッシュ化された値を送信する必要があります。これらの情報を提供することで、X のプラットフォーム上にコンバージョンイベントが記録され、適切な場合にはアトリビューションデータが返されます。さらに広告主は、購入金額、商品の ID、登録方法など、コンバージョンイベントに関する追加のメタデータを任意で提供できます。

<div id="post-conversion_event">
  #### POST conversion_event
</div>

モバイル計測用コンバージョンイベントを記録します。レスポンスには、X または X Audience Platform (TAP) のアトリビューションが示されます。

これは [GET conversion&#95;attribution](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-attribution#get-conversion-attribution) エンドポイントに対応しています。

レスポンスでは、X、TAP、またはアトリビューションなしのいずれかが示されます。`twitter_attribution` ノードは常に存在し、X のアトリビューションがない場合は値が `null` になります（以下のレスポンス例を参照してください）。TAP のアトリビューションがある場合は、`tpn_attribution` ノードが存在し、適切に値が設定されます。詳しくは [TAP overview](https://developer.x.com/en/docs/x-ads-api/measurement/overview/twitter-audience-platform) を参照してください。

各コンバージョンイベントに関連付けるメタデータを設定するためのオプションのパラメーターがいくつか用意されています。これらのメタデータはアトリビューション計算には影響しません。

<div id="resource-url">
  ##### リソース URL
</div>

`https://ads-api.x.com/12/conversion_event`

<div id="parameters">
  ##### Parameters
</div>

| Name | Description |
| :--- | :--- |
| app&#95;id  <br />*必須* | 対応するアプリストアでの一意の識別子。<br /><br />タイプ: int, string<br /><br />例: `333903271`, `com.vine.android` |
| conversion&#95;time  <br />*必須* | コンバージョンイベントの時刻。ミリ秒付きの ISO-8601 タイムスタンプ形式。<br /><br />タイプ: 文字列型<br /><br />例: `2014-05-22T02:38:28.103Z` |
| conversion&#95;type  <br />*必須* | コンバージョンイベントのタイプ。<br /><br />タイプ: enum<br /><br />取りうる値: `PURCHASE`, `SIGN_UP`, `INSTALL`, `RE_ENGAGE`, `UPDATE`, `TUTORIAL_COMPLETE`, `RESERVATION`, `ADD_TO_CART`, `ADD_TO_WISHLIST`, `LOGIN`, `CHECKOUT_INITIATED`, `SEARCH`, `LEVEL_ACHIEVED`, `ACHIEVEMENT_UNLOCKED`, `CONTENT_VIEW`, `SHARE`, `INVITE`, `ADDED_PAYMENT_INFO`, `SPENT_CREDITS`, `RATED` |
| hashed&#95;device&#95;id  <br />*必須* | HMAC&#95;SHA-256 でハッシュ化された IDFA または AdID。<br /><br />タイプ: 文字列型<br /><br />例: `ABCD1234XYZ` |
| os&#95;type  <br />*必須* | アプリの OS のタイプ。<br /><br />タイプ: enum<br /><br />取りうる値: `IOS`, `ANDROID` |
| click&#95;window  <br />*任意* | このイベントのクリック計測期間（日数）。<br /><br />タイプ: int<br /><br />**注意**: `click_window` は view&#95;through&#95;window 以上である必要があります。<br /><br />デフォルト: `14`  <br />取りうる値: `1`, `7`, `14`, `30` |
| device&#95;ip&#95;address  <br />*任意* | コンバージョンイベント発生時のデバイスの IPv4 または IPv6 アドレス。<br /><br />タイプ: 文字列型<br /><br />例: `192.133.78.1` |
| level  <br />*任意* | このイベントに関連付けられたレベル。<br /><br />タイプ: int<br /><br />例: `2` |
| non&#95;twitter&#95;engagement&#95;time  <br />*任意* | コンバージョン前の、直近の Twitter 以外でのエンゲージメントの時刻。<br /><br />タイプ: 文字列型<br /><br />例: `2014-05-22T02:38:28.103Z` |
| non&#95;twitter&#95;engagement&#95;type  <br />*任意* | コンバージョンイベント前の、Twitter 以外でのエンゲージメントのタイプ。<br /><br />タイプ: enum<br /><br />取りうる値: `CLICK`, `VIEW` |
| number&#95;items  <br />*任意* | このイベントに関連付けられたアイテム数。<br /><br />タイプ: int<br /><br />例: `2` |
| price&#95;currency  <br />*任意* | このイベントに関連付けられた通貨を示す ISO 4217 コード。<br /><br />タイプ: 文字列型<br /><br />例: `EUR`,`USD`,`JPY` |
| price&#95;micro  <br />*任意* | このイベントに関連付けられた金額（マイクロ単位）。<br /><br />タイプ: int<br /><br />例: `123450000` |
| user&#95;payment&#95;info  <br />*任意* | このイベントに関連付けられたアプリに、ユーザーの支払い情報が保存されているかどうかを示す boolean 値。<br /><br />タイプ: bool<br /><br />取りうる値: `true` または `false` |
| view&#95;through&#95;window  <br />*任意* | このイベントのビュー計測期間（日数）。<br /><br />**注意**:<br /><br />`click_window` は view&#95;through&#95;window 以上である必要があります。<br /><br />タイプ: int<br /><br />デフォルト: `1`  <br />取りうる値: `0`, `1`, `7`, `14`, `30` |

<div id="get-accountsaccount_idapp_event_tags">
  #### GET accounts/:account_id/app_event_tags
</div>

現在のアカウントに紐付いている一部またはすべての app event tags の詳細を取得します。

これらのタグは、Mobile App Conversion Tracking において、各コンバージョンタイプごとに設定されるコンバージョンウィンドウを定義します。

##### リソースURL

`https://ads-api.x.com/12/accounts/:account_id/app_event_tags`

<div id="parameters">
  ##### Parameters
</div>

| Name | Description |
| :--- | :--- |
| account&#95;id  <br />*必須* | 対象アカウントの識別子です。リソースのパス内に含まれ、[GET accounts](/ja/x-ads-api/campaign-management#accounts) を除くすべての Advertiser API リクエストで通常必須となるパラメータです。指定されたアカウントは、認証済みユーザーに関連付けられている必要があります。<br /><br />Type: 文字列型<br /><br />Example: `18ce54d4x5t` |
| app&#95;event&#95;tag&#95;ids  <br />*任意* | カンマ区切りの識別子リストを指定して、レスポンスを目的の app event tag のみに絞り込みます。最大 200 個の ID を指定できます。<br /><br />Type: 文字列型<br /><br />Example: `jhp` |
| count  <br />*任意* | 1 回のリクエストあたりで取得を試みるレコード数を指定します。<br /><br />Type: int<br /><br />Default: `200`  <br />Min, Max: `1`, `1000` |
| cursor  <br />*任意* | 次のページの結果を取得するためのカーソルを指定します。詳細は [Pagination](/ja/x-ads-api/introduction) を参照してください。<br /><br />Type: 文字列型<br /><br />Example: `8x7v00oow` |
| sort&#95;by  <br />*任意* | サポートされている属性を基準に、昇順または降順で並べ替えます。詳細は [Sorting](/ja/x-ads-api/fundamentals/sorting) を参照してください。<br /><br />Type: 文字列型<br /><br />Example: `created_at-asc` |
| with&#95;deleted  <br />*任意* | リクエストに削除済みの結果を含めます。<br /><br />Type: boolean<br /><br />Default: `false`  <br />Possible values: `true`, `false` |
| with&#95;total&#95;count  <br />*任意* | `total_count` レスポンス属性を含めます。<br /><br />**注**: このパラメータと `cursor` は排他的です。<br /><br />**注**: `total_count` を含むリクエストはレート制限が低くなり、現在は 15 分あたり 200 回に設定されています。<br /><br />Type: boolean<br /><br />Default: `false`  <br />Possible values: `true`, `false` |

これは [POST conversion&#95;event](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-event#post-conversion-event) エンドポイントに関連しています。

レスポンスでは、X、TAP、またはアトリビューションなしのいずれかが返されます。`twitter_attribution` ノードは必ず存在し、X アトリビューションがない場合は値が `null` となり、X アトリビューションがある場合は以下の例のレスポンスのように値が設定されます。TAP アトリビューションがある場合は `tpn_attribution` ノードが存在し、適切に値が設定されます。詳細については [TAP overview](https://developer.x.com/en/docs/twitter-ads-api/measurement/twitter-audience-platform/overview) を参照してください。

##### リソースURL

`https://ads-api.x.com/12/conversion_attribution`

##### パラメータ

| 名前 | 説明 |
| :--- | :--- |
| app&#95;id  <br />*required* | 対応するアプリストアでの一意の識別子。<br /><br />タイプ: int, string<br /><br />例: `333903271`, `com.vine.android` |
| conversion&#95;time  <br />*required* | ミリ秒付きの ISO-8601 タイムスタンプ形式によるコンバージョンイベントの発生時刻。<br /><br />タイプ: string<br /><br />例: `2014-05-22T02:38:28.103Z` |
| conversion&#95;type  <br />*required* | コンバージョンイベントのタイプ。<br /><br />タイプ: enum<br /><br />取りうる値: `ACHIEVEMENT_UNLOCKED`, `ADDED_PAYMENT_INFO`, `ADD_TO_CART`, `ADD_TO_WISHLIST`, `CHECKOUT_INITIATED`, `CONTENT_VIEW`, `INSTALL`, `INVITE`, `LEVEL_ACHIEVED`, `LOGIN`, `PURCHASE`, `RATED`, `RESERVATION`, `RE_ENGAGE`, `SEARCH`, `SHARE`, `SIGN_UP`, `SPENT_CREDITS`, `TUTORIAL_COMPLETE`, `UPDATE` |
| hashed&#95;device&#95;id  <br />*required* | HMAC&#95;SHA-256 でハッシュ化された IDFA または AdID。<br /><br />タイプ: string<br /><br />例: `ABCD1234XYZ` |
| os&#95;type  <br />*required* | アプリの OS のタイプ。<br /><br />タイプ: enum<br /><br />取りうる値: `IOS`, `ANDROID` |
| click&#95;window  <br />*optional* | このイベントのクリック計測期間（日単位）。<br /><br />タイプ: int<br /><br />デフォルト: `14`  <br />取りうる値: `1`, `7`, `14`, `30` |
| extra&#95;device&#95;ids  <br />*optional* | `hashed_device_id` で渡されたデバイス ID の SHA1 をさらに SHA256 でハッシュ化した値と、追加のハッシュ化済みデバイス ID。<br /><br />タイプ: string<br /><br />例: `ABCD1234XYZ`, `DCBA4321XYZ` |
| non&#95;twitter&#95;engagement&#95;time  <br />*optional* | コンバージョン前に行われた直近の非 Twitter エンゲージメントの時刻。<br /><br />タイプ: string<br /><br />例: `2014-05-22T02:38:28.103Z` |

| view&#95;through&#95;window  <br />*optional* | このイベントのビュー経由の計測期間（日単位）。<br /><br />タイプ: int<br /><br />デフォルト: `1`  <br />取りうる値: `0`, `1`, `7`, `14`, `30` |
