<div id="mact-overview">
  ## MACT の概要
</div>

X の[モバイルアプリプロモーション](https://biz.x.com/mobile-app-promotion)の計測機能により、広告主はインストールやその他のアプリ内コンバージョン獲得を目的として X 上で実施する広告キャンペーンの成果を計測できます。X のモバイル計測パートナーを利用することで、広告主は X 上でプロモーションしているアプリについて、どのコンバージョンを計測対象とするかを管理できます。広告主が計測したいイベントのタイプと計測期間（タイムウィンドウ）を設定すると、モバイル計測パートナーはそれらすべてのイベントを X に送信し、ユーザーがコンバージョンに至るまでにエンゲージしたキャンペーンおよびクリエイティブを示すアトリビューションデータを即時に受け取ります。

<div id="conversion-events">
  ### Conversion Events
</div>

[conversion event](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-event) を X に報告してアトリビューションデータを取得するには、パートナーはモバイルアプリの ID、コンバージョンのタイプとタイムスタンプ、さらに広告 ID／デバイス ID をハッシュ化した値を送信する必要があります。これらのデータを提供することで、コンバージョンイベントは X のプラットフォーム上に記録され、適切な場合にはアトリビューションも返されます。さらに、広告主は購入金額、商品の ID、登録方法など、コンバージョンイベントに関する追加のメタデータを任意で提供できます。

<div id="post-conversion_event">
  #### POST conversion_event
</div>

モバイル計測用のコンバージョンイベントを記録します。レスポンスには、X または X Audience Platform (TAP) のアトリビューションが示されます。

これは [GET conversion&#95;attribution](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-attribution#get-conversion-attribution) エンドポイントに関連します。

レスポンスでは、X、TAP、またはアトリビューションなしのいずれかが付与されます。`twitter_attribution` ノードは常に存在し、X のアトリビューションがない場合は値が `null` になります（下記のレスポンス例を参照してください）。TAP のアトリビューションが付与されている場合は、`tpn_attribution` ノードが存在し、適切な値で設定されます。詳細については [TAP overview](https://developer.x.com/en/docs/x-ads-api/measurement/overview/twitter-audience-platform) を参照してください。

各コンバージョンイベントに関連付けられたメタデータを設定するために使用できるオプションパラメータがいくつかあります。これらのメタデータはアトリビューション計算には影響しません。

<div id="resource-url">
  ##### リソース URL
</div>

`https://ads-api.x.com/12/conversion_event`

<div id="parameters">
  ##### Parameters
</div>

| Name | Description |
| :--- | :--- |
| app&#95;id  <br />*必須* | 対応するアプリストアでの一意の識別子。<br /><br />Type: int, string<br /><br />Example: `333903271`, `com.vine.android` |
| conversion&#95;time  <br />*必須* | コンバージョンイベントの時刻。ミリ秒付きの ISO-8601 タイムスタンプ形式。<br /><br />Type: 文字列型<br /><br />Example: `2014-05-22T02:38:28.103Z` |
| conversion&#95;type  <br />*必須* | コンバージョンイベントのタイプ。<br /><br />Type: enum<br /><br />Possible values: `PURCHASE`, `SIGN_UP`, `INSTALL`, `RE_ENGAGE`, `UPDATE`, `TUTORIAL_COMPLETE`, `RESERVATION`, `ADD_TO_CART`, `ADD_TO_WISHLIST`, `LOGIN`, `CHECKOUT_INITIATED`, `SEARCH`, `LEVEL_ACHIEVED`, `ACHIEVEMENT_UNLOCKED`, `CONTENT_VIEW`, `SHARE`, `INVITE`, `ADDED_PAYMENT_INFO`, `SPENT_CREDITS`, `RATED` |
| hashed&#95;device&#95;id  <br />*必須* | HMAC&#95;SHA-256 でハッシュ化された IDFA または AdID。<br /><br />Type: 文字列型<br /><br />Example: `ABCD1234XYZ` |
| os&#95;type  <br />*必須* | アプリの OS 種別。<br /><br />Type: enum<br /><br />Possible values: `IOS`, `ANDROID` |
| click&#95;window  <br />*任意* | このイベントのクリック計測期間（日数）。<br /><br />Type: int<br /><br />**Note**: `click_window` は view&#95;through&#95;window 以上である必要があります。<br /><br />Default: `14`  <br />Possible values: `1`, `7`, `14`, `30` |
| device&#95;ip&#95;address  <br />*任意* | コンバージョンイベントが発生したときのデバイスの IPv4 または IPv6 アドレス。<br /><br />Type: 文字列型<br /><br />Example: `192.133.78.1` |
| level  <br />*任意* | このイベントに関連付けられたレベル。<br /><br />Type: int<br /><br />Example: `2` |
| non&#95;twitter&#95;engagement&#95;time  <br />*任意* | コンバージョン前の、直近の Twitter 以外でのエンゲージメントの時刻。<br /><br />Type: 文字列型<br /><br />Example: `2014-05-22T02:38:28.103Z` |
| non&#95;twitter&#95;engagement&#95;type  <br />*任意* | コンバージョンイベント前の Twitter 以外でのエンゲージメントのタイプ。<br /><br />Type: enum<br /><br />Possible values: `CLICK`, `VIEW` |
| number&#95;items  <br />*任意* | このイベントに関連付けられたアイテム数。<br /><br />Type: int<br /><br />Example: `2` |
| price&#95;currency  <br />*任意* | このイベントに関連付けられた通貨を示す ISO 4217 コードであることが想定されています。<br /><br />Type: 文字列型<br /><br />Examples: `EUR`,`USD`,`JPY` |
| price&#95;micro  <br />*任意* | このイベントに関連付けられた価格（マイクロ単位の金額）。<br /><br />Type: int<br /><br />Example: `123450000` |
| user&#95;payment&#95;info  <br />*任意* | このイベントに関連付けられたアプリ内にユーザーの支払い情報が保存されているかどうかを示す boolean 値。<br /><br />Type: bool<br /><br />Possible values: `true` or `false` |
| view&#95;through&#95;window  <br />*任意* | このイベントに対するビュー経由の計測期間（日数）。<br /><br />**Note**:<br /><br />`click_window` は view&#95;through&#95;window 以上である必要があります。<br /><br />Type: int<br /><br />Default: `1`  <br />Possible values: `0`, `1`, `7`, `14`, `30` |

##### リクエスト例

<div id="get-accountsaccount_idapp_event_tags">
  #### GET accounts/:account_id/app_event_tags
</div>

現在のアカウントに関連付けられている app event tag の一部またはすべての詳細を取得します。

これらのタグは、Mobile App Conversion Tracking において、コンバージョンタイプごとに設定されるコンバージョンウィンドウを定義します。

<div id="resource-url">
  ##### リソース URL
</div>

`https://ads-api.x.com/12/accounts/:account_id/app_event_tags`

<div id="parameters">
  ##### Parameters
</div>

| Name | Description |
| :--- | :--- |
| account&#95;id  <br />*required* | 対象アカウントの識別子です。リソースのパス内に含まれ、[GET accounts](/ja/x-ads-api/campaign-management#accounts) を除くすべての Advertiser API リクエストで、一般的に必須となるパラメータです。指定するアカウントは認証済みユーザーに関連付けられている必要があります。<br /><br />Type: string<br /><br />Example: `18ce54d4x5t` |
| app&#95;event&#95;tag&#95;ids  <br />*optional* | カンマ区切りの識別子のリストを指定することで、レスポンスを目的の app event tag のみに絞り込みます。最大 200 個の ID を指定できます。<br /><br />Type: string<br /><br />Example: `jhp` |
| count  <br />*optional* | 各リクエストごとに取得を試行するレコード数を指定します。<br /><br />Type: int<br /><br />Default: `200`  <br />Min, Max: `1`, `1000` |
| cursor  <br />*optional* | 次のページの結果を取得するためのカーソルを指定します。詳細は [Pagination](/ja/x-ads-api/introduction) を参照してください。<br /><br />Type: string<br /><br />Example: `8x7v00oow` |
| sort&#95;by  <br />*optional* | サポートされている属性で、昇順または降順にソートします。詳細は [Sorting](/ja/x-ads-api/fundamentals/sorting) を参照してください。<br /><br />Type: string<br /><br />Example: `created_at-asc` |
| with&#95;deleted  <br />*optional* | 取得対象に削除済み結果を含めます。<br /><br />Type: boolean<br /><br />Default: `false`  <br />Possible values: `true`, `false` |
| with&#95;total&#95;count  <br />*optional* | `total_count` レスポンス属性を含めます。<br /><br />**Note**: このパラメータと `cursor` はどちらか一方のみ指定できます。<br /><br />**Note**: `total_count` を含むリクエストはレート制限が低くなり、現在は 15 分あたり 200 に設定されています。<br /><br />Type: boolean<br /><br />Default: `false`  <br />Possible values: `true`, `false` |

`GET https://ads-api.x.com/12/accounts/18ce54d4x5t/app_event_tags?app_event_tag_ids=jhp`
