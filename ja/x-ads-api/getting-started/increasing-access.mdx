<div id="requesting-additional-app-level-permissions">
  ### 追加のアプリレベル権限のリクエスト
</div>

アプリケーションが以下のいずれかのアプリレベル権限に限定されており、追加のエンドポイントへのアクセスを希望する場合は、**Standard Access** を申請するために X の担当窓口までご連絡ください。

2023 年 7 月以前に Ads API へのアクセスをリクエストした開発者は、以下のいずれかのアプリレベル権限をリクエストしていた可能性がありますが、これらは現在 Standard Access レベルに含まれています。

- **Analytics**（読み取り専用）：ユーザーは [Analytics](https://developer.x.com/en/docs/twitter-ads-api/analytics/overview) エンドポイントに対して[読み取り専用](https://developer.x.com/en/docs/apps/app-permissions)アクセス権があります。ユーザーは Campaign Management、Creative、Custom Audiences の各エンドポイントにはアクセスできませんが、Analytics エンドポイントのリクエストパラメータでクリエイティブエンティティを指定することで、メトリクスを取得できます。`media_id` または `media_name` 単位の粒度で取得するには、ユーザーのアプリケーションに Ads API の書き込みアクセス権が必要です。

- **Campaign Management & Creative**（読み取り & 書き込み）：ユーザーは [Campaign Management](https://developer.x.com/en/docs/twitter-ads-api/campaign-management/overview) および [Creative](https://developer.x.com/en/docs/twitter-ads-api/creatives/overview) エンドポイントに対して[読み取り & 書き込み](https://developer.x.com/en/docs/apps/app-permissions)アクセス権があります。ユーザーは Analytics エンドポイントにもアクセスできます。

- **Custom Audiences**（読み取り & 書き込み）：ユーザーは [Custom Audiences](https://developer.x.com/en/docs/twitter-ads-api/audiences/overview) エンドポイントに対して[読み取り & 書き込み](https://developer.x.com/en/docs/apps/app-permissions)アクセス権があります。ユーザーは Campaign Management、Creative、Analytics の各エンドポイントにもアクセスできます。

- **Conversion**（読み取り & 書き込み）：ユーザーは [Mobile](https://developer.x.com/en/docs/twitter-ads-api/measurement/mobile-conversions/overview) および [Web Conversion](https://developer.x.com/en/docs/twitter-ads-api/measurement/web-conversions/overview) エンドポイントに対して[読み取り & 書き込み](https://developer.x.com/en/docs/apps/app-permissions)アクセス権があります。ユーザーは他の Ads API エンドポイントへアクセスできる場合もあれば、できない場合もあります。 

<div id="requesting-an-increase-to-user-oauth-token-limits">
  ### ユーザー OAuth トークン上限引き上げの申請
</div>

2023 年 7 月以前に Ads API へのアクセスを申請した開発者は、アプリケーションのユーザー OAuth トークン上限が 5 に設定されている場合があります。開発者用 App のトークン上限を引き上げる必要がある場合は、X の担当者までご連絡ください。

<Note>**注記:** どの Ads API エンドポイントについても[レート制限](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting)を引き上げることはありません。レート制限内に収めるための方法については、[ベストプラクティス](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting)をご覧ください。</Note>
