<div id="requesting-additional-app-level-permissions">
  ### 追加の App レベル権限のリクエスト
</div>

ご利用のアプリケーションに以下のいずれかの App レベル権限しか付与されておらず、追加のエンドポイントにアクセスしたい場合は、**Standard Access** を申請するために X の担当者までご連絡ください。

2023 年 7 月以前に Ads API へのアクセスを申請した開発者は、現在は Standard Access レベルに含まれている、以下のいずれかの App レベル権限を申請している場合があります。

- **Analytics**（読み取り専用）：ユーザーは [Analytics](https://developer.x.com/en/docs/twitter-ads-api/analytics/overview) エンドポイントに [読み取り専用](https://developer.x.com/en/docs/apps/app-permissions) でアクセスできます。ユーザーは Campaign Management、Creative、Custom Audiences エンドポイントにはアクセスできませんが、Analytics エンドポイントのリクエストパラメータでクリエイティブエンティティを指定することで、メトリクスを取得できます。`media_id` または `media_name` の粒度で取得するには、ユーザーのアプリケーションに Ads API の書き込み権限が必要です。

- **Campaign Management & Creative**（読み取りおよび書き込み）：ユーザーは [Campaign Management](https://developer.x.com/en/docs/twitter-ads-api/campaign-management/overview) および [Creative](https://developer.x.com/en/docs/twitter-ads-api/creatives/overview) エンドポイントに [読み取りおよび書き込み](https://developer.x.com/en/docs/apps/app-permissions) でアクセスできます。ユーザーは Analytics エンドポイントにもアクセスできます。

- **Custom Audiences**（読み取りおよび書き込み）：ユーザーは [Custom Audiences](https://developer.x.com/en/docs/twitter-ads-api/audiences/overview) エンドポイントに
[読み取りおよび書き込み](https://developer.x.com/en/docs/apps/app-permissions) でアクセスできます。ユーザーは Campaign Management、Creative、Analytics エンドポイントにもアクセスできます。

- **Conversion**（読み取りおよび書き込み）：ユーザーは [Mobile](https://developer.x.com/en/docs/twitter-ads-api/measurement/mobile-conversions/overview) および [Web Conversion](https://developer.x.com/en/docs/twitter-ads-api/measurement/web-conversions/overview) エンドポイントに [読み取りおよび書き込み](https://developer.x.com/en/docs/apps/app-permissions) でアクセスできます。ユーザーが他の Ads API エンドポイントにアクセスできるかどうかは場合により異なります。 

<div id="requesting-an-increase-to-user-oauth-token-limits">
  ### ユーザー OAuth トークン数の上限引き上げのリクエスト
</div>

2023 年 7 月以前に Ads API へのアクセスを申請した開発者は、アプリケーションのユーザー OAuth トークン数の上限が 5 に設定されている場合があります。開発者の App のトークン上限を引き上げる必要がある場合は、X の担当窓口までご連絡ください。

<Note>**注意:** いかなる Ads API エンドポイントに対しても、[レート制限](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting) を引き上げることはありません。レート制限の範囲内に収まるようにする方法については、[ベストプラクティス](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting) を参照してください。</Note>
