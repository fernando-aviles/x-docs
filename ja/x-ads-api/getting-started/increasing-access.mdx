<div id="requesting-additional-app-level-permissions">
  ### 追加のアプリレベル権限のリクエスト
</div>

ご利用のアプリケーションに付与されているアプリレベル権限が以下のいずれかに限られており、追加のエンドポイントにアクセスしたい場合は、**Standard Access** を申請するために、X の担当者までご連絡ください。

2023 年 7 月以前に Ads API へのアクセスをリクエストした開発者は、以下のいずれかのアプリレベル権限をリクエストしていた可能性がありますが、現在はこれらは Standard Access レベルに含まれています。

- **Analytics**（読み取り専用）：ユーザーは [Analytics](https://developer.x.com/en/docs/twitter-ads-api/analytics/overview) エンドポイントに対する[読み取り専用](https://developer.x.com/en/docs/apps/app-permissions)アクセス権を持ちます。ユーザーは Campaign Management、Creative、または Custom Audiences エンドポイントにはアクセスできませんが、Analytics エンドポイントのリクエストパラメータでクリエイティブエンティティを指定することで、メトリクスを取得できます。media_id または media_name の粒度で取得するには、ユーザーのアプリケーションに Ads API の書き込みアクセス権が必要です。

- **Campaign Management & Creative**（読み取り & 書き込み）：ユーザーは [Campaign Management](https://developer.x.com/en/docs/twitter-ads-api/campaign-management/overview) および [Creative](https://developer.x.com/en/docs/twitter-ads-api/creatives/overview) エンドポイントに対する[読み取り & 書き込み](https://developer.x.com/en/docs/apps/app-permissions)アクセス権を持ちます。ユーザーは Analytics エンドポイントにもアクセスできます。

- **Custom Audiences**（読み取り & 書き込み）：ユーザーは [Custom Audiences](https://developer.x.com/en/docs/twitter-ads-api/audiences/overview) エンドポイントに対する[読み取り & 書き込み](https://developer.x.com/en/docs/apps/app-permissions)アクセス権を持ちます。ユーザーは Campaign Management、Creative、および Analytics エンドポイントにもアクセスできます。

- **Conversion**（読み取り & 書き込み）：ユーザーは [Mobile](https://developer.x.com/en/docs/twitter-ads-api/measurement/mobile-conversions/overview) および [Web Conversion](https://developer.x.com/en/docs/twitter-ads-api/measurement/web-conversions/overview) エンドポイントに対する[読み取り & 書き込み](https://developer.x.com/en/docs/apps/app-permissions)アクセス権を持ちます。ユーザーが他の Ads API エンドポイントへのアクセス権を持つ場合もあれば、持たない場合もあります。 

<div id="requesting-an-increase-to-user-oauth-token-limits">
  ### ユーザー OAuth トークン数の上限引き上げを申請する
</div>

2023 年 7 月以前に Ads API へのアクセスをリクエストした開発者は、アプリケーションのユーザー OAuth トークン数の上限が 5 個に設定されている場合があります。開発者用 App のトークン上限を引き上げる必要がある場合は、担当の X の担当者までご連絡ください。

<Note>**注:** いずれの Ads API エンドポイントについても、[レート制限](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting)を引き上げることはありません。レート制限の範囲内に収める方法については、[ベストプラクティス](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting)をご覧ください。</Note>
