<div id="connect-to-the-x-ads-platform">
  ## X Ads プラットフォームに接続する
</div>

X Ads API は、開発者が X の広告プラットフォームに接続し、世界中の X 広告主のニーズに応えるソリューションを構築できるようにします。

<Button href="/ja/x-ads-api/getting-started">
  はじめる
</Button>

***

<CardGroup cols={2}>
  <Card title="キャンペーン管理" icon="list-check" href="/ja/x-ads-api/campaign-management">プログラムで広告キャンペーンを作成、スケジュール、管理して、X 上のユーザーとのエンゲージメントを高めましょう。</Card>
  <Card title="カスタムオーディエンス" href="/ja/x-ads-api/audiences" icon="user-group">提供した X 上のデータや Web / モバイルのデータを使用して、Tailored Audiences を作成および管理します。</Card>
  <Card title="クリエイティブ" href="/ja/x-ads-api/creatives" icon="paintbrush">投稿の下書きと公開を行い、カード機能で投稿の機能を拡張し、画像や動画を管理・アップロードします。</Card>
  <Card title="広告アナリティクス" href="/ja/x-ads-api/analytics" icon="chart-pie">非同期および同期 API エンドポイントを使用して、幅広い指標に基づく広告キャンペーンの詳細なインサイトを取得します。</Card>
  <Card title="ツールとライブラリ" href="/ja/x-ads-api/tools-and-libraries" icon="screwdriver-wrench">X が提供しコミュニティがサポートするクライアントライブラリの厳選コレクションをご確認ください。</Card>
  <Card title="Postman コレクション" href="https://documenter.getpostman.com/view/7379786/SzRw1WTU" icon="code">v2 エンドポイント向けの Postman コレクションを用意しているので、Postman のビジュアルクライアントを使って API を探索できます。</Card>
  <Card title="コマンドラインツール" href="https://github.com/xdevplatform/xurl" icon="terminal">エンドポイントをコマンドラインツールで操作したい場合は、xurl が最適です。</Card>
</CardGroup>
