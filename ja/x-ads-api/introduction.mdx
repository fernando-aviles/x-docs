<div id="connect-to-the-x-ads-platform">
  ## X Ads プラットフォームに接続する
</div>

X Ads API を使用すると、開発者は X の広告プラットフォームに接続し、世界中の広告主のニーズに応えるソリューションを構築できます。

<Button href="/ja/x-ads-api/getting-started">
  はじめる
</Button>

***

<CardGroup cols={2}>
  <Card title="キャンペーン管理" icon="list-check" href="/ja/x-ads-api/campaign-management">X 上のユーザーとつながる広告キャンペーンを、プログラムから作成・スケジュール・管理できます。</Card>
  <Card title="カスタムオーディエンス" href="/ja/x-ads-api/audiences" icon="user-group">提供した X 上のデータや Web／モバイルデータを使って、Tailored Audiences を作成および管理します。</Card>
  <Card title="クリエイティブ" href="/ja/x-ads-api/creatives" icon="paintbrush">投稿の下書きと公開を行い、Cards を使って投稿の機能を拡張し、画像や動画を管理・アップロードできます。</Card>
  <Card title="広告アナリティクス" href="/ja/x-ads-api/analytics" icon="chart-pie">非同期および同期の API エンドポイントを使用して、幅広い指標にわたる広告キャンペーンの詳細なインサイトを取得します。</Card>
  <Card title="ツールとライブラリ" href="/ja/x-ads-api/tools-and-libraries" icon="screwdriver-wrench">X 製およびコミュニティがサポートするクライアントライブラリの厳選コレクションをご覧ください。</Card>
  <Card title="Postman コレクション" href="https://documenter.getpostman.com/view/7379786/SzRw1WTU" icon="code">v2 エンドポイント向けの Postman コレクションを用意しており、Postman のビジュアルクライアントを使って API を探索できます。</Card>
  <Card title="コマンドラインツール" href="https://github.com/xdevplatform/xurl" icon="terminal">エンドポイントをコマンドラインツールで扱いたい場合は、xurl をご利用ください。</Card>
</CardGroup>
