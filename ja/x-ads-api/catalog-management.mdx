<div id="overview">
  ## 概要
</div>

Catalog API は、広告主が商品フィードを設定し、商品をセットにグループ化し、カタログ内の商品を包括的に管理できるようにするコマースソリューションです。Catalog API は、カタログのプログラムによる管理を可能にし、広告主がカタログの取り込みおよび更新方法をより柔軟に制御できる中核ツールとなります。

カタログには、ユーザーの商品および商品セットに関するすべての情報が保持され、ユーザーのハンドルと関連付けられます。現在、**1 人のユーザーが作成できるカタログは 1 つのみです**。 

Catalog API は、商品を取り込む方法として次の 2 つをサポートします。

1.  Scheduled Feed: ユーザーはフィード URL（CSV、TSV、XML）を追加でき、定期的に取得されます（X は現在、最大 8GB までのファイルをサポートしています）

2.  Batch Products API: ユーザーはバッチ（JSON）リクエストで商品属性の閲覧、作成、更新、削除を行うことができます

X のマーチャントは、フィルタルールに基づいて商品セットを作成できます。これにより、商品に追加のメタデータを付与し、オーガニックコマース機能やダイナミック商品広告を通じてこれらの商品を紹介するための特別な商品セットを作成できます。Catalog API と X shopping manager は、2 種類の商品セットをサポートします。 

1.  Manual: ユーザーは最大 50 個の商品を選択し、名前と説明を設定できます

2.  Filter: ユーザーは最大 30 個のフィルターを追加し、これらのフィルターを満たす商品によるセットを自動生成できます。フィルターのタイプには、価格、Google 商品カテゴリ、商品タイプ、在庫、セール価格、カスタムフィールドなどが含まれます。

Catalog API には、カタログを管理するための 4 つのエンドポイントがあります。

* [Product Catalogs](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-catalogs) \- 商品情報のコンテナを作成します
* [Products](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/products) -  カタログ内の商品を同期的に追加、更新、閲覧、削除します
* [Product Sets](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-sets) -  商品情報に基づいて商品をグループに分類します
* [Schedule Feeds](https://developer.x.com/en/docs/twitter-ads-api/catalog-management/api-reference/scheduled-feeds) \- ファイルベースの商品データをカタログに非同期で取り込む設定を行います

<div id="prerequisites-for-the-catalog-api">
  ### Catalog API を利用するための前提条件
</div>

Catalog API エンドポイントは現在、アーリーアクセスとしてのみ利用可能です。アクセスを申請するには、X の担当営業までお問い合わせください。 

[X Shopping Manager](https://ads.x.com/shopping_manager) を通じて、利用規約に同意することが必須です。

Shopping Manager および商品仕様の詳細については、[Product specifications guide](https://business.x.com/en/help/shopping-specs.html) を参照してください。
