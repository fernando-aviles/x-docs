<div id="overview">
  ## Overview
</div>

Catalog API は、広告主が商品フィードを設定し、商品をセットにグルーピングし、カタログ商品を一元的に管理できるようにするコマースソリューションです。Catalog API は、プログラムによるカタログ管理を可能にする中核ツールとなり、広告主がカタログの取り込みおよび更新方法をより柔軟かつ詳細に制御できるようにします。

カタログには、ユーザーの商品および商品セットに関するあらゆる情報が保持され、ユーザーのハンドルに紐付けられます。現在、**1 人のユーザーが作成できるカタログは 1 つのみ**です。 

Catalog API は、商品を取り込むために次の 2 つの方法をサポートしています：

1.  Scheduled Feed：ユーザーはフィード URL（CSV、TSV、XML）を追加でき、定期的に取得されます（X では現在、最大 8GB までのファイルに対応しています）

2.  Batch Products API：ユーザーはバッチ（JSON）リクエストで、商品属性の参照、作成、更新、削除を行うことができます

X の販売事業者は、フィルタールールに基づいて商品セットを作成できます。これにより、商品に追加のメタデータを付与し、オーガニックなコマース機能やダイナミックプロダクト広告を通じてこれらの商品を訴求するための特別な商品セットを作成できます。Catalog API と X ショッピングマネージャーは、2 種類の商品セットをサポートしています。 

1.  Manual：ユーザーは最大 50 個の商品を選択し、名前と説明を設定できます

2.  Filter：ユーザーは最大 30 個のフィルターを追加し、これらのフィルター条件を満たす商品から自動的にセットを生成できます。フィルターのタイプには、価格、Google 商品カテゴリ、商品タイプ、在庫、セール価格、カスタムフィールドなどがあります。

Catalog API には、カタログを管理するための 4 つのエンドポイントがあります：

* [Product Catalogs](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-catalogs) \- 商品情報のコンテナを作成
* [Products](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/products) -  カタログ内の商品を同期的に追加、更新、参照、および削除
* [Product Sets](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-sets) -  商品情報に基づいて商品をグループに分類
* [Schedule Feeds](https://developer.x.com/en/docs/twitter-ads-api/catalog-management/api-reference/scheduled-feeds) \- ファイルベースの商品データをカタログに非同期で取り込むように設定

<div id="prerequisites-for-the-catalog-api">
  ### Catalog API を利用するための前提条件
</div>

Catalog API のエンドポイントは、現在アーリーアクセスでのみ利用可能です。アクセスを申請するには、X の担当者までお問い合わせください。 

[X Shopping Manager](https://ads.x.com/shopping_manager) を通じて、サービス利用規約に同意する必要があります。

Shopping Manager および商品仕様の詳細については、[Product specifications guide](https://business.x.com/en/help/shopping-specs.html) を参照してください。
