<div id="overview">
  ## Overview
</div>

Catalog API は、広告主が商品フィードを設定し、商品をセットにグルーピングし、カタログ商品を包括的に管理できるようにするコマース向けソリューションです。Catalog API は、プログラムからのカタログ管理を可能にする中核ツールとなり、広告主に対してカタログの取り込みおよび更新方法をより細かく制御できるようにします。

カタログには、ユーザーの商品および商品セットに関するすべての情報が保持され、ユーザーのハンドルに紐づけられます。現在、**1 人のユーザーが作成できるカタログは 1 つのみ**です。 

Catalog API では、商品を取り込む方法として 2 通りがサポートされています:

1.  Scheduled Feed: ユーザーはフィード URL（CSV、TSV、XML）を追加でき、定期的に取得されます（X は現在、最大 8GB までのファイルをサポートしています）

2.  Batch Products API: ユーザーはバッチ（JSON）リクエストにより、商品属性の参照、作成、更新、および削除を行うことができます

X のマーチャントは、フィルタールールに基づいて商品セットを作成できます。これにより、商品に追加のメタデータを付与し、オーガニックのコマース機能やダイナミックプロダクト広告を通じて商品を訴求するための特別な商品セットを作成できます。Catalog API と X Shopping Manager は、2 種類の商品セットをサポートしています。 

1.  Manual: ユーザーは最大 50 点までの商品を選択し、名前と説明を設定できます

2.  Filter: ユーザーは最大 30 個までフィルターを追加でき、これらのフィルター条件を満たす商品によるセットを自動生成できます。フィルターのタイプには、価格、Google 商品カテゴリ、商品タイプ、在庫、セール価格、カスタムフィールドなどがあります。

Catalog API には、カタログを管理するための 4 つのエンドポイントがあります:

* [Product Catalogs](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-catalogs) \- 商品情報用コンテナを作成します
* [Products](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/products) -  カタログから商品を同期的に追加、更新、参照、および削除します
* [Product Sets](https://developer.x.com/en/docs/x-ads-api/catalog-management/api-reference/product-sets) -  商品情報に基づいて商品をグループに分類します
* [Schedule Feeds](https://developer.x.com/en/docs/twitter-ads-api/catalog-management/api-reference/scheduled-feeds) \- ファイルベースの商品データをカタログに非同期で取り込む設定を行います

<div id="prerequisites-for-the-catalog-api">
  ### Catalog API の前提条件
</div>

Catalog API のエンドポイントは現在、早期アクセスプログラムとしてのみ提供されています。アクセスを申請するには、X の担当者までご連絡ください。

[X Shopping Manager](https://ads.x.com/shopping_manager) を通じて、利用規約に同意することが必須です。

Shopping Manager および商品仕様の詳細については、[Product specifications guide](https://business.x.com/en/help/shopping-specs.html) を参照してください。
