ここでは、複数のプログラミング言語やプラットフォームにまたがり、X Ads API をカバーしている、コミュニティによってサポートされている数多くのライブラリの一部を紹介します。特に記載がない限り、ここに挙げたライブラリは、Ads API のほとんどの機能をサポートしていると想定されています。詳細については、各ライブラリの作者に確認してください。

X API をサポートするライブラリを作成した場合は、ぜひ [Developer Community フォーラム](https://devcommunity.x.com/c/libraries-and-sdks/63) を通じてお知らせください。
