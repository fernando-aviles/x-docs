通貨の種別は [ISO-4217](http://en.wikipedia.org/wiki/ISO_4217) によって識別されます。これは `USD` や `EUR` のような 3 文字の文字列です。通貨の値は micros（マイクロ単位）で表されます。USD の場合、$5.50 は 5.50*1e6、つまり 5,500,000 としてエンコードされます。「整数値」を表すには、すべての通貨についてローカル通貨のマイクロ値に 1e6 (1&#95;000&#95;000) を掛ける必要があります。

Ads API は、X SMB Ads プロダクトが利用可能なすべての国の公式通貨を認識します。これらの国の一覧については、[こちら](https://business.x.com/en/help/overview/about-eligibility-for-twitter-ads.html)をご覧ください。

ほとんどの通貨は（USD: $1.23 のように）小数点以下 2 桁の「精度」を持ちます。

* `AED`, `VEF`, `PKR`, `IDR`, `HKD`, `QAR`, `PHP`, `NZD`, `INR`, `EUR`, `ARS`, `THB`, `MXN`, `EGP`, `DZD`, `SAR`, `LBP`, `COP`, `TRY`, `SGD`, `MAD`, `AUD`, `USD`, `MYR`, `CAD`, `BRL`, `GBP`.

次の通貨は小数を使用しません:

* `VND`, `KRW`, `CLP`, `JPY`

また、次の通貨は小数点以下 3 桁を使用します:

* `KWD`, `IQD`, `BHD`, `TND`

通貨の指定・利用は、[funding instruments](/ja/x-ads-api/introduction) を通じて行います。
