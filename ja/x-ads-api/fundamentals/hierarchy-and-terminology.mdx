Ads API で成果を上げるには、X Ads 内のエンティティ同士の関係を正しく理解することが重要です。このチュートリアルでは、X Ads のオブジェクト階層構造の基本について説明します。

![X Ads API hierarchy](/images/adsapi-heirarchy.png.twimg.1920.png)

<div id="ad-group-line-items">
  ## 広告グループ（line items）
</div>

Ads API では [line items](https://developer.x.com/content/developer-twitter/en/docs/tutorials/ads-api-hierarchy-terminology#line-items) と呼ばれる広告グループは、キャンペーンの下位に位置し、一連の X ユーザーに対するターゲティングや入札に使用されます。広告主は、投稿やメディア（例: In-stream 広告としてプロモーションする動画）をラインアイテムに関連付けることで配信します。「広告グループ」も参照してください。

<div id="account-media">
  ## アカウントメディア
</div>

[アカウントメディア](/ja/x-ads-api/creatives#account-media)として広告アカウントにアップロードされたクリエイティブの集合です。プロモーション用動画の[プレロールアセット](/ja/x-ads-api/campaign-management#video-views-preroll-objective)（インストリーム広告とも呼ばれます）や、[X Audience Platform](https://developer.x.com/content/developer-twitter/en/docs/ads/measurement/overview/twitter-audience-platform)上でプロモーション可能な画像を含むことができます。

<div id="ads-accounts">
  ## 広告アカウント
</div>

X Ads の階層構造の最上位にあるのが広告アカウントです。1 つの広告アカウントは複数の X ユーザーが管理できます。デモ用家具店の @Furni は、広告アカウントを管理するユーザーの一例です。広告アカウントは、[base36](https://en.wikipedia.org/wiki/Base36) で表現された英数字の文字列である account&#95;id によって識別されます。

各アカウントには、キャンペーン間で再利用可能ないくつかのエンティティ タイプが保存されています。たとえば、ターゲティングに利用できるテイラードオーディエンス、動画や画像で構成されるアカウントメディア、投稿に追加できる拡張クリエイティブであるカードなどです。

<div id="amplify-video">
  ## Amplify Video
</div>

動画アセットをアップロードする際、アップロードする主体は動画のカテゴリ（例: ツイート動画、ツイートGIF、ツイート画像、Amplify Video）を指定できます。インストリーム広告として配信される動画をアップロードする場合は、Amplify Video カテゴリの指定が必須です。これらの動画は配信可能であることを保証するために特別な処理が必要であり、そのためメディアカテゴリとして Amplify Video を指定する必要があります。

<div id="analytics">
  ## 分析
</div>

分析指標は、パートナーや広告主が、X 上でプロモーションしているコンテンツのパフォーマンスを把握するのに役立ちます。これには、インプレッション数、クリック数、動画再生数、費用などの情報が含まれます。さらに、パートナーや広告主は、リーチしたオーディエンスのさまざまなセグメントごとに、詳細な指標を取得できます。

Ads API は、キャンペーンの詳細なパフォーマンス指標を取得する方法として、同期方式と非同期方式の 2 つをサポートしています。

[同期分析](/ja/x-ads-api/analytics#synchronous-analytics)リクエストでは、要求した指標がレスポンス内で返されます。同期エンドポイントは短い期間の指定をサポートしており、リアルタイムのキャンペーンパフォーマンスを照会するのに最適です。

[非同期分析](/ja/x-ads-api/analytics#asynchronous-analytics)エンドポイントでは、要求した指標は、関連する「ジョブ」の処理が完了した後に、ダウンロード可能な結果ファイルとして取得できます。非同期エンドポイントは、より長期間にわたる指標の取得をサポートし、セグメント化されたデータを返すことができ、より多くのデータを取得する用途を想定しています。レポート作成や履歴データのバックフィルの生成に最適です。

<div id="campaigns">
  ## キャンペーン
</div>

広告主が配信する各キャンペーンは、既存のファンディングインストルメント（資金管理手段）配下で作成する必要があります。キャンペーンでは、広告キャンペーンの名前、スケジュール、予算などを定義できます。Furni の例を続けると、「Furni home decor」という名前のキャンペーンを作成することが考えられます。

なお、広告アカウントに作成できる有効なキャンペーン数は最大 200 件までに制限されています。この上限は、広告主のアカウントマネージャーによって引き上げられる場合があります。キャンペーンは、終了時間に達するか予算が使い切られるまでアクティブと見なされます。一時停止されたキャンペーンも、キャンペーン数の上限を計算する際にはアクティブなキャンペーンとして扱われます。

<div id="cards">
  ## カード
</div>

カードは、画像、動画、または UI 要素を含めることで、ツイートを視覚的に拡張する手段を提供します。Ads API では、ツイートに使用でき、その後キャンペーンでプロモーションできる複数のカードタイプをサポートしています。

<div id="creatives">
  ## クリエイティブ
</div>

広告主は、画像、GIF、動画などのクリエイティブを含むキャンペーンでツイートをプロモーションとして配信できます。これらのクリエイティブは、ツイートにリッチな写真や動画などのメディア体験を添付できるXカードと関連付けることができます。クリエイティブはツイートに直接添付することも可能です。たとえば、テキストと動画（または最大3枚の画像）を組み合わせて、プロモーションツイートを作成できます。

各ラインアイテムは、配信するために少なくとも1つのクリエイティブを関連付ける必要があります。クリエイティブには複数のオプションがあり、新しいフォロワーを獲得するための Promoted Accounts、TX Audience Platform 全体のラインアイテム向けの画像や動画などの Media Creatives、あるいは Promoted Posts などがあります。

<div id="funding-instruments">
  ## Funding Instruments
</div>

広告アカウントには Funding Instruments と呼ばれる情報も紐づいており、これは広告主が X Ads で利用するために設定したさまざまな支払い手段を指します。これには、X と締結したインサーションオーダーから、アカウントに登録されたクレジットカードまで、さまざまなものが含まれます。

<div id="line-items">
  ## 広告グループ（ラインアイテム）
</div>

キャンペーン内には 1 つ以上の広告グループを含めることができ、Ads API ではこれをラインアイテムとも呼びます。ラインアイテムは、キャンペーンをいくつかのセグメントに分けたものと考えることができ、それぞれに独自のターゲティング設定とクリエイティブがあります。複数のラインアイテムを含むキャンペーンは、「広告グループキャンペーン」と呼ばれることもあります。

1 つのキャンペーン内で複数のラインアイテムを使用する利点の 1 つは、ターゲティングとクリエイティブの組み合わせに、より多様なバリエーションを持たせられる点です。

「Furni home decor」キャンペーンでは、2 つのラインアイテムを作成するとします。1 つは「サンフランシスコの住宅購入者」、もう 1 つは「ロンドンの住宅購入者」とすることができます。

1 つのキャンペーンにつき最大 100 個のラインアイテムを設定でき、1 つの広告アカウントで保持できるアクティブなラインアイテム数は、すべてのキャンペーンを合計して最大 4,000 個までに制限されています。

<div id="mobile-app-promotion-map">

<div id="media-library">
  ## メディアライブラリ
</div>

メディアライブラリ エンドポイントを使用すると、X 広告アカウントの画像、GIF、動画を管理できます。ライブラリ内のメディアアセットは、投稿やカードの作成に利用できます。また、同じアセットを複数のクリエイティブで再利用できるため、同じアセットを繰り返しアップロードする必要がなくなります。

<div id="promoted-accounts">
  ## プロモアカウント
</div>

プロモアカウント（フォロワー獲得キャンペーン）は、現在フォローしていないが興味を持つ可能性のあるアカウントを提案する「Who to Follow（おすすめユーザー）」の一部です。プロモアカウントは、ユーザーが楽しめるさまざまなアカウントとの出会いをさらに広げるのに役立ちます。

プロモアカウントを利用すると、広告主は自分のアカウントを宣伝し、X 上でオーディエンスを拡大できます。フォロワー獲得キャンペーンは、ホームタイムライン、「Who to Follow（おすすめユーザー）」、検索結果など、X プラットフォーム上の複数の場所に表示され、他のおすすめアカウントと区別するために「プロモーション」と表示されます。

<div id="promotable-users">
  ## プロモーション対象ユーザー
</div>

各 X 広告アカウントには 1 つ以上のプロモーション対象ユーザーを設定できます。プロモーション対象ユーザーとは、その広告アカウントを通じてプロモーションできるユーザーのことです。Furni の広告アカウントにおける @Furni ハンドルは、FULL のプロモーション対象ユーザーの一例であり、@Furni とそのツイートに対してあらゆるタイプのキャンペーンを実施できることを意味します。1 つの広告アカウントに設定できる FULL のプロモーション対象ユーザーは 1 つだけです。

また、広告アカウントにはその他のプロモーション対象ユーザーを設定することもできます。たとえば、Furni 製品についての @Jack のツイートをプロモーションしたい場合、@Jack はそのアカウントにおいて、RETWEETS&#95;ONLY で示されるリツイートのみのプロモーション対象ユーザーとなります。広告主は、広告アカウントにリツイートユーザーを追加する方法について、自身の X アカウントマネージャーにお問い合わせください。

<div id="promoted-video">
  ## プロモビデオ
</div>

プロモビデオは、広告主が料金を支払って掲載するプロモツイート内の動画です。これらの動画はホームタイムライン、X 上の検索結果の最上部、またプラットフォーム内のその他の場所に表示され、「プロモーション」として明確に表示されます。

<div id="publisher-network">
  ## パブリッシャーネットワーク
</div>

詳細については、[X Audience Platform](/ja/x-ads-api/audiences) を参照してください。

<div id="scheduled-tweets">
  ## 予約ツイート
</div>

予約ツイートを使用すると、広告主やユーザーは、後の日時に公開されるようにツイートを予約投稿できます。これらのツイートを作成および管理できるだけでなく、API を使用して、ツイートが公開されたタイミングでプロモーションできるように、これらのツイートをラインアイテムに関連付けることもできます。これにより、広告主はネイティブツイートを事前に作成しておき、主要な施策に先立ってキャンペーンクリエイティブを計画できます。たとえば、新製品発表と同時に即時公開されるようにツイートクリエイティブをあらかじめ用意しておく、といった使い方が可能です。

<div id="segmentation">
  ## セグメンテーション
</div>

セグメンテーションを使用すると、パートナーや広告主は、年齢、デバイス、言語などの特定のターゲティング値ごとに分割された指標を取得できます。これは非同期分析エンドポイントでのみ利用可能です。セグメント化された指標をリクエストするには、`segmentation_type` リクエストパラメータを使用してください。セグメンテーションオプションの詳細については、「Metrics and Segmentation」を参照してください。

<div id="tailored-audience-list">
  ## Tailored Audience - List
</div>

リストから作成されるテイラードオーディエンスは、3種類あるテイラードオーディエンスのうちの1つであり、自社のユーザーや顧客のデータを含むファイルをアップロードして作成されます。アップロードされたリストはX上のユーザーと照合され、キャンペーンでそれらのユーザーを直接ターゲティングできるようになります。これらの制限事項を確認してください。

<div id="tailored-audience-web">
  ## Tailored Audience - Web
</div>

Tailored Audience from web は、Tailored Audiences の3つのタイプのうちの1つで、あなたのウェブサイトを訪問した X ユーザーをまとめたコレクションです。Tailored Audience from web を利用するには、ウェブサイトに X ピクセルを設置するか、認定済みのタグマネージャーパートナーのいずれかを利用する必要があります。これらの制限事項を確認してください。

<div id="targeting-criteria">
  ## ターゲティング条件
</div>

前述のとおり、ターゲティング条件はラインアイテムに関連付けられます。利用できるターゲティングにはさまざまな種類があり、地域、キーワード、性別といったものから、ユーザーの行動や興味関心といった、より詳細な属性まで含まれます。たとえば「Home Buyers in San Francisco」というラインアイテムでは、「home buying」という行動と「San Francisco」という地域の両方をターゲットにすることができます。

利用可能なさまざまなターゲティングのタイプに関する情報については、開発者サイトの Targeting Overview ページをご覧ください。

<div id="twitter-object-nest-ton">
  ## Twitter Object Nest (TON)
</div>

Twitter Object Nest (TON) は、クリエイティブとして使用するために、Media Upload エンドポイント経由でアップロードされたメディアや各種アセットを保管する場所です。

<div id="creatives">
  ## クリエイティブ
</div>

各ラインアイテムは、配信を行うために少なくとも 1 つのクリエイティブを関連付ける必要があります。利用可能なクリエイティブには、新しいフォロワー獲得のためのプロモアカウント（Promoted Accounts）、X Audience Platform 全体のラインアイテムで使用できる画像や動画などのメディアクリエイティブ、プロモ投稿（Promoted Posts）など、いくつかのオプションがあります。以下は、@Furni がプロモーションしてクリエイティブとして使用できる投稿の例です。
