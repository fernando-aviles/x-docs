Ads API を使って成果を出すには、X Ads 内のエンティティ同士がどのような関係にあるかを理解することが重要です。このチュートリアルでは、X Ads のオブジェクト階層構造の基本について解説します。

![X Ads API の階層構造](/images/adsapi-heirarchy.png.twimg.1920.png)

<div id="ad-group-line-items">
  ## 広告グループ（line items）
</div>

広告グループは、Ads API 上では [line items](https://developer.x.com/content/developer-twitter/en/docs/tutorials/ads-api-hierarchy-terminology#line-items) として知られており、キャンペーン配下に存在し、特定の X ユーザー群を対象としたターゲティングおよび入札に使用されます。広告主は、投稿やメディア（例: In-stream 広告として配信される動画）を line item に関連付けることでプロモーションを行います。「Ad Group」も参照してください。

<div id="account-media">
  ## アカウントメディア
</div>

[アカウントメディア](/ja/x-ads-api/creatives#account-media)として広告アカウントにアップロードされたクリエイティブのコレクションです。インストリーム広告とも呼ばれるプロモーション用動画の[プレロールアセット](/ja/x-ads-api/campaign-management#video-views-preroll-objective)や、[X Audience Platform](https://developer.x.com/content/developer-twitter/en/docs/ads/measurement/overview/twitter-audience-platform)上でプロモーション可能な画像などが含まれます。

<div id="ads-accounts">
  ## 広告アカウント
</div>

X 広告の階層構造の最上位にあるのが広告アカウントです。1 つの広告アカウントは、複数の X ユーザーによって管理できます。デモ用家具ストアの @Furni は、広告アカウントを管理するユーザーの一例です。広告アカウントは、[base36](https://en.wikipedia.org/wiki/Base36) の英数字からなる account&#95;id という文字列で識別します。

各アカウントの配下には、キャンペーン間で再利用できる複数のエンティティ タイプを保持しています。たとえば、ターゲティングに使用できるテーラードオーディエンス、動画や画像で構成されるアカウントメディア、そして投稿に追加できる拡張クリエイティブであるカードなどです。

<div id="amplify-video">
  ## Amplify Video
</div>

動画アセットをアップロードする際、アップロード側はその動画のカテゴリを指定できます（例：Tweet Video、Tweet Gif、Tweet Image、Amplify Video）。インストリーム広告として配信される動画をアップロードする場合、Amplify Video カテゴリは必須です。これらの動画は配信可能であることを保証するために特別な処理が必要であり、そのため Amplify Video のメディアカテゴリが必須となります。

<div id="analytics">
  ## アナリティクス
</div>

アナリティクス指標は、パートナーや広告主が X 上でプロモーションしているコンテンツのパフォーマンスを把握するのに役立ちます。これには、インプレッション数、クリック数、動画再生数、支出額などの情報が含まれます。さらに、パートナーや広告主は、リーチしたオーディエンスのさまざまなセグメントごとの詳細な指標を取得できます。

Ads API では、キャンペーンの詳細なパフォーマンス指標を取得する方法として、同期処理と非同期処理の 2 種類をサポートしています。

[同期アナリティクス](/ja/x-ads-api/analytics#synchronous-analytics) リクエストでは、要求した指標がレスポンス内で返されます。同期エンドポイントは短い期間の指定をサポートしており、リアルタイムなキャンペーンパフォーマンスのクエリに最適です。

[非同期アナリティクス](/ja/x-ads-api/analytics#asynchronous-analytics) エンドポイントでは、関連する「ジョブ」の処理が完了した後に、要求した指標がダウンロード可能な結果ファイルとして提供されます。非同期エンドポイントは、より長期間にわたる指標のリクエストをサポートし、セグメント化されたデータを返すことができるため、はるかに大量のデータを取得する用途を想定しています。レポートの作成や履歴データのバックフィルに最適です。

<div id="campaigns">
  ## キャンペーン
</div>

広告主が運用する各キャンペーンは、既存のファンディングインストゥルメントに紐づけて作成する必要があります。キャンペーンでは、広告キャンペーンの名前、スケジュール、予算などを定義できます。Furni の例に沿えば、「Furni home decor」という名前のキャンペーンを作成することになります。

広告アカウントには、アクティブなキャンペーンが最大 200 件までという上限がある点に注意してください。この上限は、広告主のアカウントマネージャーによって引き上げられる場合があります。キャンペーンは、終了時間に達するか、予算を使い切るまでアクティブと見なされます。一時停止中のキャンペーンも、キャンペーン数の上限を計算する際にはアクティブなキャンペーンとして扱われます。

<div id="cards">
  ## カード
</div>

カードは、画像、動画、または UI 要素をツイートに追加して、視覚的に拡張するための仕組みです。Ads API では、ツイートで利用でき、その後キャンペーンでプロモーションに使用できる複数のカードタイプがサポートされています。

<div id="creatives">
  ## クリエイティブ
</div>

広告主は、画像、GIF、動画などのクリエイティブを含むキャンペーンでツイートをプロモーションすることができます。これらのクリエイティブは、ツイートにリッチな写真、動画、メディア体験を添付できる X カードに関連付けることができます。クリエイティブはツイートに直接添付することも可能です。たとえば、テキストと動画（または最大 3 枚の画像）を組み合わせて、プロモーションツイートを作成できます。

各ラインアイテムは、配信するために少なくとも 1 つのクリエイティブが関連付けられている必要があります。クリエイティブには複数の選択肢があり、新たなフォロワー獲得のための Promoted Accounts、TX Audience Platform 全体のラインアイテム向けの画像・動画などの Media Creatives、あるいは Promoted Posts（プロモーション投稿）などが利用できます。

<div id="funding-instruments">
  ## 資金手段
</div>

広告アカウントには、資金手段も紐づいています。これは、広告主がX Adsで利用するために設定した、さまざまな資金の供給元を指します。これには、Xと締結したインサーションオーダー（Insertion Order）から、アカウントに紐づけられたクレジットカードまでが含まれます。

<div id="line-items">
  ## ラインアイテム
</div>

キャンペーン内には 1 つ以上の広告グループを作成でき、Ads API ではこれをラインアイテムとも呼びます。ラインアイテムは、各々が独自のターゲティング設定とクリエイティブを持つ、キャンペーン内の異なるセグメントと考えることができます。複数のラインアイテムを含むキャンペーンは、一般的に「広告グループキャンペーン」と呼ばれます。

1 つのキャンペーン内に複数のラインアイテムを設定する利点の 1 つは、ターゲティングとクリエイティブの組み合わせに、より幅広いバリエーションを持たせられることです。

「Furni home decor」キャンペーン内で、2 つのラインアイテムを作成したいとします。1 つは「San Francisco の住宅購入者」、もう 1 つは「London の住宅購入者」といった具合です。

1 つのキャンペーンあたり最大 100 個のラインアイテムが許可されており、広告アカウント全体では、すべてのキャンペーンを合計して最大 4,000 個のアクティブなラインアイテムに制限されます。

<div id="mobile-app-promotion-map">
  ## Mobile App Promotion (MAP)
</div>

Mobile App Promotion（MAP）は、広告主がX上でモバイルアプリを宣伝できるようにする一連の製品です。これには、アプリインストール、コンバージョン、リエンゲージメントが含まれます。

<div id="media-library">
  ## メディアライブラリ
</div>

Media Library エンドポイントを使用すると、X Ads アカウント向けの画像、GIF、動画を管理できます。ライブラリ内のメディアアセットは、投稿やカードの作成に利用できます。また、同じアセットを複数のクリエイティブで再利用できるため、繰り返しアップロードする必要がなくなります。

<div id="promoted-accounts">
  ## プロモアカウント
</div>

プロモアカウント（フォロワーキャンペーン）は「おすすめユーザー」の一部であり、現在フォローしていないが興味を持つ可能性のあるアカウントをおすすめします。プロモアカウントは、ユーザーが楽しめるアカウントの種類を、さらに幅広く紹介するのに役立ちます。

プロモアカウントを利用すると、広告主は自分のアカウントを宣伝し、X 上でのオーディエンスを拡大できます。フォロワーキャンペーンは、ホームタイムライン、「おすすめユーザー」、検索結果など、X プラットフォーム全体の複数の場所に表示され、他のおすすめアカウントと区別するために「プロモーション」とラベル付けされます。

<div id="promotable-users">
  ## プロモーション対象ユーザー
</div>

各 X Ads アカウントには 1 つ以上のプロモーション対象ユーザーを設定できます。プロモーション対象ユーザーとは、その X Ads アカウントを通じてプロモーションできるユーザーのことです。Furni の @Furni ハンドルは、Furni の X Ads アカウントにおける FULL プロモーション対象ユーザーの一例であり、@Furni とそのツイートに対してあらゆるタイプのキャンペーンを実行できることを意味します。1 つの X Ads アカウントに設定できる FULL プロモーション対象ユーザーは 1 つだけです。

なお、X Ads アカウントにはその他のプロモーション対象ユーザーを追加することもできます。たとえば、Furni の商品についての @Jack のツイートをプロモーションしたい場合、@Jack はそのアカウント上で RETWEETS&#95;ONLY で示される「リツイート専用」のプロモーション対象ユーザーになります。広告主は、X Ads アカウントにリツイート専用ユーザーを追加する方法について、担当の X アカウントマネージャーにお問い合わせください。

<div id="promoted-video">
  ## プロモ動画
</div>

プロモ動画は、広告主が料金を支払って配信するプロモツイート内の動画です。これらはホームタイムライン上、X の検索結果の最上部、およびプラットフォーム内のその他の場所に表示され、「プロモーション」として明確に表示されます。

  ## パブリッシャーネットワーク
</div>

[X Audience Platform](/ja/x-ads-api/audiences) をご覧ください。

<div id="scheduled-tweets">
  ## 予約ツイート
</div>

予約ツイートを使用すると、広告主やユーザーはツイートを作成し、後の日時に公開されるようにスケジュールできます。これらのツイートを作成・管理できることに加えて、API を使用すると、ツイートが公開されたタイミングでプロモーションできるよう、それらのツイートをラインアイテムに関連付けることが可能です。これにより、広告主はネイティブツイートを事前に作成して用意し、重要な施策に先立ってキャンペーンクリエイティブを計画できます。たとえば、新製品発表と同時に公開されるようにツイートクリエイティブをあらかじめ用意しておく、といった使い方が可能です。

<div id="segmentation">
  ## セグメンテーション
</div>

セグメンテーションを利用すると、パートナーや広告主は、年齢、デバイス、言語などの特定のターゲティング値ごとに分割した指標を取得できます。この機能は当社の非同期アナリティクスエンドポイントでのみ利用可能です。セグメント化された指標をリクエストするには、`segmentation_type` リクエストパラメータを使用してください。セグメンテーションオプションの詳細については、「Metrics and Segmentation」を参照してください。

<div id="tailored-audience-list">
  ## テーラードオーディエンス - リスト
</div>

リストから作成されるテーラードオーディエンスは、3 種類あるテーラードオーディエンスのうちの 1 つであり、自社のユーザーや顧客のデータを含むファイルをアップロードすることで作成します。アップロードしたリストは X 上のユーザーと照合され、キャンペーンでそれらのユーザーを直接ターゲティングできるようになります。これらの制限事項を必ずご確認ください。

<div id="tailored-audience-web">
  ## テーラードオーディエンス - Web
</div>

Web 由来のテーラードオーディエンスは、3 つあるテーラードオーディエンスのタイプの 1 つで、自社サイトを訪問した X ユーザーの集合です。Web 由来のテーラードオーディエンスを利用するには、自社サイトに X ピクセルを設置するか、認定済みのタグマネージャーパートナーのいずれかを使用する必要があります。これらの制限事項を必ず確認してください。

<div id="targeting-criteria">
  ## ターゲティング条件
</div>

前述のとおり、ターゲティング条件はラインアイテムに関連付けられます。利用できるターゲティングは多岐にわたり、ロケーション、キーワード、性別から、ユーザーの行動や興味関心といった、より細かな属性まで指定できます。たとえば「Home Buyers in San Francisco」というラインアイテムでは、「home buying」という行動と「San Francisco」というロケーションを組み合わせてターゲティングできます。

利用可能なさまざまなターゲティングの種類については、開発者サイトの Targeting Overview ページをご覧ください。

<div id="twitter-object-nest-ton">
  ## Twitter Object Nest (TON)
</div>

Twitter Object Nest (TON) は、Creatives として使用するために、Media Upload エンドポイントを通じてアップロードされたメディアおよび各種アセットを格納します。

</div>
