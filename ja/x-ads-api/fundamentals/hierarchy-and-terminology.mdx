Ads API を活用して成果を上げるには、X Ads のエンティティ同士がどのような関係にあるかを理解することが重要です。このチュートリアルでは、X Ads オブジェクトの階層構造の基本について解説します。

![X Ads API の階層構造](/images/adsapi-heirarchy.png.twimg.1920.png)

<div id="ad-group-line-items">
  ## Ad Group (ラインアイテム)
</div>

Ad Group は、Ads API 上では[ラインアイテム](https://developer.x.com/content/developer-twitter/en/docs/tutorials/ads-api-hierarchy-terminology#line-items)として知られており、キャンペーン配下に作成され、特定の X ユーザー群に対してターゲティングと入札を行うために使用されます。広告主は、ポストやメディア (例：In-stream 広告としてプロモーションされる動画) をラインアイテムに関連付けることでプロモーションします。「Ad Group」も参照してください。

<div id="account-media">
  ## アカウントメディア
</div>

[アカウントメディア](/ja/x-ads-api/creatives#account-media)として広告アカウントにアップロードされたクリエイティブのコレクションです。インストリーム広告とも呼ばれる、プロモーション可能な動画の[プレロールアセット](/ja/x-ads-api/campaign-management#video-views-preroll-objective)や、[X Audience Platform](https://developer.x.com/content/developer-twitter/en/docs/ads/measurement/overview/twitter-audience-platform)上でプロモーションできる画像を含めることができます。

<div id="ads-accounts">
  ## 広告アカウント
</div>

X Ads の階層の最上位には広告アカウントがあります。1 つの広告アカウントは、複数の X ユーザーによって管理できます。デモ用家具店である @Furni は、広告アカウントを管理するユーザーの一例です。広告アカウントは、[base36](https://en.wikipedia.org/wiki/Base36) の英数字文字列である account&#95;id によって識別されます。

各アカウントには、キャンペーン間で再利用できる複数のエンティティタイプが保存されます。たとえば、ターゲティングに使用できる tailored audiences、動画や画像である account media、そしてポストに追加できる拡張クリエイティブである cards などです。

<div id="amplify-video">
  ## Amplify Video
</div>

動画アセットをアップロードする際、アップロードを行う主体は動画のカテゴリ (例：Tweet Video、Tweet Gif、Tweet Image、Amplify Video) を指定できます。インストリーム広告として配信される動画をアップロードする場合は、Amplify Video カテゴリの指定が必須です。これらの動画は配信可能であることを保証するために特別な処理が必要となるため、メディアカテゴリとして Amplify Video を指定する必要があります。

<div id="analytics">
  ## アナリティクス
</div>

アナリティクスの指標は、パートナーや広告主が X 上でプロモーションしているコンテンツのパフォーマンスを把握するのに役立ちます。これには、インプレッション数、クリック数、動画再生数、支出額などの情報が含まれます。さらに、パートナーと広告主は、リーチしたオーディエンスのさまざまなセグメントごとの詳細な指標も取得できます。

Ads API は、詳細なキャンペーンのパフォーマンス指標を取得する方法として、同期および非同期の 2 つの方法をサポートしています。

[同期アナリティクス](/ja/x-ads-api/analytics#synchronous-analytics) リクエストでは、要求した指標がレスポンス内で返されます。同期エンドポイントは短い期間の指定をサポートしており、リアルタイムのキャンペーンパフォーマンスを取得するのに最適です。

[非同期アナリティクス](/ja/x-ads-api/analytics#asynchronous-analytics) エンドポイントでは、要求した指標は、関連する「ジョブ」の処理が完了した後にダウンロード可能な結果ファイルとして利用可能になります。非同期エンドポイントは、はるかに長い期間にわたる指標のリクエストをサポートし、セグメント化されたデータの返却を可能にし、より大量のデータ取得を想定しています。レポート作成や過去データのバックフィルに最適です。

<div id="campaigns">
  ## キャンペーン
</div>

広告主が実施する各キャンペーンは、既存の資金管理手段の下に作成する必要があります。キャンペーンでは、広告キャンペーンの名前、配信スケジュール、予算などを定義できます。Furni の例を使うと、「Furni home decor」という名前のキャンペーンを作成することができます。

広告アカウントには、アクティブなキャンペーンが最大 200 件までという制限がある点に注意してください。この上限は、広告主のアカウントマネージャーによって引き上げることができます。キャンペーンは、終了時間に達するか予算を使い切るまではアクティブと見なされます。一時停止中のキャンペーンも、キャンペーン数の上限を算出する際にはアクティブなキャンペーンとして扱われます。

<div id="cards">
  ## カード
</div>

カードは、ツイートに画像、動画、UI 要素などを追加して、視覚的に拡張するための仕組みです。Ads API ではツイートで利用できる複数のカードタイプがサポートされており、これらはキャンペーンでプロモーションできます。

<div id="creatives">
  ## クリエイティブ
</div>

広告主は、画像、GIF、動画などのクリエイティブを含むキャンペーンで、ツイートをプロモーション配信できます。これらのクリエイティブは、ツイートにリッチな写真や動画などのメディア体験を添付できる X カードに関連付けることができます。クリエイティブはツイートに直接添付することも可能です。たとえば、テキストと動画 (または最大 3 枚の画像) を組み合わせて、プロモーションツイートを作成できます。

各ラインアイテムは、配信するために少なくとも 1 つのクリエイティブが関連付けられている必要があります。利用できるクリエイティブには複数の種類があり、新しいフォロワー獲得のための Promoted Accounts、TX Audience Platform 全体のラインアイテム向けの画像や動画などの Media Creatives、あるいは Promoted Posts などがあります。

<div id="funding-instruments">
  ## 資金手段
</div>

広告アカウントの配下には「資金手段」もあり、これは広告主が X Ads で利用するために設定したさまざまな支払い手段を指します。これには、X と締結したインサーションオーダーから、アカウントに紐づけられたクレジットカードまでが含まれます。

<div id="line-items">
  ## ラインアイテム
</div>

キャンペーン内には、Ads API で「ラインアイテム」とも呼ばれる広告グループを 1 つ以上含めることができます。ラインアイテムは、キャンペーンを複数のセグメントに分けたものと考えることができ、それぞれが独自のターゲティング設定とクリエイティブを持ちます。複数のラインアイテムを含むキャンペーンは、「広告グループキャンペーン」と呼ばれることもあります。

1 つのキャンペーン内で複数のラインアイテムを使用する利点の 1 つは、ターゲティングとクリエイティブの組み合わせのバリエーションをより多く作成できることです。

「Furni home decor」キャンペーンでは、2 つのラインアイテムを作成するとします。1 つは「サンフランシスコの住宅購入者」、もう 1 つは「ロンドンの住宅購入者」とします。

キャンペーンごとに最大 100 個のラインアイテムを設定でき、1 つの広告アカウントで保有できる有効なラインアイテム数は、すべてのキャンペーンを合計して最大 4,000 個までに制限されています。

<div id="mobile-app-promotion-map">
  ## Mobile App Promotion (MAP)
</div>

Mobile App Promotion (MAP) は、広告主がXを通じてモバイルアプリをプロモーションできるようにする製品スイートであり、アプリインストール、コンバージョン、リエンゲージメントを含みます。

<div id="media-library">
  ## メディアライブラリ
</div>

Media Library エンドポイントを使用すると、X 広告アカウント用の画像、GIF、動画を管理できます。ライブラリ内のメディアアセットは、投稿やカードの作成に利用できます。また、複数のクリエイティブで再利用できるため、同じアセットを繰り返しアップロードする必要がなくなります。

<div id="promoted-accounts">
  ## Promoted Accounts
</div>

Promoted Accounts (フォロワーキャンペーン) は「Who to Follow」の一部であり、ユーザーが現在フォローしていないものの、興味を持つ可能性のあるアカウントをおすすめする機能です。Promoted Accounts によって、ユーザーが楽しめるさまざまなアカウントとの新たな出会いがさらに広がります。

Promoted Accounts を利用すると、広告主は自分のアカウントを宣伝し、X 上でのオーディエンスを拡大できます。フォロワーキャンペーンは、X プラットフォーム全体の複数の場所 (Home Timelines、Who to Follow、検索結果など) に表示され、他のおすすめアカウントと区別するために「Promoted」というラベルが付きます。

<div id="promotable-users">
  ## プロモーション可能なユーザー
</div>

各 X Ads アカウントには 1 つ以上のプロモーション可能なユーザーを設定できます。プロモーション可能なユーザーとは、その広告アカウントを通じてプロモーションできるユーザーのことです。Furni の @Furni ハンドルは Furni の広告アカウントにおける FULL のプロモーション可能ユーザーの一例であり、これは @Furni とそのツイートに対してあらゆる種類のキャンペーンを実施できることを意味します。1 つの広告アカウントにつき、FULL のプロモーション可能ユーザーは 1 つだけ設定できます。

なお、広告アカウントには他の種類のプロモーション可能なユーザーを設定することもできます。たとえば、@Jack の Furni 製品に関するツイートをプロモーション配信したい場合、彼はそのアカウント上で RETWEETS&#95;ONLY で示される、リツイート専用のプロモーション可能ユーザーになります。広告主は、リツイートユーザーを広告アカウントに追加する方法について、担当の X アカウントマネージャーに問い合わせてください。

<div id="promoted-video">
  ## プロモ動画
</div>

プロモ動画は、広告主が出稿したプロモツイート内に含まれる動画です。ホームタイムライン、X 上の検索結果の上部、そのほかプラットフォーム上のさまざまな場所に表示され、「プロモーション」と明確に表示されます。

  ## パブリッシャーネットワーク
</div>

[X Audience Platform](/ja/x-ads-api/audiences) を参照してください。

<div id="scheduled-tweets">
  ## 予約ツイート
</div>

予約ツイートを使うと、広告主またはユーザーは、後で公開されるようスケジュールしたツイートを作成できます。これらのツイートを作成・管理できることに加えて、API では、ツイートが公開されるタイミングでプロモーションされるように、それらのツイートをラインアイテムに関連付けることもできます。これにより、広告主はネイティブツイートを事前に用意し、重要な取り組みに先立ってキャンペーンクリエイティブを計画できます。たとえば、新製品発表と同時に即時公開されるよう、ツイートクリエイティブを事前に用意しておくことができます。

<div id="segmentation">
  ## セグメンテーション
</div>

セグメンテーションを利用すると、パートナーおよび広告主は、年齢、デバイス、言語などの特定のターゲティング値別にブレイクダウンされた指標を取得できます。これは当社の非同期アナリティクスエンドポイントでのみ利用可能です。セグメント化された指標をリクエストするには、`segmentation_type` リクエストパラメータを使用してください。セグメンテーションオプションの詳細については、「Metrics and Segmentation」を参照してください。

<div id="tailored-audience-list">
  ## テイラードオーディエンス - リスト
</div>

リストを使用したテイラードオーディエンスは、Tailored Audiences の 3 種類のうちの 1 つであり、自社のユーザーおよび顧客データを含むファイルをアップロードして作成します。リストは X 上のユーザーと照合され、キャンペーンでそのユーザーを直接ターゲティングできるようになります。必ずこれらの制限事項をご確認ください。

<div id="tailored-audience-web">
  ## テイラードオーディエンス - Web
</div>

Web 由来のテイラードオーディエンスは、3 種類あるテイラードオーディエンスのうちの 1 つで、自社のウェブサイトを訪問した X ユーザーの集合です。Web 由来のテイラードオーディエンスを利用するには、自社のウェブサイトに X ピクセルを設置するか、承認済みのタグマネージャーパートナーのいずれかを利用する必要があります。これらの制約事項を必ず確認してください。

<div id="targeting-criteria">
  ## ターゲティング条件
</div>

先ほど述べたように、ターゲティング条件はラインアイテムごとに設定されます。利用できるターゲティングにはさまざまな種類があり、ロケーション、キーワード、性別から、ユーザーの行動や興味関心といった、より細かい属性まで指定できます。「Home Buyers in San Francisco」というラインアイテムでは、「home buying」という行動と「San Francisco」というロケーションを組み合わせてターゲティングできます。

利用可能なさまざまなターゲティングタイプの詳細については、開発者サイトの「Targeting Overview」ページをご覧ください。

<div id="twitter-object-nest-ton">
  ## Twitter Object Nest (TON)
</div>

Twitter Object Nest (TON) は、クリエイティブとして使用するために Media Upload エンドポイント経由でアップロードされたメディアおよびさまざまなアセットを保存します。

<div id="creatives">
  ## クリエイティブ
</div>

配信を行うためには、各ラインアイテムに少なくとも 1 つのクリエイティブが関連付けられている必要があります。利用できるクリエイティブにはいくつかの選択肢があり、新しいフォロワーを獲得するための Promoted Accounts、X Audience Platform 全体のラインアイテムで利用できる画像や動画などの Media Creatives、プロモーション用のポストである Promoted Posts などがあります。以下は、@Furni がプロモーションを行い、クリエイティブとして使用できるポストの一例です。
