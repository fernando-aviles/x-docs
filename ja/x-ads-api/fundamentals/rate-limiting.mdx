Advertiser API には、次のドキュメントで説明されている REST API v1.1 と同様のレート制限が適用されます: [REST API Rate Limiting in v1.1](https://developer.x.com/content/developer-twitter/en/docs/basics/rate-limits)。REST API v1.1 とは異なり、エンドポイントごとの制限値を取得するためのプログラムから参照可能なインデックスは存在しません。エンドポイントのレート制限とリセットウィンドウは、HTTP レスポンスヘッダーを通じて提供されます。Ads API におけるすべてのレート制限は OAuth 1.0a を利用します。

<div id="user-level-and-ad-account-level-limits">
  ## ユーザーレベルおよび広告アカウントレベルの制限
</div>

レート制限には、ユーザートークンレベルと広告アカウントレベルの 2 種類があります。エンドポイントの一部は、広告アカウントレベルのレート制限に対応しています。ユーザートークンは、Ads API を認証して呼び出すために使用する [OAuth access token](/ja/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) です。各ユーザートークンは、1 つ以上の広告アカウントにアクセスできます。

開発者は、レスポンスヘッダーで広告アカウントレベルのレート制限が返される場合はそれを利用し、広告アカウントレベルの制限が提供されていない場合にのみユーザーレベルの制限を利用する必要があります。

ユーザーレベルのレート制限は、次のヘッダーで示されます: **x-rate-limit-limit**、**x-rate-limit-remaining**、**x-rate-limit-reset**

広告アカウントレベルのレート制限に対応しているエンドポイントでは、レート制限は次のヘッダーで示されます: **x-account-rate-limit-limit**、**x-account-rate-limit-remaining**、**x-account-rate-limit-reset**。

広告アカウントレベルのレート制限は、GET エンドポイントに対してのみ提供されます。これは、1 つのユーザートークンが複数の広告アカウントにアクセスしている場合に、アプリケーションがエンティティデータ（キャンペーンやラインアイテムオブジェクトなど）を同期できるようにするためです。書き込み処理が同じ広告アカウントレベルのレート制限を使用することは保証されていません。

広告アカウントレベルのレート制限が設定されているエンドポイントでは、ユーザーレベルのレート制限は、アプリケーション全体に対するグローバルなクォータを表す高い値に設定されています。利用可能な場合は、リクエストボリュームを制御する際に、広告アカウントレベルのレート制限を優先して使用する必要があります。

<div id="best-practices">
  ## ベストプラクティス
</div>

1. データベースに「最後に同期したタイムスタンプ」を保存し、必要に応じて `sort_by=updated_at-desc` オプションを指定してデータをリクエストすることで、最後に同期したタイムスタンプより古いデータに到達した時点で同期処理を停止できるようにしてください。これにより、同じデータを重複して同期してしまうことを防げます。

2. 1 回のリクエストで複数のエンティティを取得する: 一部のエンドポイントでは、カンマ区切りの値のリストを指定して、類似した複数のデータを取得できます。これにより、実行する呼び出しの総数を削減し、レート制限をより効率的に活用できます。

3. リクエストでは可能な最大の「count」を指定する: [GET accounts/:account&#95;id/targeting&#95;criteria](/ja/x-ads-api/campaign-management#targeting-criteria) のような一部のエンドポイントでは、最大の count 値を指定して呼び出すことが強く推奨されます。これにより、デフォルトの 200 件ではなく 1000 件のオブジェクトを取得できます。

<div id="faqs">
  ## よくある質問
</div>

*特定の広告アカウントやアプリケーションのレート制限を増やすことはできますか？*

一般的に、レート制限を個別に引き上げることはできません。既に最大規模の広告アカウントをサポートできるように設定されています。まずは本ドキュメントに記載されているベストプラクティスを実装してください。それでもなおレート制限がスケールやビジネス目標の達成に影響している場合は、ユースケースの内容や関係するリクエストの詳細をすべて添えて、X Ads API の担当窓口までご連絡ください。

<div id="scopes-of-rate-limiting">
  ## レート制限のスコープ
</div>

<div id="scopes-for-this-doc">
  ### このドキュメントで使用するスコープ
</div>

* Category: 指定されたカテゴリに属するすべてのエンドポイントは、各ウィンドウにつき 1 つ割り当てられた上限値を共有してレート制限されます。
* Endpoint: 各エンドポイントは、各ウィンドウごとに個別に割り当てられた上限値によってレート制限されます。
