Advertiser API には、[REST API v1.1 におけるレート制限](https://developer.x.com/content/developer-twitter/en/docs/basics/rate-limits)に記載されている REST API v1.1 と同様のレート制限が適用されます。REST API v1.1 と異なり、エンドポイントごとの制限をプログラム的に参照できるインデックスはありません。エンドポイントのレート制限とリセットウィンドウは、HTTP レスポンスヘッダーを通じて通知されます。Ads API におけるすべてのレート制限は、OAuth 1.0a を利用します。

<div id="user-level-and-ad-account-level-limits">
  ## ユーザーレベルおよび広告アカウントレベルの制限
</div>

レート制限には、ユーザートークンレベルと広告アカウントレベルの 2 種類があります。エンドポイントの一部は、広告アカウントレベルのレート制限を利用できるように設定されています。ユーザートークンは、Ads API を認証して呼び出す際に使用する [OAuth access token](/ja/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) です。各ユーザートークンは、1 つ以上の広告アカウントへアクセスできます。

開発者は、レスポンスヘッダーで広告アカウントレベルのレート制限が返される場合にはそれを利用し、広告アカウントレベルの制限が存在しない場合にのみユーザーレベルの制限を利用してください。

ユーザーレベルのレート制限は、次のヘッダーで表されます: **x-rate-limit-limit**、**x-rate-limit-remaining**、**x-rate-limit-reset**

広告アカウントレベルのレート制限が有効化されているエンドポイントでは、レート制限は次のヘッダーで表されます: **x-account-rate-limit-limit**、**x-account-rate-limit-remaining**、**x-account-rate-limit-reset**。

広告アカウントレベルのレート制限は、単一のユーザートークンで複数の広告アカウントへアクセスする場合に、アプリケーションがエンティティデータ（キャンペーンやラインアイテムオブジェクトなど）を同期できるようにするため、GET エンドポイントに対してのみ提供されます。書き込みアクションについては、同じ広告アカウントレベルのレート制限が適用されることは保証されません。

広告アカウントレベルのレート制限があるエンドポイントでは、ユーザーレベルのレート制限は、アプリケーション全体に対するグローバルなクオータを表す高い値に設定されています。利用可能な場合は、リクエスト量の制御において広告アカウントレベルのレート制限を優先して適用する必要があります。

<div id="best-practices">
  ## ベストプラクティス
</div>

1. データベースに「最後に同期したタイムスタンプ」を保存し、可能な場合は `sort_by=updated_at-desc` オプションを指定してデータをリクエストすることで、最後に同期したタイムスタンプより古いデータに到達した時点で同期処理を停止できるようにします。これにより、同じデータを重複して同期することを防げます。

2. 1 回のリクエストで複数のエンティティを取得する: 一部のエンドポイントでは、カンマ区切りの値リストを指定して、同種の複数のデータを取得できます。これにより、実行する呼び出しの総数を減らし、レート制限をより効率的に活用できます。

3. リクエストでは「count」の最大値を指定する: [GET accounts/:account&#95;id/targeting&#95;criteria](/ja/x-ads-api/campaign-management#targeting-criteria) などの一部のエンドポイントは、デフォルトの 200 ではなく 1000 個のオブジェクトを返すために、count の最大値を指定して呼び出すことが強く推奨されます。

<div id="faqs">
  ## よくある質問
</div>

*特定の広告アカウントや自社アプリケーションのレート制限を引き上げることは可能ですか？*

原則として、レート制限を引き上げることはできません。レート制限は、最大規模の広告アカウントをサポートできるように設定されています。まずは本ドキュメントに記載されているベストプラクティスを実装してください。それでもなおレート制限によってスケールやビジネス目標の達成が妨げられる場合は、そのユースケースおよび関連するリクエストの詳細をすべて記載したうえで、X Ads API の担当窓口までお問い合わせください。

<div id="scopes-for-this-doc">
  ### 本ドキュメントで使用するスコープ
</div>

* Category: 指定されたカテゴリに属するすべてのエンドポイントで、各ウィンドウにつき 1 つの割り当て上限を共有します。
