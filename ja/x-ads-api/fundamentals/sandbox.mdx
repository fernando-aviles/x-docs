title: サンドボックス

サンドボックスは、Ads API 実装をテストおよび構築するための環境です。

サンドボックス経由で作成されたキャンペーンはユーザーに配信されず、Funding Instruments などのオブジェクト用のテストレコードを動的に作成できます。

サンドボックスの利用は、ads-api-sandbox.x.com の適切なホスト名にリクエストを送るだけで開始できますが、サンドボックスにのみ存在する固有の機能も提供されています。

新しい広告主アカウントを作成するには、まず [POST accounts](/ja/x-ads-api/campaign-management#post-accounts) にリクエストを送信します。この呼び出しからのレスポンスには、その後のリクエストに使用できる account&#95;id が含まれます。これらのエンドポイントにより、開発者は複数の広告主アカウントを作成し、それぞれに対してテストを実行できます。

<div id="sandbox-only-endpoint-list">
  ### サンドボックス専用エンドポイント一覧：
</div>

* [POST accounts](/ja/x-ads-api/campaign-management#post-accounts) サンドボックスでアカウントを作成
* [POST accounts/:account&#95;id/features](/ja/x-ads-api/campaign-management#post-accounts-account-id-features) サンドボックスのアカウントにアカウント機能を追加
* [POST accounts/:account&#95;id/funding&#95;instruments](/ja/x-ads-api/campaign-management#post-accounts-account-id-funding-instruments) サンドボックスのアカウントに支払い手段を追加
* [DELETE accounts/:account&#95;id](/ja/x-ads-api/campaign-management#delete-accounts-account-id) サンドボックスのアカウントを削除
* [DELETE accounts/:account&#95;id/features](/ja/x-ads-api/campaign-management#delete-accounts-account-id-features) サンドボックスのアカウントからアカウント機能を削除
* [DELETE accounts/:account&#95;id/funding&#95;instruments/:funding&#95;instrument&#95;id](/ja/x-ads-api/campaign-management#delete-accounts-account-id-funding-instruments-funding-instrument-id) サンドボックスのアカウントから支払い手段を削除
