サンドボックスは、Ads API の実装をテストおよび構築するための環境です。

サンドボックス経由で作成されたキャンペーンはユーザーに配信されず、Funding Instruments などのオブジェクトに対するテスト用レコードを動的に作成できます。

サンドボックスは、ads-api-sandbox.x.com の所定のホスト名を呼び出すだけで利用でき、さらにサンドボックスにのみ用意されている独自の機能も含まれています。

新しい広告主アカウントを作成するには、まず [POST accounts](/ja/x-ads-api/campaign-management#post-accounts) にリクエストを送信します。この呼び出しのレスポンスには、その後のリクエストで使用できる `account_id` が含まれます。これらのエンドポイントを使用すると、複数の広告主アカウントを作成し、それらを対象にテストを実行できます。

<div id="sandbox-only-endpoint-list">
  ### サンドボックス専用エンドポイント一覧:
</div>

* [POST accounts](/ja/x-ads-api/campaign-management#post-accounts) サンドボックスでアカウントを作成します
* [POST accounts/:account&#95;id/features](/ja/x-ads-api/campaign-management#post-accounts-account-id-features) サンドボックス上のアカウントにアカウント機能を追加します
* [POST accounts/:account&#95;id/funding&#95;instruments](/ja/x-ads-api/campaign-management#post-accounts-account-id-funding-instruments) サンドボックス上のアカウントに資金手段を追加します
* [DELETE accounts/:account&#95;id](/ja/x-ads-api/campaign-management#delete-accounts-account-id) サンドボックス上のアカウントを削除します
* [DELETE accounts/:account&#95;id/features](/ja/x-ads-api/campaign-management#delete-accounts-account-id-features) サンドボックス上のアカウントからアカウント機能を削除します
* [DELETE accounts/:account&#95;id/funding&#95;instruments/:funding&#95;instrument&#95;id](/ja/x-ads-api/campaign-management#delete-accounts-account-id-funding-instruments-funding-instrument-id) サンドボックス上のアカウントから資金手段を削除します
