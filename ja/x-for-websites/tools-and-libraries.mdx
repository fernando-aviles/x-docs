<div id="official-resources">
  ## 公式リソース
</div>

以下のツールは、X for Websites の利用を開始する際に役立ちます。

<CardGroup cols={3}>
<Card
  title="publish.x.com"
  icon="x-twitter"
  href="https://publish.x.com/"
>
埋め込みツイート、タイムライン、ボタンを作成できます。
</Card>
<Card
  title="Twitter for WordPress"
  icon="x-twitter"
  href="https://github.com/twitter/wordpress"
>
Tweet の埋め込みや X Cards などに対応し、WordPress サイトを X 向けに最適化する公式プラグインです。
</Card>
<Card
  title="twemoji"
  icon="x-twitter"
  href="https://twemoji.x.com/"
>
X が提供する無料のオープンソースの絵文字セットで、クロスプラットフォーム対応のための JavaScript ライブラリも含まれます。
</Card>
</CardGroup>
