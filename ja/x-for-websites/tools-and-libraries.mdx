<div id="official-resources">
  ## 公式リソース
</div>

以下のツールは、Web サイトで X を利用し始める際に役立ちます。

<CardGroup cols={3}>
  <Card title="publish.x.com" icon="x-twitter" href="https://publish.x.com/">
    埋め込みツイート、タイムライン、ボタンを構築できます。
  </Card>

  <Card title="Twitter for WordPress" icon="x-twitter" href="https://github.com/twitter/wordpress">
    WordPress サイトを X 向けに最適化するための公式プラグインで、ツイートの埋め込みや X Cards に対応しています。
  </Card>

  <Card title="twemoji" icon="x-twitter" href="https://twemoji.x.com/">
    JavaScript ライブラリによるクロスプラットフォーム対応も含む、X の無料・オープンソースの絵文字文字セットです。
  </Card>
</CardGroup>
