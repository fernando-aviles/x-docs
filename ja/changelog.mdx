  ### フィルタリングオペレーターエイリアスの追加

  検索および filtered stream エンドポイント向けに、フィルタリング／クエリオペレーターの「エイリアス」がエンタープライズ、プレミアム、および v2 全体に追加されました。多くの場合、オペレーターは statuses ではなく投稿を参照します。たとえば、&quot;in&#95;reply&#95;to&#95;status&#95;id&quot; のエイリアスとして &quot;in&#95;reply&#95;to&#95;tweet&#95;id&quot; が追加されています。別のケースでは、新しいオペレーターエイリアスによってマッチング内容がより明確になります。たとえば、投稿には動画の添付が 1 つしか含まれないため、&quot;has:videos&quot; に対する新しいエイリアスとして &quot;has:video&#95;link&quot; が提供されています。詳細な例については、[v2 filtered stream オペレーター表](https://developer.x.com/en/docs/twitter-api/tweets/filtered-stream/integrate/build-a-rule#list) を参照してください。
</Update>

<Update label="Dec 14, 2021" description="X API v2：認証">
  ### OAuth 2.0 認可のサポート

  本日より、すべての開発者は Developer Console で認証方法として OAuth 2.0 を選択することで、OAuth 2.0 を使用して認証できるようになりました。今回のリリースの一環として、機密クライアントおよびパブリッククライアントの両方と、関連するすべての v2 エンドポイントでこの認証方法を使用できるようサポートを追加しました。

  OAuth 2.0 は業界標準の認可プロトコルであり、アプリケーションのスコープに対する開発者のコントロールを強化し、複数デバイス間での認可フローを改善します。言い換えると、X 上の人々向けにアプリケーションを構築している開発者は、自分の App がユーザーから要求する情報をより細かく制御できるようになり、エンドユーザーには必要なデータと情報だけを求めればよいようになります。

  この最新の認可プロトコルにより、あなたのアプリの認可のために、エンドユーザーに対して、あなたが要求した特定のスコープのみを表示する、よりシンプルな同意フローを提示できるようになります。

  このリリースの詳細については、フォーラムのお知らせをご覧ください。
</Update>

<Update label="Nov 15, 2021" description="X API v2：早期アクセス">
  ### X API v2 に対する主要なプラットフォームアップデート

  **主要なプラットフォームアップデート：X API v2 が主要バージョンに、新しい Essential と Elevated アクセス、ポリシー変更**

  本日、X API v2 が X API の主要バージョンになったことを発表します。X API v2 には、X API 上に構築されている既存の App の 90% のニーズを満たすのに十分な数のエンドポイントと機能をリリースしました。

  X API v2 における開発者エクスペリエンスをさらに改善するために、次の変更を本日リリースします。

  * API への高速かつ無料で利用できる Essential アクセス、および利用目的が承認された開発者向けの無料の Elevated アクセス。これらのアクセスレベルに関する詳細は、「About the X API」ページで確認できます。

  * X のコア機能の使い方を制限し、あなたのアプリがサポートできるユーザー数を制限していた Developer Policy 上の文言を削除します。

    * 私たちはプラットフォームを開放し、X をより良く、健全にし、パブリックな会話を拡張するツールやプロダクトを構築していただけるよう促進します。[私たちがぜひあなたに構築してほしいと考えているソリューションの一覧をご覧ください](https://developer.x.com/en/docs/twitter-api/what-to-build)。

    * 具体的には、X のコア機能を含む X のエクスペリエンスの複製を制限していた条項、ならびに多数のユーザートークンを持つために許可を必要としていた条項を削除しました。

<Update label="May 10, 2018" description="X API: Standard v1.1">
  ### 引用ペイロードでの URL レンダリングの変更

  本日、引用ペイロード内で URL がレンダリングされる方法に変更を加えます。

  引用された投稿を参照できるようにするため、新しいエンティティ &quot;quoted&#95;status&#95;permalink&quot; を追加し、引用された投稿の &quot;text&quot; フィールドから t.co リンクを削除します。

  新しい形式では、t.co リンクは &quot;quoted&#95;status&quot; オブジェクト内の引用された投稿の &quot;text&quot; フィールドに付加されなくなります。

  さらに、引用された投稿の t.co url、expanded&#95;url、display&#95;url を、これまでのように &#39;urls&#39; エンティティには含めません。代わりに、これらは &quot;url&quot;、&quot;expanded&quot;、&quot;display&quot; という URL 属性を持つ新しい &quot;quoted&#95;status&#95;permalink&quot; オブジェクトに追加されます。これは、&quot;quoted&#95;status&#95;permalink&quot; オブジェクトが引用された投稿への t.co リンク専用となり、一方で &quot;entities.urls&quot; 配列は元の投稿または引用内で共有されたリンクを識別するために使用できることを意味します。

  くわしくは、[フォーラム投稿](https://devcommunity.x.com/t/updating-how-urls-are-rendered-in-the-quote-tweet-payload/105473)および[更新されたドキュメント](https://devcommunity.x.com/t/upcoming-changes-to-the-developer-platform/104603)をお読みください。
</Update>

  Premium API をリリースしました。

  * より複雑なクエリを可能にする、はるかにリッチなクエリ言語（Sandbox + Premium）

  * 投稿の時系列カウントを返す counts エンドポイント（Premium）

  * 展開済み URL や Profile Geo などのメタデータ拡張（Premium）

  このリリースの詳細については [ブログ](https://blog.x.com/developer/en_us/topics/tools/2017/introducing-twitter-premium-apis.html) をご覧ください。

  `statuses/update` のオプションパラメーター `enable_dm_commands` を使用すると、移行期間が終了する前に、アプリケーション側で DM コマンドのサポートを早期に削除できます。デフォルト値は *true*（すなわち現在のレガシー動作）ですが、*false* に設定すると、11月1日以降の新しい動作になります。`statuses/update` のオプションパラメーター `fail_dm_commands` を *true* に設定すると、DM コマンドは API から HTTP 403（エラーコード 151）を返すようになります。デフォルト値は *false* です。このアップデートの詳細は[フォーラム](https://devcommunity.x.com/t/retiring-legacy-dm-commands-on-the-standard-tweet-api/86653)をご覧ください。
</Update>

<Update label="Feb 22, 2017" description="X API: Enterprise v1.1">
  ### 新しいエンリッチメントとペイロードの変更

  新しいエンリッチメントとして、投票メタデータが enterprise API から利用可能になりました。詳細は[ドキュメント](/ja/x-api/enterprise-gnip-2.0/fundamentals/account-activity#migration-introduction)を参照してください。

  新しいペイロードフィールド: ユーザーが投稿に写真を追加する際に「Add description」オプションを選択した場合、ペイロードの `entities.media[]` および `extended_entities.media[]` セクションに、画像の代替テキスト（description）フィールドが含まれることがあります。これはエンリッチ済みネイティブ形式でのみ利用可能です。

  デフォルトのペイロード形式: Gnip プロダクトで新しく作成されるストリームは、デフォルトで original format JSON になります。
</Update>
