Spaces lookup エンドポイントを使用すると、ライブ中またはスケジュール済みの Spaces に関する情報を取得できます。Spaces をその ID で検索したり、特定のユーザーが作成した Spaces を検索したりできます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="ID で取得" icon="microphone">
    特定の Space の詳細を取得します
  </Card>

  <Card title="複数の Space" icon="microphone-lines">
    複数の Space を同時に取得します
  </Card>

  <Card title="ホスト別" icon="user">
    ホストを指定して Space を取得します
  </Card>

  <Card title="チケット購入者" icon="ticket">
    チケットを購入したユーザーを取得します
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| メソッド | エンドポイント | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/spaces/:id`](/ja/x-api/spaces/get-space-by-id) | ID を指定してスペースを取得 |
| GET | [`/2/spaces`](/ja/x-api/spaces/get-spaces-by-ids) | 複数の ID を指定してスペースを取得 |
| GET | [`/2/spaces/by/creator_ids`](/ja/x-api/spaces/get-spaces-by-creator-ids) | クリエイターのユーザー ID を指定してスペースを取得 |
| GET | [`/2/spaces/:id/buyers`](/ja/x-api/spaces/get-space-ticket-buyers) | スペースのチケット購入者を取得 |
| GET | [`/2/spaces/:id/tweets`](/ja/x-api/spaces/get-space-posts) | スペース内で共有された投稿を取得 |

***

<div id="response-fields">
  ## レスポンスフィールド
</div>

デフォルトでは、レスポンスには `id` と `state` が含まれます。追加のフィールドをリクエストするには、次を指定します:

| Field | Description |
|:------|:------------|
| `title` | Space のタイトル |
| `host_ids` | ホストユーザーの ID |
| `speaker_ids` | スピーカーユーザーの ID |
| `participant_count` | 参加者数 |
| `scheduled_start` | 予定開始時刻 |
| `started_at` | 実際の開始時刻 |
| `ended_at` | 終了時刻 |
| `is_ticketed` | Space にチケットが設定されているかどうか |

<div id="space-states">
  ### Space の状態
</div>

| State | 説明 |
|:------|:------------|
| `live` | 現在アクティブ |
| `scheduled` | 今後の開催がスケジュール済み |
| `ended` | すでに終了 |
-------------------

<div id="getting-started">
  ## リクエスト例
</div>

```bash
curl "https://api.x.com/2/spaces/1DXxyRYNejbKM?\
space.fields=title,host_ids,participant_count,scheduled_start,state" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
