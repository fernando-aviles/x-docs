Spaces ルックアップエンドポイントを使用すると、ライブ中または予約済みの Spaces に関する情報を取得できます。Spaces を ID で取得したり、特定のユーザーが作成した Spaces を取得したりできます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="ID で取得" icon="microphone">
    特定のスペースの詳細を取得します
  </Card>

  <Card title="複数のスペース" icon="microphone-lines">
    複数のスペースをまとめて取得します
  </Card>

  <Card title="ホスト別" icon="user">
    ホストを指定してスペースを検索します
  </Card>

  <Card title="購入者" icon="ticket">
    チケットを購入したユーザーを取得します
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/spaces/:id`](/ja/x-api/spaces/get-space-by-id) | ID を指定して Space を取得 |
| GET | [`/2/spaces`](/ja/x-api/spaces/get-spaces-by-ids) | 複数の ID を指定して Space を取得 |
| GET | [`/2/spaces/by/creator_ids`](/ja/x-api/spaces/get-spaces-by-creator-ids) | 作成ユーザーの ID で Space を取得 |
| GET | [`/2/spaces/:id/buyers`](/ja/x-api/spaces/get-space-ticket-buyers) | Space のチケット購入者を取得 |
| GET | [`/2/spaces/:id/tweets`](/ja/x-api/spaces/get-space-posts) | Space で共有された投稿を取得 |

***

<div id="response-fields">
  ## レスポンスフィールド
</div>

デフォルトでは、レスポンスには `id` と `state` が含まれます。追加でリクエスト可能なフィールド:

| フィールド | 説明 |
|:------|:------------|
| `title` | スペースのタイトル |
| `host_ids` | ホストユーザーの ID |
| `speaker_ids` | スピーカーユーザーの ID |
| `participant_count` | 参加者数 |
| `scheduled_start` | 開始予定時刻 |
| `started_at` | 実際の開始時刻 |
| `ended_at` | 終了時刻 |
| `is_ticketed` | スペースがチケット制かどうか |

<div id="space-states">
  ### Space の状態
</div>

| State | 説明 |
|:------|:------------|
| `live` | 現在ライブ配信中 |
| `scheduled` | 今後の開催が予定されている |
| `ended` | すでに終了している |

***

<div id="example-request">
  ## リクエスト例
</div>

```bash
curl "https://api.x.com/2/spaces/1DXxyRYNejbKM?\
space.fields=title,host_ids,participant_count,scheduled_start,state" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
