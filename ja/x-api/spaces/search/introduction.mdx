Spaces Search エンドポイントを使用すると、キーワードでライブまたは今後開催予定の Spaces を検索できます。興味のあるトピックの Spaces を見つけることができます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="キーワード検索" icon="magnifying-glass">
    Spaces をタイトルで検索する
  </Card>

  <Card title="Spaces を探す" icon="microphone">
    ライブ中および今後予定されている Spaces を見つける
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/spaces/search`](/ja/x-api/spaces/search-spaces) | Spaces を検索 |

***

<div id="parameters">
  ## パラメーター
</div>

| Parameter | Description |
|:----------|:------------|
| `query` | 検索クエリ（必須） |
| `state` | `live` または `scheduled` で絞り込み |
| `space.fields` | 追加の Space フィールド |
| `expansions` | レスポンスに含める関連オブジェクト |
------------------------------------

<div id="example-response">
  ## リクエスト例
</div>

```bash
curl "https://api.x.com/2/spaces/search?\
query=AI&\
state=live&\
space.fields=title,host_ids,participant_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="getting-started">
  ## レスポンス例
</div>

```json
{
  "data": [
    {
      "id": "1DXxyRYNejbKM",
      "state": "live",
      "title": "Discussing AI and the Future",
      "host_ids": ["1234567890"],
      "participant_count": 245
    }
  ],
  "meta": {
    "result_count": 1
  }
}
```
