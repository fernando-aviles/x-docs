  ## X API のミュート用エンドポイントの比較
</div>

<div id="mutes-lookup">
  #### ミュートのルックアップ
</div>

v2 のミュートルックアップエンドポイントは、既存の標準 [v1.1 GET mutes/users/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-ids) および [GET mutes/users/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-list) エンドポイントに代わるものです。

次の表では、標準 v1.1 と X API v2 のミュートエンドポイントを比較します。
 

| 説明 | 標準 v1.1 | X API v2 |
| :--- | :--- | :--- |
| サポートされる HTTP メソッド | ******GET****** | ******GET****** |
| ホストドメイン | ******https://api.x.com****** | ******https://api.x.com****** |
| エンドポイントパス | ******/1.1/mutes/users/ids.json******<br /><br />/1.1/mutes/users/list.json | ******/2/users/:id/muting****** |
| [認証](/ja/resources/fundamentals/authentication) | OAuth 1.0a ユーザーコンテキスト | OAuth 1.0a ユーザーコンテキスト<br /><br />OAuth 2.0 Authorization Code with PKCE |
| デフォルトのリクエスト [レート制限](/ja/resources/fundamentals/rate-limits) | 15 分あたり 15 リクエスト (ユーザーごと)  | 15 分あたり 15 リクエスト (ユーザーごと)  |
| データ形式 | 標準 v1.1 形式 | [X API v2 形式](/ja/x-api/fundamentals/data-dictionary) (fields と expansions のリクエストパラメーターによって決定され、v1.1 形式との後方互換性はありません) <br /><br />標準 v1.1 形式から X API v2 形式への移行方法の詳細については、[データ形式移行ガイド](/ja/x-api/migrate/data-format-migration)をご覧ください。 |
| [developer App](/ja/resources/fundamentals/developer-apps) の認証情報で、[Project](/ja/resources/fundamentals/developer-apps) に関連付けられているものの使用が必須 |     | ✔️  |

<div id="manage-mutes">
  #### ミュートの管理
</div>

X API v2 のミュート管理エンドポイントは、標準 v1.1 の [POST mutes/users/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-create) と [POST mutes/users/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-destroy) エンドポイントを置き換えます。

以下の表では、標準 v1.1 と X API v2 のミュートエンドポイントを比較します。

**ユーザーをミュートする**

| 説明 | 標準 v1.1 | X API v2 |
| :--- | :--- | :--- |
| サポートされる HTTP メソッド | POST | POST |
| ホストドメイン | https://api.x.com | https://api.x.com |
| エンドポイントパス | /1.1/mutes/users/create.json | /2/users/:id/muting |
| [Authentication](/ja/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | 15分あたり50件のリクエスト | 15分あたり50件のリクエスト |
| [Project](/ja/resources/fundamentals/developer-apps) に関連付けられている [developer App](/ja/resources/fundamentals/developer-apps) の認証情報の使用が必須 |     | ✔️  |

**ユーザーのミュートを解除する**

以下の表では、標準 v1.1 と X API v2 のミュート解除エンドポイントを比較します。

| 説明 | 標準 v1.1 | X API v2 |
| :--- | :--- | :--- |
| サポートされる HTTP メソッド | POST | DELETE |
| ホストドメイン | https://api.x.com | https://api.x.com |
| エンドポイントパス | /1.1/mutes/users/destroy.json | /2/users/:source&#95;user&#95;id/muting/:target&#95;user&#95;id |
| [Authentication](/ja/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | 15分あたり50件のリクエスト | 15分あたり50件のリクエスト |
| [Project](/ja/resources/fundamentals/developer-apps) に関連付けられている [developer App](/ja/resources/fundamentals/developer-apps) の認証情報の使用が必須 |     | ✔️  |
