  ## X API のユーザー lookup エンドポイントの比較
</div>

v2 の user lookup エンドポイントは、標準的な v1.1 の [GET users/lookup](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-lookup.html) および [GET users/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-show.html) エンドポイントの代替となります。これらのバージョンの user lookup エンドポイントを使用しているコードやアプリ、ツールがあり、より新しい X API v2 エンドポイントへの移行を検討している場合は、この一連のガイドが役立ちます。 
 

次の表では、さまざまな種類の users lookup エンドポイントを比較します。
 

|     |     |     |
| :--- | :--- | :--- |
| **説明** | **Standard v1.1** | **X API v2** |
| サポートされている HTTP メソッド | `GET` | `GET` |
| ホストドメイン | `https://api.x.com` | `https://api.x.com` |
| エンドポイントパス | `/1.1/users/show.json` `/1.1/users/lookup.json` | `/2/users`<br /><br />`/2/users/:id`<br /><br />`/2/users/by`<br /><br />`/2/users/by/:username` |
| [Authentication](/ja/resources/fundamentals/authentication) | OAuth 1.0a ユーザーコンテキスト | OAuth 1.0a ユーザーコンテキスト<br /><br />App only（アプリのみ）<br /><br />OAuth 2.0 Authorization Code with PKCE |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | 15 分あたり 900 リクエスト（ユーザーごと）<br /><br />/show - 15 分あたり 900 リクエスト（アプリごと）  <br />/lookup - 15 分あたり 300 リクエスト（アプリごと） | 15 分あたり 900 リクエスト（ユーザーごと）<br /><br />15 分あたり 300 リクエスト（アプリごと） |
| レスポンスあたりのユーザー数の最大値 | /show -  1<br /><br />/lookup - 100 | 100 |
| JSON レスポンスオブジェクトの形式 | Standard v1.1 の形式 | [X API v2 の形式](/ja/x-api/fundamentals/data-dictionary)（v1.1 の形式との後方互換性はなく、fields と expansions のリクエストパラメータによって決まります）<br /><br />Standard v1.1 の形式から X API v2 の形式への移行方法の詳細については、[data 形式移行ガイド](/ja/x-api/migrate/data-format-migration)をご覧ください。 |
| ペイロード内で返す[フィールド](/ja/x-api/fundamentals/data-dictionary)を選択可能 |     | ✔   |
| [annotations](/ja/x-api/fundamentals/post-annotations) フィールド（固定された投稿で）をサポート |     | ✔   |
| 新しい[metrics](/ja/x-api/fundamentals/metrics) フィールド（固定された投稿で）のリクエストをサポート |     | ✔   |
| [conversation&#95;id](/ja/x-api/fundamentals/conversation-id) フィールド（固定された投稿で）をサポート |     | ✔   |
| [Project](/ja/resources/fundamentals/developer-apps) に関連付けられた [開発者用 App](/ja/resources/fundamentals/developer-apps) の認証情報の使用が必須 |     | ✔   |
