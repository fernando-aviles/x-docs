User lookup エンドポイントを使用すると、1人または複数のユーザーのプロフィール情報を取得できます。ユーザーを id や username で検索するか、現在認証されているユーザーの詳細を取得できます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="ID で検索" icon="fingerprint">
    一意のユーザー ID でユーザーを検索します
  </Card>

  <Card title="ユーザー名で検索" icon="at">
    @ユーザー名でユーザーを検索します
  </Card>

  <Card title="複数ユーザー" icon="users">
    1 回のリクエストで最大 100 人のユーザーを取得します
  </Card>

  <Card title="認証済みユーザー" icon="user-check">
    現在の認証ユーザーの詳細を取得します
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id`](/ja/x-api/users/get-user-by-id) | ID でユーザーを取得 |
| GET | [`/2/users`](/ja/x-api/users/get-users-by-ids) | 複数の ID でユーザーを取得（最大 100 件） |
| GET | [`/2/users/by/username/:username`](/ja/x-api/users/get-user-by-username) | ユーザー名でユーザーを取得 |
| GET | [`/2/users/by`](/ja/x-api/users/get-users-by-usernames) | 複数のユーザー名でユーザーを取得（最大 100 件） |
| GET | [`/2/users/me`](/ja/x-api/users/get-my-user) | 認証済みのユーザーを取得 |

***

<div id="example-request">
  ## リクエスト例
</div>

```bash
curl "https://api.x.com/2/users/by/username/XDevelopers?\
user.fields=created_at,description,public_metrics,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## レスポンス例
</div>

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",

    "public_metrics": {
      "followers_count": 583423,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```
