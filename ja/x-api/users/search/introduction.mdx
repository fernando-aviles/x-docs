User Search エンドポイントでは、キーワードでユーザーを検索できます。名前、ユーザー名、または自己紹介文の内容からユーザーを検索できます。

  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="キーワード検索" icon="magnifying-glass">

  </Card>

  <Card title="ユーザーを見つける" icon="user-plus">
    関連するアカウントを見つける
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## エンドポイント
</div>

| メソッド | エンドポイント | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/users/search`](/ja/x-api/users/search-users) | ユーザーを検索 |

***

<div id="example-request">
  ## リクエスト例
</div>

```bash
curl "https://api.x.com/2/users/search?\
query=python%20developer&\
user.fields=description,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## レスポンス例
</div>

```json
{
  "data": [
    {
      "id": "1234567890",

        "tweet_count": 1500

    }

  }
}
```
