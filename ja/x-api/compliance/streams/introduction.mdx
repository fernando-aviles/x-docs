X は、X API を利用して構築する開発者コミュニティへの支援に取り組んでいます。この取り組みの一環として、私たちは、API を開発者に対してオープンかつ公平であり、X を利用する人々にとって安全であり、X プラットフォーム全体にとって有益なものにすることを目指しています。X のコンテンツをオフラインで保存するすべての開発者は、そのデータがユーザーの意図と、X 上のコンテンツの現在の状態を反映していることを確実にすることが極めて重要です。たとえば、X 上の誰かが投稿やアカウントを削除したり、投稿を保護したり、投稿を編集した場合、その人の期待と意図を尊重することは、X と開発者の双方にとって非常に重要です。

コンプライアンスイベントのリアルタイムストリームは、開発者が [X Developer Agreement and Policy](https://developer.x.com/en/developer-terms/policy) に準拠した形で X のデータを維持するためのツールを提供します。 

c&#95;ompliance event&#95; ストリームは 2 種類あり、1 つは Post&#95; compliance&#95; イベント用、もう 1 つは *User compliance* イベント用です。これらのストリームは Enterprise アクセスで利用可能で、大量のデータを取り込むパートナーが、投稿の編集イベントなどのコンプライアンスイベントを「リッスン」できるように設計されています。

これらのストリームでは、次のイベントが提供されます。 

**Post compliance ストリーム: **

* delete - 投稿が削除されたことを示します。
* tweet&#95;edit - 投稿が編集されたことを示し、更新後の投稿の ID を提供します。 
* withheld - 投稿が 1 つ以上の国で非表示にされていることを示します。 
* drop - 投稿を公開ビューから削除すべきであることを示します。
* undrop - 投稿を再び表示し、公開として扱うことができることを示します。

**User compliance ストリーム: **

* **user&#95;delete** - ユーザーアカウントが削除されたことを示します。
* **user&#95;undelete** - ユーザーアカウントの削除が取り消されたことを示します。
* **user&#95;protect** - ユーザーアカウントが非公開になったことを示します。
* **user&#95;unprotect** - ユーザーアカウントが公開になったことを示します。
* **user&#95;withheld** - ユーザーアカウントが 1 つ以上の国で非表示にされていることを示します。 
* **user&#95;suspend** - ユーザーアカウントが凍結されたことを示します。
* **user&#95;unsuspend** - ユーザーアカウントの凍結が解除されたことを示します。
* **user&#95;profile&#95;modification** - ユーザープロフィールが更新されたことを示します。これには、説明、名前、場所、および URL の更新が含まれます。

**アカウントのセットアップ**

これらのエンドポイントにアクセスするには、次が必要です:

* 承認済みの [開発者アカウント](https://developer.x.com/en/portal/petition/essential/basic-info)。
* [Project](/ja/resources/fundamentals/developer-apps) 内にある [開発者用 App](/ja/resources/fundamentals/developer-apps) のキーとトークンを使用した認証。 

X API v2 エンドポイントへのアクセスの詳細については、[はじめにガイド](/ja/x-api/getting-started/getting-access) を参照してください。
