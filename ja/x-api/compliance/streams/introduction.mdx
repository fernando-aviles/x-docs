X は、X API を利用して構築する開発者コミュニティを支援することを約束しています。この取り組みの一環として、私たちは API を開発者に対してオープンかつ公平であり、X を利用する人々にとって安全で、X プラットフォーム全体にとって有益なものにすることを目指しています。X のコンテンツをオフラインで保存する開発者は誰であっても、そのデータがユーザーの意図と X 上のコンテンツの現在の状態を反映していることを確実にしなければなりません。たとえば、X 上の誰かがポストやアカウントを削除したり、ポストを保護したり、ポストを編集した場合、その人の期待と意図を X と開発者の双方が尊重することが重要です。

コンプライアンスイベントのリアルタイムストリームは、開発者が X データを [X Developer Agreement and Policy](https://developer.x.com/en/developer-terms/policy) に準拠した状態に維持するためのツールを提供します。 

c&#95;ompliance event&#95; ストリームは 2 種類あり、1 つは Post&#95; compliance&#95; イベント用、もう 1 つは *User compliance* イベント用です。これらのストリームは Enterprise アクセスで利用可能で、大量のデータを取り込むパートナーが、ポスト編集イベントのようなコンプライアンスイベントを「リッスン」できるように設計されています。

これらのストリームは、次のイベントを提供します。 

**Post compliance ストリーム: **

* delete - ポストが削除されたことを示します。

* tweet&#95;edit - ポストが編集され、更新されたポストの ID が提供されることを示します。 

* withheld - ポストが 1 つ以上の国で保留（表示制限）されていることを示します。 

* drop - ポストを公開ビューから削除すべきであることを示します。

* undrop - ポストを再び表示し、公開として扱うことができることを示します。

**User compliance ストリーム: **

* **user&#95;delete** - ユーザーアカウントが削除されたことを示します

* **user&#95;undelete** - ユーザーアカウントの削除が取り消されたことを示します

* **user&#95;protect** - ユーザーアカウントが非公開になったことを示します

* **user&#95;unprotect** - ユーザーアカウントが公開になったことを示します

* **user&#95;withheld** - ユーザーアカウントが 1 つ以上の国で保留（表示制限）されていることを示します。 

* **user&#95;suspend** - ユーザーアカウントが凍結されたことを示します

* **user&#95;unsuspend** - ユーザーアカウントの凍結が解除されたことを示します

* **user&#95;profile&#95;modification** - ユーザープロフィールが更新されたことを示します。これには、説明、名前、所在地、URL の更新が含まれます。

**アカウント設定**

これらのエンドポイントにアクセスするには、次が必要です:

* 承認済みの [開発者アカウント](https://developer.x.com/en/portal/petition/essential/basic-info)。
* [Project](/ja/resources/fundamentals/developer-apps) 内にある [developer App](/ja/resources/fundamentals/developer-apps) のキーとトークンを使用して認証すること。 

X API v2 エンドポイントへのアクセス取得について詳しくは、[はじめにガイド](/ja/x-api/getting-started/getting-access)をご覧ください。
