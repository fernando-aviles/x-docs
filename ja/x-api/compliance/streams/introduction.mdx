X は、X API を使って構築する開発者コミュニティを支援することに尽力しています。この取り組みの一環として、私たちは API を開発者に対してオープンかつ公平に保ち、X 上の人々にとって安全であり、X プラットフォーム全体にとって有益なものにすることを目指しています。X コンテンツをオフラインで保存するすべての開発者は、そのデータがユーザーの意図と X 上のコンテンツの現在の状態を反映していることを確実にすることが極めて重要です。たとえば、X 上の誰かが投稿やアカウントを削除したり、投稿を非公開にしたり、投稿を編集した場合、その人の期待と意図を X と開発者の双方が尊重することが不可欠です。

コンプライアンス イベントのリアルタイムストリームは、開発者が [X Developer Agreement and Policy](https://developer.x.com/en/developer-terms/policy) に準拠した形で X のデータを維持するためのツールを提供します。 

c&#95;ompliance event&#95; ストリームは 2 種類あり、1 つは Post&#95; compliance&#95; イベント用、もう 1 つは *User compliance* イベント用です。これらのストリームは Enterprise アクセスで利用可能で、大量のデータを取り込むパートナーが、投稿の編集イベントなどのコンプライアンス イベントを「リッスン」できるよう設計されています。

これらのストリームでは、以下のイベントが提供されます。 

**Post compliance stream: **

* delete - 投稿が削除されたことを示します。

* tweet&#95;edit - 投稿が編集され、更新後の投稿の ID が提供されることを示します。 

* withheld - 投稿が 1 つ以上の国で保留（表示制限）されていることを示します。 

* drop - 投稿を一般公開から削除すべきであることを示します。

* undrop - 投稿を再び表示し、公開コンテンツとして扱うことができることを示します。

**User compliance stream: **

* **user&#95;delete** - ユーザーアカウントが削除されたことを示します

* **user&#95;undelete** - ユーザーアカウントの削除が取り消されたことを示します

* **user&#95;protect** - ユーザーアカウントが非公開になったことを示します

* **user&#95;unprotect** - ユーザーアカウントが公開になったことを示します

* **user&#95;withheld** - ユーザーアカウントが 1 つ以上の国で保留（表示制限）されていることを示します。 

* **user&#95;suspend** - ユーザーアカウントが凍結されたことを示します

* **user&#95;unsuspend** - ユーザーアカウントの凍結が解除されたことを示します

* **user&#95;profile&#95;modification** - ユーザープロフィールが更新されたことを示します。これには、自己紹介、名前、場所、URL の更新が含まれます。

**アカウントのセットアップ**

これらのエンドポイントにアクセスするには、次のものが必要です。

* 承認済みの [開発者アカウント](https://developer.x.com/en/portal/petition/essential/basic-info)。
* [Project](/ja/resources/fundamentals/developer-apps) 内にある [開発者用 App](/ja/resources/fundamentals/developer-apps) から取得したキーとトークンを使用して認証すること。 

X API v2 エンドポイントへのアクセス方法の詳細については、[利用開始ガイド](/ja/x-api/getting-started/getting-access) を参照してください。
