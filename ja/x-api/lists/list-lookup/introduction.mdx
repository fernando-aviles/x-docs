List ルックアップエンドポイントを使用すると、List に関する情報を取得できます。id を指定して特定の List を取得するか、ユーザーが所有するすべての List を取得できます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="ID 指定" icon="list">
    特定の List の詳細を取得します
  </Card>

  <Card title="所有者別" icon="user">
    ユーザーが所有するすべての List を取得します
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id`](/ja/x-api/lists/get-list-by-id) | リストIDでリストを取得 |
| GET | [`/2/users/:id/owned_lists`](/ja/x-api/users/get-owned-lists) | 指定ユーザーが所有するリストを取得 |

***

<div id="response-fields">
  ## レスポンスのフィールド
</div>

デフォルトでは、レスポンスには `id` と `name` が含まれます。追加でリクエストできるフィールドは次のとおりです:

| フィールド | 説明 |
|:------|:------------|
| `description` | リストの説明 |
| `owner_id` | 所有者のユーザーID |
| `private` | リストが非公開かどうか |
| `follower_count` | フォロワー数 |
| `member_count` | メンバー数 |
| `created_at` | リストの作成日 |

<div id="example-request">
  ### リクエスト例
</div>

```bash
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id,member_count,follower_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
