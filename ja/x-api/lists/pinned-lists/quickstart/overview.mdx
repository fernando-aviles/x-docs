固定済みリストのエンドポイントを使用すると、ユーザーの固定済みリストを取得し、どのリストが固定されているかを管理できます。

<Note>
  **前提条件**

  作業を開始する前に、次のものが必要です。

  * 承認済みの App を含む [開発者アカウント](https://developer.x.com/en/portal/petition/essential/basic-info)
  * User Access Token（OAuth 1.0a または OAuth 2.0 PKCE）
</Note>

<div id="authentication">
  ## 認証
</div>

| 操作 | 認証 |
|:----------|:---------------|
| ピン留めされたListの参照 | OAuth 1.0a または OAuth 2.0 PKCE |
| Listのピン留め/ピン留め解除 | OAuth 1.0a または OAuth 2.0 PKCE |

<Warning>
  参照および管理のいずれの操作も、ユーザーコンテキストを伴う認証が必要です。アプリのみ認証（Bearer Token）はサポートされていません。
</Warning>

<div id="quick-example">
  ## 簡単なサンプル
</div>

<CodeGroup dropdown>
  ```bash cURL
  # ピン留めされたリストを取得
  curl "https://api.x.com/2/users/2244994945/pinned_lists" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # ピン留めされたリストを取得
  response = client.lists.get_pinned("2244994945")

  for lst in response.data:
      print(f"{lst.name}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // ピン留めされたリストを取得
  const response = await client.lists.getPinned("2244994945");

  response.data?.forEach((lst) => {
    console.log(lst.name);
  });
  ```
</CodeGroup>
