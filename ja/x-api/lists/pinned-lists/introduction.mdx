Pinned Lists エンドポイントでは、認証済みユーザーのリストを表示したり、ピン留めおよびピン留め解除したりできます。Pinned Lists はユーザーの X インターフェース上で目立つ位置に表示されます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="固定されたリストを表示" icon="thumbtack">
    ユーザーの固定されたリストを取得します
  </Card>

  <Card title="リストを固定表示" icon="plus">
    リストを固定表示します
  </Card>

  <Card title="リストの固定表示を解除" icon="minus">
    リストの固定表示を解除します
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| メソッド | エンドポイント | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/pinned_lists`](/ja/x-api/users/get-pinned-lists) | ピン留めされたリストを取得 |
| POST | [`/2/users/:id/pinned_lists`](/ja/x-api/users/pin-list) | リストをピン留め |
| DELETE | [`/2/users/:id/pinned_lists/:list_id`](/ja/x-api/users/unpin-list) | リストのピン留めを解除 |
---------------------------------------------------------------------------------------------

<div id="example-pin-a-list">
  ## 例: ピン留めリストを取得する
</div>

```bash
curl "https://api.x.com/2/users/123456789/pinned_lists?\
list.fields=name,description,member_count" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="getting-started">
  ## 例: リストをピン留めする
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"list_id": "9876543210"}'
```
