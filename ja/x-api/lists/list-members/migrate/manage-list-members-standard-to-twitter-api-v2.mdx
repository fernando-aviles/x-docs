<div id="manage-list-members-standard-v11-compared-to-x-api-v2">
  ### リストメンバーの管理：Standard v1.1 と X API v2 の比較
</div>

Standard v1.1 の [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) および [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) エンドポイントを使用している場合、本ガイドの目的は、Standard v1.1 と X API v2 のリストメンバー管理エンドポイントの共通点と相違点を理解するうえで役立てることです。

* **共通点**
  * 認証
* **相違点**
  * エンドポイント URL
  * アプリおよび Project の要件
  * HTTP メソッド
  * レート制限
  * リクエストパラメータ

<div id="similarities">
  #### 類似点
</div>

**認証**

両方のエンドポイントのバージョンは [OAuth 1.0a ユーザーコンテキスト](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication) をサポートします。そのため、以前に標準 v1.1 の List メンバー管理エンドポイントのいずれかを利用していた場合は、X API v2 バージョンへ移行しても、同じ認証方式をそのまま利用できます。

<div id="differences">
  #### 違い
</div>

**エンドポイント URL**

* Standard v1.1 エンドポイント:
  * POST https://api.x.com/1.1/lists/members/create.json
    (指定した List にメンバーを追加します)
  * POST https://api.x.com/1.1/lists/members/destroy.json
    (指定した List からメンバーを削除します)
* X API v2 エンドポイント:
  * POST https://api.x.com/2/lists/:id/members
    (指定した List にメンバーを追加します)

  * DELETE https://api.x.com/2/lists/:id/members/:user&#95;id
    (指定した List からメンバーを削除します)

**レート制限**

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| /1.1/lists/members/create.json<br /><br />なし | /2/lists/:id/members<br /><br />OAuth 1.0a ユーザーコンテキストを利用した場合、15 分間で 300 リクエスト<br /><br />OAuth 2.0 Authorization Code with PKCE を利用した場合、15 分間で 300 リクエスト |
| /1.1/lists/members/destroy.json<br /><br />なし | /2/lists/:id/members/:user&#95;id<br /><br />OAuth 1.0a ユーザーコンテキストを利用した場合、15 分間で 300 リクエスト<br /><br />OAuth 2.0 Authorization Code with PKCE を利用した場合、15 分間で 300 リクエスト |

**App と Project の要件**

X API v2 エンドポイントでは、リクエストの認証時に、[Project](/ja/resources/fundamentals/developer-apps) に関連付けられている [developer App](/ja/resources/fundamentals/developer-apps)（開発者用 App）の認証情報を使用する必要があります。すべての X API v1.1 エンドポイントでは、Project に関連付けられているかどうかに関係なく、任意の App の認証情報を使用できます。

**リクエストパラメータ**

次の Standard v1.1 のリクエストパラメータには、X API v2 における対応があります。

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| list&#95;id | id  |
| slug | 対応なし |
| screen&#95;name | 対応なし |
| owner&#95;screen&#95;name | 対応なし |
| owner&#95;id | 対応なし |
