<div id="comparing-x-apis-list-members-endpoints">
  ## X API のリストメンバーエンドポイントの比較
</div>

v2 のリストメンバーエンドポイントグループは、標準的な v1.1 の [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members)、[GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships)、[POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create)、および [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) エンドポイントを置き換えます。これらのいずれかのリストメンバーエンドポイントを使用しているコード、アプリ、またはツールがあり、より新しい X API v2 エンドポイントへの移行を検討している場合は、この一連のガイドが役立ちます。 

<div id="list-members-lookup">
  ### リストメンバーの取得
</div>

v2 の List members lookup エンドポイントは、従来の標準 [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members)、[GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships) エンドポイントに代わるものです。

次の表は、標準の v1.1 と X API v2 の List エンドポイントを比較したものです。

**List member Lookup**

|     |     |     |
| :--- | :--- | :--- |
| 説明 | 標準 v1.1 | X API v2 |
| サポートされる HTTP メソッド | `GET` | `GET` |
| ホストドメイン | `https://api.x.com` | `https://api.x.com` |
| エンドポイントパス | `/1.1/lists/members.json` | `/2/lists/:id/members` |
| [Authentication](/ja/resources/fundamentals/authentication) | OAuth 1.0a ユーザーコンテキスト<br /><br />アプリのみ | OAuth 1.0a ユーザーコンテキスト<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />アプリのみ |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | OAuth 1.0a では 15 分あたり 900 リクエスト<br /><br />アプリのみでは 15 分あたり 75 リクエスト | OAuth 1.0a では 15 分あたり 900 リクエスト<br /><br />OAuth 2.0 では 15 分あたり 900 リクエスト<br /><br />アプリのみでは 15 分あたり 900 リクエスト |

**リストメンバーシップの取得**

|     |     |     |
| :--- | :--- | :--- |
| 説明 | 標準 v1.1 | X API v2 |
| サポートされる HTTP メソッド | `GET` | `GET` |
| ホストドメイン | `https://api.x.com` | `https://api.x.com` |
| エンドポイントパス | `/1.1/lists/memberships.json` | `/2/users/:id/list_memberships` |
| [Authentication](/ja/resources/fundamentals/authentication) | OAuth 1.0a ユーザーコンテキスト<br /><br />アプリのみ | OAuth 1.0a ユーザーコンテキスト<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />アプリのみ |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | OAuth 1.0a では 15 分あたり 75 リクエスト<br /><br />アプリのみでは 15 分あたり 75 リクエスト | OAuth 1.0a では 15 分あたり 75 リクエスト<br /><br />OAuth 2.0 では 15 分あたり 75 リクエスト<br /><br />アプリのみでは 15 分あたり 75 リクエスト |

<div id="manage-list-members">
  ### リストメンバーの管理
</div>

v2 のリストメンバー管理エンドポイントは、標準の [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create)、[POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy) エンドポイントを置き換えます。

次の表は、標準の v1.1 と X API v2 のリストエンドポイントを比較したものです。

**メンバーを追加**

| 説明 | 標準 v1.1 | X API v2 |
| :--- | :--- | :--- |
| サポートされる HTTP メソッド | POST | POST |
| ホストドメイン | https://api.x.com | https://api.x.com |
| エンドポイントパス | /1.1/lists/members/create.json | /2/lists/:id/members |
| [認証](/ja/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | なし | 15 分あたり 300 リクエスト（ユーザーごと） |

**メンバーを削除**

| 説明 | 標準 v1.1 | X API v2 |
| :--- | :--- | :--- |
| サポートされる HTTP メソッド | POST | DELETE |
| ホストドメイン | https://api.x.com | https://api.x.com |
| エンドポイントパス | /1.1/lists/members/destroy.json | /2/lists/:id/:user&#95;id |
| [認証](/ja/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | なし | 15 分あたり 300 リクエスト（ユーザーごと） |

X API v2 のエンドポイントにアクセスするには、[開発者アカウントに登録](https://developer.x.com/en/portal/petition/essential/basic-info)する必要があります。認証する際は、[Project](/ja/resources/fundamentals/developer-apps) 内にある [開発者用 App](/ja/resources/fundamentals/developer-apps) のキーとトークンを使用する必要があります。

X API v2 のエンドポイントへのアクセス方法について詳しくは、[はじめに](/ja/x-api/getting-started/getting-access) ページを参照してください。
