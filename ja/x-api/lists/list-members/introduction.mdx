List Members エンドポイントでは、リストのメンバーを表示したり、リストにメンバーを追加・削除したりできます。また、ユーザーがメンバーとして所属しているリストを確認することもできます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="メンバーを表示" icon="users">
    リストに含まれるすべてのメンバーを取得する
  </Card>

  <Card title="メンバーを追加" icon="user-plus">
    リストにユーザーを追加する
  </Card>

  <Card title="メンバーを削除" icon="user-minus">
    リストからユーザーを削除する
  </Card>

  <Card title="所属リスト" icon="list">
    ユーザーが所属しているリストを表示する
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

<div id="list-members-lookup">
  ### リストメンバーの取得
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/members`](/ja/x-api/lists/get-list-members) | リストのメンバーを取得 |
| GET | [`/2/users/:id/list_memberships`](/ja/x-api/users/get-list-memberships) | ユーザーが所属しているリストを取得 |

<div id="manage-list-members">
  ### リストメンバーの管理
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| POST | [`/2/lists/:id/members`](/ja/x-api/lists/add-list-member) | メンバーの追加 |
| DELETE | [`/2/lists/:id/members/:user_id`](/ja/x-api/lists/remove-list-member) | メンバーの削除 |

***

<div id="example-get-list-members">
  ## 例: リストのメンバーを取得する
</div>

```bash
curl "https://api.x.com/2/lists/1234567890/members?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-add-a-member">
  ## 例：メンバーを追加する
</div>

```bash
curl -X POST "https://api.x.com/2/lists/1234567890/members" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "9876543210"}'
```
