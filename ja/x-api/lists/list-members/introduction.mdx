List Members エンドポイントを使用すると、リストのメンバーを表示したり、リストにメンバーを追加・削除したりできます。また、ユーザーがメンバーになっているリストを確認することもできます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="メンバーを表示" icon="users">
    リストのすべてのメンバーを取得します
  </Card>

  <Card title="メンバーを追加" icon="user-plus">
    リストにユーザーを追加します
  </Card>

  <Card title="メンバーを削除" icon="user-minus">
    リストからユーザーを削除します
  </Card>

  <Card title="メンバーシップ" icon="list">
    ユーザーが参加しているリストを表示します
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

<div id="list-members-lookup">
  ### リストメンバーの参照
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/members`](/ja/x-api/lists/get-list-members) | リストのメンバーを取得 |
| GET | [`/2/users/:id/list_memberships`](/ja/x-api/users/get-list-memberships) | ユーザーが含まれているリストを取得 |

<div id="manage-list-members">
  ### リストメンバーの管理
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/lists/:id/members`](/ja/x-api/lists/add-list-member) | メンバーを追加する |
| DELETE | [`/2/lists/:id/members/:user_id`](/ja/x-api/lists/remove-list-member) | メンバーを削除する |

***

<div id="example-get-list-members">
  ## 例：リストメンバーを取得する
</div>

```bash
curl "https://api.x.com/2/lists/1234567890/members?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-add-a-member">
  ## 例: メンバーの追加
</div>

```bash
curl -X POST "https://api.x.com/2/lists/1234567890/members" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "9876543210"}'
```
