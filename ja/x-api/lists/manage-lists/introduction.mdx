Manage Lists エンドポイントを使うと、認証されたユーザーの代わりにリストを作成、更新、削除できます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="作成" icon="plus">
    新しいリストを作成する
  </Card>

  <Card title="更新" icon="pen">
    リストの名前と説明を更新する
  </Card>

  <Card title="削除" icon="trash">
    リストを削除する
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| POST | [`/2/lists`](/ja/x-api/lists/create-list) | 新しいリストを作成します |
| PUT | [`/2/lists/:id`](/ja/x-api/lists/update-list) | リストを更新します |
| DELETE | [`/2/lists/:id`](/ja/x-api/lists/delete-list) | リストを削除します |

***

<div id="example-create-a-list">
  ## 例: リストの作成
</div>

```bash
curl -X POST "https://api.x.com/2/lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech News",
    "description": "My favorite tech journalists",
    "private": false
  }'
```

<div id="example-response">
  ## レスポンス例
</div>

```json
{
  "data": {
    "id": "1234567890",
    "name": "Tech News"
  }
}
```
