<div id="comparing-x-apis-lists-endpoints">
  ## X API の Lists エンドポイントの比較
</div>

v2 の Lists 管理エンドポイントは、最終的に [POST lists/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-create)、[POST lists/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-destroy)、および [POST lists/update](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-update) を置き換える予定です。これらのエンドポイントの旧バージョンを利用するコードやアプリ、ツールがあり、新しい X API v2 への移行を検討している場合は、このガイドをご参照ください。 

以下の表では、標準 v1.1 と X API v2 の List エンドポイントを比較します。

**List を作成する**

| 説明 | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| サポートされる HTTP メソッド | POST | POST |
| ホストドメイン | https://api.x.com | https://api.x.com |
| エンドポイントパス | /1.1/lists/create.json | /2/lists |
| [Authentication](/ja/resources/fundamentals/authentication) | OAuth 1.0a ユーザーコンテキスト | OAuth 1.0a ユーザーコンテキスト |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | なし | 15 分あたり 300 リクエスト（ユーザーごと） |

**List を削除する**

| 説明 | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| サポートされる HTTP メソッド | POST | DELETE |
| ホストドメイン | https://api.x.com | https://api.x.com |
| エンドポイントパス | /1.1/lists/destroy.json | /2/lists/:id |
| [Authentication](/ja/resources/fundamentals/authentication) | OAuth 1.0a ユーザーコンテキスト | OAuth 1.0a ユーザーコンテキスト |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | なし | 15 分あたり 300 リクエスト（ユーザーごと） |

**List を更新する**

| 説明 | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| サポートされる HTTP メソッド | POST | PUT |
| ホストドメイン | https://api.x.com | https://api.x.com |
| エンドポイントパス | /1.1/lists/update.json | /2/lists/:id |
| [Authentication](/ja/resources/fundamentals/authentication) | OAuth 1.0a ユーザーコンテキスト | OAuth 1.0a ユーザーコンテキスト |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | なし | 15 分あたり 300 リクエスト（ユーザーごと） |

X API v2 のエンドポイントにアクセスするには、[開発者アカウントに登録](https://developer.x.com/en/portal/petition/essential/basic-info)する必要があります。認証を行う際は、[Project](/ja/resources/fundamentals/developer-apps) 内にある [開発者用 App](/ja/resources/fundamentals/developer-apps) のキーとトークンを使用する必要があります。 

X API v2 のエンドポイントへのアクセス方法の詳細については、[はじめに](/ja/x-api/getting-started/getting-access)ページをご覧ください。
