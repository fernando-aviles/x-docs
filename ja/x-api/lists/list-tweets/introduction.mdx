List Posts エンドポイントを使用すると、リストのタイムラインから投稿を取得できます。リストの全メンバーによる最新の投稿を取得します。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="リストタイムライン" icon="list">
    リストメンバーの投稿を取得します
  </Card>

  <Card title="キュレーション済みフィード" icon="stream">
    キュレーション済みのコンテンツフィードにアクセスします
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/tweets`](/ja/x-api/lists/get-list-posts) | リストから投稿を取得 |

***

<div id="example-request">
  ## リクエスト例
</div>

```bash
curl "https://api.x.com/2/lists/1234567890/tweets?\
tweet.fields=created_at,author_id,public_metrics&\
expansions=author_id&\
user.fields=username&\
max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
