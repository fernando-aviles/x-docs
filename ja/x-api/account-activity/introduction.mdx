Account Activity API は、リアルタイムのアカウントアクティビティイベントを Webhook に配信します。ユーザーアカウントをサブスクライブし、ユーザーが投稿したり、DM を受信したり、フォローされたりしたときなどに通知を受け取ることができます。

<div id="how-it-works">
  ## 仕組み
</div>

1. **Webhook を登録** — Webhook URL を登録します
2. **ユーザーをサブスクライブ** — ユーザーのサブスクリプションを追加します
3. **イベントを受信** — POST リクエストでアクティビティイベントを受信します
4. **イベントを処理** — アプリケーション内でイベントを処理します

***

<div id="event-types">
  ## イベントタイプ
</div>

| カテゴリ | イベント |
|:---------|:-------|
| **投稿** | 作成、削除、いいね、いいね解除 |
| **ダイレクトメッセージ** | 受信、送信、入力中インジケーター |
| **フォロー** | フォロー、フォロー解除 |
| **ブロック** | ブロック、ブロック解除 |
| **ミュート** | ミュート、ミュート解除 |

***

<div id="webhook-security">
  ## Webhook セキュリティ
</div>

すべての webhook リクエストには次の内容が含まれます。

* **CRC validation** — webhook の正当性を検証します
* **Signature header** — `x-twitter-webhooks-signature`
* **HTTPS required** — すべての webhook URL は HTTPS が必須です

***

<div id="example-register-a-webhook">
  ## Webhook を登録する例
</div>

```bash
curl -X POST "https://api.x.com/1.1/account_activity/all/env-name/webhooks.json?\
url=https%3A%2F%2Fyour-server.com%2Fwebhook" \
  -H "Authorization: OAuth oauth_consumer_key=..."
```
