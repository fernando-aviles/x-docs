Account Activity API は、リアルタイムのアカウントアクティビティイベントを Webhook に配信します。ユーザーアカウントをサブスクライブしておくと、ユーザーが投稿したとき、DM を受信したとき、フォローされたときなどに通知を受け取ることができます。

<div id="how-it-works">
  ## 動作の仕組み
</div>

1. **Webhook を登録** — Webhook URL を登録します
2. **ユーザーを登録** — ユーザーのサブスクリプションを追加します
3. **イベントを受信** — POST リクエストとしてアクティビティイベントを受信します
4. **イベントを処理** — アプリケーション内でイベントを処理します

***

<div id="event-types">
  ## イベントタイプ
</div>

| カテゴリ | イベント |
|:---------|:-------|
| **投稿** | 作成、削除、いいね、いいね取り消し |
| **ダイレクトメッセージ** | 受信、送信、入力中インジケーター |
| **フォロー** | フォロー、フォロー解除 |
| **ブロック** | ブロック、ブロック解除 |
| **ミュート** | ミュート、ミュート解除 |

***

<div id="webhook-security">
  ## Webhook セキュリティ
</div>

すべての webhook リクエストには以下が含まれます：

* **CRC 検証** — webhook の正当性を検証
* **署名ヘッダー** — `x-twitter-webhooks-signature`
* **HTTPS 必須** — すべての webhook URL は HTTPS を使用する必要があります

***

<div id="example-register-a-webhook">
  ## 例：webhook を登録する
</div>

```bash
curl -X POST "https://api.x.com/1.1/account_activity/all/env-name/webhooks.json?\
url=https%3A%2F%2Fyour-server.com%2Fwebhook" \
  -H "Authorization: OAuth oauth_consumer_key=..."
```
