表の中には、まだ **[Coming Soon]** と記載されている項目がいくつかあることに気づくはずです。この表で **[Replacement Under Consideration]** または **[No Replacement Planned]** と記載されているエンドポイントについて、v2 バージョンの提供をご希望の場合は、[コミュニティフォーラム](https://devcommunity.x.com/) もしくは担当のエンタープライズアカウントマネージャーまでご連絡ください。
