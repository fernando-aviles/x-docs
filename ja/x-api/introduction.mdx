X API を使うと、X の公開された会話にプログラムからアクセスできます。投稿を読み取り、コンテンツを投稿し、ユーザーを管理し、トレンドを分析できます。これらはすべて、最新の REST エンドポイントと柔軟な従量課金制料金を通じて利用できます。

<div id="key-features">
  ## 主要な機能
</div>

<Tabs>
  <Tab title="データアクセス">
    ### リッチなデータオブジェクト

    投稿、ユーザー、メディアなどの詳細で構造化されたデータにアクセスできます:

    * **投稿**: 全文、メトリクス、エンティティ、注釈、会話スレッド
    * **ユーザー**: プロフィール、フォロワー数、認証ステータス
    * **メディア**: メタデータ付き画像、動画、GIF
    * **投票**: 選択肢と投票数

    [フィールド](/ja/x-api/fundamentals/fields) と [展開](/ja/x-api/fundamentals/expansions) を使用してレスポンスをカスタマイズし、必要なデータだけを取得できます。
  </Tab>

  <Tab title="リアルタイムストリーミング">
    ### フィルタ済みストリーム

    投稿が公開されると同時にリアルタイムで受け取れます。最大 1,000 個までのフィルタリングルールを定義し、一致する投稿だけを受信できます。

    ```bash
    # ルールを追加
    curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{"add": [{"value": "from:xdevelopers"}]}'

    # ストリームに接続
    curl "https://api.x.com/2/tweets/search/stream" \
      -H "Authorization: Bearer $TOKEN"
    ```

    [フィルタ済みストリームの詳細 →](/ja/x-api/posts/filtered-stream/introduction)
  </Tab>

  <Tab title="検索と分析">
    ### 全アーカイブ検索

    2006 年までさかのぼる公開投稿の全履歴を検索できます。ユーザー、キーワード、日付などの演算子を使ってクエリを構築できます。

    ```bash
    curl "https://api.x.com/2/tweets/search/all?query=AI%20lang:en" \
      -H "Authorization: Bearer $TOKEN"
    ```

    ### メトリクス

    インプレッション、いいね、リポスト、返信、動画再生数などのエンゲージメントメトリクスにアクセスできます。

    [検索の詳細 →](/ja/x-api/posts/search/introduction)
  </Tab>
</Tabs>

<div id="api-versions">
  ## API バージョン
</div>

| Version | Status | Description |
|:--------|:-------|:------------|
| **v2** | 現行 | モダンなエンドポイント、柔軟な料金体系、すべての新機能 |
| **Enterprise** | 利用可能 | 大規模向けアクセスと専任サポート |

<Tip>
  すべての新規プロジェクトには **X API v2** を使用してください。新機能や改善はすべてこのバージョンで提供されます。
</Tip>

<div id="quick-start">
  ## クイックスタート
</div>

<Steps>
  <Step title="開発者アカウントを作成する">
    [console.x.com](https://console.x.com) にサインアップし、アプリを作成します。
  </Step>

  <Step title="認証情報を取得する">
    アプリのみのリクエスト向けの Bearer Token を生成します。
  </Step>

  <Step title="リクエストを送信する">
    ユーザーを取得してみましょう:

    ```bash
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>
</Steps>
