Activity Stream エンドポイントは、サブスクライブしているユーザーのアカウントアクティビティイベントをリアルタイムで配信します。ユーザーが投稿したり、いいねやフォローをしたり、DM を受信したりした際のイベントを受け取ることができます。

<div id="event-types">
  ## イベントタイプ
</div>

| Event | 説明 |
|:------|:------------|
| `tweet_create_events` | ユーザーが新しい投稿を作成する |
| `favorite_events` | ユーザーが投稿にいいねする |
| `follow_events` | ユーザーがフォローする、またはフォローされる |
| `direct_message_events` | ユーザーがDMを送信する、または受信する |
| `block_events` | ユーザーがブロックする、またはブロック解除する |
| `mute_events` | ユーザーがミュートする、またはミュート解除する |

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/activity/stream`](/ja/x-api/activity/activity-stream) | アクティビティストリームに接続する |
| POST | [`/2/activity/subscriptions`](/ja/x-api/activity/create-x-activity-subscription) | サブスクリプションを作成する |
| GET | [`/2/activity/subscriptions`](/ja/x-api/activity/get-x-activity-subscriptions) | サブスクリプションを一覧表示する |
| PUT | [`/2/activity/subscriptions/:id`](/ja/x-api/activity/update-x-activity-subscription) | サブスクリプションを更新する |
| DELETE | [`/2/activity/subscriptions/:id`](/ja/x-api/activity/deletes-x-activity-subscription) | サブスクリプションを削除する |

***

<div id="how-it-works">
  ## 仕組み
</div>

1. **サブスクリプションを作成** — 特定ユーザーのアクティビティを受信するよう登録する
2. **ストリームに接続** — 持続的な接続を確立する
3. **イベントを受信** — アクティビティイベントをリアルタイムで受信する
4. **イベントを処理** — アプリケーションでイベントを処理する

***

<div id="example-connect-to-stream">
  ## 例: ストリームに接続する
</div>

```python
import requests

def stream_activity(bearer_token):
    url = "https://api.x.com/2/activity/stream"
    headers = {"Authorization": f"Bearer {bearer_token}"}
    
    response = requests.get(url, headers=headers, stream=True)
    
    for line in response.iter_lines():
        if line:
            print(line.decode("utf-8"))
```
