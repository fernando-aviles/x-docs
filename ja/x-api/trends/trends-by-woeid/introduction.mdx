Trends by WOEID エンドポイントは、Yahoo! の Where On Earth ID (WOEID) で識別される特定の地域のトレンドトピックを返します。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="地域別" icon="location-dot">
    サポートされている任意の地域のトレンド
  </Card>

  <Card title="グローバル対応" icon="globe">
    国・都市・地域をカバー
  </Card>

  <Card title="リアルタイム" icon="bolt">
    リアルタイムのトレンドトピック
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## エンドポイント
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/trends/by/woeid/:id`](/ja/x-api/trends/get-trends-by-woeid) | 指定した WOEID のトレンドを取得 |

***

<div id="common-woeids">
  ## 主な WOEID
</div>

| 地域 | WOEID |
|:---------|:------|
| 全世界 | 1 |
| アメリカ合衆国 | 23424977 |
| イギリス | 23424975 |
| 日本 | 23424856 |
| ニューヨーク | 2459115 |
| ロサンゼルス | 2442047 |
| ロンドン | 44418 |
| 東京 | 1118370 |

***

<div id="example-request">
  ## リクエスト例
</div>

```bash
curl "https://api.x.com/2/trends/by/woeid/1" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## レスポンス例
</div>

```json
{
  "data": [
    {
      "trend_name": "#AI",
      "tweet_count": 250000
    },
    {
      "trend_name": "Breaking News",
      "tweet_count": 180000
    }
  ]
}
```
