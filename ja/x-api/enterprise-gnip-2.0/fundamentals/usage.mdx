<div id="usage-api-twitter-api">
  ## 使用状況 API | Twitter API
</div>

<div id="overview">
  ### 概要
</div>

`Enterprise`

これは、アカウント配下のさまざまな API 全体での利用状況を監視および管理するうえで、最も重要で、かつ *最適* なツールです。

**重要な免責事項:**

Usage API から返される利用数は、トライアルやその他の請求調整により、請求書に記載される請求内容と一致しない場合があります。すべての数値は、特定の 1 日（UTC）内で消費された重複排除済みのアクティビティに基づいています。

<div id="features">
  #### 機能
</div>

* console.gnip.com の UI で利用可能な利用状況データをプログラムで取得
* ストリームレベルの利用状況データ - プロダクトレベルに加えて、ストリームレベル（例: dev と prod）での利用状況データも提供
* きめ細かく分かりやすいデータ - 検索の「requests」は Full-Archive と 30-Day Search 各プロダクトごとに分割
* Historical PowerTrack の「days」と「jobs」 

<div id="supported-apis">
  ### サポート対象の API
</div>

以下は、Usage API が現在サポートしている API の一覧です。

* PowerTrack API `enterprise`
* 30-Day Search API `enterprise`
* Full-Archive Search API `enterprise`
* Historical PowerTrack `enterprise`

<div id="limitations">
  ### 制限事項
</div>

* Usage API では、2018 年 5 月 1 日以降の利用状況データにアクセスできます。2019 年 7 月 1 日以降は、Usage API を使用して、**直近 13 か月間の各暦月分** の利用状況データにアクセスできます。

* `fromDate` と `toDate` で定義される **3 か月単位の期間** で利用状況データにアクセスできます。

以下にリクエストとレスポンスの例を示します:

```bash
curl -u<username>:<password> \
"https://gnip-api.x.com/metrics/usage/accounts/<account-name>.json?bucket=month"
```

<div id="methods">
  #### **メソッド**
</div>

| Method | 説明 |
| :--- | :--- |
| [GET /metrics/usage/accounts/{ACCOUNT_NAME}.json](#GETData) | 利用状況データを取得します |

ここで:

* :account&#95;name は、console.gnip.com に表示されるお使いのアカウントに関連付けられた名前で、大文字と小文字が区別されます。

<div id="authentication-and-rate-limit">
  #### **認証とレート制限**
</div>

<div id="authentication">
  ##### **認証**
</div>

Usage API へのすべてのリクエストには、HTTP Basic 認証が必要です。console.gnip.com へのログインや任意の Gnip ストリームへの接続に使用している、アカウントで有効化されているメールアドレスとパスワードの認証情報のいずれかを使用してください。

<div id="rate-limit">
  ##### **レート制限**
</div>

Usage API では、1分あたり2件のリクエストというレート制限が適用されます。

<div id="best-practices-limitations">
  #### **ベストプラクティスおよび制限事項**
</div>

<div id="data-availability">
  ##### **データの利用可能性**
</div>

Usage data は、処理された直近の完全な時間帯（UTC）を通じて取得された、重複排除済みのアクティビティに基づきます。Gnip がシステムをデプロイしている場合を除き、data は通常、分単位で処理および更新されます。

* Usage API を使用すると、2018 年 5 月 1 日以降の usage data にアクセスできます。2019 年 7 月 1 日以降は、Usage API により、**直近 13 か月分の暦月**の usage data にアクセスできます。 

* fromDate と toDate で定義される **3 か月間隔** で usage data にアクセスできます。

<div id="requesting-and-receiving-data">
  #### **データのリクエストと受信**
</div>

Usage API は、お使いのアカウントの API エンドポイントに対して、HTTP BASIC-AUTH 認証情報付きの HTTP GET リクエストを送信することで動作します。

<div id="get-request">
  ##### GET Request:
</div>

ユーザー認証情報とアカウント名を使用して、次のエンドポイントに GET リクエストを送信します。

https://gnip-api.x.com/metrics/usage/accounts/:account&#95;name.json

**Additional Parameters**

|     |     |
| :--- | :--- |
| bucket | 任意。利用状況データが提供される時間単位です。利用状況データは日次または月次の粒度で返すことができます。  <br />  <br />bucket を指定せずにリクエストした場合、月次の粒度で返されます。  <br />  <br />指定可能な値: &#39;month&#39; または &#39;day&#39; |
| fromDate (YYYYMMDDHHMM) | 任意。利用状況データは 2018 年 5 月 1 日以降のみ利用できます。利用状況データが提供される最も古い UTC タイムスタンプを指定します。タイムスタンプは日単位の粒度で、境界値は「含まれます」（例: 201805010000 は 0501 の 1 日分を含みます）。時・分に &#39;0000&#39; 以外の値が含まれているリクエストは、自動的に &#39;0000&#39; に設定されます。  <br />  <br />fromDate または toDate を指定せずにリクエストした場合、その月の利用状況データが月次で返され、過去 2 か月分の履歴参照も含まれます。  <br />  <br />**注意:** 2019 年 6 月 1 日以降、直近 13 か月分のカレンダー月ベースの利用状況データにアクセスできます。たとえば、10 月 10 日時点であれば、前年の 9 月 1 日まで遡った利用状況データにアクセスできます。  <br />**例:** 201810010000 を指定すると、2018 年 10 月 1 日以降のデータが返され、10 月 1 日分も含まれます。 |
| toDate (YYYYMMDDHHMM) | 任意。利用状況データが提供される最新の UTC タイムスタンプを指定します。タイムスタンプは日単位の粒度で、境界値は「含まれません」（例: 201703020000 は 0302 の 1 日分のデータを含みません）。toDate に当日もしくは将来の日付を指定した場合、利用状況データは直近の「全日」分（UTC）まで返されます。時・分に &#39;0000&#39; 以外の値が含まれているリクエストは、自動的に &#39;0000&#39; に設定されます。  <br />  <br />toDate を指定しないリクエストでは、次の bucket 単位が既定値になります（bucket=day の場合は翌日、bucket=month の場合は翌月）。fromDate と toDate の両方を指定しないリクエストでは、既定で bucket=month となり、当月分に加えて直前 2 か月分のデータが返されます。  <br />  <br />**例:** 201703050000 を指定すると、2017 年 3 月 5 日までのデータが返されますが、3 月 5 日分のデータは含まれません。 |

**Example GET Request**

次のリクエストは、2017 年 3 月 1 日から 2017 年 3 月 5 日までの期間について、月次の粒度でデータを返します。ただし 2017 年 3 月 5 日分のデータは含まれません。

curl -u &quot;https://gnip-api.x.com/metrics/usage/accounts/:account&#95;name.json?bucket=month&amp;fromdate=201403010000&amp;toDate=201403150000&quot;

| **fromDate** | 取得したい利用状況データの最も古い UTC タイムスタンプ（境界を含む）。 |
| **toDate** | 取得したい利用状況データの最も新しい UTC タイムスタンプ（境界を含まない）。 |
| **publishers** | Used、projected、products の 3 つの主要なオブジェクトをインクルード。 |
