---
title: ツイートを編集する
keywords: ["edit tweets enterprise", "enterprise edit tweets", "edit posts enterprise", "tweet edits enterprise", "edit metadata enterprise"]
---

Enterprise エンドポイントが更新され、編集済み投稿のメタデータが提供されるようになりました。&#95;Edit Posts&#95; 機能は、2022 年 9 月 1 日に X 従業員向けのテストとして最初に導入されました。この日以降、対象となる投稿は 30 分間、最大 5 回まで編集可能になりました。*2022 年 9 月 29 日以降に作成された投稿のすべてのオブジェクト* には、投稿が一度も編集されていない場合でも、投稿の編集メタデータが含まれます。投稿が編集されるたびに、新しい Post ID が作成されます。投稿の編集履歴は、元の ID から始めて、これらの ID を連結することで表現できます。さらに、編集チェーン内のいずれかの投稿が削除されると、そのチェーン内のすべての投稿も削除されます。

これらのメタデータは自動的に含まれます。利用可能な編集履歴を Post オブジェクトの一部として含めるために、リクエストパラメータを指定する必要はありません。

これらの新しいメタデータにより、開発者は次のことを把握できます。

* 投稿が作成時点で編集対象かどうか。一部の投稿 (投票付き投稿や予約投稿など) は編集できません。
* 投稿は 30 分間編集可能で、最大 5 回まで編集できます。編集可能な投稿については、編集可能時間が残っているかどうか、残り何回編集できるかを確認できます。
* 編集済みバージョンの投稿を表示しているかどうか。多くの場合、特定の過去バージョンが Post ID でリクエストされない限り、API は投稿の最新バージョンを返します。

ルートレベルに 3 つの新しい Post 属性が追加されました。

* **edit&#95;history** - 投稿の編集履歴に関連付けられたすべての Post ID を提供します。&quot;initial&#95;tweet&#95;id&quot; 属性は元の投稿を示し、&quot;edit&#95;tweet&#95;ids&quot; 属性は、その編集履歴に関連付けられたすべての ID を提供する配列です。投稿が編集されていない場合、この配列には単一の ID が含まれます。

```
"edit_history": {
    "initial\_tweet\_id": "1283764123"
    "edit\_tweet\_ids": \["1283764123"\]
  }
```

* **edit&#95;controls** - 30 分間の編集ウィンドウがいつ終了するかと、残りの編集可能回数を示す属性です。

```
"edit_controls": {  
     "editable\_until\_ms": 1660155761384
     "edits_remaining": 3   
  }
```

* **editable** - 投稿が作成された時点で編集可能だったかどうかを示します。 

&quot;editable&quot;: true

ほとんどの投稿は編集可能です。ただし、次のタイプの投稿は対象外です: 

* プロモーション投稿
* 投票を含む投稿
* 自分のスレッド以外への返信投稿
* Retweet（Quote Tweet は編集対象になります）
* nullcast の投稿
* コミュニティ投稿
* Superfollow 投稿
* コラボレーション投稿（Collaborative Post）

**未編集の投稿の属性例**

以下の JSON は、投稿編集機能が追加された後に投稿された投稿に含まれる編集メタデータを示しています。この例は、編集履歴のない投稿のものです。 

`"edit_tweet_ids"` 配列には 1 つの ID のみが含まれる点に注意してください。

```
{
  "created_at": "Wed Aug 16 18:29:02 +0000 2022",
  "id": 1557433858676740098,
  "id_str": "1557433858676740098",
  "text": "I wonder if I will every use teh edit button",
  "edit_history": {
    "initial_tweet_id": "1557433858676740098",
    "edit_tweet_ids": ["1557433858676740098"]
  },
  "edit_controls": {
    "editable_until_ms": 1660155761384,
    "edits_remaining": 5
  },
  "editable": true
}
```

**編集された投稿の属性例**

以下の JSON は、投稿の編集機能が追加された後に作成された投稿に含まれる編集メタデータを示しています。この例は、1 回だけ編集された投稿のものです。 

`"edit_tweet_ids"` 配列には 2 つの ID があり、1 つは元の投稿、もう 1 つは編集後の更新版を表している点に注意してください。

```
{
  "created_at": "Wed Aug 16 18:35:42 +0000 2022",
  "id": 1557445923210514432,
  "id_str": "1557445923210514432",
  "text": "編集ボタンを使うことがあるのだろうか",
  "edit_history": {
    "initial_tweet_id": "1557433858676740098",
    "edit_tweet_ids": ["1557433858676740098", "1557445923210514432"]
  },
  "edit_controls": {
    "editable_until_ms": 1660155761384,
    "edits_remaining": 4
  },
  "editable": true
}
```

**コンプライアンスのサポート**

[Compliance Firehose](/ja/x-api/enterprise-gnip-2.0/fundamentals/firehouse) と v2 の [batch compliance endpoint](/ja/x-api/compliance/batch-compliance/introduction) の両方が、投稿の編集をサポートするように更新されました：

新しい &quot;tweet&#95;edit&quot; イベントタイプが Compliance Firehose に追加されました。

```
{
  "tweet_edit": {
    "id": <tweetId>,
    "initial_tweet_id": <tweetId>,
    "edit_tweet_ids": [<tweetId1>, <tweetId2>, <tweetId3> ...],
    "timestamp_ms": "<timestampMsStr>"
  }
}
```
