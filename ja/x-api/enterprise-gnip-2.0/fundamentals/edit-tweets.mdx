---
title: ツイートを編集する
keywords: ["edit tweets enterprise", "enterprise edit tweets", "edit posts enterprise", "tweet edits enterprise", "edit metadata enterprise"]
---

Enterprise 向けエンドポイントは、編集済み投稿のメタデータを提供するよう更新されています。&#95;Edit Posts&#95; 機能は、まず 2022 年 9 月 1 日に X 社員を対象としたテストとして導入されました。この日以降、対象となる投稿は 30 分間、最大 5 回まで編集可能でした。*2022 年 9 月 29 日以降に作成された投稿のすべてのオブジェクト* には、その投稿が一度も編集されていない場合でも、投稿編集メタデータが含まれています。投稿が編集されるたびに、新しい投稿 ID が作成されます。投稿の編集履歴は、最初の ID から始めて、これらの ID を連結することで表現できます。さらに、編集チェーン内のいずれかの投稿が削除されると、そのチェーン内のすべての投稿も削除されます。

これらのメタデータは自動的に含まれます。利用可能な編集履歴を投稿オブジェクトの一部として含めるために、リクエストパラメータを指定する必要はありません。

これらの新しいメタデータによって、開発者は次のことを把握できます。

* 作成時点で投稿が編集対象だったかどうか。一部の投稿（投票付きの投稿や予約投稿など）は編集できません。
* 投稿は 30 分間編集可能で、最大 5 回まで編集できます。編集可能な投稿については、編集可能な時間が残っているか、あと何回編集できるかを確認できます。
* 表示している投稿が編集済みバージョンかどうか。ほとんどの場合、API は特定の過去バージョンが投稿 ID で明示的に要求されない限り、最新バージョンの投稿を返します。

ルートレベルに 3 つの新しい投稿属性が追加されました。

* **edit&#95;history** - 投稿の編集履歴に関連付けられたすべての投稿 ID を提供します。`initial&#95;tweet&#95;id` 属性は元の投稿を示し、`edit&#95;tweet&#95;ids` 属性はその編集履歴に関連付けられたすべての ID を提供する配列です。投稿が編集されていない場合、この配列には単一の ID が含まれます。

```
"edit_history": {
    "initial\_tweet\_id": "1283764123"
    "edit\_tweet\_ids": \["1283764123"\]
  }
```

* **edit&#95;controls** - 30分間の編集ウィンドウがいつ終了するかと、残りの編集可能回数を示す属性を提供します。

```
"edit_controls": {  
     "editable\_until\_ms": 1660155761384
     "edits_remaining": 3   
  }
```

* **editable** - 投稿が作成時点で編集対象になっていたかどうかを示します。 

&quot;editable&quot;: true

ほとんどの投稿は編集可能です。ただし、次の種類の投稿は編集できません。 

* プロモーションされた投稿
* 投票付き投稿
* 自分のスレッド以外への返信投稿
* Retweet（引用ツイートは編集可能である点に注意してください）
* nullcast 投稿
* Community 投稿
* Superfollow 投稿
* Collaborative 投稿

**未編集投稿の属性例**

以下の JSON は、投稿編集機能が追加された後に投稿された投稿に含まれる編集メタデータを示しています。この例は、編集履歴のない投稿です。 

`"edit_tweet_ids"` 配列に ID が 1 つだけ含まれている点に注意してください。

```
{
  "created_at": "Wed Aug 16 18:29:02 +0000 2022",
  "id": 1557433858676740098,
  "id_str": "1557433858676740098",
  "text": "I wonder if I will every use teh edit button",
  "edit_history": {
    "initial_tweet_id": "1557433858676740098",
    "edit_tweet_ids": ["1557433858676740098"]
  },
  "edit_controls": {
    "editable_until_ms": 1660155761384,
    "edits_remaining": 5
  },
  "editable": true
}
```

**編集された投稿の属性例**

以下の JSON は、投稿編集機能の追加後に投稿された投稿に含まれる編集メタデータを示しています。この例は、1 回だけ編集された投稿のものです。

`"edit_tweet_ids"` 配列には 2 つの ID があり、1 つは元の投稿、もう 1 つは編集後の投稿を指している点に注意してください。

```
{
  "created_at": "Wed Aug 16 18:35:42 +0000 2022",
  "id": 1557445923210514432,
  "id_str": "1557445923210514432",
  "text": "I wonder if I will ever use the edit button",
  "edit_history": {
    "initial_tweet_id": "1557433858676740098",
    "edit_tweet_ids": ["1557433858676740098", "1557445923210514432"]
  },
  "edit_controls": {
    "editable_until_ms": 1660155761384,
    "edits_remaining": 4
  },
  "editable": true
}
```

**コンプライアンスサポート**

[Compliance Firehose](/ja/x-api/enterprise-gnip-2.0/fundamentals/firehouse) と v2 の [batch compliance endpoint](/ja/x-api/compliance/batch-compliance/introduction) が、投稿編集に対応するように更新されました。

Compliance Firehose に新しい &quot;tweet&#95;edit&quot; イベントタイプが追加されました。

```
{
  "tweet_edit": {
    "id": <tweetId>,
    "initial_tweet_id": <tweetId>,
    "edit_tweet_ids": [<tweetId1>, <tweetId2>, <tweetId3> ...],
    "timestamp_ms": "<timestampMsStr>"
  }
}
```
