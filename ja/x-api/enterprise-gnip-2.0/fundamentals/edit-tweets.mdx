keywords: ["ツイート編集 エンタープライズ", "エンタープライズ ツイート編集", "投稿編集 エンタープライズ", "ツイート編集履歴 エンタープライズ", "メタデータ編集 エンタープライズ"]
---

Enterprise エンドポイントは、編集済みの投稿のメタデータを提供するよう更新されました。&#95;Edit Posts&#95; 機能は、2022 年 9 月 1 日に X 従業員向けのテストとして初めて導入されました。この日以降、対象となる投稿は 30 分間、最大 5 回まで編集可能でした。*2022 年 9 月 29 日以降に作成された投稿に関するすべてのオブジェクト* には、その投稿が一度も編集されていない場合でも、投稿編集メタデータが含まれています。投稿が編集されるたびに、新しい Post ID が作成されます。1 つの投稿の編集履歴は、元の ID から始めて、これらの ID を連結することで表すことができます。さらに、編集チェーン内のいずれかの投稿が削除されると、そのチェーン内のすべての投稿も削除されます。

これらのメタデータは自動的に含まれます。利用可能な編集履歴を Post オブジェクトの一部として含めるために、リクエストパラメータを指定する必要はありません。

これらの新しいメタデータにより、開発者は次のことを確認できます。

* 投稿が作成時点で編集可能だったかどうか。一部の投稿（投票付き投稿や予約投稿など）は編集できません。
* 投稿は 30 分間編集可能で、最大 5 回まで編集できます。編集可能な投稿については、編集可能な時間が残っているか、残り何回編集できるかを確認できます。
* 表示している投稿が編集済みバージョンかどうか。ほとんどの場合、API は最新バージョンの投稿を返しますが、特定の過去バージョンが Post ID で指定されている場合はそのバージョンを返します。

ルートレベルに新しい Post 属性が 3 つ追加されました。

* **edit&#95;history** - 投稿の編集履歴に関連付けられているすべての Post ID を提供します。&quot;initial&#95;tweet&#95;id&quot; 属性は元の投稿を示し、&quot;edit&#95;tweet&#95;ids&quot; 属性は、その編集履歴に関連付けられているすべての ID を提供する配列です。投稿が編集されていない場合、この配列には 1 つの ID のみが含まれます。

```
"edit_history": {
    "initial\_tweet\_id": "1283764123"
    "edit\_tweet\_ids": \["1283764123"\]
  }
```

* **edit&#95;controls** - 30 分間の編集ウィンドウの終了時刻と、残りの編集可能回数を示す属性を提供します。

```
"edit_controls": {  
     "editable\_until\_ms": 1660155761384
     "edits_remaining": 3   
  }
```

* **editable** - 投稿が作成された時点で編集対象だったかどうかを示します。 

&quot;editable&quot;: true

ほとんどの投稿は編集可能です。ただし、次の種類の投稿は対象外です。 

* プロモーション投稿
* 投票を含む投稿
* 自分自身のスレッドではない返信
* リツイート（引用ツイートは編集対象である点に注意してください）
* nullcast 投稿
* コミュニティ投稿
* Super Follow 投稿
* コラボ投稿

**編集されていない投稿の属性例**

以下の JSON は、投稿の編集機能が追加された後に投稿された投稿に含まれる編集メタデータを示しています。この例は、編集履歴が存在しない投稿の場合です。 

`"edit_tweet_ids"` 配列には ID が 1 つだけ含まれています。

```
{
  "created_at": "Wed Aug 16 18:29:02 +0000 2022",
  "id": 1557433858676740098,
  "id_str": "1557433858676740098",
  "text": "I wonder if I will every use teh edit button",
  "edit_history": {
    "initial_tweet_id": "1557433858676740098",
    "edit_tweet_ids": ["1557433858676740098"]
  },
  "edit_controls": {
    "editable_until_ms": 1660155761384,
    "edits_remaining": 5
  },
  "editable": true
}
```

**編集された投稿の属性の例**

以下の JSON は、投稿編集機能が追加された後に作成された投稿に含まれる編集メタデータを示しています。この例は、1 回だけ編集された投稿のものです。 

`"edit_tweet_ids"` 配列には 2 つの ID があり、1 つは元の投稿、もう 1 つは編集後の更新を表している点に注意してください。

```
{
  "created_at": "Wed Aug 16 18:35:42 +0000 2022",
  "id": 1557445923210514432,
  "id_str": "1557445923210514432",
  "text": "編集ボタンを使うことがあるのだろうか",
  "edit_history": {
    "initial_tweet_id": "1557433858676740098",
    "edit_tweet_ids": ["1557433858676740098", "1557445923210514432"]
  },
  "edit_controls": {
    "editable_until_ms": 1660155761384,
    "edits_remaining": 4
  },
  "editable": true
}
```

**コンプライアンス対応**

[Compliance Firehose](/ja/x-api/enterprise-gnip-2.0/fundamentals/firehouse) と v2 の [batch compliance endpoint](/ja/x-api/compliance/batch-compliance/introduction) の両方が、投稿編集をサポートするように更新されました。 

新しい「tweet&#95;edit」イベントタイプが Compliance Firehose に追加されました。

```
{
  "tweet_edit": {
    "id": <tweetId>,
    "initial_tweet_id": <tweetId>,
    "edit_tweet_ids": [<tweetId1>, <tweetId2>, <tweetId3> ...],
    "timestamp_ms": "<timestampMsStr>"
  }
}
```
