## 概要

> enterprise コンソール（console.gnip.com）は、エンタープライズ API への契約済みアクセス権をお持ちのエンタープライズデータのお客様が利用できます。現在エンタープライズデータのお客様ではないものの、詳細情報をご希望の場合は、[enterprise data](https://developer.x.com/en/products/x-api/enterprise) についてこちらからご覧いただけます。

ここでは、X の enterprise コンソールダッシュボードの概要を説明します。ここで取り上げるセクションは、製品の詳細、利用状況、一般的なアカウント管理に関して、コンソール内のそれぞれの領域に対応しています。お客様固有のアカウントについてご不明な点がある場合は、担当のアカウントマネージャーまでお問い合わせいただくか、[エンタープライズ製品向けの技術ドキュメント](/ja/x-api/enterprise-gnip-2.0/enterprise-gnip)をご確認ください。

エンタープライズトライアルおよびオンボーディングプロセスの一環として、アカウントマネージャーとのやり取りの中で、エンタープライズのお客様には [console.gnip.com](http://console.gnip.com) へのログイン情報が提供されます。ここは、エンタープライズ製品へのアクセス状況を確認および設定できるユーザーインターフェースです。コンソールへの初回の管理者アクセスは、エンタープライズ向けオンボーディングプロセスの一部として X によって設定され、その後管理者は追加ユーザーを登録できます。enterprise コンソールを使用すると、エンタープライズ製品に関連する詳細を管理および参照できます。 

次の動画では、console.gnip.com ダッシュボードの各部分について概要を説明します。 

**免責事項: 動画内で紹介されている一部の機能（特定のストリームのエンリッチメントや X 以外のデータソース製品を含む）は、現在は提供されていない場合があります。**

<div id="products-tab">
  ## Products tab
</div>

[console.gnip.com](http://console.gnip.com) にアカウントにログインすると、ダッシュボードの Products タブが表示されます。 このページには、アカウントで現在利用可能なエンタープライズ製品の概要が表示されます。

PowerTrack や Decahose のようにストリーミング配信を利用する製品については、このページに、製品名、ストリームラベル、現在のアクティブな接続数、（該当する場合は）各ストリームで現在アクティブなルール数、そして直近 24 時間に配信されたアクティビティ（例: 投稿）の生の件数が一覧表示されます。

Search API のように REST 配信を利用する製品については、このページに、製品名、ラベル（「streams」としても表示されます）、これらのエンドポイントを通じて返された現在のアクティビティ（例: 投稿）、およびエンドポイントごとの複数の種類のリクエスト数が一覧表示されます。

[Usage API](/ja/x-api/enterprise-gnip-2.0/fundamentals/usage) は、これらのデータの多くをプログラムから取得できる形で提供します。

各ストリームごとの詳細は、ストリーム名または設定ボタンをクリックすると確認できます。

<div id="overview">
  ### 概要
</div>

メインダッシュボードでいずれかのストリームをクリックすると、そのストリームの概要ページが表示されます。

ストリーミング配信プロダクトの場合、このページには次の内容が含まれます。

1. 各ストリーム接続ごとに、自分宛てに配信されているアクティビティ数を示すボリュームチャート

2. ストリーム上で現在アクティブな接続に関する詳細情報（接続IDとIPアドレス）

3. ストリームに対する最近の接続、切断、ルール更新イベントのログ

チャートのスケールは、右上隅にあるリンクで調整できます。個々の接続と切断の表示／非表示は、チャート直下の凡例内にある該当するキーをクリックすることで切り替えられます。

<div id="connections">
  ### 接続
</div>

「Connections」ページでは、ストリーム上で最近発生した接続イベントの詳細を確認できます。これには、各接続の開始および終了時刻（UTC の 24 時間表記）、各接続の継続時間、接続を行ったサーバーの IP、参照用の一意の接続 ID、そして現在の接続ステータスが含まれます。ステータスは、指定された接続に対する最新のイベントに対応しており、たとえば Client Connected（クライアント接続）や切断イベントで、その際の切断タイプが示されます。接続に関するデバッグの詳細については、[Disconnections explained ガイド](/ja/x-api/enterprise-gnip-2.0/powertrack-api#integrating-with-powertrack)を参照してください。

<div id="rules">
  ### ルール
</div>

Rules タブは PowerTrack ストリームで利用でき、ユーザーインターフェースからプレーンテキストのルールを手動で入力することで、すばやく利用を開始できます。なお、このインターフェースで手動追加できるルールは最大 1000 個までであり、初期テストの目的にのみ使用してください。本番環境では、[Rules API](/ja/x-api/enterprise-gnip-2.0/powertrack-api#api-reference-index) を使用してルールをプログラムから管理することを推奨します。

<div id="settings">
  ### 設定
</div>

Settings タブでは、ストリーム内の data の出力フォーマットを切り替えることができます。複数のフォーマットオプションがサポートされています。フォーマットを切り替えるには、各オプションを示すラジオボタンを使用します。変更はストリームへの再接続時に有効になります。なお、この設定を更新すると、次回のリクエストまたは接続から即座に反映され、新しいフォーマットによって既存のパーサーが動作しなくなる可能性があります。 

**注意:** もっとも多くの data を取得するために推奨される設定は「Leave data in the original format」です。この設定では、data が[こちら](/ja/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#post-object)で説明されている拡張済みネイティブフォーマットで返されます。Activity Streams フォーマットについては[こちら](/ja/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#activity-object)で説明しています。

<div id="usage-tab">
  ## Usage タブ
</div>

「Usage」タブでは、さまざまな期間におけるストリームの利用状況を確認できます。利用状況情報にプログラムでアクセスするには、[Usage API](/ja/x-api/enterprise-gnip-2.0/fundamentals/usage) を参照してください。

<div id="monthly">
  ### 月次
</div>

月次使用量ページでは、ストリームの利用状況がプロダクト別に表示されます。たとえば、特定のデータソースに対するカバレッジ系プロダクト（PowerTrack、Historical PowerTrack、PowerTrack Replay など）は 1 つにグループ化され、個別の数値に加えて、統合されたロールアップ集計のカウントが提供されます。カウントには、当月の月初からの累計、当月のこれまでの利用状況と残り期間に基づく月末時点の推定値、そして直近 2 か月分のカウントが含まれます。

特に、これらのカウントはプロダクトおよびストリームごとに重複排除されています。同じ PowerTrack ストリームへの複数の接続を通じて同じ投稿を受信した場合でも、この集計ではその投稿は 1 回としてカウントされます。カウントは 24 時間ごとに協定世界時 (UTC) 00:00 に更新されます。

<div id="daily">
  ### 日次
</div>

Daily Usage ページでは、当月分について、日ごと・プロダクト別の重複排除済みカウントを表示します。カウントは 24 時間ごとに協定世界時 (UTC) の 00:00 に更新されます。

<div id="rules">
  ### ルール
</div>

ルール数の上限は、契約している PowerTrack ルールパッケージに基づいており、同一の「タイプ」に属するすべてのストリームに対して適用されます。件数は、新しいルールを追加または削除するたびに更新されます。

<div id="account-tab">
  ## 「アカウント」タブ
</div>

<div id="my-profile">
  ### 自分のプロフィール
</div>

自分のユーザープロフィールの詳細を表示したり、ここでパスワードを変更したりできます。さらに、このアカウント固有のアカウント使用量のしきい値に関する通知を設定できます。API ステータスに関する通知は、https://api.twitterstat.us のステータスページから確認できます。

<div id="account-settings">
  ### アカウント設定
</div>

ユーザーの追加、削除、編集を行い、各ユーザーおよび利用しきい値アラート向けのメール通知を設定できます。

<Frame>
  <img src="/images/account-settings.png.twimg.1920.png" />
</Frame>

ユーザーには 3 種類のタイプがあります。Account Admin、User、Email Only です。  

* Account Admin は、他のユーザーの作成・削除・編集が可能であり、エンタープライズ API に接続するために、ユーザー名（メールアドレス）とパスワードによるベーシック認証を使用できます。

* User は、他のユーザーを作成または変更することはできませんが、エンタープライズ API に接続するために、ユーザー名（メールアドレス）とパスワードによるベーシック認証を使用できます。

* Email Only ユーザーはダッシュボードにアクセスできず、エンタープライズ API への接続権限もありません。［通知］セクションで通知を受信するように設定されている場合にのみ、通知を受け取ります。

<div id="usage-thresholds">
  ### 使用量しきい値
</div>

プロダクトごとの使用量しきい値を設定します。これらは、各プロダクトの警告しきい値および重大しきい値について、プロフィールで該当の通知を設定しているユーザーに対してメールアラートを送信するトリガーになります。

<Frame>
  <img src="/images/usage-thresholds.png.twimg.1920.png" />
</Frame>

これらのしきい値は 1 日に 1 回、19:30（UTC）にのみ評価され、リアルタイムで評価されるわけではない点に注意してください。
