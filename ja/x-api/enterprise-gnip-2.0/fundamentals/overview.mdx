## 概要

> enterprise console（console.gnip.com）は、契約済みの enterprise API アクセスを持つエンタープライズデータ顧客向けに提供されています。現在エンタープライズデータ顧客ではないものの、詳細を知りたい場合は、[enterprise data](https://developer.x.com/en/products/x-api/enterprise) についてこちらからご確認いただけます。

これは X の enterprise console ダッシュボードの概要です。本書で説明する各セクションでは、コンソール内のそれぞれの領域について、製品の詳細、利用状況、一般的なアカウント管理を取り上げます。ご利用中の特定アカウントに関するご質問がある場合は、担当のアカウントマネージャーにお問い合わせいただくか、[エンタープライズ製品向けの技術ドキュメント](/ja/x-api/enterprise-gnip-2.0/enterprise-gnip)をご覧ください。

エンタープライズトライアルおよびオンボーディングプロセスの一環として、アカウントマネージャーを通じて、エンタープライズ顧客には [console.gnip.com](http://console.gnip.com) へのログイン情報が提供されます。ここは、エンタープライズ製品へのアクセス状況を確認・設定できるユーザーインターフェースです。コンソールへの初回アクセスは、エンタープライズオンボーディングプロセスの一部として X によって管理者（customer admin）向けに設定され、その後管理者は追加ユーザーを招待できます。enterprise console を使用することで、エンタープライズ製品に関する詳細な設定や情報を管理・確認できます。 

次の動画では、console.gnip.com ダッシュボードのさまざまな部分について概要を説明します。 

**免責事項: この動画に示されている機能の一部（特定のストリームエンリッチメントや非 X データソース製品など）は、現在は利用できない場合があります。**

<div id="products-tab">
  ## Products タブ
</div>

[console.gnip.com](http://console.gnip.com) にログインすると、ダッシュボードの Products タブが表示されます。 このページには、アカウントで現在利用可能なエンタープライズ製品の概要が表示されます。

PowerTrack や Decahose のようなストリーミング配信を利用する製品については、このページに製品名とストリームラベル、現在のアクティブ接続数、（該当する場合は）各ストリームで現在アクティブなルール数、および直近 24 時間に配信されたアクティビティ（例: 投稿）の総件数が表示されます。

Search API のような REST 配信の製品については、このページに製品名、ラベル（&quot;streams&quot; としても表示されます）、これらのエンドポイントを通じて返されたアクティビティ（例: 投稿）の件数、およびエンドポイントごとの複数種類のリクエスト数が表示されます。

[Usage API](/ja/x-api/enterprise-gnip-2.0/fundamentals/usage) を使用すると、これらのデータの多くをプログラムから取得できます。

各ストリームの詳細は、名前または設定ボタンをクリックすると確認できます。

<div id="overview">
  ### 概要
</div>

メインダッシュボードでいずれかのストリームをクリックすると、そのストリームの概要ページが表示されます。

ストリーミング配信プロダクトでは、このページに次の内容が含まれます。

1. 各ストリーム接続ごとに配信されているアクティビティ数のボリュームチャート

2. ストリーム上で現在アクティブな接続の詳細（接続 ID と IP アドレス）

3. ストリームにおける最近の接続、切断、およびルール更新イベントのログ

チャートのスケールは、右上隅のリンクで調整できます。個々の接続および切断の表示・非表示は、チャート直下の凡例にある該当項目をクリックして切り替えることができます。

<div id="connections">
  ### Connections
</div>

[Connections] ページでは、ストリームで最近発生した接続イベントの詳細を確認できます。ここには、各接続の開始時刻および終了時刻（UTC の 24 時間表記）、各接続の継続時間、接続を行ったサーバーの IP アドレス、参照用の一意の接続 ID、そして現在の接続ステータスが含まれます。ステータスは、指定した接続に対して発生した最新のイベントに対応しており、「Client Connected（クライアント接続）」、または切断イベント（切断タイプを含む）のいずれかを表します。接続のトラブルシューティングに関する詳細は、[disconnections explained ガイド](/ja/x-api/enterprise-gnip-2.0/powertrack-api#integrating-with-powertrack) を参照してください。

<div id="rules">
  ### ルール
</div>

「Rules」タブは PowerTrack ストリームで利用でき、ユーザーインターフェース上からプレーンテキストのルールを手動で入力して、すばやく利用を開始するための手段を提供します。なお、このインターフェースで手動追加できるルールは最大 1000 件までであり、初期テストの用途にのみ使用することを想定しています。本番環境などの運用では、[Rules API](/ja/x-api/enterprise-gnip-2.0/powertrack-api#api-reference-index) を通じてプログラムからルールを管理することを推奨します。

<div id="settings">
  ### 設定
</div>

Settings タブでは、ストリーム内の data の出力形式を切り替えることができ、複数の形式オプションがサポートされています。形式を切り替えるには、各オプションを示すラジオボタンを選択します。変更は、ストリームへ再接続した際に有効になります。なお、この設定の更新は次回のリクエストまたは接続時に即座に反映され、新しい形式によってはパーサーが正しく動作しなくなる可能性があります。

**注意:** 可能な限り多くの data を取得するための推奨設定は「Leave data in the original format」です。この設定では、[こちら](/ja/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#post-object) で説明されている拡張されたネイティブ形式の data が返されます。Activity Streams 形式については [こちら](/ja/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#activity-object) で説明されています。

<div id="usage-tab">
  ## Usage タブ
</div>

Usage タブでは、さまざまな期間にわたるストリームの利用状況を確認できます。利用状況データにプログラムからアクセスするには、[Usage API](/ja/x-api/enterprise-gnip-2.0/fundamentals/usage) を参照してください。

<div id="monthly">
  ### 月次
</div>

「Monthly Usage」ページには、プロダクト別に集計されたストリーム利用状況が表示されます。たとえば、特定のデータソースに対するカバレッジ系プロダクト（PowerTrack、Historical PowerTrack、PowerTrack Replay など）はグループ化され、個別のデータに加えて、ロールアップした合算カウントも提供されます。カウントには、当月これまでの累計、推定月末値（今月これまでの利用状況と月末までの残り時間に基づく）、および直近 2 か月分のカウントが含まれます。

重要な点として、これらのカウントはプロダクトおよびストリームごとに重複排除されています。同じ PowerTrack ストリームへの複数の接続を通じて同一の投稿を受信した場合でも、この集計ではその投稿は 1 回としてのみカウントされます。カウントは 24 時間ごとに、UTC 00:00 に更新されます。

<div id="daily">
  ### 日次
</div>

Daily Usage ページでは、当月における各日について、プロダクト別に集計された一日ごとの重複排除済みカウントを確認できます。カウントは 24 時間ごとに UTC 午前 0 時に更新されます。

<div id="rules">
  ### ルール
</div>

ルール数の上限は、契約している PowerTrack ルールパッケージに基づき、特定の「タイプ」に属するすべてのストリームを対象として適用されます。ルール数は、新しいルールが追加または削除されるたびに更新されます。

<div id="account-tab">
  ## 「アカウント」タブ
</div>

<div id="my-profile">
  ### プロフィール
</div>

ご自身のユーザープロフィールの詳細を確認し、ここでパスワードを変更できます。また、アカウントごとの使用量しきい値に関する通知を設定できます。API のステータスに関する通知は、https://api.twitterstat.us のステータスページで確認できます。

<div id="account-settings">
  ### アカウント設定
</div>

ユーザーの追加・削除・編集を行い、各ユーザー向けのメール通知および利用閾値アラートを設定できます。

<Frame>
  <img src="/images/account-settings.png.twimg.1920.png" />
</Frame>

ユーザーには 3 種類のタイプがあります。Account Admin、User、Email Only です。  

* Account Admin は、他のユーザーの作成・削除・編集が可能で、エンタープライズ API に接続するために、ユーザー名（メールアドレス）とパスワードを用いたベーシック認証を使用できます

* User は、他のユーザーを作成または変更することはできませんが、エンタープライズ API に接続するために、ユーザー名（メールアドレス）とパスワードを用いたベーシック認証を使用できます

* Email Only ユーザーはダッシュボードへのアクセス権がなく、エンタープライズ API への接続は許可されておらず、通知セクションで受信するように設定されている場合にのみ通知を受け取ります。

<div id="usage-thresholds">
  ### 使用量のしきい値
</div>

プロダクトごとの利用量のしきい値を設定します。ここで設定したしきい値に達すると、各プロダクトの警告しきい値および重大しきい値について、プロフィールで該当する通知を有効にしているユーザーにメールアラートが送信されます。

<Frame>
  <img src="/images/usage-thresholds.png.twimg.1920.png" />
</Frame>

これらのしきい値は 1 日に 1 回、19:30（UTC）に評価されます。リアルタイムでは評価されない点に注意してください。
