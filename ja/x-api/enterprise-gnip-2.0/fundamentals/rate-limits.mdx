<div id="overview">
  ## 概要
</div>

毎日、何万という開発者が X API にリクエストを送信しています。こうした膨大な数のリクエストを管理するために、送信できるリクエスト数には制限が設けられています。これらの制限によって、開発者コミュニティが依存している信頼性が高くスケーラブルな API を提供することが可能になります。 

許可されるリクエストの最大数は、特定の期間、いわゆる時間ウィンドウに基づいて決まります。たとえば、あるエンドポイントに 900 リクエスト/15 分というレート制限がある場合、任意の 15 分間のウィンドウ内で最大 900 件のリクエストが許可されます。
