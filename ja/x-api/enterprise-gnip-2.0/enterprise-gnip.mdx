エンタープライズ API は、X のデータに依存する方々に対して、最高レベルのアクセス性と信頼性を提供します。Premium を超えてスケールし、より高い信頼性を備えたアクセスやカスタマイズされたパッケージ、長期契約が必要になった場合に最適です。Enterprise API へのアクセスには、専任のアカウントマネージャーとパーソナライズされた技術サポートが付帯します。

Basic や Pro のソリューションではニーズを十分に満たせないと判断した場合は、次のリンクからエンタープライズ製品へのアクセスを申請できます。

<Button href="https://developer.x.com/en/products/twitter-api/enterprise/enterprise-api-interest-form">
  アクセスを申請する
</Button>

<div id="available-endpoints">
  ## 利用可能なエンドポイント
</div>

| リアルタイム | [PowerTrack API](/ja/x-api/enterprise-gnip-2.0/powertrack-api) | さまざまなオペレーターやルールを使ってフィルタリング可能な、公開投稿の完全なリアルタイムカバレッジを提供します。 |
| :--- | :--- | :--- |
| [Decahose API](/ja/x-api/enterprise-gnip-2.0/fundamentals/decahose-api) | すべての公開投稿およびそれらへのいいねのうち、10% をランダムサンプルとしてストリーミングします。 |
| :--- | :--- | :--- |
| [Account Activity API](/ja/x-api/enterprise-gnip-2.0/fundamentals/account-activity) | ユーザーを購読し、投稿、ダイレクトメッセージ、いいね、フォローなど、さまざまなアクティビティを受信します。 |
| :--- | :--- | :--- |
| 履歴 | [Search API](/ja/x-api/enterprise-gnip-2.0/fundamentals/search-api) | 高度なフィルタリングツールを使用して、直近 30 日分または公開投稿の全アーカイブを検索します。 |
| [Historical PowerTrack API](/ja/x-api/enterprise-gnip-2.0/powertrack-api) | コスト効率の高いバッチアクセス手法を使用して、公開投稿の全アーカイブをフィルタリングします。 |
| インサイト | [Engagement API](/ja/x-api/enterprise-gnip-2.0/fundamentals/engagement-api) | 公開投稿のインプレッション数とエンゲージメント数を測定します。 |
| コンプライアンス | [Compliance Firehose API](/ja/x-api/enterprise-gnip-2.0/fundamentals/firehouse) | すべてのコンプライアンスイベントをストリーミングします。 |
| 利用状況 | [Usage API](/ja/x-api/enterprise-gnip-2.0/fundamentals/usage) | エンタープライズ製品全体のアクティビティ利用状況へのプログラムによるアクセスを提供します。 |

<div id="important-concepts">
  ## 重要な概念
</div>

<div id="gnip-console">
  ### Gnip Console
</div>

[Gnip Console](/ja/x-api/enterprise-gnip-2.0/fundamentals/overview) を使用して、エンタープライズ製品やアカウントへのアクセスを管理できます。 

<div id="enrichments">
  ### エンリッチメント
</div>

有料プランをご利用の開発者向けに、プレミアム API のレスポンスペイロードにメタデータを追加しました。展開済みURL、投票データ、プロフィールの位置情報については、[エンリッチメントのセクション](/ja/x-api/enterprise-gnip-2.0/fundamentals/data-enrichments)を参照してください。
 

<div id="advanced-filtering-tools">
  ### 高度なフィルタリングツール
</div>

Premium Search API では、標準の検索エンドポイントでは利用できない高度な演算子セットを利用できます。これらの演算子の多くは無料のサンドボックスユーザーでも利用できますが、有料プランを利用すると、さらに充実した演算子セットにアクセスできます。詳しくは、[「ルールとフィルター」のセクション](/ja/x-api/enterprise-gnip-2.0/fundamentals/rules-filtering#getting-started-with-enterprise-rules-and-queries)をご覧ください。

<div id="explore-x-api-v2">
  ## X API v2 を探索する
</div>

v2 で現在利用できる機能を確認したい場合は、新機能についてはドキュメントを参照し、将来的に X API v2 へ移行する際に役立つリソースについてはマイグレーションハブをご覧ください。新しい v2 エンドポイントセクションに記載されている各エンドポイントのマイグレーションガイドにもアクセスできます。

[詳しく見る](/ja/x-api/migrate/overview)
