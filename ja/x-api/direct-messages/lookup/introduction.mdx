Direct Messages のルックアップエンドポイントでは、認証ユーザーの DM イベントを取得できます。1 対 1 の会話とグループ会話の両方のメッセージが含まれます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="すべてのDMイベント" icon="messages">
    ユーザーのDMイベントをすべて取得します
  </Card>

  <Card title="1対1" icon="message">
    特定の会話のイベントを取得します
  </Card>

  <Card title="会話IDで取得" icon="comments">
    会話IDでイベントを取得します
  </Card>

  <Card title="イベントの種類" icon="bell">
    メッセージ、参加、退出
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/dm_events`](/ja/x-api/direct-messages/get-dm-events) | ユーザーのDMイベントをすべて取得 |
| GET | [`/2/dm_conversations/with/:participant_id/dm_events`](/ja/x-api/direct-messages/get-dm-events-for-a-dm-conversation) | 一対一のDM会話からイベントを取得 |
| GET | [`/2/dm_conversations/:dm_conversation_id/dm_events`](/ja/x-api/direct-messages/get-dm-events-for-a-dm-conversation-1) | DM会話IDを指定してイベントを取得 |

***

<div id="event-types">
  ## イベントタイプ
</div>

| Event | Description |
|:------|:------------|
| `MessageCreate` | 会話でメッセージが送信されたとき |
| `ParticipantsJoin` | ユーザーが会話に参加したとき |
| `ParticipantsLeave` | ユーザーが会話から退出したとき |

***

<div id="data-retention">
  ## データ保持期間
</div>

<Note>
  これらのエンドポイントからは、**過去30日分**のイベントを取得できます。
</Note>
