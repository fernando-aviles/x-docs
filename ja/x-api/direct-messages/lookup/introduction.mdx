Direct Messages のルックアップエンドポイントを使用すると、認証済みユーザーの DM イベントを取得できます。一対一およびグループの会話の両方におけるメッセージが対象です。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="すべてのDMイベント" icon="messages">
    ユーザーのすべてのDMイベントを取得します
  </Card>

  <Card title="1対1" icon="message">
    特定のDM会話のイベントを取得します
  </Card>

  <Card title="会話ID指定" icon="comments">
    会話IDでイベントを取得します
  </Card>

  <Card title="イベントタイプ" icon="bell">
    メッセージ、参加、退出
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/dm_events`](/ja/x-api/direct-messages/get-dm-events) | ユーザーのすべてのDMイベントを取得 |
| GET | [`/2/dm_conversations/with/:participant_id/dm_events`](/ja/x-api/direct-messages/get-dm-events-for-a-dm-conversation) | 一対一の会話のイベントを取得 |
| GET | [`/2/dm_conversations/:dm_conversation_id/dm_events`](/ja/x-api/direct-messages/get-dm-events-for-a-dm-conversation-1) | 会話IDを指定してイベントを取得 |

***

<div id="event-types">
  ## イベントタイプ
</div>

| Event | Description |
|:------|:------------|
| `MessageCreate` | 会話でメッセージが送信されたとき |
| `ParticipantsJoin` | 会話にユーザーが参加したとき |
| `ParticipantsLeave` | 会話からユーザーが退出したとき |

***

<div id="data-retention">
  ## データ保持期間
</div>

<Note>
  過去**30日分**のイベントを、これらのエンドポイントから取得できます。
</Note>
