DMブロック管理エンドポイントを使用すると、認証済みユーザーに代わって指定したアカウントをブロックまたはブロック解除できます。これらのエンドポイントには、2つの POST メソッドが用意されています。

* **/2/users/:id/dm/block**: アカウントをブロックできます
* **/2/users/:id/dm/unblock**: アカウントのブロックを解除できます

<div id="authentication">
  ### 認証
</div>

ユーザーの代わりにリクエストを送信する場合、これらのエンドポイントには [OAuth 1.0a ユーザーコンテキスト](/ja/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) または [OAuth 2.0 Authorization Code with PKCE](/ja/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) のいずれかを用いて認証を行い、リクエストを代行するユーザーに紐づくユーザー Access Token を利用する必要があります。ユーザー Access Token は、[3-legged OAuth flow](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens)（OAuth 1.0a）または [Authorization Code with PKCE grant flow](/ja/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)（OAuth 2.0）を使用して生成できます。

<div id="making-a-request">
  ### リクエストの送信
</div>

Block

ユーザーがあなたのアプリでの認証を済ませたら、以下のようにユーザーに代わって Block エンドポイントを呼び出せます。

```
      curl --request POST 'https://api.x.com/2/users/:id/dm/block' --header 'Authorization: ••••••'
```

リクエストが成功すると、以下のような JSON レスポンスが表示されます。

```
{
   "data": {
       "blocked": true
   }
}
```

**ブロック解除**

ユーザーの認証があなたのアプリで完了したら、以下のようにそのユーザーに代わって Unblock エンドポイントを呼び出すことができます。

```
      curl --request POST 'https://api.x.com/2/users/:id/dm/unblock' --header 'Authorization: ••••••'
```

リクエストが成功した場合、次のような JSON レスポンスが表示されます。

```
{
   "data": {
       "blocked": false
   }
}
```
