Manage Direct Messages エンドポイントでは、認証済みユーザーに代わってダイレクトメッセージを送信および削除できます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="メッセージを送信" icon="paper-plane">
    他のユーザーにDMを送信する
  </Card>

  <Card title="メッセージを削除" icon="trash">
    自分のDMを削除する
  </Card>

  <Card title="会話を作成" icon="comments">
    新しい会話を開始する
  </Card>

  <Card title="グループメッセージ" icon="users">
    グループ会話にメッセージを送信する
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| POST | `/2/dm_conversations` | 新しいDM会話を作成する |
| POST | `/2/dm_conversations/with/:participant_id/messages` | 1対1のDM会話にメッセージを送信する |
| POST | `/2/dm_conversations/:dm_conversation_id/messages` | 既存のDM会話にメッセージを送信する |
| DELETE | `/2/dm_events/:id` | DMイベントを削除する |

***

<div id="example-send-a-message">
  ## 例：メッセージの送信
</div>

```bash
curl -X POST "https://api.x.com/2/dm_conversations/with/1234567890/messages" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello! How are you?"}'
```

<div id="example-response">
  ## レスポンス例
</div>

```json
{
  "data": {
    "dm_conversation_id": "1234567890-0987654321",
    "dm_event_id": "1122334455667788990"
  }
}
```

***

<div id="message-types">
  ## メッセージの種類
</div>

テキストメッセージを送信し、メディアを添付できます。

```json
{
  "text": "Check out this photo!",
  "attachments": [{
    "media_id": "1234567890123456789"
  }]
}
```
