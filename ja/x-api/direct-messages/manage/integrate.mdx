このガイドでは、アプリケーションに Direct Messages の管理エンドポイントを統合するために必要な主要な概念について説明します。

***

<div id="authentication">
  ## 認証
</div>

DM エンドポイントを利用するにはユーザー認証が必要です。

| Method | 説明 |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/ja/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | 推奨 |
| [OAuth 1.0a User Context](/ja/resources/fundamentals/authentication) | レガシーサポート |

<Warning>
  App-Only 認証には対応していません。ダイレクトメッセージはすべて非公開です。
</Warning>

<div id="required-scopes-oauth-20">
  ### 必須スコープ (OAuth 2.0)
</div>

| スコープ | 必須となる用途 |
|:------|:-------------|
| `dm.write` | メッセージの送信と削除 |
| `dm.read` | `dm.write` を利用する場合に必須 |
| `tweet.read` | DM 関連スコープと併せて必須 |
| `users.read` | DM 関連スコープと併せて必須 |

***

<div id="endpoints-overview">
  ## エンドポイント一覧
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| POST | `/2/dm_conversations/with/:participant_id/messages` | 1対1のメッセージを送信 |
| POST | `/2/dm_conversations` | グループ会話を作成 |
| POST | `/2/dm_conversations/:dm_conversation_id/messages` | 会話にメッセージを追加 |
| DELETE | `/2/dm_events/:event_id` | メッセージを削除 |

<div id="sending-messages">
  ## メッセージの送信
</div>

<div id="one-to-one-message">
  ### 1対1メッセージ
</div>

特定のユーザーにメッセージを送信します。既存の会話がない場合は、新しい会話が作成されます：

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/dm_conversations/with/9876543210/messages" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"text": "Hello!"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 1対1のDMを送信
  response = client.dm_conversations.create_message(
      participant_id="9876543210",
      text="Hello!"
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 1対1のDMを送信
  const response = await client.dmConversations.createMessage({
    participantId: "9876543210",
    text: "Hello!",
  });
  console.log(response.data);
  ```
</CodeGroup>

<div id="group-conversation">
  ### グループ会話
</div>

新しいグループ会話を作成し、最初のメッセージを送信します:

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/dm_conversations" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "conversation_type": "Group",
      "participant_ids": ["944480690", "906948460078698496"],
      "message": {"text": "Welcome to our group!"}
    }'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # グループ会話を作成します
  response = client.dm_conversations.create(
      conversation_type="Group",
      participant_ids=["944480690", "906948460078698496"],
      message={"text": "Welcome to our group!"}
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // グループ会話を作成します
  const response = await client.dmConversations.create({
    conversationType: "Group",
    participantIds: ["944480690", "906948460078698496"],
    message: { text: "Welcome to our group!" },
  });
  console.log(response.data);
  ```
</CodeGroup>

<Note>
  `conversation_type` フィールドは `"Group"` に設定する必要があります（大文字・小文字を区別します）。
</Note>

<div id="add-to-existing-conversation">
  ### 既存の会話に追加
</div>

参加している任意の会話にメッセージを送信します：

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/dm_conversations/1582103724607971328/messages" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"text": "Another message"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 既存の会話にメッセージを追加
  response = client.dm_conversations.add_message(
      dm_conversation_id="1582103724607971328",
      text="Another message"
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 既存の会話にメッセージを追加
  const response = await client.dmConversations.addMessage({
    dmConversationId: "1582103724607971328",
    text: "Another message",
  });
  console.log(response.data);
  ```
</CodeGroup>

<div id="media-attachments">
  ## メディアの添付
</div>

各メッセージには 1 つのメディア（写真、動画、または GIF）のみを添付できます。

<Steps>
  <Step title="メディアをアップロードする">
    [Media Upload endpoint](/ja/x-api/media/quickstart/media-upload-chunked) を使用してファイルをアップロードし、`media_id` を取得します。
  </Step>

  <Step title="メッセージに含める">
    ```json
    {
      "text": "Check out this image!",
      "attachments": [{"media_id": "1583157113245011970"}]
    }
    ```
  </Step>
</Steps>

<Note>
  * 認証済みユーザー自身がそのメディアをアップロードしている必要があります
  * メディアはアップロード後 24 時間利用可能です
  * メッセージごとに添付できるメディアは 1 件のみです
</Note>

***

<div id="sharing-posts">
  ## 投稿を共有する
</div>

メッセージ本文に投稿を含めるには、その投稿のURLを本文に追加します。

```json
{
  "text": "これを見ましたか？ https://x.com/XDevelopers/status/1580559079470145536"
}
```

レスポンスには、投稿ID が格納された `referenced_tweets` フィールドが含まれます。

***

<div id="message-requirements">
  ## メッセージ要件
</div>

| 項目 | 必須 | 備考 |
|:------|:---------|:------|
| `text` | はい* | `attachments` がない場合は必須 |
| `attachments` | はい* | `text` がない場合は必須 |

*`text` と `attachments` の少なくともどちらか一方は指定する必要があります。

***

<div id="id-compatibility-with-v11">
  ## v1.1 との ID 互換性
</div>

会話 ID とイベント ID は、v1.1 と v2 のエンドポイント間で共有されています。これにより、ハイブリッドなワークフローが可能になります。

* v2 でメッセージを作成する
* v1.1 でメッセージを削除する（v2 ではまだサポートされていません）
* x.com の URL から会話 ID を参照する

***

<div id="error-handling">
  ## エラー処理
</div>

| ステータス | エラー | 解決方法 |
|:-------|:------|:---------|
| 400 | 無効なリクエスト | リクエストボディの形式を確認してください |
| 401 | 認証されていません | アクセストークンを確認してください |
| 403 | アクセスが拒否されました | スコープとユーザー権限を確認してください |
| 429 | リクエストが多すぎます | 待機してから再試行してください |

<div id="common-issues">
  ### よくある問題
</div>

<AccordionGroup>
  <Accordion title="ユーザーに送信できない">
    受信者が、知らないユーザーからのメッセージを受信しないDM設定にしているか、あなたをブロックしている可能性があります。
  </Accordion>

  <Accordion title="メディアを添付できない">
    メディアが同じ認証済みユーザーによってアップロードされており、アップロードから24時間以内であることを確認してください。
  </Accordion>

  <Accordion title="グループを作成できない">
    すべての参加者のIDが有効であり、各ユーザーがグループDMへの招待を許可していることを確認してください。
  </Accordion>
</AccordionGroup>
