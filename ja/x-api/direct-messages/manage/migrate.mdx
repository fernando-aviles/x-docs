  ## v1.1 と v2 の Direct Message 管理エンドポイントの比較
</div>

Direct Message エンドポイントの v1.1 と v2 の両バージョンには、ダイレクトメッセージを作成するためのメソッドがあります。本ガイドは、両者の違いを理解し、v2 への移行に役立つ情報を提供することを目的としています。 

両バージョン間の大きな違いは、v1.1 では 1 対 1 の会話のみをサポートするのに対し、v2 ではグループ会話のサポートが追加された点です。この結果として、v1.1 では「message created」イベントのみをサポートしますが、v2 では会話への参加者の参加・離脱に関連するイベントもサポートします。実際、v2 の根本的な更新点の 1 つは、dm&#95;conversations をコアな API オブジェクトとして確立したことです。   

v1.1 では、Direct Message を管理するためのエンドポイントが 2 つあります:

* POST direct&#95;messages/events/new - 1 対 1 の Direct Message を作成します。この v1.1 エンドポイントは 1 対 1 のメッセージのみを作成でき、グループメッセージはサポートしません。  

* DELETE direct&#95;messages/events/destroy - 認証ユーザーのビューから 1 対 1 のメッセージを削除します。 

今回の v2 リリースでは、Direct Message を作成するための POST メソッドが 3 つあります: 

* **POST /2/dm&#95;conversations/with/:participant&#95;id/messages** - 1 対 1 の Direct Message を作成します。このメソッドは、既存の 1 対 1 会話にメッセージを追加するか、新しい会話を作成します。:participant&#95;id パスパラメータは、メッセージを受信するアカウントのユーザー ID です。 

* **POST /2/dm&#95;conversations** - 新しいグループ会話を作成し、その会話に Direct Message を追加します。これらのリクエストには、会話参加者のリストが必要です。同じ参加者リストで複数の会話を作成できる点に注意してください。これらのリクエストは常に新しい会話 ID を返します。 

* **POST /2/dm&#95;conversations/:dm&#95;conversation&#95;id/messages** - Direct Message を作成し、既存の会話に追加します。:dm&#95;conversation&#95;id パスパラメータは、メッセージを追加する対象の会話の ID です。 

重要なポイントとして、会話 ID とイベント ID は、X Platform の v1.1 と v2 の両バージョン間で共有されます。これは、両バージョンを併用できることを意味します。たとえば、Direct Messages v1.1 エンドポイントには、単一のイベントを返すメソッドやイベントを削除するメソッドがあり、これらは v2 ではまだ利用できません。ID は v1.1 と v2 で共通のため、v2 から提供された ID に基づいて v1.1 リクエストを行ったり、X アプリケーション上の会話 URL に表示されている会話 ID を参照してリクエストすることができます。
