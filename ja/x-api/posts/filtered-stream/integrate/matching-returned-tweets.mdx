<div id="matching-returned-posts-to-their-associated-rule">
  ### 返される投稿を対応するルールにひも付ける
</div>

filtered stream エンドポイントでは、1 つの接続で複数のルールを設定できます。ストリームで投稿を受信し始める前に、どの種類の投稿に関心があるかを指定するルールを作成する必要があります。 

ユーザー属性、位置情報、言語など、さまざまな属性に基づいて投稿にマッチさせるルールを指定する際、そのルールを上位レベルで区別するためにタグを付与できます。タグは、特に多数のルールを設定している場合に、ルールに文脈を与えるのに有効な方法です。フィルタリングルールは、どの投稿アクティビティが接続を通じて送信されるかを決定します。

別の種類の投稿を取得するために新しいフィルタリングルールを追加する必要がある場合や、既存のルールを削除する必要がある場合は、App から [POST tweets/search/stream/rules](/ja/x-api/posts/filtered-stream#post-2-tweets-search-stream-rules) エンドポイントにリクエストを送信することで実行できます。このリクエストが送信されると、フィルタリングルールは自動的に更新され、再接続することなく、その変更がデータストリームにそのまま反映されます。多くの場合、ルールの追加はおおむね 20 秒以内に有効になります。可能性は低いものの、外部要因（たとえばネットワーク接続状況）によっては、マッチする投稿を受信し始めるまでにさらに時間がかかる場合があります。list rule エンドポイントでルールが見つからない場合は、ルール作成リクエストが成功しているかを確認してください。これは、ログを確認してエラーメッセージがないかを調べることで行えます。

<div id="matching-rules">
  #### 一致したルール
</div>

フィルタ済みストリーム接続を通じてアクティビティが配信されるとき、`matching_rules` 配列には、その配信されたポストに対してどのフィルターが一致したかを示すリストが含まれます。

ポストのペイロードには、特定のポストが配信される原因となったルールの `id` とタグを含む、追加の文字列メタデータがあります。複数のルールが 1 つのポストに一致した場合でも、アクティビティは 1 回だけ配信され、そのメタデータ内に一致した各ルールが含まれます。一致したルールは、特定のポストを特定のルールと関連付ける簡単な方法を提供し、多数の異なるルールを持っている場合に特に役立ちます。このようにデータが単一のストリームを通じて配信されるため、一意の `id` とタグを持つことがマッチングのために不可欠です。 

**以下は、ポストのペイロード内で `matching_rules` 配列がどのような形で現れるかの例です。**

```"matching_rules": [
    {
      "id": "1166916266197536768",
      "tag": "test-rule-tag-00000"
    },
    {
      "id": "1166916266197536769",
      "tag": "test-rule-tag-12345"
    }
  ]
```

<div id="rule-tags">
  #### ルールタグ
</div>

フィルタリングルールは作成時に、ルールごとにタグを付けて作成できます。ルールタグ自体には特別な意味はなく、ルールに付随して保持される不透明な文字列として扱われます。タグは返されるアクティビティ内の `matching_rules` メタデータに含まれ、上位レベルでルールを区別しやすくすることを目的としています。 

タグは、フィルタリングルールを論理的なグループにまとめる簡便な方法を提供します。たとえば、特定のルールに対して一意の ID を生成してそれをタグとして付与し、App が処理するアクティビティ内でその ID を参照することで、結果を特定の顧客、キャンペーン、カテゴリ、その他の関連グループに関連付けることができます。

タグは既存のルールに対して更新できず、ルール作成時にのみ指定できる点に注意してください。タグを「更新」または「名前変更」するには、まずそのルールを削除し、次に目的のタグを指定して再度追加する必要があります。最もよい方法は、タグとして一意の識別子を使用し、システム側でその識別子を自分の App 内のさまざまな他のデータポイントに関連付けるようにすることです。これにより、ルールセット自体を変更せずに運用できます。
