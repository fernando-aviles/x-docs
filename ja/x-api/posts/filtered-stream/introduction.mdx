Filtered Stream エンドポイントを使用すると、フィルタールールに一致する投稿をリアルタイムで受信できます。強力なオペレーターを使ってルールを作成し、永続的なストリームに接続して、公開されるたびに一致する投稿を受信します。

  ## 概要
</div>

<CardGroup cols={2}>

  </Card>

  <Card title="永続的なルール" icon="filter">

  </Card>
</CardGroup>

<div id="how-it-works">
  ## 仕組み
</div>

1. **ルールを作成** — オペレーターを使ってフィルタールールを定義
2. **ストリームに接続** — 永続的な HTTP 接続を確立
3. **投稿を受信** — 一致する投稿をリアルタイムに受信

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│ Create/     │      │ Connect to  │      │ Receive     │
│ manage      │  →   │ streaming   │  →   │ matching    │
│ rules       │      │ endpoint    │      │ Posts       │
└─────────────┘      └─────────────┘      └─────────────┘
```

<div id="building-rules">
  ## ルールの作成
</div>

ルールでは、検索クエリと同じ演算子を使用します。

```
(AI OR "machine learning") lang:en -is:retweet
```

<div id="example-rules">
  ### ルールの例
</div>

| ルール | 一致する投稿 |
|:-----|:--------|
| `#python` | #python のハッシュタグを含む投稿 |
| `from:elonmusk` | @elonmusk による投稿 |
| `"breaking news" has:images` | &quot;breaking news&quot; というフレーズと画像を含む投稿 |
| `(@XDevelopers OR @X) -is:retweet` | リツイートを除外したメンション |

<div id="connecting-to-the-stream">
  ## ストリームへの接続
</div>

投稿を受信するために永続的な HTTP 接続を確立します。

```python
import requests

def stream_posts(bearer_token):
    url = "https://api.x.com/2/tweets/search/stream"
    headers = {"Authorization": f"Bearer {bearer_token}"}
    
    response = requests.get(url, headers=headers, stream=True)
    
    for line in response.iter_lines():
        if line:
            print(line.decode("utf-8"))
```

<div id="keep-alive-signals">
  ### キープアライブ信号
</div>

ストリームは接続を維持するために、20 秒ごとに空行（`\r\n`）を送信します。20 秒間データまたはキープアライブ信号を受信しない場合は、再接続してください。

  ## 投稿の編集
</div>

ストリームは、編集履歴とともに編集後の投稿を配信します。各編集ごとに新しい Post ID が生成されます。

```json

    "id": "1234567893",
    "text": "Hello world! (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891", "1234567893"]
  }
}
```
