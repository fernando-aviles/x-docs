  ## X API のフィルタリングストリームエンドポイントの比較
</div>

X API v2 のフィルタリングストリームエンドポイント群は、[Standard v1.1 statuses/filter](https://developer.x.com/en/docs/x-api/v1/tweets/filter-realtime/api-reference/post-statuses-filter) と [PowerTrack API](/ja/x-api/enterprise-gnip-2.0/powertrack-api) を置き換えるものです。既存のコード、アプリ、ツールで旧バージョンのフィルタリングストリームエンドポイントを利用していて、新しい X API v2 エンドポイントへの移行を検討している場合、この比較が移行の第一歩として役立ちます。

次の、より詳しい移行ガイドも参照してください：

[Standard v1.1 から X API v2 への移行](x-api/posts/filtered-stream#standard-v1-1-compared-to-x-api-v2)

[PowerTrack API から X API v2 への移行](/ja/x-api/enterprise-gnip-2.0/powertrack-api#powertrack-operators)
