<div id="comparing-x-apis-filtered-stream-endpoints">
  ## X API のフィルタ済みストリームエンドポイントの比較
</div>

v2 フィルタ済みストリームエンドポイントグループは、[標準 v1.1 statuses/filter](https://developer.x.com/en/docs/x-api/v1/tweets/filter-realtime/api-reference/post-statuses-filter) と [PowerTrack API](/ja/x-api/enterprise-gnip-2.0/powertrack-api) を置き換えるものです。既存のコード、アプリ、またはツールで旧バージョンのフィルタ済みストリームエンドポイントを使用していて、新しい X API v2 エンドポイントへの移行を検討している場合、この比較が移行の検討を始める際の助けになります。

より詳細な移行ガイドについては次を参照してください。

[標準 v1.1 から X API v2 への移行](x-api/posts/filtered-stream#standard-v1-1-compared-to-x-api-v2)

[PowerTrack API から X API v2 への移行](/ja/x-api/enterprise-gnip-2.0/powertrack-api#powertrack-operators)
