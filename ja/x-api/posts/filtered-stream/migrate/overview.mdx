  ## X API のフィルタ済みストリームエンドポイントの比較
</div>

v2 のフィルタ済みストリームエンドポイントグループは、[standard v1.1 statuses/filter](https://developer.x.com/en/docs/x-api/v1/tweets/filter-realtime/api-reference/post-statuses-filter) および [PowerTrack API](/ja/x-api/enterprise-gnip-2.0/powertrack-api) を置き換えるものです。フィルタ済みストリームエンドポイントの旧バージョンを使用しているコード、App、ツールがあり、新しい X API v2 エンドポイントへの移行を検討している場合、この比較が移行を始める際の参考になります。

以下の、より詳しい移行ガイドも参照してください:

[Standard v1.1 から X API v2 への移行](x-api/posts/filtered-stream#standard-v1-1-compared-to-x-api-v2)

[PowerTrack API から X API v2 への移行](/ja/x-api/enterprise-gnip-2.0/powertrack-api#powertrack-operators)
