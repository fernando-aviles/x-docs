Manage Posts エンドポイントでは、認証済みユーザーに代わって投稿を作成および削除できます。コンテンツの投稿、スレッドの作成、ユーザーの投稿管理を行うアプリケーションを構築できます。

<div id="endpoints">
  ## エンドポイント
</div>

| メソッド | エンドポイント | 説明 |
|:-------|:---------|:------------|
| POST | [`/2/tweets`](/ja/x-api/posts/create-post) | 新しい投稿を作成 |
| DELETE | [`/2/tweets/:id`](/ja/x-api/posts/delete-post) | 投稿を削除 |

<div id="creating-posts">
  ## 投稿の作成
</div>

<div id="basic-post">
  ### 通常の投稿
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from the API!"}'
```

<div id="reply-to-a-post">
  ### 投稿に返信する
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "This is a reply!",
    "reply": {
      "in_reply_to_tweet_id": "1234567890"
    }
  }'
```

<div id="quote-a-post">
  ### 投稿を引用する
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Check this out!",
    "quote_tweet_id": "1234567890"
  }'
```

<div id="post-with-media">
  ### メディア付きの投稿
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Photo of the day",
    "media": {
      "media_ids": ["1234567890123456789"]
    }
  }'
```

<Note>
  まず [Media Upload エンドポイント](/ja/x-api/media/quickstart/media-upload-chunked) を使ってメディアをアップロードし、その後、投稿内で `media_id` を参照してください。
</Note>

<div id="post-with-poll">
  ### 投票付きの投稿
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "What is your favorite color?",
    "poll": {
      "options": ["Red", "Blue", "Green", "Yellow"],
      "duration_minutes": 1440
    }
  }'
```

***

<div id="deleting-posts">
  ## 投稿を削除する
</div>

```bash
curl -X DELETE "https://api.x.com/2/tweets/1234567890" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<Warning>
  現在の認証ユーザーが作成した投稿のみ削除できます。
</Warning>
