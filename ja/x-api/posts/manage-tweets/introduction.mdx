Manage Posts エンドポイントを使用すると、認証済みユーザーに代わって投稿を作成および削除できます。コンテンツを投稿し、スレッドを作成し、ユーザーの投稿を管理するアプリケーションを構築できます。

<div id="endpoints">
  ## エンドポイント
</div>

| メソッド | エンドポイント | 説明 |
|:-------|:---------|:------------|
| POST | [`/2/tweets`](/ja/x-api/posts/create-post) | 新規投稿を作成 |

--------------------------------------------------------------------

## 投稿の作成

<div id="reply-to-a-post">
  ### 基本的な投稿
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from the API!"}'
```

<div id="quote-a-post">
  ### 投稿に返信する
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "This is a reply!",
    "reply": {
      "in_reply_to_tweet_id": "1234567890"
    }
  }'
```

<div id="post-with-media">
  ### 投稿を引用する
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Check this out!",
    "quote_tweet_id": "1234567890"
  }'
```

<div id="post-with-poll">
  ### メディア付き投稿
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Photo of the day",
    "media": {
      "media_ids": ["1234567890123456789"]
    }
  }'
```

<Note>
  まず [Media Upload endpoint](/ja/x-api/media/quickstart/media-upload-chunked) を使ってメディアをアップロードし、その後、投稿で `media_id` を参照してください。
</Note>

### 投票付き投稿

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "What is your favorite color?",
    "poll": {
      "options": ["Red", "Blue", "Green", "Yellow"],
      "duration_minutes": 1440
    }
  }'
```

***

<div id="getting-started">
  ## 投稿の削除
</div>

```bash
curl -X DELETE "https://api.x.com/2/tweets/1234567890" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<Warning>
  認証済みユーザー自身が作成した投稿のみ削除できます。
</Warning>
