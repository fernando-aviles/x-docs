このガイドでは、X API を使用してブックマークした投稿を取得する方法を説明します。

<Note>
  **前提条件**

  始める前に、次のものが必要です。

  * 承認済みの App が紐づいた [開発者アカウント](https://developer.x.com/en/portal/petition/essential/basic-info)
  * `bookmark.read` スコープが付与されたユーザーアクセストークン（OAuth 2.0 PKCE）
</Note>

***

<div id="get-your-bookmarks">
  ## ブックマークを取得する
</div>

<Steps>
  <Step title="自分のユーザーIDを取得する">
    認証済みユーザーのIDが必要です。`/2/users/me` エンドポイント、または [ユーザー検索エンドポイント](/ja/x-api/users/lookup/introduction)を使って取得できます。
  </Step>

  <Step title="ブックマークをリクエストする">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/users/2244994945/bookmarks?\
      tweet.fields=created_at,public_metrics,author_id&\
      max_results=10" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # ページネーション付きでブックマークされた投稿を取得する
      for page in client.bookmarks.get(
          "2244994945",
          tweet_fields=["created_at", "public_metrics", "author_id"],
          max_results=10
      ):
          for post in page.data:
              print(f"{post.text[:50]}... - Likes: {post.public_metrics.like_count}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // ページネーション付きでブックマークされた投稿を取得する
      const paginator = client.bookmarks.get("2244994945", {
        tweetFields: ["created_at", "public_metrics", "author_id"],
        maxResults: 10,
      });

      for await (const page of paginator) {
        page.data?.forEach((post) => {
          console.log(`${post.text?.slice(0, 50)}... - Likes: ${post.public_metrics?.like_count}`);
        });
      }
      ```
    </CodeGroup>
  </Step>

<div id="include-author-information">
  ## 投稿者情報を含める
</div>

投稿者に関する情報を取得するには、expansions パラメーターを使用します。

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/2244994945/bookmarks?\
  tweet.fields=created_at,author_id&\
  expansions=author_id&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 投稿者情報付きでブックマークを取得
  for page in client.bookmarks.get(
      "2244994945",
      tweet_fields=["created_at", "author_id"],
      expansions=["author_id"],
      user_fields=["username", "verified"]
  ):
      for post in page.data:
          print(f"{post.text[:50]}...")
      # 投稿者情報は page.includes.users に含まれます
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 投稿者情報付きでブックマークを取得
  const paginator = client.bookmarks.get("2244994945", {
    tweetFields: ["created_at", "author_id"],
    expansions: ["author_id"],
    userFields: ["username", "verified"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text?.slice(0, 50)}...`);
    });
    # 投稿者情報は page.includes?.users に含まれます
  }
  ```
</CodeGroup>

<div id="required-scopes">
  ## 必要なスコープ
</div>

OAuth 2.0 PKCE を使用する場合、アクセストークンには次のスコープが必要です。

| Scope | Description |
|:------|:------------|
| `bookmark.read` | ブックマークを読み取る |
| `tweet.read` | 投稿データを読み取る |
| `users.read` | ユーザーデータを読み取る（expansions 用） |
