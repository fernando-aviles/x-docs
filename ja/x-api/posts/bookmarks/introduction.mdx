Bookmarks エンドポイントを使用すると、認証済みユーザーのブックマーク済み投稿を表示、追加、削除できます。ブックマークは非公開で、作成したユーザー本人にしか表示されません。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="ブックマークを表示" icon="bookmark">
    ブックマーク済みのすべての投稿を取得する
  </Card>

  <Card title="ブックマークを追加" icon="plus">
    ポストをブックマークに追加する
  </Card>

  <Card title="ブックマークを削除" icon="minus">
    ブックマーク済みポストをブックマークから削除する
  </Card>

  <Card title="ブックマークフォルダ" icon="folder">
    ブックマークをフォルダに整理する
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/bookmarks`](/ja/x-api/users/get-bookmarks) | ユーザーのブックマークを取得 |
| POST | [`/2/users/:id/bookmarks`](/ja/x-api/users/create-bookmark) | ポストをブックマークする |
| DELETE | [`/2/users/:id/bookmarks/:tweet_id`](/ja/x-api/users/delete-bookmark) | ブックマークを削除 |
| GET | [`/2/users/:id/bookmarks/folders`](/ja/x-api/users/get-bookmark-folders) | ブックマークフォルダを取得 |
| GET | [`/2/users/:id/bookmarks/folders/:folder_id`](/ja/x-api/users/get-bookmarks-by-folder-id) | フォルダ内のポストを取得 |

***

<div id="example-get-bookmarks">
  ## 例: ブックマークの取得
</div>

```bash
curl "https://api.x.com/2/users/123456789/bookmarks?\
tweet.fields=created_at,author_id,public_metrics" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-add-bookmark">
  ## 例: ブックマークを追加
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
