Bookmarks エンドポイントを使用すると、認証済みのユーザーのブックマークされた投稿を表示、追加、および削除できます。Bookmarks は非公開で、作成したユーザーにしか表示されません。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="ブックマークを表示" icon="bookmark">
    ブックマーク済みのすべての投稿を取得
  </Card>

  <Card title="ブックマークを追加" icon="plus">
    投稿をブックマークに追加
  </Card>

  <Card title="ブックマークを削除" icon="minus">
    ブックマーク済みの投稿を削除
  </Card>

  <Card title="ブックマークフォルダー" icon="folder">
    ブックマークをフォルダーに整理
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/bookmarks`](/ja/x-api/users/get-bookmarks) | ユーザーのブックマークを取得する |
| POST | [`/2/users/:id/bookmarks`](/ja/x-api/users/create-bookmark) | 投稿をブックマークする |
| DELETE | [`/2/users/:id/bookmarks/:tweet_id`](/ja/x-api/users/delete-bookmark) | ブックマークを削除する |
| GET | [`/2/users/:id/bookmarks/folders`](/ja/x-api/users/get-bookmark-folders) | ブックマークフォルダーを取得する |
| GET | [`/2/users/:id/bookmarks/folders/:folder_id`](/ja/x-api/users/get-bookmarks-by-folder-id) | フォルダー内の投稿を取得する |

***

<div id="example-get-bookmarks">
  ## 例：ブックマークを取得する
</div>

```bash
curl "https://api.x.com/2/users/123456789/bookmarks?\
tweet.fields=created_at,author_id,public_metrics" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-add-bookmark">
  ## 例：ブックマークを追加する
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
