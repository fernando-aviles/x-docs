<div id="postman">
  #### Postman
</div>

Postman は、エンドポイントを試してみるのに便利なツールです。各 Postman リクエストには、利用可能な項目をすばやく把握できるように、すべてのパスパラメータとボディパラメータが含まれています。Postman コレクションの詳細については、「[Postman の使い方](/ja/tutorials/postman-getting-started)」ページをご覧ください。

<div id="authentication">
  #### 認証
</div>

すべての X API v2 エンドポイントでは、認証情報（キーやトークン）を使ってリクエストを認証する必要があります。

これらのエンドポイントでは、[OAuth 2.0 Authorization Code フロー（PKCE 使用）](/ja/resources/fundamentals/authentication/oauth-2-0/authorization-code) を利用する必要があります。つまり、リクエストを正常に行うには、キーのセットとユーザーのアクセストークンを使用しなければなりません。アクセストークンは、代理でリクエストを行う対象ユーザーにひも付いている必要があります。別のユーザーのアクセストークンを生成したい場合、そのユーザーは [Authorize URL](/ja/resources/fundamentals/authentication#authorize-url) を使ってあなたのアプリを承認または認証する必要があります。

なお、OAuth 2.0 は扱いが難しい場合があります。この認証方式に慣れていない場合は、[ライブラリ](/ja/x-api/tools-and-libraries/overview) や Postman のようなツールを使って、リクエストを正しく認証することを推奨します。

<div id="developer-console-projects-and-developer-apps">
  #### Developer Console、Project、および開発者用 App
</div>

X API v2 エンドポイントで利用可能な認証情報一式を取得するには、[開発者アカウント](/ja/resources/fundamentals/developer-portal)を保有し、そのアカウント内に[Project](/ja/resources/fundamentals/developer-apps)を作成し、その Project 内に[開発者用 App](/ja/resources/fundamentals/developer-apps)を作成している必要があります。その後、開発者用 App 内でキーとトークンを確認できます。

<div id="rate-limits">
  #### レート制限
</div>

毎日、何万もの開発者が X API にリクエストを送信しています。この膨大な数のリクエストを管理するため、各エンドポイントには [レート制限](/ja/resources/fundamentals/rate-limits) が設けられており、アプリまたは認証済みユーザーに代わって送信できるリクエスト数が制限されています。

これらのエンドポイントにはユーザーレベルでレート制限が適用されています。つまり、あなたがリクエストを送信している認証済みユーザーは、どの開発者用 App を経由する場合でも、そのエンドポイントを呼び出せる回数が一定数に制限されます。GET メソッドでは、15 分間の時間枠あたり 180 リクエストというユーザーレート制限があります。Bookmarks lookup エンドポイントの GET メソッドでは、直近のブックマーク済み投稿を最大 800 件まで取得できます。さらに、POST メソッドと DELETE メソッドでは、15 分間あたり 50 リクエストというユーザーレート制限があります。

<div id="get-bookmarks">
  #### ブックマークを取得
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123/bookmarks?tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # ユーザーのブックマークを取得
  for page in client.bookmarks.get(user_id="123", tweet_fields=["created_at", "public_metrics"]):
      for post in page.data:
          print(f"{post.text} - いいね数: {post.public_metrics.like_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // ユーザーのブックマークを取得
  const paginator = client.bookmarks.get("123", {
    tweetFields: ["created_at", "public_metrics"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text} - いいね数: ${post.public_metrics?.like_count}`);
    });
  }
  ```
</CodeGroup>

<div id="create-a-bookmark">
  #### ブックマークを作成する
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/bookmarks" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 投稿をブックマークする
  response = client.bookmarks.create(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 投稿をブックマークする
  const response = await client.bookmarks.create("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
