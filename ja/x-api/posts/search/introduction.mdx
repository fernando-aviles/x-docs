Search Posts エンドポイントでは、強力なクエリ演算子を使って特定の条件に一致する投稿を検索できます。キーワード、ハッシュタグ、メンション、URL など、さまざまな対象を検索できます。

<div id="overview">
  ## 概要
</div>

X では、検索可能な期間とアクセス要件が異なる 2 種類の検索エンドポイントを提供しています。

<CardGroup cols={2}>
  <Card title="最近の検索" icon="clock">
    **直近 7 日間**の投稿を検索できます。すべての開発者が利用できます。
  </Card>

  <Card title="全アーカイブ検索" icon="vault">
    2006 年までさかのぼる**全アーカイブ**を検索できます。従量課金プランおよび Enterprise 契約のお客様が利用できます。
  </Card>
</CardGroup>

***

<div id="use-cases">
  ## 利用例
</div>

* **ブランドモニタリング** — ブランドや製品に対する言及を追跡する
* **トレンド分析** — トピックやイベントに関する会話を分析する
* **調査** — 学術研究や市場調査のためのデータを収集する
* **リアルタイムリスニング** — 新規の投稿にリアルタイムで反応するアプリケーションを構築する

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | Description | Access |
|:-------|:---------|:------------|:-------|
| GET | [`/2/tweets/search/recent`](/ja/x-api/posts/search-recent-posts) | 過去7日間の投稿を検索 | すべての開発者 |
| GET | [`/2/tweets/search/all`](/ja/x-api/posts/search-all-posts) | すべての投稿アーカイブを検索 | 従量課金制、Enterprise |

<div id="query-operators">
  ## クエリ演算子
</div>

投稿の属性に一致する演算子を使用してクエリを構築します。

```
(AI OR "artificial intelligence") lang:en -is:retweet has:links
```

<AccordionGroup>
  <Accordion title="キーワード演算子">
    | Operator | Example              | Description           |
    | :------- | :------------------- | :-------------------- |
    | Keyword  | `python`             | 指定した単語を含む投稿に一致        |
    | Phrase   | `"machine learning"` | 指定したフレーズ全体に完全一致       |
    | Hashtag  | `#AI`                | 指定したハッシュタグを含む投稿に一致    |
    | Mention  | `@XDevelopers`       | 特定ユーザーへのメンションを含む投稿に一致 |
  </Accordion>

  <Accordion title="ユーザー演算子">
    | Operator       | Example          | Description     |
    | :------------- | :--------------- | :-------------- |
    | `from:`        | `from:elonmusk`  | 特定ユーザーによる投稿     |
    | `to:`          | `to:XDevelopers` | 特定ユーザーへの返信      |
    | `retweets_of:` | `retweets_of:X`  | 特定ユーザーの投稿のリツイート |
  </Accordion>

  <Accordion title="コンテンツ演算子">
    | Operator       | Example          | Description |
    | :------------- | :--------------- | :---------- |
    | `has:images`   | `cat has:images` | 画像を含む投稿     |
    | `has:videos`   | `has:videos`     | 動画を含む投稿     |
    | `has:links`    | `has:links`      | リンクを含む投稿    |
    | `has:mentions` | `has:mentions`   | メンションを含む投稿  |
    | `url:`         | `url:github.com` | 特定のURLを含む投稿 |
  </Accordion>

  <Accordion title="フィルター演算子">
    | Operator      | Example       | Description |
    | :------------ | :------------ | :---------- |
    | `lang:`       | `lang:en`     | 指定した言語の投稿   |
    | `-is:retweet` | `-is:retweet` | リツイートを除外    |
    | `-is:reply`   | `-is:reply`   | 返信を除外       |
    | `is:verified` | `is:verified` | 認証済みユーザーの投稿 |
  </Accordion>
</AccordionGroup>

<div id="recent-search">
  ## 最近の検索
</div>

**過去7日間**の投稿を検索できます。すべての開発者が利用できます。

<div id="features">
  ### 機能
</div>

* リクエストごとに最大100件の投稿
* 大規模な結果セットに対応したページネーション
* すべての主要なクエリ演算子
* 512文字のクエリ長（Enterpriseでは4,096文字）

<div id="full-archive-search">
  ## フルアーカイブ検索
</div>

2006年3月まで遡る**全期間の投稿アーカイブ**を検索できます。

<Note>
  フルアーカイブ検索は従量課金プランおよび Enterprise プランをご利用のお客様がご利用いただけます。
</Note>

<div id="features">
  ### 機能
</div>

* リクエストあたり最大500件の投稿
* すべての投稿履歴にアクセス
* すべてのクエリ演算子が利用可能
* クエリ文字数は1,024文字（Enterpriseでは4,096文字）
