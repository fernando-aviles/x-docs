Search Posts エンドポイントを使用すると、強力なクエリ演算子を用いて特定の条件に一致する投稿を検索できます。キーワード、ハッシュタグ、メンション、URL などを対象に検索できます。

<div id="overview">
  ## 概要
</div>

X には、対象期間とアクセス要件が異なる 2 つの検索エンドポイントがあります。

<CardGroup cols={2}>
  <Card title="最近の検索" icon="clock">
    **直近 7 日間**の投稿を検索します。すべての開発者が利用可能です。
  </Card>

  <Card title="全アーカイブ検索" icon="vault">
    2006 年までさかのぼる **全アーカイブ**を検索します。従量課金制プランおよび Enterprise プランのお客様が利用できます。
  </Card>
</CardGroup>

***

<div id="use-cases">
  ## ユースケース
</div>

* **ブランドモニタリング** — 自社ブランドや製品に関する言及を追跡する
* **トレンド分析** — トピックやイベントに関する会話を分析する
* **リサーチ** — 学術研究や市場調査向けのデータを収集する
* **リアルタイムリスニング** — 新しい投稿に反応するアプリケーションを構築する

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | Description | Access |
|:-------|:---------|:------------|:-------|
| GET | [`/2/tweets/search/recent`](/ja/x-api/posts/search-recent-posts) | 過去7日間の投稿を検索 | すべての開発者 |
| GET | [`/2/tweets/search/all`](/ja/x-api/posts/search-all-posts) | 投稿アーカイブ全体を検索 | 従量課金制、Enterprise |

<div id="query-operators">
  ## クエリ演算子
</div>

投稿の属性に一致する演算子を使用してクエリを構築します。

```
(AI OR "artificial intelligence") lang:en -is:retweet has:links
```

<AccordionGroup>
  <Accordion title="キーワード演算子">
    | Operator | Example              | Description          |
    | :------- | :------------------- | :------------------- |
    | Keyword  | `python`             | 指定した語を含む投稿           |
    | Phrase   | `"machine learning"` | 指定したフレーズと完全一致する投稿    |
    | Hashtag  | `#AI`                | 指定したハッシュタグを含む投稿      |
    | Mention  | `@XDevelopers`       | 指定したユーザーへのメンションを含む投稿 |
  </Accordion>

  <Accordion title="ユーザー演算子">
    | Operator       | Example          | Description     |
    | :------------- | :--------------- | :-------------- |
    | `from:`        | `from:elonmusk`  | 特定ユーザーによる投稿     |
    | `to:`          | `to:XDevelopers` | 特定ユーザー宛ての返信     |
    | `retweets_of:` | `retweets_of:X`  | 特定ユーザーの投稿のリツイート |
  </Accordion>

  <Accordion title="コンテンツ演算子">
    | Operator       | Example          | Description |
    | :------------- | :--------------- | :---------- |
    | `has:images`   | `cat has:images` | 画像を含む投稿     |
    | `has:videos`   | `has:videos`     | 動画を含む投稿     |
    | `has:links`    | `has:links`      | リンクを含む投稿    |
    | `has:mentions` | `has:mentions`   | メンションを含む投稿  |
    | `url:`         | `url:github.com` | 特定のURLを含む投稿 |
  </Accordion>

  <Accordion title="フィルター演算子">
    | Operator      | Example       | Description   |
    | :------------ | :------------ | :------------ |
    | `lang:`       | `lang:en`     | 特定の言語の投稿      |
    | `-is:retweet` | `-is:retweet` | リツイートを除外      |
    | `-is:reply`   | `-is:reply`   | 返信を除外         |
    | `is:verified` | `is:verified` | 認証済みユーザーによる投稿 |
  </Accordion>
</AccordionGroup>

<div id="recent-search">
  ## 最近の検索
</div>

過去7日間の投稿を検索できます。すべての開発者が利用可能です。

<div id="features">
  ### 機能
</div>

* リクエストごとに最大100件の投稿
* 大規模な結果セット向けのページネーション
* 主要なクエリ演算子をすべてサポート
* クエリ文字数は512文字（Enterpriseは4,096文字）

<div id="full-archive-search">
  ## フルアーカイブ検索
</div>

2006年3月までさかのぼる**全期間の投稿アーカイブ**を検索できます。

<Note>
  フルアーカイブ検索は、従量課金制および Enterprise プランのお客様にご利用いただけます。
</Note>

<div id="features">
  ### 機能
</div>

* リクエストあたり最大500件の投稿
* 投稿履歴全体へのアクセス
* すべてのクエリ演算子が利用可能
* クエリ文字数は1,024文字（Enterpriseでは4,096文字）
