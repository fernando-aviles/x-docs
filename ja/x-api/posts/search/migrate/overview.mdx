<div id="comparing-x-apis-search-posts-endpoints">
  ## X API の Search Posts エンドポイントの比較
</div>

v2 Search Tweets エンドポイントは、最終的に [standard v1.1 search/posts](/ja/x-api/posts/search/introduction) エンドポイントおよび [enterprise Search API](/ja/x-api/enterprise-gnip-2.0/fundamentals/search-api) を置き換える予定です。古いバージョンの X の検索エンドポイントを使用しているコードやアプリケーション、ツールがあり、新しい X API v2 エンドポイントへの移行を検討している場合は、このガイドが役に立ちます。

***

**フィルタリングオペレーターの比較**

投稿検索の 4 つのバージョン（standard、enterprise、v2）は、利用可能なオペレーターが異なり、さらに各バージョン内でもオペレーターの利用可能範囲が異なります。これらについては以下で説明します。

Enterprise

* Enterprise オペレーターにサブティアはありません

X API v2

* **Self-serve:** 任意の Project で利用可能
* **Enterprise:** Project を使用する場合に利用可能

これらそれぞれのオペレーターセットの詳細は、対応するガイドで確認できます。

* [Enterprise operators](/ja/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [X API v2 operators](/ja/x-api/posts/search/integrate/build-a-query#operators)
