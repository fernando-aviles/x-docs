このガイドでは、2006年3月までさかのぼる X の全アーカイブから投稿を検索するために、最初のフルアーカイブ検索リクエストを送信する手順を説明します。

<Warning>
  フルアーカイブ検索を利用するには、[Self-serve](/ja/x-api/getting-started/about-x-api) または [Enterprise](/ja/x-api/getting-started/about-x-api) へのアクセスが必要です。このエンドポイントを使用するには、[アクセスをアップグレード](https://developer.x.com/en/portal/products)してください。
</Warning>

<Note>
  **前提条件**

  始める前に、次のものが必要です。

  * [開発者アカウント](https://developer.x.com/en/portal/petition/essential/basic-info)
  * アプリの Bearer Token（Developer Console の「Keys and tokens」で確認できます）
</Note>

***

<div id="step-1-build-a-query">
  ## ステップ 1: クエリを作成する
</div>

Full-archive search では、すべてのクエリ演算子を利用できます。Recent search と同じ要領でクエリを作成してください。

```
from:XDevelopers lang:en
```

<Tip>
  フルアーカイブ検索は、最大 1,024 文字までのクエリをサポートします（Enterprise では 4,096 文字まで）。
</Tip>

***

<div id="step-2-set-a-time-range">
  ## ステップ 2: 期間を設定する
</div>

デフォルトでは、検索結果には過去30日間の投稿が返されます。特定の期間を検索するには、`start_time` と `end_time` を使用します。

| パラメータ | 形式 | 例 |
|:----------|:-------|:--------|
| `start_time` | ISO 8601 | `2020-01-01T00:00:00Z` |
| `end_time` | ISO 8601 | `2020-12-31T23:59:59Z` |

***

<div id="step-3-make-a-request">
  ## ステップ 3：リクエストを送信する
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/search/all?\
  query=from%3AXDevelopers&\
  start_time=2020-01-01T00%3A00%3A00Z&\
  end_time=2020-12-31T23%3A59%3A59Z&\
  max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # ページネーション付きのフルアーカイブ検索
  for page in client.posts.search_all(
      query="from:XDevelopers",
      start_time="2020-01-01T00:00:00Z",
      end_time="2020-12-31T23:59:59Z",
      max_results=100
  ):
      for post in page.data:
          print(post.text)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // ページネーション付きのフルアーカイブ検索
  const paginator = client.posts.searchAll({
    query: "from:XDevelopers",
    startTime: "2020-01-01T00:00:00Z",
    endTime: "2020-12-31T23:59:59Z",
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(post.text);
    });
  }
  ```
</CodeGroup>

<div id="step-5-add-fields-and-expansions">
  ## 手順 5: フィールドと展開を追加する
</div>

クエリパラメータで追加のデータをリクエストします。

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/search/all?\
  query=from%3AXDevelopers&\
  start_time=2020-01-01T00%3A00%3A00Z&\
  end_time=2020-12-31T23%3A59%3A59Z&\
  tweet.fields=created_at,public_metrics,author_id&\
  expansions=author_id&\
  user.fields=username,description&\
  max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # フィールドと展開を指定して検索
  for page in client.posts.search_all(
      query="from:XDevelopers",
      start_time="2020-01-01T00:00:00Z",
      end_time="2020-12-31T23:59:59Z",
      tweet_fields=["created_at", "public_metrics", "author_id"],
      expansions=["author_id"],
      user_fields=["username", "description"],
      max_results=100
  ):
      for post in page.data:
          print(f"{post.created_at}: {post.text[:50]}...")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // フィールドと展開を指定して検索
  const paginator = client.posts.searchAll({
    query: "from:XDevelopers",
    startTime: "2020-01-01T00:00:00Z",
    endTime: "2020-12-31T23:59:59Z",
    tweetFields: ["created_at", "public_metrics", "author_id"],
    expansions: ["author_id"],
    userFields: ["username", "description"],
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.created_at}: ${post.text?.slice(0, 50)}...`);
    });
  }
  ```
</CodeGroup>

<div id="step-6-paginate-through-results">
  ## ステップ 6: 結果をページングする
</div>

SDK ではページネーションが自動的に処理されます。cURL を使用する場合は、レスポンスに含まれる `next_token` を使用します。

```bash
curl "https://api.x.com/2/tweets/search/all?\
query=from%3AXDevelopers&\
max_results=500&\
next_token=b26v89c19zqg8o3fo7gesq314yb9l2l4ptqy" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="key-differences-from-recent-search">
  ## Recent Search との主な違い
</div>

| Feature | Recent Search | Full-Archive Search |
|:--------|:--------------|:--------------------|
| 時間範囲 | 直近7日間 | 2006年3月から現在まで |
| 必要なアクセスレベル | すべての開発者 | 従量課金制、Enterprise |
| リクエストあたりの最大取得件数 | 100 | 500 |
| クエリ長 | 512文字 | 1,024文字 |
| レート制限 | 450 / 15分 | 300 / 15分、1 / 秒 |
| 認証方式 | App-Only、User Context | App-Only のみ |

***

<div id="common-parameters">
  ## 共通パラメータ
</div>

| Parameter | Description | Default |
|:----------|:------------|:--------|
| `query` | 検索クエリ（必須） | — |
| `max_results` | 1ページあたりの投稿数（10〜500） | 10 |
| `start_time` | 取得する最も古い投稿のタイムスタンプ | 30日前 |
| `end_time` | 取得する最も新しい投稿のタイムスタンプ | 現在 |
| `next_token` | ページネーション用トークン | — |
| `tweet.fields` | 追加で取得する投稿のフィールド | `id`, `text` |
| `expansions` | 併せて取得する関連オブジェクト | — |
