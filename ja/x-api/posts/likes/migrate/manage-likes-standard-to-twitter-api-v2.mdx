<div id="manage-likes-standard-v11-compared-to-x-api-v2">
  ### いいねの管理: standard v1.1 と X API v2 の比較
</div>

standard v1.1 の [POST favorites/create](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-create) と [POST favorites/destroy](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-destroy) エンドポイントを使用してきた場合、このガイドは、standard v1.1 と X API v2 の「いいね」管理エンドポイントの共通点と相違点を理解するのに役立つことを目的としています。

* **共通点**
  * OAuth 1.0a ユーザーコンテキスト
* **相違点**
  * エンドポイント URL と HTTP メソッド
  * アプリと Project の要件
  * リクエストパラメータ

<div id="similarities">
  #### 類似点
</div>

**OAuth 1.0a ユーザーコンテキストによる認証**

どちらのエンドポイントバージョンも [OAuth 1.0a ユーザーコンテキスト](/ja/resources/fundamentals/authentication#oauth-1-0a-2) をサポートしています。そのため、以前に v1.1 の標準的な manage&#95;favorites エンドポイントのいずれかを使用していた場合は、X API v2 のエンドポイントに移行しても、同じ認証方式を引き続き利用できます。

<div id="differences">
  #### 相違点
</div>

**エンドポイント URL と HTTP メソッド**

* Standard v1.1 エンドポイント:
  * POST https://api.x.com/1.1/favorites/create.json
    (投稿を「いいね」する)
  * POST https://api.x.com/1.1/favorites/destroy.json
    (投稿の「いいね」を取り消す)
* X API v2 エンドポイント:
  * POST https://api.x.com/2/tweets/:id/likes
    (投稿を「いいね」する)
  * DELETE https://api.x.com/2/tweets/:id/likes/:tweet&#95;id
    (投稿の「いいね」を取り消す) 

**App と Project の要件**

X API v2 エンドポイントを使用する場合、リクエストを認証するときに、[developer App](/ja/resources/fundamentals/developer-apps) と関連付けられた [Project](/ja/resources/fundamentals/developer-apps) の認証情報を使用する必要があります。すべての X API v1.1 エンドポイントでは、App からの認証情報、または App と関連付けられた App の認証情報を使用できます。

**リクエストパラメーター**

次の Standard v1.1 リクエストパラメーターには、X API v2 での対応するパラメーターがあります。

| Standard v1.1 | X API v2 |
| :--- | :--- |
| id  | id  |
| includes&#95;entities | 対応するパラメーターはありません |

Standard v1.1 のパラメーターはクエリパラメーターとして渡されますが、X API v2 のパラメーターは、POST エンドポイントではリクエストボディパラメーターとして、DELETE エンドポイントではパスパラメーターとして渡される点に注意してください。

また、Standard v1.1 エンドポイントを使用する場合、投稿に「いいね」するユーザーの id は必須ではありません。[OAuth 1.0a User Context](/ja/resources/fundamentals/authentication) とともに渡される [Access Tokens](/ja/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) によって、どのユーザーが「いいね」または「いいね」の取り消しを行っているかが特定されるためです。

<div id="like-a-post-v2">
  ### 投稿にいいねする (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/likes" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python
  # OAuth 1.0a ユーザーコンテキスト認証が必要です
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/likes"
  response = requests.post(url, auth=auth, json={"tweet_id": "1234567890"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 投稿にいいねする
  response = client.posts.like(user_id="123456789", tweet_id="1234567890")
  print(f"Liked: {response.data.liked}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 投稿にいいねする
  const response = await client.posts.like("123456789", { tweetId: "1234567890" });
  console.log(`Liked: ${response.data?.liked}`);
  ```
</CodeGroup>

<div id="unlike-a-post-v2">
  ### 投稿のいいねを解除する (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/123456789/likes/1234567890" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  # OAuth 1.0a ユーザーコンテキスト認証が必要です
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/likes/1234567890"
  response = requests.delete(url, auth=auth)
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",

  ```

