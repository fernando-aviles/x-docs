<div id="comparing-x-apis-likes-endpoints">
  ## X API の Likes エンドポイントの比較
</div>

このガイドでは、次の領域に焦点を当てます。

* **API リクエストパラメータ** - X API v2 のエンドポイントでは、新しい一連のリクエストパラメータが導入されています。特に Labs を利用したことがある方にはおなじみのパラメータもありますが、[fields](/ja/x-api/fundamentals/fields) や [expansions](/ja/x-api/fundamentals/expansions) パラメータの導入など、多くの重要な違いがあります。

* **App と Project の要件** - X API v2 にアクセスするには、[Project](/ja/resources/fundamentals/developer-apps) に関連付けられた [developer App](/ja/resources/fundamentals/developer-apps) の認証情報を使用する必要があります。

<div id="likes-lookup">
  #### いいねのルックアップ
</div>

**投稿に「いいね」したユーザー**

liked users エンドポイントは v2 で追加された新機能で、特定の投稿に「いいね」したユーザーに関する情報を取得できます。

| 説明 | X API v2 |
| :--- | :--- |
| サポートされる HTTP メソッド | GET |
| ホストドメイン | https://api.x.com |
| エンドポイントパス | /2/tweets/:id/liking&#95;users |
| [認証](/ja/resources/fundamentals/authentication) | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a ユーザーコンテキスト |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | 15 分あたり 75 リクエスト（アプリごと）<br /><br />15 分あたり 75 リクエスト（ユーザーごと） |

**ユーザーが「いいね」した投稿**

次の表では、Standard v1.1 の [GET favorites/list](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-favorites-list) エンドポイントと、X API v2 の「いいね」済み投稿関連エンドポイントを比較します。

| 説明 | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| サポートされる HTTP メソッド | GET | GET |
| ホストドメイン | https://api.x.com | https://api.x.com |
| エンドポイントパス | /1.1/favorites/list.json | /2/users/:id/liked&#95;tweets |
| [認証](/ja/resources/fundamentals/authentication) | OAuth 1.0a ユーザーコンテキスト | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a ユーザーコンテキスト |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | 15 分あたり 75 リクエスト | 15 分あたり 75 リクエスト（アプリごと）<br /><br />15 分あたり 75 リクエスト（ユーザーごと） |
| データ形式 | Standard v1.1 フォーマット | [X API v2 フォーマット](/ja/x-api/fundamentals/data-dictionary)（fields および expansions リクエストパラメータによって決定され、v1.1 フォーマットとの後方互換性はありません）<br /><br />Standard v1.1 フォーマットから X API v2 フォーマットへの移行方法については、[データ形式移行ガイド](/ja/x-api/migrate/data-format-migration)をご覧ください。 |

<div id="manage-likes">
  #### いいねの管理
</div>

v2 のいいね管理エンドポイントは、v1.1 の [POST favorites/create](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-create) および [POST favorites/destroy](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-destroy) エンドポイントを置き換えるものです。

次の表では、標準の v1.1 と X API v2 のいいね管理エンドポイントを比較します。

<div id="like-a-post">
  #### 投稿をいいねする
</div>

| 説明 | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| サポートされる HTTP メソッド | POST | POST |
| ホストドメイン | https://api.x.com | https://api.x.com |
| エンドポイントパス | /1.1/favorites/create.json | /2/users/:id/likes |
| [認証](/ja/resources/fundamentals/authentication) | OAuth 1.0a ユーザーコンテキスト | OAuth 1.0a ユーザーコンテキスト |
| デフォルトのリクエスト[レート制限](/ja/resources/fundamentals/rate-limits) | 24 時間あたり 1000 リクエスト（ユーザーごと）<br /><br />24 時間あたり 1000 リクエスト（アプリごと） | 15 分あたり 50 リクエスト（ユーザーごと）<br /><br />24 時間あたり 1000 リクエスト（ユーザーごと、DELETE と共有） |

<div id="unlike-a-post">
  #### 投稿の「いいね」を解除する
</div>

| 説明 | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| 対応している HTTP メソッド | POST | DELETE |
| ホストドメイン | https://api.x.com | https://api.x.com |
| エンドポイントパス | /1.1/favorites/destroy.json | /2/users/:id/likes/:tweet&#95;id |
| [認証](/ja/resources/fundamentals/authentication) | OAuth 1.0a ユーザーコンテキスト | OAuth 1.0a ユーザーコンテキスト |
| 既定のリクエスト [レート制限](/ja/resources/fundamentals/rate-limits) | 24 時間あたり 1000 リクエスト（ユーザーごと）<br /><br />24 時間あたり 1000 リクエスト（アプリごと） | 15 分あたり 50 リクエスト（ユーザーごと）<br /><br />24 時間あたり 1000 リクエスト（ユーザーごと、POST と共有） |
