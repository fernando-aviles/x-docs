Likes エンドポイントでは、投稿に「いいね」を付けたり取り消したり、特定の投稿に「いいね」したユーザーを確認したり、ユーザーが「いいね」した投稿を取得したりできます。

  ## 概要

<div id="endpoints">
  ## エンドポイント
</div>

<div id="likes-lookup">
  ### いいねの参照
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/liking_users`](/ja/x-api/posts/get-liking-users) | 投稿に「いいね」したユーザーを取得 |
| GET | [`/2/users/:id/liked_tweets`](/ja/x-api/users/get-liked-posts) | ユーザーが「いいね」した投稿を取得 |

<div id="manage-likes">
  ### いいねの管理
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/likes`](/ja/x-api/users/like-post) | 投稿を「いいね」する |
| DELETE | [`/2/users/:id/likes/:tweet_id`](/ja/x-api/users/unlike-post) | 投稿の「いいね」を取り消す |

***

<div id="important-notes">
  ## 重要な注意事項
</div>

<Note>
  liking users エンドポイントは、実際の「いいね」の数に関係なく、全期間を通じて 1 つの投稿ごとに最大 **100 人のユーザー** までしか返しません。
</Note>

***

<div id="example-get-liking-users">
  ## 例: ポストをいいねしたユーザーを取得する
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890/liking_users?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-like-a-post">
  ## 例: 投稿にいいねする
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
