Likes エンドポイントを使用すると、投稿に「いいね」やその取り消しを行ったり、特定の投稿に「いいね」したユーザーを確認したり、特定のユーザーが「いいね」した投稿を取得したりできます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="投稿をいいねする" icon="heart">
    ユーザーに代わって投稿をいいねする
  </Card>

  <Card title="投稿のいいねを取り消す" icon="heart-crack">
    投稿からいいねを削除する
  </Card>

  <Card title="いいねしたユーザー" icon="users">
    投稿にいいねしたユーザーを確認する
  </Card>

  <Card title="いいねした投稿" icon="list-heart">
    ユーザーがいいねした投稿を取得する
  </Card>
</CardGroup>

***

<div id="endpoints">
  ## エンドポイント
</div>

<div id="likes-lookup">
  ### いいねの取得
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/liking_users`](/ja/x-api/posts/get-liking-users) | 投稿に「いいね」したユーザーを取得 |
| GET | [`/2/users/:id/liked_tweets`](/ja/x-api/users/get-liked-posts) | ユーザーが「いいね」した投稿を取得 |

<div id="manage-likes">
  ### いいねを管理する
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/likes`](/ja/x-api/users/like-post) | 投稿に「いいね」する |
| DELETE | [`/2/users/:id/likes/:tweet_id`](/ja/x-api/users/unlike-post) | 投稿への「いいね」を取り消す |

***

<div id="important-notes">
  ## 重要な注意事項
</div>

<Note>
  「liking users」エンドポイントは、実際の「いいね」の数にかかわらず、任意の投稿について通算で最大 **100 人のユーザー** までしか返しません。
</Note>

***

<div id="example-get-liking-users">
  ## 例: いいねしたユーザーを取得
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890/liking_users?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-like-a-post">
  ## 例：投稿をいいねする
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
