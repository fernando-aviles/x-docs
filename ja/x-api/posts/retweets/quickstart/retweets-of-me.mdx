このガイドでは、他のユーザーにリツイートされたあなたの投稿を取得する方法を順を追って説明します。

<Note>
  **前提条件**

  作業を始める前に、次のものが必要です。

  * 承認済みのアプリを持つ [開発者アカウント](https://developer.x.com/en/portal/petition/essential/basic-info)
  * User Access Token（OAuth 1.0a または OAuth 2.0 PKCE）
</Note>

***

<div id="why-use-retweets-of-me">
  ## なぜ Retweets of Me を使うのか
</div>

Retweets of Me エンドポイントは、次のようなことに役立ちます。

* **エンゲージメントを追跡** — 自分のどの投稿が共有されているかを確認できます
* **反響を把握** — オーディエンスに響いているコンテンツを把握できます
* **戦略に生かす** — 共有パターンに基づいてコンテンツ戦略を調整できます

***

<div id="get-your-retweeted-posts">
  ## リポストされた自分の投稿を取得する
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/reposts_of_me?\
  tweet.fields=created_at,public_metrics&\
  max_results=10" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # リポストされた自分の投稿を取得する
  for page in client.posts.get_reposts_of_me(
      tweet_fields=["created_at", "public_metrics"],
      max_results=10
  ):
      for post in page.data:
          print(f"{post.text[:50]}... - リポスト数: {post.public_metrics.retweet_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // リポストされた自分の投稿を取得する
  const paginator = client.posts.getRepostsOfMe({
    tweetFields: ["created_at", "public_metrics"],
    maxResults: 10,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text?.slice(0, 50)}... - リポスト数: ${post.public_metrics?.retweet_count}`);
    });
  }
  ```
</CodeGroup>

<div id="filter-by-time-range">
  ## 時間範囲でフィルタリングする
</div>

特定の期間にリポストされた投稿を取得します。

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/reposts_of_me?\
  start_time=2024-01-01T00%3A00%3A00Z&\
  end_time=2024-01-31T23%3A59%3A59Z&\
  tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 指定した時間範囲のリポストされた投稿を取得
  for page in client.posts.get_reposts_of_me(
      start_time="2024-01-01T00:00:00Z",
      end_time="2024-01-31T23:59:59Z",
      tweet_fields=["created_at", "public_metrics"]
  ):
      for post in page.data:
          print(f"{post.created_at}: {post.text[:50]}...")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 指定した時間範囲のリポストされた投稿を取得
  const paginator = client.posts.getRepostsOfMe({
    startTime: "2024-01-01T00:00:00Z",
    endTime: "2024-01-31T23:59:59Z",
    tweetFields: ["created_at", "public_metrics"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.created_at}: ${post.text?.slice(0, 50)}...`);
    });
  }
  ```
</CodeGroup>

<div id="common-parameters">
  ## 共通パラメーター
</div>

| パラメーター | 説明 | デフォルト |
|:----------|:------------|:--------|
| `max_results` | 1 ページあたりの結果数 (1-100) | 10 |
| `start_time` | 最も古い投稿のタイムスタンプ (ISO 8601) | — |
| `end_time` | 最新の投稿のタイムスタンプ (ISO 8601) | — |
| `pagination_token` | 次ページ用のトークン | — |
| `tweet.fields` | 追加の投稿フィールド | `id`, `text` |
