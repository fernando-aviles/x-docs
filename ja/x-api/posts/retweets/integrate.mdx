<div id="authentication">
  #### 認証
</div>

すべての X API v2 エンドポイントでは、キーやトークンとも呼ばれる一連の認証情報を使って、リクエストを認証する必要があります。

Retweets lookup エンドポイントへのリクエストの認証には、OAuth 1.0a ユーザーコンテキストまたは OAuth 2.0 Bearer Token のいずれかを使用できます。

Retweets 管理エンドポイントでは OAuth 1.0a ユーザーコンテキストの使用が必要です。これは、リクエストを正常に行うために、一連の API キーとユーザーアクセストークンを使用しなければならないことを意味します。アクセストークンは、あなたが代理としてリクエストを送信するユーザーに関連付けられている必要があります。別のユーザー用のアクセストークンを生成したい場合、そのユーザーは 3-legged OAuth フローを使用してあなたの App を承認または認証する必要があります。

OAuth 1.0a の利用は難しい場合があることに注意してください。この認証方法に慣れていない場合は、リクエストを正しく認証するために [library](/ja/x-api/tools-and-libraries/overview) を使用することをおすすめします。

**ご注意ください**

次のフィールドをリクエストする場合、OAuth 1.0a ユーザーコンテキストが必須です。

* tweet.fields.non&#95;public&#95;metrics
* tweet.fields.promoted&#95;metrics
* tweet.fields.organic&#95;metrics
* media.fields.non&#95;public&#95;metrics
* media.fields.promoted&#95;metrics
* media.fields.organic&#95;metrics

<div id="developer-console-projects-and-developer-apps">
  #### 開発者コンソール、Project、および開発者用 App
</div>

X API v2 エンドポイントで使用できる一連の認証情報を取得するには、まず[開発者アカウントに登録](https://developer.x.com/en/portal/petition/essential/basic-info)し、そのアカウント内に[Project](/ja/resources/fundamentals/developer-apps)を作成し、その Project 内に[開発者用 App](/ja/resources/fundamentals/developer-apps)を作成する必要があります。作成後は、その開発者用 App 内でキーとトークンを確認できます。

<div id="rate-limits">
  #### レート制限
</div>

毎日、何千人もの開発者が X API に対してリクエストを送信しています。この膨大なリクエスト量を管理するために、各エンドポイントには[レート制限](/ja/x-api/fundamentals/rate-limits)が設定されており、アプリケーションや認証済みユーザーごとに送信できるリクエストの数が制限されています。

Retweets を管理するエンドポイントは、15 分あたり 1 ユーザーにつき 50 リクエストに制限されています。さらに、POST エンドポイントでは、3 時間の時間枠あたり 1 ユーザーかつ 1 アプリケーションにつき 300 リクエストに制限されています。

Retweets lookup エンドポイントでは、15 分の時間枠あたり 75 リクエストに制限されています。加えて、このエンドポイントから返されるのは、最新の 100 人のリツイートしたユーザーのみです。

<div id="fields-and-expansions">
  #### フィールドと展開
</div>

X API v2 では、`fields` と `expansions` と呼ばれる一連のツールを使用して、API レスポンスとして取得したい data を正確に選択できます。`expansions` パラメータを使用すると、ペイロード内で参照されているオブジェクトを展開してレスポンスに含めることができます。たとえば、このエンドポイントでは、次の [expansions](/ja/x-api/fundamentals/expansions) を取得できます。

* attachments.poll&#95;ids
* attachments.media&#95;keys
* author&#95;id, entities.mentions.username
* geo.place&#95;id
* in&#95;reply&#95;to&#95;user&#95;id,
* referenced&#95;tweets.id,
* referenced&#95;tweets.id.author&#95;id

`fields` パラメータを使用すると、さまざまな data オブジェクトのうち、どの [fields](/ja/x-api/fundamentals/fields) を受け取りたいかを正確に選択できます。これらのエンドポイントからは、主に Post オブジェクトが返されます。デフォルトでは、Post オブジェクトには `id` と `text` フィールドが含まれます。`tweet.created_at` や `tweet.entities` のような追加フィールドを受け取るには、`fields` パラメータを使って明示的にリクエストする必要があります。連携での利用を検討すべき重要なフィールドとしては、投票データ、メトリクス、Post のアノテーション、会話 ID フィールドなどがあります。

[X API v2 data dictionary](/ja/x-api/fundamentals/data-dictionary) には、[fields と expansions を使用する方法](/ja/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions) を組み合わせて利用する手順を解説したガイドを用意しています。

<div id="get-users-who-retweeted-a-post">
  #### 投稿をリポストしたユーザーを取得
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/1234567890/retweeted_by?user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 投稿をリポストしたユーザーを取得
  response = client.posts.get_retweeted_by(
      "1234567890",
      user_fields=["username", "verified"]
  )
  for user in response.data:
      print(f"{user.username} - Verified: {user.verified}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 投稿をリポストしたユーザーを取得
  const response = await client.posts.getRetweetedBy("1234567890", {
    userFields: ["username", "verified"],
  });

  response.data?.forEach((user) => {
    console.log(`${user.username} - Verified: ${user.verified}`);
  });
  ```
</CodeGroup>

<div id="retweet-a-post">
  #### 投稿をリツイートする
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/retweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 投稿をリツイートする
  response = client.posts.retweet(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 投稿をリツイートする
  const response = await client.posts.retweet("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
