Retweets エンドポイントを使用すると、リツイートおよびその取り消しを行い、特定の投稿を誰がリツイートしたかを確認し、自分の投稿に対するリポストを取得できます。

<div id="endpoints">
  ## エンドポイント
</div>

<div id="retweets-lookup">
  ### リポストのルックアップ
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/retweeted_by`](/ja/x-api/posts/get-reposted-by) | 投稿をリポストしたユーザーを取得 |
| GET | [`/2/tweets/:id/quote_tweets`](/ja/x-api/posts/get-quoted-posts) | 投稿の引用投稿を取得 |
| GET | [`/2/users/reposts_of_me`](/ja/x-api/users/get-reposts-of-me) | 認証済みユーザーの投稿のリポストを取得 |

<div id="manage-retweets">
  ### リポストを管理する
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/retweets`](/ja/x-api/users/repost-post) | 投稿をリポストする |
| DELETE | [`/2/users/:id/retweets/:tweet_id`](/ja/x-api/users/unrepost-post) | リポストを元に戻す |

***

<div id="example-get-retweeting-users">
  ## 例：リポストしたユーザーを取得する
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890/retweeted_by?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-retweet-a-post">
  ## 例：投稿をリツイートする
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/retweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
