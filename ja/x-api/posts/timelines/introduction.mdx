Timelines エンドポイントでは、ユーザーのタイムライン、メンションフィード、ホームフィードから投稿を取得できます。ユーザーが投稿したコンテンツを取得したり、そのユーザーへのメンションを含む投稿を確認したり、そのユーザー向けにパーソナライズされたホームタイムラインを表示したりできます。

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/ja/x-api/users/get-posts) | 指定ユーザーの投稿を取得 |
| GET | [`/2/users/:id/mentions`](/ja/x-api/users/get-mentions) | 指定ユーザーに言及している投稿を取得 |
| GET | [`/2/users/:id/timelines/reverse_chronological`](/ja/x-api/users/get-timeline) | ホームタイムラインを取得 |

<div id="user-posts-timeline">
  ## ユーザーの投稿タイムライン
</div>

特定のユーザーが作成した最新の投稿を取得します。

<div id="features">
  ### 機能
</div>

* 最新の投稿を最大3,200件まで取得
* 返信とリツイートを除外可能
* ページネーション対応
* 時間ベースのフィルタリングによる過去データへのアクセス

<div id="reverse-chronological-home-timeline">
  ## 逆時系列のホームタイムライン
</div>

認証済みユーザーのホームタイムラインを新しい順（逆時系列）で取得します。

<div id="features">
  ### 機能
</div>

* フォローしているアカウントの投稿
* 直近3,200件の投稿（または直近7日分）
* アルゴリズムによるランキングは適用されません
* ユーザー認証が必要です

<Note>
  このエンドポイントには、[OAuth 1.0a User Context](/ja/resources/fundamentals/authentication) または [OAuth 2.0 Authorization Code with PKCE](/ja/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) が必要です。
</Note>

<div id="filtering-options">
  ## フィルタリングのオプション
</div>

<div id="exclude-parameter">
  ### exclude パラメータ
</div>

特定の投稿タイプを除外します:

| Value      | 効果       |
| :--------- | :------- |
| `retweets` | リツイートを除外 |
| `replies`  | 返信を除外    |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="time-based-filtering">
  ### 時間ベースのフィルタリング
</div>

| Parameter | Description |
|:----------|:------------|
| `start_time` | 最も古い投稿のタイムスタンプ（ISO 8601） |
| `end_time` | 最も新しい投稿のタイムスタンプ（ISO 8601） |
| `since_id` | このIDより後の投稿を返します |
| `until_id` | このIDより前の投稿を返します |
