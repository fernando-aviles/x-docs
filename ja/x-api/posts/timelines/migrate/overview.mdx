<div id="comparing-x-apis-timelines-endpoints">
  ## X API のタイムラインエンドポイントの比較
</div>

v2 の逆時系列タイムライン、ユーザー投稿タイムライン、およびユーザー言及タイムラインの各エンドポイントは、それぞれ [v1.1 statuses/home&#95;timeine](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-home_timeline)、[v1.1 statuses/user&#95;timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-user_timeline.html)、[v1.1 statuses/mentions&#95;timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-mentions_timeline.html) エンドポイントを置き換えるものです。以前のバージョンのこれらのエンドポイントを使用しているコード、アプリ、ツールがあり、新しい X API v2 エンドポイントへの移行を検討している場合は、本ガイドを参照してください。より詳細な移行ガイドについては、[Standard v1.1 migration to X API v2](/ja/x-api/posts/timelines/migrate/standard-to-twitter-api-v2) を参照してください。

このページには、次の 3 つの比較表が含まれています。

* 逆時系列のホームタイムライン
* ユーザー投稿タイムライン
* ユーザー言及タイムライン

| Timeline navigation options | 更新ポーリングに使用される since&#95;id（排他的）<br /><br />max&#95;id（包括的） | start&#95;time<br /><br />end&#95;time<br /><br />更新ポーリングに使用される since&#95;id（排他的）<br /><br />until&#95;id（排他的） |

| Supports requesting and receiving [annotations](/ja/x-api/fundamentals/post-annotations) | 該当なし | 投稿テキストに基づき推定された注釈データを含む投稿結果を返します（例: 「Music Genre」と「Folk Music」や、「Musician」と「Dolly Parton」など）。 |
| Supports requesting and receiving specific Post [metrics](/ja/x-api/fundamentals/metrics) | 該当なし | 各投稿ごとに利用可能な public&#95;metrics を含む投稿結果を返します（retweet&#95;count、reply&#95;count、quote&#95;count、like&#95;count など）。<br />  <br />OAuth 1.0a User Context で利用可能:  <br />impression&#95;count、user&#95;profile&#95;clicks、url&#95;link&#95;clicks などの追加の non&#95;public&#95;metrics。<br /><br />view&#95;count や動画再生メトリクスなどの追加のメディアメトリクス。<br /><br />プロモーション投稿向けに、OAuth 1.0a User Context で利用可能な追加の organic&#95;metrics および promoted&#95;metrics。 |

| Post JSON format | [Standard v1.1 data format](/ja/x-api/fundamentals/data-dictionary) | [X API v2](/ja/x-api/fundamentals/data-dictionary) フォーマット（fields と expansions のリクエストパラメータによって決定され、v1.1 フォーマットとの後方互換性はありません）<br /><br />Standard v1.1 フォーマットから X API v2 フォーマットへの移行方法の詳細については、[data formats migration guide](/ja/x-api/migrate/data-format-migration) を参照してください。 |
| Results order | 新しい順（逆時系列） | 新しい順（逆時系列） |

| Requires the use of credentials from a [developer App](/ja/resources/fundamentals/developer-apps) associated with a [Project](/ja/resources/fundamentals/developer-apps) |     | ✔   |
| Provides Post edit history | ✔   | ✔   |
