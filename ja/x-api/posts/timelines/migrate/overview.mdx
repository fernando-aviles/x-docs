<div id="comparing-x-apis-timelines-endpoints">
  ## X API のタイムラインエンドポイントの比較
</div>

v2 の逆時系列タイムライン、ユーザー投稿タイムライン、およびユーザーメンションタイムラインの各エンドポイントは、それぞれ [v1.1 statuses/home&#95;timeine](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-home_timeline)、[v1.1 statuses/user&#95;timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-user_timeline.html)、[v1.1 statuses/mentions&#95;timeline](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-mentions_timeline.html) エンドポイントを置き換えるものです。このエンドポイントの旧バージョンを使用しているコード、アプリ、ツールがあり、新しい X API v2 エンドポイントへの移行を検討している場合は、本ガイドが役立ちます。より詳細な移行ガイドについては、[Standard v1.1 migration to X API v2](/ja/x-api/posts/timelines/migrate/standard-to-twitter-api-v2) を参照してください。

このページには、次の 3 つの比較表が含まれます。

* 逆時系列ホームタイムライン
* ユーザー投稿タイムライン
* ユーザーメンションタイムライン

  ### ユーザーの投稿タイムライン

|     |     |     |
| :--- | :--- | :--- |
| **Description** | **Standard v1.1** | **X API v2** |
| Documentation | [APIリファレンス](https://developer.x.com/en/docs/twitter-api/v1/tweets/timelines/api-reference/get-statuses-user_timeline.html) | [APIリファレンス](/ja/x-api/posts/user-posts-timeline-by-user-id) |
| HTTP methods supported | GET | GET |
| Host domain | https://api.x.com | https://api.x.com |
| Endpoint paths | /1.1/statuses/user&#95;timeline.json | /2/users/:id/tweets |
| Required parameters | user&#95;id または screen&#95;name | パスパラメーター :id として設定された User ID |
| Authentication | OAuth 1.0a User Context<br /><br />OAuth 2.0 App-Only | OAuth 1.0a User Context<br /><br />OAuth 2.0 App-Only<br /><br />OAuth 2.0 Authorization Code with PKCE |
| Request rate limits | OAuth 1.0a User Context 利用時は 15 分あたり 900 リクエスト<br /><br />OAuth 2.0 App-Only 利用時は 15 分あたり 1500 リクエスト<br /><br />24 時間あたりのリクエスト上限: 100,000 | OAuth 1.0a User Context 利用時は 15 分間のウィンドウごとに 900 リクエスト<br /><br />OAuth 2.0 App-Only 利用時は 15 分間のウィンドウごとに 1500 リクエスト |
| Default Posts per response | 15  | 10  |
| Maximum Posts per response | 200 | 100 |
| Historical Posts available | 最新の 3,200 件の投稿（リツイートを含む） | 最新の 3,200 件の投稿（リツイートを含む） |
| Timeline navigation options | 更新ポーリング用に使用される since&#95;id（排他的）<br /><br />max&#95;id（包括的） | start&#95;time<br /><br />end&#95;time<br /><br />更新ポーリング用に使用される since&#95;id（排他的）<br /><br />until&#95;id（排他的） |
| Optional parameters for results refinement | count  <br />exclude&#95;replies  <br />include&#95;rts  <br />trim&#95;user  <br />tweet&#95;mode  <br />since&#95;id  <br />max&#95;id | max&#95;results  <br />exclude(retweets,replies)  <br />tweet.fields  <br />user.fields  <br />place.fields  <br />media.fields  <br />poll.fields  <br />expansions  <br />start&#95;time  <br />end&#95;time  <br />since&#95;id  <br />until&#95;id |
| Supports requesting and receiving [annotations](/ja/x-api/fundamentals/post-annotations) | 該当なし | 投稿テキストに基づき推定されたアノテーションデータ（例: 「Music Genre」と「Folk Music」や「Musician」と「Dolly Parton」など）を含む投稿結果を返します |
| Supports requesting and receiving specific Post [metrics](/ja/x-api/fundamentals/metrics) | 該当なし | 各投稿ごとに利用可能な public&#95;metrics を含む投稿結果を返します。public&#95;metrics には retweet&#95;count、reply&#95;count、quote&#95;count、like&#95;count などが含まれます。<br /><br />OAuth 1.0a User Context で利用可能: <br />impression&#95;count、user&#95;profile&#95;clicks、url&#95;link&#95;clicks などの追加の non&#95;public&#95;metrics。<br /><br />view&#95;count や動画再生に関するメディアメトリクスなどの追加のメディアメトリクス。<br /><br />プロモーション投稿向けには、OAuth 1.0a User Context で利用可能な追加の organic&#95;metrics および promoted&#95;metrics。 |
| Supports requesting and receiving [conversation&#95;id](/ja/x-api/fundamentals/conversation-id) | 該当なし | conversation&#95;id フィールドを返します。この値は返信スレッド内で最初に公開された投稿を表し、会話の追跡に役立ちます。 |
| Post JSON format | [Standard v1.1 data format](/ja/x-api/fundamentals/data-dictionary) | [X API v2](/ja/x-api/fundamentals/data-dictionary) 形式（fields および expansions リクエストパラメーターによって決定され、v1.1 形式との後方互換性はありません）<br /><br />Standard v1.1 形式から X API v2 形式への移行方法の詳細については、[data formats migration guide](/ja/x-api/migrate/data-format-migration) を参照してください。 |
| Results order | 新しい順（逆時系列） | 新しい順（逆時系列） |
| Results pagination | 該当なし（投稿 ID によるナビゲーションを使用する必要があります） | pagination&#95;token を使用して、結果を前方向または後方向にたどって確認できます |
| Requires the use of credentials from a [developer App](/ja/resources/fundamentals/developer-apps) associated with a [Project](/ja/resources/fundamentals/developer-apps) |     | ✔   |
| Provides Post edit history | ✔   | ✔   |
