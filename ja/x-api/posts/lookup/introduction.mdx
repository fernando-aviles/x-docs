投稿参照エンドポイントを使用すると、ID を指定して 1 件または複数の投稿を取得できます。これらのエンドポイントを使用して、投稿の最新の詳細を取得したり、投稿が利用可能かどうかを確認したり、編集履歴を確認したりできます。

<div id="overview">
  ## 概要
</div>

投稿は、X における中心となるコンテンツです。各投稿には次の要素を含めることができます。

* 最大 280 文字のテキスト
* 添付メディア（画像、動画、GIF）
* 投票、場所、URL
* 返信、引用、メンション

投稿は作成後 30 分以内であれば最大 5 回まで編集できます。各編集によって新しい投稿 id が割り当てられ、編集履歴は保持されます。

<div id="use-cases">
  ## ユースケース
</div>

* **投稿コンテンツの表示** — アプリケーションで投稿の詳細を表示する
* **利用可能性の確認** — 投稿がまだ存在しているか、削除されたかを確認する
* **コンプライアンス管理** — コンプライアンスイベントのために投稿の変更を追跡する
* **分析** — 特定の投稿のエンゲージメントメトリクスを取得する

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id`](/ja/x-api/posts/get-post-by-id) | ID を指定して単一の投稿を取得 |
| GET | [`/2/tweets`](/ja/x-api/posts/get-posts-by-ids) | ID を指定して複数の投稿を取得（最大 100 件） |
