投稿ルックアップエンドポイントを使用すると、1 つ以上の投稿を ID を指定して取得できます。これらのエンドポイントを使用して、投稿の最新の詳細を取得したり、投稿が利用可能かどうかを確認したり、編集履歴を確認したりできます。

<div id="overview">
  ## 概要
</div>

投稿は、X における中心的なコンテンツです。各投稿には次の要素を含めることができます。

* 最大 280 文字のテキスト
* メディアの添付（画像、動画、GIF）
* 投票、場所情報、URL
* 返信、引用、メンション

投稿は作成から 30 分以内であれば最大 5 回まで編集できます。各編集のたびに新しい投稿 ID が生成され、編集履歴は保持されます。

<div id="use-cases">
  ## ユースケース
</div>

* **投稿内容の表示** — アプリケーション内で投稿の詳細を表示する
* **利用可否の確認** — 投稿がまだ存在するか、削除されたかを確認する
* **コンプライアンス管理** — コンプライアンスイベント向けに投稿の変更を追跡する
* **分析** — 特定の投稿のエンゲージメント指標を取得する

***

<div id="endpoints">
  ## エンドポイント
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id`](/ja/x-api/posts/get-post-by-id) | ID を指定して単一の投稿を取得します |
| GET | [`/2/tweets`](/ja/x-api/posts/get-posts-by-ids) | ID を指定して複数の投稿を取得します（最大 100 件） |
