<div id="comparing-x-apis-post-counts-endpoints">
  ## X API の投稿数エンドポイントを比較する
</div>

v2 の投稿数エンドポイントは、最終的に [enterprise Search API の counts エンドポイント](/ja/x-api/enterprise-gnip-2.0/fundamentals/search-api#counts-requests-post-count) を置き換える予定です。既存のコード、アプリ、ツールで古いバージョンの投稿数エンドポイントを使用していて、新しい X API v2 のエンドポイントへの移行を検討している場合は、本ガイドを参照してください。

***

<div id="recent-post-counts-comparison">
  ## 最近の投稿数の比較
</div>

Post counts エンドポイントのエンタープライズ版では、過去 30 日分、またはフルアーカイブ全体の投稿数を取得できます。そのため、7 日間のみを対象とする v2 の recent Post counts エンドポイントは、上記いずれのエンドポイントの直接的な代替にはなりません。

比較を容易にするため、ここでは v2 の recent Post counts エンドポイントが、エンタープライズの 30 日エンドポイントとどのように比較できるかを確認します。

次の表では、各種 recent Post counts エンドポイントを比較します。

| **説明** | **エンタープライズ** | **X API v2** |
| :--- | :--- | :--- |
| ホストドメイン | https://gnip-api.x.com | https://api.x.com |
| エンドポイントパス | /search/30day/accounts/:account&#95;name/:label/counts.json | /2/tweets/counts/recent |
| [認証](/ja/resources/fundamentals/authentication) | ベーシック認証 | OAuth 2.0 Bearer Token |
| タイムスタンプ形式 | YYYYMMDDhhmm | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |
| 取得対象となる投稿の最大経過期間 | 31 日 | 7 日 |
| サポートされる HTTP メソッド | GET | GET |
| 既定のリクエストレート制限 | 1 秒あたり 20 リクエスト（検索データとカウントリクエストの合算）  <br />1 分あたりのレート制限は、契約書に記載されたとおりパートナーごとに異なります。 | 15 分あたりユーザーごとに 180 リクエスト  <br />15 分あたり App ごとに 450 リクエスト |
| [annotations](/ja/x-api/fundamentals/post-annotations) を使用したフィルタリングをサポート |     | ✔   |
| [conversation&#95;id](/ja/x-api/fundamentals/conversation-id) を使用したフィルタリングをサポート |     | ✔   |
| 投稿の data 配列の JSON キー名 | results | data |
| 時間粒度 | 日、時間、分 | 日、時間、分 |
| タイムゾーン | UTC | UTC |
| 期間を指定するためのリクエストパラメータ | fromDate  <br />toDate | start&#95;time  <br />end&#95;time |
| 投稿 ID によるページングのためのリクエストパラメータ |     | since&#95;id  <br />until&#95;id |
| [Project](/ja/resources/fundamentals/developer-apps) に関連付けられた [開発者用 App](/ja/resources/fundamentals/developer-apps) の認証情報が必要 |     | ✔   |

<div id="filtering-operator-comparison">
  ### フィルタリング演算子の比較
</div>

2つの異なるバージョン（Enterprise と v2）の投稿数エンドポイントでは、利用可能な演算子が異なり、さらに各バージョン内でも演算子の利用レベルが異なります。以下で説明します。

Enterprise

* Enterprise 演算子に下位レベルはありません。すべての Enterprise 演算子は、すべての Enterprise ユーザーが利用できます。

X API v2

* **Core:** これらの演算子は、すべての v2 ユーザーが利用できます。
* **Advanced:** これらの演算子は、Academic Research アクセスが承認されたユーザーのみが利用できます。

各演算子セットの詳細は、それぞれのガイドで確認できます。

* [Enterprise operators](/ja/x-api/enterprise-gnip-2.0/fundamentals/search-api#building-search-queries)
* [X API v2 operators](/ja/x-api/posts/search/integrate/build-a-query)

X API v2 内のこれらの異なる演算子レベルが分かったところで、投稿数における演算子の利用可否を示す表を以下に示します（セルが空欄の場合、その演算子は利用できません）。
