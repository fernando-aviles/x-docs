<div id="comparing-x-apis-post-counts-endpoints">
  ## X API の投稿数エンドポイントの比較
</div>

v2 の投稿数エンドポイントは、最終的に [enterprise Search API の counts エンドポイント](/ja/x-api/enterprise-gnip-2.0/fundamentals/search-api#counts-requests-post-count) に取って代わる予定です。既存のコード、アプリ、またはツールで旧バージョンの投稿数エンドポイントを使用していて、新しい X API v2 エンドポイントへの移行を検討している場合は、このガイドを参照してください。

***

<div id="recent-post-counts-comparison">
  ## 直近の投稿数の比較
</div>

投稿数エンドポイントのエンタープライズ版では、30 日分または全アーカイブからのカウントを取得できます。そのため、7 日間を対象とする v2 recent Post counts エンドポイントは、前述のいずれのエンドポイントの直接的な代替にはなりません。

ただし、比較を容易にするために、ここでは v2 recent Post counts エンドポイントがエンタープライズの 30 日エンドポイントとどのように比較できるかを見ていきます。

次の表は、さまざまな recent Post counts エンドポイントの種類を比較したものです。

| **説明** | **Enterprise** | **X API v2** |
| :--- | :--- | :--- |
| ホストドメイン | https://gnip-api.x.com | https://api.x.com |
| エンドポイントパス | /search/30day/accounts/:account&#95;name/:label/counts.json | /2/tweets/counts/recent |
| [認証](/ja/resources/fundamentals/authentication) | Basic 認証 | OAuth 2.0 Bearer Token |
| タイムスタンプ形式 | YYYYMMDDhhmm | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |
| 対象となる投稿の最大経過日数 | 31 日 | 7 日 |
| サポートされる HTTP メソッド | GET | GET |
| デフォルトのリクエストレート制限 | 1 秒あたり 20 リクエスト（検索 data とカウントリクエストを合算）  <br />1 分あたりのレート制限は、契約で規定されているとおりパートナーごとに異なります。 | 15 分あたり 1 ユーザーにつき 180 リクエスト  <br />15 分あたり 1 App につき 450 リクエスト |
| [annotations](/ja/x-api/fundamentals/post-annotations) を利用したフィルタリングのサポート |     | ✔   |
| [conversation&#95;id](/ja/x-api/fundamentals/conversation-id) を利用したフィルタリングのサポート |     | ✔   |
| 投稿の data 配列の JSON キー名 | results | data |
| 時間粒度 | 日、時、または分 | 日、時、または分 |
| タイムゾーン | UTC | UTC |
| 期間を選択するためのリクエストパラメータ | fromDate  <br />toDate | start&#95;time  <br />end&#95;time |
| 投稿 ID でナビゲートするためのリクエストパラメータ |     | since&#95;id  <br />until&#95;id |
| [Project](/ja/resources/fundamentals/developer-apps) に関連付けられた [開発者用 App](/ja/resources/fundamentals/developer-apps) の認証情報の使用が必要 |     | ✔   |

<div id="filtering-operator-comparison">
  ### フィルタリングオペレーターの比較
</div>

投稿数の Enterprise 版と v2 版では、利用できるオペレーターが異なり、それぞれのバージョン内でもオペレーターの利用レベルが異なります。これらについて以下で説明します。

Enterprise

* Enterprise オペレーターにサブレベルはありません。すべての Enterprise オペレーターは、すべての Enterprise ユーザーが利用できます。

X API v2

* **Core:** これらのオペレーターは、すべての v2 ユーザーが利用できます。
* **Advanced:** これらのオペレーターは、Academic Research アクセスが承認されたユーザーのみが利用できます。

それぞれのオペレーターセットの詳細については、次のガイドを参照してください。

* [Enterprise operators](/ja/x-api/enterprise-gnip-2.0/fundamentals/search-api#building-search-queries)
* [X API v2 operators](/ja/x-api/posts/search/integrate/build-a-query)
