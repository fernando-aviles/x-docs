<div id="manage-replies-in-realtime">
  ### リアルタイムで返信を管理する
</div>

hide replies エンドポイントを使うと、無関係である可能性が非常に高い返信をユーザーが非表示にできるようにするワークフローを構築できます。

有用なアプリは、多くの場合、複数の技術を組み合わせてユーザーに価値を提供します。このページでは、[Perspective API](https://www.perspectiveapi.com/) を使って返信を非表示にする方法を説明します。この API は、Google 内の組織である [Jigsaw](https://jigsaw.google.com/) によって、有害なコメントを検出するように訓練された人工知能です。アプリケーションロジックは次のように動作します。

1.  ユーザーの投稿を読み取り、その返信を非表示または再表示するための許可をユーザーから取得します。
2.  [Account Activity API](https://developer.x.com/en/docs/x-api/v1/accounts-and-users/subscribe-account-activity/overview) を使って、受信した返信を検出します。
3.  Perspective API に対して、「スコア」（0 から 1 の数値）を要求します。これは、そのアルゴリズムが、コメントを過去に見た有害なコメントとどの程度似ていると判断しているかを示す確信度です（Perspective はサービスに送信されたテキストを保存しません）。
4.  アルゴリズムのスコアが非常に高い場合に、返信を非表示にするよう hide replies を呼び出します。

<div id="strive-for-transparency">
  #### 透明性を心がける
</div>

Perspective は実際の投稿データで学習されていないため、特定の言語のニュアンスによっては、ユーザーが非表示にしたくない返信をこのアプリが非表示にしてしまう場合があります。どのようなテクノロジーやアプローチを用いてアプリを設計する場合でも、常に可能な限りの配慮を払い、アプリが何を非表示にしているのかをユーザーが理解し、自分で変更できるようにしてください。

* 最も望ましいのは、常にユーザーを信頼し、判断の主導権を完全にユーザーに委ねることです。つまり、ユーザー体験には、アプリがユーザーに代わって行った操作を取り消すためのコントロールを必ず含めるべきです。
* 人工知能を使用する場合、投稿を検出して非表示にする際には、非常に高い信頼度のしきい値を使用するようアプリを設計してください。
* すべての人が同じ言葉を使うわけではないため、アプリはどのようなバイアスも回避できるように設計する必要があります。当事者が再定義して肯定的に使っている言葉やスラングが、誤検知につながる可能性に注意してください。
* 人工知能をトレーニングする場合は、X で日常的に使われる言葉に近い言語使用を反映したモデルの採用を検討してください。
