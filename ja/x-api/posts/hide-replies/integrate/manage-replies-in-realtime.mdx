<div id="manage-replies-in-realtime">
  ### リアルタイムで返信を管理する
</div>

hide replies エンドポイントを使用すると、無関係である可能性が非常に高い返信をユーザーが非表示にできるようにするワークフローを構築できます。

有用なアプリケーションは、ユーザーにとって価値あるものにするために、しばしば複数の技術を組み合わせます。このページでは、[Perspective API](https://www.perspectiveapi.com/) を使用して返信を非表示にする方法を紹介します。この API は、Google 内部の組織である [Jigsaw](https://jigsaw.google.com/) によってトレーニングされた人工知能で、有害なコメントを検出します。アプリケーションロジックは次のように動作します。

1.  ユーザーの投稿を読み取り、その返信を非表示または再表示するための許可をユーザーに求めます。
2.  [Account Activity API](https://developer.x.com/en/docs/x-api/v1/accounts-and-users/subscribe-account-activity/overview) を使用して、受信した返信を検出します。
3.  Perspective API に対して、「スコア」（0〜1 の数値）の提供を依頼します。これは、そのアルゴリズムが、あるコメントを過去に見た有害なコメントと類似しているとどの程度確信しているかを示します。（Perspective はサービスに送信されたテキストを保存しません）。
4.  アルゴリズムのスコアが非常に高い場合は、hide replies エンドポイントを呼び出します。

<div id="strive-for-transparency">
  #### 透明性を心がける
</div>

Perspective は実際の投稿で学習されていないため、特定の言語表現の微妙な違いによって、ユーザーが非表示にしたくない返信をこのアプリが非表示にしてしまう場合があります。アプリの設計にどのような技術や手法を用いる場合でも、常に最善を尽くして、アプリが何を非表示にしたのかをユーザーが理解し、自分で変更できるようにしてください。

* 最も望ましいのは、常にユーザーを信頼し、判断の主導権をユーザーに完全に委ねることです。つまり、ユーザー体験には、アプリがユーザーの代理で実行したあらゆる操作を元に戻せるコントロールを含める必要があります。
* 人工知能を利用する場合、アプリは投稿を検知して非表示にする際に、非常に高い信頼度のしきい値を使用するべきです。
* 誰もが同じ言葉を使うわけではないため、アプリはあらゆるバイアスを避けるよう設計する必要があります。本来差別的だったがあえて肯定的に使い直されている言葉やスラングが、誤検知（false positive）につながる可能性があることに注意してください。
* 人工知能を学習させる場合は、X 上で頻繁に使用される言語をできるだけ反映したモデルの採用を検討してください。
