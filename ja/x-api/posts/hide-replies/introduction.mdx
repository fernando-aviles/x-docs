Hide Replies エンドポイントでは、認証済みユーザー本人が作成した投稿への返信を非表示または再表示できます。非表示にした返信には引き続きアクセスできますが、表示するには追加のクリックが必要になります。

<div id="endpoint">
  ## エンドポイント
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| PUT | [`/2/tweets/:tweet_id/hidden`](/ja/x-api/posts/hide-reply) | 返信を非表示または非表示を解除する |

***

<div id="how-it-works">
  ## 動作の仕組み
</div>

返信を非表示にするには `hidden: true` を、再表示するには `hidden: false` を指定して PUT リクエストを送信します。

```json
{
  "hidden": true
}
```

***

<div id="example-hide-a-reply">
  ## 例：返信を非表示にする
</div>

```bash
curl -X PUT "https://api.x.com/2/tweets/1234567890/hidden" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"hidden": true}'
```

<div id="example-response">
  ## レスポンス例
</div>

```json
{
  "data": {
    "hidden": true
  }
}
```
