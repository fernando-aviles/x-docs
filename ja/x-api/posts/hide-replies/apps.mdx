  ## 返信非表示エンドポイントを利用しているアプリ
</div>

ここでは、返信非表示エンドポイントを統合した開発者によって構築された注目すべきアプリを紹介します。自分たちのテクノロジーと X API を組み合わせることで、すべてのユーザーがパブリックな会話をより良いものにできる、有用な体験を生み出しました。

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge は返信非表示機能を統合することで、企業が自社の X フィードをクリーンで読みやすい状態に保てるようにしています。返信は手動で非表示にできるほか、担当者は Clarabridge のテキスト分析を利用して、不適切な表現やブランドポリシーに反する表現を自動的に検出することもできます。

[ウェブサイトへ ▸](https://www.clarabridge.com/ "ウェブサイトへ ▸")

[X 上の Clarabridge](https://x.com/Clarabridge "X 上の Clarabridge")

![Perspective API template app](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Perspective API テンプレートアプリ**

Perspective は、Alphabet 傘下の組織である Jigsaw によってトレーニングされた人工知能で、有害なコメントを検出するためのものです。このアプリは、あるユーザーに届く返信を検出し、その返信が過去に Perspective が見てきた有害なコメントにどれだけ近いかを示す「スコア」に基づいて、自動的に返信を非表示にします。これは X が開発したオープンソースのテンプレートアプリです。ユーザー向けのツールを構築できるよう、自由にカスタマイズしてご利用ください。

[アプリを使う ▸](https://quintessential-yoke.glitch.me "アプリを使う ▸")

[X 上の Jigsaw](https://x.com/jigsaw "X 上の Jigsaw")

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle は、ビジネスアプリケーションを柔軟なスクリプトで接続するためのプラットフォームです。指定したキーワードを含む返信を検出して非表示にする統合スクリプトを構築しています。試す前に、Hide replies が有効になっているアプリがあることを確認し、リポジトリ内の手順に従ってください。

[アプリへ ▸](https://github.com/reshufflehq/reshuffle "アプリへ ▸")

[X 上の Reshuffle](https://x.com/reshufflehq "X 上の Reshuffle")

![Hide unwanted replies](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 396 397%22%3E%3C/svg%3E)

**Hide unwanted replies**

人気アプリ QuotedReplies の開発者である Dara Oladosu は、彼が定義したいくつかの条件を満たす返信を自動的に非表示にするアプリを構築しました。これには、過去に彼がミュートしてきた特定のキーワードを含む返信など、攻撃的な行動を示す可能性が高いと判断される返信が含まれます。

[アプリへ ▸](https://hideunwantedreplies.com/ "アプリへ ▸")

[X 上の Dara Oladosu](https://x.com/dara_tobi "X 上の Dara Oladosu")

![Pandaflow](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 94 94%22%3E%3C/svg%3E)

**Pandaflow**

Pandaflow は、ワークフローを自動化するノーコードプラットフォームです。ユーザーが定義したカスタムフローに基づいて、プログラムで返信を非表示にできるよう、このエンドポイントを統合しています。
