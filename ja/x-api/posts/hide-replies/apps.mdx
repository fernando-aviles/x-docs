  ## 返信を非表示にするエンドポイントを利用しているアプリ
</div>

こちらは、返信を非表示にするエンドポイントを統合した開発者によって構築された、注目すべきアプリの一覧です。これらのアプリは自分たちの技術と X API を組み合わせることで、すべてのユーザーがパブリックな会話をより良いものにできるよう支援する有用な体験を生み出しています。

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge は返信を非表示にする機能を統合し、企業が自社の X フィードをクリーンで読みやすい状態に保てるようにしています。返信は手動で非表示にできるほか、担当者は Clarabridge のテキスト分析を使って、不適切な表現やブランドポリシーに沿わない表現を自動的に検出することもできます。

[Web サイトへ ▸](https://www.clarabridge.com/ "Web サイトへ ▸")

[X 上の Clarabridge](https://x.com/Clarabridge "X 上の Clarabridge")

![Perspective API テンプレートアプリ](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Perspective API テンプレートアプリ**

Perspective は、Jigsaw（Alphabet 傘下の組織）によってトレーニングされた人工知能で、有害なコメントを検出します。このアプリは、ユーザーに届く返信を検出し、Perspective がそのコメントを過去に見た有害なコメントとどの程度類似しているかを示す「スコア」に基づいて、返信を自動的に非表示にします。これは X によって開発されたオープンソースのテンプレートアプリです。ユーザー向けのツールを構築できるよう、ニーズに合わせてカスタマイズしてご利用ください。

[アプリを使う ▸](https://quintessential-yoke.glitch.me "アプリを使う ▸")

[X 上の Jigsaw](https://x.com/jigsaw "X 上の Jigsaw")

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle は、ビジネスアプリケーションを柔軟なスクリプトで接続するためのプラットフォームです。このプラットフォームでは、指定したキーワードを含む返信を検出して非表示にする統合スクリプトを構築しています。試す際は、まず Hide replies が有効なアプリを用意し、そのうえでリポジトリ内の手順に従ってください。

[アプリへ ▸](https://github.com/reshufflehq/reshuffle "アプリへ ▸")

[X 上の Reshuffle](https://x.com/reshufflehq "X 上の Reshuffle")

![不要な返信を非表示にする](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 396 397%22%3E%3C/svg%3E)

**不要な返信を非表示にする**

人気アプリ QuotedReplies の開発者である Dara Oladosu は、彼自身が定めた条件に合致し、攻撃的な行動をとる可能性が高いと判断される返信を自動的に非表示にするアプリを開発しました。これには、過去に彼がミュートした特定のキーワードを含む返信などが含まれます。

[アプリへ ▸](https://hideunwantedreplies.com/ "アプリへ ▸")

[X 上の Dara Oladosu](https://x.com/dara_tobi "X 上の Dara Oladosu")

![Pandaflow](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 94 94%22%3E%3C/svg%3E)

**Pandaflow**

Pandaflow は、ワークフローを自動化するためのノーコードプラットフォームです。このサービスではエンドポイントを統合し、ユーザーが自分で定義したカスタムフローに基づいて、返信をプログラムで非表示にできるようにしています。

[アプリへ ▸](https://pandaflow.io/ "アプリへ ▸")

[X 上の Pandaflow](https://x.com/pandaflowio "X 上の Pandaflow")
