  ## 返信を非表示にするエンドポイントを利用しているアプリ
</div>

ここでは、返信を非表示にするエンドポイントを統合した開発者によって構築された、注目すべきアプリを紹介します。彼らは自分たちのテクノロジーと X API を組み合わせることで、すべてのユーザーが公開の場での会話をより良くできるよう支援する、有用な体験を生み出しました。

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge は返信を非表示にする機能を統合しており、企業が X のフィードをクリーンで読みやすい状態に保てるようにします。返信は手動で非表示にできるほか、エージェントは Clarabridge のテキスト分析を利用して、ブランドポリシーに反する不適切な言葉やその他の表現を自動的に検出することもできます。

[Web サイトへ ▸](https://www.clarabridge.com/ "Web サイトへ ▸")

[X 上の Clarabridge](https://x.com/Clarabridge "X 上の Clarabridge")

![Perspective API テンプレート App](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Perspective API テンプレート App**

Perspective は、Alphabet 傘下の組織である Jigsaw によって、攻撃的なコメントを検出するために訓練された人工知能です。この App は特定のユーザー宛てに届く返信を検出し、Perspective が過去に見た攻撃的なコメントとどの程度似ているかを示す「スコア」に基づいて、返信を自動的に非表示にします。これは X が開発したオープンソースのテンプレート App です。ユーザー向けツールを構築するためにカスタマイズして利用することを推奨します。

[App を使う ▸](https://quintessential-yoke.glitch.me "App を使う ▸")

[X 上の Jigsaw](https://x.com/jigsaw "X 上の Jigsaw")

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle は、ビジネスアプリケーション同士を柔軟なスクリプトで接続するためのプラットフォームです。彼らは、指定したキーワードを含む返信を検出して非表示にする統合スクリプトを構築しました。試すにはまず、Hide replies 用に有効化された App を持っていることを確認し、リポジトリ内の手順に従ってください。

[App へ移動 ▸](https://github.com/reshufflehq/reshuffle "App へ移動 ▸")

[X 上の Reshuffle](https://x.com/reshufflehq "X 上の Reshuffle")

![不要な返信を隠す](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 396 397%22%3E%3C/svg%3E)

**不要な返信を隠す**

人気 App である QuotedReplies の開発者 Dara Oladosu は、過去にミュートしてきた特定のキーワードを含む返信など、虐待的な行動を示す可能性が高いと自身が判断した条件を満たす返信を自動的に非表示にする App を構築しました。

[App へ移動 ▸](https://hideunwantedreplies.com/ "App へ移動 ▸")

[X 上の Dara Oladosu](https://x.com/dara_tobi "X 上の Dara Oladosu")

![Pandaflow](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 94 94%22%3E%3C/svg%3E)

**Pandaflow**

Pandaflow は、ワークフローを自動化するノーコードプラットフォームです。彼らはエンドポイントを統合し、ユーザーが定義したカスタムフローに基づいて返信をプログラムから非表示にできるようにしています。
