このガイドでは、自分が開始した会話の投稿への返信を非表示にしたり再表示したりする方法を説明します。

<Note>
  **前提条件**

  作業を始める前に、次のものが必要です。

  * 承認済みの App が紐づいた[開発者アカウント](https://developer.x.com/en/portal/petition/essential/basic-info)
  * User Access Token（OAuth 1.0a または OAuth 2.0 PKCE）
</Note>

***

<div id="hide-a-reply">
  ## 返信を非表示にする
</div>

<Steps>
  <Step title="返信の投稿 ID を確認する" icon="message">
    非表示にしたい返信の投稿 ID を取得します。認証済みユーザーが開始した会話への返信のみ非表示にできます。

    ```
    https://x.com/user/status/1232720193182412800
                              └── ここが返信の投稿 ID です
    ```
  </Step>

  <Step title="非表示にするリクエストを送信する" icon="eye-slash">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X PUT "https://api.x.com/2/tweets/1232720193182412800/hidden" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"hidden": true}'
      ```

      ```python Python SDK
      from xdk import Client
      from xdk.oauth1_auth import OAuth1

      oauth1 = OAuth1(
          api_key="YOUR_API_KEY",
          api_secret="YOUR_API_SECRET",
          access_token="YOUR_ACCESS_TOKEN",
          access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
      )

      client = Client(auth=oauth1)

      # Hide a reply
      response = client.posts.hide_reply("1232720193182412800", hidden=True)
      print(f"Hidden: {response.data.hidden}")
      ```

      ```javascript JavaScript SDK
      import { Client, OAuth1 } from "@xdevplatform/xdk";

      const oauth1 = new OAuth1({
        apiKey: "YOUR_API_KEY",
        apiSecret: "YOUR_API_SECRET",
        accessToken: "YOUR_ACCESS_TOKEN",
        accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
      });

      const client = new Client({ oauth1 });

      // Hide a reply
      const response = await client.posts.hideReply("1232720193182412800", {
        hidden: true,
      });
      console.log(`Hidden: ${response.data?.hidden}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="返信が非表示になったことを確認する" icon="check">
    ```json
    {
      "data": {
        "hidden": true
      }
    }
    ```

    返信はメインの会話ビューから非表示になりました。ユーザーは「非表示の返信を表示」をクリックすることで引き続き表示できます。
  </Step>
</Steps>

***

<div id="unhide-a-reply">
  ## 返信の非表示を解除する
</div>

非表示にした返信を再び表示するには、次のようにします。

<CodeGroup dropdown>
  ```bash cURL
  curl -X PUT "https://api.x.com/2/tweets/1232720193182412800/hidden" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"hidden": false}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 返信の非表示を解除する
  response = client.posts.hide_reply("1232720193182412800", hidden=False)
  print(f"Hidden: {response.data.hidden}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 返信の非表示を解除する
  const response = await client.posts.hideReply("1232720193182412800", {
    hidden: false,
  });
  console.log(`Hidden: ${response.data?.hidden}`);
  ```
</CodeGroup>

**レスポンス：**

```json
{
  "data": {
    "hidden": false
  }
}
```

***

<div id="important-notes">
  ## 重要な注意事項
</div>

<Note>
  * 会話の返信を非表示にできるのは、**あなたが開始した**会話に対する返信のみです
  * 非表示にした返信は、「非表示の返信を表示」から引き続き表示できます
  * 返信を非表示にしても、返信を投稿したユーザーには通知されません
</Note>
