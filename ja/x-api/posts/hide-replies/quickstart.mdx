このガイドでは、自分が開始した会話内の投稿への返信を非表示および再表示する方法を説明します。

<Note>
  **前提条件**

  作業を始める前に、次のものが必要です。

  * 承認済みの App を含む [開発者アカウント](https://developer.x.com/en/portal/petition/essential/basic-info)
  * User Access Token (OAuth 1.0a または OAuth 2.0 PKCE)
</Note>

***

<div id="hide-a-reply">
  ## 返信を非表示にする
</div>

<Steps>
  <Step title="返信の投稿IDを見つける" icon="message">
    非表示にしたい返信の投稿IDを取得します。認証済みユーザーが開始した会話への返信のみ非表示にできます。

    ```
    https://x.com/user/status/1232720193182412800
                              └── ここが投稿IDです
    ```
  </Step>

  <Step title="非表示リクエストを送信する" icon="eye-slash">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X PUT "https://api.x.com/2/tweets/1232720193182412800/hidden" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"hidden": true}'
      ```

      ```python Python SDK
      from xdk import Client
      from xdk.oauth1_auth import OAuth1

      oauth1 = OAuth1(
          api_key="YOUR_API_KEY",
          api_secret="YOUR_API_SECRET",
          access_token="YOUR_ACCESS_TOKEN",
          access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
      )

      client = Client(auth=oauth1)

      # 返信を非表示にする
      response = client.posts.hide_reply("1232720193182412800", hidden=True)
      print(f"Hidden: {response.data.hidden}")
      ```

      ```javascript JavaScript SDK
      import { Client, OAuth1 } from "@xdevplatform/xdk";

      const oauth1 = new OAuth1({
        apiKey: "YOUR_API_KEY",
        apiSecret: "YOUR_API_SECRET",
        accessToken: "YOUR_ACCESS_TOKEN",
        accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
      });

      const client = new Client({ oauth1 });

      // 返信を非表示にする
      const response = await client.posts.hideReply("1232720193182412800", {
        hidden: true,
      });
      console.log(`Hidden: ${response.data?.hidden}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="返信が非表示になっていることを確認する" icon="check">
    ```json
    {
      "data": {
        "hidden": true
      }
    }
    ```

    これで、その返信はメインの会話ビューには表示されなくなります。ユーザーは「非表示の返信を表示」をクリックすることで、引き続きその返信を表示できます。
  </Step>
</Steps>

***

<div id="unhide-a-reply">
  ## 返信を再表示する
</div>

非表示にした返信を再度表示するには、次のようにします。

<CodeGroup dropdown>
  ```bash cURL
  curl -X PUT "https://api.x.com/2/tweets/1232720193182412800/hidden" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"hidden": false}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 返信の非表示を解除する
  response = client.posts.hide_reply("1232720193182412800", hidden=False)
  print(f"Hidden: {response.data.hidden}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 返信の非表示を解除する
  const response = await client.posts.hideReply("1232720193182412800", {
    hidden: false,
  });
  console.log(`Hidden: ${response.data?.hidden}`);
  ```
</CodeGroup>

**レスポンス:**

```json
{
  "data": {
    "hidden": false
  }
}
```

***

<div id="important-notes">
  ## 重要な注意事項
</div>

<Note>
  * 返信を非表示にできるのは、**あなたが開始した**会話の返信のみです
  * 非表示にした返信は、「非表示の返信を表示」から引き続き確認できます
  * 返信が非表示にされても、その返信の投稿者には通知されません
</Note>
