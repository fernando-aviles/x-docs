* 1% サンプリング ストリーム。
* 10% サンプリング ストリーム。一般的に「Decahose」と呼ばれます。

これらは、どちらも大量のデータを配信するため、「volume streams」と呼ばれます。1% ストリームであっても、毎秒数十件もの投稿を配信する可能性があります。これらのストリームを使用すると、トレンドの特定と追跡、全体的な感情のモニタリング、世界的な出来事の監視など、さまざまなことが可能になります。 

これらのストリーミング エンドポイントは、永続的な HTTP GET 接続を通じて [Post objects](/ja/x-api/fundamentals/data-dictionary#tweet) を配信し、[OAuth 2.0 App-Only](/ja/resources/fundamentals/authentication#oauth-2-0) 認証を使用します。Essential アクセスでは、同時に保持できる接続は 1 つです。すべてのアクセスレベルで、接続リクエストは 15 分間に最大 50 回行うことができます。

これらの volume stream エンドポイントでは、投稿の編集に対応しています。これらのエンドポイントは、編集履歴を含む編集済みの投稿を配信し、その中には投稿 ID の配列が含まれます。編集履歴のない投稿の場合、この配列には 1 つの ID のみが格納されます。編集された投稿の場合、この配列には複数の ID が含まれ、編集が行われた順序を反映して昇順に並んでおり、配列の最後の要素が最新バージョンです。投稿編集の仕組みの詳細については、[Post edits fundamentals](/ja/x-api/fundamentals/edit-posts) ページを参照してください。 

*これらの API を使用するには、まず当社のエンタープライズ セールス チームと連絡を取り、アカウントを開設する必要があります。*

<Note>
  **アカウントのセットアップ**

  これらのエンドポイントにアクセスするには、次のものが必要です。

  * 承認済みの [developer account](https://developer.x.com/en/portal/petition/essential/basic-info)。
  * [Project](/ja/resources/fundamentals/developer-apps) 内にある [developer App](/ja/resources/fundamentals/developer-apps) から発行されるキーとトークンを使用して認証すること。 

  X API v2 のエンドポイントへのアクセス方法の詳細については、[getting started guide](/ja/x-api/getting-started/getting-access) を参照してください。
</Note>
