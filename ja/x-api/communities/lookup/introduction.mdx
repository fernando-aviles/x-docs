Communities ルックアップエンドポイントを使用すると、ID を指定して X Communities の情報を取得できます。

<div id="overview">
  ## 概要
</div>

Community は、X 上でメンバーが投稿を共有し、トピックについて議論し、共通の関心事を通じてつながることができる公開または非公開のグループです。

***

<div id="endpoint">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/communities/:id`](/ja/x-api/communities/get-community-by-id) | ID でコミュニティを取得 |

***

<div id="response-fields">
  ## レスポンスフィールド
</div>

| フィールド | 説明 |
|:------|:------------|
| `id` | コミュニティID |
| `name` | コミュニティ名 |
| `description` | コミュニティの説明 |
| `created_at` | 作成日時 |
| `member_count` | メンバー数 |
| `is_private` | コミュニティが非公開かどうか |

***

<div id="example-request">
  ## リクエストの例
</div>

```bash
curl "https://api.x.com/2/communities/1234567890?\
community.fields=name,description,member_count,created_at" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
