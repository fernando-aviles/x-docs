Communities lookup エンドポイントでは、ID を指定して X Communities の情報を取得できます。

<div id="overview">
  ## 概要
</div>

コミュニティは、X 上にある公開または非公開のグループで、メンバーが投稿を共有したり、トピックについて議論したり、共通の関心事を通じてつながったりできます。

***

<div id="endpoint">
  ## エンドポイント
</div>

| Method | Endpoint | 説明 |
|:-------|:---------|:------------|
| GET | [`/2/communities/:id`](/ja/x-api/communities/get-community-by-id) | ID でコミュニティを取得する |

***

<div id="response-fields">
  ## レスポンスフィールド
</div>

| Field | 説明 |
|:------|:------------|
| `id` | コミュニティID |
| `name` | コミュニティ名 |
| `description` | コミュニティの説明 |
| `created_at` | 作成日時 |
| `member_count` | メンバー数 |
| `is_private` | コミュニティが非公開かどうか |

***

<div id="example-request">
  ## リクエスト例
</div>

```bash
curl "https://api.x.com/2/communities/1234567890?\
community.fields=name,description,member_count,created_at" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
