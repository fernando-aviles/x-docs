Communities Search エンドポイントを使用すると、キーワードでコミュニティを検索できます。興味のあるトピックに関するコミュニティを見つけることができます。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="キーワード検索" icon="magnifying-glass">
    コミュニティを名前や説明で検索
  </Card>

  <Card title="コミュニティを見つける" icon="users-rectangle">
    参加するコミュニティを見つける
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/communities/search`](/ja/x-api/communities/search-communities) | コミュニティを検索 |

***

<div id="parameters">
  ## パラメータ
</div>

| パラメータ | 説明 |
|:----------|:------------|
| `query` | 検索クエリ（必須） |
| `max_results` | 1 ページあたりの結果数（最大 100） |
| `community.fields` | 追加の Community フィールド |

***

<div id="example-request">
  ## リクエストの例
</div>

```bash
curl "https://api.x.com/2/communities/search?\
query=Python&\
max_results=10&\
community.fields=name,description,member_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
