公式 SDK、コミュニティライブラリ、開発者ツールを利用して、開発をより効率的に進めましょう。

***

<div id="official-sdks">
  ## 公式 SDK
</div>

X では、X API v2 を完全にサポートする TypeScript と Python 向けの公式 SDK を提供しています。

<CardGroup cols={2}>
  <Card title="Python SDK" icon="python" href="/ja/xdks/python/overview">
    非同期処理への対応、型ヒント、自動トークン更新機能を備えています。データ分析や自動化に最適です。
  </Card>

  <Card title="TypeScript SDK" icon="js" href="/ja/xdks/typescript/overview">
    完全な型安全性と ESM のサポートを提供します。Node.js や最新のバンドラーで動作します。
  </Card>
</CardGroup>

<div id="building-a-library">
  ## ライブラリを作成しましたか？
</div>

X API 向けのライブラリを作成した場合は、ぜひコミュニティと共有してください。

1. [Libraries &amp; SDKs フォーラム](https://devcommunity.x.com/c/libraries-and-sdks/63) に投稿する
2. このページに掲載される場合があります。

README で提供している [バージョンバッジ](https://twbadges.glitch.me/) を使用して、API 互換性を示してください。
