X API v2 はデフォルトで最小限のデータのみを返します。各オブジェクトタイプに対して追加データをリクエストするには、**fields パラメーター**を使用します。

***

<div id="how-fields-work">
  ## フィールドの仕組み
</div>

デフォルトでは、投稿を取得した場合に返されるのは `id`、`text`、`edit_history_tweet_ids` のみです。より多くのデータを取得するには、リクエストにフィールドパラメータを追加します。

```bash
# デフォルトレスポンス - 最小限のフィールド
curl "https://api.x.com/2/tweets/1234567890" \
  -H "Authorization: Bearer $TOKEN"

# With additional fields
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=created_at,public_metrics,author_id" \
  -H "Authorization: Bearer $TOKEN"
```

***

<div id="available-field-parameters">
  ## 利用可能なフィールドパラメータ
</div>

各オブジェクトタイプごとに対応するフィールドパラメータがあります。

| オブジェクト | パラメータ | ドキュメント |
|:-------|:----------|:--------------|
| 投稿 (Tweet) | `tweet.fields` | [投稿フィールド](/ja/x-api/fundamentals/data-dictionary#tweet) |
| ユーザー | `user.fields` | [ユーザーフィールド](/ja/x-api/fundamentals/data-dictionary#user) |
| メディア | `media.fields` | [メディアフィールド](/ja/x-api/fundamentals/data-dictionary#media) |
| 投票 | `poll.fields` | [投票フィールド](/ja/x-api/fundamentals/data-dictionary#poll) |
| 場所 | `place.fields` | [場所フィールド](/ja/x-api/fundamentals/data-dictionary#place) |

***

<div id="example-post-fields">
  ## 例: 投稿フィールド
</div>

`tweet.fields` を使用して、特定の投稿のフィールドをリクエストします:

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=created_at,public_metrics,lang" \
  -H "Authorization: Bearer $TOKEN"
```

レスポンス:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "edit_history_tweet_ids": ["1234567890"],
    "created_at": "2024-01-15T12:00:00.000Z",
    "lang": "en",
    "public_metrics": {
      "retweet_count": 10,
      "reply_count": 5,
      "like_count": 100,
      "quote_count": 2
    }
  }
}
```

***

<div id="example-user-fields">
  ## 例: ユーザーフィールド
</div>

`user.fields` パラメーターを使って、特定のユーザーフィールドをリクエストします:

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers?user.fields=created_at,description,public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

レスポンス：

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "The voice of the X Developer Platform",
    "public_metrics": {
      "followers_count": 570842,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```

<div id="fields-for-related-objects">
  ## 関連オブジェクトのフィールド
</div>

関連オブジェクト（たとえば投稿の作成者）のフィールドを取得するには、次の 2 つが必要です。

1. 関連オブジェクトを含めるための **expansion**
2. そのオブジェクトタイプ用の **fields パラメーター**

```bash
# 投稿と投稿者の詳細を取得
curl "https://api.x.com/2/tweets/1234567890?expansions=author_id&user.fields=description,public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

レスポンス：

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "author_id": "2244994945"
  },
  "includes": {
    "users": [{
      "id": "2244994945",
      "name": "X Developers",
      "username": "xdevelopers",
      "description": "The voice of the X Developer Platform",
      "public_metrics": {
        "followers_count": 570842,
        "following_count": 2048
      }
    }]
  }
}
```

[展開（expansions）についてさらに詳しく学ぶ →](/ja/x-api/fundamentals/expansions)

<div id="important-notes">
  ## 重要な注意事項
</div>

<Warning>
  **サブフィールドを個別にリクエストすることはできません。** `public_metrics` をリクエストすると、すべてのメトリクス（いいね、Repost、返信、引用）が返されます。`public_metrics.like_count` だけをリクエストすることはできません。
</Warning>

* レスポンス内のフィールドの順序は、リクエスト時の順序と異なる場合があります
* レスポンスに含まれていないフィールドは、その値が `null` または空であることを意味します
* 一部のフィールドは特定の認証が必要です（例：プライベートメトリクスにはユーザーコンテキストが必要）
* 各エンドポイントのAPIリファレンスを確認して、利用可能なフィールドを確認してください
