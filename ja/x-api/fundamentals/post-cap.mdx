X API v2 は **従量課金制** の料金モデルを採用しています。課金は、アプリケーションごとに計測される実際の API 利用量に基づいて行われます。

***

<div id="how-billing-works">
  ## 課金の仕組み
</div>

| 概念 | 説明 |
|:--------|:------------|
| **クレジット制** | 事前にクレジットを購入し、API の利用に応じて差し引かれます |
| **リクエストごとの課金** | エンドポイントごとに料金が異なります |
| **リアルタイムトラッキング** | Developer Console で利用状況をリアルタイムに確認できます |
| **上限なし** | 月間の利用上限はなく、必要なだけ利用できます |

<div id="deduplication">
  ## 重複排除
</div>

<Note>
  **1 日単位の重複排除**: 同じ投稿が 1 日のうちに複数のクエリから返された場合でも、請求上は 1 回分としてのみカウントされます。
</Note>

これは次のような意味です:

* 同じ投稿を 1 日のうちに複数回取得する = 課金は 1 回
* 翌日に同じ投稿を再取得する = 課金が 1 回追加
* 同じリクエスト内での異なる投稿 = それぞれ個別にカウント

<div id="pricing-details">
  ## 料金の詳細
</div>

エンドポイントおよびオペレーションごとの最新の料金については、[Developer Console](https://console.x.com) を参照してください。

料金は次の条件によって異なる場合があります。

* エンドポイントのタイプ（search / lookup / stream）
* オペレーション（read / write）
* データの対象範囲（recent / full-archive）

<div id="faqs">
  ## FAQ
</div>

<Accordion title="クレジットを使い切った場合はどうなりますか？">
  クレジットを追加購入するまで、API リクエストはエラーになります。中断を防ぐために、残高アラートを設定してください。
</Accordion>

<Accordion title="毎月の最低利用料はありますか？">
  いいえ。ご利用分のみお支払いいただきます。利用量も費用もゼロの月があって構いません。
</Accordion>

<Accordion title="ストリーミングはどのように課金されますか？">
  日次の重複排除を行ったうえで、Filtered Stream を通じて配信される一意の各投稿が、利用量としてカウントされます。
</Accordion>

<Accordion title="失敗したリクエストもカウントされますか？">
  いいえ。data を含む成功したレスポンスのみが課金対象です。
</Accordion>
