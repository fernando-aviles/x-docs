X API v2 は **従量課金制 (pay-per-usage)** の料金体系を採用しています。請求額は、アプリ単位でトラッキングされる実際の API 利用量に基づいて計算されます。

***

<div id="how-billing-works">
  ## 課金の仕組み
</div>

| 概念 | 説明 |
|:--------|:------------|
| **クレジット制** | 事前にクレジットを購入し、API を利用するたびに消費されます |
| **リクエスト単位の料金** | エンドポイントごとに異なる料金が設定されています |
| **リアルタイムトラッキング** | 開発者コンソールで利用状況をリアルタイムに確認できます |
| **上限なし** | 必要なだけ利用できます — 月間の利用上限はありません |

***

<div id="deduplication">
  ## 重複排除
</div>

<Note>
  **日次の重複排除**: 同じ投稿が 1 日のうちに複数のクエリから返された場合でも、請求上は 1 回分の請求としてのみカウントされます。
</Note>

これは次のことを意味します。

* 同じ投稿を 1 日のうちに複数回取得する = 請求は 1 回分
* 翌日に同じ投稿を再取得する = 追加で 1 回分の請求
* 同一リクエスト内の異なる投稿 = それぞれが個別にカウントされます

<div id="monitoring-usage">
  ## 利用状況の監視
</div>

[開発者コンソール](https://console.x.com)で利用状況を確認できます：

| 指標 | 説明 |
|:-------|:------------|
| **合計利用量** | 課金期間内に取得された投稿数 |
| **エンドポイント別** | エンドポイント種別ごとの内訳 |
| **App 別** | 開発者用 App ごとの利用状況 |
| **コスト追跡** | リアルタイムのコスト計算 |
| **クレジット残高** | 残りの前払いクレジット |

<div id="pricing-details">
  ## 料金の詳細
</div>

各エンドポイントおよび操作ごとの最新の料金については、[開発者コンソール](https://console.x.com)をご確認ください。

料金は次の条件によって異なる場合があります。

* エンドポイントのタイプ（検索 / ルックアップ / ストリーム）
* 操作（読み取り / 書き込み）
* データスコープ（直近 / 全アーカイブ）

<div id="faqs">
  ## よくある質問
</div>

<Accordion title="クレジットを使い切った場合はどうなりますか？">
  クレジットを追加購入するまで、API リクエストはエラーになります。中断を防ぐために残高アラートを設定してください。
</Accordion>

<Accordion title="月額の最低利用料はありますか？">
  いいえ。使用した分だけお支払いください。利用も費用もゼロの月があっても問題ありません。
</Accordion>

<Accordion title="ストリーミングはどのように課金されますか？">
  Filtered Stream を通じて配信される一意の投稿ごとに、日次の重複排除後の件数が利用量としてカウントされます。
</Accordion>

<Accordion title="失敗したリクエストもカウントされますか？">
  いいえ。課金対象となるのは、data を返す成功したレスポンスのみです。
</Accordion>
