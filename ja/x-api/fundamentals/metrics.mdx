X API では、投稿およびメディアに関するエンゲージメント指標を取得できます。任意の認証方法で公開指標にアクセスでき、自身のコンテンツについてはユーザー認証を用いることで非公開指標にもアクセスできます。

***

<div id="metric-types">
  ## メトリクスタイプ
</div>

| タイプ | 認証 | 説明 |
|:-----|:---------------|:------------|
| **公開** | Bearer Token | 誰でも閲覧できるメトリクス（いいね、リポスト、返信） |
| **非公開** | ユーザーコンテキスト | 非公開のメトリクス（インプレッション、クリック） |
| **オーガニック** | ユーザーコンテキスト | プロモーションしていない表示から得られるメトリクス |
| **プロモーション** | ユーザーコンテキスト | 広告表示から得られるメトリクス |

<Note>
  **30 日間の制限**: 非公開、オーガニック、およびプロモーションのメトリクスは、過去 30 日以内に作成された投稿に対してのみ利用できます。
</Note>

***

<div id="available-metrics">
  ## 利用可能な指標
</div>

<div id="post-metrics">
  ### 投稿指標
</div>

| 指標 | タイプ | フィールドパス |
|:-------|:-----|:-----------|
| リポスト | 公開 | `public_metrics.retweet_count` |
| 引用 | 公開 | `public_metrics.quote_count` |
| いいね | 公開 | `public_metrics.like_count` |
| 返信 | 公開 | `public_metrics.reply_count` |
| インプレッション | 非公開 | `non_public_metrics.impression_count` |
| URL クリック数 | 非公開 | `non_public_metrics.url_link_clicks` |
| プロフィールクリック数 | 非公開 | `non_public_metrics.user_profile_clicks` |

<div id="media-metrics-videos">
  ### メディアメトリクス（動画）
</div>

| 指標 | タイプ | フィールドパス |
|:-------|:-----|:-----------|
| 視聴回数 | 公開 | `public_metrics.view_count` |
| 再生 0% | 非公開 | `non_public_metrics.playback_0_count` |
| 再生 25% | 非公開 | `non_public_metrics.playback_25_count` |
| 再生 50% | 非公開 | `non_public_metrics.playback_50_count` |
| 再生 75% | 非公開 | `non_public_metrics.playback_75_count` |
| 再生 100% | 非公開 | `non_public_metrics.playback_100_count` |

<div id="requesting-metrics">
  ## メトリクスのリクエスト
</div>

<div id="public-metrics-any-auth">
  ### 公開メトリクス（任意の認証）
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

レスポンス:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "public_metrics": {
      "retweet_count": 50,
      "reply_count": 12,
      "like_count": 234,
      "quote_count": 5
    }
  }
}
```

<div id="private-metrics-user-context">
  ### プライベートメトリクス（ユーザーコンテキスト）
</div>

あなたが所有する投稿に対しては、ユーザーコンテキストでの OAuth 1.0a または OAuth 2.0 が必要です：

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=non_public_metrics,organic_metrics" \
  -H "Authorization: OAuth oauth_consumer_key=...,oauth_token=..."
```

レスポンス:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "non_public_metrics": {
      "impression_count": 5432,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    },
    "organic_metrics": {
      "impression_count": 5432,
      "like_count": 234,
      "reply_count": 12,
      "retweet_count": 50,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    }
  }
}
```

<div id="video-metrics">
  ## 動画メトリクス
</div>

動画再生メトリクスには、`media` エクスパンションを使用します。

```bash
curl "https://api.x.com/2/tweets/1234567890?\
tweet.fields=attachments&\
expansions=attachments.media_keys&\
media.fields=public_metrics,non_public_metrics" \
  -H "Authorization: OAuth ..."
```

レスポンス:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Check out this video!",
    "attachments": {
      "media_keys": ["13_9876543210"]
    }
  },
  "includes": {
    "media": [{
      "media_key": "13_9876543210",
      "type": "video",
      "public_metrics": {
        "view_count": 12543
      },
      "non_public_metrics": {
        "playback_0_count": 12543,
        "playback_25_count": 9876,
        "playback_50_count": 7654,
        "playback_75_count": 5432,
        "playback_100_count": 3210
      }
    }]
  }
}
```

<div id="organic-vs-promoted-metrics">
  ## オーガニック指標とプロモーション指標
</div>

投稿が広告としてプロモーションされた場合、指標はオーガニック分とプロモーション分に分かれます:

| Context      | Description           |
| :----------- | :-------------------- |
| **Organic**  | 通常のタイムライン表示からの指標      |
| **Promoted** | 有料広告インプレッションからの指標     |
| **Public**   | 合計値（オーガニック + プロモーション） |

内訳を確認するには、両方の指標をリクエストしてください:

```bash
tweet.fields=public_metrics,organic_metrics,promoted_metrics
```

<div id="metric-definitions">
  ## メトリクスの定義
</div>

<Accordion title="インプレッション">
  投稿がユーザーの画面に表示された回数。ユニーク数ではなく、同じユーザーが2回閲覧した場合は2インプレッションとしてカウントされます。
</Accordion>

<Accordion title="リポスト数">
  リポスト（Repost／リツイート）の回数。引用投稿は含みません。
</Accordion>

<Accordion title="引用数">
  引用投稿（コメント付きリポスト）の数。常にオーガニックです。
</Accordion>

<Accordion title="動画再生数">
  その動画を含むすべての投稿を集計した数値。動画が複数の投稿でリポストされていても、すべて合算して1つの総再生数として集計されます。
</Accordion>

<Accordion title="再生クォータイル">
  動画のそれぞれの再生割合まで視聴したユニークユーザー数。離脱率の把握に役立ちます。
</Accordion>

<div id="requirements-summary">
  ## 要件の概要
</div>

| メトリクスフィールド | 必要な認証 |
|:-------------|:-----------------------|
| `public_metrics` | Bearer Token（いずれか） |
| `non_public_metrics` | User context（所有する投稿のみ） |
| `organic_metrics` | User context（所有する投稿のみ） |
| `promoted_metrics` | User context（プロモーションされた投稿のみ） |
