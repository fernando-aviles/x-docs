X 上のすべての返信は、会話スレッドに属します。`conversation_id` フィールドを使用すると、会話ツリー全体を識別し、追跡して再構築できます。

***

<div id="how-it-works">
  ## 動作の仕組み
</div>

誰かが投稿し、他のユーザーが返信すると、すべての返信には、会話を開始した元の投稿の ID を示す同じ `conversation_id` が付きます。

```
Original post (ID: 1234567890)  ← conversation_id for all replies
├── Reply 1 (ID: 1234567891)    → conversation_id: 1234567890
│   └── Reply to Reply 1        → conversation_id: 1234567890
└── Reply 2 (ID: 1234567892)    → conversation_id: 1234567890
    └── Reply to Reply 2        → conversation_id: 1234567890
```

スレッドがどれだけ深くなっても、すべての投稿は同じ `conversation_id` を持ちます。

***

<div id="requesting-conversation_id">
  ## conversation_id をリクエストする
</div>

`tweet.fields` に `conversation_id` を追加します。

```bash
curl "https://api.x.com/2/tweets/1234567891?tweet.fields=conversation_id,in_reply_to_user_id,referenced_tweets" \
  -H "Authorization: Bearer $TOKEN"
```

レスポンス:

```json
{
  "data": {
    "id": "1234567891",
    "text": "@user Great point!",
    "conversation_id": "1234567890",
    "in_reply_to_user_id": "2244994945",
    "referenced_tweets": [{
      "type": "replied_to",
      "id": "1234567890"
    }]
  }
}
```

***

<div id="getting-a-full-conversation">
  ## 会話全体を取得する
</div>

スレッド内のすべての投稿を取得するには、検索演算子として `conversation_id` を使用します。

```bash
curl "https://api.x.com/2/tweets/search/recent?\
query=conversation_id:1234567890&\
tweet.fields=author_id,created_at,in_reply_to_user_id&\
expansions=author_id" \
  -H "Authorization: Bearer $TOKEN"
```

元の投稿へのすべての返信を逆時系列で返します。

<div id="use-cases">
  ## ユースケース
</div>

<Tabs>
  <Tab title="スレッド再構築">
    会話ツリー全体を再構築します:

    ```python
    import requests

    conversation_id = "1234567890"
    url = f"https://api.x.com/2/tweets/search/recent"
    params = {
        "query": f"conversation_id:{conversation_id}",
        "tweet.fields": "author_id,in_reply_to_user_id,referenced_tweets,created_at",
        "max_results": 100
    }

    response = requests.get(url, headers=headers, params=params)
    replies = response.json()["data"]

    # 返信を created_at でソートして時系列順に並べる
    replies.sort(key=lambda x: x["created_at"])
    ```
  </Tab>

  <Tab title="会話モニタリング">
    特定の会話への返信をリアルタイムでストリームします:

    ```bash
    # 会話用のフィルタ済みストリームルールを追加
    curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{"add": [{"value": "conversation_id:1234567890"}]}'
    ```
  </Tab>

  <Tab title="会話分析">
    会話内の返信数を集計します:

    ```bash
    curl "https://api.x.com/2/tweets/counts/recent?\
    query=conversation_id:1234567890" \
      -H "Authorization: Bearer $TOKEN"
    ```
  </Tab>
</Tabs>

<div id="related-fields">
  ## 関連フィールド
</div>

| Field | Description |
|:------|:------------|
| `conversation_id` | スレッドを開始した元の投稿のID |
| `in_reply_to_user_id` | 返信先の投稿のユーザーID |
| `referenced_tweets` | `type: "replied_to"` と親投稿のIDを含む配列 |

<div id="notes">
  ## 注意事項
</div>

* 元の投稿の `conversation_id` は、その投稿自身の `id` と同じです
* `conversation_id` は、投稿を返すすべての v2 エンドポイントで利用できます
* 会話をリアルタイムで監視するには、[filtered stream](/ja/x-api/posts/filtered-stream/introduction) と組み合わせて使用してください
* 大規模なスレッドを扱う場合は、[pagination](/ja/x-api/fundamentals/pagination) と組み合わせて使用してください
