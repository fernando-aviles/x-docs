注釈は、投稿の内容に関するセマンティックなメタデータを提供します。X は投稿を解析し、エンティティ（人物、場所、製品）やコンテキスト（トピック、ドメイン）を特定して、コンテンツを理解したりフィルタリングしたりするのに役立てます。

---

<div id="annotation-types">
  ## アノテーションの種類
</div>

<div id="entity-annotations">
  ### エンティティ注釈
</div>

固有表現認識（NER）は、投稿テキスト内での特定のエンティティの出現箇所を特定します。

| タイプ | 例 |
|:-----|:---------|
| **Person** | Barack Obama, Elon Musk |
| **Place** | San Francisco, Japan |
| **Product** | iPhone, ChatGPT |
| **Organization** | NASA, Google |
| **Other** | Super Bowl, Diabetes |

エンティティ注釈には、信頼度スコアとテキスト内での位置情報が含まれます。

<div id="context-annotations">
  ### コンテキスト注釈
</div>

投稿をトピックとドメインごとに分類するセマンティック解析：

- **Domain**: 大まかなカテゴリ（スポーツ、エンターテインメント、テクノロジー）
- **Entity**: ドメイン内の特定のトピック（NBA、マーベル映画、AI）

コンテキスト注釈を使用すると、キーワードに依存せずに投稿をフィルタリングおよび分類できます。

---

<div id="requesting-annotations">
  ## 注釈をリクエストする
</div>

`tweet.fields` に `context_annotations` と `entities` を追加します：

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=context_annotations,entities" \
  -H "Authorization: Bearer $TOKEN"
```

***

```json

    "entities": {

      ]

    "context_annotations": [
      {
        "domain": {
          "id": "86",

          "description": "映画"

        }
      },
      {
        "domain": {
          "id": "65",
          "name": "Interests and Hobbies Vertical"
        },
        "entity": {
          "id": "781974596752842752",
          "name": "Entertainment"
        }
      }
    ]
  }
}
```

<div id="entity-annotation-fields">
  ## エンティティ注釈フィールド
</div>

| フィールド | 説明 |
|:------|:------------|
| `start` | テキスト内の開始位置 |
| `end` | テキスト内の終了位置 |
| `probability` | 信頼度スコア (0〜1) |
| `type` | エンティティのタイプ (Person、Place など) |
| `normalized_text` | 正規化されたエンティティ名 |

<div id="using-annotations-in-filters">
  ## フィルターでアノテーションを利用する
</div>

<div id="search-and-filtered-stream">
  ### 検索とフィルタ済みストリーム
</div>

コンテキストアノテーションのエンティティ ID で投稿をフィルタリングします：

```bash
# 特定のエンティティに関する投稿
context:86.1234567890

# Posts in a specific domain
context:86.*
```


<div id="practical-examples">
  ### 実践的な例
</div>

```bash
# Posts about the NBA
query=context:26.852137520

# Apple製品に関する投稿
query=context:47.10026792024

# Posts about movies
query=context:86.*
```

<div id="important-notes">
  ## 重要な注意事項
</div>

<Warning>
**すべての投稿にアノテーションが付与されているわけではありません。** アノテーションの付与範囲は次の要因に依存します:
- 対応している言語
- X のタクソノミーにおけるトピックの網羅状況
- 投稿テキストの意味的な豊かさ（意味情報の密度）
</Warning>

- アノテーションは過去にさかのぼって適用されることはなく、エンティティが追跡され始めた時点以降にのみ付与されます
- 同じエンティティが複数のドメインに属する場合があります（例: 有名人は Person であり Actor でもある）
- エンティティ ID はドメインをまたいでも変わりません
