Expansions を使用すると、関連オブジェクトを 1 回の API レスポンスでまとめて取得できます。複数のリクエストを送信する代わりに、1 回の呼び出しで投稿とその投稿者、メディア、または参照先の投稿を取得できます。

***

<div id="how-expansions-work">
  ## 展開の仕組み
</div>

expansions を指定してリクエストすると、API はレスポンスの `includes` セクションに完全なオブジェクトをインクルードして返します。

```bash
curl "https://api.x.com/2/tweets/1234567890?expansions=author_id" \
  -H "Authorization: Bearer $TOKEN"
```

レスポンス：

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "author_id": "2244994945"
  },
  "includes": {
    "users": [{
      "id": "2244994945",
      "name": "X Developers",
      "username": "xdevelopers"
    }]
  }
}
```

`data` 内の `author_id` は、`includes` 内のユーザーオブジェクトを参照します。

***

<div id="post-expansions">
  ## 投稿の展開
</div>

| 展開 | 戻り値 | ユースケース |
|:----------|:--------|:---------|
| `author_id` | User オブジェクト | 投稿の作成者の詳細を取得 |
| `referenced_tweets.id` | Post オブジェクト（複数） | 引用元/返信先の投稿を取得 |
| `referenced_tweets.id.author_id` | User オブジェクト（複数） | 参照されている投稿の作成者を取得 |
| `in_reply_to_user_id` | User オブジェクト | 返信先のユーザーを取得 |
| `attachments.media_keys` | Media オブジェクト（複数） | 画像・動画・GIF を取得 |
| `attachments.poll_ids` | Poll オブジェクト | 投票の選択肢と投票数を取得 |
| `geo.place_id` | Place オブジェクト | 位置情報の詳細を取得 |
| `entities.mentions.username` | User オブジェクト（複数） | メンションされているユーザーを取得 |
| `edit_history_tweet_ids` | Post オブジェクト（複数） | 編集された投稿の以前のバージョンを取得 |

<div id="combining-with-fields">
  ## フィールドとの組み合わせ
</div>

Expansions は、各オブジェクトのデフォルトのフィールドを返します。追加のフィールドも取得したい場合は、Expansions とフィールドパラメータを組み合わせて指定します。

```bash
curl "https://api.x.com/2/tweets/1234567890?\
expansions=author_id,attachments.media_keys&\
user.fields=description,public_metrics&\
media.fields=url,alt_text" \
  -H "Authorization: Bearer $TOKEN"
```

レスポンス：

```json
{
  "data": {
    "id": "1234567890",
    "text": "Check out this image!",
    "author_id": "2244994945",
    "attachments": {
      "media_keys": ["3_1234567890"]
    }
  },
  "includes": {
    "users": [{
      "id": "2244994945",
      "name": "X Developers",
      "username": "xdevelopers",
      "description": "The voice of the X Developer Platform",
      "public_metrics": {
        "followers_count": 570842
      }
    }],
    "media": [{
      "media_key": "3_1234567890",
      "type": "photo",
      "url": "https://pbs.twimg.com/media/example.jpg",
      "alt_text": "Example image"
    }]
  }
}
```

<div id="multiple-expansions">
  ## 複数の展開
</div>

複数の展開を、カンマ区切りのリストとして指定します：

```bash
expansions=author_id,referenced_tweets.id,attachments.media_keys
```

<div id="common-patterns">
  ## 一般的なパターン
</div>

<Tabs>
  <Tab title="投稿のコンテキスト全体">
    Get a post with author, media, and referenced posts:
    1 つの投稿と、その投稿の作成者、メディア、および参照されている投稿を取得します：

    ```bash
    expansions=author_id,attachments.media_keys,referenced_tweets.id
    tweet.fields=created_at,public_metrics,conversation_id
    user.fields=username,name,profile_image_url
    media.fields=url,preview_image_url,type
    ```
  </Tab>

  <Tab title="会話スレッド">
    Get replies with their authors:
    返信とそれぞれの作成者を取得します：

    ```bash
    expansions=author_id,in_reply_to_user_id,referenced_tweets.id
    tweet.fields=conversation_id,in_reply_to_user_id,created_at
    user.fields=username,name
    ```
  </Tab>

  <Tab title="固定された投稿があるユーザー">
    Get a user profile with their pinned post:
    ユーザーのプロフィールと、そのユーザーが固定している投稿を取得します：

    ```bash
    expansions=pinned_tweet_id
    user.fields=description,public_metrics,verified
    tweet.fields=created_at,public_metrics
    ```
  </Tab>
</Tabs>

<div id="linking-data-and-includes">
  ## data とインクルードの関連付け
</div>

`includes` 内のオブジェクトには位置情報が含まれていません。それらを ID で関連付けてください。

```python
# Python の例
response = api_call()
post = response["data"]
users = {u["id"]: u for u in response["includes"]["users"]}

# 作成者を取得
author = users.get(post["author_id"])
print(f"{author['name']} said: {post['text']}")
```

```javascript
// JavaScript の例
const { data: post, includes } = response;
const users = Object.fromEntries(
  includes.users.map(u => [u.id, u])
);

const author = users[post.author_id];
console.log(`${author.name} said: ${post.text}`);
```
