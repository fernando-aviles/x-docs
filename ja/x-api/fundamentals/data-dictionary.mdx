X API は、投稿、ユーザー、メディアなどを表す構造化された JSON オブジェクトを返します。このリファレンスでは、各オブジェクトタイプで利用可能なすべてのフィールドを網羅的に説明します。

***

  ## クイックナビゲーション
</div>

|:-------|:------------|:-----------------|
| [投稿（ツイート）](#post-tweet) | 投稿、返信、リポスト、引用 | `tweet.fields` |
| [ユーザー](#user) | アカウントプロフィールとメタデータ | `user.fields` |
| [Space](#space) | ライブ音声会話 | `space.fields` |

<Tip>

</Tip>

<div id="post-tweet">
  ## 投稿（ツイート）
</div>

投稿は、X におけるコンテンツの基本単位です。各 Post オブジェクトには、テキスト、メタデータ、および投稿者、メディア、投票などの関連オブジェクトへの参照が含まれます。

**デフォルトフィールド:** `id`, `text`, `edit_history_tweet_ids`

追加のフィールドをリクエストするには `tweet.fields` を使用し、関連オブジェクトを含めるには `expansions` を使用します。

<div id="all-post-fields">
  ### すべての投稿のフィールド
</div>

| フィールド名                                           | タイプ           | 説明                                                                                                         | 用途                                               |
| :----------------------------------------------- | :------------ | :--------------------------------------------------------------------------------------------------------- | :----------------------------------------------- |
| **id (デフォルト)**                                   | string        | 要求された投稿の一意の識別子。                                                                                            | 特定の投稿をプログラムから取得するために使用します。                       |
| **text（デフォルト）**                                  | string        | ツイート本文の UTF-8 テキストです。有効な文字の詳細については [twitter-text](https://github.com/twitter/twitter-text/) を参照してください。     | キーワード抽出や感情分析・分類に利用できます。                          |
| **edit&#95;history&#95;tweet&#95;ids (default)** | object        | 投稿のすべてのバージョンを示す一意の識別子。編集されていない投稿では ID は 1 つだけですが、編集履歴のある投稿では複数の ID があります。                                  | 投稿の編集履歴を取得するために使用します。                            |
| **article**                                      | object        | この投稿に含まれる記事 (Article) のメタデータを保持します。                                                                        | Article のテキストやエンティティを取得するために使用します。               |
| **attachments**                                  | object        | この投稿に含まれる（存在する場合の）添付メディアの種類を示します。                                                                          | 指定した `expansions` で返されるオブジェクトを理解するために使用します。      |
| **author&#95;id**                                | string        | この投稿を作成したユーザーの一意の識別子。                                                                                      | User オブジェクトを取得したり、ピアレビュー用にデータセットを共有したりする際に使用します。 |
| **card&#95;uri**                                 | string        | この投稿に含まれる Card の URI。                                                                                      |                                                  |
| **community&#95;id**                             | string        | この投稿が属している Community の一意の識別子。                                                                              |                                                  |
| **context&#95;annotations**                      | array         | 投稿に対するコンテキスト注釈を保持します。                                                                                      | エンティティ認識／抽出やトピック分析に利用できます。                       |
| **conversation&#95;id**                          | string        | 会話の起点となっている元の投稿の ID（直接の返信およびその返信への返信を含む）。                                                                  | 投稿から会話全体を再構築するために使用します。                          |
| **created&#95;at**                               | 日付 (ISO 8601) | 投稿が作成された日時。                                                                                                | 時系列分析や、投稿がいつ作成されたかを把握するのに有用です。                   |
| **display&#95;text&#95;range**                   | array         | 表示されるテキスト部分の開始インデックスと終了インデックスを含む配列。                                                                        | 長い投稿で、デフォルトでどのテキスト部分が表示されるかを把握するのに有用です。          |
| **edit&#95;controls**                            | object        | 投稿をあとどのくらいの期間編集できるか、および残りの編集回数を示します。                                                                       | 投稿が編集可能かどうかを判断するために使用します。                        |
| **entities**                                     | object        | 投稿本文から解析されたエンティティです。詳細は X Objects の entities を参照してください。                                                    | ハッシュタグ、URL、メンションなどに関する追加情報を提供します。                |
| **geo**                                          | object        | ジオタグが付与された投稿の位置情報または場所を表します。                                                                               | ジオタグ付き投稿の位置情報を取得するために使用されます。                     |
| **in&#95;reply&#95;to&#95;user&#95;id**          | string        | 対象の投稿が返信である場合、このフィールドには元の投稿の作成者の id が入ります。                                                                 | 投稿が別の投稿への返信かどうかを判定するために使用します。                    |
| **lang**                                         | string        | X によって検出された場合の投稿の言語です。                                                                                     | 投稿を話し言葉の言語ごとに分類するために使用します。                       |
| **non&#95;public&#95;metrics**                   | object        | リクエスト時点における、その投稿の非公開エンゲージメント指標です。ユーザーコンテキスト認証が必要です。                                                        | その投稿によって生成されたインプレッションの合計を把握するために使用します。           |
| **note&#95;tweet**                               | object        | 長文投稿（280文字超）の本文全体を含みます。                                                                                    | 投稿の全文を取得するために使用します。                              |
| **organic&#95;metrics**                          | object        | リクエスト時点における、その投稿のオーガニックコンテキストで計測されたエンゲージメント指標です。ユーザーコンテキスト認証が必要です。                                         | 投稿のオーガニックなエンゲージメントを測定するために使用します。                 |
| **possibly&#95;sensitive**                       | boolean       | コンテンツがセンシティブなものとして認識される可能性があるかどうかを示します。                                                                    | 特定のタイプのコンテンツの流通状況を分析するために使用します。                  |
| **promoted&#95;metrics**                         | object        | リクエスト時点における、その投稿のプロモーションコンテキストで計測されたエンゲージメント指標です。ユーザーコンテキスト認証が必要です。                                        | 投稿がプロモーションされた際のエンゲージメントを測定するために使用します。            |
| **public&#95;metrics**                           | object        | リクエスト時点における、その投稿の公開エンゲージメント指標です。                                                                           | 投稿のエンゲージメントを測定するために使用します。                        |
| **referenced&#95;tweets**                        | array         | この投稿が参照している投稿（リツイート、引用投稿、返信など）の一覧です。                                                                       | リツイートなどにおける会話の構造を理解するために使用します。                   |
| **reply&#95;settings**                           | string        | 特定の投稿に誰が返信できるかを示します。値は &quot;everyone&quot;、&quot;mentioned&#95;users&quot;、&quot;followers&quot; のいずれかです。 | 投稿の会話に対する返信設定を判定するために使用します。                      |
| **withheld**                                     | object        | [差し止め対象のコンテンツ](https://help.x.com/en/rules-and-policies/tweet-withheld-by-country)の差し止めに関する詳細を含みます。        |                                                  |
| **scopes**                                       | object        | 投稿の公開範囲に関する詳細を含みます。                                                                                        | 投稿を閲覧できるユーザーを示します。プロモーション投稿でのみ返されます。             |
| **media&#95;metadata**                           | 配列            | ツイートに添付されているメディアのメタデータを含みます。                                                                               | ツイートに添付されたメディアの `alt_text` など、追加のメタデータを取得できます。   |

**Tweet オブジェクトの取得**

**リクエスト例**

次のリクエストでは、[Tweets lookup](/ja/resources/fundamentals/rate-limits) エンドポイントを使用して、対象の Tweet のフィールドをリクエストします。必ず `$BEARER_TOKEN` を、ご自身で生成した [Bearer Token](/ja/resources/fundamentals/authentication) に置き換えてください。

```bash
curl --request GET 'https://api.x.com/2/tweets?ids=1212092628029698048&tweet.fields=attachments,author_id,context_annotations,created_at,entities,geo,id,in_reply_to_user_id,lang,possibly_sensitive,public_metrics,referenced_tweets,text,withheld&expansions=referenced_tweets.id' --header 'Authorization: Bearer $BEARER_TOKEN'
```

<div id="user">
  ### User
</div>

user オブジェクトには、参照されるユーザーを表す Twitter ユーザーアカウントのメタデータが含まれます。user オブジェクトは、[users lookup](/ja/x-api/users/lookup/introduction) エンドポイントで返される主要なオブジェクトです。このエンドポイントで追加のユーザー フィールドをリクエストする場合は、`user.fields` パラメーターを使用します。

user オブジェクトは、子オブジェクトとしてツイート (Tweet) オブジェクト内に含まれ、展開することもできます。オブジェクトは `?expansions=author_id` または `?expansions=in_reply_to_user_id` で展開可能で、デフォルトのフィールドのみを含む簡略化されたオブジェクトを取得できます。オブジェクトを補完するために追加のフィールドをリクエストする場合は、`user.fields` パラメーターを expansions と併用してください。

<div id="space">
  ### Space
</div>

Spaces は、ライブ音声会話を通じて表現と交流を可能にします。Space データ辞書には Space に関する関連メタデータが含まれており、すべての詳細はリアルタイムで更新されます。

User オブジェクトは user リソースで取得および展開できます。これらのオブジェクトは、`expansions` クエリパラメータに `host_ids`、`creator_id`、`speaker_ids`、`mentioned_user_ids` の少なくとも 1 つを追加することで展開用に利用できます。

ツイートと異なり、Space は一時的なもので、終了後、または作成者によってキャンセルされた場合には利用できなくなります。アプリで Spaces のデータを扱う場合は、常に最新の情報を返す責任があり、プラットフォーム上で利用できなくなったデータは削除する必要があります。[Spaces lookup endpoints](/ja/x-api/spaces/lookup/introduction) を使用すると、ユーザーの期待や意図を尊重できていることを確認できます。

</div>

List オブジェクトには、参照されている List を記述する [Twitter Lists](https://help.x.com/en/using-twitter/twitter-lists) のメタデータが含まれます。List オブジェクトは、List ルックアップエンドポイントで返される主要オブジェクトです。このエンドポイントで追加の List フィールドをリクエストする場合は、`list.fields` フィールドパラメータを使用します。

List オブジェクトは、他のデータオブジェクトの子としては現れません。ただし、ユーザーオブジェクトは user リソース内で取得および展開できます。これらのオブジェクトは、`expansions` クエリパラメータに `owner_id` を追加することで展開対象として利用できます。追加のフィールドをリクエストして主要な List オブジェクトを補完する場合はこの展開を `list.fields` フィールドパラメータと共に使用し、展開オブジェクトを補完するには `user.fields` を使用します。

| Field Value        | Type            | Description                                                                                                                       | How it can be used                              |
| :----------------- | :-------------- | :-------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------- |
| id (default)       | string          | この List の一意の識別子。<br />`"id": "2244994945"`                                                                                        | 特定の List についての情報をプログラムから取得するために使用します。           |
| name (default)     | string          | List の作成時に定義された List の名前。<br />`"name": "Twitter Lists"`                                                                          |                                                 |
| created&#95;at     | date (ISO 8601) | List が作成された UTC 日時。<br />`"created_at": "2013-12-14T04:35:55.000Z"`                                                               | List が Twitter 上にどれくらい存在しているかを確認できます。           |
| description        | string          | ユーザーに List について知らせるための簡潔な説明。<br />`"description": "People that are active members of the Bay area cycling community on Twitter."` |                                                 |
| follower&#95;count | integer         | この List をフォローしているユーザー数を示します。<br />`"follower_count": 198`                                                                         |                                                 |
| member&#95;count   | integer         | この List に含まれているメンバー数を示します。<br />`"member_count": 60`                                                                              |                                                 |
| private            | boolean         | List が非公開かどうかを示します。<br />`"private": false`                                                                                       |                                                 |
| owner&#95;id       | string          | この List のオーナーの一意の識別子。<br />`"owner_id": "1255542774432063488"`                                                                    | このユーザーが他に所有している List の特定や、ユーザーオブジェクトの展開に使用できます。 |

<div id="direct-message-events">
  ### ダイレクトメッセージイベント
</div>

ダイレクトメッセージ (DM) の会話はイベントによって構成されます。X API v2 は現在、MessageCreate、ParticipantsJoin、ParticipantsLeave の 3 種類のイベントタイプをサポートしています。

DM イベントオブジェクトは [Direct Message lookup](/ja/x-api/direct-messages/lookup/introduction) エンドポイントから返され、[Manage Direct Messages](/ja/x-api/direct-messages/lookup/introduction) エンドポイントでダイレクトメッセージが正常に作成されると、MessageCreate イベントが生成されます。

DM イベントをリクエストする場合、デフォルトで含まれるイベントオブジェクトの属性 (フィールド) は 3 つあります: id、event&#95;type、text です。追加のイベントフィールドを受け取るには、[fields](/ja/x-api/fundamentals/fields) パラメータ dm&#95;event.fields を使用して、他のフィールドを選択します。利用可能なその他のイベントフィールドには、次のものが含まれます: dm&#95;conversation&#95;id、created&#95;at、sender&#95;id、attachments、participant&#95;ids、referenced&#95;tweets。

これらのフィールドのいくつかは、ダイレクトメッセージイベントに関連する他の X オブジェクトの ID を表します:

* sender&#95;id - メッセージを送信した、またはグループ会話に参加者を招待したアカウントの ID
* partricipants&#95;ids - アカウント ID の配列。ParticipantsJoin および ParticipantsLeave イベントでは、この配列にはイベントを作成したアカウントの単一の ID が含まれます
* attachments - 送信者によって Twitter にアップロードされたコンテンツのメディア ID を表します
* referenced&#95;tweets - text フィールド内でツイート URL が検出された場合、そのツイートの ID がレスポンスに含まれます

sender&#95;id、participant&#95;ids、referenced&#95;tweets.id、および attachments.media&#95;keys の [expansions](/ja/x-api/fundamentals/expansions) を指定することで、これらの Twitter オブジェクト ID を展開できます。

|     |     |     |     |
| :--- | :--- | :--- | :--- |
| **Field value** | **Type** | **Description** | **How it can be used** |
| id (default) | string | イベントの一意の識別子。<br /><br />&quot;id&quot;: &quot;1050118621198921728&quot; | v1.1 のエンドポイントで利用可能な、特定の会話イベントをプログラムで取得するために使用します。 |
| event&#95;type (default) | string | イベントのタイプを示します。現在サポートされているタイプは 3 種類です。<br /><br />* MessageCreate<br />    <br />* ParticipantsJoin<br />    <br />* ParticipantsLeave<br />    <br /><br />&quot;event&#95;type&quot;: &quot;MessageCreate&quot; | 会話の履歴を取得する際に、メッセージがいつ作成されたか、またグループ会話の場合は参加者がいつ参加および退出したかを把握するために使用します。すべての GET メソッドは、event&#95;type= クエリパラメータを使って特定のイベントタイプでのフィルタリングをサポートします。 |
| text (default) | string | ダイレクトメッセージの実際の UTF-8 テキスト。<br /><br />&quot;text&quot;: &quot;Hello, just you!&quot; | チャットボットでは、メッセージ内容を解析して自動応答を判断するために使用できます。会話検索機能を構築する用途にも利用できます。 |
| entities          | object | ダイレクトメッセージ内のテキストから解析されたエンティティ。                                       | ハッシュタグ、URL、メンションなどに関する追加情報を提供します。 |

**ダイレクトメッセージイベントオブジェクトの取得**

**サンプルリクエスト**

この例では、1 対 1 の会話に関連するイベントを取得するリクエストを作成します。このリクエストは、基本的なダイレクトメッセージイベントのフィールドに加えて、参照されているツイートおよびその作成者に関する追加フィールドも返します。次の内容を要求するクエリを作成します。

* 作成時刻やどの会話 (dm&#95;conversation) に属しているかといった、基本的なイベント属性。
* ダイレクトメッセージを送信したアカウントの ID と説明。
* 参照されているツイートのテキストおよびその投稿時刻。
* 参照されているツイート作成者のアカウント ID と説明。

これらの属性を返すために、リクエストクエリには次の内容を含めます。

`?dm_event.fields=id,sender_id,text,created_at,dm_conversation_id&expansions=sender_id,referenced_tweets.id&tweet.fields=created_at,text,author_id&user.fields=description`

```bash
      curl --request GET 'https://api.x.com/2/dm_conversations/with/:participant_id/dm_events?tweet.fields=created_at,text,author_id&user.fields=description&expansions=sender_id,participant_ids,referenced_tweets.id&dm_event.fields=id,sender_id,text,participant_ids,created_at,'
    --header 'Authorization: Bearer $BEARER_TOKEN'
```

必ず $BEARER&#95;TOKEN を自分で生成した [Bearer Token](/ja/resources/fundamentals/authentication#using-and-generating-an-app-only-bearer-token) に置き換えてください。

<div id="community">
  ### Community

コミュニティは、X ユーザーがつながり、情報を共有し、最も関心のある議論により深く関与するための専用スペースです。

<div id="how-to-use-fields-and-expansions">
  ## フィールドと展開（expansions）の使い方
</div>

デフォルトでは、[fields](/ja/x-api/fundamentals/fields) や [expansions](/ja/x-api/fundamentals/expansions) パラメータを使用せずにリクエストを行うと、X API v2 の data オブジェクトには、少数のデフォルトフィールドのみが含まれます。このガイドでは、レスポンス内で追加のオブジェクトとフィールドを受け取るために、リクエストで `fields` および `expansions` クエリパラメータをどのように使用するかを説明します。

このガイドでは、次のツイートのスクリーンショットに含まれる、いくつかのフィールドをリクエストする例を見ていきます。
 

![この画像には、@X が投稿したツイートのスクリーンショットが含まれています。ツイート本文、ユーザー名、投稿日時、ソース、公開メトリクスが表示されています。動画も含まれています。](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/ScreenShotDataDictionaryGuide.png.twimg.1920.png)

スクリーンショットで分かるように、このツイートには、ツイートの投稿者、ツイートのメトリクス、作成時刻、動画、および動画の再生回数など、複数の情報が表示されています。また、スクリーンショット上には表示されていないものの、依然としてリクエスト可能なデータもいくつか存在します。 

API にリクエストを行うと、デフォルトのレスポンスはシンプルで、デフォルトのツイートフィールド（`id` と `text`）のみが含まれます。また、利用しているエンドポイントから返されるのはプライマリオブジェクトのみであり、そのプライマリオブジェクトに関連する可能性のある data オブジェクトは返されません。

このシンプルさと、fields パラメータおよび expansions パラメータを組み合わせることで、ユースケースに応じて必要なフィールドだけをリクエストできるようになります。

   attachments、author&#95;id、created&#95;at、public&#95;metrics。
