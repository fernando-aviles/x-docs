API レスポンスに一度に返せる数を超える結果が含まれている場合は、ページネーションを使ってすべてのページのデータを取得できます。

***

<div id="how-pagination-works">
  ## ページネーションの仕組み
</div>

1. 最初のリクエストで `max_results` パラメータを指定する
2. レスポンスの `meta` オブジェクト内に `next_token` が含まれているか確認する
3. 含まれている場合は、そのトークンを `pagination_token` パラメータとして指定して次のリクエストを送信する
4. `next_token` が返されなくなるまで繰り返す

```bash
# Initial request
curl "https://api.x.com/2/users/12345/tweets?max_results=100" \
  -H "Authorization: Bearer $TOKEN"

# レスポンスにnext_tokenが含まれます
# {"data": [...], "meta": {"next_token": "abc123", ...}}

# Next page
curl "https://api.x.com/2/users/12345/tweets?max_results=100&pagination_token=abc123" \
  -H "Authorization: Bearer $TOKEN"
```

***

<div id="pagination-tokens">
  ## ページネーショントークン
</div>

| Token | Description |
|:------|:------------|
| `next_token` | レスポンスの `meta` フィールドに含まれます。次のページを取得するために使用します。 |
| `previous_token` | レスポンスの `meta` フィールドに含まれます。前のページを取得するために使用します。 |
| `pagination_token` | リクエストパラメータです。`next_token` または `previous_token` の値を指定します。 |

***

<div id="response-structure">
  ## レスポンス構造
</div>

```json
{
  "data": [
    {"id": "1234", "text": "..."},
    {"id": "1235", "text": "..."}
  ],
  "meta": {
    "result_count": 100,
    "next_token": "7140w9gefhslx3",
    "previous_token": "77qp89slxjd"
  }
}
```

結果がこれ以上ない場合、`next_token` は返されません。

```json
{
  "data": [...],
  "meta": {
    "result_count": 42,
    "previous_token": "77qp89abc"
  }
}
```

***

<div id="pagination-parameters">
  ## ページネーション用パラメータ
</div>

| Parameter | Description | Default |
|:----------|:------------|:--------|
| `max_results` | 1ページあたりの結果数 | エンドポイントごとに異なる |
| `pagination_token` | 前のレスポンスで返されたトークン | なし |

各エンドポイントのAPIリファレンスで、`max_results` の上限値を確認してください。

***

<div id="example-paginating-through-all-results">
  ## 例: すべての結果をページングして取得する
</div>

<Tabs>
  <Tab title="Python">
    ```python
    import requests

    def get_all_tweets(user_id, bearer_token):
        url = f"https://api.x.com/2/users/{user_id}/tweets"
        headers = {"Authorization": f"Bearer {bearer_token}"}
        params = {"max_results": 100}
        
        all_tweets = []
        
        while True:
            response = requests.get(url, headers=headers, params=params)
            data = response.json()
            
            if "data" in data:
                all_tweets.extend(data["data"])
            
            # 次のページがあるか確認
            next_token = data.get("meta", {}).get("next_token")
            if not next_token:
                break
                
            params["pagination_token"] = next_token
        
        return all_tweets
    ```
  </Tab>

  <Tab title="JavaScript">
    ```javascript
    async function getAllTweets(userId, bearerToken) {
      const url = `https://api.x.com/2/users/${userId}/tweets`;
      const headers = { Authorization: `Bearer ${bearerToken}` };
      
      let allTweets = [];
      let paginationToken = null;
      
      do {
        const params = new URLSearchParams({ max_results: 100 });
        if (paginationToken) {
          params.set("pagination_token", paginationToken);
        }
        
        const response = await fetch(`${url}?${params}`, { headers });
        const data = await response.json();
        
        if (data.data) {
          allTweets.push(...data.data);
        }
        
        paginationToken = data.meta?.next_token;
      } while (paginationToken);
      
      return allTweets;
    }
    ```
  </Tab>
</Tabs>

<div id="best-practices">
  ## ベストプラクティス
</div>

<CardGroup cols={2}>
  <Card title="max_results を活用する" icon="arrow-up-1-9">
    API 呼び出し回数を最小限に抑えるために、許可されている最大の `max_results` を指定します。
  </Card>

  <Card title="部分ページを処理する" icon="square-check">
    最後のページには、`max_results` より少ない結果しか含まれない場合があります。
  </Card>

  <Card title="トークンを保存する" icon="database">
    後でページネーションを再開する必要がある場合に備えて、`next_token` を保存しておきます。
  </Card>

  <Card title="ページネーションでポーリングしない" icon="clock">
    新しいデータを取得する場合は、繰り返しページネーションする代わりに `since_id` を使用します。
  </Card>
</CardGroup>

***

<div id="result-ordering">
  ## 結果の並び順
</div>

結果は**逆時系列順**で返されます。

* 最初のページの最初の結果 = 最も新しい結果
* 最後のページの最後の結果 = 最も古い結果

この並び順は、ページ内およびページ間の両方に適用されます。

***

<div id="notes">
  ## 注意事項
</div>

* ページネーション用トークンは不透明な文字列型です。トークンの内容を解析したり、変更したりしないでください
* トークンは一定時間後に期限切れになる場合があります
* 取得した結果数が `max_results` より少なくても、さらに結果が存在する可能性があります（`next_token` が返ってこなくなるまで継続してください）
* 自動ページネーション処理には [SDKs](/ja/x-api/tools-and-libraries/sdks) を使用してください
