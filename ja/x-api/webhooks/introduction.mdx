<div id="how-webhooks-work">
  ## Webhook の仕組み
</div>

```
┌──────────┐      ┌──────────┐      ┌──────────┐
│ X Event  │  →   │ X Server │  →   │ Your     │
│ Occurs   │      │          │      │ Webhook  │
└──────────┘      └──────────┘      └──────────┘
```

1. **イベント発生** — ユーザーが投稿やDMを行う
2. **X がリクエスト送信** — webhook URL に POST リクエストを送信
3. **サーバーで処理** — サーバー側でイベントを処理
4. **200 応答** — 受信確認として HTTP 200 OK を返す

***

<div id="webhook-requirements">
  ## Webhook の要件
</div>

| 要件 | 説明 |
|:------------|:------------|
| **HTTPS** | Webhook URL は HTTPS を使用する必要があります |
| **Public** | URL はインターネットから公開アクセス可能である必要があります |
| **Fast response** | 10 秒以内にレスポンスを返す必要があります |
| **200 OK** | 受信を確認するためにステータスコード 200 を返す必要があります |

<div id="challenge-response-check-crc">
  ### チャレンジレスポンスチェック (CRC)
</div>

X は CRC リクエストを送信して、webhook を検証します。HMAC-SHA256 ハッシュで応答してください。

```python
import hmac
import hashlib
import base64

def handle_crc(crc_token, consumer_secret):
    sha256_hash = hmac.new(
        consumer_secret.encode(),
        crc_token.encode(),
        hashlib.sha256
    ).digest()
    
    return {
        "response_token": "sha256=" + base64.b64encode(sha256_hash).decode()
    }
```

<div id="signature-verification">
  ### シグネチャ検証
</div>

`x-twitter-webhooks-signature` ヘッダーを使用して、webhook リクエストの正当性を検証します。
