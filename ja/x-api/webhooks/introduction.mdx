Webhook を使用すると、data をリアルタイムにサーバーへ配信できます。更新をポーリングするのではなく、イベントが発生したタイミングで data を受け取ることができます。

<div id="how-webhooks-work">
  ## Webhook の仕組み
</div>

```
┌──────────┐      ┌──────────┐      ┌──────────┐
│ X Event  │  →   │ X Server │  →   │ Your     │
│ Occurs   │      │          │      │ Webhook  │
└──────────┘      └──────────┘      └──────────┘
```

1. **イベント発生** — ユーザーが投稿したり、DM を送信したりする
2. **X がリクエスト送信** — あなたの webhook URL に POST リクエストを送信
3. **処理を実行** — あなたのサーバーがイベントを処理する
4. **200 を返す** — 受信確認として 200 OK を返す

***

<div id="webhook-requirements">
  ## Webhook の要件
</div>

| 要件 | 説明 |
|:------------|:------------|
| **HTTPS** | Webhook URL は HTTPS を使用する必要があります |
| **Public** | URL は公開され、インターネットからアクセス可能である必要があります |
| **Fast response** | 10 秒以内にレスポンスを返す必要があります |
| **200 OK** | 受信確認としてステータスコード 200 を返す必要があります |

<div id="challenge-response-check-crc">
  ### チャレンジ-レスポンスチェック（CRC）
</div>

X は CRC リクエストを送信してあなたの webhook を検証します。HMAC-SHA256 ハッシュで応答してください。

```python
import hmac
import hashlib
import base64

def handle_crc(crc_token, consumer_secret):
    sha256_hash = hmac.new(
        consumer_secret.encode(),
        crc_token.encode(),
        hashlib.sha256
    ).digest()
    
    return {
        "response_token": "sha256=" + base64.b64encode(sha256_hash).decode()
    }
```

</div>
