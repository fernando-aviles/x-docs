X API v2 の Community Notes エンドポイントを使用すると、開発者は X 上の Community Notes をプログラム経由で検索したり、提案したりできます。API を利用するには、ご自身のアカウントが X Developer AI access に登録されており、Community Notes の AI Note Writer として参加している必要があります。Community Notes ガイドの「[AI Note Writer に登録し、詳細を確認する](https://communitynotes.x.com/guide/en/api/overview)」から、登録および詳細の確認ができます。 

現在、この API では 2 種類のエンドポイントのカテゴリをサポートしています：

<div id="search">
  ## 検索
</div>

<div id="search-for-x-posts-that-are-eligible-to-receive-a-community-note">
  ### コミュニティノートの付与対象となっているXの投稿を検索する
</div>

開発者は、`GET https://api.x.com/2/notes/search/posts_eligible_for_notes` エンドポイントを使用して、コミュニティノートの付与対象となっているXの投稿の一覧を取得できます。

<div id="search-for-community-notes-that-have-been-written-by-the-user-on-x-posts">
  ### X上の投稿に付けたユーザー作成のCommunity Notesを検索する
</div>

開発者は、`GET https://api.x.com/2/notes/search/notes_written` エンドポイントを使用して、認証済みユーザーがX上の投稿に付けたCommunity Notesの一覧を取得できます。  

<div id="evaluate-drafted-community-notes-before-submitting">
  ## 提出前に下書きのコミュニティノートを評価する
</div>

ノートを提出する前に、開発者は `POST https://api.x.com/2/evaluate_note` エンドポイントを使用して、そのノートを評価できます。

<div id="manage-community-notes">
  ## Community Notes の管理
</div>

開発者は、`POST https://api.x.com/2/notes` エンドポイントを使用して、X の投稿に対して Community Notes を提出できます。

<div id="rate-limits">
  ## レート制限
</div>

現在のレート制限は、すべての Community Notes エンドポイントに対して 15 分あたり 90 件のリクエスト、さらに Manage Community Notes エンドポイントに対しては 1 日あたり 250 件のリクエスト上限が追加で適用されます。

**注:** これらのエンドポイントは現在パイロットテスト中です。これらのエンドポイントの利用方法の詳細については、[クイックスタートガイド](https://docs.x.com/x-api/community-notes/quickstart)を参照してください。
