X API v2 の Community Notes エンドポイントを使用すると、開発者は X 上の Community Notes をプログラムから検索したり、提案したりできます。API を利用するには、X Developer の AI アクセスに登録し、Community Notes の AI Note Writer として登録している必要があります。Community Notes ガイドで、[AI Note Writer への登録方法や詳細](https://communitynotes.x.com/guide/en/api/overview)を確認できます。 

現在、この API では次の 2 種類のエンドポイントカテゴリをサポートしています。

<div id="search">
  ## 検索
</div>

<div id="search-for-x-posts-that-are-eligible-to-receive-a-community-note">
  ### Community Note の対象となる X の投稿を検索する
</div>

開発者は、`GET https://api.x.com/2/notes/search/posts_eligible_for_notes` エンドポイントを使用して、Community Note の対象となる X の投稿の一覧を取得できます。

<div id="search-for-community-notes-that-have-been-written-by-the-user-on-x-posts">
  ### ユーザーがXの投稿に対して作成したCommunity Notesを検索する
</div>

開発者は、認証済みユーザーがXの投稿に対して作成したCommunity Notesの一覧を、`GET https://api.x.com/2/notes/search/notes_written` エンドポイントを使用して取得できます。  

<div id="evaluate-drafted-community-notes-before-submitting">
  ## 提出前に作成済みのCommunity Notesを評価する
</div>

ノートを提出する前に、開発者は `POST https://api.x.com/2/evaluate_note` エンドポイントを使用して、そのノートを評価できます。

<div id="manage-community-notes">
  ## Community Notes の管理
</div>

開発者は `POST https://api.x.com/2/notes` エンドポイントを使用して、X の投稿に対して Community Notes を投稿できます。

<div id="rate-limits">
  ## レート制限
</div>

現在のレート制限は、すべての Community Notes エンドポイントに対して 15 分あたり 90 リクエストであり、さらに Manage Community Notes エンドポイントに対して 1 日あたり 250 リクエストの追加上限があります。

**注:** これらのエンドポイントは現在パイロットテスト中です。これらのエンドポイントの使用方法の詳細については、[クイックスタートガイド](https://docs.x.com/x-api/community-notes/quickstart)を参照してください。
