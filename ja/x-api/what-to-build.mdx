X API は、モデレーション、アナリティクス、コミュニティ作りなど、さまざまな分野での可能性を広げます。ここでは、次のプロジェクトのヒントとなるアイデアをいくつか紹介します。

***

<div id="build-for-safety-moderation">
  ## 安全性とモデレーションのために開発する
</div>

X 上で、より健全な会話が生まれるよう支援しましょう。

<CardGroup cols={2}>
  <Card title="モデレーションツール" icon="shield">
    ユーザーが返信を管理し、コンテンツをフィルターし、快適な利用体験を守れるようにするツールを構築しましょう。
  </Card>

  <Card title="嫌がらせ対策" icon="ban">
    攻撃的・嫌がらせ的なコンテンツを検出してフラグ付けし、一括ブロック用のツールを提供しましょう。
  </Card>
</CardGroup>

**関連エンドポイント:**

* [Blocks](/ja/x-api/users/blocks/introduction) — ユーザーのブロックとブロック解除
* [Mutes](/ja/x-api/users/mutes/introduction) — アカウントとキーワードのミュート
* [Hide replies](/ja/x-api/posts/hide-replies/introduction) — 不要な返信を非表示にする
* [Manage posts](/ja/x-api/posts/manage-tweets/introduction) — 返信設定を制御する

<div id="getting-started">
  ## はじめに
</div>

さあ、始めましょう。進め方は次のとおりです。

<Steps>
  <Step title="アクセス権を取得">
    [開発者アカウントに登録](/ja/x-api/getting-started/getting-access)し、アプリを作成します。
  </Step>

  <Step title="基本を学ぶ">
    [最初のリクエストを送信](/ja/x-api/getting-started/make-your-first-request)して、API を使ってみましょう。
  </Step>

  <Step title="ツールを選ぶ">
    使用する言語向けの [SDK またはライブラリ](/ja/x-api/tools-and-libraries/overview) を選択します。
  </Step>

  <Step title="開発して公開する">
    小さく始めて、改善を重ね、構築したものを共有しましょう。
  </Step>
</Steps>
