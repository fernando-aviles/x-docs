X API は、モデレーション、アナリティクス、コミュニティ構築など、さまざまな可能性を広げます。次のプロジェクトのヒントとなるアイデアをいくつか紹介します。

***

<div id="build-for-safety-moderation">
  ## セーフティとモデレーションのための機能を構築する
</div>

X 上で、より健全な会話が生まれるよう支援しましょう。

<CardGroup cols={2}>
  <Card title="モデレーションツール" icon="shield">
    ユーザーが返信を管理し、コンテンツをフィルタリングし、快適な利用体験を守れるようにするツールを構築しましょう。
  </Card>

  <Card title="ハラスメント対策" icon="ban">
    攻撃的・嫌がらせコンテンツを検出してフラグを付け、一括ブロックツールを提供しましょう。
  </Card>
</CardGroup>

**関連エンドポイント:**

* [Blocks](/ja/x-api/users/blocks/introduction) — ユーザーをブロック／ブロック解除する
* [Mutes](/ja/x-api/users/mutes/introduction) — アカウントとキーワードをミュートする
* [Hide replies](/ja/x-api/posts/hide-replies/introduction) — 不要な返信を非表示にする
* [Manage posts](/ja/x-api/posts/manage-tweets/introduction) — 返信設定を管理する

<div id="build-for-creators">
  ## クリエイター向けに構築する

<CardGroup cols={2}>

  <Card title="クロスポスティング" icon="share-nodes">
    複数のプラットフォームや形式間でコンテンツを同期できるようにします。
  </Card>

  <Card title="スレッド作成ツール" icon="layer-group">
    ユーザーが長文スレッドを作成して公開できるようにします。
  </Card>

  <Card title="Bot と自動化" icon="robot">
    会話に付加価値をもたらす便利な Bot を作成できるようにします。
  </Card>
</CardGroup>

**関連するエンドポイント:**

* [投稿を管理](/ja/x-api/posts/manage-tweets/introduction) — 投稿を作成および削除します
* [メディアアップロード](/ja/x-api/media/quickstart/media-upload-chunked) — 画像や動画をアップロードします
* [Spaces](/ja/x-api/spaces/lookup/introduction) — 音声会話を発見します

<div id="getting-started">
  ## はじめに
</div>

準備はできましたか？ 次のステップに進みましょう。

<Steps>
  <Step title="アクセス権を取得">
    [開発者アカウントに登録](/ja/x-api/getting-started/getting-access)し、App を作成します。
  </Step>

  <Step title="基本を学ぶ">
    [最初のリクエストを送信](/ja/x-api/getting-started/make-your-first-request)して、API を使ってみましょう。
  </Step>

  <Step title="ツールを選ぶ">
    使用する言語に合った[SDK またはライブラリ](/ja/x-api/tools-and-libraries/overview)を選びます。
  </Step>

  <Step title="開発して公開する">
    小さく始めて改善を重ね、作ったものを共有しましょう。
  </Step>
</Steps>
