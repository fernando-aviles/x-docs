Usage エンドポイントでは、消費した投稿数を含む API の使用状況を監視できます。コストを管理し、上限内に収めるために、使用状況をプログラムから追跡してください。

<div id="overview">
  ## 概要
</div>

<CardGroup cols={2}>
  <Card title="投稿の利用状況" icon="chart-simple">
    消費された投稿数を追跡
  </Card>

  <Card title="日別の内訳" icon="calendar-days">
    日別の利用状況を表示
  </Card>

  <Card title="アプリ単位" icon="gauge">
    アプリ全体の利用状況を監視
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## エンドポイント
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/usage/tweets`](/ja/x-api/usage/get-usage) | 投稿の利用状況データを取得します |

***

<div id="response-data">
  ## レスポンスデータ
</div>

レスポンスには、日別の投稿消費数が含まれます。

```json
{
  "data": {
    "daily_project_usage": [
      {
        "date": "2024-01-15",
        "usage": [
          {
            "app_id": "12345678",
            "tweets_consumed": 15420
          }
        ]
      }
    ],
    "project_id": "1234567890",
    "project_cap": 10000000
  }
}
```

<div id="fields">
  ### フィールド
</div>

| フィールド | 説明 |
|:------|:------------|
| `daily_project_usage` | 日次利用データの配列 |
| `date` | YYYY-MM-DD 形式の日付 |
| `app_id` | 使用している App の ID |
| `tweets_consumed` | その日に消費された投稿数 |
| `project_cap` | 月間の投稿上限数 |
----------------------------

<div id="use-cases">
  ## リクエストの例
</div>

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

***

<div id="getting-started">
  ## ユースケース
</div>

* **コスト監視** — プランの上限に対する利用量を追跡する
* **アラート** — 上限に近づいたときにアラートを設定する
* **最適化** — 利用量の多いエンドポイントを特定する
* **レポート作成** — 利用状況レポートを生成する

<Tip>
  リソースは UTC 基準の 24 時間ウィンドウ内で重複排除されるため、同じリソースを 1 日のうちに複数回リクエストしても、請求は 1 回分としてのみカウントされます。 [料金について詳しく見る →](/ja/x-api/getting-started/pricing)
</Tip>
