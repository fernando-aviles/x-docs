このガイドでは、最初の X API リクエストを行う手順を説明します。開始する前に、[アプリの認証情報を持つ開発者アカウント](/ja/x-api/getting-started/getting-access)が必要です。

***

<div id="quick-start-with-curl">
  ## cURL でクイックスタート
</div>

API をテストする最も手っ取り早い方法は cURL を使うことです。ユーザー情報を取得してみましょう。

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

`$BEARER_TOKEN` を実際の Bearer Token の値に置き換えてください。次のようなレスポンスが返ってきます:

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers"
  }
}
```

***

<div id="step-by-step-guide">
  ## ステップバイステップガイド
</div>

<Steps>
  <Step title="Bearer Token を取得する">
    [開発者コンソール](https://console.x.com)で対象のアプリを開き、Bearer Token をコピーします。
  </Step>

  <Step title="エンドポイントを選択する">
    まずは次の初心者向けエンドポイントのいずれかから始めてください:

    | エンドポイント | 機能 |
    |:---------|:-------------|
    | [User lookup](/ja/x-api/users/lookup/introduction) | ユーザー名または ID でユーザープロフィールを取得 |
    | [Post lookup](/ja/x-api/posts/lookup/introduction) | ID で投稿を取得 |
    | [Recent search](/ja/x-api/posts/search/introduction) | 直近 7 日間の投稿を検索 |
  </Step>

  <Step title="リクエストを送信する">
    cURL、Postman、またはお好みの HTTP クライアントを使用します:

    ```bash
    # ユーザー名でユーザーを検索
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>

  <Step title="レスポンスを解析する">
    レスポンスは JSON 形式です。主要なデータは `data` フィールドに含まれています:

    ```json
    {
      "data": {
        "id": "2244994945",
        "name": "X Developers",
        "username": "xdevelopers"
      }
    }
    ```
  </Step>
</Steps>

***

<div id="request-more-data-with-fields">
  ## fields を指定してより多くのデータをリクエストする
</div>

デフォルトでは、エンドポイントは最小限のフィールドのみを返します。追加のデータを取得するには、`fields` パラメータを使用します。

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers?user.fields=created_at,description,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

レスポンス:

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "X Developer Platformの声",
    "public_metrics": {
      "followers_count": 570842,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```

[フィールドについて詳しく →](/ja/x-api/fundamentals/fields)

<div id="using-code-instead-of-curl">
  ## cURL の代わりにコードを使用する
</div>

<Tabs>
  <Tab title="Python">
    ```python
    import requests

    bearer_token = "YOUR_BEARER_TOKEN"
    url = "https://api.x.com/2/users/by/username/xdevelopers"

    headers = {"Authorization": f"Bearer {bearer_token}"}
    response = requests.get(url, headers=headers)

    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    ```javascript
    const bearerToken = "YOUR_BEARER_TOKEN";
    const url = "https://api.x.com/2/users/by/username/xdevelopers";

    fetch(url, {
      headers: { Authorization: `Bearer ${bearerToken}` }
    })
      .then(res => res.json())
      .then(data => console.log(data));
    ```
  </Tab>

  <Tab title="公式 SDK">
    本番環境での利用には、公式 SDK の使用を推奨します。

    * [Python SDK](/ja/xdks/python/overview)
    * [TypeScript SDK](/ja/xdks/typescript/overview)

    これらの SDK は、認証、ページネーション、レート制限を自動的に処理します。
  </Tab>
</Tabs>

<div id="troubleshooting">
  ## トラブルシューティング
</div>

<Accordion title="401 Unauthorized（認証されていません）">
  * Bearer Token が正しいか確認してください
  * トークンが再発行されていないことを確認してください
  * `Authorization` ヘッダーの形式を確認してください: `Bearer YOUR_TOKEN`
</Accordion>

<Accordion title="403 Forbidden（アクセス拒否）">
  * アプリがこのエンドポイントへアクセスできない可能性があります
  * 一部のエンドポイントでは、ユーザーコンテキストでの認証（OAuth 1.0a または 2.0）が必要です
  * 開発者コンソールでアプリの権限を確認してください
</Accordion>

<Accordion title="429 Too Many Requests（リクエスト過多）">
  * レート制限に達しています
  * 再試行のタイミングを確認するには、`x-rate-limit-reset` ヘッダーを参照してください
  * コード内で指数バックオフを実装してください
</Accordion>
