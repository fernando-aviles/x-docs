このガイドでは、最初の X API リクエストを行う手順を説明します。開始する前に、[アプリ認証情報を持つ開発者アカウント](/ja/x-api/getting-started/getting-access)が必要です。

***

<div id="quick-start-with-curl">
  ## cURL を使ったクイックスタート
</div>

API をテストする最も手っ取り早い方法は、cURL を使うことです。ユーザー情報を取得してみましょう：

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

`$BEARER_TOKEN` を実際の Bearer Token に置き換えてください。次のようなレスポンスが返ってきます:

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers"
  }
}
```

***

<div id="step-by-step-guide">
  ## ステップバイステップガイド
</div>

<Steps>
  <Step title="Bearer Token を取得する">
    [Developer Console](https://console.x.com) で自分のアプリに移動し、Bearer Token をコピーしてください。
  </Step>

  <Step title="エンドポイントを選ぶ">
    まずは、次の初心者向けエンドポイントのいずれかから始めてください。

    | Endpoint | 機能 |
    |:---------|:-------------|
    | [User lookup](/ja/x-api/users/lookup/introduction) | ユーザープロフィールをユーザー名または ID で取得 |
    | [Post lookup](/ja/x-api/posts/lookup/introduction) | 投稿を ID で取得 |
    | [Recent search](/ja/x-api/posts/search/introduction) | 直近 7 日間の投稿を検索 |
  </Step>

  <Step title="リクエストを送信する">
    cURL、Postman、またはお好みの HTTP クライアントを使用してください。

    ```bash
    # ユーザー名でユーザーを取得
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>

  <Step title="レスポンスを解析する">
    レスポンスは JSON 形式です。主要なデータは `data` フィールドに含まれています。

    ```json
    {
      "data": {
        "id": "2244994945",
        "name": "X Developers",
        "username": "xdevelopers"
      }
    }
    ```
  </Step>
</Steps>

<div id="request-more-data-with-fields">
  ## fields を使ってより多くの data をリクエストする
</div>

既定では、エンドポイントは最小限のフィールドのみを返します。追加の data を取得するには、`fields` パラメータを使用します。

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers?user.fields=created_at,description,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

レスポンス:

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "The voice of the X Developer Platform",
    "public_metrics": {
      "followers_count": 570842,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```

[フィールドについてさらに詳しく →](/ja/x-api/fundamentals/fields)

<div id="using-code-instead-of-curl">
  ## cURL の代わりにコードを使用する
</div>

<Tabs>
  <Tab title="Python">
    ```python
    import requests

    bearer_token = "YOUR_BEARER_TOKEN"
    url = "https://api.x.com/2/users/by/username/xdevelopers"

    headers = {"Authorization": f"Bearer {bearer_token}"}
    response = requests.get(url, headers=headers)

    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    ```javascript
    const bearerToken = "YOUR_BEARER_TOKEN";
    const url = "https://api.x.com/2/users/by/username/xdevelopers";

    fetch(url, {
      headers: { Authorization: `Bearer ${bearerToken}` }
    })
      .then(res => res.json())
      .then(data => console.log(data));
    ```
  </Tab>

  <Tab title="公式 SDK">
    本番環境での利用には、公式 SDK を推奨します。

    * [Python SDK](/ja/xdks/python/overview)
    * [TypeScript SDK](/ja/xdks/typescript/overview)

    これらの SDK は、認証、ページネーション、レート制限を自動的に処理します。
  </Tab>
</Tabs>

<div id="troubleshooting">
  ## トラブルシューティング
</div>

<Accordion title="401 Unauthorized（認証エラー）">
  * Bearer Token が正しいことを確認してください
  * トークンが再生成されて無効になっていないか確認してください
  * `Authorization` ヘッダーの形式を確認してください: `Bearer YOUR_TOKEN`
</Accordion>

<Accordion title="403 Forbidden（アクセス禁止）">
  * アプリにこのエンドポイントへのアクセス権がない可能性があります
  * 一部のエンドポイントでは、ユーザーコンテキストでの認証（OAuth 1.0a または 2.0）が必要です
  * Developer Console でアプリの権限を確認してください
</Accordion>

<Accordion title="429 Too Many Requests（リクエスト過多）">
  * レート制限に達しました
  * 再試行できるタイミングを確認するには、`x-rate-limit-reset` ヘッダーを確認してください
  * コード内で指数バックオフを実装してください
</Accordion>
