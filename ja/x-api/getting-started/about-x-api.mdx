X API は、X 上の公開されている会話データへプログラムからアクセスするための手段を提供します。投稿を取得し、トレンドを分析し、連携機能を構築し、プラットフォーム上で新しい体験を創出できます。

***

<div id="what-you-can-do">
  ## できること
</div>

| 機能 | 説明 |
|:-----------|:------------|
| **投稿を読む** | 投稿を検索・取得し、リアルタイムにストリーミングする |
| **コンテンツを公開する** | 投稿、返信、スレッドを作成する |
| **ユーザーを管理する** | ユーザー情報を取得し、フォロー、ブロック、ミュートを管理する |
| **データを分析する** | 各種メトリクスやトレンド、エンゲージメント分析にアクセスする |
| **連携機能を構築する** | DM を送信し、リストを管理し、Spaces と連携する |

***

<div id="api-versions">
  ## API バージョン
</div>

<Tabs>
  <Tab title="X API v2（推奨）">
    X API の現行バージョンで、最新機能と柔軟な料金体系を備えています。

    **v2 を使う理由:**

    * 従量課金制（月額上限なし）
    * モダンな JSON レスポンス形式
    * 柔軟な [フィールド](/ja/x-api/fundamentals/fields) と [展開](/ja/x-api/fundamentals/expansions)
    * 高度な機能: アノテーション、会話の追跡、編集履歴
    * すべての新しいエンドポイントと機能

    **開始手順:**

    1. [console.x.com](https://console.x.com) に登録
    2. アプリを作成し、認証情報を取得
    3. [最初のリクエストを送信する](/ja/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1（レガシー）">
    以前のバージョンの X API です。サポートは限定的なため、新規プロジェクトには v2 を使用してください。

    **引き続き利用可能なもの:**

    * 一部のメディアアップロード用エンドポイント
    * レガシーなストリーミング（非推奨）
    * 一部の特殊なエンドポイント

    **v2 への移行:**
    エンドポイントのマッピングやデータ形式の変更については、[移行ガイド](/ja/x-api/migrate/overview) を参照してください。
  </Tab>

  <Tab title="Enterprise">
    高度なニーズを持つ法人向けの大規模アクセス。

    **機能:**

    * 全量 Firehose へのアクセス
    * 過去データのバックフィル
    * 専任サポート
    * カスタムのレート制限
    * コンプライアンス向けストリーム

    [Enterprise 営業へのお問い合わせ →](/ja/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

<div id="v2-highlights">
  ## v2 のハイライト
</div>

<Accordion title="フィールドと展開">
  必要な data だけをリクエストできます。`fields` パラメータで特定の属性を指定し、`expansions` で関連オブジェクトを含めます。

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [フィールドの詳細 →](/ja/x-api/fundamentals/fields)
</Accordion>

<Accordion title="投稿の注釈">
  投稿には、人、場所、プロダクト、トピックを識別する意味情報付きの注釈が含まれます。ストリームや検索をトピックでフィルタリングできます。

  [注釈の詳細 →](/ja/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="エンゲージメント指標">
  自分の投稿について、公開メトリクス（いいね、Repost、返信）と非公開メトリクス（インプレッション、クリック）にアクセスできます。

  [指標の詳細 →](/ja/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="会話の追跡">
  `conversation_id` を使用して会話スレッド全体を再構成できます。スレッド全体にわたる返信を追跡できます。

  [会話の追跡について詳しく見る →](/ja/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="編集履歴">
  すべての以前のバージョンと編集に関するメタデータを含む、投稿の編集履歴にアクセスできます。

  [投稿の編集について詳しく見る →](/ja/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## 料金
</div>

X API v2 では、**従量課金制**の料金モデルを採用しています。

| 利点 | 説明 |
|:--------|:------------|
| **サブスクリプションなし** | 利用した分だけ支払う |
| **上限なし** | 必要なだけ利用できる |
| **クレジット制** | クレジットを購入し、リクエストごとに消費される |
| **リアルタイム追跡** | 開発者コンソールで利用状況をリアルタイムに監視できる |
| **重複排除** | 同一リソースを24時間以内に2回リクエストしても課金は1回のみ |

[料金の詳細を見る →](/ja/x-api/getting-started/pricing)
