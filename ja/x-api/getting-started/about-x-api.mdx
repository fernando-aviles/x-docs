X API は、X 上の公開されている会話にプログラムからアクセスするための API です。投稿を取得し、トレンドを分析し、連携機能を構築して、このプラットフォーム上で新しいユーザー体験を創出できます。

***

<div id="what-you-can-do">
  ## できること
</div>

| 機能 | 説明 |
|:-----------|:------------|
| **投稿の閲覧** | 投稿を検索・取得し、リアルタイムでストリーミングする |
| **コンテンツの公開** | 投稿、返信、スレッドを作成する |
| **ユーザーの管理** | ユーザーを取得し、フォロー、ブロック、ミュートを管理する |
| **データの分析** | 指標、トレンド、エンゲージメント分析にアクセスする |
| **連携機能の構築** | DM を送信し、リストを管理し、Spaces と連携する |

***

<div id="api-versions">
  ## API バージョン
</div>

<Tabs>
  <Tab title="X API v2 (推奨)">
    最新の機能と柔軟な料金体系を備えた、現在推奨されている X API のバージョンです。

    **v2 を利用する理由:**

    * 従量課金制 — 月間上限なし
    * 最新の JSON レスポンス形式
    * 柔軟な [フィールド](/ja/x-api/fundamentals/fields) と [展開](/ja/x-api/fundamentals/expansions)
    * 高度な機能: アノテーション、会話追跡、編集履歴
    * 新規エンドポイントと機能はすべて v2 で提供

    **はじめに:**

    1. [console.x.com](https://console.x.com) でサインアップする
    2. アプリを作成して認証情報を取得する
    3. [最初のリクエストを送信する](/ja/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1 (レガシー)">
    以前のバージョンの X API です。サポートは限定的なため、新しいプロジェクトには v2 を使用してください。

    **現在も利用可能な機能:**

    * 一部のメディアアップロードエンドポイント
    * レガシーストリーミング（非推奨）
    * 一部の特殊なエンドポイント

    **v2 への移行:**
    エンドポイントの対応関係やデータ形式の変更については、[移行ガイド](/ja/x-api/migrate/overview) を参照してください。
  </Tab>

  <Tab title="Enterprise">
    高度なニーズを持つ企業向けの大規模アクセスプランです。

    **機能:**

    * 完全な Firehose アクセス
    * 過去データのバックフィル
    * 専任サポート
    * カスタムレートリミット
    * コンプライアンスストリーム

    [Enterprise 営業担当に問い合わせる →](/ja/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

  <Card title="スペース" icon="microphone">

  <Card title="トレンド" icon="arrow-trend-up">

  </Card>
</CardGroup>

<div id="v2-highlights">
  ## v2 のハイライト
</div>

<Accordion title="フィールドと展開">
  必要なデータだけをリクエストできます。`fields` パラメータを使って特定の属性を選択し、`expansions` を使って関連オブジェクトを含めます。

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [フィールドの詳細はこちら →](/ja/x-api/fundamentals/fields)
</Accordion>

<Accordion title="投稿アノテーション">
  投稿には、人、場所、製品、トピックを識別するセマンティックなアノテーションが含まれます。ストリームや検索結果をトピックでフィルタリングできます。

  [アノテーションの詳細はこちら →](/ja/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="エンゲージメントメトリクス">
  公開メトリクス（いいね、リポスト、返信）と、自分の投稿に対する非公開メトリクス（インプレッション、クリック）にアクセスできます。

  [メトリクスの詳細はこちら →](/ja/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="会話の追跡">
  `conversation_id` を使用して、会話スレッド全体を再構築します。スレッド全体にわたる返信を追跡できます。

  [会話トラッキングの詳細はこちら →](/ja/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="編集履歴">
  投稿の編集履歴にアクセスできます。すべての過去バージョンと編集メタデータが含まれます。

  [投稿編集の詳細はこちら →](/ja/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## 料金
</div>

X API v2 は **従量課金制** の料金体系を採用しています：

| Benefit | Description |
|:--------|:------------|
| **No subscriptions** | 利用した分だけ支払う |
| **No caps** | 必要なだけ利用できます |
| **Credit-based** | クレジットを購入し、リクエストごとに差し引かれます |
| **Real-time tracking** | Developer Console で利用状況をリアルタイムに確認できます |
| **Deduplication** | 同一リソースを 24 時間以内に 2 回リクエストしても、課金は 1 回分のみです |

[料金の詳細を見る →](/ja/x-api/getting-started/pricing)
