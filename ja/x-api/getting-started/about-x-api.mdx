X API は、X 上の公開されている会話へのプログラムによるアクセスを提供します。投稿を取得し、トレンドを分析し、連携機能を実装し、プラットフォーム上で新しい体験を創出できます。

***

<div id="what-you-can-do">
  ## できること
</div>

| 機能 | 説明 |
|:-----------|:------------|
| **投稿を読む** | 投稿を検索・参照し、リアルタイムでストリーミングする |
| **コンテンツを公開する** | 投稿、返信、スレッドを作成する |
| **ユーザーを管理する** | ユーザーを参照し、フォロー、ブロック、ミュートを管理する |
| **データを分析する** | 指標やトレンド、エンゲージメント分析にアクセスする |
| **インテグレーションを構築する** | DM を送信し、リストを管理し、Spaces と連携する |

***

<div id="api-versions">
  ## API バージョン
</div>

<Tabs>
  <Tab title="X API v2 (推奨)">
    最新の X API バージョンであり、モダンな機能と柔軟な料金体系を備えています。

    **v2 を使う理由:**

    * 従量課金制 — 月間上限なし
    * モダンな JSON レスポンス形式
    * 柔軟な [fields](/ja/x-api/fundamentals/fields) と [expansions](/ja/x-api/fundamentals/expansions)
    * 高度な機能: アノテーション、会話トラッキング、編集履歴
    * 新しいエンドポイントと機能はすべて v2 で提供されます

    **利用開始手順:**

    1. [console.x.com](https://console.x.com) にサインアップ
    2. App を作成し、認証情報を取得
    3. [最初のリクエストを送信する](/ja/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1 (レガシー)">
    旧バージョンの X API です。サポートは限定的なため、新規プロジェクトには v2 を使用してください。

    **まだ利用可能なもの:**

    * 一部のメディアアップロードエンドポイント
    * レガシーストリーミング（非推奨）
    * 一部の特化したエンドポイント

    **v2 への移行:**
    エンドポイントの対応関係やデータ形式の変更については、[移行ガイド](/ja/x-api/migrate/overview)を参照してください。
  </Tab>

  <Tab title="Enterprise">
    高度なニーズを持ち、大規模アクセスを必要とする企業向けのプランです。

    **主な特長:**

    * Firehose への完全アクセス
    * 過去データのバックフィル
    * 専任サポート
    * カスタムレート制限
    * コンプライアンスストリーム

    [Enterprise 営業担当までお問い合わせ →](/ja/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

<div id="v2-highlights">
  ## v2 のハイライト
</div>

<Accordion title="フィールドと expansions">
  必要なデータだけをリクエストできます。`fields` パラメータを使って特定の属性を選択し、`expansions` で関連オブジェクトを含めます。

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [fields の詳細はこちら →](/ja/x-api/fundamentals/fields)
</Accordion>

<Accordion title="投稿のアノテーション">
  投稿には、人、場所、商品・製品、トピックを識別するセマンティックアノテーションが含まれます。ストリームや検索結果をトピックでフィルタリングできます。

  [アノテーションの詳細はこちら →](/ja/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="エンゲージメントメトリクス">
  自分の投稿について、公開メトリクス（いいね、リポスト、返信）と非公開メトリクス（インプレッション、クリック）にアクセスできます。

  [メトリクスの詳細はこちら →](/ja/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="会話トラッキング">
  `conversation_id` を使用して会話スレッド全体を再構築できます。スレッド全体にわたる返信を追跡できます。

  [会話トラッキングの詳細はこちら →](/ja/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="編集履歴">
  過去のすべてのバージョンと編集メタデータを含む、投稿の編集履歴にアクセスできます。

  [投稿の編集の詳細はこちら →](/ja/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## 料金
</div>

X API v2 は **従量課金制** の料金体系です。

| 利点 | 説明 |
|:--------|:------------|
| **サブスクリプション不要** | 使用した分だけ支払います |
| **上限なし** | 必要なだけ利用できます |
| **クレジット制** | クレジットを購入し、リクエストごとに消費されます |
| **リアルタイム追跡** | 開発者コンソールで利用状況をリアルタイムに確認できます |
| **重複排除** | 同じリソースを 24 時間以内に 2 回リクエストしても、課金は 1 回だけです |

[料金の詳細を見る →](/ja/x-api/getting-started/pricing)
