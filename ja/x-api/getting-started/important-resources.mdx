<div id="response-structure">
  ### レスポンスの構造
</div>

すべての v2 レスポンスは次の構造になっています。

```json
{
  "data": { ... },      // プライマリオブジェクト
  "includes": { ... },  // 展開されたオブジェクト(リクエストされた場合)
  "meta": { ... },      // ページネーション情報
  "errors": [ ... ]     // 部分的エラー(存在する場合)
}
```

<div id="common-parameters">
  ### 共通パラメーター
</div>

| Parameter | Use |
|:----------|:----|
| `tweet.fields` | 特定の投稿フィールドをリクエストする |
| `user.fields` | 特定のユーザーフィールドをリクエストする |
| `expansions` | 関連オブジェクトを含める |
| `max_results` | ページごとの結果数の上限を設定する |
| `pagination_token` | 次または前のページを取得する |

<div id="authentication-methods">
  ### 認証方法
</div>

| 方法 | 用途 |
|:-------|:---------|
| Bearer Token | 公開データの読み取り専用 |
| OAuth 2.0 | 細かなスコープでのユーザー操作 |
| OAuth 1.0a | ユーザー操作（レガシー、フル権限） |
