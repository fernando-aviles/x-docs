<div id="response-structure">
  ### レスポンスの構造
</div>

すべての v2 レスポンスは次の構造に従います。

```json
{
  "data": { ... },      // プライマリオブジェクト
  "includes": { ... },  // 展開されたオブジェクト(リクエストされた場合)
  "meta": { ... },      // ページネーション情報
  "errors": [ ... ]     // 部分的エラー(存在する場合)
}
```

<div id="common-parameters">
  ### 共通パラメータ
</div>

| Parameter | 用途 |
|:----------|:----|
| `tweet.fields` | 取得する投稿フィールドを指定 |
| `user.fields` | 取得するユーザーフィールドを指定 |
| `expansions` | 関連オブジェクトを含める |
| `max_results` | 1ページあたりの結果数の上限を指定 |
| `pagination_token` | 次／前ページを取得 |

<div id="authentication-methods">
  ### 認証方法
</div>

| 方法 | ユースケース |
|:-------|:---------|
| Bearer Token | 読み取り専用の公開データ |
| OAuth 2.0 | 詳細なスコープ制御が必要なユーザー操作 |
| OAuth 1.0a | ユーザー操作（レガシー、フル権限） |
