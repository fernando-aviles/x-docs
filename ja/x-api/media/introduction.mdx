メディアオブジェクトは、1つの写真、動画、またはアニメーションGIFを表すオブジェクトです。メディアオブジェクトは X API 内の多くのエンドポイントで使用され、投稿、ダイレクトメッセージ、ユーザープロフィール、広告クリエイティブなどに含めることができます。各メディアオブジェクトは、解像度や形式の異なる複数の表示または再生用バリエーションを持つ場合があります。

<div id="media-types-size-restrictions">
  ## メディアタイプとサイズ制限
</div>

API 経由でのアップロード時のサイズ制限

* **Image**: `5 MB`
* **GIF**: `15 MB`
* **Video**: `512 MB` (`media_category=amplify_video` を使用する場合)

<div id="creation">
  ## 作成
</div>

投稿、ダイレクトメッセージ、ユーザープロフィール画像、ホスト型広告カードなどのオブジェクトは、1 つ以上のメディアオブジェクトを含めることができます。これらのトップレベルオブジェクトは総称して「エンティティ」と呼ばれます。該当するエンティティ作成用 API（例: [`POST /2/tweets`](/ja/x-api/posts/creation-of-a-post)）には、一意の `media_id` を使用して 1 つ以上のメディアオブジェクトを渡すことができます。

メディアオブジェクトを含むエンティティは、次の手順で作成します。

1. 推奨される[チャンク](/ja/x-api-/media/quickstart/media-upload-chunked)アップロード（画像/GIF/動画）または従来の[シンプル](/ja/x-api/media-upload/media-upload)アップロード（画像のみ）のいずれかを使用して、メディアファイルをアップロードします。
2. 手順 1 の結果として `media_id` を受け取ります。エンティティが複数の `media_id` パラメータの指定を許可している場合は、異なるメディアに対してこの手順を複数回繰り返すことができます。
3. `media_id` とその他の必須パラメータを含めて適切なエンドポイントを呼び出し、エンティティを作成します。たとえば、[`POST /2/tweets`](/ja/x-api/posts/creation-of-a-post) エンドポイントを使用して、投稿に `media_id` を添付します。
