アカウントアクティビティ操作用のクライアント

このクライアントは、X API のアカウントアクティビティ関連エンドポイントとやり取りするためのメソッドを提供します。アカウントアクティビティに関連するすべての操作について、認証、リクエストの整形、レスポンスの解析を処理します。
