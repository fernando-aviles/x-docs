<div id="fetchnext">
  ### fetchNext
</div>

▸ **fetchNext**(): `Promise`&lt;`void`&gt;

次のページを取得し、現在のインスタンスに項目を追加します。

このメソッドは、次のページのdataを取得し、その項目を現在のpaginatorインスタンスに追加します。ページネーションの状態とメタデータを更新します。

<div id="returns">
  #### 戻り値
</div>

`Promise`&lt;`void`&gt;

**`例`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // 最初のページを取得
console.log(followers.items.length); // フォロワー数

if (!followers.done) {
  await followers.fetchNext(); // 2ページ目を取得
  console.log(followers.items.length); // ページ全体のフォロワー総数
}
```

**`Throws`**

API リクエストが失敗した場合にスローされます

<div id="next">
  ### next
</div>

▸ **next**(): `Promise`&lt;[`Paginator`](/ja/xdks/typescript/reference/classes/Paginator)&lt;`any`&gt;&gt;

次のページを、新しいインスタンスとして取得します。

このメソッドは現在の paginator の状態に影響を与えることなく、次のページから開始する新しい paginator インスタンスを作成します。

<div id="returns">
  #### 戻り値
</div>

`Promise`&lt;[`Paginator`](/ja/xdks/typescript/reference/classes/Paginator)&lt;`any`&gt;&gt;

次のページ用の新しい `Paginator` インスタンス

**`Example`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // 最初のページを取得

if (!followers.done) {
  const nextPage = await followers.next(); // 新しいインスタンスとして次のページを取得
  console.log(followers.items.length); // まだ最初のページ
  console.log(nextPage.items.length); // 2ページ目
}
```
