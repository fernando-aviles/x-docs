ダイレクトメッセージ操作用のクライアント

このクライアントは、X API のダイレクトメッセージ用エンドポイントとやり取りするためのメソッドを提供します。認証、リクエストのフォーマット、ダイレクトメッセージ関連のすべての操作に対するレスポンスのパースを行います。
