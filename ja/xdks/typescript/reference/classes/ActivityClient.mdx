アクティビティ関連の操作を行うためのクライアント

このクライアントは、X API のアクティビティ関連エンドポイントとやり取りするためのメソッドを提供します。認証、リクエストのフォーマット、レスポンスの解析を行い、アクティビティに関するすべての操作を処理します。
