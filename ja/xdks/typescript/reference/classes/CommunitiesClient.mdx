コミュニティ関連の操作を行うための Client

この Client は、X API のコミュニティ関連エンドポイントとやり取りするためのメソッドを提供します。認証、リクエストのフォーマット、レスポンスの解析を処理し、コミュニティに関連するすべての操作を扱います。
