ページネーション対応レスポンスのインターフェース

X API からのページネーション対応 API レスポンスの構造を表します。

<div id="type-parameters">
  ## 型パラメーター
</div>

| 名前 | 説明 |
| :------ | :------ |
| `T` | レスポンス内の要素の型 |

<div id="properties">
  ## プロパティ
</div>

<ResponseField name="data" type="T[]" required>
現在のページの項目を格納した配列

</ResponseField>

<ResponseField name="meta" type="Object">
ページネーション用のメタデータ

<Expandable title="プロパティ">
<ResponseField name="Name" type="Type | 説明" required>
</ResponseField>

<ResponseField name="resultCount" type="number | 現在のページ内の結果数">
</ResponseField>

<ResponseField name="nextToken" type="string | 次のページを取得するためのトークン">
</ResponseField>

<ResponseField name="previousToken" type="string | 前のページを取得するためのトークン">
</ResponseField>
</Expandable>
</ResponseField>

<ResponseField name="includes" type="Record&lt;string, any&gt;">
追加の関連オブジェクト（ユーザー、ツイートなど）

</ResponseField>

<ResponseField name="errors" type="any[]">
レスポンス内で発生したエラー

</ResponseField>
