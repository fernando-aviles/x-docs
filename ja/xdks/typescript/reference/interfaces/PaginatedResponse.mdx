ページング対応レスポンスインターフェース

X API から返されるページング対応の API レスポンス構造を表します。

<div id="type-parameters">
  ## 型パラメーター
</div>

| 名前 | 説明 |
| :------ | :------ |
| `T` | レスポンス内のアイテムのタイプ |

<div id="properties">
  ## プロパティ
</div>

<ResponseField name="data" type="T[]" required>
現在のページに含まれる項目の配列

</ResponseField>

<ResponseField name="meta" type="Object">
ページネーションに関するメタデータ

<Expandable title="プロパティ">
<ResponseField name="Name" type="型 | 説明" required>
</ResponseField>

<ResponseField name="resultCount" type="number | 現在のページの結果数">
</ResponseField>

<ResponseField name="nextToken" type="string | 次のページを取得するためのトークン">
</ResponseField>

<ResponseField name="previousToken" type="string | 前のページを取得するためのトークン">
</ResponseField>
</Expandable>
</ResponseField>

<ResponseField name="includes" type="Record&lt;string, any&gt;">
追加で含まれるオブジェクト（ユーザー、ツイートなど）

</ResponseField>

<ResponseField name="errors" type="any[]">
レスポンス内のエラー一覧

</ResponseField>
