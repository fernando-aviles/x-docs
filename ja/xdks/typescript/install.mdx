自分の Project で X API 用 TypeScript SDK を使い始めましょう。

<div id="install">
  ## インストール
</div>

<CodeGroup>
  ```bash npm theme={null}
  npm install @xdevplatform/xdk
  ```

  ```bash yarn theme={null}
  yarn add @xdevplatform/xdk
  ```

  ```bash pnpm theme={null}
  pnpm add @xdevplatform/xdk
  ```
</CodeGroup>

<div id="typescript-support">
  ## TypeScript サポート
</div>

この SDK は TypeScript で実装されており、完全なタイプ定義を備えています。追加のタイプ定義パッケージは不要です。

<div id="requirements">
  ## 必要条件
</div>

* Node.js 16 以上
* TypeScript 4.5 以上（TypeScript を使用する場合）
