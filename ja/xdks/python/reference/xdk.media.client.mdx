<div id="get_analytics">
  ### `get_analytics`
</div>

メディアのアナリティクスを取得
メディアに関する分析データを取得します。

<div id="parameters">
  #### パラメーター
</div>

<ParamField path="path.media_keys" type="List">
Media Key をカンマ区切りで指定するリストです。1 回のリクエストで最大 100 個まで指定できます。
</ParamField>

<ParamField path="path.end_time" type="str">
YYYY-MM-DDTHH:mm:ssZ。時間範囲の終了時刻を表す UTC タイムスタンプです。
</ParamField>

<ParamField path="path.start_time" type="str">
YYYY-MM-DDTHH:mm:ssZ。時間範囲の開始時刻を表す UTC タイムスタンプです。
</ParamField>

<ParamField path="path.granularity" type="str">
検索件数結果の集計粒度です。
</ParamField>

<ParamField path="path.media_analytics_fields" type="List or None" default="None">
表示する MediaAnalytics フィールドをカンマ区切りで指定します。
</ParamField>

<div id="returns">
  #### 戻り値
</div>

`GetAnalyticsResponse` - レスポンスデータ
