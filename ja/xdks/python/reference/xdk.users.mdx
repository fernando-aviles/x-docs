<div id="block_dms">
  ### `block_dms`
</div>

DM をブロックする
認証済みユーザーに対して、指定されたユーザー ID を基準に、そのユーザーとの間で送受信されるダイレクトメッセージをブロックします。

#### パラメーター

<ParamField path="path.id" type="Any">
  認証済みユーザーがDMのブロックをリクエストしている対象ユーザーのID。
</ParamField>
