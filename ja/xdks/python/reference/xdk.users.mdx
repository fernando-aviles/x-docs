<div id="block_dms">
  ### `block_dms`
</div>

DM をブロックする
認証済みユーザーに代わって、特定のユーザーの id を指定し、そのユーザーとのダイレクトメッセージの送受信をブロックします。

#### パラメーター

<ParamField path="path.id" type="Any">
  認証済みユーザーがDMをブロックしようとしている対象ユーザーのIDです。
</ParamField>
