X API SDK 向けの堅牢なストリーミングユーティリティです。

このモジュールは、自動再接続、指数バックオフ、および包括的なエラー処理を備えたストリーミング接続の管理機能を提供します。クライアントは接続管理を気にすることなくストリーミングエンドポイントを利用でき、SDK がすべての復旧処理を自動的に行います。

<div id="xdkstreamingstream_with_retry">
  ### `xdk.streaming.stream_with_retry`
</div>

自動再接続と指数バックオフ付きで、エンドポイントからストリーミング data を受信します。
この関数は、次の内容を含む接続管理全体を処理します：

- 切断時の自動再接続
- 再試行遅延のためのジッター付き指数バックオフ
- エラーを再試行可能かどうか、または致命的かどうかの分類
- 接続状態を監視するためのライフサイクルコールバック
