X API SDK 向けのカーソルベースのページネーション用ユーティリティです。

このモジュールは、すべての API クライアントで効率的なページネーションをサポートするための Cursor クラスを提供します。Cursor を使用すると、.pages() と .items() の両メソッドで、型安全性を保ちながらページングされた結果を簡単に反復処理できます。

<div id="xdkpaginatorcursor">
  ### `xdk.paginator.cursor`
</div>

適切な型推論とバリデーションを備えたカーソルを作成します。
このファクトリ関数は型推論を支援し、レスポンスの型に対する
適切な型ヒントが得られるようにするとともに、そのメソッドが
静的解析時と実行時の両方でページネーションをサポートしていることを検証します。

  #### パラメーター
</div>

ラップ対象の API メソッド（ページネーションに対応している必要があります）
</ParamField>
