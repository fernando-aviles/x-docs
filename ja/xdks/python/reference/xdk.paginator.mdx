X API SDK 向けのカーソルベースのページネーション用ユーティリティです。

このモジュールは、すべての API クライアントでスムーズなページネーションを行うための Cursor クラスを提供します。Cursor を使用すると、型安全性を維持しながら、.pages() と .items() の両メソッドを使ってページネーションされた結果を簡単に反復処理できます。

<div id="xdkpaginatorcursor">
  ### `xdk.paginator.cursor`
</div>

適切な型推論とバリデーションを備えたカーソルを作成します。
このファクトリー関数は型推論を支援し、レスポンス型に対して
適切な型ヒントが得られるようにし、対象のメソッドが
静的解析時と実行時の両方でページネーションをサポートしていることを検証します。

</ParamField>
