このモジュールは、X API とやり取りするための中核となる Client クラスを提供します。
すべてのサブクライアントを統括し、認証、セッション管理、
および OAuth 2.0 PKCE フローを処理します。すべての機能は OpenAPI 仕様から生成されています。

<div id="__init__">
  ### `__init__`

X API クライアントを初期化します。

<div id="parameters">
  #### パラメーター
</div>

<ParamField path="path.base_url" type="str" default="'https://api.x.com'">
X API のベース URL（省略時は [https://api.x.com](https://api.x.com)）。
</ParamField>

<ParamField path="path.bearer_token" type="str or None" default="None">
X API 用のベアラートークン（App-only 認証）。
</ParamField>

<ParamField path="path.access_token" type="str or None" default="None">
ユーザーコンテキスト向けの OAuth2 アクセストークン（ベアラートークンとして直接利用可能）。
</ParamField>

<ParamField path="path.client_id" type="str or None" default="None">
X API 用の client ID（OAuth2 PKCE フローで必須）。
</ParamField>

<ParamField path="path.client_secret" type="str or None" default="None">
X API 用の client secret。
</ParamField>

<ParamField path="path.redirect_uri" type="str or None" default="None">
OAuth2 認可用のリダイレクト URI。
</ParamField>

<ParamField path="path.token" type="Dict[str, Any] or None" default="None">
既存の OAuth2 トークンの辞書（存在する場合）。指定された場合は、`access_token` が抽出されます。
</ParamField>

<ParamField path="path.scope" type="str or List[str] or None" default="None">
OAuth2 の認可スコープを表す空白区切りの文字列、または文字列のリスト。
</ParamField>

<ParamField path="path.authorization_base_url" type="str" default="'https://x.com/i'">
OAuth2 認可のベース URL（省略時は [https://x.com/i](https://x.com/i)）。
</ParamField>

<ParamField path="path.auth" type="OAuth1">
OAuth1.0a 認証用の OAuth1 インスタンス。
</ParamField>

<div id="exchange_code">
  ### `exchange_code`
</div>

認可コードをトークンに交換します（TypeScript API と同等です）。

<div id="parameters">
  #### パラメーター
</div>

<ParamField path="path.code" type="Any">
コールバックで受け取った認可コード。
</ParamField>

<ParamField path="path.code_verifier" type="Any" default="None">
任意のコードベリファイア（省略時は保存済みのベリファイアを使用します）。
</ParamField>

<div id="fetch_token">
  ### `fetch_token`
</div>

認可レスポンス URL からトークンを取得します（レガシー方式）。

<div id="parameters">
  #### パラメーター
</div>

<ParamField path="path.authorization_response" type="Any">
認可後に受信した完全なコールバック URL。
</ParamField>

<div id="get_authorization_url">
  ### `get_authorization_url`
</div>

OAuth 2.0 PKCE フロー用の認可 URL を取得します。

<div id="parameters">
  #### パラメーター
</div>

<ParamField path="path.state" type="Any" default="None">
セキュリティ向上のための任意の state パラメーターです。
</ParamField>

<div id="is_token_expired">
  ### `is_token_expired`
</div>

OAuth2 トークンが有効期限切れかどうかを確認します。

<div id="refresh_token">
  ### `refresh_token`
</div>

OAuth 2.0 トークンを更新します。
