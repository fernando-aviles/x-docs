このモジュールは、X API と連携するための中核となる Client クラスを提供します。
このクラスはすべてのサブクライアントを統括し、認証、セッション管理、
および OAuth 2.0 PKCE フローの処理を行います。すべての機能は OpenAPI 仕様から自動生成されています。

  ## コンストラクター
</div>

<div id="__init__">
  ### `__init__`
</div>

X API のクライアントを初期化します。

#### パラメータ

<ParamField path="path.base_url" type="str" default="'https://api.x.com'">
X API のベース URL（デフォルトは [https://api.x.com](https://api.x.com)）。
</ParamField>

<ParamField path="path.bearer_token" type="str or None" default="None">
X API 用の Bearer Token（アプリ専用認証）。
</ParamField>

<ParamField path="path.access_token" type="str or None" default="None">
ユーザーコンテキスト用の OAuth2 アクセストークン（Bearer Token として直接使用できます）。
</ParamField>

<ParamField path="path.client_id" type="str or None" default="None">
X API 用のクライアント ID（OAuth2 PKCE フローで必須）。
</ParamField>

<ParamField path="path.client_secret" type="str or None" default="None">
X API 用のクライアントシークレット。
</ParamField>

<ParamField path="path.redirect_uri" type="str or None" default="None">
OAuth2 認可用のリダイレクト URI。
</ParamField>

<ParamField path="path.token" type="Dict[str, Any] or None" default="None">
既存の OAuth2 トークンの辞書オブジェクト（存在する場合）。指定された場合は access_token が抽出されます。
</ParamField>

<ParamField path="path.scope" type="str or List[str] or None" default="None">
OAuth2 の認可スコープを指定する、スペース区切りの文字列または文字列のリスト。
</ParamField>

<ParamField path="path.authorization_base_url" type="str" default="'https://x.com/i'">
OAuth2 認可用のベース URL（デフォルトは [https://x.com/i](https://x.com/i)）。
</ParamField>

<ParamField path="path.auth" type="OAuth1">
OAuth 1.0a 認証用の OAuth1 インスタンス。
</ParamField>

<div id="exchange_code">
  ### `exchange_code`
</div>

認可コードをトークンと交換します（TypeScript API と一致します）。

#### パラメータ

<ParamField path="path.code" type="Any">
コールバックで受け取った認可コード。
</ParamField>

<ParamField path="path.code_verifier" type="Any" default="None">
省略可能なコード検証子（指定しない場合は保存済みの検証子が使用されます）。
</ParamField>

<div id="fetch_token">
  ### `fetch_token`
</div>

認可レスポンス URL を使用してトークンを取得します（レガシーな方法）。

#### パラメータ

<ParamField path="path.authorization_response" type="Any">
認可後に返される完全なコールバック URL。
</ParamField>

<div id="get_authorization_url">
  ### `get_authorization_url`
</div>

OAuth 2.0 PKCE フロー用の認可 URL を取得します。

<div id="parameters">
  #### パラメーター
</div>

<ParamField path="path.state" type="Any" default="None">
セキュリティ強化のための省略可能な state パラメーターです。
</ParamField>

<div id="is_token_expired">
  ### `is_token_expired`
</div>

OAuth2 トークンが期限切れかどうかを確認します。

<div id="refresh_token">
  ### `refresh_token`
</div>

OAuth 2.0 トークンを更新します。
