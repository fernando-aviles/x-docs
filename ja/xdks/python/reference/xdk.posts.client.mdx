</div>

<ParamField path="path.query" type="str">

</ParamField>

<ParamField path="path.start_time" type="str or None" default="None">
YYYY-MM-DDTHH:mm:ssZ。投稿が提供される最も古い UTC タイムスタンプ（直近 7 日間以内）です。タイムスタンプは秒単位で指定され、下限値を含みます（例: 12:00:01 はその分の最初の 1 秒を含みます）。
</ParamField>

<ParamField path="path.end_time" type="str or None" default="None">
YYYY-MM-DDTHH:mm:ssZ。投稿が提供される最も新しい UTC タイムスタンプです。タイムスタンプは秒単位で指定され、上限値は含みません（例: 12:00:01 はその分の最初の 1 秒を含みません）。
</ParamField>

<ParamField path="path.since_id" type="Any or None" default="None">
指定された ID より大きい（つまり、より新しい）投稿 ID を持つ結果を返します。
</ParamField>

<ParamField path="path.until_id" type="Any or None" default="None">
指定された ID より小さい（つまり、より古い）投稿 ID を持つ結果を返します。
</ParamField>

<ParamField path="path.next_token" type="Any or None" default="None">
このパラメータは、次の「ページ」の結果を取得するために使用されます。パラメータに指定する値は、API が返すレスポンスから直接取得するものであり、変更しないでください。
</ParamField>

<ParamField path="path.pagination_token" type="Any or None" default="None">
このパラメータは、次の「ページ」の結果を取得するために使用されます。パラメータに指定する値は、API が返すレスポンスから直接取得するものであり、変更しないでください。
</ParamField>
