</div>

<div id="parameters">
  #### Parameters
</div>

<ParamField path="path.query" type="str">

</ParamField>

<ParamField path="path.start_time" type="str or None" default="None">
YYYY-MM-DDTHH:mm:ssZ。投稿が提供される最も古い UTC タイムスタンプ（直近 7 日以内）を指定します。タイムスタンプは秒単位の精度で、下限値を含みます（例: 12:00:01 はその分の最初の 1 秒を含みます）。
</ParamField>

<ParamField path="path.end_time" type="str or None" default="None">
YYYY-MM-DDTHH:mm:ssZ。投稿が提供される最新の UTC タイムスタンプを指定します。タイムスタンプは秒単位の精度で、上限値は含まれません（例: 12:00:01 はその分の最初の 1 秒を含みません）。
</ParamField>

<ParamField path="path.since_id" type="Any or None" default="None">
指定した ID より大きい（つまり、より新しい）投稿 ID を持つ結果を返します。
</ParamField>

<ParamField path="path.until_id" type="Any or None" default="None">
指定した ID より小さい（つまり、より古い）投稿 ID を持つ結果を返します。
</ParamField>

<ParamField path="path.next_token" type="Any or None" default="None">
このパラメータは、次の「ページ」の結果を取得するために使用されます。このパラメータで使用する値は、API が返すレスポンスから直接取得するものであり、変更してはいけません。
</ParamField>

<ParamField path="path.pagination_token" type="Any or None" default="None">
このパラメータは、次の「ページ」の結果を取得するために使用されます。このパラメータで使用する値は、API が返すレスポンスから直接取得するものであり、変更してはいけません。

  #### Parameters
</div>

<ParamField path="path.query" type="str">
投稿にマッチさせるためのクエリ / ルール / フィルターを 1 つ指定します。最大クエリ長については [https://t.co/rulelength](https://t.co/rulelength) を参照してください。
</ParamField>

<ParamField path="path.start_time" type="str or None" default="None">
YYYY-MM-DDTHH:mm:ssZ。投稿が提供される最も古い UTC タイムスタンプです。タイムスタンプは秒単位の粒度で、開始時刻を含みます（例: 12:00:01 はその分の最初の 1 秒を含みます）。
</ParamField>

<ParamField path="path.end_time" type="str or None" default="None">
YYYY-MM-DDTHH:mm:ssZ。投稿が提供される最も新しい UTC タイムスタンプです。タイムスタンプは秒単位の粒度で、終了時刻は含みません（例: 12:00:01 はその分の最初の 1 秒を含みません）。
</ParamField>

<ParamField path="path.since_id" type="Any or None" default="None">
指定した ID より大きい（すなわち、より新しい）投稿 ID を持つ結果を返します。
</ParamField>

<ParamField path="path.until_id" type="Any or None" default="None">
指定した ID より小さい（すなわち、より古い）投稿 ID を持つ結果を返します。
</ParamField>

<ParamField path="path.max_results" type="int or None" default="None">
1 回のリクエストで返される検索結果の最大数です。
</ParamField>

<ParamField path="path.next_token" type="Any or None" default="None">
次の「ページ」の結果を取得するために使用するパラメータです。このパラメータに指定する値は API が返すレスポンスから直接取得されるものであり、変更すべきではありません。
</ParamField>

<ParamField path="path.pagination_token" type="Any or None" default="None">
次の「ページ」の結果を取得するために使用するパラメータです。このパラメータに指定する値は API が返すレスポンスから直接取得されるものであり、変更すべきではありません。
</ParamField>

<ParamField path="path.sort_order" type="str or None" default="None">
結果を返す順序を指定します。
</ParamField>

<ParamField path="path.tweet_fields" type="List or None" default="None">
表示するツイートのフィールドを、カンマ区切りのリストで指定します。
</ParamField>

<ParamField path="path.expansions" type="List or None" default="None">
展開するフィールドを、カンマ区切りのリストで指定します。
</ParamField>

<ParamField path="path.media_fields" type="List or None" default="None">
表示する Media のフィールドを、カンマ区切りのリストで指定します。
</ParamField>

<ParamField path="path.poll_fields" type="List or None" default="None">
表示する Poll のフィールドを、カンマ区切りのリストで指定します。
</ParamField>

<ParamField path="path.user_fields" type="List or None" default="None">
表示する User のフィールドを、カンマ区切りのリストで指定します。
</ParamField>

<ParamField path="path.place_fields" type="List or None" default="None">
表示する Place のフィールドを、カンマ区切りのリストで指定します。
</ParamField>
