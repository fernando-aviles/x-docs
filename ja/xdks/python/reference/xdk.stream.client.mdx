このモジュールは、X API のストリームエンドポイントとやり取りするためのクライアントを提供します。
リアルタイムストリーミング処理は、データが到着し次第順次返すジェネレーターを返します。
ストリーミング接続は、自動的に指数バックオフ付きのリトライロジックで管理され、堅牢に動作します。

<div id="labels_compliance">
  ### `labels_compliance`
</div>

投稿ラベルのストリーミング（Streaming）
投稿に適用されたすべてのラベル付与イベントをストリーミング配信します。

すべての公開ポルトガル語投稿をリアルタイムでストリーミングします。
これは、利用可能になり次第リアルタイムで data を返すストリーミングエンドポイントです。
返される各項目は、ストリームからの1つのデータポイントを表します。

ストリームが切断された場合、クライアント側での操作なしに SDK が自動的に再接続します。
