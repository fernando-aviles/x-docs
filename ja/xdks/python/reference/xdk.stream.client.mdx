このモジュールは、X API のストリームエンドポイントとやり取りするためのクライアントを提供します。
リアルタイムストリーミングの操作では、データの到着に応じて逐次データを生成するジェネレーターが返されます。
ストリーミング接続は、堅牢な処理を行えるよう、指数バックオフ付きのリトライロジックによって自動的に管理されます。

<div id="labels_compliance">
