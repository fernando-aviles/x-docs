このモジュールは、X API の activity エンドポイントとやり取りするためのクライアントを提供します。
リアルタイムストリーミングの操作では、到着したデータを逐次生成するジェネレーターが返されます。
ストリーミング接続は、指数バックオフによるリトライロジックで自動的に管理され、堅牢に動作します。

<div id="stream">
  ### `stream`
</div>

アクティビティストリーム（ストリーミング）
X アクティビティのストリーム
これは、利用可能になり次第、リアルタイムで data を返すストリーミングエンドポイントです。
返される各項目は、ストリームからの単一のデータポイントを表します。
接続は、指数バックオフを用いたリトライロジックによって自動的に管理されます。
ストリームが切断された場合でも、SDK がクライアント側での操作なしに自動的に再接続します。

#### パラメーター

<ParamField path="path.backfill_minutes" type="int or None" default="None">
バックフィルを行う時間（分単位）を指定します。
</ParamField>

<ParamField path="path.start_time" type="str or None" default="None">
YYYY-MM-DDTHH:mm:ssZ。投稿ラベルが提供される最も早い UTC タイムスタンプです。
</ParamField>

<ParamField path="path.end_time" type="str or None" default="None">
YYYY-MM-DDTHH:mm:ssZ。投稿ラベルが提供される最も遅い UTC タイムスタンプです。
</ParamField>

<ParamField path="path.stream_config" type="StreamConfig">
リトライ動作、タイムアウト、コールバックをカスタマイズするためのオプションの StreamConfig です。
</ParamField>
