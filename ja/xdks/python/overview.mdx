Python XDK (X Developer Kit) は、Python を使用して X API v2 と連携するための公式クライアントライブラリです。これを使うことで、開発者は API をすばやく使い始め、アプリケーションを構築できます。公式の [OpenAPI 仕様](https://api.x.com/2/openapi.json) に基づいて生成されています。低レベルな HTTP の詳細を抽象化しつつ、必要に応じてきめ細かな制御も提供します。

<div id="key-features">
  ## 主な特長
</div>

- 🔐 **OAuth 対応**: Bearer Token（アプリ専用）認証、PKCE 付き OAuth 2.0（ユーザーコンテキスト）、OAuth 1.0 を完全にサポートします。
- 🔄 **ページネーション**: 大量の結果を自動でページングします。XDK が `next_token` を使ったページネーション処理を代行するため、開発者が複数回の API 呼び出しを行う必要はありません。
- 📡 **ストリーミング**: filtered stream（フィルタ済みストリーム）など、永続的な HTTP 接続を必要とするエンドポイント向けに、リアルタイムのデータストリーミングをサポートします。
- 🎯 **包括的な対応**: 検索、タイムライン、filtered stream などを含む、すべての X API v2 エンドポイントをサポートします。
**バージョン互換性**: Python 3.8 以降。CPython および PyPy でテスト済み。
