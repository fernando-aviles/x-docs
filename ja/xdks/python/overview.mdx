Python XDK（X Developer Kit）は、Python を使用して X API v2 と連携するための公式クライアントライブラリです。これにより、開発者はすばやく API の利用を開始し、それを使ってアプリケーションを構築できます。このライブラリは、公式の [OpenAPI 仕様](https://api.x.com/2/openapi.json) に基づいて生成されています。低レベルな HTTP の詳細を抽象化しつつ、必要に応じて細かな制御も可能にします。

<div id="key-features">
  ## 主な機能
</div>

- 🔐 **OAuth 対応**: Bearer Token（アプリ専用）認証、PKCE を用いた OAuth 2.0（ユーザーコンテキスト）、OAuth 1.0 をフルサポート。
- 🔄 **ページネーション**: 大規模な結果セットを自動でページングします。`next_token` を使って複数回 API を呼び出す必要はなく、ページネーション処理は XDK が代行します。
- 📡 **ストリーミング**: filtered stream のような、永続的な HTTP 接続を必要とするエンドポイント向けに、リアルタイムなデータストリーミングをサポートします。
- 🎯 **包括的なカバー範囲**: 検索、タイムライン、filtered stream などを含む、すべての X API v2 エンドポイントをサポートします。
**バージョン互換性**: Python 3.8 以降対応。CPython および PyPy 上でテスト済みです。
