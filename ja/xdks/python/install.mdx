XDK Python SDK は GitHub リポジトリから直接取得でき、`pip` を使ってインストールできます。

<div id="prerequisites">
  ## 前提条件
</div>

- Python 3.8 以上
- 仮想環境用の `pip` と `venv`（推奨）

<div id="quick-install">
  ## クイックインストール
</div>

GitHub のサブディレクトリから XDK をインストールします。

```bash
pip install xdk
```

`main` ブランチから最新で生成されたバージョンを取得します。


<div id="development-install">
  ## 開発用インストール
</div>

開発やコントリビュートを行う場合:

1. リポジトリをクローンします:
   ```bash
   git clone https://github.com/xdevplatform/xdk.git
   cd xdk/python
   ```
2. 依存関係を編集可能モードでインストールします:
   ```bash
   pip install -e .
   ```
   これにより、SDK とその実行時依存関係がインストールされます。
3. （任意）テストおよび Lint 用の開発用依存関係をインストールします:
   ```bash
   pip install -e .[dev]
   ```

<div id="verification">
  ## 検証
</div>

インストールを確認します。

```python
import xdk
print(xdk.__version__)  # XDKのバージョンを出力します
```

**注:** XDK は OpenAPI 仕様から自動生成されているため、変更がないか必ず [X API の変更履歴](https://docs.x.com/changelog) とリポジトリ内の XDK のリリースノートを確認してください。
Python XDK を用いた詳細なコード例については、[コードサンプルの GitHub リポジトリ](https://github.com/xdevplatform/samples/tree/main/python) を参照してください。
