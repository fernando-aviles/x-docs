XDK Python SDK は GitHub リポジトリから直接入手でき、`pip` でインストールできます。

<div id="prerequisites">
  ## 前提条件
</div>

- Python 3.8 以降。
- 仮想環境用の `pip` と `venv`（推奨）。

<div id="quick-install">
  ## クイックインストール
</div>

GitHub リポジトリ内のサブディレクトリから XDK をインストールします：

```bash
pip install xdk
```

これにより、`main` ブランチから最新の生成済みバージョンを取得します。


<div id="development-install">
  ## 開発用インストール
</div>

開発やコントリビューションを行う場合:

1. リポジトリをクローンします:
   ```bash
   git clone https://github.com/xdevplatform/xdk.git
   cd xdk/python
   ```
2. 依存関係を編集可能モードでインストールします:
   ```bash
   pip install -e .
   ```
   これにより、SDK とその実行時依存関係がインストールされます。
3. （任意）テストや lint 用の開発用依存関係をインストールします:
   ```bash
   pip install -e .[dev]
   ```

<div id="verification">
  ## 検証
</div>

インストールを確認します：

```python
import xdk
print(xdk.__version__)  # XDKのバージョンを出力します
```

**注:** XDK は OpenAPI 仕様から生成されているため、常に [X API の変更履歴](https://docs.x.com/changelog) と、リポジトリ内の XDK リリースノートで変更内容を確認してください。
Python XDK を使った詳細なコード例については、[コードサンプルの GitHub リポジトリ](https://github.com/xdevplatform/samples/tree/main/python)を参照してください。
