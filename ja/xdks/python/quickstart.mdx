この例では、XDK を使い、Bearer Token 認証で投稿をすばやく検索する方法を示します。

<div id="step-1-install-the-sdk">
  ## ステップ 1: SDK をインストール
</div>

```bash
pip install xdk
```

<div id="step-2-get-your-bearer-token">
  ## ステップ 2: Bearer Token を取得する
</div>

1. [X Developer Console](https://developer.x.com/en/portal/dashboard) にログインします。
2. アプリを作成するか、既存のアプリを選択します。
3. 「Keys and Tokens」セクションで、Bearer Token（アプリのみ認証）を生成します。

<div id="step-3-write-and-run-your-first-script">
  ## ステップ3: 最初のスクリプトを作成して実行する
</div>

`quickstart.py` という名前のファイルを作成します。

```python
# クライアントをインポート
from xdk import Client
# 実際のBearer Tokenに置き換えてください
client = Client(bearer_token="YOUR_BEARER_TOKEN_HERE")
# "api"に言及している最近の投稿を取得
# search_recentはIteratorを返すので、それを反復処理します
for page in client.posts.search_recent(query="api", max_results=10):
    if page.data and len(page.data) > 0:
        # 最初の投稿にアクセス - Pydanticモデルは属性とdictの両方のアクセスをサポートしています
        first_post = page.data[0]
        post_text = first_post.text if hasattr(first_post, 'text') else first_post.get('text', '')
        print(f"Latest Post: {post_text}")
        break
    else:
        print("No Posts found.")
        break
```

実行します：

```bash
python quickstart.py
```

**想定される出力**:

```
最新の投稿: XDK Python SDKに関するエキサイティングなアップデート!
```

**トラブルシューティング**：401 エラーが返された場合は、Bearer Token を再確認してください。レート制限 (429) エラーの場合は、しばらく待ってから再試行してください。
