**要約（tl;dr）**

Ryerson University における Migration and Integration 分野の Canada Excellence Research Chair（CERC）の研究員である Stein Monteiro 氏が、Twitter データを活用し、農民抗議運動の際のインド系ディアスポラとインド本国との関係に関する研究をどのように前進させたのかを紹介します。

Stein Monteiro 氏にとって、インドで起きた農民抗議運動は興味深い問いを投げかけました。それは、「インドで大きな出来事が起きたとき、インド系ディアスポラはどのように行動するのか」というものです。Twitter の API の助けを借りて、彼はその答えを明らかにすることができました。詳しくは本記事でご覧ください。
</Note>

<div id="challenge">
  ## 課題
</div>

カナダの Ryerson University における Canada Excellence Research Chair (CERC) in Migration and Integration のリサーチフェローである Stein Monteiro にとって、仕事は統計、文化、そして時事問題の交差点に位置しています。経済学の専門性が学術界での成功の土台となりましたが、移民研究への情熱に火をつけたのは、彼自身の経験でした。

インドで生まれ育った Stein は、高校時代をドバイで過ごした後、学部課程のためにカナダへ渡りました。彼にとって、異国で「新参者」である感覚は非常に馴染み深いものでした。新しい社会制度、気候、生活様式の中を渡り歩く経験は初めてではなかったのです。新しい文化や環境へと適応していくプロセスは、移民の社会統合の歩みに対する彼の関心をかき立てました。経済学の研究を進める中でも、こうしたより個人的な経験の魅力は色あせることなく、彼は両方の世界を結びつけようと考えるようになりました。経済学の博士号を取得するため、彼は学位論文のテーマとして移民研究の文献を中心に据えました。

この学位論文に取り組む中で、Stein は独学でコーディングを習得しました。その後 Humber College で統計担当者として働いた際には、学んだことを実務で活かすことができました。コーディングによって業務の自動化が可能になり、データを整理して集計することで仕事を単純化できたのです。

自分の業務プロセスをコードという形に落とし込むことで、Stein は問題をより容易に特定できるようになり、自身の作業や思考プロセスを他者に対してステップごとに説明できるようになりました。これは、問題を捉え、解決策を構築するまったく新しい視点を開いてくれるものでした。彼はこのスキルセットが持つ無限の可能性を少しずつ実感するようになり、その知見を携えて Canada Excellence Research Chair (CERC) に加わりました。 

CERC 在籍中、Stein の関心を引いたのは、ソーシャルメディア上のオンライン・アクティビズム、とりわけ 2020 年 8 月に導入された 3 つの物議を醸す法律をきっかけとしたインドの農民抗議運動をめぐって見られた動きでした。彼には、これらの抗議行動と自身の研究とのつながりが見えていました。リアルタイムで起きていることが、移民およびディアスポラ全体の経験についての情報を明らかにしうるという、重要な瞬間でした。

自分の周囲で議論が一気に広がるなか、彼は、オンライン・アクティビズムが、カナダ、英国、オーストラリア、そして湾岸諸国に暮らすインド系ディアスポラの人々の行動にどのような影響を与えているのかを考えました。ソーシャルネットワークは、移民をどのようにしてインド国内の議論と結びつけているのか。 

いよいよ、行動に移すべき時が来ていました。 

<div id="solution">
  ## ソリューション
</div>

インド系ディアスポラと農民抗議運動との結びつきをより深く理解するために、Stein はオンライン上の議論に耳を傾ける必要があると考え、その舞台として Twitter に目を向けました。

Stein はこう語ります。「こうしたローカルな出来事が国際的なオーディエンスに届いたのは、Twitter が国際的な現象だからというだけでなく、人々、つまりごく普通の人たちがオンラインで互いに話し、ハッシュタグだけでお互いにつながることができたからです。」彼にとって Twitter は、「インドで起きている農民抗議運動に、インド人でなくても、あるいはインド人でも世界の別の場所にいても、参加者になれる」場でした。

Stein は Twitter を、抗議者たち、反抗議のレトリック、政府寄りの主体、そして現場で実際に起きていることのフィルターのかかっていない体験が交錯する場所だと捉えました。そして、自身もその動きの中に加わりたいと考えました。 

こうした会話を追いながら、Stein はいくつかの点に焦点を絞る必要がありました。インドで誰かがオンラインに何かを投稿したとき、そのツイートはどのようにして世界中へと届いていくのか。情報はネットワークやハッシュタグなどを通じてどのように流れていくのか。そして、インドから発信されるツイートに対して、ディアスポラはどのように反応しているのか。 

Stein は、Twitter の API の助けを借りることで、そうした点をより明確に把握できるようになりました。Academic Research のプロダクトトラックが導入されたことで、履歴データに加えて、大量のツイートや投稿者情報にもアクセスできるようになり、さらなる分析が可能になったのです。 

Stein にとって、API の持つ力とは、長期間にわたるデータへのアクセス性でした。これにより、会話の時間軸 ― 誰が何をリツイートし、誰が誰と話しているのか ― を描き出すことができたのです。 

こうした情報のすべてを手にした Stein は、その結果に衝撃を受けました。インドの状況に反応するインド系ディアスポラの活動は、驚くほど活発だったのです。Stein はこう語ります。「それはタイムラグのある反応ですらなく、ほとんど即時でした。1 日という短い期間のうちに、インドで投稿している人々の投稿がリツイートされ、そのリツイートが世界の他の地域で起きているのを目の当たりにしたのです。」

データが示していたのは明快な事実でした。ソーシャルメディアは、移民やディアスポラが母国とつながり続け、重要な議論の中で積極的な役割を果たすことを可能にしているのです。

<div id="impact">
  ## 影響
</div>

Twitter のオープン API を使用することで、Stein は移民としての経験をめぐる、より大きな議論全体についての洞察をもたらすタイムリーな出来事を調査することができました。データへのアクセスと、そのデータをフィルタリングおよびソートするための機能は、このプロジェクトにとって極めて重要な役割を果たしました。 

さらに重要なことに、Stein は、Twitter が学術研究全体にとって重要なツールであると認識しました。彼にとって研究における最大のハードルの 1 つは、データを世界中から収集する必要があるという点です。幸いにも、Twitter の世界的な普及により、世界各地で多額の費用をかけて調査やフォーカスグループを実施することなく、グローバルな情報にアクセスできます。 

Stein は次のように述べています。「Twitter は研究者や学術コミュニティに対し、自身の研究目的のためにデータにアクセスする新たな手段と、新しい方法論を開発する機会を与えてくれますが、それは同時に費用対効果の高い方法でもあります。」また、オンラインで起きている会話が有用だったのは、「非常にありのままで、偏りのない会話が、研究者がその会話に介入することなく、人々の間で交わされていたからだ」と考えています。 

Stein の研究は、Twitter が世界中の人々をつなぐツールであり続けると同時に、Twitter の API がそのつながりから生まれる大規模なインサイトを収集するのに役立つことを証明しました。
