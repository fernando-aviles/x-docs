**要点（tl;dr）は以下のとおりです**

Ryerson University の Canada Excellence Research Chair (CERC) in Migration and Integration の研究員である Stein Monteiro 氏が、農民抗議運動の際に見られたインド系ディアスポラとインド本国との関係に関する研究を深めるために、どのように Twitter のデータを活用したかを学びましょう。

Stein Monteiro 氏にとって、インドで起きた農民抗議運動は興味深い問いを投げかけるものでした。それは、「インドで大きな出来事が起きたとき、インド系ディアスポラはどのように行動するのか」というものです。Twitter の API の助けを借りて、彼はその答えを明らかにすることができました。詳細はこちらをご覧ください。
</Note>

<div id="challenge">
  ## 課題
</div>

カナダのライアソン大学における移民・統合分野の Canada Excellence Research Chair (CERC) のリサーチフェローである Stein Monteiro にとって、仕事は統計、文化、そして時事問題が交差する地点に位置しています。経済学の専門性が学術的なキャリアの基盤となった一方で、移民研究への情熱をかき立てたのは、彼自身の経験でした。

インドで生まれ育った Stein は、高校時代をドバイで過ごし、その後カナダに渡って学部課程を修了しました。彼にとって「新しい国で暮らし始める」という感覚は、とても馴染み深いものでした。新しい社会制度や気候、生活様式の中を手探りで進んでいく経験は、彼にとって決して珍しいものではなかったのです。新たな文化や環境に適応していくプロセスは、移民の社会統合の歩みに対する関心を呼び起こしました。経済学の研究を続ける中でも、こうしたより個人的な経験の引力はなお強く、彼はこの二つの世界を結びつけようと考えるようになりました。経済学の博士号を取得するにあたり、彼は移民研究の文献に焦点を当てて博士論文に取り組みました。

この論文に取り組むなかで、Stein は独学でコーディングを習得しました。その後 Humber College で統計担当の職に就いた際には、そこで学んだことを実務に生かすことができました。コーディングによって業務の自動化が可能になり、データの整理や集計を通じて仕事をより効率化できるようになったのです。

自らの業務プロセスをコードという形に落とし込むことで、Stein は問題をより容易に特定し、自身の仕事や思考プロセスを他者に対してステップごとに説明できるようになりました。これは、問題を捉え、解決策を構築する全く新しい視点を開くものでした。彼はこのスキルセットがもつ無限の可能性を少しずつ実感していき、その知見を Canada Excellence Research Chair (CERC) にも持ち込みました。 

CERC での勤務中、Stein の関心を強く引いたのは、ソーシャルメディア上で目にしたオンライン・アクティビズム、とりわけ（2020 年 8 月に導入された 3 つの物議を醸す法律に端を発した）インドの農民抗議運動をめぐる動きでした。彼には、これらの抗議活動と自身の研究との間に関連性が見えていました。これは重要な瞬間でした。リアルタイムで起きている事象が、移民やディアスポラ全体の経験に関する情報を明らかにしてくれるかもしれなかったのです。

議論が一気に盛り上がるなかで、彼はカナダ、英国、オーストラリア、そして湾岸諸国に暮らすインド系ディアスポラの人々の活動に、オンライン・アクティビズムがどのような影響を与えているのかを考えました。ソーシャルネットワークは、移民をインドでの議論とどのようにつないでいるのか。 

いよいよ本格的に取り組むときが来ていました。 

<div id="solution">
  ## Solution
</div>

インド系ディアスポラと農民による抗議活動との関係性をよりよく理解するために、Stein はオンライン上の会話に耳を傾ける必要があると考え、その舞台として Twitter に目を向けました。

Stein によると、「こうしたローカルな出来事が国際的なオーディエンスに届いたのは、Twitter が国際的なプラットフォームだからというだけでなく、人々、つまりごく普通の人々がオンラインで互いに話し、ハッシュタグだけを通じて互いにつながることができたからです。」彼にとって Twitter とは、「インドで起きている農民の抗議活動に、インド人でなくても、あるいはインド人でも世界の別の地域にいても、参加者になれる」場でした。

Stein は、Twitter を、抗議者、反抗議のレトリック、親政府の勢力、そして現場で実際に何が起きているのかというフィルターのかかっていない体験が交わる場所だと見なしていました。そして彼自身もその渦中に身を置きたいと考えました。 

こうしたやり取りを追いながら、Stein はいくつかの点に焦点を絞る必要がありました。インドで誰かがオンラインに何かを投稿したとき、そのツイートはどのようにして世界の他の地域へ届くのか。情報はネットワークやハッシュタグなどを通じてどのように流れていくのか。そしてディアスポラは、インドから流れてくるツイートにどのように反応しているのか。 

Stein は Twitter の API の助けを借りて、こうした点を明確にすることができました。Academic Research プロダクトトラックによって、過去のデータに加え、大量のツイートや投稿者の情報にアクセスし、さらに分析できるようになったのです。 

Stein にとって、API の力とは、長期間にわたってデータにアクセスできることであり、それによって会話の時間的な次元、つまり「誰が何をリツイートしているのか」「誰が誰と話しているのか」を描き出せることでした。 

こうした情報のすべてを手にした Stein は、その結果に衝撃を受けました。インドの状況に反応するインド系ディアスポラの活動レベルが非常に高かったのです。Stein はこう述べています。「タイムラグのある活動ですらなく、ほとんど即時でした。1 日のうちに、インドで投稿した人々のツイートがリツイートされ、それが世界中でリツイートされているのが見て取れました。」

データは明らかでした。ソーシャルメディアは、移民やディアスポラが母国とつながり続け、重要な議論に積極的な役割を果たすことを可能にしているのです。

<div id="impact">
  ## 影響
</div>

Twitter のオープン API を利用することで、Stein 氏はタイムリーな出来事を調査し、移民経験というより大きなテーマに関する議論への洞察を得ることができました。データへのアクセスや、そのデータをフィルタリングおよびソートするための機能は、このプロジェクトにとって極めて重要な役割を果たしました。

さらに重要なのは、Stein 氏が、学術研究全体にとってのツールとしての Twitter の重要性を認識したことです。彼にとって、研究における最大のハードルの 1 つは、データを世界中から収集する必要があることです。幸いにも、Twitter の国際的なプレゼンスにより、世界各地で多額の費用をかけて調査やフォーカスグループを実施することなく、グローバルな情報にアクセスすることができます。

Stein 氏は次のように述べています。「Twitter は、研究者や学術コミュニティが、自身の研究目的のためにデータへアクセスするための新しい手段を提供してくれます。新しい手法を開発することもできますし、コスト面でも効率的です。」また、オンライン上で行われる会話が有用であった理由については、「それらはほとんどフィルタされておらず、偏りもなく、研究者が会話に介入することなく、人々の間で自然に交わされているやり取りだったからです」と述べています。

Stein 氏の研究は、Twitter が世界中の人々をつなぐツールであり続けていること、そして Twitter の API が、そのつながりから生まれる大規模なインサイトを収集するのに役立つことを証明しました。
