<Note>
**要点まとめ**

成功へのトレンドを切り開く: Red Cloud Financial Services は、ある鉱業会社から新しいグリーンテクノロジーのマーケティング支援を依頼された際、X の分析データを基盤とした Audiense のターゲティングツールを活用してデータを「採掘」し、新たなオーディエンスにリーチしました。
</Note>

<div id="situation">
  ## 状況
</div>

Red Cloud Financial Services は、上場している鉱業会社クライアントが開発した新しい特許出願中の技術について、まったく新しいオーディエンスに対して認知度を高めることを支援する任務を負っていました。 

同社は、この新製品で成果を上げる方法を見つけ、新たな地域へと展開しながら、その新しい顧客層にリーチできるキャンペーンを効果的に実施する必要がありました。 

この依頼には 2 つの重要な課題がありました。 

1. **新しいオーディエンスにリーチする**

    既存の鉱業分野の顧客に注力するのではなく、クライアントの新しいテクノロジーは、グリーン・イノベーションや社会的責任に関心のある、より広いセグメントに訴求するものでした。これは Red Cloud にとって未知の領域であり、それまで実施してきたキャンペーンとはまったく異なるものでした。

1. **具体的な ROI を示す**

    クライアントは有料キャンペーンに慣れていませんでした。Red Cloud に対して、認知向上を目的としたキャンペーンの ROI を明確に示し、さらに Red Cloud が直接の経験をほとんど持たないオーディエンスから成果を出すことが求められたことは、非常に困難な課題でした。 
    
    Red Cloud は、既存顧客にリーチしつつ新規見込み顧客をリサーチするために Audiense に頼りました。Audiense の X マーケティング製品は、強力なオーディエンスターゲティングツールを活用して、インパクトのある X キャンペーンを提供することを専門としています。

<div id="solution">
  ## 解決策
</div>

Red Cloud は、まず期待値の設定から着手しました。Audiense から得られるインサイトを活用してキャンペーンのパフォーマンス予測を作成することで、キャンペーンの最終目標と、それに紐づく KPI についてクライアントの期待値を適切に設定することができました。 

Audiense の支援を受けて、Red Cloud は X 上での企業ニュースと関連する株式情報の収集に調査を集中しました。Audiense のプラットフォームにより、キャンペーンと、動画再生数やウェブサイトトラフィックの増加として表れる関心の高まりとの間にある、潜在的な相関関係を見つけやすくなりました。

3 段階のアプローチ：

1. まったく新しいオーディエンスを構築する。

    クライアントからの指示を踏まえ、Red Cloud Financial はキャンペーンのターゲットとする 2 つの主要オーディエンスを特定しました。1 つ目のセグメントは鉱業と投資、2 つ目はクリーンテック、電気自動車、ESG および責任ある投資です。X のデータは、将来のキャンペーンに向けてそれらのオーディエンスと確実に整合させるうえで、Red Cloud をさらに支援しました。

1. 新しいオーディエンスをセグメント化する。 

    新しく定義したオーディエンスは幅広い業界を網羅していましたが、その間には多くの共通点がありました。Audiense は、Red Cloud Financial がこれらの新しいセグメントを深掘りし、インフルエンサー、コンテンツ消費の傾向などを特定するのに役立ちました。これらのインサイトは、どのアカウントをフォローすべきかを判断するうえでも有用で、フォロー返しを期待しつつ、Red Cloud とクライアント双方のオーディエンス拡大につなげました。

1. どれが最も価値が高いかを判断する。 
    
    どれが最も価値が高いかを判断するために、Audiense の [Targeting Pack 機能](https://help.audiense.com/knowledge/what-is-a-targeting-pack)を使って、Red Cloud は精緻にターゲティングされた有料 X 広告キャンペーンを作成すると同時に、蓄積された X セグメントのデータをオーガニックキャンペーンに活用しました。Targeting Pack 機能から得られたインサイトを活かして、Audiense と Red Cloud は 2 つのオーディエンスをそれぞれ対象とする 2 本の独自の動画を制作しました。これにより、どの動画が一貫して最も高い成果を上げるキャンペーンであるかを見極め、ターゲティングをぶらすことなく進めることができました。

<div id="impact">
  ## 成果
</div>

Audiense のプラットフォームと X 上でのリサーチにより、Red Cloud は適切なオーディエンスを見つけ出してセグメント化し、それらを活用してフォロワーを増やすとともに、オーガニックおよび有料コンテンツ双方のソーシャルメディア全体戦略の立案に役立てることができました。

Red Cloud Financial はクライアントの期待を上回る成果を上げました。実際、キャンペーンの結果が非常に良好だったため、クライアントは次のキャンペーンを実施し、その規模をさらに拡大することを決定しました。 

- 複数のキャンペーン合計で 350 万回超のインプレッションと 280 万回超の総ビューを獲得
- クライアントの新しい特許出願中テクノロジーに関連する会話量が増加
- 新テクノロジーに関するプロモーション記事とプレスリリースからの 7,000 人の新規訪問者を含め、ウェブサイトへのリファラルトラフィックが増加していることを確認

これは、X 上のオーディエンス分析とターゲティングが、新たなオーディエンスへのリーチ、マーケティングキャンペーンの精緻化、そして実際の成果創出にどのように貢献できるかを示す好例です。クライアントのブランド構築とビジネスの成長を支援する、またとない好機となり得ます。
