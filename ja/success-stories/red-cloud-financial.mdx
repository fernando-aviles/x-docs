<Note>
**要点のまとめ**

成功への道筋：Red Cloud Financial Services は、ある鉱業会社から新しいグリーンテクノロジーのマーケティング支援を依頼された際、X のアナリティクスに基づいて構築された Audiense のターゲティングツールを活用し、データを掘り起こして新たなオーディエンスにリーチしました。
</Note>

<div id="situation">
  ## 状況
</div>

Red Cloud Financial Services は、上場鉱業会社クライアントが開発した新しい特許出願中のテクノロジーについて、まったく新しいオーディエンスの間で認知を高める支援をする役割を担っていました。 

この企業は、新たな地域へ進出し、その新しい顧客層にリーチできるキャンペーンを効果的に展開するために、この新製品で成果を出す方法を見つけなければなりませんでした。 

この依頼には、2 つの大きな課題がありました。 

1. **新しいオーディエンスへのリーチ**

    既存の鉱業系顧客にフォーカスするのではなく、クライアントの新テクノロジーは、グリーンイノベーションや社会的責任に関心を持つ、より広いセグメントに訴求するものでした。これは Red Cloud にとって未知の領域であり、それまで実施してきたキャンペーンとはまったく異なるものでした。

1. **具体的な ROI の提示**
    
    クライアントは有料キャンペーンに慣れていませんでした。Red Cloud にとって、認知向上を目的としたキャンペーンの ROI を明確に示し、かつ自社がほとんど直接経験を持たないオーディエンスから成果を出すことが求められたのは、非常にハードルの高い課題でした。 
    
    Red Cloud は、既存顧客にリーチしつつ新規見込み顧客を調査するために、Audiense に支援を求めました。Audiense の X マーケティングプロダクトは、強力なオーディエンスターゲティングツールを用いて、インパクトのある X キャンペーンを実現することを専門としています。

<div id="solution">
  ## Solution
</div>

Red Cloud は、まず期待値のすり合わせから着手しました。Audiense から得られるインサイトを活用してキャンペーンのパフォーマンス予測を作成し、キャンペーンの最終目標と、それに紐づく KPI についてクライアントの期待値を適切に設定することができました。 

Audiense の支援を受けて、Red Cloud は企業ニュースや関連する株式情報を収集する主要な情報源として X にリサーチを集中させました。Audiense のプラットフォームにより、キャンペーンと、動画再生数の増加やウェブサイトトラフィックの増加といった関心の高まりとの間に潜在的な相関関係を見つけることが容易になりました。

3 段階のアプローチ:

1. まったく新しいオーディエンスを構築する。

    クライアントからの指示を受けて、Red Cloud Financial はキャンペーンの対象として集中すべき 2 つの主要オーディエンスを特定しました。1 つ目のセグメントには鉱業と投資、2 つ目にはクリーンテック、電気自動車、ESG、責任ある投資が含まれていました。X のデータは、将来のキャンペーンに向けてこれらのオーディエンスのターゲットを最適化するうえで、Red Cloud をさらに支援しました。

1. 新しいオーディエンスをセグメント化する。 

    新しいオーディエンスは幅広い業界をカバーしていましたが、その間には多くの共通点がありました。Audiense は、Red Cloud Financial がこれらの新しいセグメントを掘り下げ、インフルエンサー、コンテンツ消費の傾向などを特定するのに役立ちました。これらのインサイトは、どのアカウントをフォローすべきかを判断する際にも役立ち、その結果、相互フォローによって Red Cloud およびクライアントのオーディエンス拡大につながることが期待されました。

1. どれが最も価値が高いかを判断する。 
    
    どれが最も価値が高いかを判断する。Audiense の [Targeting Pack 機能](https://help.audiense.com/knowledge/what-is-a-targeting-pack) を使って、Red Cloud は高精度にターゲティングされた有料の X 広告キャンペーンを作成し、同時に蓄積された X セグメント向けのデータをオーガニックキャンペーンに活用しました。Targeting Pack 機能から得られたインサイトを活用し、Audiense と Red Cloud は 2 つのオーディエンスそれぞれをターゲットにした 2 本の独自の動画を作成しました。これにより、どの動画が一貫して最も高い成果を上げるキャンペーンであるかを特定し、ターゲティングの方向性を維持し続けることができました。

<div id="impact">
  ## 成果
</div>

Audiense のプラットフォームと X 上でのリサーチは、Red Cloud が適切なオーディエンスを発見してセグメント化し、それらを活用してフォロワーを増やすとともに、オーガニックと有料コンテンツの双方を含むソーシャルメディア全体の戦略立案に役立ちました。

Red Cloud Financial は、クライアントの期待を上回りました。実際、キャンペーンの成果が非常に良好だったため、クライアントはさらなるキャンペーンの実施とその拡大に踏み切りました。 

- すべてのキャンペーン合計で、350 万回超のインプレッションと 280 万回超の総ビュー数を獲得
- クライアントの新しい特許出願中テクノロジーに関連する会話量が増加
- 自社サイトへの参照トラフィックが増加し、新テクノロジーに関するプロモーション記事およびプレスリリースから 7,000 人の新規訪問者を獲得

これは、X 上でのオーディエンス分析とターゲティングが、新たなオーディエンスへのリーチ、マーケティングキャンペーンの精緻化、そして具体的な成果の創出にどのように役立つかを示す好例です。クライアントのブランド構築とビジネス拡大を支援できる絶好の機会となり得ます。
