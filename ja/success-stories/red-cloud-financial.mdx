<Note>
**要点まとめ**

成功に向けて順調に前進中：Red Cloud Financial Services は、ある鉱業会社から新しいグリーンテクノロジーのマーケティング支援を依頼された際、X の分析に基づいて構築された Audiense のターゲティングツールを活用してデータを「採掘」し、新たなオーディエンスにリーチしました。
</Note>

<div id="situation">
  ## 状況
</div>

Red Cloud Financial Services は、上場している鉱業会社のクライアントから、新たに開発した特許出願中の技術について、まったく新しいオーディエンスの間で認知を高める支援を依頼されました。 

同社は、この新製品で成果を上げて新たな市場へと展開し、その新規顧客にリーチできるキャンペーンを効果的に実施する方法を見つける必要がありました。 

この依頼には、2 つの主要な課題がありました。 

1. **新しいオーディエンスへのリーチ**

    既存の鉱業顧客にフォーカスするのではなく、クライアントの新技術は、グリーンイノベーションや社会的責任に関心を持つ、より広いセグメントに訴求するものでした。これは Red Cloud にとって未知の領域であり、これまでに実施してきたキャンペーンとはまったく異なるものでした。

1. **具体的な ROI を示すこと**
    
    クライアントは有料キャンペーンに慣れていませんでした。認知向上を目的としたキャンペーンの ROI を Red Cloud が明確に示し、さらに自社がほとんど直接的な経験を持たないオーディエンスから結果を出すことが期待されており、それは非常に難しい課題でした。 
    
    Red Cloud は、既存顧客にリーチしつつ新規見込み顧客の調査を行うために Audiense に依頼しました。Audiense の X マーケティング向けプロダクトは、強力なオーディエンスターゲティングツールを用いて、インパクトのある X キャンペーンを提供することを専門としています。

<div id="solution">
  ## ソリューション
</div>

Red Cloud は、まず期待値の設定から着手しました。Audiense のインサイトを活用してキャンペーンのパフォーマンス予測を作成することで、Red Cloud はクライアントに対し、キャンペーンの最終目標とそれに紐づく KPI についての期待値を明確にすることができました。 

Audiense の支援を受けながら、Red Cloud は X 上でのリサーチに注力し、企業ニュースや関連する株式情報の収集を行いました。Audiense のプラットフォームにより、キャンペーンと、動画再生数やウェブサイトトラフィックの増加として表れる関心の高まりとの間にある潜在的な相関関係を簡単に見つけることができました。

3 段階のアプローチ：

1. まったく新しいオーディエンスを構築する。

    クライアントからの指示を踏まえ、Red Cloud Financial はキャンペーンのターゲットとする 2 つの主要オーディエンスを特定しました。1 つ目のセグメントは鉱業（マイニング）と投資、2 つ目はクリーンテック、電気自動車、ESG、責任投資です。X のデータは、将来のキャンペーンに向けて、それらのオーディエンスとの整合をさらに高めるのに役立ちました。

1. 新しいオーディエンスをセグメント化する。 

    新しいオーディエンスは幅広い業界を網羅していたものの、その間には多くの共通点がありました。Audiense は、Red Cloud Financial がこれらの新しいセグメントを掘り下げ、インフルエンサーやコンテンツ消費傾向などを特定するのに役立ちました。これらのインサイトにより、どのアカウントをフォローすべきかを判断し、相互フォローによる Red Cloud およびクライアントのオーディエンス拡大につなげることができました。

1. どれが最も価値が高いかを判断する。 
    
    どれが最も価値が高いかを判断するために、Audiense の [Targeting Pack 機能](https://help.audiense.com/knowledge/what-is-a-targeting-pack)を活用して、Red Cloud は高精度にターゲティングした有料の X 広告キャンペーンを作成しつつ、蓄積された X セグメントのデータをオーガニックキャンペーンに利用しました。Targeting Pack 機能から得られたインサイトを活用し、Audiense と Red Cloud は 2 つのオーディエンスそれぞれをターゲットとする 2 本のユニークな動画を制作しました。その結果、どの動画が一貫して最も高いパフォーマンスを示すキャンペーンであるかを特定し、狙いを外すことなくターゲティングを維持することができました。

<div id="impact">
  ## 成果
</div>

Audiense のプラットフォームと X 上でのリサーチにより、Red Cloud は適切なオーディエンスを見つけてセグメント化し、そのオーディエンスを活用してフォロワーを増やすとともに、オーガニックおよび有料コンテンツの両方における全体的なソーシャルメディア戦略の立案に役立てることができました。

Red Cloud Financial はクライアントの期待を上回る成果を上げました。実際、キャンペーンの結果が非常に良好だったため、クライアントはさらに次のキャンペーンを実施し、その規模を拡大することを決定しました。 

- 複数のキャンペーンを合計して 350 万回超のインプレッションと 280 万回超の総ビューを獲得
- クライアントの新しい特許出願中のテクノロジーに関連する会話量が増加
- 新テクノロジーに関するプロモーション記事とプレスリリースからの 7,000 人の新規訪問者を含め、ウェブサイトへのリファラルトラフィックの増加を確認

これは、X 上のオーディエンス分析とターゲティングが、新たなオーディエンスの開拓、マーケティングキャンペーンの最適化、そして実際の成果の創出にどのように役立つかを示す好例です。クライアントのブランド構築とビジネス拡大を支援する絶好の機会になり得ます。
