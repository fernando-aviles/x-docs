<div id="situation">
  ## 状況
</div>

これまで、デジタルマーケターは自社のデータを統合的に把握できていませんでした。あるシステムにはオーガニックデータがあり、別のシステムには有料データがあり、会話はさらに別の場所から発生している、といった状況です。しかし、クライアントやステークホルダーから「昨日は何インプレッション獲得しましたか？」に続けて「そのうちオーガニックと有料の内訳はどうなっていますか？」といった質問を受ける中で、こうしたデータを効率的に集約・解釈する手段の必要性はこれまで以上に高まっています。

こうした課題を解決するため、10年以上にわたり X Developer Platform を基盤としてきたソーシャル分析プラットフォーム ListenFirst は、オーガニックおよび有料の X データを、単一の信頼できる情報源として収集できるツールを構築する必要がありました。従来、このオーガニックデータと有料データは、異なるプラットフォームや API、エンドポイントにまたがる別々のサイロに分断されており、集約したり、集計したり、あるいは組み合わせて活用したりすることは、まったく想定されていませんでした。

<div id="solution">
  ## 解決策
</div>

クライアント向けのインサイトをより効率的に導き出す方法を模索する中で、ListenFirst は X の v2 エンドポイントを採用し、ユーザーが X 上で話している内容を自社プラットフォームに反映するプロセスを合理化しました。ListenFirst のチームは、「よりクリーンなデータを作る」という明確な目標を掲げて取り組みを進めました。

> *「私たちにとって v2 を活用することは、統合の最適化そのものです。自社サイト上で組み合わせなければならない要素が少なければ少ないほど、運用が容易になり、より多くのブランド、より多くのコンテンツ、そしてより良いインサイトへと、私たちの提供価値を拡張できるのです。」*
> 
> - ListenFirst Chief Product Officer, Jonathan Farb

X の v2 API、特に Tweets lookup エンドポイントの採用をチームが優先した理由は、エンゲージメント数とインプレッション数の精度でした。このエンドポイントを利用することで、ListenFirst は、自社の顧客が他の場面で目にするネイティブの X アナリティクス上の数値と整合性の取れた、より信頼性の高いメトリクスを生成できるようになりました。

<div id="impact">
  ## 影響
</div>

まだ初期段階ではありますが、v2 を採用したことで ListenFirst の効率は向上しています。以前は、ListenFirst は複数の API 群からデータをつなぎ合わせる必要があり、その数値はネイティブのアナリティクスで確認できるものと一致していませんでした。v2 を利用することで、ListenFirst の数値は X のネイティブアナリティクスとより整合するようになり、精度と顧客からの信頼が向上しました。現在、ListenFirst は、ブランドが X 上でマーケティング戦略を完成させるのに役立つ、根拠を示せる精緻なインサイトを提供できています。ListenFirst は、v2 をさらに活用することで、精度と透明性を高め、クライアント向け指標に対する信頼を一層向上できると考えています。
