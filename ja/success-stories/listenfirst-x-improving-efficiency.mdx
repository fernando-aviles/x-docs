<div id="situation">
  ## 状況
</div>

これまでデジタルマーケターは、自社のデータを一元的に把握する手段を持っていませんでした。あるシステムにはオーガニックデータ、別のシステムには有料データがあり、会話はまた別のチャネルで発生するといった状況が一般的でした。一方で、クライアントやステークホルダーからは「昨日はどれくらいのインプレッション数を獲得したか？」に続けて「そのうちオーガニックと有料の割合はどうなっているのか？」といった質問が寄せられるようになり、こうしたデータを集約し解釈するための、よりシンプルで効率的な方法の必要性がこれまで以上に高まっています。

こうした課題を解決するため、ソーシャルアナリティクスプラットフォームであり、10年以上にわたり X Developer Platform 上に構築されてきた ListenFirst は、オーガニックと有料の X データを「単一の信頼できる情報源」から収集できるツールを作る必要がありました。従来、このオーガニックデータと有料データは、異なるプラットフォーム、API、エンドポイントにまたがる個別のサイロに存在しており、集約・合算・ブレンドして活用することはまったく想定されていませんでした。

<div id="solution">
  ## 解決策
</div>

クライアント向けのインサイトをより効率的に生み出す方法を模索する中で、ListenFirst は X の v2 エンドポイントを採用し、X 上でユーザーがどのような会話をしているかを自社プラットフォームに取り込むプロセスを効率化しました。ListenFirst のチームは、「よりクリーンなデータを作る」という明確な目標を掲げて作業に取り組みました。

> *「私たちにとって v2 を活用することは、統合の最適化です。自社サイト上で組み合わせる必要がある要素が少なければ少ないほど、運用が容易になり、より多くのブランド、より多くのコンテンツ、そしてより優れたインサイトへと提供範囲を拡大することができます。」*
> 
> - ListenFirst Chief Product Officer、Jonathan Farb

X の v2 API、特に Tweets lookup エンドポイントの採用を優先した理由は、エンゲージメント数とインプレッション数の精度でした。このエンドポイントを活用することで、ListenFirst は、顧客が他のネイティブな X アナリティクスで目にする数値と整合した、より信頼性の高い指標を生成できるようになりました。

<div id="impact">
  ## 影響
</div>

まだ初期段階ではあるものの、v2 の採用によって ListenFirst の効率性は向上しています。これまで ListenFirst は、複数の API 群からデータをつなぎ合わせる必要があり、その数値はネイティブのアナリティクスで確認できるものと一致していませんでした。v2 を利用することで、ListenFirst の数値は X のネイティブアナリティクスにより近づき、精度と顧客からの信頼が向上しました。現在、ListenFirst は、ブランドが X 上でマーケティング戦略を完成させるのに役立つ、説明可能で洗練されたインテリジェンスを提供できるようになっています。ListenFirst は、v2 をさらに活用することで、精度と透明性を高め、クライアント向けの指標に対する信頼を強化できると考えています。
