<div id="situation">
  ## 状況
</div>

従来、デジタルマーケターは自分たちのデータを統合的に把握することができていませんでした。あるシステムにはオーガニックのデータがあり、別のシステムには有料のデータがあり、会話データはまた別の場所にある、といった状況です。しかし、クライアントやステークホルダーから「昨日、どれくらいインプレッションを獲得しましたか？」に続けて「そのうち、オーガニックと有料の内訳はどうなっていますか？」といった質問を受ける中で、こうしたデータを集約し、解釈するための効率的な方法の必要性は、これまでになく高まっています。

こうした課題を解決するために、X Developer Platform を活用して 10 年以上にわたり構築されてきたソーシャルアナリティクスプラットフォームである ListenFirst は、単一の信頼できる情報源からオーガニックおよび有料の X データを収集するためのツールを作成する必要がありました。これまで、このオーガニックおよび有料データは、異なるプラットフォーム、API、エンドポイント間で別々のサイロに分かれて存在しており、集約したり、合算したり、あるいは統合して分析したりすることを想定して設計されてはいませんでした。

<div id="solution">
  ## 解決策
</div>

クライアント向けのインサイトをより効率的に導き出す方法を模索する中で、ListenFirst は X の v2 エンドポイントを採用し、X 上でユーザーが話している内容を自社プラットフォームに取り込むプロセスを効率化しました。ListenFirst のチームは、「よりクリーンなデータを作る」という明確な目標を掲げて取り組みを開始しました。

> *「私たちにとって v2 を活用することは、インテグレーションの最適化にほかなりません。自社サイト上で組み合わせる必要がある要素が少なくなればなるほど、運用が容易になり、より多くのブランド、より多くのコンテンツ、そしてより優れたインサイトへと提供内容をスケールさせることができます。」*
> 
> - ListenFirst Chief Product Officer、Jonathan Farb

ListenFirst のチームが X の v2 API、特に Tweets lookup エンドポイントの採用を優先した理由は、エンゲージメント数とインプレッション数の精度にありました。このエンドポイントを活用することで、ListenFirst は、顧客がネイティブの X アナリティクスで目にする数値と整合した、より信頼性の高いメトリクスを生成できるようになりました。

<div id="impact">
  ## 影響
</div>

まだ初期段階ではありますが、v2 の採用は ListenFirst の効率性向上に寄与しています。これまで ListenFirst は、複数の API セットから取得したデータをつなぎ合わせる必要があり、その数値はネイティブのアナリティクスで確認できる値と一致していませんでした。v2 を活用することで、ListenFirst の数値は X のネイティブアナリティクスとの整合性が高まり、精度と顧客からの信頼が向上しました。現在、ListenFirst は、ブランドが X 上でマーケティング戦略を完結できるよう、根拠が明確で洗練されたインテリジェンスを提供できるようになりました。ListenFirst は、v2 をさらに導入していくことで、精度と透明性を高めることにより、クライアントに提供する指標に対する信頼が強化されると考えています。
