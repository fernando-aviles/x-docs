<div id="situation">
  ## 状況
</div>

COVID-19 の流行拡大に伴い、アジア系アメリカ人および太平洋諸島系住民（AAPI）に向けられたヘイト事件が増加しました。こうした事件の一部はニュースで報道されましたが、何千人もの人々が、調査、アドボカシー（提言活動）、支援体制の強化を通じてヘイト事件に対応・対処している全米報告センター [Stop AAPI Hate](https://stopaapihate.org/) に報告を行っていました。この時期に、[The American Asian Foundation (TAAF)](https://www.taaf.org/) が設立されました。この団体は、X を活用して、こうした事件が標的となった人々にどのような個人的影響を与えているのかを、新たな視点から示そうとしたチームを牽引する存在となりました。

<div id="solution">
  ## ソリューション
</div>

2人のエンジニアから成る小さなチームは、インシデントデータの情報源としてXに着目しました。彼らがこのプラットフォームを選んだ理由は2つあります。1つ目は、ニュースや人々のアイデアや考え、日常生活の出来事、コミュニティで起きている出来事など、豊かで多様な情報が含まれていることです。これにより、Xはさまざまな層の人々からなる母集団に関する、ユニークで親密なサンプルを提供します。2つ目は、TAAFの開発者がdataへアクセスできる真にオープンなAPIを備えた唯一のプラットフォームであり、そのdataを収集・分析するための高度なツールを提供していることです。 

X API v2 の search Tweets および Tweets lookup エンドポイントを使って、チームは投稿のステータスを検索し、人々がヘイトインシデントを報告したタイミング（さらにはどのハッシュタグを使っていたかまで）を特定できました。これにより、チームは1023文字の検索クエリを設計し、何十億件もの投稿を、チームが扱える規模まで絞り込むことができました。 

次のステップは、その投稿が本当にヘイトインシデントに関するものであるかどうかを検証する作業でした。チームは自然言語処理を用いたツールを開発し、何千件もの投稿の中からこのプロジェクトに関連するものをふるい分けられるようにしました。学習済みの機械学習モデルを適用した後、精度をさらに高めるために、人間の目による検証も行いました。 

2021年、TAAFはStop AAPI Hate連合とともに、[Documenting Anti-AAPI Hate Codebook](https://stopaapihate.org/wp-content/uploads/2021/12/SAH-x-TAAF-Codebook-FINAL-2021-08-19.pdf) の共著も行いました。このリソースには、コミュニティベースのデータ収集のための標準や実務に関するドラフトが含まれており、人々がX上で共有していたインシデントをチームが分類するうえで役立ちました。 

そこからの次の課題は、このデータを人々が容易に理解できる形で提示することでした。TAAFはデータ可視化ツール [Decoding Hate](https://decodinghate.taaf.org/) を作成し、膨大なデータ量をインタラクティブに表示できるようにしました。データビジュアライゼーションスタジオの協力を得て、注釈付きのXのdataを活用し、何千件もの投稿を、AAPIコミュニティで何が起きていたのかという真実を明らかにする洞察に富んだストーリーへと変換することができました。

<div id="impact">
  ## 影響
</div>

Decoding Hate プロジェクトは、これまで報告されてこなかった何千件ものヘイト関連の事案を検知することに貢献し、現在もその役割を果たし続けています。このプロジェクトは、AAPI コミュニティの中で起きている個々の体験への認知を高めるための継続的なツールとなりました。

今後のフェーズでは、TAAF は Stop AAPI Hate と提携し、X 上でヘイト事案を報告した人々一人ひとりに対して、人間の担当者による個別対応をパイロット的に実施します。このフェーズでは、Stop AAPI Hate が、自身が経験したヘイトについて投稿している多くの人々と積極的に関わり合い、[Stop AAPI Hate Reporting Center](https://stopaapihate.org/) を通じて事案を報告するよう促します。より多くの人が Stop AAPI Hate に報告するほど、この連合組織とそのパートナーは、現在発生しているヘイト事案の性質をより正確に把握でき、最も効果的な政策的解決策を提唱できるようになります。 

AAPI コミュニティで起きているヘイト関連の事案を明らかにするだけでなく、このプロジェクトは X の API の価値にも光を当てています。この事例は、適切なデータを適切なツールと組み合わせて活用することで、開発者が公益のためのイノベーションを X 上で実現できることを示しています。
