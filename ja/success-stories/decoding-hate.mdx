<div id="situation">
  ## 状況
</div>

COVID-19 の流行後、アジア系アメリカ人および太平洋諸島系アメリカ人（AAPI）を対象としたヘイト事案が増加しました。こうした事案の一部はニュースで取り上げられましたが、何千人もの人々が、調査・アドボカシー・能力構築を通じてヘイト事案に対応・対処している全米報告センター [Stop AAPI Hate](https://stopaapihate.org/) に報告を行っていました。この時期に、[The Asian American Foundation (TAAF)](https://www.taaf.org/) が設立されました。この団体は、こうした事案が被害を受けた人々にどのような影響を及ぼしているのかを示す新たな手段として X を活用しようとしたチームを主導する存在となりました。

<div id="solution">
  ## 解決策
</div>

2人のエンジニアから成る小規模チームは、インシデントデータの情報源としてXに注目しました。彼らがこのプラットフォームを選んだ理由は2つあります。1つ目は、ニュース、人々の考えや意見、日常生活の出来事、地域社会で起きていることなど、豊かで多様な情報を含んでいることです。これにより、Xはさまざまな集団に属する人々についての、独自かつ身近なサンプルを提供します。2つ目は、TAAFの開発者がデータにアクセスできる真にオープンなAPIを持つ唯一のプラットフォームであり、そのデータを収集・分析するための高度なツールを備えていることです。 

X API v2 の search Tweets および Tweets lookup エンドポイントを利用することで、チームは投稿内容を検索し、人々がヘイトインシデントを報告したタイミング（さらに、どのハッシュタグを使っているかまで）を特定することができました。これによってチームは、数十億件の投稿を、扱える件数まで絞り込む1023文字の検索クエリを設計できました。 

次の課題は、その投稿が実際にヘイトインシデントについてのものかどうかを検証することでした。チームは自然言語処理を用いたツールを開発し、数千件の投稿をふるいにかけて、プロジェクトに関連するものを見つけられるようにしました。学習済み機械学習モデルを適用した後、精度をさらに高めるために、人間の手で投稿を検証しました。 

2021年、TAAFは Stop AAPI Hate 連合と共同で [Documenting Anti-AAPI Hate Codebook](https://stopaapihate.org/wp-content/uploads/2021/12/SAH-x-TAAF-Codebook-FINAL-2021-08-19.pdf) も執筆しました。このリソースには、地域コミュニティ主導のデータ収集のための標準と実務の草案が含まれており、人々がX上で共有しているインシデントをチームが分類するのに役立ちました。 

次の課題は、このデータを人々が容易に理解できる形で提示することでした。TAAFは膨大な量のデータをインタラクティブに表示するデータ可視化ツール [Decoding Hate](https://decodinghate.taaf.org/) を作成しました。データ可視化スタジオの協力を得て、注釈付きのXのデータを活用し、数千件の投稿を、AAPIコミュニティで実際に起きていた事象の真実を明らかにする洞察に富んだストーリーへと変換することができました。

<div id="impact">
  ## 影響
</div>

Decoding Hate プロジェクトは、これまでほとんど報告されてこなかった何千件ものヘイト関連事案の検知に貢献しており、現在もその役割を果たし続けています。このプロジェクトは、AAPI コミュニティ内で起きている一人ひとりの経験への認知を広げるための継続的なツールとなっています。

次のフェーズの取り組みとして、TAAF は Stop AAPI Hate と提携し、X 上でヘイト事案を報告した人々に対して、人による個別対応を試験的に行います。このフェーズでは、Stop AAPI Hate が、自身の経験したヘイトについて投稿している多くの人々と積極的にやり取りし、[Stop AAPI Hate Reporting Center](https://stopaapihate.org/) を通じて事案を報告するよう促します。Stop AAPI Hate への報告が増えれば増えるほど、連合体とそのパートナーは、発生しているヘイト事案の実態をより深く理解し、最も効果的な政策的解決策を提言できるようになります。 

AAPI コミュニティで起きているヘイト関連事案を可視化するだけでなく、このプロジェクトは X の API の価値にも光を当てています。この事例は、適切なツールと適切なデータを活用することで、開発者が良い目的のために X を使ってイノベーションを起こせることを示しています。
