<Note>
**要点は以下のとおりです**

開発者兼クリエイターである Aaron Ng が、X の API を活用して、X 上のネットワークを検索できる検索エンジン「Flocknet」をどのように構築したかを紹介します。ユーザーは Flocknet を利用してネットワークを拡大し、人材を採用し、投資先候補を探しています。当初は彼自身の個人的な利用のために構築された Flocknet は、今では X 上で数百万件の連絡先を管理する手助けをしています。
</Note>

<div id="challenge">
  ## 課題
</div>

Aaron Ng がニューヨークで開催されたデザインカンファレンスに参加したとき、彼は自分と同じ業界の人たちとつながり、実際に会いたいと考えていました。ところがそのとき、つながることは、たとえ X 上のデザイナー仲間であっても、自分が思っていた以上に難しいことだと気づきました。彼のコミュニティの多くは、特に業界の友人たちは X を利用していました。果たして、自分の友人のうち誰がその街に来ているのかを知る手段はないのだろうか。誰が近くにいるのかわからないまま、どうやって業界のつながりのある人たちと再会すればいいのだろうか。

Aaron はすぐに、この課題をチャンスと捉えました。そして、その起業家精神から、Flocknet が生まれました。 

<div id="solution">
  ## ソリューション
</div>

わずか週末の間に Aaron は、自分の X ネットワーク上の人々や友人、他のプロフェッショナルを、彼らのツイートを見なくても検索・ソートし、最新の動向を追えるプロダクトを構築することができました。彼はこの Project で X の API を使うことを選び、「質問があれば聞ける相手がいて、そして［X の］チームが気にかけてくれていると分かっていることが、体験をとても良いものにしてくれる」と語っています。さらに、「自分が開発を続けるモチベーションになったコミュニティの多くは X 上にありました──だからこそ X は自分にとってとても重要な場所になったし、自分の利用体験を高めるツールを作りたいと思ったのです」と付け加えています。  

自身の創造性、推進力、経験を組み合わせることで Flocknet が誕生しました。これは、自分の X ネットワーク内の人を見つけるための検索エンジン兼コンタクト管理ツールです。X の follows エンドポイントと Python を活用することで、Flocknet はユーザーがフォロワーを職種、勤務先、所在地、その他多数の属性で検索できるようにします。

当初は自分の個人的な利用を想定していましたが、Flocknet は大きな関心を集め、一般に共有すべきものだと分かりました。そこで彼はすぐに、Flocknet を現在の姿へとスケールアップさせることに注力しました。

<div id="impact">
  ## インパクト
</div>

わずか数か月のうちに、Flocknet はユーザーに代わって数百万件の連絡先を管理するようになりました。特に技術系のプロフェッショナルにとって有用で、採用から投資、その間にあるあらゆる用途にまで幅広く活用されています。実際、Aaron 自身も Flocknet を通じて人材を採用しています。

しかし、Aaron はまだ満足していません。寄せられる新機能リクエストに注目しながら、製品を拡張する方法を常に模索し続けています。

最終的に Aaron は、主な活動の場が X にあるコミュニティのメンバーであれば誰でも、より良い体験が得られるようなメタプラットフォームへと X を変える方法を見出しました。彼はこう語ります。「とにかくたくさんのものを作っています。そして、自分にとって役に立ち、ほかの人にとっても役に立つものを作るのが大好きなんです」。そして、まさにそのとおりのことを成し遂げたのです。
