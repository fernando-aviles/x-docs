<Note>
**概要**

開発者でありクリエイターでもある Aaron Ng 氏は、X の API を活用して、あなたの X 上のネットワークを検索できる検索エンジン Flocknet を開発しました。人々は Flocknet を使ってネットワークを拡大し、優秀な人材を採用し、投資リードを獲得しています。もともとは自分自身の個人的な利用のために構築された Flocknet は、今では多くの人が X 上の数百万件の連絡先を管理するのに役立っています。
</Note>

<div id="challenge">
  ## 課題
</div>

Aaron Ng がニューヨークで開催されたデザインカンファレンスに参加したとき、彼は同じ業界の人たちとつながり、直接会いたいと考えていました。ところがそのとき、彼は自分のデザイナー仲間たちとでさえ、X 上でつながることが想像以上に難しいと気づきました。彼のコミュニティの多くは X 上におり、特に業界の友人たちはほとんどそこにいました。自分の友人のうち誰が街に来ているのか、知る方法はないのだろうか？誰が近くにいるかわからないまま、どうやって業界のつながりと再会すればよいのだろうか？

Aaron はすぐに、この課題をチャンスとして捉えました。そして、その起業家精神から、Flocknet が誕生しました。 

<div id="solution">
  ## ソリューション
</div>

わずか1週末で、Aaron はツイートを見なくても、自分の X ネットワーク内の人々、友人、その他のプロフェッショナルを検索・ソートし、その動向を追い続けられるプロダクトを構築しました。彼はこのプロジェクトで X の API を使うことを選び、「質問があれば聞ける相手がいて、しかも [X の] チームがきちんと気にかけてくれているとわかるのは、とても良い体験です」と語っています。さらに「自分が作り続けるモチベーションを与えてくれたコミュニティの多くは X 上にありました。だからこそ、X は自分にとってとても重要な場所になったし、もっと便利に使えるようなツールを作りたいと思ったのです」と付け加えています。  

自身の創造性、情熱、そして経験を組み合わせて、Flocknet は誕生しました。これは、X ネットワーク内の人々を見つけるための検索エンジン兼連絡先管理ツールです。X の Follows エンドポイントと Python を活用することで、Flocknet はユーザーが自分のフォロワーを、職種、勤務先、所在地、その他多数の属性で検索できるようにしています。

当初は自分だけの個人的な利用を想定していましたが、Flocknet には非常に大きな反響があり、共有すべきものだと確信するようになりました。そこで彼はすぐに開発の方向性を切り替え、Flocknet を現在の形になるまでスケールさせることに注力しました。

<div id="impact">
  ## インパクト
</div>

ほんの数か月のうちに、Flocknet はユーザーに代わって数百万件のコンタクトを管理するようになりました。特に技術系のプロフェッショナルに重宝されており、採用から投資、その間にあるあらゆる用途にまで幅広く利用されています。実際、Aaron 自身も Flocknet を通じて人材を採用しています。 

しかし、Aaron の挑戦はまだ終わっていません。寄せられる新機能リクエストに注目しながら、プロダクトを拡張する方法を常に模索し続けています。 

最終的に Aaron は、コミュニティの主な活動場所が X にあるあらゆる人の体験を向上させる「メタプラットフォーム」として X を活用する方法を見つけました。彼はこう語っています。「とにかくいろいろ作るんだ。自分にも役に立って、ほかの人にも役に立つものを作るのが大好きなんだ」と。そして、まさにそのとおりのことをやってのけました。
