<Note>
**要点は以下のとおりです**

開発者兼クリエイターである Aaron Ng が、X の API を使って、自分の X 上のネットワーク向け検索エンジン「Flocknet」をどのように構築したかを紹介します。人々は Flocknet を活用してネットワークを拡大したり、優秀な人材を採用したり、投資案件のリードを獲得したりしています。もともとは彼自身の個人的な利用のために構築された Flocknet は、現在では X 上で数百万件におよぶつながりを管理する手助けをしています。
</Note>

<div id="challenge">
  ## 課題
</div>

Aaron Ng がニューヨークで開催されたデザインカンファレンスに参加したとき、同じ業界の人たちとつながり、実際に会いたいと考えていました。ところがそのとき彼は、自分のデザイナー仲間たちとさえ、X 上でつながることが想像以上に難しいということに気づきました。彼のコミュニティの多くは X を利用しており、とくに業界の友人たちはほとんどが X にいました。自分の友人のうち、誰がニューヨークに来ているのかを知る方法はないのだろうか。どの知り合いが近くにいるのかわからないまま、どうやって業界の人脈と再会できるのだろうか。

Aaron はすぐに、この課題をビジネスチャンスとして捉えました。そして彼の起業家精神から、Flocknet が誕生しました。 

<div id="solution">
  ## ソリューション
</div>

わずか週末の間に Aaron は、自分の X ネットワーク内の人々、友人、その他のプロフェッショナルを、ツイートを見なくても検索・ソートし、最新情報を追い続けられるプロダクトを構築しました。彼はこのプロジェクトに X の API を使うことを選び、「質問できる相手がいるとわかっていて、さらに X のチームが気にかけてくれているとわかると、体験がとても良いものになる」と語ります。さらに「自分の開発を続けるモチベーションになっていたコミュニティの多くが X 上にありました――だからこそ X は自分にとってとても重要な場所になっていて、自分の利用体験を高めるツールを作りたいと思ったのです」と付け加えています。  

自身の創造性、推進力、経験を組み合わせることで、Flocknet が誕生しました。これは、自分の X ネットワーク内で人を見つけるための検索エンジン兼コンタクト管理ツールです。X の follows エンドポイントと Python を活用することで、Flocknet はユーザーがフォロワーを職種、勤務先、所在地、その他多数の属性で検索できるようにします。

当初は自分用に作られたツールでしたが、Flocknet には非常に大きな関心が集まり、共有すべきものだと彼は確信しました。そこで彼はすぐに、Flocknet を現在の姿にまでスケールさせることに注力するよう方向転換しました。

<div id="impact">
  ## インパクト
</div>

わずか数か月のうちに、Flocknet はユーザーに代わって数百万件の連絡先を管理するまでになりました。特にテクノロジー業界のプロフェッショナルに重宝されており、採用から投資、その中間にあるあらゆる用途にまで使われています。実際、Aaron 自身も Flocknet を通じて人材を採用してきました。 

しかし、Aaron はまだ歩みを止めていません。寄せられる機能要望に注目しながら、プロダクトを拡張するための方法を継続的に模索しています。 

最終的に Aaron は、コミュニティの主な活動場所が X にある人たちの体験を向上させるために、X をメタプラットフォームへと変える方法を見つけました。彼はこう語ります。「とにかくいろいろなものを作っているだけなんです。そして、自分にとって役に立ち、ほかの人にとっても役に立つものを作るのが大好きなんです」。そして彼は、まさにそのとおりのことを実現しました。
