<div id="general">
  ## 一般
</div>

<AccordionGroup>
  <Accordion title="OAuth とは何ですか?">
    OAuth は、ユーザーがパスワードを共有することなく、自分に代わってアプリケーションが動作することを承認できる認可プロトコルです。詳細は [oauth.net](http://oauth.net/) を参照してください。
  </Accordion>

  <Accordion title="アクセストークンはどのように生成しますか?">
    アクセストークンを生成するには、[X app](/ja/resources/fundamentals/developer-apps) が必要です。アクセストークンの詳細については [こちら](/ja/resources/fundamentals/authentication#oauth-1-0a-2) を参照してください。
  </Accordion>

  <Accordion title="X app はどのように作成しますか?">
    [X app](/ja/resources/fundamentals/developer-apps) を作成するには、[開発者アカウント](/ja/resources/fundamentals/developer-portal) が必要です。サインアップは [こちら](https://developer.x.com/en/portal/petition/essential/basic-info) から行えます。
  </Accordion>

  <Accordion title="すでに X app を持っている場合、そのアプリを表示および編集するにはどうすればよいですか?">
    developer.x.com で X アカウントにログインしている場合は、[X app dashboard](https://developer.x.com/content/developer-twitter/en/apps) からアプリを表示および編集できます。
  </Accordion>
</AccordionGroup>

<div id="technical">
  ## 技術情報
</div>

<AccordionGroup>
  <Accordion title="アクセストークンはどれくらいの期間有効ですか？">
    アクセストークンには明示的な有効期限はありません。ユーザーが自分の X アカウント設定でアプリケーションを明示的に取り消した場合、または X がアプリケーションを停止した場合、そのアクセストークンは無効化されます。アプリケーションが停止されている場合は、[X app](/ja/resources/fundamentals/developer-apps) ダッシュボードに、そのアプリケーションが停止されている旨の注記が表示されます。
  </Accordion>

  <Accordion title="アクセストークンが無効になった場合はどうなりますか？">
    ユーザーのアクセストークンは、いつでも無効に&#95;なる可能性がある&#95;と想定してください。このような状況になった場合は、ユーザーにアプリケーションの再認可を求めてください。この状況を適切に処理することは、良好なユーザー体験を提供するうえで重要です。
  </Accordion>

  <Accordion title="アプリケーション登録ページで読み取り/書き込みアクセスについて尋ねられます。書き込みとは具体的に何を指しますか？">
    多くのユーザーは、アプリケーションによる自分の情報の読み取りは許可しますが、ユーザープロフィール情報の変更や新しい投稿の作成までは必ずしも許可しません。X API を介して情報を更新する場合 — 名前や所在地の変更、新しい投稿の追加など — には、HTTP POST が必要です。HTTP POST を必要とするすべての API メソッドは書き込みメソッドと見なされ、読み取りおよび書き込みアクセス権が必要になります。
  </Accordion>
</AccordionGroup>
