<div id="general">
  ## 全般
</div>

<AccordionGroup>
  <Accordion title="OAuth とは何ですか？">
    OAuth は認証プロトコルであり、ユーザーがパスワードを共有することなく、自分に代わってアプリケーションを操作することを許可できるようにします。詳細は [oauth.net](http://oauth.net/) を参照してください。
  </Accordion>

  <Accordion title="アクセストークンはどのように発行しますか？">
    アクセストークンを発行するには、[X app](/ja/resources/fundamentals/developer-apps) が必要です。アクセストークンの詳細は[こちら](/ja/resources/fundamentals/authentication#oauth-1-0a-2)をご覧ください。
  </Accordion>

  <Accordion title="X app はどのように作成しますか？">
    [X app](/ja/resources/fundamentals/developer-apps) を作成するには、[開発者アカウント](/ja/resources/fundamentals/developer-portal) が必要です。サインアップは[こちら](https://developer.x.com/en/portal/petition/essential/basic-info)から行えます。
  </Accordion>

  <Accordion title="すでに X app を持っている場合、そのアプリを表示および編集するにはどうすればよいですか？">
    developer.x.com で X アカウントにログインしていれば、[X app ダッシュボード](https://developer.x.com/content/developer-twitter/en/apps) からアプリを表示および編集できます。
  </Accordion>
</AccordionGroup>

<div id="technical">
  ## 技術的な内容
</div>

<AccordionGroup>
  <Accordion title="アクセストークンの有効期間はどのくらいですか？">
    アクセストークンに明示的な有効期限はありません。ユーザーが自分の X アカウント設定でアプリケーションを明示的に取り消した場合、または X がアプリケーションを停止した場合、アクセストークンは無効化されます。アプリケーションが停止されている場合は、[X app](/ja/resources/fundamentals/developer-apps) ダッシュボードに、そのアプリケーションが停止されている旨の注記が表示されます。
  </Accordion>

  <Accordion title="アクセストークンが無効になった場合はどうなりますか？">
    ユーザーのアクセストークンは、いつでも無効になる *可能性がある* と想定してください。この状況が発生した場合は、ユーザーにアプリケーションの再認可を求めてください。このケースを適切に処理することは、良好なユーザー体験を提供するうえで重要です。
  </Accordion>

  <Accordion title="アプリケーション登録ページで read/write アクセスについて確認されます。write とは具体的に何を指しますか？">
    多くのユーザーは、アプリケーションに自分の情報を読み取らせることには抵抗がなくても、必ずしもユーザープロフィール情報を変更したり、新しい投稿を行ったりすることまでは許可しません。X API を介して情報を更新する場合、名前や場所の更新、新しい投稿の追加など、いずれも HTTP POST が必要です。HTTP POST を必要とする API メソッドはすべて write メソッドとみなされ、read &amp; write アクセスが必要になります。
  </Accordion>
</AccordionGroup>
