<div id="using-and-generating-an-app-only-bearer-token">
  ### アプリ専用 Bearer Token の使用と生成
</div>

Bearer Token は、開発者が X API を利用する際の、より安全なエントリポイントを提供するものであり、OAuth 2.0 を構成する中核機能の 1 つです。

Bearer Token を使用する認証は、アプリケーション専用認証とも呼ばれます。Bearer Token は、`curl` コマンドのようなスクリプトを使用して生成する、形式が特定されていないバイト配列です。Bearer Token は、App の設定内にある「Keys and tokens」セクションから、開発者コンソールを通じて取得することもできます。この機能の詳細については、[OAuth の公式ドキュメント](https://oauth.net/2/bearer-tokens/)を参照してください。

<div id="when-are-they-used">
  #### いつ使用しますか？
</div>

Bearer Token の使用が必要な製品は次のとおりです。

* [Engagement API](/ja/x-api/enterprise-gnip-2.0/fundamentals/engagement-api)
* [Account Activity API](/ja/x-api/enterprise-gnip-2.0/fundamentals/account-activity)
* v2 や Labs エンドポイントなど、OAuth 2.0 Bearer Token 認証を利用するその他の API です。

<div id="prerequisites">
  #### 前提条件
</div>

[開発者アカウントに登録](https://developer.x.com/en/portal/petition/essential/basic-info)し、[X App](/ja/resources/fundamentals/developer-apps)を作成しておく必要があります。これらを用意したら、[開発者コンソール](/ja/resources/fundamentals/developer-portal)で表示される API キーも取得する必要があります。以下の手順に従ってください。

1. developer.x.com で X アカウントにログインします。
2. [X App ダッシュボード](https://developer.x.com/content/developer-twitter/en/apps)に移動し、アクセストークンを生成したい X App を開きます。
3. 「keys and tokens」ページに移動します。
4. このページに API キー、ユーザーアクセス・トークン、および Bearer Token が表示されます。

<div id="how-to-generate-a-bearer-token">
  ### Bearer Token を生成する方法
</div>

App 用の Bearer Token は、App の他の「Keys and Tokens」と同じ場所で確認できます。

[X App](/ja/resources/fundamentals/developer-apps) から事前に取得した次の consumer API key を自分の値に置き換えたうえで、以下の cURL リクエストをコマンドラインにコピーして実行してください。なお、このページで使用している consumer API key は失効しており、実際のリクエストには使用できません。

* **API key** `<API key>` 例: `xvz1evFS4wEEPTGEFPHBog`
* **API secret key** `<API secret key>` 例: `L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg`

  ```bash
  curl -u "$API_KEY:$API_SECRET_KEY" \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
  ```

以下は、API key を入力した状態の curl リクエスト例です。

```bash
   curl -u 'xvz1evFS4wEEPTGEFPHBog:L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg' \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
```

レスポンスは次のようになります。この Bearer Token はすでに無効化されています:

`{"token_type":"bearer","access_token":"AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F"}`

OAuth 2.0 でリソースにアクセスする際の認証に使われる Bearer Token は次のとおりです:

`AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F`
