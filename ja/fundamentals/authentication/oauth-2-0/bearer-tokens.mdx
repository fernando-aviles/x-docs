<div id="using-and-generating-an-app-only-bearer-token">
  ### アプリ専用 Bearer Token の使用と生成
</div>

Bearer Token により、開発者は X API を利用する際に、より安全なエントリポイントを確保できます。これは OAuth 2.0 の中核的な機能の 1 つです。

Bearer Token を使用する認証は、アプリケーション専用認証とも呼ばれます。Bearer Token は、`curl` コマンドのようなスクリプトを使用して生成する、形式が規定されていないバイト配列です。また、Developer Console の自分の App の設定内にある「Keys and tokens」セクションから Bearer Token を取得することもできます。この機能の詳細については、[OAuth の公式ドキュメント](https://oauth.net/2/bearer-tokens/)を参照してください。

<div id="when-are-they-used">
  #### それらはいつ使用しますか？
</div>

Bearer Token の使用が必要なプロダクトは、次のとおりです。

* [Engagement API](/ja/x-api/enterprise-gnip-2.0/fundamentals/engagement-api)
* [Account Activity API](/ja/x-api/enterprise-gnip-2.0/fundamentals/account-activity)
* v2 や Labs のエンドポイントなど、OAuth 2.0 Bearer Token 認証を利用するその他の API

<div id="prerequisites">
  #### 前提条件
</div>

[開発者アカウントに登録](https://developer.x.com/en/portal/petition/essential/basic-info)し、[X App](/ja/resources/fundamentals/developer-apps)を作成しておく必要があります。これらを用意したら、[Developer Console](/ja/resources/fundamentals/developer-portal)で確認できる API キーも取得する必要があります。以下の手順に従ってください。

1. developer.x.com で自分の X アカウントにログインします。
2. [X App dashboard](https://developer.x.com/content/developer-twitter/en/apps) に移動し、アクセス・トークンを生成したい X App を開きます。
3. 「Keys and tokens」ページに移動します。
4. このページで、API キー、ユーザーアクセス・トークン、および Bearer Token を確認できます。

<div id="how-to-generate-a-bearer-token">
  ### Bearer Token を生成する方法
</div>

App の Bearer Token は、他の「Keys and Tokens」と同じ場所で確認できます。

[X App](/ja/resources/fundamentals/developer-apps) から取得済みの次の consumer API keys を設定したうえで、以下の cURL リクエストをコマンドラインにコピーして実行してください。なお、このページで使用している consumer API keys はすでに無効化されており、実際のリクエストでは動作しません。

* **API key** `<API key>` 例: `xvz1evFS4wEEPTGEFPHBog`
* **API secret key** `<API secret key>` 例: `L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg`

  ```bash
  curl -u "$API_KEY:$API_SECRET_KEY" \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
  ```

以下は、ご自身の API keys を入力した状態の cURL リクエストの例です。

```bash
   curl -u 'xvz1evFS4wEEPTGEFPHBog:L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg' \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
```

レスポンスは次のようになります。この Bearer Token は現在は利用できないものです:

`{"token_type":"bearer","access_token":"AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F"}`

OAuth 2.0 でリソースにアクセスする際に使用する Bearer Token は次のとおりです:

`AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F`
