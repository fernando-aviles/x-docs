<div id="api-key-and-secret">
  ### API Key と Secret
</div>

API Key と Secret（Consumer Key と Secret とも呼ばれます）は、X API にアクセスするために必要となる、最も基本的な認証情報です。これらの認証情報は X App のユーザー名とパスワードに相当し、どのアプリからリクエストが送信されているのかを X API が把握するために使用されます。 

これらの認証情報は、[認証エンドポイント](/ja/resources/fundamentals/authentication/api-reference) によって、[User Access Token と Secret](/ja/resources/fundamentals/authentication/oauth-1-0a/api-key-and-secret) や [Bearer Token](/ja/resources/fundamentals/authentication/oauth-2-0/bearer-tokens) などの追加の認証情報を生成するために使用できます。また、OAuth 1.0a ユーザーコンテキスト認証が必要なリクエストを[認可する](/ja/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request)ために、Access Token やその他の認可パラメータと併せて、これらの認証情報を使用する必要があります。 

<div id="how-to-acquire-an-api-key-and-secret">
  #### API Key と Secret の取得方法
</div>

X API の API Key と Secret を取得するには、次の手順に従ってください。

1. [X の開発者アカウントに登録します](https://developer.x.com/en/apply-for-access)
2. [Developer Console](/ja/resources/fundamentals/developer-portal) 内で [X App](/ja/resources/fundamentals/developer-apps) を作成します。なお、[X API v2](/ja/x-api/introduction) を利用したい場合は、必ず開発者用 App のキーとトークンを使用する必要があります。
    

X App を作成すると、API Key と Secret に加えて Bearer Token が表示されます。これらの認証情報は一度しか表示されませんので、パスワードマネージャーなどの安全な場所に必ず保存してください。

キーやトークンの取り扱いについては、認証情報が漏えいした場合に取るべき対応も含め、[authentication best practices](/ja/resources/fundamentals/authentication/guides/authentication-best-practices) ページで詳しく説明しています。
 

<div id="how-to-find-and-regenerate-your-api-key-and-secret-after-app-creation">
  #### App 作成後に API Key と Secret を確認および再生成する方法
</div>

すでに App を作成済みで、API Key と Secret を確認または再生成する必要がある場合は、次の手順に従ってください。

1. Developer Console にアクセスします
2. サイドナビゲーションで「Apps」ドロップダウンを展開します
3. 確認または再生成したい API Key と Secret が関連付けられている App を開きます
4. 「Keys and tokens」タブを開きます

ここで、App に関連付けられているすべての認証情報を確認できます。 
 

<div id="how-to-use-your-api-key-and-secret">
  #### API Key と Secret の使用方法
</div>

X Developer Platform を使い始めたばかりであれば、まずはプラットフォームで利用可能な機能を確認するために [ツールやライブラリ](/ja/resources/tools-and-libraries) の利用をおすすめします。これらのツールは認証処理を適切に扱い、多くの時間と手間を節約できます。特に、開発初心者の方には [Postman を使い始める](/ja/tutorials/postman-getting-started) か [Insomnia](https://insomnia.rest/) から始めることを推奨します。 

リクエストをゼロから構築したい場合は、[OAuth 1.0a リクエストの認可](/ja/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request) に関するガイドを参照してください。
