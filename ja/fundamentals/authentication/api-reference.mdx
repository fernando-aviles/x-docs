<div id="post-oauthrequest_token">
  ### POST oauth/request_token
</div>

Consumer アプリケーションがユーザー認可をリクエストするための OAuth Request Token を取得するためのエンドポイントです。このメソッドは、[OAuth 1.0a 認証フロー](http://oauth.net/core/1.0/#anchor9)における[セクション 6.1](https://oauth.net/core/1.0/#auth_step1) に相当します。

**すべての OAuth 認可ステップで HTTPS を使用することが必須です。**

**使用上の注意:** `oauth_nonce` には ASCII 文字のみが有効です。

**リソース URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/request_token`

**リソース情報[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| レスポンス形式 | JSON |
| 認証が必要か | No  |
| レート制限の対象か | Yes |

**パラメータ[](#parameters "Permalink to this headline")**

| 名前 | 必須 | 説明 | 例 |
| :--- | :--- | :--- | :--- |
| oauth&#95;callback | 必須 | OAuth 1.0a に準拠するため、このパラメータは**必須**です。ここで指定した値は、アプリケーションによるユーザーのアカウントへのアクセスが承認された場合に、そのユーザーがリダイレクトされる URL として使用されます。アウト・オブ・バンドの PIN モードの場合は、これを `oob` に設定します。これはまた、デスクトップ/モバイルアプリケーションで使用するカスタムコールバックを指定する方法でもあります。事前登録済みのコールバックがあるかどうかにかかわらず、このステップでは常に `oauth_callback` を送信してください。<br /><br />このエンドポイントで使用されるあらゆるコールバック URL は、developer.x.com 上のアプリ設定内で構成されている必要があります。* | `http://themattharris.local/auth.php` `twitterclient://callback` |
| x&#95;auth&#95;access&#95;type | 任意 | アプリケーションがユーザーのアカウントに対して要求するアクセスレベルを上書きします。サポートされる値は `read` または `write` です。このパラメータは、開発者が read/write アプリケーションを登録しつつ、必要に応じて読み取り専用アクセスのみを要求できるようにすることを意図しています。 |     |

コールバック URL の承認方法については[このページ](/ja/resources/fundamentals/developer-apps#callback-urls)を参照してください。

**注意** - developer.x.com で X アカウントにログインしている場合、[X アプリ](/ja/resources/fundamentals/developer-apps)を [X アプリダッシュボード](https://developer.x.com/en/apps)から表示および編集できます。

**リクエスト例[](#example-request "Permalink to this headline")**

Request URL: `POST https://api.x.com/oauth/request_token`

Request POST Body: *N/A*

Authorization Header: `OAuth oauth_nonce="K7ny27JTpKVsTgdyLdDfmQQWVLERj2zAK5BslRsqyw", oauth_callback="http%3A%2F%2Fmyapp.com%3A3005%2Ftwitter%2Fprocess_callback", oauth_signature_method="HMAC-SHA1", oauth_timestamp="1300228849", oauth_consumer_key="OqEqJeafRSF11jBMStrZz", oauth_signature="Pc%2BMLdv028fxCErFyi8KXFM%2BddU%3D", oauth_version="1.0"`

レスポンス: `oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik&oauth_token_secret=Kd75W4OQfb2oJTV0vzGzeXftVAwgMnEK9MumzYcM&oauth_callback_confirmed=true`

<div id="get-oauthauthorize">
  ### GET oauth/authorize
</div>

Consumer アプリケーションが OAuth Request Token を使用してユーザー認可を要求できるようにします。このメソッドは、[OAuth 1.0 認証フロー](http://oauth.net/core/1.0/#anchor9)の [Section 6.2](http://oauth.net/core/1.0/#auth_step2) を満たします。デスクトップアプリケーションは必ずこのメソッドを使用する必要があり（[GET oauth / authenticate](/ja/resources/fundamentals/authentication/api-reference#get-oauth-authenticate) は使用できません）、他の方法は利用できません。

**使用上の注意:** `oauth_callback` はこのメソッドには一切送信されません。代わりに [POST oauth / request&#95;token](/ja/resources/fundamentals/authentication/api-reference#post-oauth-request-token) に指定してください。

**Resource URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/authorize`

**Resource Information[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| Response formats | JSON |
| Requires authentication? | Yes |
| Rate limited? | Yes |

**Parameters[](#parameters "Permalink to this headline")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| Name | Required | Description | Default Value | Example |
| force&#95;login | optional | ユーザーに資格情報の再入力を強制し、正しいユーザーアカウントが認可されるようにします。 |     |     |
| screen&#95;name | optional | OAuth ログイン画面のユーザー名入力ボックスを、指定された値であらかじめ入力します。 |     |     |

**Example request[](#example-request "Permalink to this headline")**

ユーザーを Web ブラウザーで `oauth/authorize` ステップに遷移させ、その際に oauth&#95;token パラメーターを含めます:
`https://api.x.com/oauth/authorize?oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik`

<div id="get-oauthauthenticate">
  ### GET oauth/authenticate
</div>

Consumer アプリケーションが OAuth の `request_token` を使用してユーザーに対して認可を要求できます。

このメソッドは、コールバック認証フローを使用するアプリケーション向けに、[OAuth 1.0 認証フロー](http://oauth.net/core/1.0/#anchor9)の [Section 6.2](http://oauth.net/core/1.0/#auth_step2) を置き換えるものです。`force_login` パラメータが `true` に設定されていない限り、このメソッドは現在ログインしているユーザーを、アクセス認可を行うアカウントとして使用します。

このメソッドは、ユーザーがすでにアプリケーションに権限を付与している場合、ユーザーが再度アプリケーションを承認することなくリダイレクトが行われる点で、[GET oauth / authorize](/ja/resources/fundamentals/authentication/api-reference#get-oauth-authorize) と異なります。この動作を実現するには、[application record](https://developer.x.com/apps) で *Use Sign in with X* 設定を有効にする必要があります。

**Resource URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/authenticate`

**Resource Information[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| レスポンス形式 | JSON |
| 認証が必要ですか？ | Yes |
| レート制限はありますか？ | Yes |

**Parameters[](#parameters "Permalink to this headline")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| 名前 | 必須 | 説明 | デフォルト値 | 例 |
| force&#95;login | optional | 正しいユーザーのアカウントが認可されるように、ユーザーに資格情報の再入力を強制します。 |     | *true* |
| screen&#95;name | optional | OAuth ログイン画面のユーザー名入力ボックスに、指定した値をあらかじめ入力します。 |     |     |

**Example request[](#example-request "Permalink to this headline")**

Web ブラウザでユーザーを `oauth/authenticate` ステップにリダイレクトし、oauth&#95;token パラメータを含めます:
`https://api.x.com/oauth/authenticate?oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik`

<div id="post-oauthaccess_token">
  ### POST oauth/access_token
</div>

コンシューマーアプリケーションが OAuth Request Token を OAuth Access Token と交換するためのエンドポイントです。このメソッドは、[OAuth 1.0 認証フロー](http://oauth.net/core/1.0/#anchor9)の [セクション 6.3](http://oauth.net/core/1.0/#auth_step3) の要件を満たします。

**Resource URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/access_token`

**Resource Information[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| レスポンス形式 | JSON |
| 認証が必要ですか？ | はい |
| レート制限がありますか？ | はい |

**Parameters[](#parameters "Permalink to this headline")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| 名前 | 必須 | 説明 | デフォルト値 | 例 |
| oauth&#95;token | 必須 | ここでの `oauth_token` は、`request_token` ステップで返された `oauth_token` と同じである必要があります。 |     |     |
| oauth&#95;verifier | 必須 | OAuth の Web フローを使用している場合は、このパラメータにコールバック URL で返された *oauth&#95;verifier* の値を設定します。Out-of-band OAuth を使用している場合は、この値を PIN コードに設定します。OAuth 1.0a に準拠するため、このパラメータは**必須**です。OAuth 1.0a は厳格に適用されており、*oauth&#95;verifier* を使用しないアプリケーションは OAuth フローを完了できません。 |     |     |

**Example request[](#example-request "Permalink to this headline")**

`POST https://api.x.com/oauth/access_token?oauth_token=qLBVyoAAAAAAx72QAAATZxQWU6P&oauth_verifier=ghLM8lYmAxDbaqL912RZSRjCCEXKDIzx`

PIN ベースの場合: `POST https://api.x.com/oauth/access_token?oauth_token=9Npq8AAAAAAAx72QBRABZ4DAfY9&oauth_verifier=4868795`

**Example response[](#example-response "Permalink to this headline")**

`oauth_token=6253282-eWudHldSbIaelX7swmsiHImEL4KinwaGloHANdrY&oauth_token_secret=2EEfA6BG5ly3sR3XjE0IBSnlQu4ZrUzPiYTmrkVU&user_id=6253282&screen_name=xapi`

<div id="post-oauthinvalidate_token">
  ### POST oauth/invalidate_token
</div>

登録済みアプリケーションは、自身のクライアント認証情報を提示することで、発行済みの OAuth access&#95;token を取り消すことができます。いったん access&#95;token が無効化されると、新たにトークンを発行しようとした場合には別の access&#95;token が発行され、無効化されたトークンは以後使用できなくなります。

**リソース URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/1.1/oauth/invalidate_token`

**リソース情報[](#resource-information "Permalink to this headline")**

|              |                                  |
| :----------- | :------------------------------- |
| レスポンス形式      | JSON                             |
| 認証は必要ですか？    | はい - 無効化したいアクセストークンを持つユーザーコンテキスト |
| レート制限はありますか？ | はい                               |

**リクエスト例[](#example-request "Permalink to this headline")**

```bash
        curl --request POST
          --url 'https://api.x.com/1.1/oauth/invalidate_token.json'
          --header 'authorization: OAuth oauth_consumer_key="CLIENT_KEY",
         oauth_nonce="AUTO_GENERATED_NONCE", oauth_signature="AUTO_GENERATED_SIGNATURE",
         oauth_signature_method="HMAC-SHA1", oauth_timestamp="AUTO_GENERATED_TIMESTAMP",
         oauth_token="ACCESS_TOKEN", oauth_version="1.0"'
```

**レスポンス例[](#example-response "この見出しへのパーマリンク")**

```bash
        HTTP/1.1 200 OK
        Content-Type: application/json; charset=utf-8
        Content-Length: 127
        ...

        {"access_token":"ACCESS_TOKEN"}
```

**トークンが無効化された後のエラーレスポンス例[](#example-error-response-after-token-has-been-invalidated "Permalink to this headline")**

```bash
        HTTP/1.1 401 Authorization Required
        ...

        {"errors": [{
          "code": 89,
          "message": "Invalid or expired token."}
        ]}
```

<div id="post-oauth2token">
  ### POST oauth2/token
</div>

登録済みアプリケーションが OAuth 2 Bearer Token を取得できるようにします。取得した Bearer Token は、ユーザーコンテキストなしでアプリケーション自身の名義で API リクエストを行うために使用できます。これは [アプリケーション専用認証](/ja/resources/fundamentals/authentication/oauth-2-0/application-only) と呼ばれます。

Bearer Token は oauth2/invalidate&#95;token を使用して無効化できます。一度 Bearer Token が無効化されると、新しく作成されたトークンは別の Bearer Token となり、以前のトークンは使用できなくなります。

1 つのアプリケーションに対して、有効な Bearer Token は 1 つだけ存在できます。このメソッドを繰り返し呼び出した場合、無効化されるまでは既存の同じトークンが返されます。

成功したレスポンスには、付与された Bearer Token を記述する JSON 構造が含まれます。

このメソッドで受け取ったトークンはキャッシュする必要があります。短時間に頻繁に呼び出した場合、HTTP 403（コード 99）でリクエストが拒否されます。

**Resource URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth2/token`

**Resource Information[](#resource-information "Permalink to this headline")**

|                          |                                                            |
| :----------------------- | :--------------------------------------------------------- |
| Response formats         | JSON                                                       |
| Requires authentication? | はい - Basic 認証。API key をユーザー名、API key secret をパスワードとして使用します |
| Rate limited?            | はい                                                         |

**Parameters[](#parameters "Permalink to this headline")**

|                |          |                                                                                                                                                                              |               |                          |
| :------------- | :------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------ | :----------------------- |
| Name           | Required | Description                                                                                                                                                                  | Default Value | Example                  |
| grant&#95;type | 必須       | アプリケーションが要求しているグラントの種類を指定します。現時点では *client&#95;credentials* のみが許可されています。詳細については、[アプリケーション専用認証](/ja/resources/fundamentals/authentication/oauth-2-0/application-only) を参照してください。 |               | *client&#95;credentials* |

**Example request[](#example-request "Permalink to this headline")**

```bash
    POST /oauth2/token HTTP/1.1
    Host: api.x.com
    User-Agent: My X App v1.0.23
    Authorization: Basic eHZ6MWV2R ... o4OERSZHlPZw==
    Content-Type: application/x-www-form-urlencoded;charset=UTF-8
    Content-Length: 29
    Accept-Encoding: gzip

    grant_type=client_credentials
```

**レスポンス例：**

```bash
    HTTP/1.1 200 OK
    Status: 200 OK
    Content-Type: application/json; charset=utf-8
    ...
    Content-Encoding: gzip
    Content-Length: 140

    {"token_type":"bearer","access_token":"AAAA%2FAAA%3DAAAAAAAA"}
```

<div id="post-oauth2invalidate_token">
  ### POST oauth2/invalidate_token
</div>

登録済みアプリケーションが、自身のクライアント認証情報を提示することで、発行済みの OAuth 2.0 Bearer Token を失効させることができます。Bearer Token が無効化されると、新たに Bearer Token を発行しようとした場合は別の Bearer Token が返され、無効化されたトークンは以後使用できなくなります。

成功したレスポンスには、失効した Bearer Token を示す JSON 構造体が含まれます。

**Resource URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth2/invalidate_token`

**Resource Information[](#resource-information "Permalink to this headline")**

|                          |                                                                                                                                                          |
| :----------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Response formats         | JSON                                                                                                                                                     |
| Requires authentication? | Yes - [OAuth 1.0a](/ja/resources/fundamentals/authentication/oauth-1-0a)（アプリケーションの consumer API key とアプリケーション所有者の access token および access token secret を使用） |
| Rate limited?            | Yes                                                                                                                                                      |

**Parameters[](#parameters "Permalink to this headline")**

| Name             | Required | Description            |
| :--------------- | :------- | :--------------------- |
| access&#95;token | required | 無効化したい Bearer Token の値 |

**Example request[](#example-request "Permalink to this headline")**

```
        curl --request POST
          --url 'https://api.x.com/oauth2/invalidate_token?access_token=AAAA%2FAAA%3DAAAAAAAA'
          --header 'authorization: OAuth oauth_consumer_key="CLIENT_KEY",
         oauth_nonce="AUTO_GENERATED_NONCE", oauth_signature="AUTO_GENERATED_SIGNATURE",
         oauth_signature_method="HMAC-SHA1", oauth_timestamp="AUTO_GENERATED_TIMESTAMP",
         oauth_token="ACCESS_TOKEN", oauth_version="1.0"'
```

**レスポンス例[](#example-response "Permalink to this headline")**

```
         Status: 200 OK
         Content-Type: application/json; charset=utf-8
         Content-Length: 135
         ...
       {
        "access_token": "AAAA%2FAAA%3DAAAAAAAA"
        }
```
