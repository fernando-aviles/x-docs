[開発者コンソール](https://console.x.com) は、X API へのアクセスを管理するための中核となるハブです。App の作成、認証情報の生成、利用状況の監視、請求の管理まで、すべてを 1 か所で行えます。

<Button href="https://console.x.com">開発者コンソールを開く</Button>

***

<div id="what-you-can-do">
  ## できること
</div>

<CardGroup cols={2}>
  <Card title="App の作成と管理" icon="grid-2">
    API 認証情報を取得するための App を作成・設定します。認証方式、権限、コールバック URL を構成します。
  </Card>

  <Card title="利用状況とコストの監視" icon="chart-line">
    API の利用状況をリアルタイムに把握します。エンドポイントごとのコストを確認し、クレジット残高を管理します。
  </Card>

  <Card title="認証情報の生成" icon="key">
    App 用の API key、access token、OAuth 認証情報を作成します。
  </Card>

  <Card title="クレジットの購入" icon="credit-card">
    従量課金制のためのクレジットを購入します。サブスクリプションや長期契約は不要です。
  </Card>
</CardGroup>

<div id="getting-started">
  ## はじめに
</div>

<Steps>
  <Step title="開発者アカウントに登録する">
    [console.x.com](https://console.x.com) にアクセスし、X アカウントでサインインします。Developer Agreement (開発者規約) に同意します。
  </Step>

  <Step title="最初の App を作成する">
    **New App** をクリックし、名前と説明を入力します。これにより API 認証情報が生成されます。
  </Step>

  <Step title="認証情報を保存する">
    API Key、API Secret、Access Token をコピーして安全な場所に保管します。これらは再表示されません。
  </Step>

  <Step title="開発を開始する">
    認証情報を使用して API リクエストの認証を行います。[クイックスタートガイド](/ja/x-api/getting-started/make-your-first-request) を参照してください。
  </Step>
</Steps>

<Warning>
  **認証情報は安全に保管してください。** API key やトークンは生成時に一度だけ表示されます。パスワードマネージャーやセキュアなボルト (保管庫) を使用してください。紛失した場合は再生成する必要があり、その際に古い認証情報は無効になります。
</Warning>

<div id="billing-credits">
  ## 請求とクレジット
</div>

X API は、クレジットベース方式の従量課金制を採用しています。

| 機能 | 説明 |
|:--------|:------------|
| **月額料金なし** | 使った分だけ支払う形式で、サブスクリプションは不要 |
| **クレジットベース** | 事前にクレジットを購入し、API 利用時に差し引かれます |
| **リアルタイム追跡** | コンソールのダッシュボードで利用状況とコストをリアルタイムに監視 |
| **エンドポイント単位の料金** | エンドポイントごとに料金が異なります |
| **重複排除** | 同じリソースを 24 時間以内に 2 回リクエストしても、課金は 1 回のみ |

最新の料金の確認とクレジットの購入は [開発者コンソール](https://console.x.com) から行えます。

[料金の詳細はこちら →](/ja/x-api/getting-started/pricing)

<div id="team-management">
  ## チーム管理
</div>

<Note>
  チーム管理は **Enterprise アカウント** のみで利用できます。
</Note>

Enterprise アカウントでは、チームメンバーを招待して共同作業できます。

| ロール | 権限 |
|:-----|:-------------|
| **Administrator** | フルアクセス権: App、請求、チームメンバー、およびロールを管理 |
| **Developer** | 自分の App を管理、チームの App への閲覧専用アクセス |

チームメンバーを招待するには、コンソールの Team ページに移動し、そのメンバーの X のハンドルを入力します。
