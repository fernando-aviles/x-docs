[Developer Console](https://console.x.com) は、X API へのアクセスを管理するための中⼼的なハブです。アプリの作成、クレデンシャル（資格情報）の発⾏、利⽤状況の監視、課⾦・請求の管理まで、すべてを 1 か所で⾏えます。

<Button href="https://console.x.com">Developer Console を開く</Button>

***

<div id="what-you-can-do">
  ## できること
</div>

<CardGroup cols={2}>
  <Card title="アプリを作成・管理" icon="grid-2">
    API 認証情報を取得するためのアプリを作成・設定します。認証方式、権限、コールバック URL を設定します。
  </Card>

  <Card title="利用状況とコストを監視" icon="chart-line">
    API の利用状況をリアルタイムで追跡します。エンドポイントごとのコストを確認し、クレジット残高を管理できます。
  </Card>

  <Card title="認証情報の生成" icon="key">
    アプリ用の API キー、アクセストークン、OAuth 認証情報を作成します。
  </Card>

  <Card title="クレジットの購入" icon="credit-card">
    従量課金の請求に使うクレジットを購入します。サブスクリプション契約やコミットメントは不要です。
  </Card>
</CardGroup>

<div id="getting-started">
  ## はじめに
</div>

<Steps>
  <Step title="開発者アカウントにサインアップする">
    [console.x.com](https://console.x.com) にアクセスし、X アカウントでサインインします。開発者規約（Developer Agreement）に同意します。
  </Step>

  <Step title="最初のアプリを作成する">
    **New App** をクリックし、名前と説明を入力します。これにより API 認証情報が生成されます。
  </Step>

  <Step title="認証情報を保存する">
    API Key、API Secret、Access Tokens をコピーし、安全な場所に保管します。これらは再度表示されません。
  </Step>

  <Step title="開発を開始する">
    認証情報を使用して API リクエストの認証を行います。[クイックスタートガイド](/ja/x-api/getting-started/make-your-first-request) を参照してください。
  </Step>
</Steps>

<Warning>
  **認証情報は安全に保管してください。** API キーやトークンは、生成時に一度しか表示されません。パスワードマネージャーやセキュアな保管庫を使用してください。紛失した場合は再生成する必要があり、その際に古い認証情報は無効になります。
</Warning>

<div id="billing-credits">
  ## 請求とクレジット
</div>

X API では、クレジットベースの従量課金制が採用されています。

| 機能 | 説明 |
|:--------|:------------|
| **月額料金なし** | 使った分だけ支払う方式で、サブスクリプションは不要です |
| **クレジットベース** | 事前にクレジットを購入し、API を利用するたびに差し引かれます |
| **リアルタイム追跡** | Developer Console のダッシュボードで利用状況とコストを監視できます |
| **エンドポイント単位の料金** | エンドポイントごとに料金が異なります |
| **重複排除** | 同じリソースを 24 時間以内に 2 回リクエストしても、課金対象となるのは 1 回分のみです |

現在の料金の確認とクレジットの購入は [Developer Console](https://console.x.com) から行えます。

[料金の詳細はこちら →](/ja/x-api/getting-started/pricing)

<div id="team-management">
  ## チーム管理
</div>

<Note>
  チーム管理は **Enterprise アカウント** でのみご利用いただけます。
</Note>

Enterprise アカウントでは、チームメンバーを招待して共同作業できます。

| 役割 | 機能 |
|:-----|:-------------|
| **Administrator** | アプリ、請求、チームメンバー、役割を管理できる完全なアクセス権 |
| **Developer** | 自分のアプリを管理でき、チームのアプリには読み取り専用でアクセス可能 |

チームメンバーを招待するには、コンソール内の Team ページに移動し、そのユーザーの X ハンドルを入力します。
