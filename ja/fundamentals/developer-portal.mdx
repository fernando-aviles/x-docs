[開発者コンソール](https://console.x.com) は、X API へのアクセスを管理するための中心的なハブです。アプリを作成し、認証情報を生成し、使用状況を監視し、課金を管理できます。これらをすべて 1 か所で一元管理できます。

<Button href="https://console.x.com">開発者コンソールを開く</Button>

***

<div id="what-you-can-do">
  ## できること
</div>

<CardGroup cols={2}>
  <Card title="アプリの作成と管理" icon="grid-2">
    API認証情報を取得するためのアプリをセットアップします。認証方式、権限、コールバックURLを設定します。
  </Card>

  <Card title="利用状況とコストの監視" icon="chart-line">
    APIの利用状況をリアルタイムで追跡します。エンドポイントごとのコストを確認し、クレジット残高を管理します。
  </Card>

  <Card title="認証情報の生成" icon="key">
    アプリ向けのAPIキー、アクセストークン、OAuth認証情報を作成します。
  </Card>

  <Card title="クレジットの購入" icon="credit-card">
    従量課金のためのクレジットを購入できます。サブスクリプションや長期契約は不要です。
  </Card>
</CardGroup>

<div id="getting-started">
  ## はじめに
</div>

<Steps>
  <Step title="開発者アカウントに登録する">
    [console.x.com](https://console.x.com) にアクセスして X アカウントでサインインし、Developer Agreement（開発者利用規約）に同意します。
  </Step>

  <Step title="最初のアプリを作成する">
    **New App** をクリックし、名前と説明を入力します。これにより API 資格情報が生成されます。
  </Step>

  <Step title="資格情報を保存する">
    API Key、API Secret、Access Token をコピーして安全に保管します。これらが再度表示されることはありません。
  </Step>

  <Step title="開発を開始する">
    資格情報を使用して API リクエストを認証します。[クイックスタートガイド](/ja/x-api/getting-started/make-your-first-request) を参照してください。
  </Step>
</Steps>

<Warning>
  **資格情報は安全に保管してください。** API Key や Access Token などは、生成時に一度だけ表示されます。パスワードマネージャーやセキュアなボールトを使用してください。紛失した場合は再生成する必要があり、その際に古い資格情報は無効になります。
</Warning>

<div id="billing-credits">
  ## 請求とクレジット
</div>

X API では、クレジット制にもとづく従量課金モデルを採用しています。

| 機能 | 説明 |
|:--------|:------------|
| **月額料金なし** | 使った分だけ支払う方式で、サブスクリプションは不要です |
| **クレジット制** | 事前にクレジットを購入し、API 利用時に差し引かれます |
| **リアルタイムトラッキング** | 開発者コンソールのダッシュボードで利用状況とコストをリアルタイムに監視できます |
| **エンドポイント別の料金** | エンドポイントごとに料金が異なります |
| **重複排除** | 同一リソースを 24 時間以内に 2 回リクエストしても、課金は 1 回分のみとなります |

最新の料金の確認とクレジットの購入は [開発者コンソール](https://console.x.com) で行えます。

[料金の詳細はこちら →](/ja/x-api/getting-started/pricing)

<div id="team-management">
  ## チーム管理
</div>

<Note>
  チーム管理は **Enterprise アカウント** でのみ利用できます。
</Note>

Enterprise アカウントでは、チームメンバーを招待して共同作業を行うことができます。

| ロール | 権限 |
|:-----|:-------------|
| **Administrator** | アプリ、請求、チームメンバーおよびロールを管理できるフルアクセス |
| **Developer** | 自分のアプリを管理でき、チームのアプリには読み取り専用アクセス |

チームメンバーを招待するには、コンソールの Team ページに移動し、そのメンバーの X ハンドルを入力します。
