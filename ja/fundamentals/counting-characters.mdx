X の投稿には、最大 **280文字** まで含めることができます。ただし、すべての文字が同じようにカウントされるわけではありません。絵文字、URL、一部の Unicode 範囲には独自のカウント規則があります。

---

<div id="character-weights">
  ## 文字の重み
</div>

X では重み付きの文字数カウント方式を使用しています。ほとんどの文字は 1 としてカウントされますが、一部の文字は 2 としてカウントされます。

| 文字種 | 重み | 最大文字数 |
|:---------------|:-------|:---------------|
| ラテン文字、句読点、一般的な記号 | 1 | 280 |
| 絵文字 | 2 | 絵文字 140 個 |
| CJK（中国語、日本語、韓国語） | 2 | 140 文字 |
| その他の Unicode | 2（デフォルト） | 可変 |

<Tip>
アプリで文字数を正確にカウントするには、オープンソースの [twitter-text](https://github.com/twitter/twitter-text) ライブラリを使用してください。
</Tip>

---

<div id="emoji-counting">
  ## 絵文字のカウント
</div>

すべての絵文字は、複雑さに関係なく常に **2文字** として数えられます。

| Emoji | 表示 | 文字数 | Unicode |
|:------|:--------|:----------------|:--------|
| 👾 | 単一の絵文字 | 2 | U+1F47E |
| 🙋🏽 | 肌の色指定あり | 2 | 🙋 + 🏽 修飾子 |
| 👨‍🎤 | ZWJ で結合されたもの | 2 | 👨 + ZWJ + 🎤 |
| 👨‍👩‍👧‍👦 | 家族シーケンス | 2 | 絵文字4つ + ZWJ 3つ |

Zero-width joiner (ZWJ) は絵文字を視覚的に結合しますが、文字数には影響しません。

---

<div id="url-handling">
  ## URL の扱い
</div>

すべての URL は `t.co` の短縮 URL に変換され、元の長さに関係なく **23 文字**としてカウントされます。

```
https://example.com                    → 23 characters
https://example.com/very/long/path     → 23 characters
```

<Note>
  これは、投稿テキスト内で検出された有効な URL すべてに適用されます。
</Note>

***


<div id="special-cases">
  ## 特別なケース
</div>

| コンテンツ | カウントルール |
|:--------|:--------------|
| **返信内の @メンション** | 返信の先頭に自動的に追加される @メンションはカウントされません |
| **新しい @メンション** | 手動で追加した @メンションは通常どおりカウントされます |
| **メディア** | 添付メディア（公式クライアント経由）は文字数0としてカウントされます |
| **ハッシュタグ** | 通常どおりカウントされます（# + タグのテキスト） |

---

<div id="text-encoding">
  ## テキストエンコーディング
</div>

X API では **UTF-8** エンコーディングが必須です。文字数は Unicode 正規化形式 C (NFC) に基づいて計算されます。

`café` の例:

| Form | Bytes | Characters |
|:-----|:------|:-----------|
| NFC (composed) | `c a f é` | 4 |
| NFD (decomposed) | `c a f e ́` | 5 |

X では NFC に正規化してから文字数を計算するため、どちらの場合も 4 文字としてカウントされます。

---

<div id="implementation">
  ## 実装
</div>

正確な文字数カウントのために、公式の [twitter-text](https://github.com/twitter/twitter-text) ライブラリを使用してください。

<Tabs>
  <Tab title="JavaScript">
```javascript
import { parseTweet } from 'twitter-text';

const result = parseTweet('Hello, world! 👋');
console.log(result.weightedLength); // 16
console.log(result.valid);          // true
```
  </Tab>
  <Tab title="Python">
```python
from twitter_text import parse_tweet

result = parse_tweet('Hello, world! 👋')
print(result.weightedLength)  # 16
print(result.valid)           # True
```
  </Tab>
</Tabs>

このライブラリは、絵文字シーケンス、URL 検出、Unicode 正規化を含むあらゆるエッジケースを処理します。
