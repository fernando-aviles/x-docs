X の投稿には最大 **280文字** まで含められます。ただし、すべての文字が同じようにカウントされるわけではなく、絵文字、URL、特定の Unicode 範囲には特別なカウントルールが適用されます。

---

<div id="character-weights">
  ## 文字カウントの重み付け
</div>

X では、重み付きの文字カウント方式を使用しています。ほとんどの文字は 1 としてカウントされますが、一部の文字は 2 としてカウントされます。

| 文字種別 | 重み | 最大文字数 |
|:---------------|:-------|:---------------|
| ラテン文字、句読点、一般的な記号 | 1 | 280 |
| 絵文字 | 2 | 絵文字 140 個 |
| CJK（中国語、日本語、韓国語） | 2 | 140 文字 |
| その他の Unicode | 2（デフォルト） | 可変 |

<Tip>
アプリ内で正確に文字数をカウントするには、オープンソースの [twitter-text](https://github.com/twitter/twitter-text) ライブラリを使用してください。
</Tip>

---

<div id="emoji-counting">
  ## 絵文字のカウント
</div>

すべての絵文字は、複雑さに関係なく **2文字** としてカウントされます。

| Emoji | 表示 | 文字数 | Unicode |
|:------|:--------|:----------------|:--------|
| 👾 | 単一の絵文字 | 2 | U+1F47E |
| 🙋🏽 | 肌の色指定あり | 2 | 🙋 + 🏽 修飾子 |
| 👨‍🎤 | ZWJ で結合 | 2 | 👨 + ZWJ + 🎤 |
| 👨‍👩‍👧‍👦 | 家族シーケンス | 2 | 4 emojis + 3 ZWJs |

Zero-width joiner (ZWJ) は絵文字を視覚的に結合しますが、文字数は増えません。

---

<div id="url-handling">
  ## URL の扱い
</div>

すべての URL は `t.co` の短縮 URL に変換され、元の長さに関係なく常に **23 文字**としてカウントされます。

```
https://example.com                    → 23 characters
https://example.com/very/long/path     → 23 characters
```

<Note>
  これは、投稿テキスト中で検出されたすべての有効な URL に適用されます。
</Note>

***


<div id="special-cases">
  ## 特別なケース
</div>

| コンテンツ | カウントルール |
|:--------|:--------------|
| **返信内の @メンション** | 返信の先頭に自動的に挿入される @メンションはカウントされません |
| **新しい @メンション** | 手動で追加した @メンションは通常どおり文字数としてカウントされます |
| **メディア** | 公式クライアント経由で添付されたメディアは 0 文字としてカウントされます |
| **ハッシュタグ** | 通常どおり文字数としてカウントされます（# ＋ タグのテキスト） |

<div id="text-encoding">
  ## テキストエンコーディング
</div>

X API では **UTF-8** エンコーディングが必須です。文字数は Unicode 正規化形式 C（NFC）に基づいて計算されます。

`café` の例:

| 形式 | バイト数 | 文字数 |
|:-----|:--------|:-------|
| NFC（合成済み） | `c a f é` | 4 |
| NFD（分解済み） | `c a f e ́` | 5 |

X では NFC に正規化されるため、どちらの場合も 4 文字として扱われます。

<div id="implementation">
  ## 実装
</div>

文字数を正確にカウントするために、公式の [twitter-text](https://github.com/twitter/twitter-text) ライブラリを使用してください。

<Tabs>
  <Tab title="JavaScript">
```javascript
import { parseTweet } from 'twitter-text';

const result = parseTweet('Hello, world! 👋');
console.log(result.weightedLength); // 16
console.log(result.valid);          // true
```
  </Tab>
  <Tab title="Python">
```python
from twitter_text import parse_tweet

result = parse_tweet('Hello, world! 👋')
print(result.weightedLength)  # 16
print(result.valid)           # True
```
  </Tab>
</Tabs>

このライブラリは、絵文字シーケンス、URL 検出、Unicode 正規化など、さまざまなエッジケースをすべて処理します。
