I. **定義**

本契約においては、次の定義が適用されます。

1. **「クレジット」**とは、有料サービスの利用を可能にする目的であなたが購入する仮想単位を意味し、各 API コールまたはアクションごとに、料金表に基づいて特定の数のクレジットが差し引かれます。クレジットは、法律で義務付けられる場合を除き払い戻し不可であり、譲渡不可であり、別途定めがない限り有効期限はありません。

2\. **「開発者サイト」**とは、[**https://developer.x.com**](https://developer.x.com/) に所在する X の開発者サイトを意味します。

3\. **「ダイレクトメッセージ」**とは、X のダイレクトメッセージ機能を使用して、1 人のユーザーが 1 人以上の特定の他のユーザーに対して X アプリケーション上で送信するプライベートメッセージを意味します。

4\. **「知的財産権」**とは、すべての著作権、著作者人格権、特許権、商標権、および世界中の（登録済みか未登録かを問わない）その他すべての知的財産権または類似の権利を意味します。

5\. **「ライセンス対象資料」**とは、個別または集合的に、X API および X コンテンツを意味します。

6\. **「有料サービス」**とは、X から購入したクレジットが、料金ページに記載されたとおり、あなたによるコールおよび機能の利用状況に基づきあなたのアカウントから差し引かれることと引き換えに、あなたがアクセスするライセンス対象資料の機能または機能性を意味します。本契約に別段の定めがない限り、「ライセンス対象資料」へのすべての言及には有料サービスを含むものとします。

7\. **「決済ポータル」**とは、ライセンス対象資料の利用へのオプトイン、有料サービスのためのクレジット購入の管理、有料サービスの支払方法の管理、「自動チャージ」（第 VII.F 条参照）の有効化、およびアカウント情報の更新のためにあなたに提供されるオンラインポータルを意味します。 

8\. **「サービス」**とは、X コンテンツを表示する、またはその他の形でライセンス対象資料を使用する、あなたのサービス、ウェブサイト、アプリケーションおよびその他の提供物（リサーチを含みます）を意味します。

9\. **「投稿」**とは、X アプリケーションを通じて配信される短文テキストおよびマルチメディア形式のメッセージを意味します。

10\. **「料金表」**とは、[https://console.x.com/pricing](https://console.x.com/pricing) に掲載されている、API コールまたはアクションごとの最新の料金一覧を意味し、X は通知の上これを更新することがあります。

11\. **「X」**とは、（a）お客様の主たる事業所が欧州連合、EFTA 加盟国および英国以外にある場合には X Corp.（865 FM 1209, Building 2, Bastrop, TX 78602, USA）を、または（b）お客様の主たる事業所が欧州連合、EFTA 加盟国または英国にある場合には X Internet Unlimited Company（One Cumberland Place, Fenian Street, Dublin 2, D02 AX07, Ireland）を意味します。

12\. **「X API」**とは、X Application Programming Interfaces（それぞれ「API」）、Software Development Kits（それぞれ「SDK」）、および Developer Site を通じて X により提供される関連ツール、ドキュメント、データ、テクノロジー、コード、その他の資料を意味します。

13\. **「X Applications」**とは、一般的に「X」と呼ばれる、X のリアルタイム情報サービスを意味し、X がそのウェブサイトおよび X が所有、運営または管理するモバイルアプリケーション、ソーシャルプラグインおよびアプリケーションプログラミングインターフェイスにおいて現在提供しているサービスを含みます。
