I. **定義**

本契約において、以下の定義が適用されます。

1. **「クレジット」**とは、有料サービスの利用を可能にするためにあなたが購入する仮想単位をいい、各 API コールまたはアクションごとに、料金表に基づき特定数のクレジットが差し引かれます。クレジットは、法律で要求される場合を除き払い戻し不可であり、譲渡不可であり、別途明示的に定めのない限り有効期限はありません。

2\. **「Developer Site」**とは、[**https://developer.x.com**](https://developer.x.com/) にある X の開発者向けサイトをいいます。

3\. **「Direct Message」**とは、X のダイレクトメッセージ機能を利用して、X アプリケーション上で 1 人のユーザーから 1 人以上の他の特定のユーザーに送信される非公開メッセージをいいます。

4\. **「知的財産権」**とは、世界中におけるすべての著作権、著作者人格権、特許権、商標権、およびその他すべての知的財産権またはこれに類する権利（登録済みか否かを問いません）をいいます。

5\. **「ライセンス対象資料」**とは、個別にまたは集合的に、X API および X コンテンツをいいます。

6\. **「有料サービス」**とは、X から購入したクレジットの差し引きと引き換えにあなたがアクセスするライセンス対象資料の機能または機能群をいい、あなたによるコールおよび機能の利用に基づき、当社の料金ページに詳細が記載されているとおり、あなたのアカウントから差し引かれます。本契約に別段の定めがない限り、「ライセンス対象資料」への言及には有料サービスが含まれるものとします。

7\. **「Payment Portal」**とは、ライセンス対象資料の利用へのオプトイン、有料サービス用クレジットの購入管理、有料サービス用の支払い方法の管理、「自動チャージ」（第 VII.F 条参照）の有効化、およびアカウント情報の更新のためにあなたに提供されるオンラインポータルをいいます。 

8\. 「**サービス**」とは、X コンテンツを表示する、またはその他ライセンス対象資料を利用する、あなたのサービス、ウェブサイト、アプリケーション、その他の提供物（調査を含みます）をいいます。

9\. **「投稿」**とは、X アプリケーションを通じて配信される短文テキストおよびマルチメディアベースのメッセージをいいます。

10\. **「料金表」**とは、[https://console.x.com/pricing](https://console.x.com/pricing) で確認できる、API コールまたはアクションごとの最新の料金リストをいい、X は通知のうえこれを更新することがあります。

11\. **「X」**とは、（a）あなたの主たる事業所が欧州連合、EFTA 加盟国、および英国の外にある場合には X Corp.（865 FM 1209, Building 2, Bastrop, TX 78602, USA）を、または（b）あなたの主たる事業所が欧州連合、EFTA 加盟国、または英国にある場合には X Internet Unlimited Company（One Cumberland Place, Fenian Street, Dublin 2, D02 AX07, Ireland）を意味します。

12\. **「X API」**とは、X のアプリケーション・プログラミング・インターフェイス（それぞれ「API」）、ソフトウェア開発キット（それぞれ「SDK」）、および Developer Site を通じて X により提供される関連ツール、ドキュメント、データ、テクノロジー、コード、その他の資料を意味します。

13\. **「X Applications」**とは、一般に「X」と呼ばれる、X のリアルタイム情報サービスを意味し、これには、現在 X が自社ウェブサイトおよび X が所有、運営、または管理するモバイルアプリケーション、ソーシャルプラグイン、ならびにアプリケーション・プログラミング・インターフェイス（API）を通じて提供しているサービスが含まれます。

14\. **「X Content」**とは、投稿、各投稿ごとに生成される固有の識別番号、X エンドユーザーのプロフィール情報、および X API を通じて、または X により承認されたその他の手段によりあなたに利用可能とされるその他一切のデータおよび情報、ならびにそれらの複製および派生物を意味します。
