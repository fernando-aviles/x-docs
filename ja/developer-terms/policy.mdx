<div id="x-developers">
  ## X + Developers
</div>

X は開発者を大切にしています。X のデータの力を活用して、このコミュニティが生み出すツールやサービスには、私たちも常に喜びと驚きを感じています。このコミュニティへの取り組みの一環として、開発者に対してオープンかつ公正であり、X を利用する人々にとって安全であり、X プラットフォーム全体にとって有益となるようなデータへのアクセスを提供することを目指しています。これらの目的を推進するために、API および X Content の適切な利用に関する当社のルールと期待事項を理解していただくためのガイドとして、Developer Policy を策定しました。

この Developer Policy（「**Policy**」）は、X のアプリケーション、サービス、ウェブサイト、ウェブページおよびコンテンツから成るエコシステムと連携する開発者向けの規則およびガイドラインを定めるものです。本 Policy は、X API および X Content へのアクセスおよびその利用を定める、X とお客様との契約（Developer Agreement または X とのその他の書面による契約のいずれか）の一部を構成します。本 Policy に違反する行為は、お客様の契約違反とみなされます。本 Policy は、予告なく随時変更されることがあります。本 Policy で使用され、本 Policy において定義されていない大文字で始まる用語は、[Developer Agreement](/ja/developer-terms/agreement) または Master License Agreement に定められた意味を有します。

</div>

1. **成功するための準備を整える** - X のあらゆるポリシーを遵守する責任は、あなた自身にあります。X API および X Content にアクセスする前に、本ポリシーと、本書内でリンクしている各種ポリシーを確認し、その内容を理解しておくことが重要です。事前にポリシーを確認しておけば、将来的に多大な手戻り作業が発生することを防げる可能性があります。

2. **プライバシーとコントロールは不可欠** - X 上の人々のプライバシーを保護・擁護することは、当社のコアとなる理念に組み込まれています。そのため、X のデータを、人々が合理的に期待するプライバシーと矛盾する形で利用することを禁止しています。X API を利用したり X Content にアクセスすることにより、あなたはこのコミットメントを守るうえで特別な役割を担うことになります。とりわけ、人々のプライバシーを尊重し、自身のデータがどのように利用されるかについて、透明性を確保し、コントロール手段を提供することが重要です。

3. **プラットフォーム利用ガイドラインに従う** - X API および X Content へのアクセスが承認されることは、最初のステップに過ぎません。X プラットフォームをどのように利用すれば、計画している用途がポリシーに準拠するかについて疑問が生じた場合は、まず当社の Platform Usage Guidelines（プラットフォーム利用ガイドライン）を参照してください。

これら 3 つの主要セクションがそれぞれ何を意味するのかについては、以下でさらに詳しく説明しています。X API および X Content の利用が当社のポリシーに合致していることを確認するため、必ず注意深くお読みください。

当社が、本ポリシー（または他の X のポリシー）に違反していると判断した場合、X API および X Content へのあなたのアクセスを一時停止、または恒久的に取り消すことがあります。

最後に、X は、X アプリケーションの改善、商用利用の有無の確認、ならびに承認済みユースケースおよび本ポリシーへの準拠状況を確認する目的で、X API のあなたの利用状況を監視する場合があることにご留意ください。

お読みいただきありがとうございます。そして、X と共にプロダクトを構築してくださってありがとうございます。あなたがどのようなものを生み出すのか、楽しみにしています。

<div id="privacy-and-control-are-essential">
  ## プライバシーとコントロールは不可欠です
</div>

X はプライバシーを重視しており、X Content や X API を利用するすべての人にも同様の姿勢を求めます。X Developer Platform、X API、または X Content を、人々の合理的なプライバシーの期待と整合しない形で利用した場合、API および X Content へのアクセスの一時停止や打ち切りを含むエンフォースメント措置の対象となることがあります。

プライバシーとコントロールへの取り組みは、X Content のあらゆる利用と、当社の API を用いて構築するサービスのあらゆる側面に及ばなければなりません。そのため、あなたのサービスを利用する人々は、あなたがその人たちのデータをどのように利用し、またその人たちに代わってどのように X にアクセスするかを理解し、同意している必要があります。これは、人々に対して明確で包括的かつ透明性のあるプライバシーポリシーを提示するとともに、その人たちに代わっていかなる行動を取る前にも、サービス利用者一人ひとりから明示的かつ十分な説明に基づく同意を得ることで実現できます。**なお、利用者があなたのサービスに対して認証を行うこと自体は、それだけで同意を意味するものではない点に注意してください。**

<div id="consent-permissions">
  ## 同意と権限
</div>

**特に、以下のいずれかを行う前には、必ず当事者から明示的かつ十分な説明に基づく同意を取得しなければなりません。**

* 当事者の代理で *いかなる* 行為を行うこと。これには以下が含まれますが、これらに限定されません。
  * X へのコンテンツの投稿
  * アカウントのフォロー/フォロー解除
  * プロフィールまたはアカウント情報の変更
  * 投稿にハッシュタグやその他のコンテンツを追加すること

* X API またはその他の X のツール以外の手段でアクセスしたコンテンツを再配信すること

* 他者の X コンテンツを使用して製品またはサービスを宣伝すること

* ダイレクトメッセージ (DM) などの非公開コンテンツ、その他の私的または機密情報を保存すること

* 保護されたコンテンツ、その他の私的または機密情報を共有または公開すること

**あなたのサービスがユーザーに X へコンテンツを投稿することを許可する場合、公開前に次のことを行わなければなりません。**

* 何が公開されるのかを正確に表示する
* コンテンツにどのような位置情報 (ある場合) が追加されるのかを、サービスの利用者に明確に示す

**あなたのサービスが、ユーザーにあなたのサービスと X の両方にコンテンツを投稿することを許可する場合、公開前に次のことを行わなければなりません。**

* コンテンツを投稿する許可を取得する
* コンテンツをどこに投稿するのかを説明する

**すべての X コンテンツの「保護」および「ブロック」ステータスを尊重しなければなりません。ある人物の認証トークンを使用して取得したコンテンツを、そのコンテンツを閲覧する権限のない別の人物に提供してはなりません。**

* **保護されたアカウント:** [保護されたアカウント](https://help.x.com/safety-and-security/public-and-protected-posts) のコンテンツは、そのアカウントをフォローすることを所有者から承認された人だけが利用できます。したがって、保護されたアカウントにアクセスするサービスを運用する場合、そのコンテンツを閲覧する権限を持つ特定のユーザーに対してのみ、そのコンテンツを提供する目的でアクセスすることができます。
* **ブロックされたアカウント:** X 上のユーザーは、任意の理由で自分のアカウントへのアクセスを[ブロック](https://help.x.com/using-x/blocking-and-unblocking-accounts)することができます。この選択を回避する目的で、トークンから得た情報 (またはその他の API ベースの操作) を混在させることは許可されません。

**ダイレクトメッセージ (DM) は本質的に非公開であるため、DM 機能を提供するサービスは、個人のプライバシーを保護するために追加の措置を講じる必要があります。DM コンテンツを、そのコンテンツを閲覧する権限のない人に提供してはなりません。あなたのサービスが DM 機能を提供する場合、次のことも行わなければなりません。**

* DM の既読通知イベントを送信する場合は、その旨をユーザーに通知すること。これは、サービス内で直接通知を提供する方法、または会話の他の参加者からの既読通知を表示する方法によって行うことができます。
* DM で送信されるメディアを「共有」(すなわち、複数の DM 間で再利用可能) として設定する前に同意を得ること。DM 内のメディアを「共有」とする場合は、そのメディアの URL を知っている者であれば誰でもそのコンテンツにアクセスできることを、明確な通知によって示さなければなりません。

<div id="content-compliance">
  ## コンテンツコンプライアンス
</div>

**X コンテンツをオフラインで保存する場合、そのコンテンツが X 上で現在どのような状態にあるかに合わせて最新の状態に保つ必要があります。** 具体的には、X 上でコンテンツが削除または変更された場合、あなたが保有している当該コンテンツも削除または変更しなければなりません。これは、合理的な範囲で可能な限り速やかに、または X もしくは該当する X アカウントの所有者からそのような要請を受領してから 24 時間以内、もしくはあなたと X との契約または適用法で別途求められる期間内に行う必要があります。法令で禁じられている場合を除き、この義務は履行しなければならず、そのような場合であっても、X による書面での明示的な許可がある場合に限られます。

変更されたコンテンツには様々な形態があります。これには（これらに限定されませんが）次のようなものが含まれます。

* 非公開にされた、または保護されたステータスを得たコンテンツ
* プラットフォームから停止措置の対象となったコンテンツ
* ジオタグが削除されたコンテンツ
* X 上で保留または削除されたコンテンツ

<div id="off-x-matching">
  ## X 外でのマッチング
</div>

**X 上の人物を、X 外で取得または保存した情報と照合できる状況は、厳しく制限されています。** X 外でのマッチングとは、X Content（X コンテンツ）、たとえば X の @handle や user ID を、特定の人物、世帯、デバイス、ブラウザ、その他の X 外の識別子と関連付けることを指します。これを行えるのは、その関連付けを行う前に、その人物から明示的なオプトインによる同意を得ている場合、または以下で説明する場合に限られます。

人物の X 上のアイデンティティを X 外の識別子にリンクするための、その人物の明示的なオプトイン同意がない状況では、あなたが行うあらゆる関連付けは、その目的で利用されることが合理的に期待される情報のみに基づいていなければなりません。さらに、その人物の明示的なオプトイン同意がない場合、あなたが保有する誰かに関する記録を X 上のアイデンティティと照合しようとすることができるのは、次の情報に基づく場合に限られます。

* **その人物があなたに直接提供した情報。** なお、あなたとの間にこれまで関係のない個人に関する記録（第三者から取得した個人に関する data を含む）は、この基準を満たしません。および／または
* **公開データ。** この文脈における「公開データ」とは、次を指します。
  * 職業団体の会員名簿などの、公開され一般に入手可能な情報源から、あなたが取得した人物に関する情報
  * X 上で、その人物について公開されている情報。これには次が含まれます。
    * 投稿
    * アカウントの自己紹介文や公開されている位置情報を含むプロフィール情報
    * 表示名および @handle

<div id="using-geo-data">
  ## ジオデータの使用
</div>

**ジオデータの利用には、その情報の機微性により追加の制限が適用されます。** サービスが投稿に位置情報を付加する場合、ユーザーに対して以下を開示しなければなりません。

* いつ位置情報を追加するのか
* 位置情報をジオタグとして追加するのか、注釈データとして追加するのか
* 位置情報が「場所」として表示されるのか、地理座標として表示されるのか

アプリケーションがユーザーに位置情報付きで投稿させることを可能にする場合は、X の[ジオガイドライン](/ja/developer-terms/geo-guidelines)を完全に遵守しなければなりません。

**位置データまたは地理情報を単独で利用することは禁止されています。** 投稿の一部としての場合を除き、X コンテンツに含まれる位置データやその他の地理情報を保存、集約、またはキャッシュしてはならず、また、他者に対してそれを許可することもできません。たとえば、投稿から位置データや地理情報のみを切り離して、個々のユーザーが時間の経過とともにどこにいたかを表示することはできません。ヒートマップや、集約されたジオアクティビティ（例：特定の都市でハッシュタグを利用している人数）を示すツールは許可されています。

**API ベースのボットアカウントを運用する場合、そのアカウントがどのようなアカウントであり、誰が責任を負っているのかを明確に示さなければなりません。** あなたのアカウントがボットであるかどうかについて、人を誤解させたり混乱させたりしてはいけません。そのための有効な方法として、プロフィールの自己紹介欄に、そのアカウントがボットである旨の記載を含めることが挙げられます。

<div id="x-cards">
  ## Xカード
</div>

**高品質なユーザー体験を確保するため、カードが表示されるすべてのプラットフォームで正しくレンダリングされるようにカードを開発する必要があります。** カードを使用する際に従う必要がある追加のルールは次のとおりです。

* カード内にセンシティブなメディアを表示する予定がある場合、その投稿のセンシティブなメディア設定を「true」にする必要があります

* カード内、またはカードを通じて X 上で金銭的インセンティブ（仮想通貨を含む）を付与してはなりません
* URL やメディアなど、誤解を招く、または文脈上関連性のないコンテンツやアクションをカード内に含めてはなりません
* 投稿内でそのアプリを明示的に宣伝または言及している場合にのみ、その投稿に App Card を添付することができます
