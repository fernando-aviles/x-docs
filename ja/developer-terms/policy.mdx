<div id="x-developers">
  ## X + Developers
</div>

X は開発者を大切にしています。私たちは、X のデータの力を活用してこのコミュニティが生み出すツールやサービスに、常に喜びと驚きを感じています。このコミュニティへの取り組みの一環として、開発者に対してオープンかつ公平であり、X を利用する人々にとって安全であり、X プラットフォーム全体にとって有益となるようなデータへのアクセスを提供することを目指しています。こうした目標をさらに推進するために、API および X Content の適切な利用に関する当社のルールと期待事項を理解していただくためのガイドとして、「Developer Policy」（**本ポリシー**）を策定しました。

この Developer Policy（「**本ポリシー**」）は、X のアプリケーション、サービス、ウェブサイト、ウェブページおよびコンテンツから成るエコシステムと連携する開発者向けのルールとガイドラインを定めるものです。本ポリシーは、X API および X Content へのアクセスおよびその利用を規定する、X との契約（Developer Agreement または X とのその他の書面による契約の一部）に組み込まれています。本ポリシーへの違反は、それらの契約への違反とみなされます。本ポリシーは、予告なく随時変更される場合があります。本ポリシーで使用され、本ポリシー内で定義されていない大文字で始まる用語は、[Developer Agreement](/ja/developer-terms/agreement) または Master License Agreement において定義された意味を有するものとします。

<div id="using-this-policy">
  ## このポリシーの使い方
</div>

このポリシーは、できる限り分かりやすく理解しやすい構成にしています。X API および X Content を利用する際は、以下のポリシーセクションの情報を常に念頭に置いてください。

1. **成功への準備を整える** - すべての X ポリシーを遵守する責任はあなたにあります。X API および X Content にアクセスする前に、このポリシーおよび本書で参照しているポリシーを確認し、理解することが重要です。ポリシーの確認に費やす時間は、将来的に何時間もの手戻りを防ぐことにつながるかもしれません。

2. **プライバシーとコントロールは不可欠** - X 上の人々のプライバシーを保護・擁護することは、当社の企業としての根幹に組み込まれています。そのため、人々が合理的に期待するプライバシーに反する形で X のデータを利用することを禁じています。X API を利用したり X Content にアクセスすることにより、あなたはこの取り組みを守る特別な役割を担うことになります。何よりもまず、人々のプライバシーを尊重し、そのデータがどのように利用されるかについて、透明性とコントロールを提供する責任があります。

3. **プラットフォーム利用ガイドラインに従う** - X API および X Content へのアクセスが承認されることは、あくまで最初のステップにすぎません。X プラットフォームの利用に関して、予定している利用方法がポリシーに準拠していることを確認したい場合は、必ず最初にプラットフォーム利用ガイドラインを参照してください。

これら 3 つの重要なセクションのそれぞれが意味する内容については、この後でさらに詳細に説明しています。X API および X Content の利用が当社のポリシーに沿ったものであることを確認するため、必ずよくお読みください。

当社が、あなたが本ポリシー（または他のいかなる X ポリシー）に違反していると判断した場合、X API および X Content へのアクセスを一時停止、または恒久的に取り消すことがあります。

最後に、X は X API のあなたの利用状況を、X アプリケーションの改善、商用利用の調査、および承認されたユースケースおよび本ポリシーへの準拠状況の確認の目的で監視する場合があることにご留意ください。

ここまでお読みいただきありがとうございます。また、私たちと共に X 上で構築してくださり感謝します。あなたが何を生み出すのか、楽しみにしています。

  ## 成功に向けた準備を整える
</div>

X API を利用する際には、サービスを初日から正しく構築しておくことで、多くの潜在的な落とし穴を回避できます。Developer Policy の本セクションには、X API または X Content を使用する前に、すべての開発者が遵守しなければならないルールが記載されています。

Free、Basic、Pro プラン（[developer.x.com/en](http://developer.x.com/en) に記載）は、ホビーユース、商用プロトタイピング、初期段階の X プロダクト統合、エンドユーザー数が限られたアプリケーションのサポートを目的として設計されています。X API と X Content の利用がこの範囲を超える場合は、Enterprise プラン（[developer.x.com/en](http://developer.x.com/en) に記載）に申し込む（またはすでに購読している）必要があります。

**X 開発者プラットフォームで提案されるあらゆる利用方法は、ポリシー遵守を確認するために審査されます。そのため、X API および X Content の利用計画について、アクセスを付与・維持する条件として、開示（および必要に応じて更新）することが求められます。** 新規開発者は全員、X API にアクセスするために[開発者アカウントを申請](https://developer.x.com/portal/petition/essential/basic-info)する必要があります。現在の開発者で、承認済みの開発者アカウントを持たない場合は、X からの指示に従って申請しなければなりません。このプロセスの一環として、X API および X Content の利用目的について、文章による説明を提出していただきます。

利用事例（use case）の説明は、あなたにとって拘束力を有するものであり、そこから実質的に逸脱することは、当社ルール違反となり得るほか、措置の対象となる可能性があります。利用事例の内容に実質的な変更を行う場合は、その旨を当社に通知し、新たな目的で X Content を利用し始める前に承認を受けなければなりません。そうしない場合、API およびデータへのアクセスが停止もしくは終了されることがあります。

**X API を基盤として構築する場合や X Content にアクセスする場合、すべての X ポリシーに従わなければなりません。** これには、本[Developer Policy](/ja/developer-terms/policy)、[Automation Rules](https://help.x.com/rules-and-policies/x-automation)、[Display Requirements](https://developer.x.com/developer-terms/display-requirements.html)、[API Restricted Uses Rules](/ja/developer-terms/restricted-use-cases)、[X Rules](https://help.x.com/rules-and-policies/x-rules)、[X Brand Resources](https://about.x.com/who-we-are/brand-toolkit)のほか、X API または X Content の利用に関連して X と締結するその他の合意（[Developer Agreement](/ja/developer-terms/agreement) や、該当する場合は Master Licensing Agreement または Order を含みますが、これらに限定されません）が含まれます。また、これらのポリシーの変更や、X によって新たに導入されるポリシーにも従う必要があります。あなたのサービスの利用状況を監視し、サービスを適切に設計することで、利用者による X ポリシー違反を防止する責任はあなたにあります。これを行わない場合、API および X Content へのアクセスが停止または終了されることがあります。

**単一の利用事例、または実質的に類似もしくは重複する利用事例に対して、複数のアプリケーションを登録することはできません。** この文脈における「利用事例（use case）」とは、アプリケーションを通じて行われる、一貫した分析、表示、またはアクションの集合を意味します。「ホワイトラベル」版のツールやサービスは許可されません。アプリケーションの「ホワイトラベル」版を提供する予定がある場合は、当社に通知し、個別の承認を受けなければなりません。

*これらのルールに対する唯一の例外として、* 同一サービスの development、staging、production インスタンス用に最大 3 つのアプリケーションを作成・利用することができます。これらのアプリは 1 つのアカウントに登録されている必要があり、単一サービスの dev、staging、prod インスタンスであることが、名前および説明において明確に識別できるようにしなければなりません。**development または staging 用のアプリケーションを、本番（production）目的で使用することはできません。**

**すべての API key およびその他のアクセス認証情報は秘密として保持しなければなりません。** 他人が所有する API key やその他のアクセス認証情報を使用したり、他者がそれらを使用することを助長または支援したりしてはなりません。

**X とのライセンス契約により、X API および X Content の利用は制限されます。とりわけ、X API には、データの公正な利用を確保し、プラットフォーム上のスパムと闘うためのレート制限が設けられています。** レート制限や、本ポリシーや X との契約に記載された、または [Developer Site](https://developer.x.com/) に掲載された、あるいは X から通知されたその他の制限や制約を超過したり回避したりしてはなりません。

<div id="privacy-and-control-are-essential">
  ## プライバシーとコントロールは不可欠です
</div>

X はプライバシーを重視しており、X Content や X API を利用するすべての方にも同様の姿勢を求めています。X デベロッパープラットフォーム、X API、または X Content を、人々が合理的に期待するプライバシーに反する方法で利用した場合、API および X Content へのアクセスの一時停止や終了を含む、各種の措置の対象となることがあります。

プライバシーとコントロールへの取り組みは、X Content のあらゆる利用と、当社の API を使って構築するサービスのあらゆる側面にまで及ばなければなりません。そのため、あなたのサービスを利用する人々は、あなたが彼らのデータをどのように利用し、彼らに代わってどのように X にアクセスするのかを理解し、同意している必要があります。これは、人々に対して明確で、包括的かつ透明性の高いプライバシーポリシーを提示するとともに、彼らに代わっていかなる行為を行う前にも、あなたのサービスを利用する各人から明示的かつ十分な説明に基づく同意を得ることで実現できます。**なお、ある人があなたのサービスに対して認証を行ったという事実だけでは、同意があったとはみなされない点に注意してください。**

<div id="consent-permissions">
  ## 同意と許可
</div>

**特に、以下のいずれかを行う前には、必ず当該の人から明示的かつ十分な説明に基づく同意を得なければなりません。**

* 本人に代わって *いかなる* 行為を行うこと。これには、以下が含まれます（ただし、これらに限定されません）：
  * X へのコンテンツの投稿
  * アカウントのフォロー／フォロー解除
  * プロフィールまたはアカウント情報の変更
  * 投稿にハッシュタグやその他のコンテンツを追加すること

* X API やその他の X のツール以外の手段で取得したコンテンツを再公開すること

* 他者の X コンテンツを、製品やサービスの宣伝に利用すること

* ダイレクトメッセージ（DM）などの非公開コンテンツ、またはその他の私的もしくは機密情報を保存すること

* 保護されたコンテンツ、またはその他の私的もしくは機密情報を共有または公開すること

**あなたのサービスが人々に X へコンテンツを投稿する機能を提供する場合、公開前に以下を実施しなければなりません。**

* 何が公開されるのかを正確に表示すること
* コンテンツにどのような位置情報（ある場合）が追加されるかを、あなたのサービスの利用者に対して明確に示すこと

**あなたのサービスが、人々にあなたのサービスと X の両方へコンテンツを投稿する機能を提供する場合、公開前に以下を実施しなければなりません。**

* コンテンツを投稿するための許可を取得すること
* コンテンツをどこに投稿するのかを説明すること

**すべての X コンテンツについて、その保護状態およびブロック状態を尊重しなければなりません。一人の認証トークンを使って取得したコンテンツを、そのコンテンツの閲覧が許可されていない別の人に提供してはなりません。**

* **保護されたアカウント：** [保護されたアカウント](https://help.x.com/safety-and-security/public-and-protected-posts)のコンテンツは、そのアカウントをフォローすることを所有者から承認された人にのみ閲覧可能です。したがって、保護されたアカウントにアクセスするサービスを運営する場合、そのコンテンツを閲覧する権限を持つ特定の人に対してのみ、そのコンテンツを提供するためにアクセスすることができます。
* **ブロックされたアカウント：** X を利用する人々は、理由を問わず、自分のアカウントへのアクセスを[ブロック](https://help.x.com/using-x/blocking-and-unblocking-accounts)することができます。トークン（またはその他の API ベースの処理）から得た情報を組み合わせて利用し、この選択を回避しようとする行為は許可されません。

**ダイレクトメッセージ（DM）は性質上非公開であるため、DM 機能を提供するサービスは、個人のプライバシーを保護するための追加の措置を講じなければなりません。DM の閲覧が許可されていない人に DM コンテンツを提供してはなりません。あなたのサービスが DM 機能を提供する場合、次のことも行う必要があります。**

* DM に既読通知イベントを送信する場合は、その旨を人々に通知すること。これは、サービス内で直接通知を表示するか、会話内の他の参加者からの既読通知を表示することによって行うことができます。
* DM で送信されるメディアを「共有」（すなわち、複数の DM 間で再利用可能）として設定する前に、同意を取得すること。DM 内のメディアを「共有」できるようにする場合は、このコンテンツがメディアの URL を知っているすべての人からアクセス可能となることを、明確な通知によって示さなければなりません。

<div id="content-compliance">
  ## コンテンツのコンプライアンス
</div>

**X コンテンツをオフラインで保存する場合、そのコンテンツの X 上での最新の状態を常に反映させておく必要があります。** 具体的には、X 上でコンテンツが削除または変更された場合、あなたが保有する当該コンテンツも削除または変更しなければなりません。これは、合理的に可能な限り速やかに、または X もしくは該当する X アカウント所有者からそのような要請を受領してから 24 時間以内、あるいは X との契約または適用法により別途求められる期間内に行う必要があります。法令によりこの対応が禁止されている場合を除き、この義務は適用されますが、そのような場合であっても、X の明示的な書面による許可がある場合にのみ免除されます。

変更されたコンテンツには、様々な形態があります。これには（これらに限定されませんが）次が含まれます。

* 非公開にされた、または保護されたステータスになったコンテンツ
* プラットフォーム上で配信停止されたコンテンツ
* ジオタグが削除されたコンテンツ
* X 上で表示保留または削除されたコンテンツ

<div id="off-x-matching">
  ## X 外でのマッチング
</div>

**X 上の人物を、X 外で取得または保存した情報と照合できる状況は、厳しく制限しています。** X 外でのマッチングとは、X コンテンツ（X の @handle やユーザー ID を含む）を、人物、世帯、デバイス、ブラウザ、その他の X 外の識別子と関連付けることを指します。こうした関連付けは、その人物から事前に明示的なオプトイン同意を得ている場合、または以下に記載する場合にのみ行うことができます。

ある人物の X 上のアイデンティティを X 外の識別子にリンクすることについて、その人物から明示的なオプトイン同意を得ていない場合、あなたが行ういかなる関連付けも、その目的で利用されることを合理的に想定できる情報のみに基づいていなければなりません。加えて、人物の明示的なオプトイン同意がない場合、あなたが自らの記録を X 上のアイデンティティと照合しようと試みることができるのは、次の情報に基づく場合に限られます。

* **その人物から直接提供された情報。** あなたとの間にこれまで関係のない個人に関する記録（第三者から取得した個人に関するデータを含む）は、この基準を満たさないことに注意してください。および／または
* **公開データ。** この文脈における「公開データ」とは、次を指します。
  * あなたが、公的に一般に利用可能な情報源（職業団体の会員名簿など）から取得した、その人物に関する情報
  * X 上でその人物について公開されている情報で、次のものを含みます。
    * 投稿
    * アカウントの自己紹介や公開されている所在地を含むプロフィール情報
    * 表示名および @handle

<div id="your-privacy-policy">
  ## プライバシーポリシー
</div>

**お客様のサービスのプライバシーポリシーは、利用者がそのサービスをダウンロード、インストール、または登録する前に提示しなければなりません。** プライバシーポリシーには、少なくとも次の情報を開示する必要があります。

* お客様がサービス利用者から収集する情報
* その情報の利用および共有方法（X との共有を含みます）
* 利用者が自分の情報に関する問い合わせや要請を行うための連絡方法

お客様のプライバシーポリシーは、適用されるすべての法律と整合しており、かつ[「X プライバシーポリシー」](https://x.com/privacy)および[当社の他のサービスおよび関連会社のプライバシーポリシー](https://help.x.com/rules-and-policies/x-services-and-corporate-affiliates)と比較して、利用者に対する保護水準がそれらを下回ってはなりません。お客様自身のプライバシーポリシーまたは X のプライバシーポリシーを遵守できない場合、X API へのアクセスおよびすべての X コンテンツの利用を停止しなければなりません。

<div id="using-geo-data">
  ## 位置情報データの利用
</div>

**位置情報データは、その機微な性質上、追加の制限の対象となります。** サービスが投稿に位置情報を付加する場合、ユーザーに対して次の点を開示する必要があります。

* いつ位置情報を付加するのか
* 位置情報をジオタグとして付加しているのか、注釈データとして付加しているのか
* その位置情報が「場所」として表示されるのか、地理座標として表示されるのか

アプリケーションで、ユーザーが自分の位置情報付きで投稿できるようにしている場合は、X の[位置情報に関するガイドライン](/ja/developer-terms/geo-guidelines)を完全に順守しなければなりません。

**位置情報データや地理情報を単独で利用することは禁止されています。** 投稿の一部として扱う場合を除き、X コンテンツに含まれる位置情報データおよびその他の地理情報を保存、集約、またはキャッシュしてはならず、また第三者に対してもこれを許可してはなりません。たとえば、個人が時間の経過とともにどこにいたかを示す目的で、投稿から位置情報データや地理情報だけを切り離して利用することはできません。集約された地理的アクティビティ（例: 特定の都市でハッシュタグを使用している人の数）を表示するヒートマップや関連ツールは許可されています。

<div id="x-passwords">

<div id="content-redistribution">

</div>

**X コンテンツを入手する最良の方法は、X から直接取得することです。そのため、X コンテンツを第三者へ再配布することには制限があります。** X コンテンツを、ダウンロード可能なデータセットや API 経由などで第三者に提供する場合は、（以下に記載の例外を除き）配布できるのは投稿 ID（Post IDs）、ダイレクトメッセージ ID（Direct Message IDs）、および/またはユーザー ID（User IDs）のみです。

<div id="x-cards">
