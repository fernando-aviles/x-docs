当社の開発者向けプラットフォームを利用するには、[Developer Agreement and Policy](/ja/developer-terms/agreement) の内容を確認し、同意していただく必要があります。また、[Display Requirements](https://developer.x.com/en/developer-terms/display-requirements.html) や [Automation Rules](https://help.twitter.com/en/rules-and-policies/twitter-automation) を含む関連ポリシーにも同意し、順守していただく必要があります。これらの契約およびポリシーでは、他の内容とあわせて、いくつかの制限された利用ケースについての指針を示しています。以下で、これらの制限の一部について追加情報を提供します。

<div id="sensitive-information">
  ## 機微な情報
</div>

X ユーザーについて、X データを利用して機微な特性を導き出したり推測したりする際には注意が必要です。次のような X ユーザーに関する情報を導出または推測したり、そのように導出または推測された情報を保存したりしては決してなりません。

* 健康状態（妊娠を含む）
* 不健全な財務状況や経済状態
* 政治的な所属または信条
* 人種的または民族的出自
* 宗教的または哲学的な所属または信条
* 性生活または性的指向
* 労働組合への所属
* 犯罪の疑いまたは実際に犯罪を行ったこと

個人データ（たとえば、ユーザーID、ユーザー名、その他の識別子）を一切保存しない形での X コンテンツの集約分析は認められますが、その分析が適用される法律および Developer Agreement and Policy のすべての条項に準拠していることが条件となります。

<div id="off-x-matching">
  ## X外でのマッチング
</div>

X外でのマッチングとは、X上のコンテンツ（Xのユーザー名やユーザーIDを含む）を、人、世帯、デバイス、ブラウザー、その他のX外の識別子と関連付けることを指します。例えば、Xのユーザー名を、企業の顧客記録（例：「John Doe」として登録されている顧客レコードを、X上の @johndoe に対応させること）と関連付けるような場合です。

私たちは、人々がX上で、必要に応じて実名とは別の、仮名によるアイデンティティを作成できるようにしたいと考えています。Xユーザーに関するいかなる情報でも、X外の識別子と関連付けようとする場合には、その関連付けを行う前に、そのユーザーから明示的なオプトイン同意を取得することを求めます。例えば、あなたのサービスへのサインアッププロセスの一環として、ユーザーが自らのXハンドルをあなたに直接共有する場合などに、その同意を取得できます。

ユーザーのX上でのアイデンティティをX外の識別子にリンクすることについて、ユーザーからの明示的なオプトイン同意がない状況では、あなたが行うあらゆる関連付けは、その目的での利用がユーザーにとって合理的に予期しうる情報のみに基づく必要があります。ユーザーが、自分が提供した情報を使って自分のXアカウントをX外のアイデンティティにリンクしていることを知ったら驚くような場合は、そのような行為は行わないでください。さらに、個人からの明示的なオプトイン同意がない場合、あなたが保有する誰かに関する記録をX上のアイデンティティとマッチングしようと試みることができるのは、以下の情報に基づく場合に限られます。

* **ユーザーがあなたに直接提供した情報。** あなたがこれまでに関係を持ったことのない個人に関する記録（第三者から取得した個人に関するデータを含む）は、この基準を満たしません。および／または
* **パブリックデータ。** この文脈における「パブリックデータ」とは、次のものを指します。
  * 公開され、一般に利用可能なリソース（職業団体の会員名簿など）から取得した、ユーザーに関する情報
  * X上で公開されている、ユーザーに関する情報（以下を含む）:
    * 投稿
    * ユーザーの自己紹介文や公開している所在地を含む、プロフィール情報
    * 表示される名前およびユーザー名

<div id="redistribution-of-x-content">
  ## X コンテンツの再配布
</div>

X API を通じて取得した X コンテンツを第三者と共有する必要がある場合、最も適切な方法は、投稿 ID、ダイレクトメッセージ ID、および／またはユーザー ID を共有することです。コンテンツのエンドユーザーは、X API を使用してそれらを「再取得」（すなわち、完全な投稿、ユーザー、またはダイレクトメッセージのコンテンツをリクエスト）できます。これにより、X コンテンツのエンドユーザーが常に最新の情報を直接当社から取得できるようになります。

当社は、非自動化手段による再取得済み X コンテンツの限定的な再配布を許可します。この方法で再取得済み X コンテンツを第三者と共有する場合、1 受領者あたり 1 日に共有できる再取得済みの公開投稿オブジェクトおよび／またはユーザーオブジェクトは最大 50,000 件までであり、このデータを一般に公開してはなりません（たとえば、ブログ投稿への添付ファイルとして、または公開された Github リポジトリで公開することなど）。

X コンテンツの再配布に関して、ほかにもいくつか留意すべき点があります。

* X から事前の明示的な書面による許可を受けていない限り、30 日間の期間内に単一の組織に対して配布できる投稿 ID の合計は 1,500,000 件までです。
* 学術機関に代わって、非商用の研究のみを目的として投稿 ID および／またはユーザー ID を再配布する個人は、無制限の投稿 ID および／またはユーザー ID を再配布することが許可されています。
* 上記のとおりに X コンテンツを共有する許可をリクエストするには、API Policy サポートフォームをご利用ください。

許可された範囲で X コンテンツを第三者に配布する場合でも、そのコンテンツは引き続き Developer Agreement および Developer Policy の対象となり、当該第三者は、X の [Terms of Service](https://twitter.com/en/tos)、[Privacy Policy](https://twitter.com/en/privacy)、[Developer Agreement](/ja/developer-terms/agreement)、および [Developer Policy](/ja/developer-terms/policy) に同意したうえで X コンテンツを受領しなければなりません。

<div id="multiple-applications">
  ## 複数のアプリケーション
</div>

単一のユースケース、または実質的に類似・重複するユースケースに対して、複数のアプリケーションを登録することはできません。これらのポリシーの詳細については[こちら](https://twittercommunity.com/t/policy-clarification-multiple-applications-for-the-same-use-case/92080)をご覧ください。

ここで「ユースケース」とは、アプリケーションを通じて実行される、一貫性のある分析、表示、アクションのまとまりを意味します。同じサービスまたはアプリケーションを異なるエンドユーザーに提供する場合でも、それは 1 つのユースケースと見なされます。ただし、ツールやサービスの「ホワイトラベル」版はこの限りではありません。アプリケーションの「ホワイトラベル」版を提供する予定がある場合は、必ず事前に当社へ通知し、個別の承認を受けてください。これらのルールは、あなたが登録するアプリケーションだけでなく、あなたのツールやサービスのエンドユーザーが登録するアプリケーションにも適用されます。あなたのツールやサービスを利用する目的でエンドユーザーにアプリケーションの登録を求める場合、あなた自身、あなたのアプリケーション、あなたの顧客、および／またはあなたのツールやサービスのエンドユーザーが、措置の対象となる可能性があります。

このルールの唯一の例外は、同一サービスに対して開発（「dev」）、ステージング、本番（「prod」）の各インスタンスを作成する場合です。これらのアプリケーションは（たとえばアプリケーションの名前や説明で）明確に区別してラベル付けし、開発またはステージング用のアプリケーションを本番目的で使用しないようにしてください。

<div id="automation-spam-and-auto-responses">
  ## 自動化、スパム、自動レスポンス
</div>

スパムを作成したり、スパム的な行為に関与したりする目的で X の API や開発者向け製品を利用することは禁止されています。スパムに関する [X Rules](https://t.co/rules) を確認し、アプリケーションおよびユーザーがアプリケーションを通じて当社のポリシーに違反しないようにしてください。

アプリケーションが、投稿の作成、アカウントのフォロー、ダイレクトメッセージの送信など、X サービス上での書き込み操作に利用される場合は、サービスがガイドラインに準拠していることを確認するため、[Automation Rules](https://support.twitter.com/articles/76915) を十分に確認してください。特に、次の点を遵守する必要があります。

* [自動返信や自動メッセージ](https://twittercommunity.com/t/policy-clarification-automated-replies-and-mentions/94444) を送信する前に、必ずユーザーから明示的な同意を取得してください
* 連絡の受信を希望しないというユーザーからのリクエストには、直ちに応じてください
* [一括フォロー](https://twittercommunity.com/t/policy-clarification-aggressive-following-and-inorganic-following-behavior/92769) を含む、大量・攻撃的・スパム的なアクションを決して行わないでください
* [複数アカウント](https://blog.twitter.com/developer/en_us/topics/tips/2018/automation-and-the-use-of-multiple-accounts.html) に、同一または実質的に類似したコンテンツを決して投稿しないでください

<div id="measuring-the-x-service">
  ## Xサービスの測定
</div>

ベンチマークや競合上の目的で、Xの可用性、パフォーマンス、機能、または利用状況を測定するためにX APIを使用してはいけません。例えば、次のような目的でX APIを使用してはなりません。

* アクティブユーザー数やアカウント総数など、Xユーザーに関する集計指標を算出すること
* 1日あたりの投稿総数や、ユーザーエンゲージメント数、アカウントエンゲージメント数など、X上の投稿に関する集計指標を算出すること
* [X Rules](https://help.twitter.com/en/rules-and-policies/twitter-rules) で認められている場合を除き、X上のスパムやセキュリティを測定または分析すること

<div id="surveillance-privacy-and-user-protection">
  ## 監視、プライバシー、ユーザー保護
</div>

X では、ユーザーのプライバシーを保護し擁護することが、当社の企業の DNA の中核に組み込まれており、開発者向けプロダクトやデータプロダクトにもそのコミットメントが反映されています。X のデータは、世界に善い影響をもたらす強力な力になり得ると信じています ― ジャカルタの洪水時の人命救助から、USGS による地震の追跡、国連と協力した持続可能な開発目標の達成に至るまで、さまざまな場面で役立っています。しかし、監視を目的とする、またはユーザーのプライバシーに関する合理的な期待に反するその他いかなる方法による X データおよび X API の利用も、いかなる主体に対しても禁止します。例外は一切ありません。

当社のデータおよび開発者向けプロダクトの禁止用途については、[Developer Agreement](/ja/developer-terms/agreement) で説明しており、その中には X ユーザーやそのコンテンツの調査・追跡の禁止、さらには（抗議活動、集会、コミュニティの組織化会合などの）機微なイベントの追跡、警告、監視の禁止も含まれます。

これらの条件の下で禁止される活動のカテゴリーには、次のものが含まれます（これらに限定されるものではありません）。

* 労働組合やアクティビスト団体など、機微なグループや組織の調査・追跡
* 身元調査やその他あらゆる形態の厳格な審査
* クレジットまたは保険のリスク分析
* 個人プロファイリングや心理的特性に基づくセグメンテーション
* 顔認識

これらのポリシーは、当社の API のすべてのユーザーに適用されます。これらの目的で X API を不正利用した場合は、アクセスの一時停止や終了を含む措置の対象となります。

X アカウントに関する情報を求める法執行機関向けの追加情報については、[https://t.co/le](https://t.co/le) を参照してください。

さらに現時点では、[Grok](https://help.x.com/en/using-x/about-grok) を例外として、基盤モデルまたは最先端モデルの微調整または学習を目的とした、X API および／または X Content のあらゆる利用を禁止します。
