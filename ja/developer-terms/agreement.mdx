**I. 定義**

本契約においては、以下の定義が適用されます。

1. “**Developer Site**”とは、[**https://developer.x.com/**](https://developer.x.com/) にあるXの開発者向けサイトを意味します。

2. “**Direct Message**”とは、Xのダイレクトメッセージ機能を使用して、X Applications上で1人のユーザーから1人以上の他の特定のユーザーに送信される非公開メッセージを意味します。

3. “**Intellectual Property Rights**”とは、世界中のすべての著作権、著作者人格権、特許権、商標権、その他あらゆる知的財産権またはこれに類する権利（登録済みか未登録かを問わない）を意味します。

4. “**Licensed Material**”とは、個別または総称して、X APIおよびX Contentを意味します。

5. &quot;**Paid Service(s)**”とは、本契約および当該機能に適用される条件に従い、継続的な料金の支払いと引き換えにアクセスするLicensed Materialの機能を意味します。本契約に別途定めがない限り、「Licensed Material」へのすべての言及にはPaid Service(s)が含まれることを意図します。

6. “**Payment Portal**”とは、Licensed Materialの利用を選択し、Paid Servicesのサブスクリプションを管理し、Paid Servicesの支払方法を管理し、アカウント情報を更新するために、お客様が利用できるよう提供されるオンラインポータルを意味します。

7. “**Services**”とは、X Contentを表示する、またはその他の方法でLicensed Materialを利用する、お客様のサービス、ウェブサイト、アプリケーション、およびその他の提供物（リサーチを含む）を意味します。

8. “**Post**”とは、X Applicationsを通じて配信される短文テキストおよびマルチメディアベースのメッセージ（投稿）を意味します。

9. “**X**”とは、(a) お客様の主たる事業所が欧州連合、EFTA加盟国、および英国の外にある場合は X Corp.（865 FM 1209, Building 2, Bastrop, TX 78602, USA）を、または (b) お客様の主たる事業所が欧州連合、EFTA加盟国、または英国にある場合は X Internet Unlimited Company（One Cumberland Place, Fenian Street, Dublin 2, D02 AX07, Ireland）を意味します。

10. “**X API**”とは、X Application Programming Interfaces（それぞれ、**“API”**）、Software Development Kits（それぞれ、**“SDK”**）、およびDeveloper Siteを通じてXによって提供される関連ツール、ドキュメント、データ、テクノロジー、コード、その他の資料を意味します。

11. “**X Applications**”とは、一般に「X」と呼ばれるXのリアルタイム情報サービスを意味し、XのウェブサイトおよびXが所有、運営、または管理するモバイルアプリケーション、ソーシャルプラグイン、アプリケーションプログラミングインターフェイスを通じて現在提供されているサービスを含みます。

12. “**X Content**”とは、Post、各Postに対して生成される一意の識別番号、Xエンドユーザーのプロフィール情報、およびX APIまたはXにより承認されたその他の手段を通じてお客様に提供されるその他のデータおよび情報、ならびにそれらの複製物および派生物を意味します。

13. “**X Marks**”とは、本契約に従って使用する目的に限り、Developer Siteを通じて提供されるものを含め、Xがお客様に利用可能にするXの名前、商標、およびロゴを意味します。

14. “**Users**”とは、お客様のServicesの訪問者、ユーザー、または顧客を意味します。

* DM に対して既読通知イベントを送信する場合は、その旨を人々に通知すること。これは、あなたのサービス内で直接通知を表示するか、会話内の他の参加者からの既読通知を表示することで行うことができます。

**X コンテンツの周囲で、どのように、どこに広告を掲載できるかについては制限があります。** まず、あなたの広告は投稿と似せたり、利用者が投稿と誤認するおそれがあってはなりません。その他の広告に関するルールは次のとおりです。

* **X コンテンツとあなたの広告の間には明確な区別がなければなりません。** X 広告以外の広告を X のタイムライン内に掲載することはできません。
* **X は、X API を通じて広告を配信する権利を留保します。** X が API 経由で広告配信を開始した後に、あなたが X 広告の配信を行うことを選択した場合、関連する利用規約および条件に従い、当社は広告収益の一部をあなたに分配します。
* **X コンテンツや X API から取得した情報を使用して、X プラットフォーム外で人々を広告の対象とすることはできません。**

以下に挙げる X のサービスまたは機能を利用する場合には、次の追加ルールが適用されます。

<div id="x-login">
  ### Xログイン
</div>

**OAuthプロトコルなどを利用して、Xへのログインおよびログアウトを行うためのオプションを、ユーザーが簡単に見つけられるように提示しなければなりません。** *Sign in with X* オプションは、あなたのサービス上の他のいかなるサインアップまたはサインイン機能と少なくとも同等に目立つように表示しなければなりません。Xアカウントを持っていないユーザーに対しても、Xを通じてアカウントを作成できる機会を提供しなければなりません。

**あなたのサービス上で、ユーザーが *Sign in with X* を通じて認証を行った場合、そのユーザーのXアイデンティティを明確に表示しなければなりません。** Xアイデンティティには、そのユーザーの現在のXの@handle、アバター、およびXロゴが含まれます。あなたのサービス上でユーザーのXフォロワーを表示する場合、そのフォロー関係がX上のものであることを明確に示さなければなりません。

<div id="x-cards">
  ### X Cards
</div>

**質の高い体験を提供するためには、Cards が表示されるすべてのプラットフォームで正しくレンダリングされるように Card を開発する必要があります。** Cards を利用する際に従う必要がある追加のルールは次のとおりです。

* Card 内でそのようなメディアを表示する予定がある場合は、その投稿のセンシティブメディア設定を「true」にしなければなりません
* Card 内のすべてのアセットをホストする際には HTTPS を使用しなければなりません。Card によってブラウザでアクティブな混在コンテンツに関する警告が表示されるようなことがあってはなりません
* 音声および動画コンテンツには停止または一時停止コントロールを含める必要があり、自動再生される動画についてはデフォルトで「ミュート（音声オフ）」に設定しなければなりません

**Card の想定されている用途を含め、X が Card に対して設けているいかなる制限を超えたり迂回したりしてはなりません。** Cards の利用に関する追加の制限は次のとおりです。

* X の承認なく、Cards 内に第三者によるスポンサー付きコンテンツを配置してはなりません
* Card 内または Card から X 上に金銭的インセンティブ（仮想通貨を含む）を付与してはなりません
* Card 内に、URL やメディアなど、誤解を招く、または文脈上関連性のないコンテンツやアクションを含めてはなりません
* 投稿内で誰かがそのアプリを明示的に宣伝または言及している場合にのみ、App Card を投稿に添付することができます
