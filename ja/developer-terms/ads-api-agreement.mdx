**2.1** 「**Campaign**」とは、デスクトップ、モバイルウェブサイト、またはモバイルアプリケーションにおける広告キャンペーン、またはその一部を意味します。

**2.2** 「**Client**」とは、Ads Products の 1 つ以上を利用し、かつ各場合において X により承認された、X の広告主（同時に Company の顧客でもあるもの）を意味します。

**2.4** 「**Company Materials**」とは、Ads Products を通じて Company から X に提供される、あらゆる Company のデータ、成果物、またはユーザーコンテンツを意味します。

**2.5** 「**Company Service**」とは、X Materials もしくはその一部を表示またはその他の方法で利用する、Company のウェブサイト、アプリケーションおよびその他の提供物を意味します。

**2.6** 「**Data**」とは、メトリクス、データ、および X が Company に提供するその他一切の情報および／またはコンテンツを意味し、かかる情報のいずれかを分析または利用することにより（集計か否かを問わず）導出される、あらゆる結果、利用統計、データまたはその他の情報を含みます。

**2.7** 「**End Users**」とは、Ads Products を当該 Client に代わって利用する、Client の従業員または認められた代理人を意味します。

**2.8** 「**Marks**」とは、文脈に応じて、X Marks および／または Company Marks を意味します。

**2.9** 「**Materials**」とは、文脈に応じて、X Materials および／または Company Materials を意味します。

**2.10** 「**Personal Data**」とは、生存する個人に関するデータであって、当該データから、または当該データと、データ管理者の占有下にあるか、または占有下に置かれる可能性のある他の情報とを組み合わせることにより、当該個人が識別されるか、または識別され得るものを意味します。

**2.11** 「**X Ads**」とは、X Network 上への広告掲載を含む、X の広告プロダクトおよびサービスを意味します。

**2.12** 「**X Code**」とは、X によって開発され、Company に提供される、少なくとも X のサーバーを呼び出すコンピュータコードを意味します。

**2.13** 「**X Marks**」とは、本契約に基づき Company による使用のために X から Company に提供された（または本契約に基づく Company による使用について X により別途許可された）、X の名前およびあらゆる X のロゴ、商標および／またはサービスマークを意味します。

**2.14** 「**X Materials**」とは、X によって生成された、あらゆる X のデータ、成果物またはユーザーコンテンツ（その派生物を含む）および、X によって生成、収集または開発された、または本契約に従って X から Company に提供もしくは利用可能とされる、あらゆる X のデータ、成果物またはユーザーコンテンツ（その派生物を含む）を意味し、Company と X とのパートナーシップから生じる、またはこれに基づきもしくはこれに起因して発生するあらゆるデータ、あらゆるデバイスレベルのデータ、または Company もしくは X により承認された第三者が Company の X 広告キャンペーンから、またはこれに関連して収集、推定、導出または取得する、あらゆるコンバージョン、エンゲージメント、トラッキングまたはターゲティングデータを含みます。明確化のため、また、これを制限することなく述べると、「X Materials」には、[別紙 A](#Exhibit-A) で定義される X Ads API、X Code、Data、Ads Products、およびカスタムオーディエンス（下記で定義）を作成するために使用されるあらゆる X ユーザー ID が含まれます。

**2.15** 「**X Network**」とは、X が、現在知られている、または今後開発されるいかなる媒体においても広告を配信し得る、あらゆる形態のメディア、アプリケーションおよびデバイスを含む、広告チャネルのネットワークを意味します。

**2.17** 「**X Service**」とは、次のものを意味します。(i) X によって運営されるリアルタイムのコンテンツおよび情報サービス、(ii) そのようなサービスを可能にする技術およびシステムであって、これには、X によって現在提供されている消費者向けおよび広告向けプロダクトおよびサービス、および X が所有、運営および／または管理するウェブサイト、モバイルアプリケーション、ソーシャルプラグインおよび API を含み、さらに、制限なく、Measurement Code、あらゆる HTML タグまたはその他のコード、インターネットポータル、ダッシュボード、システムおよび分析ツールならびに関連サービスが含まれ、さらに (iii) X およびその Affiliates によって提供されるその他一切のプロダクトまたはサービス（制限なく、例示のみを目的として、X Audience Platform および Data &amp; Enterprise Solutions を含む）を意味します。
