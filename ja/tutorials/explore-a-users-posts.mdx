<div id="introduction">
  ## はじめに
</div>

[recent search endpoint](/ja/x-api/posts/search/introduction) では直近 7 日間に公開された投稿のみを取得できますが、user Post timeline エンドポイントと user mention timeline エンドポイントを使用すると、認可されたユーザー（user ID を使用）について、過去 7 日より前の投稿やメンションも取得できます。開発者は、これらのエンドポイントを使用して、ユーザーのタイムラインやメンション内の投稿のトピック、エンティティ、感情を分析できます。このチュートリアルでは、user Tweet timeline エンドポイントと user mention timeline エンドポイントを使用して、ユーザーの投稿とメンションを探索する方法を説明します。
 

<div id="prerequisites">
  ## 前提条件
</div>

* ユーザーのツイートタイムラインエンドポイントおよびユーザーのメンションタイムラインエンドポイントを利用するには、有効な開発者アカウントが必要です。
* 作成済みの [Project](/ja/resources/fundamentals/developer-apps) も必要です。
* [開発者アカウントに登録](https://developer.x.com/en/portal/petition/essential/basic-info)し、[新しい Developer Console エクスペリエンス](https://developer.x.com/en/portal/opt-in.html) を有効化している必要があります。
* [Developer Console](/ja/resources/fundamentals/developer-portal) 内で作成された [Project](/ja/resources/fundamentals/developer-apps) に紐づく開発者用 App の有効なキーとトークンがあればアクセスできます。
* [X Developer Console](/ja/resources/fundamentals/developer-portal) 内の自分の App から取得した Bearer Token が必要です。
* 承認済みの開発者アカウントをお持ちでない場合は、[アクセスを申請](https://developer.x.com/en/apply-for-access)できます。

<div id="approved-developer-account">
  ## 承認済みの開発者アカウント
</div>

まだお持ちでない場合は、[こちら](https://developer.x.com/en/apply-for-access)から申請してください。

<div id="create-a-project-and-connect-an-app">
  ## Project を作成して App を接続する
</div>

[Developer Console](https://developer.x.com/en/portal/dashboard) で「Create a new App」をクリックします。

<Frame>
  <img src="/images/projects.png.twimg.1920.png" />
</Frame>

App に名前を付け、該当するユースケースを選択し、Project の説明を入力します。次に、新しい App を作成するか、既存の [App](/ja/resources/fundamentals/developer-apps) を接続します（App は、X API への HTTP リクエストを行うために必要な API key を格納するコンテナです）。

<Frame>
  <img src="/images/add-your-app.png.twimg.1920.png" />
</Frame>

「Create a new App instead」をクリックし、新しい App を作成するために App の名前を入力します。

<Frame>
  <img src="/images/last-step-name-your-app.png.twimg.1920.png" />
</Frame>

「Complete」をクリックすると、X API v2 の新しいエンドポイントに接続するために使用できる API key と Bearer Token を取得できます。

<Frame>
  <img src="/images/here-are-your-keys.png.twimg.1920.png" />
</Frame>

API key、API secret key、Bearer Token の横にある (+) をクリックし、これらの値をローカル環境内の安全な場所にコピーします。次のステップで API リクエストを行う際に必要になります。

注: 上のスクリーンショット内のキーは非表示になっていますが、ご自身の Developer Console では、API key、API secret key、Bearer Token の実際の値を確認できます。
 

<div id="how-to-get-the-user-id-for-a-user-to-use-in-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## ユーザーのツイートタイムラインおよびユーザーのメンションタイムラインエンドポイントで使用するユーザーIDを取得する方法
</div>

ユーザーのツイートタイムラインおよびユーザーのメンションタイムラインエンドポイントを使用すると、ユーザーIDを使って投稿を取得できます。ユーザー名からユーザーIDを取得するには、新しい [user lookup endpoint v2](/ja/x-api/users/lookup/quickstart/user-lookup) を使用します。USER&#95;NAME を任意のユーザー名に置き換え、XXXX を上で取得した自身の Bearer Token に置き換えてください。

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

以下のように、レスポンス内にユーザーIDが返されます：

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```

<div id="connecting-to-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## ユーザーのツイートタイムラインおよびメンションタイムラインエンドポイントへの接続
</div>

特定ユーザーのツイートタイムラインを取得するには、ターミナルで次の curl コマンドを実行します（`USER&#95;ID` を取得対象のユーザーのユーザーIDに、`XXXX` を上で取得した自身の Bearer Token に置き換えてください）。

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```

これらのリクエストに対するJSONレスポンスには、デフォルトで投稿のidとテキストが含まれていることを確認できます（例を以下に示します）。

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 X API v2 が初めての方は、最初のリクエストを作成するためのステップバイステップガイドをご確認ください https://t.co/4rZqThpSbp"
}
```

レスポンスに追加のフィールド（ユーザー情報やコンテキスト注釈などの追加の Tweet フィールド）を含めたい場合は、それらのフィールドをレスポンスで返してもらうよう明示的に指定する必要があります。詳しくは、[fields と expansions の使い方に関するガイド](/ja/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)を参照してください。

任意のプログラミング言語を使用して、これらの投稿を取得することもできます。ユーザーのツイートタイムラインおよびユーザーのメンションタイムラインの各エンドポイント向けに用意している Python、Node（JavaScript）、Java、Ruby のサンプルコードを、[GitHub リポジトリ](https://github.com/xdevplatform/Twitter-API-v2-sample-code)で確認してください。

<div id="exploring-the-users-posts">
  ## ユーザーの投稿を探索する
</div>

ユーザーのツイートタイムラインエンドポイントとユーザーのメンションタイムラインエンドポイントを使って投稿を取得する方法を理解できたら、そこからその投稿を探索し始めることができます。たとえば、ユーザーのメンション内に共通して出現する固有表現を特定したい場合は、次のようにします。

API リクエストで、Tweet のレスポンスに `context_annotations` オブジェクトが返されるように指定します。

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

レスポンスで、メンションに名前付きエンティティが含まれているかどうかを確認できます。例を次に示します。

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "ブランドと企業"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

メンションにどの人気エンティティがよく登場しているかを確認したい場合は、メンション内の各ツイートを解析して、人気エンティティの出現回数をカウントすることができます。

タイムライン上のメディアを含むすべての投稿について、プレビュー画像の URL を調べたい場合は、次のようにします。

API リクエストで、`tweet.media` フィールドに `preview_image_url` を含めるよう指定し、さらに `attachments.media_keys` を値とする `expansions` パラメーターも指定します。

```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

レスポンス内の includes オブジェクトに、次のように preview&#95;image&#95;url が含まれていることが確認できます。

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```

ユーザーの投稿の閲覧方法を理解したら、他の API やサービスも組み合わせて、投稿をさらに活用できます。以下は、ユーザーのツイートタイムラインエンドポイントおよびユーザーのメンションタイムラインエンドポイントを利用する際に参照すると便利なリソースです。
