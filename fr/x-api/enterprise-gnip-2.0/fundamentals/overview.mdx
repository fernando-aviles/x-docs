<div id="overview">
  ## Vue d’ensemble
</div>

> La console entreprise (sur console.gnip.com) est disponible pour les clients de données entreprise disposant d’un accès contractuel aux API entreprise. Si vous n’êtes pas actuellement client de données entreprise mais souhaitez obtenir plus d’informations, vous pouvez en savoir plus sur les [données entreprise](https://developer.x.com/en/products/x-api/enterprise) ici.

Cette section présente le tableau de bord de la console entreprise de X. Les sections décrites correspondent à chaque zone spécifique de la console consacrée aux détails des produits, à l’utilisation et à la gestion générale du compte. Si vous avez des questions concernant votre compte, veuillez contacter votre responsable de compte attitré ou consulter notre [documentation technique pour les produits entreprise](/fr/x-api/enterprise-gnip-2.0/enterprise-gnip).

Dans le cadre de la phase d’essai entreprise et du processus d’intégration avec votre responsable de compte, les clients entreprise recevront des identifiants pour [console.gnip.com](http://console.gnip.com), l’interface utilisateur où l’accès aux produits entreprise peut être consulté et configuré. L’accès initial à la console pour l’administrateur client est configuré par X dans le cadre du processus d’intégration entreprise, puis les administrateurs peuvent ajouter des utilisateurs supplémentaires. La console entreprise vous permet de gérer vos produits entreprise et d’accéder à davantage de détails les concernant. 

La vidéo suivante présente une vue d’ensemble des différentes parties du tableau de bord console.gnip.com. 

**Avertissement : veuillez noter que certaines fonctionnalités présentées dans la vidéo, notamment certains enrichissements de flux et certains produits de sources de données non X, peuvent ne plus être disponibles.**

<div id="products-tab">
  ## Onglet Products
</div>

Après vous être connecté à votre compte sur [console.gnip.com](http://console.gnip.com), vous arrivez sur l’onglet Products du tableau de bord. Cette page présente une vue d’ensemble des produits Enterprise actuellement disponibles sur votre compte.

Pour les produits utilisant une diffusion en streaming comme PowerTrack ou Decahose, cette page répertorie le nom du produit, le libellé du flux, le nombre de connexions actuellement actives, le nombre de règles actuellement actives pour chacun (le cas échéant), ainsi que le nombre brut d’activités (par exemple, des Publications) livrées au cours des 24 dernières heures.

Pour les produits avec une livraison REST, comme Search API, cette page répertorie le nom du produit, les libellés (également affichés comme « streams »), les activités (par exemple, des Publications) renvoyées par ces endpoints, ainsi que plusieurs types de décomptes de requêtes par endpoint.

Notez que l’[Usage API](/fr/x-api/enterprise-gnip-2.0/fundamentals/usage) fournit une grande partie de ces données de manière programmatique.

Des détails spécifiques par flux sont disponibles en cliquant sur le nom ou sur le bouton des paramètres.

### Aperçu

Si vous cliquez sur l’un des flux dans le tableau de bord principal, vous accédez à une page d’aperçu de ce flux.

Pour les produits de diffusion en continu, cette page inclut les éléments suivants :

1. Un graphique de volume affichant le nombre d’activités qui vous sont livrées via chaque connexion de flux spécifique 

2. Des détails (ID de connexion et adresse IP) sur les connexions actuellement actives sur le flux 

3. Un journal des événements récents de connexion, de déconnexion et de mise à jour des règles pour votre flux

Notez que l’échelle du graphique peut être ajustée à l’aide des liens dans le coin supérieur droit. La visibilité des connexions et déconnexions individuelles peut être activée ou désactivée en cliquant sur l’élément correspondant dans la légende située directement sous le graphique.

<div id="connections">
  ### Connexions
</div>

La page Connexions fournit des détails sur les événements de connexion récents dans votre flux. Cela inclut les heures de début et de fin pour chaque connexion (en UTC sur 24 heures), la durée de chaque connexion, l’IP du serveur qui a établi la connexion, un id de connexion unique à des fins de référence, ainsi que l’état de la connexion en cours. L’état correspond à l’événement le plus récent pour la connexion spécifiée – c’est‑à‑dire « Client Connected » ou une déconnexion, avec le type de déconnexion précisé. Pour plus de détails sur le diagnostic des connexions, consultez le [guide sur les déconnexions](/fr/x-api/enterprise-gnip-2.0/powertrack-api#integrating-with-powertrack).

<div id="api-help">
  ### Aide relative à l’API
</div>

La page d’aide relative à l’API fournit les URL des endpoints de l’API pour votre flux, ainsi que, le cas échéant, l’endpoint Rules API associé au flux. Elle comprend également des exemples de commandes curl et des instructions expliquant comment se connecter à l’endpoint du flux, ainsi que comment ajouter, supprimer et répertorier par programmation des règles via l’endpoint Rules API de votre flux.

<div id="rules">
  ### Règles
</div>

L’onglet Règles est disponible pour les flux PowerTrack et offre un moyen rapide de démarrer en saisissant manuellement des règles en texte brut au moyen d’une interface utilisateur. Notez que cette interface prend uniquement en charge l’ajout de jusqu’à 1 000 règles via cette méthode manuelle et ne doit être utilisée que pour les tests initiaux. Nous vous recommandons de gérer vos règles par programmation via l’[API Rules](/fr/x-api/enterprise-gnip-2.0/powertrack-api#api-reference-index) dans tout environnement de production.

<div id="settings">
  ### Paramètres
</div>

L’onglet Paramètres vous permet de modifier le format de sortie des données dans votre flux, où plusieurs formats sont proposés. Pour changer le format, utilisez simplement les boutons radio indiquant les différentes options. La modification prendra effet lors de la reconnexion au flux. Notez que la mise à jour de ce paramètre sera appliquée immédiatement à la prochaine requête ou connexion et peut rendre votre analyseur incompatible avec le nouveau format. 

**Veuillez noter :** le paramètre recommandé pour obtenir le plus de données est « Laisser les données dans leur format d’origine », qui renverra les données dans le format natif enrichi décrit [ici](/fr/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#post-object).  Le format Activity Streams est décrit [ici](/fr/x-api/enterprise-gnip-2.0/fundamentals/data-dictionary#activity-object).

<div id="usage-tab">
  ## Onglet Usage
</div>

L’onglet Usage fournit une vue détaillée de l’utilisation de vos flux sur différentes périodes. Pour un accès programmatique aux informations d’utilisation, consultez l’[API Usage](/fr/x-api/enterprise-gnip-2.0/fundamentals/usage).

<div id="monthly">
  ### Monthly
</div>

La page Monthly Usage affiche l’utilisation de votre flux répartie par produit. Par exemple, les produits de couverture (comme PowerTrack, Historical PowerTrack et PowerTrack Replay) pour une source de données donnée seront regroupés afin de fournir à la fois des données distinctes et un décompte récapitulatif global. Les décomptes affichent le cumul depuis le début du mois en cours, une estimation de fin de mois (calculée à partir de l’utilisation du mois jusqu’à présent et du temps restant dans le mois), ainsi que les décomptes des deux mois précédents.

Il est important de noter que ces décomptes sont dédupliqués pour chaque produit et flux. Si vous avez reçu la même Publication via plusieurs connexions au même flux PowerTrack, cette Publication sera comptée une seule fois à ces fins. Les décomptes sont mis à jour toutes les 24 heures à 00 h 00 UTC.

<div id="daily">
  ### Quotidien
</div>

La page Daily Usage affiche, pour chaque jour du mois en cours, des nombres quotidiens dédupliqués, ventilés par produit. Les nombres sont mis à jour toutes les 24 heures à 00 h 00 UTC.

<div id="rules">
  ### Règles
</div>

Les limites de règles sont basées sur le forfait de règles PowerTrack défini dans votre contrat et s’appliquent à tous les flux d’un même type. Les décomptes sont mis à jour chaque fois qu’une nouvelle règle est ajoutée ou supprimée.

<div id="account-tab">
  ## Onglet « Compte »
</div>

<div id="my-profile">
  ### Mon profil
</div>

Consultez les détails de votre profil utilisateur et modifiez votre mot de passe ici. Vous pouvez également configurer des notifications de seuil d’utilisation spécifiques à votre compte. Les notifications d’état de l’API sont disponibles via la page d’état à l’adresse https://api.twitterstat.us.

<div id="account-settings">
  ### Paramètres du compte
</div>

Vous pouvez ajouter, supprimer et modifier des utilisateurs, et configurer les notifications par e‑mail pour chaque utilisateur ainsi que les alertes de seuil d’utilisation.

<Frame>
  <img src="/images/account-settings.png.twimg.1920.png" />
</Frame>

Veuillez noter qu’il existe trois types d’utilisateurs : Account Admin, User et Email Only.  

* Les administrateurs de compte sont autorisés à créer, supprimer et modifier d’autres utilisateurs et peuvent utiliser l’authentification de base avec un nom d’utilisateur (adresse e‑mail) et un mot de passe pour se connecter aux API Enterprise.

* Les utilisateurs ne peuvent pas créer ni modifier d’autres utilisateurs, mais peuvent utiliser l’authentification de base avec un nom d’utilisateur (adresse e‑mail) et un mot de passe pour se connecter aux API Enterprise.

* Les utilisateurs Email Only n’ont pas accès au tableau de bord, ne sont pas autorisés à se connecter aux API Enterprise et reçoivent uniquement des notifications s’ils sont configurés pour en recevoir dans la section Notifications.

<div id="usage-thresholds">
  ### Seuils d’utilisation
</div>

Configurez les seuils de volume pour vos produits. Ceux-ci déclencheront des alertes par e-mail pour les utilisateurs qui ont activé ces notifications dans leur profil, à la fois pour le seuil d’avertissement et le seuil critique de chaque produit.

<Frame>
  <img src="/images/usage-thresholds.png.twimg.1920.png" />
</Frame>

Veuillez noter que ces seuils sont évalués une fois par jour à 19 h 30 (UTC) et ne sont pas évalués en temps réel.
