<div id="overview">
  ## Présentation
</div>

Chaque jour, plusieurs milliers de développeurs envoient des requêtes vers l’API X. Pour gérer le très grand volume de ces requêtes, des limites sont imposées sur le nombre de requêtes pouvant être effectuées. Ces limites nous aident à fournir une API fiable et évolutive sur laquelle notre communauté de développeurs s’appuie. 

Le nombre maximal de requêtes autorisé est défini sur un intervalle de temps, une période ou une fenêtre temporelle donnée. Si un endpoint a une limite de 900 requêtes/15 minutes, jusqu’à 900 requêtes sont autorisées au cours de n’importe quelle fenêtre de 15 minutes.
