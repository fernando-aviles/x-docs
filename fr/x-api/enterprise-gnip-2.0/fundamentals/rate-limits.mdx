<div id="overview">
  ## Présentation
</div>

Chaque jour, plusieurs milliers de développeurs envoient des requêtes à la X API. Pour aider à gérer le volume important de ces requêtes, nous imposons des limites au nombre de requêtes pouvant être effectuées. Ces limites nous aident à fournir une API fiable et évolutive sur laquelle notre communauté de développeurs s’appuie. 

Le nombre maximal de requêtes autorisées est basé sur un intervalle de temps, une période ou fenêtre temporelle définie. Si un endpoint a une limite de débit de 900 requêtes/15 minutes, alors jusqu’à 900 requêtes peuvent être effectuées sur n’importe quelle fenêtre de 15 minutes.
