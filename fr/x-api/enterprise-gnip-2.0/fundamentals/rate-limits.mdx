<div id="overview">
  ## Vue d’ensemble
</div>

Chaque jour, plusieurs milliers de développeurs envoient des requêtes vers X API. Pour aider à gérer l’important volume de ces requêtes, des limites sont appliquées au nombre de requêtes pouvant être effectuées. Ces limites nous permettent de fournir une API fiable et évolutive sur laquelle notre communauté de développeurs s’appuie. 

Le nombre maximal de requêtes autorisées est défini sur un intervalle de temps, c’est‑à‑dire une période ou fenêtre temporelle donnée. Si un endpoint a une limite de débit de 900 requêtes/15 minutes, alors jusqu’à 900 requêtes peuvent être effectuées sur n’importe quel intervalle de 15 minutes.
