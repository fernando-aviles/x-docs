La fonctionnalité Expansions vous permet d&#39;inclure des objets associés dans une seule réponse d&#39;API. Au lieu d&#39;effectuer plusieurs requêtes, récupérez une Publication et son auteur, ses médias ou les Publications référencées en un seul appel.

***

<div id="how-expansions-work">
  ## Fonctionnement des expansions
</div>

Lorsque vous demandez une expansion, l’API inclut l’objet complet dans la section `includes` de la réponse :

```bash
curl "https://api.x.com/2/tweets/1234567890?expansions=author_id" \
  -H "Authorization: Bearer $TOKEN"
```

Réponse :

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "author_id": "2244994945"
  },
  "includes": {
    "users": [{
      "id": "2244994945",
      "name": "X Developers",
      "username": "xdevelopers"
    }]
  }
}
```

Le `author_id` dans `data` renvoie à l’objet utilisateur dans `includes`.

***

<div id="post-expansions">
  ## Expansions de publications
</div>

| Expansion | Renvoie | Cas d&#39;utilisation |
|:----------|:--------|:------------------|
| `author_id` | Objet utilisateur | Obtenir les détails de l&#39;auteur de la publication |
| `referenced_tweets.id` | Objet(s) Publication | Obtenir les publications citées ou celles auxquelles il est répondu |
| `referenced_tweets.id.author_id` | Objet(s) utilisateur | Obtenir les auteurs des publications référencées |
| `in_reply_to_user_id` | Objet utilisateur | Obtenir l&#39;utilisateur auquel on répond |
| `attachments.media_keys` | Objet(s) média | Obtenir les images, vidéos, GIF |
| `attachments.poll_ids` | Objet sondage | Obtenir les options et les votes du sondage |
| `geo.place_id` | Objet lieu | Obtenir les détails du lieu |
| `entities.mentions.username` | Objet(s) utilisateur | Obtenir les utilisateurs mentionnés |
| `edit_history_tweet_ids` | Objet(s) Publication | Obtenir les versions précédentes des publications modifiées |

<div id="combining-with-fields">
  ## Combiner avec les champs
</div>

Les Expansions renvoient les champs par défaut pour chaque objet. Pour obtenir des champs supplémentaires, combinez les Expansions avec des paramètres de champs :

```bash
curl "https://api.x.com/2/tweets/1234567890?\
expansions=author_id,attachments.media_keys&\
user.fields=description,public_metrics&\
media.fields=url,alt_text" \
  -H "Authorization: Bearer $TOKEN"
```

Réponse :

```json
{
  "data": {
    "id": "1234567890",
    "text": "Découvrez cette image !",
    "author_id": "2244994945",
    "attachments": {
      "media_keys": ["3_1234567890"]
    }
  },
  "includes": {
    "users": [{
      "id": "2244994945",
      "nom": "X Developers",
      "username": "xdevelopers",
      "description": "La voix de la plateforme de développement X",
      "public_metrics": {
        "followers_count": 570842
      }
    }],
    "media": [{
      "media_key": "3_1234567890",
      "type": "photo",
      "url": "https://pbs.twimg.com/media/example.jpg",
      "alt_text": "Image d'exemple"
    }]
  }
}
```

<div id="multiple-expansions">
  ## Plusieurs expansions
</div>

Demandez plusieurs expansions en les répertoriant dans une liste séparée par des virgules :

```bash
expansions=author_id,referenced_tweets.id,attachments.media_keys
```

<div id="common-patterns">
  ## Modèles courants
</div>

<Tabs>
  <Tab title="Contexte complet d’une publication">
    Obtenez une publication avec son auteur, ses médias et les publications référencées :

    ```bash
    expansions=author_id,attachments.media_keys,referenced_tweets.id
    tweet.fields=created_at,public_metrics,conversation_id
    user.fields=username,name,profile_image_url
    media.fields=url,preview_image_url,type
    ```
  </Tab>

  <Tab title="Fil de conversation">
    Obtenez les réponses avec leurs auteurs :

    ```bash
    expansions=author_id,in_reply_to_user_id,referenced_tweets.id
    tweet.fields=conversation_id,in_reply_to_user_id,created_at
    user.fields=username,name
    ```
  </Tab>

  <Tab title="Utilisateur avec publication épinglée">
    Obtenez le profil d’un utilisateur avec sa publication épinglée :

    ```bash
    expansions=pinned_tweet_id
    user.fields=description,public_metrics,verified
    tweet.fields=created_at,public_metrics
    ```
  </Tab>
</Tabs>

<div id="linking-data-and-includes">
  ## Mise en relation de data et includes
</div>

Les objets présents dans `includes` ne contiennent pas d&#39;informations de position. Reliez-les à l&#39;aide de leurs id :

```python
# Python example
response = api_call()
post = response["data"]
users = {u["id"]: u for u in response["includes"]["users"]}

# Récupérer l'auteur
author = users.get(post["author_id"])
print(f"{author['name']} said: {post['text']}")
```

```javascript
// Exemple JavaScript
const { data: post, includes } = response;
const users = Object.fromEntries(
  includes.users.map(u => [u.id, u])
);

const author = users[post.author_id];
console.log(`${author.name} said: ${post.text}`);
```
