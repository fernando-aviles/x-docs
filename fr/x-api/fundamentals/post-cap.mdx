X API v2 utilise une tarification **à l&#39;usage**. Vous êtes facturé en fonction de votre consommation réelle de l&#39;API, suivie au niveau de l&#39;App.

***

<div id="how-billing-works">
  ## Fonctionnement de la facturation
</div>

| Concept | Description |
|:--------|:------------|
| **Facturation basée sur des crédits** | Achetez des crédits à l’avance, qui sont débités à mesure que vous utilisez l’API |
| **Tarification à la requête** | Chaque endpoint a un coût différent |
| **Suivi en temps réel** | Surveillez l’utilisation dans la Console de développement |
| **Sans plafond** | Utilisez autant que nécessaire — aucune limite mensuelle |

<div id="deduplication">
  ## Déduplication
</div>

<Note>
  **Déduplication quotidienne** : si la même publication est renvoyée par plusieurs requêtes au cours d&#39;une journée, elle ne compte qu&#39;une seule fois pour la facturation.
</Note>

Cela signifie :

* Récupérer la même publication plusieurs fois en une journée = 1 opération facturée
* Récupérer une publication à nouveau le lendemain = 1 opération facturée supplémentaire
* Différentes publications dans la même requête = chacune est comptabilisée séparément

  ## Détails tarifaires
</div>

Pour connaître les tarifs actuels par endpoint et par opération, consultez la [Console de développement](https://console.x.com).

Les tarifs peuvent varier selon :

* le type d&#39;endpoint (search vs lookup vs stream)
* l&#39;opération (read vs write)
* le périmètre des données (recent vs full-archive)

<div id="faqs">
  ## FAQ
</div>

<Accordion title="Que se passe-t-il si j'ai épuisé mes crédits ?">
  Les requêtes API échoueront jusqu&#39;à ce que vous achetiez plus de crédits. Configurez des alertes de solde pour éviter toute interruption de service.
</Accordion>

<Accordion title="Y a-t-il des minimums mensuels ?">
  Non. Payez uniquement ce que vous utilisez. Vous pouvez avoir des mois sans aucune utilisation et donc sans aucun coût.
</Accordion>

<Accordion title="Comment le streaming est-il facturé ?">
  Chaque publication unique livrée via le flux filtré est comptabilisée dans votre utilisation, après déduplication quotidienne.
</Accordion>

<Accordion title="Les requêtes ayant échoué sont-elles comptabilisées ?">
  Non. Seules les réponses réussies renvoyant des données sont facturées.
</Accordion>
