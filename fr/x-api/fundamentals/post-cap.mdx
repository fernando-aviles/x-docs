X API v2 utilise une tarification **à l&#39;usage**. La facturation est basée sur la consommation effective de l&#39;API, suivie au niveau de l&#39;application.

***

<div id="how-billing-works">
  ## Fonctionnement de la facturation
</div>

| Concept | Description |
|:--------|:------------|
| **Basée sur des crédits** | Achetez des crédits à l’avance, débités à mesure que vous utilisez l’API |
| **Tarification par requête** | Chaque endpoint a un coût différent |
| **Suivi en temps réel** | Suivez votre utilisation dans la Developer Console |
| **Sans limite** | Utilisez autant que nécessaire, sans limite mensuelle |

<div id="deduplication">
  ## Déduplication
</div>

<Note>
  **Déduplication quotidienne** : si la même publication est renvoyée par plusieurs requêtes au cours d&#39;une même journée, elle ne compte qu&#39;une seule fois pour la facturation.
</Note>

Cela signifie :

* Récupérer la même publication plusieurs fois en une journée = 1 opération de facturation
* Récupérer à nouveau une publication le lendemain = 1 opération de facturation supplémentaire
* Des publications différentes dans la même requête = chacune est facturée séparément

<div id="pricing-details">
  ## Détails des tarifs
</div>

Pour connaître les tarifs actuels par endpoint et par opération, consultez le [Developer Console](https://console.x.com).

La tarification peut varier en fonction de :

* Type d’endpoint (recherche vs consultation vs flux)
* Opération (lecture vs écriture)
* Étendue des données (récentes vs archive complète)

<div id="faqs">
  ## FAQ
</div>

<Accordion title="Que se passe-t-il si je n’ai plus de crédits ?">
  Les requêtes API échoueront jusqu’à ce que vous achetiez plus de crédits. Configurez des alertes de solde pour éviter toute interruption.
</Accordion>

<Accordion title="Y a-t-il un minimum mensuel ?">
  Non. Payez uniquement ce que vous utilisez. Vous pouvez avoir des mois sans aucune utilisation et donc sans aucun coût.
</Accordion>

<Accordion title="Comment le streaming est-il facturé ?">
  Chaque Publication unique livrée via un flux filtré est comptabilisée dans votre consommation, après déduplication quotidienne.
</Accordion>

<Accordion title="Les requêtes ayant échoué sont-elles comptabilisées ?">
  Non. Seules les réponses réussies qui renvoient des données sont facturées.
</Accordion>
