L’X API fournit des métriques d’engagement pour les publications et les médias. Accédez aux métriques publiques avec n’importe quel type d’authentification, ou aux métriques privées pour votre propre contenu avec l’authentification utilisateur.

***

<div id="metric-types">
  ## Types de métriques
</div>

| Type | Authentification | Description |
|:-----|:---------------|:------------|
| **Publique** | Bearer Token | Visible par tous (mentions J&#39;aime, republications, réponses) |
| **Non publique** | Contexte utilisateur | Métriques privées (impressions, clics) |
| **Organique** | Contexte utilisateur | Métriques issues de vues non promotionnelles |
| **Promue** | Contexte utilisateur | Métriques issues de vues d&#39;annonces publicitaires |

<Note>
  **Limite de 30 jours** : les métriques non publiques, organiques et promues ne sont disponibles que pour les publications créées au cours des 30 derniers jours.
</Note>

***

<div id="available-metrics">
  ## Mesures disponibles
</div>

<div id="post-metrics">
  ### Métriques de Publication
</div>

| Métrique | Type | Chemin du champ |
|:-------|:-----|:-----------|
| Republications | Public | `public_metrics.retweet_count` |
| Citations | Public | `public_metrics.quote_count` |
| J&#39;aime | Public | `public_metrics.like_count` |
| Réponses | Public | `public_metrics.reply_count` |
| Impressions | Non public | `non_public_metrics.impression_count` |
| Clics sur l&#39;URL | Non public | `non_public_metrics.url_link_clicks` |
| Clics sur le profil | Non public | `non_public_metrics.user_profile_clicks` |

<div id="media-metrics-videos">
  ### Métriques des médias (vidéos)
</div>

| Métrique | Type | Chemin du champ |
|:-------|:-----|:-----------|
| Vues | Public | `public_metrics.view_count` |
| Lecture à 0 % | Non public | `non_public_metrics.playback_0_count` |
| Lecture à 25 % | Non public | `non_public_metrics.playback_25_count` |
| Lecture à 50 % | Non public | `non_public_metrics.playback_50_count` |
| Lecture à 75 % | Non public | `non_public_metrics.playback_75_count` |
| Lecture à 100 % | Non public | `non_public_metrics.playback_100_count` |

<div id="requesting-metrics">
  ## Récupérer des métriques
</div>

<div id="public-metrics-any-auth">
  ### Métriques publiques (quel que soit le mode d’authentification)
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

Réponse :

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "public_metrics": {
      "retweet_count": 50,
      "reply_count": 12,
      "like_count": 234,
      "quote_count": 5
    }
  }
}
```

<div id="private-metrics-user-context">
  ### Statistiques privées (contexte utilisateur)
</div>

Nécessite OAuth 1.0a ou OAuth 2.0 avec un contexte utilisateur pour les publications qui vous appartiennent :

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=non_public_metrics,organic_metrics" \
  -H "Authorization: OAuth oauth_consumer_key=...,oauth_token=..."
```

Réponse :

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "non_public_metrics": {
      "impression_count": 5432,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    },
    "organic_metrics": {
      "impression_count": 5432,
      "like_count": 234,
      "reply_count": 12,
      "retweet_count": 50,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    }
  }
}
```

<div id="video-metrics">
  ## Métriques vidéo
</div>

Pour les métriques de lecture vidéo, utilisez l&#39;expansion media :

```bash
curl "https://api.x.com/2/tweets/1234567890?\
tweet.fields=attachments&\
expansions=attachments.media_keys&\
media.fields=public_metrics,non_public_metrics" \
  -H "Authorization: OAuth ..."
```

Réponse :

```json
{
  "data": {
    "id": "1234567890",
    "text": "Check out this video!",
    "attachments": {
      "media_keys": ["13_9876543210"]
    }
  },
  "includes": {
    "media": [{
      "media_key": "13_9876543210",
      "type": "video",
      "public_metrics": {
        "view_count": 12543
      },
      "non_public_metrics": {
        "playback_0_count": 12543,
        "playback_25_count": 9876,
        "playback_50_count": 7654,
        "playback_75_count": 5432,
        "playback_100_count": 3210
      }
    }]
  }
}
```

<div id="organic-vs-promoted-metrics">
  ## Statistiques organiques vs promues
</div>

Si une publication a été promue en tant que publicité, les statistiques sont réparties entre les vues organiques et les vues promues :

| Contexte      | Description                                                |
| :------------ | :--------------------------------------------------------- |
| **Organique** | Statistiques issues des vues normales du fil d’actualité   |
| **Promue**    | Statistiques issues des impressions publicitaires payantes |
| **Publique**  | Total combiné (organique + promue)                         |

Demandez les deux pour voir la répartition :

```bash
tweet.fields=public_metrics,organic_metrics,promoted_metrics
```

<div id="metric-definitions">
  ## Définitions des métriques
</div>

<Accordion title="Impressions">
  Nombre de fois où la publication est apparue sur l’écran d’un utilisateur. Valeur non unique : si le même utilisateur la voit deux fois, cela compte pour deux impressions.
</Accordion>

<Accordion title="Nombre de republications">
  Nombre de republications (retweets). N’inclut pas les publications citées.
</Accordion>

<Accordion title="Nombre de citations">
  Nombre de publications citées (republications avec commentaire). Elles sont toujours organiques.
</Accordion>

<Accordion title="Vues de la vidéo">
  Agrégé sur toutes les publications contenant la vidéo. Une vidéo republicliée dans plusieurs publications a un seul nombre total de vues.
</Accordion>

<Accordion title="Quartiles de lecture">
  Nombre d’utilisateurs uniques ayant visionné la vidéo jusqu’à chaque pourcentage de progression. Utile pour comprendre les taux d’abandon.
</Accordion>

  ## Récapitulatif des exigences
</div>

| Champ de métriques | Authentification requise |
|:-------------|:-----------------------|
| `public_metrics` | Bearer Token (any) |
| `non_public_metrics` | Contexte utilisateur (publications de l’utilisateur uniquement) |
| `organic_metrics` | Contexte utilisateur (publications de l’utilisateur uniquement) |
| `promoted_metrics` | Contexte utilisateur (publications sponsorisées uniquement) |
