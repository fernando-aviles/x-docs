Les annotations fournissent des métadonnées sémantiques sur le contenu des publications. X analyse les publications pour identifier les entités (personnes, lieux, produits) et le contexte (thèmes, domaines) afin de vous aider à mieux comprendre et à filtrer le contenu.

---

<div id="annotation-types">
  ## Types d’annotation
</div>

<div id="entity-annotations">
  ### Annotations d'entités
</div>

La reconnaissance d'entités nommées (NER) identifie des mentions spécifiques dans le texte d’une Publication :

| Type | Exemples |
|:-----|:---------|
| **Person** | Barack Obama, Elon Musk |
| **Place** | San Francisco, Japan |
| **Product** | iPhone, ChatGPT |
| **Organization** | NASA, Google |
| **Other** | Super Bowl, Diabetes |

Les annotations d’entités comportent un score de confiance et une position dans le texte.

<div id="context-annotations">
  ### Annotations de contexte
</div>

Analyse sémantique permettant de classer les publications par sujet et par domaine :

- **Domaine** : Catégorie large (sport, divertissement, technologie)
- **Entité** : Sujet spécifique au sein du domaine (NBA, films Marvel, IA)

Les annotations de contexte aident à filtrer et à catégoriser les publications sans s’appuyer sur des mots-clés.

---

<div id="requesting-annotations">
  ## Demander des annotations
</div>

Ajoutez `context_annotations` et `entities` à vos `tweet.fields` :

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=context_annotations,entities" \
  -H "Authorization: Bearer $TOKEN"
```

***


<div id="response-structure">
  ## Structure de la réponse
</div>

```json
{
  "data": {
    "id": "1234567890",
    "text": "Just saw the new Marvel movie - it was amazing!",
    "entities": {
      "annotations": [
        {
          "start": 17,
          "end": 22,
          "probability": 0.9234,
          "type": "Organization",
          "normalized_text": "Marvel"
        }
      ]
    },
    "context_annotations": [
      {
        "domain": {
          "id": "86",
          "name": "Movie",
          "description": "Un film"
        },
        "entity": {
          "id": "1234567890",
          "name": "Marvel Cinematic Universe"
        }
      },
      {
        "domain": {
          "id": "65",
          "name": "Interests and Hobbies Vertical"
        },
        "entity": {
          "id": "781974596752842752",
          "name": "Entertainment"
        }
      }
    ]
  }
}
```

***


<div id="entity-annotation-fields">
  ## Champs d’annotation d’entité
</div>

| Champ | Description |
|:------|:------------|
| `start` | Position de début dans le texte |
| `end` | Position de fin dans le texte |
| `probability` | Score de confiance (0-1) |
| `type` | Type d’entité (personne, lieu, etc.) |
| `normalized_text` | Nom normalisé de l’entité |

<div id="using-annotations-in-filters">
  ## Utiliser les annotations dans les filtres
</div>

<div id="search-and-filtered-stream">
  ### Recherche et flux filtré
</div>

Filtrer les publications par ID d&#39;entité d&#39;annotation de contexte :

```bash
# Publications concernant une entité spécifique
context:86.1234567890

# Publications dans un domaine spécifique
context:86.*
```


<div id="practical-examples">
  ### Exemples pratiques
</div>

```bash
# Posts about the NBA
query=context:26.852137520

# Publications à propos des produits Apple
query=context:47.10026792024

# Posts about movies
query=context:86.*
```

---

<div id="important-notes">
  ## Notes importantes
</div>

<Warning>
**Toutes les publications ne sont pas annotées.** La couverture des annotations dépend de :
- La prise en charge de la langue
- La couverture des sujets dans la taxonomie de X
- La richesse sémantique du texte de la publication
</Warning>

- Les annotations ne sont pas rétroactives — elles ne sont appliquées que lorsque les entités sont suivies
- La même entité peut apparaître dans plusieurs domaines (par exemple, une célébrité est à la fois Person et Actor)
- Les id d'entité sont stables entre les domaines
