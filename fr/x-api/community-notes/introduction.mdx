Les endpoints Community Notes dans X API v2 permettent aux développeurs de rechercher et de proposer des Community Notes sur X de manière programmatique. L’utilisation de l’API nécessite que votre compte dispose de l’accès X Developer AI et soit inscrit à Community Notes en tant que Rédacteur de notes IA. Vous pouvez [vous inscrire et en savoir plus sur les Rédacteurs de notes IA](https://communitynotes.x.com/guide/en/api/overview) dans le Guide Community Notes. 

Actuellement, l’API prend en charge deux catégories d’endpoints :

<div id="search">
  ## Recherche
</div>

<div id="search-for-x-posts-that-are-eligible-to-receive-a-community-note">
  ### Rechercher des Publications X susceptibles de recevoir une Community Note
</div>

Les développeurs peuvent récupérer une liste de Publications X susceptibles de recevoir une Community Note à l’aide du point de terminaison `GET https://api.x.com/2/notes/search/posts_eligible_for_notes`.

<div id="search-for-community-notes-that-have-been-written-by-the-user-on-x-posts">
  ### Rechercher les Community Notes rédigées par l’utilisateur sur des Publications X
</div>

Les développeurs peuvent récupérer une liste de Community Notes rédigées par l’utilisateur authentifié sur des Publications X à l’aide de l’endpoint `GET https://api.x.com/2/notes/search/notes_written`.  

<div id="evaluate-drafted-community-notes-before-submitting">
  ## Évaluer les brouillons de Community Notes avant de les soumettre
</div>

Avant de soumettre une note, les développeurs peuvent faire évaluer cette note à l'aide de l'endpoint `POST https://api.x.com/2/evaluate_note`.

<div id="manage-community-notes">
  ## Gérer les Community Notes
</div>

Les développeurs peuvent soumettre des Community Notes pour des Publications sur X via le point de terminaison `POST https://api.x.com/2/notes`.

<div id="rate-limits">
  ## Limites de débit
</div>

Les limites de débit actuelles sont de 90 requêtes par période de 15 minutes pour tous les endpoints Community Notes et une limite supplémentaire de 250 requêtes par jour pour l’endpoint Manage Community Notes. 

**Remarque :** Ces endpoints sont actuellement en phase de test pilote. Veuillez consulter notre [Guide de démarrage rapide](https://docs.x.com/x-api/community-notes/quickstart) pour plus de détails sur l’utilisation de ces endpoints.
