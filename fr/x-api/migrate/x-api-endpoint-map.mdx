Vous remarquerez que plusieurs éléments sont encore signalés comme **[Coming Soon]**. Si vous voyez dans ce tableau un élément marqué comme **[Replacement Under Consideration]** ou **[No Replacement Planned]**, et que vous souhaitez que nous publiions une version v2 de cet endpoint, veuillez nous en informer via notre [forum communautaire](https://devcommunity.x.com/) ou votre responsable de compte Enterprise.
