Le tableau suivant met en correspondance les endpoints de X API v2 avec les endpoints standard v1.1 et Enterprise correspondants. Pour en savoir plus sur chacune de ces versions et de ces niveaux, veuillez consulter notre [guide de démarrage avec X API](/fr/x-api/getting-started/about-x-api).

Vous remarquerez que nous avons encore plusieurs éléments marqués **[À venir]**. Si vous voyez dans ce tableau un élément marqué **[Remplacement à l’étude]** ou **[Aucun remplacement prévu]**, et que vous souhaitez que nous publiions une version v2 de cet endpoint, veuillez nous en informer via notre [forum communautaire](https://devcommunity.x.com/) ou votre responsable de compte Enterprise.
