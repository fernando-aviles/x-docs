Un objet média représente une photo, une vidéo ou un GIF animé. Les objets média sont utilisés par de nombreux points de terminaison de X API et peuvent être inclus dans les Publications, les Messages privés, les profils d’utilisateurs, les créations publicitaires, entre autres. Chaque objet média peut avoir plusieurs variantes d’affichage ou de lecture, avec différentes résolutions ou différents formats.

<div id="media-types-size-restrictions">
  ## Types de média et restrictions de taille
</div>

Restrictions de taille pour l’envoi via l’API

* **Image** : `5 MB`
* **GIF** : `15 MB`
* **Vidéo** : `512 MB` (lorsque vous utilisez `media_category=amplify_video`)

<div id="creation">
  ## Création
</div>

Des objets tels que les publications, les Messages privés, les photos de profil utilisateur, les cartes Ads hébergées, etc. peuvent contenir un ou plusieurs objets média. Ces objets de premier niveau sont collectivement appelés entités. L’API de création d’entité concernée (par exemple [`POST /2/tweets`](/fr/x-api/posts/creation-of-a-post)) peut recevoir un ou plusieurs objets média à l’aide d’un `media_id` unique.

Une entité qui contient un ou plusieurs objets média peut être créée en suivant les étapes ci-dessous :

1. Téléversez le ou les fichiers média en utilisant soit la méthode recommandée de téléversement [fractionné](/fr/x-api-/media/quickstart/media-upload-chunked) (images/GIF/vidéo), soit l’ancienne méthode de téléversement [simple](/fr/x-api/media-upload/media-upload) (images uniquement).
2. Recevez un `media_id` à l’issue de l’étape 1. Cette étape peut être répétée plusieurs fois avec différents médias si l’entité autorise la transmission de plusieurs paramètres `media_id`.
3. Créez l’entité en appelant l’endpoint approprié, en incluant le `media_id` et les autres paramètres obligatoires. Par exemple, joignez un `media_id` à une Publication à l’aide de l’endpoint [`POST /2/tweets`](/fr/x-api/posts/creation-of-a-post).
