<div id="key-features">
  ## Fonctionnalités clés
</div>

<Tabs>
  <Tab title="Accès aux données">
    ### Objets de données riches

    Accédez à des données détaillées et structurées pour les publications, les utilisateurs, les médias et plus encore :

    * **Publications** : texte complet, métriques, entités, annotations, fils de conversation
    * **Utilisateurs** : profils, nombre d’abonnés, statut de vérification du compte
    * **Médias** : images, vidéos, GIFs avec métadonnées
    * **Sondages** : options et nombre de votes

    Personnalisez les réponses avec les [fields](/fr/x-api/fundamentals/fields) et les [expansions](/fr/x-api/fundamentals/expansions) pour obtenir exactement les données dont vous avez besoin.
  </Tab>

  <Tab title="Diffusion en temps réel">
    ### Flux filtré

    Recevez les publications en temps réel, au moment où elles sont publiées. Définissez jusqu’à 1 000 règles de filtrage pour ne recevoir que les publications correspondantes.

    ```bash
    # Ajouter une règle
    curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{"add": [{"value": "from:xdevelopers"}]}'

    # Se connecter au flux
    curl "https://api.x.com/2/tweets/search/stream" \
      -H "Authorization: Bearer $TOKEN"
    ```

    [En savoir plus sur le flux filtré →](/fr/x-api/posts/filtered-stream/introduction)
  </Tab>

  <Tab title="Recherche et analyses">
    ### Recherche sur l’ensemble des archives

    Recherchez dans l’intégralité de l’historique des publications publiques — depuis 2006. Créez des requêtes avec des opérateurs pour les utilisateurs, mots-clés, dates, et plus encore.

    ```bash
    curl "https://api.x.com/2/tweets/search/all?query=AI%20lang:en" \
      -H "Authorization: Bearer $TOKEN"
    ```

    ### Métriques

    Accédez aux métriques d’engagement, notamment les impressions, mentions « J’aime », republications, réponses et vues vidéo.

    [En savoir plus sur la recherche →](/fr/x-api/posts/search/introduction)
  </Tab>
</Tabs>

<div id="quick-start">
  ## Démarrage rapide
</div>

<Steps>
  <Step title="Créer un compte développeur">
    Inscrivez-vous sur [console.x.com](https://console.x.com) et créez une App.
  </Step>

  <Step title="Obtenir vos identifiants">
    Générez votre Jeton Bearer pour les requêtes en mode app-only.
  </Step>

  <Step title="Envoyer une requête">
    Essayez de rechercher un utilisateur :

    ```bash
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>
</Steps>
