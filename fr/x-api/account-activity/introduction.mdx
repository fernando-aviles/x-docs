L’API Account Activity transmet en temps réel les événements d’activité de compte à votre webhook. Abonnez-vous à des comptes d’utilisateurs et recevez des notifications lorsqu’ils publient, reçoivent des Messages privés, sont suivis, et plus encore.

<div id="how-it-works">
  ## Comment ça fonctionne
</div>

1. **Enregistrer le webhook** — Enregistrez l’URL de votre webhook
2. **Abonner des utilisateurs** — Ajoutez des abonnements utilisateur
3. **Recevoir des événements** — Recevez les événements d’activité via des requêtes POST
4. **Traiter les événements** — Traitez les événements dans votre application

***

<div id="event-types">
  ## Types d’événements
</div>

| Catégorie | Événements |
|:---------|:-------|
| **Publications** | Créer, supprimer, ajouter aux favoris, retirer des favoris |
| **Messages privés** | Reçu, envoyé, indicateur de saisie |
| **Abonnements** | S’abonner, se désabonner |
| **Blocages** | Bloquer, débloquer |
| **Mises en sourdine** | Mettre en sourdine, annuler la mise en sourdine |

***

<div id="webhook-security">
  ## Sécurité des webhooks
</div>

Toutes les requêtes de webhook incluent :

* **Validation CRC** — Vérifier l’authenticité du webhook
* **En-tête de signature** — `x-twitter-webhooks-signature`
* **HTTPS obligatoire** — Toutes les URL de webhook doivent utiliser HTTPS

***

<div id="example-register-a-webhook">
  ## Exemple : Enregistrer un webhook
</div>

```bash
curl -X POST "https://api.x.com/1.1/account_activity/all/env-name/webhooks.json?\
url=https%3A%2F%2Fyour-server.com%2Fwebhook" \
  -H "Authorization: OAuth oauth_consumer_key=..."
```
