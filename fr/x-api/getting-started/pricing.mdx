<div id="deduplication">
  ## Déduplication
</div>

Toutes les ressources sont dédupliquées dans une **fenêtre de 24 heures correspondant à une journée en UTC**. Si vous effectuez une requête pour une ressource (comme une Publication) et qu’elle vous est facturée, effectuer à nouveau une requête pour la même ressource dans cette fenêtre n’entraînera pas de frais supplémentaires.

Cela signifie :

* Effectuer plusieurs requêtes pour la même Publication dans une journée ne génère qu’une seule facturation
* La fenêtre de déduplication est réinitialisée à minuit (UTC)
* Cela s’applique à toutes les ressources facturables (Publications, utilisateurs, etc.)

<Note>
  La déduplication est une **garantie souple**. Bien qu’elle s’applique dans la grande majorité des cas, il peut exister des cas limites spécifiques, comme des interruptions de service, qui entraînent l’absence de déduplication de certaines ressources.
</Note>

<div id="credit-balance">
  ## Solde de crédits
</div>

Votre solde de crédits est affiché dans la Console de développement. Des crédits sont déduits en temps réel à mesure que vous effectuez des requêtes API.

<Warning>
  Surveillez régulièrement votre solde de crédits pour éviter toute interruption de service. Ajoutez des crédits avant que votre solde n’atteigne zéro afin de garantir un accès ininterrompu à l’API.

  ***Remarque :** Il est possible que le solde de crédits d’un compte devienne légèrement négatif. Dans ce cas, les requêtes API seront bloquées jusqu’à ce que vous ajoutiez suffisamment de crédits pour couvrir le solde négatif.*
</Warning>

<div id="auto-recharge">
  ### Recharge automatique
</div>

Activez la recharge automatique pour recharger automatiquement votre solde de crédit et éviter les interruptions de service. Configurez cette fonctionnalité dans la Console de développement :

| Paramètre | Description |
|:--------|:------------|
| **Montant de la recharge** | Le montant à ajouter lorsque la recharge automatique est déclenchée (par exemple, 25 $) |
| **Seuil de déclenchement** | La recharge automatique s’active lorsque votre solde tombe en dessous de ce montant (par exemple, 5 $) |

<Note>
  La recharge automatique nécessite un moyen de paiement enregistré défini comme moyen de paiement par défaut. Vous pouvez la désactiver à tout moment dans la Console de développement ou en contactant l’assistance.
</Note>

***

<div id="spending-limits">
  ### Plafonds de dépenses
</div>

Définissez un montant maximal que vous pouvez dépenser par cycle de facturation pour maîtriser vos coûts. Une fois ce plafond atteint, les requêtes à l’API seront bloquées jusqu’au cycle de facturation suivant.

| Option | Description |
|:-------|:------------|
| **Spending limit** | Définissez un montant spécifique en dollars comme plafond de dépenses par cycle de facturation |

<Tip>
  Utilisez les plafonds de dépenses pour éviter les frais inattendus, en particulier pendant le développement et les tests.
</Tip>

<div id="monitoring-usage">
  ## Surveiller l&#39;utilisation
</div>

Suivez de manière programmatique l&#39;utilisation de l&#39;API à l&#39;aide de l&#39;[endpoint Usage](/fr/x-api/usage/introduction) :

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

Cela renvoie des décomptes quotidiens de consommation de Publications pour vous aider à :

* Suivre votre consommation par rapport à votre budget
* Configurer des alertes lorsque vous approchez des limites
* Identifier les points de terminaison à forte consommation
* Générer des rapports d’utilisation
