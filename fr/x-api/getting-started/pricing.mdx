<div id="deduplication">
  ## Déduplication
</div>

Toutes les ressources sont dédupliquées sur une **fenêtre de 24 heures correspondant à une journée en UTC**. Si vous effectuez une requête pour une ressource (comme une Publication) et qu’elle vous est facturée, effectuer une nouvelle requête pour cette même ressource dans cette fenêtre n’entraînera pas de frais supplémentaires.

Cela signifie :

* Effectuer plusieurs requêtes pour la même Publication au cours d’une journée ne compte que pour une seule facturation
* La fenêtre de déduplication est réinitialisée à minuit (UTC)
* Cela s’applique à toutes les ressources facturables (Publications, utilisateurs, etc.)

<Note>
  La déduplication est une **garantie non stricte**. Bien qu’elle s’applique dans la grande majorité des cas, certains cas limites, comme des interruptions de service, peuvent empêcher la déduplication de certaines ressources.
</Note>

<div id="credit-balance">
  ## Solde de crédits
</div>

Votre solde de crédits est affiché dans la Developer Console. Des crédits sont déduits en temps réel à mesure que vous effectuez des requêtes à l’API.

<Warning>
  Surveillez régulièrement votre solde de crédits pour éviter toute interruption de service. Ajoutez des crédits avant que votre solde n’atteigne zéro afin de garantir un accès ininterrompu à l’API.

  ***Remarque :** Il est possible que le solde de crédits d’un compte devienne légèrement négatif. Dans ce cas, les requêtes à l’API seront bloquées jusqu’à ce que vous ajoutiez suffisamment de crédits pour couvrir le solde négatif.*
</Warning>

<div id="auto-recharge">
  ### Recharge automatique
</div>

Activez la recharge automatique pour réapprovisionner votre solde de crédits et éviter les interruptions de service. Configurez cette option dans le Developer Console :

| Paramètre | Description |
|:--------|:------------|
| **Montant de la recharge** | Montant ajouté lorsque la recharge automatique se déclenche (par exemple, 25 $) |
| **Seuil de déclenchement** | La recharge automatique s’active lorsque votre solde passe en dessous de ce montant (par exemple, 5 $) |

<Note>
  La recharge automatique nécessite un mode de paiement enregistré et défini comme mode de paiement par défaut. Vous pouvez l’annuler à tout moment dans le Developer Console ou en contactant l’assistance.
</Note>

***

<div id="spending-limits">
  ### Plafonds de dépenses
</div>

Définissez un montant maximal que vous pouvez dépenser par cycle de facturation pour contrôler les coûts. Une fois ce plafond atteint, les requêtes vers l&#39;API seront bloquées jusqu&#39;au prochain cycle de facturation.

| Option | Description |
|:-------|:------------|
| **Spending limit** | Définissez un montant en dollars précis comme dépense maximale par cycle de facturation |

<Tip>
  Utilisez les plafonds de dépenses pour éviter les frais inattendus, en particulier pendant le développement et les tests.
</Tip>

<div id="monitoring-usage">
  ## Suivi de l’utilisation
</div>

Suivez l’utilisation de l’API de manière programmatique avec l’[endpoint Usage](/fr/x-api/usage/introduction) :

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

Cela renvoie les volumes quotidiens de consommation de Publications, ce qui vous permet de :

* Suivre la consommation par rapport à votre budget
* Configurer des alertes à l&#39;approche de vos limites
* Identifier les points de terminaison à forte consommation
* Générer des rapports d&#39;utilisation
