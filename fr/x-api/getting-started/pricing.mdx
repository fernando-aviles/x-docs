<div id="deduplication">
  ## Déduplication
</div>

Toutes les ressources sont dédupliquées sur une **fenêtre de 24 heures correspondant à une journée UTC**. Si vous effectuez une requête pour une ressource (comme une Publication) et êtes facturé pour celle-ci, effectuer à nouveau une requête pour la même ressource dans cette fenêtre n’entraînera pas de frais supplémentaires.

Cela signifie :

* Effectuer plusieurs requêtes pour la même Publication dans une journée compte comme une seule facturation
* La fenêtre de déduplication est réinitialisée à minuit (UTC)
* Cela s’applique à toutes les ressources facturables (Publications, utilisateurs, etc.)

<Note>
  La déduplication est une **garantie non stricte**. Bien qu’elle soit assurée dans la grande majorité des cas, il peut exister des cas limites spécifiques, comme des pannes de service, qui font que certaines ressources ne sont pas dédupliquées.
</Note>

<div id="credit-balance">
  ## Solde de crédits
</div>

Votre solde de crédits est affiché dans la Console de Développement. Des crédits sont déduits en temps réel à mesure que vous effectuez des requêtes à l’API.

<Warning>
  Surveillez régulièrement votre solde de crédits afin d’éviter toute interruption de service. Ajoutez des crédits avant que votre solde n’atteigne zéro pour garantir un accès ininterrompu à l’API.

  ***Remarque :** il est possible que le solde de crédits d’un compte devienne légèrement négatif. Dans ce cas, les requêtes à l’API seront bloquées jusqu’à ce que vous ajoutiez des crédits pour couvrir le solde négatif.*
</Warning>

<div id="auto-recharge">
  ### Recharge automatique
</div>

Activez la recharge automatique pour reconstituer automatiquement votre solde de crédits et éviter les interruptions de service. Configurez cette option dans la Console de Développement :

| Paramètre | Description |
|:----------|:------------|
| **Montant de recharge** | Montant à ajouter lorsque la recharge automatique se déclenche (par exemple, 25 $) |
| **Seuil de déclenchement** | La recharge automatique s’active lorsque votre solde passe en dessous de ce montant (par exemple, 5 $) |

<Note>
  La recharge automatique nécessite un mode de paiement enregistré défini comme mode de paiement par défaut. Vous pouvez l’annuler à tout moment dans la Console de Développement ou en contactant le support.
</Note>

<div id="spending-limits">
  ### Plafonds de dépenses
</div>

Définissez un montant maximal que vous pouvez dépenser par cycle de facturation pour maîtriser vos coûts. Une fois que ce plafond est atteint, les requêtes API seront bloquées jusqu&#39;au prochain cycle de facturation.

| Option | Description |
|:-------|:------------|
| **Plafond de dépenses** | Définissez un montant spécifique en dollars comme dépense maximale par cycle de facturation |

<Tip>
  Utilisez les plafonds de dépenses pour éviter les frais inattendus, en particulier pendant le développement et les tests.
</Tip>

<div id="monitoring-usage">
  ## Surveiller l’utilisation
</div>

Suivez l’utilisation de votre API de manière programmatique avec l’endpoint [Usage](/fr/x-api/usage/introduction) :

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

Cela renvoie les décomptes quotidiens de consommation de Publications, ce qui vous aide à :

* Suivre la consommation par rapport à votre budget
* Configurer des alertes à l’approche des limites
* Identifier les points de terminaison à forte consommation
* Générer des rapports d’utilisation
