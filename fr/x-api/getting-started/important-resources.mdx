<div id="quick-reference">
  ## Référence rapide
</div>

<div id="response-structure">
  ### Structure de la réponse
</div>

Toutes les réponses v2 respectent cette structure :

```json
{
  "data": { ... },      // Objet(s) principal(aux)
  "includes": { ... },  // Objets développés (si demandés)
  "meta": { ... },      // Informations de pagination
  "errors": [ ... ]     // Erreurs partielles (le cas échéant)
}
```

<div id="common-parameters">
  ### Paramètres courants
</div>

| Paramètre | Utilisation |
|:----------|:----|
| `tweet.fields` | Demander des champs spécifiques de publication |
| `user.fields` | Demander des champs spécifiques de l’utilisateur |
| `expansions` | Inclure les objets associés |
| `max_results` | Limiter le nombre de résultats par page |
| `pagination_token` | Récupérer la page suivante/précédente |

<div id="authentication-methods">
  ### Méthodes d’authentification
</div>

| Méthode | Cas d’utilisation |
|:-------|:------------------|
| Bearer Token | Données publiques en lecture seule |
| OAuth 2.0 | Actions utilisateur avec des autorisations fines |
| OAuth 1.0a | Actions utilisateur (ancien protocole, permissions complètes) |

[Guide complet sur l’authentification →](/fr/resources/fundamentals/authentication/overview)
