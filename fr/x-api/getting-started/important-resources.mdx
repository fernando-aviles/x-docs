<div id="quick-reference">
  ## Référence rapide
</div>

<div id="response-structure">
  ### Structure de la réponse
</div>

Toutes les réponses de l’API v2 suivent cette structure :

```json
{
  "data": { ... },      // Objet(s) principal(aux)
  "includes": { ... },  // Objets étendus (si demandés)
  "meta": { ... },      // Informations de pagination
  "errors": [ ... ]     // Erreurs partielles (le cas échéant)
}
```

<div id="common-parameters">
  ### Paramètres courants
</div>

| Paramètre | Utilisation |
|:----------|:----|
| `tweet.fields` | Récupérer des champs de publication spécifiques |
| `user.fields` | Récupérer des champs d’utilisateur spécifiques |
| `expansions` | Inclure des objets associés |
| `max_results` | Limiter les résultats par page |
| `pagination_token` | Récupérer la page suivante ou précédente |

<div id="authentication-methods">
  ### Méthodes d’authentification
</div>

| Méthode | Cas d’usage |
|:-------|:------------|
| Jeton Bearer | Données publiques en lecture seule |
| OAuth 2.0 | Actions utilisateur avec des périmètres d’autorisation granulaires |
| OAuth 1.0a | Actions utilisateur (héritée, permissions complètes) |
