Ce guide vous accompagne pour effectuer votre première requête vers l&#39;X API. Vous aurez besoin d&#39;un [compte développeur avec des identifiants d&#39;App](/fr/x-api/getting-started/getting-access) avant de commencer.

***

<div id="quick-start-with-curl">
  ## Démarrage rapide avec cURL
</div>

Le moyen le plus rapide de tester l&#39;API est d&#39;utiliser cURL. Recherchons un utilisateur :

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

Remplacez `$BEARER_TOKEN` par votre jeton Bearer réel. Vous recevrez une réponse de ce type :

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers"
  }
}
```

***

<div id="step-by-step-guide">
  ## Guide étape par étape
</div>

<Steps>
  <Step title="Récupérer votre Jeton Bearer">
    Dans la [Console de développement](https://console.x.com), accédez à votre App et copiez le Jeton Bearer.
  </Step>

  <Step title="Choisir un endpoint">
    Commencez avec l’un de ces endpoints simples pour débuter :

    | Endpoint | Ce qu’il fait |
    |:---------|:-------------|
    | [User lookup](/fr/x-api/users/lookup/introduction) | Récupérer un profil utilisateur par nom d’utilisateur ou id |
    | [Post lookup](/fr/x-api/posts/lookup/introduction) | Récupérer une Publication par id |
    | [Recent search](/fr/x-api/posts/search/introduction) | Rechercher des Publications des 7 derniers jours |
  </Step>

  <Step title="Effectuer la requête">
    Utilisez cURL, Postman ou votre client HTTP préféré :

    ```bash
    # Rechercher un utilisateur par nom d’utilisateur
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>

  <Step title="Analyser la réponse">
    Les réponses sont au format JSON. Les données principales se trouvent dans le champ `data` :

    ```json
    {
      "data": {
        "id": "2244994945",
        "name": "X Developers",
        "username": "xdevelopers"
      }
    }
    ```
  </Step>
</Steps>

***

<div id="request-more-data-with-fields">
  ## Obtenir plus de données avec les champs
</div>

Par défaut, les endpoints renvoient un ensemble minimal de champs. Utilisez le paramètre de requête `fields` pour récupérer des données supplémentaires :

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers?user.fields=created_at,description,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

Réponse :

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "La voix de la plateforme X Developer",
    "public_metrics": {
      "followers_count": 570842,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```

[En savoir plus sur les champs →](/fr/x-api/fundamentals/fields)

<div id="using-code-instead-of-curl">
  ## Utiliser du code plutôt que cURL
</div>

<Tabs>
  <Tab title="Python">
    ```python
    import requests

    bearer_token = "YOUR_BEARER_TOKEN"
    url = "https://api.x.com/2/users/by/username/xdevelopers"

    headers = {"Authorization": f"Bearer {bearer_token}"}
    response = requests.get(url, headers=headers)

    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    ```javascript
    const bearerToken = "YOUR_BEARER_TOKEN";
    const url = "https://api.x.com/2/users/by/username/xdevelopers";

    fetch(url, {
      headers: { Authorization: `Bearer ${bearerToken}` }
    })
      .then(res => res.json())
      .then(data => console.log(data));
    ```
  </Tab>

  <Tab title="SDK officiels">
    Pour un usage en production, nous recommandons d’utiliser les SDK officiels :

    * [SDK Python](/fr/xdks/python/overview)
    * [SDK TypeScript](/fr/xdks/typescript/overview)

    Ils gèrent automatiquement l’authentification, la pagination et la limitation de débit.
  </Tab>
</Tabs>

<div id="troubleshooting">
  ## Dépannage
</div>

<Accordion title="401 Non autorisé">
  * Vérifiez que votre Jeton Bearer est correct
  * Assurez-vous que le jeton n&#39;a pas été régénéré
  * Vérifiez le format de l&#39;en-tête `Authorization` : `Bearer YOUR_TOKEN`
</Accordion>

<Accordion title="403 Interdit">
  * Votre app n’a peut-être pas accès à ce point de terminaison
  * Certains points de terminaison nécessitent une authentification en contexte utilisateur (OAuth 1.0a ou 2.0)
  * Vérifiez les autorisations de votre app dans la Console de développement
</Accordion>

<Accordion title="429 Trop de requêtes">
  * Vous avez atteint une limite de taux de requêtes
  * Vérifiez l&#39;en-tête `x-rate-limit-reset` pour savoir quand réessayer
  * Mettez en place une stratégie de backoff exponentiel dans votre code
</Accordion>
