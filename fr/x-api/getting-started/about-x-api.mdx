X API offre un accès programmatique à la conversation publique sur X. Récupérez des publications, analysez les tendances, créez des intégrations et concevez de nouvelles expériences sur la plateforme.

***

<div id="what-you-can-do">
  ## Ce que vous pouvez faire
</div>

| Fonctionnalité | Description |
|:-----------|:------------|
| **Lire des publications** | Rechercher, consulter et diffuser des publications en temps réel |
| **Publier du contenu** | Créer des publications, des réponses et des fils de discussion |
| **Gérer les utilisateurs** | Rechercher des utilisateurs, gérer les abonnements, les blocages et les sourdines |
| **Analyser les données** | Accéder aux métriques, aux tendances et aux statistiques d’engagement |
| **Créer des intégrations** | Envoyer des DM, gérer les listes et interagir avec les Spaces |

***

<div id="api-versions">
  ## Versions de l’API
</div>

<Tabs>
  <Tab title="X API v2 (recommandée)">
    La version actuelle de la X API avec des fonctionnalités modernes et une tarification flexible.

    **Pourquoi utiliser v2 :**

    * Tarification à l’usage, sans plafonds mensuels
    * Format de réponse JSON moderne
    * [fields](/fr/x-api/fundamentals/fields) et [expansions](/fr/x-api/fundamentals/expansions) flexibles
    * Fonctionnalités avancées : annotations, suivi des conversations, historique des modifications
    * Tous les nouveaux points de terminaison et fonctionnalités

    **Pour commencer :**

    1. Inscrivez-vous sur [console.x.com](https://console.x.com)
    2. Créez une application et obtenez des identifiants
    3. [Effectuez votre première requête](/fr/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1 (héritée)">
    La version précédente de la X API. Prise en charge limitée ; utilisez v2 pour les nouveaux projets.

    **Toujours disponible :**

    * Certains points de terminaison de téléversement de médias
    * Streaming hérité (obsolète)
    * Certains points de terminaison spécialisés

    **Migrer vers v2 :**
    Consultez le [guide de migration](/fr/x-api/migrate/overview) pour la correspondance des points de terminaison et les modifications de format des données.
  </Tab>

  <Tab title="Enterprise">
    Accès à fort volume pour les entreprises avec des besoins avancés.

    **Fonctionnalités :**

    * Accès complet au firehose
    * Récupération de données historiques
    * Support dédié
    * Limites de débit personnalisées
    * Flux de conformité

    [Contacter l’équipe commerciale Enterprise →](/fr/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

<div id="v2-highlights">
  ## Points forts de la v2
</div>

<Accordion title="Champs et expansions">
  Demandez seulement les données dont vous avez besoin. Utilisez les paramètres `fields` pour sélectionner des attributs spécifiques et `expansions` pour inclure des objets associés.

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [En savoir plus sur les champs →](/fr/x-api/fundamentals/fields)
</Accordion>

<Accordion title="Annotations de publications">
  Les publications incluent des annotations sémantiques identifiant des personnes, des lieux, des produits et des sujets. Filtrez les flux et les recherches par sujet.

  [En savoir plus sur les annotations →](/fr/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="Mesures d'engagement">
  Accédez aux mesures publiques (mentions J’aime, republications, réponses) et aux mesures privées (impressions, clics) pour vos propres publications.

  [En savoir plus sur les mesures →](/fr/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="Suivi de conversation">
  Reconstituez des fils de conversation complets à l’aide de `conversation_id`. Suivez les réponses sur l’ensemble du fil.

  [En savoir plus sur le suivi de conversation →](/fr/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="Historique des modifications">
  Accédez à l’historique des modifications des publications, y compris toutes les versions précédentes et les métadonnées de modification.

  [En savoir plus sur la modification de publications →](/fr/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## Tarification
</div>

X API v2 utilise une tarification **à l&#39;usage** :

| Avantage | Description |
|:--------|:------------|
| **Aucun abonnement** | Payez uniquement ce que vous utilisez |
| **Aucune limite** | Utilisez autant que nécessaire |
| **Basée sur des crédits** | Achetez des crédits, débités à chaque requête |
| **Suivi en temps réel** | Surveillez votre utilisation dans la Developer Console |
| **Déduplication** | La même ressource demandée deux fois en 24 heures n&#39;est facturée qu&#39;une seule fois |

[Voir les détails de la tarification →](/fr/x-api/getting-started/pricing)
