L’endpoint de recherche de communautés vous permet de récupérer des informations sur les communautés X à partir de leur id.

<div id="overview">
  ## Vue d’ensemble
</div>

Les Communautés sont des groupes publics ou privés sur X où les membres peuvent partager des Publications, discuter de sujets et se retrouver autour d’intérêts communs.

***

<div id="endpoint">
  ## Point de terminaison
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/communities/:id`](/fr/x-api/communities/get-community-by-id) | Obtenir une communauté par identifiant |

***

<div id="response-fields">
  ## Champs de réponse
</div>

| Champ | Description |
|:------|:------------|
| `id` | ID de la communauté |
| `name` | Nom de la communauté |
| `description` | Description de la communauté |
| `created_at` | Date de création |
| `member_count` | Nombre de membres |
| `is_private` | Indique si la communauté est privée |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/communities/1234567890?\
community.fields=name,description,member_count,created_at" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
