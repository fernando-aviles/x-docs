Le point de terminaison Usage vous permet de surveiller votre utilisation de l’API, y compris le nombre de Publications consommées. Suivez votre utilisation par programmation pour gérer vos coûts et respecter les limites.

<div id="endpoint">
  ## Endpoint
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/usage/tweets`](/fr/x-api/usage/get-usage) | Récupérer les data d&#39;utilisation des publications |

***

<div id="response-data">
  ## Données de la réponse
</div>

La réponse contient le nombre quotidien de consultations des Publications :

```json
{
  "data": {
    "daily_project_usage": [
      {
        "date": "2024-01-15",
        "usage": [
          {
            "app_id": "12345678",
            "tweets_consumed": 15420
          }
        ]
      }
    ],
    "project_id": "1234567890",
    "project_cap": 10000000
  }
}
```

<div id="fields">
  ### Champs
</div>

| Champ | Description |
|:------|:------------|
| `daily_project_usage` | Tableau des données d&#39;utilisation quotidiennes |
| `date` | Date au format YYYY-MM-DD |
| `app_id` | ID de votre application |
| `tweets_consumed` | Publications consommées ce jour-là |
| `project_cap` | Votre limite mensuelle de publications |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="use-cases">
  ## Cas d’usage
</div>

* **Suivi des coûts** — Suivez la consommation par rapport aux limites de votre formule
* **Alertes** — Configurez des alertes lorsque vous approchez des limites
* **Optimisation** — Identifiez les endpoints les plus consommateurs
* **Rapports** — Générez des rapports d’utilisation

<Tip>
  Les ressources sont dédupliquées dans une fenêtre de 24 heures en UTC, ainsi demander plusieurs fois la même ressource dans une journée n’est facturé qu’une seule fois. [En savoir plus sur la tarification →](/fr/x-api/getting-started/pricing)
</Tip>
