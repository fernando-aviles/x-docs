Le endpoint Usage vous permet de surveiller votre utilisation de l’API, y compris le nombre de Publications consommées. Suivez votre utilisation de l’API par programmation afin de gérer vos coûts et de rester dans les limites prévues.

<div id="endpoint">
  ## Endpoint
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/usage/tweets`](/fr/x-api/usage/get-usage) | Récupérer les données d&#39;utilisation des publications |

***

<div id="response-data">
  ## Données de la réponse
</div>

La réponse inclut les décomptes quotidiens de consommation de Publications :

```json
{
  "data": {
    "daily_project_usage": [
      {
        "date": "2024-01-15",
        "usage": [
          {
            "app_id": "12345678",
            "tweets_consumed": 15420
          }
        ]
      }
    ],
    "project_id": "1234567890",
    "project_cap": 10000000
  }
}
```

<div id="fields">
  ### Champs
</div>

| Champ | Description |
|:------|:------------|
| `daily_project_usage` | Tableau des données d&#39;utilisation quotidiennes |
| `date` | Date au format AAAA-MM-JJ |
| `app_id` | L&#39;id de votre application |
| `tweets_consumed` | Publications consommées ce jour-là |
| `project_cap` | Votre limite mensuelle de publications |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="use-cases">
  ## Cas d’utilisation
</div>

* **Suivi des coûts** — Suivre la consommation par rapport aux limites de votre offre
* **Alertes** — Configurer des alertes à l’approche des limites
* **Optimisation** — Identifier les endpoints les plus consommateurs
* **Reporting** — Générer des rapports d’utilisation

<Tip>
  Les ressources sont dédupliquées sur une période de 24 heures en UTC, donc demander la même ressource plusieurs fois au cours d’une journée ne donne lieu qu’à une seule facturation. [En savoir plus sur la tarification →](/fr/x-api/getting-started/pricing)
</Tip>
