L’endpoint Usage vous permet de surveiller votre consommation de l’API, y compris le nombre de Publications consommées. Suivez votre consommation de façon programmatique afin de maîtriser les coûts et de rester dans les limites prévues.

<div id="endpoint">
  ## Endpoint
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/usage/tweets`](/fr/x-api/usage/get-usage) | Récupérer les données d&#39;utilisation des publications |

***

<div id="response-data">
  ## Données de la réponse
</div>

La réponse comprend les nombres quotidiens de consommation de Publications :

```json
{
  "data": {
    "daily_project_usage": [
      {
        "date": "2024-01-15",
        "usage": [
          {
            "app_id": "12345678",
            "tweets_consumed": 15420
          }
        ]
      }
    ],
    "project_id": "1234567890",
    "project_cap": 10000000
  }
}
```

<div id="fields">
  ### Champs
</div>

| Champ | Description |
|:------|:------------|
| `daily_project_usage` | Tableau des données d&#39;utilisation quotidiennes |
| `date` | Date au format YYYY-MM-DD |
| `app_id` | L&#39;id de votre App |
| `tweets_consumed` | Publications consommées ce jour-là |
| `project_cap` | Votre limite mensuelle de publications |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="use-cases">
  ## Cas d’usage
</div>

* **Suivi des coûts** — Surveillez la consommation par rapport aux limites de votre offre
* **Alertes** — Configurez des alertes à l’approche des limites
* **Optimisation** — Identifiez les endpoints à forte consommation
* **Génération de rapports** — Générez des rapports d’utilisation

<Tip>
  Les ressources sont dédupliquées sur une période de 24 heures (UTC) : ainsi, demander plusieurs fois la même ressource au cours d’une journée ne donne lieu qu’à une seule facturation. [En savoir plus sur la tarification →](/fr/x-api/getting-started/pricing)
</Tip>
