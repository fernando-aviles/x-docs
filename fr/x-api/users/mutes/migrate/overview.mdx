  ## Comparaison des endpoints de mise en sourdine de X API
</div>

<div id="mutes-lookup">
  #### Recherche des comptes mis en sourdine
</div>

Le point de terminaison de recherche des comptes mis en sourdine de la v2 remplacera les points de terminaison standards [v1.1 GET mutes/users/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-ids) et [GET mutes/users/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-list).

Le tableau suivant compare les points de terminaison de mise en sourdine standards v1.1 et ceux de X API v2 :
 

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | ******GET****** | ******GET****** |
| Domaine de l’hôte | ******https://api.x.com****** | ******https://api.x.com****** |
| Chemin du point de terminaison | ******/1.1/mutes/users/ids.json******<br /><br />/1.1/mutes/users/list.json | ******/2/users/:id/muting****** |
| [Authentification](/fr/resources/fundamentals/authentication) | Contexte utilisateur OAuth 1.0a | Contexte utilisateur OAuth 1.0a<br /><br />Code d’autorisation OAuth 2.0 avec PKCE |
| [Limites de taux](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 15 requêtes par 15 min (par utilisateur) | 15 requêtes par 15 min (par utilisateur) |
| Formats de données | Format standard v1.1 | [Format X API v2](/fr/x-api/fundamentals/data-dictionary) (déterminé par les paramètres de requête fields et expansions, non rétrocompatible avec les formats v1.1)<br /><br />Pour en savoir plus sur la migration du format standard v1.1 vers le format X API v2, veuillez consulter notre [guide de migration des formats de données](/fr/x-api/migrate/data-format-migration). |
| Nécessite l’utilisation d’identifiants provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) |     | ✔️  |

<div id="manage-mutes">
  #### Gérer les masquages
</div>

Les endpoints v2 de gestion des masquages remplaceront les endpoints standard v1.1 [POST mutes/users/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-create) et [POST mutes/users/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-destroy).

Les tableaux suivants comparent les endpoints de masquage standard v1.1 et ceux de X API v2 :

**Masquer un utilisateur**

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/mutes/users/create.json | /2/users/:id/muting |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [limites de taux](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 50 requêtes par tranche de 15 min | 50 requêtes par tranche de 15 min |
| Nécessite l’utilisation d’identifiants provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Project](/fr/resources/fundamentals/developer-apps) |     | ✔️  |

**Retirer le masquage d’un utilisateur**

Les tableaux suivants comparent les endpoints de retrait de masquage standard v1.1 et X API v2 :

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | DELETE |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/mutes/users/destroy.json | /2/users/:source&#95;user&#95;id/muting/:target&#95;user&#95;id |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [limites de taux](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 50 requêtes par tranche de 15 min | 50 requêtes par tranche de 15 min |
| Nécessite l’utilisation d’identifiants provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Project](/fr/resources/fundamentals/developer-apps) |     | ✔️  |
