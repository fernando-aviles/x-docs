<div id="comparing-x-apis-mutes-endpoints">
  ## Comparaison des endpoints de mise en sourdine dans X API
</div>

<div id="mutes-lookup">
  #### Recherche des mises en sourdine
</div>

Le endpoint de recherche des mises en sourdine de la v2 remplacera les endpoints standards [v1.1 GET mutes/users/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-ids) et [GET mutes/users/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/get-mutes-users-list).

Le tableau suivant compare les endpoints de mise en sourdine standard v1.1 et X API v2 :
 

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | ******GET****** | ******GET****** |
| Domaine hôte | ******https://api.x.com****** | ******https://api.x.com****** |
| Chemin de l’endpoint | ******/1.1/mutes/users/ids.json******<br /><br />/1.1/mutes/users/list.json | ******/2/users/:id/muting****** |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Limites de débit](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 15 requêtes par tranche de 15 min (par utilisateur) | 15 requêtes par tranche de 15 min (par utilisateur) |
| Formats de données | Format Standard v1.1 | [Format X API v2](/fr/x-api/fundamentals/data-dictionary) (déterminé par les paramètres de requête fields et expansions, non rétrocompatible avec les formats v1.1)<br /><br />Pour en savoir plus sur la migration du format Standard v1.1 vers le format X API v2, consultez notre [guide de migration des formats de données](/fr/x-api/migrate/data-format-migration). |
| Nécessite l’utilisation d’identifiants issus d’une [developer App](/fr/resources/fundamentals/developer-apps) associée à un [Project](/fr/resources/fundamentals/developer-apps) |     | ✔️  |

<div id="manage-mutes">
  #### Gérer les mises en sourdine
</div>

Les endpoints v2 de gestion des mises en sourdine remplaceront les endpoints standard v1.1 [POST mutes/users/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-create) et [POST mutes/users/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/mute-block-report-users/api-reference/post-mutes-users-destroy).

Les tableaux suivants comparent les endpoints de mise en sourdine standard v1.1 et X API v2 :

**Mettre un utilisateur en sourdine**

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine d’hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/mutes/users/create.json | /2/users/:id/muting |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Limites de débit](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 50 requêtes toutes les 15 min | 50 requêtes toutes les 15 min |
| Nécessite l’utilisation d’identifiants issus d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) |     | ✔️  |

**Réactiver le son d’un utilisateur**

Les tableaux suivants comparent les endpoints de réactivation de la sourdine standard v1.1 et X API v2 :

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | DELETE |
| Domaine d’hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/mutes/users/destroy.json | /2/users/:source&#95;user&#95;id/muting/:target&#95;user&#95;id |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Limites de débit](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 50 requêtes toutes les 15 min | 50 requêtes toutes les 15 min |
| Nécessite l’utilisation d’identifiants issus d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) |     | ✔️  |
