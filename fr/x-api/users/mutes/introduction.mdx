Les endpoints Mutes vous permettent de masquer et d’annuler le masquage d’utilisateurs, et de récupérer la liste des utilisateurs masqués par l’utilisateur authentifié.

<div id="endpoints">
  ## Endpoints
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/muting`](/fr/x-api/users/get-muting) | Obtenir la liste des utilisateurs masqués |
| POST | [`/2/users/:id/muting`](/fr/x-api/users/mute-user) | Masquer un utilisateur |
| DELETE | [`/2/users/:source_user_id/muting/:target_user_id`](/fr/x-api/users/unmute-user) | Ne plus masquer un utilisateur |

***

<div id="example-get-muted-users">
  ## Exemple : Obtenir les comptes masqués
</div>

```bash
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-mute-a-user">
  ## Exemple : Mettre un utilisateur en sourdine
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/muting" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
