Les endpoints Mutes vous permettent de masquer ou de réactiver des utilisateurs et de récupérer la liste des utilisateurs masqués par l&#39;utilisateur authentifié.

<div id="endpoints">
  ## Points de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------------------|:------------|
| GET | [`/2/users/:id/muting`](/fr/x-api/users/get-muting) | Récupérer les utilisateurs mis en sourdine |
| POST | [`/2/users/:id/muting`](/fr/x-api/users/mute-user) | Mettre un utilisateur en sourdine |
| DELETE | [`/2/users/:source_user_id/muting/:target_user_id`](/fr/x-api/users/unmute-user) | Rétablir le son pour un utilisateur |

***

<div id="example-get-muted-users">
  ## Exemple : récupérer les utilisateurs mis en sourdine
</div>

```bash
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-mute-a-user">
  ## Exemple : masquer un utilisateur
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/muting" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
