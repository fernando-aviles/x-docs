Ce guide présente les principaux concepts dont vous avez besoin pour intégrer les endpoints de mise en sourdine dans votre application.

***

<div id="authentication">
  ## Authentification
</div>

Les endpoints de mise en sourdine nécessitent une authentification utilisateur pour accéder aux listes de sourdine privées :

| Méthode | Description |
|:--------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/fr/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Recommandée pour les nouvelles applications |
| [OAuth 1.0a User Context](/fr/resources/fundamentals/authentication) | Pour compatibilité avec les intégrations existantes |

<Warning>
  L’authentification « App-only » n’est pas prise en charge. Vous devez vous authentifier au nom d’un utilisateur.
</Warning>

<div id="required-scopes-oauth-20">
  ### Scopes obligatoires (OAuth 2.0)
</div>

| Scope | Obligatoire pour |
|:------|:-----------------|
| `mute.read` | Récupérer les comptes mis en sourdine |
| `mute.write` | Mettre en sourdine et retirer la mise en sourdine de comptes |
| `users.read` | Obligatoire avec les scopes de mise en sourdine |
------------------------------------------------------------------

<div id="fields-and-expansions">
  ## Vue d’ensemble des endpoints
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | `/2/users/:id/muting` | Obtenir la liste des comptes masqués |
| POST | `/2/users/:id/muting` | Masquer un compte |
| DELETE | `/2/users/:source_user_id/muting/:target_user_id` | Ne plus masquer un compte |

### Exemple avec des champs

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123456789/muting?\
  user.fields=username,verified,created_at&\
  max_results=100" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Récupère les comptes mis en sourdine avec des champs supplémentaires
  for page in client.users.get_muting(
      user_id="123456789",
      user_fields=["username", "verified", "created_at"],
      max_results=100
  ):
      for user in page.data:
          print(f"{user.username} - Vérifié : {user.verified}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  const paginator = client.users.getMuting("123456789", {
    userFields: ["username", "verified", "created_at"],
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(`${user.username} - Vérifié : ${user.verified}`);
    });
  }
  ```
</CodeGroup>

<div id="behavior-differences">
  ## Pagination
</div>

Pour les utilisateurs ayant d’importantes listes de comptes masqués, les résultats sont paginés :

<CodeGroup dropdown>
  ```bash cURL
  # Première requête
  curl "https://api.x.com/2/users/123/muting?max_results=100" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"

  # Requête suivante avec jeton de pagination
  curl "https://api.x.com/2/users/123/muting?max_results=100&pagination_token=NEXT_TOKEN" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Le SDK gère la pagination automatiquement
  all_muted = []

  for page in client.users.get_muting(user_id="123", max_results=100):
      if page.data:
          all_muted.extend(page.data)

  print(f"{len(all_muted)} comptes masqués")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  async function getAllMutedUsers(userId) {
    const allMuted = [];

    // Le SDK gère la pagination automatiquement
    const paginator = client.users.getMuting(userId, { maxResults: 100 });

    for await (const page of paginator) {
      if (page.data) {
        allMuted.push(...page.data);
      }
    }

    return allMuted;
  }

  // Utilisation
  const muted = await getAllMutedUsers("123");
  console.log(`${muted.length} comptes masqués`);
  ```
</CodeGroup>

## Différences de comportement

### Mise en sourdine vs blocage

| Fonctionnalité | Mettre en sourdine | Bloquer |
|:--------|:-----|:------|
| Voir leurs Publications | Non (masquées) | Non |
| Ils voient vos Publications | Oui | Non |
| Ils vous suivent | Oui (peuvent suivre) | Non (supprimé) |
| Ils peuvent vous envoyer un message privé | Oui | Non |
| Notification envoyée | Non | Non |

<Tip>
  La mise en sourdine est privée — l’utilisateur mis en sourdine n’est pas notifié et ne peut pas savoir qu’il a été mis en sourdine.
</Tip>
