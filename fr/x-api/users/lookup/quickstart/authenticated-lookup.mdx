Ce guide vous explique comment récupérer le profil de l&#39;utilisateur actuellement authentifié à l&#39;aide de l&#39;endpoint `/me`.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin :

  * D&#39;un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une application approuvée
  * D&#39;un jeton d&#39;accès utilisateur (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

***

<div id="get-the-authenticated-user">
  ## Récupérer l’utilisateur authentifié
</div>

Envoyez une requête au point de terminaison `/me` avec un jeton d’accès utilisateur (User Access Token) :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/me?\
  user.fields=created_at,description,verified,public_metrics,profile_image_url" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Récupérer l’utilisateur authentifié
  response = client.users.get_me(
      user_fields=["created_at", "description", "verified", "public_metrics", "profile_image_url"]
  )

  print(f"Nom d’utilisateur : {response.data.username}")
  print(f"ID : {response.data.id}")
  print(f"Abonnés : {response.data.public_metrics.followers_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Récupérer l’utilisateur authentifié
  const response = await client.users.getMe({
    userFields: ["created_at", "description", "verified", "public_metrics", "profile_image_url"],
  });

  console.log(`Nom d’utilisateur : ${response.data?.username}`);
  console.log(`ID : ${response.data?.id}`);
  console.log(`Abonnés : ${response.data?.public_metrics?.followers_count}`);
  ```
</CodeGroup>

<div id="use-case">
  ## Cas d&#39;utilisation
</div>

L&#39;endpoint `/me` est essentiel lorsque :

* **Vérifier l&#39;authentification** — Confirmez que l&#39;utilisateur est correctement authentifié
* **Obtenir l&#39;id utilisateur** — Récupérez l&#39;id de l&#39;utilisateur authentifié pour d&#39;autres appels à l&#39;API
* **Personnaliser les expériences** — Affichez le profil de l&#39;utilisateur dans votre application
* **Requêtes pour le compte d&#39;un utilisateur** — Identifiez pour quel utilisateur vous effectuez des requêtes

***

<div id="include-pinned-post">
  ## Inclure la Publication épinglée
</div>

Récupérez la Publication épinglée de l’utilisateur :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/me?\
  user.fields=pinned_tweet_id&\
  expansions=pinned_tweet_id&\
  tweet.fields=created_at,text" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Récupérer l’utilisateur authentifié et sa Publication épinglée
  response = client.users.get_me(
      user_fields=["pinned_tweet_id"],
      expansions=["pinned_tweet_id"],
      tweet_fields=["created_at", "text"]
  )

  print(f"Username: {response.data.username}")
  # La Publication épinglée se trouve dans response.includes.tweets
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Récupérer l’utilisateur authentifié et sa Publication épinglée
  const response = await client.users.getMe({
    userFields: ["pinned_tweet_id"],
    expansions: ["pinned_tweet_id"],
    tweetFields: ["created_at", "text"],
  });

  console.log(`Username: ${response.data?.username}`);
  // La Publication épinglée se trouve dans response.includes?.tweets
  ```
</CodeGroup>

<div id="available-fields">
  ## Champs disponibles
</div>

| Champ | Description |
|:------|:------------|
| `created_at` | Date de création du compte |
| `description` | Biographie de l&#39;utilisateur |
| `profile_image_url` | URL de l&#39;avatar |
| `verified` | Statut de vérification |
| `public_metrics` | Nombre d&#39;abonnés et d&#39;abonnements |
| `location` | Emplacement défini par l&#39;utilisateur |
| `url` | Site web de l&#39;utilisateur |
| `protected` | Statut de compte protégé |
| `pinned_tweet_id` | ID de la Publication épinglée |

***

<div id="authentication-requirement">
  ## Conditions d’authentification
</div>

<Warning>
  Le point de terminaison `/me` nécessite une authentification en contexte utilisateur (User Context). L’authentification App-Only (Bearer Token) n’est pas prise en charge.
</Warning>

Utilisez l’une des méthodes suivantes :

* [OAuth 1.0a User Context](/fr/resources/fundamentals/authentication)
* [OAuth 2.0 Authorization Code with PKCE](/fr/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)
