Ce guide vous explique comment rechercher des utilisateurs à partir de leur ID ou de leur nom d’utilisateur.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin :

  * D’un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une application approuvée
  * Du Bearer Token de votre application
</Note>

***

<div id="look-up-by-id">
  ## Rechercher par ID
</div>

<div id="single-user">
  ### Un seul utilisateur
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/2244994945?\
  user.fields=created_at,description,verified,public_metrics" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer un utilisateur par ID
  response = client.users.get(
      "2244994945",
      user_fields=["created_at", "description", "verified", "public_metrics"]
  )

  print(f"Nom : {response.data.name}")
  print(f"Nom d'utilisateur : {response.data.username}")
  print(f"Abonnés : {response.data.public_metrics.followers_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérer un utilisateur par ID
  const response = await client.users.get("2244994945", {
    userFields: ["created_at", "description", "verified", "public_metrics"],
  });

  console.log(`Nom : ${response.data?.name}`);
  console.log(`Nom d'utilisateur : ${response.data?.username}`);
  console.log(`Abonnés : ${response.data?.public_metrics?.followers_count}`);
  ```
</CodeGroup>

<div id="multiple-users">
  ### Plusieurs utilisateurs
</div>

Recherchez jusqu&#39;à 100 utilisateurs à la fois :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users?\
  ids=2244994945,783214,6253282&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer plusieurs utilisateurs par ID
  response = client.users.get_users(
      ids=["2244994945", "783214", "6253282"],
      user_fields=["username", "verified"]
  )

  for user in response.data:
      print(f"{user.username} - Vérifié : {user.verified}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérer plusieurs utilisateurs par ID
  const response = await client.users.getUsers({
    ids: ["2244994945", "783214", "6253282"],
    userFields: ["username", "verified"],
  });

  response.data?.forEach((user) => {
    console.log(`${user.username} - Vérifié : ${user.verified}`);
  });
  ```
</CodeGroup>

<div id="look-up-by-username">
  ## Rechercher par nom d&#39;utilisateur
</div>

<div id="single-user">
  ### Un seul utilisateur
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/by/username/XDevelopers?\
  user.fields=created_at,description,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer un utilisateur par son nom d'utilisateur
  response = client.users.get_by_username(
      "XDevelopers",
      user_fields=["created_at", "description", "verified"]
  )

  print(f"ID : {response.data.id}")
  print(f"Nom : {response.data.name}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérer un utilisateur par son nom d'utilisateur
  const response = await client.users.getByUsername("XDevelopers", {
    userFields: ["created_at", "description", "verified"],
  });

  console.log(`ID : ${response.data?.id}`);
  console.log(`Nom : ${response.data?.name}`);
  ```
</CodeGroup>

<div id="multiple-users">
  ### Plusieurs utilisateurs
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/by?\
  usernames=XDevelopers,X,elonmusk&\
  user.fields=created_at,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer plusieurs utilisateurs via leur nom d'utilisateur
  response = client.users.get_users_by_usernames(
      usernames=["XDevelopers", "X", "elonmusk"],
      user_fields=["created_at", "verified"]
  )

  for user in response.data:
      print(f"{user.username} - {user.created_at}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérer plusieurs utilisateurs via leur nom d'utilisateur
  const response = await client.users.getUsersByUsernames({
    usernames: ["XDevelopers", "X", "elonmusk"],
    userFields: ["created_at", "verified"],
  });

  response.data?.forEach((user) => {
    console.log(`${user.username} - ${user.created_at}`);
  });
  ```
</CodeGroup>

<div id="available-fields">
  ## Champs disponibles
</div>

| Champ | Description |
|:------|:------------|
| `created_at` | Date de création du compte |
| `description` | Bio de l’utilisateur |
| `profile_image_url` | URL de l’avatar |
| `verified` | Statut de vérification |
| `public_metrics` | Nombre d’abonnés/abonnements |
| `location` | Lieu défini par l’utilisateur |
| `url` | Site web de l’utilisateur |
| `protected` | Statut de protection du compte |
| `pinned_tweet_id` | ID de la publication épinglée |
