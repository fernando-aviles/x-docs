Les endpoints de recherche d’utilisateurs vous permettent de récupérer les informations de profil d’un ou de plusieurs utilisateurs. Recherchez des utilisateurs par leur id, leur nom d’utilisateur, ou obtenez des informations détaillées sur l’utilisateur actuellement authentifié.

<div id="endpoints">
  ## Points de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:----------------------|:------------|
| GET | [`/2/users/:id`](/fr/x-api/users/get-user-by-id) | Récupérer un utilisateur par identifiant |
| GET | [`/2/users`](/fr/x-api/users/get-users-by-ids) | Récupérer des utilisateurs par identifiants (jusqu&#39;à 100) |
| GET | [`/2/users/by/username/:username`](/fr/x-api/users/get-user-by-username) | Récupérer un utilisateur par nom d&#39;utilisateur |
| GET | [`/2/users/by`](/fr/x-api/users/get-users-by-usernames) | Récupérer des utilisateurs par noms d&#39;utilisateur (jusqu&#39;à 100) |
| GET | [`/2/users/me`](/fr/x-api/users/get-my-user) | Récupérer l&#39;utilisateur authentifié |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/users/by/username/XDevelopers?\
user.fields=created_at,description,public_metrics,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## Exemple de réponse
</div>

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "XDevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "The voice of the X developer community",
    "verified": true,
    "public_metrics": {
      "followers_count": 583423,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```
