  ## Comparaison des endpoints de recherche d’utilisateurs de X API
</div>

Les endpoints v2 de recherche d’utilisateurs remplaceront les endpoints standard v1.1 [GET users/lookup](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-lookup.html) et [GET users/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-show.html). Si vous avez du code, des applications ou des outils qui utilisent l’une de ces versions des endpoints de recherche d’utilisateurs et que vous envisagez de migrer vers le nouvel endpoint X API v2, alors cette série de guides est faite pour vous. 
 

Les tableaux suivants comparent les différents types de endpoints de recherche d’utilisateurs :
 

|     |     |     |
| :--- | :--- | :--- |
| **Description** | **Standard v1.1** | **X API v2** |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine de l’hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin d’endpoint | `/1.1/users/show.json` `/1.1/users/lookup.json` | `/2/users`<br /><br />`/2/users/:id`<br /><br />`/2/users/by`<br /><br />`/2/users/by/:username` |
| [Authentification](/fr/resources/fundamentals/authentication) | Contexte utilisateur OAuth 1.0a | Contexte utilisateur OAuth 1.0a<br /><br />App only<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Limites de taux](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 900 requêtes par 15 min (par utilisateur)<br /><br />/show - 900 requêtes par 15 min (par App)  <br />/lookup - 300 requêtes par 15 min (par App) | 900 requêtes par 15 min (par utilisateur)<br /><br />300 requêtes par 15 min (par App) |
| Nombre maximal d’utilisateurs par réponse | /show -  1<br /><br />/lookup - 100 | 100 |
| Format de l’objet de réponse JSON | Format standard v1.1 | [Format X API v2](/fr/x-api/fundamentals/data-dictionary) (déterminé par les paramètres de requête fields et expansions, non rétrocompatible avec les formats v1.1)<br /><br />Pour en savoir plus sur la façon de migrer du format Standard v1.1 vers le format X API v2, veuillez consulter notre [guide de migration des formats de données](/fr/x-api/migrate/data-format-migration). |
| Prise en charge de la sélection des [champs](/fr/x-api/fundamentals/data-dictionary) à renvoyer dans le payload |     | ✔   |
| Prise en charge des champs [annotations](/fr/x-api/fundamentals/post-annotations) (dans la Publication épinglée) |     | ✔   |
| Prise en charge de la requête des nouveaux champs [metrics](/fr/x-api/fundamentals/metrics) (dans la Publication épinglée) |     | ✔   |
| Prise en charge du champ [conversation&#95;id](/fr/x-api/fundamentals/conversation-id) (dans la Publication épinglée) |     | ✔   |
| Nécessite l’utilisation d’identifiants provenant d’une [developer App](/fr/resources/fundamentals/developer-apps) associée à un [project](/fr/resources/fundamentals/developer-apps) |     | ✔   |
