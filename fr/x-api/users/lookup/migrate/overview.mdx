  ## Comparaison des endpoints de recherche d’utilisateurs de X API
</div>

Les endpoints de recherche d’utilisateurs de la v2 remplaceront les endpoints standard v1.1 [GET users/lookup](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-lookup.html) et [GET users/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-show.html). Si vous avez du code, des apps ou des outils qui utilisent l’une de ces versions des endpoints de recherche d’utilisateurs et que vous envisagez de migrer vers le nouvel endpoint X API v2, ces guides vous sont destinés. 
 

Les tableaux suivants comparent les différents types d’endpoints de recherche d’utilisateurs :
 

|     |     |     |
| :--- | :--- | :--- |
| **Description** | **Standard v1.1** | **X API v2** |
| HTTP methods supported | Méthodes HTTP prises en charge | Méthodes HTTP prises en charge |
| Host domain | `https://api.x.com` | `https://api.x.com` |
| Endpoint path | Chemin d’endpoint : `/1.1/users/show.json` `/1.1/users/lookup.json` | Chemin d’endpoint : `/2/users`<br /><br />`/2/users/:id`<br /><br />`/2/users/by`<br /><br />`/2/users/by/:username` |
| [Authentication](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />App uniquement<br /><br />OAuth 2.0 Authorization Code with PKCE |
| Default request [rate limits](/fr/resources/fundamentals/rate-limits) | 900 requêtes par 15 min (par utilisateur)<br /><br />/show - 900 requêtes par 15 min (par app)  <br />/lookup - 300 requêtes par 15 min (par app) | 900 requêtes par 15 min (par utilisateur)<br /><br />300 requêtes par 15 min (par app) |
| Maximum Users per response | /show -  1<br /><br />/lookup - 100 | 100 |
| JSON response object format | Format JSON Standard v1.1 | [Format X API v2](/fr/x-api/fundamentals/data-dictionary) (déterminé par les champs et les paramètres de requête expansions, non rétrocompatible avec les formats v1.1)<br /><br />Pour en savoir plus sur la migration du format Standard v1.1 vers le format X API v2, veuillez consulter notre [guide de migration des formats de données](/fr/x-api/migrate/data-format-migration). |
| Supports selecting which [fields](/fr/x-api/fundamentals/data-dictionary) return in the payload |     | ✔ (permet de sélectionner quels champs sont renvoyés dans la charge utile)  |
| Supports the [annotations](/fr/x-api/fundamentals/post-annotations) fields (on pinned Post) |     | ✔ (prend en charge les champs annotations sur la Publication épinglée)  |
| Supports requesting new [metrics](/fr/x-api/fundamentals/metrics) fields (on pinned Post) |     | ✔ (prend en charge la demande de nouveaux champs metrics sur la Publication épinglée)  |
| Supports the [conversation&#95;id](/fr/x-api/fundamentals/conversation-id) field (on pinned Post) |     | ✔ (prend en charge le champ conversation&#95;id sur la Publication épinglée)  |
| Requires the use of credentials from a [developer App](/fr/resources/fundamentals/developer-apps) associated with a [project](/fr/resources/fundamentals/developer-apps) |     | ✔ (nécessite l’utilisation d’identifiants provenant d’une App développeur associée à un projet)  |
