Les endpoints Follows vous permettent de suivre ou de vous désabonner d’utilisateurs, et de récupérer les listes d’abonnés et d’abonnements de n’importe quel utilisateur.

<div id="endpoints">
  ## Points de terminaison
</div>

<div id="follows-lookup">
  ### Recherche des suivis
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/followers`](/fr/x-api/users/get-followers) | Récupérer les abonnés d’un utilisateur |
| GET | [`/2/users/:id/following`](/fr/x-api/users/get-following) | Récupérer les comptes suivis par un utilisateur |

<div id="manage-follows">
  ### Gérer les abonnements
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------------------|:------------|
| POST | [`/2/users/:id/following`](/fr/x-api/users/follow-user) | S’abonner à un utilisateur |
| DELETE | [`/2/users/:source_user_id/following/:target_user_id`](/fr/x-api/users/unfollow-user) | Se désabonner d’un utilisateur |

***

<div id="example-get-followers">
  ## Exemple : Obtenir les abonnés
</div>

```bash
curl "https://api.x.com/2/users/2244994945/followers?\
user.fields=username,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-follow-a-user">
  ## Exemple : Suivre un utilisateur
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/following" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "2244994945"}'
```
