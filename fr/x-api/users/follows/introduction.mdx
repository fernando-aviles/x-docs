Les endpoints Follows vous permettent de suivre ou de ne plus suivre des utilisateurs, et de récupérer les listes d’abonnés et d’abonnements de n’importe quel utilisateur.

<div id="endpoints">
  ## Points de terminaison
</div>

<div id="follows-lookup">
  ### Recherche des relations de suivi
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/followers`](/fr/x-api/users/get-followers) | Obtenir les abonnés d’un utilisateur |
| GET | [`/2/users/:id/following`](/fr/x-api/users/get-following) | Obtenir les comptes qu’un utilisateur suit |

<div id="manage-follows">
  ### Gérer les abonnements
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/following`](/fr/x-api/users/follow-user) | Suivre un utilisateur |
| DELETE | [`/2/users/:source_user_id/following/:target_user_id`](/fr/x-api/users/unfollow-user) | Ne plus suivre un utilisateur |

***

<div id="example-get-followers">
  ## Exemple : Récupérer les abonnés
</div>

```bash
curl "https://api.x.com/2/users/2244994945/followers?\
user.fields=username,verified,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-follow-a-user">
  ## Exemple : suivre un utilisateur
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/following" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "2244994945"}'
```
