  ## Comparaison des endpoints de suivi de X API
</div>

<div id="follows-lookup">
  ### Recherche des relations de suivi
</div>

Les endpoints v2 de recherche de relations de suivi remplaceront les endpoints Standard v1.1 [followers/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-followers-ids), v1.1 [followers/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-followers-list), v1.1 [friends/ids](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-friends-ids) et v1.1 [friends/list](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-friends-list).

Les tableaux suivants comparent les différents types d’endpoints de recherche de relations de suivi :

|     |     |     |
| :--- | :--- | :--- |
| **Description** | **Standard v1.1** | **X API v2** |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine d’hébergement | `https://api.x.com` | `https://api.x.com` |
| Chemin d’endpoint | /1.1/friends/ids.json<br /><br />/1.1/friends/list.json<br /><br />/1.1/followers/ids.json<br /><br />/1.1/followers/list.json | /2/users/:id/following<br /><br />/2/users/:id/followers |
| [Authentication](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App uniquement | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />App uniquement |
| [Limites de taux](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 15 requêtes par 15 min (par utilisateur)<br /><br />15 requêtes par 15 min (par App) | 15 requêtes par 15 min (par utilisateur)<br /><br />15 requêtes par 15 min (par App) |
| Nombre maximal d’utilisateurs par réponse | GET friends/id et GET followers/id renvoient un maximum de 5 000 identifiants d’utilisateurs par page.<br /><br />  <br /><br />GET friends/list et GET followers/list renvoient un maximum de 200 objets utilisateur par page. | 1 000 objets utilisateur par page |
| Pagination | Un jeton est renvoyé dans un champ next&#95;cursor, qui peut ensuite être transmis comme valeur du paramètre cursor pour renvoyer la page suivante de résultats. | Un jeton est renvoyé dans un champ next&#95;token, qui peut ensuite être transmis comme valeur du paramètre token pour renvoyer la page suivante de résultats.<br /><br />La charge utile v2 fournit également un champ previous&#95;token, qui peut aussi être transmis avec le paramètre pagination&#95;token pour renvoyer la page précédente de résultats. |
| Format JSON | Format Standard v1.1 | [Format X API v2](/fr/x-api/fundamentals/data-dictionary) (déterminé par les paramètres de requête fields et expansions, non rétrocompatible avec les formats v1.1)<br /><br />Pour en savoir plus sur la migration du format Standard v1.1 vers le format X API v2, consultez notre [guide de migration des formats de données](/fr/x-api/migrate/data-format-migration). |
| Permet de sélectionner quels [champs](/fr/x-api/fundamentals/data-dictionary) sont renvoyés dans la charge utile |     | ✔   |
| Prend en charge les champs d’[annotations](/fr/x-api/fundamentals/post-annotations) de Publication |     | ✔   |
| Permet de demander de nouveaux champs de [métriques](/fr/x-api/fundamentals/metrics) |     | ✔   |
| Prend en charge le champ [conversation&#95;id](/fr/x-api/fundamentals/conversation-id) |     | ✔   |
| Nécessite l’utilisation d’identifiants provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [projet](/fr/resources/fundamentals/developer-apps) |     | ✔   |

<div id="manage-follows">
  #### Gérer les abonnements
</div>

Les points de terminaison de gestion des abonnements de la v2 remplaceront les points de terminaison standard de la v1.1 [POST friendships/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/post-friendships-create) et [POST friendships/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/post-friendships-destroy).

Les tableaux suivants comparent les points de terminaison standard de la v1.1 et de X API v2 pour la création d’un abonnement :

<div id="follow-a-user">
  #### Suivre un utilisateur
</div>

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin de l’endpoint | /1.1/friendships/create.json | /2/users/:id/following |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Limites de taux](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 50 requêtes par 15 min | 50 requêtes par 15 min |
| Nombre maximal d’opérations quotidiennes par utilisateur | 400 | 400 |
| Nombre maximal d’opérations quotidiennes par App | 1000 | 1000 |
| Nécessite l’utilisation d’identifiants provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Project](/fr/resources/fundamentals/developer-apps) |     | ✔️  |

<div id="unfollow-a-user">
  #### Ne plus suivre un utilisateur
</div>

Les tableaux suivants comparent les points de terminaison de suppression de suivi standard v1.1 et X API v2 :

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | DELETE |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin du point de terminaison | /1.1/friendships/destroy.json | /2/users/:source&#95;user&#95;id/following/:target&#95;user&#95;id |
| [Authentification](/fr/resources/fundamentals/authentication) | Contexte utilisateur OAuth 1.0a | Contexte utilisateur OAuth 1.0a<br /><br />Code d&#39;autorisation OAuth 2.0 avec PKCE |
| [Limites de taux](/fr/resources/fundamentals/rate-limits) de requête par défaut | 15 requêtes par 15 min (par utilisateur) | 50 requêtes par 15 min (par utilisateur) |
| Nombre maximal d&#39;opérations quotidiennes par application | Aucune | 500 |
| Nécessite l&#39;utilisation d&#39;identifiants d&#39;une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) |     | ✔️  |
