Les endpoints Blocks vous permettent de bloquer ou de débloquer des utilisateurs et d’obtenir la liste des utilisateurs bloqués par l’utilisateur authentifié.

<div id="endpoints">
  ## Points de terminaison
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/blocking`](/fr/x-api/users/get-blocking) | Récupérer les utilisateurs bloqués |
| POST | [`/2/users/:id/blocking`](/fr/x-api/users/block-dms) | Bloquer un utilisateur |
| DELETE | `/2/users/:source_user_id/blocking/:target_user_id` | Débloquer un utilisateur |

***

<div id="example-get-blocked-users">
  ## Exemple : Obtenir la liste des utilisateurs bloqués
</div>

```bash
curl "https://api.x.com/2/users/123456789/blocking?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-block-a-user">
  ## Exemple : bloquer un utilisateur
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/blocking" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
