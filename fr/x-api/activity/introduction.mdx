L’endpoint Activity Stream assure la diffusion en temps réel des événements d’activité de compte pour les utilisateurs abonnés. Recevez des événements lorsque les utilisateurs publient des Publications, aiment, suivent, reçoivent des DM, et plus encore.

<div id="event-types">
  ## Types d’événements
</div>

| Événement | Description |
|:------|:------------|
| `tweet_create_events` | L’utilisateur publie une nouvelle Publication |
| `favorite_events` | L’utilisateur aime une Publication |
| `follow_events` | L’utilisateur suit ou est suivi |
| `direct_message_events` | L’utilisateur envoie ou reçoit un DM |
| `block_events` | L’utilisateur bloque ou débloque |
| `mute_events` | L’utilisateur met en sourdine ou réactive |

<div id="how-it-works">
  ## Fonctionnement
</div>

1. **Créer un abonnement** — S’abonner à l’activité d’un utilisateur
2. **Se connecter au flux** — Établir une connexion persistante
3. **Recevoir les événements** — Recevoir des événements d’activité en temps réel
4. **Traiter les événements** — Traiter ces événements dans votre application

***

<div id="example-connect-to-stream">
  ## Exemple : connexion au flux
</div>

```python
import requests

def stream_activity(bearer_token):
    url = "https://api.x.com/2/activity/stream"
    headers = {"Authorization": f"Bearer {bearer_token}"}
    
    response = requests.get(url, headers=headers, stream=True)
    
    for line in response.iter_lines():
        if line:
            print(line.decode("utf-8"))
```
