<div id="building-a-library">
  ## Vous développez une bibliothèque ?
</div>

Si vous avez créé une bibliothèque X API, partagez-la avec la communauté :

1. Publiez un message dans le [forum Libraries &amp; SDKs](https://devcommunity.x.com/c/libraries-and-sdks/63)
2. Nous pourrons éventuellement l’ajouter à cette page !

Utilisez nos [badges de version](https://twbadges.glitch.me/) dans votre README pour indiquer la compatibilité avec l’API.
