Les endpoints « Manage Lists » vous permettent de créer, de mettre à jour et de supprimer des listes pour le compte des utilisateurs authentifiés.

  </Card>
</CardGroup>

***

<div id="endpoints">
  ## Endpoints
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/lists`](/fr/x-api/lists/create-list) | Créer une nouvelle Liste |
| PUT | [`/2/lists/:id`](/fr/x-api/lists/update-list) | Mettre à jour une Liste |
| DELETE | [`/2/lists/:id`](/fr/x-api/lists/delete-list) | Supprimer une Liste |

***

<div id="example-create-a-list">
  ## Exemple : création d’une liste
</div>

```bash
curl -X POST "https://api.x.com/2/lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech News",
    "description": "My favorite tech journalists",
    "private": false
  }'
```

<div id="example-response">
  ## Exemple de réponse
</div>

```json
{
  "data": {
    "id": "1234567890",
    "name": "Tech News"
  }
}
```
