<div id="comparing-x-apis-lists-endpoints">
  ## Comparaison des endpoints de listes de X API
</div>

Les endpoints v2 de gestion des listes remplaceront à terme [POST lists/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-create), [POST lists/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-destroy) et [POST lists/update](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-update). Si vous avez du code, des applications ou des outils qui utilisent une version plus ancienne de ces endpoints et que vous envisagez de migrer vers la nouvelle X API v2, ce guide est fait pour vous.

Les tableaux suivants comparent les endpoints de listes de la version standard v1.1 et de X API v2 :

**Créer une liste**

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/lists/create.json | /2/lists |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Limites de débit](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | Aucune | 300 requêtes par 15 min (par utilisateur) |

**Supprimer une liste**

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | DELETE |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/lists/destroy.json | /2/lists/:id |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Limites de débit](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | Aucune | 300 requêtes par 15 min (par utilisateur) |

**Mettre à jour une liste**

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | PUT |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/lists/update.json | /2/lists/:id |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Limites de débit](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | Aucune | 300 requêtes par 15 min (par utilisateur) |

Pour accéder aux endpoints X API v2, vous devez [créer un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info). Lors de l’authentification, vous devez utiliser des clés et des jetons provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) située dans un [Projet](/fr/resources/fundamentals/developer-apps).

Pour en savoir plus sur l’accès aux endpoints X API v2, consultez notre page de [prise en main](/fr/x-api/getting-started/getting-access).
