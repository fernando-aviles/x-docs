<div id="manage-lists-standard-v11-compared-to-x-api-v2">
  ### Gérer les listes : version standard v1.1 comparée à X API v2
</div>

Si vous utilisez les endpoints de la version standard v1.1 [POST lists/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-create), [POST lists/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-destroy) et [POST lists/update](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-update), ce guide a pour objectif de vous aider à comprendre les similitudes et les différences entre les endpoints de gestion des listes de la version standard v1.1 et ceux de X API v2.

* **Similitudes**
  * Authentification
* **Différences**
  * URL des endpoints
  * Exigences relatives à l’App et au Projet
  * Méthodes HTTP
  * Limites de taux
  * Paramètres de requête

<div id="similarities">
  #### Similarités
</div>

**Authentification**

Les deux versions de ces endpoints prennent en charge [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication). Par conséquent, si vous utilisiez auparavant l’un des endpoints standard v1.1 de gestion des listes, vous pouvez continuer à utiliser la même méthode d’authentification si vous migrez vers la version X API v2.

<div id="differences">
  #### Différences
</div>

**URL d’endpoint**

* Endpoints Standard v1.1 :
  * POST https://api.x.com/1.1/lists/create.json
    (Crée une liste)
  * POST https://api.x.com/1.1/lists/destroy.json
    (Supprime une liste)
  * POST https://api.x.com/1.1/lists/update.json
    (Met à jour une liste)
* Endpoint X API v2 :
  * POST https://api.x.com/2/lists
    (Crée une liste)

  * DELETE https://api.x.com/2/lists/:id
    (Supprime une liste)

  * PUT https://api.x.com/2/lists/:id
    (Met à jour une liste)

**Limites de débit**

| **Standard v1.1** | **X API v2** |
| :--- | :--- |
| /1.1/lists/create.json<br /><br />aucune | /2/lists<br /><br />300 requêtes par fenêtre de 15 minutes avec OAuth 1.0a User Context |
| /1.1/lists/destroy.json<br /><br />aucune | /2/lists/:id<br /><br />300 requêtes par fenêtre de 15 minutes avec OAuth 1.0a User Context |
| /1.1/lists/update.json<br /><br />aucune | /2/lists/:id<br /><br />300 requêtes par fenêtre de 15 minutes avec OAuth 1.0a User Context |

**Exigences relatives aux Apps et aux Projets**

Les endpoints X API v2 exigent que vous utilisiez des informations d’identification provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) lors de l’authentification de vos requêtes. Tous les endpoints X API v1.1 peuvent utiliser des informations d’identification provenant d’Apps, qu’elles soient ou non associées à un Projet.

**Paramètres de requête**

Les paramètres de requête Standard v1.1 suivants ont des équivalents dans X API v2 :

**Créer une liste**

| **Standard** | **X API v2** |
| :--- | :--- |
| name | name |
| mode | private |
| description | description |

**Supprimer/mettre à jour une liste**

| **Standard** | **X API v2** |
| :--- | :--- |
| owner&#95;screen&#95;name | Aucun équivalent |
| owner&#95;id | Aucun équivalent |
| list&#95;id | id  |
| slug | Aucun équivalent |

<Note>
  **Veuillez noter :** les paramètres Standard v1.1 sont transmis en tant que paramètres de requête, tandis que les paramètres X API v2 sont transmis dans le corps de la requête (pour l’endpoint POST) ou en tant que paramètres de chemin (pour les endpoints DELETE et PUT).
</Note>

<div id="create-a-list-v2">
  ### Créer une liste (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/lists" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"name": "Ma liste", "description": "Une excellente liste"}'
  ```

  ```python Python
  # Nécessite l’authentification OAuth 1.0a User Context
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/lists"
  data = {"name": "Ma liste", "description": "Une excellente liste"}

  response = requests.post(url, auth=auth, json=data)
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Créer une liste
  response = client.lists.create(name="Ma liste", description="Une excellente liste")
  print(f"Liste créée : {response.data.id}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Créer une liste
  const response = await client.lists.create({
    name: "Ma liste",
    description: "Une excellente liste",
  });
  console.log(`Liste créée : ${response.data?.id}`);
  ```
</CodeGroup>

<div id="delete-a-list-v2">
  ### Supprimer une liste (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/lists/123456789" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  # Requiert une authentification OAuth 1.0a User Context
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/lists/123456789"
  response = requests.delete(url, auth=auth)
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",

  client = Client(auth=oauth1)

  # Supprimer une liste
  response = client.lists.delete("123456789")
  print(f"Deleted: {response.data.deleted}")
  ```
