<div id="comparing-x-apis-list-members-endpoints">
  ## Comparaison des endpoints List members de X API
</div>

Le groupe d’endpoints List members de X API v2 remplacera les endpoints standard v1.1 [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members), [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships), [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) et [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy). Si vous avez du code, des applications ou des outils qui utilisent l’une de ces versions des endpoints List members et que vous envisagez de migrer vers le nouveau groupe d’endpoints X API v2, cet ensemble de guides est fait pour vous. 

<div id="list-members-lookup">
  ### Recherche des membres d’une liste
</div>

Les endpoints v2 de recherche des membres de liste remplaceront les endpoints standard [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members) et [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships).

Les tableaux suivants comparent les endpoints des listes standard v1.1 et X API v2 :

**Recherche de membre de liste**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine de l’hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin de l’endpoint | `/1.1/lists/members.json` | `/2/lists/:id/members` |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />Application uniquement | OAuth 1.0a User Context<br /><br />Code d’autorisation OAuth 2.0 avec PKCE<br /><br />Application uniquement |
| Limites de fréquence de requêtes par défaut ([rate limits](/fr/resources/fundamentals/rate-limits)) | 900 requêtes par 15 min avec OAuth 1.0a<br /><br />75 requêtes par 15 min avec application uniquement | 900 requêtes par 15 min avec OAuth 1.0a<br /><br />900 requêtes par 15 min avec OAuth 2.0<br /><br />900 requêtes par 15 min avec application uniquement |

**Recherche d’appartenance à une liste**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine de l’hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin de l’endpoint | `/1.1/lists/memberships.json` | `/2/users/:id/list_memberships` |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />Application uniquement | OAuth 1.0a User Context<br /><br />Code d’autorisation OAuth 2.0 avec PKCE<br /><br />Application uniquement |
| Limites de fréquence de requêtes par défaut ([rate limits](/fr/resources/fundamentals/rate-limits)) | 75 requêtes par 15 min avec OAuth 1.0a<br /><br />75 requêtes par 15 min avec application uniquement | 75 requêtes par 15 min avec OAuth 1.0a<br /><br />75 requêtes par 15 min avec OAuth 2.0<br /><br />75 requêtes par 15 min avec application uniquement |

<div id="manage-list-members">
  ### Gérer les membres de Liste
</div>

Les endpoints v2 de gestion des membres de Liste remplaceront les endpoints standard [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) et [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy).

Les tableaux suivants comparent les endpoints de Liste standard v1.1 et X API v2 :

**Ajouter un membre**

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin de l&#39;endpoint | /1.1/lists/members/create.json | /2/lists/:id/members |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| Limites de fréquence des [requêtes](/fr/resources/fundamentals/rate-limits) par défaut | Aucune | 300 requêtes par 15 min (par utilisateur) |

**Supprimer un membre**

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | DELETE |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin de l&#39;endpoint | /1.1/lists/members/destroy.json | /2/lists/:id/:user&#95;id |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| Limites de fréquence des [requêtes](/fr/resources/fundamentals/rate-limits) par défaut | Aucune | 300 requêtes par 15 min (par utilisateur) |

Pour accéder aux endpoints X API v2, vous devez [créer un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info). Lors de l’authentification, vous devez utiliser des clés et des jetons provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) située dans un [Projet](/fr/resources/fundamentals/developer-apps). 

Pour en savoir plus sur l’accès aux endpoints X API v2, consultez notre page [Premiers pas](/fr/x-api/getting-started/getting-access).
