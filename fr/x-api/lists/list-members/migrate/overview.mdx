<div id="comparing-x-apis-list-members-endpoints">
  ## Comparaison des endpoints X API pour les membres de listes
</div>

Le groupe d’endpoints v2 pour les membres de listes remplacera les endpoints standard v1.1 [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members), [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships), [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) et [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy). Si vous avez du code, des apps ou des outils qui utilisent l’une de ces versions des endpoints de membres de listes et que vous envisagez de migrer vers le nouvel endpoint X API v2, alors cet ensemble de guides vous est destiné. 

<div id="list-members-lookup">
  ### Recherche des membres de liste
</div>

Les endpoints v2 de recherche des membres de Liste remplaceront les endpoints standard [GET lists/members](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-members) et [GET lists/memberships](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-memberships).

Les tableaux suivants comparent les endpoints de Liste standard v1.1 et X API v2 :

**Recherche de membres de liste**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin d’endpoint | `/1.1/lists/members.json` | `/2/lists/:id/members` |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />Application uniquement | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />Application uniquement |
| [Limites de débit](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 900 requêtes par tranche de 15 min avec OAuth 1.0a<br /><br />75 requêtes par tranche de 15 min avec Application uniquement | 900 requêtes par tranche de 15 min avec OAuth 1.0a<br /><br />900 requêtes par tranche de 15 min avec OAuth 2.0<br /><br />900 requêtes par tranche de 15 min avec Application uniquement |

**Recherche des appartenances à des listes**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin d’endpoint | `/1.1/lists/memberships.json` | `/2/users/:id/list_memberships` |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />Application uniquement | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />Application uniquement |
| [Limites de débit](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 75 requêtes par tranche de 15 min avec OAuth 1.0a<br /><br />75 requêtes par tranche de 15 min avec Application uniquement | 75 requêtes par tranche de 15 min avec OAuth 1.0a<br /><br />75 requêtes par tranche de 15 min avec OAuth 2.0<br /><br />75 requêtes par tranche de 15 min avec Application uniquement |

<div id="manage-list-members">
  ### Gérer les membres de liste
</div>

Les endpoints v2 de gestion des membres de liste remplaceront les endpoints standard v1.1 [POST lists/members/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-create) et [POST lists/members/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-members-destroy).

Les tableaux suivants comparent les endpoints de liste standard v1.1 et X API v2 :

**Ajouter un membre**

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin de l’endpoint | /1.1/lists/members/create.json | /2/lists/:id/members |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Limites de fréquence](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | Aucune | 300 requêtes par 15 min (par utilisateur) |

**Supprimer un membre**

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | DELETE |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin de l’endpoint | /1.1/lists/members/destroy.json | /2/lists/:id/:user&#95;id |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Limites de fréquence](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | Aucune | 300 requêtes par 15 min (par utilisateur) |

Pour accéder aux endpoints X API v2, vous devez [créer un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info). Lors de l’authentification, vous devez utiliser des clés et des jetons provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) située dans un [Projet](/fr/resources/fundamentals/developer-apps). 

Pour en savoir plus sur la façon d’obtenir l’accès aux endpoints X API v2, consultez notre page [mise en route](/fr/x-api/getting-started/getting-access).
