Les endpoints List Members vous permettent d’afficher les membres d’une Liste, d’ajouter des membres à vos Listes et d’en retirer. Vous pouvez également voir de quelles Listes un utilisateur est membre.

<div id="endpoints">
  ## Points de terminaison
</div>

<div id="list-members-lookup">
  ### Recherche des membres d’une Liste
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/members`](/fr/x-api/lists/get-list-members) | Obtenir les membres d’une Liste |
| GET | [`/2/users/:id/list_memberships`](/fr/x-api/users/get-list-memberships) | Obtenir les Listes dont un utilisateur est membre |

<div id="manage-list-members">
  ### Gérer les membres de liste
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/lists/:id/members`](/fr/x-api/lists/add-list-member) | Ajouter un membre |
| DELETE | [`/2/lists/:id/members/:user_id`](/fr/x-api/lists/remove-list-member) | Supprimer un membre |

***

<div id="example-get-list-members">
  ## Exemple : Obtenir les membres d’une liste
</div>

```bash
curl "https://api.x.com/2/lists/1234567890/members?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-add-a-member">
  ## Exemple : ajouter un membre
</div>

```bash
curl -X POST "https://api.x.com/2/lists/1234567890/members" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "9876543210"}'
```
