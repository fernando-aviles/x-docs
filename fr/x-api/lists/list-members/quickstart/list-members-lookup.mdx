Ce guide vous explique comment récupérer les membres d’une List.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin de :

  * d’un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une App approuvée
  * du Bearer Token de votre App
</Note>

***

<div id="get-list-members">
  ## Obtenir les membres de la Liste
</div>

<Steps>
  <Step title="Trouver l'identifiant de la Liste">
    Vous pouvez trouver l&#39;identifiant de la Liste dans l&#39;URL lorsque vous affichez une Liste :

    ```
    https://x.com/i/lists/84839422
                          └── Ceci est l'identifiant de la Liste
    ```
  </Step>

  <Step title="Envoyer la requête pour les membres de la Liste">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/lists/84839422/members?\
      user.fields=created_at,username,verified&\
      max_results=100" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Récupérer les membres de la Liste avec pagination
      for page in client.lists.get_members(
          "84839422",
          user_fields=["created_at", "username", "verified"],
          max_results=100
      ):
          for user in page.data:
              print(f"{user.username} - A rejoint : {user.created_at}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Récupérer les membres de la Liste avec pagination
      const paginator = client.lists.getMembers("84839422", {
        userFields: ["created_at", "username", "verified"],
        maxResults: 100,
      });

      for await (const page of paginator) {
        page.data?.forEach((user) => {
          console.log(`${user.username} - A rejoint : ${user.created_at}`);
        });
      }
      ```
    </CodeGroup>
  </Step>

  <Step title="Examiner la réponse">

<div id="include-additional-data">
  ## Inclure des données supplémentaires
</div>

Utilisez le paramètre `expansions` pour obtenir des données associées comme les publications épinglées :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/84839422/members?\
  user.fields=created_at&\
  expansions=pinned_tweet_id&\
  tweet.fields=created_at" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer les membres de la liste avec expansions
  for page in client.lists.get_members(
      "84839422",
      user_fields=["created_at"],
      expansions=["pinned_tweet_id"],
      tweet_fields=["created_at"]
  ):
      for user in page.data:
          print(f"{user.username}")
      # Les publications épinglées se trouvent dans page.includes.tweets
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérer les membres de la liste avec expansions
  const paginator = client.lists.getMembers("84839422", {
    userFields: ["created_at"],
    expansions: ["pinned_tweet_id"],
    tweetFields: ["created_at"],
  });

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(user.username);
    });
    // Les publications épinglées se trouvent dans page.includes?.tweets
  }
  ```
</CodeGroup>
