Ce guide vous explique comment ajouter et supprimer des membres d’une Liste.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin :

  * D’un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une application approuvée
  * D’un jeton d’accès utilisateur (OAuth 1.0a ou OAuth 2.0 PKCE)
  * D’une Liste dont vous êtes propriétaire
</Note>

***

<div id="add-a-member-to-a-list">
  ## Ajouter un membre à une Liste
</div>

<Steps>
  <Step title="Récupérer l’identifiant de la Liste et l’identifiant de l’utilisateur">
    Vous avez besoin de l’identifiant de votre Liste et de l’identifiant de l’utilisateur que vous souhaitez ajouter. Vous pouvez obtenir les identifiants des utilisateurs à l’aide du [user lookup endpoint](/fr/x-api/users/lookup/introduction).
  </Step>

  <Step title="Ajouter le membre">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/lists/1441162269824405510/members" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"user_id": "2244994945"}'
      ```

      ```python Python SDK
      from xdk import Client
      from xdk.oauth1_auth import OAuth1

      oauth1 = OAuth1(
          api_key="YOUR_API_KEY",
          api_secret="YOUR_API_SECRET",
          access_token="YOUR_ACCESS_TOKEN",
          access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
      )

      client = Client(auth=oauth1)

      # Ajouter un membre à une Liste
      response = client.lists.add_member(
          list_id="1441162269824405510",
          user_id="2244994945"
      )

      print(f"Is member: {response.data.is_member}")
      ```

      ```javascript JavaScript SDK
      import { Client, OAuth1 } from "@xdevplatform/xdk";

      const oauth1 = new OAuth1({
        apiKey: "YOUR_API_KEY",
        apiSecret: "YOUR_API_SECRET",
        accessToken: "YOUR_ACCESS_TOKEN",
        accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
      });

      const client = new Client({ oauth1 });

      // Ajouter un membre à une Liste
      const response = await client.lists.addMember("1441162269824405510", {
        userId: "2244994945",
      });

      console.log(`Is member: ${response.data?.is_member}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Examiner la réponse">
    ```json
    {
      "data": {
        "is_member": true
      }
    }
    ```
  </Step>
</Steps>

<div id="remove-a-member-from-a-list">
  ## Supprimer un membre d&#39;une liste
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/lists/1441162269824405510/members/2244994945" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Supprimer un membre d'une liste
  response = client.lists.remove_member(
      list_id="1441162269824405510",
      user_id="2244994945"
  )

  print(f"Est membre : {response.data.is_member}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Supprimer un membre d'une liste
  const response = await client.lists.removeMember(
    "1441162269824405510",
    "2244994945"
  );

  console.log(`Est membre : ${response.data?.is_member}`);
  ```
</CodeGroup>

**Réponse :**

```json
{
  "data": {
    "is_member": false
  }
}
```

***

<div id="important-notes">
  ## Remarques importantes
</div>

<Note>
  * Vous pouvez uniquement gérer les membres des Listes dont vous êtes le propriétaire
  * L’ajout d’un utilisateur à une Liste ne nécessite pas son autorisation
  * Les utilisateurs peuvent voir à quelles Listes publiques ils ont été ajoutés
</Note>
