Ce guide vous explique comment récupérer des publications à partir de la timeline d’une Liste.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin des éléments suivants :

  * Un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une App approuvée
  * Le Bearer Token de votre App
</Note>

***

<Steps>
  <Step title="Trouver l’ID d’une Liste" icon="list">
    Vous pouvez trouver l’ID d’une Liste dans l’URL lorsque vous consultez une Liste sur x.com :

    ```
    https://x.com/i/lists/84839422
                          └── Il s’agit de l’ID de la Liste
    ```
  </Step>

  <Step title="Récupérer la timeline de la Liste" icon="terminal">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/lists/84839422/tweets?\
      tweet.fields=created_at,public_metrics,author_id&\
      expansions=author_id&\
      user.fields=username,verified&\
      max_results=10" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Récupérer des publications d'une Liste avec pagination
      for page in client.lists.get_tweets(
          "84839422",
          tweet_fields=["created_at", "public_metrics", "author_id"],
          expansions=["author_id"],
          user_fields=["username", "verified"],
          max_results=10
      ):
          for post in page.data:
              print(f"{post.text[:50]}... - Likes: {post.public_metrics.like_count}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Récupérer des publications d'une Liste avec pagination
      const paginator = client.lists.getTweets("84839422", {
        tweetFields: ["created_at", "public_metrics", "author_id"],
        expansions: ["author_id"],
        userFields: ["username", "verified"],
        maxResults: 10,
      });

      for await (const page of paginator) {
        page.data?.forEach((post) => {
          console.log(`${post.text?.slice(0, 50)}... - Likes: ${post.public_metrics?.like_count}`);
        });
      }
      ```
    </CodeGroup>
  </Step>

  <Step title="Examiner la Réponse" icon="eye">
    ```json
    {
      "data": [
        {
          "id": "1458172421115101189",
          "text": "Check out our latest announcement...",
          "author_id": "4172587277",
          "created_at": "2024-01-15T10:30:00.000Z",
          "public_metrics": {
            "retweet_count": 42,
            "reply_count": 5,
            "like_count": 156,
            "quote_count": 3
          },
          "edit_history_tweet_ids": ["1458172421115101189"]
        }
      ],
      "includes": {
        "users": [
          {
            "id": "4172587277",
            "username": "TechNews",
            "verified": true
          }
        ]
      },
      "meta": {
        "result_count": 1,
        "next_token": "7140dibdnow9c7btw3z2vwioavpvutgzrzm9icis4ndix"
      }
    }
    ```
  </Step>

  <Step title="Paginer les résultats" icon="arrow-right">
    Les SDK gèrent la pagination automatiquement. Avec cURL, utilisez le `next_token` de la Réponse pour obtenir davantage de publications :

    ```bash
    curl "https://api.x.com/2/lists/84839422/tweets?\
    max_results=10&\
    pagination_token=7140dibdnow9c7btw3z2vwioavpvutgzrzm9icis4ndix" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>
</Steps>

<Note>
  Cet endpoint renvoie jusqu’à 800 des publications les plus récentes de la Liste.
</Note>
