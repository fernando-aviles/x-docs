L’endpoint List Posts vous permet de récupérer les Publications de la timeline d’une Liste. Obtenez les dernières Publications de tous les membres d’une Liste.

<div id="overview">
  ## Vue d’ensemble
</div>

<CardGroup cols={2}>
  <Card title="Fil de Liste" icon="list">
    Récupérez les Publications des membres de la Liste
  </Card>

  <Card title="Flux personnalisé" icon="stream">
    Accédez à vos flux de contenu personnalisés
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## Point de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/tweets`](/fr/x-api/lists/get-list-posts) | Récupérer les publications d&#39;une Liste |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/lists/1234567890/tweets?\
tweet.fields=created_at,author_id,public_metrics&\
expansions=author_id&\
user.fields=username&\
max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
