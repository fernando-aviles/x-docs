L’endpoint List Posts vous permet de récupérer des Publications à partir de la timeline d’une Liste. Récupérez les Publications les plus récentes de tous les membres d’une Liste.

<div id="overview">
  ## Vue d’ensemble
</div>

<CardGroup cols={2}>
  <Card title="Fil de liste" icon="list">
    Obtenez les publications des membres de la liste
  </Card>

  <Card title="Fil personnalisé" icon="stream">
    Accédez à vos fils de contenu personnalisés
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## Endpoint
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/tweets`](/fr/x-api/lists/get-list-posts) | Obtenir les Publications d&#39;une liste |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/lists/1234567890/tweets?\
tweet.fields=created_at,author_id,public_metrics&\
expansions=author_id&\
user.fields=username&\
max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
