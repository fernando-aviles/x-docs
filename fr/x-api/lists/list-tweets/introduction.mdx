Le point de terminaison List Posts permet de récupérer les Publications de la timeline d&#39;une List. Obtenez les Publications les plus récentes de tous les membres d&#39;une List.

<div id="overview">
  ## Vue d&#39;ensemble
</div>

<CardGroup cols={2}>
  <Card title="Fil de Liste" icon="list">
    Récupérez les publications des membres de la liste
  </Card>

  <Card title="Flux de contenu sélectionné" icon="stream">
    Accédez à vos flux de contenu sélectionnés
  </Card>
</CardGroup>

***

<div id="endpoint">
  ## Endpoint
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/lists/:id/tweets`](/fr/x-api/lists/get-list-posts) | Récupérer les publications d’une liste |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/lists/1234567890/tweets?\
tweet.fields=created_at,author_id,public_metrics&\
expansions=author_id&\
user.fields=username&\
max_results=100" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
