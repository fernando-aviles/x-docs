  ## Comparaison des endpoints de recherche de Publications de listes de X API
</div>

L’endpoint v2 de recherche de Publications de listes remplacera l’endpoint standard v1.1 [GET lists/statuses](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-statuses). Si vous avez du code, des applications ou des outils qui utilisent cette version de l’endpoint et que vous envisagez de migrer vers le nouvel endpoint X API v2, ces guides vous sont destinés.

Les tableaux suivants comparent les endpoints standard v1.1 et X API v2 pour les listes :

**Recherche de liste par identifiant**

|     |     |     |
| :--- | :--- | :--- |
| Description | v1.1 standard | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine de l’hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin de l’endpoint | `/1.1/lists/statuses.json` | `/2/lists/:id/tweets` |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App uniquement | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />App uniquement |
| Limites de fréquence de requêtes par défaut ([rate limits](/fr/resources/fundamentals/rate-limits)) | 900 requêtes par 15 min avec OAuth 1.0a<br /><br />900 requêtes par 15 min avec App uniquement | 900 requêtes par 15 min avec OAuth 1.0a<br /><br />900 requêtes par 15 min avec OAuth 2.0<br /><br />900 requêtes par 15 min avec App uniquement |

Pour accéder aux endpoints X API v2, vous devez [vous inscrire pour obtenir un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info). Lors de l’authentification, vous devez utiliser des clés et des jetons provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) qui se trouve dans un [Projet](/fr/resources/fundamentals/developer-apps). 

Pour en savoir plus sur l’accès aux endpoints X API v2, consultez notre page [mise en route](/fr/x-api/getting-started/getting-access).
