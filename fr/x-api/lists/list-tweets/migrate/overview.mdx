  ## Comparaison des points de terminaison de recherche de Publications de Liste de X API
</div>

Le point de terminaison de recherche de Publications de Liste v2 remplacera le point de terminaison standard v1.1 [GET lists/statuses](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-statuses). Si vous disposez de code, d&#39;applications ou d&#39;outils qui utilisent cette version du point de terminaison et que vous envisagez de migrer vers le nouveau point de terminaison X API v2, cet ensemble de guides est fait pour vous.

Les tableaux suivants comparent les points de terminaison de Liste standard v1.1 et X API v2 :

**Recherche de Liste par ID**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin du point de terminaison | `/1.1/lists/statuses.json` | `/2/lists/:id/tweets` |
| [Authentification](/fr/resources/fundamentals/authentication) | Contexte utilisateur OAuth 1.0a<br /><br />App uniquement | Contexte utilisateur OAuth 1.0a<br /><br />Code d&#39;autorisation OAuth 2.0 avec PKCE<br /><br />App uniquement |
| [Limites de taux](/fr/resources/fundamentals/rate-limits) de requête par défaut | 900 requêtes par 15 min avec OAuth 1.0a<br /><br />900 requêtes par 15 min avec App uniquement | 900 requêtes par 15 min avec OAuth 1.0a<br /><br />900 requêtes par 15 min avec OAuth 2.0<br /><br />900 requêtes par 15 min avec App uniquement |

Pour accéder aux points de terminaison X API v2, vous devez [créer un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info). Lors de l&#39;authentification, vous devez utiliser des clés et des jetons provenant d&#39;une [App développeur](/fr/resources/fundamentals/developer-apps) située dans un [Projet](/fr/resources/fundamentals/developer-apps).

Pour en savoir plus sur l&#39;accès aux points de terminaison X API v2, consultez notre page de [prise en main](/fr/x-api/getting-started/getting-access).
