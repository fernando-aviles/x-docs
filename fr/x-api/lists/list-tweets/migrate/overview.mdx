  ## Comparaison des points de terminaison de recherche des publications de liste de X API
</div>

Le point de terminaison v2 de recherche des publications de liste remplacera le point de terminaison standard v1.1 [GET lists/statuses](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-statuses). Si vous avez du code, des applications ou des outils qui utilisent cette version du point de terminaison et que vous envisagez de migrer vers le nouveau point de terminaison X API v2, alors cette série de guides est faite pour vous.

Les tableaux suivants comparent les points de terminaison de listes standard v1.1 et X API v2 :

**Recherche de liste par ID**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine d’hébergement | `https://api.x.com` | `https://api.x.com` |
| Chemin du point de terminaison | `/1.1/lists/statuses.json` | `/2/lists/:id/tweets` |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App uniquement | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />App uniquement |
| [Limites de débit](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 900 requêtes par 15 min avec OAuth 1.0a<br /><br />900 requêtes par 15 min avec App uniquement | 900 requêtes par 15 min avec OAuth 1.0a<br /><br />900 requêtes par 15 min avec OAuth 2.0<br /><br />900 requêtes par 15 min avec App uniquement |

Pour accéder aux points de terminaison X API v2, vous devez [vous inscrire pour obtenir un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info). Lors de l’authentification, vous devez utiliser des clés et des tokens provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) qui se trouve au sein d’un [Projet](/fr/resources/fundamentals/developer-apps). 

Pour en savoir plus sur l’accès aux points de terminaison X API v2, consultez notre page [prise en main](/fr/x-api/getting-started/getting-access).
