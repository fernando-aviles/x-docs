Les endpoints Pinned Lists vous permettent de consulter, d’épingler et de désépingler des Listes pour l’utilisateur authentifié. Les Listes épinglées sont mises en avant dans l’interface X de l’utilisateur.

<div id="endpoints">
  ## Points de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/pinned_lists`](/fr/x-api/users/get-pinned-lists) | Obtenir les Listes épinglées |
| POST | [`/2/users/:id/pinned_lists`](/fr/x-api/users/pin-list) | Épingler une Liste |
| DELETE | [`/2/users/:id/pinned_lists/:list_id`](/fr/x-api/users/unpin-list) | Désépingler une Liste |

***

<div id="example-get-pinned-lists">
  ## Exemple : obtenir les Listes épinglées
</div>

```bash
curl "https://api.x.com/2/users/123456789/pinned_lists?\
list.fields=name,description,member_count" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-pin-a-list">
  ## Exemple : épingler une liste
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/pinned_lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"list_id": "9876543210"}'
```
