Ce guide vous explique comment récupérer les Listes épinglées d&#39;un utilisateur.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin de :

  * D&#39;un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une application approuvée
  * D&#39;un jeton d&#39;accès utilisateur (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

***

<div id="get-pinned-lists">
  ## Récupérer les listes épinglées
</div>

<Steps>
  <Step title="Obtenir votre ID utilisateur">
    Vous avez besoin de l’id de l’utilisateur authentifié. Vous pouvez l’obtenir à l’aide de l’[endpoint de recherche d’utilisateurs](/fr/x-api/users/lookup/introduction) ou à partir de votre Access Token (la partie numérique correspond à votre id utilisateur).
  </Step>

  <Step title="Récupérer les listes épinglées">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/users/2244994945/pinned_lists?\
      list.fields=follower_count,member_count,owner_id&\
      expansions=owner_id&\
      user.fields=created_at,username" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Récupérer les listes épinglées
      response = client.lists.get_pinned(
          "2244994945",
          list_fields=["follower_count", "member_count", "owner_id"],
          expansions=["owner_id"],
          user_fields=["created_at", "username"]
      )

      for lst in response.data:
          print(f"{lst.name} - {lst.follower_count} abonnés")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Récupérer les listes épinglées
      const response = await client.lists.getPinned("2244994945", {
        listFields: ["follower_count", "member_count", "owner_id"],
        expansions: ["owner_id"],
        userFields: ["created_at", "username"],
      });

      response.data?.forEach((lst) => {
        console.log(`${lst.name} - ${lst.follower_count} abonnés`);
      });
      ```
    </CodeGroup>
  </Step>

  <Step title="Examiner la réponse">
    ```json
    {
      "data": [
        {
          "id": "1454155907651158017",
          "name": "Tech News",
          "follower_count": 150,
          "member_count": 25,
          "owner_id": "2244994945"
        }
      ],
      "includes": {
        "users": [
          {
            "id": "2244994945",
            "username": "XDevelopers",
            "name": "X Developers",
            "created_at": "2013-12-14T04:35:55.000Z"
          }
        ]
      },
      "meta": {
        "result_count": 1
      }
    }
    ```
  </Step>
</Steps>

<div id="available-list-fields">
  ## Champs de liste disponibles
</div>

| Champ | Description |
|:------|:------------|
| `description` | Description de la liste |
| `owner_id` | ID utilisateur du propriétaire |
| `private` | Indique si la liste est privée |
| `member_count` | Nombre de membres |
| `follower_count` | Nombre d&#39;abonnés |
| `created_at` | Date de création de la liste |
