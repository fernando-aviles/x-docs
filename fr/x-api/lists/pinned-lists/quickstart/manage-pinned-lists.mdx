Ce guide vous explique comment épingler et désépingler des Listes.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin de :

  * Un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une application approuvée
  * Un jeton d’accès utilisateur (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

***

<div id="pin-a-list">
  ## Épingler une Liste
</div>

<Steps>
  <Step title="Obtenir votre identifiant d’utilisateur et l’identifiant de la Liste">
    Vous avez besoin de l’identifiant de l’utilisateur authentifié et de l’identifiant de la Liste que vous souhaitez épingler. Vous pouvez trouver les identifiants des Listes dans l’URL lorsque vous consultez une Liste.
  </Step>

  <Step title="Épingler la Liste">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/users/2244994945/pinned_lists" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"list_id": "1454155907651158017"}'
      ```

      ```python Python SDK
      from xdk import Client
      from xdk.oauth1_auth import OAuth1

      oauth1 = OAuth1(
          api_key="YOUR_API_KEY",
          api_secret="YOUR_API_SECRET",
          access_token="YOUR_ACCESS_TOKEN",
          access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
      )

      client = Client(auth=oauth1)

      # Épingler une Liste
      response = client.lists.pin(
          user_id="2244994945",
          list_id="1454155907651158017"
      )

      print(f"Pinned: {response.data.pinned}")
      ```

      ```javascript JavaScript SDK
      import { Client, OAuth1 } from "@xdevplatform/xdk";

      const oauth1 = new OAuth1({
        apiKey: "YOUR_API_KEY",
        apiSecret: "YOUR_API_SECRET",
        accessToken: "YOUR_ACCESS_TOKEN",
        accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
      });

      const client = new Client({ oauth1 });

      // Épingler une Liste
      const response = await client.lists.pin("2244994945", {
        listId: "1454155907651158017",
      });

      console.log(`Pinned: ${response.data?.pinned}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Vérifier la réponse">
    ```json
    {
      "data": {
        "pinned": true
      }
    }
    ```
  </Step>
</Steps>

<div id="unpin-a-list">
  ## Retirer une Liste des épinglés
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/2244994945/pinned_lists/1454155907651158017" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Retirer une Liste des épinglés
  response = client.lists.unpin(
      user_id="2244994945",
      list_id="1454155907651158017"
  )

  print(f"Épinglée : {response.data.pinned}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Retirer une Liste des épinglés
  const response = await client.lists.unpin("2244994945", "1454155907651158017");

  console.log(`Épinglée : ${response.data?.pinned}`);
  ```
</CodeGroup>

**Réponse :**

```json
{
  "data": {
    "pinned": false
  }
}
```

<div id="important-notes">
  ## Remarques importantes
</div>

<Note>
  * Vous pouvez uniquement épingler des listes que vous suivez ou dont vous êtes le propriétaire
  * Les listes épinglées apparaissent en haut de vos listes dans l&#39;application X
  * Vous ne pouvez épingler qu&#39;un nombre limité de listes
</Note>
