<div id="comparing-x-apis-list-lookup-endpoints">
  ## Comparaison des endpoints de recherche de List dans X API
</div>

Le groupe d&#39;endpoints de recherche de List de la v2 remplacera les endpoints standards v1.1 [GET lists/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-show) et [GET lists/ownership](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-ownerships). Si vous avez du code, des applications ou des outils qui utilisent l&#39;une de ces versions des endpoints de recherche de List et que vous envisagez de migrer vers le nouvel endpoint X API v2, alors cette série de guides est faite pour vous.

Les tableaux suivants comparent les endpoints List standard v1.1 et X API v2 :

**Recherche de List par ID**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin d&#39;endpoint | `/1.1/lists/show.json` | `/2/lists/:id` |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App only | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />App only |
| Limites de débit des requêtes par défaut ([rate limits](/fr/resources/fundamentals/rate-limits)) | 75 requêtes par 15 min avec OAuth 1.0a<br /><br />75 requêtes par 15 min avec OAuth 2.0<br /><br />75 requêtes par 15 min avec App only | 75 requêtes par 15 min avec OAuth 1.0a<br /><br />75 requêtes par 15 min avec OAuth 2.0<br /><br />75 requêtes par 15 min avec App only |

**Recherche de List appartenant à un utilisateur**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin d&#39;endpoint | `/1.1/lists/ownerships.json` | `/2/users/:id/owned_lists` |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App only | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code avec PKCE<br /><br />App only |
| Limites de débit des requêtes par défaut ([rate limits](/fr/resources/fundamentals/rate-limits)) | 15 requêtes par 15 min avec OAuth 1.0a<br /><br />15 requêtes par 15 min avec App only | 15 requêtes par 15 min avec OAuth 1.0a<br /><br />15 requêtes par 15 min avec OAuth 2.0<br /><br />15 requêtes par 15 min avec App only |

Pour accéder aux endpoints X API v2, vous devez [créer un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info). Pour l&#39;authentification, vous devez utiliser des clés et des tokens provenant d&#39;une [App développeur](/fr/resources/fundamentals/developer-apps) qui se trouve dans un [Projet](/fr/resources/fundamentals/developer-apps).

Pour en savoir plus sur l&#39;obtention de l&#39;accès aux endpoints X API v2, consultez notre page [guide de démarrage](/fr/x-api/getting-started/getting-access).
