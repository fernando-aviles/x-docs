<div id="comparing-x-apis-list-lookup-endpoints">
  ## Comparaison des endpoints de recherche de listes de X API
</div>

Le groupe d’endpoints de recherche de listes v2 remplacera les endpoints standard v1.1 [GET lists/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-show) et [GET lists/ownership](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-ownerships). Si vous avez du code, des apps ou des outils qui utilisent l’une de ces versions des endpoints de recherche de listes et que vous envisagez de migrer vers le nouvel endpoint X API v2, alors cet ensemble de guides est pour vous.

Les tableaux suivants comparent les endpoints de liste standard v1.1 et X API v2 :

**Recherche de liste par ID**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| HTTP methods supported | `GET` | `GET` |
| Host domain | `https://api.x.com` | `https://api.x.com` |
| Endpoint path | `/1.1/lists/show.json` | `/2/lists/:id` |
| [Authentication](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App uniquement | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />App uniquement |
| Default request [rate limits](/fr/resources/fundamentals/rate-limits) | 75 requêtes par 15 min avec OAuth 1.0a<br /><br />75 requêtes par 15 min avec OAuth 2.0<br /><br />75 requêtes par 15 min avec App uniquement | 75 requêtes par 15 min avec OAuth 1.0a<br /><br />75 requêtes par 15 min avec OAuth 2.0<br /><br />75 requêtes par 15 min avec App uniquement |

**Recherche de listes appartenant à l’utilisateur**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| HTTP methods supported | `GET` | `GET` |
| Host domain | `https://api.x.com` | `https://api.x.com` |
| Endpoint path | `/1.1/lists/ownerships.json` | `/2/users/:id/owned_lists` |
| [Authentication](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App uniquement | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />App uniquement |
| Default request [rate limits](/fr/resources/fundamentals/rate-limits) | 15 requêtes par 15 min avec OAuth 1.0a<br /><br />15 requêtes par 15 min avec App uniquement | 15 requêtes par 15 min avec OAuth 1.0a<br /><br />15 requêtes par 15 min avec OAuth 2.0<br /><br />15 requêtes par 15 min avec App uniquement |

Pour accéder aux endpoints X API v2, vous devez [vous inscrire pour obtenir un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info). Lors de l’authentification, vous devez utiliser des clés et des jetons provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) située au sein d’un [Projet](/fr/resources/fundamentals/developer-apps).

Pour en savoir plus sur l’accès aux endpoints X API v2, consultez notre page de [prise en main](/fr/x-api/getting-started/getting-access).
