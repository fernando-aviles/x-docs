  ## Comparaison des points de terminaison de consultation de Liste de X API
</div>

Le groupe de points de terminaison de consultation de Liste v2 remplacera les points de terminaison standard v1.1 [GET lists/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-show) et [GET lists/ownership](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-ownerships). Si vous avez du code, des applications ou des outils qui utilisent l&#39;une de ces versions des points de terminaison de consultation de Liste, et que vous envisagez de migrer vers le point de terminaison X API v2 plus récent, cet ensemble de guides est fait pour vous.

Les tableaux suivants comparent les points de terminaison de Liste standard v1.1 et X API v2 :

**Consultation de Liste par ID**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin du point de terminaison | `/1.1/lists/show.json` | `/2/lists/:id` |
| [Authentification](/fr/resources/fundamentals/authentication) | Contexte utilisateur OAuth 1.0a<br /><br />App uniquement | Contexte utilisateur OAuth 1.0a<br /><br />Code d&#39;autorisation OAuth 2.0 avec PKCE<br /><br />App uniquement |
| [Limites de taux](/fr/resources/fundamentals/rate-limits) de requête par défaut | 75 requêtes par 15 min avec OAuth 1.0a<br /><br />75 requêtes par 15 min avec OAuth 2.0<br /><br />75 requêtes par 15 min avec App uniquement | 75 requêtes par 15 min avec OAuth 1.0a<br /><br />75 requêtes par 15 min avec OAuth 2.0<br /><br />75 requêtes par 15 min avec App uniquement |

**Consultation de Liste détenue par l&#39;utilisateur**

|     |     |     |
| :--- | :--- | :--- |
| Description | Standard v1.1 | X API v2 |
| Méthodes HTTP prises en charge | `GET` | `GET` |
| Domaine hôte | `https://api.x.com` | `https://api.x.com` |
| Chemin du point de terminaison | `/1.1/lists/ownerships.json` | `/2/users/:id/owned_lists` |
| [Authentification](/fr/resources/fundamentals/authentication) | Contexte utilisateur OAuth 1.0a<br /><br />App uniquement | Contexte utilisateur OAuth 1.0a<br /><br />Code d&#39;autorisation OAuth 2.0 avec PKCE<br /><br />App uniquement |
| [Limites de taux](/fr/resources/fundamentals/rate-limits) de requête par défaut | 15 requêtes par 15 min avec OAuth 1.0a<br /><br />15 requêtes par 15 min avec App uniquement | 15 requêtes par 15 min avec OAuth 1.0a<br /><br />15 requêtes par 15 min avec OAuth 2.0<br /><br />15 requêtes par 15 min avec App uniquement |

Pour accéder aux points de terminaison X API v2, vous devez [créer un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info). Lors de l&#39;authentification, vous devez utiliser les clés et jetons d&#39;une [App développeur](/fr/resources/fundamentals/developer-apps) située dans un [Projet](/fr/resources/fundamentals/developer-apps).

Pour en savoir plus sur l&#39;accès aux points de terminaison X API v2, consultez notre page [premiers pas](/fr/x-api/getting-started/getting-access).
