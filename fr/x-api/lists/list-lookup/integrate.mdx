<div id="authentication">
  ## Authentification
</div>

Les points de terminaison de recherche de Listes prennent en charge plusieurs méthodes d’authentification :

| Méthode | Idéal pour | Accès aux Listes privées ? |
|:--------|:-----------|:---------------------------|
| [OAuth 2.0 App-Only](/fr/resources/fundamentals/authentication#oauth-2-0) | Données de Listes publiques | Non |
| [OAuth 2.0 Authorization Code with PKCE](/fr/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | Applications destinées aux utilisateurs | Oui (possédées ou suivies) |
| [OAuth 1.0a User Context](/fr/resources/fundamentals/authentication) | Anciennes intégrations | Oui (possédées ou suivies) |

<div id="example-request">
  ### Exemple de requête
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/84839422?\
  list.fields=description,member_count,follower_count,private" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python SDK Python
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer une liste par id
  response = client.lists.get(
      list_id="84839422",
      list_fields=["description", "member_count", "follower_count", "private"]
  )
  print(response.data)
  ```

  ```javascript SDK JavaScript
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  const response = await client.lists.get("84839422", {
    listFields: ["description", "member_count", "follower_count", "private"],
  });
  console.log(response.data);
  ```
</CodeGroup>

<div id="available-fields">
  ### Champs disponibles
</div>

<Accordion title="list.fields">
  | Champ | Description |
  |:------|:------------|
  | `created_at` | Horodatage de création de la liste |
  | `description` | Description de la liste |
  | `follower_count` | Nombre d’abonnés |
  | `member_count` | Nombre de membres |
  | `owner_id` | id utilisateur du propriétaire |
  | `private` | Indique si la liste est privée |
</Accordion>

<Accordion title="user.fields (requires owner_id expansion)">
  | Champ | Description |
  |:------|:------------|
  | `username` | Identifiant @ du propriétaire |
  | `name` | Nom d’affichage du propriétaire |
  | `verified` | Statut de vérification du propriétaire |
  | `profile_image_url` | URL de l’avatar du propriétaire |
</Accordion>

<div id="example-with-expansions">
  ### Exemple avec expansions
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/84839422?\
  list.fields=description,member_count,follower_count,owner_id&\
  expansions=owner_id&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python SDK Python
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer une liste avec l'expansion du propriétaire
  response = client.lists.get(
      list_id="84839422",
      list_fields=["description", "member_count", "follower_count", "owner_id"],
      expansions=["owner_id"],
      user_fields=["username", "verified"]
  )

  print(response.data)
  print(response.includes)  # Contient l'objet utilisateur du propriétaire
  ```

  ```javascript SDK JavaScript
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  const response = await client.lists.get("84839422", {
    listFields: ["description", "member_count", "follower_count", "owner_id"],
    expansions: ["owner_id"],
    userFields: ["username", "verified"],
  });

  console.log(response.data);
  console.log(response.includes); // Contient l'objet utilisateur du propriétaire
  ```
</CodeGroup>

<div id="pagination">
  ## Pagination
</div>

Lors de la récupération des listes dont vous êtes propriétaire, les résultats sont paginés :

<CodeGroup dropdown>
  ```bash cURL
  # Première requête
  curl "https://api.x.com/2/users/123/owned_lists?max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"

  # Requête suivante avec jeton de pagination
  curl "https://api.x.com/2/users/123/owned_lists?max_results=100&pagination_token=NEXT_TOKEN" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Le SDK gère la pagination automatiquement
  all_lists = []

  for page in client.lists.get_user_owned_lists(user_id="123", max_results=100):
      if page.data:
          all_lists.extend(page.data)

  print(f"{len(all_lists)} listes trouvées")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  async function getAllOwnedLists(userId) {
    const allLists = [];

    // Le SDK gère la pagination automatiquement
    const paginator = client.lists.getUserOwnedLists(userId, { maxResults: 100 });

    for await (const page of paginator) {
      if (page.data) {
        allLists.push(...page.data);
      }
    }

    return allLists;
  }

  // Utilisation
  const lists = await getAllOwnedLists("123");
  console.log(`${lists.length} listes trouvées`);
  ```
</CodeGroup>

<div id="private-lists">
  ## Listes privées
</div>

* Les listes privées ne sont visibles que par leur propriétaire
* Vous devez vous authentifier en tant que propriétaire pour récupérer les détails d’une liste privée
* Le champ `private` indique si une liste est privée

***

<div id="error-handling">
  ## Gestion des erreurs
</div>

| Statut | Erreur | Solution |
|:-------|:------|:---------|
| 400 | Requête invalide | Vérifiez le format de l’id de liste |
| 401 | Non autorisé | Vérifiez l’authentification |
| 403 | Interdit | La liste est peut-être privée |
| 404 | Introuvable | La liste n’existe pas |
| 429 | Trop de requêtes | Attendez et réessayez |
