Les endpoints de recherche de List vous permettent de récupérer des informations sur les List. Recherchez une List spécifique par ID ou récupérez toutes les List détenues par un utilisateur.

<div id="endpoints">
  ## Points de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------------------|:------------|
| GET | [`/2/lists/:id`](/fr/x-api/lists/get-list-by-id) | Récupérer une liste par identifiant |
| GET | [`/2/users/:id/owned_lists`](/fr/x-api/users/get-owned-lists) | Récupérer les listes appartenant à un utilisateur |

***

<div id="response-fields">
  ## Champs de réponse
</div>

Par défaut, la réponse inclut `id` et `name`. Pour demander des champs supplémentaires :

| Champ | Description |
|:------|:------------|
| `description` | Description de la Liste |
| `owner_id` | ID utilisateur du propriétaire |
| `private` | Indique si la Liste est privée |
| `follower_count` | Nombre d’abonnés |
| `member_count` | Nombre de membres |
| `created_at` | Date de création de la Liste |

<div id="example-request">
  ### Exemple de requête
</div>

```bash
curl "https://api.x.com/2/lists/1234567890?\
list.fields=description,owner_id,member_count,follower_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
