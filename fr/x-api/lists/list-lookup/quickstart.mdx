Ce guide vous explique comment consulter les informations d’une List à l’aide des endpoints de recherche de List.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin de :

  * D’un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une App approuvée
  * Du Bearer Token de votre App
</Note>

***

<div id="get-a-list-by-id">
  ## Obtenir une liste par ID
</div>

Récupérer les détails d’une liste spécifique :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/1234567890?\
  list.fields=description,owner_id,member_count,follower_count,private,created_at" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtenir une liste par ID
  response = client.lists.get(
      "1234567890",
      list_fields=["description", "owner_id", "member_count", "follower_count", "private", "created_at"]
  )

  print(f"List: {response.data.name}")
  print(f"Members: {response.data.member_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtenir une liste par ID
  const response = await client.lists.get("1234567890", {
    listFields: ["description", "owner_id", "member_count", "follower_count", "private", "created_at"],
  });

  console.log(`List: ${response.data?.name}`);
  console.log(`Members: ${response.data?.member_count}`);
  ```
</CodeGroup>

<div id="get-lists-owned-by-a-user">
  ## Récupérer les listes appartenant à un utilisateur
</div>

Récupérez toutes les listes appartenant à un utilisateur spécifique :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/2244994945/owned_lists?\
  list.fields=description,member_count,follower_count&\
  max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer les listes appartenant à un utilisateur avec pagination
  for page in client.lists.get_owned_lists(
      "2244994945",
      list_fields=["description", "member_count", "follower_count"],
      max_results=100
  ):
      for lst in page.data:
          print(f"{lst.name} - {lst.member_count} membres")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérer les listes appartenant à un utilisateur avec pagination
  const paginator = client.lists.getOwnedLists("2244994945", {
    listFields: ["description", "member_count", "follower_count"],
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((lst) => {
      console.log(`${lst.name} - ${lst.member_count} membres`);
    });
  }
  ```
</CodeGroup>

<div id="include-owner-information">
  ## Inclure les informations sur le propriétaire
</div>

Étendez les données utilisateur du propriétaire :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/lists/1234567890?\
  list.fields=description,owner_id&\
  expansions=owner_id&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérez la liste avec les informations sur le propriétaire
  response = client.lists.get(
      "1234567890",
      list_fields=["description", "owner_id"],
      expansions=["owner_id"],
      user_fields=["username", "verified"]
  )

  print(f"List: {response.data.name}")
  # Les informations sur le propriétaire se trouvent dans response.includes.users
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérez la liste avec les informations sur le propriétaire
  const response = await client.lists.get("1234567890", {
    listFields: ["description", "owner_id"],
    expansions: ["owner_id"],
    userFields: ["username", "verified"],
  });

  console.log(`List: ${response.data?.name}`);
  // Les informations sur le propriétaire se trouvent dans response.includes?.users
  ```
</CodeGroup>

<div id="available-fields">
  ## Champs disponibles
</div>

| Champ | Description |
|:------|:------------|
| `description` | Description de la Liste |
| `owner_id` | ID de l’utilisateur propriétaire |
| `private` | Indique si la Liste est privée |
| `member_count` | Nombre de membres |
| `follower_count` | Nombre d’abonnés |
| `created_at` | Date de création de la Liste |
