Les endpoints Batch Compliance vous permettent de téléverser des jeux de données d’id de Publications ou d’id d’utilisateurs et d’obtenir leur état de conformité actuel. Utilisez-les pour identifier les Publications supprimées, les comptes suspendus et d’autres événements de conformité.

<div id="how-it-works">
  ## Fonctionnement
</div>

1. **Créer un job** — Indiquez le type (Publications ou utilisateurs) et l’URL de téléversement
2. **Téléverser les ID** — Téléversez votre jeu de données vers l’URL fournie
3. **Attendre le traitement** — Le job est traité de manière asynchrone
4. **Télécharger les résultats** — Obtenez l’état de conformité pour chaque ID

  ## Points de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------|:------------|

| GET | [`/2/compliance/jobs/:id`](/fr/x-api/compliance/get-compliance-job-by-id) | Consulter l’état d’un job |
| GET | [`/2/compliance/jobs`](/fr/x-api/compliance/get-compliance-jobs) | Répertorier tous les jobs |

<div id="job-types">
  ## Types de tâches
</div>

| Type | Description |
|:-----|:------------|
| `tweets` | Vérifier l&#39;état de conformité des Publications |
| `users` | Vérifier l&#39;état de conformité des utilisateurs |

***

<div id="compliance-events">
  ## Événements de conformité
</div>

<div id="post-events">
  ### Événements de Publication
</div>

| Événement | Description |
|:------|:------------|
| `deleted` | Publication supprimée par l’utilisateur |
| `bounced` | Publication n’a pas passé le contrôle de conformité |
| `protected` | Compte passé en mode protégé |
| `suspended` | Compte suspendu |
| `scrub_geo` | Données de géolocalisation supprimées |

<div id="user-events">
  ### Événements utilisateur
</div>

| Événement | Description |
|:------|:------------|
| `deleted` | Le compte a été supprimé |
| `suspended` | Le compte a été suspendu |
| `protected` | Le compte est devenu protégé |
| `deactivated` | Le compte a été désactivé |

***

<div id="example-create-a-job">
  ## Exemple : création d’un job
</div>

```bash
curl -X POST "https://api.x.com/2/compliance/jobs" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "tweets",
    "name": "my-compliance-job"
  }'
```
