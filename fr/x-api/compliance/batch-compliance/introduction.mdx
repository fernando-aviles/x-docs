Les endpoints Batch Compliance vous permettent de téléverser des ensembles d’ID de Publication ou d’ID d’utilisateur et de recevoir leur statut de conformité actuel. Utilisez-les pour identifier les Publications supprimées, les comptes suspendus et d’autres événements de conformité.

<div id="how-it-works">
  ## Fonctionnement
</div>

1. **Créer une tâche** — Spécifiez le type (Publications ou utilisateurs) et l’URL de téléversement
2. **Téléverser les identifiants** — Téléversez votre jeu de données vers l’URL fournie
3. **Attendre le traitement** — La tâche est traitée de manière asynchrone
4. **Télécharger les résultats** — Récupérez l’état de conformité pour chaque identifiant

***

<div id="endpoints">
  ## Points de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------------------|:------------|
| POST | [`/2/compliance/jobs`](/fr/x-api/compliance/create-compliance-job) | Créer une nouvelle tâche de conformité |
| GET | [`/2/compliance/jobs/:id`](/fr/x-api/compliance/get-compliance-job-by-id) | Obtenir l&#39;état de la tâche |
| GET | [`/2/compliance/jobs`](/fr/x-api/compliance/get-compliance-jobs) | Lister toutes les tâches |

***

<div id="job-types">
  ## Types de tâches
</div>

| Type | Description |
|:-----|:------------|
| `tweets` | Vérifier le statut de conformité des publications |
| `users` | Vérifier le statut de conformité des utilisateurs |

***

<div id="compliance-events">
  ## Événements de conformité
</div>

<div id="post-events">
  ### Événements liés aux publications
</div>

| Event | Description |
|:------|:------------|
| `deleted` | Publication supprimée par l’utilisateur |
| `bounced` | La publication a échoué à la vérification de conformité |
| `protected` | Le compte est passé en mode protégé |
| `suspended` | Le compte a été suspendu |
| `scrub_geo` | Les données de géolocalisation ont été supprimées |

<div id="user-events">
  ### Événements utilisateur
</div>

| Événement | Description |
|:------|:------------|
| `deleted` | Le compte a été supprimé |
| `suspended` | Le compte a été suspendu |
| `protected` | Le compte est passé en mode protégé |
| `deactivated` | Le compte a été désactivé |

***

<div id="example-create-a-job">
  ## Exemple : Créer une tâche
</div>

```bash
curl -X POST "https://api.x.com/2/compliance/jobs" \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "tweets",
    "name": "my-compliance-job"
  }'
```
