X s’engage auprès de notre communauté de développeurs qui créent avec X API. Dans le cadre de cet engagement, nous visons à rendre notre API ouverte et équitable pour les développeurs, sûre pour les personnes sur X et bénéfique pour la plateforme X dans son ensemble. Il est crucial que tout développeur qui stocke du contenu X hors ligne s’assure que les données reflètent l’intention de l’utilisateur et l’état actuel du contenu sur X. Par exemple, lorsqu’une personne sur X supprime une Publication ou son compte, protège ses Publications ou modifie une Publication, il est essentiel, pour X comme pour nos développeurs, de respecter les attentes et l’intention de cette personne.

Les flux en temps réel d’événements de conformité fournissent aux développeurs les outils nécessaires pour maintenir les données de X en conformité avec le [X Developer Agreement and Policy](https://developer.x.com/en/developer-terms/policy). 

Il existe deux flux d’événements de c&#95;ompliance&#95;, l’un pour les événements de Post&#95; compliance&#95; et l’autre pour les événements de *conformité des utilisateurs*. Ces flux sont disponibles avec un accès Enterprise et sont conçus pour aider les partenaires qui ingèrent de grands volumes de données à « écouter » les événements de conformité, tels que les événements de modification de Publication.

Ces flux fournissent les événements suivants : 

**Flux de conformité des Publications : **

* delete - indique que la Publication a été supprimée.

* tweet&#95;edit - indique qu’une Publication a été modifiée et fournit l’id de la Publication mise à jour. 

* withheld - indique que la Publication a été retenue dans un ou plusieurs pays. 

* drop - indique que la Publication doit être retirée de l’affichage public.

* undrop - indique que la Publication peut à nouveau être affichée et traitée comme publique.

**Flux de conformité des utilisateurs : **

* **user&#95;delete** - indique que le compte utilisateur a été supprimé

* **user&#95;undelete** - indique que le compte utilisateur a été restauré

* **user&#95;protect** - indique que le compte utilisateur est devenu privé

* **user&#95;unprotect** - indique que le compte utilisateur est redevenu public

* **user&#95;withheld** - indique que le compte utilisateur a été retenu dans un ou plusieurs pays. 

* **user&#95;suspend** - indique que le compte utilisateur a été suspendu

* **user&#95;unsuspend** - indique que le compte utilisateur a été rétabli

* **user&#95;profile&#95;modification** - indique que le profil utilisateur a été mis à jour. Cela inclut une description, un nom, une localisation et une URL mis à jour.

**Configuration du compte**

Pour accéder à ces endpoints, vous aurez besoin de :

* D’un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) approuvé.
* De vous authentifier à l’aide des clés et jetons d’une [App développeur](/fr/resources/fundamentals/developer-apps) qui se trouve dans un [Projet](/fr/resources/fundamentals/developer-apps). 

Pour en savoir plus sur l’accès aux endpoints X API v2, consultez notre [guide de démarrage](/fr/x-api/getting-started/getting-access).
