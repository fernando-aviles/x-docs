Les endpoints Likes vous permettent d’ajouter ou de retirer des mentions J’aime sur des Publications, de voir quels utilisateurs ont aimé une Publication et de récupérer les Publications aimées par un utilisateur.

<div id="endpoints">
  ## Points de terminaison
</div>

<div id="likes-lookup">
  ### Recherche des mentions « J’aime »
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/liking_users`](/fr/x-api/posts/get-liking-users) | Obtenir la liste des utilisateurs qui ont aimé une Publication |
| GET | [`/2/users/:id/liked_tweets`](/fr/x-api/users/get-liked-posts) | Obtenir les Publications qu’un utilisateur a aimées |

<div id="manage-likes">
  ### Gérer les mentions J’aime
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/likes`](/fr/x-api/users/like-post) | Aimer une Publication |
| DELETE | [`/2/users/:id/likes/:tweet_id`](/fr/x-api/users/unlike-post) | Retirer son J’aime d’une Publication |

***

<div id="important-notes">
  ## Notes importantes
</div>

<Note>
  Le endpoint liking users renvoie au maximum **100 utilisateurs** par Publication sur l&#39;ensemble de la période, quel que soit le nombre réel de mentions « J&#39;aime ».
</Note>

***

<div id="example-get-liking-users">
  ## Exemple : Récupérer les utilisateurs qui ont aimé une publication
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890/liking_users?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-like-a-post">
  ## Exemple : aimer une Publication
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
