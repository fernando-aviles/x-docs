Les endpoints Likes vous permettent d’ajouter ou de retirer une mention J’aime à des Publications, de voir quels utilisateurs ont aimé une Publication et de récupérer les Publications qu’un utilisateur a aimées.

<div id="endpoints">
  ## Points de terminaison de l’API
</div>

<div id="likes-lookup">
  ### Consultation des mentions J’aime
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/liking_users`](/fr/x-api/posts/get-liking-users) | Récupérer les utilisateurs qui ont aimé une publication |
| GET | [`/2/users/:id/liked_tweets`](/fr/x-api/users/get-liked-posts) | Récupérer les publications aimées par un utilisateur |

<div id="manage-likes">
  ### Gérer les J’aime
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/likes`](/fr/x-api/users/like-post) | Aimer une publication |
| DELETE | [`/2/users/:id/likes/:tweet_id`](/fr/x-api/users/unlike-post) | Retirer le J’aime d’une publication |

***

<div id="important-notes">
  ## Remarques importantes
</div>

<Note>
  Le point de terminaison liking users renvoie un maximum de **100 utilisateurs** par Publication sur l’ensemble de sa durée de vie, quel que soit le nombre réel de mentions « J’aime ».
</Note>

***

<div id="example-get-liking-users">
  ## Exemple : Récupérer les utilisateurs ayant aimé
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890/liking_users?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-like-a-post">
  ## Exemple : Aimer une publication
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
