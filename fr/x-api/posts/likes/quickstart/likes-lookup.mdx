Ce guide vous explique comment récupérer les données de mentions J’aime à l’aide de la X API.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin de :

  * D’un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une App approuvée
  * Du Jeton Bearer de votre App (pour les données publiques) ou d’un jeton d’accès utilisateur (pour les métriques privées)
</Note>

<div id="get-users-who-liked-a-post">
  ## Obtenir la liste des utilisateurs qui ont aimé une Publication
</div>

Récupérez la liste des utilisateurs qui ont aimé une Publication spécifique :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/1354143047324299264/liking_users?\
  user.fields=created_at,username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtenir les utilisateurs qui ont aimé une Publication avec pagination
  for page in client.posts.get_liking_users(
      "1354143047324299264",
      user_fields=["created_at", "username", "verified"]
  ):
      for user in page.data:
          print(f"{user.username} - Inscription : {user.created_at}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtenir les utilisateurs qui ont aimé une Publication avec pagination
  const paginator = client.posts.getLikingUsers("1354143047324299264", {
    userFields: ["created_at", "username", "verified"],
  });

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(`${user.username} - Inscription : ${user.created_at}`);
    });
  }
  ```
</CodeGroup>

<div id="get-a-users-liked-posts">
  ## Récupérer les Publications aimées d’un utilisateur
</div>

Récupérez les Publications qu’un utilisateur spécifique a aimées :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/2244994945/liked_tweets?\
  tweet.fields=created_at,public_metrics&\
  max_results=10" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer les Publications aimées d’un utilisateur avec pagination
  for page in client.users.get_liked_tweets(
      "2244994945",
      tweet_fields=["created_at", "public_metrics"],
      max_results=10
  ):
      for post in page.data:
          print(f"{post.text[:50]}... - Likes: {post.public_metrics.like_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérer les Publications aimées d’un utilisateur avec pagination
  const paginator = client.users.getLikedTweets("2244994945", {
    tweetFields: ["created_at", "public_metrics"],
    maxResults: 10,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text?.slice(0, 50)}... - Likes: ${post.public_metrics?.like_count}`);
    });
  }
  ```
</CodeGroup>

<div id="include-additional-data">
  ## Inclure des données supplémentaires
</div>

Utilisez le paramètre expansions pour obtenir des données associées, comme les Publications épinglées :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/1354143047324299264/liking_users?\
  user.fields=created_at&\
  expansions=pinned_tweet_id&\
  tweet.fields=created_at" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer les utilisateurs ayant aimé avec l’expansion de Publication épinglée
  for page in client.posts.get_liking_users(
      "1354143047324299264",
      user_fields=["created_at"],
      expansions=["pinned_tweet_id"],
      tweet_fields=["created_at"]
  ):
      for user in page.data:
          print(f"{user.username}")
      # Les Publications épinglées se trouvent dans page.includes.tweets
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérer les utilisateurs ayant aimé avec l’expansion de Publication épinglée
  const paginator = client.posts.getLikingUsers("1354143047324299264", {
    userFields: ["created_at"],
    expansions: ["pinned_tweet_id"],
    tweetFields: ["created_at"],
  });

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(user.username);
    });
    // Les Publications épinglées se trouvent dans page.includes?.tweets
  }
  ```
</CodeGroup>
