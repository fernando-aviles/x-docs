<div id="comparing-x-apis-likes-endpoints">
  ## Comparaison des endpoints Likes de X API
</div>

Ces guides porteront sur les domaines suivants :

* **Paramètres de requête API** - L’endpoint X API v2 introduit un nouvel ensemble de paramètres de requête. Bien que certains paramètres vous soient familiers, en particulier si vous intégrez déjà avec Labs, il existe de nombreuses différences importantes, comme l’introduction des paramètres [fields](/fr/x-api/fundamentals/fields) et [expansions](/fr/x-api/fundamentals/expansions).

* **Conditions requises pour l’App et le Projet** - Pour accéder à X API v2, vous devrez utiliser des identifiants provenant d’une [developer App](/fr/resources/fundamentals/developer-apps) qui est associée à un [Project](/fr/resources/fundamentals/developer-apps)

<div id="likes-lookup">
  #### Recherche des Likes
</div>

**Utilisateurs ayant aimé une Publication**

L’endpoint des utilisateurs ayant aimé est une nouvelle fonctionnalité de la v2, qui vous permet d’obtenir des informations sur les utilisateurs qui ont aimé une Publication.

| Description | X API v2 |
| :--- | :--- |
| Méthodes HTTP prises en charge | GET |
| Domaine hôte | https://api.x.com |
| Chemin d’endpoint | /2/tweets/:id/liking&#95;users |
| [Authentication](/fr/resources/fundamentals/authentication) | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a User Context |
| Default request [rate limits](/fr/resources/fundamentals/rate-limits) | 75 requests per 15 min (per App)<br /><br />75 requests per 15 min (per user) |

**Publications aimées par un utilisateur**

Le tableau suivant compare l’endpoint standard v1.1 [GET favorites/list](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-favorites-list) et les endpoints X API v2 pour les Publications aimées :

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | GET | GET |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/favorites/list.json | /2/users/:id/liked&#95;tweets |
| [Authentication](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a User Context |
| Default request [rate limits](/fr/resources/fundamentals/rate-limits) | 75 requests per 15 min | 75 requests per 15 min (per App)<br /><br />75 requests per 15 min (per user) |
| Formats de données | Format standard v1.1 | [X API v2 format](/fr/x-api/fundamentals/data-dictionary) (déterminé par les paramètres de requête fields et expansions, non rétrocompatible avec les formats v1.1)<br /><br />Pour en savoir plus sur la migration du format standard v1.1 vers le format X API v2, veuillez consulter notre [data formats migration guide](/fr/x-api/migrate/data-format-migration). |

<div id="manage-likes">
  #### Gérer les mentions J’aime
</div>

Les endpoints v2 de gestion des mentions J’aime remplacent les endpoints v1.1 [POST favorites/create](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-create) et [POST favorites/destroy](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-destroy).

Les tableaux suivants comparent les endpoints standard de gestion des mentions J’aime dans la v1.1 et dans X API v2 :

<div id="like-a-post">
  #### Aimer une Publication
</div>

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin de l’endpoint | /1.1/favorites/create.json | /2/users/:id/likes |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| Limites de [débit des requêtes](/fr/resources/fundamentals/rate-limits) par défaut | 1000 requêtes par tranche de 24 heures (par utilisateur)<br /><br />1000 requêtes par tranche de 24 heures (par application) | 50 requêtes par tranche de 15 minutes (par utilisateur)<br /><br />1000 requêtes par tranche de 24 heures (par utilisateur, partagé avec DELETE) |

<div id="unlike-a-post">
  #### Annuler un J&#39;aime sur une Publication
</div>

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | DELETE |
| Domaine d’hébergement | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/favorites/destroy.json | /2/users/:id/likes/:tweet&#95;id |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| [Limites de débit](/fr/resources/fundamentals/rate-limits) des requêtes par défaut | 1000 requêtes toutes les 24 heures (par utilisateur)<br /><br />1000 requêtes toutes les 24 heures (par application) | 50 requêtes toutes les 15 min (par utilisateur)<br /><br />1000 requêtes toutes les 24 heures (par utilisateur, partagé avec POST) |
