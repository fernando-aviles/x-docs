<div id="comparing-x-apis-likes-endpoints">
  ## Comparaison des endpoints Likes de X API
</div>

Ces guides se concentreront sur les aspects suivants :

* **Paramètres de requête de l’API** - L’endpoint de X API v2 introduit un nouveau jeu de paramètres de requête. Bien que certains paramètres vous seront familiers, en particulier si vous avez déjà intégré Labs, il existe de nombreuses différences importantes, comme l’introduction des paramètres [fields](/fr/x-api/fundamentals/fields) et [expansions](/fr/x-api/fundamentals/expansions).

* **Exigences pour l’App et le Project** - Pour accéder à X API v2, vous devrez utiliser des identifiants provenant d’une [developer App](/fr/resources/fundamentals/developer-apps) qui est associée à un [Project](/fr/resources/fundamentals/developer-apps).

<div id="likes-lookup">
  #### Recherche des J’aime
</div>

**Utilisateurs qui ont aimé une Publication**

L’endpoint des utilisateurs ayant aimé une Publication est une nouvelle fonctionnalité de v2, qui vous permet d’obtenir des informations sur les utilisateurs ayant aimé une Publication.

| Description | X API v2 |
| :--- | :--- |
| Méthodes HTTP prises en charge | GET |
| Domaine de l’hôte | https://api.x.com |
| Chemin de l’endpoint | /2/tweets/:id/liking&#95;users |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a User Context |
| Limites de taux de requêtes par défaut ([rate limits](/fr/resources/fundamentals/rate-limits)) | 75 requêtes par 15 min (par App)<br /><br />75 requêtes par 15 min (par utilisateur) |

**Publications aimées par un utilisateur**

Les tableaux suivants comparent l’endpoint standard v1.1 [GET favorites/list](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-favorites-list) et les endpoints X API v2 pour les Publications aimées :

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | GET | GET |
| Domaine de l’hôte | https://api.x.com | https://api.x.com |
| Chemin de l’endpoint | /1.1/favorites/list.json | /2/users/:id/liked&#95;tweets |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a User Context |
| Limites de taux de requêtes par défaut ([rate limits](/fr/resources/fundamentals/rate-limits)) | 75 requêtes par 15 min | 75 requêtes par 15 min (par App)<br /><br />75 requêtes par 15 min (par utilisateur) |
| Formats de données | Format standard v1.1 | [Format X API v2](/fr/x-api/fundamentals/data-dictionary) (déterminé par les paramètres de requête fields et expansions, non rétrocompatible avec les formats v1.1)<br /><br />Pour en savoir plus sur la migration du format standard v1.1 vers le format X API v2, consultez notre [guide de migration des formats de données](/fr/x-api/migrate/data-format-migration). |

<div id="manage-likes">
  #### Gérer les mentions J’aime
</div>

Les endpoints de gestion des mentions J’aime de la v2 remplacent les endpoints v1.1 [POST favorites/create](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-create) et [POST favorites/destroy](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-destroy).

Les tableaux suivants comparent les endpoints standard de gestion des mentions J’aime de la v1.1 et de X API v2 :

<div id="like-a-post">
  #### Aimer une Publication
</div>

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin de l’endpoint | /1.1/favorites/create.json | /2/users/:id/likes |
| [Authentification](/fr/resources/fundamentals/authentication) | Contexte utilisateur OAuth 1.0a | Contexte utilisateur OAuth 1.0a |
| [Limites de taux par défaut pour les requêtes](/fr/resources/fundamentals/rate-limits) | 1000 requêtes par période de 24 heures (par utilisateur)<br /><br />1000 requêtes par période de 24 heures (par App) | 50 requêtes par 15 minutes (par utilisateur)<br /><br />1000 requêtes par période de 24 heures (par utilisateur, partagé avec DELETE) |

<div id="unlike-a-post">
  #### Retirer un J’aime d’une Publication
</div>

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| HTTP methods supported | POST | DELETE |
| Host domain | https://api.x.com | https://api.x.com |
| Endpoint path | /1.1/favorites/destroy.json | /2/users/:id/likes/:tweet&#95;id |
| [Authentication](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| Default request [rate limits](/fr/resources/fundamentals/rate-limits) | 1000 requêtes par période de 24 heures (par utilisateur)<br /><br />1000 requêtes par période de 24 heures (par App) | 50 requêtes par 15 minutes (par utilisateur)<br /><br />1000 requêtes par période de 24 heures (par utilisateur, partagé avec POST) |
