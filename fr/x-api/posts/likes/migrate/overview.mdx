<div id="comparing-x-apis-likes-endpoints">
  ## Comparaison des endpoints Likes de X API
</div>

Ces guides se concentreront sur les points suivants :

* **Paramètres de requête d’API** - L’endpoint de X API v2 introduit un nouvel ensemble de paramètres de requête. Bien que certains paramètres vous soient familiers, en particulier si vous avez déjà intégré Labs, il existe de nombreuses différences importantes, comme l’introduction des paramètres [champs](/fr/x-api/fundamentals/fields) et [expansions](/fr/x-api/fundamentals/expansions).

* **Conditions requises pour l’App et le Projet** - Pour accéder à X API v2, vous devrez utiliser des identifiants provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) qui est associée à un [Projet](/fr/resources/fundamentals/developer-apps).

<div id="likes-lookup">
  #### Recherche des J’aime
</div>

**Utilisateurs qui ont aimé une Publication**

L’endpoint des utilisateurs ayant aimé une Publication est une nouvelle fonctionnalité de v2, qui vous permet d’obtenir des informations sur les utilisateurs ayant aimé une Publication.

| Description | X API v2 |
| :--- | :--- |
| Méthodes HTTP prises en charge | GET |
| Domaine hôte | https://api.x.com |
| Chemin d’endpoint | /2/tweets/:id/liking&#95;users |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a User Context |
| Limites de [fréquence](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 75 requêtes par 15 min (par application)<br /><br />75 requêtes par 15 min (par utilisateur) |

**Publications aimées par un utilisateur**

Les tableaux suivants comparent l’endpoint Standard v1.1 [GET favorites/list](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-favorites-list) et les endpoints X API v2 pour les Publications aimées :

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | GET | GET |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/favorites/list.json | /2/users/:id/liked&#95;tweets |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a User Context |
| Limites de [fréquence](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 75 requêtes par 15 min | 75 requêtes par 15 min (par application)<br /><br />75 requêtes par 15 min (par utilisateur) |
| Formats de données | Format Standard v1.1 | [Format X API v2](/fr/x-api/fundamentals/data-dictionary) (déterminé par les paramètres de requête fields et expansions, non rétrocompatible avec les formats v1.1)<br /><br />Pour en savoir plus sur la migration du format Standard v1.1 vers le format X API v2, consultez notre [guide de migration des formats de données](/fr/x-api/migrate/data-format-migration). |

<div id="manage-likes">
  #### Gérer les mentions J’aime
</div>

Les endpoints v2 de gestion des mentions J’aime remplacent les endpoints v1.1 [POST favorites/create](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-create) et [POST favorites/destroy](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-destroy).

Les tableaux suivants comparent les endpoints standard v1.1 et X API v2 de gestion des mentions J’aime :

<div id="like-a-post">
  #### Aimer une Publication
</div>

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine d’hébergement | https://api.x.com | https://api.x.com |
| Chemin de l’endpoint | /1.1/favorites/create.json | /2/users/:id/likes |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| Limites de [débit de requêtes](/fr/resources/fundamentals/rate-limits) par défaut | 1000 requêtes par période de 24 heures (par utilisateur)<br /><br />1000 requêtes par période de 24 heures (par application) | 50 requêtes par période de 15 minutes (par utilisateur)<br /><br />1000 requêtes par période de 24 heures (par utilisateur, partagé avec DELETE) |

<div id="unlike-a-post">
  #### Retirer un Like d’une publication
</div>

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | DELETE |
| Domaine de l’hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/favorites/destroy.json | /2/users/:id/likes/:tweet&#95;id |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| Limites de [débit](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 1000 requêtes par période de 24 heures (par utilisateur)<br /><br />1000 requêtes par période de 24 heures (par application) | 50 requêtes par 15 minutes (par utilisateur)<br /><br />1000 requêtes par période de 24 heures (par utilisateur, partagées avec POST) |
