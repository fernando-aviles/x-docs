<div id="manage-likes-standard-v11-compared-to-x-api-v2">
  ### Gérer les Likes : standard v1.1 par rapport à X API v2
</div>

Si vous avez travaillé avec les endpoints standard v1.1 [POST favorites/create](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-create) et [POST favorites/destroy](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-favorites-destroy), l’objectif de ce guide est de vous aider à comprendre les similarités et les différences entre les endpoints de gestion des Likes du standard v1.1 et de X API v2.

* **Similarités**
  * Contexte utilisateur OAuth 1.0a
* **Différences**
  * URL des endpoints et méthodes HTTP
  * Exigences liées à l’App et au Project
  * Paramètres de la requête

<div id="similarities">
  #### Similarités
</div>

**Méthode d’authentification OAuth 1.0a User Context**

Les deux versions d’endpoint prennent en charge [OAuth 1.0a User Context](/fr/resources/fundamentals/authentication#oauth-1-0a-2). Par conséquent, si vous utilisiez auparavant l’un des endpoints standard v1.1 pour gérer les favoris, vous pouvez continuer à utiliser la même méthode d’authentification si vous migrez vers la version X API v2.

<div id="differences">
  #### Différences
</div>

**URLs d’endpoint et méthodes HTTP**

* Endpoints Standard v1.1 :
  * POST https://api.x.com/1.1/favorites/create.json
    (ajouter un J’aime à une Publication)
  * POST https://api.x.com/1.1/favorites/destroy.json
    (retirer un J’aime d’une Publication)
* Endpoint X API v2 :
  * POST https://api.x.com/2/tweets/:id/likes
    (ajouter un J’aime à une Publication)
  * DELETE https://api.x.com/2/tweets/:id/likes/:tweet&#95;id
    (retirer un J’aime d’une Publication) 

**Exigences pour les Apps et les Projects**

Les endpoints X API v2 exigent que vous utilisiez des identifiants issus d’une [developer App](/fr/resources/fundamentals/developer-apps) associée à un [Project](/fr/resources/fundamentals/developer-apps) pour authentifier vos requêtes. Tous les endpoints X API v1.1 peuvent utiliser des identifiants provenant d’Apps ou d’Apps associées à une App.

**Paramètres de requête**

Les paramètres de requête Standard v1.1 suivants ont des équivalents dans X API v2 :

| Standard v1.1 | X API v2 |
| :--- | :--- |
| id  | id  |
| includes&#95;entities | Aucun équivalent |

Veuillez noter que les paramètres Standard v1.1 sont transmis sous forme de paramètres de requête, tandis que les paramètres X API v2 sont transmis sous forme de paramètres de corps de requête pour l’endpoint POST ou de paramètres de chemin pour l’endpoint DELETE.

De plus, un id de l’utilisateur qui aime une Publication n’est pas requis lorsque vous utilisez les endpoints Standard v1.1, car les [Access Tokens](/fr/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) transmis avec [OAuth 1.0a User Context](/fr/resources/fundamentals/authentication) permettent de déduire quel utilisateur initie l’ajout ou le retrait du J’aime.

<div id="like-a-post-v2">
  ### Aimer une publication (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/likes" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python
  # Nécessite une authentification OAuth 1.0a en contexte utilisateur
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/likes"
  response = requests.post(url, auth=auth, json={"tweet_id": "1234567890"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Aimer une publication
  response = client.posts.like(user_id="123456789", tweet_id="1234567890")
  print(f"Liked: {response.data.liked}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Aimer une publication
  const response = await client.posts.like("123456789", { tweetId: "1234567890" });
  console.log(`Liked: ${response.data?.liked}`);
  ```
</CodeGroup>
