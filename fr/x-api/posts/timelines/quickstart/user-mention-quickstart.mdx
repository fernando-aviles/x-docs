Ce guide vous explique comment récupérer les Publications qui mentionnent un utilisateur spécifique.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin de :

  * d&#39;un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une application approuvée
  * du Bearer Token de votre application (pour les données publiques) ou d&#39;un User Access Token (pour les métriques privées)
</Note>

***

<div id="get-user-mentions">
  ## Obtenir les mentions d’utilisateur
</div>

<Steps>
  <Step title="Obtenir l’ID d’utilisateur">
    Trouvez l’ID d’utilisateur à l’aide du [point de terminaison de recherche d’utilisateur](/fr/x-api/users/lookup/introduction). Par exemple, @XDevelopers a pour ID d’utilisateur `2244994945`.
  </Step>

  <Step title="Interroger la timeline des mentions">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/users/2244994945/mentions?\
      tweet.fields=created_at,public_metrics,author_id&\
      expansions=author_id&\
      user.fields=username,verified&\
      max_results=10" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Récupérer la timeline des mentions avec pagination
      for page in client.posts.get_user_mentions(
          "2244994945",
          tweet_fields=["created_at", "public_metrics", "author_id"],
          expansions=["author_id"],
          user_fields=["username", "verified"],
          max_results=10
      ):
          for post in page.data:
              print(f"@{post.author_id}: {post.text[:50]}...")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Récupérer la timeline des mentions avec pagination
      const paginator = client.posts.getUserMentions("2244994945", {
        tweetFields: ["created_at", "public_metrics", "author_id"],
        expansions: ["author_id"],
        userFields: ["username", "verified"],
        maxResults: 10,
      });

      for await (const page of paginator) {
        page.data?.forEach((post) => {
          console.log(`@${post.author_id}: ${post.text?.slice(0, 50)}...`);
        });
      }
      ```
    </CodeGroup>
  </Step>

<div id="filter-mentions">
  ## Filtrer les mentions
</div>

<div id="exclude-replies">
  ### Exclure les réponses
</div>

Obtenez uniquement les Publications originales qui mentionnent l’utilisateur :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/2244994945/mentions?\
  exclude=replies&\
  max_results=10" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtenir les mentions en excluant les réponses
  for page in client.posts.get_user_mentions(
      "2244994945",
      exclude=["replies"],
      max_results=10
  ):
      for post in page.data:
          print(post.text)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtenir les mentions en excluant les réponses
  const paginator = client.posts.getUserMentions("2244994945", {
    exclude: ["replies"],
    maxResults: 10,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(post.text);
    });
  }
  ```
</CodeGroup>

<div id="get-mentions-in-a-time-range">
  ### Obtenir les mentions dans une plage de temps donnée
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/2244994945/mentions?\
  start_time=2024-01-01T00%3A00%3A00Z&\
  end_time=2024-01-31T23%3A59%3A59Z" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtenir les mentions dans une plage de temps donnée
  for page in client.posts.get_user_mentions(
      "2244994945",
      start_time="2024-01-01T00:00:00Z",
      end_time="2024-01-31T23:59:59Z"
  ):
      for post in page.data:
          print(f"{post.created_at}: {post.text[:50]}...")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtenir les mentions dans une plage de temps donnée
  const paginator = client.posts.getUserMentions("2244994945", {
    startTime: "2024-01-01T00:00:00Z",
    endTime: "2024-01-31T23:59:59Z",
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.created_at}: ${post.text?.slice(0, 50)}...`);
    });
  }
  ```
</CodeGroup>

<div id="common-parameters">
  ## Paramètres courants
</div>

| Paramètre | Description | Valeur par défaut |
|:----------|:------------|:------------------|
| `max_results` | Résultats par page (1-100) | 10 |
| `start_time` | Horodatage de la Publication la plus ancienne (ISO 8601) | — |
| `end_time` | Horodatage de la Publication la plus récente (ISO 8601) | — |
| `since_id` | Renvoie les Publications après cet ID | — |
| `until_id` | Renvoie les Publications avant cet ID | — |
| `exclude` | Exclure `retweets`, `replies` ou les deux | — |
| `pagination_token` | Jeton de pagination pour la page suivante | — |
