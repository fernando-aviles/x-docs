Les endpoints Timelines vous permettent de récupérer des Publications à partir des timelines d’utilisateurs, des fils de mentions et du fil d’accueil. Récupérez le contenu publié par un utilisateur, voyez quelles Publications le mentionnent ou affichez son fil d’accueil personnalisé.

<div id="endpoints">
  ## Points de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/fr/x-api/users/get-posts) | Récupérer les Publications d’un utilisateur |
| GET | [`/2/users/:id/mentions`](/fr/x-api/users/get-mentions) | Récupérer les Publications mentionnant un utilisateur |
| GET | [`/2/users/:id/timelines/reverse_chronological`](/fr/x-api/users/get-timeline) | Récupérer le fil d’accueil |

  ## Chronologie des publications d’un utilisateur
</div>

Récupérez les publications les plus récentes créées par un utilisateur spécifique.

<div id="features">

</div>

* Jusqu’à 3 200 Publications parmi les plus récentes
* Exclure les réponses et les retweets
* Prise en charge de la pagination
* Accès historique avec filtrage par période

<div id="reverse-chronological-home-timeline">
  ## Fil d&#39;accueil en ordre chronologique inverse
</div>

Obtenez le fil d&#39;accueil de l&#39;utilisateur authentifié dans l&#39;ordre chronologique inverse.

<div id="features">
  ### Fonctionnalités
</div>

* Publications des comptes suivis
* 3 200 dernières publications (ou 7 jours)
* Sans classement algorithmique
* Nécessite l’authentification de l’utilisateur

<Note>
  Cet endpoint nécessite [OAuth 1.0a User Context](/fr/resources/fundamentals/authentication) ou [OAuth 2.0 Authorization Code with PKCE](/fr/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2).
</Note>

<div id="filtering-options">
  ## Options de filtrage
</div>

<div id="exclude-parameter">
  ### Paramètre d’exclusion
</div>

Exclure certains types de Publications :

| Valeur     | Effet                |
| :--------- | :------------------- |
| `retweets` | Exclure les retweets |
| `replies`  | Exclure les réponses |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="time-based-filtering">
  ### Filtrage temporel
</div>

| Paramètre | Description |
|:----------|:------------|
| `start_time` | Horodatage de la Publication la plus ancienne (ISO 8601) |
| `end_time` | Horodatage de la Publication la plus récente (ISO 8601) |
| `since_id` | Renvoie les Publications après cet ID |
| `until_id` | Renvoie les Publications avant cet ID |
