Les endpoints Timelines vous permettent de récupérer des Publications à partir des chronologies d’utilisateurs, des flux de mentions et de la chronologie d’accueil. Récupérez le contenu publié par un utilisateur, voyez quelles Publications le mentionnent ou affichez sa chronologie d’accueil personnalisée.

</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/fr/x-api/users/get-posts) | Récupérer les Publications d’un utilisateur |

</div>

<div id="reverse-chronological-home-timeline">
  ## Timeline d’accueil en ordre chronologique inverse
</div>

Récupérez la timeline d’accueil de l’utilisateur authentifié dans l’ordre chronologique inverse.

<div id="features">
  ### Fonctionnalités
</div>

* Publications des comptes suivis
* 3 200 Publications les plus récentes (ou 7 jours)
* Sans classement algorithmique
* Nécessite l’authentification de l’utilisateur

<Note>
  Cet endpoint nécessite [OAuth 1.0a User Context](/fr/resources/fundamentals/authentication) ou [OAuth 2.0 Authorization Code with PKCE](/fr/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2).
</Note>

<div id="filtering-options">
  ## Options de filtrage
</div>

<div id="exclude-parameter">
  ### Paramètre exclude
</div>

Exclut certains types de Publications :

| Valeur     | Effet                |
| :--------- | :------------------- |
| `retweets` | Exclure les retweets |
| `replies`  | Exclure les réponses |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="time-based-filtering">
  ### Filtrage temporel
</div>

| Paramètre | Description |
|:----------|:------------|
| `start_time` | Horodatage de la Publication la plus ancienne (ISO 8601) |
| `end_time` | Horodatage de la Publication la plus récente (ISO 8601) |
| `since_id` | Renvoie les Publications postérieures à cet identifiant |
| `until_id` | Renvoie les Publications antérieures à cet identifiant |
