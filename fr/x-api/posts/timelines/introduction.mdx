Les endpoints Timelines vous permettent de récupérer des Publications à partir des timelines d’utilisateurs, des flux de mentions et du fil d’accueil. Récupérez le contenu publié d’un utilisateur, voyez quelles Publications le mentionnent ou affichez son fil d’accueil personnalisé.

## Chronologie des publications d’un utilisateur

Récupérez les publications les plus récentes d’un utilisateur donné.

### Fonctionnalités

* Jusqu’aux 3 200 publications les plus récentes
* Exclure les réponses et les retweets
* Prise en charge de la pagination
* Accès historique avec filtrage temporel

## Fil d’accueil en ordre chronologique inverse

Récupérez le fil d’accueil de l’utilisateur authentifié par ordre chronologique inverse.

### Fonctionnalités

* Publications des comptes suivis
* 3 200 dernières Publications (ou 7 jours)
* Sans classement algorithmique
* Nécessite l’authentification de l’utilisateur

<Note>
  Cet endpoint nécessite [OAuth 1.0a User Context](/fr/resources/fundamentals/authentication) ou [OAuth 2.0 Authorization Code with PKCE](/fr/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2).
</Note>

## Options de filtrage

<div id="time-based-filtering">
  ### Paramètre `exclude`
</div>

Filtrez certains types de publications :

| Valeur     | Effet                |
| :--------- | :------------------- |
| `retweets` | Exclure les retweets |
| `replies`  | Exclure les réponses |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

### Filtrage temporel

| Paramètre | Description |
|:----------|:------------|
| `start_time` | Horodatage de la Publication la plus ancienne (ISO 8601) |
| `end_time` | Horodatage de la Publication la plus récente (ISO 8601) |
| `since_id` | Renvoie les Publications postérieures à cet id |
| `until_id` | Renvoie les Publications antérieures à cet id |
