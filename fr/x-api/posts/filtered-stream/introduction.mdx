Les endpoints Filtered Stream vous permettent de recevoir en temps réel les Publications qui correspondent à vos règles de filtrage. Créez des règles à l’aide d’opérateurs puissants, puis connectez-vous à un flux persistant pour recevoir les Publications correspondantes dès leur publication.

<div id="how-it-works">
  ## Fonctionnement
</div>

1. **Créer des règles** — Définissez des règles de filtrage à l’aide d’opérateurs
2. **Se connecter au flux** — Établissez une connexion HTTP persistante
3. **Recevoir des publications** — Recevez en temps réel les publications correspondantes

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│ Créer/      │      │ Se connecter│      │ Recevoir les│
│ gérer les   │  →   │ au point de │  →   │ Publications│

│             │      │ de streaming│      │ dantes      │
└─────────────┘      └─────────────┘      └─────────────┘
```

<div id="building-rules">
  ## Création de règles
</div>

Les règles utilisent les mêmes opérateurs que les requêtes de recherche :

```
(AI OR "machine learning") lang:en -is:retweet
```

<div id="example-rules">
  ### Exemples de règles
</div>

| Règle | Correspondances |
|:-----|:--------|
| `#python` | Publications avec le hashtag #python |
| `from:elonmusk` | Publications de @elonmusk |
| `"breaking news" has:images` | Publications contenant l’expression « breaking news » et des images |
| `(@XDevelopers OR @X) -is:retweet` | Mentions, hors retweets |

<div id="connecting-to-the-stream">
  ## Connexion au flux
</div>

Établissez une connexion HTTP persistante pour recevoir des Publications :

```python
import requests

def stream_posts(bearer_token):
    url = "https://api.x.com/2/tweets/search/stream"
    headers = {"Authorization": f"Bearer {bearer_token}"}
    
    response = requests.get(url, headers=headers, stream=True)
    
    for line in response.iter_lines():
        if line:
            print(line.decode("utf-8"))
```

<div id="keep-alive-signals">
  ### Signaux de keep-alive
</div>

Le flux envoie des lignes vides (`\r\n`) toutes les 20 secondes pour maintenir la connexion. Si vous ne recevez aucune donnée ni signal de keep-alive pendant 20 secondes, reconnectez-vous.

<div id="post-edits">
  ## Modifications de Publications
</div>

Le flux diffuse les Publications modifiées avec leur historique de modifications. Chaque modification crée un nouvel ID de Publication :

```json
{
  "data": {
    "id": "1234567893",
    "text": "Hello world! (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891", "1234567893"]
  }
}
```
