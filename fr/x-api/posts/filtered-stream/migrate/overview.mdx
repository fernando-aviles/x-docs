<div id="comparing-x-apis-filtered-stream-endpoints">
  ## Comparaison des endpoints de flux filtré de X API
</div>

Le groupe d&#39;endpoints de flux filtré v2 remplace les endpoints [standard v1.1 statuses/filter](https://developer.x.com/en/docs/x-api/v1/tweets/filter-realtime/api-reference/post-statuses-filter) et [PowerTrack API](/fr/x-api/enterprise-gnip-2.0/powertrack-api). Si votre code, vos applications ou vos outils utilisent une ancienne version de l&#39;endpoint de flux filtré et que vous envisagez de migrer vers le nouvel endpoint X API v2, cette comparaison peut vous aider à démarrer.

Consultez nos guides de migration plus détaillés pour :

[Migration depuis Standard v1.1 vers X API v2](x-api/posts/filtered-stream#standard-v1-1-compared-to-x-api-v2)

[Migration depuis PowerTrack API vers X API v2](/fr/x-api/enterprise-gnip-2.0/powertrack-api#powertrack-operators)
