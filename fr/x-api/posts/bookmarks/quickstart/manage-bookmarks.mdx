Ce guide vous explique comment ajouter et supprimer des signets via la X API.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin :

  * d’un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une App approuvée
  * d’un jeton d’accès utilisateur avec le scope `bookmark.write` (OAuth 2.0 PKCE)
</Note>

***

<div id="add-a-bookmark">
  ## Ajouter un signet
</div>

<Steps>
  <Step title="Récupérer l'identifiant utilisateur">
    Vous avez besoin de l&#39;identifiant de l&#39;utilisateur authentifié. Vous pouvez le trouver en utilisant l&#39;endpoint `/2/users/me` ou l&#39;[endpoint de recherche d&#39;utilisateur](/fr/x-api/users/lookup/introduction).
  </Step>

  <Step title="Récupérer l'ID de la Publication">
    Trouvez l&#39;ID de la Publication dans l&#39;URL lorsque vous affichez une Publication :

    ```
    https://x.com/XDevelopers/status/1460323737035677698
                                    └── Ceci est l'ID de la Publication
    ```
  </Step>

  <Step title="Ajouter le signet">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/users/2244994945/bookmarks" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"tweet_id": "1460323737035677698"}'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # Ajouter un signet
      response = client.bookmarks.create(
          user_id="2244994945",
          tweet_id="1460323737035677698"
      )

      print(f"Bookmarked: {response.data.bookmarked}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // Ajouter un signet
      const response = await client.bookmarks.create("2244994945", {
        tweetId: "1460323737035677698",
      });

      console.log(`Bookmarked: ${response.data?.bookmarked}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Examiner la réponse">
    ```json
    {
      "data": {
        "bookmarked": true
      }
    }
    ```
  </Step>
</Steps>

***

<div id="remove-a-bookmark">
  ## Supprimer un signet
</div>

Supprimez une Publication de vos signets :

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/2244994945/bookmarks/1460323737035677698" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Supprimer un signet
  response = client.bookmarks.delete(
      user_id="2244994945",
      tweet_id="1460323737035677698"
  )

  print(f"Bookmarked: {response.data.bookmarked}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Supprimer un signet
  const response = await client.bookmarks.delete("2244994945", "1460323737035677698");

  console.log(`Bookmarked: ${response.data?.bookmarked}`);
  ```
</CodeGroup>

**Réponse :**

```json
{
  "data": {
    "bookmarked": false
  }
}
```

***

<div id="required-scopes">
  ## Scopes requis
</div>

Lorsque vous utilisez OAuth 2.0 PKCE, votre jeton d&#39;accès doit inclure les scopes suivants :

| Scope | Description |
|:------|:------------|
| `bookmark.write` | Ajouter et supprimer des signets |
| `tweet.read` | Lire les données de Publication |
| `users.read` | Lire les données d&#39;utilisateur |
