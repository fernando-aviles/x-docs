<div id="authentication">
  #### Authentification
</div>

Tous les endpoints de X API v2 exigent que vous authentifiiez vos requêtes à l’aide d’un ensemble d’identifiants, également appelés clés et jetons.

Ces endpoints spécifiques nécessitent l’utilisation du [flux de code d’autorisation OAuth 2.0 avec PKCE](/fr/resources/fundamentals/authentication/oauth-2-0/authorization-code), ce qui signifie que vous devez utiliser un ensemble de clés et de jetons d’accès utilisateur pour qu’une requête aboutisse. Les jetons d’accès doivent être associés à l’utilisateur pour le compte duquel vous effectuez la requête. Si vous souhaitez générer un ensemble de jetons d’accès pour un autre utilisateur, celui-ci doit autoriser ou authentifier votre application à l’aide d’une [URL Authorize](/fr/resources/fundamentals/authentication#authorize-url).

Notez que le protocole OAuth 2.0 peut être complexe à utiliser. Si vous ne connaissez pas cette méthode d’authentification, nous vous recommandons d’utiliser une [bibliothèque](/fr/x-api/tools-and-libraries/overview) ou un outil comme Postman pour authentifier correctement vos requêtes.

<div id="developer-console-projects-and-developer-apps">
  #### Console de Développement, Projets et Apps développeur
</div>

Pour obtenir un ensemble d’identifiants d’authentification qui fonctionneront avec les endpoints de X API v2, vous devez disposer d’un [compte développeur](/fr/resources/fundamentals/developer-portal), configurer un [Projet](/fr/resources/fundamentals/developer-apps) dans ce compte, puis créer une [App développeur](/fr/resources/fundamentals/developer-apps) au sein de ce Projet. Vous pourrez ensuite retrouver vos clés et jetons dans votre App développeur.

<div id="rate-limits">
  #### Limites de débit
</div>

Chaque jour, plusieurs milliers de développeurs envoient des requêtes à X API. Pour aider à gérer le volume considérable de ces requêtes, des [limites de débit](/fr/resources/fundamentals/rate-limits) sont appliquées à chaque endpoint, ce qui limite le nombre de requêtes que vous pouvez effectuer au nom de votre application ou au nom d’un utilisateur authentifié.

Ces endpoints sont limités au niveau utilisateur, ce qui signifie que l’utilisateur authentifié pour lequel vous effectuez la requête ne peut appeler l’endpoint qu’un certain nombre de fois, quel que soit l’App développeur. Il existe une limite de débit utilisateur de 180 requêtes par fenêtre de 15 minutes pour la méthode GET. Avec la méthode GET de l’endpoint Bookmarks lookup, vous recevrez 800 de vos Publications ajoutées aux favoris les plus récentes. De plus, il existe une limite de débit utilisateur de 50 requêtes par fenêtre de 15 minutes pour les méthodes POST et DELETE.

<div id="get-bookmarks">
  #### Obtenir les signets
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123/bookmarks?tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Obtenir les signets de l'utilisateur
  for page in client.bookmarks.get(user_id="123", tweet_fields=["created_at", "public_metrics"]):
      for post in page.data:
          print(f"{post.text} - Mentions J'aime : {post.public_metrics.like_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Obtenir les signets de l'utilisateur
  const paginator = client.bookmarks.get("123", {
    tweetFields: ["created_at", "public_metrics"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text} - Mentions J'aime : ${post.public_metrics?.like_count}`);
    });
  }
  ```
</CodeGroup>

<div id="create-a-bookmark">
  #### Créer un signet
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/bookmarks" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Ajouter une Publication à vos signets
  response = client.bookmarks.create(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Ajouter une Publication à vos signets
  const response = await client.bookmarks.create("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
