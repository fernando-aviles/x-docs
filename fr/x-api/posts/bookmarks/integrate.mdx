<div id="authentication">
  #### Authentification
</div>

Tous les endpoints de X API v2 exigent que vous authentifiiez vos requêtes avec un ensemble d’identifiants, également appelés clés et jetons.

Ces endpoints spécifiques nécessitent l’utilisation du [flux OAuth 2.0 Authorization Code Flow with PKCE](/fr/resources/fundamentals/authentication/oauth-2-0/authorization-code), ce qui signifie que vous devez utiliser un ensemble de clés et de jetons d’accès utilisateur (Access Tokens) pour effectuer une requête avec succès. Les Access Tokens doivent être associés à l’utilisateur pour le compte duquel vous effectuez la requête. Si vous souhaitez générer un ensemble d’Access Tokens pour un autre utilisateur, celui-ci doit autoriser ou authentifier votre App à l’aide d’une [URL d’autorisation](/fr/resources/fundamentals/authentication#authorize-url).

Veuillez noter qu’OAuth 2.0 peut être difficile à utiliser. Si vous ne maîtrisez pas encore bien cette méthode d’authentification, nous vous recommandons d’utiliser une [bibliothèque](/fr/x-api/tools-and-libraries/overview) ou un outil comme Postman pour authentifier correctement vos requêtes.

<div id="developer-console-projects-and-developer-apps">
  #### Developer Console, Projects et Apps développeur
</div>

Pour obtenir un ensemble d’identifiants d’authentification compatibles avec les endpoints de X API v2, vous devez disposer d’un [compte développeur](/fr/resources/fundamentals/developer-portal), configurer un [Project](/fr/resources/fundamentals/developer-apps) dans ce compte et créer une [developer App](/fr/resources/fundamentals/developer-apps) au sein de ce Project. Vous pourrez ensuite retrouver vos clés et jetons dans votre developer App.

<div id="rate-limits">
  #### Limites de débit
</div>

Chaque jour, plusieurs milliers de développeurs envoient des requêtes à la X API. Pour aider à gérer le volume considérable de ces requêtes, des [limites de débit](/fr/resources/fundamentals/rate-limits) sont appliquées à chaque endpoint afin de restreindre le nombre de requêtes que vous pouvez effectuer au nom de votre application ou au nom d’un utilisateur authentifié.

Ces endpoints sont limités au niveau utilisateur, ce qui signifie que l’utilisateur authentifié pour lequel vous effectuez la requête ne peut appeler l’endpoint qu’un certain nombre de fois, quelle que soit l’App développeur. La limite de débit utilisateur est de 180 requêtes par fenêtre de 15 minutes pour la méthode GET. Avec la méthode GET de l’endpoint Bookmarks lookup, vous récupérerez 800 de vos Publications les plus récentes ajoutées aux favoris. De plus, la limite de débit utilisateur est de 50 requêtes par fenêtre de 15 minutes pour les méthodes POST et DELETE.

<div id="get-bookmarks">
  #### Récupérer les signets
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123/bookmarks?tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Récupérer les signets de l'utilisateur
  for page in client.bookmarks.get(user_id="123", tweet_fields=["created_at", "public_metrics"]):
      for post in page.data:
          print(f"{post.text} - Likes: {post.public_metrics.like_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Récupérer les signets de l'utilisateur
  const paginator = client.bookmarks.get("123", {
    tweetFields: ["created_at", "public_metrics"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text} - Likes: ${post.public_metrics?.like_count}`);
    });
  }
  ```
</CodeGroup>

<div id="create-a-bookmark">
  #### Créer un signet
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/bookmarks" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python SDK Python
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Ajouter une publication aux signets
  response = client.bookmarks.create(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript SDK JavaScript
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Ajouter une publication aux signets
  const response = await client.bookmarks.create("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
