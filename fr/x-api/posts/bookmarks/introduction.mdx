Les endpoints Bookmarks vous permettent d’afficher, d’ajouter et de supprimer les Publications ajoutées aux signets pour l’utilisateur authentifié. Les Bookmarks sont privés et ne sont visibles que par l’utilisateur qui les a créés.

<div id="endpoints">
  ## Endpoints
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/bookmarks`](/fr/x-api/users/get-bookmarks) | Récupérer les favoris de l&#39;utilisateur |
| POST | [`/2/users/:id/bookmarks`](/fr/x-api/users/create-bookmark) | Ajouter une publication aux favoris |
| DELETE | [`/2/users/:id/bookmarks/:tweet_id`](/fr/x-api/users/delete-bookmark) | Supprimer un favori |
| GET | [`/2/users/:id/bookmarks/folders`](/fr/x-api/users/get-bookmark-folders) | Récupérer les dossiers de favoris |
| GET | [`/2/users/:id/bookmarks/folders/:folder_id`](/fr/x-api/users/get-bookmarks-by-folder-id) | Récupérer les publications d&#39;un dossier |

***

<div id="example-get-bookmarks">
  ## Exemple : récupérer les signets
</div>

```bash
curl "https://api.x.com/2/users/123456789/bookmarks?\
tweet.fields=created_at,author_id,public_metrics" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-add-bookmark">
  ## Exemple : Ajouter un signet
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/bookmarks" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
