Ce guide vous explique comment obtenir le nombre de Publications (volume) des 7 derniers jours.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin :

  * D&#39;un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une application approuvée
  * Du Bearer Token de votre application
</Note>

***

<div id="get-recent-post-counts">
  ## Obtenir le nombre de Publications récentes
</div>

<Steps>
  <Step title="Construire une requête">
    Utilisez la même syntaxe de requête que pour la recherche récente. Par exemple, pour compter les Publications de @XDevelopers :

    ```
    from:XDevelopers
    ```
  </Step>

  <Step title="Effectuer la requête">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/tweets/counts/recent?\
      query=from%3AXDevelopers&\
      granularity=day" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Obtenir le nombre de Publications récentes
      response = client.posts.count_recent(
          query="from:XDevelopers",
          granularity="day"
      )

      for bucket in response.data:
          print(f"{bucket.start}: {bucket.tweet_count} Publications")

      print(f"Total : {response.meta.total_tweet_count}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Obtenir le nombre de Publications récentes
      const response = await client.posts.countRecent({
        query: "from:XDevelopers",
        granularity: "day",
      });

      response.data?.forEach((bucket) => {
        console.log(`${bucket.start}: ${bucket.tweet_count} Publications`);
      });

      console.log(`Total : ${response.meta?.total_tweet_count}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Examiner la réponse">
    ```json
    {
      "data": [
        {
          "end": "2024-01-16T00:00:00.000Z",
          "start": "2024-01-15T00:00:00.000Z",
          "tweet_count": 5
        },
        {
          "end": "2024-01-17T00:00:00.000Z",
          "start": "2024-01-16T00:00:00.000Z",
          "tweet_count": 3
        },
        {
          "end": "2024-01-18T00:00:00.000Z",
          "start": "2024-01-17T00:00:00.000Z",
          "tweet_count": 8
        }
      ],
      "meta": {
        "total_tweet_count": 16
      }
    }
    ```
  </Step>
</Steps>

<div id="granularity-options">
  ## Options de granularité
</div>

Contrôlez la façon dont les décomptes sont regroupés :

| Granularity | Description |
|:------------|:------------|
| `minute` | Nombre par minute |
| `hour` | Nombre par heure (par défaut) |
| `day` | Nombre par jour |

<CodeGroup dropdown>
  ```bash cURL
  # Récupérer les décomptes horaires
  curl "https://api.x.com/2/tweets/counts/recent?\
  query=python%20lang%3Aen&\
  granularity=hour" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer les décomptes horaires
  response = client.posts.count_recent(
      query="python lang:en",
      granularity="hour"
  )

  for bucket in response.data:
      print(f"{bucket.start}: {bucket.tweet_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérer les décomptes horaires
  const response = await client.posts.countRecent({
    query: "python lang:en",
    granularity: "hour",
  });

  response.data?.forEach((bucket) => {
    console.log(`${bucket.start}: ${bucket.tweet_count}`);
  });
  ```
</CodeGroup>

<div id="filter-by-time-range">
  ## Filtrer par plage temporelle
</div>

Limiter les décomptes à une période donnée :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/counts/recent?\
  query=from%3AXDevelopers&\
  start_time=2024-01-10T00%3A00%3A00Z&\
  end_time=2024-01-15T00%3A00%3A00Z&\
  granularity=day" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Obtenir les décomptes pour une période donnée
  response = client.posts.count_recent(
      query="from:XDevelopers",
      start_time="2024-01-10T00:00:00Z",
      end_time="2024-01-15T00:00:00Z",
      granularity="day"
  )

  print(f"Total Publications: {response.meta.total_tweet_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Obtenir les décomptes pour une période donnée
  const response = await client.posts.countRecent({
    query: "from:XDevelopers",
    startTime: "2024-01-10T00:00:00Z",
    endTime: "2024-01-15T00:00:00Z",
    granularity: "day",
  });

  console.log(`Total Publications: ${response.meta?.total_tweet_count}`);
  ```
</CodeGroup>

<div id="common-parameters">
  ## Paramètres courants
</div>

| Paramètre | Description | Valeur par défaut |
|:----------|:------------|:------------------|
| `query` | Requête de recherche (Obligatoire) | — |
| `granularity` | Granularité temporelle | `hour` |
| `start_time` | Horodatage le plus ancien (ISO 8601) | Il y a 7 jours |
| `end_time` | Horodatage le plus récent (ISO 8601) | Maintenant |
