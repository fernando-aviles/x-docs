Les endpoints de comptage de Publications renvoient, au fil du temps, le nombre de Publications correspondant à une requête, sans renvoyer les Publications elles-mêmes. Utilisez ces endpoints pour analyser les tendances, comprendre l’ampleur des conversations et affiner vos requêtes avant d’effectuer une recherche.

<div id="endpoints">
  ## Endpoints
</div>

| Endpoint | Description | Access |
|:---------|:------------|:-------|
| GET [`/2/tweets/counts/recent`](/fr/x-api/posts/get-count-of-recent-posts) | Compte les publications des 7 derniers jours | Tous les développeurs |
| GET [`/2/tweets/counts/all`](/fr/x-api/posts/get-count-of-all-posts) | Compte les publications de l’archive complète | Facturation à l’usage, Enterprise |

***

<div id="granularity-options">
  ## Options de granularité
</div>

Indiquez comment les décomptes sont regroupés à l&#39;aide du paramètre `granularity` :

| Granularity | Description | Cas d’usage |
|:------------|:------------|:-----------|
| `minute` | Décomptes par minute | Surveillance en temps réel |
| `hour` | Décomptes par heure (valeur par défaut) | Analyse quotidienne |
| `day` | Décomptes par jour | Tendances à long terme |

<div id="recent-counts">
  ## Comptages récents
</div>

Compter les Publications des **7 derniers jours**. Accessible à tous les développeurs.

<div id="features">
  ### Fonctionnalités
</div>

* Décomptes regroupés par minute, heure ou jour
* Mêmes opérateurs de requête que pour la recherche récente
* Longueur maximale de la requête : 512 caractères

<div id="example-response">
  ### Exemple de réponse
</div>

```json
{
  "data": [
    { "start": "2024-01-15T00:00:00.000Z", "end": "2024-01-15T01:00:00.000Z", "tweet_count": 1523 },
    { "start": "2024-01-15T01:00:00.000Z", "end": "2024-01-15T02:00:00.000Z", "tweet_count": 1247 },
    { "start": "2024-01-15T02:00:00.000Z", "end": "2024-01-15T03:00:00.000Z", "tweet_count": 892 }
  ],
  "meta": {
    "total_tweet_count": 3662
  }
}
```

<div id="full-archive-counts">
  ## Décomptes sur l’archive complète
</div>

Obtenez le nombre de Publications dans **l’archive complète** depuis 2006.

<Note>
  La fonctionnalité de décompte sur l’archive complète est disponible pour les clients au paiement à l’usage et les clients Enterprise.
</Note>

<div id="features">
  ### Fonctionnalités
</div>

* Compter les Publications historiques pour n&#39;importe quelle période
* Tous les opérateurs de requête sont disponibles
* Longueur maximale de requête de 1 024 caractères (4 096 pour Enterprise)

<div id="pagination">
  ### Pagination
</div>

Les résultats sont paginés sur des périodes de 31 jours par réponse :

* **Granularité par jour** : 31 jours par page
* **Granularité par heure** : 744 heures (31 jours) par page
* **Granularité par minute** : 44 640 minutes (31 jours) par page

<div id="important-notes">
  ## Notes importantes
</div>

<Note>
  **Dénombrements vs résultats de recherche**

  Les dénombrements peuvent ne pas correspondre exactement aux résultats de recherche. Les points de terminaison de recherche appliquent un filtrage de conformité supplémentaire qui n’est pas effectué par les points de terminaison de dénombrement.
</Note>
