Les endpoints de comptage de Publications renvoient le nombre de Publications correspondant à une requête au fil du temps, sans renvoyer les Publications elles-mêmes. Utilisez ces endpoints pour analyser les tendances, comprendre l’ampleur des conversations et affiner vos requêtes avant d’effectuer une recherche.

<div id="endpoints">
  ## Endpoints
</div>

| Endpoint | Description | Access |
|:---------|:------------|:-------|
| GET [`/2/tweets/counts/recent`](/fr/x-api/posts/get-count-of-recent-posts) | Nombre de Publications des 7 derniers jours | Tous les développeurs |
| GET [`/2/tweets/counts/all`](/fr/x-api/posts/get-count-of-all-posts) | Nombre de Publications de l&#39;archive complète | Facturation à l&#39;utilisation, Enterprise |

***

<div id="granularity-options">
  ## Options de granularité
</div>

Indiquez comment les comptages sont regroupés à l&#39;aide du paramètre `granularity` :

| Granularité | Description | Cas d&#39;utilisation |
|:------------|:------------|:------------------|
| `minute` | Comptages par minute | Surveillance en temps réel |
| `hour` | Comptages par heure (valeur par défaut) | Analyse quotidienne |
| `day` | Comptages par jour | Tendances à long terme |

***

<div id="recent-counts">
  ## Décomptes récents
</div>

Calculez le nombre de Publications des **7 derniers jours**. Disponible pour tous les développeurs.

<div id="features">
  ### Fonctionnalités
</div>

* Comptages regroupés par minute, heure ou jour
* Mêmes opérateurs de requête que pour la recherche récente
* Longueur de requête maximale de 512 caractères

<div id="example-response">
  ### Exemple de réponse
</div>

```json
{
  "data": [
    { "start": "2024-01-15T00:00:00.000Z", "end": "2024-01-15T01:00:00.000Z", "tweet_count": 1523 },
    { "start": "2024-01-15T01:00:00.000Z", "end": "2024-01-15T02:00:00.000Z", "tweet_count": 1247 },
    { "start": "2024-01-15T02:00:00.000Z", "end": "2024-01-15T03:00:00.000Z", "tweet_count": 892 }
  ],
  "meta": {
    "total_tweet_count": 3662
  }
}
```

<div id="full-archive-counts">
  ## Décomptes sur l’archive complète
</div>

Obtenez le nombre de Publications depuis l’**archive complète** remontant jusqu’à 2006.

<Note>
  Les décomptes sur l’archive complète sont disponibles pour les clients à l’usage et les clients Enterprise.
</Note>

<div id="features">
  ### Fonctionnalités
</div>

* Compter les Publications historiques sur n’importe quelle période
* Tous les opérateurs de requête sont disponibles
* Longueur de requête pouvant atteindre 1 024 caractères (4 096 pour Enterprise)

<div id="pagination">
  ### Pagination
</div>

Les résultats sont paginés par périodes de 31 jours par réponse :

* **Granularité jour** : 31 jours par page
* **Granularité heure** : 744 heures (31 jours) par page
* **Granularité minute** : 44 640 minutes (31 jours) par page

</div>

<div id="important-notes">
  ## Remarques importantes
</div>

<Note>
  **Comptages vs résultats de recherche**

  Les comptages peuvent ne pas correspondre exactement aux résultats de recherche. Les endpoints de recherche appliquent un filtrage de conformité supplémentaire que les endpoints de comptage n’appliquent pas.
</Note>
