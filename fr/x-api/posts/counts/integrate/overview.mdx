Cette page présente les outils et concepts clés pour intégrer les endpoints de comptage des publications.

***

<div id="helpful-tools">
  ## Outils pratiques
</div>

Avant de commencer à explorer des concepts clés, nous vous recommandons d’utiliser l’un des outils ou exemples de code suivants pour commencer à tester le fonctionnement de ces endpoints.

<div id="code-samples">
  ### Exemples de code
</div>

Vous souhaitez mettre en place ces endpoints dans votre langage de programmation préféré ? Nous proposons plusieurs exemples de code que vous pouvez utiliser comme point de départ sur notre [page GitHub](https://github.com/xdevplatform/Twitter-API-v2-sample-code), y compris un [client Python](https://github.com/xdevplatform/search-tweets-python).

<div id="libraries">
  ### Bibliothèques
</div>

Tirez parti de l’une de nos nombreuses [bibliothèques tierces développées par la communauté](/fr/x-api/tools-and-libraries/overview) pour vous aider à démarrer. Vous pouvez trouver une bibliothèque compatible avec les points de terminaison v2 en recherchant l’étiquette de version appropriée.

<div id="postman">
  ### Postman
</div>

Postman est un excellent outil que vous pouvez utiliser pour tester ces endpoints. Chaque requête Postman contient tous les paramètres de l’endpoint concerné afin de vous aider à comprendre rapidement ce qui est à votre disposition. Pour en savoir plus sur nos collections Postman, veuillez consulter notre page [Utiliser Postman](/fr/tutorials/postman-getting-started).

<div id="key-concepts">
  ## Concepts clés
</div>

<div id="authentication">
  ### Authentification
</div>

Tous les endpoints de X API v2 exigent que les requêtes soient [authentifiées](/fr/resources/fundamentals/authentication) avec un ensemble d’identifiants, également appelés clés et jetons. Cet endpoint spécifique nécessite l’utilisation d’[OAuth 2.0 Bearer Token](/fr/resources/fundamentals/authentication#oauth-2-0), ce qui signifie que vous devez transmettre un [Bearer Token](/fr/resources/fundamentals/authentication#bearer-token-also-known-as-app-only) pour effectuer une requête réussie. Vous pouvez générer un Bearer Token soit directement dans une App développeur, soit à l’aide de l’endpoint [POST oauth2/token](/fr/resources/fundamentals/authentication#post-oauth2-token).

<div id="developer-console-projects-and-developer-apps">
  ### Console de Développement, Projets et Apps développeur
</div>

Pour travailler avec n’importe quel endpoint de X API v2, vous devez disposer d’un [compte développeur](/fr/resources/fundamentals/developer-portal), configurer un [Projet](/fr/resources/fundamentals/developer-apps) dans ce compte, puis créer une [App développeur](/fr/resources/fundamentals/developer-apps) dans ce Projet. Les clés et jetons de cette App développeur fonctionneront avec les endpoints de comptage de Publications récentes. Si vous souhaitez utiliser l’endpoint de comptage de Publications sur l’archive complète, ou utiliser les opérateurs avancés et des requêtes plus longues, vous devrez avoir été approuvé pour un accès Entreprise.

Veuillez consulter notre section sur l’accès Entreprise pour en savoir plus.

<div id="rate-limits">
  ### Limites de débit
</div>

Chaque jour, plusieurs milliers de développeurs envoient des requêtes à X API. Pour aider à gérer ce volume, des [limites de débit](/fr/x-api/fundamentals/rate-limits) sont appliquées à chaque endpoint afin de limiter le nombre de requêtes que chaque développeur peut effectuer au nom d’une application ou d’un utilisateur authentifié.

Cet endpoint est soumis à une limite de débit au niveau de l’App, ce qui signifie que vous, en tant que développeur, ne pouvez effectuer qu’un nombre déterminé de requêtes vers cet endpoint sur une période donnée depuis une App donnée (définie par les identifiants que vous utilisez).

<div id="building-queries">
  ### Créer des requêtes
</div>

La caractéristique principale de ces endpoints est l&#39;utilisation d&#39;une requête unique pour filtrer les Publications dans les décomptes qui vous sont renvoyés. Ces requêtes sont composées d&#39;opérateurs qui portent sur des attributs de Publication et d&#39;utilisateur, comme les mots-clés du message, les hashtags et les URL. Les opérateurs peuvent être combinés dans des requêtes à l&#39;aide de la logique booléenne et de parenthèses pour affiner le comportement de correspondance de la requête.

Vous pouvez consulter notre guide sur [comment créer une requête](/fr/x-api/posts/counts/integrate/build-a-query) pour en savoir plus.

<div id="pagination">
  ### Pagination
</div>

Pour les décomptes récents de Publications, aucun next&#95;token n&#39;est renvoyé, ce qui signifie que, quelle que soit la granularité, vous obtiendrez le volume de Publications des 7 derniers jours en un seul appel d&#39;API.

Pour les décomptes de Publications sur l&#39;intégralité des archives, vous obtiendrez des données pour les 30 derniers jours. Pour des données de plus de 30 jours, vous recevrez un next&#95;token que vous pourrez ensuite utiliser pour paginer et récupérer les données supplémentaires.
