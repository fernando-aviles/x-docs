Cette page présente les outils et concepts clés pour intégrer les endpoints de comptage des Publications.

***

<div id="helpful-tools">
  ## Outils pratiques
</div>

Avant de commencer à explorer certains concepts clés, nous vous recommandons d&#39;utiliser l&#39;un des outils ou exemples de code suivants pour tester les fonctionnalités de ces endpoints.

<div id="code-samples">
  ### Exemples de code
</div>

Vous souhaitez mettre en place ces endpoints avec du code dans votre langage de programmation préféré ? Nous proposons plusieurs exemples de code que vous pouvez utiliser comme point de départ sur notre [page GitHub](https://github.com/xdevplatform/Twitter-API-v2-sample-code), y compris un [client Python](https://github.com/xdevplatform/search-tweets-python).

<div id="libraries">
  ### Bibliothèques
</div>

Tirez parti de l&#39;une de nos nombreuses [bibliothèques tierces développées par la communauté](/fr/x-api/tools-and-libraries/overview) pour vous aider à démarrer. Vous pouvez trouver une bibliothèque compatible avec les points de terminaison v2 en recherchant la balise de version appropriée.

<div id="postman">
  ### Postman
</div>

Postman est un excellent outil que vous pouvez utiliser pour tester ces endpoints. Chaque requête Postman inclut tous les paramètres de l&#39;endpoint correspondant pour vous aider à comprendre rapidement ce qui est à votre disposition. Pour en savoir plus sur nos collections Postman, consultez notre page [Utiliser Postman](/fr/tutorials/postman-getting-started).

<div id="key-concepts">
  ## Concepts essentiels
</div>

<div id="authentication">
  ### Authentification
</div>

Tous les endpoints de X API v2 exigent que les requêtes soient [authentifiées](/fr/resources/fundamentals/authentication) à l’aide d’un ensemble d’identifiants, également appelés clés et jetons. Cet endpoint particulier nécessite l’utilisation d’[OAuth 2.0 Bearer Token](/fr/resources/fundamentals/authentication#oauth-2-0), ce qui signifie que vous devez inclure un [Bearer Token](/fr/resources/fundamentals/authentication#bearer-token-also-known-as-app-only) pour effectuer une requête avec succès. Vous pouvez soit générer un Bearer Token directement depuis une App développeur, soit en générer un à l’aide de l’endpoint [POST oauth2/token](/fr/resources/fundamentals/authentication#post-oauth2-token).

<div id="developer-console-projects-and-developer-apps">
  ### Developer Console, Projets et Apps développeur
</div>

Pour utiliser n&#39;importe quel endpoint de X API v2, vous devez disposer d&#39;un [compte développeur](/fr/resources/fundamentals/developer-portal), configurer un [Projet](/fr/resources/fundamentals/developer-apps) dans ce compte, puis créer une [App développeur](/fr/resources/fundamentals/developer-apps) dans ce Projet. Les clés et jetons de cette App développeur fonctionneront avec les endpoints de comptage de Publications récentes. Si vous souhaitez utiliser l&#39;endpoint de comptage de Publications sur l&#39;intégralité de l&#39;archive ou exploiter les opérateurs avancés et une longueur de requête plus importante, vous devrez avoir obtenu un accès Enterprise.

Veuillez consulter notre section consacrée à l&#39;accès Enterprise pour en savoir plus.

<div id="rate-limits">
  ### Limites de débit
</div>

Chaque jour, plusieurs milliers de développeurs envoient des requêtes à la X API. Pour gérer ce volume, des [limites de débit](/fr/x-api/fundamentals/rate-limits) sont appliquées à chaque endpoint, ce qui restreint le nombre de requêtes que chaque développeur peut effectuer pour le compte d&#39;une application ou d&#39;un utilisateur authentifié.

Cet endpoint est limité au niveau de l&#39;application, ce qui signifie que vous, en tant que développeur, ne pouvez effectuer qu&#39;un certain nombre de requêtes vers cet endpoint sur une période donnée à partir d&#39;une application donnée (telle qu&#39;identifiée par les identifiants que vous utilisez).

<div id="building-queries">
  ### Créer des requêtes
</div>

La fonctionnalité principale de ces endpoints est l&#39;utilisation d&#39;une requête unique pour filtrer les Publications dans les décomptes qui vous sont renvoyés. Ces requêtes sont constituées d&#39;opérateurs qui portent sur des attributs de Publication et d&#39;utilisateur, tels que des mots-clés de message, des hashtags et des URL. Les opérateurs peuvent être combinés dans des requêtes à l&#39;aide de logique booléenne et de parenthèses pour affiner la façon dont la requête effectue ses correspondances.

Vous pouvez consulter notre guide sur [comment créer une requête](/fr/x-api/posts/counts/integrate/build-a-query) pour en savoir plus.

<div id="pagination">
  ### Pagination
</div>

Pour les décomptes de Publications récentes, aucun next&#95;token n’est renvoyé, ce qui signifie que, quel que soit le niveau de granularité, vous obtiendrez le volume de Publications des 7 derniers jours en un seul appel d’API.

Pour les décomptes de Publications sur l’ensemble de l’archive, vous obtiendrez des données pour les 30 derniers jours. Pour les données de plus de 30 jours, vous recevrez un next&#95;token que vous pourrez ensuite utiliser pour effectuer la pagination et récupérer les données supplémentaires.
