<div id="comparing-x-apis-search-posts-endpoints">
  ## Comparaison des endpoints de recherche de publications de X API
</div>

L&#39;endpoint v2 Search Tweets finira par remplacer l&#39;endpoint [standard v1.1 search/posts](/fr/x-api/posts/search/introduction) et l&#39;[enterprise Search API](/fr/x-api/enterprise-gnip-2.0/fundamentals/search-api). Si vous avez du code, des applications ou des outils qui utilisent une version plus ancienne d&#39;un endpoint de recherche X et que vous envisagez de migrer vers les nouveaux endpoints de X API v2, ce guide est fait pour vous.

***

**Comparaison des opérateurs de filtrage**

Les quatre versions différentes (standard, Enterprise et v2) de recherche de Publications diffèrent par les opérateurs disponibles et présentent également différents niveaux de disponibilité des opérateurs au sein de chaque version, comme expliqué ci-dessous.

Enterprise

* Il n’existe pas de sous-niveaux d’opérateurs Enterprise

X API v2

* **En libre-service :** Disponible lors de l’utilisation de n’importe quel Project
* **Enterprise :** Disponible lors de l’utilisation d’un Project

Vous pouvez en savoir plus sur chacun de ces ensembles d’opérateurs dans leurs guides respectifs :

* [Enterprise operators](/fr/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [X API v2 operators](/fr/x-api/posts/search/integrate/build-a-query#operators)
