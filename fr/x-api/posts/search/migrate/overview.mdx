<div id="comparing-x-apis-search-posts-endpoints">
  ## Comparaison des endpoints de recherche de Publications de X API
</div>

L’endpoint v2 Search Tweets finira par remplacer l’endpoint [standard v1.1 search/posts](/fr/x-api/posts/search/introduction) et l’[enterprise Search API](/fr/x-api/enterprise-gnip-2.0/fundamentals/search-api). Si votre code, vos applications ou vos outils utilisent une ancienne version d’un endpoint de recherche X et que vous envisagez de migrer vers les nouveaux endpoints X API v2, alors ce guide est fait pour vous.

***

**Comparaison des opérateurs de filtrage**

Les quatre versions différentes (standard, enterprise et v2) de recherche de Publications diffèrent par les opérateurs disponibles et présentent également différents niveaux de disponibilité des opérateurs au sein de chaque version, expliqués ci-dessous.

Enterprise

* Il n’existe pas de sous-niveaux d’opérateurs enterprise

X API v2

* **Libre-service :** disponible lors de l’utilisation de n’importe quel Projet
* **Enterprise :** disponible lors de l’utilisation d’un Projet

Vous pouvez en savoir plus sur chacun de ces ensembles d’opérateurs dans leurs guides respectifs :

* [Opérateurs Enterprise](/fr/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [Opérateurs X API v2](/fr/x-api/posts/search/integrate/build-a-query#operators)
