Les endpoints Search Posts vous permettent de trouver des Publications correspondant à des critères précis à l&#39;aide de puissants opérateurs de requête. Recherchez des mots-clés, des hashtags, des mentions, des URL et plus encore.

<div id="overview">
  ## Vue d’ensemble
</div>

X propose deux endpoints de recherche avec des plages temporelles et des exigences d’accès différentes :

<CardGroup cols={2}>
  <Card title="Recherche récente" icon="clock">
    Recherchez des publications des **7 derniers jours**. Disponible pour tous les développeurs.
  </Card>

  <Card title="Recherche dans l’archive complète" icon="vault">
    Recherchez dans **l’archive complète** depuis 2006. Disponible pour les clients à l’usage (pay-per-use) et les clients Enterprise.
  </Card>
</CardGroup>

***

<div id="use-cases">
  ## Cas d’utilisation
</div>

* **Surveillance de la marque** — Suivre les mentions de votre marque ou de vos produits
* **Analyse des tendances** — Analyser les conversations autour de sujets ou d’événements
* **Recherche** — Rassembler des données pour la recherche académique ou de marché
* **Écoute en temps réel** — Créer des applications qui réagissent aux nouvelles Publications

***

<div id="endpoints">
  ## Points de terminaison
</div>

| Method | Endpoint | Description | Access |
|:-------|:---------|:------------|:-------|
| GET | [`/2/tweets/search/recent`](/fr/x-api/posts/search-recent-posts) | Rechercher des publications des 7 derniers jours | Tous les développeurs |
| GET | [`/2/tweets/search/all`](/fr/x-api/posts/search-all-posts) | Rechercher dans l’intégralité de l’archive des publications | Facturation à l’utilisation, Entreprise |

<div id="query-operators">
  ## Opérateurs de requête
</div>

Créez des requêtes à l&#39;aide d&#39;opérateurs qui ciblent les attributs des publications :

```
(AI OR "artificial intelligence") lang:en -is:retweet has:links
```

<AccordionGroup>
  <Accordion title="Opérateurs de mots-clés">
    | Opérateur | Exemple              | Description                                           |
    | :-------- | :------------------- | :---------------------------------------------------- |
    | Keyword   | `python`             | Correspond aux Publications contenant le mot          |
    | Phrase    | `"machine learning"` | Correspond à l’expression exacte                      |
    | Hashtag   | `#AI`                | Correspond aux Publications avec le hashtag           |
    | Mention   | `@XDevelopers`       | Correspond aux Publications mentionnant l’utilisateur |
  </Accordion>

  <Accordion title="Opérateurs d’utilisateurs">
    | Opérateur      | Exemple          | Description                                |
    | :------------- | :--------------- | :----------------------------------------- |
    | `from:`        | `from:elonmusk`  | Publications d’un utilisateur              |
    | `to:`          | `to:XDevelopers` | Réponses adressées à un utilisateur        |
    | `retweets_of:` | `retweets_of:X`  | Retweets des Publications d’un utilisateur |
  </Accordion>

  <Accordion title="Opérateurs de contenu">
    | Opérateur      | Exemple          | Description                      |
    | :------------- | :--------------- | :------------------------------- |
    | `has:images`   | `cat has:images` | Publications avec des images     |
    | `has:videos`   | `has:videos`     | Publications avec des vidéos     |
    | `has:links`    | `has:links`      | Publications avec des liens      |
    | `has:mentions` | `has:mentions`   | Publications avec des mentions   |
    | `url:`         | `url:github.com` | Publications avec une URL donnée |
  </Accordion>

  <Accordion title="Opérateurs de filtre">
    | Opérateur     | Exemple       | Description                          |
    | :------------ | :------------ | :----------------------------------- |
    | `lang:`       | `lang:en`     | Publications dans une langue donnée  |
    | `-is:retweet` | `-is:retweet` | Exclure les retweets                 |
    | `-is:reply`   | `-is:reply`   | Exclure les réponses                 |
    | `is:verified` | `is:verified` | Publications d’utilisateurs vérifiés |
  </Accordion>
</AccordionGroup>

<div id="recent-search">
  ## Recherche récente
</div>

Recherchez des Publications des **7 derniers jours**. Fonctionnalité accessible à tous les développeurs.

<div id="features">
  ### Fonctionnalités
</div>

* Jusqu’à 100 Publications par requête
* Pagination pour les grands ensembles de résultats
* Tous les principaux opérateurs de requête
* Longueur de requête de 512 caractères (4 096 pour Enterprise)

<div id="full-archive-search">
  ## Recherche dans l’archive complète
</div>

Recherchez dans **l’archive complète des Publications**, remontant à mars 2006.

<Note>
  La recherche dans l’archive complète est disponible pour les clients facturés à l’usage et les clients Enterprise.
</Note>

<div id="features">
  ### Fonctionnalités
</div>

* Jusqu’à 500 publications par requête
* Accès à l’historique complet des publications
* Tous les opérateurs de requête disponibles
* Longueur de requête de 1 024 caractères (4 096 pour Enterprise)
