Les endpoints de recherche de Publications vous permettent de trouver des Publications correspondant à des critères spécifiques grâce à de puissants opérateurs de requête. Recherchez des mots-clés, des hashtags, des mentions, des URL et plus encore.

<div id="overview">
  ## Vue d’ensemble
</div>

X propose deux endpoints de recherche avec des plages temporelles et des conditions d’accès différentes :

<CardGroup cols={2}>
  <Card title="Recherche récente" icon="clock">
    Recherchez des Publications datant des **7 derniers jours**. Disponible pour tous les développeurs.
  </Card>

  <Card title="Full-Archive Search" icon="vault">
    Recherchez dans l’**archive complète** en remontant jusqu’en 2006. Disponible pour les clients au paiement à l’utilisation et les clients Enterprise.
  </Card>
</CardGroup>

***

<div id="use-cases">
  ## Cas d’utilisation
</div>

* **Surveillance de marque** — Suivez les mentions de votre marque ou de vos produits
* **Analyse des tendances** — Analysez les conversations autour de sujets ou d’événements
* **Recherche** — Rassemblez des données pour la recherche académique ou de marché
* **Écoute en temps réel** — Créez des applications qui réagissent aux nouvelles Publications

***

<div id="endpoints">
  ## Points de terminaison
</div>

| Méthode | Point de terminaison | Description | Accès |
|:-------|:---------------------|:------------|:------|
| GET | [`/2/tweets/search/recent`](/fr/x-api/posts/search-recent-posts) | Rechercher des publications des 7 derniers jours | Tous les développeurs |
| GET | [`/2/tweets/search/all`](/fr/x-api/posts/search-all-posts) | Rechercher dans l’archive complète des publications | Facturation à l’utilisation, Enterprise |

***

<div id="query-operators">
  ## Opérateurs de requête
</div>

Créez des requêtes à l’aide d’opérateurs qui s’appliquent aux attributs des publications :

```
(AI OR "artificial intelligence") lang:en -is:retweet has:links
```

<AccordionGroup>
  <Accordion title="Opérateurs de mots-clés">
    | Opérateur | Exemple              | Description                                               |
    | :-------- | :------------------- | :-------------------------------------------------------- |
    | Keyword   | `python`             | Correspond aux Publications contenant ce mot              |
    | Phrase    | `"machine learning"` | Correspond à l&#39;expression exacte                      |
    | Hashtag   | `#AI`                | Correspond aux Publications avec ce hashtag               |
    | Mention   | `@XDevelopers`       | Correspond aux Publications mentionnant l&#39;utilisateur |
  </Accordion>

  <Accordion title="Opérateurs liés aux utilisateurs">
    | Opérateur      | Exemple          | Description                                    |
    | :------------- | :--------------- | :--------------------------------------------- |
    | `from:`        | `from:elonmusk`  | Publications d&#39;un utilisateur              |
    | `to:`          | `to:XDevelopers` | Réponses adressées à un utilisateur            |
    | `retweets_of:` | `retweets_of:X`  | Retweets des Publications d&#39;un utilisateur |
  </Accordion>

  <Accordion title="Opérateurs de contenu">
    | Opérateur      | Exemple          | Description                               |
    | :------------- | :--------------- | :---------------------------------------- |
    | `has:images`   | `cat has:images` | Publications avec des images              |
    | `has:videos`   | `has:videos`     | Publications avec des vidéos              |
    | `has:links`    | `has:links`      | Publications avec des liens               |
    | `has:mentions` | `has:mentions`   | Publications avec des mentions            |
    | `url:`         | `url:github.com` | Publications contenant une URL spécifique |
  </Accordion>

  <Accordion title="Opérateurs de filtrage">
    | Opérateur     | Exemple       | Description                              |
    | :------------ | :------------ | :--------------------------------------- |
    | `lang:`       | `lang:en`     | Publications dans une langue donnée      |
    | `-is:retweet` | `-is:retweet` | Exclut les retweets                      |
    | `-is:reply`   | `-is:reply`   | Exclut les réponses                      |
    | `is:verified` | `is:verified` | Publications d&#39;utilisateurs vérifiés |
  </Accordion>
</AccordionGroup>

<div id="recent-search">
  ## Recherche récente
</div>

Recherchez des Publications datant des **7 derniers jours**. Fonctionnalité accessible à tous les développeurs.

<div id="features">
  ### Fonctionnalités
</div>

* Jusqu&#39;à 100 publications par requête
* Pagination pour les grands ensembles de résultats
* Tous les principaux opérateurs de requête
* Longueur de requête de 512 caractères (4 096 pour Enterprise)

<div id="full-archive-search">
  ## Recherche dans l’archive complète
</div>

Recherchez dans **l’archive complète des publications** remontant à mars 2006.

<Note>
  La recherche dans l’archive complète est disponible pour les clients facturés à l’usage et les clients Enterprise.
</Note>

<div id="features">
  ### Fonctionnalités
</div>

* Jusqu’à 500 Publications par requête
* Accès à l’historique complet des Publications
* Tous les opérateurs de requête disponibles
* Longueur de requête de 1 024 caractères (4 096 pour Enterprise)
