Ce guide vous explique comment masquer et réafficher des réponses aux Publications dans les conversations que vous avez initiées.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin de :

  * D&#39;un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une App approuvée
  * D&#39;un jeton d&#39;accès utilisateur (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

***

<div id="hide-a-reply">
  ## Masquer une réponse
</div>

<Steps>
  <Step title="Trouver l'ID de la Publication de la réponse" icon="message">
    Récupérez l&#39;ID de la réponse que vous souhaitez masquer. Vous ne pouvez masquer que les réponses aux conversations démarrées par l&#39;utilisateur authentifié.

    ```
    https://x.com/user/status/1232720193182412800
                              └── Ceci est l'ID de la Publication
    ```
  </Step>

  <Step title="Envoyer la requête de masquage" icon="eye-slash">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X PUT "https://api.x.com/2/tweets/1232720193182412800/hidden" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"hidden": true}'
      ```

      ```python Python SDK
      from xdk import Client
      from xdk.oauth1_auth import OAuth1

      oauth1 = OAuth1(
          api_key="YOUR_API_KEY",
          api_secret="YOUR_API_SECRET",
          access_token="YOUR_ACCESS_TOKEN",
          access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
      )

      client = Client(auth=oauth1)

      # Masquer une réponse
      response = client.posts.hide_reply("1232720193182412800", hidden=True)
      print(f"Hidden: {response.data.hidden}")
      ```

      ```javascript JavaScript SDK
      import { Client, OAuth1 } from "@xdevplatform/xdk";

      const oauth1 = new OAuth1({
        apiKey: "YOUR_API_KEY",
        apiSecret: "YOUR_API_SECRET",
        accessToken: "YOUR_ACCESS_TOKEN",
        accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
      });

      const client = new Client({ oauth1 });

      // Masquer une réponse
      const response = await client.posts.hideReply("1232720193182412800", {
        hidden: true,
      });
      console.log(`Hidden: ${response.data?.hidden}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="Confirmer que la réponse est masquée" icon="check">
    ```json
    {
      "data": {
        "hidden": true
      }
    }
    ```

    La réponse est maintenant masquée dans la vue principale de la conversation. Les utilisateurs peuvent toujours la voir en cliquant sur « Afficher les réponses masquées ».
  </Step>
</Steps>

***

<div id="unhide-a-reply">
  ## Réafficher une réponse
</div>

Pour réafficher une réponse masquée :

<CodeGroup dropdown>
  ```bash cURL
  curl -X PUT "https://api.x.com/2/tweets/1232720193182412800/hidden" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"hidden": false}'
  ```

  ```python SDK Python
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Réafficher une réponse
  response = client.posts.hide_reply("1232720193182412800", hidden=False)
  print(f"Hidden: {response.data.hidden}")
  ```

  ```javascript SDK JavaScript
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Réafficher une réponse
  const response = await client.posts.hideReply("1232720193182412800", {
    hidden: false,
  });
  console.log(`Hidden: ${response.data?.hidden}`);
  ```
</CodeGroup>

**Réponse :**

```json
{
  "data": {
    "hidden": false
  }
}
```

***

<div id="important-notes">
  ## Remarques importantes
</div>

<Note>
  * Vous ne pouvez masquer que les réponses aux conversations **que vous avez initiées**
  * Les réponses masquées restent visibles via « Afficher les réponses masquées »
  * L’auteur de la réponse n’est pas averti lorsque sa réponse est masquée
</Note>
