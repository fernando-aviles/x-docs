<div id="apps-using-the-hide-replies-endpoint">
  ## Apps utilisant l’endpoint Hide replies
</div>

Voici une collection d’apps remarquables créées par des développeurs qui ont intégré l’endpoint Hide replies. En associant leur technologie à la X API, ils ont créé des expériences utiles pour aider tous les utilisateurs à améliorer la conversation publique.

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge intègre le masquage des réponses afin que les entreprises puissent garder leur fil X propre et agréable à lire. Les réponses peuvent être masquées manuellement, et les agents peuvent également utiliser les capacités d’analyse de texte de Clarabridge pour détecter automatiquement les grossièretés et autres formulations qui ne sont pas conformes à la politique de la marque.

[Aller sur le site ▸](https://www.clarabridge.com/ "Aller sur le site ▸")

[Clarabridge sur X](https://x.com/Clarabridge "Clarabridge sur X")

![Perspective API template app](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**App modèle Perspective API**

Perspective est une intelligence artificielle entraînée par Jigsaw (une unité d’Alphabet) pour détecter les commentaires toxiques. Cette app détecte les réponses entrantes d’une personne et masque automatiquement une réponse en fonction du « score » qui indique le niveau de confiance de Perspective quant au fait qu’un commentaire est similaire à des commentaires toxiques qu’elle a déjà vus. Il s’agit d’une app modèle open source développée par X. Nous vous encourageons à la personnaliser pour créer des outils pour vos utilisateurs.

[Utiliser l’app ▸](https://quintessential-yoke.glitch.me "Utiliser l’app ▸")

[Jigsaw sur X](https://x.com/jigsaw "Jigsaw sur X")

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle est une plateforme permettant de connecter des applications métier avec des scripts flexibles. Ils ont créé un script d’intégration pour détecter et masquer les réponses qui incluent les mots-clés que vous définissez. Pour l’essayer, assurez-vous d’avoir une app valide activée pour Hide replies, puis suivez les instructions dans le dépôt.

[Aller sur l’app ▸](https://github.com/reshufflehq/reshuffle "Aller sur l’app ▸")

[Reshuffle sur X](https://x.com/reshufflehq "Reshuffle sur X")

![Hide unwanted replies](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 396 397%22%3E%3C/svg%3E)

**Hide unwanted replies**

Dara Oladosu, le développeur derrière l’app populaire QuotedReplies, a créé une app qui masque automatiquement les réponses répondant à certains critères qu’il a identifiés comme étant plus susceptibles de refléter un comportement abusif, notamment les réponses contenant certains mots-clés qu’il a mis en sourdine par le passé.

[Aller sur l’app ▸](https://hideunwantedreplies.com/ "Aller sur l’app ▸")

[Dara Oladosu sur X](https://x.com/dara_tobi "Dara Oladosu sur X")

![Pandaflow](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 94 94%22%3E%3C/svg%3E)

**Pandaflow**

Pandaflow est une plateforme no code pour automatiser des workflows. Ils intègrent l’endpoint afin que les utilisateurs puissent masquer des réponses de manière programmatique en fonction d’un flux personnalisé qu’ils définissent.

[Aller sur l’app ▸](https://pandaflow.io/ "Aller sur l’app ▸")

[Pandaflow sur X](https://x.com/pandaflowio "Pandaflow sur X")
