  ## Applications utilisant l’endpoint de masquage des réponses
</div>

Voici une sélection d’applications remarquables créées par des développeurs qui ont intégré l’endpoint de masquage des réponses. En associant leurs technologies à la X API, ils ont créé des expériences utiles pour aider tous les utilisateurs à améliorer la conversation publique.

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge intègre le masquage des réponses afin que les entreprises puissent garder leur fil X propre et agréable à lire. Les réponses peuvent être masquées manuellement, et les agents peuvent également utiliser l’analyse de texte de Clarabridge pour détecter automatiquement les propos grossiers et tout autre langage non conforme à la politique de la marque.

[Aller sur le site ▸](https://www.clarabridge.com/ "Aller sur le site ▸")

[Clarabridge sur X](https://x.com/Clarabridge "Clarabridge sur X")

![Perspective API template app](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Application modèle Perspective API**

Perspective est une intelligence artificielle entraînée par Jigsaw (une unité d’Alphabet) pour détecter les commentaires toxiques. Cette application détecte les réponses entrantes d’une personne et masque automatiquement une réponse en fonction du « score » qui indique le degré de confiance de Perspective dans le fait qu’un commentaire est similaire à des commentaires toxiques qu’il a déjà vus. Il s’agit d’une application modèle open source développée par X. Nous vous encourageons à la personnaliser pour créer des outils pour vos utilisateurs.

[Utiliser l’application ▸](https://quintessential-yoke.glitch.me "Utiliser l’application ▸")

[Jigsaw sur X](https://x.com/jigsaw "Jigsaw sur X")

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle est une plateforme permettant de connecter des applications métier à l’aide de scripts flexibles. Ils ont créé un script d’intégration pour détecter et masquer les réponses qui contiennent les mots-clés que vous définissez. Pour l’essayer, assurez-vous d’avoir une application valide activée pour le masquage des réponses, puis suivez les instructions dans le dépôt.

[Accéder à l’application ▸](https://github.com/reshufflehq/reshuffle "Accéder à l’application ▸")

[Reshuffle sur X](https://x.com/reshufflehq "Reshuffle sur X")

![Hide unwanted replies](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 396 397%22%3E%3C/svg%3E)

**Masquer les réponses indésirables**

Dara Oladosu, le développeur à l’origine de la populaire application QuotedReplies, a créé une application qui masque automatiquement les réponses répondant à certains critères qu’il a identifiés comme plus susceptibles de refléter un comportement abusif, y compris les réponses contenant certains mots-clés qu’il a mis en sourdine par le passé.

[Accéder à l’application ▸](https://hideunwantedreplies.com/ "Accéder à l’application ▸")

[Dara Oladosu sur X](https://x.com/dara_tobi "Dara Oladosu sur X")

![Pandaflow](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 94 94%22%3E%3C/svg%3E)

**Pandaflow**

Pandaflow est une plateforme sans code pour automatiser des workflows. Ils intègrent l’endpoint afin que les utilisateurs puissent masquer des réponses de façon programmatique en fonction d’un workflow personnalisé qu’ils définissent.

[Accéder à l’application ▸](https://pandaflow.io/ "Accéder à l’application ▸")

[Pandaflow sur X](https://x.com/pandaflowio "Pandaflow sur X")
