Le point de terminaison Hide Replies vous permet de masquer ou de réafficher les réponses aux Publications créées par l’utilisateur authentifié. Les réponses masquées restent accessibles, mais nécessitent un clic supplémentaire pour être consultées.

<div id="endpoint">
  ## Point de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------------------|:------------|
| PUT | [`/2/tweets/:tweet_id/hidden`](/fr/x-api/posts/hide-reply) | Masquer ou réafficher une réponse |

***

<div id="how-it-works">
  ## Comment cela fonctionne
</div>

Envoyez une requête PUT avec `hidden: true` pour masquer une réponse, ou `hidden: false` pour l&#39;afficher à nouveau :

```json
{
  "hidden": true
}
```

***

<div id="example-hide-a-reply">
  ## Exemple : Masquer une réponse
</div>

```bash
curl -X PUT "https://api.x.com/2/tweets/1234567890/hidden" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"hidden": true}'
```

<div id="example-response">
  ## Exemple de réponse
</div>

```json
{
  "data": {
    "hidden": true
  }
}
```
