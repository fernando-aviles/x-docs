<div id="comparing-x-apis-manage-posts-endpoints">
  ## Comparaison des endpoints de gestion des Publications de X API
</div>

Les endpoints v2 de gestion des Publications remplaceront les endpoints standards v1.1 [POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) et [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id). Si vous avez du code, des applications ou des outils qui utilisent la version v1.1 des endpoints de gestion des Publications et que vous envisagez de migrer vers le nouvel endpoint X API v2, cette série de guides est faite pour vous.

Les tableaux suivants comparent les endpoints standards v1.1 et X API v2 de gestion des Publications :

<div id="create-a-post">
  ### Créer une publication
</div>

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin de l&#39;endpoint | /1.1/statuses/update.json | /2/tweets |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Limites de fréquence des requêtes par défaut](/fr/x-api/fundamentals/rate-limits) | Aucune<br /><br />300 requêtes par tranche de 3 heures, par utilisateur et par App. Partagées avec l&#39;endpoint v1.1 POST Retweets. | 200 requêtes par tranche de 15 minutes, par utilisateur<br /><br />300 requêtes par tranche de 3 heures, par utilisateur et par App. Partagées avec l&#39;endpoint v2 POST Retweets. |
| Nécessite l&#39;utilisation d&#39;identifiants provenant d&#39;une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) |     | ✔   |

<div id="delete-a-post">
  ### Supprimer une Publication
</div>

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | DELETE |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin de l’endpoint | /1.1/statuses/destroy/:id.json | /2/tweets/:id |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE |
| [Limites de fréquence des requêtes par défaut](/fr/x-api/fundamentals/rate-limits) | Aucune | 50 requêtes par tranche de 15 min et par utilisateur |
| Nécessite l’utilisation d’identifiants provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) |     | ✔   |
