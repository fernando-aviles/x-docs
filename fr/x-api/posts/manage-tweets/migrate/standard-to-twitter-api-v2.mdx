<div id="standard-v11-compared-to-x-api-v2">
  ## Standard v1.1 comparé à X API v2
</div>

Si vous avez travaillé avec les points de terminaison standard v1.1 [POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) et [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id), l&#39;objectif de ce guide est de vous aider à comprendre les similitudes et les différences entre les points de terminaison standard et les points de terminaison de gestion des Publications dans X API v2.

* **Similitudes**
  * Authentification
* **Différences**
  * URL des points de terminaison

  * Exigences relatives à l&#39;App et au Projet

  * Paramètres de requête

<div id="similarities">
  ### Similarités
</div>

**Authentification**

Les endpoints de gestion des Publications dans la v1.1 standard et dans X API v2 ([POST statuses/update](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-update) et [POST statuses/destroy/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-destroy-id)) utilisent tous deux [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication). Par conséquent, si vous utilisiez auparavant l&#39;un des endpoints standard v1.1, vous pouvez continuer à utiliser la même méthode d&#39;authentification en migrant vers la version X API v2.

<div id="differences">
  ### Différences
</div>

**URL d’endpoint**

* Endpoints standard v1.1 :
  * https://api.x.com/1.1/statuses/update.json
    (Crée une Publication)
  * `https://api.x.com/1.1/statuses/destroy/:id.json`
    (Supprime une Publication)
* Endpoint X API v2 :
  * https://api.x.com/2/tweets
    (Crée une Publication)
  * https://api.x.com/2/tweets/:id
    (Supprime la Publication spécifiée)

<div id="app-and-project-requirements">
  ### Conditions requises pour l’App et le Projet
</div>

Les endpoints de X API v2 exigent que vous utilisiez des identifiants provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) lors de l’authentification de vos requêtes. Tous les endpoints X API v1.1 peuvent utiliser des identifiants provenant d’Apps autonomes ou d’Apps associées à un projet.

<div id="request-parameters">
  ### Paramètres de requête
</div>

Les paramètres de requête standard v1.1 suivants acceptaient l’un des deux paramètres de requête suivants (user&#95;id ou screen&#95;name). Le X API v2 n’accepte que l’id numérique de la Publication pour l’endpoint DELETE, et celui-ci doit être transmis dans le chemin de l’endpoint.

Pour l’endpoint POST, des paramètres supplémentaires devront être transmis dans le corps JSON de la requête. Vous pouvez en savoir plus sur les paramètres disponibles dans le [guide de référence de l’API](/fr/x-api/posts/manage-tweets/introduction).

  ## Exemples de code

<div id="create-a-post-v2">
  ### Créer une publication (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/tweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"text": "Hello world!"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Créer une publication
  response = client.posts.create(text="Hello world!")
  print(f"Publication créée : {response.data.id}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Créer une publication
  const response = await client.posts.create({ text: "Hello world!" });
  console.log(`Publication créée : ${response.data?.id}`);
  ```
</CodeGroup>

  ### Supprimer une publication (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/tweets/1234567890" \

  ```

  from xdk.oauth1_auth import OAuth1
