Les endpoints Manage Posts vous permettent de créer et de supprimer des Publications au nom d&#39;utilisateurs authentifiés. Développez des applications qui publient du contenu, créent des fils de discussion ou gèrent les Publications des utilisateurs.

</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------------------|:------------|
| POST | [`/2/tweets`](/fr/x-api/posts/create-post) | Créer une nouvelle Publication |

<div id="creating-posts">
  ## Création de publications
</div>

<div id="basic-post">
  ### Publication standard
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello from the API!"}'
```

<div id="reply-to-a-post">
  ### Répondre à une publication
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "This is a reply!",
    "reply": {
      "in_reply_to_tweet_id": "1234567890"
    }
  }'
```

<div id="quote-a-post">
  ### Citer une publication
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Check this out!",
    "quote_tweet_id": "1234567890"
  }'
```

<div id="post-with-media">
  ### Publication avec média
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Photo of the day",
    "media": {
      "media_ids": ["1234567890123456789"]
    }
  }'
```

<Note>
  Téléversez d&#39;abord le média à l&#39;aide du [point de terminaison Media Upload](/fr/x-api/media/quickstart/media-upload-chunked), puis indiquez le `media_id` dans votre Publication.
</Note>

<div id="post-with-poll">
  ### Publication avec un sondage
</div>

```bash
curl -X POST "https://api.x.com/2/tweets" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "What is your favorite color?",
    "poll": {
      "options": ["Red", "Blue", "Green", "Yellow"],
      "duration_minutes": 1440
    }
  }'
```

***

<div id="deleting-posts">
  ## Suppression de publications
</div>

```bash
curl -X DELETE "https://api.x.com/2/tweets/1234567890" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<Warning>
  Vous ne pouvez supprimer que les Publications créées par l’utilisateur authentifié.
</Warning>
