* Flux échantillonné à 1 %.
* Flux échantillonné à 10 %. Couramment appelé « Decahose ».

On les appelle des « flux volumétriques » car ils fournissent tous deux de grands volumes de données. Même le flux à 1 % peut émettre plusieurs dizaines de Publications chaque seconde. Avec ces flux, vous pouvez identifier et suivre des tendances, surveiller le sentiment général, surveiller des événements mondiaux, et bien plus encore. 

Ces endpoints de streaming fournissent des [objets Publication](/fr/x-api/fundamentals/data-dictionary#tweet) via une connexion HTTP GET persistante et utilisent l’authentification [OAuth 2.0 App-Only](/fr/resources/fundamentals/authentication#oauth-2-0). Avec l’accès Essential, vous pouvez avoir une connexion à la fois. Pour tous les niveaux d’accès, les requêtes de connexion peuvent être effectuées jusqu’à 50 fois par fenêtre de 15 minutes.

Ces endpoints de flux volumétriques prennent en charge les Publications modifiées. Ils fournissent les Publications modifiées avec leur historique de modifications, y compris un tableau d’ID de Publication. Pour les Publications sans historique de modification, ce tableau contient un seul ID. Pour les Publications qui ont été modifiées, ce tableau contient plusieurs ID, classés par ordre croissant reflétant l’ordre des modifications, la version la plus récente se trouvant à la dernière position du tableau. Pour en savoir plus sur le fonctionnement des modifications de Publication, consultez la page [Principes de base des modifications de Publication](/fr/x-api/fundamentals/edit-posts). 

*Pour utiliser ces API, vous devez d’abord configurer un compte auprès de notre équipe commerciale Enterprise.*

<Note>
  **Configuration du compte**

  Pour accéder à ces endpoints, vous aurez besoin :

  * D’un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) approuvé.
  * De vous authentifier en utilisant les clés et jetons d’une [App développeur](/fr/resources/fundamentals/developer-apps) qui se trouve dans un [Projet](/fr/resources/fundamentals/developer-apps). 

  Pour en savoir plus sur l’obtention de l’accès aux endpoints X API v2, consultez notre [guide de démarrage](/fr/x-api/getting-started/getting-access).
</Note>
