Ce guide vous explique comment récupérer les utilisateurs qui ont retweeté une Publication spécifique.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin de :

  * D&#39;un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une App approuvée
  * Du jeton Bearer de votre App (pour les données publiques) ou d&#39;un User Access Token (pour les métriques privées)
</Note>

***

<div id="get-users-who-retweeted-a-post">
  ## Récupérer les utilisateurs qui ont retweeté une Publication
</div>

<Steps>
  <Step title="Trouver l’ID de la Publication">
    Récupérez l’ID de la Publication dont vous voulez lister les Retweets :

    ```
    https://x.com/XDevelopers/status/1354143047324299264
                                    └── Ceci est l’ID de la Publication
    ```
  </Step>

  <Step title="Effectuer la requête">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/tweets/1354143047324299264/retweeted_by?\
      user.fields=created_at,username,verified" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # Récupérer les utilisateurs qui ont retweeté une Publication avec pagination
      for page in client.posts.get_retweeted_by(
          "1354143047324299264",
          user_fields=["created_at", "username", "verified"]
      ):
          for user in page.data:
              print(f"{user.username} - Inscription : {user.created_at}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // Récupérer les utilisateurs qui ont retweeté une Publication avec pagination
      const paginator = client.posts.getRetweetedBy("1354143047324299264", {
        userFields: ["created_at", "username", "verified"],
      });

      for await (const page of paginator) {
        page.data?.forEach((user) => {
          console.log(`${user.username} - Inscription : ${user.created_at}`);
        });
      }
      ```
    </CodeGroup>
  </Step>

  <Step title="Examiner la réponse">

  </Step>
</Steps>

<div id="include-additional-data">
  ## Inclure des données supplémentaires
</div>

Utilisez le paramètre expansions pour récupérer des données associées, comme les Publications épinglées :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/1354143047324299264/retweeted_by?\
  user.fields=created_at&\
  expansions=pinned_tweet_id&\
  tweet.fields=created_at" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # Récupérer les utilisateurs qui retweetent avec le paramètre expansions
  for page in client.posts.get_retweeted_by(
      "1354143047324299264",
      user_fields=["created_at"],
      expansions=["pinned_tweet_id"],
      tweet_fields=["created_at"]
  ):
      for user in page.data:
          print(f"{user.username}")
      # Les Publications épinglées se trouvent dans page.includes.tweets
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // Récupérer les utilisateurs qui retweetent avec le paramètre expansions
  const paginator = client.posts.getRetweetedBy("1354143047324299264", {
    userFields: ["created_at"],
    expansions: ["pinned_tweet_id"],
    tweetFields: ["created_at"],
  });

  for await (const page of paginator) {
    page.data?.forEach((user) => {
      console.log(user.username);
    });
    // Les Publications épinglées se trouvent dans page.includes?.tweets
  }
  ```
</CodeGroup>
