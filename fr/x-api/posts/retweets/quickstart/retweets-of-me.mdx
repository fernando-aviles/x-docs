Ce guide vous explique comment récupérer vos Publications qui ont été retweetées par d&#39;autres utilisateurs.

<Note>
  **Prérequis**

  Avant de commencer, vous aurez besoin de :

  * D&#39;un [compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) avec une application approuvée
  * D&#39;un jeton d&#39;accès utilisateur (OAuth 1.0a ou OAuth 2.0 PKCE)
</Note>

***

<div id="why-use-retweets-of-me">
  ## Pourquoi utiliser Retweets of Me ?
</div>

Le point de terminaison « Retweets of Me » vous aide à :

* **Suivre l’engagement** — Voir lesquelles de vos Publications sont partagées
* **Comprendre la résonance** — Identifier quels contenus résonnent auprès de votre public
* **Orienter votre stratégie** — Adapter votre stratégie de contenu en fonction des tendances de partage

***

<div id="get-your-retweeted-posts">
  ## Récupérer vos publications retweetées
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/reposts_of_me?\
  tweet.fields=created_at,public_metrics&\
  max_results=10" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Récupérer vos publications qui ont été retweetées
  for page in client.posts.get_reposts_of_me(
      tweet_fields=["created_at", "public_metrics"],
      max_results=10
  ):
      for post in page.data:
          print(f"{post.text[:50]}... - Retweets: {post.public_metrics.retweet_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Récupérer vos publications qui ont été retweetées
  const paginator = client.posts.getRepostsOfMe({
    tweetFields: ["created_at", "public_metrics"],
    maxResults: 10,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text?.slice(0, 50)}... - Retweets: ${post.public_metrics?.retweet_count}`);
    });
  }
  ```
</CodeGroup>

<div id="filter-by-time-range">
  ## Filtrer par plage temporelle
</div>

Obtenez des Publications retweetées sur une période donnée :

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/reposts_of_me?\
  start_time=2024-01-01T00%3A00%3A00Z&\
  end_time=2024-01-31T23%3A59%3A59Z&\
  tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # Récupérer les Publications retweetées sur une plage temporelle donnée
  for page in client.posts.get_reposts_of_me(
      start_time="2024-01-01T00:00:00Z",
      end_time="2024-01-31T23:59:59Z",
      tweet_fields=["created_at", "public_metrics"]
  ):
      for post in page.data:
          print(f"{post.created_at}: {post.text[:50]}...")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // Récupérer les Publications retweetées sur une plage temporelle donnée
  const paginator = client.posts.getRepostsOfMe({
    startTime: "2024-01-01T00:00:00Z",
    endTime: "2024-01-31T23:59:59Z",
    tweetFields: ["created_at", "public_metrics"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.created_at}: ${post.text?.slice(0, 50)}...`);
    });
  }
  ```
</CodeGroup>

<div id="common-parameters">
  ## Paramètres généraux
</div>

| Paramètre | Description | Par défaut |
|:----------|:------------|:--------|
| `max_results` | Résultats par page (1 à 100) | 10 |
| `start_time` | Horodatage de la publication la plus ancienne (ISO 8601) | — |
| `end_time` | Horodatage de la publication la plus récente (ISO 8601) | — |
| `pagination_token` | Jeton pour accéder à la page suivante | — |
| `tweet.fields` | Champs supplémentaires de la publication | `id`, `text` |
