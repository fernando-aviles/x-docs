<div id="manage-retweets-standard-v11-compared-to-x-api-v2">
  ### Gérer les Retweets : standard v1.1 par rapport à X API v2
</div>

Si vous avez utilisé les endpoints standard v1.1 [POST statuses/retweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-retweet-id) et [POST statuses/unretweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-unretweet-id), l’objectif de ce guide est de vous aider à comprendre les similitudes et les différences entre les endpoints de Retweets standard et ceux de X API v2.

* **Similarités**
  * Authentification
* **Différences**
  * URLs des endpoints et méthodes HTTP
  * Limitations des requêtes
  * Exigences relatives à l’App et au Projet
  * Paramètres de requête

<div id="similarities">
  #### Similarités
</div>

**Authentification**

Les endpoints de gestion des Retweets de la version standard v1.1 et de X API v2 ([POST statuses/retweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-retweet-id) et [POST statuses/unretweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-unretweet-id)) utilisent tous deux [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication). Par conséquent, si vous utilisiez auparavant l’un des endpoints de consultation des Retweets de la version standard v1.1, vous pouvez continuer à utiliser la même méthode d’authentification si vous migrez vers la version X API v2 de ces endpoints. 

<div id="differences">
  #### Différences
</div>

**URL de points de terminaison et méthodes HTTP**

* Points de terminaison standard v1.1 :
  * https://api.x.com/1.1/statuses/retweet/:id.json
    (Effectue un Retweet d&#39;une Publication. Renvoie la Publication d&#39;origine avec les détails du Retweet intégrés)
  * https://api.x.com/1.1/statuses/unretweet/:id.json
    (Annule un Retweet. Renvoie la Publication d&#39;origine avec les détails du Retweet intégrés)
* Point de terminaison X API v2 :
  * https://api.x.com/2/tweets/:id/retweets
    (Effectue un Retweet d&#39;une Publication donnée)
  * https://api.x.com/2/users/:id/retweets/:source&#95;tweet&#95;id
    (Annule un Retweet d&#39;une Publication donnée) 

**Conditions requises pour l&#39;App et le Projet**

Les points de terminaison X API v2 exigent que vous utilisiez des identifiants issus d&#39;une [developer App](/fr/resources/fundamentals/developer-apps) associée à un [Project](/fr/resources/fundamentals/developer-apps) pour authentifier vos requêtes. Tous les points de terminaison X API v1.1 peuvent utiliser des identifiants provenant d&#39;Apps autonomes ou d&#39;Apps associées à un Project.

**Paramètres de requête**

Les paramètres de requête standard v1.1 suivants acceptaient deux paramètres de requête (user&#95;id ou screen&#95;name). X API v2 n&#39;accepte que l&#39;id utilisateur numérique, qui doit être transmis dans le chemin du point de terminaison.

| Standard v1.1 | X API v2 |
| :--- | :--- |
| **id** | **id** |
| **includes&#95;entities** | Aucun équivalent |

Veuillez noter que les paramètres Standard v1.1 sont transmis en tant que paramètres de requête, tandis que les paramètres X API v2 sont transmis dans le corps de la requête pour le point de terminaison POST ou en tant que paramètres de chemin pour le point de terminaison DELETE.

De plus, l&#39;id de l&#39;utilisateur qui effectue un Retweet d&#39;une Publication n&#39;est pas requis lors de l&#39;utilisation des points de terminaison standard v1.1, car les [Access Tokens](/fr/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) transmis avec [OAuth 1.0a User Context](/fr/resources/fundamentals/authentication) permettent de déterminer quel utilisateur initie le Retweet ou annule un Retweet.

<div id="retweet-a-post-v2">
  ### Retweeter une publication (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/retweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python
  # Nécessite une authentification OAuth 1.0a User Context
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/retweets"
  response = requests.post(url, auth=auth, json={"tweet_id": "1234567890"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Retweeter une publication
  response = client.posts.retweet(user_id="123456789", tweet_id="1234567890")
  print(f"Retweeted: {response.data.retweeted}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Retweeter une publication
  const response = await client.posts.retweet("123456789", { tweetId: "1234567890" });
  console.log(`Retweeted: ${response.data?.retweeted}`);
  ```
</CodeGroup>

<div id="undo-a-retweet-v2">
  ### Annuler un Retweet (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/123456789/retweets/1234567890" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  # Nécessite une authentification OAuth 1.0a User Context
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/retweets/1234567890"
  response = requests.delete(url, auth=auth)
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",

  # Annuler un Retweet

  ```
