<div id="manage-retweets-standard-v11-compared-to-x-api-v2">
  ### Gérer les Retweets : standard v1.1 par rapport à X API v2
</div>

Si vous avez travaillé avec les endpoints standard v1.1 [POST statuses/retweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-retweet-id) et [POST statuses/unretweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-unretweet-id), ce guide a pour objectif de vous aider à comprendre les similitudes et les différences entre les endpoints de Retweets standard et ceux de X API v2.

* **Similarités**
  * Authentification
* **Différences**
  * URL des endpoints et méthodes HTTP
  * Limites de requête
  * Exigences d’App et de Projet
  * Paramètres de requête

<div id="similarities">
  #### Similarités
</div>

**Authentification**

Les versions standard v1.1 et X API v2 gèrent toutes deux les Retweets ([POST statuses/retweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-retweet-id) et [POST statuses/unretweet/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/post-statuses-unretweet-id)) et utilisent [OAuth 1.0a User Context](https://developer.x.com/content/developer-twitter/resources/fundamentals/authentication) pour l’authentification. Par conséquent, si vous utilisiez auparavant l’un des endpoints standard v1.1 de recherche de Retweets, vous pouvez continuer à utiliser la même méthode d’authentification lors de votre migration vers la version X API v2. 

<div id="differences">
  #### Différences
</div>

**URL d’endpoint et méthodes HTTP**

* Endpoints standard v1.1 :
  * https://api.x.com/1.1/statuses/retweet/:id.json
    (Retweete une Publication. Renvoie la Publication d’origine avec les détails du Retweet intégrés)
  * https://api.x.com/1.1/statuses/unretweet/:id.json
    (Annule un Retweet. Renvoie la Publication d’origine avec les détails du Retweet intégrés)
* Endpoint X API v2 :
  * https://api.x.com/2/tweets/:id/retweets
    (Retweete une Publication donnée)
  * https://api.x.com/2/users/:id/retweets/:source&#95;tweet&#95;id
    (Annule le Retweet d’une Publication donnée) 

**Exigences liées à l’App et au Projet**

Les endpoints X API v2 exigent que vous utilisiez des identifiants issus d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) pour authentifier vos requêtes. Tous les endpoints X API v1.1 standard peuvent utiliser des identifiants provenant d’Apps ou d’Apps associées à une App.

**Paramètres de requête**

Les paramètres de requête standard v1.1 suivants acceptaient deux paramètres de requête (user&#95;id ou screen&#95;name). X API v2 accepte uniquement l’id utilisateur numérique, qui doit être transmis dans le chemin de l’endpoint.

| Standard v1.1 | X API v2 |
| :--- | :--- |
| **id** | **id** |
| **includes&#95;entities** | Aucun équivalent |

Veuillez noter que les paramètres standard v1.1 sont transmis en tant que paramètres de requête, tandis que les paramètres X API v2 sont transmis en tant que paramètres dans le corps de la requête pour l’endpoint POST ou en tant que paramètres de chemin pour l’endpoint DELETE.

De plus, un id de l’utilisateur qui retweete une Publication n’est pas obligatoire lors de l’utilisation des endpoints standard v1.1, car les [Access Tokens](/fr/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow) transmis avec l’[OAuth 1.0a User Context](/fr/resources/fundamentals/authentication) permettent de déduire quel utilisateur initie le Retweet ou annule un Retweet.

<div id="retweet-a-post-v2">
  ### Retweeter une publication (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123456789/retweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python
  # Nécessite une authentification OAuth 1.0a User Context
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/retweets"
  response = requests.post(url, auth=auth, json={"tweet_id": "1234567890"})
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Retweeter une publication
  response = client.posts.retweet(user_id="123456789", tweet_id="1234567890")
  print(f"Retweeted: {response.data.retweeted}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // Retweeter une publication
  const response = await client.posts.retweet("123456789", { tweetId: "1234567890" });
  console.log(`Retweeted: ${response.data?.retweeted}`);
  ```
</CodeGroup>

<div id="undo-a-retweet-v2">
  ### Annuler un Retweet (v2)
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/123456789/retweets/1234567890" \
    -H "Authorization: OAuth ..."
  ```

  ```python Python
  # Nécessite l'authentification OAuth 1.0a User Context
  import requests
  from requests_oauthlib import OAuth1

  auth = OAuth1(
      "API_KEY", "API_SECRET",
      "ACCESS_TOKEN", "ACCESS_TOKEN_SECRET"
  )

  url = "https://api.x.com/2/users/123456789/retweets/1234567890"
  response = requests.delete(url, auth=auth)
  print(response.json())
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # Annuler un Retweet
  response = client.posts.unretweet(user_id="123456789", tweet_id="1234567890")
  print(f"Retweeted: {response.data.retweeted}")
  ```

