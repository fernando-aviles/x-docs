<div id="comparing-x-apis-retweets-endpoints">
  ## Comparaison des endpoints Retweets de X API
</div>

**Recherche de Retweets**

L’endpoint v2 de recherche de Retweets remplacera les endpoints standards [v1.1 GET statuses/retweets/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweets-id) et [v1.1 GET statuses/retweets/:ids](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweeters-ids).

Les tableaux suivants comparent les endpoints standards v1.1 et les endpoints Retweets de X API v2 :

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | GET | GET |
| Domaine d’hébergement | https://api.x.com | https://api.x.com |
| Chemin de l’endpoint | /1.1/retweeters/id.json<br /><br />`/1.1/retweets/ids.json` | /2/users/:id/retweeted&#95;by |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a User Context |
| Limites de [rate limits](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 75 requêtes par 15 min | 75 requêtes par 15 min (par App)<br /><br />75 requêtes par 15 min (par utilisateur) |
| Format des données | Format standard v1.1 | [Format X API v2](/fr/x-api/fundamentals/data-dictionary) (déterminé par les paramètres de requête fields et expansions, non rétrocompatible avec les formats v1.1)<br /><br />Pour en savoir plus sur la façon de migrer du format standard v1.1 vers le format X API v2, consultez notre [guide de migration des formats de données](/fr/x-api/migrate/data-format-migration). |
| Nécessite l’utilisation d’identifiants provenant d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) |     | ✔️  |

<div id="manage-retweets">
  ### Gérer les Retweets
</div>

Les tableaux suivants comparent l’endpoint d’annulation de Retweet de la v1.1 standard et de X API v2 :

**Retweeter une Publication**

| Description | v1.1 standard | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | POST |
| Domaine d’hébergement | https://api.x.com | https://api.x.com |
| Chemin de l’endpoint | /1.1/statuses/retweet/:id.json | /2/users/:id/retweets |
| [Authentication](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| Limites de requêtes par défaut ([Rate limits](/fr/resources/fundamentals/rate-limits)) | Aucune<br /><br />300 requêtes par fenêtre de 3 heures (par utilisateur, par app). Partagé avec l’endpoint POST Tweet | 50 requêtes par 15 minutes (par utilisateur)<br /><br />300 requêtes par fenêtre de 3 heures (par utilisateur, par app). Ces limites sont partagées avec l’endpoint POST Tweet pour la gestion des Publications. |
| Nécessite l’utilisation d’identifiants provenant d’une [developer App](/fr/resources/fundamentals/developer-apps) associée à un [Project](/fr/resources/fundamentals/developer-apps) |     | ✔️  |

  #### Annuler un Retweet
