<div id="comparing-x-apis-retweets-endpoints">
  ## Comparaison des points de terminaison Retweets de X API
</div>

**Recherche de Retweets**

Le point de terminaison v2 de recherche de Retweets remplacera les points de terminaison standard v1.1 [GET statuses/retweets/:id](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweets-id) et [GET statuses/retweets/:ids](https://developer.x.com/en/docs/twitter-api/v1/tweets/post-and-engage/api-reference/get-statuses-retweeters-ids).

Les tableaux suivants comparent les points de terminaison Retweets standard v1.1 et X API v2 :

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | GET | GET |
| Domaine d’hébergement | https://api.x.com | https://api.x.com |
| Chemin du point de terminaison | /1.1/retweeters/id.json<br /><br />`/1.1/retweets/ids.json` | /2/users/:id/retweeted&#95;by |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 2.0 Bearer Token<br /><br />OAuth 1.0a User Context |
| [Limites de fréquence](/fr/resources/fundamentals/rate-limits) de requêtes par défaut | 75 requêtes par 15 min | 75 requêtes par 15 min (par App)<br /><br />75 requêtes par 15 min (par utilisateur) |
| Format des données | Format standard v1.1 | [Format X API v2](/fr/x-api/fundamentals/data-dictionary) (déterminé par les paramètres de requête fields et expansions, non rétrocompatible avec les formats v1.1)<br /><br />Pour en savoir plus sur la migration du format standard v1.1 vers le format X API v2, consultez notre [guide de migration des formats de données](/fr/x-api/migrate/data-format-migration). |
| Nécessite l’utilisation d’identifiants issus d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Projet](/fr/resources/fundamentals/developer-apps) |     | ✔️  |

<div id="manage-retweets">
  ### Gérer les Retweets
</div>

Les tableaux suivants comparent l’endpoint standard v1.1 et X API v2 pour annuler un Retweet :

**Retweeter une Publication**

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| HTTP methods supported | POST | POST |
| Host domain | https://api.x.com | https://api.x.com |
| Endpoint path | /1.1/statuses/retweet/:id.json | /2/users/:id/retweets |
| [Authentication](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| Default request [rate limits](/fr/resources/fundamentals/rate-limits) | Aucune<br /><br />300 requêtes par fenêtre de 3 heures (par utilisateur, par app). Partagé avec l’endpoint POST Tweet | 50 requêtes par tranche de 15 minutes (par utilisateur)<br /><br />300 requêtes par fenêtre de 3 heures (par utilisateur, par app). Ceci est partagé avec l’endpoint POST Tweet pour gérer les Publications. |
| Requires the use of credentials from a [developer App](/fr/resources/fundamentals/developer-apps) that is associated with a [Project](/fr/resources/fundamentals/developer-apps) |     | ✔️  |

<div id="undo-a-retweet">
  #### Annuler un Retweet
</div>

Le tableau suivant compare l’endpoint d’annulation de Retweet standard v1.1 et celui de X API v2 :

| Description | Standard v1.1 | X API v2 |
| :--- | :--- | :--- |
| Méthodes HTTP prises en charge | POST | DELETE |
| Domaine hôte | https://api.x.com | https://api.x.com |
| Chemin d’endpoint | /1.1/statuses/unretweet/:id.json | /2/users/:id/retweets/:source&#95;tweet&#95;id |
| [Authentification](/fr/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| Limites de fréquence des requêtes par défaut ([rate limits](/fr/resources/fundamentals/rate-limits)) | Aucune | 50 requêtes par 15 min (par utilisateur) |
| Nécessite l’utilisation d’identifiants issus d’une [App développeur](/fr/resources/fundamentals/developer-apps) associée à un [Project](/fr/resources/fundamentals/developer-apps) |     | ✔️  |
