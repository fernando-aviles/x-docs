Le point de terminaison Personalized Trends renvoie des sujets tendance personnalisés pour l’utilisateur authentifié, en fonction de sa localisation et de ses centres d’intérêt.

<div id="endpoint">
  ## Point de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------------------|:------------|
| GET | `/2/users/personalized_trends` | Obtenir les tendances personnalisées |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/users/personalized_trends" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-response">
  ## Exemple de réponse
</div>

```json
{
  "data": [
    {
      "trend_name": "#AI",
      "tweet_count": 125000
    },
    {
      "trend_name": "Machine Learning",
      "tweet_count": 85000
    }
  ]
}
```
