L’endpoint Trends by WOEID renvoie les tendances pour une zone géographique donnée, identifiée par un identifiant Yahoo! Where On Earth (WOEID).

  ## Vue d’ensemble
</div>

<div id="endpoint">
  ## Endpoint
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/trends/by/woeid/:id`](/fr/x-api/trends/get-trends-by-woeid) | Obtenir les tendances pour un WOEID |

***

<div id="common-woeids">
  ## WOEID courants
</div>

| Localisation | WOEID |
|:---------|:------|
| Monde entier | 1 |
| États-Unis | 23424977 |
| Royaume-Uni | 23424975 |
| Japon | 23424856 |
| New York | 2459115 |
| Los Angeles | 2442047 |
| Londres | 44418 |
| Tokyo | 1118370 |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/trends/by/woeid/1" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## Exemple de réponse
</div>

```json
{
  "data": [
    {
      "trend_name": "#AI",
      "tweet_count": 250000
    },
    {
      "trend_name": "Breaking News",
      "tweet_count": 180000
    }
  ]
}
```
