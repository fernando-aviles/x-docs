L’endpoint Spaces Search vous permet de rechercher des Spaces en direct ou programmés à l’aide de mots-clés. Recherchez des Spaces sur des sujets qui vous intéressent.

  ## Aperçu

***

<div id="endpoint">
  ## Point de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------------------|:------------|
| GET | [`/2/spaces/search`](/fr/x-api/spaces/search-spaces) | Rechercher des Spaces |

***

<div id="parameters">
  ## Paramètres
</div>

| Paramètre | Description |
|:----------|:------------|
| `query` | Requête de recherche (obligatoire) |
| `state` | Filtrer par `live` ou `scheduled` |
| `space.fields` | Champs Space supplémentaires |
| `expansions` | Objets associés à inclure |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/spaces/search?\
query=AI&\
state=live&\
space.fields=title,host_ids,participant_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-response">
  ## Exemple de réponse
</div>

```json
{
  "data": [
    {
      "id": "1DXxyRYNejbKM",
      "state": "live",
      "title": "Discussing AI and the Future",
      "host_ids": ["1234567890"],
      "participant_count": 245
    }
  ],
  "meta": {
    "result_count": 1
  }
}
```
