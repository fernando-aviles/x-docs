Les endpoints de recherche de Spaces vous permettent de récupérer des informations sur les Spaces en direct ou programmés. Recherchez des Spaces par leur id ou trouvez des Spaces créés par des utilisateurs spécifiques.

<div id="endpoints">
  ## Endpoints
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/spaces/:id`](/fr/x-api/spaces/get-space-by-id) | Récupérer un Space par identifiant |
| GET | [`/2/spaces`](/fr/x-api/spaces/get-spaces-by-ids) | Récupérer des Spaces par identifiants |
| GET | [`/2/spaces/by/creator_ids`](/fr/x-api/spaces/get-spaces-by-creator-ids) | Récupérer des Spaces par identifiants d&#39;utilisateurs créateurs |
| GET | [`/2/spaces/:id/buyers`](/fr/x-api/spaces/get-space-ticket-buyers) | Récupérer les acheteurs de billets pour un Space |
| GET | [`/2/spaces/:id/tweets`](/fr/x-api/spaces/get-space-posts) | Récupérer les Publications partagées dans un Space |

***

<div id="response-fields">
  ## Champs de réponse
</div>

Par défaut, la réponse inclut `id` et `state`. Demandez des champs supplémentaires :

| Champ | Description |
|:------|:------------|
| `title` | Titre de l’espace |
| `host_ids` | ID des utilisateurs hôtes |
| `speaker_ids` | ID des utilisateurs intervenants |
| `participant_count` | Nombre de participants |
| `scheduled_start` | Heure de début planifiée |
| `started_at` | Heure de début réelle |
| `ended_at` | Heure de fin |
| `is_ticketed` | Indique si l’espace est payant |

<div id="space-states">
  ### États des Spaces
</div>

| État | Description |
|:------|:------------|
| `live` | Actif |
| `scheduled` | Planifié (à venir) |
| `ended` | Terminé |

***

<div id="example-request">
  ## Exemple de requête
</div>

```bash
curl "https://api.x.com/2/spaces/1DXxyRYNejbKM?\
space.fields=title,host_ids,participant_count,scheduled_start,state" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
