Les endpoints de consultation des messages privés vous permettent de récupérer les événements de messages privés (DM) pour l’utilisateur authentifié, y compris les messages issus de conversations individuelles et de groupe.

<div id="endpoints">
  ## Endpoints
</div>

| Méthode | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/dm_events`](/fr/x-api/direct-messages/get-dm-events) | Récupérer tous les événements de DM pour l’utilisateur |
| GET | [`/2/dm_conversations/with/:participant_id/dm_events`](/fr/x-api/direct-messages/get-dm-events-for-a-dm-conversation) | Récupérer les événements d’une conversation en tête-à-tête |
| GET | [`/2/dm_conversations/:dm_conversation_id/dm_events`](/fr/x-api/direct-messages/get-dm-events-for-a-dm-conversation-1) | Récupérer les événements par id de conversation |

***

<div id="event-types">
  ## Types d’événements
</div>

| Événement | Description |
|:------|:------------|
| `MessageCreate` | Un message a été envoyé dans la conversation |
| `ParticipantsJoin` | Un utilisateur a rejoint la conversation |
| `ParticipantsLeave` | Un utilisateur a quitté la conversation |

***

<div id="data-retention">
  ## Rétention des données
</div>

<Note>
  Les événements couvrant les **30 derniers jours** sont disponibles via ces endpoints.
</Note>
