Les endpoints de recherche de Messages privés vous permettent de récupérer les événements de messages privés pour l’utilisateur authentifié, y compris les messages provenant des conversations individuelles et des conversations de groupe.

<div id="endpoints">
  ## Points de terminaison
</div>

| Méthode | Point de terminaison | Description |
|:-------|:---------------------|:------------|
| GET | [`/2/dm_events`](/fr/x-api/direct-messages/get-dm-events) | Récupérer tous les événements de messages privés pour l’utilisateur |
| GET | [`/2/dm_conversations/with/:participant_id/dm_events`](/fr/x-api/direct-messages/get-dm-events-for-a-dm-conversation) | Récupérer les événements d’une conversation en tête-à-tête |
| GET | [`/2/dm_conversations/:dm_conversation_id/dm_events`](/fr/x-api/direct-messages/get-dm-events-for-a-dm-conversation-1) | Récupérer les événements par identifiant de conversation |

***

<div id="event-types">
  ## Types d’événements
</div>

| Événement | Description |
|:------|:------------|
| `MessageCreate` | Un message a été envoyé dans la conversation |
| `ParticipantsJoin` | Un utilisateur a rejoint la conversation |
| `ParticipantsLeave` | Un utilisateur a quitté la conversation |

***

<div id="data-retention">
  ## Rétention des données
</div>

<Note>
  Les événements des **30 derniers jours** sont disponibles via ces points de terminaison.
</Note>
