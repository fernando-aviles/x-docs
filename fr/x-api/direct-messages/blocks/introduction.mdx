Les endpoints de gestion des blocages de DM vous permettent de bloquer ou de débloquer un compte donné au nom d’un utilisateur authentifié. Pour ces endpoints, deux méthodes POST sont disponibles :

* **/2/users/:id/dm/block** : permet de bloquer un compte
* **/2/users/:id/dm/unblock** : permet de débloquer un compte

<div id="getting-started">
  ### Pour commencer
</div>

<div id="authentication">
  ### Authentification
</div>

Étant donné que vous effectuez des requêtes pour le compte d’un utilisateur, vous devez authentifier ces endpoints à l’aide soit d’[OAuth 1.0a User Context](/fr/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow), soit d’[OAuth 2.0 Authorization Code with PKCE](/fr/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2), et utiliser les jetons d’accès utilisateur associés à l’utilisateur pour le compte duquel vous effectuez la requête. Vous pouvez générer ce jeton d’accès utilisateur à l’aide du [flux OAuth à 3 volets](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens) (OAuth 1.0a) ou du [flux de type Authorization Code avec PKCE](/fr/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) (OAuth 2.0).

<div id="making-a-request">
  ### Effectuer une requête
</div>

Block

Une fois qu’un utilisateur s’est authentifié auprès de votre App, vous pouvez appeler l’endpoint Block en son nom comme indiqué ci-dessous :

```
      curl --request POST 'https://api.x.com/2/users/:id/dm/block' --header 'Authorization: ••••••'
```

Si la requête aboutit, vous devriez voir la réponse JSON suivante :

```
{
   "data": {
       "blocked": true
   }
}
```

**Débloquer**

Une fois qu’un utilisateur s’est authentifié auprès de votre App, vous pouvez appeler l’endpoint Unblock en son nom, comme illustré ci-dessous :

```
      curl --request POST 'https://api.x.com/2/users/:id/dm/unblock' --header 'Authorization: ••••••'
```

Si la requête aboutit, vous devriez voir la réponse JSON comme ci-dessous :

```
{
   "data": {
       "blocked": false
   }
}
```
