<div id="introduction">
  ## Introduction
</div>

Ce tutoriel explique ce dont vous avez besoin pour commencer à utiliser le
langage de programmation R et l’X API v2. En utilisant R pour vous connecter au
point de terminaison [user lookup](/fr/x-api/users/lookup/introduction), je vais
montrer comment manipuler le JSON renvoyé par l’X API. `User lookup` est une
méthode GET et renvoie des informations sur un utilisateur ou un groupe
d’utilisateurs, spécifiés par un identifiant d’utilisateur ou un nom
d’utilisateur.

Si vous ne le connaissez pas, R est l’un des langages les plus populaires pour
les tâches courantes de science des données comme l’analyse de séries
temporelles, la modélisation, la visualisation et d’autres formes d’analyse de
données, et il est souvent utilisé en conjonction avec l’X API. Avec le point de
terminaison `user lookup`, vous pouvez utiliser l’[user object](/fr/x-api/fundamentals/data-dictionary#user)
pour déterminer s’il existe une corrélation entre le nombre d’abonnés qu’une
personne a et le score de sentiment de sa biographie. L’`user object` peut
également être utilisé pour cartographier un groupe de comptes en fonction du
lieu indiqué publiquement dans leurs profils.

<div id="getting-started-with-the-x-api">
  ### Premiers pas avec l’X API
</div>

Avant de pouvoir utiliser l’X API v2, vous devrez
[vous inscrire](https://developer.x.com/en/portal/petition/essential/basic-info)
pour obtenir un compte développeur.

Une fois que vous disposez d’un compte développeur approuvé, vous devrez d’abord créer un
[Projet](/fr/resources/fundamentals/developer-apps). Les projets vous permettent d’organiser votre travail
en fonction de la manière dont vous avez l’intention d’utiliser l’X API, afin que vous puissiez gérer
efficacement votre accès à l’API et suivre votre utilisation.

Chaque Projet contient une [App](/fr/resources/fundamentals/developer-apps), avec laquelle vous pouvez
générer les identifiants nécessaires pour utiliser l’X API. Vous pouvez en apprendre davantage
sur la façon de débuter avec l’X API dans la section
[Getting started](/fr/x-api/getting-started/about-x-api) de notre
documentation.

<div id="getting-your-r-environment-set-up">
  ### Configuration de votre environnement R
</div>

Tout d’abord, vous devez [télécharger R](https://cloud.r-project.org/), ce que vous pouvez faire
sur le [site web de CRAN.](https://cran.r-project.org/)

Ensuite, pour configurer un environnement de travail avec R, vous pouvez utiliser
[RStudio](https://www.rstudio.com/), le pack d’extensions R pour
[Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=Ikuyadeu.r-pack),
ou un
[Jupyter notebook](https://docs.anaconda.com/anaconda/navigator/tutorials/r-lang/)
si vous venez de l’écosystème Python.

<div id="setting-up-your-environment-variable">
  ### Configuration de votre variable d&#39;environnement
</div>

Pour les exemples de code que je vais vous montrer, vous devrez créer une
variable d&#39;environnement pour votre Bearer Token. Le Bearer Token est ce qui vous permet
de vous authentifier auprès de la X API et de commencer à effectuer des requêtes. Commencez par remplacer
&quot;your-bearer-token&quot; par votre propre Bearer Token, que vous pouvez obtenir dans la
section des clés et des jetons de votre App dans la Console de Développement. Vous devrez exécuter
cette ligne de code dans la console avant de commencer à écrire un script.

```r
Sys.setenv(BEARER_TOKEN = "votre-jeton-porteur")
```

<div id="making-your-request">
  ### Effectuer votre requête
</div>

Vous pouvez utiliser le package
[httr](https://cran.r-project.org/web/packages/httr/index.html) pour effectuer des requêtes HTTP
vers X API. Si vous ne l&#39;avez pas encore installé, veuillez
installer ce package dans votre console. Vous devrez également installer
[jsonlite](https://cran.r-project.org/web/packages/jsonlite/index.html) pour travailler
avec notre objet JSON et [dplyr](https://dplyr.tidyverse.org/) pour la manipulation des données.

```r
install.packages("httr")
install.packages("jsonlite")
install.packages("dplyr")
```

Vous pouvez maintenant commencer à écrire votre script R pour vous connecter à l’API. Au début du fichier, chargez les packages httr, jsonlite et dplyr.

```r
require(httr)
require(jsonlite)
require(dplyr)
```

La première étape dans votre exemple de code consiste à préparer votre authentification
auprès de X API. Récupérez le
[Bearer Token](/fr/resources/fundamentals/authentication#using-and-generating-an-app-only-bearer-token) que vous avez obtenu depuis
votre application, et transmettez‑le dans les en‑têtes de votre requête pour l’authentification. Dans l’exemple
ci‑dessous, remplacez $BEARER&#95;TOKEN par votre jeton.

```r
bearer_token <- Sys.getenv("$BEARER_TOKEN")
headers <- c(`Authorization` = sprintf('Bearer %s', bearer_token))
```

Une fois votre authentification configurée, définissez les paramètres de votre requête.
Par défaut, vous recevrez l’id, le nom et le nom d’utilisateur de chaque utilisateur renvoyé.
Vous pouvez ajuster cette charge utile JSON en ajoutant des
[champs](/fr/x-api/fundamentals/fields) et des
[expansions](/fr/x-api/fundamentals/expansions). Pour cet exemple, vous aurez besoin
de la biographie de profil de l’utilisateur, que vous demandez avec le paramètre user.fields=description,
et d’une expansion contenant la Publication épinglée de l’utilisateur.

```r
params <- list(`user.fields` = 'description', `expansions` = 'pinned_tweet_id')
```

Vous êtes maintenant prêt à formater votre URL avec le handle X, également appelé
compte, pour lequel vous souhaitez obtenir plus d’informations. Utilisez la méthode readline
pour que cet exemple soit réutilisable. Après avoir saisi le handle que vous souhaitez consulter,
formatez votre URL de façon à inclure le handle que vous avez défini en remplaçant $USERNAME par
le handle X souhaité.

```r
handle <- readline('$USERNAME')
url_handle <- sprintf('https://api.x.com/2/users/by?usernames=%s', handle)
```

À ce stade, utilisez le package httr pour effectuer une requête GET vers l’URL que vous venez de créer, fournissez nos informations d’authentification dans l’en-tête et passez les paramètres que vous avez définis. Vous pouvez enregistrer la réponse en tant qu’objet texte dans la variable obj et l’afficher pour voir le résultat de la requête que vous avez effectuée.

```r
response <-
  httr::GET(url = url_handle,
    httr::add_headers(.headers = headers),
    query = params)
obj <- httr::content(response, as = "text")
print(obj)
```

<div id="working-with-our-json-payload">
  ### Travailler avec notre charge utile JSON
</div>

L’une de mes façons préférées de travailler avec un document JSON est d’utiliser un data frame, qui vous permet d’accéder facilement à des données imbriquées complexes. Pour ce faire, utilisez la méthode fromJSON du package jsonlite pour aplatir votre fichier, de sorte que les champs se retrouvent dans un même objet. Ensuite, convertissez cet objet en data frame. Vous êtes maintenant prêt à consulter ce data frame.

```
json_data <- fromJSON(obj, flatten = TRUE) %>% as.data.frame View(json_data)
```

Vous pouvez accéder aux champs des données depuis la DataFrame et les insérer dans une chaîne de caractères qui contient le handle, le nom d’utilisateur et la bio.

```r
final <-
  sprintf(
    "Identifiant : %s\nBio : %s\nPublication épinglée : %s",
    json_data$data.username,
    json_data$data.description,
    json_data$includes.tweets.text
  )
```

Utilisez `cat` au lieu de `print` pour afficher l&#39;objet avec des sauts de ligne entre chaque champ que vous récupérez.

```r
cat(final)
```

Si vous aviez plusieurs handles pour lesquels vous faisiez des requêtes, vous pourriez facilement utiliser une boucle
pour accéder à chaque élément du data frame.
