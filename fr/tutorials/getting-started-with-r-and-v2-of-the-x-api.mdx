<div id="introduction">
  ## Introduction
</div>

Ce tutoriel vous expliquera ce dont vous avez besoin pour commencer avec
le langage de programmation R et X API v2. En utilisant R pour vous connecter à
l’endpoint [user lookup](/fr/x-api/users/lookup/introduction), nous verrons comment travailler
avec le JSON renvoyé par X API. L’endpoint user lookup est une méthode GET et renvoie
des informations sur un utilisateur ou un groupe d’utilisateurs, spécifiés par un identifiant d’utilisateur ou un
nom d’utilisateur.

Si vous ne le connaissez pas, R est l’un des langages les plus populaires pour les tâches
courantes de science des données comme l’analyse de séries temporelles, la modélisation, la
visualisation et d’autres analyses de données, et il est souvent utilisé conjointement
avec X API. Avec l’endpoint user lookup, vous pouvez utiliser
l’[user object](/fr/x-api/fundamentals/data-dictionary#user) pour
déterminer une corrélation entre le nombre d’abonnés d’une personne et le
score de sentiment de sa biographie. L’objet user peut également être utilisé pour cartographier un groupe de
comptes en fonction du lieu indiqué publiquement dans leurs profils.

<div id="getting-started-with-the-x-api">
  ### Premiers pas avec X API
</div>

Avant de pouvoir utiliser X API v2, vous devez
[vous inscrire](https://developer.x.com/en/portal/petition/essential/basic-info)
pour obtenir un compte développeur.

Une fois que votre compte développeur est approuvé, vous devez d’abord créer un
[Project](/fr/resources/fundamentals/developer-apps). Les Projects vous permettent d’organiser votre travail
en fonction de la manière dont vous prévoyez d’utiliser X API, afin de gérer efficacement
votre accès à l’API et de suivre votre utilisation.

Chaque Project contient une [App](/fr/resources/fundamentals/developer-apps), avec laquelle vous pouvez
générer les identifiants nécessaires pour utiliser X API. Vous pouvez en savoir plus
sur la façon de démarrer avec X API dans la section
[Prise en main](/fr/x-api/getting-started/about-x-api) de notre
documentation.

<div id="getting-your-r-environment-set-up">
  ### Configuration de votre environnement R
</div>

Tout d’abord, vous devez [télécharger R](https://cloud.r-project.org/), ce que vous pouvez faire
sur le [site CRAN](https://cran.r-project.org/).

Ensuite, pour configurer un environnement de travail avec R, vous pouvez utiliser
[RStudio](https://www.rstudio.com/), le pack d’extensions R pour
[Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=Ikuyadeu.r-pack),
ou un
[Jupyter notebook](https://docs.anaconda.com/anaconda/navigator/tutorials/r-lang/)
si vous venez de l’écosystème Python.

<div id="setting-up-your-environment-variable">
  ### Configuration de votre variable d&#39;environnement
</div>

Pour les exemples de code que je vais vous montrer aujourd’hui, vous devrez créer une
variable d&#39;environnement pour votre Bearer Token. Le Bearer Token est ce qui vous permet
de vous authentifier auprès de la X API et de commencer à effectuer des requêtes. Commencez par remplacer
« your-bearer-token » par votre propre Bearer Token, que vous pouvez obtenir dans la
section des clés et des tokens de votre App dans le Developer Console. Vous devrez exécuter
cette ligne de code dans la console avant de commencer à écrire un script.

```r
Sys.setenv(BEARER_TOKEN = "votre-jeton-porteur")
```

<div id="making-your-request">
  ### Effectuer votre requête
</div>

Vous pouvez utiliser le package
[httr](https://cran.r-project.org/web/packages/httr/index.html) pour effectuer des requêtes HTTP
vers le X API. Si vous ne l&#39;avez pas encore installé, installez ce package dans votre console. Vous devrez également installer
[jsonlite](https://cran.r-project.org/web/packages/jsonlite/index.html) pour travailler
avec notre objet JSON et [dplyr](https://dplyr.tidyverse.org/) pour manipuler les données.

```r
install.packages("httr")
install.packages("jsonlite")
install.packages("dplyr")
```

Vous pouvez maintenant commencer à écrire votre script R pour vous connecter à l’API. En haut du
fichier, chargez les packages httr, jsonlite et dplyr.

```r
require(httr)
require(jsonlite)
require(dplyr)
```

La première étape de votre exemple de code consiste à configurer l’authentification pour
X API. Récupérez le
[Bearer Token](/fr/resources/fundamentals/authentication#using-and-generating-an-app-only-bearer-token) que vous avez obtenu à partir
de votre App et incluez-le dans vos en-têtes pour l’authentification. Dans l’exemple
ci-dessous, remplacez $BEARER&#95;TOKEN par votre jeton.

```r
bearer_token <- Sys.getenv("$BEARER_TOKEN")
headers <- c(`Authorization` = sprintf('Bearer %s', bearer_token))
```

Une fois votre authentification configurée, définissez les paramètres de votre requête.
Par défaut, vous recevrez l’id, le nom et le nom d’utilisateur de chaque utilisateur retourné.
Vous pouvez ajuster ce payload JSON en ajoutant des
[champs](/fr/x-api/fundamentals/fields) et des
[expansions](/fr/x-api/fundamentals/expansions). Pour cet exemple, vous aurez besoin
de la bio de profil de l’utilisateur, que vous demandez avec user.fields=description,
et d’une expansion qui contient la publication épinglée de l’utilisateur.

```r
params <- list(`user.fields` = 'description', `expansions` = 'pinned_tweet_id')
```

Vous êtes maintenant prêt à formater votre URL avec le handle X, également appelé
compte, pour lequel vous souhaitez obtenir plus d’informations. Utilisez la méthode readline
afin de rendre cet exemple réutilisable. Après avoir saisi le handle que vous souhaitez consulter,
formatez votre URL pour qu’elle contienne le handle que vous avez défini en remplaçant $USERNAME par
le handle X souhaité.

```r
handle <- readline('$USERNAME')
url_handle <- sprintf('https://api.x.com/2/users/by?usernames=%s', handle)
```

À ce stade, utilisez le package httr pour effectuer une requête GET vers l’URL que vous venez de
créer, transmettez vos informations d’authentification dans l’en-tête, et indiquez les
paramètres que vous avez définis. Vous pouvez enregistrer la réponse en tant qu’objet texte dans la
variable obj et l’imprimer pour afficher le résultat de la requête que vous avez effectuée.

```r
response <-
  httr::GET(url = url_handle,
    httr::add_headers(.headers = headers),
    query = params)
obj <- httr::content(response, as = "text")
print(obj)
```

<div id="working-with-our-json-payload">
  ### Travailler avec notre charge utile JSON
</div>

L’une de mes façons préférées de travailler avec un JSON consiste à utiliser un data frame, qui vous permet
d’accéder facilement à des données imbriquées complexes. Pour ce faire, utilisez la méthode fromJSON du
package jsonlite pour aplatir votre fichier afin que les champs se retrouvent dans le même
objet. Ensuite, convertissez cet objet en data frame. Vous êtes maintenant prêt à visualiser ce
data frame.

```
json_data <- fromJSON(obj, flatten = TRUE) %>% as.data.frame View(json_data)
```

Vous pouvez accéder aux champs des données à partir du DataFrame et les insérer dans une chaîne de caractères qui contient le handle, le nom d’utilisateur et la bio.

```r
final <-
  sprintf(
    "Identifiant : %s\nBio : %s\nPublication épinglée : %s",
    json_data$data.username,
    json_data$data.description,
    json_data$includes.tweets.text
  )
```

Utilisez cat au lieu de print pour afficher l&#39;objet avec des sauts de ligne entre chaque champ que vous récupérez.

```r
cat(final)
```

Si vous aviez effectué des requêtes pour plusieurs handles, vous pourriez facilement utiliser une boucle pour accéder à chaque élément du data frame.
