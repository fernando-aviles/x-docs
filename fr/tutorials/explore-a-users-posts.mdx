<div id="introduction">
  ## Introduction
</div>

Alors que l’[endpoint de recherche récente](/fr/x-api/posts/search/introduction) ne vous permet de récupérer que des Publications datant des 7 derniers jours, les endpoints de timeline des Publications d’un utilisateur et de timeline des mentions d’un utilisateur vous permettent de récupérer des Publications et des mentions antérieures aux 7 derniers jours, pour un utilisateur autorisé (en utilisant l’id de l’utilisateur). Les développeurs peuvent utiliser ces endpoints pour étudier les sujets, les entités et le sentiment des Publications issues de la timeline d’un utilisateur ou de ses mentions. Dans ce tutoriel, nous vous montrerons comment explorer les Publications et les mentions d’un utilisateur à l’aide des endpoints user Tweet timeline et user mention timeline.
 

<div id="prerequisites">
  ## Conditions requises
</div>

* Pour pouvoir utiliser les endpoints de timeline des Tweets d’un utilisateur et de ses mentions, vous devez disposer d’un compte développeur valide. 
* Vous devez également avoir créé un [Projet](/fr/resources/fundamentals/developer-apps).
* Vous devez vous être [inscrit](https://developer.x.com/en/portal/petition/essential/basic-info) à un compte développeur et avoir activé la [nouvelle expérience de la Console de Développement](https://developer.x.com/en/portal/opt-in.html). 
* L’accès est possible avec des clés et des jetons actifs pour une App développeur qui est rattachée à un [Projet](/fr/resources/fundamentals/developer-apps) créé dans la [Console de Développement](/fr/resources/fundamentals/developer-portal).
* Un Bearer Token émis par votre App dans la [Console de Développement X](/fr/resources/fundamentals/developer-portal).
* Si vous n’avez pas de compte développeur approuvé, vous pouvez [en faire la demande](https://developer.x.com/en/apply-for-access).

<div id="how-to-get-the-user-id-for-a-user-to-use-in-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## Comment obtenir l’ID d’un utilisateur pour l’utiliser dans les endpoints de chronologie des Tweets d’utilisateur et des mentions d’utilisateur
</div>

Les endpoints de chronologie des Tweets d’utilisateur et des mentions d’utilisateur vous permettent d’obtenir des Publications à l’aide de l’ID utilisateur. Pour obtenir l’ID utilisateur à partir d’un nom d’utilisateur, vous pouvez utiliser le nouvel [endpoint user lookup v2](/fr/x-api/users/lookup/quickstart/user-lookup). Remplacez USER&#95;NAME par le nom d’utilisateur de votre choix et XXXX par votre propre Bearer Token obtenu ci-dessus.

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

Vous verrez l&#39;identifiant utilisateur dans la réponse comme indiqué ci-dessous :

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```

<div id="connecting-to-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## Connexion aux endpoints de la timeline des Tweets d’utilisateur et de la timeline des mentions d’utilisateur
</div>

Afin d’obtenir la timeline des Tweets d’un utilisateur, exécutez la commande curl suivante dans votre terminal (assurez-vous de remplacer USER&#95;ID par l’ID de l’utilisateur de votre choix et XXXX par votre propre Bearer Token que vous avez obtenu ci-dessus)

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```

Vous verrez que la réponse JSON à ces requêtes contient par défaut l’identifiant et le texte des Publications (exemple ci-dessous).

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 If you are new to the X API v2, check out this step-by-step guide to making your first request https://t.co/4rZqThpSbp"
}
```

Si vous souhaitez que des champs supplémentaires soient renvoyés dans la réponse (tels que des informations sur l’utilisateur, des champs de Tweet supplémentaires comme les annotations de contexte, etc.), vous devez spécifier explicitement ces champs dans votre réponse. Pour savoir comment procéder, consultez le [guide sur l’utilisation des champs et des expansions](/fr/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions).

Vous pouvez également récupérer ces Publications en utilisant les langages de programmation de votre choix. Consultez nos exemples de code en Python, Node (JavaScript), Java et Ruby pour les endpoints de chronologie des Tweets d’utilisateur et de chronologie des mentions d’utilisateur dans notre [dépôt GitHub](https://github.com/xdevplatform/Twitter-API-v2-sample-code).

<div id="exploring-the-users-posts">
  ## Explorer les Publications d’un utilisateur
</div>

Une fois que vous savez comment obtenir des Publications à l’aide des endpoints user Tweet timeline et user mention timeline, vous pouvez commencer à explorer ses Publications. Par exemple, si vous souhaitez identifier les entités nommées courantes présentes dans les mentions d’un utilisateur, vous pouvez procéder comme suit :

Dans la requête API, spécifiez que vous voulez que l’objet context&#95;annotations soit inclus dans les Réponses Tweet :

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

Dans la réponse, vous verrez si des entités nommées sont présentes dans les mentions. Voici un exemple :

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "Marques et entreprises"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

Si vous souhaitez voir quelles entités populaires apparaissent dans vos mentions, vous pouvez compter ces entités populaires en analysant chaque Tweet dans vos mentions.

Si vous souhaitez explorer l’URL de l’image d’aperçu pour toutes les Publications de votre fil qui contiennent des médias, vous pouvez procéder comme suit :

Dans la requête d’API, spécifiez que vous voulez le preview&#95;image&#95;url dans les champs tweet.media, et attachments.media&#95;keys dans le paramètre expansions.

```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

Dans la réponse, vous verrez le champ preview&#95;image&#95;url dans l&#39;objet includes, comme indiqué ci-dessous :

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```
