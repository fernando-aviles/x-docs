<div id="introduction">
  ## Introduction
</div>

Postman est une application de bureau et une application web qui vous permet d’effectuer des requêtes vers une API depuis une interface graphique. Nous recommandons d’utiliser Postman avec X API, X Ads API et les endpoints Labs lorsque vous explorez les fonctionnalités des API, ainsi que lorsque vous cherchez à résoudre des problèmes avec votre application. 

Nous proposons actuellement deux collections Postman :

<div id="prerequisites">
  ### Prérequis
</div>

Avant de commencer à utiliser les collections Postman de X, vous devez vous assurer de disposer des accès et des identifiants appropriés pour l’outil de la plateforme développeur X que vous souhaitez utiliser. Vous pouvez en savoir plus sur l’obtention de ces accès via notre [page « Premiers pas »](/fr/resources/platform-overview).

Une fois que vous disposez d’un [compte développeur,](https://developer.x.com/en/portal/petition/essential/basic-info) que vous avez configuré une [App développeur](/fr/resources/fundamentals/developer-apps) et un ensemble de clés et jetons d’[authentification](/fr/resources/fundamentals/authentication), et que vous avez correctement configuré votre environnement pour envoyer des requêtes à l’API spécifique que vous prévoyez d’utiliser, vous pouvez suivre les étapes ci-dessous pour commencer.
 

<div id="getting-started-with-xs-postman-collections">
  ## Premiers pas avec les collections Postman de X
</div>

<div id="step-one-add-one-of-the-x-postman-collections-to-your-account">
  ### Première étape : ajouter l’une des collections Postman de X à votre compte
</div>

Même si vous pourriez configurer manuellement les endpoints spécifiques que vous souhaitez utiliser dans Postman, nous avons déjà fait tout le travail pour vous et créé une collection prête à l’emploi des API pertinentes. Il vous suffit de cliquer sur l’un des liens de la section précédente « Postman collections » et une collection contenant tous les endpoints associés à l’API choisie sera ajoutée à votre application Postman. Ces collections sont également disponibles dans le [réseau d’API Postman](https://explore.postman.com/). Chaque endpoint inclura automatiquement les paramètres disponibles, des exemples de réponses, ainsi que le type d’authentification déjà configuré ; vous n’aurez plus qu’à ajouter vos identifiants et les valeurs de paramètres pour commencer à explorer les fonctionnalités.

Dans cet exemple, nous allons travailler avec la [collection API v2](https://app.getpostman.com/run-collection/9956214-784efcda-ed4c-4491-a4c0-a26470a67400) de X. 
 

<div id="step-two-add-your-keys-and-tokens-as-environmental-variables">
  ### Étape deux : ajouter vos clés et jetons en tant que variables d’environnement
</div>

Lorsque vous ajoutez la collection à votre instance Postman, un environnement appelé « X API v2 » sera automatiquement ajouté, et vous devrez y ajouter vos clés et jetons. Dans cette étape, nous allons vous guider tout au long du processus d’ajout de vos clés et jetons depuis votre App développeur dans l’environnement « X API v2 ». 

Pour ajouter vos clés et jetons à l’environnement « X API v2 », cliquez sur le bouton « manage environments » dans le coin supérieur droit de Postman. Vous devrez cliquer sur le bouton des paramètres dans le coin supérieur droit. 
 

<Frame>
  <img src="/images/using-postman-1.png.twimg.1920.png" alt="Cette image montre le bouton « manage environments » mis en évidence dans la console Postman." />
</Frame>

Dans la liste des environnements, cliquez sur « X API v2 ». 

Ensuite, ajoutez une variable pour chacune des différentes clés et chacun des différents jetons que vous avez générés via le tableau de bord des Apps dans le tableau. Voici un exemple de ce à quoi votre tableau devrait ressembler :

| VARIABLE | VALEUR INITIALE | VALEUR ACTUELLE |
| :--- | :--- | :--- |
| consumer&#95;key | `QAktM6W6DF6F7XXXXXX` | `QAktM6W6DF6F7XXXXXX` |
| consumer&#95;secret | `AJX560A2Omgwyjr6Mml2esedujnZLHXXXXXX` | `AJX560A2Omgwyjr6Mml2esedujnZLHXXXXXX` |
| access&#95;token | `1995XXXXX-0NGqVhk3s96IX6SgT3H2bbjOPjcyQXXXXXXX` | `1995XXXXX-0NGqVhk3s96IX6SgT3H2bbjOPjcyQXXXXXXX` |
| token&#95;secret | `rHVuh7dgDuJCOGeoe4tndtjKwWiDjBZHLaZXXXXXX` | `rHVuh7dgDuJCOGeoe4tndtjKwWiDjBZHLaZXXXXXX` |
| bearer&#95;token | `AAAAAAAAAAAAAAAAAAAAAL9v6AAAAAAA99t03huuqRYg0mpYAAFRbPR3XXXXXXX` | `AAAAAAAAAAAAAAAAAAAAAL9v6AAAAAAA99t03huuqRYg0mpYAAFRbPR3XXXXXXX` |

Notez que les clés et jetons utilisés dans le tableau ci-dessus sont fictifs et ne fonctionneront pas s’ils sont utilisés dans une requête. 

Une fois que vous avez ajouté vos identifiants en tant que variables et que vous vous êtes assuré que l’environnement « X API v2 » est sélectionné, vous serez prêt à effectuer des requêtes vers la collection X API v2. En effet, l’onglet d’autorisation de chaque endpoint est configuré pour hériter automatiquement des variables de cet environnement. 

Pour utiliser Postman avec des User Access Tokens, passez à XXXX pour accéder aux informations supplémentaires expliquant comment procéder.

<div id="step-three-select-an-endpoint">
  ### Étape trois : Sélectionner un point de terminaison
</div>

L&#39;étape suivante consiste à choisir un point de terminaison dans la collection et à commencer à créer votre requête. Vous pouvez sélectionner un point de terminaison à partir du menu de navigation situé à droite. Voici à quoi cela ressemble :

<Frame>
  <img src="/images/using-postman-2.png.twimg.1920.png" alt="Cette image montre la requête « Single Posts » sélectionnée sous la liste déroulante « Post Lookup » dans la section « X API v2 »." />
</Frame>

Pour cet exemple, nous allons utiliser le point de terminaison X API v2 &gt; Post Lookup &gt; Single Post. 

<div id="step-four-add-values-to-the-params-tab">
  #### Quatrième étape : ajouter des valeurs dans l’onglet Params
</div>

L’étape suivante consiste à vous rendre dans l’onglet Params. Vous devriez voir un ensemble de paramètres inactifs, avec des descriptions expliquant ce que fait chaque paramètre, ainsi qu’une liste de toutes les valeurs possibles que vous pouvez transmettre avec votre requête. 

Dans cet exemple, nous allons activer les paramètres de requête expansions et tweet.fields et ajouter les valeurs suivantes :

|     |     |
| :--- | :--- |
| **Clé** | **Valeur** |
| `tweet.fields` | `created_at,attachments` |
| expansions | author&#95;id |

En plus d’ajouter les paramètres de requête, nous devons ajouter la variable de chemin obligatoire id. Comme cet endpoint renvoie des Publications, nous devons ajouter un ID de Publication valide comme valeur.

Vous pouvez trouver l’ID de la Publication en accédant à x.com, en cliquant sur une Publication, puis en regardant l’URL. Par exemple, l’ID de Publication de l’URL suivante est `1228393702244134912` :

`https://x.com/XDevelopers/status/1228393702244134912`

Dans l’onglet Params, faites défiler la page au‑delà de tous les paramètres de requête pour afficher la section « Path Variables ». Nous allons ajouter l’ID de Publication que vous souhaitez utiliser comme valeur pour la clé id.

Si vous avez correctement renseigné tous les éléments de cette étape, l’onglet Params devrait ressembler à ce qui suit :

  ### Générer un jeton d’accès utilisateur avec Postman :
</div>

<div id="using-oauth-10a-to-generate-a-user-access-token">
  #### Utiliser OAuth 1.0a pour générer un jeton d’accès utilisateur
</div>

Consultez le processus en trois étapes utilisé dans la [collection de test du flux OAuth1.0a](https://www.postman.com/xapidevelopers/workspace/twitter-s-public-workspace/collection/9956214-784efcda-ed4c-4491-a4c0-a26470a67400?ctx=documentation).

<div id="using-oauth-20-to-generate-a-user-access-token">
  #### Utiliser OAuth 2.0 pour générer un jeton d’accès utilisateur
</div>

Si vous souhaitez générer un jeton d’accès utilisateur OAuth 2.0 dans Postman, vous pouvez le faire pour utiliser des jetons d’accès OAuth 2.0 avec la [collection Postman X API v2](https://www.postman.com/xapidevelopers/workspace/twitter-s-public-workspace/collection/9956214-784efcda-ed4c-4491-a4c0-a26470a67400?ctx=documentation). 

Cliquez sur la collection dans votre espace de travail, accédez à l’onglet intitulé « Auth » et sélectionnez le type « OAuth 2.0 ». À partir de là, sous l’en-tête « Configure New Token », allez à l’endroit où il est indiqué « Configuration Options ». Vous pouvez définir le « Grant Type » sur « Authorization Code (With PKCE) ».

Vous devrez mettre à jour votre URL de rappel afin qu’elle corresponde à l’URL de rappel associée à votre application. De plus, vous devrez mettre à jour les paramètres suivants :

* Auth URL -  https://x.com/i/oauth2/authorize
* Access Token URL -  https://api.x.com/2/oauth2/token
* Client ID - Votre client ID OAuth 2.0 à partir du Dev Portal
* Client Secret - Si vous utilisez un client confidentiel
* Update Scope - Scopes correspondant aux endpoints que vous souhaitez utiliser. Exemple : « tweet.read users.read »
* Votre URL de rappel (également appelée URL de redirection). Elle doit correspondre à ce que vous avez dans les paramètres d’authentification de votre App.
* State - state

Lorsque vous êtes prêt, vous pouvez cliquer sur « Get New Access Token » pour générer un jeton d’accès. Si une boîte de dialogue indique qu’une erreur s’est produite, vous devrez peut-être appuyer sur le bouton Retour pour vous connecter. Vous devrez autoriser votre application à accéder à votre compte en cliquant sur « Authorize app » dans la boîte de dialogue.

Après avoir autorisé votre application, vous serez redirigé vers Postman, où vous pourrez voir votre jeton et sélectionner le bouton « Use Token » pour commencer à effectuer des requêtes pour le compte d’un utilisateur autorisé.

Vous êtes maintenant prêt à utiliser la collection Postman.

<div id="whats-next">
  ## Et ensuite ?
</div>

Si vous cliquez sur le bouton « Code » dans Postman, vous pouvez convertir la requête que nous venons de créer en un langage de votre choix, comme Python, Node ou Ruby, pour vous aider à démarrer. Postman dispose d’une [excellente documentation](https://learning.getpostman.com/) qui peut vous être utile. Nous proposons également du [code d’exemple sur GitHub](https://github.com/xdevplatform) qui peut vous aider à vous intégrer plus rapidement aux endpoints.
