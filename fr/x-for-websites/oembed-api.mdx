Vous pouvez utiliser l’API oEmbed pour récupérer de manière programmatique du contenu intégrable, comme des [Tweets](https://developer.x.com/en/docs/twitter-for-websites/embedded-tweets/overview) et des [timelines](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview).

La réponse de l’API oEmbed contiendra un extrait de code HTML qui sera automatiquement reconnu lorsque [le JavaScript des widgets X est inclus sur la page](https://developer.x.com/web/javascript/loading).

Veuillez noter que l’API est recommandée pour effectuer des tâches en grand volume, et nous vous conseillons d’utiliser notre outil complet [publish.x.com](https://publish.x.com/#) pour intégrer du contenu.

  <Tab title="Chronologies intégrées">
    L’extrait HTML renvoyé sera automatiquement reconnu comme une [timeline intégrée](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview) lorsque [le JavaScript de widget de X est inclus sur la page](https://developer.x.com/web/javascript/loading).

    L’endpoint oEmbed permet de personnaliser l’apparence finale d’une timeline intégrée en définissant les propriétés correspondantes dans le balisage HTML, qui seront interprétées par le JavaScript de X fourni par défaut avec la Réponse HTML. Le format du balisage renvoyé peut évoluer au fil du temps à mesure que X ajoute de nouvelles fonctionnalités ou ajuste la représentation de sa timeline.

    Pour une timeline X spécifiée par l’URL de la timeline, la Réponse est renvoyée dans un format JSON compatible [oEmbed](https://oembed.com/). Les timelines utilisateur et liste sont prises en charge. Le balisage de la timeline est destiné à être mis en cache sur vos serveurs pendant une durée maximale correspondant à la durée de cache recommandée, indiquée par la propriété cache&#95;age.

    ## Resource URL

    ## Example Requests

    ```bash
    curl --request GET --url 'https://publish.x.com/oembed?url=https%3A%2F%2Ftwitter.com%2FInterior%2Fstatus%2F507185938620219395'
    twurl -H publish.x.com "/oembed?url=https://x.com/Interior/status/463440424141459456"
    ```

    ## Exemple de réponse

    ```json

    {
      "url": "https://x.com/TwitterDev",
      "title": "",
      "html": "<a class=\"twitter-timeline\" href=\"https://x.com/TwitterDev\">Tweets by TwitterDev</a>\n<script async src=\"//platform.x.com/widgets.js\" charset=\"utf-8\"></script>",
      "width": null,
      "height": null,
      "type": "rich",
      "cache_age": "3153600000",
      "provider_name": "Twitter",
      "provider_url": "https://x.com",
      "version": "1.0"
    }
    ```

    L&#39;extrait HTML renvoyé sera automatiquement reconnu comme un [Tweet intégré](https://developer.x.com/web/embedded-tweets) lorsque [le JavaScript du widget de X est inclus sur la page](https://developer.x.com/web/javascript/loading).

    Le point de terminaison oEmbed permet de personnaliser l&#39;apparence finale d&#39;un Tweet intégré en définissant les propriétés correspondantes dans le balisage HTML, qui sera interprété par le JavaScript de X fourni par défaut avec la réponse HTML. Le format du balisage renvoyé peut évoluer au fil du temps à mesure que X ajoute de nouvelles fonctionnalités ou ajuste sa représentation des Tweets.

    Le balisage de secours du Tweet doit être mis en cache sur vos serveurs pour une durée maximale correspondant à la durée de vie du cache suggérée, spécifiée par la propriété `cache_age`.

Les Tweets sont fondamentalement du texte et ont donc une hauteur imprévisible qui ne peut pas être mise à l&#39;échelle comme une image ou une vidéo. En conséquence, la Réponse oEmbed ne fournira pas de valeur pour `height`.
