Vous pouvez utiliser l’API oEmbed pour récupérer par programmation du contenu intégré, comme des [Tweets](https://developer.x.com/en/docs/twitter-for-websites/embedded-tweets/overview) et des [timelines](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview). 

La réponse de l’API oEmbed contiendra un extrait de code HTML qui sera automatiquement reconnu lorsque [le JavaScript de widget X est inclus sur la page](https://developer.x.com/web/javascript/loading).

Veuillez noter que l’API est recommandée pour effectuer des opérations en masse, et nous vous conseillons d’utiliser notre outil robuste [publish.x.com](https://publish.x.com/#) pour intégrer du contenu.

<Tabs>
  <Tab title="Timelines intégrées">
    Le fragment HTML retourné sera automatiquement reconnu comme une [timeline intégrée](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview) lorsque [le JavaScript du widget X est inclus sur la page](https://developer.x.com/web/javascript/loading).

    Le point de terminaison oEmbed permet de personnaliser l’apparence finale d’une timeline intégrée en définissant les propriétés correspondantes dans le balisage HTML, qui seront interprétées par le JavaScript de X fourni par défaut avec la réponse HTML. Le format du balisage retourné peut évoluer au fil du temps à mesure que X ajoute de nouvelles fonctionnalités ou ajuste la représentation de sa timeline.

    Pour une timeline X spécifiée par l’URL de la timeline, dans un format JSON compatible avec [oEmbed](https://oembed.com/). Les timelines d’utilisateurs et de listes sont prises en charge. Le balisage de la timeline est destiné à être mis en cache sur vos serveurs pour une durée maximale correspondant à la durée de cache suggérée, spécifiée par la propriété cache&#95;age.

    ## URL de la ressource

    *https://publish.x.com/oembed*

    | Authentification requise ? | Non  |
    | Limité par un quota        | Non  |

    ## Exemples de requêtes

    ```bash
    curl --request GET --url 'https://publish.x.com/oembed?url=https%3A%2F%2Ftwitter.com%2FInterior%2Fstatus%2F507185938620219395'
    twurl -H publish.x.com "/oembed?url=https://x.com/Interior/status/463440424141459456"
    ```

    ## Exemple de réponse

    ```json

    {
      "url": "https://x.com/TwitterDev",
      "title": "",
      "html": "<a class=\"twitter-timeline\" href=\"https://x.com/TwitterDev\">Tweets by TwitterDev</a>\n<script async src=\"//platform.x.com/widgets.js\" charset=\"utf-8\"></script>",
      "width": null,
      "height": null,
      "type": "rich",
      "cache_age": "3153600000",
      "provider_name": "Twitter",
      "provider_url": "https://x.com",
      "version": "1.0"
    }
    ```

  <Tab title="Tweets intégrés">
    L&#39;extrait HTML renvoyé sera automatiquement reconnu comme un [Tweet intégré](https://developer.x.com/web/embedded-tweets) lorsque [le JavaScript du widget de X est inclus sur la page](https://developer.x.com/web/javascript/loading).

    Le point de terminaison oEmbed permet de personnaliser l&#39;apparence finale d&#39;un Tweet intégré en définissant les propriétés correspondantes dans le balisage HTML, qui sera interprété par le JavaScript de X fourni par défaut avec la réponse HTML. Le format du balisage renvoyé peut évoluer au fil du temps à mesure que X ajoute de nouvelles fonctionnalités ou ajuste sa représentation des Tweets.

    Le balisage de secours du Tweet doit être mis en cache sur vos serveurs pour une durée maximale correspondant à la durée de vie du cache suggérée, spécifiée par la propriété `cache_age`.

    *https://publish.x.com/oembed*

Par nature, les Tweets sont du texte et ont donc une hauteur imprévisible qui ne peut pas être redimensionnée comme une image ou une vidéo. De plus, la réponse oEmbed ne fournira pas de valeur pour `height`.
