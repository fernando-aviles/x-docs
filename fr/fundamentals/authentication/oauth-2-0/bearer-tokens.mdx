<div id="using-and-generating-an-app-only-bearer-token">
  ### Utiliser et générer un Bearer Token pour application uniquement
</div>

Un Bearer Token permet aux développeurs de disposer d’un point d’entrée plus sécurisé pour utiliser la X API et constitue l’une des fonctionnalités essentielles d’OAuth 2.0. 

L’authentification qui utilise un Bearer Token est également appelée authentification pour application uniquement. Un Bearer Token est un tableau d’octets de format non spécifié que vous générez à l’aide d’un script, par exemple une commande curl. Vous pouvez également obtenir un Bearer Token depuis la Console de Développement, dans la section des clés et des jetons des paramètres de votre application. Vous trouverez plus d’informations sur cette fonctionnalité dans la [documentation officielle d’OAuth](https://oauth.net/2/bearer-tokens/).

<div id="when-are-they-used">
  #### À quel moment sont-ils utilisés ?
</div>

Les produits qui nécessitent l’utilisation d’un Bearer Token sont les suivants :

* [Engagement API](/fr/x-api/enterprise-gnip-2.0/fundamentals/engagement-api)
* [Account Activity API](/fr/x-api/enterprise-gnip-2.0/fundamentals/account-activity)
* D’autres API qui utilisent l’authentification par Bearer Token OAuth 2.0, comme les endpoints v2 et Labs.

<div id="prerequisites">
  #### Prérequis
</div>

Vous devez [créer un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) et une [X App](/fr/resources/fundamentals/developer-apps). Une fois cela fait, vous devrez également obtenir les clés API disponibles dans la [Console de Développement](/fr/resources/fundamentals/developer-portal). Suivez les étapes ci-dessous :

1. Connectez-vous à votre compte X sur developer.x.com.
2. Accédez au [tableau de bord X App](https://developer.x.com/content/developer-twitter/en/apps) et ouvrez la X App pour laquelle vous souhaitez générer des jetons d&#39;accès.
3. Accédez à la page « Keys and tokens ».
4. Vous trouverez les clés API, les jetons d&#39;accès utilisateur et le Bearer Token sur cette page.

<div id="how-to-generate-a-bearer-token">
  ### Comment générer un Bearer Token
</div>

Vous pouvez trouver le Bearer Token de votre App avec le reste de vos « Keys and Tokens ».

Copiez la requête cURL suivante dans votre ligne de commande après avoir remplacé les clés d’API consommateur suivantes, préalablement obtenues à partir de votre [X App](/fr/resources/fundamentals/developer-apps). Notez que les clés d’API consommateur utilisées sur cette page ont été désactivées et ne fonctionneront pas pour des requêtes réelles.

* **Clé d’API** `<API key>` par exemple : `xvz1evFS4wEEPTGEFPHBog`
* **Clé secrète d’API** `<API secret key>` par exemple : `L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg`

  ```bash
  curl -u "$API_KEY:$API_SECRET_KEY" \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
  ```

Voici un exemple de la façon dont la requête cURL doit apparaître une fois vos clés d’API renseignées :

```bash
   curl -u 'xvz1evFS4wEEPTGEFPHBog:L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg' \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
```

Voici à quoi ressemblerait la réponse. Notez qu&#39;il s&#39;agit d&#39;un Bearer Token désactivé :

`{"token_type":"bearer","access_token":"AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F"}`

Notre Bearer Token utilisé pour s&#39;authentifier auprès des ressources avec OAuth 2.0 serait :

`AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F`
