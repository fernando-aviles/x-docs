<div id="using-and-generating-an-app-only-bearer-token">
  ### Utilisation et génération d’un Bearer Token applicatif (app-only)
</div>

Un Bearer Token offre aux développeurs un point d’entrée plus sécurisé pour utiliser X API et constitue l’une des fonctionnalités clés d’OAuth 2.0. 

L’authentification qui utilise un Bearer Token est également appelée authentification applicative (app-only). Un Bearer Token est un tableau d’octets au format non spécifié que vous générez à l’aide d’un script, par exemple une commande curl. Vous pouvez également obtenir un Bearer Token depuis le Developer Console, dans la section des clés et des tokens des paramètres de votre App. Vous trouverez plus d’informations sur cette fonctionnalité dans la [documentation officielle d’OAuth](https://oauth.net/2/bearer-tokens/).

<div id="when-are-they-used">
  #### Quand sont-ils utilisés ?
</div>

Les produits pour lesquels l&#39;utilisation d&#39;un Bearer Token est requise sont les suivants :

* [Engagement API](/fr/x-api/enterprise-gnip-2.0/fundamentals/engagement-api)
* [Account Activity API](/fr/x-api/enterprise-gnip-2.0/fundamentals/account-activity)
* D&#39;autres API qui utilisent l&#39;authentification OAuth 2.0 Bearer Token, comme les points de terminaison v2 et Labs.

<div id="prerequisites">
  #### Prérequis
</div>

Vous devez [créer un compte développeur](https://developer.x.com/en/portal/petition/essential/basic-info) et avoir créé une [X App](/fr/resources/fundamentals/developer-apps). Une fois ces éléments en place, vous devrez également obtenir les clés d’API disponibles dans le [Developer Console](/fr/resources/fundamentals/developer-portal). Suivez les étapes ci-dessous :

1. Connectez-vous à votre compte X sur developer.x.com.
2. Accédez au [X App dashboard](https://developer.x.com/content/developer-twitter/en/apps) et ouvrez la X App pour laquelle vous souhaitez générer des jetons d’accès.
3. Accédez à la page « keys and tokens ».
4. Vous trouverez les clés d’API, les jetons d’accès utilisateur et le Bearer Token sur cette page.

<div id="how-to-generate-a-bearer-token">
  ### Comment générer un Bearer Token
</div>

Vous pouvez trouver le Bearer Token de votre App avec le reste de vos « Keys and Tokens ».

Copiez la requête cURL suivante dans votre ligne de commande après avoir remplacé les clés d’API consommateur suivantes, préalablement obtenues depuis votre [X App](/fr/resources/fundamentals/developer-apps). Notez que les clés d’API consommateur utilisées sur cette page ont été désactivées et ne fonctionneront pas pour des requêtes réelles.

* **API key** `<API key>` par exemple `xvz1evFS4wEEPTGEFPHBog`
* **API secret key** `<API secret key>` par exemple `L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg`

  ```bash
  curl -u "$API_KEY:$API_SECRET_KEY" \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
  ```

Voici un exemple de ce à quoi la requête curl doit ressembler une fois vos clés d’API renseignées :

```bash
   curl -u 'xvz1evFS4wEEPTGEFPHBog:L8qq9PZyRg6ieKGEKhZolGC0vJWLw8iEJ88DRdyOg' \
  --data 'grant_type=client_credentials' \
  'https://api.x.com/oauth2/token'
```

Voici à quoi la réponse ressemblerait. Notez qu&#39;il s&#39;agit d&#39;un Bearer Token désactivé :

`{"token_type":"bearer","access_token":"AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F"}`

Notre Bearer Token utilisé pour s’authentifier auprès des ressources avec OAuth 2.0 serait :

`AAAAAAAAAAAAAAAAAAAAAMLheAAAAAAA0%2BuSeid%2BULvsea4JtiGRiSDSJSI%3DEUifiRBkKG5E2XzMDjRfl76ZC9Ub0wnz4XsNiRVBChTYbJcE3F`
