Les connexions TLS sont obligatoires pour accéder aux endpoints de X API. La communication via TLS préserve la confidentialité et la sécurité des utilisateurs en protégeant les informations échangées entre l’utilisateur et X API lorsqu’elles transitent sur l’Internet public. Les connexions à X API requièrent la version 1.2 du protocole TLS.


<div id="verification">
  ## Vérification
</div>

<div id="use-an-up-to-date-root-store">
  ### Utiliser un magasin de racines à jour
</div>

Il est important que votre application ou bibliothèque utilise un magasin de certificats racines fiable et à jour lors de la vérification du certificat X. Lorsque c’est possible, utiliser le magasin de racines fourni par votre système d’exploitation peut être l’approche la plus simple. Sinon, le [magasin de racines Mozilla (NSS)](https://www.mozilla.org/en-US/about/governance/policies/security-group/certs/) est entretenu de manière publique et transparente. cURL fournit également [une version de ce magasin au format PEM](https://curl.haxx.se/docs/caextract.html).

X émet actuellement la majorité de nos certificats à partir de la [DigiCert High Assurance EV Root CA](https://www.digicert.com/digicert-root-certificates.htm), mais ce n’est pas le cas pour 100 % des certificats liés à X et cela pourrait ne pas rester vrai indéfiniment. Se fier uniquement aux autorités racines DigiCert actuellement utilisées peut donc entraîner des problèmes avec votre application à l’avenir.

<div id="check-crls-and-the-ocsp-status">
  ### Vérifier les CRL et le statut OCSP[](#check-crls-and-the-ocsp-status "Permalien vers ce titre")
</div>

De nombreuses applications ne vérifient pas les listes de révocation de certificats (CRL) pour les certificats délivrés ou s’appuient sur le système d’exploitation pour le faire. Assurez-vous que votre application ou votre bibliothèque TLS est configurée pour forcer la vérification des CRL et d’OCSP (Online Certificate Status Protocol) avant d’accepter le certificat de X.

<div id="cdns">
  ### CDNs[](#cdns "Permalink vers ce titre")
</div>

Lorsque vous affichez des Tweets contenant des médias, utilisez l’attribut `media_url_https` comme URL HTTPS pour l’affichage des images. À l’avenir, toutes les URL fournies par les endpoints de l’API fourniront des chemins HTTPS.

<div id="provide-an-indication-of-security-status">
  ## Indiquer l’état de sécurité
</div>

Si possible, vous devez afficher une indication de l’état actuel de la connexion entre votre application et X. Certains navigateurs Web l’indiquent en affichant une icône de verrouillage, tandis que d’autres indiquent l’état de la connexion actuelle au moyen d’un message descriptif.
