<div id="general">
  ## Général
</div>

<AccordionGroup>
  <Accordion title="Qu’est-ce qu’OAuth ?">
    OAuth est un protocole d’authentification qui permet aux utilisateurs d’approuver une application pour qu’elle agisse en leur nom sans partager leur mot de passe. Vous pouvez trouver plus d’informations sur [oauth.net](http://oauth.net/).
  </Accordion>

  <Accordion title="Comment générer des jetons d’accès ?">
    Vous devez disposer d’une [X app](/fr/resources/fundamentals/developer-apps) pour générer des jetons d’accès. Pour en savoir plus sur les jetons d’accès, consultez [ce document](/fr/resources/fundamentals/authentication#oauth-1-0a-2). 
  </Accordion>

  <Accordion title="Comment créer une X app ?">
    Vous devez disposer d’un [compte développeur](/fr/resources/fundamentals/developer-portal) pour créer une [X app](/fr/resources/fundamentals/developer-apps). Vous pouvez en créer un en vous inscrivant [ici](https://developer.x.com/en/portal/petition/essential/basic-info).
  </Accordion>

  <Accordion title="Si je dispose déjà d’une X app, comment puis-je afficher et modifier cette app ?">
    Vous pouvez afficher et modifier votre app depuis le&amp;nbsp[tableau de bord X app](https://developer.x.com/content/developer-twitter/en/apps) si vous êtes connecté à votre compte X sur developer.x.com.
  </Accordion>
</AccordionGroup>

<div id="technical">
  ## Technique
</div>

<AccordionGroup>
  <Accordion title="Quelle est la durée de vie d’un jeton d’accès ?">
    Les jetons d’accès n’ont pas de date d’expiration explicite. Un jeton d’accès sera invalidé si un utilisateur révoque explicitement une application dans les paramètres de son compte X, ou si X suspend une application. Si une application est suspendue, une note apparaîtra dans le tableau de bord [X app](/fr/resources/fundamentals/developer-apps) indiquant qu’elle a été suspendue.
  </Accordion>

  <Accordion title="Que se passe-t-il si un jeton d’accès devient invalide ?">
    Supposons que le jeton d’accès d’un utilisateur puisse devenir invalide à tout moment. Si cela se produit, invitez l’utilisateur à autoriser à nouveau l’application. Il est important de gérer cette situation de manière fluide pour offrir une bonne expérience utilisateur.
  </Accordion>

  <Accordion title="La page d’enregistrement de l’application demande des autorisations de lecture/écriture. Qu’est-ce qui constitue une écriture ?">
    De nombreux utilisateurs font confiance à une application pour lire leurs informations, mais pas nécessairement pour modifier les informations de leur profil utilisateur ou publier de nouvelles publications. La mise à jour d’informations via X API – qu’il s’agisse du nom, de la localisation ou de l’ajout d’une nouvelle publication – nécessite une requête HTTP POST. Toute méthode d’API qui nécessite une requête HTTP POST est considérée comme une méthode d’écriture et requiert des autorisations de lecture et d’écriture.
  </Accordion>
</AccordionGroup>
