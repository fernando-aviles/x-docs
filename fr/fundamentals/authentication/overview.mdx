Les X API traitent d’énormes quantités de données. La façon dont nous garantissons la sécurité de ces données pour les développeurs comme pour les utilisateurs passe par l’authentification. Il existe plusieurs méthodes d’authentification, chacune répertoriée ci-dessous.

La plupart des développeurs n’auront pas besoin de se préoccuper de la complexité de l’authentification, car les bibliothèques clientes gèrent automatiquement ces aspects.

Vous pouvez trouver une liste des bibliothèques clientes disponibles sur notre page [Outils et bibliothèques](/fr/resources/tools-and-libraries).

  <Card title="Flux de code d’autorisation OAuth 2.0 avec PKCE" href="/fr/resources/fundamentals/authentication/oauth-2-0/authorization-code">
    OAuth 2.0 User Context vous permet de vous authentifier pour le compte d’un autre compte avec un contrôle plus précis sur le périmètre d’accès d’une application, ainsi que des flux d’autorisation sur plusieurs appareils.

    <br />

<Note>
  **Remarque :**
  Les clés d’API de votre App et l’App only Access Token, ainsi que votre Access Token personnel et votre Access Token Secret, peuvent être obtenus dans la section [X developer Apps](/fr/resources/fundamentals/developer-apps) de la [Console de Développement](/fr/resources/fundamentals/developer-portal).

  **Si vous souhaitez effectuer des requêtes pour le compte d’un autre utilisateur**, vous devrez générer un jeu distinct d’Access Tokens pour cet utilisateur en utilisant le [flux OAuth en 3 étapes](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens), puis transmettre les jetons de cet utilisateur avec vos requêtes OAuth 1.0a User Context ou en contexte utilisateur OAuth 2.0.
</Note>
