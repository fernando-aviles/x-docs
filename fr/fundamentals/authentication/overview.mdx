Les X API gèrent d’énormes quantités de données. La sécurité de ces données, pour les développeurs comme pour les utilisateurs, repose sur l’authentification. Il existe plusieurs méthodes d’authentification, décrites ci-dessous.

La plupart des développeurs n’auront pas à gérer la complexité liée à l’authentification, car les bibliothèques clientes la prennent automatiquement en charge.

Vous trouverez une liste des bibliothèques clientes disponibles sur notre page [Outils et bibliothèques](/fr/resources/tools-and-libraries).

<Note>
  **Remarque :**
  Les clés d’API de votre App et le jeton d’accès App only, ainsi que votre jeton d’accès personnel et votre secret de jeton d’accès, peuvent être obtenus dans la section [X developer Apps](/fr/resources/fundamentals/developer-apps) disponible dans la [Developer Console](/fr/resources/fundamentals/developer-portal).

  **Si vous souhaitez effectuer des requêtes au nom d’un autre utilisateur**, vous devrez générer un jeu distinct de jetons d’accès pour cet utilisateur en utilisant le [flux OAuth à 3 étapes](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens), puis transmettre les jetons de cet utilisateur avec vos requêtes en contexte utilisateur OAuth 1.0a ou en contexte utilisateur OAuth 2.0.
</Note>
