<div id="api-key-and-secret">
  ### Clé API et secret
</div>

La clé API et le secret (également appelés clé et secret client) sont les identifiants les plus fondamentaux nécessaires pour accéder à la X API. Ces identifiants jouent le rôle de nom d’utilisateur et de mot de passe pour votre App X et sont utilisés par la X API pour identifier de quelle App proviennent les requêtes. 

Ces identifiants peuvent être utilisés par les [endpoints d’authentification](/fr/resources/fundamentals/authentication/api-reference) pour générer d’autres identifiants, comme les [jetons d’accès utilisateur et leurs secrets](/fr/resources/fundamentals/authentication/oauth-1-0a/api-key-and-secret), ainsi que les [jetons Bearer](/fr/resources/fundamentals/authentication/oauth-2-0/bearer-tokens). Vous devez également utiliser ces identifiants avec des jetons d’accès et d’autres paramètres d’autorisation pour [autoriser les requêtes](/fr/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request) qui nécessitent une authentification OAuth 1.0a dans un contexte utilisateur. 

<div id="how-to-acquire-an-api-key-and-secret">
  #### Comment obtenir une clé et un secret d’API
</div>

Pour obtenir une clé et un secret d’API X, veuillez suivre les étapes suivantes :

1. [Inscrivez-vous pour créer un compte développeur X](https://developer.x.com/en/apply-for-access)
2. Créez une [App X](/fr/resources/fundamentals/developer-apps) dans la [Console de développement](/fr/resources/fundamentals/developer-portal). Notez que si vous souhaitez utiliser [X API v2](/fr/x-api/introduction), vous devez utiliser des clés et des jetons provenant d’une App développeur.
    

Lorsque vous créez votre App X, votre clé et votre secret d’API vous sont fournis, ainsi qu’un Jeton Bearer. Veuillez noter que nous n’affichons ces identifiants qu’une seule fois, veillez donc à les enregistrer dans votre gestionnaire de mots de passe ou dans un endroit sécurisé.

Vous trouverez davantage de recommandations sur la façon de gérer vos clés et vos jetons sur notre page consacrée aux [bonnes pratiques d’authentification](/fr/resources/fundamentals/authentication/guides/authentication-best-practices), qui inclut des détails sur ce que vous devez faire si vos identifiants ont été compromis.
 

<div id="how-to-find-and-regenerate-your-api-key-and-secret-after-app-creation">
  #### Comment retrouver et régénérer votre clé API et votre secret après la création de l&#39;App
</div>

Si vous avez déjà créé une App et que vous devez retrouver ou régénérer votre clé API et votre secret, veuillez suivre ces étapes :

1. Accédez à la Console de développement
2. Développez le menu déroulant « Apps » dans la barre latérale de navigation
3. Ouvrez l&#39;App associée à la clé API et au secret que vous souhaitez retrouver ou régénérer
4. Accédez à l&#39;onglet « Keys and tokens »

Depuis cet emplacement, vous trouverez tous les identifiants associés à votre App. 
 

<div id="how-to-use-your-api-key-and-secret">
  #### Comment utiliser votre clé et votre secret d’API
</div>

Si vous faites simplement vos premiers pas sur la plateforme développeur X, nous vous recommandons d’utiliser un [outil ou une bibliothèque](/fr/resources/tools-and-libraries) pour voir ce qui est disponible sur la plateforme. Ces outils gèrent l’authentification de manière transparente et peuvent vous faire gagner beaucoup de temps et vous éviter bien des frustrations. Nous recommandons en particulier de [commencer avec Postman](/fr/tutorials/postman-getting-started) ou [Insomnia](https://insomnia.rest/) pour les développeurs débutants. 

Si vous souhaitez construire une requête à partir de zéro, veuillez consulter notre guide sur [l’autorisation d’une requête OAuth 1.0a](/fr/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request).
