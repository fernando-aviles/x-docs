<div id="api-key-and-secret">
  ### Clé et secret d’API
</div>

La clé et le secret d’API (également appelés Consumer Key et Consumer Secret) sont les informations d’identification les plus fondamentales Obligatoires pour accéder à X API. Ces identifiants agissent comme le nom d’utilisateur et le mot de passe de votre application X, et sont utilisés par X API pour savoir de quelle application proviennent les requêtes. 

Ces identifiants peuvent être utilisés par les [endpoints d’authentification](/fr/resources/fundamentals/authentication/api-reference) pour générer des identifiants supplémentaires, tels que les [jetons d’accès utilisateur et leurs secrets](/fr/resources/fundamentals/authentication/oauth-1-0a/api-key-and-secret) et les [Bearer Tokens](/fr/resources/fundamentals/authentication/oauth-2-0/bearer-tokens). Vous devez également utiliser ces identifiants avec des jetons d’accès et d’autres paramètres d’autorisation pour [autoriser des requêtes](/fr/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request) qui nécessitent une authentification OAuth 1.0a User Context. 

<div id="how-to-acquire-an-api-key-and-secret">
  #### Comment obtenir une clé et un secret d’API
</div>

Pour obtenir une clé et un secret X API, veuillez suivre les étapes suivantes :

1. [Inscrivez-vous pour obtenir un compte développeur X](https://developer.x.com/en/apply-for-access)
2. Créez une [X App](/fr/resources/fundamentals/developer-apps) dans la [Developer Console](/fr/resources/fundamentals/developer-portal). Notez que si vous souhaitez utiliser [X API v2](/fr/x-api/introduction), vous devez utiliser des clés et des jetons provenant d’une App développeur.
    

Lorsque vous créez votre X App, votre clé d’API et votre secret vous sont fournis, ainsi qu’un Bearer Token. Veuillez noter que nous n’affichons ces identifiants qu’une seule fois ; veillez donc à les enregistrer dans votre gestionnaire de mots de passe ou dans un endroit sécurisé.

Nous proposons davantage de recommandations sur la façon de gérer vos clés et vos jetons sur notre page consacrée aux [meilleures pratiques d’authentification](/fr/resources/fundamentals/authentication/guides/authentication-best-practices), y compris des détails sur ce que vous devez faire si vos identifiants ont été compromis.
 

<div id="how-to-find-and-regenerate-your-api-key-and-secret-after-app-creation">
  #### Comment trouver et régénérer votre API Key et Secret après la création de l&#39;App
</div>

Si vous avez déjà créé une App et que vous devez trouver ou régénérer votre API Key et Secret, veuillez suivre les étapes suivantes :

1. Accédez au Developer Console
2. Ouvrez la liste déroulante &#39;Apps&#39; dans la barre latérale de navigation
3. Ouvrez l&#39;App associée à l&#39;API Key et au Secret que vous souhaitez trouver ou régénérer
4. Accédez à l&#39;onglet &#39;Keys and tokens&#39;

Vous y trouverez tous les identifiants associés à votre App. 
 

<div id="how-to-use-your-api-key-and-secret">
  #### Comment utiliser votre clé et votre secret d’API
</div>

Si vous faites simplement vos premiers pas avec la plateforme pour développeurs X, nous vous recommandons d’utiliser un [outil ou une bibliothèque](/fr/resources/tools-and-libraries) pour découvrir ce qui est disponible sur la plateforme. Ces outils gèrent l’authentification de manière transparente et peuvent vous faire gagner beaucoup de temps et vous éviter bien des frustrations. Nous recommandons tout particulièrement de [démarrer avec Postman](/fr/tutorials/postman-getting-started) ou [Insomnia](https://insomnia.rest/) pour les développeurs débutants. 

Si vous souhaitez créer une requête à partir de zéro, consultez notre guide sur [l’autorisation d’une requête avec OAuth 1.0a](/fr/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request).
