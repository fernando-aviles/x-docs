<div id="api-key-and-secret">
  ### API Key and Secret
</div>

La clé API et le secret (également appelés Consumer Key et Consumer Secret) sont les identifiants les plus fondamentaux nécessaires pour accéder à X API. Ces identifiants jouent le rôle de nom d’utilisateur et de mot de passe de votre application X et sont utilisés par X API pour identifier l’application à l’origine des requêtes. 

Ces identifiants peuvent être utilisés par les [endpoints d’authentification](/fr/resources/fundamentals/authentication/api-reference) pour générer d’autres identifiants, tels que les [jetons d’accès utilisateur (Access Tokens) et leurs secrets](/fr/resources/fundamentals/authentication/oauth-1-0a/api-key-and-secret), ainsi que les [Bearer Tokens](/fr/resources/fundamentals/authentication/oauth-2-0/bearer-tokens). Vous devez également utiliser ces identifiants en combinaison avec des Access Tokens et d’autres paramètres d’autorisation pour [autoriser les requêtes](/fr/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request) qui nécessitent une authentification OAuth 1.0a User Context. 

<div id="how-to-acquire-an-api-key-and-secret">
  #### Comment obtenir une clé et un secret d’API
</div>

Pour obtenir une clé et un secret d’API X, veuillez suivre les étapes suivantes :

1. [Créez un compte développeur X](https://developer.x.com/en/apply-for-access)
2. Créez une [X App](/fr/resources/fundamentals/developer-apps) dans la [Console de Développement](/fr/resources/fundamentals/developer-portal). Notez que si vous souhaitez utiliser [X API v2](/fr/x-api/introduction), vous devez utiliser les clés et jetons provenant d’une App développeur.
    

Lorsque vous créez votre X App, votre clé et votre secret d’API, ainsi qu’un Bearer Token, s’afficheront. Veuillez noter que nous n’affichons ces identifiants qu’une seule fois ; assurez-vous donc de les enregistrer dans votre gestionnaire de mots de passe ou dans un endroit sécurisé.

Vous trouverez plus de recommandations sur la façon de gérer vos clés et jetons sur notre page consacrée aux [bonnes pratiques d’authentification](/fr/resources/fundamentals/authentication/guides/authentication-best-practices), y compris des détails sur ce que vous devez faire si vos identifiants ont été compromis.
 

<div id="how-to-find-and-regenerate-your-api-key-and-secret-after-app-creation">
  #### Comment retrouver et régénérer votre API Key et Secret après la création de l&#39;App
</div>

Si vous avez déjà créé une App et que vous devez retrouver ou régénérer votre API Key et Secret, veuillez suivre les étapes suivantes :

1. Accédez à la Console de Développement
2. Déployez le menu déroulant « Apps » dans la barre latérale de navigation
3. Ouvrez l&#39;App associée à l&#39;API Key et au Secret que vous souhaitez retrouver ou régénérer
4. Accédez à l&#39;onglet « Keys and tokens »

Depuis cet onglet, vous trouverez tous les identifiants associés à votre App. 
 

<div id="how-to-use-your-api-key-and-secret">
  #### Comment utiliser votre clé et votre secret d’API
</div>

Si vous ne faites qu’explorer la plateforme développeur X, nous vous recommandons d’utiliser un [outil ou une bibliothèque](/fr/resources/tools-and-libraries) pour voir ce qui est disponible sur la plateforme. Ces outils gèrent l’authentification de manière transparente et peuvent vous faire gagner beaucoup de temps et vous éviter bien des frustrations. Nous recommandons tout particulièrement de [commencer avec Postman](/fr/tutorials/postman-getting-started) ou [Insomnia](https://insomnia.rest/) pour les développeurs débutants. 

Si vous souhaitez créer une requête à partir de zéro, consultez notre guide sur [l’autorisation d’une requête OAuth 1.0a](/fr/resources/fundamentals/authentication/oauth-1-0a/authorizing-a-request).
