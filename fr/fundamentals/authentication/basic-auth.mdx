<div id="basic-authentication">
  ## Authentification de base
</div>

De nombreuses API d’entreprise de X requièrent l’utilisation de l’authentification HTTP Basic. Pour effectuer avec succès une requête vers une API qui nécessite l’authentification Basic, vous devez transmettre une combinaison valide d’adresse e‑mail et de mot de passe dans l’en-tête d’autorisation pour chaque requête. La combinaison adresse e‑mail et mot de passe est la même que celle que vous utilisez pour accéder à la [console de l’API d’entreprise](https://console.gnip.com/), et peut être modifiée depuis cette console. 

Lorsque vous construisez une requête utilisant l’authentification Basic, veillez à ajouter l’en-tête HTTP Authentication: Basic avec des identifiants encodés, sur HTTPS.

Dans l’exemple de requête cURL suivant, vous devez remplacer `<email_address>` et `<password>` par vos identifiants avant d’envoyer la requête :

```bash
curl -v --compressed -u<email_address>:<password>
    "https://gnip-api.x.com/search/30day/accounts/<account-name>/prod/counts.json?query=from%3Axdevelopers"
```
