<div id="basic-authentication">
  ## Authentification de base
</div>

De nombreuses API Enterprise de X nécessitent l’utilisation de l’authentification HTTP Basic. Pour effectuer une requête vers une API qui requiert l’authentification Basic, vous devez transmettre une combinaison adresse e‑mail et mot de passe valide dans l’en-tête d’autorisation pour chaque requête. La combinaison adresse e‑mail et mot de passe est la même que celle que vous utilisez pour accéder à la [console Enterprise API](https://console.gnip.com/), et peut être modifiée depuis cette console. 

Lorsque vous créez une requête utilisant l’authentification Basic, assurez-vous d’ajouter l’en-tête HTTP Authentication: Basic avec des identifiants encodés, transmis sur HTTPS.

Dans l’exemple de requête cURL suivant, remplacez `<email_address>` et `<password>` par vos identifiants avant d’envoyer la requête :

```bash
curl -v --compressed -u<email_address>:<password>
    "https://gnip-api.x.com/search/30day/accounts/<account-name>/prod/counts.json?query=from%3Axdevelopers"
```
