<div id="basic-authentication">
  ## Authentification de base
</div>

De nombreuses API Enterprise de X nécessitent l&#39;utilisation de l&#39;authentification HTTP Basic. Pour qu&#39;une requête vers une API qui requiert l&#39;authentification Basic aboutisse, vous devez transmettre une combinaison valide d&#39;adresse e‑mail et de mot de passe dans un en‑tête d&#39;autorisation pour chaque requête. La combinaison e‑mail et mot de passe est la même que celle que vous utiliserez pour accéder à la [console des API Enterprise](https://console.gnip.com/), et peut être modifiée depuis cette console. 

Lorsque vous construisez une requête utilisant l&#39;authentification Basic, assurez‑vous d&#39;ajouter l&#39;en‑tête HTTP Authentication: Basic avec les identifiants encodés via HTTPS.

Dans l&#39;exemple de requête cURL suivant, vous devez remplacer `<email_address>` et `<password>` par vos identifiants avant d&#39;envoyer la requête :

```bash
curl -v --compressed -u<email_address>:<password>
    "https://gnip-api.x.com/search/30day/accounts/<account-name>/prod/counts.json?query=from%3Axdevelopers"
```
