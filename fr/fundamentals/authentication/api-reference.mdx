<div id="post-oauthrequest_token">
  ### POST oauth/request_token
</div>

Permet à une application cliente d’obtenir un OAuth Request Token pour demander l’autorisation de l’utilisateur. Cette méthode remplit la [section 6.1](https://oauth.net/core/1.0/#auth_step1) du [flux d’authentification OAuth 1.0](http://oauth.net/core/1.0/#anchor9).

**L’utilisation de HTTPS est obligatoire pour toutes les étapes d’autorisation OAuth.**

**Remarque d’utilisation :** seules les valeurs ASCII sont acceptées pour `oauth_nonce`.

**URL de la ressource[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/request_token`

**Informations sur la ressource[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| Formats de réponse | JSON |
| Nécessite une authentification ? | Non |
| Soumise à une limitation de débit ? | Oui |

**Paramètres[](#parameters "Permalink to this headline")**

| Nom | Obligatoire | Description | Exemple |
| :--- | :--- | :--- | :--- |
| oauth&#95;callback | Obligatoire | Pour être conforme à OAuth 1.0a, ce paramètre est **obligatoire**. La valeur que vous indiquez ici sera utilisée comme URL vers laquelle un utilisateur est redirigé s’il approuve l’accès de votre application à son compte. Définissez cette valeur sur `oob` pour le mode code (out‑of‑band PIN). C’est également ainsi que vous spécifiez des callbacks personnalisés à utiliser dans les applications de bureau/mobile. Envoyez toujours un `oauth_callback` à cette étape, indépendamment d’un callback pré‑enregistré.<br /><br />Nous exigeons que toute URL de callback utilisée avec ce point de terminaison soit configurée dans les paramètres de l’application sur developer.x.com* | `http://themattharris.local/auth.php` `twitterclient://callback` |
| x&#95;auth&#95;access&#95;type | Facultatif | Remplace le niveau d’accès qu’une application demande pour le compte d’un utilisateur. Les valeurs prises en charge sont `read` ou `write`. Ce paramètre est destiné à permettre à un développeur d’enregistrer une application en lecture/écriture, mais aussi de demander un accès en lecture seule lorsque cela est approprié. |     |

Pour en savoir plus sur la manière d’approuver vos URL de callback, consultez [cette page](/fr/resources/fundamentals/developer-apps#callback-urls).

**Veuillez noter** - Vous pouvez afficher et modifier vos [applications X](/fr/resources/fundamentals/developer-apps) existantes via le [tableau de bord des applications X](https://developer.x.com/en/apps) si vous êtes connecté à votre compte X sur developer.x.com.

**Exemple de requête[](#example-request "Permalink to this headline")**

URL de la requête : `POST https://api.x.com/oauth/request_token`

Corps POST de la requête : *N/A*

En‑tête Authorization : `OAuth oauth_nonce="K7ny27JTpKVsTgdyLdDfmQQWVLERj2zAK5BslRsqyw", oauth_callback="http%3A%2F%2Fmyapp.com%3A3005%2Ftwitter%2Fprocess_callback", oauth_signature_method="HMAC-SHA1", oauth_timestamp="1300228849", oauth_consumer_key="OqEqJeafRSF11jBMStrZz", oauth_signature="Pc%2BMLdv028fxCErFyi8KXFM%2BddU%3D", oauth_version="1.0"`

Réponse : `oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik&oauth_token_secret=Kd75W4OQfb2oJTV0vzGzeXftVAwgMnEK9MumzYcM&oauth_callback_confirmed=true`

<div id="get-oauthauthorize">
  ### GET oauth/authorize
</div>

Permet à une application Consumer d’utiliser un OAuth Request Token pour demander l’autorisation de l’utilisateur. Cette méthode répond aux exigences de la [Section 6.2](http://oauth.net/core/1.0/#auth_step2) du [flux d’authentification OAuth 1.0](http://oauth.net/core/1.0/#anchor9). Les applications de bureau doivent utiliser cette méthode (et ne peuvent pas utiliser [GET oauth / authenticate](/fr/resources/fundamentals/authentication/api-reference#get-oauth-authenticate)).

**Remarque d’utilisation :** Un `oauth_callback` n’est jamais envoyé à cette méthode ; fournissez-le plutôt à [POST oauth / request&#95;token](/fr/resources/fundamentals/authentication/api-reference#post-oauth-request-token).

**URL de la ressource[](#resource-url "Permalien vers ce titre")**

`https://api.x.com/oauth/authorize`

**Informations sur la ressource[](#resource-information "Permalien vers ce titre")**

|     |     |
| :--- | :--- |
| Formats de Réponse | JSON |
| Nécessite une authentification ? | Oui |
| Soumis à une limitation de débit ? | Oui |

**Paramètres[](#parameters "Permalien vers ce titre")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| Nom | Obligatoire | Description | Valeur par défaut | Exemple |
| force&#95;login | facultatif | Force l’utilisateur à saisir ses identifiants pour garantir que le bon compte utilisateur est autorisé. |     |     |
| screen&#95;name | facultatif | Préremplit le champ du nom d’utilisateur de l’écran de connexion OAuth avec la valeur fournie. |     |     |

**Exemple de requête[](#example-request "Permalien vers ce titre")**

Envoyez l’utilisateur vers l’étape `oauth/authorize` dans un navigateur Web, en incluant un paramètre `oauth_token` :
`https://api.x.com/oauth/authorize?oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik`

<div id="get-oauthauthenticate">
  ### GET oauth/authenticate
</div>

Permet à une application consommatrice d&#39;utiliser un `request_token` OAuth pour demander l’autorisation d’un utilisateur.

Cette méthode remplace la [section 6.2](http://oauth.net/core/1.0/#auth_step2) du [flux d’authentification OAuth 1.0](http://oauth.net/core/1.0/#anchor9) pour les applications utilisant le flux d’authentification avec callback. La méthode utilisera l’utilisateur actuellement connecté comme compte pour l’autorisation d’accès, sauf si le paramètre `force_login` est défini sur `true`.

Cette méthode diffère de [GET oauth / authorize](/fr/resources/fundamentals/authentication/api-reference#get-oauth-authorize) en ce que, si l’utilisateur a déjà accordé l’autorisation à l’application, la redirection se produira sans que l’utilisateur ait à approuver à nouveau l’application. Pour obtenir ce comportement, vous devez activer le paramètre *Use Sign in with X* dans l’[enregistrement de votre application](https://developer.x.com/apps).

**Resource URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth/authenticate`

**Resource Information[](#resource-information "Permalink to this headline")**

|     |     |
| :--- | :--- |
| Formats de réponse | JSON |
| Authentification requise ? | Oui |
| Soumis à une limite de débit ? | Oui |

**Parameters[](#parameters "Permalink to this headline")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| Nom | Obligatoire | Description | Valeur par défaut | Exemple |
| force&#95;login | facultatif | Force l’utilisateur à saisir ses identifiants afin de s’assurer que le compte du bon utilisateur est autorisé. |     | *true* |
| screen&#95;name | facultatif | Préremplit le champ de nom d’utilisateur de l’écran de connexion OAuth avec la valeur fournie. |     |     |

**Example request[](#example-request "Permalink to this headline")**

Redirigez l’utilisateur vers l’étape `oauth/authenticate` dans un navigateur Web, en incluant un paramètre oauth&#95;token :
`https://api.x.com/oauth/authenticate?oauth_token=Z6eEdO8MOmk394WozF5oKyuAv855l4Mlqo7hhlSLik`

<div id="post-oauthaccess_token">
  ### POST oauth/access_token
</div>

Permet à une application cliente (Consumer) d’échanger le OAuth Request Token contre un OAuth Access Token. Cette méthode répond à la [section 6.3](http://oauth.net/core/1.0/#auth_step3) du [flux d’authentification OAuth 1.0](http://oauth.net/core/1.0/#anchor9).

**Resource URL[](#resource-url "Lien permanent vers ce titre")**

`https://api.x.com/oauth/access_token`

**Resource Information[](#resource-information "Lien permanent vers ce titre")**

|     |     |
| :--- | :--- |
| Formats de Réponse | JSON |
| Authentification requise ? | Oui |
| Soumis à des limites de fréquence ? | Oui |

**Parameters[](#parameters "Lien permanent vers ce titre")**

|     |     |     |     |     |
| :--- | :--- | :--- | :--- | :--- |
| Nom | Obligatoire | Description | Valeur par défaut | Exemple |
| oauth&#95;token | obligatoire | Le `oauth_token` ici doit être identique au `oauth_token` renvoyé à l’étape `request_token`. |     |     |
| oauth&#95;verifier | obligatoire | Si vous utilisez le flux web OAuth, définissez ce paramètre sur la valeur de `_oauth_verifier_` renvoyée dans l’URL de rappel (callback). Si vous utilisez OAuth hors bande (out-of-band), définissez cette valeur sur le code PIN. Pour respecter OAuth 1.0a, ce paramètre est **obligatoire**. OAuth 1.0a est strictement appliqué et les applications qui n’utilisent pas `_oauth_verifier_` ne pourront pas terminer le flux OAuth. |     |     |

**Example request[](#example-request "Lien permanent vers ce titre")**

`POST https://api.x.com/oauth/access_token?oauth_token=qLBVyoAAAAAAx72QAAATZxQWU6P&oauth_verifier=ghLM8lYmAxDbaqL912RZSRjCCEXKDIzx`

Depuis une requête basée sur un code PIN : `POST https://api.x.com/oauth/access_token?oauth_token=9Npq8AAAAAAAx72QBRABZ4DAfY9&oauth_verifier=4868795`

**Example response[](#example-response "Lien permanent vers ce titre")**

`oauth_token=6253282-eWudHldSbIaelX7swmsiHImEL4KinwaGloHANdrY&oauth_token_secret=2EEfA6BG5ly3sR3XjE0IBSnlQu4ZrUzPiYTmrkVU&user_id=6253282&screen_name=xapi`

<div id="post-oauthinvalidate_token">
  ### POST oauth/invalidate_token
</div>

Permet à une application enregistrée de révoquer un access&#95;token OAuth émis en présentant ses identifiants de client. Une fois qu’un access&#95;token a été invalidé, toute nouvelle tentative de création renverra un jeton d’accès différent et l’utilisation du jeton invalidé ne sera plus autorisée.

**URL de la ressource[](#resource-url "Permalink to this headline")**

`https://api.x.com/1.1/oauth/invalidate_token`

**Informations sur la ressource[](#resource-information "Permalink to this headline")**

|                                 |                                                                                 |
| :------------------------------ | :------------------------------------------------------------------------------ |
| Formats de réponse              | JSON                                                                            |
| Authentification requise ?      | Oui - Contexte utilisateur avec les jetons d’accès que vous souhaitez invalider |
| Soumis à des limites de débit ? | Oui                                                                             |

**Exemple de requête[](#example-request "Permalink to this headline")**

```bash
        curl --request POST
          --url 'https://api.x.com/1.1/oauth/invalidate_token.json'
          --header 'authorization: OAuth oauth_consumer_key="CLIENT_KEY",
         oauth_nonce="AUTO_GENERATED_NONCE", oauth_signature="AUTO_GENERATED_SIGNATURE",
         oauth_signature_method="HMAC-SHA1", oauth_timestamp="AUTO_GENERATED_TIMESTAMP",
         oauth_token="ACCESS_TOKEN", oauth_version="1.0"'
```

**Exemple de réponse[](#example-response "Lien permanent vers ce titre")**

```bash
        HTTP/1.1 200 OK
        Content-Type: application/json; charset=utf-8
        Content-Length: 127
        ...

        {"access_token":"ACCESS_TOKEN"}
```

**Exemple de réponse d’erreur après invalidation du jeton[](#example-error-response-after-token-has-been-invalidated "Permalien vers ce titre")**

```bash
        HTTP/1.1 401 Authorization Required
        ...

        {"errors": [{
          "code": 89,
          "message": "Invalid or expired token."}
        ]}
```

<div id="post-oauth2token">
  ### POST oauth2/token
</div>

Permet à une application enregistrée d’obtenir un Bearer Token OAuth 2, qui peut être utilisé pour effectuer des requêtes d’API pour le compte de l’application elle-même, sans contexte utilisateur. Ceci est appelé [Authentification applicative seule](/fr/resources/fundamentals/authentication/oauth-2-0/application-only).

Un Bearer Token peut être invalidé à l’aide de oauth2/invalidate&#95;token. Une fois qu’un Bearer Token a été invalidé, toute nouvelle tentative de création produira un Bearer Token différent et l’utilisation du jeton précédent ne sera plus autorisée.

Un seul Bearer Token peut être actif pour une application, et des requêtes répétées vers cette méthode produiront le même jeton déjà existant jusqu’à ce qu’il ait été invalidé.

Les réponses réussies contiennent une structure JSON décrivant le Bearer Token accordé.

Les jetons reçus par cette méthode doivent être mis en cache. Si vous tentez cette opération trop fréquemment, les requêtes seront rejetées avec un code HTTP 403 portant le code 99.

**URL de la ressource[](#resource-url "Permalien vers ce titre")**

`https://api.x.com/oauth2/token`

**Informations sur la ressource[](#resource-information "Permalien vers ce titre")**

|                                  |                                                                                                                          |
| :------------------------------- | :----------------------------------------------------------------------------------------------------------------------- |
| Formats de réponse               | JSON                                                                                                                     |
| Nécessite une authentification ? | Oui - Authentification Basic avec votre clé API comme nom d’utilisateur et le secret de votre clé API comme mot de passe |
| Soumis à des limites de débit ?  | Oui                                                                                                                      |

**Paramètres[](#parameters "Permalien vers ce titre")**

|                |             |                                                                                                                                                                                                                                                         |                   |                          |
| :------------- | :---------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :---------------- | :----------------------- |
| Nom            | Obligatoire | Description                                                                                                                                                                                                                                             | Valeur par défaut | Exemple                  |
| grant&#95;type | Obligatoire | Spécifie le type de grant demandé par l’application. Pour le moment, seul *client&#95;credentials* est autorisé. Voir [Authentification applicative seule](/fr/resources/fundamentals/authentication/oauth-2-0/application-only) pour plus d’informations. |                   | *client&#95;credentials* |

**Exemple de requête[](#example-request "Permalien vers ce titre")**

```bash
    POST /oauth2/token HTTP/1.1
    Host: api.x.com
    User-Agent: My X App v1.0.23
    Authorization: Basic eHZ6MWV2R ... o4OERSZHlPZw==
    Content-Type: application/x-www-form-urlencoded;charset=UTF-8
    Content-Length: 29
    Accept-Encoding: gzip

    grant_type=client_credentials
```

**Exemple de réponse :**

```bash
    HTTP/1.1 200 OK
    Status: 200 OK
    Content-Type: application/json; charset=utf-8
    ...
    Content-Encoding: gzip
    Content-Length: 140

    {"token_type":"bearer","access_token":"AAAA%2FAAA%3DAAAAAAAA"}
```

<div id="post-oauth2invalidate_token">
  ### POST oauth2/invalidate_token
</div>

Permet à une application enregistrée de révoquer un Bearer Token OAuth 2.0 émis en présentant ses identifiants client. Une fois qu&#39;un Bearer Token a été invalidé, toute nouvelle tentative d&#39;en créer un produira un Bearer Token différent et l&#39;utilisation du jeton invalidé ne sera plus autorisée.

Les réponses réussies incluent une structure JSON décrivant le Bearer Token révoqué.

**Resource URL[](#resource-url "Permalink to this headline")**

`https://api.x.com/oauth2/invalidate_token`

**Resource Information[](#resource-information "Permalink to this headline")**

|                          |                                                                                                                                                                                                                             |
| :----------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Response formats         | JSON                                                                                                                                                                                                                        |
| Requires authentication? | Oui - [OAuth 1.0a](/fr/resources/fundamentals/authentication/oauth-1-0a) avec les clés API consommateur de l&#39;application et le jeton d&#39;accès &amp; le secret de jeton d&#39;accès du propriétaire de l&#39;application |
| Rate limited?            | Oui                                                                                                                                                                                                                         |

**Parameters[](#parameters "Permalink to this headline")**

| Name             | Required    | Description                                            |
| :--------------- | :---------- | :----------------------------------------------------- |
| access&#95;token | Obligatoire | La valeur du Bearer Token que vous souhaitez invalider |

**Example request[](#example-request "Permalink to this headline")**

```
        curl --request POST
          --url 'https://api.x.com/oauth2/invalidate_token?access_token=AAAA%2FAAA%3DAAAAAAAA'
          --header 'authorization: OAuth oauth_consumer_key="CLIENT_KEY",
         oauth_nonce="AUTO_GENERATED_NONCE", oauth_signature="AUTO_GENERATED_SIGNATURE",
         oauth_signature_method="HMAC-SHA1", oauth_timestamp="AUTO_GENERATED_TIMESTAMP",
         oauth_token="ACCESS_TOKEN", oauth_version="1.0"'
```

**Exemple de réponse[](#example-response "Permalien vers ce titre")**

```
         Status: 200 OK
         Content-Type: application/json; charset=utf-8
         Content-Length: 135
         ...
       {
        "access_token": "AAAA%2FAAA%3DAAAAAAAA"
        }
```
