Les limites de taux contrôlent le nombre de requêtes API que vous pouvez effectuer sur une période donnée. Elles garantissent une utilisation équitable et la stabilité du système au sein de l’ensemble de la plateforme.

***

<div id="how-rate-limits-work">
  ## Fonctionnement des limites de taux
</div>

| Concept | Description |
|:--------|:------------|
| **Fenêtre temporelle** | La plupart des limites se réinitialisent toutes les 15 minutes |
| **Limites par utilisateur** | S’appliquent lorsque vous utilisez OAuth 1.0a ou des jetons utilisateur OAuth 2.0 |
| **Limites par App** | S’appliquent lorsque vous utilisez l’authentification Jeton Bearer (App uniquement) |
| **Spécifiques à l’endpoint** | Chaque endpoint a sa propre limite |

***

<div id="checking-your-limits">
  ## Vérifier vos limites
</div>

Chaque réponse d’API inclut des en-têtes indiquant l’état actuel de votre limitation de débit :

```
x-rate-limit-limit: 900
x-rate-limit-remaining: 847
x-rate-limit-reset: 1705420800
```

| En-tête                  | Description                                                    |
| :----------------------- | :------------------------------------------------------------- |
| `x-rate-limit-limit`     | Nombre maximal de requêtes autorisées dans la fenêtre actuelle |
| `x-rate-limit-remaining` | Requêtes restantes dans la fenêtre actuelle                    |
| `x-rate-limit-reset`     | Horodatage Unix auquel la limite est réinitialisée             |

***

<div id="rate-limit-errors">
  ## Erreurs liées aux limites de débit
</div>

Lorsque vous dépassez une limite de débit, vous recevrez une réponse **429 Too Many Requests** :

```json
{
  "errors": [{
    "code": 88,
    "message": "Rate limit exceeded"
  }]
}
```

<div id="best-practices">
  ## Bonnes pratiques
</div>

<CardGroup cols={2}>
  <Card title="Mettre en cache les réponses" icon="database">
    Stockez localement les réponses de l&#39;API afin de réduire les requêtes répétées pour les mêmes données.
  </Card>

  <Card title="Utiliser un backoff exponentiel" icon="clock-rotate-left">
    En cas de limitation de débit, attendez avant de réessayer. Doublez le temps d’attente à chaque nouvelle tentative.
  </Card>

  <Card title="Vérifier les en-têtes" icon="list-check">
    Surveillez les en-têtes de limitation de débit afin d’anticiper et d’éviter d’atteindre les limites.
  </Card>

  <Card title="Utiliser le streaming" icon="signal-stream">
    Pour les données en temps réel, utilisez un flux filtré au lieu de sonder les points de terminaison de recherche.
  </Card>
</CardGroup>
