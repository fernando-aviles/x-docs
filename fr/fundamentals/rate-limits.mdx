Les limites de débit contrôlent le nombre de requêtes API que vous pouvez effectuer pendant une période donnée. Elles garantissent une utilisation équitable et la stabilité du système à l&#39;échelle de la plateforme.

<div id="how-rate-limits-work">
  ## Fonctionnement des limites de débit
</div>

| Concept | Description |
|:--------|:------------|
| **Fenêtre temporelle** | La plupart des limites se réinitialisent toutes les 15 minutes |
| **Limites par utilisateur** | S’appliquent lors de l’utilisation de jetons utilisateur OAuth 1.0a ou OAuth 2.0 |
| **Limites par application** | S’appliquent lors de l’utilisation de l’authentification Bearer Token (app-only) |
| **Spécifiques à l’endpoint** | Chaque endpoint possède sa propre limite |

***

<div id="checking-your-limits">
  ## Vérifier vos limites
</div>

Chaque réponse de l’API comporte des en-têtes indiquant l’état actuel de vos limites de débit :

```
x-rate-limit-limit: 900
x-rate-limit-remaining: 847
x-rate-limit-reset: 1705420800
```

| En-tête                  | Description                                                    |
| :----------------------- | :------------------------------------------------------------- |
| `x-rate-limit-limit`     | Nombre maximal de requêtes autorisées pour la fenêtre actuelle |
| `x-rate-limit-remaining` | Nombre de requêtes restantes pour la fenêtre actuelle          |
| `x-rate-limit-reset`     | Horodatage Unix auquel la limite est réinitialisée             |

***

<div id="rate-limit-errors">
  ## Erreurs de limitation de débit
</div>

Lorsque vous dépassez une limite de débit, vous recevrez une réponse **429 Too Many Requests** :

```json
{
  "errors": [{
    "code": 88,
    "message": "Rate limit exceeded"
  }]
}
```

<div id="best-practices">
  ## Bonnes pratiques
</div>

<CardGroup cols={2}>
  <Card title="Mettre les réponses en cache" icon="database">

  <Card title="Utiliser un backoff exponentiel" icon="clock-rotate-left">
    En cas de limitation de débit, attendez avant de réessayer. Doublez le temps d&#39;attente à chaque nouvelle tentative.
  </Card>

  <Card title="Vérifier les en-têtes" icon="list-check">
    Surveillez les en-têtes de limitation de débit pour éviter d&#39;atteindre les limites de manière proactive.
  </Card>

  <Card title="Utiliser le streaming" icon="signal-stream">
    Pour les données en temps réel, utilisez un flux filtré plutôt que d&#39;interroger en continu les endpoints de recherche.
  </Card>
</CardGroup>
