Les limites de débit contrôlent le nombre de requêtes API que vous pouvez effectuer sur une période donnée. Elles garantissent une utilisation équitable et la stabilité du système à l’échelle de la plateforme.

***

<div id="how-rate-limits-work">
  ## Fonctionnement des limites de débit
</div>

| Concept | Description |
|:--------|:------------|
| **Fenêtre temporelle** | La plupart des limites sont réinitialisées toutes les 15 minutes |
| **Limites par utilisateur** | S’appliquent lorsque vous utilisez des jetons utilisateur OAuth 1.0a ou OAuth 2.0 |
| **Limites par application** | S’appliquent lorsque vous utilisez l’authentification Bearer Token (en mode application uniquement) |
| **Spécifique à chaque endpoint** | Chaque endpoint a sa propre limite |

***

<div id="checking-your-limits">
  ## Vérifier vos limites
</div>

Chaque réponse d’API inclut des en-têtes indiquant l’état actuel de vos limites de débit :

```
x-rate-limit-limit: 900
x-rate-limit-remaining: 847
x-rate-limit-reset: 1705420800
```

| En-tête                  | Description                                                            |
| :----------------------- | :--------------------------------------------------------------------- |
| `x-rate-limit-limit`     | Nombre maximal de requêtes autorisées dans la fenêtre actuelle         |
| `x-rate-limit-remaining` | Requêtes restantes dans la fenêtre actuelle                            |
| `x-rate-limit-reset`     | Horodatage Unix correspondant au moment où la limite est réinitialisée |

***

<div id="rate-limit-errors">
  ## Erreurs de limitation de débit
</div>

Lorsque vous dépassez une limite de débit, vous recevrez une **réponse 429 Too Many Requests** :

```json
{
  "errors": [{
    "code": 88,
    "message": "Rate limit exceeded"
  }]
}
```

  ## Bonnes pratiques
</div>

<CardGroup cols={2}>

    En cas de limitation de débit, attendez avant de réessayer. Doublez le temps d’attente à chaque nouvelle tentative.
  </Card>

  <Card title="Vérifier les en-têtes" icon="list-check">
    Surveillez les en-têtes de limitation de débit pour éviter d’atteindre les limites de manière proactive.
  </Card>

  <Card title="Utiliser le streaming" icon="signal-stream">
    Pour les données en temps réel, utilisez le flux filtré au lieu d’interroger les points de terminaison de recherche.
  </Card>
</CardGroup>
