Afin de prendre en charge un nombre maximal plus important de campagnes et de permettre la récupération efficace de toutes les entités associées à un compte, l'API Advertiser prend désormais en charge la pagination pour de nombreux endpoints GET. Le mécanisme de pagination est simple à utiliser et très proche de la pagination par curseur de l'API REST, telle que décrite dans [Utilisation de curseurs pour parcourir des collections](https://developer.x.com/en/docs/x-api/v1/pagination).

<div id="getting-started">
  ## Premiers pas
</div>

Pour certaines requêtes GET spécifiques, nous acceptons désormais les paramètres de requête `cursor` et `count`, qui sont tous les deux facultatifs. Si une réponse contient plus de `count` entités, ces endpoints renverront désormais les `count` premières entités ainsi qu’une clé `next_cursor` dans le JSON de la réponse.

`GET https://ads-api.x.com/5/accounts/abc1/campaigns?count=50`

```json
{
  "data": \[...\],
  "next_cursor": "c-3yvu1pzhd3i7",
  "request": {...}
}
```

Pour obtenir la série suivante de réponses, vous ajouteriez `cursor` à vos paramètres de requête :

`GET https://ads-api.x.com/5/accounts/abc1/campaigns?cursor=c-3yvu1pzhd3i7&count=50`

```json
{
  "data": \[...\],
  "next_cursor": "c-3w3zdyg8ywan",
  "request": {...}
}
```


<div id="going-deeper">
  ## Approfondir
</div>

Pour la plupart des endpoints, la valeur maximale de `count` est **1 000**, la valeur minimale est **1** et la valeur par défaut est **200**.

La valeur fournie par `next_cursor` est toujours une chaîne de caractères et doit être considérée comme opaque ; l’implémentation est susceptible d’être modifiée. Si moins de `count` entités sont renvoyées dans la page en cours de l’ensemble de résultats, la valeur de `next_cursor` sera `null`.

**Remarque :** les endpoints d’analytics ne prennent pas en charge ce style de pagination. La pagination sur les endpoints de statistiques est prise en charge en spécifiant des périodes temporelles. Consultez la documentation de ces endpoints individuels pour plus d’informations.
