Le sandbox est un environnement qui vous permet de tester et de développer votre implémentation de l&#39;Ads API.

Les campagnes créées dans le sandbox ne seront pas diffusées aux utilisateurs et des enregistrements de test pour des objets tels que les Funding Instruments peuvent être créés dynamiquement.

Utiliser le sandbox est aussi simple que d&#39;appeler le nom d&#39;hôte approprié ads-api-sandbox.x.com, mais il offre également certaines fonctionnalités uniques qui ne se trouvent que dans le sandbox.

Effectuez une première requête vers [POST accounts](/fr/x-ads-api/campaign-management#post-accounts) pour créer un nouveau compte annonceur. La réponse à cet appel contiendra un account&#95;id qui pourra être utilisé pour les requêtes suivantes. Ces points de terminaison permettent aux clients de créer et de tester plusieurs comptes annonceurs.

* [DELETE accounts/:account&#95;id](/fr/x-ads-api/campaign-management#delete-accounts-account-id) Supprimer un compte dans l&#39;environnement sandbox
* [DELETE accounts/:account&#95;id/features](/fr/x-ads-api/campaign-management#delete-accounts-account-id-features) Supprimer une fonctionnalité de compte d&#39;un compte dans l&#39;environnement sandbox
