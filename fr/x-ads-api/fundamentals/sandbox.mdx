Le sandbox est un environnement qui vous permet de tester et de développer votre implémentation de l’Ads API.

Les campagnes créées dans le sandbox ne seront pas diffusées auprès des utilisateurs et des enregistrements de test pour des objets tels que les Funding Instruments peuvent être créés dynamiquement.

L’utilisation du sandbox est aussi simple que d’appeler le nom d’hôte approprié ads-api-sandbox.x.com, mais il offre également certaines fonctionnalités spécifiques disponibles uniquement dans le sandbox.

Effectuez d’abord une requête vers [POST accounts](/fr/x-ads-api/campaign-management#post-accounts) pour créer un nouveau compte annonceur. La réponse à cet appel contiendra un account&#95;id qui pourra être utilisé pour les requêtes suivantes. Ces points de terminaison permettent aux utilisateurs de créer et de tester plusieurs comptes annonceurs.
