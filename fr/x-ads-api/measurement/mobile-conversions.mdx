<div id="mact-overview">
  ## Présentation de MACT
</div>

La mesure de la [promotion d’app mobile](https://biz.x.com/mobile-app-promotion) sur X permet aux annonceurs de suivre le succès des campagnes publicitaires sur X conçues pour générer des installations ou d’autres conversions au sein de l’application. Un partenaire de mesure mobile X permet à un annonceur de gérer les conversions qu’il souhaite suivre à partir des applications qu’il promeut sur X. Une fois que l’annonceur a défini le type et les fenêtres temporelles des événements qu’il souhaite suivre, le partenaire de mesure mobile enverra tous ces événements à X et recevra immédiatement des données d’attribution indiquant la campagne et la création publicitaire avec lesquelles l’utilisateur a interagi et qui ont conduit à la conversion.

<div id="conversion-events">
  ### Événements de conversion
</div>

Afin de signaler un [événement de conversion](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-event) à X et d’obtenir des données d’attribution, le partenaire doit envoyer l’ID de l’application mobile, le type et l’horodatage de la conversion, ainsi qu’une valeur hachée de l’ID publicitaire/d’appareil. Le fait de fournir ces données permet d’enregistrer l’événement de conversion sur la plateforme de X et de renvoyer également l’attribution lorsque cela est approprié. En outre, l’annonceur peut choisir de fournir des métadonnées supplémentaires sur l’événement de conversion, telles que la valeur d’un achat, l’ID d’un produit ou la méthode d’inscription.

<div id="post-conversion_event">
  #### POST conversion_event
</div>

Enregistrer un événement de conversion de mesure mobile. La réponse indiquera une attribution à X ou à X Audience Platform (TAP).

Ce point de terminaison est lié à [GET conversion&#95;attribution](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-attribution#get-conversion-attribution).

Une attribution X, TAP ou aucune attribution sera revendiquée dans la réponse. Le nœud `twitter_attribution` sera toujours présent et aura une valeur de `null` lorsqu’il n’y a pas d’attribution X (voir l’exemple de réponse ci-dessous). Si une attribution TAP est revendiquée, un nœud `tpn_attribution` sera présent et renseigné en conséquence. Veuillez consulter la [présentation de TAP](https://developer.x.com/en/docs/x-ads-api/measurement/overview/twitter-audience-platform) pour plus d’informations.

Plusieurs paramètres facultatifs sont disponibles pour définir les métadonnées associées à chaque événement de conversion. Ces métadonnées n’ont aucun effet sur les calculs d’attribution.

<div id="resource-url">
  ##### URL de la ressource
</div>

`https://ads-api.x.com/12/conversion_event`

<div id="parameters">
  ##### Paramètres
</div>

| Nom | Description |
| :--- | :--- |
| app&#95;id  <br />*required* | L’identifiant unique auprès de la boutique d’applications correspondante.<br /><br />Type : int, chaîne de caractères<br /><br />Exemple : `333903271`, `com.vine.android` |
| conversion&#95;time  <br />*required* | L’horodatage de l’événement de conversion au format ISO-8601, avec les millisecondes ajoutées.<br /><br />Type : chaîne de caractères<br /><br />Exemple : `2014-05-22T02:38:28.103Z` |
| conversion&#95;type  <br />*required* | Le type d’événement de conversion.<br /><br />Type : enum<br /><br />Valeurs possibles : `PURCHASE`, `SIGN_UP`, `INSTALL`, `RE_ENGAGE`, `UPDATE`, `TUTORIAL_COMPLETE`, `RESERVATION`, `ADD_TO_CART`, `ADD_TO_WISHLIST`, `LOGIN`, `CHECKOUT_INITIATED`, `SEARCH`, `LEVEL_ACHIEVED`, `ACHIEVEMENT_UNLOCKED`, `CONTENT_VIEW`, `SHARE`, `INVITE`, `ADDED_PAYMENT_INFO`, `SPENT_CREDITS`, `RATED` |
| hashed&#95;device&#95;id  <br />*required* | L’IDFA ou l’AdID haché avec HMAC&#95;SHA-256.<br /><br />Type : chaîne de caractères<br /><br />Exemple : `ABCD1234XYZ` |
| os&#95;type  <br />*required* | Le type de système d’exploitation pour l’application.<br /><br />Type : enum<br /><br />Valeurs possibles : `IOS`, `ANDROID` |
| click&#95;window  <br />*optional* | La fenêtre de clic pour cet événement, en jours.<br /><br />Type : int<br /><br />**Remarque** : `click_window` doit être supérieur ou égal à view&#95;through&#95;window<br /><br />Valeur par défaut : `14`  <br />Valeurs possibles : `1`, `7`, `14`, `30` |
| device&#95;ip&#95;address  <br />*optional* | L’adresse IPv4 ou IPv6 de l’appareil au moment où l’événement de conversion s’est produit.<br /><br />Type : chaîne de caractères<br /><br />Exemple : `192.133.78.1` |
| level  <br />*optional* | Un niveau associé à cet événement.<br /><br />Type : int<br /><br />Exemple : `2` |
| non&#95;twitter&#95;engagement&#95;time  <br />*optional* | L’heure de la dernière interaction non-Twitter avant la conversion.<br /><br />Type : chaîne de caractères<br /><br />Exemple : `2014-05-22T02:38:28.103Z` |
| non&#95;twitter&#95;engagement&#95;type  <br />*optional* | Le type d’interaction non-Twitter avant l’événement de conversion.<br /><br />Type : enum<br /><br />Valeurs possibles : `CLICK`, `VIEW` |
| number&#95;items  <br />*optional* | Nombre d’éléments associés à cet événement.<br /><br />Type : int<br /><br />Exemple : `2` |
| price&#95;currency  <br />*optional* | Doit être un code ISO 4217 indiquant la devise associée à cet événement.<br /><br />Type : chaîne de caractères<br /><br />Exemples : `EUR`,`USD`,`JPY` |
| price&#95;micro  <br />*optional* | Un montant de prix associé à cet événement, en micro-unités.<br /><br />Type : int<br /><br />Exemple : `123450000` |
| user&#95;payment&#95;info  <br />*optional* | Une valeur booléenne indiquant si les informations de paiement de l’utilisateur sont stockées dans l’application associée à cet événement.<br /><br />Type : bool<br /><br />Valeurs possibles : `true` ou `false` |
| view&#95;through&#95;window  <br />*optional* | La fenêtre de vue indirecte (view-through) pour cet événement, en jours.<br /><br />**Remarque** :<br /><br />`click_window` doit être supérieur ou égal à view&#95;through&#95;window.<br /><br />Type : int<br /><br />Valeur par défaut : `1`  <br />Valeurs possibles : `0`, `1`, `7`, `14`, `30` |
