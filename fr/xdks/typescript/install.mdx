Commencez à utiliser le SDK TypeScript pour X API dans votre projet.

<div id="install">
  ## Installation
</div>

<CodeGroup>
  ```bash npm theme={null}
  npm install @xdevplatform/xdk
  ```

  ```bash yarn theme={null}
  yarn add @xdevplatform/xdk
  ```

  ```bash pnpm theme={null}
  pnpm add @xdevplatform/xdk
  ```
</CodeGroup>

<div id="typescript-support">
  ## Prise en charge de TypeScript
</div>

Le SDK est écrit en TypeScript et inclut des définitions de types complètes. Aucun package de type supplémentaire n’est nécessaire.

<div id="requirements">
  ## Prérequis
</div>

* Node.js 16+
* TypeScript 4.5+ (si vous utilisez TypeScript)
