Paginator X API riche en fonctionnalités

Cette classe fournit une prise en charge complète de la pagination pour X API, notamment :

* Itération automatique avec les boucles `for await...of`
* Contrôle manuel des pages avec `fetchNext()` et `fetchPrevious()`
* Accès aux métadonnées pour les jetons de pagination et les compteurs
* Gestion des erreurs et détection des limites de débit
* Prise en charge de la pagination dans les deux sens (avant et arrière)

**`Exemple`**

```typescript
// Automatic iteration
const followers = await client.users.getFollowers('783214');
for await (const follower of followers) {
  console.log(follower.username);
}

// Manual control
const followers = await client.users.getFollowers('783214');
await followers.fetchNext();
console.log(followers.items.length); // Number of followers
console.log(followers.meta.nextToken); // Jeton de page suivante

// Check status
if (!followers.done) {
  await followers.fetchNext();
}
```

<div id="fetchnext">
  ### fetchNext
</div>

▸ **fetchNext**(): `Promise`&lt;`void`&gt;

Récupère la page suivante et ajoute les éléments à l’instance actuelle

Cette méthode récupère la page suivante de données et ajoute les éléments à
l’instance de paginateur actuelle. Elle met à jour l’état de la pagination et les métadonnées.

#### Renvoie

`Promise`&lt;`void`&gt;

**`Exemple`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // Récupérer la première page
console.log(followers.items.length); // Nombre d'abonnés

if (!followers.done) {
  await followers.fetchNext(); // Récupérer la deuxième page
  console.log(followers.items.length); // Total d'abonnés sur l'ensemble des pages
}
```

**`Throws`**

Lorsque la requête à l&#39;API échoue

<div id="next">
  ### next
</div>

▸ **next**(): `Promise`&lt;[`Paginator`](/fr/xdks/typescript/reference/classes/Paginator)&lt;`T`&gt;&gt;

Récupère la page suivante sous la forme d&#39;une nouvelle instance

Cette méthode crée une nouvelle instance de `Paginator` qui commence à la page suivante, sans affecter l&#39;état du `Paginator` actuel.

#### Renvoie

`Promise`&lt;[`Paginator`](/fr/xdks/typescript/reference/classes/Paginator)&lt;`T`&gt;&gt;

Nouvelle instance de `Paginator` pour la page suivante

**`Exemple`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // Récupérer la première page

if (!followers.done) {
  const nextPage = await followers.next(); // Obtenir la page suivante en tant que nouvelle instance
  console.log(followers.items.length); // Toujours la première page
  console.log(nextPage.items.length); // Deuxième page
}
```
