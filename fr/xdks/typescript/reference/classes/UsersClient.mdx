Client pour les opérations relatives aux utilisateurs

Ce client fournit des méthodes pour interagir avec les endpoints relatifs aux utilisateurs
de la X API. Il gère l’authentification, le formatage des requêtes et l’analyse des réponses
pour toutes les opérations liées aux utilisateurs.
