Client pour les opérations sur les utilisateurs

Ce client fournit des méthodes pour interagir avec les endpoints users
de la X API. Il gère l’authentification, le formatage des requêtes et l’analyse des réponses
pour l’ensemble des opérations liées aux utilisateurs.
