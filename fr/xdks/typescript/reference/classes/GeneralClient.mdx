Client pour les opérations générales

Ce client fournit des méthodes pour interagir avec les endpoints généraux
de X API. Il gère l’authentification, le formatage des requêtes et l’analyse des réponses
pour toutes les opérations générales associées.

Renvoie la spécification OpenAPI complète au format JSON. (Voir https://github.com/OAI/OpenAPI-Specification/blob/master/README.md)
