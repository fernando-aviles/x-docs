Client pour les opérations sur les listes

Ce client fournit des méthodes pour interagir avec les endpoints de listes
de X API. Il gère l&#39;authentification, le formatage des requêtes et l&#39;analyse des réponses
pour toutes les opérations relatives aux listes.
