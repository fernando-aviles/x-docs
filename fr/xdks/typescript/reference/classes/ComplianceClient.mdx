Client pour les opérations de conformité

Ce client fournit des méthodes pour interagir avec les endpoints de conformité
de X API. Il gère l&#39;authentification, le formatage des requêtes et l&#39;analyse des
réponses pour toutes les opérations liées à la conformité.
