Client pour les opérations liées aux actualités

Ce Client fournit des méthodes pour interagir avec les endpoints de la X API dédiés aux actualités. Il gère l&#39;authentification, le formatage des requêtes et l&#39;analyse des réponses pour toutes les opérations liées aux actualités.
