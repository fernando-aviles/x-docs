Client pour les opérations liées à l’activité de compte

Ce client fournit des méthodes pour interagir avec les endpoints d’activité de compte
de la X API. Il gère l’authentification, le formatage des requêtes et l’analyse des Réponses
pour toutes les opérations liées à l’activité de compte.
