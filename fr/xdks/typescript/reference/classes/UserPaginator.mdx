<div id="fetchnext">
  ### fetchNext
</div>

▸ **fetchNext**(): `Promise`&lt;`void`&gt;

Récupère la page suivante et ajoute les éléments à l’instance actuelle

Cette méthode récupère la page suivante de données et ajoute les éléments à
l’instance actuelle du paginateur. Elle met à jour l’état de la pagination et les métadonnées.

#### Renvoie

`Promise`&lt;`void`&gt;

**`Exemple`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // Récupère la première page
console.log(followers.items.length); // Nombre d'abonnés

if (!followers.done) {
  await followers.fetchNext(); // Récupère la deuxième page
  console.log(followers.items.length); // Total des abonnés sur toutes les pages
}
```

**`Throws`**

Lorsque la requête d’API échoue

<div id="next">
  ### next
</div>

▸ **next**(): `Promise`&lt;[`Paginator`](/fr/xdks/typescript/reference/classes/Paginator)&lt;`any`&gt;&gt;

Récupérer la page suivante sous la forme d&#39;une nouvelle instance

Cette méthode crée une nouvelle instance de Paginator qui démarre à partir de la page suivante,
sans affecter l&#39;état du Paginator actuel.

#### Renvoie

`Promise`&lt;[`Paginator`](/fr/xdks/typescript/reference/classes/Paginator)&lt;`any`&gt;&gt;

Nouvelle instance de `Paginator` pour la page suivante

**`Exemple`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // Récupère la première page

if (!followers.done) {
  const nextPage = await followers.next(); // Obtient la page suivante en tant que nouvelle instance
  console.log(followers.items.length); // Toujours la première page
  console.log(nextPage.items.length); // Deuxième page
}
```
