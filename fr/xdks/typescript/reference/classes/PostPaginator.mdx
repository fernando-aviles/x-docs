<div id="fetchnext">
  ### fetchNext
</div>

▸ **fetchNext**(): `Promise`&lt;`void`&gt;

Récupère la page suivante et ajoute les éléments à l&#39;instance actuelle

Cette méthode récupère la page suivante de données et ajoute les éléments à
l&#39;instance actuelle du paginateur. Elle met à jour l&#39;état de la pagination et les métadonnées.

#### Renvoie

`Promise`&lt;`void`&gt;

**`Exemple`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // Récupérer la première page
console.log(followers.items.length); // Nombre d'abonnés

if (!followers.done) {
  await followers.fetchNext(); // Récupérer la deuxième page
  console.log(followers.items.length); // Total d'abonnés sur l'ensemble des pages
}
```

**`Throws`**

Lorsque la requête à l’API échoue

#### Hérité de

[Paginator](/fr/xdks/typescript/reference/classes/Paginator).[fetchNext](/fr/xdks/typescript/reference/classes/Paginator#fetchnext)

<div id="next">
  ### next
</div>

▸ **next**(): `Promise`&lt;[`Paginator`](/fr/xdks/typescript/reference/classes/Paginator)&lt;`any`&gt;&gt;

Récupère la page suivante sous la forme d&#39;une nouvelle instance

Cette méthode crée une nouvelle instance de paginator qui démarre à la page suivante,
sans modifier l&#39;état du paginator actuel.

#### Renvoie

`Promise`&lt;[`Paginator`](/fr/xdks/typescript/reference/classes/Paginator)&lt;`any`&gt;&gt;

Nouvelle instance de `Paginator` pour la page suivante

**`Exemple`**

```typescript
const followers = await client.users.getFollowers('783214');
await followers.fetchNext(); // Récupérer la première page

if (!followers.done) {
  const nextPage = await followers.next(); // Obtenir la page suivante en tant que nouvelle instance
  console.log(followers.items.length); // Toujours la première page
  console.log(nextPage.items.length); // Deuxième page
}
```
