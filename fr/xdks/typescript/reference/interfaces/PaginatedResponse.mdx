Interface de réponse paginée

Représente la structure d’une réponse paginée renvoyée par la X API.

<div id="type-parameters">
  ## Paramètres de type
</div>

| Nom | Description |
| :------ | :------ |
| `T` | Le type des éléments de la réponse |

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="data" type="T[]" required>
Tableau des éléments de la page actuelle

</ResponseField>

<ResponseField name="meta" type="Object">
Métadonnées de pagination

<Expandable title="propriétés">
<ResponseField name="Name" type="Type | Description" required>
</ResponseField>

<ResponseField name="resultCount" type="number | Nombre de résultats sur la page actuelle">
</ResponseField>

<ResponseField name="nextToken" type="string | Jeton pour récupérer la page suivante">
</ResponseField>

<ResponseField name="previousToken" type="string | Jeton pour récupérer la page précédente">
</ResponseField>
</Expandable>
</ResponseField>

<ResponseField name="includes" type="Record&lt;string, any&gt;">
Objets supplémentaires inclus (utilisateurs, Tweets, etc.)

</ResponseField>

<ResponseField name="errors" type="any[]">
Toutes les erreurs présentes dans la réponse

</ResponseField>
