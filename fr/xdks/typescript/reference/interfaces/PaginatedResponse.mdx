Interface de réponse paginée

Représente la structure d’une réponse paginée provenant du X API.

<div id="type-parameters">
  ## Paramètres de type
</div>

| Nom | Description |
| :------ | :------ |
| `T` | Type des éléments de la réponse |

<div id="properties">
  ## Propriétés
</div>

<ResponseField name="data" type="T[]" required>
Tableau d’éléments de la page actuelle

</ResponseField>

<ResponseField name="meta" type="Object">
Métadonnées relatives à la pagination

<Expandable title="Propriétés">
<ResponseField name="Name" type="Type | Description" required>
</ResponseField>

<ResponseField name="resultCount" type="number | Number of results in the current page">
</ResponseField>

<ResponseField name="nextToken" type="string | Token for fetching the next page">
</ResponseField>

<ResponseField name="previousToken" type="string | Token for fetching the previous page">
</ResponseField>
</Expandable>
</ResponseField>

<ResponseField name="includes" type="Record&lt;string, any&gt;">
Objets supplémentaires inclus (utilisateurs, Tweets, etc.)

</ResponseField>

<ResponseField name="errors" type="any[]">
Ensemble des erreurs présentes dans la réponse

</ResponseField>
