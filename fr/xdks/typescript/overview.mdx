Un SDK TypeScript complet pour l’X API (anciennement Twitter API) avec des fonctionnalités avancées, notamment la pagination intelligente, plusieurs méthodes d’authentification, le streaming en temps réel et une sécurité de typage complète.

<div id="key-features">
  ## Fonctionnalités clés
</div>

* **🔐 Authentification** : authentification en contexte utilisateur (OAuth1.0a, OAuth2.0) et en mode application seule (Bearer Token)
* **🔄 Pagination** : pagination automatique avec prise en charge de l’itération asynchrone
* **📡 Streaming** : streaming piloté par les événements avec reconnexion automatique
* **📚 Sécurité de typage** : définitions TypeScript complètes pour tous les endpoints et paramètres
* **🎯 Prise en charge complète de X API** : utilisateurs, publications, listes, signets, communautés et plus encore

<div id="quick-start">
  ## Démarrage rapide
</div>

<CodeGroup dropdown>
  ```typescript quickstart.ts theme={null}
  import { 
      Client, 
      type ClientConfig,
      type Users
  } from '@xdevplatform/xdk';

  const config: ClientConfig = { bearerToken: 'your-bearer-token' };

  const client: Client = new Client(config);

  async function main(): Promise<void> {
    const userResponse: Users.GetByUsernameResponse = await client.users.getByUsername('XDevelopers');
    const username: string = userResponse.data?.username!;
    console.log(username);
  }

  main();
  ```

  ```javascript quickstart.js theme={null}
  import { Client } from '@xdevplatform/xdk';

  const client = new Client({ bearerToken: 'your-bearer-token' });

  const userResponse = await client.users.getByUsername('XDevelopers');
  const username = userResponse.data.username;
  console.log(username);
  ```
</CodeGroup>
