Le XDK Python (X Developer Kit) est notre bibliothèque cliente officielle pour interagir avec la X API v2 à l’aide de Python. Il permet aux développeurs de se lancer rapidement avec notre API et de créer des applications. Il est généré à partir de notre [spécification OpenAPI officielle](https://api.x.com/2/openapi.json). Il masque les détails HTTP de bas niveau tout en offrant un contrôle fin lorsque cela est nécessaire.

<div id="key-features">
  ## Fonctionnalités principales
</div>

- 🔐 **Prise en charge d’OAuth** : prise en charge complète de l’authentification Bearer Token (app-only), d’OAuth 2.0 avec PKCE (contexte utilisateur) et d’OAuth 1.0.
- 🔄 **Pagination** : pagination automatique des résultats volumineux. Le XDK gère la pagination sans que vous ayez à effectuer plusieurs appels à l’API en utilisant le `next_token`.
- 📡 **Streaming** : prise en charge du streaming de données en temps réel pour les endpoints comme `filtered stream` qui nécessitent une connexion HTTP persistante.
- 🎯 **Couverture complète** : prise en charge de tous les endpoints X API v2, notamment la recherche, les timelines, `filtered-stream` et plus encore.

**Compatibilité des versions** : Python 3.8+. Testé sur CPython et PyPy.
