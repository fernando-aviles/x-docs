Le XDK Python (X Developer Kit) est notre bibliothèque cliente officielle pour interagir avec la X API v2 en Python. Il permet aux développeurs de démarrer rapidement avec notre API et de développer des applications qui l’utilisent. Il est généré à partir de notre [spécification OpenAPI](https://api.x.com/2/openapi.json) officielle. Il masque les détails HTTP de bas niveau tout en offrant un contrôle fin lorsque c’est nécessaire.

<div id="key-features">
  ## Fonctionnalités clés
</div>

- 🔐 **Prise en charge d’OAuth** : prise en charge complète de l’authentification par Jeton Bearer (app-only), OAuth 2.0 avec PKCE (contexte utilisateur) et OAuth 1.0.
- 🔄 **Pagination** : gère automatiquement la pagination pour de grands volumes de résultats. Le XDK prend en charge la pagination sans que vous ayez à effectuer plusieurs appels d’API avec le `next_token`.
- 📡 **Streaming** : prend en charge le streaming de données en temps réel pour les endpoints comme le filtered stream qui nécessitent une connexion HTTP persistante.
- 🎯 **Couverture complète** : prend en charge tous les endpoints X API v2, notamment la recherche, les timelines, le filtered stream et bien plus encore.
**Compatibilité des versions** : Python 3.8+. Testé sur CPython et PyPy.
