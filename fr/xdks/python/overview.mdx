Le XDK Python (X Developer Kit) est notre bibliothèque cliente officielle pour interagir avec la X API v2 à l’aide de Python. Il permet aux développeurs de prendre rapidement en main notre API et de développer des applications avec celle-ci. Il est généré à partir de notre [spécification OpenAPI officielle](https://api.x.com/2/openapi.json). Il masque les détails HTTP de bas niveau tout en offrant un contrôle fin lorsque c’est nécessaire.

<div id="key-features">
  ## Fonctionnalités clés
</div>

- 🔐 **Prise en charge d’OAuth** : prise en charge complète de l’authentification par Bearer Token (app-only), OAuth 2.0 avec PKCE (contexte utilisateur) et OAuth 1.0.
- 🔄 **Pagination** : parcourt automatiquement de grands volumes de résultats. Le XDK gère la pagination sans que vous ayez à effectuer plusieurs appels à l’API en utilisant le `next_token`.
- 📡 **Streaming** : prend en charge le streaming de données en temps réel pour les endpoints tels que filtered stream qui nécessitent une connexion HTTP persistante.
- 🎯 **Couverture complète** : prend en charge tous les endpoints X API v2, y compris search, timelines, filtered-stream et plus encore.
**Compatibilité des versions** : Python 3.8+. Testé sur CPython et PyPy.
