Cet exemple illustre comment rechercher rapidement des Publications à l&#39;aide de xdk avec l&#39;authentification Bearer Token.

<div id="step-1-install-the-sdk">
  ## Étape 1 : Installez le SDK
</div>

```bash
pip install xdk
```

<div id="step-2-get-your-bearer-token">
  ## Étape 2 : Obtenir votre Bearer Token
</div>

1. Connectez-vous à la [X Developer Console](https://developer.x.com/en/portal/dashboard).
2. Créez une application ou sélectionnez-en une existante.
3. Sous « Keys and Tokens », générez un Bearer Token (authentification app-only).

<div id="step-3-write-and-run-your-first-script">
  ## Étape 3 : écrire et exécuter votre premier script
</div>

Créez un fichier `quickstart.py` :

```python
# Importer le client
from xdk import Client
# Remplacer par votre Bearer Token réel
client = Client(bearer_token="YOUR_BEARER_TOKEN_HERE")
# Récupérer les Publications récentes mentionnant "api"
# search_recent retourne un Iterator, donc itérer dessus
for page in client.posts.search_recent(query="api", max_results=10):
    if page.data and len(page.data) > 0:
        # Accéder à la première Publication - les modèles Pydantic prennent en charge l'accès par attribut et par dictionnaire
        first_post = page.data[0]
        post_text = first_post.text if hasattr(first_post, 'text') else first_post.get('text', '')
        print(f"Latest Post: {post_text}")
        break
    else:
        print("Aucune Publication trouvée.")
        break
```

Exécutez-la :

```bash
python quickstart.py
```

**Résultat attendu**:

```
Latest Post: Exciting updates on XDK Python SDK!
```

**Dépannage** : Si vous obtenez une erreur 401, revérifiez votre Bearer Token. En cas de limitation de débit (429), attendez avant de réessayer.
