Ce module fournit un client pour interagir avec les endpoints de streaming de la X API.
Les opérations de streaming en temps réel renvoient des générateurs qui produisent les données au fur et à mesure de leur arrivée.
Les connexions de streaming sont gérées automatiquement avec une stratégie de nouvelle tentative avec backoff exponentiel pour une gestion robuste.
