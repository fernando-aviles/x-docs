<div id="get_analytics">
  ### `get_analytics`
</div>

Obtenir les statistiques des médias
Récupère les données analytiques pour les médias.

<div id="parameters">
  #### Paramètres
</div>

<ParamField path="path.media_keys" type="List">
Une liste de Media Keys séparées par des virgules. Jusqu’à 100 sont autorisées dans une seule requête.
</ParamField>

<ParamField path="path.end_time" type="str">
YYYY-MM-DDTHH:mm:ssZ. L’horodatage UTC représentant la fin de l’intervalle de temps.
</ParamField>

<ParamField path="path.start_time" type="str">
YYYY-MM-DDTHH:mm:ssZ. L’horodatage UTC représentant le début de l’intervalle de temps.
</ParamField>

<ParamField path="path.granularity" type="str">
La granularité des résultats de comptage de la recherche.
</ParamField>

<ParamField path="path.media_analytics_fields" type="List or None" default="None">
Une liste de champs MediaAnalytics séparés par des virgules à afficher.
</ParamField>

<div id="returns">
  #### Valeur de retour
</div>

`GetAnalyticsResponse` - Données de réponse
