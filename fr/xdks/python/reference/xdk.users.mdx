<div id="block_dms">
  ### `block_dms`
</div>

Bloquer les messages privés
Bloque, pour l’utilisateur authentifié, les messages privés envoyés à ou reçus d’un utilisateur spécifique identifié par son id.

<div id="parameters">
  #### Paramètres
</div>

<ParamField path="path.id" type="Any">
  L’identifiant de l’utilisateur cible dont l’utilisateur authentifié demande le blocage des DM.
</ParamField>

#### Renvoie

`BlockDmsResponse` - Données de réponse
