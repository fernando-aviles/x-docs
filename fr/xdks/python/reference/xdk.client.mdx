Ce module fournit la classe principale `Client` pour interagir avec l'API X.
Il coordonne tous les sous-clients et gère l'authentification, la gestion des sessions
et les flux OAuth2 PKCE. L'ensemble des fonctionnalités est généré à partir de la spécification OpenAPI.

<div id="parameters">
  #### Paramètres
</div>

<ParamField path="path.base_url" type="str" default="'https://api.x.com'">
L’URL de base pour X API (par défaut : [https://api.x.com](https://api.x.com)).
</ParamField>

<ParamField path="path.bearer_token" type="str or None" default="None">
Le Bearer Token pour X API (authentification en mode application uniquement).
</ParamField>

<ParamField path="path.access_token" type="str or None" default="None">
Le jeton d’accès OAuth2 pour le contexte utilisateur (peut être utilisé directement comme Bearer Token).
</ParamField>

<ParamField path="path.client_id" type="str or None" default="None">
L’identifiant client pour X API (obligatoire pour le flux OAuth2 PKCE).
</ParamField>

<ParamField path="path.client_secret" type="str or None" default="None">
Le secret client pour X API.
</ParamField>

<ParamField path="path.redirect_uri" type="str or None" default="None">
L’URI de redirection pour l’autorisation OAuth2.
</ParamField>

<ParamField path="path.token" type="Dict[str, Any] or None" default="None">
Un dictionnaire de jetons OAuth2 existant (s’il est disponible). S’il est fourni, `access_token` sera extrait.
</ParamField>

<ParamField path="path.scope" type="str or List[str] or None" default="None">
Une chaîne de caractères avec des valeurs séparées par des espaces ou une liste de chaînes de caractères représentant les scopes d’autorisation OAuth2.
</ParamField>

<ParamField path="path.authorization_base_url" type="str" default="'https://x.com/i'">
L’URL de base pour l’autorisation OAuth2 (par défaut : [https://x.com/i](https://x.com/i)).
</ParamField>

<ParamField path="path.auth" type="OAuth1">
Instance OAuth1 pour l’authentification OAuth1.0a.
</ParamField>
