<div id="create_replay_job">
  ### `create_replay_job`
</div>

Créer une tâche de relecture
Crée une tâche de relecture pour récupérer les activités jusqu’aux cinq derniers jours pour tous les abonnements associés à un webhook donné.

<div id="parameters">
  #### Paramètres
</div>

<ParamField path="path.webhook_id" type="Any">
  L&#39;identifiant unique de la configuration du webhook.
</ParamField>

<ParamField path="path.from_date" type="str">
  L’horodatage UTC le plus ancien (point de départ, inclus) à partir duquel les événements seront fournis, au format yyyymmddhhmm.
</ParamField>

<ParamField path="path.to_date" type="str">
  L’horodatage UTC le plus récent (point de fin, exclu) jusqu’auquel les événements seront fournis, au format yyyymmddhhmm.
</ParamField>

<div id="returns">
  #### Valeur de retour
</div>

`CreateReplayJobResponse` - Données de réponse
