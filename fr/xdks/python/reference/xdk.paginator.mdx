Outils de pagination basés sur des curseurs pour le SDK X API.

Ce module fournit la classe Cursor pour une prise en charge fluide de la pagination sur
tous les clients de l'API. Cursor permet d'itérer facilement sur des résultats paginés
en utilisant les méthodes .pages() et .items() avec une sécurité de typage appropriée.

<div id="xdkpaginatorcursor">
  ### `xdk.paginator.cursor`
</div>

Crée un curseur avec inférence de type et validation adéquates.
Cette fonction de fabrique aide à l’inférence de type afin que vous obteniez les bons
indications de type pour le type de Réponse, et valide que la méthode
prend en charge la pagination tant lors de l’analyse statique qu’à l’exécution.
