Utilitaires de pagination avec curseur pour le SDK X API.

Ce module fournit une classe Cursor pour une prise en charge élégante de la pagination sur
tous les clients de l’API. Cursor permet d’itérer facilement sur des résultats paginés
à l’aide des méthodes .pages() et .items(), avec un typage sûr.

<div id="xdkpaginatorcursor">
  ### `xdk.paginator.cursor`
</div>

Crée un curseur avec une inférence de types et une validation correctes.
Cette fonction de fabrique facilite l’inférence de types, afin que vous disposiez de bonnes
indications de type pour le type de réponse, et vérifie que la méthode
prend en charge la pagination aussi bien lors de l’analyse statique qu’à l’exécution.
