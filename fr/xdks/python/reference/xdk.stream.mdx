<div id="labels_compliance">
  ### `labels_compliance`
</div>

Diffuse les libellés de Publications (streaming)
Diffuse tous les événements d’attribution de libellés appliqués aux Publications.
Il s’agit d’un endpoint de streaming qui renvoie des données en temps réel dès qu’elles sont disponibles.
Chaque élément renvoyé représente un seul point de données provenant du flux.
La connexion est automatiquement gérée avec une logique de nouvelle tentative avec attente exponentielle.
Si le flux est déconnecté, le SDK se reconnectera automatiquement sans intervention du Client.

<div id="parameters">
  #### Paramètres
</div>

<ParamField path="path.backfill_minutes" type="int or None" default="None">
  Le nombre de minutes de backfill demandé.
</ParamField>

<ParamField path="path.start_time" type="str or None" default="None">
  YYYY-MM-DDTHH:mm:ssZ. L’horodatage UTC le plus ancien à partir duquel les labels de Publication seront fournis.
</ParamField>

<ParamField path="path.end_time" type="str or None" default="None">
  YYYY-MM-DDTHH:mm:ssZ. L’horodatage UTC le plus récent à partir duquel les labels de Publication seront fournis.
</ParamField>

<ParamField path="path.stream_config" type="StreamConfig">
  StreamConfig facultatif pour personnaliser la stratégie de nouvelle tentative, les délais d’expiration et les callbacks.
</ParamField>
