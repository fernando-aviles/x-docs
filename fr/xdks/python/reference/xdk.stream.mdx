<div id="labels_compliance">
  ### `labels_compliance`
</div>

Diffuse en continu les libellés de Publications (streaming).
Diffuse tous les événements d’étiquetage appliqués aux Publications.
Il s’agit d’un endpoint de streaming qui fournit les données en temps réel dès qu’elles sont disponibles.
Chaque élément émis représente une donnée unique provenant du flux.
La connexion est gérée automatiquement avec une logique de nouvelle tentative utilisant un backoff exponentiel.
Si le flux est interrompu, le SDK se reconnectera automatiquement sans intervention du client.

<div id="parameters">
  #### Paramètres
</div>

<ParamField path="path.backfill_minutes" type="int or None" default="None">
  Le nombre de minutes de rattrapage demandé.
</ParamField>

<ParamField path="path.start_time" type="str or None" default="None">
  YYYY-MM-DDTHH:mm:ssZ. L’horodatage UTC le plus ancien à partir duquel des libellés de Publication seront fournis.
</ParamField>

<ParamField path="path.end_time" type="str or None" default="None">
  YYYY-MM-DDTHH:mm:ssZ. L’horodatage UTC le plus récent à partir duquel des libellés de Publication seront fournis.
</ParamField>

<ParamField path="path.stream_config" type="StreamConfig">
  StreamConfig facultatif pour personnaliser le comportement de réessai, les délais d’expiration et les callbacks.
</ParamField>
