Ce module fournit un client pour interagir avec les endpoints d’activité de X API.
Les opérations de streaming en temps réel renvoient des générateurs qui émettent les données au fur et à mesure de leur arrivée.
Les connexions de streaming sont automatiquement gérées avec une stratégie de nouvelle tentative avec backoff exponentiel pour une gestion robuste.

<div id="stream">
  ### `stream`
</div>

Flux d’activité (streaming)
Flux d’activités X
Il s’agit d’un endpoint de streaming qui fournit des données en temps réel dès qu’elles sont disponibles.
Chaque élément émis représente un seul point de données provenant du flux.
La connexion est gérée automatiquement avec une logique de nouvelle tentative avec backoff exponentiel.
Si la connexion au flux est interrompue, le SDK se reconnectera automatiquement sans intervention du client.
