Ce module fournit un client pour interagir avec les endpoints d’activité de X API.
Les opérations de streaming en temps réel renvoient des générateurs qui produisent les données à mesure de leur arrivée.
Les connexions de streaming sont automatiquement gérées grâce à une logique de nouvelle tentative avec backoff exponentiel pour une meilleure robustesse.

<div id="stream">
  ### `stream`
</div>

Flux d’activité (Streaming)
Flux d’activités sur X
Il s’agit d’un endpoint de streaming qui fournit des données en temps réel dès qu’elles sont disponibles.
Chaque élément émis représente un point de données individuel provenant du flux.
La connexion est automatiquement gérée avec une stratégie de reconnexion à temporisation exponentielle.
Si le flux est interrompu, le SDK se reconnectera automatiquement sans intervention du Client.
