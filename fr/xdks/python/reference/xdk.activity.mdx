<div id="stream">
  ### `stream`
</div>

Flux d’activités (streaming)
Flux d’activités X
Il s’agit d’un endpoint de streaming qui fournit les données en temps réel au fur et à mesure de leur disponibilité.
Chaque élément émis représente un point de données unique provenant du flux.
La connexion est gérée automatiquement avec une logique de reconnexion utilisant un backoff exponentiel.
Si le flux est interrompu, le SDK se reconnectera automatiquement sans intervention du client.

<div id="parameters">
  #### Paramètres
</div>

<ParamField path="path.backfill_minutes" type="int or None" default="None">
  Le nombre de minutes de rattrapage demandé.
</ParamField>

<ParamField path="path.start_time" type="str or None" default="None">
  YYYY-MM-DDTHH:mm:ssZ. L’horodatage UTC le plus ancien à partir duquel les libellés des Publications seront fournis.
</ParamField>

<ParamField path="path.end_time" type="str or None" default="None">
  YYYY-MM-DDTHH:mm:ssZ. L’horodatage UTC le plus récent à partir duquel les libellés des Publications seront fournis.
</ParamField>

<ParamField path="path.stream_config" type="StreamConfig">
  StreamConfig facultatif pour personnaliser le comportement de réessai, les délais d’expiration et les fonctions de rappel.
</ParamField>
