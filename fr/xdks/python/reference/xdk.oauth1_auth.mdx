Ce module fournit des fonctionnalités d’authentification OAuth 1.0a pour des flux
d’autorisation sécurisés. Il inclut la génération de jetons de requête, la génération d’URL
d’autorisation, l’échange de jetons d’accès et la génération de signatures OAuth1.
