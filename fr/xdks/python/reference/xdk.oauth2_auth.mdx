Ce module fournit des fonctionnalités d’authentification OAuth 2.0 PKCE (Proof Key for Code Exchange) pour des flux d’autorisation sécurisés. Il inclut la génération du code verifier, la gestion des jetons et la prise en charge du rafraîchissement automatique des jetons.

<div id="class-xdkoauth2_authoauth2pkceauth">
  ### `class xdk.oauth2_auth.OAuth2PKCEAuth`
</div>
