Le SDK XDK pour Python est disponible directement depuis le dépôt GitHub et peut être installé via `pip`.

<div id="prerequisites">
  ## Prérequis
</div>

- Python 3.8 ou version ultérieure.
- `pip` et `venv` pour les environnements virtuels (recommandé).

<div id="quick-install">
  ## Installation rapide
</div>

Installez XDK depuis le sous-répertoire GitHub :

```bash
pip install xdk
```

Cette commande récupère la dernière version générée à partir de la branche `main`.


<div id="development-install">
  ## Installation pour le développement
</div>

Pour le développement ou pour contribuer :

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/xdevplatform/xdk.git
   cd xdk/python
   ```
2. Installez les dépendances en mode éditable :
   ```bash
   pip install -e .
   ```
   Cette commande installe le SDK et ses dépendances d’exécution.
3. (Facultatif) Installez les dépendances de développement pour les tests et le linting :
   ```bash
   pip install -e .[dev]
   ```

<div id="verification">
  ## Vérification
</div>

Testez l’installation :

```python
import xdk
print(xdk.__version__)  # Doit afficher la version du XDK
```

**Remarque :** Étant donné que le XDK est généré à partir de la spécification OpenAPI, veillez à consulter systématiquement le [journal des modifications de X API](https://docs.x.com/changelog) ainsi que les notes de version du XDK dans le dépôt pour prendre en compte d’éventuels changements.
Pour des exemples de code détaillés utilisant le XDK Python, consultez notre [dépôt GitHub d’exemples de code](https://github.com/xdevplatform/samples/tree/main/python).
