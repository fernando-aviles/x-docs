Le SDK Python XDK est disponible directement sur le dépôt GitHub et peut être installé via `pip`.

<div id="prerequisites">
  ## Prérequis
</div>

- Python 3.8 ou version ultérieure.
- `pip` et `venv` pour les environnements virtuels (recommandé).

<div id="quick-install">
  ## Installation rapide
</div>

Installez le XDK à partir du sous-répertoire GitHub :

```bash
pip install xdk
```

Cela récupère la version générée la plus récente à partir de la branche `main`.


<div id="development-install">
  ## Installation pour le développement
</div>

Pour le développement ou pour contribuer au projet :

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/xdevplatform/xdk.git
   cd xdk/python
   ```
2. Installez les dépendances en mode éditable :
   ```bash
   pip install -e .
   ```
   Cela installe le SDK et ses dépendances d’exécution.
3. (Facultatif) Installez les dépendances de développement pour les tests et le linting :
   ```bash
   pip install -e .[dev]
   ```

<div id="verification">
  ## Vérification
</div>

Testez l&#39;installation :

```python
import xdk
print(xdk.__version__)  # Devrait afficher la version de xdk
```

**Remarque :** Étant donné que le XDK est généré à partir de la spécification OpenAPI, reportez-vous toujours au [changelog de la X API](https://docs.x.com/changelog) ainsi qu’aux notes de version du XDK dans le dépôt pour toute modification.
Pour des exemples de code détaillés utilisant le XDK Python, consultez notre [dépôt GitHub d’exemples de code](https://github.com/xdevplatform/samples/tree/main/python).
