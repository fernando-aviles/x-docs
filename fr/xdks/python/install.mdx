Le SDK Python XDK est disponible directement à partir du dépôt GitHub et peut être installé avec `pip`.

<div id="prerequisites">
  ## Prérequis
</div>

- Python 3.8 ou version ultérieure.
- `pip` et `venv` pour les environnements virtuels (recommandé).

<div id="quick-install">
  ## Installation rapide
</div>

Installez xdk à partir du sous-répertoire GitHub :

```bash
pip install xdk
```

Cela récupère la dernière version générée à partir de la branche `main`.


<div id="development-install">
  ## Installation pour le développement
</div>

Pour le développement ou pour contribuer :

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/xdevplatform/xdk.git
   cd xdk/python
   ```
2. Installez les dépendances en mode editable :
   ```bash
   pip install -e .
   ```
   Cela installe le SDK et ses dépendances d’exécution.
3. (Facultatif) Installez les dépendances de développement pour les tests et le linting :
   ```bash
   pip install -e .[dev]
   ```

<div id="verification">
  ## Vérification
</div>

Testez l’installation :

```python
import xdk
print(xdk.__version__)  # Devrait afficher la version de XDK
```

**Remarque :** Étant donné que le XDK est généré à l’aide de la spécification OpenAPI, consultez toujours le [changelog de X API](https://docs.x.com/changelog) et les notes de version du XDK dans le dépôt pour vérifier les éventuelles modifications.
Pour des exemples de code détaillés avec le XDK Python, consultez notre [dépôt GitHub d’exemples de code](https://github.com/xdevplatform/samples/tree/main/python).
