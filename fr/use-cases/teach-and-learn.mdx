<div id="educators">
  ## Enseignants
</div>

Introduisez l'API dans vos cours pour enseigner aux étudiants les bases
de la programmation et de précieuses compétences en traitement des données.

**Ressources :**

Vous êtes un enseignant et vous souhaitez utiliser X API dans votre cours ? Ce
[guide pour enseigner avec X API](https://dev.to/suhemparack/a-guide-to-teaching-with-the-twitter-api-v2-3n08)
vous aidera à comprendre X API, pourquoi elle est utilisée par les enseignants, quels types de
cours sont enseignés avec l'API, et tout ce que vous devez savoir pour
vous lancer.

**À la une :**

Les programmes ci-dessous sont conçus et mis en œuvre à l'aide de X API v2 :

- [Social Media Data Mining and Analysis](https://canvas.uw.edu/courses/1434897)
  par Dr Tanu Mitra

- [Data Science &amp; Society](https://dssoc.github.io/) par Dr Chris Bail

- [Introduction to Cultural Analytics &amp; Python](https://melaniewalsh.github.io/Intro-Cultural-Analytics/welcome.html)
  par Dr Melanie Walsh

- [Oxford Spring School in Advanced Research Methods, Analysing X Data](https://github.com/cjbarrie/oxspsch)
  par Dr Chris Barrie
