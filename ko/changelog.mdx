  ### DM 이벤트 동작 변경

  오늘 X API V2 DM 이벤트 동작을 변경했습니다. 이번 변경으로 participant&#95;ids 배열은 ParticipantsJoin 및 ParticipantsLeave 이벤트에만 포함되며, 이벤트 시점에 참여하거나 나간 참가자만을 나열합니다. MessageCreate 이벤트에는 더 이상 participant&#95;ids 배열이 포함되지 않습니다. 자세한 내용은 [여기](https://devcommunity.x.com/t/upcoming-change-to-x-api-dm-events-endpoints-behavior/241841)를 참고하세요.

<Update label="Aug 3, 2022" description="X API v2">
  ### 필터링 연산자 별칭 추가

  필터링/쿼리 연산자 &quot;별칭&quot;이 엔터프라이즈, 프리미엄 및 v2 전반의 검색 및 필터링 스트림 엔드포인트에 추가되었습니다. 많은 경우 연산자는 상태(statuses)가 아닌 포스트를 가리키며, 예를 들어 &quot;in&#95;reply&#95;to&#95;status&#95;id&quot;의 별칭으로 &quot;in&#95;reply&#95;to&#95;tweet&#95;id&quot;를 사용할 수 있습니다. 다른 경우에는 새 연산자 별칭을 통해 매칭 방식이 더 명확해집니다. 예를 들어, 포스트는 동영상 첨부 파일을 하나만 가질 수 있으므로 &quot;has:videos&quot;에 대한 새 별칭인 &quot;has:video&#95;link&quot;가 제공됩니다. 더 많은 예시는 [v2 filtered stream 연산자 표](https://developer.x.com/en/docs/twitter-api/tweets/filtered-stream/integrate/build-a-rule#list)를 확인하세요.
</Update>

<Update label="2021년 12월 14일" description="X API v2: 인증">
  ### OAuth 2.0 인증 지원

  오늘부터 모든 개발자는 개발자 콘솔에서 인증 방식으로 OAuth 2.0을 선택해 OAuth 2.0으로 인증할 수 있습니다. 이번 릴리스의 일환으로 confidential 클라이언트와 public 클라이언트를 모두 지원하며, 이 인증 방식을 사용할 수 있도록 모든 관련 v2 엔드포인트에 지원을 추가했습니다.

  OAuth 2.0은 애플리케이션의 스코프에 대해 개발자가 더 많은 제어 권한을 가질 수 있게 해주고, 여러 기기에 걸친 인가 플로우를 개선해 주는 업계 표준 인가 프로토콜입니다. 다시 말해, X 사용자를 위한 애플리케이션을 구축하는 개발자는 자신의 앱이 사용자에게 요청하는 정보에 대해 더 많은 제어 권한을 갖게 되며, 최종 사용자에게 꼭 필요한 데이터와 정보만 요청하면 됩니다.

  이 최신 인가 프로토콜을 사용하면, 앱 인가를 위한 동의 플로우를 더욱 간소화된 방식으로 최종 사용자에게 제공할 수 있으며, 여기에는 여러분이 요청한 특정 스코프만 표시됩니다.

  이번 출시와 관련해 더 자세한 내용을 알아보려면 포럼 공지를 방문해 주세요.
</Update>

<Update label="2021년 11월 15일" description="X API v2: 얼리 액세스">
  ### X API v2에 대한 주요 플랫폼 업데이트

  **주요 플랫폼 업데이트: X API v2가 기본 버전이 되었으며, 새로운 Essential 및 Elevated 액세스와 정책 변경 사항이 도입되었습니다.**

  오늘 우리는 X API v2가 X API의 기본 버전이 되었음을 알립니다. X API v2에 충분한 엔드포인트와 기능을 출시하여, X API를 기반으로 구축된 기존 앱의 90% 요구 사항을 충족할 수 있게 되었습니다.

  X API v2 개발자 경험을 한층 더 개선하기 위해 오늘 다음 변경 사항을 출시합니다.

  * API에 대한 빠르고 무료인 Essential 액세스와, 사용 사례가 승인된 개발자에게 제공되는 무료 Elevated 액세스. 이러한 액세스 레벨에 대한 자세한 내용은 About the X API 페이지에서 확인할 수 있습니다.

  * X의 핵심 기능을 활용하는 방식을 제한하고, 앱을 통해 지원할 수 있는 사용자 수를 제한하던 개발자 정책의 문구를 제거합니다.

    * X를 더 나은, 더 건강한 곳으로 만들고, 공중 대화를 확장하는 도구와 제품을 여러분이 구축할 수 있도록 플랫폼을 개방합니다. [우리가 여러분이 만들기를 바라는 솔루션 목록을 확인해 보세요](https://developer.x.com/en/docs/twitter-api/what-to-build).

    * 구체적으로, X 경험을 복제하는 것을 제한하던 조항(여기에는 X의 핵심 기능이 포함됨)과, 많은 수의 사용자 토큰을 보유하기 위해 별도 허가를 요구하던 조항을 제거했습니다.

    * X에서 사람들을 돕는 솔루션을 구축하려면, 개발자가 X에서 제공되는 일부 기능을 구축(또는 복제)해야 하는 경우가 자주 있다는 것을 알고 있습니다. 이번 개발자 정책 변경은 개발자 생태계에 명확성을 제공하고, 개발자가 공중 대화에 기여하는 빌드, 혁신, 영향력 창출을 더 쉽게 할 수 있는 개방형 API 플랫폼을 제공하는 것을 목표로 합니다.

  이번 출시와, 이 시점에 이르기까지의 X API 출시 내역에 대해 더 많은 세부 정보를 알고 싶다면 [포럼 게시글](https://devcommunity.x.com/t/ushering-in-a-new-era-for-the-twitter-developer-platform-with-the-twitter-api-v2/162087)을 참고해 주세요.

  * filtered stream에 대해 동시에 최대 1,000개의 규칙을 설정할 수 있는 증가된 규칙 한도(기존 Standard product track의 Basic access level에서 제공되는 25개에서 증가).

  * Standard product track의 Basic access level에서 제공되는 512자 한도에서 늘어난, 쿼리 및 규칙에 대한 1,024자 길이 제한

  이번 출시 내용에 대해 더 알아보려면 [포럼 공지](https://devcommunity.x.com/t/introducing-the-new-academic-research-product-track/148632)를 방문하세요.

  오늘 우리는 포스트 객체에 `reply_settings`라는 새 필드를 도입합니다. 이 필드는 post lookup, hide replies, recent search, sampled stream, filtered stream, follows lookup, user post timeline, user mention timeline endpoint를 포함하여 포스트를 반환하는 모든 X API v2 endpoint에서, 또는 어떤 endpoint에서든 포스트 객체를 [expanding](/ko/x-api/fundamentals/expansions)하여 사용할 수 있습니다.

<Update label="Feb 25, 2020" description="v2 Labs 엔드포인트: 포스트 및 사용자, Recent Search, Hide Replies">
  ### v2 Labs 엔드포인트 릴리스

  오늘 우리는 포스트 및 사용자, Recent Search, Hide Replies 엔드포인트를 Labs v2에서 제공하기 시작합니다. Labs v1 엔드포인트는 사용이 중단되며, 이 초기 릴리스 이후 90일 뒤 완전히 폐기됩니다. v1 문서도 이 기간 동안 계속 제공됩니다. 이 버전 관리 전략에 대한 피드백은 [피드백 채널](https://twitterdevfeedback.uservoice.com/)을 통해 보내실 수 있습니다.

  포스트 및 사용자 엔드포인트에는 다음과 같은 변경 사항이 있습니다.

  * [fields](/ko/x-api/fundamentals/fields)를 쿼리 매개변수로 도입

  * 쿼리 매개변수로 사용되던 [formats](https://developer.x.com/en/docs/labs#payload) 제거

  * 포스트 및 사용자에서 단일 ID [조회](https://developer.x.com/en/docs/labs/overview/versioning/migration-guide#id-lookup-path)를 위한 경로 변수 추가

  * GET /users에서 단일 및 여러 사용자 이름 [조회](/ko/x-api/migrate/overview#username-lookup-path)를 위한 경로 및 쿼리 매개변수 조정

  * 필드 이름 `stats` 를 `public_metrics` 로 변경

  기타 변경 사항은 다음과 같습니다.

  * 사용자에서 `most_recent_tweet_id` 확장 필드 제거

<Update label="2019년 2월 13일" description="X API: Enterprise v1.1">
  ### is:reply 연산자 추가

  오늘부터 is:reply 연산자를 [엔터프라이즈 검색 API](/ko/x-api/enterprise-gnip-2.0/fundamentals/search-api)와 유료 버전의 [프리미엄 검색 엔드포인트](https://developer.x.com/content/developer-twitter/en/docs/tweets/search/api-reference/premium-search)에서 사용할 수 있습니다.

  is:reply 불리언 연산자는 모든 포스트에 대한 답글만 남기도록 필터링하거나, 규칙과 일치하는 명시적인 답글만 걸러내는 데 사용할 수 있습니다. 이 연산자는 is:quote 연산자와 동일한 방식으로 동작합니다.

  Search API를 사용할 때 모든 `is:` 및 `has:` 연산자는 키워드나 해시태그와 같은 단독 연산자와 함께 사용해야 한다는 점을 기억하세요.

  이 연산자에 대해서는 [문서](/ko/x-api/enterprise-gnip-2.0/fundamentals/rules-filtering)에서 더 자세히 알아볼 수 있습니다.
</Update>

<Update label="2018년 5월 10일" description="X API: Standard v1.1">
  ### 인용 페이로드 렌더링 변경

  오늘부터 인용 페이로드에서 URL이 렌더링되는 방식이 변경됩니다.

  인용된 포스트를 참조할 수 있도록 &quot;quoted&#95;status&#95;permalink&quot;라는 새 엔티티를 추가하고, 인용된 포스트의 &quot;text&quot; 필드에서 t.co 링크를 제거할 예정입니다.

  새로운 형식에서는 &quot;quoted&#95;status&quot; 객체 내 인용된 포스트의 &quot;text&quot; 필드에 더 이상 t.co 링크가 추가되지 않습니다.

  또한, 인용된 포스트의 t.co url, expanded&#95;url, display&#95;url을 더 이상 ‘urls’ 엔티티에 넣지 않습니다. 대신, 이러한 값들은 &quot;url&quot;, &quot;expanded&quot;, &quot;display&quot; URL 속성을 가진 새로운 &quot;quoted&#95;status&#95;permalink&quot; 객체에 추가됩니다. 즉, &quot;quoted&#95;status&#95;permalink&quot; 객체는 인용된 포스트로 돌아가는 t.co 링크 전용으로 사용되며, &quot;entities.urls&quot; 배열은 원본 포스트 또는 인용 포스트 안에서 공유된 링크를 식별하는 데 사용할 수 있습니다.

  자세한 내용은 [포럼 게시글](https://devcommunity.x.com/t/updating-how-urls-are-rendered-in-the-quote-tweet-payload/105473)과 [업데이트된 문서](https://devcommunity.x.com/t/upcoming-changes-to-the-developer-platform/104603)를 참조하세요.
</Update>

<Update label="Nov 14, 2017" description="X API: Premium v1.1">
  ### Premium API 출시

  Premium API를 출시했습니다.

  이 새로운 API는 엔터프라이즈 데이터 플랫폼의 품질과 안정성을 기반으로 하며, 계층형 과금 모델을 통해 더 널리 제공됩니다. 이제 처음으로, 표준 엔드포인트에서 제공되던 제한적인 7일치 데이터 대신 30일치 포스트 전체를 검색할 수 있으며, 선택적으로 프로필 위치 정보, URL 확장, 설문조사 데이터에 대한 프리미엄 보강 기능에도 접근할 수 있습니다. 다음은 새로 추가된 기능의 일부입니다:

  * 요청당 더 많은 포스트를 반환 (Sandbox + Premium)

  * 더 복잡한 쿼리를 작성할 수 있게 해주는 훨씬 더 풍부한 쿼리 언어 (Sandbox + Premium)

  * 포스트 개수의 시계열 집계를 반환하는 counts 엔드포인트 (Premium)

  * 확장된 URL 및 Profile Geo와 같은 메타데이터 보강 기능 (Premium)

  이번 출시 내용에 대해 더 알아보려면 [블로그 글](https://blog.x.com/developer/en_us/topics/tools/2017/introducing-twitter-premium-apis.html)을 참조하세요.

  새로운 페이로드 필드: 사용자가 포스트에 사진을 추가할 때 &quot;Add description&quot; 옵션을 선택하면, 페이로드의 entities.media[] 및 extended&#95;entities.media[] 섹션에 Image Alt-Text(description) 필드가 포함될 수 있습니다. 이는 보강된 네이티브(enriched native) 형식에서만 제공됩니다.

  기본 페이로드 형식: Gnip 제품에서 새로 생성된 스트림은 이제 original 형식 JSON을 기본값으로 사용합니다.
</Update>
