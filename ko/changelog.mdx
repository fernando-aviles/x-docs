  ### DM 이벤트 동작 방식 변경

MessageCreate 이벤트에는 더 이상 `participant_ids` 배열이 포함되지 않습니다. 자세한 내용은 [여기](https://devcommunity.x.com/t/upcoming-change-to-x-api-dm-events-endpoints-behavior/241841)를 참고하세요.
</Update>

<Update label="Aug 3, 2022" description="X API v2">
  ### 필터링 연산자 별칭 추가

  검색 및 filtered stream 엔드포인트 전반(엔터프라이즈, 프리미엄, v2)에 필터링/쿼리 연산자 “별칭”이 추가되었습니다. 많은 경우 연산자는 statuses 대신 포스트를 가리킵니다. 예를 들어, &quot;in&#95;reply&#95;to&#95;tweet&#95;id&quot;는 &quot;in&#95;reply&#95;to&#95;status&#95;id&quot;의 별칭입니다. 다른 경우에는 새로운 연산자 별칭이 수행되는 매칭을 더 명확하게 합니다. 예를 들어, 포스트에는 한 개의 비디오 첨부만 있을 수 있으므로, &quot;has:videos&quot;에 대한 새로운 별칭 &quot;has:video&#95;link&quot;가 제공됩니다. 더 많은 예시는 [v2 filtered stream 연산자 표](https://developer.x.com/en/docs/twitter-api/tweets/filtered-stream/integrate/build-a-rule#list)를 참고하세요.
</Update>

  ### OAuth 2.0 인증 지원

  오늘부로 모든 개발자는 Developer Console에서 인증 방식으로 OAuth 2.0을 선택하여 OAuth 2.0을 사용해 인증할 수 있습니다. 이번 릴리스의 일환으로 기밀 및 공용 클라이언트에 대한 지원과 이 인증 방식을 사용할 수 있는 모든 관련 v2 엔드포인트를 추가했습니다.

  OAuth 2.0은 애플리케이션의 스코프에 대해 개발자가 더 세밀하게 제어할 수 있도록 하고, 여러 기기에 걸친 인가 플로우를 개선하는 업계 표준 인가 프로토콜입니다. 다시 말해, X 이용자를 위한 애플리케이션을 구축하는 개발자는 자신의 앱이 사용자에게 요청하는 정보에 대해 더 많은 제어권을 갖게 되며, 이를 통해 최종 사용자에게 꼭 필요한 데이터와 정보만 요청할 수 있습니다.

  이 현대적인 인가 프로토콜을 사용하면 앱 인가를 위한 동의 플로우를 더욱 간소화된 형태로 최종 사용자에게 제공할 수 있으며, 이 플로우에는 여러분이 요청한 특정 스코프만 표시됩니다.

  이번 출시와 관련된 더 자세한 내용은 포럼 공지를 방문해 확인하세요.

<Update label="Nov 15, 2021" description="X API v2: Early Access">
  ### X API v2에 대한 주요 플랫폼 업데이트

  **주요 플랫폼 업데이트: X API v2가 이제 기본 버전이 되었으며, 새로운 Essential 및 Elevated 액세스, 그리고 정책 변경 포함**

  오늘 X API v2가 X API의 기본 버전이 되었음을 발표합니다. 우리는 X API v2에 X API를 기반으로 구축된 기존 앱의 90% 요구 사항을 충족할 수 있을 만큼 충분한 엔드포인트와 기능을 출시했습니다.

  X API v2 개발자 경험을 한층 더 향상하기 위해 오늘 다음과 같은 변경 사항을 출시합니다.

  * API에 대한 빠르고 무료로 제공되는 Essential 액세스, 그리고 사용 사례가 승인된 개발자에게 제공되는 무료 Elevated 액세스. 이러한 액세스 레벨에 대한 더 자세한 내용은 About the X API 페이지에서 확인하실 수 있습니다.

  * X의 핵심 기능을 기반으로 무엇을 구축할 수 있는지 제한하고, 앱이 지원할 수 있는 사용자 수를 제한하던 Developer Policy 상의 문구를 제거합니다.

    * 우리 플랫폼을 개방하여, 여러분이 X를 더 좋고 건전하게 만들며 공적 대화를 확장하는 도구와 제품을 구축하도록 장려하고자 합니다. [우리가 여러분이 구축해 주기를 바라는 솔루션 목록을 확인해 보세요](https://developer.x.com/en/docs/twitter-api/what-to-build).

    * 구체적으로, X의 핵심 기능을 포함해 X 경험을 복제하는 것을 제한하던 조항과, 많은 수의 사용자 토큰을 보유하려면 허가를 받도록 요구하던 조항을 제거했습니다.

    * X에서 사람들을 돕는 솔루션을 구축하는 일은, 종종 개발자가 X에서 제공되는 일부 기능을 직접 구축(또는 복제)해야 함을 의미한다는 것을 알고 있습니다. Developer Policy에 대한 이러한 변경 사항은 개발자 생태계에 명확성을 제공하고, 개발자가 공적 대화에 기여하는 빌드와 혁신을 더 쉽게 할 수 있도록 하는 개방형 API 플랫폼을 제공하기 위한 것입니다.

  이번 출시와, 이 시점에 이르기까지 진행된 X API 출시 사항에 대해 더 많은 내용을 [포럼 게시글](https://devcommunity.x.com/t/ushering-in-a-new-era-for-the-twitter-developer-platform-with-the-twitter-api-v2/162087)에서 다루고 있습니다.

<Update label="Jan 26, 2021" description="X API v2 학술 연구 제품 트랙 소개">
  ### 학술 연구 제품 트랙 소개

  오늘 우리는 [Academic Research 제품 트랙](/ko/resources/fundamentals/developer-apps)을 [X API v2](/ko/x-api/introduction)에 새로 도입합니다. 이 업데이트를 통해 학술 연구자를 위한 새로운 신청 프로세스가 추가되며, 승인을 받은 연구자에게는 더 높은 수준의 접근 권한과 고급 기능을 제공하는 Academic Research [Project](/ko/resources/fundamentals/developer-apps)가 부여됩니다.

  새로운 Academic Research 제품 트랙을 통해 다음과 같은 기능을 사용할 수 있습니다.

  * 현재로서는 Academic Research 제품 트랙에서만 사용할 수 있는 새로운 X API v2 [전체 아카이브 검색 엔드포인트](/ko/x-api/posts/full-archive-search).

  * Basic [access level](https://developer.x.com/en/products/x-api/early-access/guide#na_2)의 [Standard 제품 트랙](/ko/resources/fundamentals/developer-apps)에 제공되던 50만 개에서 1,000만 개로 늘어난 [포스트 상한](/ko/x-api/fundamentals/post-cap).

  * [최근 검색](/ko/x-api/posts/recent-search), [전체 아카이브 검색](/ko/x-api/posts/full-archive-search), [필터링된 스트림](/ko/x-api/posts/filtered-stream)에 사용할 수 있는 새로운 필터 연산자. 여기에는 `$`(일명 캐시태그), `bio`(필터링된 스트림에서만 사용 가능), `bio_name`(필터링된 스트림에서만 사용 가능), `bio_location`(필터링된 스트림에서만 사용 가능), `place`, `place_country`, `point_radius`, `bounding_box`, `-is:nullcast`, `has:cashtags`, `has:geo`가 포함됩니다.

  * 필터링된 스트림에 대해 동시 규칙 수가 25개(기존 Basic access level의 Standard 제품 트랙에서 제공되던 한도)에서 1,000개로 증가한 규칙 한도.

  * 쿼리 및 규칙의 문자 수 한도가 512자(기존 Basic access level의 Standard 제품 트랙에서 제공되던 한도)에서 1,024자로 증가.

  이번 출시 내용에 대해 더 자세히 알아보려면 [포럼 공지](https://devcommunity.x.com/t/introducing-the-new-academic-research-product-track/148632)를 방문하세요.
</Update>

<Update label="Dec 18, 2020" description="X API v2용 대화 답글 설정 포스트 필드">
  ### 답글 설정 필드 추가

  오늘 우리는 post 객체에 `reply_settings`라는 새 필드를 도입합니다. 이 필드는 post 조회, 답글 숨기기, 최근 검색, 샘플 스트림, 필터링된 스트림, 팔로우 조회, 사용자 포스트 타임라인, 사용자 멘션 타임라인 엔드포인트를 포함해 포스트를 반환하는 모든 X API v2 엔드포인트에서 사용할 수 있으며, 어떤 엔드포인트에서든 post 객체를 [expansions](/ko/x-api/fundamentals/expansions)로 확장해도 사용할 수 있습니다.

  이 필드는 포스트 작성자가 다른 사람들이 자신의 포스트에 어떻게 답글을 달 수 있도록 허용했는지를 나타내며, 모두에게 허용했는지, 포스트에서 멘션한 사람만 허용했는지, 혹은 자신이 팔로우하는 사람에게만 허용했는지를 표시합니다. `reply_settings` 필드에서 반환되는 값에는 `everyone`, `mentionedUsers`, `following`이 포함됩니다. 포스트에 대해 별도의 대화 제어가 설정되지 않은 경우에도 이 필드는 여전히 post 객체에 `everyone` 값을 가진 상태로 포함됩니다.
</Update>

  * 사용자에서 `most_recent_tweet_id` 확장(expansion) 제거

  * 포스트의 `source` 필드에서 HTML 태그를 제거하여 해당 필드를 더 쉽게 파싱할 수 있도록 함

  최근 검색의 핵심 검색 기능, 페이지네이션 및 기타 기능은 동일하게 유지됩니다.

  v1에서 v2로 업데이트할 때를 위해 일부 [마이그레이션 자료](/ko/x-api/migrate/overview)를 준비해 두었습니다.

  이 변경 사항에 대해 더 자세한 내용은 [포럼 공지](https://devcommunity.x.com/t/releasing-a-new-version-of-labs-endpoints/134219)를 참고하세요.

  오늘부로 is:reply 연산자를 [엔터프라이즈 검색 API](/ko/x-api/enterprise-gnip-2.0/fundamentals/search-api) 및 [프리미엄 검색 엔드포인트](https://developer.x.com/content/developer-twitter/en/docs/tweets/search/api-reference/premium-search)의 유료 버전에서 사용할 수 있게 되었습니다.

  is:reply 불리언 연산자는 포스트에 대한 모든 답글을 필터링하거나, 규칙과 일치하는 명시적인 답글만 걸러내는 데 사용할 수 있습니다. 이 연산자는 is:quote 연산자와 동일한 방식으로 동작합니다.

  Search API를 사용할 때 모든 &#39;is:&#39; 및 &#39;has:&#39; 연산자는 키워드나 해시태그와 같은 단독 연산자와 함께 사용해야 한다는 점을 기억하세요.

  이 연산자에 대해서는 [문서](/ko/x-api/enterprise-gnip-2.0/fundamentals/rules-filtering)에서 더 자세히 알아볼 수 있습니다.
</Update>

<Update label="May 10, 2018" description="X API: Standard v1.1">
  ### 인용 페이로드 렌더링 변경 사항

  오늘 인용 페이로드에서 URL이 렌더링되는 방식에 변경을 추가합니다.

  인용 포스트를 참조할 수 있도록 &quot;quoted&#95;status&#95;permalink&quot;라는 새로운 엔터티를 추가하고, 인용 포스트의 &quot;text&quot; 필드에서 t.co 링크를 제거할 예정입니다.

  새로운 형식에서는 &quot;quoted&#95;status&quot; 객체의 인용 포스트 &quot;text&quot; 필드에 더 이상 t.co 링크가 추가되지 않습니다.

  또한 더 이상 인용 포스트의 t.co url, expanded&#95;url, display&#95;url을 ‘urls’ 엔터티에 넣지 않습니다. 대신, 이들은 &quot;url&quot;, &quot;expanded&quot;, &quot;display&quot; URL 속성을 가진 새로운 &quot;quoted&#95;status&#95;permalink&quot; 객체에 추가됩니다. 이는 &quot;quoted&#95;status&#95;permalink&quot; 객체는 인용 포스트로 돌아가는 t.co 링크 전용으로 사용되고, &quot;entities.urls&quot; 배열은 원본 포스트 또는 인용 내에서 공유된 다른 링크를 식별하는 데 사용할 수 있음을 의미합니다.

  자세한 내용은 [포럼 게시물](https://devcommunity.x.com/t/updating-how-urls-are-rendered-in-the-quote-tweet-payload/105473)과 [업데이트된 문서](https://devcommunity.x.com/t/upcoming-changes-to-the-developer-platform/104603)를 참고하세요.

  ### Premium API 출시

  Premium API를 출시했습니다.

  이 새로운 API는 엔터프라이즈 데이터 플랫폼의 품질과 안정성을 기반으로 하며, 계층형 가격 모델을 통해 더 널리 제공됩니다. 이제 처음으로, 표준 엔드포인트에서 제공되던 제한된 7일치 데이터 대신 최대 30일치 포스트를 검색할 수 있으며, 선택적으로 프로필 지오, URL 확장, 설문조사 데이터에 대한 프리미엄 보강 기능에도 접근할 수 있습니다. 새로운 기능의 일부는 다음과 같습니다:

  * 포스트의 시계열 개수를 반환하는 counts 엔드포인트 (Premium)

  * 확장된 URL 및 프로필 지오와 같은 메타데이터 보강 기능 (Premium)

  이번 출시와 관련된 자세한 내용은 [블로그 글](https://blog.x.com/developer/en_us/topics/tools/2017/introducing-twitter-premium-apis.html)에서 확인하세요.
