<div id="introduction">
  ## 소개
</div>

[최근 검색 엔드포인트](/ko/x-api/posts/search/introduction)는 최근 7일 이내에 게시된 포스트만 가져올 수 있지만, 사용자 포스트 타임라인 및 사용자 멘션 타임라인 엔드포인트를 사용하면 인증된 사용자(user ID 사용)에 대해 최근 7일 이전의 포스트와 멘션도 조회할 수 있습니다. 개발자는 이 엔드포인트를 사용하여 사용자의 타임라인이나 멘션에 포함된 토픽, 엔터티, 감성(sentiment)을 분석할 수 있습니다. 이 튜토리얼에서는 사용자 트윗 타임라인 엔드포인트와 사용자 멘션 타임라인 엔드포인트를 사용해 사용자의 포스트와 멘션을 탐색하는 방법을 살펴봅니다.
 

<div id="prerequisites">
  ## 필수 조건
</div>

* 사용자 트윗 타임라인 및 사용자 멘션 타임라인 엔드포인트를 사용하려면 유효한 개발자 계정이 있어야 합니다. 
* [Project](/ko/resources/fundamentals/developer-apps)가 생성되어 있어야 합니다.
* [개발자 계정에 가입](https://developer.x.com/en/portal/petition/essential/basic-info)하고 [새로운 Developer Console 환경](https://developer.x.com/en/portal/opt-in.html)을 활성화해야 합니다. 
* [Developer Console](/ko/resources/fundamentals/developer-portal)에서 생성된 [Project](/ko/resources/fundamentals/developer-apps)에 연결된 개발자 App의 활성 상태 키와 토큰으로 접근할 수 있어야 합니다.
* [X Developer Console](/ko/resources/fundamentals/developer-portal)에 있는 App에서 발급된 Bearer Token이 필요합니다.
* 승인된 개발자 계정이 없는 경우, [승인을 신청](https://developer.x.com/en/apply-for-access)할 수 있습니다.

<div id="approved-developer-account">
  ## 승인된 개발자 계정
</div>

아직 개발자 계정을 만들지 않았다면 [여기에서 신청할 수 있습니다](https://developer.x.com/en/apply-for-access).

<div id="create-a-project-and-connect-an-app">
  ## Project를 생성하고 App을 연결하기
</div>

[개발자 콘솔](https://developer.x.com/en/portal/dashboard)에서 &#39;Create a new App&#39;를 클릭합니다.

<Frame>
  <img src="/images/projects.png.twimg.1920.png" />
</Frame>

Project에 이름을 지정하고, 적절한 사용 사례를 선택한 다음 Project 설명을 입력합니다. 그다음 새 App을 생성하거나, 기존 [App](/ko/resources/fundamentals/developer-apps)을 연결할 수 있습니다(App은 X API에 HTTP 요청을 보내는 데 필요한 API 키를 담는 컨테이너입니다).

<Frame>
  <img src="/images/add-your-app.png.twimg.1920.png" />
</Frame>

&#39;Create a new App instead&#39;를 클릭하고 새 App을 생성하기 위해 App 이름을 지정합니다.

<Frame>
  <img src="/images/last-step-name-your-app.png.twimg.1920.png" />
</Frame>

&#39;Complete&#39;를 클릭하면 API 키와 Bearer Token이 발급되며, 이를 사용하여 X API v2의 새로운 엔드포인트에 연결할 수 있습니다.

<Frame>
  <img src="/images/here-are-your-keys.png.twimg.1920.png" />
</Frame>

API key, API secret key 및 Bearer Token 옆의 (+)를 클릭하고 이 값을 로컬 머신의 안전한 위치에 복사합니다. 다음 단계에서 API 호출을 수행할 때 이 값이 필요합니다.

참고: 위 스크린샷의 키 값은 숨겨져 있지만, 사용자의 개발자 콘솔에서는 API key, API secret key 및 Bearer Token의 실제 값을 확인할 수 있습니다.
 

<div id="how-to-get-the-user-id-for-a-user-to-use-in-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## user Tweet timeline 및 user mention timeline 엔드포인트에서 사용할 사용자 ID를 가져오는 방법
</div>

user Tweet timeline 및 user mention timeline 엔드포인트를 사용하면 사용자 ID를 사용해 포스트를 가져올 수 있습니다. username에서 사용자 ID를 가져오려면 새로운 [user lookup endpoint v2](/ko/x-api/users/lookup/quickstart/user-lookup)를 사용할 수 있습니다. USER&#95;NAME을 원하는 username으로 바꾸고, XXXX를 위에서 얻은 자신의 Bearer Token으로 바꾸세요.

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

아래 예시와 같이 응답에서 사용자 ID를 확인할 수 있습니다:

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```

<div id="connecting-to-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## 사용자 트윗 타임라인 및 사용자 멘션 타임라인 엔드포인트에 연결하기
</div>

사용자의 트윗 타임라인을 가져오려면 터미널에서 다음 curl 명령을 실행하세요(원하는 사용자의 user ID로 USER&#95;ID를, 위에서 발급받은 본인의 Bearer Token으로 XXXX를 각각 바꿔 입력해야 합니다).

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```

이들 요청에 대한 JSON 응답에는 기본적으로 포스트의 id와 텍스트가 포함됩니다(아래 예시 참조).

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 If you are new to the X API v2, check out this step-by-step guide to making your first request https://t.co/4rZqThpSbp"
}
```

응답에 추가 필드(예: 사용자 정보, context annotations와 같은 추가 Tweet 필드 등)를 포함해서 반환받고 싶다면, 해당 필드를 응답에 명시적으로 지정해야 합니다. 자세한 방법은 [fields 및 expansions 사용 방법 가이드](/ko/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)를 참고하세요.

원하는 프로그래밍 언어를 사용하여 이러한 포스트를 가져올 수도 있습니다. user Tweet timeline 및 user mention timeline 엔드포인트용 Python, Node (JavaScript), Java, Ruby 샘플 코드는 저희 [GitHub 저장소](https://github.com/xdevplatform/Twitter-API-v2-sample-code)에서 확인할 수 있습니다.

<div id="exploring-the-users-posts">
  ## 사용자의 포스트 살펴보기
</div>

user Tweet timeline 및 user mention timeline 엔드포인트를 사용해 포스트를 가져오는 방법을 알게 되면, 해당 사용자의 포스트를 탐색해 볼 수 있습니다. 예를 들어, 사용자의 멘션에 나타나는 공통의 명명 개체를 식별하고 싶다면 다음과 같이 할 수 있습니다:

API 요청에서 Tweet 응답에 `context&#95;annotations` 객체가 포함되어 반환되도록 지정합니다:

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

응답에서 멘션에 이름이 지정된 엔터티가 있는지 확인할 수 있습니다. 예시는 다음과 같습니다.

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "브랜드 및 회사"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

멘션에서 어떤 인기 엔터티가 나타나는지 확인하려면, 멘션에 포함된 각 트윗을 파싱하여 인기 엔터티의 개수를 집계할 수 있습니다.

타임라인에서 미디어가 포함된 모든 포스트의 미리보기 이미지 URL을 확인하고 싶다면, 다음과 같이 할 수 있습니다.

API 요청에서 `tweet.media` 필드에 `preview_image_url`을 포함하고, `attachments.media_keys`를 값으로 하는 `expansions`를 지정하세요.

```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

응답의 `includes` 객체에서 아래와 같이 preview&#95;image&#95;url을 확인할 수 있습니다:

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```

사용자의 포스트를 탐색하는 방법을 이해했다면, 다른 API 및 서비스를 사용해 포스트를 보다 다양하게 활용할 수도 있습니다. 아래는 사용자 트윗 타임라인 및 사용자 멘션 타임라인 엔드포인트를 사용할 때 참고하기 좋은 리소스입니다.
