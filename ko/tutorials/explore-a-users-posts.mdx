<div id="introduction">
  ## 소개
</div>

[최근 검색 endpoint](/ko/x-api/posts/search/introduction)는 지난 7일 이내에 게시된 포스트만 가져올 수 있지만, user Post timeline endpoint와 user mention timeline endpoint를 사용하면 인가된 사용자(사용자 id 사용)의 지난 7일보다 더 이전에 게시된 포스트와 멘션도 조회할 수 있습니다. 개발자는 이 endpoint를 사용해 사용자의 타임라인이나 멘션에 있는 포스트의 토픽, 엔티티, 감성을 분석할 수 있습니다. 이 튜토리얼에서는 user Tweet timeline endpoint와 user mention timeline endpoint를 사용해 사용자의 포스트와 멘션을 탐색하는 방법을 설명합니다.
 

<div id="prerequisites">
  ## 사전 준비 사항
</div>

* 사용자 트윗 타임라인 엔드포인트와 사용자 멘션 타임라인 엔드포인트를 사용하려면 유효한 개발자 계정이 필요합니다. 
* [Project](/ko/resources/fundamentals/developer-apps)가 생성되어 있어야 합니다.
* [개발자 계정에 가입](https://developer.x.com/en/portal/petition/essential/basic-info)한 뒤, [new Developer Console 경험](https://developer.x.com/en/portal/opt-in.html)을 활성화해야 합니다. 
* [Developer Console](/ko/resources/fundamentals/developer-portal)에서 생성된 [Project](/ko/resources/fundamentals/developer-apps)에 연결된 개발자 App의 활성 키와 토큰이 있어야 합니다.
* [X Developer Console](/ko/resources/fundamentals/developer-portal)에 있는 App의 Bearer Token이 있어야 합니다.
* 승인된 개발자 계정이 없다면 [신청](https://developer.x.com/en/apply-for-access)하여 승인 요청을 할 수 있습니다.

<div id="approved-developer-account">
  ## 승인된 개발자 계정
</div>

아직 개발자 계정이 없다면 [개발자 계정을 신청하세요](https://developer.x.com/en/apply-for-access).

<div id="create-a-project-and-connect-an-app">
  ## Project를 생성하고 App을 연결하기
</div>

[Developer Console](https://developer.x.com/en/portal/dashboard)에서 **Create a new App**을 클릭합니다.

<Frame>
  <img src="/images/projects.png.twimg.1920.png" />
</Frame>

이름을 지정하고, 적절한 사용 사례를 선택한 뒤 Project 설명을 입력합니다. 그런 다음 새 App을 만들거나, 기존 [App](/ko/resources/fundamentals/developer-apps)을 연결할 수 있습니다(App은 X API에 HTTP 요청을 보내는 데 필요한 API 키를 담고 있는 컨테이너입니다).

<Frame>
  <img src="/images/add-your-app.png.twimg.1920.png" />
</Frame>

**‘create a new App instead’**를 클릭한 다음, 새 App을 생성하기 위해 App 이름을 입력합니다.

<Frame>
  <img src="/images/last-step-name-your-app.png.twimg.1920.png" />
</Frame>

완료를 클릭하면, X API v2의 새 엔드포인트에 연결하는 데 사용할 API 키와 Bearer Token을 받게 됩니다.

<Frame>
  <img src="/images/here-are-your-keys.png.twimg.1920.png" />
</Frame>

API key, API secret key, Bearer Token 옆의 (+)를 클릭한 뒤 이 값을 로컬 컴퓨터의 안전한 위치에 복사해 두십시오. 다음 단계에서 API 호출을 할 때 이 값이 필요합니다.

참고: 위 스크린샷의 키 값은 숨겨져 있지만, 직접 접속한 Developer Console에서는 API key, API secret key, Bearer Token의 실제 값을 확인할 수 있습니다.
 

<div id="how-to-get-the-user-id-for-a-user-to-use-in-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## user Tweet 타임라인 및 user mention 타임라인 엔드포인트에서 사용할 사용자 ID를 가져오는 방법
</div>

user Tweet 타임라인 및 user mention 타임라인 엔드포인트를 사용하면 사용자 ID를 사용하여 포스트를 가져올 수 있습니다. 사용자 이름에서 사용자 ID를 가져오려면 새로운 [user lookup endpoint v2](/ko/x-api/users/lookup/quickstart/user-lookup)를 사용할 수 있습니다. USER&#95;NAME을 원하는 사용자 이름으로 바꾸고 XXXX를 위에서 발급받은 Bearer Token으로 바꾸세요

```bash
  curl --request GET 'https://api.x.com/2/users/by/username/USER_NAME --header 'Authorization: Bearer XXXXXX'
```

아래와 같이 응답에 사용자 id가 표시됩니다:

```json
{
   "data": {
       "id": "2244994945",
       "name": "Developers",
       "username": "XDevelopers"
   }
}
```

<div id="connecting-to-the-user-tweet-timeline-and-user-mention-timeline-endpoints">
  ## 사용자 트윗 타임라인 및 사용자 멘션 타임라인 엔드포인트에 연결하기
</div>

특정 사용자의 트윗 타임라인을 가져오려면 터미널에서 다음 curl 명령을 실행하세요 (USER&#95;ID는 원하는 사용자의 사용자 id로, XXXX는 위에서 발급받은 본인의 Bearer Token으로 바꾸면 됩니다).

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/tweets' --header 'Authorization: Bearer XXXXXX'
```

이 요청에 대한 JSON 응답에는 기본적으로 포스트의 id와 텍스트가 포함됩니다(아래 예시 참조).

```yaml
{
   "id": "1334200897081987072",
   "text": "👀 If you are new to the X API v2, check out this step-by-step guide to making your first request https://t.co/4rZqThpSbp"
}
```

응답의 일부로 추가 필드(사용자 정보, context annotations 등의 추가 트윗 필드 등)를 반환받고 싶다면, 요청에 이러한 필드를 명시적으로 지정해야 합니다. 이에 대한 자세한 방법은 [fields 및 expansions 사용 방법 가이드](/ko/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)를 참고하세요.

원하는 프로그래밍 언어로도 이러한 포스트를 가져올 수 있습니다. user Tweet timeline 및 user mention timeline 엔드포인트에 대한 Python, Node (JavaScript), Java, Ruby 샘플 코드는 [GitHub 리포지토리](https://github.com/xdevplatform/Twitter-API-v2-sample-code)에서 확인할 수 있습니다.

<div id="exploring-the-users-posts">
  ## 사용자의 포스트 살펴보기
</div>

user Tweet timeline 및 user mention timeline 엔드포인트를 사용해 포스트를 가져오는 방법을 숙지했다면, 이제 해당 사용자의 포스트를 살펴볼 수 있습니다. 예를 들어, 사용자의 멘션에 공통으로 등장하는 개체명(named entity)을 식별하고 싶다면 다음과 같이 할 수 있습니다.

API 요청에서 트윗 응답에 `context_annotations` 객체가 반환되도록 지정합니다:

```bash
curl --request GET 'https://api.x.com/2/users/USER_ID/mentions?tweet.fields=context_annotations' --header 'Authorization: Bearer XXXXXX'
```

응답에서 멘션에 어떤 이름이 지정된 엔터티가 있는지 확인할 수 있습니다. 예시는 다음과 같습니다.

```json
{
   "domain": {
       "id": "47",
       "name": "Brand",
       "description": "브랜드 및 회사"
   },
   "entity": {
       "id": "783214",
       "name": "X"
   }
}
```

멘션에서 어떤 인기 있는 엔티티가 나타나는지 확인하려면, 멘션에 있는 각 트윗을 파싱하여 인기 있는 엔티티의 개수를 집계해 둘 수 있습니다.

타임라인에서 미디어를 포함하는 모든 포스트의 미리보기 이미지 URL을 살펴보고 싶다면, 다음과 같이 하면 됩니다.

API 요청에서 `tweet.media` 필드에 `preview_image_url`을 포함하도록 지정하고, `expansions`에 `attachments.media_keys`를 추가하십시오.

```bash
curl --request GET 'https://api.x.com/2/users/2244994945/mentions?max_results=100&media.fields=preview_image_url&expansions=attachments.media_keys' --header 'Authorization: Bearer XXXXXX'
```

응답의 includes 객체에서 아래와 같이 preview&#95;image&#95;url을 확인할 수 있습니다:

```json
{
   "includes": {
       "media": [
           {
               "media_key": "16_1334657439640121344",
               "preview_image_url": "https://pbs.twimg.com/tweet_video_thumb/EoWn3rqU8AAtFWL.jpg",
               "type": "animated_gif"
           }
       ]
   }
}
```

사용자의 포스트를 탐색하는 방법을 이해했다면, 다른 API 및 서비스를 함께 사용해 포스트로 더 다양한 작업을 수행할 수 있습니다. 아래에는 사용자 트윗 타임라인 및 사용자 멘션 타임라인 엔드포인트를 사용할 때 참고할 수 있는 몇 가지 리소스를 정리했습니다.
