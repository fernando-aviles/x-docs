<div id="introduction">
  ## 소개
</div>

이 튜토리얼에서는 프로그래밍 언어 R과 X API v2를 시작하는 데 필요한 사항을 단계별로 살펴봅니다. R을 사용하여
[user lookup](/ko/x-api/users/lookup/introduction) 엔드포인트에 연결하면서,
X API에서 반환되는 JSON을 어떻게 다루는지 살펴보겠습니다. user lookup 엔드포인트는
GET 메서드이며, 사용자 id 또는 username으로 지정된 하나의 사용자 또는 여러 사용자에 대한 정보를 반환합니다.

익숙하지 않을 수 있지만, R은 시계열 분석, 모델링, 시각화 및 기타 데이터 분석과 같은 일반적인 데이터 사이언스 작업에 가장 널리 사용되는 언어 중 하나이며, X API와 함께 자주 사용됩니다. user
lookup 엔드포인트를 사용하면
[user object](/ko/x-api/fundamentals/data-dictionary#user)를 활용하여
어떤 사람이 보유한 팔로워 수와 그 사람의 프로필 소개(bio)에 대한 감성 점수 사이의 상관관계를 파악할 수 있습니다. user object는 또한 각 계정의 프로필에 공개적으로 기재된 위치 정보를 기반으로 계정 그룹을 매핑하는 데 사용할 수도 있습니다.

<div id="getting-started-with-the-x-api">
  ### X API 시작하기
</div>

X API v2를 사용하기 전에
[가입](https://developer.x.com/en/portal/petition/essential/basic-info)
하여 개발자 계정을 생성해야 합니다.

개발자 계정 승인을 받은 후, 먼저
[Project](/ko/resources/fundamentals/developer-apps)를 생성해야 합니다. Project는 X API를 어떻게 사용할지에 따라 작업을 구성할 수 있도록 해 주며, 이를 통해 API 접근을 효과적으로 관리하고 사용량을 모니터링할 수 있습니다.

각 Project에는 X API를 사용하는 데 필요한 인증 정보를 생성할 수 있는 [App](/ko/resources/fundamentals/developer-apps)이 포함되어 있습니다. X API를 시작하는 방법에 대한 자세한 내용은 문서의
[시작하기](/ko/x-api/getting-started/about-x-api) 섹션에서 확인할 수 있습니다.

<div id="getting-your-r-environment-set-up">
  ### R 환경 설정하기
</div>

먼저 [R을 다운로드](https://cloud.r-project.org/)해야 합니다. 이는
[CRAN 웹사이트](https://cran.r-project.org/)에서 할 수 있습니다.

다음으로 R을 사용할 환경을 설정하려면
[R Studio](https://www.rstudio.com/),
[Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=Ikuyadeu.r-pack)의 R 확장 팩,
또는 Python 환경에 익숙하다면
[Jupyter notebook](https://docs.anaconda.com/anaconda/navigator/tutorials/r-lang/)을
사용할 수 있습니다.

<div id="setting-up-your-environment-variable">
  ### 환경 변수 설정하기
</div>

오늘 보여 드릴 코드 예제들을 위해, Bearer Token을 위한 환경 변수를 설정해야
합니다. Bearer Token은 X API에 인증을 수행해 요청을 보낼 수 있게 해 주는
토큰입니다. 먼저 “your-bearer-token”을 Developer Console의 해당 App
‘keys and tokens’ 섹션에서 발급받은 본인의 Bearer Token으로 바꾸십시오.
스크립트를 작성하기 전에 이 코드 한 줄을 콘솔에서 실행해야 합니다.

```r
Sys.setenv(BEARER_TOKEN = "your-bearer-token")
```

<div id="making-your-request">
  ### 요청 보내기
</div>

패키지
[httr](https://cran.r-project.org/web/packages/httr/index.html)를 사용해 X API로 HTTP
요청을 보낼 수 있습니다. 아직 설치하지 않았다면 R 콘솔에서
이 패키지를 설치하세요. 또한 JSON 객체를 다루기 위해
[jsonlite](https://cran.r-project.org/web/packages/jsonlite/index.html)와 데이터
조작을 위해 [dplyr](https://dplyr.tidyverse.org/)도 설치해야 합니다.

```r
install.packages("httr")
install.packages("jsonlite")
install.packages("dplyr")
```

이제 API에 연결할 R 스크립트 작성을 시작할 수 있습니다. 파일 맨 위에서 httr, jsonlite, dplyr 패키지를 불러옵니다.

```r
require(httr)
require(jsonlite)
require(dplyr)
```

코드 예제의 첫 번째 단계는 X API 인증을 위한 설정입니다. App에서 가져온
[Bearer Token](/ko/resources/fundamentals/authentication#using-and-generating-an-app-only-bearer-token)을 가져와 인증을 위해 요청 헤더에 전달하세요. 아래 예제에서
$BEARER&#95;TOKEN을 자신의 토큰으로 바꾸면 됩니다.

```r
bearer_token <- Sys.getenv("$BEARER_TOKEN")
headers <- c(`Authorization` = sprintf('Bearer %s', bearer_token))
```

인증 설정을 마쳤다면, 요청에 사용할 매개변수를 정의합니다.
기본적으로 응답에는 가져온 각 사용자에 대한 id, 이름, username이 포함됩니다.
추가 [필드](/ko/x-api/fundamentals/fields)와
[expansions](/ko/x-api/fundamentals/expansions)를 지정해 응답 페이로드를 조정할 수 있습니다.
이 예제에서는 user.fields=description을 사용해 사용자의 프로필 자기소개(bio)를 요청하고,
사용자의 고정 포스트를 포함하도록 expansions 매개변수도 함께 지정합니다.

```r
params <- list(`user.fields` = 'description', `expansions` = 'pinned_tweet_id')
```

이제 더 많은 정보를 얻고자 하는 계정, 즉 X 핸들을 사용해 URL을 포맷할 준비가 되었습니다. 이 샘플을 재사용할 수 있도록 `readline` 메서드를 사용하세요. 조회하려는 핸들을 입력한 다음, `$USERNAME`을 원하는 X 핸들로 바꿔서 지정한 핸들이 포함되도록 URL을 포맷합니다.

```r
handle <- readline('$USERNAME')
url_handle <- sprintf('https://api.x.com/2/users/by?usernames=%s', handle)
```

이제 httr 패키지를 사용하여 방금 생성한 URL에 GET 요청을 보내고, 헤더를 통해 인증 정보를 전달한 다음, 정의해 둔 매개변수들을 함께 넘깁니다. 응답을 텍스트 객체로 변수 obj에 저장한 뒤 이를 출력하여, 방금 보낸 요청의 결과를 확인할 수 있습니다.

```r
response <-
  httr::GET(url = url_handle,
    httr::add_headers(.headers = headers),
    query = params)
obj <- httr::content(response, as = "text")
print(obj)
```

<div id="working-with-our-json-payload">
  ### JSON 페이로드 다루기
</div>

제가 JSON으로 작업할 때 가장 선호하는 방법 중 하나는 데이터 프레임(data frame)을 활용하는 것입니다. 데이터 프레임을 사용하면 복잡하게 중첩된 data에 쉽게 접근할 수 있습니다. 이를 위해 jsonlite 패키지의 fromJSON 함수로 파일을 평탄화하여 필드가 동일한 객체 안에 있도록 만듭니다. 그런 다음 그 객체를 데이터 프레임으로 전달합니다. 이제 이 데이터 프레임을 확인할 준비가 되었습니다.

```
json_data <- fromJSON(obj, flatten = TRUE) %>% as.data.frame View(json_data)
```

데이터 프레임에서 data의 필드를 가져와 핸들, 사용자 이름, 소개(bio)를 포함하는 문자열로 만들 수 있습니다.

```r
final <-
  sprintf(
    "핸들: %s\n소개: %s\n고정된 게시물: %s",
    json_data$data.username,
    json_data$data.description,
    json_data$includes.tweets.text
  )
```

가져오는 각 필드를 줄바꿈으로 구분해 객체를 확인하려면 `print` 대신 `cat`을 사용하세요.

```r
cat(final)
```

여러 개의 핸들에 대해 요청을 보냈다면, 루프를 사용해 각 데이터 프레임 요소에 손쉽게 접근할 수 있습니다.
