<div id="introduction">
  ## 소개
</div>

v2에서 제공되는 [Search Posts endpoints](/ko/x-api/posts/search/introduction)를 사용하면,
여러분이 작성한 검색 쿼리를 기반으로 관심 있는 주제와 관련된 포스트를
조회할 수 있습니다. v2 Search Posts에는 서로 다른 두 가지 엔드포인트가
제공됩니다. 하나는 승인된 계정을 가진 모든 개발자가 사용할 수 있으며 최대 7일 전까지의
포스트를 검색할 수 있는 recent search이고, 다른 하나는
[Academic Research product track](https://developer.x.com/en/products/x-api/early-access/guide#na_2)에
승인된 연구자만 사용할 수 있는 full-archive search로,
2006년 3월까지 거슬러 올라가는 전체 포스트 아카이브를 검색할 수 있습니다.

전체 검색 기능은
[search overview page](/ko/x-api/posts/search/introduction)에서 확인할 수 있습니다.

이 Search Posts 엔드포인트는 학계 연구자들의 가장 일반적인 사용 사례 중
하나를 다룹니다. 예를 들어, 종단 연구를 수행하거나 과거의 특정 주제나
이벤트를 분석하는 데 사용할 수 있습니다.

이 튜토리얼은 공개 X 데이터의 전체 이력을 검색하기 위해 full-archive search 엔드포인트를 사용하려는
연구자를 위한 단계별 가이드를 제공합니다. 또한, 위치 정보가 포함된 포스트를
가져오는 것과 같이 데이터셋을 구축하는 다양한 방법과,
하나의 쿼리에 대해 사용 가능한 포스트를 페이지를 넘기며 조회하는 방법을
보여줍니다.

<div id="prerequisites">
  ### 사전 요구 사항
</div>

현재 이 엔드포인트는
[Academic Research 제품 트랙](https://developer.x.com/en/solutions/academic-research/products-for-researchers)의 일부로만 제공됩니다.
이 엔드포인트를 사용하려면
[사용 권한을 신청](https://developer.x.com/en/portal/petition/academic/is-it-right-for-you)해야 합니다.
이 트랙에 대한
[신청 절차 및 요구 사항](https://developer.x.com/en/solutions/academic-research/application-info)에 대해 자세히 알아보세요.

**주의 사항**

위 스크린샷의 키 값은 숨겨져 있지만, 실제 Developer Console에서는
API Key, API Secret Key, Bearer Token의 실제 값을 확인할 수 있습니다.
이 키들과 Bearer Token은 full-archive search 엔드포인트를 호출할 때 필요하므로
반드시 안전한 곳에 보관해 두십시오.

<div id="connecting-to-the-full-archive-search-endpoint">
  ### 전체 아카이브 검색 엔드포인트에 연결하기
</div>

아래 cURL 명령어는 @XDevelopers 계정에서 과거 포스트를 가져오는 방법을 보여줍니다.
$BEARER&#95;TOKEN을 자신의 Bearer Token으로 바꾼 뒤, 전체 요청을 터미널에 붙여넣고 &quot;return&quot; 키를 누르세요.

```bash
curl --request GET 'https://api.x.com/2/tweets/search/all?query=from:xdevelopers' --header 'Authorization: Bearer $BEARER_TOKEN'
```

응답 JSON이 표시됩니다.

기본적으로 가장 최근 포스트 10개만 반환됩니다. 한 요청당 10개보다
많은 포스트를 받으려면 아래와 같이 max&#95;results 매개변수를 사용하여
요청당 최대 500개의 포스트까지 설정할 수 있습니다:

```bash
curl --request GET 'https://api.x.com/2/tweets/search/all?query=from:xdevelopers&max_results=500' --header 'Authorization: Bearer $BEARER_TOKEN'
```

###

쿼리 작성

위의 예시 호출에서 볼 수 있듯이, `query` 파라미터를 사용하면
검색하려는 data를 지정할 수 있습니다. 예를 들어 *covid* 또는 *coronavirus*라는
단어를 포함하는 모든 포스트를 가져오고 싶다면,
괄호 안에서 OR 연산자를 사용해 쿼리를
`(covid OR coronavirus)`와 같이 구성할 수 있고, 그러면 API 호출은 다음과 같이
표현됩니다:

```bash
curl --request GET 'https://api.x.com/2/tweets/search/all?query=(covid%20OR%20coronavirus)&max_results=500' --header 'Authorization: Bearer $BEARER_TOKEN'
```

마찬가지로 리포스트가 아닌 *covid19*라는 단어를 포함하는 모든 포스트를
가져오려면, 논리 NOT(하이픈 -으로 표현됨)과 함께 is:retweet 연산자를 사용할 수
있습니다. 따라서 쿼리는 covid19 -is:retweet가 되고, API 호출은 다음과 같습니다:

```bash
curl --request GET 'https://api.x.com/2/tweets/search/all?query=covid19%20-is:retweet&max_results=500' --header 'Authorization: Bearer $BEARER_TOKEN'
```

전체 보관 검색 엔드포인트에서 지원되는 연산자 전체 목록은
[이 가이드](/ko/x-api/posts/search/integrate/build-a-query)에서 확인하세요.

<div id="using-the-start_time-and-end_time-parameters-to-get-historical-posts">
  ### start_time 및 end_time 파라미터를 사용하여 과거 포스트 가져오기
</div>

전체 아카이브 검색 엔드포인트를 사용할 때, 기본적으로 최근 30일 동안의
포스트가 반환됩니다. 30일보다 더 오래된 포스트를 가져오려면
API 호출에서 start&#95;time 및 end&#95;time 파라미터를 사용할 수 있습니다. 이들
파라미터는 예를 들어 2020-12-21T13:00:00.00Z와 같은 유효한 RFC3339 날짜-시간
형식이어야 합니다. 따라서 2020년 12월 한 달 동안 XDevelopers
계정의 모든 포스트를 가져오려면 API 호출은 다음과 같습니다:

```bash
curl --request GET 'https://api.x.com/2/tweets/search/all?query=from:XDevelopers&start_time=2020-12-01T00:00:00.00Z&end_time=2021-01-01T00:00:00.00Z' --header 'Authorization: Bearer $BEARER_TOKEN'
```

###

지오태그된 과거 포스트 가져오기

지오태그된 포스트는 도시, 주, 국가 등과 같은 지리 정보가 연관된 포스트를 의미합니다.

<div id="using-hasgeo-operator">
  #### has:geo 연산자 사용하기
</div>

지리 정보가 포함된 포스트를 가져오려면 `has:geo` 연산자를 사용할 수 있습니다.
예를 들어, 다음 cURL 요청은 @XDevelopers 핸들에서 지리 정보가 포함된 포스트만 가져옵니다:

```
curl --request GET
'https://api.x.com/2/tweets/search/all?query=from:xdevelopers%20has:geo' --header
'Authorization: Bearer $BEARER_TOKEN'
```

<div id="using-place_country-operator">
  #### place_country 연산자 사용
</div>

마찬가지로 place&#95;country 연산자를 사용하여 지리 정보(geo data)가 포함된 포스트를 특정 국가로 제한할 수 있습니다. 아래 cURL 명령어는 미국에서 작성된 @XDevelopers 계정의 모든 포스트를 가져옵니다.

```
curl --request GET
'https://api.x.com/2/tweets/search/all?query=from:xdevelopers%20place_country:US'
--hbasheader 'Authorization: Bearer XXXXX'
```

국가는 위에서 ISO 알파-2 문자 코드를 사용해 지정합니다. 사용 가능한 ISO 코드는 [여기](http://en.wikipedia.org/wiki/ISO_3166-1_alpha-2)에서 확인할 수 있습니다.

<div id="getting-more-than-500-historical-posts-using-the-next_token">
  ### next_token을 사용하여 500개보다 많은 과거 포스트 가져오기
</div>

위에서 언급했듯이, 기본적으로 전체 아카이브 검색 엔드포인트에 대한 쿼리에서는
요청당 최대 500개의 포스트만 가져올 수 있습니다. 해당 쿼리로 가져올 수 있는
포스트가 500개를 초과하는 경우, JSON 응답에 next&#95;token이 포함되며, 이를
API 호출에 추가하여 이 쿼리에 대한 다음 포스트를 가져올 수 있습니다.
이 next&#95;token은 JSON 응답의 메타 객체에 포함되어 있으며,
대략 다음과 같은 형태입니다:

```
{ "newest_id": "12345678...", "oldest_id": "12345678...", "result_count": 500,
"nebashxt_token": "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX" }
```

따라서 다음으로 조회 가능한 포스트를 가져오려면 이 메타 객체에 있는 next&#95;token 값을 가져와, 아래 예시와 같이 전체 아카이브 검색 엔드포인트에 대한 API 호출에서 next&#95;token 값으로 사용하십시오(이때 Bearer Token과 이전 API 호출에서 받은 Next Token 값은 본인의 것을 사용해야 합니다).

```
curl --request GET
'https://api.x.com/2/tweets/search/all?max_results=500&query=covid&next_token=XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX'
--header 'Authorization: Bearer $BEARER_TOKEN'
```

이렇게 하면 next&#95;token이 사용 가능한지 계속 확인할 수 있고, 수집하려는 포스트 수에 아직 도달하지 않았다면 각 요청마다 새로운 next&#95;token을 사용해 전체 아카이브 엔드포인트를 계속 호출할 수 있습니다.

아래는 전체 아카이브 검색 엔드포인트를 사용할 때 도움이 될 수 있는 자료들입니다. 여러분의 의견을 듣고 싶습니다. 이 엔드포인트에 대한 질문이 있으면
[@XDevelopers](https://x.com/XDevelopers) 또는
[커뮤니티 포럼](https://devcommunity.x.com/)으로 문의해 주세요.
