  ## 재미로 무언가를 만들어 볼 새로운 방법을 탐색하세요
</div>

<CardGroup>
<Card title="아트를 만들어 보세요">
  창의적인 에너지를 전 세계와 공유하세요. 즐거움을 주고 대화를 이끌어내는 인터랙티브한 경험을 만들어 보세요.
</Card>

<Card title="하드웨어나 기기를 연결하세요">
  물이 필요할 때 포스트를 올리는 식물? 초인종을 누르면 벨 대신 DM을 보내는 도어벨? 이런 것들은 개발자들이 X를 사물인터넷(IoT)에
  연결하기 위해 만든 재미있는 것들 중 일부에 불과합니다.
</Card>

<Card title="API를 탐색하세요">
  전 세계에서 오가는 대화의 구석구석을 탐색해 새로운 것을 배우고,
  아이디어를 얻고, 시야를 넓혀 보세요.
</Card>

<Card title="X 계정을 관리하거나 자동화하세요">
  몇 줄의 코드만으로 포스트를 예약하고, 타임라인과 소통하며,
  새로운 연결을 만들어 보세요.
</Card>

<Card title="X의 특별함을 지켜 주세요">
  있는 그대로의 자신으로 있으세요, 독특할수록 좋습니다. 그게 바로 X입니다.
</Card>
