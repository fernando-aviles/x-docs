<div id="educators">
  ## 교육자
</div>

프로그래밍 기초와 유용한 데이터 처리 기술을 가르치기 위해 수업에 API를 활용해 보세요.

**자료:**

강의에서 X API를 사용하고 싶은 교육자이신가요? 이
[X API로 수업하기 가이드](https://dev.to/suhemparack/a-guide-to-teaching-with-the-twitter-api-v2-3n08)는
X API를 이해하고, 교육자들이 왜 X API를 사용하는지, 어떤 종류의
수업이 API를 활용해 진행되고 있는지, 그리고 시작하는 데 알아야 할 모든 내용을 파악하는 데
도움이 될 것입니다.

**주요 사례:**

아래 교과 과정은 X API v2를 활용해 설계 및 운영되고 있습니다:

- Dr. Tanu Mitra의
  [Social Media Data Mining and Analysis](https://canvas.uw.edu/courses/1434897)

- Dr. Chris Bail의 [Data Science & Society](https://dssoc.github.io/)

- Dr. Melanie Walsh의
  [Introduction to Cultural Analytics & Python](https://melaniewalsh.github.io/Intro-Cultural-Analytics/welcome.html)

- Dr. Chris Barrie의
  [Oxford Spring School in Advanced Research Methods, Analysing X Data](https://github.com/cjbarrie/oxspsch)
