아래 표는 X API v2 엔드포인트를 해당하는 표준 v1.1 및 엔터프라이즈 엔드포인트와 매핑한 것입니다. 각 버전과 티어에 대해 더 알아보려면 [X API 시작 가이드](/ko/x-api/getting-started/about-x-api)를 방문하세요.

여전히 여러 항목이 **[Coming Soon]**으로 표시되어 있는 것을 확인하실 수 있습니다. 이 표에서 **[Replacement Under Consideration]** 또는 **[No Replacement Planned]**로 표시된 항목 중 v2 버전의 엔드포인트가 제공되기를 원하는 것이 있다면, [커뮤니티 포럼](https://devcommunity.x.com/)이나 엔터프라이즈 계정 매니저를 통해 알려 주세요.
