Communities 조회 엔드포인트를 사용하면 X Communities 커뮤니티의 id를 기준으로 정보를 조회할 수 있습니다.

<div id="overview">
  ## 개요
</div>

커뮤니티는 구성원들이 포스트를 공유하고, 주제를 토론하며, 공통 관심사를 중심으로 소통할 수 있는 X의 공개 또는 비공개 그룹입니다.

<div id="endpoint">
  ## Endpoint
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/communities/:id`](/ko/x-api/communities/get-community-by-id) | ID로 커뮤니티 조회 |

***

<div id="response-fields">
  ## 응답 필드
</div>

| 필드 | 설명 |
|:------|:------------|
| `id` | 커뮤니티 ID |
| `name` | 커뮤니티 이름 |
| `description` | 커뮤니티 설명 |
| `created_at` | 생성 일시 |
| `member_count` | 구성원 수 |
| `is_private` | 커뮤니티가 비공개인지 여부 |

***

<div id="example-request">
  ## 예시 요청
</div>

```bash
curl "https://api.x.com/2/communities/1234567890?\
community.fields=name,description,member_count,created_at" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
