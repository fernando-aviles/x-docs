Communities 검색 엔드포인트를 사용하면 키워드로 Communities를 검색할 수 있습니다. 관심 있는 주제와 관련된 Communities를 찾아볼 수 있습니다.

<div id="endpoint">
  ## 엔드포인트
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/communities/search`](/ko/x-api/communities/search-communities) | 커뮤니티 검색 |

***

<div id="parameters">
  ## 매개변수
</div>

| 매개변수 | 설명 |
|:----------|:------------|
| `query` | 검색 쿼리 (필수) |
| `max_results` | 페이지당 결과 개수 (최대 100) |
| `community.fields` | 추가 Community 필드 |
----------------------------------------

<div id="getting-started">
  ## 예제 요청
</div>

```bash
curl "https://api.x.com/2/communities/search?\
query=Python&\
max_results=10&\
community.fields=name,description,member_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
