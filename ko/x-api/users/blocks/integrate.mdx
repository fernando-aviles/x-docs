이 가이드는 애플리케이션에 blocks 엔드포인트를 통합하는 데 필요한 핵심 개념을 설명합니다.

***

<div id="authentication">
  ## 인증
</div>

Blocks 엔드포인트는 사용자 인증이 필요합니다.

| Method | Description |
|:-------|:------------|
| [OAuth 2.0 Authorization Code with PKCE](/ko/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | 신규 애플리케이션에 권장됩니다 |
| [OAuth 1.0a User Context](/ko/resources/fundamentals/authentication) | 레거시 지원 |

<Warning>
  App-Only 인증은 지원되지 않습니다. 반드시 사용자를 대신하여 인증해야 합니다.
</Warning>

<div id="required-scopes-oauth-20">
  ### 필수 스코프 (OAuth 2.0)
</div>

| Scope | 필수 대상 |
|:------|:-------------|
| `block.read` | 차단된 계정 조회 |
| `block.write` | 계정 차단 및 차단 해제 |
| `users.read` | `block` 스코프와 함께 필수 |

<div id="what-happens-when-you-block">
  ## 차단하면 어떻게 되나요
</div>

<CardGroup cols={2}>
  <Card title="상대방이 할 수 없는 것" icon="xmark">
    * 로그아웃한 상태인 경우를 제외하고 내 포스트를 볼 수 없음
    * 나를 팔로우할 수 없음
    * 나에게 DM을 보낼 수 없음
    * 나를 리스트에 추가할 수 없음
    * 사진에서 나를 태그할 수 없음
  </Card>

  <Card title="내가 할 수 없는 것" icon="xmark">
    * 상대방의 포스트를 볼 수 없음
    * 상대방을 팔로우할 수 없음
    * 상대방에게 DM을 보낼 수 없음
  </Card>
</CardGroup>

<Note>
  나를 팔로우 중인 계정을 차단하면, 해당 계정은 자동으로 나를 언팔로우합니다.
</Note>

<div id="pagination">
  ## 페이지네이션
</div>

차단 목록이 많은 사용자의 경우, 결과가 페이지 단위로 나누어 반환됩니다:

<CodeGroup dropdown>
  ```bash cURL
  # 첫 번째 요청
  curl "https://api.x.com/2/users/123/blocking?max_results=100" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"

  # 페이지네이션 토큰을 사용한 이후 요청
  curl "https://api.x.com/2/users/123/blocking?max_results=100&pagination_token=NEXT_TOKEN" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  # OAuth 2.0 사용자 액세스 토큰 사용
  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # SDK가 페이지네이션을 자동으로 처리합니다
  all_blocked = []

  for page in client.users.get_blocking(user_id="123", max_results=100):
      if page.data:
          all_blocked.extend(page.data)

  print(f"Blocked {len(all_blocked)} users")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  async function getAllBlockedUsers(userId) {
    const allBlocked = [];

    // SDK가 페이지네이션을 자동으로 처리합니다
    const paginator = client.users.getBlocking(userId, { maxResults: 100 });

    for await (const page of paginator) {
      if (page.data) {
        allBlocked.push(...page.data);
      }
    }

    return allBlocked;
  }

  // 사용 예시
  const blocked = await getAllBlockedUsers("123");
  console.log(`Blocked ${blocked.length} users`);
  ```
</CodeGroup>

<div id="error-handling">
  ## 오류 처리
</div>

| Status | Error | Solution |
|:-------|:------|:---------|
| 400 | 잘못된 요청 | 사용자 id 형식을 확인하세요 |
| 401 | 인증 실패 | 액세스 토큰을 확인하세요 |
| 403 | 권한 없음 | 스코프와 권한을 확인하세요 |
| 404 | 찾을 수 없음 | 해당 사용자가 존재하지 않습니다 |
| 429 | 너무 많은 요청 | 기다렸다가 다시 시도하세요 |
