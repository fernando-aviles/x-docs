Mutes 엔드포인트를 사용하면 사용자를 뮤트하거나 뮤트 해제하고, 인증된 사용자가 뮤트한 사용자 리스트를 조회할 수 있습니다.

<div id="endpoints">
  ## 엔드포인트
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/muting`](/ko/x-api/users/get-muting) | 음소거된 사용자 가져오기 |
| POST | [`/2/users/:id/muting`](/ko/x-api/users/mute-user) | 사용자 음소거하기 |
| DELETE | [`/2/users/:source_user_id/muting/:target_user_id`](/ko/x-api/users/unmute-user) | 사용자 음소거 해제하기 |

***

<div id="example-get-muted-users">
  ## 예시: 뮤트한 사용자 조회
</div>

```bash
curl "https://api.x.com/2/users/123456789/muting?\
user.fields=username,description" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-mute-a-user">
  ## 예: 사용자 뮤트하기
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/muting" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"target_user_id": "9876543210"}'
```
