  ## X API의 사용자 조회 엔드포인트 비교
</div>

v2 사용자 조회 엔드포인트는 기존 표준 v1.1 [GET users/lookup](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-lookup.html) 및 [GET users/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/follow-search-get-users/api-reference/get-users-show.html) 엔드포인트를 대체합니다. 이러한 버전의 사용자 조회 엔드포인트를 사용하는 코드, 앱 또는 도구가 있고 최신 X API v2 엔드포인트로 마이그레이션을 고려 중이라면, 이 가이드 모음이 여러분을 위한 것입니다. 
 

다음 표는 다양한 유형의 사용자 조회 엔드포인트를 비교합니다.
 

|     |     |     |
| :--- | :--- | :--- |
| **설명** | **표준 v1.1** | **X API v2** |
| 지원되는 HTTP 메서드 | `GET` | `GET` |
| 호스트 도메인 | `https://api.x.com` | `https://api.x.com` |
| 엔드포인트 경로 | `/1.1/users/show.json` `/1.1/users/lookup.json` | `/2/users`<br /><br />`/2/users/:id`<br /><br />`/2/users/by`<br /><br />`/2/users/by/:username` |
| [Authentication](/ko/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context<br /><br />App only(앱 전용)<br /><br />OAuth 2.0 Authorization Code with PKCE |
| 기본 요청 [rate limits](/ko/resources/fundamentals/rate-limits) | 15분당 900개 요청(사용자당)<br /><br />/show - 15분당 900개 요청(App당)  <br />/lookup - 15분당 300개 요청(App당) | 15분당 900개 요청(사용자당)<br /><br />15분당 300개 요청(App당) |
| 응답당 최대 사용자 수 | /show -  1<br /><br />/lookup - 100 | 100 |
| JSON 응답 객체 형식 | 표준 v1.1 형식 | [X API v2 형식](/ko/x-api/fundamentals/data-dictionary) (fields 및 expansions 요청 매개변수에 의해 결정되며, v1.1 형식과 하위 호환되지 않음)<br /><br />표준 v1.1 형식에서 X API v2 형식으로 마이그레이션하는 방법에 대해 자세히 알아보려면 [data formats migration guide](/ko/x-api/migrate/data-format-migration)를 참조하세요. |
| 페이로드에서 어떤 [fields](/ko/x-api/fundamentals/data-dictionary)를 반환할지 선택 지원 |     | ✔   |
| [annotations](/ko/x-api/fundamentals/post-annotations) 필드 지원(상단 고정 포스트에 대해) |     | ✔   |
| 새로운 [metrics](/ko/x-api/fundamentals/metrics) 필드 요청 지원(상단 고정 포스트에 대해) |     | ✔   |
| [conversation&#95;id](/ko/x-api/fundamentals/conversation-id) 필드 지원(상단 고정 포스트에 대해) |     | ✔   |
| [developer App](/ko/resources/fundamentals/developer-apps)에 연결된 [project](/ko/resources/fundamentals/developer-apps)의 자격 증명 사용 필요 |     | ✔   |
