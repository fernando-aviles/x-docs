이 가이드는 `/me` 엔드포인트를 사용하여 현재 인증된 사용자의 프로필을 조회하는 방법을 설명합니다.

<Note>
  **사전 준비 사항**

  시작하기 전에 다음이 필요합니다.

  * 승인이 완료된 App이 포함된 [개발자 계정](https://developer.x.com/en/portal/petition/essential/basic-info)
  * 사용자 액세스 토큰(User Access Token) (OAuth 1.0a 또는 OAuth 2.0 PKCE)
</Note>

<div id="get-the-authenticated-user">
  ## 인증된 사용자 가져오기
</div>

User Access Token을 사용하여 `/me` 엔드포인트에 요청을 보내세요:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/me?\
  user.fields=created_at,description,verified,public_metrics,profile_image_url" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 인증된 사용자 가져오기
  response = client.users.get_me(
      user_fields=["created_at", "description", "verified", "public_metrics", "profile_image_url"]
  )

  print(f"Username: {response.data.username}")
  print(f"ID: {response.data.id}")
  print(f"Followers: {response.data.public_metrics.followers_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 인증된 사용자 가져오기
  const response = await client.users.getMe({
    userFields: ["created_at", "description", "verified", "public_metrics", "profile_image_url"],
  });

  console.log(`Username: ${response.data?.username}`);
  console.log(`ID: ${response.data?.id}`);
  console.log(`Followers: ${response.data?.public_metrics?.followers_count}`);
  ```
</CodeGroup>

<div id="use-case">
  ## 사용 사례
</div>

`/me` 엔드포인트는 다음과 같은 경우에 필수적입니다:

* **인증 검증** — 사용자가 제대로 인증되었는지 확인
* **사용자 ID 가져오기** — 다른 API 호출을 위해 인증된 사용자의 ID 조회
* **경험 개인화** — 앱에서 사용자의 프로필 표시
* **대리 요청** — 누구를 대신해 요청을 보내는지 파악

<div id="include-pinned-post">
  ## 고정된 포스트 포함
</div>

사용자의 고정된 포스트를 요청하려면:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/me?\
  user.fields=pinned_tweet_id&\
  expansions=pinned_tweet_id&\
  tweet.fields=created_at,text" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 고정된 포스트를 포함한 인증된 사용자 가져오기
  response = client.users.get_me(
      user_fields=["pinned_tweet_id"],
      expansions=["pinned_tweet_id"],
      tweet_fields=["created_at", "text"]
  )

  print(f"Username: {response.data.username}")
  # 고정된 포스트는 response.includes.tweets에 포함되어 있습니다
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 고정된 포스트를 포함한 인증된 사용자 가져오기
  const response = await client.users.getMe({
    userFields: ["pinned_tweet_id"],
    expansions: ["pinned_tweet_id"],
    tweetFields: ["created_at", "text"],
  });

  console.log(`Username: ${response.data?.username}`);
  // 고정된 포스트는 response.includes?.tweets에 포함되어 있습니다
  ```
</CodeGroup>

<div id="available-fields">
  ## 사용 가능한 필드
</div>

| Field | Description |
|:------|:------------|
| `created_at` | 계정 생성 일시 |
| `description` | 사용자 소개 |
| `profile_image_url` | 프로필 이미지 URL |
| `verified` | 인증 상태 |
| `public_metrics` | 팔로워/팔로잉 수 |
| `location` | 사용자가 설정한 위치 |
| `url` | 사용자의 웹사이트 |
| `protected` | 비공개 계정 상태 |
| `pinned_tweet_id` | 고정된 포스트 ID |

<div id="authentication-requirement">
  ## 인증 요구 사항
</div>

<Warning>
  `/me` 엔드포인트는 User Context 인증이 필요합니다. App-Only (Bearer Token) 인증은 지원되지 않습니다.
</Warning>

다음 중 하나를 사용해야 합니다:

* [OAuth 1.0a User Context](/ko/resources/fundamentals/authentication)
* [OAuth 2.0 Authorization Code with PKCE](/ko/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)
