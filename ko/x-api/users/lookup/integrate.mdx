이 가이드는 애플리케이션에 User lookup 엔드포인트를 통합하는 데 필요한 핵심 개념을 설명합니다.

<div id="authentication">
  ## 인증
</div>

모든 X API v2 엔드포인트는 인증이 필요합니다. 사용 사례에 맞는 방식을 선택하세요:

| Method | 적합한 용도 | 비공개 메트릭에 접근 가능 여부 |
|:-------|:---------|:---------------------------|
| [OAuth 2.0 App-Only](/ko/resources/fundamentals/authentication#oauth-2-0) | 서버 간 통신, 공개 데이터 | 아니요 |
| [OAuth 2.0 Authorization Code with PKCE](/ko/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2) | 사용자용 앱 | 예 (승인된 사용자의 데이터) |
| [OAuth 1.0a User Context](/ko/resources/fundamentals/authentication) | 레거시 연동 | 예 (승인된 사용자의 데이터) |

<div id="app-only-authentication">
  ### 앱 전용 인증
</div>

공개 사용자 데이터에는 Bearer Token을 사용하세요:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/by/username/XDevelopers" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # username으로 사용자 조회
  response = client.users.get_by_username("XDevelopers")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  const response = await client.users.getByUsername("XDevelopers");
  console.log(response.data);
  ```
</CodeGroup>

<div id="user-context-authentication">
  ### 사용자 컨텍스트 인증
</div>

인증된 사용자 엔드포인트(`/2/users/me`)를 호출하려면 필요합니다:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/me" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  # OAuth 2.0 사용자 액세스 토큰 사용
  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 인증된 사용자의 프로필 가져오기
  response = client.users.get_me()
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  // OAuth 2.0 사용자 액세스 토큰 사용
  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  const response = await client.users.getMe();
  console.log(response.data);
  ```
</CodeGroup>

<Warning>
  `/2/users/me` 엔드포인트는 사용자 컨텍스트 인증에서만 사용할 수 있습니다. App-only 토큰을 사용하면 오류가 반환됩니다.
</Warning>

<div id="fields-and-expansions">
  ## 필드와 expansions
</div>

X API v2는 기본적으로 최소한의 data만을 반환합니다. 필요한 정보를 정확히 요청하려면 `fields`와 `expansions`를 사용하세요.

<div id="default-response">
  ### 기본 응답
</div>

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "XDevelopers"
  }
}
```

<div id="available-fields">
  ### 사용 가능한 필드
</div>

<Accordion title="user.fields">
  | Field | Description |
  |:------|:------------|
  | `created_at` | 계정 생성 타임스탬프 |
  | `description` | 사용자 소개 |
  | `entities` | 소개란에서 추출된 URL |
  | `location` | 사용자가 지정한 위치 |
  | `pinned_tweet_id` | 고정된 포스트 ID |
  | `profile_image_url` | 프로필 이미지 URL |
  | `protected` | 계정 보호 여부 |
  | `public_metrics` | 팔로워/팔로잉 수 |
  | `url` | 웹사이트 URL |
  | `verified` | 인증 상태 |
  | `withheld` | 제한 관련 정보 |
</Accordion>

<Accordion title="tweet.fields (pinned_tweet_id 확장 필요)">
  | Field | Description |
  |:------|:------------|
  | `created_at` | 포스트 생성 타임스탬프 |
  | `text` | 포스트 내용 |
  | `public_metrics` | 참여 지표 |
  | `entities` | 해시태그, 멘션, URL |
</Accordion>

<div id="example-with-fields">
  ### 필드 사용 예시
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/by/username/XDevelopers?\
  user.fields=created_at,description,public_metrics,verified&\
  expansions=pinned_tweet_id&\
  tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 추가 필드와 expansions를 사용해 사용자 가져오기
  response = client.users.get_by_username(
      "XDevelopers",
      user_fields=["created_at", "description", "public_metrics", "verified"],
      expansions=["pinned_tweet_id"],
      tweet_fields=["created_at", "public_metrics"]
  )

  print(response.data)
  print(response.includes)  # 확장된 고정 트윗을 포함함
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  const response = await client.users.getByUsername("XDevelopers", {
    userFields: ["created_at", "description", "public_metrics", "verified"],
    expansions: ["pinned_tweet_id"],
    tweetFields: ["created_at", "public_metrics"],
  });

  console.log(response.data);
  console.log(response.includes); // 확장된 고정 트윗을 포함함
  ```
</CodeGroup>

<div id="batch-lookups">
  ## 배치 조회
</div>

단일 요청으로 여러 사용자를 조회할 수 있습니다:

<CodeGroup dropdown>
  ```bash cURL (ID로 조회)
  curl "https://api.x.com/2/users?ids=2244994945,783214,6253282&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```bash cURL (사용자 이름으로 조회)
  curl "https://api.x.com/2/users/by?usernames=XDevelopers,X,XAPI&\
  user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # ID로 여러 사용자 조회
  response = client.users.get_users(
      ids=["2244994945", "783214", "6253282"],
      user_fields=["username", "verified"]
  )
  for user in response.data:
      print(f"{user.username}: {user.verified}")

  # 사용자 이름으로 여러 사용자 조회
  response = client.users.get_users_by_usernames(
      usernames=["XDevelopers", "X", "XAPI"],
      user_fields=["username", "verified"]
  )
  for user in response.data:
      print(f"{user.username}: {user.verified}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // ID로 여러 사용자 조회
  const byIds = await client.users.getUsers({
    ids: ["2244994945", "783214", "6253282"],
    userFields: ["username", "verified"],
  });
  byIds.data.forEach((user) => {
    console.log(`${user.username}: ${user.verified}`);
  });

  // 사용자 이름으로 여러 사용자 조회
  const byUsernames = await client.users.getUsersByUsernames({
    usernames: ["XDevelopers", "X", "XAPI"],
    userFields: ["username", "verified"],
  });
  byUsernames.data.forEach((user) => {
    console.log(`${user.username}: ${user.verified}`);
  });
  ```
</CodeGroup>

<Tip>
  배치 요청은 최대 100명의 사용자로 제한됩니다. 더 큰 데이터 세트의 경우 여러 개의 요청으로 나누어 호출하세요.
</Tip>

<div id="error-handling">
  ## 오류 처리
</div>

<div id="common-errors">
  ### 일반적인 오류
</div>

| Status | 오류 | 해결 방법 |
|:-------|:------|:---------|
| 400 | 잘못된 요청 | 매개변수 형식을 확인하세요 |
| 401 | 인증 실패 | 인증 자격 증명을 확인하세요 |
| 403 | 허용되지 않음 | 앱 권한을 확인하세요 |
| 404 | 찾을 수 없음 | 사용자가 존재하지 않거나 정지된 상태입니다 |
| 429 | 요청이 너무 많음 | 잠시 기다린 후 다시 시도하세요 (레이트 리밋을 참조하세요) |

<div id="suspended-or-deleted-users">
  ### 정지되었거나 삭제된 사용자
</div>

사용자가 정지되었거나 삭제된 경우:

* 단일 사용자 조회 시 `404`를 반환합니다.
* 다중 사용자 조회 시 결과에서 해당 사용자는 제외되고, 관련 정보가 `errors` 배열에 포함됩니다.

```json
{
  "data": [
    { "id": "2244994945", "username": "XDevelopers" }
  ],
  "errors": [
    {
      "resource_id": "1234567890",
      "resource_type": "user",
      "title": "Not Found Error",
      "detail": "Could not find user with id: [1234567890]."
    }
  ]
}
```

<div id="protected-users">
  ### 보호된 사용자
</div>

팔로우하지 않는 보호된 계정의 경우:

* 기본 정보(id, 이름, username)는 확인할 수 있습니다
* 보호된 콘텐츠(고정된 포스트)는 제한될 수 있습니다
* `protected: true`는 계정 상태를 나타냅니다
