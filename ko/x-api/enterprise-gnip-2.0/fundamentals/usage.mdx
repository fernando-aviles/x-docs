  ## 사용량 API | Twitter API
</div>

<div id="overview">
  ### 개요
</div>

`Enterprise`

Usage API는 계정에서 사용하는 다양한 API 전반의 사용량을 모니터링하고 관리하는 데 도움이 되는 가장 중요하고 *최고의* 도구입니다.

**중요한 고지사항:**

Usage API에서 반환되는 사용량 수치는 평가판 및 기타 결제 조정으로 인해 청구서에 표시되는 수치와 일치하지 않을 수 있습니다. 모든 수치는 특정 하루(UTC 기준) 동안 소비된 활동에서 중복을 제거한 값에 기반합니다.

<div id="features">
  #### 기능
</div>

* console.gnip.com UI에서 확인할 수 있는 사용량 data를 프로그래밍 방식으로 가져오기
* 스트림 수준 사용량 data - 제품 수준에 더해 스트림 수준(예: dev 및 prod)의 사용량 data 제공
* 세분화되고 설명적인 data - 검색 &quot;요청(requests)&quot;이 Full-Archive 및 30-Day Search 제품별로 구분되어 제공됨
* Historical PowerTrack의 &quot;days&quot; 및 &quot;jobs&quot; 사용량 

<div id="supported-apis">
  ### 지원되는 API
</div>

아래는 현재 Usage API에서 지원하는 API 목록입니다.

* PowerTrack API `enterprise`
* 30-Day Search API `enterprise`
* Full-Archive Search API `enterprise`
* Historical PowerTrack `enterprise`

<div id="limitations">
  ### 제한 사항
</div>

* Usage API를 사용하면 2018년 5월 1일부터의 사용량 데이터를 조회할 수 있습니다. 2019년 7월 1일 이후에는 Usage API를 통해 **직전 13개월(달력 기준)** 의 사용량 데이터에 접근할 수 있습니다.

* fromDate와 toDate로 정의된 **3개월 단위**로 사용량 데이터에 접근할 수 있습니다.

<div id="methods">
  #### **Methods**
</div>

| Method | Description |
| :--- | :--- |
| [GET /metrics/usage/accounts/{ACCOUNT_NAME}.json](#GETData) | 사용량 data를 조회합니다 |

Where:

* :account&#95;name은(는) console.gnip.com에 표시되는, 계정과 연결된 (대소문자를 구분하는) 이름입니다.

<div id="authentication-and-rate-limit">
  #### **인증 및 요청 한도**
</div>

<div id="authentication">
  ##### **Authentication**
</div>

Usage API에 대한 모든 요청에는 HTTP 기본 인증이 필요하며, console.gnip.com에 로그인하거나 어떤 Gnip 스트림에 연결할 때 사용하는 계정의 활성화된 이메일/비밀번호 자격 증명 중 하나를 사용할 수 있습니다.

<div id="rate-limit">
  ##### **요청 제한**
</div>

Usage API에는 분당 2회 요청 제한이 적용됩니다.

<div id="best-practices-limitations">
  #### **모범 사례 및 제한 사항**
</div>

<div id="data-availability">
  ##### **데이터 가용성**
</div>

사용량 데이터는 data가 처리된 마지막 전체 기간(UTC) 동안 소비된 활동에서 중복을 제거한 결과를 기반으로 합니다. 일반적으로 data는 분 단위까지 실시간에 가깝게 처리 및 업데이트되지만, Gnip이 시스템을 배포하는 경우는 예외입니다.

* Usage API를 사용하면 2018년 5월 1일 이후의 사용량 데이터에 액세스할 수 있습니다. 2019년 7월 1일 이후에는 Usage API를 통해 **직전 13개월(달력 기준)** 동안의 사용량 데이터에 액세스할 수 있습니다.

* fromDate와 toDate로 정의된 **3개월 단위 구간**별로 사용량 데이터에 액세스할 수 있습니다.

<div id="requesting-and-receiving-data">
  #### **데이터 요청 및 수신**
</div>

Usage API는 HTTP Basic 인증 자격 증명을 사용해 계정의 API 엔드포인트로 HTTP GET 요청을 보내는 방식으로 동작합니다.

<div id="get-request">
  ##### GET Request:
</div>

사용자 자격 증명과 계정 name을 사용하여 다음 엔드포인트로 GET 요청을 보냅니다:

https://gnip-api.x.com/metrics/usage/accounts/:account&#95;name.json

**추가 매개변수**

|     |     |
| :--- | :--- |
| bucket | 선택 사항. 사용량 데이터가 제공될 시간 단위입니다. 사용량 데이터는 일 단위 또는 월 단위로 반환될 수 있습니다.  <br />  <br />bucket을 지정하지 않고 요청하면 월 단위로 반환됩니다.  <br />  <br />옵션: &#39;month&#39; 또는 &#39;day&#39; |
| fromDate (YYYYMMDDHHMM) | 선택 사항. 사용량 데이터는 2018년 5월 1일부터만 이용 가능합니다. 사용량 데이터가 제공될 수 있는 가장 오래된 UTC 타임스탬프입니다. 타임스탬프는 일 단위이며, 해당 날짜를 포함합니다(예: 201805010000에는 5월 1일 전체가 포함됩니다). 시와 분 값에 &#39;0000&#39; 이외의 값을 포함한 요청은 &#39;0000&#39;으로 처리됩니다.  <br />  <br />fromDate 또는 toDate 없이 요청하는 경우, 현재 월에 대한 사용량 데이터가 월 단위로 반환되며, 직전 두 달에 대한 이력 데이터가 함께 제공됩니다.  <br />  <br />**참고:** 2019년 6월 1일부터 지난 13개월(달력 기준)의 사용량 데이터에 접근할 수 있습니다. 예를 들어, 10월 10일이라면, 이전 해 9월 1일까지의 사용량 데이터에 접근할 수 있습니다.  <br />**예:** 201810010000은 2018년 10월 1일부터(10월 1일 포함) 시작하는 데이터를 반환합니다. |
| toDate (YYYYMMDDHHMM) | 선택 사항. 사용량 데이터가 제공될 최신 UTC 타임스탬프입니다. 타임스탬프는 일 단위이며, 해당 날짜는 포함되지 않습니다(예: 201703020000에는 3월 2일 데이터가 포함되지 않습니다). toDate가 오늘 또는 미래의 날짜로 지정된 경우, 사용량 데이터는 마지막으로 완료된 하루(UTC)까지 반환됩니다. 시와 분 값에 &#39;0000&#39; 이외의 값을 포함한 요청은 &#39;0000&#39;으로 처리됩니다.  <br />  <br />toDate 없이 요청하면, 다음 bucket으로 기본 설정됩니다(bucket=day인 경우 내일, bucket=month인 경우 다음 달). fromDate와 toDate를 모두 지정하지 않고 요청하는 경우 bucket=month로 기본 설정되며, 현재 월과 바로 이전 두 달에 대한 데이터를 표시합니다.  <br />  <br />**예:** 201703050000은 2017년 3월 5일까지의 데이터를 반환하되, 3월 5일의 어떠한 데이터도 포함하지 않습니다. |

**GET Request 예시**

이 요청은 2017년 3월 1일부터 2017년 3월 5일까지의 월 단위 데이터(3월 5일 데이터는 제외)를 반환합니다.

curl -u &quot;https://gnip-api.x.com/metrics/usage/accounts/:account&#95;name.json?bucket=month&amp;fromdate=201403010000&amp;toDate=201403150000&quot;

다음 표는 Usage API가 반환하는 사용량 data의 루트 수준 데이터 구조를 설명합니다. 필드에 여러 단계의 하위 필드가 있는 경우 제공된 링크를 클릭하여 하위 필드에 대한 세부 정보를 확인하세요.

전체 Usage API payload 예시를 보고 싶다면 [이 페이지](/ko/x-api/usage/introduction)를 방문하세요.

|     |     |
| :--- | :--- |
| **account** | 사용량 data가 요청된 account를 나타내는 객체입니다. |
| **bucket** | 사용량 data가 제공되는 시간 단위입니다. &#39;day&#39; 또는 &#39;month&#39;일 수 있습니다. |
| **fromDate** | 가져오려는 사용량 data의 가장 이른 UTC 타임스탬프입니다(포함). |
