<div id="overview">
  ## 개요
</div>

매일 수천 명이 넘는 개발자들이 X API에 요청을 보냅니다. 이렇게 방대한 양의 요청을 관리하기 위해, 수행할 수 있는 요청 수에는 제한이 설정되어 있습니다. 이러한 제한은 우리 개발자 커뮤니티가 의존하는 안정적이고 확장 가능한 API를 제공하는 데 도움이 됩니다. 

허용되는 최대 요청 수는 일정한 시간 간격, 즉 특정 기간 또는 시간 창(window)에 따라 결정됩니다. 예를 들어, 어떤 엔드포인트의 rate limit이 900 requests/15-minutes라면, 임의의 15분 구간 동안 최대 900개의 요청이 허용된다는 의미입니다.
