<div id="overview">
  ## 개요
</div>

매일 수많은 개발자들이 X API에 요청을 보냅니다. 이렇게 방대한 양의 요청을 관리하기 위해 일정 시간 동안 보낼 수 있는 요청 수에 한도(레이트 리밋)를 두고 있습니다. 이러한 한도는 개발자 커뮤니티가 의존하는 안정적이고 확장 가능한 API를 제공하는 데 도움이 됩니다. 

허용되는 최대 요청 수는 특정 시간 간격, 즉 일정 기간 또는 시간 윈도우를 기준으로 정해집니다. 예를 들어, 어떤 엔드포인트의 레이트 리밋이 15분당 900건의 요청이라면, 임의의 15분 간격 동안 최대 900건의 요청이 허용된다는 의미입니다.
