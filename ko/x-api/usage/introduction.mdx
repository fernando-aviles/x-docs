<div id="endpoint">
  ## 엔드포인트
</div>

| 메서드 | 엔드포인트 | 설명 |
|:-------|:---------|:------------|
| GET | [`/2/usage/tweets`](/ko/x-api/usage/get-usage) | 포스트 사용량 데이터를 가져옵니다 |

***

<div id="response-data">
  ## 응답 데이터
</div>

응답에는 일별 포스트 소비량 집계가 포함됩니다:

```json
{
  "data": {
    "daily_project_usage": [
      {
        "date": "2024-01-15",
        "usage": [
          {
            "app_id": "12345678",
            "tweets_consumed": 15420
          }
        ]
      }
    ],
    "project_id": "1234567890",
    "project_cap": 10000000
  }
}
```

<div id="fields">
  ### 필드
</div>

| 필드 | 설명 |
|:------|:------------|
| `daily_project_usage` | 일별 사용량 data 배열 |
| `date` | YYYY-MM-DD 형식의 날짜 |
| `app_id` | 앱의 id |
| `tweets_consumed` | 해당 날짜에 소비된 포스트 수 |
| `project_cap` | 월간 포스트 한도 |

***

<div id="example-request">
  ## 요청 예시
</div>

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="use-cases">
  ## 사용 사례
</div>

* **비용 모니터링** — 요금제 한도 대비 사용량을 추적합니다
* **알림** — 한도에 근접했을 때 알림을 설정합니다
* **최적화** — 사용량이 많은 엔드포인트를 파악합니다
* **보고** — 사용량 보고서를 생성합니다

<Tip>
  리소스는 UTC 기준 24시간 기간 내에서 중복이 제거되므로, 같은 리소스를 하루에 여러 번 요청해도 한 번만 요금이 청구됩니다. [요금에 대해 더 알아보기 →](/ko/x-api/getting-started/pricing)
</Tip>
