X는 X API로 서비스를 구축하는 개발자 커뮤니티를 지원하기 위해 최선을 다하고 있습니다. 이러한 약속의 일환으로, 우리는 API를 개발자에게 개방적이고 공정하게 제공하며, X 사용자에게는 안전하고 X 플랫폼 전체에도 이로운 방향으로 운영하고자 합니다. X 콘텐츠를 오프라인으로 저장하는 모든 개발자는 해당 데이터가 사용자 의도와 X 상의 콘텐츠 최신 상태를 반영하도록 하는 것이 매우 중요합니다. 예를 들어, X 사용자가 포스트나 계정을 삭제하거나, 포스트를 보호(비공개 전환)하거나, 포스트를 편집하는 경우, 그 사람의 기대와 의도를 X와 개발자 모두가 존중하는 것이 중요합니다.

실시간 컴플라이언스 이벤트 스트림은 개발자가 X 데이터를 [X Developer Agreement and Policy](https://developer.x.com/en/developer-terms/policy)를 준수하도록 유지하는 데 필요한 도구를 제공합니다. 

두 가지 c&#95;ompliance event&#95; 스트림이 있으며, 하나는 포스트&#95; 컴플라이언스&#95; 이벤트용이고, 다른 하나는 *사용자 컴플라이언스* 이벤트용입니다. 이 스트림은 Enterprise 액세스 권한에서 제공되며, 대량의 데이터를 수집하는 파트너가 포스트 편집 이벤트와 같은 컴플라이언스 이벤트를 &#39;수신&#39;할 수 있도록 설계되었습니다.

이 스트림은 다음과 같은 이벤트를 제공합니다: 

**Post compliance stream: **

* delete - 포스트가 삭제되었음을 나타냅니다.

* tweet&#95;edit - 포스트가 편집되었음을 나타내며, 업데이트된 포스트의 ID를 제공합니다. 

* withheld - 포스트가 하나 이상의 국가에서 보류(차단)되었음을 나타냅니다. 

* drop - 포스트를 공개 보기에서 제거해야 함을 나타냅니다.

* undrop - 포스트를 다시 표시하고 공개로 취급할 수 있음을 나타냅니다.

**User compliance stream: **

* **user&#95;delete** - 사용자 계정이 삭제되었음을 나타냅니다.

* **user&#95;undelete** - 사용자 계정 삭제가 취소되었음을 나타냅니다.

* **user&#95;protect** - 사용자 계정이 비공개로 전환되었음을 나타냅니다.

* **user&#95;unprotect** - 사용자 계정이 공개로 전환되었음을 나타냅니다.

* **user&#95;withheld** - 사용자 계정이 하나 이상의 국가에서 보류(차단)되었음을 나타냅니다. 

* **user&#95;suspend** - 사용자 계정이 정지되었음을 나타냅니다.

* **user&#95;unsuspend** - 사용자 계정 정지가 해제되었음을 나타냅니다.

* **user&#95;profile&#95;modification** - 사용자 프로필이 업데이트되었음을 나타냅니다. 여기에는 설명, 이름, 위치, URL 업데이트가 포함됩니다.

**계정 설정**

이 엔드포인트에 액세스하려면 다음이 필요합니다:

* 승인된 [developer account](https://developer.x.com/en/portal/petition/essential/basic-info)
