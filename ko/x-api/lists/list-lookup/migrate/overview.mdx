  ## X API의 List 조회 엔드포인트 비교
</div>

v2 List 조회 엔드포인트 그룹은 기존 v1.1의 표준 [GET lists/show](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-show)와 [GET lists/ownership](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/get-lists-ownerships) 엔드포인트를 대체합니다. 이러한 버전의 List 조회 엔드포인트를 사용하는 코드, 앱 또는 도구를 보유하고 있고 최신 X API v2 엔드포인트로 마이그레이션을 고려 중이라면, 이 가이드 모음은 여러분을 위한 것입니다.

아래 표는 표준 v1.1과 X API v2 List 엔드포인트를 비교한 것입니다.

**ID로 List 조회**

|     |     |     |
| :--- | :--- | :--- |
| 설명 | 표준 v1.1 | X API v2 |
| 지원되는 HTTP 메서드 | `GET` | `GET` |
| 호스트 도메인 | `https://api.x.com` | `https://api.x.com` |
| 엔드포인트 경로 | `/1.1/lists/show.json` | `/2/lists/:id` |
| [인증](/ko/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App only | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />App only |
| 기본 요청 [요청 한도](/ko/resources/fundamentals/rate-limits) | OAuth 1.0a 사용 시 15분당 75회 요청<br /><br />OAuth 2.0 사용 시 15분당 75회 요청<br /><br />App only 사용 시 15분당 75회 요청 | OAuth 1.0a 사용 시 15분당 75회 요청<br /><br />OAuth 2.0 사용 시 15분당 75회 요청<br /><br />App only 사용 시 15분당 75회 요청 |

**사용자 소유 List 조회**

|     |     |     |
| :--- | :--- | :--- |
| 설명 | 표준 v1.1 | X API v2 |
| 지원되는 HTTP 메서드 | `GET` | `GET` |
| 호스트 도메인 | `https://api.x.com` | `https://api.x.com` |
| 엔드포인트 경로 | `/1.1/lists/ownerships.json` | `/2/users/:id/owned_lists` |
| [인증](/ko/resources/fundamentals/authentication) | OAuth 1.0a User Context<br /><br />App only | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />App only |
| 기본 요청 [요청 한도](/ko/resources/fundamentals/rate-limits) | OAuth 1.0a 사용 시 15분당 15회 요청<br /><br />App only 사용 시 15분당 15회 요청 | OAuth 1.0a 사용 시 15분당 15회 요청<br /><br />OAuth 2.0 사용 시 15분당 15회 요청<br /><br />App only 사용 시 15분당 15회 요청 |

X API v2 엔드포인트에 액세스하려면 [개발자 계정에 가입](https://developer.x.com/en/portal/petition/essential/basic-info)해야 합니다. 인증 시에는 [개발자 App](/ko/resources/fundamentals/developer-apps)이 위치한 [Project](/ko/resources/fundamentals/developer-apps)에서 발급된 키와 토큰을 사용해야 합니다. 

X API v2 엔드포인트에 대한 액세스 권한을 얻는 방법은 [시작하기](/ko/x-api/getting-started/getting-access) 페이지에서 자세히 알아보세요.
