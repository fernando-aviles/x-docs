<div id="comparing-x-apis-lists-endpoints">
  ## X API의 Lists 엔드포인트 비교
</div>

v2 List 관리 엔드포인트는 결국 [POST lists/create](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-create), [POST lists/destroy](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-destroy), [POST lists/update](https://developer.x.com/en/docs/twitter-api/v1/accounts-and-users/create-manage-lists/api-reference/post-lists-update)를 대체합니다. 기존 버전의 이러한 엔드포인트를 사용하는 코드, 앱 또는 도구가 있고 최신 X API v2로 마이그레이션을 고려하고 있다면 이 가이드를 참고하십시오.

다음 표는 표준 v1.1과 X API v2의 List 엔드포인트를 비교한 것입니다.

**List 생성**

| 설명 | 표준 v1.1 | X API v2 |
| :--- | :--- | :--- |
| 지원 HTTP 메서드 | POST | POST |
| 호스트 도메인 | https://api.x.com | https://api.x.com |
| 엔드포인트 경로 | /1.1/lists/create.json | /2/lists |
| [인증](/ko/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| 기본 요청 [레이트 리밋](/ko/resources/fundamentals/rate-limits) | 없음 | 15분당 300회 요청(사용자 기준) |

**List 삭제**

| 설명 | 표준 v1.1 | X API v2 |
| :--- | :--- | :--- |
| 지원 HTTP 메서드 | POST | DELETE |
| 호스트 도메인 | https://api.x.com | https://api.x.com |
| 엔드포인트 경로 | /1.1/lists/destroy.json | /2/lists/:id |
| [인증](/ko/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| 기본 요청 [레이트 리밋](/ko/resources/fundamentals/rate-limits) | 없음 | 15분당 300회 요청(사용자 기준) |

**List 업데이트**

| 설명 | 표준 v1.1 | X API v2 |
| :--- | :--- | :--- |
| 지원 HTTP 메서드 | POST | PUT |
| 호스트 도메인 | https://api.x.com | https://api.x.com |
| 엔드포인트 경로 | /1.1/lists/update.json | /2/lists/:id |
| [인증](/ko/resources/fundamentals/authentication) | OAuth 1.0a User Context | OAuth 1.0a User Context |
| 기본 요청 [레이트 리밋](/ko/resources/fundamentals/rate-limits) | 없음 | 15분당 300회 요청(사용자 기준) |

X API v2 엔드포인트를 사용하려면 [개발자 계정에 가입](https://developer.x.com/en/portal/petition/essential/basic-info)해야 합니다. 인증 시에는 [developer App](/ko/resources/fundamentals/developer-apps)이 소속된 [Project](/ko/resources/fundamentals/developer-apps)에서 발급한 키와 토큰을 사용해야 합니다.

X API v2 엔드포인트에 대한 액세스 권한을 얻는 방법은 [시작하기](/ko/x-api/getting-started/getting-access) 페이지에서 자세히 알아보세요.
