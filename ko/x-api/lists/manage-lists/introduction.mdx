<div id="endpoints">
  ## 엔드포인트
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| POST | [`/2/lists`](/ko/x-api/lists/create-list) | 새 리스트 생성 |
| PUT | [`/2/lists/:id`](/ko/x-api/lists/update-list) | 리스트 수정 |
| DELETE | [`/2/lists/:id`](/ko/x-api/lists/delete-list) | 리스트 삭제 |

***

<div id="example-create-a-list">
  ## 예제: 리스트 생성
</div>

```bash
curl -X POST "https://api.x.com/2/lists" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech News",
    "description": "My favorite tech journalists",
    "private": false
  }'
```

<div id="example-response">
  ## 예시 응답
</div>

```json
{
  "data": {
    "id": "1234567890",
    "name": "Tech News"
  }
}
```
