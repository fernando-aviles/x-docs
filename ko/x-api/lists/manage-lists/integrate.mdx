<div id="authentication">
  #### 인증
</div>

모든 X API v2 엔드포인트는 키와 토큰이라고도 부르는 자격 증명 세트를 사용해 요청을 인증해야 합니다.

이 엔드포인트들은 [OAuth 1.0a User Context](/ko/resources/fundamentals/authentication)를 사용해야 하며, 이는 성공적인 요청을 위해 API 키 세트와 사용자 Access Token 세트를 사용해야 한다는 의미입니다. Access Token은 여러분이 대신하여 요청을 보내려는 사용자와 연결되어 있어야 합니다. 다른 사용자를 위한 Access Token 세트를 생성하려면, 해당 사용자가 [3-legged OAuth flow](/ko/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow)를 사용해 여러분의 앱을 승인하거나 인증해야 합니다.

OAuth 1.0a는 사용하기 까다로울 수 있습니다. 이 인증 방식에 익숙하지 않다면, [라이브러리](/ko/x-api/tools-and-libraries/overview)나 Postman과 같은 도구를 사용해 요청을 올바르게 인증할 것을 권장합니다.

<div id="developer-console-projects-and-developer-apps">
  #### Developer Console, Project 및 개발자 App
</div>

X API v2 엔드포인트에서 사용할 수 있는 인증 자격 증명 세트를 받으려면 먼저 [개발자 계정에 가입](https://developer.x.com/en/portal/petition/essential/basic-info)하고 해당 계정 내에 [Project](/ko/resources/fundamentals/developer-apps)를 설정한 다음, 그 Project 내에 [개발자 App](/ko/resources/fundamentals/developer-apps)을 생성해야 합니다. 그런 다음 해당 개발자 App에서 키와 토큰을 확인할 수 있습니다.

<div id="rate-limits">
  #### Rate limits
</div>

매일 수많은 개발자들이 X API에 요청을 보냅니다. 이러한 요청의 막대한 양을 관리하기 위해 각 엔드포인트에는 [rate limits](/ko/x-api/fundamentals/rate-limits)가 설정되어 있으며, 이를 통해 앱 또는 인증된 사용자를 대신해 보낼 수 있는 요청 횟수가 제한됩니다.

이러한 엔드포인트에는 사용자 단위의 요청 한도(rate limit)가 적용되며, 이는 요청을 보내는 데 사용되는 인증된 사용자가 어떤 개발자 App을 사용하든 관계없이 해당 엔드포인트를 호출할 수 있는 횟수에 제한이 있다는 의미입니다.

아래 표는 각 엔드포인트의 요청 한도(rate limit)를 보여줍니다.

|     |     |     |
| :--- | :--- | :--- |
| **Endpoint** | **HTTP method** | **Rate limit** |
| /2/lists | POST | 15분당 300건의 요청 |
| /2/lists/:id | DELETE / PUT | 15분당 300건의 요청 |

<div id="create-a-list">
  #### 리스트 생성
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/lists" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"name": "My List", "description": "A list of interesting accounts"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 새 리스트 생성
  response = client.lists.create(
      name="My List",
      description="A list of interesting accounts"
  )
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 새 리스트 생성
  const response = await client.lists.create({
    name: "My List",
    description: "A list of interesting accounts",
  });
  console.log(response.data);
  ```
</CodeGroup>
