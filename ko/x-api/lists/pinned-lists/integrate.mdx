<div id="helpful-tools">
  ## 유용한 도구
</div>

이 엔드포인트를 통합하는 데 도움이 되는 몇 가지 핵심 개념을 살펴보기 전에, 먼저 다음 도구에 익숙해지는 것을 권장합니다:

<div id="postman">
  ### Postman
</div>

Postman은 엔드포인트를 시험해 볼 때 사용할 수 있는 매우 유용한 도구입니다. 각 Postman 요청에는 어떤 항목을 사용할 수 있는지 빠르게 파악하는 데 도움이 되도록 모든 경로 및 본문 매개변수가 포함되어 있습니다. Postman 컬렉션에 대해 더 알아보려면 [&quot;Postman 사용하기&quot;](/ko/tutorials/postman-getting-started) 페이지를 방문하세요.

  ## 핵심 개념

<div id="authentication">
  ### 인증
</div>

모든 X API v2 엔드포인트에서는 키와 토큰으로도 불리는 자격 증명 세트를 사용해 요청을 인증해야 합니다. 이 엔드포인트에 대한 요청을 인증하기 위해 OAuth 1.0a User Context를 사용할 수 있습니다.

[OAuth 1.0a User Context](/ko/resources/fundamentals/authentication)를 사용한다는 것은 요청을 성공적으로 수행하려면 API 키와 사용자 액세스 토큰 세트를 사용해야 한다는 의미입니다. 액세스 토큰은 요청을 대신 수행하려는 대상 사용자와 연결되어 있어야 합니다. 다른 사용자의 액세스 토큰 세트를 생성하려면, 해당 사용자가 [3-legged OAuth flow](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens)를 사용해 앱을 승인해야 합니다.

OAuth 1.0a는 사용하기 어려울 수 있습니다. 이 인증 방법에 익숙하지 않다면 [라이브러리](/ko/x-api/tools-and-libraries/overview)를 사용하거나 Postman과 같은 도구를 사용하는 것을 권장합니다.

<div id="developer-console-projects-and-developer-apps">
  ### 개발자 콘솔, Project, 그리고 개발자 App
</div>

X API v2 엔드포인트에서 사용할 수 있는 인증 자격 증명을 발급받으려면, 먼저 [개발자 계정에 가입](https://developer.x.com/en/portal/petition/essential/basic-info)하고 해당 계정 내에 [Project](/ko/resources/fundamentals/developer-apps)를 설정한 뒤, 그 Project 내에 [개발자 App](/ko/resources/fundamentals/developer-apps)을 생성해야 합니다. 그런 다음 해당 개발자 App에서 키와 토큰을 확인할 수 있습니다.

<div id="rate-limits">
  ### 요청 한도
</div>

매일 수많은 개발자들이 X API에 요청을 보냅니다. 이러한 요청의 방대한 양을 관리하기 위해, [요청 한도](/ko/x-api/fundamentals/rate-limits)를 각 엔드포인트에 두어 앱 또는 인증된 사용자를 대신해 보낼 수 있는 요청 수를 제한합니다.

이러한 엔드포인트에는 사용자 단위로 요청 한도가 적용되므로, 여러분이 요청을 보내는 대상인 인증된 사용자는 어떤 개발자 App을 사용하든 각 엔드포인트를 호출할 수 있는 횟수가 정해져 있습니다.

아래 표는 각 엔드포인트에 적용되는 요청 한도를 보여줍니다.

| Endpoint | HTTP method | Rate limit |
| :--- | :--- | :--- |
| /2/users/:id/pinned&#95;lists | POST | 15분당 50회 요청 |
| /2/users/:id/pinned&#95;lists/:list&#95;id | DELETE | 15분당 50회 요청 |
| /2/users/:id/pinned&#95;lists | GET | 15분당 15회 요청 |

<div id="fields-and-expansions">
  ### 필드와 expansions
</div>

X API v2 GET 엔드포인트를 사용하면 `fields` 및 `expansions`라고 불리는 도구 집합을 통해, API에서 어떤 data를 반환할지 정확하게 선택할 수 있습니다. `expansions` 매개변수를 사용하면 페이로드에서 참조되는 객체를 확장하여 함께 가져올 수 있습니다. 예를 들어, 고정된 리스트(pinned Lists)를 조회할 때는 다음 [expansions](/ko/x-api/fundamentals/expansions)을(를) 가져올 수 있습니다:

* `owner_id`

`fields` 매개변수를 사용하면 서로 다른 data 객체 안에서 어떤 [fields](/ko/x-api/fundamentals/fields)를 수신할지 정확하게 선택할 수 있습니다. 이 엔드포인트는 주로 사용자 객체를 반환합니다. 기본적으로 List 객체는 `id` 및 `name` 필드를 반환합니다. `list.created_at` 또는 `list.description`과 같은 추가 필드를 받으려면, 별도로 `fields` 매개변수를 사용해 이러한 필드를 요청해야 합니다.

[X API v2 데이터 사전](/ko/x-api/fundamentals/data-dictionary)에 [fields와 expansions](/ko/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)를 함께 사용하는 방법에 대한 가이드를 추가했습니다.

아래 표는 lookup 엔드포인트에서 사용 가능한 필드와 expansions를 보여줍니다:

| Endpoint | Fields | Expansions |
| :--- | :--- | :--- |
| /2/users/:id/pinned&#95;lists | `list.fields`, `user.fields` | `owner_id` |
