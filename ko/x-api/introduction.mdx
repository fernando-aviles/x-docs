<div id="pricing">
  ## 요금제
</div>

X API는 **사용량 기반 종량제(pay-per-usage)** 요금을 사용합니다. 구독도, 월 한도도 없습니다. 사용한 만큼만 비용을 지불하세요.

<CardGroup cols={2}>
  <Card title="유연한 확장" icon="chart-line">
    작게 시작해서 점진적으로 확장하세요. 실제 사용량에 비례해 비용이 증가합니다.
  </Card>

  <Card title="무약정" icon="unlock">
    계약이나 최소 지출 금액이 없습니다. 언제든지 중단할 수 있습니다.
  </Card>

  <Card title="실시간 추적" icon="gauge-high">
    개발자 콘솔에서 사용량과 비용을 실시간으로 모니터링하세요.
  </Card>

  <Card title="크레딧 기반" icon="coins">
    크레딧을 미리 구매해 두고, API를 사용할 때마다 차감됩니다.
  </Card>
</CardGroup>

<div id="key-features">
  ## 주요 기능
</div>

<Tabs>
  <Tab title="데이터 액세스">
    ### 풍부한 데이터 객체

    게시물, 사용자, 미디어 등과 관련된 상세하고 구조화된 데이터에 액세스할 수 있습니다.

    * **포스트**: 전체 텍스트, 메트릭, 엔티티, 주석, 대화 스레드
    * **사용자**: 프로필, 팔로워 수, 인증 상태
    * **미디어**: 메타데이터가 포함된 이미지, 비디오, GIF
    * **투표**: 선택지와 득표 수

    [fields](/ko/x-api/fundamentals/fields)와 [expansions](/ko/x-api/fundamentals/expansions)를 사용해 응답을 맞춤 구성하여 필요한 데이터만 정확히 받아볼 수 있습니다.
  </Tab>

  <Tab title="실시간 스트리밍">
    ### 필터링된 스트림

    게시물이 게시되는 즉시 실시간으로 전달받을 수 있습니다. 최대 1,000개의 필터링 규칙을 정의하여 일치하는 게시물만 수신하세요.

    ```bash
    # 규칙 추가
    curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{"add": [{"value": "from:xdevelopers"}]}'

    # 스트림에 연결
    curl "https://api.x.com/2/tweets/search/stream" \
      -H "Authorization: Bearer $TOKEN"
    ```

    [필터링된 스트림 자세히 알아보기 →](/ko/x-api/posts/filtered-stream/introduction)
  </Tab>

  <Tab title="검색 및 분석">
    ### 전체 아카이브 검색

    2006년까지 거슬러 올라가는 전체 공개 게시물 기록을 검색할 수 있습니다. 사용자, 키워드, 날짜 등 다양한 연산자를 사용해 쿼리를 구성하세요.

    ```bash
    curl "https://api.x.com/2/tweets/search/all?query=AI%20lang:en" \
      -H "Authorization: Bearer $TOKEN"
    ```

    ### 메트릭

    노출수, 좋아요, 리포스트, 답글, 동영상 조회수 등 참여 메트릭을 확인할 수 있습니다.

    [검색 자세히 알아보기 →](/ko/x-api/posts/search/introduction)
  </Tab>
</Tabs>

<div id="api-versions">
  ## API 버전
</div>

| 버전 | 상태 | 설명 |
|:--------|:-------|:------------|
| **v2** | 현재 | 최신 엔드포인트, 유연한 요금제, 모든 신규 기능 지원 |
| **Enterprise** | 사용 가능 | 전담 지원이 포함된 대규모 사용량용 액세스 |

<Tip>
  새 프로젝트에는 항상 **X API v2**를 사용하세요. 모든 신규 기능과 개선 사항은 여기에서 제공됩니다.
</Tip>

<div id="quick-start">
  ## 빠른 시작
</div>

<Steps>
  <Step title="개발자 계정 만들기">
    [console.x.com](https://console.x.com)에 가입하고 App을 생성하세요.
  </Step>

  <Step title="자격 증명 발급받기">
    App 전용 요청을 위해 Bearer 토큰을 생성하세요.
  </Step>

  <Step title="요청 보내기">
    사용자를 조회해 보세요:

    ```bash
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>
</Steps>
