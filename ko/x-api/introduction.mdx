<div id="pricing">
  ## 요금제
</div>

X API는 **사용량 기반 과금(pay-per-usage)** 모델을 사용합니다. 구독이나 월 사용 한도는 없습니다. 사용한 만큼만 비용을 지불하면 됩니다.

<CardGroup cols={2}>
  <Card title="유연한 확장" icon="chart-line">
    작게 시작해서 점진적으로 확장하세요. 비용은 실제 사용량에 따라 늘어납니다.
  </Card>

  <Card title="약정 없음" icon="unlock">
    계약이나 최소 지출 요건이 없습니다. 언제든지 중단할 수 있습니다.
  </Card>

  <Card title="실시간 추적" icon="gauge-high">
    Developer Console에서 사용량과 비용을 실시간으로 모니터링하세요.
  </Card>

  <Card title="크레딧 기반" icon="coins">
    크레딧을 미리 구매해 두면, API 사용량에 따라 차감됩니다.
  </Card>
</CardGroup>

<div id="key-features">
  ## 주요 기능
</div>

<Tabs>
  <Tab title="데이터 액세스">
    ### 풍부한 데이터 객체

    포스트, 사용자, 미디어 등 다양한 리소스에 대한 상세하고 구조화된 데이터에 액세스할 수 있습니다.

    * **포스트**: 전체 텍스트, 지표, 엔티티, 주석, 대화 스레드
    * **사용자**: 프로필, 팔로워 수, 인증 상태
    * **미디어**: 메타데이터가 포함된 이미지, 동영상, GIF
    * **투표**: 옵션 및 투표 수

    [fields](/ko/x-api/fundamentals/fields) 및 [expansions](/ko/x-api/fundamentals/expansions)를 사용해 응답을 원하는 대로 맞춤 설정하여 필요한 데이터만 정확히 받아보세요.
  </Tab>

  <Tab title="실시간 스트리밍">
    ### 필터링된 스트림

    게시되는 즉시 포스트를 실시간으로 수신할 수 있습니다. 최대 1,000개의 필터링 규칙을 정의해 조건에 맞는 포스트만 수신하세요.

    ```bash
    # 규칙 추가
    curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{"add": [{"value": "from:xdevelopers"}]}'

    # 스트림에 연결
    curl "https://api.x.com/2/tweets/search/stream" \
      -H "Authorization: Bearer $TOKEN"
    ```

    [필터링된 스트림 자세히 알아보기 →](/ko/x-api/posts/filtered-stream/introduction)
  </Tab>

  <Tab title="검색 및 분석">
    ### 전체 아카이브 검색

    2006년까지 거슬러 올라가는 전체 공개 포스트 기록을 검색할 수 있습니다. 사용자, 키워드, 날짜 등 다양한 연산자를 사용해 쿼리를 구성하세요.

    ```bash
    curl "https://api.x.com/2/tweets/search/all?query=AI%20lang:en" \
      -H "Authorization: Bearer $TOKEN"
    ```

    ### 지표

    노출 수, 좋아요, 리포스트, 답글, 동영상 조회수를 포함한 참여 지표에 액세스할 수 있습니다.

    [검색 자세히 알아보기 →](/ko/x-api/posts/search/introduction)
  </Tab>
</Tabs>

<div id="api-versions">
  ## API 버전
</div>

| 버전 | 상태 | 설명 |
|:--------|:-------|:------------|
| **v2** | 최신 | 최신 엔드포인트, 유연한 과금, 모든 신규 기능 |
| **Enterprise** | 사용 가능 | 전용 지원이 포함된 대용량 액세스 |

<Tip>
  새로운 모든 프로젝트에는 **X API v2**를 사용하세요. 모든 신규 기능과 개선 사항이 여기에 제공됩니다.
</Tip>

<div id="quick-start">
  ## 빠른 시작
</div>

<Steps>
  <Step title="개발자 계정 만들기">
    [console.x.com](https://console.x.com)에 가입하고 앱을 생성하세요.
  </Step>

  <Step title="자격 증명 가져오기">
    앱 전용 요청에 사용할 Bearer Token을 생성하세요.
  </Step>

  <Step title="요청 보내기">
    사용자를 조회해 보세요:

    ```bash
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>
</Steps>
