<div id="comparing-x-apis-search-posts-endpoints">
  ## X API의 포스트 검색 엔드포인트 비교
</div>

v2 Search Tweets 엔드포인트는 궁극적으로 [표준 v1.1 search/posts](/ko/x-api/posts/search/introduction) 엔드포인트와 [enterprise Search API](/ko/x-api/enterprise-gnip-2.0/fundamentals/search-api)를 대체하게 됩니다. 기존 버전의 X 검색 엔드포인트를 사용하는 코드, 앱 또는 도구가 있고 이를 최신 X API v2 엔드포인트로 마이그레이션하는 것을 고려 중이라면, 이 가이드는 여러분을 위한 것입니다.

***

<div id="recent-search-comparison">
  ## 최근 검색 비교
</div>

| **설명** | **Standard v1.1** | **X API v2** |
| :--- | :--- | :--- |
| 호스트 도메인 | https://api.x.com | https://api.x.com |
| 엔드포인트 경로 | /1.1/search/tweets.json | /2/tweets/search/recent |
| [인증](/ko/resources/fundamentals/authentication) | OAuth 1.0a User Context  <br />OAuth 2.0 App-Only | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />OAuth 2.0 App-Only |
| 타임스탬프 형식 | YYYYMMDD | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |
| 반환되는 포스트의 최대 과거 기간 | 7일 | 7일 |
| 지원되는 HTTP 메서드 | GET | GET |
| 기본 요청 rate limit | OAuth 1.0a User Context 사용 시 15분당 180개 요청<br /><br />OAuth 2.0 App-Only 사용 시 15분당 450개 요청 | **셀프 서비스:**<br /><br />OAuth 2.0 App-Only 사용 시 15분당 60개 요청<br /><br />OAuth 1.0a User Context 사용 시 15분당 60개 요청<br /><br />OAuth 2.0 Authorization Code with PKCE 사용 시 15분당 60개 요청 |
| 완전히 전개된 URL 제공 |     | ✔   |
| 응답당 최대 포스트 수 (기본값) | 100 (15) | 100 (10) |
| 포스트 JSON 형식 | Standard v1.1 형식 | [X API v2 형식](/ko/x-api/fundamentals/data-dictionary) (요청 파라미터인 fields 및 expansions에 의해 결정되며, v1.1 형식과 하위 호환되지 않음)<br /><br />Standard v1.1 형식에서 X API v2 형식으로 마이그레이션하는 방법을 자세히 알아보려면 [데이터 형식 마이그레이션 가이드](/ko/x-api/migrate/data-format-migration)를 참조하세요. |
| 페이로드에서 어떤 [fields](/ko/x-api/fundamentals/fields)를 반환할지 선택 가능 |     | ✔   |
| [annotations](/ko/x-api/fundamentals/post-annotations)의 요청 및 수신 지원 |     | ✔   |
| 포스트 객체 내 특정 [metrics](/ko/x-api/fundamentals/metrics) 요청 및 수신 지원 |     | ✔   |
| [conversation&#95;id](/ko/x-api/fundamentals/conversation-id) 연산자 및 필드 지원 |     | ✔   |
| 포스트 수정 이력 제공 | ✔   | ✔   |
| 포스트 data 배열에 대한 JSON 키 이름 | statuses | data |
| 페이지네이션에 대한 JSON 키 이름 | search&#95;metadata.next&#95;results | meta.next&#95;token |
| 시간 범위로 아카이브 탐색 지원 | ✔   | ✔   |
| 시간 기반 요청의 시간 해상도 | 일(day) | 초(second) |
| 표준 시간대 | UTC | UTC |
| 시간 기준 탐색을 위한 요청 파라미터 | until | start&#95;time  <br />end&#95;time |
| 포스트 ID 기준 탐색을 위한 요청 파라미터 | since&#95;id   <br />max&#95;id | since&#95;id   <br />until&#95;id |
| 페이지네이션을 위한 요청 파라미터 | URL 인코딩된 쿼리 제공 | next&#95;token |
| [Project](/ko/resources/fundamentals/developer-apps)와 연결된 [개발자 App](/ko/resources/fundamentals/developer-apps)의 자격 증명 사용 필요 |     | ✔   |

**필터링 연산자 비교**

포스트 검색의 네 가지 버전(standard, enterprise, v2)은 사용 가능한 연산자가 서로 다르며, 각 버전 내에서도 연산자 가용 수준에 차이가 있습니다. 이에 대해서는 아래에서 설명합니다.

Enterprise

* enterprise 연산자에는 하위 티어가 없습니다.

X API v2

* **Self-serve:** 어떤 Project를 사용하든 사용 가능
* **Enterprise:** Project를 사용할 때 사용 가능

각 연산자 세트에 대해서는 다음 가이드를 통해 더 자세히 확인할 수 있습니다:

* [Enterprise 연산자](/ko/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [X API v2 연산자](/ko/x-api/posts/search/integrate/build-a-query#operators)
