<div id="comparing-x-apis-search-posts-endpoints">
  ## X API의 포스트 검색 엔드포인트 비교
</div>

v2 Search Tweets 엔드포인트는 결국 [표준 v1.1 search/posts](/ko/x-api/posts/search/introduction) 엔드포인트와 [Enterprise Search API](/ko/x-api/enterprise-gnip-2.0/fundamentals/search-api)를 대체하게 됩니다. X 검색 엔드포인트의 이전 버전을 사용하는 코드, 앱 또는 도구가 있고, 이를 최신 X API v2 엔드포인트로 마이그레이션하는 것을 고려하고 있다면 이 가이드를 참고하세요.

***

| **설명** | **Standard v1.1** | **X API v2** |
| :--- | :--- | :--- |

| 엔드포인트 경로 | /1.1/search/tweets.json | /2/tweets/search/recent |
| [인증](/ko/resources/fundamentals/authentication) | OAuth 1.0a User Context  <br />OAuth 2.0 App-Only | OAuth 1.0a User Context<br /><br />OAuth 2.0 Authorization Code with PKCE<br /><br />OAuth 2.0 App-Only |
| 타임스탬프 형식 | YYYYMMDD | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |

| 기본 요청 한도 | OAuth 1.0a User Context 사용 시 15분당 180회 요청<br /><br />OAuth 2.0 App-Only 사용 시 15분당 450회 요청 | **셀프 서비스:**<br /><br />OAuth 2.0 App-Only 사용 시 15분당 60회 요청<br /><br />OAuth 1.0a User Context 사용 시 15분당 60회 요청<br /><br />OAuth 2.0 Authorization Code with PKCE 사용 시 15분당 60회 요청 |
| 완전히 확장된 URL 제공 |     | ✔   |
| 응답당 최대 포스트 수(기본값) | 100 (15) | 100 (10) |
| 포스트 JSON 형식 | Standard v1.1 형식 | [X API v2 형식](/ko/x-api/fundamentals/data-dictionary) (fields 및 expansions 요청 파라미터에 의해 결정되며, v1.1 형식과 하위 호환되지 않음)<br /><br />Standard v1.1 형식에서 X API v2 형식으로 마이그레이션하는 방법에 대한 자세한 내용은 [data 형식 마이그레이션 가이드](/ko/x-api/migrate/data-format-migration)를 참조하세요. |
| 페이로드에 어떤 [fields](/ko/x-api/fundamentals/fields)를 포함할지 선택 지원 |     | ✔   |
| [annotations](/ko/x-api/fundamentals/post-annotations)를 요청 및 수신하는 기능 지원 |     | ✔   |
| 포스트 객체 내에서 특정 [metrics](/ko/x-api/fundamentals/metrics)를 요청하는 기능 지원 |     | ✔   |
| [conversation&#95;id](/ko/x-api/fundamentals/conversation-id) 연산자 및 필드 지원 |     | ✔   |
| 포스트 편집 이력 제공 | ✔   | ✔   |
| 포스트 data 배열에 대한 JSON 키 이름 | statuses | data |
| 페이지네이션에 대한 JSON 키 이름 | search&#95;metadata.next&#95;results | meta.next&#95;token |
| 시간 범위별 아카이브 탐색 지원 | ✔   | ✔   |
| 시간 기반 요청의 해상도 | 일 | 초 |
| 시간대 | UTC | UTC |

**필터링 연산자 비교**

검색 포스트의 네 가지 버전(standard, enterprise, v2)은 사용 가능한 연산자가 서로 다르며, 각 버전 내에서도 연산자 가용 수준이 서로 다릅니다. 이에 대해서는 아래에서 설명합니다.

Enterprise

* enterprise 연산자에는 하위 티어가 없습니다.

X API v2

* **Self-serve:** 모든 Project에서 사용 가능
* **Enterprise:** Project를 사용할 때 사용 가능

각 연산자 세트에 대해 더 자세히 알고 싶다면, 해당 가이드를 참조하세요:

* [Enterprise 연산자](/ko/x-api/enterprise-gnip-2.0/fundamentals/search-api#available-operators)
* [X API v2 연산자](/ko/x-api/posts/search/integrate/build-a-query#operators)

이제 X API v2 내의 서로 다른 연산자 레벨을 이해했으므로, 검색 포스트에 대한 연산자 가용성을 정리한 다음 표를 확인해 보세요(셀을 비워 둔 경우 해당 연산자는 사용할 수 없습니다).
