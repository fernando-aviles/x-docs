Search Posts 엔드포인트를 사용하면 강력한 쿼리 연산자를 사용해 특정 조건과 일치하는 포스트를 찾을 수 있습니다. 키워드, 해시태그, 멘션, URL 등을 검색할 수 있습니다.

<div id="overview">
  ## 개요
</div>

X는 서로 다른 시간 범위와 액세스 조건을 가진 두 가지 검색 엔드포인트를 제공합니다:

<CardGroup cols={2}>
  <Card title="최근 검색" icon="clock">
    **최근 7일간**의 포스트를 검색합니다. 모든 개발자가 사용할 수 있습니다.
  </Card>

  <Card title="전체 아카이브 검색" icon="vault">
    2006년까지 거슬러 올라가는 **전체 아카이브**를 검색합니다. 종량제(pay-per-use) 및 Enterprise 고객이 사용할 수 있습니다.
  </Card>
</CardGroup>

***

<div id="use-cases">
  ## 사용 사례
</div>

* **브랜드 모니터링** — 브랜드나 제품에 대한 언급을 추적합니다
* **트렌드 분석** — 주제나 이벤트를 둘러싼 대화를 분석합니다
* **연구** — 학술 또는 시장 조사를 위한 데이터를 수집합니다
* **실시간 리스닝** — 새로운 포스트에 실시간으로 반응하는 애플리케이션을 구축합니다

***

<div id="endpoints">
  ## 엔드포인트
</div>

| Method | Endpoint | Description | Access |
|:-------|:---------|:------------|:-------|
| GET | [`/2/tweets/search/recent`](/ko/x-api/posts/search-recent-posts) | 최근 7일 이내 포스트 검색 | 모든 개발자 |
| GET | [`/2/tweets/search/all`](/ko/x-api/posts/search-all-posts) | 전체 포스트 아카이브 검색 | 사용량 기반 과금, Enterprise |

***

<div id="query-operators">
  ## 쿼리 연산자
</div>

포스트의 속성과 일치하는 연산자를 사용해 쿼리를 작성합니다:

```
(AI OR "artificial intelligence") lang:en -is:retweet has:links
```

<AccordionGroup>
  <Accordion title="키워드 연산자">
    | Operator | Example              | Description        |
    | :------- | :------------------- | :----------------- |
    | Keyword  | `python`             | 해당 단어를 포함하는 포스트    |
    | Phrase   | `"machine learning"` | 해당 구문이 정확히 포함된 포스트 |
    | Hashtag  | `#AI`                | 해당 해시태그가 포함된 포스트   |
    | Mention  | `@XDevelopers`       | 해당 사용자를 멘션한 포스트    |
  </Accordion>

  <Accordion title="사용자 연산자">
    | Operator       | Example          | Description           |
    | :------------- | :--------------- | :-------------------- |
    | `from:`        | `from:elonmusk`  | 특정 사용자가 작성한 포스트       |
    | `to:`          | `to:XDevelopers` | 특정 사용자에게 보낸 답글        |
    | `retweets_of:` | `retweets_of:X`  | 특정 사용자의 포스트를 리트윗한 포스트 |
  </Accordion>

  <Accordion title="콘텐츠 연산자">
    | Operator       | Example          | Description     |
    | :------------- | :--------------- | :-------------- |
    | `has:images`   | `cat has:images` | 이미지가 포함된 포스트    |
    | `has:videos`   | `has:videos`     | 동영상이 포함된 포스트    |
    | `has:links`    | `has:links`      | 링크가 포함된 포스트     |
    | `has:mentions` | `has:mentions`   | 멘션이 포함된 포스트     |
    | `url:`         | `url:github.com` | 특정 URL이 포함된 포스트 |
  </Accordion>

  <Accordion title="필터 연산자">
    | Operator      | Example       | Description      |
    | :------------ | :------------ | :--------------- |
    | `lang:`       | `lang:en`     | 특정 언어로 작성된 포스트   |
    | `-is:retweet` | `-is:retweet` | 리트윗 제외           |
    | `-is:reply`   | `-is:reply`   | 답글 제외            |
    | `is:verified` | `is:verified` | 인증된 사용자가 작성한 포스트 |
  </Accordion>
</AccordionGroup>

<div id="recent-search">
  ## 최근 검색
</div>

**지난 7일** 동안의 포스트를 검색할 수 있습니다. 모든 개발자가 사용할 수 있습니다.

<div id="features">
  ### 기능
</div>

* 요청당 최대 100개의 포스트
* 대규모 결과 집합을 위한 페이지네이션
* 모든 핵심 쿼리 연산자 지원
* 쿼리 길이 512자 (Enterprise는 4,096자)

<div id="full-archive-search">
  ## 전체 아카이브 검색
</div>

2006년 3월까지 거슬러 올라가는 **전체 포스트 아카이브**를 검색할 수 있습니다.

* 전체 포스트 이력에 대한 접근
* 모든 쿼리 연산자 사용 가능
* 쿼리 길이 1,024자 (Enterprise의 경우 4,096자)
