이 가이드는 2006년 3월까지 소급되는 전체 X 아카이브에서 포스트를 찾기 위해 첫 전체 아카이브 검색 요청을 만드는 방법을 단계별로 안내합니다.

<Warning>
  전체 아카이브 검색을 사용하려면 [셀프 서비스](/ko/x-api/getting-started/about-x-api) 또는 [엔터프라이즈](/ko/x-api/getting-started/about-x-api) 액세스가 필요합니다. 이 엔드포인트를 사용하려면 [액세스를 업그레이드](https://developer.x.com/en/portal/products)하세요.
</Warning>

<Note>
  **사전 준비 사항**

  시작하기 전에 다음이 필요합니다.

  * [개발자 계정](https://developer.x.com/en/portal/petition/essential/basic-info)
  * 앱의 Bearer Token(개발자 콘솔의 &quot;Keys and tokens&quot;에서 확인 가능)
</Note>

***

<div id="step-1-build-a-query">
  ## 1단계: 쿼리 작성하기
</div>

전체 아카이브 검색은 모든 쿼리 연산자를 지원합니다. 최근 검색과 같은 방식으로 쿼리를 작성하세요:

```
from:XDevelopers lang:en
```

<Tip>
  전체 아카이브 검색은 최대 1,024자(엔터프라이즈의 경우 4,096자)까지의 쿼리를 지원합니다.
</Tip>

***

<div id="step-2-set-a-time-range">
  ## 2단계: 기간 설정
</div>

기본적으로 검색 결과에는 최근 30일 동안의 포스트가 반환됩니다. 특정 기간만 검색하려면 `start_time`과 `end_time`을 사용하세요:

| Parameter | Format | Example |
|:----------|:-------|:--------|
| `start_time` | ISO 8601 | `2020-01-01T00:00:00Z` |
| `end_time` | ISO 8601 | `2020-12-31T23:59:59Z` |

***

<div id="step-3-make-a-request">
  ## 3단계: 요청 보내기
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/search/all?\
  query=from%3AXDevelopers&\
  start_time=2020-01-01T00%3A00%3A00Z&\
  end_time=2020-12-31T23%3A59%3A59Z&\
  max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 페이지네이션을 사용해 전체 아카이브를 검색합니다.
  for page in client.posts.search_all(
      query="from:XDevelopers",
      start_time="2020-01-01T00:00:00Z",
      end_time="2020-12-31T23:59:59Z",
      max_results=100
  ):
      for post in page.data:
          print(post.text)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 페이지네이션을 사용해 전체 아카이브를 검색합니다.
  const paginator = client.posts.searchAll({
    query: "from:XDevelopers",
    startTime: "2020-01-01T00:00:00Z",
    endTime: "2020-12-31T23:59:59Z",
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(post.text);
    });
  }
  ```
</CodeGroup>

<div id="step-5-add-fields-and-expansions">
  ## 5단계: 필드와 expansions 추가
</div>

쿼리 매개변수로 추가 데이터를 요청합니다:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/search/all?\
  query=from%3AXDevelopers&\
  start_time=2020-01-01T00%3A00%3A00Z&\
  end_time=2020-12-31T23%3A59%3A59Z&\
  tweet.fields=created_at,public_metrics,author_id&\
  expansions=author_id&\
  user.fields=username,description&\
  max_results=100" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 필드와 expansions를 사용하여 검색
  for page in client.posts.search_all(
      query="from:XDevelopers",
      start_time="2020-01-01T00:00:00Z",
      end_time="2020-12-31T23:59:59Z",
      tweet_fields=["created_at", "public_metrics", "author_id"],
      expansions=["author_id"],
      user_fields=["username", "description"],
      max_results=100
  ):
      for post in page.data:
          print(f"{post.created_at}: {post.text[:50]}...")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 필드와 expansions를 사용하여 검색
  const paginator = client.posts.searchAll({
    query: "from:XDevelopers",
    startTime: "2020-01-01T00:00:00Z",
    endTime: "2020-12-31T23:59:59Z",
    tweetFields: ["created_at", "public_metrics", "author_id"],
    expansions: ["author_id"],
    userFields: ["username", "description"],
    maxResults: 100,
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.created_at}: ${post.text?.slice(0, 50)}...`);
    });
  }
  ```
</CodeGroup>

<div id="step-6-paginate-through-results">
  ## 6단계: 결과 페이지네이션 처리
</div>

SDK에서는 페이지네이션을 자동으로 처리합니다. cURL을 사용하는 경우, 응답에서 `next_token`을 사용하세요:

```bash
curl "https://api.x.com/2/tweets/search/all?\
query=from%3AXDevelopers&\
max_results=500&\
next_token=b26v89c19zqg8o3fo7gesq314yb9l2l4ptqy" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="key-differences-from-recent-search">
  ## 최근 검색과의 주요 차이점
</div>

| 기능 | Recent Search | Full-Archive Search |
|:--------|:--------------|:--------------------|
| 시간 범위 | 최근 7일 | 2006년 3월부터 현재까지 |
| 필수 액세스 수준 | 모든 개발자 | 사용량 기반 과금, Enterprise |
| 요청당 최대 결과 수 | 100 | 500 |
| 쿼리 길이 | 512자 | 1,024자 |
| 요청 한도 | 15분당 450회 | 15분당 300회, 초당 1회 |
| 인증 | App-Only, User Context | App-Only 전용 |

<div id="common-parameters">
  ## 공통 매개변수
</div>

| 매개변수 | 설명 | 기본값 |
|:----------|:------------|:--------|
| `query` | 검색 쿼리(필수) | — |
| `max_results` | 페이지당 포스트 개수 (10-500) | 10 |
| `start_time` | 가장 오래된 포스트의 타임스탬프 | 30일 전 |
| `end_time` | 가장 최신 포스트의 타임스탬프 | 현재 |
| `next_token` | 페이지네이션 토큰 | — |
| `tweet.fields` | 추가 포스트 필드 | `id`, `text` |
| `expansions` | 포함할 관련 객체 | — |
