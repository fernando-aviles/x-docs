</div>

Postman은 엔드포인트를 테스트해 볼 수 있는 매우 유용한 도구입니다. 각 Postman 요청에는 사용 가능한 항목을 빠르게 파악할 수 있도록 모든 경로 및 본문 매개변수가 포함되어 있습니다. Postman 컬렉션에 대해 더 알아보려면 [&quot;Postman 사용하기&quot;](/ko/tutorials/postman-getting-started) 페이지를 방문하세요.

<div id="authentication">
  ### 인증
</div>

모든 X API v2 엔드포인트는 키와 토큰이라고도 불리는 자격 증명을 사용하여 요청을 인증해야 합니다.

이 엔드포인트는 [OAuth 1.0a User Context](/ko/resources/fundamentals/authentication)를 사용해야 하며, 이는 성공적인 요청을 보내기 위해 API 키와 사용자 Access Token 세트를 사용해야 함을 의미합니다. Access Token은 요청을 대신 보내려는 해당 사용자와 연결되어 있어야 합니다. 다른 사용자를 위한 Access Token 세트를 생성하려는 경우, 해당 사용자는 [3-legged OAuth flow](/ko/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow)를 사용하여 귀하의 App을 승인하거나 인증해야 합니다.

OAuth 1.0a는 사용하기 어려울 수 있다는 점에 유의하세요. 이 인증 방식에 익숙하지 않다면, [라이브러리](/ko/x-api/tools-and-libraries/overview)를 사용하거나 Postman과 같은 도구를 사용하거나 OAuth 2.0을 사용하여 요청을 인증할 것을 권장합니다.

[PKCE를 사용하는 OAuth 2.0 Authorization Code](/ko/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)는 애플리케이션의 범위(scope)와 여러 디바이스에 걸친 인가 플로우를 보다 세밀하게 제어할 수 있도록 해 줍니다. OAuth 2.0을 사용하면 사용자 대신 수행할 수 있는 권한을 세분화된 스코프 단위로 선택할 수 있습니다.

App에서 OAuth 2.0을 사용하려면, 개발자 콘솔의 App 설정 섹션에 있는 App의 인증 설정에서 OAuth 2.0을 활성화해야 합니다.

<div id="developer-console-projects-and-developer-apps">
  ### 개발자 콘솔, Project, 그리고 개발자 App
</div>

X API v2 엔드포인트에서 사용할 인증 자격 증명 세트를 발급받으려면, [developer account](/ko/resources/fundamentals/developer-portal)가 있어야 하며, 해당 계정 내에 [Project](/ko/resources/fundamentals/developer-apps)를 설정하고 그 Project 안에 [developer App](/ko/resources/fundamentals/developer-apps)을 생성해야 합니다. 그런 다음 개발자 App에서 키와 토큰을 확인할 수 있습니다.

<div id="rate-limits">
  ### Rate limits
</div>

매일 수많은 개발자들이 X API에 요청을 보냅니다. 이러한 대량의 요청을 효율적으로 관리하기 위해, 각 엔드포인트에는 [rate limits](https://developer.x.com/x-api/fundamentals/rate-limits)가 설정되어 있으며, 이는 앱 또는 인증된 사용자를 대신해 보낼 수 있는 요청 수를 제한합니다.

해당 엔드포인트들은 사용자 단위로 rate limit이 적용되며, 이는 요청을 보내는 대상이 되는 인증된 사용자가 어떤 개발자 App을 사용하든 해당 엔드포인트를 호출할 수 있는 횟수가 일정 횟수로 제한된다는 의미입니다. POST 메서드에는 15분당 200건의 사용자 rate limit이 있습니다. DELETE 메서드에는 15분당 50건의 rate limit이 있습니다. 추가로, manage Posts 또는 manage Retweets 권한으로 생성된 포스트를 포함하여 [3시간당 300건의 요청 제한](https://blog.x.com/developer/en_us/topics/tools/2018/new-developer-requirements-to-protect-our-platform)이 있습니다.

<div id="source-labels">
  ### 소스 라벨
</div>

앱 이름과 웹사이트 URL은 애플리케이션이 프로그래밍 방식으로 생성하는 모든 포스트의 메타데이터 내에서 [소스 라벨](https://help.x.com/en/using-twitter/how-to-tweet#source-labels)로 표시됩니다. X 앱의 사용 사례가 변경되는 경우, [Developer Terms](https://developer.x.com/content/developer-twitter/en/developer-terms/agreement-and-policy)를 준수하도록 이 설정에서 사용 사례를 반드시 업데이트해야 합니다.

<div id="profile-settings">
  ### 프로필 설정
</div>

프로필 설정에서 위치 정보 기능을 켜 둔 경우에만 포스트에 위치를 추가할 수 있습니다. 위치 정보 기능을 켜 두지 않았다면 요청 본문에 위치 매개변수를 포함할 수는 있지만, 해당 위치는 포스트에 연결되지 않습니다. 이미지에 사용자를 태그하는 기능에도 마찬가지로 적용됩니다. 태그하려는 사용자가 사진 태그 허용을 켜 두지 않았다면, 포스트가 정상적으로 생성되더라도 태그된 사용자 목록에 그 사용자의 이름은 표시되지 않습니다.

<div id="adding-media-to-a-post">
  ### 포스트에 미디어 추가하기
</div>

현재로서는 X API v2만으로 미디어를 처음부터 끝까지 업로드하는 방법은 없습니다. 그러나 이전에 업로드한 미디어를 포스트에 첨부할 수는 있습니다. 이미 [v1 미디어 엔드포인트를 사용하여 업로드한](https://developer.x.com/en/docs/twitter-api/v1/media/upload-media/api-reference/post-media-upload) 미디어나 [X Media Studio](https://media.x.com/en/articles/products/2018/media-studio)를 통해 업로드된 미디어의 미디어 id를 사용할 수 있습니다. 이러한 미디어 id는 본인 또는 인증된 사용자의 것만 사용할 수 있습니다.

<div id="create-a-post">
  ### 포스트 생성
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/tweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"text": "Hello world!"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 포스트 생성
  response = client.posts.create(text="Hello world!")
  print(f"Created Post: {response.data.id}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 포스트 생성
  const response = await client.posts.create({ text: "Hello world!" });
  console.log(`Created Post: ${response.data?.id}`);
  ```
</CodeGroup>
