<div id="comparing-x-apis-post-counts-endpoints">
  ## X API의 포스트 개수 엔드포인트 비교
</div>

v2 포스트 개수 엔드포인트는 향후 [enterprise Search API의 counts 엔드포인트](/ko/x-api/enterprise-gnip-2.0/fundamentals/search-api#counts-requests-post-count)를 대체하게 됩니다. 기존 버전의 포스트 개수 엔드포인트를 사용하는 코드, 앱 또는 도구가 있고, 이를 최신 X API v2 엔드포인트로 마이그레이션하는 것을 고려 중이라면 이 가이드는 여러분을 위한 것입니다.

***

<div id="recent-post-counts-comparison">
  ## 최근 포스트 개수 비교
</div>

포스트 개수용 엔터프라이즈 endpoint는 최근 30일 또는 전체 아카이브(full-archive)에 대한 개수를 조회할 수 있습니다. 따라서 7일 기간을 조회하는 v2 최근 포스트 개수 endpoint는 앞에서 언급한 어느 endpoint도 직접적으로 대체하지 않습니다.

그러나 비교에 도움이 되도록, v2 최근 포스트 개수 endpoint가 엔터프라이즈 30일 endpoint와 어떻게 비교되는지 살펴보겠습니다.

다음 표는 다양한 최근 포스트 개수 endpoint를 비교한 것입니다:

| **설명** | **엔터프라이즈** | **X API v2** |
| :--- | :--- | :--- |
| 호스트 도메인 | https://gnip-api.x.com | https://api.x.com |
| Endpoint 경로 | /search/30day/accounts/:account&#95;name/:label/counts.json | /2/tweets/counts/recent |
| [인증](/ko/resources/fundamentals/authentication) | 기본 인증(Basic authentication) | OAuth 2.0 Bearer Token |
| 타임스탬프 형식 | YYYYMMDDhhmm | YYYY-MM-DDTHH:mm:ssZ  <br />[ISO 8601 / RFC 3339](https://tools.ietf.org/html/rfc3339#section-5.6) |
| 반환되는 포스트의 최대 경과 기간 | 31일 | 7일 |
| 지원되는 HTTP 메서드 | GET | GET |
| 기본 요청 속도 제한 | 검색 data 및 개수 요청을 합산하여 1초당 20개 요청  <br />분당 요청 한도는 계약서에 명시된 대로 파트너별로 달라집니다. | 사용자당 15분당 180개 요청  <br />App당 15분당 450개 요청 |
| [annotations](/ko/x-api/fundamentals/post-annotations)을 사용한 필터링 지원 |     | ✔   |
| [conversation&#95;id](/ko/x-api/fundamentals/conversation-id)을 사용한 필터링 지원 |     | ✔   |
| 포스트 data 배열에 대한 JSON 키 이름 | results | data |
| 시간 세분화 단위 | 일, 시간, 또는 분 | 일, 시간, 또는 분 |
| 표준 시간대 | UTC | UTC |
| 기간 선택을 위한 요청 매개변수 | fromDate  <br />toDate | start&#95;time  <br />end&#95;time |
| 포스트 ID를 기준으로 탐색하기 위한 요청 매개변수 |     | since&#95;id  <br />until&#95;id |
| [Project](/ko/resources/fundamentals/developer-apps)와 연결된 [developer App](/ko/resources/fundamentals/developer-apps)의 자격 증명 필요 |     | ✔   |

<div id="filtering-operator-comparison">
  ### 필터링 연산자 비교
</div>

두 가지 서로 다른 버전(enterprise 및 v2)의 포스트 카운트 기능은 사용 가능한 연산자가 다르며, 각 버전 내부에서도 연산자 제공 수준이 서로 다릅니다. 이에 대한 내용은 아래에서 설명합니다.

Enterprise

* enterprise 연산자는 하위 티어가 없습니다. 모든 enterprise 연산자는 모든 enterprise 사용자에게 제공됩니다.

X API v2

* **Core:** 이 연산자는 모든 v2 사용자에게 제공됩니다.
* **Advanced:** 이 연산자는 Academic Research 접근 권한으로 승인된 사용자에게만 제공됩니다.

각 연산자 집합에 대한 자세한 내용은 다음 가이드를 참고하세요.

* [Enterprise operators](/ko/x-api/enterprise-gnip-2.0/fundamentals/search-api#building-search-queries)
* [X API v2 operators](/ko/x-api/posts/search/integrate/build-a-query)

이제 X API v2 내의 이러한 연산자 수준을 이해했으므로, 포스트 카운트에서 연산자별 사용 가능 여부를 정리한 아래 표를 확인하세요(셀을 비워 둔 경우 해당 연산자는 사용할 수 없습니다).
