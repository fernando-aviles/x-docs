<div id="helpful-tools">
  ## 유용한 도구
</div>

핵심 개념을 살펴보기 전에, 다음 도구나 코드 샘플 중 하나를 사용해 이 엔드포인트들의 기능을 먼저 테스트해 볼 것을 권장합니다.

<div id="code-samples">
  ### 코드 샘플
</div>

선호하는 프로그래밍 언어로 이 엔드포인트를 호출하는 코드를 바로 작성해 보고 싶으신가요? 시작점으로 활용할 수 있는 여러 코드 샘플을 [GitHub 페이지](https://github.com/xdevplatform/Twitter-API-v2-sample-code)에서 제공하고 있으며, 여기에는 [Python 클라이언트](https://github.com/xdevplatform/search-tweets-python)도 포함되어 있습니다.

<div id="libraries">
  ### 라이브러리
</div>

시작할 때는 다양한 [커뮤니티 서드파티 라이브러리](/ko/x-api/tools-and-libraries/overview)를 활용할 수 있습니다. v2 엔드포인트를 지원하는 라이브러리는 해당 버전 태그를 확인해 찾을 수 있습니다.

<div id="postman">
  ### Postman
</div>

Postman은 이러한 엔드포인트를 테스트하는 데 사용할 수 있는 훌륭한 도구입니다. 각 Postman 요청에는 해당 엔드포인트에 지정된 모든 매개변수가 포함되어 있어, 어떤 기능이 제공되는지 빠르게 파악하는 데 도움이 됩니다. Postman 컬렉션에 대해 자세히 알아보려면 [Postman 사용하기](/ko/tutorials/postman-getting-started) 페이지를 방문하세요.

<div id="key-concepts">
  ## 핵심 개념
</div>

<div id="authentication">
  ### 인증
</div>

모든 X API v2 엔드포인트는 키와 토큰이라고도 불리는 자격 증명 세트로 [인증](/ko/resources/fundamentals/authentication)된 요청이 필요합니다. 이 엔드포인트는 [OAuth 2.0 Bearer Token](/ko/resources/fundamentals/authentication#oauth-2-0)을 사용해야 하며, 이는 요청을 성공적으로 처리하려면 [Bearer Token](/ko/resources/fundamentals/authentication#bearer-token-also-known-as-app-only)을 함께 보내야 함을 의미합니다. Bearer Token은 개발자 App 내에서 직접 생성하거나, [POST oauth2/token](/ko/resources/fundamentals/authentication#post-oauth2-token) 엔드포인트를 사용해 생성할 수 있습니다.

<div id="developer-console-projects-and-developer-apps">
  ### 개발자 콘솔, Project, 그리고 개발자 App
</div>

어떤 X API v2 엔드포인트를 사용하려면, 먼저 [개발자 계정](/ko/resources/fundamentals/developer-portal)을 보유해야 하며, 해당 계정 내에 [Project](/ko/resources/fundamentals/developer-apps)를 설정하고, 그 Project 안에 [개발자 App](/ko/resources/fundamentals/developer-apps)을 생성해야 합니다. 해당 개발자 App 내의 키와 토큰은 최근 포스트 개수 조회 엔드포인트에서 사용할 수 있습니다. 전체 아카이브 포스트 개수 조회 엔드포인트를 사용하거나, 고급 연산자와 더 긴 쿼리 길이를 활용하려면 엔터프라이즈 액세스 승인을 받아야 합니다.

자세한 내용은 엔터프라이즈 액세스 섹션을 참조하세요.

<div id="rate-limits">
  ### 레이트 리밋
</div>

매일 수천 명이 넘는 개발자들이 X API에 요청을 보냅니다. 이 요청량을 관리하기 위해, 각 엔드포인트에는 [레이트 리밋](/ko/x-api/fundamentals/rate-limits)이 설정되어 있으며, 이는 각 개발자가 앱 또는 인증된 사용자를 대신해 보낼 수 있는 요청 수를 제한합니다.

이 엔드포인트에는 앱 레벨 레이트 리밋이 적용됩니다. 즉, 개발자인 여러분은 사용 중인 자격 증명으로 식별되는 각 앱별로, 일정 기간 동안 이 엔드포인트에 보낼 수 있는 요청 수에 제한을 받습니다.

<div id="building-queries">
  ### 쿼리 작성
</div>

이 엔드포인트의 핵심 기능은 단일 쿼리를 사용해 포스트를 필터링하고, 그 결과로 집계된 카운트를 제공한다는 점입니다. 이러한 쿼리는 메시지 키워드, 해시태그, URL과 같은 포스트 및 사용자 속성과 일치하는 연산자로 구성됩니다. 연산자는 불리언 논리와 괄호를 사용해 쿼리로 결합할 수 있으며, 이를 통해 쿼리의 일치 방식을 더욱 정교하게 조정할 수 있습니다.

자세한 내용은 [쿼리 작성 방법](/ko/x-api/posts/counts/integrate/build-a-query) 가이드를 참고하세요.

<div id="pagination">
  ### 페이지네이션
</div>

최근 포스트 개수 조회의 경우에는 next&#95;token이 반환되지 않습니다. 이는 집계 단위와 관계없이 하나의 API 호출로 지난 7일간의 포스트 개수를 모두 받는다는 의미입니다.

전체 보관소 포스트 개수 조회의 경우, 지난 30일간의 데이터를 받게 됩니다. 30일을 초과하는 데이터에 대해서는 next&#95;token이 반환되며, 이를 사용해 페이지네이션을 수행하여 추가 데이터를 가져올 수 있습니다.
