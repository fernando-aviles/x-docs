<div id="helpful-tools">
  ## 유용한 도구
</div>

몇 가지 핵심 개념을 살펴보기 전에, 다음 도구나 코드 샘플 중 하나를 사용해 각 엔드포인트의 기능을 테스트해 볼 것을 권장합니다.

<div id="code-samples">
  ### 코드 샘플
</div>

선호하는 프로그래밍 언어로 이 엔드포인트들을 사용하는 방법이 궁금하신가요? 시작점으로 활용할 수 있는 여러 가지 코드 샘플을 [GitHub 페이지](https://github.com/xdevplatform/Twitter-API-v2-sample-code)에서 제공하며, 여기에는 [Python 클라이언트](https://github.com/xdevplatform/search-tweets-python)도 포함되어 있습니다.

<div id="libraries">
  ### 라이브러리
</div>

시작하는 데 도움이 되도록 다양한 [커뮤니티 서드파티 라이브러리](/ko/x-api/tools-and-libraries/overview)를 활용할 수 있습니다. 해당 버전 태그를 확인해 v2 엔드포인트와 호환되는 라이브러리를 찾을 수 있습니다.

<div id="postman">
  ### Postman
</div>

Postman은 이러한 엔드포인트를 테스트해 볼 수 있는 유용한 도구입니다. 각 Postman 요청에는 해당 엔드포인트의 모든 매개변수가 포함되어 있어, 어떤 옵션이 제공되는지 빠르게 파악하는 데 도움이 됩니다. Postman 컬렉션에 대해 더 알아보려면 [Using Postman](/ko/tutorials/postman-getting-started) 페이지를 방문하세요.

  ## 핵심 개념
</div>

<div id="authentication">
  ### 인증
</div>

모든 X API v2 엔드포인트는 키 및 토큰이라고도 불리는 일련의 자격 증명 세트를 사용해 [인증](/ko/resources/fundamentals/authentication)된 요청이어야 합니다. 이 엔드포인트는 [OAuth 2.0 Bearer Token](/ko/resources/fundamentals/authentication#oauth-2-0)을 사용해야 하며, 이는 성공적인 요청을 보내려면 [Bearer Token](/ko/resources/fundamentals/authentication#bearer-token-also-known-as-app-only)을 함께 전달해야 함을 의미합니다. Bearer Token은 개발자 App에서 직접 생성하거나, [POST oauth2/token](/ko/resources/fundamentals/authentication#post-oauth2-token) 엔드포인트를 사용해 생성할 수 있습니다.

<div id="developer-console-projects-and-developer-apps">
  ### Developer Console, Project, 그리고 개발자 App
</div>

어떤 X API v2 엔드포인트를 사용하더라도, 먼저 [개발자 계정](/ko/resources/fundamentals/developer-portal)을 보유해야 하며, 해당 계정 내에 [Project](/ko/resources/fundamentals/developer-apps)를 설정하고, 그 Project 내에 [개발자 App](/ko/resources/fundamentals/developer-apps)을 생성해야 합니다. 해당 개발자 App에서 발급된 키와 토큰은 최근 포스트 개수 엔드포인트에서 사용할 수 있습니다. 전체 아카이브 포스트 개수 엔드포인트를 사용하거나 고급 연산자와 더 긴 쿼리 길이를 활용하려면, 엔터프라이즈 액세스 승인을 받아야 합니다.

자세한 내용은 엔터프라이즈 액세스 섹션을 참조해 주십시오.

<div id="rate-limits">
  ### 요청 한도
</div>

매일 수많은 개발자들이 X API에 요청을 보냅니다. 이 요청량을 관리하기 위해 각 엔드포인트에는 [요청 한도](/ko/x-api/fundamentals/rate-limits)가 설정되어 있으며, 이를 통해 각 개발자가 앱을 대신하거나 인증된 사용자를 대신해 보낼 수 있는 요청 수가 제한됩니다.

이 엔드포인트에는 앱 단위(App-level) 요청 한도가 적용됩니다. 이는 개발자인 여러분이 사용하는 자격 증명으로 식별되는 각 앱마다, 정해진 기간 동안 이 엔드포인트에 보낼 수 있는 요청 수가 제한된다는 의미입니다.

<div id="building-queries">
  ### 쿼리 작성
</div>

이 엔드포인트들의 핵심 기능은 단일 쿼리를 사용해 포스트를 필터링하고 그 결과를 집계해 제공하는 것입니다. 이러한 쿼리는 메시지 키워드, 해시태그, URL과 같은 포스트 및 사용자 속성과 일치하는 연산자로 구성됩니다. 연산자는 불리언 논리와 괄호를 사용해 하나의 쿼리로 결합할 수 있으며, 이를 통해 쿼리의 매칭 방식을 더 정교하게 조정할 수 있습니다.

[쿼리 작성 방법](/ko/x-api/posts/counts/integrate/build-a-query) 가이드를 참고해 더 자세히 알아볼 수 있습니다.

<div id="pagination">
  ### 페이지네이션
</div>

최근 포스트 개수에 대해서는 `next_token`이 반환되지 않습니다. 즉, 집계 단위에 관계없이 하나의 API 호출로 지난 7일 동안의 포스트 수를 모두 받게 됩니다.

전체 아카이브 포스트 개수의 경우 지난 30일간의 data를 받게 됩니다. 30일을 초과하는 기간의 data에 대해서는 `next_token`이 반환되며, 이를 사용해 페이지네이션으로 추가 data를 가져올 수 있습니다.
