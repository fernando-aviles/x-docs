이 가이드는 2006년 3월까지의 과거 포스트 수를 조회하는 방법을 설명합니다.

<Warning>
  전체 아카이브 포스트 수 기능을 사용하려면 [Self-serve](/ko/x-api/getting-started/about-x-api) 또는 [Enterprise](/ko/x-api/getting-started/about-x-api) 액세스가 필요합니다.
</Warning>

<Note>
  **사전 준비 사항**

  시작하기 전에 다음이 필요합니다.

  * Self-serve 또는 Enterprise 액세스가 있는 [개발자 계정](https://developer.x.com/en/portal/petition/essential/basic-info)
  * 앱의 Bearer Token
</Note>

<div id="get-full-archive-post-counts">
  ## 전체 아카이브 포스트 수 가져오기
</div>

<Steps>
  <Step title="쿼리 작성">
    전체 아카이브 검색과 동일한 쿼리 구문을 사용합니다. 예를 들어 @XDevelopers 계정의 포스트 개수를 집계하려면 다음과 같이 지정합니다:

    ```
    from:XDevelopers
    ```
  </Step>

  <Step title="시간 범위 설정">
    특정 과거 기간을 검색하려면 `start_time`과 `end_time`을 지정합니다:

    | 매개변수 | 형식 | 예시 |
    |:----------|:-------|:--------|
    | `start_time` | ISO 8601 | `2020-01-01T00:00:00Z` |
    | `end_time` | ISO 8601 | `2020-12-31T23:59:59Z` |
  </Step>

  <Step title="요청 보내기">
    <CodeGroup dropdown>
      ```bash cURL
      curl "https://api.x.com/2/tweets/counts/all?\
      query=from%3AXDevelopers&\
      start_time=2020-01-01T00%3A00%3A00Z&\
      end_time=2020-12-31T23%3A59%3A59Z&\
      granularity=day" \
        -H "Authorization: Bearer $BEARER_TOKEN"
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_BEARER_TOKEN")

      # 전체 아카이브 포스트 수 가져오기
      response = client.posts.count_all(
          query="from:XDevelopers",
          start_time="2020-01-01T00:00:00Z",
          end_time="2020-12-31T23:59:59Z",
          granularity="day"
      )

      for bucket in response.data:
          print(f"{bucket.start}: {bucket.tweet_count} 포스트")

      print(f"총계: {response.meta.total_tweet_count} 포스트")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

      // 전체 아카이브 포스트 수 가져오기
      const response = await client.posts.countAll({
        query: "from:XDevelopers",
        startTime: "2020-01-01T00:00:00Z",
        endTime: "2020-12-31T23:59:59Z",
        granularity: "day",
      });

      response.data?.forEach((bucket) => {
        console.log(`${bucket.start}: ${bucket.tweet_count} 포스트`);
      });

      console.log(`총계: ${response.meta?.total_tweet_count} 포스트`);
      ```
    </CodeGroup>
  </Step>

  <Step title="응답 검토">
    ```json
    {
      "data": [
        {
          "end": "2020-01-02T00:00:00.000Z",
          "start": "2020-01-01T00:00:00.000Z",
          "tweet_count": 3
        },
        {
          "end": "2020-01-03T00:00:00.000Z",
          "start": "2020-01-02T00:00:00.000Z",
          "tweet_count": 5
        }
      ],
      "meta": {
        "total_tweet_count": 8
      }
    }
    ```
  </Step>
</Steps>

<div id="granularity-options">
  ## 세분화 옵션
</div>

집계 방식(그룹화 기준)을 제어합니다:

| Granularity | 설명 |
|:------------|:------------|
| `minute` | 분 단위 개수 |
| `hour` | 시간 단위 개수(기본값) |
| `day` | 일 단위 개수 |

<div id="paginate-through-results">
  ## 결과를 페이지 단위로 조회하기
</div>

긴 기간 범위를 조회할 때는 응답의 `next_token`을 사용하세요:

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/counts/all?\
  query=from%3AXDevelopers&\
  start_time=2015-01-01T00%3A00%3A00Z&\
  end_time=2020-12-31T23%3A59%3A59Z&\
  granularity=day&\
  next_token=abc123" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 페이지네이션을 사용해 집계 결과 가져오기
  next_token = None

  while True:
      response = client.posts.count_all(
          query="from:XDevelopers",
          start_time="2015-01-01T00:00:00Z",
          end_time="2020-12-31T23:59:59Z",
          granularity="day",
          next_token=next_token
      )
      
      for bucket in response.data:
          print(f"{bucket.start}: {bucket.tweet_count}")
      
      next_token = response.meta.next_token
      if not next_token:
          break
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 페이지네이션을 사용해 집계 결과 가져오기
  let nextToken = undefined;

  do {
    const response = await client.posts.countAll({
      query: "from:XDevelopers",
      startTime: "2015-01-01T00:00:00Z",
      endTime: "2020-12-31T23:59:59Z",
      granularity: "day",
      nextToken,
    });

    response.data?.forEach((bucket) => {
      console.log(`${bucket.start}: ${bucket.tweet_count}`);
    });

    nextToken = response.meta?.next_token;
  } while (nextToken);
  ```
</CodeGroup>

<div id="key-differences-from-recent-counts">
  ## 최근 집계와의 주요 차이점
</div>

| 기능 | 최근 집계 | 전체 아카이브 집계 |
|:--------|:--------------|:--------------------|
| 시간 범위 | 최근 7일 | 2006년 3월부터 현재까지 |
| 필요한 액세스 | 모든 개발자 | 사용량 기반 과금, 엔터프라이즈 |
| 기본 시간 범위 | 최근 7일 | 최근 30일 |

<div id="common-parameters">
  ## 공통 매개변수
</div>

| Parameter | 설명 | 기본값 |
|:----------|:------------|:--------|
| `query` | 검색 쿼리(필수) | — |
| `granularity` | 시간 버킷 단위 | `hour` |
| `start_time` | 가장 이른 타임스탬프(ISO 8601) | 30일 전 |

| `next_token` | 페이지네이션 토큰 | — |
