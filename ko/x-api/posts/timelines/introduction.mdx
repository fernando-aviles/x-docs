Timelines 엔드포인트를 사용하면 사용자 타임라인, 멘션 피드, 홈 피드에서 게시물을 조회할 수 있습니다. 사용자가 작성한 게시물을 가져오고, 해당 사용자를 멘션한 게시물을 확인하거나, 해당 사용자의 개인화된 홈 타임라인을 볼 수 있습니다.

<div id="endpoints">
  ## 엔드포인트
</div>

| 메서드 | 엔드포인트 | 설명 |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/ko/x-api/users/get-posts) | 사용자의 게시물 조회 |
| GET | [`/2/users/:id/mentions`](/ko/x-api/users/get-mentions) | 사용자가 언급된 게시물 조회 |
| GET | [`/2/users/:id/timelines/reverse_chronological`](/ko/x-api/users/get-timeline) | 홈 타임라인 조회 |

<div id="reverse-chronological-home-timeline">
  ## 최신순 홈 타임라인
</div>

인증된 사용자의 홈 타임라인을 최신순으로 가져옵니다.

<div id="features">
  ### 기능
</div>

* 팔로우하는 계정의 게시물
* 최신 게시물 최대 3,200개(또는 최근 7일치)

* 사용자 인증 필요

  이 엔드포인트는 [OAuth 1.0a User Context](/ko/resources/fundamentals/authentication) 또는 [OAuth 2.0 Authorization Code with PKCE](/ko/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)가 필요합니다.
</Note>

<div id="filtering-options">
  ## 필터 옵션
</div>

<div id="exclude-parameter">
  ### exclude 매개변수
</div>

특정 게시물 type을 제외합니다:

| 값          | 효과      |
| :--------- | :------ |
| `retweets` | 리게시물 제외 |
| `replies`  | 답글 제외   |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="time-based-filtering">
  ### 시간 기반 필터링
</div>

| Parameter | Description |
|:----------|:------------|
| `start_time` | 가장 오래된 게시물의 타임스탬프(ISO 8601) |
| `end_time` | 가장 최신 게시물의 타임스탬프(ISO 8601) |
| `since_id` | 이 ID 이후의 게시물을 반환합니다 |
| `until_id` | 이 ID 이전의 게시물을 반환합니다 |
