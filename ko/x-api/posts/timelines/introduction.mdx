Timelines 엔드포인트를 사용하면 사용자 타임라인, 멘션 피드, 홈 피드에서 포스트를 조회할 수 있습니다. 특정 사용자가 작성한 포스트를 가져오거나, 해당 사용자를 언급한 포스트를 확인하거나, 그 사용자의 개인화된 홈 타임라인을 볼 수 있습니다.

<div id="endpoints">
  ## 엔드포인트
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/users/:id/tweets`](/ko/x-api/users/get-posts) | 사용자의 포스트 조회 |
| GET | [`/2/users/:id/mentions`](/ko/x-api/users/get-mentions) | 사용자를 언급한 포스트 조회 |

<div id="reverse-chronological-home-timeline">
  ## 최신순 홈 타임라인
</div>

인증된 사용자의 홈 타임라인을 최신순으로 가져옵니다.

<div id="features">
  ### 기능
</div>

* 팔로우 중인 계정의 포스트

  이 엔드포인트에는 [OAuth 1.0a User Context](/ko/resources/fundamentals/authentication) 또는 [OAuth 2.0 Authorization Code with PKCE](/ko/resources/fundamentals/authentication#oauth-2-0-authorization-code-flow-with-pkce-2)가 필요합니다.
</Note>

<div id="filtering-options">
  ## 필터링 옵션
</div>

<div id="exclude-parameter">
  ### exclude 매개변수
</div>

특정 포스트 유형을 제외합니다:

| 값          | 효과      |
| :--------- | :------ |
| `retweets` | 리포스트 제외 |
| `replies`  | 답글 제외   |

```bash
curl "https://api.x.com/2/users/123/tweets?exclude=retweets,replies" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="time-based-filtering">
  ### 시간 기반 필터링
</div>

| Parameter | Description |
|:----------|:------------|
| `start_time` | 가장 오래된 포스트의 타임스탬프(ISO 8601) |
| `end_time` | 가장 최신 포스트의 타임스탬프(ISO 8601) |
| `since_id` | 이 id 이후의 포스트를 반환합니다 |
| `until_id` | 이 id 이전의 포스트를 반환합니다 |
