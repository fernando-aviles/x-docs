<div id="helpful-tools">
  ## 유용한 도구

<div id="postman">
  #### Postman
</div>

Postman은 엔드포인트를 테스트해 볼 수 있는 매우 유용한 도구입니다. 각 Postman 요청에는 어떤 기능을 사용할 수 있는지 빠르게 파악하는 데 도움이 되도록 모든 경로 및 본문 매개변수가 포함됩니다. Postman 컬렉션에 대해 더 알아보려면 [&quot;Postman 사용하기&quot;](/ko/tutorials/postman-getting-started) 페이지를 방문하세요.

<div id="authentication">
  #### 인증
</div>

모든 X API v2 엔드포인트에서는 키와 토큰으로도 불리는 자격 증명 세트를 사용해 요청을 인증해야 합니다.

Retweets 조회 엔드포인트에 대한 요청을 인증할 때는 OAuth 1.0a User Context 또는 OAuth 2.0 Bearer Token 둘 중 하나를 사용할 수 있습니다.

Retweets 관리 엔드포인트는 OAuth 1.0a User Context 사용이 필요하며, 이는 성공적인 요청을 위해 API 키와 사용자 액세스 토큰 세트를 반드시 사용해야 함을 의미합니다. 액세스 토큰은 요청을 대신 수행하려는 해당 사용자와 연결되어 있어야 합니다. 다른 사용자의 액세스 토큰 세트를 생성하려면, 해당 사용자가 3-legged OAuth 플로를 통해 App을 승인하거나 인증해야 합니다.

OAuth 1.0a는 사용하기 까다로울 수 있습니다. 이 인증 방식에 익숙하지 않다면, 요청을 올바르게 인증하기 위해 [라이브러리](/ko/x-api/tools-and-libraries/overview) 사용을 권장합니다.

**유의 사항**

다음 필드를 요청하는 경우, OAuth 1.0a User Context가 필수입니다:

* tweet.fields.non&#95;public&#95;metrics
* tweet.fields.promoted&#95;metrics
* tweet.fields.organic&#95;metrics
* media.fields.non&#95;public&#95;metrics
* media.fields.promoted&#95;metrics
* media.fields.organic&#95;metrics

<div id="developer-console-projects-and-developer-apps">
  #### Developer Console, Project, 그리고 개발자 App
</div>

X API v2 endpoint에서 사용할 수 있는 인증 자격 증명 세트를 발급받으려면, 먼저 [개발자 계정을 신청](https://developer.x.com/en/portal/petition/essential/basic-info)하고, 해당 계정 안에 [Project](/ko/resources/fundamentals/developer-apps)를 설정한 다음, 그 Project 내에 [개발자 App](/ko/resources/fundamentals/developer-apps)을 생성해야 합니다. 그런 다음 개발자 App 내에서 키와 토큰을 확인할 수 있습니다.

<div id="rate-limits">
  #### 요청 한도
</div>

매일 수천 명이 넘는 개발자들이 X API에 요청을 보냅니다. 이러한 대량의 요청을 관리하기 위해 각 엔드포인트에는 [요청 한도](/ko/x-api/fundamentals/rate-limits)가 설정되어 있으며, 이는 앱을 대신해서 또는 인증된 사용자를 대신해서 보낼 수 있는 요청 수를 제한합니다.

리트윗 관리 엔드포인트는 15분당(사용자당) 50개의 요청으로 제한됩니다. 추가로, POST 엔드포인트의 경우 3시간 동안(사용자당, 앱당) 300개의 요청으로 제한됩니다.

리트윗 조회 엔드포인트의 경우 15분당 75개의 요청으로 제한됩니다. 또한 이 엔드포인트는 가장 최근에 리트윗한 사용자 100명만 반환합니다.

<div id="fields-and-expansions">
  #### 필드와 expansions
</div>

X API v2를 사용하면 `fields` 및 `expansions`라는 도구 세트를 통해 API에서 어떤 data를 반환받을지 정확하게 선택할 수 있습니다. `expansions` 파라미터를 사용하면 페이로드에서 참조되는 객체를 확장해 함께 반환받을 수 있습니다. 예를 들어, 이 엔드포인트를 사용하면 다음과 같은 [expansions](/ko/x-api/fundamentals/expansions)을(를) 가져올 수 있습니다:

* attachments.poll&#95;ids
* attachments.media&#95;keys
* author&#95;id, entities.mentions.username
* geo.place&#95;id
* in&#95;reply&#95;to&#95;user&#95;id,
* referenced&#95;tweets.id,
* referenced&#95;tweets.id.author&#95;id

`fields` 파라미터를 사용하면 다양한 data 객체 내에서 어떤 [fields](/ko/x-api/fundamentals/fields)를 받을지 정확하게 선택할 수 있습니다. 이 엔드포인트들은 주로 포스트 객체를 반환합니다. 기본적으로 포스트 객체는 `id`와 `text` 필드를 반환합니다. `tweet.created_at` 또는 `tweet.entities`와 같은 추가 필드를 받으려면 `fields` 파라미터를 사용해 해당 필드를 명시적으로 요청해야 합니다. 통합 시 활용을 고려할 만한 중요한 필드로는 투표 data, 메트릭, 포스트 주석(annotations), 그리고 대화 ID 필드 등이 있습니다.

[X API v2 data dictionary](/ko/x-api/fundamentals/data-dictionary)에 [fields와 expansions를 함께 사용하는 방법](/ko/x-api/fundamentals/data-dictionary#how-to-use-fields-and-expansions)에 대한 가이드를 추가해 두었습니다.

<div id="get-users-who-retweeted-a-post">
  #### 포스트를 리트윗한 사용자 조회
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/tweets/1234567890/retweeted_by?user.fields=username,verified" \
    -H "Authorization: Bearer $BEARER_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_BEARER_TOKEN")

  # 포스트를 리트윗한 사용자 조회
  response = client.posts.get_retweeted_by(
      "1234567890",
      user_fields=["username", "verified"]
  )
  for user in response.data:
      print(f"{user.username} - Verified: {user.verified}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ bearerToken: "YOUR_BEARER_TOKEN" });

  // 포스트를 리트윗한 사용자 조회
  const response = await client.posts.getRetweetedBy("1234567890", {
    userFields: ["username", "verified"],
  });

  response.data?.forEach((user) => {
    console.log(`${user.username} - Verified: ${user.verified}`);
  });
  ```
</CodeGroup>

<div id="retweet-a-post">
  #### 포스트를 리트윗하기
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/retweets" \
    -H "Authorization: OAuth ..." \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 포스트를 리트윗하기
  response = client.posts.retweet(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 포스트를 리트윗하기
  const response = await client.posts.retweet("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
