* 1% 샘플링 스트림.
* 10% 샘플링 스트림. 일반적으로 &quot;Decahose&quot;라고 불립니다.

이 스트림들은 모두 많은 양의 데이터를 전달하기 때문에 &quot;볼륨 스트림(volume streams)&quot;이라고 불립니다. 1% 스트림만으로도 매초 수십 개의 포스트가 전송될 수 있습니다. 이러한 스트림을 사용하면 트렌드를 식별·추적하고, 전반적인 여론을 모니터링하고, 전 세계 이벤트를 모니터링하는 등 다양한 작업을 수행할 수 있습니다. 

이 스트리밍 엔드포인트는 지속적인 HTTP GET 연결을 통해 [Post objects](/ko/x-api/fundamentals/data-dictionary#tweet)를 전달하며, [OAuth 2.0 App-Only](/ko/resources/fundamentals/authentication#oauth-2-0) 인증을 사용합니다. Essential 액세스의 경우 한 번에 하나의 연결만 가질 수 있습니다. 모든 액세스 레벨에서 15분 동안 최대 50번까지 연결 요청을 보낼 수 있습니다.

이 볼륨 스트림 엔드포인트는 수정된 포스트를 지원합니다. 이 엔드포인트는 포스트의 수정 이력과 함께, 포스트 ID 배열을 포함하여 수정된 포스트를 전달합니다. 수정 이력이 없는 포스트의 경우 이 배열에는 ID 하나만 포함됩니다. 수정된 포스트의 경우 이 배열에는 여러 개의 ID가 포함되며, 수정된 순서를 반영하여 오름차순으로 정렬되고, 가장 최근 버전이 배열의 마지막 위치에 있습니다. 포스트 수정이 어떻게 작동하는지에 대한 자세한 내용은 [Post edits fundamentals](/ko/x-api/fundamentals/edit-posts) 페이지를 참조하세요. 

*이러한 API를 사용하려면 먼저 엔터프라이즈 영업팀을 통해 계정을 개설해야 합니다.*

<Note>
  **계정 설정**

  이 엔드포인트에 액세스하려면 다음이 필요합니다:

  * 승인된 [개발자 계정](https://developer.x.com/en/portal/petition/essential/basic-info).
  * [Project](/ko/resources/fundamentals/developer-apps) 내에 위치한 [개발자 App](/ko/resources/fundamentals/developer-apps)의 키와 토큰을 사용해 인증해야 합니다. 

  X API v2 엔드포인트에 대한 액세스 권한을 얻는 방법에 대해 자세히 알아보려면 [시작하기 가이드](/ko/x-api/getting-started/getting-access)를 확인하세요.
</Note>
