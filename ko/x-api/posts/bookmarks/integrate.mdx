<div id="authentication">
  #### 인증
</div>

모든 X API v2 엔드포인트는 키와 토큰으로 구성된 자격 증명 세트를 사용해 요청을 인증해야 합니다.

이 특정 엔드포인트들은 [PKCE가 포함된 OAuth 2.0 Authorization Code Flow](/ko/resources/fundamentals/authentication/oauth-2-0/authorization-code)를 사용해야 하며, 이는 성공적인 요청을 위해 키와 사용자 Access Token 세트를 함께 사용해야 한다는 의미입니다. Access Token은 대신 요청을 보내려는 해당 사용자와 연결되어 있어야 합니다. 다른 사용자를 위한 Access Token 세트를 생성하려면, 그 사용자가 [Authorize URL](/ko/resources/fundamentals/authentication#authorize-url)을 통해 귀하의 App을 승인하거나 인증해야 합니다.

OAuth 2.0은 사용하기 까다로울 수 있습니다. 이 인증 방식에 익숙하지 않다면, [라이브러리](/ko/x-api/tools-and-libraries/overview)나 Postman과 같은 도구를 사용하여 요청을 올바르게 인증할 것을 권장합니다.

<div id="developer-console-projects-and-developer-apps">
  #### 개발자 콘솔, 프로젝트, 개발자 App
</div>

X API v2 엔드포인트와 함께 사용할 수 있는 인증 자격 증명 세트를 얻으려면 [개발자 계정](/ko/resources/fundamentals/developer-portal)을 보유하고, 해당 계정 내에 [Project](/ko/resources/fundamentals/developer-apps)를 설정하고, 그 Project 내에 [developer App](/ko/resources/fundamentals/developer-apps)을 생성해야 합니다. 그런 다음 해당 개발자 App 내에서 키와 토큰을 확인할 수 있습니다.

<div id="rate-limits">
  #### 요청 한도
</div>

매일 수천 명의 개발자가 X API에 요청을 보냅니다. 이렇게 막대한 수의 요청을 관리하기 위해 각 엔드포인트에는 [요청 한도](/ko/resources/fundamentals/rate-limits)가 설정되어 있으며, 이를 통해 App 또는 인증된 사용자를 대신해 보낼 수 있는 요청 수가 제한됩니다.

이 엔드포인트들은 사용자 단위로 요청이 제한되며, 이는 요청을 수행하는 인증된 사용자가 어떤 개발자 App을 사용하든 해당 엔드포인트를 호출할 수 있는 횟수에 제한이 있다는 의미입니다. GET 메서드의 경우, 사용자 요청 한도는 15분 동안 180회입니다. Bookmarks 조회 엔드포인트의 GET 메서드를 사용하면 가장 최근에 북마크한 게시물 800개를 반환받습니다. 추가로, POST 및 DELETE 메서드의 경우 사용자 요청 한도는 15분 동안 50회입니다.

<div id="get-bookmarks">
  #### 북마크 가져오기
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123/bookmarks?tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 사용자의 북마크 가져오기
  for page in client.bookmarks.get(user_id="123", tweet_fields=["created_at", "public_metrics"]):
      for post in page.data:
          print(f"{post.text} - 좋아요: {post.public_metrics.like_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 사용자의 북마크 가져오기
  const paginator = client.bookmarks.get("123", {
    tweetFields: ["created_at", "public_metrics"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text} - 좋아요: ${post.public_metrics?.like_count}`);
    });
  }
  ```
</CodeGroup>

<div id="create-a-bookmark">
  #### 북마크 생성
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/bookmarks" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 게시물을 북마크합니다
  response = client.bookmarks.create(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 게시물을 북마크합니다
  const response = await client.bookmarks.create("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
