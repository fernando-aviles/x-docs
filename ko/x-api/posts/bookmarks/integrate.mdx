<div id="postman">
  #### Postman
</div>

Postman은 엔드포인트를 손쉽게 테스트할 수 있는 유용한 도구입니다. 각 Postman 요청에는 모든 경로 및 본문 매개변수가 포함되어 있어 어떤 기능을 사용할 수 있는지 빠르게 파악하는 데 도움이 됩니다. Postman 컬렉션에 대해 더 알아보려면 [&quot;Postman 사용하기&quot;](/ko/tutorials/postman-getting-started) 페이지를 방문하세요.

<div id="authentication">
  #### 인증
</div>

모든 X API v2 엔드포인트에서는 키와 토큰이라고도 부르는 자격 증명 세트로 요청을 인증해야 합니다.

다음 엔드포인트들은 [PKCE를 사용하는 OAuth 2.0 Authorization Code Flow](/ko/resources/fundamentals/authentication/oauth-2-0/authorization-code)를 사용해야 합니다. 이는 성공적인 요청을 위해 키 세트와 사용자 액세스 토큰을 함께 사용해야 함을 의미합니다. 액세스 토큰은 여러분이 대리로 요청을 보내고자 하는 사용자와 연결되어 있어야 합니다. 다른 사용자를 위한 액세스 토큰 세트를 생성하려면, 해당 사용자가 [Authorize URL](/ko/resources/fundamentals/authentication#authorize-url)을 사용해 여러분의 앱을 승인하거나 인증해야 합니다.

OAuth 2.0은 사용하기 까다로울 수 있습니다. 이 인증 방식에 익숙하지 않다면, [라이브러리](/ko/x-api/tools-and-libraries/overview)나 Postman과 같은 도구를 사용해 요청을 올바르게 인증할 것을 권장합니다.

<div id="developer-console-projects-and-developer-apps">
  #### 개발자 콘솔, Project, 그리고 개발자 App
</div>

X API v2 엔드포인트에서 사용할 수 있는 인증 자격 증명 세트를 발급받으려면 [개발자 계정](/ko/resources/fundamentals/developer-portal)을 보유하고, 해당 계정 내에 [Project](/ko/resources/fundamentals/developer-apps)를 설정한 뒤, 그 Project 안에 [개발자 App](/ko/resources/fundamentals/developer-apps)을 생성해야 합니다. 이후 개발자 App에서 키와 토큰을 확인할 수 있습니다.

<div id="rate-limits">
  #### Rate limits
</div>

매일 수많은 개발자들이 X API에 요청을 보냅니다. 이러한 요청의 막대한 양을 관리하기 위해 각 엔드포인트에는 [rate limits](/ko/resources/fundamentals/rate-limits)가 설정되어 있으며, 이는 앱 또는 인증된 사용자를 대신해 보낼 수 있는 요청 수를 제한합니다.

이 엔드포인트는 사용자 수준에서 rate limit이 적용되며, 이는 여러분이 요청을 보내는 대상인 인증된 사용자가 어떤 개발자 App을 사용하든지에 관계없이 해당 엔드포인트를 호출할 수 있는 횟수에 제한이 있다는 의미입니다. GET 메서드의 경우 15분당 180개의 요청이라는 사용자 rate limit이 있습니다. Bookmarks 조회 엔드포인트의 GET 메서드를 사용하면 가장 최근에 북마크한 포스트 최대 800개를 반환받게 됩니다. 또한 POST 및 DELETE 메서드에는 15분당 50개의 요청이라는 사용자 rate limit이 있습니다.

<div id="get-bookmarks">
  #### 북마크 가져오기
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl "https://api.x.com/2/users/123/bookmarks?tweet.fields=created_at,public_metrics" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 사용자의 북마크를 가져옵니다.
  for page in client.bookmarks.get(user_id="123", tweet_fields=["created_at", "public_metrics"]):
      for post in page.data:
          print(f"{post.text} - Likes: {post.public_metrics.like_count}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 사용자의 북마크를 가져옵니다.
  const paginator = client.bookmarks.get("123", {
    tweetFields: ["created_at", "public_metrics"],
  });

  for await (const page of paginator) {
    page.data?.forEach((post) => {
      console.log(`${post.text} - Likes: ${post.public_metrics?.like_count}`);
    });
  }
  ```
</CodeGroup>

<div id="create-a-bookmark">
  #### 북마크 만들기
</div>

<CodeGroup dropdown>
  ```bash cURL
  curl -X POST "https://api.x.com/2/users/123/bookmarks" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"tweet_id": "1234567890"}'
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 포스트를 북마크로 저장합니다
  response = client.bookmarks.create(user_id="123", tweet_id="1234567890")
  print(response.data)
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 포스트를 북마크로 저장합니다
  const response = await client.bookmarks.create("123", { tweetId: "1234567890" });
  console.log(response.data);
  ```
</CodeGroup>
