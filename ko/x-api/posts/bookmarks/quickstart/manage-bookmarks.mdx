이 가이드는 X API를 사용해 북마크를 추가하거나 제거하는 방법을 설명합니다.

<Note>
  **사전 준비 사항**

  시작하기 전에 다음이 필요합니다.

  * 승인이 완료된 App이 연결된 [개발자 계정](https://developer.x.com/en/portal/petition/essential/basic-info)
  * `bookmark.write` 범위가 부여된 User Access Token (OAuth 2.0 PKCE)
</Note>

***

<div id="add-a-bookmark">
  ## 북마크 추가
</div>

<Steps>
  <Step title="사용자 ID 가져오기">
    인증된 사용자의 ID가 필요합니다. `/2/users/me` 엔드포인트나 [user lookup endpoint](/ko/x-api/users/lookup/introduction)를 사용해 찾을 수 있습니다.
  </Step>

  <Step title="포스트 ID 가져오기">
    포스트를 볼 때 URL에서 포스트 ID를 확인하세요:

    ```
    https://x.com/XDevelopers/status/1460323737035677698
                                    └── 여기의 값이 포스트 ID입니다
    ```
  </Step>

  <Step title="북마크 추가">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X POST "https://api.x.com/2/users/2244994945/bookmarks" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"tweet_id": "1460323737035677698"}'
      ```

      ```python Python SDK
      from xdk import Client

      client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

      # 북마크 추가
      response = client.bookmarks.create(
          user_id="2244994945",
          tweet_id="1460323737035677698"
      )

      print(f"Bookmarked: {response.data.bookmarked}")
      ```

      ```javascript JavaScript SDK
      import { Client } from "@xdevplatform/xdk";

      const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

      // 북마크 추가
      const response = await client.bookmarks.create("2244994945", {
        tweetId: "1460323737035677698",
      });

      console.log(`Bookmarked: ${response.data?.bookmarked}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="응답 확인하기">
    ```json
    {
      "data": {
        "bookmarked": true
      }
    }
    ```
  </Step>
</Steps>

<div id="remove-a-bookmark">
  ## 북마크 삭제
</div>

북마크에서 포스트를 삭제합니다:

<CodeGroup dropdown>
  ```bash cURL
  curl -X DELETE "https://api.x.com/2/users/2244994945/bookmarks/1460323737035677698" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN"
  ```

  ```python Python SDK
  from xdk import Client

  client = Client(bearer_token="YOUR_USER_ACCESS_TOKEN")

  # 북마크 삭제
  response = client.bookmarks.delete(
      user_id="2244994945",
      tweet_id="1460323737035677698"
  )

  print(f"Bookmarked: {response.data.bookmarked}")
  ```

  ```javascript JavaScript SDK
  import { Client } from "@xdevplatform/xdk";

  const client = new Client({ accessToken: "YOUR_USER_ACCESS_TOKEN" });

  // 북마크 삭제
  const response = await client.bookmarks.delete("2244994945", "1460323737035677698");

  console.log(`Bookmarked: ${response.data?.bookmarked}`);
  ```
</CodeGroup>

**응답:**

```json
{
  "data": {
    "bookmarked": false
  }
}
```

<div id="required-scopes">
  ## 필수 스코프
</div>

OAuth 2.0 PKCE를 사용할 때 액세스 토큰에는 다음 스코프가 포함되어 있어야 합니다.

| Scope | Description |
|:------|:------------|
| `bookmark.write` | 북마크 추가 및 제거 |
| `tweet.read` | 포스트 데이터 읽기 |
| `users.read` | 사용자 데이터 읽기 |
