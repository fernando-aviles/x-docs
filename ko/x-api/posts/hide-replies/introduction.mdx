Hide Replies 엔드포인트를 사용하면 인증된 사용자가 작성한 포스트에 대한 답글을 숨기거나 다시 표시할 수 있습니다. 숨겨진 답글은 여전히 볼 수 있지만, 확인하려면 추가로 한 번 더 클릭해야 합니다.

<div id="endpoint">
  ## 엔드포인트
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| PUT | [`/2/tweets/:tweet_id/hidden`](/ko/x-api/posts/hide-reply) | 답글을 숨기거나 숨기기를 해제합니다 |

***

<div id="how-it-works">
  ## 작동 방식
</div>

답글을 숨기려면 `hidden: true`를, 숨김을 해제하려면 `hidden: false`를 포함해 PUT 요청을 보내십시오:

```json
{
  "hidden": true
}
```

***

<div id="example-hide-a-reply">
  ## 예시: 답글 숨기기
</div>

```bash
curl -X PUT "https://api.x.com/2/tweets/1234567890/hidden" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"hidden": true}'
```

<div id="example-response">
  ## 응답 예시
</div>

```json
{
  "data": {
    "hidden": true
  }
}
```
