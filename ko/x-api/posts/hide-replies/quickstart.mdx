이 가이드는 사용자가 직접 시작한 대화에서 포스트에 대한 답글을 숨기고 다시 표시하는 방법을 안내합니다.

<Note>
  **사전 준비 사항**

  시작하기 전에 다음 항목이 필요합니다.

  * 승인이 완료된 App이 연결된 [개발자 계정](https://developer.x.com/en/portal/petition/essential/basic-info)
  * 사용자 액세스 토큰(User Access Token, OAuth 1.0a 또는 OAuth 2.0 PKCE)
</Note>

***

<div id="hide-a-reply">
  ## 답글 숨기기
</div>

<Steps>
  <Step title="답글의 포스트 ID 찾기" icon="message">
    숨기려는 답글의 포스트 ID를 확인합니다. 인증된 사용자가 시작한 대화에 대한 답글만 숨길 수 있습니다.

    ```
    https://x.com/user/status/1232720193182412800
                              └── 이 값이 포스트 ID입니다
    ```
  </Step>

  <Step title="숨기기 요청 보내기" icon="eye-slash">
    <CodeGroup dropdown>
      ```bash cURL
      curl -X PUT "https://api.x.com/2/tweets/1232720193182412800/hidden" \
        -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
        -H "Content-Type: application/json" \
        -d '{"hidden": true}'
      ```

      ```python Python SDK
      from xdk import Client
      from xdk.oauth1_auth import OAuth1

      oauth1 = OAuth1(
          api_key="YOUR_API_KEY",
          api_secret="YOUR_API_SECRET",
          access_token="YOUR_ACCESS_TOKEN",
          access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
      )

      client = Client(auth=oauth1)

      # 답글 숨기기
      response = client.posts.hide_reply("1232720193182412800", hidden=True)
      print(f"Hidden: {response.data.hidden}")
      ```

      ```javascript JavaScript SDK
      import { Client, OAuth1 } from "@xdevplatform/xdk";

      const oauth1 = new OAuth1({
        apiKey: "YOUR_API_KEY",
        apiSecret: "YOUR_API_SECRET",
        accessToken: "YOUR_ACCESS_TOKEN",
        accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
      });

      const client = new Client({ oauth1 });

      // 답글 숨기기
      const response = await client.posts.hideReply("1232720193182412800", {
        hidden: true,
      });
      console.log(`Hidden: ${response.data?.hidden}`);
      ```
    </CodeGroup>
  </Step>

  <Step title="답글이 숨겨졌는지 확인하기" icon="check">
    ```json
    {
      "data": {
        "hidden": true
      }
    }
    ```

    이제 해당 답글은 기본 대화 보기에서 숨겨집니다. 사용자는 &quot;숨겨진 답글 보기&quot;를 클릭하면 여전히 이 답글을 볼 수 있습니다.
  </Step>
</Steps>

***

<div id="unhide-a-reply">
  ## 답글 숨김 해제
</div>

숨겨진 답글을 다시 표시하려면:

<CodeGroup dropdown>
  ```bash cURL
  curl -X PUT "https://api.x.com/2/tweets/1232720193182412800/hidden" \
    -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"hidden": false}'
  ```

  ```python Python SDK
  from xdk import Client
  from xdk.oauth1_auth import OAuth1

  oauth1 = OAuth1(
      api_key="YOUR_API_KEY",
      api_secret="YOUR_API_SECRET",
      access_token="YOUR_ACCESS_TOKEN",
      access_token_secret="YOUR_ACCESS_TOKEN_SECRET"
  )

  client = Client(auth=oauth1)

  # 답글 숨김 해제
  response = client.posts.hide_reply("1232720193182412800", hidden=False)
  print(f"Hidden: {response.data.hidden}")
  ```

  ```javascript JavaScript SDK
  import { Client, OAuth1 } from "@xdevplatform/xdk";

  const oauth1 = new OAuth1({
    apiKey: "YOUR_API_KEY",
    apiSecret: "YOUR_API_SECRET",
    accessToken: "YOUR_ACCESS_TOKEN",
    accessTokenSecret: "YOUR_ACCESS_TOKEN_SECRET",
  });

  const client = new Client({ oauth1 });

  // 답글 숨김 해제
  const response = await client.posts.hideReply("1232720193182412800", {
    hidden: false,
  });
  console.log(`Hidden: ${response.data?.hidden}`);
  ```
</CodeGroup>

**응답:**

```json
{
  "data": {
    "hidden": false
  }
}
```

<div id="important-notes">
  ## 중요 참고 사항
</div>

<Note>
  * 사용자가 시작한 대화에 대한 답글만 숨길 수 있습니다
  * 숨겨진 답글은 여전히 &quot;숨겨진 답글 보기&quot;를 통해 볼 수 있습니다
  * 답글 작성자는 자신의 답글이 숨겨졌다는 사실에 대한 알림을 받지 않습니다
</Note>
