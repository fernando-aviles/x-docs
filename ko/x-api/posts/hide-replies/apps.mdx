  ## hide replies 엔드포인트를 사용하는 앱
</div>

다음은 hide replies 엔드포인트를 통합한 개발자들이 만든 주목할 만한 앱 모음입니다. 이들은 자신들의 기술을 X API와 결합하여, 모든 사용자가 공개 대화를 더 잘 관리하고 향상시킬 수 있는 유용한 경험을 만들어 냈습니다.

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge는 hide replies를 통합해 기업이 자사의 X 피드를 깔끔하고 읽기 좋게 유지할 수 있도록 합니다. 답글은 수동으로 숨길 수 있으며, 상담원은 Clarabridge의 텍스트 분석 기능을 사용해 욕설이나 브랜드 정책에 부합하지 않는 표현을 자동으로 감지해 숨길 수도 있습니다.

[웹사이트로 이동 ▸](https://www.clarabridge.com/ "웹사이트로 이동 ▸")

[X에서 Clarabridge 살펴보기](https://x.com/Clarabridge "Clarabridge on X")

![Perspective API 템플릿 앱](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.tagext.1920.png)

**Perspective API 템플릿 앱**

Perspective는 Jigsaw(Alphabet 산하 조직)가 유해 댓글을 감지하도록 학습시킨 인공지능입니다. 이 앱은 사용자가 받는 답글을 탐지하고, Perspective가 과거에 본 유해 댓글과 얼마나 유사한지에 대한 “점수”에 따라 자동으로 답글을 숨깁니다. 이 앱은 X가 개발한 오픈 소스 템플릿 앱입니다. 이를 각자 서비스에 맞게 커스터마이즈해 사용자용 도구를 구축해 보시기를 권장합니다.

[앱 사용하기 ▸](https://quintessential-yoke.glitch.me "앱 사용하기 ▸")

[X에서 Jigsaw 살펴보기](https://x.com/jigsaw "Jigsaw on X")

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle은 비즈니스 애플리케이션을 유연한 스크립트로 연결하는 플랫폼입니다. 이들은 사용자가 정의한 키워드를 포함하는 답글을 탐지하고 숨기는 통합 스크립트를 구축했습니다. 직접 사용해 보려면, 먼저 Hide replies용으로 활성화된 유효한 앱이 있는지 확인한 다음, 저장소의 안내를 따르십시오.

[X에서 Reshuffle 살펴보기](https://x.com/reshufflehq "Reshuffle on X")

**원치 않는 답글 숨기기**

인기 앱 QuotedReplies를 만든 개발자 Dara Oladosu는, 학대적 행동을 보일 가능성이 더 높은 것으로 본인이 판단한 몇 가지 기준을 충족하는 답글을 자동으로 숨기는 앱을 만들었습니다. 여기에는 과거에 자신이 뮤트했던 특정 키워드를 포함하는 답글 등이 포함됩니다.

**Pandaflow**

Pandaflow는 워크플로를 자동화하기 위한 노코드 플랫폼입니다. 이들은 엔드포인트를 통합해, 사용자가 정의한 커스텀 플로우에 따라 프로그래밍 방식으로 답글을 숨길 수 있도록 합니다.
