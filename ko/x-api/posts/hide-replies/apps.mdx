  ## 답글 숨기기 endpoint를 사용하는 앱
</div>

여기에는 답글 숨기기 endpoint를 연동한 개발자들이 만든 주목할 만한 앱들이 모여 있습니다. 이들은 X API와 자사 기술을 결합해 모든 사용자가 공개 대화를 더 잘 관리하고 향상시킬 수 있는 유용한 경험을 만들었습니다.

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge는 답글 숨기기 기능을 통합하여 기업이 자신의 X 피드를 깔끔하고 읽기 좋게 유지할 수 있도록 합니다. 답글은 수동으로 숨길 수도 있고, 에이전트가 Clarabridge의 텍스트 분석 기능을 사용해 비속어 및 브랜드 정책에 부합하지 않는 표현을 자동으로 감지할 수도 있습니다.

[웹사이트로 이동 ▸](https://www.clarabridge.com/ "웹사이트로 이동 ▸")

[X의 Clarabridge](https://x.com/Clarabridge "X의 Clarabridge")

![Perspective API template app](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Perspective API 템플릿 앱**

Perspective는 Jigsaw(Alphabet 산하 조직)에서 유해 댓글을 탐지하도록 학습한 인공지능입니다. 이 앱은 사용자가 받는 답글을 감지하고, Perspective가 과거에 본 유해 댓글과 얼마나 비슷한지에 대한 신뢰도를 나타내는 “점수”에 따라 해당 답글을 자동으로 숨깁니다. 이는 X에서 개발한 오픈 소스 템플릿 앱입니다. 이 템플릿을 사용자 맞춤형으로 수정해 여러분의 사용자들을 위한 도구를 만들어 보시기 바랍니다.

[앱 사용 ▸](https://quintessential-yoke.glitch.me "앱 사용 ▸")

[X의 Jigsaw](https://x.com/jigsaw "X의 Jigsaw")

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle은 비즈니스 애플리케이션을 유연한 스크립트와 연결하는 플랫폼입니다. 이들은 사용자가 정의한 키워드를 포함하는 답글을 감지해 숨기는 연동 스크립트를 만들었습니다. 사용해 보려면 먼저 Hide replies endpoint가 활성화된 유효한 앱이 있는지 확인한 다음, 저장소의 안내를 따라 진행하세요.

[앱으로 이동 ▸](https://github.com/reshufflehq/reshuffle "앱으로 이동 ▸")

[X의 Reshuffle](https://x.com/reshufflehq "X의 Reshuffle")

**원치 않는 답글 숨기기**

인기 앱 QuotedReplies의 개발자인 Dara Oladosu는, 자신이 정한 여러 기준을 충족해 학대적 행위를 보일 가능성이 높은 답글을 자동으로 숨기는 앱을 만들었습니다. 여기에는 과거에 자신이 뮤트한 특정 키워드를 포함한 답글 등이 포함됩니다.

[X의 Dara Oladosu](https://x.com/dara_tobi "X의 Dara Oladosu")

![Pandaflow](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 94 94%22%3E%3C/svg%3E)

**Pandaflow**

Pandaflow는 워크플로우를 자동화하는 노코드 플랫폼입니다. 이들은 endpoint를 통합해 사용자가 정의한 사용자 지정 플로우에 따라 프로그래밍 방식으로 답글을 숨길 수 있게 했습니다.

[앱으로 이동 ▸](https://pandaflow.io/ "앱으로 이동 ▸")

[X의 Pandaflow](https://x.com/pandaflowio "X의 Pandaflow")
