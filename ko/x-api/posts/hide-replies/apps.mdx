  ## 답글 숨기기 endpoint를 사용하는 App
</div>

다음은 답글 숨기기 endpoint를 통합한 개발자들이 만든 주목할 만한 App 모음입니다. 이들이 자체 기술을 X API와 결합해, 모든 사용자가 공개 대화를 더욱 향상시킬 수 있도록 돕는 유용한 경험을 만들어 냈습니다.

![Clarabridge](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/clarabridge.jpg.twimg.1920.jpg)

**Clarabridge**

Clarabridge는 답글 숨기기 기능을 통합해, 기업이 X 피드를 깔끔하고 읽기 좋은 상태로 유지할 수 있도록 합니다. 답글은 수동으로 숨길 수도 있고, 에이전트가 Clarabridge의 텍스트 분석 기능을 사용해 불필요한 욕설이나 브랜드 정책에 맞지 않는 표현을 자동으로 탐지해 숨길 수도 있습니다.

[웹사이트로 이동 ▸](https://www.clarabridge.com/ "웹사이트로 이동 ▸")

[X에서 Clarabridge 보기](https://x.com/Clarabridge "X에서 Clarabridge 보기")

![Perspective API 템플릿 App](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/hide-replies/perspective-logo.png.twimg.1920.png)

**Perspective API 템플릿 App**

Perspective는 Jigsaw(Alphabet 산하 조직)가 유해한 댓글을 탐지하도록 학습시킨 인공지능입니다. 이 App은 사용자가 받은 답글을 탐지하고, 과거에 보았던 유해한 댓글과 유사하다고 Perspective가 판단하는 신뢰도를 나타내는 “점수”에 따라 자동으로 답글을 숨깁니다. 이는 X에서 개발한 오픈 소스 템플릿 App입니다. 여러분이 사용자용 도구를 만들 수 있도록, 이 템플릿을 기반으로 맞춤화해 사용하시기를 권장합니다.

[App 사용하기 ▸](https://quintessential-yoke.glitch.me "App 사용하기 ▸")

[X에서 Jigsaw 보기](https://x.com/jigsaw "X에서 Jigsaw 보기")

![Reshuffle](data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 150 150%22%3E%3C/svg%3E)

**Reshuffle**

Reshuffle는 비즈니스 애플리케이션을 유연한 스크립트로 연결하는 플랫폼입니다. 이들은 사용자가 정의한 키워드를 포함하는 답글을 탐지하고 숨기는 통합 스크립트를 만들었습니다. 사용해 보려면, 먼저 Hide replies용으로 활성화된 유효한 App이 있는지 확인한 다음, 저장소에 있는 안내를 따르면 됩니다.

**원치 않는 답글 숨기기**

인기 App인 QuotedReplies를 만든 개발자 Dara Oladosu는, 자신이 정한 여러 기준을 충족하는 답글을 자동으로 숨기는 App을 만들었습니다. 여기에는 과거에 자신이 음소거했던 특정 키워드를 포함해, 학대적 행태를 보일 가능성이 높은 답글들이 포함됩니다.

**Pandaflow**

Pandaflow는 워크플로우를 자동화하는 노코드 플랫폼입니다. 이들은 endpoint를 통합해, 사용자가 정의한 커스텀 플로에 따라 프로그래밍 방식으로 답글을 숨길 수 있도록 했습니다.
