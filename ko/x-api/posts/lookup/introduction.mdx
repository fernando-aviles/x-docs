포스트 조회 엔드포인트를 사용하면 하나 이상의 포스트를 ID로 조회할 수 있습니다. 이 엔드포인트를 사용하여 최신 포스트 상세 정보를 가져오거나, 포스트의 사용 가능 여부를 확인하거나, 편집 기록을 검토할 수 있습니다.

<div id="overview">
  ## 개요
</div>

포스트는 X의 핵심 콘텐츠입니다. 각 포스트에는 다음과 같은 내용을 담을 수 있습니다:

* 최대 280자의 텍스트
* 첨부 미디어(이미지, 동영상, GIF)
* 투표, 장소, URL
* 답글, 인용, 멘션

포스트는 생성 후 30분 이내에 최대 5회까지 편집할 수 있습니다. 각 편집 시 새로운 포스트 ID가 생성되며, 편집 이력은 모두 보존됩니다.

<div id="use-cases">
  ## 사용 사례
</div>

* **포스트 내용 표시** — 애플리케이션에서 포스트 세부 정보를 표시합니다
* **게시 여부 확인** — 포스트가 아직 존재하는지 또는 삭제되었는지 확인합니다
* **규정 준수 관리** — 컴플라이언스 이벤트를 위해 포스트 변경 사항을 추적합니다
* **분석** — 특정 포스트의 참여 지표를 조회합니다
