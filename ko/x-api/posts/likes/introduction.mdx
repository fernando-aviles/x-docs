<div id="endpoints">
  ## 엔드포인트
</div>

<div id="likes-lookup">
  ### 좋아요 조회
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/tweets/:id/liking_users`](/ko/x-api/posts/get-liking-users) | 포스트에 좋아요를 누른 사용자를 조회합니다 |
| GET | [`/2/users/:id/liked_tweets`](/ko/x-api/users/get-liked-posts) | 사용자가 좋아요한 포스트를 조회합니다 |

<div id="manage-likes">
  ### 좋아요 관리
</div>

| Method | Endpoint | 설명 |
|:-------|:---------|:------------|
| POST | [`/2/users/:id/likes`](/ko/x-api/users/like-post) | 포스트에 좋아요 추가 |
| DELETE | [`/2/users/:id/likes/:tweet_id`](/ko/x-api/users/unlike-post) | 포스트의 좋아요 취소 |

***

<div id="important-notes">
  ## 중요 사항
</div>

<Note>
  좋아요한 사용자 엔드포인트는 실제 좋아요 수와 관계없이, 전체 기간 동안 각 포스트에 대해 최대 **100명**의 사용자만 반환합니다.
</Note>

***

<div id="example-get-liking-users">
  ## 예시: 좋아요한 사용자 조회
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890/liking_users?\
user.fields=username,verified" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="example-like-a-post">
  ## 예제: 포스트에 좋아요 표시하기
</div>

```bash
curl -X POST "https://api.x.com/2/users/123456789/likes" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tweet_id": "1234567890"}'
```
