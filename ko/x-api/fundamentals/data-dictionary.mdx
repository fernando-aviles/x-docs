X API는 포스트, 사용자, 미디어 등을 표현하는 구조화된 JSON 객체를 반환합니다. 이 문서는 각 객체 유형에 대해 제공되는 모든 필드를 문서화합니다.

***

<div id="quick-navigation">
  ## 빠른 탐색
</div>

| 객체 | 설명 | 필드 매개변수 |
|:-------|:------------|:-----------------|
| [포스트(트윗)](#post-tweet) | 포스트, 답글, 리포스트, 인용 포스트 | `tweet.fields` |
| [User](#user) | 계정 프로필 및 메타데이터 | `user.fields` |
| [Space](#space) | 실시간 오디오 대화 | `space.fields` |
| [List](#list) | 선별된 계정 모음 | `list.fields` |
| [Media](#media) | 이미지, 동영상, GIF | `media.fields` |
| [Poll](#poll) | 투표 질문 및 선택지 | `poll.fields` |
| [Place](#place) | 위치 및 지리 정보 | `place.fields` |

</Tip>

<div id="post-tweet">
  ## 포스트 (트윗)
</div>

포스트는 X에서 핵심 콘텐츠 단위입니다. 각 포스트 객체에는 텍스트, 메타데이터, 작성자, 미디어, 투표 등의 관련 객체에 대한 참조가 포함됩니다.

**기본 필드:** `id`, `text`, `edit_history_tweet_ids`

추가 필드를 요청하려면 `tweet.fields`를 사용하고, 관련 객체를 포함하려면 `expansions`를 사용하세요.

<div id="all-post-fields">
  ### 포스트의 모든 필드
</div>

| 필드 값                                         | 유형            | 설명                                                                                                                     | 용도                                                         |
| :------------------------------------------- | :------------ | :--------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------- |
| **id(기본값)**                                  | 문자열           | 요청된 트윗의 고유 식별자입니다.                                                                                                     | 이 값을 사용하여 프로그램에서 특정 트윗을 조회할 수 있습니다.                        |
| **text(기본값)**                                | 문자열           | 트윗의 실제 UTF-8 텍스트입니다. 허용되는 문자에 대한 자세한 내용은 [twitter-text](https://github.com/twitter/twitter-text/)를 참조하세요.              | 키워드 추출 및 감성 분석/분류에 사용할 수 있습니다.                             |
| **edit&#95;history&#95;tweet&#95;ids (기본값)** | 객체            | 트윗의 모든 버전에 대한 고유 식별자입니다. 수정된 적이 없는 트윗은 ID가 하나이고, 수정 내역이 있는 트윗은 여러 개의 ID가 존재합니다.                                        | 이 정보를 사용하여 트윗의 수정 내역을 조회할 수 있습니다.                          |
| **article**                                  | 객체            | 이 트윗에 포함된 Article의 메타데이터를 포함합니다.                                                                                       | 이를 사용하여 Article의 텍스트와 엔티티를 가져올 수 있습니다.                     |
| **attachments**                              | 객체            | 이 트윗에 포함된 첨부 요소(있는 경우)의 유형을 지정합니다.                                                                                     | 요청한 expansions에 대해 반환된 첨부 객체를 해석하는 데 사용할 수 있습니다.           |
| **author&#95;id**                            | 문자열           | 이 트윗을 게시한 사용자(User)의 고유 식별자입니다.                                                                                        | User 객체를 hydrate(복원)하거나, 동료 검토를 위해 데이터셋을 공유할 때 사용할 수 있습니다. |
| **card&#95;uri**                             | 문자열           | 이 트윗에 포함된 카드(Card)의 URI입니다.                                                                                            |                                                            |
| **community&#95;id**                         | 문자열           | 이 포스트가 속한 커뮤니티(Community)의 고유 식별자입니다.                                                                                  |                                                            |
| **context&#95;annotations**                  | 배열            | 트윗에 대한 컨텍스트 주석(context annotations)을 포함합니다.                                                                            | 엔티티 인식/추출 및 토픽 분석에 사용할 수 있습니다.                             |
| **conversation&#95;id**                      | 문자열           | 대화(직접 답글 및 답글에 대한 답글을 포함)의 원본 트윗 ID입니다.                                                                                | 이 값을 사용하여 특정 트윗을 기준으로 대화를 재구성할 수 있습니다.                     |
| **created&#95;at**                           | 날짜 (ISO 8601) | 트윗이 생성된 시각입니다.                                                                                                         | 시계열 분석 및 트윗 생성 시점을 파악하는 데 유용합니다.                           |
| **display&#95;text&#95;range**               | 배열            | 표시되는 텍스트 구간의 시작 인덱스와 끝 인덱스를 포함하는 배열입니다.                                                                                | 긴 포스트에서 기본적으로 어느 텍스트 구간이 표시되는지 파악하는 데 유용합니다.               |
| **edit&#95;controls**                        | 객체            | 트윗을 앞으로 얼마나 더 수정할 수 있는지와 남은 수정 가능 횟수를 나타냅니다.                                                                           | 해당 트윗이 수정 가능 상태인지 판별하는 데 사용할 수 있습니다.                       |
| **entities**                                 | 객체            | 트윗 텍스트에서 파싱된 엔티티를 포함합니다. 자세한 내용은 X 객체의 entities 필드를 참조하세요.                                                             | 해시태그, URL, 멘션 등과 관련된 추가 정보를 제공합니다.                         |
| **geo**                                      | 객체            | 지오태그가 포함된 트윗이 가리키는 위치(장소)를 나타냅니다.                                                                                      | 지오태그가 포함된 트윗의 위치를 식별하는 데 사용합니다.                            |
| **in&#95;reply&#95;to&#95;user&#95;id**      | 문자열           | 표시되는 트윗이 답글인 경우, 이 필드에는 원본 트윗 작성자의 ID가 포함됩니다.                                                                          | 해당 트윗이 다른 트윗에 대한 답글인지 여부를 판단하는 데 사용합니다.                    |
| **lang**                                     | 문자열           | X에서 감지한 경우, 트윗의 언어입니다.                                                                                                 | 트윗을 사용 언어별로 분류하는 데 사용합니다.                                  |
| **non&#95;public&#95;metrics**               | 객체            | 요청 시점을 기준으로 트윗에 대해 집계된 비공개 참여 지표입니다. 사용자 컨텍스트 인증이 필요합니다.                                                               | 해당 트윗으로 생성된 전체 노출 수를 파악하는 데 사용합니다.                         |
| **note&#95;tweet**                           | 객체            | 장문 포스트(280자 초과)의 경우, 포스트의 전체 텍스트를 포함합니다.                                                                               | 포스트의 전체 텍스트를 가져오는 데 사용합니다.                                 |
| **organic&#95;metrics**                      | 객체            | 요청 시점을 기준으로 트윗에 대해, 오가닉(유료 프로모션이 아닌) 컨텍스트에서 집계된 참여 지표입니다. 사용자 컨텍스트 인증이 필요합니다.                                          | 트윗의 오가닉 참여도를 측정하는 데 사용합니다.                                 |
| **possibly&#95;sensitive**                   | 불리언           | 콘텐츠가 민감한 것으로 간주될 수 있는지를 나타냅니다.                                                                                         | 특정 유형의 콘텐츠가 어떻게 유통되는지 분석하는 데 사용합니다.                        |
| **promoted&#95;metrics**                     | 객체            | 요청 시점을 기준으로 트윗에 대해, 프로모션(유료 광고) 컨텍스트에서 집계된 참여 지표입니다. 사용자 컨텍스트 인증이 필요합니다.                                               | 트윗이 프로모션되었을 때의 참여도를 측정하는 데 사용합니다.                          |
| **public&#95;metrics**                       | 객체            | 요청 시점을 기준으로 트윗에 대해 집계된 공개 참여 지표입니다.                                                                                    | 트윗의 공개 참여도를 측정하는 데 사용합니다.                                  |
| **referenced&#95;tweets**                    | 배열            | 이 트윗이 참조하는 트윗 목록으로, 리트윗, 인용 트윗, 답글 등이 포함됩니다.                                                                           | 리트윗, 인용, 답글 등과 관련된 대화 맥락을 이해하는 데 사용합니다.                    |
| **reply&#95;settings**                       | 문자열           | 해당 트윗에 누가 답글을 남길 수 있는지를 나타냅니다. 가능한 값은 &quot;everyone&quot;, &quot;mentioned&#95;users&quot;, &quot;followers&quot;입니다. | 트윗의 답글 허용 범위 설정을 확인하는 데 사용합니다.                             |
| **withheld**                                 | 객체            | [제한된 콘텐츠](https://help.x.com/en/rules-and-policies/tweet-withheld-by-country)에 대한 제한 관련 세부 정보를 포함합니다.                  |                                                            |
| **scopes**                                   | 객체            | 트윗의 노출 범위(scope)에 대한 세부 정보를 포함합니다.                                                                                     | 이 포스트를 볼 수 있는 대상을 나타냅니다. 프로모션된 포스트에만 반환됩니다.                |
| **media&#95;metadata**                       | 배열            | 트윗에 첨부된 미디어에 대한 메타데이터를 포함합니다.                                                                                          | 트윗에 첨부된 미디어의 `alt_text`와 같은 추가 메타데이터를 조회할 수 있습니다.          |

**트윗 객체 가져오기**

**요청 예제**

다음 요청에서는 [Tweets lookup](/ko/resources/fundamentals/rate-limits) 엔드포인트에서 해당 트윗의 필드를 요청합니다. `$BEARER_TOKEN`을 본인이 발급받은 [Bearer Token](/ko/resources/fundamentals/authentication)으로 바꿔서 사용해야 합니다.

```bash
curl --request GET 'https://api.x.com/2/tweets?ids=1212092628029698048&tweet.fields=attachments,author_id,context_annotations,created_at,entities,geo,id,in_reply_to_user_id,lang,possibly_sensitive,public_metrics,referenced_tweets,text,withheld&expansions=referenced_tweets.id' --header 'Authorization: Bearer $BEARER_TOKEN'
```

user 객체에는 참조된 사용자를 설명하는 Twitter 사용자 계정 메타데이터가 포함되어 있습니다. user 객체는 [users lookup](/ko/x-api/users/lookup/introduction) 엔드포인트에서 반환되는 기본 객체입니다. 이 엔드포인트에서 추가 사용자 필드를 요청하려면 `user.fields` 필드 파라미터를 사용하면 됩니다.

user 객체는 Tweet 객체의 하위 객체로도 포함되며, 확장되어 반환될 수 있습니다. 이 객체는 기본 필드만 포함된 간략한 형태로 가져오기 위해 `?expansions=author_id` 또는 `?expansions=in_reply_to_user_id`와 함께 expansion 대상으로 사용할 수 있습니다. 객체를 완전하게 가져오기 위해 추가 필드를 요청하려면 필드 파라미터 `user.fields`와 함께 해당 expansion을 사용하십시오.

<div id="space">
  ### Space
</div>

Space는 실시간 오디오 대화를 통해 표현과 상호작용을 가능하게 합니다. Space 데이터 사전에는 Space에 대한 관련 메타데이터가 포함되어 있으며, 모든 세부 정보는 실시간으로 업데이트됩니다.

User 객체는 User 리소스에서 찾을 수 있으며, `host_ids`, `creator_id`, `speaker_ids`, `mentioned_user_ids` 중 하나 이상을 `expansions` 쿼리 매개변수에 추가하여 확장할 수 있습니다.

트윗과 달리 Space는 일시적이며 종료되거나 생성자가 취소하면 더 이상 이용할 수 없습니다. 앱에서 Space 데이터를 처리할 때는 가장 최신 정보를 제공할 책임이 있으며, 플랫폼에서 더 이상 제공되지 않는 데이터는 삭제해야 합니다. [Spaces 조회 엔드포인트](/ko/x-api/spaces/lookup/introduction)는 사용자의 기대와 의도를 준수하는 데 도움을 줄 수 있습니다.

<div id="list">
  ### 목록
</div>

List 객체에는 참조된 List를 설명하는 [Twitter Lists](https://help.x.com/en/using-twitter/twitter-lists) 메타데이터가 포함됩니다. List 객체는 List lookup 엔드포인트에서 기본적으로 반환되는 주요 객체입니다. 이 엔드포인트에서 추가 List 필드를 요청하려면 `list.fields` 필드 매개변수를 사용하면 됩니다.

List 객체는 다른 data 객체의 하위 객체로 포함되지 않습니다. 그러나 user 객체는 user 리소스에서 조회하고 expansions를 통해 확장할 수 있습니다. 이러한 객체는 `expansions` 쿼리 매개변수에 `owner_id`를 추가하여 확장할 수 있습니다. 기본 List 객체를 완성하기 위해 추가 필드를 요청할 때 `list.fields` 필드 매개변수와, 확장 객체를 완성하기 위해 `user.fields`를 함께 사용하십시오.

| Field Value        | Type          | Description                                                                                                                          | How it can be used                                        |
| :----------------- | :------------ | :----------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------- |
| id (default)       | 문자열           | 이 List의 고유 식별자입니다.<br />`"id": "2244994945"`                                                                                         | 특정 List에 대한 정보를 프로그래밍 방식으로 조회하는 데 사용합니다.                  |
| name (default)     | 문자열           | List를 생성할 때 지정한 List의 이름입니다.<br />`"name": "Twitter Lists"`                                                                          |                                                           |
| created&#95;at     | 날짜 (ISO 8601) | List가 생성된 UTC 날짜 및 시간입니다.<br />`"created_at": "2013-12-14T04:35:55.000Z"`                                                            | List가 Twitter에서 얼마나 오래 존재했는지 확인하는 데 사용할 수 있습니다.           |
| description        | 문자열           | 사용자에게 List에 대해 알려 주는 간단한 설명입니다.<br />`"description": "People that are active members of the Bay area cycling community on Twitter."` |                                                           |

| owner&#95;id       | 문자열           | 이 List 소유자의 고유 식별자입니다.<br />`"owner_id": "1255542774432063488"`                                                                      | 이 사용자가 다른 List도 소유하고 있는지 확인하고 User 객체를 확장하는 데 사용할 수 있습니다. |

<div id="direct-message-events">
  ### Direct Message 이벤트
</div>

Direct Message(DM) 대화는 여러 이벤트로 구성됩니다. X API v2는 현재 세 가지 이벤트 유형을 지원합니다: MessageCreate, ParticipantsJoin, ParticipantsLeave.

DM 이벤트 객체는 [Direct Message 조회](/ko/x-api/direct-messages/lookup/introduction) 엔드포인트에서 반환되며, [Direct Message 관리](/ko/x-api/direct-messages/lookup/introduction) 엔드포인트를 통해 Direct Message가 성공적으로 생성되면 MessageCreate 이벤트가 생성됩니다.

DM 이벤트를 요청하면 기본적으로 포함되는 이벤트 객체 속성(또는 필드)은 세 가지입니다: `id`, `event_type`, `text`. 추가 이벤트 필드를 응답에 포함하려면 [fields](/ko/x-api/fundamentals/fields) 파라미터인 `dm_event.fields`를 사용하여 다른 필드를 선택할 수 있습니다. 사용 가능한 기타 이벤트 필드는 다음과 같습니다: `dm_conversation_id`, `created_at`, `sender_id`, `attachments`, `participant_ids`, `referenced_tweets`.

이 필드들 중 여러 개는 Direct Message 이벤트와 관련된 다른 X 객체의 ID를 제공합니다:

* `sender_id` - 메시지를 보낸 계정 또는 그룹 대화에 참여자를 초대한 계정의 ID
* `partricipants_ids` - 계정 ID 배열입니다. ParticipantsJoin 및 ParticipantsLeave 이벤트의 경우 이 배열에는 이벤트를 생성한 계정의 단일 ID가 포함됩니다.
* `attachments` - 발신자가 Twitter에 업로드한 콘텐츠의 미디어 ID를 제공합니다.
* `referenced_tweets` - `text` 필드에서 트윗 URL이 발견되면, 해당 트윗의 ID가 응답에 포함됩니다.

`sender_id`, `participant_ids`, `referenced_tweets.id`, `attachments.media_keys`에 대한 [expansions](/ko/x-api/fundamentals/expansions)를 사용하여 이러한 Twitter 객체 ID를 확장할 수 있습니다.

| :--- | :--- | :--- | :--- |
| **Field value** | **Type** | **Description** | **How it can be used** |
| id (default) | string | 이벤트의 고유 식별자입니다.<br /><br />&quot;id&quot;: &quot;1050118621198921728&quot; | 이를 사용해 프로그래밍 방식으로 특정 대화 이벤트를 조회할 수 있습니다(v1.1 엔드포인트에서 사용 가능). |
| event&#95;type (default) | string | 이벤트의 유형을 설명합니다. 현재 세 가지 유형이 지원됩니다:<br /><br />* MessageCreate<br />    <br />* ParticipantsJoin<br />    <br />* ParticipantsLeave<br />    <br /><br />&quot;event&#95;type&quot;: &quot;MessageCreate&quot; | 대화 내역을 조회할 때 메시지가 언제 생성되었는지 파악하고, 그룹 대화의 경우 참가자가 언제 참여하고 나갔는지 이해하는 데 사용합니다. 모든 GET 메서드는 event&#95;type= 형태의 쿼리 매개변수를 사용해 특정 이벤트 유형으로 필터링하는 기능을 지원합니다. |

* 참조된 트윗의 텍스트와 게시 시점

  ### 커뮤니티

커뮤니티는 X 사용자들이 서로 연결하고, 공유하고, 가장 관심 있는 주제에 대해 더 깊이 토론할 수 있도록 마련된 전용 공간입니다.

커뮤니티의 포스트는 X의 누구나 볼 수 있지만, 해당 커뮤니티 구성원만 상호작용하고 토론에 참여할 수 있습니다.

<div id="how-to-use-fields-and-expansions">
  ## fields 및 expansions 사용 방법
</div>

기본적으로 X API v2 데이터 객체는 [fields](/ko/x-api/fundamentals/fields) 또는 [expansions](/ko/x-api/fundamentals/expansions) 매개변수를 사용하지 않고 요청을 보낼 경우 소수의 기본 필드만 포함합니다. 이 가이드는 요청에서 `fields` 및 `expansions` 쿼리 매개변수를 사용하여 응답에서 추가 객체와 필드를 받아오는 방법을 보여줍니다.

이 가이드에서는 아래 트윗 스크린샷에 대해 여러 필드를 요청해 보겠습니다.
 

![이 이미지는 @X 계정이 게시한 트윗의 스크린샷입니다. 트윗 텍스트, 사용자 이름, 게시 일시, 소스, 공개 지표를 볼 수 있으며, 동영상도 포함되어 있습니다.](https://cdn.cms-twdigitalassets.com/content/dam/developer-twitter/ScreenShotDataDictionaryGuide.png.twimg.1920.png)

스크린샷에서 볼 수 있듯이, 트윗 작성자, 트윗 지표, 생성 타임스탬프, 동영상, 동영상 조회 수 등 트윗과 관련된 여러 정보가 화면에 표시됩니다. 또한 스크린샷에는 보이지 않지만 여전히 요청할 수 있는 여러 데이터도 존재합니다. 

API에 요청을 보낼 때 기본 응답은 단순하며, 기본 트윗 필드(id와 text)만 포함합니다. 또한 사용 중인 엔드포인트에서 반환되는 기본 객체만 수신하며, 기본 객체와 연관될 수 있는 다른 관련 데이터 객체는 기본적으로 포함되지 않습니다.

이러한 단순한 기본 동작과 `fields`, `expansions` 매개변수를 함께 사용하면, 사용 사례에 따라 필요한 필드만 선택적으로 요청할 수 있습니다. 
 

<div id="requesting-additional-fields-and-objects">
  #### 추가 필드 및 객체 요청
</div>

먼저 트윗 ID와 [GET /tweets 엔드포인트](/ko/x-api/posts/lookup/introduction)를 사용하여 [트윗 객체](/ko/x-api/fundamentals/data-dictionary#tweet)를 요청합니다.

요청:

```bash
curl --request GET --url 'https://api.x.com/2/tweets?ids=1260294888811347969' \
  --header 'Authorization: Bearer $BEARER_TOKEN'
```

응답:

```
{
    "data": [
        {
            "id": "1260294888811347969",
            "text": "내 트윗에 대한 트윗을 놓치지 마세요. \n\niOS에서 이제 댓글이 포함된 리트윗을 한곳에서 모두 확인할 수 있습니다. https://t.co/oanjZfzC6y"
        }
    ]
}
```

다음 단계별 가이드에서는 스크린샷에 표시된 추가 데이터를 가져오는 방법을 안내합니다.

1. 요청할 추가 필드를 정하려면 [오브젝트 모델](/ko/x-api/fundamentals/data-dictionary#tweet)을 사용하거나, 엔드포인트의 API 레퍼런스 페이지에 나열된 필드 목록을 검토하세요.

   이 경우 다음과 같은 추가 필드를 요청합니다:
   attachments, author&#95;id, created&#95;at, public&#95;metrics.

2. 위 필드를 값으로 사용하여 `tweet.fields` 쿼리 매개변수를 콤마로 구분된 목록으로 만듭니다:
   `?tweet.fields=attachments,author_id,created_at,public_metrics`

3. 이전에 수행한 GET /tweets 요청에 쿼리 매개변수를 추가하세요.

요청:

`curl --request GET --url 'https://api.x.com/2/tweets?ids=1260294888811347969&tweet.fields=attachments,author_id,created_at,public_metrics' \   --header 'Authorization: Bearer $BEARER_TOKEN'`

응답:

```
{

        {
            "id": "1260294888811347969",

            "author_id": "783214",
            "public_metrics": {

```

4. 다음으로, 트윗에 포함된 동영상 관련 필드를 요청합니다. 이를 위해 `expansions` 매개변수에 `attachments.media_keys` 값을 지정하여 요청에 추가합니다.

?expansions=attachments.media&#95;keys

요청:

```bash
curl --request GET --url 'https://api.x.com/2/tweets?ids=1260294888811347969&tweet.fields=attachments,author_id,created_at,public_metrics&expansions=attachments.media_keys' \
  --header 'Authorization: Bearer $BEARER_TOKEN'
```

?media.fields=public&#95;metrics,duration&#95;ms

요청:
 

`curl --request GET --url 'https://api.x.com/2/tweets?ids=1260294888811347969&tweet.fields=attachments,author_id,created_at,public_metrics&expansions=attachments.media_keys&media.fields=duration_ms,public_metrics' --header 'Authorization: Bearer $BEARER_TOKEN'`

* media.fields=public&#95;metrics,duration&#95;ms

