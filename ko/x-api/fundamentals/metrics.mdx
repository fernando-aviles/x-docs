X API는 포스트와 미디어에 대한 참여 지표를 제공합니다. 공개 지표는 어떤 인증 방식으로든 조회할 수 있으며, 사용자 인증을 사용하면 본인 콘텐츠에 대한 비공개 지표를 조회할 수 있습니다.

***

<div id="metric-types">
  ## 지표 유형
</div>

| 유형 | 인증 | 설명 |
|:-----|:---------------|:------------|
| **Public** | Bearer Token | 누구나 볼 수 있는 지표 (좋아요, 리포스트, 답글) |
| **Non-public** | 사용자 컨텍스트 | 비공개 지표 (노출 수, 클릭 수) |
| **Organic** | 사용자 컨텍스트 | 프로모션되지 않은 노출에서 발생한 오가닉 지표 |
| **Promoted** | 사용자 컨텍스트 | 광고 노출에서 발생한 프로모션 지표 |

<Note>
  **30일 제한**: 비공개, 오가닉, 프로모션 지표는 지난 30일 이내에 생성된 포스트에 대해서만 제공됩니다.
</Note>

<div id="available-metrics">
  ## 제공되는 지표
</div>

<div id="post-metrics">
  ### 포스트 메트릭
</div>

| 메트릭 | 유형 | 필드 경로 |
|:-------|:-----|:-----------|
| 리포스트 수 | 공개 | `public_metrics.retweet_count` |
| 인용 수 | 공개 | `public_metrics.quote_count` |
| 좋아요 수 | 공개 | `public_metrics.like_count` |
| 답글 수 | 공개 | `public_metrics.reply_count` |
| 노출 수 | 비공개 | `non_public_metrics.impression_count` |
| URL 클릭 수 | 비공개 | `non_public_metrics.url_link_clicks` |
| 프로필 클릭 수 | 비공개 | `non_public_metrics.user_profile_clicks` |

<div id="media-metrics-videos">
  ### 미디어 지표(동영상)
</div>

| 지표 | 유형 | 필드 경로 |
|:-------|:-----|:-----------|
| 조회수 | 공개 | `public_metrics.view_count` |
| 재생 0% | 비공개 | `non_public_metrics.playback_0_count` |
| 재생 25% | 비공개 | `non_public_metrics.playback_25_count` |
| 재생 50% | 비공개 | `non_public_metrics.playback_50_count` |
| 재생 75% | 비공개 | `non_public_metrics.playback_75_count` |
| 재생 100% | 비공개 | `non_public_metrics.playback_100_count` |

<div id="requesting-metrics">
  ## 메트릭 요청하기
</div>

<div id="public-metrics-any-auth">
  ### 공개 메트릭(모든 인증 방식)
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

응답:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "public_metrics": {
      "retweet_count": 50,
      "reply_count": 12,
      "like_count": 234,
      "quote_count": 5
    }
  }
}
```

<div id="private-metrics-user-context">
  ### 비공개 메트릭(사용자 컨텍스트)
</div>

본인이 소유한 포스트에 사용자 컨텍스트로 접근하려면 OAuth 1.0a 또는 OAuth 2.0이 필요합니다:

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=non_public_metrics,organic_metrics" \
  -H "Authorization: OAuth oauth_consumer_key=...,oauth_token=..."
```

응답:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "non_public_metrics": {
      "impression_count": 5432,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    },
    "organic_metrics": {
      "impression_count": 5432,
      "like_count": 234,
      "reply_count": 12,
      "retweet_count": 50,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    }
  }
}
```

<div id="video-metrics">
  ## 동영상 지표
</div>

동영상 재생 관련 지표에는 media 확장을 사용하세요:

```bash
curl "https://api.x.com/2/tweets/1234567890?\
tweet.fields=attachments&\
expansions=attachments.media_keys&\
media.fields=public_metrics,non_public_metrics" \
  -H "Authorization: OAuth ..."
```

응답:

```json
{
  "data": {
    "id": "1234567890",
    "text": "이 비디오를 확인하세요!",
    "attachments": {
      "media_keys": ["13_9876543210"]
    }
  },
  "includes": {
    "media": [{
      "media_key": "13_9876543210",
      "type": "video",
      "public_metrics": {
        "view_count": 12543
      },
      "non_public_metrics": {
        "playback_0_count": 12543,
        "playback_25_count": 9876,
        "playback_50_count": 7654,
        "playback_75_count": 5432,
        "playback_100_count": 3210
      }
    }]
  }
}
```

<div id="organic-vs-promoted-metrics">
  ## 자연(Organic) 지표 vs. 프로모션(Promoted) 지표
</div>

포스트를 광고로 집행한 경우, 지표는 자연 노출과 프로모션 노출로 구분됩니다:

| Context      | Description                   |
| :----------- | :---------------------------- |
| **Organic**  | 일반 타임라인 노출에서 생성된 지표           |
| **Promoted** | 유료 광고 노출에서 생성된 지표             |
| **Public**   | 합산된 전체 지표(Organic + Promoted) |

세부 내역을 보려면 둘 다 요청하세요:

```bash
tweet.fields=public_metrics,organic_metrics,promoted_metrics
```

<div id="metric-definitions">
  ## 측정항목 정의
</div>

<Accordion title="노출 수">
  포스트가 사용자의 화면에 표시된 횟수입니다. 고유 사용자 기준이 아니며, 동일한 사용자가 두 번 본 경우 노출 수 2회로 계산됩니다.
</Accordion>

<Accordion title="리포스트 수">
  리포스트(리트윗) 횟수입니다. 인용 포스트는 포함되지 않습니다.
</Accordion>

<Accordion title="인용 수">
  인용 포스트(코멘트가 있는 리포스트) 횟수입니다. 항상 오가닉입니다.
</Accordion>

<Accordion title="동영상 조회수">
  해당 동영상을 포함하는 모든 포스트를 기준으로 합산한 수치입니다. 하나의 동영상이 여러 포스트에서 리포스트된 경우에도 동영상별로 하나의 총 조회수로 집계됩니다.
</Accordion>

<Accordion title="재생 구간별 완료율(쿼타일)">
  동영상의 각 구간(퍼센트)까지 재생을 완료한 고유 사용자 수입니다. 시청 이탈 구간을 파악하는 데 유용합니다.
</Accordion>

  ## 요구 사항 요약
</div>

|:-------------|:-----------------------|

| `promoted_metrics` | 사용자 컨텍스트 (프로모션된 포스트만) |
