X API는 포스트와 미디어에 대한 참여 지표를 제공합니다. 어떤 인증 방식으로든 공개 지표를 조회하거나, 사용자 인증을 통해 자신의 콘텐츠에 대한 비공개 지표를 조회할 수 있습니다.

***

<div id="metric-types">
  ## 메트릭 유형
</div>

| 유형 | 인증 | 설명 |
|:-----|:---------------|:------------|
| **공개** | Bearer Token | 모든 사용자에게 보이는 메트릭 (좋아요, 리포스트, 답글) |
| **비공개** | 사용자 컨텍스트 | 비공개 메트릭 (노출 수, 클릭 수) |
| **오가닉** | 사용자 컨텍스트 | 프로모션되지 않은 조회에서 발생한 메트릭 |
| **프로모션** | 사용자 컨텍스트 | 광고 조회에서 발생한 메트릭 |

<Note>
  **30일 제한**: 비공개, 오가닉, 프로모션 메트릭은 최근 30일 이내에 작성된 포스트에 대해서만 제공됩니다.
</Note>

***

<div id="available-metrics">
  ## 사용 가능한 지표
</div>

<div id="post-metrics">
  ### 포스트 메트릭
</div>

| 메트릭 | 유형 | 필드 경로 |
|:-------|:-----|:-----------|
| 리포스트 | 공개 | `public_metrics.retweet_count` |
| 인용 | 공개 | `public_metrics.quote_count` |
| 좋아요 | 공개 | `public_metrics.like_count` |
| 답글 | 공개 | `public_metrics.reply_count` |
| 노출 수 | 비공개 | `non_public_metrics.impression_count` |
| URL 클릭 수 | 비공개 | `non_public_metrics.url_link_clicks` |
| 프로필 클릭 수 | 비공개 | `non_public_metrics.user_profile_clicks` |

<div id="media-metrics-videos">
  ### 미디어 메트릭(동영상)
</div>

| Metric | 유형 | 필드 경로 |
|:-------|:-----|:-----------|
| 조회수 | 공개 | `public_metrics.view_count` |
| 재생 0% | 비공개 | `non_public_metrics.playback_0_count` |
| 재생 25% | 비공개 | `non_public_metrics.playback_25_count` |
| 재생 50% | 비공개 | `non_public_metrics.playback_50_count` |
| 재생 75% | 비공개 | `non_public_metrics.playback_75_count` |
| 재생 100% | 비공개 | `non_public_metrics.playback_100_count` |

<div id="requesting-metrics">
  ## 메트릭 요청
</div>

<div id="public-metrics-any-auth">
  ### 공개 지표(모든 인증 방식)
</div>

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

응답:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "public_metrics": {
      "retweet_count": 50,
      "reply_count": 12,
      "like_count": 234,
      "quote_count": 5
    }
  }
}
```

<div id="private-metrics-user-context">
  ### 비공개 지표(사용자 컨텍스트)
</div>

사용자가 소유한 포스트에는 OAuth 1.0a 또는 사용자 컨텍스트가 포함된 OAuth 2.0이 필요합니다:

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=non_public_metrics,organic_metrics" \
  -H "Authorization: OAuth oauth_consumer_key=...,oauth_token=..."
```

응답:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "non_public_metrics": {
      "impression_count": 5432,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    },
    "organic_metrics": {
      "impression_count": 5432,
      "like_count": 234,
      "reply_count": 12,
      "retweet_count": 50,
      "url_link_clicks": 89,
      "user_profile_clicks": 156
    }
  }
}
```

<div id="video-metrics">
  ## 동영상 메트릭
</div>

동영상 재생 메트릭에는 `media` 확장을 사용합니다:

```bash
curl "https://api.x.com/2/tweets/1234567890?\
tweet.fields=attachments&\
expansions=attachments.media_keys&\
media.fields=public_metrics,non_public_metrics" \
  -H "Authorization: OAuth ..."
```

응답:

```json
{
  "data": {
    "id": "1234567890",
    "text": "이 비디오를 확인하세요!",
    "attachments": {
      "media_keys": ["13_9876543210"]
    }
  },
  "includes": {
    "media": [{
      "media_key": "13_9876543210",
      "type": "video",
      "public_metrics": {
        "view_count": 12543
      },
      "non_public_metrics": {
        "playback_0_count": 12543,
        "playback_25_count": 9876,
        "playback_50_count": 7654,
        "playback_75_count": 5432,
        "playback_100_count": 3210
      }
    }]
  }
}
```

<div id="organic-vs-promoted-metrics">
  ## 자연 vs. 프로모션 지표
</div>

포스트가 광고로 프로모션된 경우, 지표는 자연 노출과 프로모션 노출로 나뉩니다:

| Context   | Description               |
| :-------- | :------------------------ |
| **자연 노출** | 일반 타임라인 노출에서 발생한 지표       |
| **프로모션**  | 유료 광고 노출에서 발생한 지표         |
| **공개**    | 자연 노출과 프로모션 노출을 합산한 전체 지표 |

세부 분포를 확인하려면 두 가지 모두를 요청하십시오:

```bash
tweet.fields=public_metrics,organic_metrics,promoted_metrics
```

<div id="metric-definitions">
  ## 지표 정의
</div>

<Accordion title="노출 수">
  포스트가 사용자의 화면에 표시된 횟수입니다. 고유 사용자를 기준으로 하지 않으며, 동일한 사용자가 두 번 본 경우 두 번의 노출로 계산됩니다.
</Accordion>

<Accordion title="리포스트 수">
  리포스트(리트윗) 횟수입니다. 인용 포스트는 포함되지 않습니다.
</Accordion>

<Accordion title="인용 수">
  인용 포스트(댓글이 포함된 리포스트) 횟수입니다. 항상 오가닉입니다.
</Accordion>

<Accordion title="동영상 조회수">
  해당 동영상을 포함하는 모든 포스트를 합산한 수치입니다. 동영상이 여러 포스트에서 리포스트된 경우에도 총 조회수는 하나의 집계 수치로 제공됩니다.
</Accordion>

<Accordion title="재생 구간(Quartile)">
  동영상의 각 구간별(퍼센트 기준)로 해당 구간까지 재생을 완료한 고유 사용자 수입니다. 이탈률을 파악하는 데 유용합니다.
</Accordion>

<div id="requirements-summary">
  ## 요구 사항 요약
</div>

| Metric field | 인증 필요 여부 |
|:-------------|:-----------------------|
| `public_metrics` | Bearer Token (모든 유형) |
| `non_public_metrics` | 사용자 컨텍스트 (소유한 포스트만) |
| `organic_metrics` | 사용자 컨텍스트 (소유한 포스트만) |
| `promoted_metrics` | 사용자 컨텍스트 (프로모션된 포스트만) |
