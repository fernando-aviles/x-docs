어노테이션은 포스트 콘텐츠에 대한 시맨틱 메타데이터를 제공합니다. X는 포스트를 분석하여 엔터티(사람, 장소, 제품)와 컨텍스트(주제, 도메인)를 식별해, 콘텐츠를 이해하고 필터링하는 데 도움이 됩니다.

---

<div id="annotation-types">
  ## 주석 유형
</div>

<div id="entity-annotations">
  ### 개체 주석
</div>

개체명 인식(NER)은 포스트 텍스트에서 특정 개체 언급을 식별합니다.

| 유형 | 예시 |
|:-----|:---------|
| **사람** | Barack Obama, Elon Musk |
| **장소** | San Francisco, Japan |
| **제품** | iPhone, ChatGPT |
| **조직** | NASA, Google |
| **기타** | Super Bowl, Diabetes |

개체 주석에는 신뢰도 점수와 텍스트 내 위치 정보가 포함됩니다.

<div id="context-annotations">
  ### 컨텍스트 주석
</div>

포스트를 주제와 도메인별로 분류하는 의미 분석입니다.

- **도메인**: 상위 범주 (스포츠, 엔터테인먼트, 기술)
- **엔터티**: 도메인 내의 구체적인 주제 (NBA, 마블 영화, AI)

컨텍스트 주석은 키워드에 의존하지 않고 포스트를 필터링하고 분류하는 데 도움이 됩니다.

---

<div id="requesting-annotations">
  ## 주석(annotations) 요청하기
</div>

`tweet.fields`에 `context_annotations`와 `entities`를 추가하세요:

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=context_annotations,entities" \
  -H "Authorization: Bearer $TOKEN"
```

***

<div id="entity-annotation-fields">
  ## 엔터티 주석 필드
</div>

| 필드 | 설명 |
|:------|:------------|
| `start` | 텍스트 내 시작 위치 |
| `end` | 텍스트 내 끝 위치 |
| `probability` | 신뢰 점수(0-1) |
| `type` | 엔터티 유형(사람, 장소 등) |
| `normalized_text` | 표준화된 엔터티 이름 |

<div id="using-annotations-in-filters">
  ## 필터에서 Annotations 활용하기
</div>

<div id="search-and-filtered-stream">
  ### 검색 및 필터링된 스트림
</div>

컨텍스트 애노테이션 엔터티 ID를 기준으로 포스트를 필터링합니다:

```bash
# 특정 엔티티에 관한 포스트
context:86.1234567890

# 특정 도메인 내 포스트
context:86.*
```


<div id="practical-examples">
  ### 실제 예시
</div>

```bash
# Posts about the NBA
query=context:26.852137520

# Apple 제품에 대한 포스트
query=context:47.10026792024

# Posts about movies
query=context:86.*
```

<div id="important-notes">
  ## 중요한 참고 사항
</div>

<Warning>
**모든 포스트에 어노테이션이 있는 것은 아닙니다.** 어노테이션 범위는 다음 요소에 따라 달라집니다.
- 지원되는 언어
- X 분류 체계에서의 토픽 범위
- 포스트 텍스트의 의미적 풍부함
</Warning>

- 어노테이션은 소급 적용되지 않으며, 엔터티가 추적될 때만 적용됩니다
- 동일한 엔터티가 여러 도메인에 나타날 수 있습니다(예: 유명 인사는 Person이면서 Actor이기도 함)
- 엔터티 id는 도메인 전반에서 변하지 않습니다
