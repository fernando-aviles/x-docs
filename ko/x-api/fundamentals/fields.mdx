X API v2는 기본적으로 최소한의 데이터만 반환합니다. 각 객체 타입에 대해 추가 데이터를 요청하려면 **필드 매개변수(fields parameters)**를 사용하세요.

***

<div id="how-fields-work">
  ## 필드의 동작 방식
</div>

기본적으로 포스트 조회는 `id`, `text`, `edit_history_tweet_ids`만 반환합니다. 더 많은 데이터를 받으려면 요청에 필드 매개변수를 추가하세요:

```bash
# 기본 응답 - 최소 필드
curl "https://api.x.com/2/tweets/1234567890" \
  -H "Authorization: Bearer $TOKEN"

# With additional fields
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=created_at,public_metrics,author_id" \
  -H "Authorization: Bearer $TOKEN"
```

***

<div id="available-field-parameters">
  ## 사용 가능한 필드 매개변수
</div>

각 객체 유형마다 고유한 필드 매개변수가 있습니다:

| 객체 | 매개변수 | 문서 |
|:-------|:----------|:--------------|
| 포스트 (트윗) | `tweet.fields` | [포스트 필드](/ko/x-api/fundamentals/data-dictionary#tweet) |
| User | `user.fields` | [사용자 필드](/ko/x-api/fundamentals/data-dictionary#user) |
| Media | `media.fields` | [미디어 필드](/ko/x-api/fundamentals/data-dictionary#media) |
| Poll | `poll.fields` | [투표 필드](/ko/x-api/fundamentals/data-dictionary#poll) |
| Place | `place.fields` | [장소 필드](/ko/x-api/fundamentals/data-dictionary#place) |

***

<div id="example-post-fields">
  ## 예시: 포스트 필드
</div>

`tweet.fields`를 사용하여 특정 포스트 필드를 요청합니다.

```bash
curl "https://api.x.com/2/tweets/1234567890?tweet.fields=created_at,public_metrics,lang" \
  -H "Authorization: Bearer $TOKEN"
```

응답:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "edit_history_tweet_ids": ["1234567890"],
    "created_at": "2024-01-15T12:00:00.000Z",
    "lang": "en",
    "public_metrics": {
      "retweet_count": 10,
      "reply_count": 5,
      "like_count": 100,
      "quote_count": 2
    }
  }
}
```

***

<div id="example-user-fields">
  ## 예시: 사용자 필드
</div>

`user.fields`를 사용해 특정 사용자 필드를 요청합니다:

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers?user.fields=created_at,description,public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

응답:

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "The voice of the X Developer Platform",
    "public_metrics": {
      "followers_count": 570842,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```

<div id="fields-for-related-objects">
  ## 관련 객체에 대한 필드
</div>

관련 객체(예: 포스트 작성자)의 필드를 가져오려면 다음 두 가지가 필요합니다:

1. 관련 객체를 포함하기 위한 **확장(expansion)**
2. 해당 객체 유형에 대한 **fields 매개변수**

```bash
# 작성자 세부 정보가 포함된 포스트 가져오기
curl "https://api.x.com/2/tweets/1234567890?expansions=author_id&user.fields=description,public_metrics" \
  -H "Authorization: Bearer $TOKEN"
```

응답:

```json
{
  "data": {
    "id": "1234567890",
    "text": "Hello world!",
    "author_id": "2244994945"
  },
  "includes": {
    "users": [{
      "id": "2244994945",
      "name": "X Developers",
      "username": "xdevelopers",
      "description": "The voice of the X Developer Platform",
      "public_metrics": {
        "followers_count": 570842,
        "following_count": 2048
      }
    }]
  }
}
```

[expansions 자세히 알아보기 →](/ko/x-api/fundamentals/expansions)

<div id="important-notes">
  ## 중요 사항
</div>

<Warning>
  **하위 필드를 요청할 수 없습니다.** `public_metrics`를 요청하면 모든 메트릭(좋아요, 리포스트, 답글, 인용)이 반환됩니다. `public_metrics.like_count`만 따로 요청할 수는 없습니다.
</Warning>

* 응답에서 필드 순서는 요청의 순서와 다를 수 있습니다.
* 응답에서 필드가 누락된 경우 해당 값은 `null`이거나 비어 있다는 의미입니다.
* 일부 필드는 특정 인증이 필요합니다(예: 비공개 메트릭은 사용자 컨텍스트가 필요).
* 사용 가능한 필드는 각 엔드포인트의 API 레퍼런스를 확인하세요.
