X의 포스트는 게시 후 30분 이내에 최대 5회까지 편집할 수 있습니다. X API를 통해 전체 편집 내역과 메타데이터를 모두 조회할 수 있습니다.

***

<div id="edit-rules">
  ## 편집 규칙
</div>

| 규칙 | 세부 정보 |
|:-----|:--------|
| **시간 제한** | 원본 포스트 게시 시점부터 30분 |
| **편집 횟수 제한** | 최대 5회 편집 가능 |
| **ID 동작** | 각 편집 시 새로운 포스트 ID가 생성됩니다 |
| **삭제** | 어떤 버전이든 삭제하면 전체 체인이 삭제됩니다 |

***

<div id="what-cant-be-edited">
  ## 편집할 수 없는 항목
</div>

일부 포스트 유형은 편집할 수 없습니다.

* 프로모션 포스트(광고)
* 투표가 포함된 포스트
* 다른 사용자에게 단 답글(자기 자신과의 스레드가 아님)
* 리포스트(인용 포스트는 *편집할 수 있습니다*)
* 커뮤니티 포스트
* 공동 작성 포스트
* 예약된 포스트

***

<div id="edit-data-in-responses">
  ## 응답의 data 수정
</div>

<div id="default-fields">
  ### 기본 필드
</div>

모든 포스트 응답에는 `edit_history_tweet_ids`가 기본적으로 포함됩니다.

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"]
  }
}
```

* 단일 ID = 한 번도 편집되지 않음
* 여러 ID = 편집 기록(오래된 것부터)

<div id="edit-controls">
  ### 편집 컨트롤
</div>

편집 상태 정보를 가져오려면 `edit_controls`를 요청합니다:

```bash
curl "https://api.x.com/2/tweets/1234567891?tweet.fields=edit_controls" \
  -H "Authorization: Bearer $TOKEN"
```

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"],
    "edit_controls": {
      "is_edit_eligible": true,
      "editable_until": "2024-01-15T12:30:00.000Z",
      "edits_remaining": 3
    }
  }
}
```

| Field              | Description           |
| :----------------- | :-------------------- |
| `is_edit_eligible` | 포스트를 수정할 수 있는지 여부     |
| `editable_until`   | 포스트 수정 가능 시간이 종료되는 시각 |
| `edits_remaining`  | 남은 수정 가능 횟수(0-5)      |

***

<div id="getting-edit-history">
  ## 편집 기록 가져오기
</div>

`edit_history_tweet_ids` 확장을 사용하여 모든 버전에 대한 전체 포스트 객체를 가져옵니다:

```bash
curl "https://api.x.com/2/tweets/1234567891?\
tweet.fields=edit_controls&\
expansions=edit_history_tweet_ids" \
  -H "Authorization: Bearer $TOKEN"
```

```json
{
  "data": {
    "id": "1234567891",
    "text": "Updated text (edited)",
    "edit_history_tweet_ids": ["1234567890", "1234567891"],
    "edit_controls": {
      "is_edit_eligible": true,
      "editable_until": "2024-01-15T12:30:00.000Z",
      "edits_remaining": 3
    }
  },
  "includes": {
    "tweets": [{
      "id": "1234567890",
      "text": "Original text (with typo)",
      "edit_history_tweet_ids": ["1234567890", "1234567891"],
      "edit_controls": {
        "is_edit_eligible": true,
        "editable_until": "2024-01-15T12:30:00.000Z",
        "edits_remaining": 3
      }
    }]
  }
}
```

<div id="which-version-is-returned">
  ## 어떤 버전이 반환되나요?
</div>

기본적으로 API는 수정된 포스트의 **가장 최근 버전**을 반환합니다.

특정 버전을 가져오려면 해당 포스트 ID를 사용해 직접 요청하세요.

```bash
# 원본 버전 가져오기
curl "https://api.x.com/2/tweets/1234567890" -H "Authorization: Bearer $TOKEN"

# 편집된 버전 가져오기  
curl "https://api.x.com/2/tweets/1234567891" -H "Authorization: Bearer $TOKEN"
```

<div id="metrics-for-edited-posts">
  ## 편집된 포스트의 지표
</div>

편집된 포스트의 각 버전은 고유한 참여 지표를 가집니다. 각 지표는 참여가 발생했을 때 사용자에게 표시되고 있던 버전에 집계됩니다.

***

<div id="availability">
  ## 이용 가능 여부
</div>

편집 메타데이터는 다음에 대해 사용할 수 있습니다:

* 2022년 9월 29일 이후에 생성된 모든 포스트
* 포스트를 반환하는 모든 v2 엔드포인트
* 검색, 타임라인, 스트림, 조회를 포함하여

이 날짜 이전에 생성된 포스트에는 편집 메타데이터가 제공되지 않습니다.

<div id="use-cases">
  ## 사용 사례
</div>

<Tabs>
  <Tab title="변경 사항 추적">
    포스트의 편집을 모니터링하고 변경 내용을 기록합니다:

    ```python
    def check_for_edits(post):
        history = post.get("edit_history_tweet_ids", [])
        if len(history) > 1:
            print(f"Post {post['id']} has been edited {len(history) - 1} times")
    ```
  </Tab>

  <Tab title="편집 여부 표시">
    UI에 &quot;edited&quot; 배지를 표시합니다:

    ```javascript
    const isEdited = post.edit_history_tweet_ids?.length > 1;
    if (isEdited) {
      showEditedBadge();
    }
    ```
  </Tab>

  <Tab title="원본 콘텐츠 가져오기">
    편집된 포스트의 원본 버전을 가져옵니다:

    ```python
    original_id = post["edit_history_tweet_ids"][0]
    original = api.get_tweet(original_id)
    ```
  </Tab>
</Tabs>
