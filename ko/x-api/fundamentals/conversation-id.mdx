X에서 각 답글은 하나의 대화 스레드에 속합니다. `conversation_id` 필드는 전체 대화 트리를 식별하고 추적하며 재구성할 수 있도록 해 줍니다.

***

<div id="how-it-works">
  ## 작동 방식
</div>

어떤 사용자가 포스트를 작성하고 다른 사람들이 답글을 달면, 모든 답글은 동일한 `conversation_id`를 공유합니다. 이 값은 해당 대화를 시작한 원본 포스트의 ID입니다.

```
Original post (ID: 1234567890)  ← conversation_id for all replies
├── Reply 1 (ID: 1234567891)    → conversation_id: 1234567890
│   └── Reply to Reply 1        → conversation_id: 1234567890
└── Reply 2 (ID: 1234567892)    → conversation_id: 1234567890
    └── Reply to Reply 2        → conversation_id: 1234567890
```

스레드가 아무리 길어져도 모든 포스트는 동일한 `conversation_id`를 공유합니다.

***

<div id="requesting-conversation_id">
  ## conversation_id 요청
</div>

`tweet.fields`에 `conversation_id`를 추가하세요:

```bash
curl "https://api.x.com/2/tweets/1234567891?tweet.fields=conversation_id,in_reply_to_user_id,referenced_tweets" \
  -H "Authorization: Bearer $TOKEN"
```

응답:

```json
{
  "data": {
    "id": "1234567891",
    "text": "@user Great point!",
    "conversation_id": "1234567890",
    "in_reply_to_user_id": "2244994945",
    "referenced_tweets": [{
      "type": "replied_to",
      "id": "1234567890"
    }]
  }
}
```

***

<div id="getting-a-full-conversation">
  ## 전체 대화 가져오기
</div>

스레드의 모든 포스트를 검색하려면 `conversation_id` 검색 연산자를 사용하세요:

```bash
curl "https://api.x.com/2/tweets/search/recent?\
query=conversation_id:1234567890&\
tweet.fields=author_id,created_at,in_reply_to_user_id&\
expansions=author_id" \
  -H "Authorization: Bearer $TOKEN"
```

이는 원본 포스트에 대한 모든 답글을 최신순(가장 최근 것이 먼저 오도록)으로 정렬해 반환합니다.

<div id="use-cases">
  ## 사용 사례
</div>

<Tabs>
  <Tab title="스레드 재구성">
    전체 대화 트리를 복원합니다:

    ```python
    import requests

    conversation_id = "1234567890"
    url = f"https://api.x.com/2/tweets/search/recent"
    params = {
        "query": f"conversation_id:{conversation_id}",
        "tweet.fields": "author_id,in_reply_to_user_id,referenced_tweets,created_at",
        "max_results": 100
    }

    response = requests.get(url, headers=headers, params=params)
    replies = response.json()["data"]

    # created_at으로 정렬하여 시간 순서대로 정렬합니다
    replies.sort(key=lambda x: x["created_at"])
    ```
  </Tab>

  <Tab title="대화 모니터링">
    특정 대화에 대한 답글을 실시간으로 스트리밍합니다:

    ```bash
    # 특정 대화를 위한 필터링된 스트림 규칙을 추가합니다
    curl -X POST "https://api.x.com/2/tweets/search/stream/rules" \
      -H "Authorization: Bearer $TOKEN" \
      -d '{"add": [{"value": "conversation_id:1234567890"}]}'
    ```
  </Tab>

  <Tab title="대화 분석">
    대화 내 답글 수를 집계합니다:

    ```bash
    curl "https://api.x.com/2/tweets/counts/recent?\
    query=conversation_id:1234567890" \
      -H "Authorization: Bearer $TOKEN"
    ```
  </Tab>
</Tabs>

***

<div id="related-fields">
  ## 관련 필드
</div>

| Field | Description |
|:------|:------------|
| `conversation_id` | 스레드를 시작한 원본 포스트의 id |
| `in_reply_to_user_id` | 답글 대상 포스트 작성자의 사용자 id |
| `referenced_tweets` | `type: "replied_to"` 및 상위 포스트 id를 포함하는 배열 |

<div id="notes">
  ## 참고 사항
</div>

* 원본 포스트의 `conversation_id`는 해당 포스트의 `id`와 동일합니다
* `conversation_id`는 포스트를 반환하는 모든 v2 엔드포인트에서 제공됩니다
* 실시간으로 대화를 모니터링하려면 [filtered stream](/ko/x-api/posts/filtered-stream/introduction)과 함께 사용하세요
* 대규모 스레드를 처리하려면 [pagination](/ko/x-api/fundamentals/pagination)과 함께 사용하세요
