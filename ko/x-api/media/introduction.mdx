미디어 객체는 하나의 사진, 동영상 또는 애니메이션 GIF를 나타냅니다. 미디어 객체는 X API 내의 많은 엔드포인트에서 사용되며, 포스트, 다이렉트 메시지, 사용자 프로필, 광고 크리에이티브 등 다양한 곳에 포함될 수 있습니다. 각 미디어 객체는 해상도나 형식이 다른 여러 가지 표시 또는 재생용 버전을 가질 수 있습니다.

<div id="media-types-size-restrictions">
  ## 미디어 유형 및 크기 제한
</div>

API를 통해 업로드할 때의 크기 제한

* **이미지**: `5 MB`
* **GIF**: `15 MB`
* **비디오**: `512 MB` (`media_category=amplify_video` 사용 시)

<div id="creation">
  ## 생성
</div>

포스트, 다이렉트 메시지, 사용자 프로필 사진, 호스팅된 Ads 카드 등과 같은 객체는 하나 이상의 미디어 객체를 포함할 수 있습니다. 이러한 최상위 객체를 통틀어 엔티티라고 합니다. 해당 엔티티를 생성하는 API(예: [`POST /2/tweets`](/ko/x-api/posts/creation-of-a-post))에 고유한 `media_id`를 사용해 하나 이상의 미디어 객체를 전달할 수 있습니다.

미디어 객체를 포함하는 엔티티는 다음 단계를 따라 생성할 수 있습니다.

1. 권장되는 [조각 단위(chunked)](/ko/x-api-/media/quickstart/media-upload-chunked) 업로드(이미지/GIF/동영상) 또는 이전 방식의 [단순(simple)](/ko/x-api/media-upload/media-upload) 업로드(이미지만)를 사용해 미디어 파일을 업로드합니다.
2. 1단계에서 `media_id`를 받습니다. 엔티티가 여러 개의 `media_id` 매개변수 전달을 허용하는 경우, 이 단계를 서로 다른 미디어에 대해 여러 번 반복할 수 있습니다.
3. 적절한 엔드포인트를 호출하면서 `media_id`와 기타 필수 매개변수를 포함해 엔티티를 생성합니다. 예를 들어, [`POST /2/tweets`](/ko/x-api/posts/creation-of-a-post) 엔드포인트를 사용하여 포스트에 `media_id`를 첨부할 수 있습니다.
