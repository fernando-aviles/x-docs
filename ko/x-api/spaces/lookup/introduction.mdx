Spaces 조회 엔드포인트를 사용하면 진행 중이거나 예약된 Space에 대한 정보를 가져올 수 있습니다. Space ID로 Space를 조회하거나 특정 사용자가 생성한 Space를 찾을 수 있습니다.

<div id="endpoints">
  ## 엔드포인트
</div>

| Method | Endpoint | Description |
|:-------|:---------|:------------|
| GET | [`/2/spaces/:id`](/ko/x-api/spaces/get-space-by-id) | ID로 스페이스 조회 |
| GET | [`/2/spaces`](/ko/x-api/spaces/get-spaces-by-ids) | 여러 ID로 스페이스 조회 |
| GET | [`/2/spaces/by/creator_ids`](/ko/x-api/spaces/get-spaces-by-creator-ids) | 생성자 사용자 ID로 스페이스 조회 |
| GET | [`/2/spaces/:id/buyers`](/ko/x-api/spaces/get-space-ticket-buyers) | 스페이스 티켓 구매자 조회 |
| GET | [`/2/spaces/:id/tweets`](/ko/x-api/spaces/get-space-posts) | 스페이스에서 공유된 포스트 조회 |

***

<div id="response-fields">
  ## 응답 필드
</div>

기본적으로 응답에는 `id`와 `state`만 포함됩니다. 추가 필드를 받으려면 다음 필드를 요청하세요:

| Field | Description |
|:------|:------------|
| `title` | Space 제목 |
| `host_ids` | 호스트 사용자 ID |
| `speaker_ids` | 발언자 사용자 ID |
| `participant_count` | 참여자 수 |
| `scheduled_start` | 예정된 시작 시간 |
| `started_at` | 실제 시작 시간 |
| `ended_at` | 종료 시간 |
| `is_ticketed` | 티켓이 발급된 Space인지 여부 |

<div id="space-states">
  ### Space 상태
</div>

| 상태 | 설명 |
|:------|:------------|
| `live` | 현재 진행 중 |
| `scheduled` | 향후 예정됨 |
| `ended` | 종료됨 |

***

<div id="example-request">
  ## 요청 예제
</div>

```bash
curl "https://api.x.com/2/spaces/1DXxyRYNejbKM?\
space.fields=title,host_ids,participant_count,scheduled_start,state" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
