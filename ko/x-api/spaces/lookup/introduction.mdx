Spaces 조회 엔드포인트는 라이브 중이거나 예약된 Spaces에 대한 정보를 조회할 수 있게 해줍니다. id로 Spaces를 조회하거나 특정 사용자가 생성한 Spaces를 찾을 수 있습니다.

  </Card>
</CardGroup>

<div id="endpoints">
  ## 엔드포인트
</div>

| 메서드 | 엔드포인트 | 설명 |
|:-------|:---------|:------------|
| GET | [`/2/spaces/:id`](/ko/x-api/spaces/get-space-by-id) | ID로 Space 조회 |
| GET | [`/2/spaces`](/ko/x-api/spaces/get-spaces-by-ids) | ID로 여러 Space 조회 |
| GET | [`/2/spaces/by/creator_ids`](/ko/x-api/spaces/get-spaces-by-creator-ids) | Space를 생성한 사용자 ID로 Space 조회 |
| GET | [`/2/spaces/:id/buyers`](/ko/x-api/spaces/get-space-ticket-buyers) | 해당 Space의 티켓 구매자 조회 |
| GET | [`/2/spaces/:id/tweets`](/ko/x-api/spaces/get-space-posts) | Space에서 공유된 포스트 조회 |

***

<div id="response-fields">
  ## 응답 필드
</div>

기본적으로 응답에는 `id`와 `state`가 포함됩니다. 추가 필드를 요청하려면 다음을 사용하세요:

| 필드 | 설명 |
|:------|:------------|
| `title` | Space 제목 |
| `host_ids` | 호스트 사용자 ID |
| `speaker_ids` | 스피커 사용자 ID |
| `participant_count` | 참가자 수 |
| `scheduled_start` | 예정된 시작 시간 |
| `started_at` | 실제 시작 시간 |
| `ended_at` | 종료 시간 |
| `is_ticketed` | Space가 티켓팅인지 여부 |

<div id="space-states">
  ### Space 상태
</div>

| 상태 | 설명 |
|:------|:------------|
| `live` | 현재 진행 중 |
| `scheduled` | 향후 진행 예정 |
| `ended` | 종료됨 |

***

<div id="example-request">
  ## 요청 예시
</div>

```bash
curl "https://api.x.com/2/spaces/1DXxyRYNejbKM?\
space.fields=title,host_ids,participant_count,scheduled_start,state" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```
