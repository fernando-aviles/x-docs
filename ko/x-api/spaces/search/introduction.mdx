Spaces Search 엔드포인트를 사용하면 키워드를 사용해 라이브 또는 예정된 Space를 검색할 수 있습니다. 관심 있는 주제와 관련된 Space를 찾아보세요.

<div id="endpoint">
  ## 엔드포인트
</div>

| Method | Endpoint | 설명 |
|:-------|:---------|:------------|
| GET | [`/2/spaces/search`](/ko/x-api/spaces/search-spaces) | Spaces 검색 |

***

<div id="parameters">
  ## 매개변수
</div>

| 매개변수 | 설명 |
|:----------|:------------|
| `query` | 검색 쿼리(필수) |
| `state` | `live` 또는 `scheduled` 상태로 필터링 |
| `space.fields` | 추가 Space 필드 |
| `expansions` | 포함할 관련 객체 |
----------------------------

<div id="example-response">
  ## 요청 예시
</div>

```bash
curl "https://api.x.com/2/spaces/search?\
query=AI&\
state=live&\
space.fields=title,host_ids,participant_count" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

<div id="getting-started">
  ## 예제 응답
