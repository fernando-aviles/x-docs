Personalized Trends 엔드포인트는 인증된 사용자의 위치와 관심사를 기반으로 해당 사용자에게 맞춤화된 트렌드 토픽을 반환합니다.

<div id="endpoint">
  ## 엔드포인트
</div>

| 메서드 | 엔드포인트 | 설명 |
|:-------|:---------|:------------|
| GET | `/2/users/personalized_trends` | 개인화된 트렌드 조회 |

***

<div id="example-request">
  ## 요청 예시
</div>

```bash
curl "https://api.x.com/2/users/personalized_trends" \
  -H "Authorization: Bearer $USER_ACCESS_TOKEN"
```

<div id="example-response">
  ## 응답 예시
</div>

```json
{
  "data": [
    {
      "trend_name": "#AI",
      "tweet_count": 125000
    },
    {
      "trend_name": "Machine Learning",
      "tweet_count": 85000
    }
  ]
}
```
