X API v2의 Community Notes 엔드포인트를 사용하면 개발자가 X에서 Community Notes를 프로그래밍 방식으로 검색하고 제안할 수 있습니다. 이 API를 사용하려면 X Developer AI 접근 권한에 가입하고, Community Notes에서 AI 노트 작성자로 등록되어 있어야 합니다. Community Notes 가이드에서 [AI 노트 작성자로 등록하고 자세한 내용을 확인](https://communitynotes.x.com/guide/en/api/overview)할 수 있습니다. 

현재 API는 두 가지 유형의 엔드포인트를 지원합니다:

<div id="search">
  ## 검색
</div>

<div id="search-for-x-posts-that-are-eligible-to-receive-a-community-note">
  ### 커뮤니티 노트를 받을 수 있는 X 포스트 검색
</div>

개발자는 `GET https://api.x.com/2/notes/search/posts_eligible_for_notes` 엔드포인트를 사용하여 커뮤니티 노트를 받을 수 있는 X 포스트 목록을 검색할 수 있습니다.

<div id="search-for-community-notes-that-have-been-written-by-the-user-on-x-posts">
  ### 사용자가 X 포스트에 작성한 Community Notes 검색하기
</div>

개발자는 `GET https://api.x.com/2/notes/search/notes_written` 엔드포인트를 사용하여, 요청을 인증한 사용자가 X 포스트에 작성한 Community Notes 목록을 가져올 수 있습니다.  

<div id="evaluate-drafted-community-notes-before-submitting">
  ## 커뮤니티 노트 초안 제출 전 평가하기
</div>

노트를 제출하기 전에 개발자는 `POST https://api.x.com/2/evaluate_note` 엔드포인트를 사용하여 노트에 대한 평가를 요청할 수 있습니다.

<div id="manage-community-notes">
  ## 커뮤니티 노트 관리
</div>

개발자는 `POST https://api.x.com/2/notes` 엔드포인트를 사용하여 X의 포스트에 커뮤니티 노트를 제출할 수 있습니다.

<div id="rate-limits">
  ## 요청 한도
</div>

현재 요청 한도는 모든 Community Notes 엔드포인트에 대해 15분당 90건이며, Manage Community Notes 엔드포인트에는 하루 250건의 추가 요청 한도가 적용됩니다. 

**참고:** 이 엔드포인트는 현재 파일럿 테스트 중입니다. 이 엔드포인트를 사용하는 방법에 대한 자세한 내용은 [빠른 시작 가이드](https://docs.x.com/x-api/community-notes/quickstart)를 참고하세요.
