스트리밍 데이터를 사용할 때에는 연결 시간을 최대화하고 일치하는 모든 데이터를 빠짐없이 수신하는 것이 근본적인 목표입니다. 이를 위해서는 중복 연결을 활용하고, 연결 끊김을 자동으로 감지해 빠르게 재연결하며, 유실된 데이터를 복구하기 위한 계획을 마련하는 것이 중요합니다.

이 통합 가이드에서는 중복 연결, 백필(backfill), 데이터 복구 등 다양한 복구 및 중복성 기능에 대해 설명합니다.
 

<div id="redundant-connections">
  ## 중복 연결
</div>

중복 연결은 스트림에 둘 이상의 동시 연결을 설정할 수 있게 해 줍니다. 이렇게 하면 두 개의 별도 consumer가 같은 스트림에 연결하여 두 연결 모두를 통해 동일한 데이터를 수신하므로, 중복성이 확보됩니다. 따라서 한 스트림이 끊기거나 애플리케이션의 기본 서버에 장애가 발생하는 등의 다양한 상황에서, 앱은 즉시 전환되는 핫 페일오버 기능을 갖추게 됩니다.

중복 스트림을 사용하려면 기본 연결에 사용한 것과 동일한 URL에 단순히 다시 연결하면 됩니다. 스트림 데이터는 두 연결을 통해 모두 전송됩니다.

<div id="backfill">
  ## 백필
</div>

연결이 끊어진 것을 감지한 후에는 시스템이 스트림에 다시 연결할 수 있어야 합니다. 가능하다면 시스템이 연결 끊김이 얼마나 오래 지속되었는지 기록해 두었다가, 적절한 복구 기능을 사용해 데이터를 백필(backfill)할 수 있어야 합니다. 

연결 끊김이 5분 이하였다고 판단되면 백필 파라미터인 `backfillMinutes`를 사용할 수 있습니다. 이 파라미터를 `GET /powerstream` 요청과 함께 전달하면, 과거 1분에서 5분 사이에 규칙과 일치한 포스트를 받을 수 있습니다. 일반적으로 이러한 과거 포스트는 새로 매칭된 포스트보다 먼저 전달되며, 포스트에 대한 중복 제거도 수행되지 않습니다. 이는 예를 들어 90초 동안만 연결이 끊어졌는데 2분 분량의 백필 데이터를 요청하는 경우, 30초 분량의 중복 포스트를 수신하게 된다는 의미이며, 시스템이 이를 처리할 수 있어야 합니다. 다음은 백필 파라미터를 포함한 요청 예시입니다:

`curl 'https://api.x.com/2/powerstream?backfillMinutes=5' -H "Authorization: Bearer $ACCESS_TOKEN"`

연결 끊김 시간이 5분을 초과했다고 판단되는 경우, [최근 검색 엔드포인트](/ko/x-api/posts/search/introduction) 또는 복구 기능을 사용하여 누락된 데이터를 요청할 수 있습니다. 

<div id="recovery">
  ## Recovery
</div>

5분 백필(backfill) 기간 내에 다시 연결하지 못한 경우, Recovery 기능을 사용해 최근 24시간 이내에 놓친 데이터를 복구할 수 있습니다.

스트리밍 Recovery 기능을 사용하면 백필 기간을 24시간으로 확장할 수 있습니다. Recovery를 사용하면 데이터를 놓친 기간을 ‘재생(replay)’할 수 있습니다. `startTime` 및 `endTime` 요청 매개변수를 사용해 연결 요청을 보내면 Recovery 스트림이 시작됩니다. 연결되면 Recovery가 지정된 기간을 다시 스트리밍한 후 연결을 종료합니다.  

|     |     |     |
| :--- | :--- | :--- |
| **이름** | **유형** | **설명** |
| `startTime` | date (ISO 8601) | YYYY-MM-DDTHH:mm:ssZ (ISO 8601/RFC 3339).<br /><br />복구를 시작할 UTC 기준 시작 시각을 의미합니다. |
| `endTime` | date (ISO 8601) | YYYY-MM-DDTHH:mm:ssZ (ISO 8601/RFC 3339).<br /><br />복구를 종료할 UTC 기준 종료 시각을 의미합니다. |

요청 URL 예시: `https://api.x.com/2/powerstream?startTime=2022-07-12T15:10:00Z&endTime=2022-07-12T15:20:00Z`
