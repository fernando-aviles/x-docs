스트리밍 데이터를 처리할 때는 연결 시간을 최대화하고 일치하는 모든 데이터를 수신하는 것이 핵심 목표입니다. 이를 위해 중복(이중화) 연결을 활용하고, 연결이 끊어졌는지 자동으로 감지하여 빠르게 재연결하며, 손실된 데이터를 복구하기 위한 계획을 마련하는 것이 중요합니다.

이 통합 가이드에서는 중복(이중화) 연결, 백필(backfill), 복구 등 다양한 복구 및 이중화 기능에 대해 설명합니다.
 

<div id="redundant-connections">
  ## 중복 연결
</div>

중복 연결은 스트림에 동시에 둘 이상의 연결을 설정할 수 있게 해 줍니다. 이렇게 하면 두 개의 별도 컨슈머가 동일한 스트림에 연결되어 두 연결 모두를 통해 동일한 data를 수신하므로, 중복성이 확보됩니다. 따라서 한 스트림 연결이 끊기거나 애플리케이션의 기본 서버에 장애가 발생하는 등의 다양한 상황에서 앱은 hot failover(핫 페일오버)를 사용할 수 있습니다.

중복 스트림을 사용하려면 기본 연결에 사용하던 것과 동일한 URL에 다시 연결하기만 하면 됩니다. 스트림에 대한 data는 두 연결 모두를 통해 전송됩니다.

<div id="backfill">
  ## 백필
</div>

연결이 끊어진 것을 감지한 후에는 시스템이 스트림에 자동으로 다시 연결할 수 있도록 충분히 똑똑하게 설계되어야 합니다. 가능하다면, 적절한 복구 기능을 사용해 데이터를 백필(backfill)할 수 있도록 연결이 끊겨 있었던 시간이 얼마나 되었는지 시스템이 기록하도록 해야 합니다. 

연결이 끊긴 시간이 5분 이하였다고 확인한 경우, 백필 매개변수인 `backfillMinutes`를 사용할 수 있습니다. 이 매개변수를 `GET /powerstream` 요청에 함께 전달하면, 과거 1분에서 5분 사이에 규칙과 일치했던 포스트를 수신하게 됩니다. 일반적으로 이러한 과거 포스트를 새로 매칭된 포스트보다 먼저 전달하며, 포스트를 중복 제거하지도 않습니다. 이는 예를 들어 90초 동안 연결이 끊겼지만 2분 분량의 백필 데이터를 요청한다면, 시스템이 허용해야 하는 30초 분량의 중복 포스트를 수신하게 된다는 의미입니다. 아래는 백필 매개변수를 포함한 요청 예시입니다:

`curl 'https://api.x.com/2/powerstream?backfillMinutes=5' -H "Authorization: Bearer $ACCESS_TOKEN"`

연결이 끊긴 시간이 5분을 초과한 경우에는 [recent search endpoint](/ko/x-api/posts/search/introduction) 또는 복구 기능을 활용하여 누락된 데이터를 요청할 수 있습니다. 

<div id="recovery">
  ## 복구
</div>

5분 백필 윈도우 내에 다시 연결하지 못한 경우, 복구 기능을 사용하여 지난 24시간 동안 누락된 데이터를 복구할 수 있습니다.

스트리밍 복구 기능을 사용하면 최대 24시간까지 확장된 백필 윈도우를 사용할 수 있습니다. 복구 기능을 통해 누락된 데이터가 발생한 기간을 ‘재생(replay)’할 수 있습니다. `startTime` 및 `endTime` 요청 매개변수를 사용해 연결 요청을 하면 복구 스트림이 시작됩니다. 연결되면 Recovery 기능이 지정된 기간을 다시 스트리밍한 다음 연결을 종료합니다.  

|     |     |     |
| :--- | :--- | :--- |
| **이름** | **유형** | **설명** |
| `startTime` | 날짜(ISO 8601) | YYYY-MM-DDTHH:mm:ssZ (ISO 8601/RFC 3339).<br /><br />복구를 시작할 UTC 기준 시작 시간을 나타내는 날짜입니다. |
| `endTime` | 날짜(ISO 8601) | YYYY-MM-DDTHH:mm:ssZ (ISO 8601/RFC 3339).<br /><br />복구를 종료할 UTC 기준 종료 시간을 나타내는 날짜입니다. |

요청 URL 예시: `https://api.x.com/2/powerstream?startTime=2022-07-12T15:10:00Z&endTime=2022-07-12T15:20:00Z`
