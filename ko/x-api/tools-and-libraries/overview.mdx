공식 SDK와 커뮤니티 라이브러리, 개발자 도구로 개발을 더 빠르게 진행하세요.

***

<div id="official-sdks">
  ## 공식 SDK
</div>

X는 X API v2를 완전히 지원하는 TypeScript 및 Python 공식 SDK를 제공합니다:

<CardGroup cols={2}>
  <Card title="Python SDK" icon="python" href="/ko/xdks/python/overview">
    비동기 처리 지원, 타입 힌트, 자동 토큰 갱신 기능을 제공합니다. 데이터 분석과 자동화에 적합합니다.
  </Card>

  <Card title="TypeScript SDK" icon="js" href="/ko/xdks/typescript/overview">
    완전한 타입 안정성과 ESM 지원을 제공합니다. Node.js 및 최신 번들러에서 동작합니다.
  </Card>
</CardGroup>

<div id="community-libraries">
  ## 커뮤니티 라이브러리
</div>

<div id="building-a-library">
  ## 라이브러리를 만들고 계신가요?
</div>

X API용 라이브러리를 만들었다면 커뮤니티와 공유해 주세요:

1. [Libraries &amp; SDKs forum](https://devcommunity.x.com/c/libraries-and-sdks/63)에 게시글을 올리세요.
2. 저희가 이 페이지에 추가할 수도 있습니다!

README에 [version badges](https://twbadges.glitch.me/)를 사용해 API 호환성을 표시하세요.
