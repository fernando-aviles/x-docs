<div id="official-sdks">
  ## 공식 SDK
</div>

X는 TypeScript 및 Python용 공식 SDK를 제공하며, X API v2를 전면 지원합니다.

<CardGroup cols={2}>
  <Card title="Python SDK" icon="python" href="/ko/xdks/python/overview">
    비동기 처리, 타입 힌트, 자동 토큰 갱신을 지원합니다. 데이터 분석과 자동화에 적합합니다.
  </Card>

  <Card title="TypeScript SDK" icon="js" href="/ko/xdks/typescript/overview">
    완전한 타입 안전성과 ESM을 지원합니다. Node.js 및 최신 번들러에서 작동합니다.
  </Card>
</CardGroup>

<div id="building-a-library">
  ## 라이브러리를 만들고 계신가요?
</div>

X API 라이브러리를 만들었다면 커뮤니티와 공유해 주세요:

1. [Libraries &amp; SDKs 포럼](https://devcommunity.x.com/c/libraries-and-sdks/63)에 게시글을 올리세요.
2. 이 페이지에 추가될 수도 있습니다!

README에서 [버전 배지](https://twbadges.glitch.me/)를 사용해 API 호환성을 표시하세요.
