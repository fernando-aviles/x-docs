X API는 **사용량 기반 과금(pay-per-usage)** 모델을 사용합니다. 구독도 없고 월 사용 한도도 없으며, 사용한 만큼만 비용을 지불하면 됩니다.

<div id="deduplication">
  ## 중복 제거
</div>

모든 리소스는 **UTC 기준 24시간(하루) 중복 제거 윈도우** 내에서 중복 제거됩니다. 특정 리소스(예: 포스트)를 요청해 과금이 발생한 경우, 해당 기간 내에 동일한 리소스를 다시 요청하더라도 추가 요금이 청구되지 않습니다.

이는 다음을 의미합니다:

* 같은 포스트를 하루에 여러 번 요청해도 한 번만 과금됩니다
* 중복 제거 윈도우는 UTC 자정에 초기화됩니다
* 이는 모든 과금 대상 리소스(포스트, 사용자 등)에 적용됩니다

<Note>
  중복 제거는 **완전히 보장되는 것은 아닌 소프트 보장(soft guarantee)**입니다. 대부분의 경우에는 중복 제거가 이루어지지만, 서비스 중단과 같은 특정 예외 상황에서는 리소스가 중복 제거되지 않을 수 있습니다.
</Note>

<div id="credit-balance">
  ## 크레딧 잔액
</div>

크레딧 잔액은 개발자 콘솔에 표시됩니다. API 요청을 수행할 때마다 크레딧이 실시간으로 차감됩니다.

<Warning>
  서비스 중단을 방지하려면 크레딧 잔액을 정기적으로 확인하세요. API 이용을 중단 없이 유지하려면 잔액이 0에 도달하기 전에 크레딧을 추가하세요.

  ***참고:** 계정 크레딧 잔액이 약간 음수가 될 수 있습니다. 이 경우, 음수 잔액을 해소할 만큼 충분한 크레딧을 추가하기 전까지 API 요청이 차단됩니다.*
</Warning>

<div id="auto-recharge">
  ### 자동 충전
</div>

자동 충전을 활성화하여 크레딧 잔액을 자동으로 보충하고 서비스 중단을 방지할 수 있습니다. 개발자 콘솔에서 다음을 설정합니다:

| Setting | Description |
|:--------|:------------|
| **Recharge amount** | 자동 충전이 실행될 때 추가되는 금액 (예: $25) |
| **Trigger threshold** | 잔액이 이 금액 아래로 떨어지면 자동 충전이 활성화되는 기준 금액 (예: $5) |

<Note>
  자동 충전을 사용하려면 기본 결제 수단으로 설정된 저장된 결제 수단이 필요합니다. 언제든지 개발자 콘솔에서 또는 지원팀에 문의하여 취소할 수 있습니다.
</Note>

<div id="spending-limits">
  ### 지출 한도
</div>

비용을 관리하기 위해 청구 주기마다 사용할 수 있는 최대 금액을 설정할 수 있습니다. 한도에 도달하면 다음 청구 주기까지 API 요청이 차단됩니다.

| Option | Description |
|:-------|:------------|
| **Spending limit** | 청구 주기당 최대 지출 한도로 사용할 구체적인 달러 금액을 설정합니다 |

<Tip>
  특히 개발 및 테스트 중 예기치 않은 요금이 발생하지 않도록 지출 한도를 사용하세요.
</Tip>

<div id="monitoring-usage">
  ## 사용량 모니터링
</div>

[Usage endpoint](/ko/x-api/usage/introduction)를 사용해 API 사용량을 프로그램 방식으로 추적하세요:

```bash
curl "https://api.x.com/2/usage/tweets" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

이는 일별 포스트 사용량을 반환하여 다음을 수행하는 데 도움이 됩니다:

* 예산 대비 사용량 추적
* 한도에 근접할 때 알림 설정
* 사용량이 높은 엔드포인트 파악
* 사용량 보고서 생성
