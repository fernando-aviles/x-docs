<div id="quick-start-with-curl">
  ## cURL로 빠르게 시작하기
</div>

API를 가장 빠르게 테스트하는 방법은 cURL을 사용하는 것입니다. 사용자를 조회해 보겠습니다.

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

`$BEARER_TOKEN`을 실제 Bearer Token으로 교체하면 다음과 같은 응답이 반환됩니다:

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers"
  }
}
```

***

<div id="step-by-step-guide">
  ## 단계별 가이드
</div>

<Steps>
  <Step title="Bearer Token 가져오기">
    [개발자 콘솔](https://console.x.com)에서 앱 상세 페이지로 이동해 Bearer Token을 복사합니다.
  </Step>

  <Step title="엔드포인트 선택하기">
    다음과 같은 입문자용 엔드포인트 중 하나로 시작해 보세요:

    | 엔드포인트 | 기능 |
    |:---------|:-------------|
    | [User lookup](/ko/x-api/users/lookup/introduction) | 사용자 이름 또는 ID로 사용자 프로필 가져오기 |
    | [Post lookup](/ko/x-api/posts/lookup/introduction) | ID로 포스트 가져오기 |
    | [Recent search](/ko/x-api/posts/search/introduction) | 최근 7일 동안의 포스트 검색 |
  </Step>

  <Step title="요청 보내기">
    cURL, Postman 또는 선호하는 HTTP 클라이언트를 사용하세요:

    ```bash
    # 사용자 이름으로 사용자 조회
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```
  </Step>

  <Step title="응답 파싱하기">
    응답은 JSON 형식입니다. 주요 데이터는 `data` 필드에 있습니다:

    ```json
    {
      "data": {
        "id": "2244994945",
        "name": "X Developers",
        "username": "xdevelopers"
      }
    }
    ```
  </Step>
</Steps>

<div id="request-more-data-with-fields">
  ## 필드로 더 많은 data를 요청하기
</div>

기본적으로 엔드포인트는 최소한의 필드만 반환합니다. 추가 data를 요청하려면 `fields` 매개변수를 사용하세요:

```bash
curl "https://api.x.com/2/users/by/username/xdevelopers?user.fields=created_at,description,public_metrics" \
  -H "Authorization: Bearer $BEARER_TOKEN"
```

응답:

```json
{
  "data": {
    "id": "2244994945",
    "name": "X Developers",
    "username": "xdevelopers",
    "created_at": "2013-12-14T04:35:55.000Z",
    "description": "The voice of the X Developer Platform",
    "public_metrics": {
      "followers_count": 570842,
      "following_count": 2048,
      "tweet_count": 14052,
      "listed_count": 1672
    }
  }
}
```

[필드에 대해 자세히 알아보기 →](/ko/x-api/fundamentals/fields)

<div id="using-code-instead-of-curl">
  ## cURL 대신 코드 사용하기
</div>

<Tabs>
  <Tab title="Python">
    ```python
    import requests

    bearer_token = "YOUR_BEARER_TOKEN"
    url = "https://api.x.com/2/users/by/username/xdevelopers"

    headers = {"Authorization": f"Bearer {bearer_token}"}
    response = requests.get(url, headers=headers)

    print(response.json())
    ```
  </Tab>

  <Tab title="JavaScript">
    ```javascript
    const bearerToken = "YOUR_BEARER_TOKEN";
    const url = "https://api.x.com/2/users/by/username/xdevelopers";

    fetch(url, {
      headers: { Authorization: `Bearer ${bearerToken}` }
    })
      .then(res => res.json())
      .then(data => console.log(data));
    ```
  </Tab>

  <Tab title="공식 SDK">
    프로덕션 환경에서는 공식 SDK 사용을 권장합니다.

    * [Python SDK](/ko/xdks/python/overview)
    * [TypeScript SDK](/ko/xdks/typescript/overview)

    이 SDK들은 인증, 페이지네이션, 요청 속도 제한을 자동으로 처리합니다.
  </Tab>
</Tabs>

<div id="troubleshooting">
  ## 문제 해결
</div>

<Accordion title="401 권한 없음">
  * Bearer Token이 올바른지 확인하세요
  * 토큰이 재발급되지 않았는지 확인하세요
  * `Authorization` 헤더 형식이 `Bearer YOUR_TOKEN`인지 확인하세요
</Accordion>

<Accordion title="403 금지됨">
  * 앱에 이 엔드포인트에 대한 접근 권한이 없을 수 있습니다
  * 일부 엔드포인트는 사용자 컨텍스트 기반 인증(OAuth 1.0a 또는 2.0)을 필요로 합니다
  * 개발자 콘솔에서 앱의 권한을 확인하세요
</Accordion>

<Accordion title="429 요청 과다">
  * 요청 한도에 도달했습니다
  * 언제 다시 시도할 수 있는지 `x-rate-limit-reset` 헤더를 확인하세요
  * 코드에서 지수 백오프를 구현하세요
</Accordion>

[전체 오류 참조 →](/ko/x-api/fundamentals/response-codes-and-errors)
