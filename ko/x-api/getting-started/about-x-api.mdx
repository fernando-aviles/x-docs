X API는 X의 공개 대화에 프로그래밍 방식으로 접근할 수 있도록 제공합니다. 포스트를 조회하고, 트렌드를 분석하며, 통합을 구축하고, 플랫폼에서 새로운 경험을 만들어 보세요.

***

<div id="what-you-can-do">
  ## 가능한 작업
</div>

| 기능 | 설명 |
|:-----------|:------------|
| **포스트 읽기** | 포스트를 실시간으로 검색, 조회, 스트리밍할 수 있습니다 |
| **콘텐츠 게시** | 포스트, 답글, 스레드를 생성할 수 있습니다 |
| **사용자 관리** | 사용자를 조회하고 팔로우, 차단, 숨기기를 관리할 수 있습니다 |
| **데이터 분석** | 지표, 트렌드, 참여도 분석에 대한 데이터를 확인할 수 있습니다 |
| **통합 구축** | DM을 보내고 리스트를 관리하며 Spaces와 상호작용할 수 있습니다 |

<div id="api-versions">
  ## API 버전
</div>

<Tabs>
  <Tab title="X API v2 (권장)">
    최신 기능과 유연한 요금제를 제공하는 X API의 현재 버전입니다.

    **v2를 사용해야 하는 이유:**

    * 사용량 기반 과금 — 월 사용 한도 없음
    * 최신 JSON 응답 형식
    * 유연한 [fields](/ko/x-api/fundamentals/fields) 및 [expansions](/ko/x-api/fundamentals/expansions)
    * 고급 기능: 애노테이션(annotations), 대화 추적, 편집 이력
    * 모든 신규 엔드포인트 및 기능 제공

    **시작하기:**

    1. [console.x.com](https://console.x.com)에 가입합니다.
    2. 앱을 생성하고 자격 증명을 발급받습니다.
    3. [첫 번째 요청 보내기](/ko/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1 (레거시)">
    이전 버전의 X API입니다. 지원이 제한적이므로, 새로운 Project에는 v2 사용을 권장합니다.

    **여전히 제공되는 항목:**

    * 일부 미디어 업로드 엔드포인트
    * 더 이상 권장되지 않는 레거시 스트리밍
    * 일부 특수 엔드포인트

    **v2로 마이그레이션:**
    엔드포인트 매핑 및 데이터 형식 변경 사항은 [마이그레이션 가이드](/ko/x-api/migrate/overview)를 참고하세요.
  </Tab>

  <Tab title="Enterprise">
    고급 요구 사항이 있는 기업을 위한 대량 액세스입니다.

    **기능:**

    * 전체 파이어호스(firehose) 액세스
    * 과거 데이터 백필(backfill)
    * 전담 지원
    * 맞춤형 요청 한도
    * 컴플라이언스 스트림

    [Enterprise 영업팀 문의 →](/ko/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

<div id="v2-highlights">
  ## v2 주요 기능
</div>

<Accordion title="필드와 expansions">
  필요한 data만 요청하세요. `fields` 매개변수를 사용해 특정 속성을 선택하고, `expansions`로 관련 객체를 포함할 수 있습니다.

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [필드에 대해 더 알아보기 →](/ko/x-api/fundamentals/fields)
</Accordion>

<Accordion title="포스트 주석">
  포스트에는 사람, 장소, 상품, 토픽을 식별하는 의미 기반 주석이 포함됩니다. 이 주석을 사용해 스트림과 검색 결과를 토픽별로 필터링할 수 있습니다.

  [주석에 대해 더 알아보기 →](/ko/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="참여 지표">
  자신의 포스트에 대해 공개 지표(좋아요, 리포스트, 답글)와 비공개 지표(노출 수, 클릭 수)에 접근할 수 있습니다.

  [지표에 대해 더 알아보기 →](/ko/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="대화 추적">
  `conversation_id`를 사용해 전체 대화 스레드를 재구성할 수 있습니다. 전체 스레드에 걸친 답글을 추적할 수 있습니다.

  [대화 추적에 대해 더 알아보기 →](/ko/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="수정 이력">
  이전 모든 버전과 수정 관련 메타데이터를 포함해 포스트의 수정 이력에 접근할 수 있습니다.

  [포스트 수정에 대해 더 알아보기 →](/ko/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## 요금
</div>

X API v2는 **사용량 기반 과금(pay-per-usage)** 모델을 사용합니다:

| 혜택 | 설명 |
|:--------|:------------|
| **구독 없음** | 실제 사용한 만큼만 과금 |
| **상한선 없음** | 필요한 만큼 제한 없이 사용 |
| **크레딧 기반** | 크레딧을 구매하고, 요청당 차감 |
| **실시간 추적** | 개발자 콘솔에서 실시간으로 사용량 모니터링 |
| **중복 제거** | 동일 리소스를 24시간 이내에 두 번 요청해도 한 번만 과금 |

[요금 상세 보기 →](/ko/x-api/getting-started/pricing)
