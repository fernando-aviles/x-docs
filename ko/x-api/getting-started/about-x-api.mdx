X API를 사용하면 X의 공개 대화에 프로그램 방식으로 액세스할 수 있습니다. 게시물을 조회하고, 트렌드를 분석하고, 통합을 구축하고, 플랫폼에서 새로운 경험을 만들어 보세요.

***

<div id="what-you-can-do">
  ## 가능한 작업
</div>

| 기능 | 설명 |
|:-----------|:------------|
| **게시물 읽기** | 게시물을 검색·조회하고 실시간으로 스트리밍할 수 있습니다 |
| **콘텐츠 게시** | 게시물, 답글, 스레드를 작성할 수 있습니다 |
| **사용자 관리** | 사용자를 조회하고 팔로우, 차단, 뮤트 상태를 관리할 수 있습니다 |
| **데이터 분석** | 지표, 트렌드, 참여 분석 데이터에 접근할 수 있습니다 |
| **통합 기능 구축** | DM을 보내고 리스트를 관리하며 Spaces와 상호작용할 수 있습니다 |

<div id="api-versions">
  ## API 버전
</div>

<Tabs>
  <Tab title="X API v2 (추천)">
    최신 기능과 유연한 과금 체계를 제공하는 현재 X API 버전입니다.

    **v2를 사용해야 하는 이유:**

    * 사용량 기반 과금 — 월별 한도 없음
    * 현대적인 JSON 응답 형식
    * 유연한 [필드](/ko/x-api/fundamentals/fields) 및 [expansions](/ko/x-api/fundamentals/expansions)
    * 고급 기능: 주석(annotations), 대화 추적(conversation tracking), 수정 이력(edit history)
    * 모든 신규 엔드포인트와 기능 제공

    **시작하기:**

    1. [console.x.com](https://console.x.com)에 가입합니다.
    2. App을 생성하고 자격 증명을 발급받습니다.
    3. [첫 요청 보내기](/ko/x-api/getting-started/make-your-first-request)
  </Tab>

  <Tab title="X API v1.1 (레거시)">
    이전 버전의 X API입니다. 지원이 제한되므로, 새로운 프로젝트에는 v2 사용을 권장합니다.

    **여전히 제공되는 기능:**

    * 일부 미디어 업로드 엔드포인트
    * 레거시 스트리밍(사용 중단 예정)
    * 일부 특수 목적 엔드포인트

    **v2로 마이그레이션하기:**
    엔드포인트 매핑과 데이터 형식 변경 사항은 [마이그레이션 가이드](/ko/x-api/migrate/overview)를 참조하세요.
  </Tab>

  <Tab title="Enterprise">
    고급 요구사항이 있는 비즈니스를 위한 대량 데이터 액세스입니다.

    **기능:**

    * 전체 Firehose 액세스
    * 과거 데이터 backfill
    * 전담 지원
    * 맞춤형 요청 한도
    * 컴플라이언스 스트림

    [Enterprise 영업팀 문의 →](/ko/enterprise/forms/enterprise-api-interest)
  </Tab>
</Tabs>

<div id="v2-highlights">
  ## v2 주요 사항
</div>

<Accordion title="필드와 expansions">
  필요한 데이터만 요청하세요. `fields` 파라미터로 특정 속성을 선택하고, `expansions`로 관련 객체를 포함할 수 있습니다.

  ```bash
  curl "https://api.x.com/2/tweets/123?tweet.fields=created_at,public_metrics&expansions=author_id&user.fields=username" \
    -H "Authorization: Bearer $TOKEN"
  ```

  [필드에 대해 더 알아보기 →](/ko/x-api/fundamentals/fields)
</Accordion>

<Accordion title="게시물 주석">
  게시물에는 사람, 장소, 상품, 주제 등을 식별하는 의미 기반 주석이 포함됩니다. 스트림과 검색 결과를 주제별로 필터링할 수 있습니다.

  [주석에 대해 더 알아보기 →](/ko/x-api/fundamentals/post-annotations)
</Accordion>

<Accordion title="활동 지표">
  공개 지표(좋아요, 리게시물, 답글)와 본인 게시물에 대한 비공개 지표(노출 수, 클릭 수)에 액세스할 수 있습니다.

  [지표에 대해 더 알아보기 →](/ko/x-api/fundamentals/metrics)
</Accordion>

<Accordion title="대화 추적">
  `conversation_id`를 사용해 전체 대화 스레드를 재구성하세요. 전체 스레드에 걸친 답글을 추적할 수 있습니다.

  [대화 추적에 대해 더 알아보기 →](/ko/x-api/fundamentals/conversation-id)
</Accordion>

<Accordion title="수정 기록">
  이전 모든 버전과 수정 메타데이터를 포함해 게시물의 수정 이력에 액세스할 수 있습니다.

  [게시물 수정에 대해 더 알아보기 →](/ko/x-api/fundamentals/edit-posts)
</Accordion>

<div id="pricing">
  ## 가격
</div>

X API v2는 **사용량 기반(pay-per-usage)** 과금 모델을 사용합니다:

| 혜택 | 설명 |
|:--------|:------------|
| **구독 없음** | 사용한 만큼만 결제 |
| **상한선 없음** | 필요한 만큼 자유롭게 사용 |
| **크레딧 기반** | 크레딧을 구매한 뒤 요청당 차감 |
| **실시간 추적** | 개발자 콘솔에서 사용량 모니터링 |
| **중복 제거** | 동일한 리소스를 24시간 내 두 번 요청해도 한 번만 과금 |

[요금 세부 정보 보기 →](/ko/x-api/getting-started/pricing)
