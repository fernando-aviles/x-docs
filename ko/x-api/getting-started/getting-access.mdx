X API를 시작하려면 회원가입, 앱 생성, 자격 증명 저장의 세 단계를 따르면 됩니다.

<Button href="https://console.x.com">지금 가입하기</Button>

***

<div id="step-1-create-a-developer-account">
  ## 1단계: 개발자 계정 만들기
</div>

<Steps>
  <Step title="Developer Console로 이동">
    [console.x.com](https://console.x.com)에 접속하여 X 계정으로 로그인하세요.
  </Step>

  <Step title="Developer Agreement 동의하기">
    Developer Agreement와 정책(Policy)을 검토하고 동의하세요.
  </Step>

  <Step title="프로필 완료하기">
    API를 어떻게 사용할 계획인지에 대한 기본 정보를 입력하세요.
  </Step>
</Steps>

***

<div id="step-2-create-an-app">
  ## 2단계: 앱 만들기
</div>

가입을 완료한 후, API 자격 증명을 받기 위해 앱을 만듭니다:

<Steps>
  <Step title="'New App' 클릭">
    Developer Console 대시보드에서 새 앱을 만듭니다.
  </Step>

  <Step title="앱 세부 정보 입력">
    앱의 이름, 설명, 사용 목적을 입력합니다.
  </Step>

  <Step title="자격 증명 생성">
    콘솔에서 API 키와 토큰이 생성됩니다.
  </Step>
</Steps>

***

<div id="step-3-save-your-credentials">
  ## 3단계: 자격 증명 저장하기
</div>

인증 방식에 따라 여러 자격 증명을 받게 됩니다:

| Credential | Purpose |
|:-----------|:--------|
| **API Key &amp; Secret** | 앱을 식별합니다. 토큰을 생성하고 OAuth 1.0a 요청에 서명하는 데 사용됩니다. |
| **Bearer Token** | 공개 데이터를 읽기 위한 앱 전용 인증입니다. |
| **Access Token &amp; Secret** | 본인 계정을 대신해 요청을 보냅니다(OAuth 1.0a). |
| **Client ID &amp; Secret** | 사용자 컨텍스트 요청을 위한 OAuth 2.0 인증입니다. |

<Warning>
  **바로 저장하세요.** 자격 증명은 한 번만 표시됩니다. 비밀번호 관리자나 보안 금고에 보관하세요. 분실한 경우 다시 생성해야 하며, 이때 기존 자격 증명은 더 이상 유효하지 않습니다.
</Warning>

***

<div id="which-credentials-do-you-need">
  ## 어떤 자격 증명이 필요하나요?
</div>

<Tabs>
  <Tab title="공개 data 읽기">
    공개 data에 단순히 읽기 전용으로 액세스할 때는 **Bearer Token**을 사용하세요.

    ```bash
    curl "https://api.x.com/2/users/by/username/xdevelopers" \
      -H "Authorization: Bearer $BEARER_TOKEN"
    ```

    적합한 용도: 포스트 검색, 사용자 조회, 트렌드 읽기.
  </Tab>

  <Tab title="사용자로서 동작하기">
    사용자 대신 동작하려면 **OAuth 2.0**(권장) 또는 **OAuth 1.0a**를 사용하세요.

    OAuth 2.0은 세분화된 권한 범위를 제공하므로 필요한 권한만 요청할 수 있습니다.

    적합한 용도: 포스트 작성, 좋아요, 팔로우, DM 액세스.

    [OAuth 2.0 가이드 →](/ko/resources/fundamentals/authentication/oauth-2-0/overview)
  </Tab>

  <Tab title="본인으로서 동작하기">
    자신의 계정으로 요청을 보내려면 **Access Token &amp; Secret**을 사용하세요.

    이 토큰들은 앱을 소유한 계정을 나타냅니다.

    적합한 용도: 테스트, 개인 봇, 개인용 자동화.
  </Tab>
</Tabs>
