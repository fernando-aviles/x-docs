<div id="response-structure">
  ### 응답 구조
</div>

모든 v2 응답은 다음과 같은 구조를 가집니다:

```json
{
  "data": { ... },      // 기본 객체
  "includes": { ... },  // 확장된 객체(요청 시)
  "meta": { ... },      // 페이지네이션 정보
  "errors": [ ... ]     // 부분 오류(있는 경우)
}
```

<div id="common-parameters">
  ### 공통 매개변수
</div>

| 매개변수 | 용도 |
|:----------|:----|
| `tweet.fields` | 특정 게시물 필드를 요청 |
| `user.fields` | 특정 사용자 필드를 요청 |
| `expansions` | 관련 객체를 포함 |
| `max_results` | 페이지당 결과 수를 제한 |
| `pagination_token` | 다음/이전 페이지를 가져오기 |

<div id="authentication-methods">
  ### 인증 방식
</div>

| 방식 | 사용 사례 |
|:-------|:---------|
| Bearer 토큰 | 읽기 전용 공개 데이터 |
| OAuth 2.0 | 세분화된 권한 범위의 사용자 작업 |
| OAuth 1.0a | 사용자 작업 (레거시, 전체 권한) |

[전체 인증 가이드 →](/ko/resources/fundamentals/authentication/overview)
