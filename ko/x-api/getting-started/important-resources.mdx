<div id="quick-reference">
  ## 간단 참고
</div>

<div id="response-structure">
  ### 응답 구조
</div>

모든 v2 응답은 다음 구조를 따릅니다:

```json
{
  "data": { ... },      // 기본 객체
  "includes": { ... },  // 확장된 객체(요청 시)
  "meta": { ... },      // 페이지네이션 정보
  "errors": [ ... ]     // 부분 오류(있는 경우)
}
```

<div id="common-parameters">
  ### 공통 매개변수
</div>

| 매개변수 | 설명 |
|:----------|:----|
| `tweet.fields` | 반환할 포스트 필드 지정 |
| `user.fields` | 반환할 사용자 필드 지정 |
| `expansions` | 관련 객체를 함께 포함하도록 요청 |
| `max_results` | 페이지당 최대 결과 수 설정 |
| `pagination_token` | 다음/이전 페이지를 조회하는 데 사용 |

<div id="authentication-methods">
  ### 인증 방법
</div>

| 방법 | 사용 용도 |
|:-------|:---------|
| Bearer Token | 공개 데이터 읽기 전용 |
| OAuth 2.0 | 세분화된 권한 범위의 사용자 작업 |
| OAuth 1.0a | 사용자 작업 (레거시, 전체 권한) |

[전체 인증 가이드 →](/ko/resources/fundamentals/authentication/overview)
