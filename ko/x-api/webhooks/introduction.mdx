<div id="how-webhooks-work">
  ## 웹훅이 작동하는 방식
</div>

```
┌──────────┐      ┌──────────┐      ┌──────────┐
│ X Event  │  →   │ X Server │  →   │ Your     │
│ Occurs   │      │          │      │ Webhook  │
└──────────┘      └──────────┘      └──────────┘
```

1. **이벤트 발생** — 사용자가 포스트를 작성하거나 DM을 보내는 등의 활동을 합니다.
2. **X가 요청 전송** — X가 웹훅 URL로 POST 요청을 전송합니다.
3. **이벤트 처리** — 서버가 해당 이벤트를 처리합니다.
4. **200으로 응답** — 이벤트 수신을 확인하기 위해 200 OK로 응답합니다.

<div id="webhook-requirements">
  ## 웹훅 요구 사항
</div>

| 요구 사항 | 설명 |
|:------------|:------------|
| **HTTPS** | 웹훅 URL은 HTTPS를 사용해야 합니다 |
| **공개** | URL은 외부에서 공개적으로 접근 가능해야 합니다 |
| **빠른 응답** | 10초 이내에 응답을 반환해야 합니다 |
| **200 OK** | 수신 확인을 위해 200 상태 코드를 반환해야 합니다 |

<div id="challenge-response-check-crc">
  ### 챌린지-응답 검사 (CRC)
</div>

X는 웹후크를 검증하기 위해 CRC 요청을 보냅니다. HMAC-SHA256 해시로 응답하세요:

```python
import hmac
import hashlib
import base64

def handle_crc(crc_token, consumer_secret):
    sha256_hash = hmac.new(
        consumer_secret.encode(),
        crc_token.encode(),
        hashlib.sha256
    ).digest()
    
    return {
        "response_token": "sha256=" + base64.b64encode(sha256_hash).decode()
    }
```
