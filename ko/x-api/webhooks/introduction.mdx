<div id="how-webhooks-work">
  ## 웹훅 동작 방식
</div>

```
┌──────────┐      ┌──────────┐      ┌──────────┐
│ X Event  │  →   │ X Server │  →   │ Your     │
│ Occurs   │      │          │      │ Webhook  │
└──────────┘      └──────────┘      └──────────┘
```

1. **이벤트 발생** — 사용자가 포스트를 올리거나 DM을 보내는 등의 이벤트가 발생합니다.
2. **X에서 요청 전송** — X가 웹훅 URL로 POST 요청을 전송합니다.
3. **이벤트 처리** — 귀하의 서버에서 해당 이벤트를 처리합니다.
4. **200 응답** — 수신을 확인하기 위해 200 OK를 반환합니다.

<div id="webhook-requirements">
  ## Webhook 요구 사항
</div>

| 요구 사항 | 설명 |
|:------------|:------------|
| **HTTPS** | Webhook URL은 HTTPS를 사용해야 합니다 |
| **Public** | URL은 공개적으로 접근 가능해야 합니다 |
| **Fast response** | 10초 이내에 응답해야 합니다 |
| **200 OK** | 요청 수신을 확인하기 위해 200 상태 코드를 반환해야 합니다 |

<div id="challenge-response-check-crc">
  ### Challenge-Response 검사 (CRC)
</div>

X는 CRC 요청을 보내 웹훅을 검증합니다. HMAC-SHA256 해시값으로 응답하세요:

```python
import hmac
import hashlib
import base64

def handle_crc(crc_token, consumer_secret):
    sha256_hash = hmac.new(
        consumer_secret.encode(),
        crc_token.encode(),
        hashlib.sha256
    ).digest()
    
    return {
        "response_token": "sha256=" + base64.b64encode(sha256_hash).decode()
    }
```
