<div id="overview">
  ## 개요
</div>

필터링된 스트림 엔드포인트 그룹은 개발자가 공개 포스트 스트림을 필터링할 수 있게 해 줍니다. 이 엔드포인트 그룹에는 규칙을 생성 및 관리하고, 해당 규칙을 적용하여 일치하는 공개 포스트만 반환하도록 포스트 스트림을 필터링할 수 있게 해 주는 여러 엔드포인트가 포함됩니다. 이 엔드포인트 그룹을 사용하면 특정 주제와 이벤트를 수신하고, 경쟁과 관련된 대화를 모니터링하며, 트렌드가 어떻게 형성되는지 파악하는 등 다양한 작업을 수행할 수 있습니다.

개발자는 REST [rules 엔드포인트](/ko/x-api/posts/filtered-stream#post-2-tweets-search-stream-rules)를 사용하여 정의된 기준과 일치하는 포스트를 필터링하기 위한 규칙을 추가하고 제거할 수 있습니다. 이러한 [규칙](/ko/x-api/posts/filtered-stream#building-rules-for-filtered-stream)은 메시지 키워드, 해시태그, URL과 같은 포스트 속성과 일치하도록 하는 연산자를 사용해 생성할 수 있습니다. 연산자와 규칙 절은 불리언 로직과 괄호로 결합하여 필터의 매칭 동작을 세밀하게 조정할 수 있습니다. 

규칙을 여러 개 추가한 후에는 웹훅을 등록하여 X가 JSON 형식의 [Post 객체](/ko/x-api/fundamentals/data-dictionary#tweet)를 전달하도록 할 수 있습니다. 웹훅에는 규칙과 일치하는 콘텐츠만 전달됩니다.

이 엔드포인트는 편집된 포스트를 지원합니다. 웹훅은 하나 이상의 필터와 일치하는 편집된 포스트를 해당 포스트의 편집 이력과 함께 수신하며, 이 이력에는 포스트 ID 배열이 포함됩니다. 편집 이력이 없는 포스트의 경우 이 배열에는 단일 ID만 포함됩니다. 편집된 포스트의 경우 이 배열에는 여러 ID가 포함되며, 편집 순서를 반영해 오름차순으로 정렬되고, 가장 최신 버전은 배열의 마지막 위치에 있습니다. 포스트 편집이 작동하는 방식에 대한 자세한 내용은 [Posts edits fundamentals](/ko/x-api/fundamentals/edit-posts) 페이지를 참조하세요. 

**참고:** 이 엔드포인트 그룹은 규칙을 설정하는 방식이 [v2 filtered stream 엔드포인트](/ko/x-api/posts/filtered-stream/introduction)와 유사합니다. 유일한 차이점은 규칙과 일치하는 포스트의 전달 방식입니다.

* v2 filtered stream 엔드포인트의 경우, 지속적인 연결을 설정하고 규칙과 일치하는 포스트를 수신해야 합니다.
* 이 filtered stream 웹훅 엔드포인트의 경우, 웹훅을 등록하면 X가 규칙과 일치하는 포스트를 웹훅으로 전달합니다.

이 방식은 클라이언트 단의 연결 끊김이나 서비스의 정상적인 재시작으로 인해 서버 측에서 발생하는 연결 해제를 별도로 처리할 필요를 없애 줍니다. 초당 수백 건의 이벤트를 전달할 가능성이 높기 때문에, 웹훅 서버는 이러한 동시 연결 시도를 처리할 수 있어야 합니다.

이 엔드포인트는 현재 Enterprise 개발자에게 제공되며, 다음과 같은 구성을 지원합니다.

* Project당 25,000개 이상의 규칙
* 규칙을 작성할 때 모든 연산자 사용 가능
* 최대 2048자 길이의 규칙 생성 가능
* Enterprise 액세스는 [여기](https://developer.x.com/en/products/x-api/enterprise/enterprise-api-interest-form)에서 신청할 수 있습니다.

필터링된 스트림을 통해 반환되는 포스트는 월별 [포스트 상한](/ko/x-api/fundamentals/post-cap)에 포함됩니다.
