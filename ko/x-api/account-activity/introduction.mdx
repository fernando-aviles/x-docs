Account Activity API는 계정 활동 이벤트를 실시간으로 웹훅에 전달합니다. 사용자 계정을 구독하면 사용자가 포스트를 올리거나 DM을 받거나 팔로우되는 등의 활동이 발생할 때마다 알림을 받을 수 있습니다.

<div id="how-it-works">
  ## 동작 방식
</div>

1. **웹훅 등록** — 웹훅 URL을 등록합니다
2. **사용자 구독** — 사용자 구독을 설정합니다
3. **이벤트 수신** — POST 요청으로 활동 이벤트를 수신합니다
4. **이벤트 처리** — 애플리케이션에서 이벤트를 처리합니다

***

<div id="event-types">
  ## 이벤트 유형
</div>

| 카테고리 | 이벤트 |
|:---------|:-------|
| **포스트** | 생성, 삭제, 좋아요, 좋아요 취소 |
| **다이렉트 메시지** | 수신, 발신, 입력 중 표시 |
| **팔로우** | 팔로우, 언팔로우 |
| **차단** | 차단, 차단 해제 |
| **뮤트** | 뮤트, 뮤트 해제 |

***

<div id="webhook-security">
  ## Webhook 보안
</div>

모든 webhook 요청에는 다음이 포함됩니다:

* **CRC 검증** — webhook의 진위 여부 검증
* **Signature 헤더** — `x-twitter-webhooks-signature`
* **HTTPS 필수** — 모든 webhook URL은 반드시 HTTPS를 사용해야 합니다

***

<div id="example-register-a-webhook">
  ## 예제: 웹훅 등록
</div>

```bash
curl -X POST "https://api.x.com/1.1/account_activity/all/env-name/webhooks.json?\
url=https%3A%2F%2Fyour-server.com%2Fwebhook" \
  -H "Authorization: OAuth oauth_consumer_key=..."
```
