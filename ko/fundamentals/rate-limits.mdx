요청 한도는 일정 기간 동안 보낼 수 있는 API 요청 수를 제한합니다. 이는 플랫폼 전반에서 공정한 사용과 시스템 안정성을 보장하기 위해 존재합니다.

***

<div id="how-rate-limits-work">
  ## 레이트 리밋이 동작하는 방식
</div>

| 개념 | 설명 |
|:--------|:------------|
| **시간 윈도우** | 대부분의 제한은 15분마다 재설정됩니다 |
| **사용자당 제한** | OAuth 1.0a 또는 OAuth 2.0 사용자 토큰을 사용할 때 적용됩니다 |
| **앱별 제한** | Bearer Token (앱 전용) 인증을 사용할 때 적용됩니다 |
| **엔드포인트별 제한** | 각 엔드포인트마다 고유한 제한이 있습니다 |

***

<div id="checking-your-limits">
  ## 요청 한도 확인하기
</div>

모든 API 응답 헤더에는 현재 요청 한도(레이트 리밋) 상태가 표시됩니다.

```
x-rate-limit-limit: 900
x-rate-limit-remaining: 847
x-rate-limit-reset: 1705420800
```

| Header                   | Description              |
| :----------------------- | :----------------------- |
| `x-rate-limit-limit`     | 현재 시간 윈도우에서 허용되는 최대 요청 수 |
| `x-rate-limit-remaining` | 현재 시간 윈도우에서 남아 있는 요청 수   |
| `x-rate-limit-reset`     | 제한이 초기화되는 유닉스 타임스탬프      |

***

<div id="rate-limit-errors">
  ## Rate limit 오류
</div>

요청 제한을 초과하면 **429 Too Many Requests** 응답이 반환됩니다:

```json
{
  "errors": [{
    "code": 88,
    "message": "Rate limit exceeded"
  }]
}
```
