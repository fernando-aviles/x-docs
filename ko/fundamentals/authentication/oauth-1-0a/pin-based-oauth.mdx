<div id="pin-based-authorization">
  ### PIN 기반 인증
</div>

PIN 기반 OAuth 플로우는 [3-legged OAuth](/ko/resources/fundamentals/authentication/oauth-1-0a/obtaining-user-access-tokens) 프로세스의 한 변형으로, 승인 후 사용자를 리다이렉트하기 위해 웹 브라우저에 접근하거나 웹 브라우저를 임베드할 수 없는 애플리케이션을 위한 것입니다. 이러한 애플리케이션의 예로는 명령줄 애플리케이션, 임베디드 시스템, 게임 콘솔, 특정 유형의 모바일 앱 등이 있습니다.

PIN 기반 OAuth 플로우는 앱이 `request_token` 요청에서 `oauth_callback`을 `oob`로 설정할 때 시작됩니다. `oob`라는 용어는 out-of-band OAuth를 의미합니다. 사용자는 여전히 X를 방문해 로그인하거나 앱을 승인하지만, 액세스를 승인한 뒤 애플리케이션으로 자동 리다이렉트되지는 않습니다. 대신 애플리케이션으로 돌아가 이 값을 입력하라는 안내와 함께 숫자로 된 PIN 코드가 표시됩니다.

<Note>
  **Note:** PIN 기반 인증을 사용할 때에도 X 앱 설정 내의 `callback_url`은 여전히 필수입니다.
</Note>

 

<div id="implementing-the-pin-based-oauth-flow">
  #### PIN 기반 OAuth 플로 구현
</div>

PIN 기반 플로는 [3-legged authorization](/ko/resources/fundamentals/authentication/oauth-1-0a/obtaining-user-access-tokens) (및 [Sign in with X](/ko/resources/fundamentals/authentication#log-in-with-x))과 동일한 방식으로 구현되지만, 다음과 같은 차이점이 있습니다.

1. [POST oauth/request&#95;token](/ko/resources/fundamentals/authentication/api-reference#post-oauth-request-token) 호출 시 `oauth_callback` 값은 `oob`로 설정해야 합니다.

2. 사용자가 [GET oauth/authenticate](/ko/resources/fundamentals/authentication/api-reference#get-oauth-authenticate) 또는 [GET oauth/authorize URL](/ko/resources/fundamentals/authentication/api-reference#get-oauth-authorize)를 통해 X로 이동하여 앱을 승인한 후에는 `callback_url`로 리디렉션되지 않습니다. 대신 X에서 생성한 약 7자리의 PIN과, 이 PIN을 애플리케이션에 입력하라는 안내가 표시된 화면을 보게 됩니다.

3. 사용자가 이 PIN을 애플리케이션에 입력하면, 애플리케이션은 이 PIN 번호를 [POST oauth/access&#95;token](/ko/resources/fundamentals/authentication/api-reference#post-oauth-access-token) 호출에서 `oauth_verifier`로 사용하여 `access_token`을 획득합니다.

<Note>
  **참고:** PIN 번호는 재사용할 수 없으며, 획득한 `access_token`은 해당 애플리케이션 사용자의 요청에 사용해야 합니다.
</Note>
