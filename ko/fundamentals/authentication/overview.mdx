X API는 방대한 양의 데이터를 처리합니다. 이 데이터를 개발자와 사용자 모두에게 안전하게 보호하는 방법은 인증(authentication)을 통해서입니다. 인증에는 여러 가지 방식이 있으며, 아래에 나열되어 있습니다.

대부분의 개발자는 클라이언트 라이브러리가 이러한 복잡한 작업을 자동으로 처리하므로, 인증과 관련된 복잡성을 직접 다룰 필요가 없습니다.

사용 가능한 클라이언트 라이브러리 목록은 [도구 및 라이브러리](/ko/resources/tools-and-libraries) 페이지에서 확인할 수 있습니다.

<Note>
  **참고:**
  App의 API Key와 App 전용 Access Token뿐만 아니라 개인 Access Token과 Access Token Secret은 [개발자 콘솔](/ko/resources/fundamentals/developer-portal)의 [X developer Apps](/ko/resources/fundamentals/developer-apps) 섹션에서 확인하고 발급받을 수 있습니다.

  **다른 사용자를 대신해 요청을 보내려면**, 해당 사용자를 위해 [3-legged OAuth flow](https://developer.x.com/resources/fundamentals/authentication/obtaining-user-access-tokens)를 사용해 별도의 Access Token 세트를 생성한 다음, OAuth 1.0a User Context 또는 OAuth 2.0 User Context 요청 시 그 사용자의 토큰을 함께 전달해야 합니다.
</Note>
