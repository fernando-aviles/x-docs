X의 포스트 하나에는 최대 **280자**까지 포함할 수 있습니다. 그러나 모든 문자가 동일하게 계산되지는 않으며, 이모지, URL, 특정 유니코드 범위에는 별도의 계산 규칙이 적용됩니다.

---

<div id="character-weights">
  ## 문자 가중치
</div>

X는 가중치 기반 문자 수 계산 시스템을 사용합니다. 대부분의 문자는 1로 계산되지만, 일부 문자는 2로 계산됩니다:

| 문자 유형 | 가중치 | 최대 문자 수 |
|:---------------|:-------|:---------------|
| 라틴 문자, 문장 부호, 일반 기호 | 1 | 280 |
| 이모지 | 2 | 이모지 140개 |
| CJK(중국어, 일본어, 한국어) | 2 | 140자 |
| 그 외 유니코드 문자 | 2 (기본값) | 가변적 |

<Tip>
앱에서 문자를 정확하게 계산하려면 오픈 소스 라이브러리인 [twitter-text](https://github.com/twitter/twitter-text)를 사용하세요.
</Tip>

---

<div id="emoji-counting">
  ## 이모지 계산
</div>

모든 이모지는 복잡성과 관계없이 **2자**로 계산됩니다:

| Emoji | 표시 | 문자 수 | 유니코드 |
|:------|:--------|:----------------|:--------|
| 👾 | 단일 이모지 | 2 | U+1F47E |
| 🙋🏽 | 피부색 지정 이모지 | 2 | 🙋 + 🏽 수정자 |
| 👨‍🎤 | ZWJ로 결합된 이모지 | 2 | 👨 + ZWJ + 🎤 |
| 👨‍👩‍👧‍👦 | 가족 이모지 시퀀스 | 2 | 이모지 4개 + ZWJ 3개 |

Zero-width joiner (ZWJ)는 이모지를 시각적으로 결합하지만, 문자 수에는 영향을 주지 않습니다.

---

<div id="url-handling">
  ## URL 처리
</div>

모든 URL은 `t.co` 단축 URL로 변환되며, 원래 길이에 상관없이 **23자**로 계산됩니다.

```
https://example.com                    → 23자
https://example.com/very/long/path     → 23자
```

<Note>
  이는 포스트 본문에서 감지된 모든 유효한 URL에 적용됩니다.
</Note>

***


<div id="special-cases">
  ## 특수 사례
</div>

| Content | Counting rule |
|:--------|:--------------|
| **답글의 @멘션** | 답글 맨 앞에 자동으로 추가되는 @멘션은 문자 수에 포함되지 않습니다 |
| **새로운 @멘션** | 사용자가 직접 추가하는 @멘션은 일반적으로 문자 수에 포함됩니다 |
| **미디어** | 공식 클라이언트를 통해 첨부된 미디어는 문자 수 0자로 처리됩니다 |
| **해시태그** | 일반 규칙대로 문자 수를 계산합니다 (# + 태그 텍스트) |

<div id="text-encoding">
  ## 텍스트 인코딩
</div>

X API는 **UTF-8** 인코딩을 사용해야 합니다. 문자 길이는 Unicode 정규화 형식 C(NFC)를 사용하여 계산됩니다.

`café` 예시:

| 형식 | 바이트 | 문자 수 |
|:-----|:------|:-----------|
| NFC (조합형) | `c a f é` | 4 |
| NFD (분해형) | `c a f e ́` | 5 |

X는 NFC로 정규화하므로, 둘 다 문자 수가 4자로 동일합니다.

<div id="implementation">
  ## 구현
</div>

정확한 문자 수 계산을 위해 공식 [twitter-text](https://github.com/twitter/twitter-text) 라이브러리를 사용하세요:

<Tabs>
  <Tab title="JavaScript">
```javascript
import { parseTweet } from 'twitter-text';

const result = parseTweet('Hello, world! 👋');
console.log(result.weightedLength); // 16
console.log(result.valid);          // true
```
  </Tab>
  <Tab title="Python">
```python
from twitter_text import parse_tweet

result = parse_tweet('Hello, world! 👋')
print(result.weightedLength)  # 16
print(result.valid)           # True
```
  </Tab>
</Tabs>

이 라이브러리는 이모지 시퀀스, URL 감지, 유니코드 정규화 등을 포함한 모든 예외적인 경우를 처리합니다.
