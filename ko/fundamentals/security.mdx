<div id="protecting-credentials">
  ## 자격 증명 보호
</div>

API 키와 토큰은 앱에 접근할 수 있는 열쇠입니다. 반드시 안전하게 보호하세요:

<Steps>
  <Step title="환경 변수 사용">
    자격 증명은 코드가 아니라 환경 변수에 저장하세요.

    ```bash
    export X_API_KEY="your-api-key"
    export X_API_SECRET="your-api-secret"
    ```
  </Step>

  <Step title="비밀 정보를 커밋하지 마세요">
    자격 증명 파일을 `.gitignore`에 추가하세요. `git-secrets`와 같은 도구를 사용해 실수로 커밋되는 것을 방지하세요.
  </Step>

  <Step title="정기적으로 교체">
    정기적으로 키를 재발급하고, 유출이 의심될 경우 즉시 재발급하세요.
  </Step>

  <Step title="최소 권한 사용">
    앱에 실제로 필요한 OAuth 범위만 요청하세요.
  </Step>
</Steps>

<div id="if-credentials-are-compromised">
  ### 자격 증명이 유출된 경우
</div>

1. [Developer Console](https://console.x.com)에서 **즉시 재발급**합니다.
2. **이전 토큰을 취소**합니다 — 재발급하면 이전 자격 증명은 자동으로 무효화됩니다.
3. **사용 내역을 점검**합니다 — 무단 API 활동이 없는지 확인합니다.
4. **앱을 업데이트**합니다 — 모든 환경에 새 자격 증명을 배포합니다.

<div id="application-security">
  ## 애플리케이션 보안
</div>

<div id="input-validation">
  ### 입력 검증
</div>

사용자 입력을 절대 신뢰하지 마십시오. 사용하기 전에 모든 데이터를 검증하고 정제하십시오:

```python
# Bad - vulnerable to injection
query = f"from:{user_input}"

# Good - validate input first
import re
if re.match(r'^[a-zA-Z0-9_]{1,15}$', user_input):
    query = f"from:{user_input}"
```

<div id="output-encoding">
  ### 출력 인코딩
</div>

HTML로 출력하기 전에 X API data를 이스케이프하여 XSS를 방지하세요:

```javascript
// 나쁜 예 - XSS에 취약함
element.innerHTML = tweet.text;

// 좋은 예 - HTML 이스케이프 처리
element.textContent = tweet.text;
```

<div id="common-vulnerabilities-to-prevent">
  ### 방지해야 할 일반적인 취약점
</div>

| 취약점 | 방지 방법 |
|:--------------|:-----------|
| **XSS** | 렌더링하기 전에 사용자가 생성한 콘텐츠를 모두 이스케이프 처리합니다 |
| **CSRF** | 폼에 CSRF 방지 토큰을 사용하고 OAuth state 매개변수를 검증합니다 |
| **SQL Injection** | 매개변수화된 쿼리를 사용하고, 절대 사용자 입력을 문자열로 단순 연결하지 않습니다 |
| **Open redirects** | 허용 목록(allowlist)을 기준으로 콜백 URL을 검증합니다 |

<div id="oauth-security">
  ## OAuth 보안
</div>

<div id="state-parameter">
  ### state 매개변수
</div>

OAuth 플로에서는 CSRF를 방지하기 위해 항상 `state` 매개변수를 사용해야 합니다:

```python
import secrets

# 인증 전 state 생성
state = secrets.token_urlsafe(32)
session['oauth_state'] = state

# 콜백 후 state 확인
if request.args.get('state') != session.get('oauth_state'):
    abort(403)  # State 불일치 - CSRF 공격 가능성
```

<div id="token-storage">
  ### 토큰 저장
</div>

| 토큰 유형 | 저장 권장사항 |
|:-----------|:-----------------------|
| **Access tokens** | 암호화된 데이터베이스 또는 보안 금고 |
| **Refresh tokens** | 추가 액세스 제어가 적용된 암호화된 데이터베이스 |
| **Bearer tokens** | 환경 변수 또는 보안 설정 |

<div id="resources">
  ## 컴플라이언스 체크리스트
</div>

<Accordion title="X API 개발자를 위한 보안 요구사항">
  * [ ] 모든 API 요청에 TLS/HTTPS 사용
  * [ ] 자격 증명 정보는 안전하게 저장 (코드나 로그에 저장 금지)
  * [ ] 사용자 토큰은 저장 시 암호화
  * [ ] 사용자가 제공한 데이터에 대한 입력 검증 수행
  * [ ] XSS 방지를 위한 출력 인코딩 적용
  * [ ] OAuth 플로우에 CSRF 보호 적용
  * [ ] 민감한 데이터는 제외하고 보안 로깅 활성화
  * [ ] 보안 사고 대응 계획 문서화
  * [ ] 종속성 정기적으로 업데이트
  * [ ] 최소한의 OAuth 범위만 요청
</Accordion>
