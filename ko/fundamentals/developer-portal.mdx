[개발자 콘솔](https://console.x.com)은 X API 액세스를 관리하는 중앙 허브입니다. 앱을 생성하고, 자격 증명을 생성하며, 사용량을 모니터링하고, 청구를 관리할 수 있습니다.

<Button href="https://console.x.com">개발자 콘솔 열기</Button>

***

<div id="what-you-can-do">
  ## 할 수 있는 작업
</div>

<CardGroup cols={2}>
  <Card title="앱 생성 및 관리" icon="grid-2">
    API 자격 증명을 발급받기 위해 앱을 설정합니다. 인증, 권한, 콜백 URL을 구성합니다.
  </Card>

  <Card title="사용량 및 비용 모니터링" icon="chart-line">
    API 사용량을 실시간으로 추적합니다. 엔드포인트별 비용을 확인하고 크레딧 잔액을 관리합니다.
  </Card>

  <Card title="자격 증명 생성" icon="key">
    앱에서 사용할 API 키, 액세스 토큰, OAuth 자격 증명을 생성합니다.
  </Card>

  <Card title="크레딧 구매" icon="credit-card">
    사용량 기반 과금에 사용할 크레딧을 구매합니다. 구독이나 약정은 필요하지 않습니다.
  </Card>
</CardGroup>

***

<div id="getting-started">
  ## 시작하기
</div>

<Steps>
  <Step title="개발자 계정 가입">
    [console.x.com](https://console.x.com)으로 이동하여 X 계정으로 로그인합니다. Developer Agreement(개발자 약관)에 동의합니다.
  </Step>

  <Step title="첫 앱 만들기">
    **New App**을 클릭하고 이름과 설명을 입력합니다. 그러면 API 자격 증명이 생성됩니다.
  </Step>

  <Step title="자격 증명 저장">
    API Key, API Secret, Access Token을 복사하여 안전하게 보관합니다. 이 정보는 다시 표시되지 않습니다.
  </Step>

  <Step title="개발 시작하기">
    자격 증명을 사용해 API 요청을 인증합니다. [퀵스타트 가이드](/ko/x-api/getting-started/make-your-first-request)를 확인하세요.
  </Step>
</Steps>

<Warning>
  **자격 증명을 안전하게 보관하세요.** API 키와 토큰은 생성 시 한 번만 표시됩니다. 비밀번호 관리자나 보안 금고를 사용하세요. 분실한 경우 다시 생성해야 하며, 이때 기존 자격 증명은 더 이상 유효하지 않습니다.
</Warning>

<div id="billing-credits">
  ## 결제 및 크레딧
</div>

X API는 크레딧 기반 시스템을 사용하는 사용량 기반 과금제를 제공합니다:

| 기능 | 설명 |
|:--------|:------------|
| **월 구독료 없음** | 사용한 만큼만 결제 — 별도 구독 요금 없음 |
| **크레딧 기반** | 크레딧을 미리 구매하고, API 사용 시 차감 |
| **실시간 추적** | 개발자 콘솔 대시보드에서 사용량과 비용을 실시간으로 모니터링 |
| **엔드포인트별 요금** | 엔드포인트마다 요금이 다름 |
| **중복 제거** | 동일 리소스를 24시간 내 두 번 요청해도 한 번만 과금됨 |

[개발자 콘솔](https://console.x.com)에서 현재 요금을 확인하고 크레딧을 구매할 수 있습니다.

[요금에 대해 더 알아보기 →](/ko/x-api/getting-started/pricing)

<div id="team-management">
  ## 팀 관리
</div>

<Note>
  팀 관리는 **엔터프라이즈 계정**에서만 사용할 수 있습니다.
</Note>

엔터프라이즈 계정은 팀 구성원을 초대해 함께 작업할 수 있습니다.

| 역할 | 권한 |
|:-----|:-------------|
| **관리자** | 모든 권한: 앱, 결제, 팀 구성원 및 역할 관리 |
| **개발자** | 본인 앱 관리, 팀 앱에 대한 읽기 전용 권한 |

팀 구성원을 초대하려면 콘솔의 팀 페이지로 이동한 후 초대할 사용자의 X 핸들을 입력하세요.
