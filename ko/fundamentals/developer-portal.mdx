[Developer Console](https://console.x.com)은 X API 액세스를 관리하기 위한 중앙 허브입니다. 앱을 생성하고 자격 증명을 발급받으며, 사용량을 모니터링하고 결제를 관리하는 작업을 한곳에서 수행할 수 있습니다.

<Button href="https://console.x.com">Developer Console 열기</Button>

<div id="getting-started">
  ## 시작하기
</div>

<Steps>
  <Step title="개발자 계정 가입하기">
    [console.x.com](https://console.x.com)으로 이동해 X 계정으로 로그인합니다. Developer Agreement에 동의합니다.
  </Step>

  <Step title="첫 앱 만들기">
    **New App**을 클릭하고 이름과 설명을 입력합니다. 이 과정에서 API 자격 증명이 생성됩니다.
  </Step>

  <Step title="자격 증명 저장하기">
    API Key, API Secret, Access Token을 복사해 안전하게 보관합니다. 한 번 표시된 후에는 다시 확인할 수 없습니다.
  </Step>

  <Step title="개발 시작하기">
    자격 증명을 사용해 API 요청을 인증합니다. [빠른 시작 가이드](/ko/x-api/getting-started/make-your-first-request)를 참고하세요.
  </Step>
</Steps>

<Warning>
  **자격 증명을 안전하게 보관하세요.** API 키와 토큰은 생성 시 한 번만 표시됩니다. 비밀번호 관리자나 보안 금고를 사용하세요. 분실한 경우 다시 생성해야 하며, 이때 기존 자격 증명은 더 이상 유효하지 않습니다.
</Warning>

<div id="billing-credits">
  ## 과금 및 크레딧
</div>

X API는 크레딧 기반 시스템을 사용하는 사용량 기반 과금 방식을 사용합니다:

| 기능 | 설명 |
|:--------|:------------|
| **월별 요금 없음** | 사용한 만큼만 결제 — 구독 요금 없음 |
| **크레딧 기반** | 크레딧을 선결제하고, API 사용 시 차감 |
| **실시간 추적** | 콘솔 대시보드에서 사용량과 비용을 실시간으로 모니터링 |
| **엔드포인트별 요금** | 엔드포인트마다 비용이 다름 |
| **중복 제거** | 같은 리소스를 24시간 내에 두 번 요청해도 한 번만 과금 |

현재 요금을 확인하고 크레딧을 구매하려면 [Developer Console](https://console.x.com)을 이용하세요.

[요금에 대해 자세히 알아보기 →](/ko/x-api/getting-started/pricing)

<div id="team-management">
  ## 팀 관리
</div>

<Note>
  팀 관리는 **엔터프라이즈 계정**에서만 사용할 수 있습니다.
</Note>

엔터프라이즈 계정은 팀 구성원을 초대하여 함께 작업할 수 있습니다:

| 역할 | 권한 |
|:-----|:-------------|
| **Administrator** | 전체 권한: 앱, 결제, 팀 구성원 및 역할 관리 |
| **Developer** | 자신의 앱 관리, 팀 앱에 대한 읽기 전용 권한 |

팀 구성원을 초대하려면 콘솔에서 팀 페이지로 이동한 다음 해당 사용자의 X 핸들을 입력합니다.
