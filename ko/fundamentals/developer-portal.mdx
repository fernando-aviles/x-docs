[개발자 콘솔](https://console.x.com)은 X API 액세스를 관리하는 중심 허브입니다. 한 곳에서 App을 생성하고, 자격 증명을 발급하며, 사용량을 모니터링하고, 결제를 관리할 수 있습니다.

<Button href="https://console.x.com">개발자 콘솔 열기</Button>

***

<div id="what-you-can-do">
  ## 가능한 작업
</div>

<CardGroup cols={2}>
  <Card title="앱 생성 및 관리" icon="grid-2">
    API 자격 증명을 받기 위해 앱을 설정합니다. 인증, 권한, 콜백 URL을 구성합니다.
  </Card>

  <Card title="사용량 및 비용 모니터링" icon="chart-line">
    실시간으로 API 사용량을 추적합니다. 엔드포인트별 비용을 확인하고 크레딧 잔액을 관리합니다.
  </Card>

  <Card title="자격 증명 생성" icon="key">
    앱을 위해 API 키, 액세스 토큰, OAuth 자격 증명을 생성합니다.
  </Card>

  <Card title="크레딧 구매" icon="credit-card">
    사용량 기반 청구를 위한 크레딧을 구매합니다. 구독이나 장기 약정은 필요하지 않습니다.
  </Card>
</CardGroup>

<div id="getting-started">
  ## 시작하기
</div>

<Steps>
  <Step title="개발자 계정 가입하기">
    [console.x.com](https://console.x.com)에 접속해 X 계정으로 로그인하세요. Developer Agreement(개발자 계약)에 동의하세요.
  </Step>

  <Step title="첫 번째 앱 만들기">
    **New App**을 클릭하고 이름과 설명을 입력하세요. 그러면 API 자격 증명이 생성됩니다.
  </Step>

  <Step title="자격 증명 저장하기">
    API Key, API Secret, Access Tokens를 복사해 안전하게 보관하세요. 이 정보는 다시 표시되지 않습니다.
  </Step>

  <Step title="개발 시작하기">
    자격 증명을 사용해 API 요청을 인증하세요. [빠른 시작 가이드](/ko/x-api/getting-started/make-your-first-request)를 참고하세요.
  </Step>
</Steps>

<Warning>
  **자격 증명을 안전하게 보관하세요.** API Key와 토큰은 생성 시 한 번만 표시됩니다. 비밀번호 관리자나 보안 금고 서비스를 사용하세요. 분실한 경우 다시 생성해야 하며, 이때 기존 자격 증명은 무효화됩니다.
</Warning>

<div id="billing-credits">
  ## 과금 및 크레딧
</div>

X API는 크레딧 기반 시스템을 사용하는 사용량 기반(pay-per-usage) 과금 방식을 제공합니다:

| 기능 | 설명 |
|:--------|:------------|
| **월 요금 없음** | 사용한 만큼만 지불하며, 별도의 구독은 필요 없습니다 |
| **크레딧 기반** | 크레딧을 미리 구매하고, API 사용량에 따라 차감됩니다 |
| **실시간 추적** | 개발자 콘솔 대시보드에서 사용량과 비용을 실시간으로 모니터링합니다 |
| **엔드포인트별 요금** | 엔드포인트마다 비용이 다르게 책정됩니다 |
| **중복 제거** | 동일한 리소스를 24시간 이내에 두 번 이상 요청해도 한 번만 과금됩니다 |

현재 요금을 확인하고 크레딧을 구매하려면 [개발자 콘솔](https://console.x.com)을 방문하세요.

[요금에 대해 더 알아보기 →](/ko/x-api/getting-started/pricing)

<div id="team-management">
  ## 팀 관리
</div>

<Note>
  팀 관리는 **Enterprise 계정**에서만 제공됩니다.
</Note>

Enterprise 계정에서는 팀원을 초대하여 함께 작업할 수 있습니다:

| Role | Capabilities |
|:-----|:-------------|
| **Administrator** | 전체 권한: App, 결제, 팀원 및 역할 관리 |
| **Developer** | 본인의 App 관리, 팀 App에 대한 읽기 전용 권한 |

팀원을 초대하려면 콘솔에서 Team 페이지로 이동한 후 해당 사용자의 X 핸들을 입력하세요.
