X API의 모든 객체—포스트, 사용자, 리스트, DM, Spaces—에는 고유한 ID가 있습니다. 이러한 ID의 작동 방식을 이해하면 신뢰할 수 있는 연동을 구축하는 데 도움이 됩니다.

***

<div id="id-format">
  ## ID 형식
</div>

X ID는 &quot;Snowflake&quot;라고 불리는 시스템으로 생성되는 **64비트 부호 없는 정수**입니다. 각 ID에는 다음 정보가 인코딩되어 있습니다:

* **타임스탬프** — 객체가 생성된 시점
* **워커 번호** — 어떤 서버가 ID를 생성했는지
* **시퀀스 번호** — 해당 밀리초 내에서의 순서

이는 ID가 대략 생성 시간 순으로 정렬된다는 뜻입니다. 값이 더 큰 ID일수록 일반적으로 더 최근에 생성된 객체를 나타냅니다.

<Tip>
  ID는 단일 객체 유형 내에서만이 아니라, X 전체에서 전역적으로 고유한 값입니다.
</Tip>

***

<div id="string-vs-integer-representation">
  ## 문자열 vs. 정수 표현
</div>

<Warning>
  **코드에서는 항상 문자열 id를 사용하세요.** 일부 프로그래밍 언어(예: JavaScript)는 64비트 정수를 정확하게 표현할 수 없습니다.
</Warning>

JavaScript에서 정수는 53비트까지로 제한됩니다. 이로 인해 큰 id를 사용할 때 정밀도가 손실될 수 있습니다:

```javascript
// 정밀도가 손실됩니다!
const id = 10765432100123456789;
console.log(id.toString()); // "10765432100123458000" — 잘못된 값!

// 대신 문자열을 사용하세요
const id = "10765432100123456789";
console.log(id); // "10765432100123456789" — 올바른 값!
```

<div id="api-versions">
  ### API 버전
</div>

| 버전 | ID 형식 |
|:--------|:----------|
| **X API v2** | ID는 기본적으로 문자열 형태로 반환됩니다 |
| **X API v1.1** | `id`(정수)와 `id_str`(문자열)을 모두 반환하지만 — 항상 `id_str`를 사용해야 합니다 |

<div id="working-with-ids">
  ## ID 다루기
</div>

<div id="storing-ids">
  ### ID 저장하기
</div>

데이터베이스에는 ID를 문자열 또는 64비트 정수로 저장하세요:

| Database | 권장 유형 |
|:---------|:-----------------|
| PostgreSQL | `BIGINT` 또는 `TEXT` |
| MySQL | `BIGINT UNSIGNED` 또는 `VARCHAR(20)` |
| MongoDB | 문자열 |
| SQLite | `TEXT` (SQLite 정수는 최대 63비트입니다) |

<div id="comparing-ids">
  ### ID 비교
</div>

ID를 시간 순서대로 정렬하기 위해 비교할 때:

```python
# Python - safe for 64-bit integers
if int(id1) > int(id2):
    print("id1 is newer")

# JavaScript - 문자열로 비교 (같은 길이의 ID에 대해 사전순으로 작동)
# 또는 BigInt 사용
if (BigInt(id1) > BigInt(id2)) {
    console.log("id1 is newer");
}
```

<div id="common-id-types">
  ## 일반적인 ID 유형
</div>

| 객체 | ID 예시 | 비고 |
|:-------|:-----------|:------|
| 포스트(트윗) | `1234567890123456789` | 트윗 ID라고도 함 |
| 사용자 | `2244994945` | 더 오래된 계정일수록 ID가 더 짧음 |
| 리스트 | `1234567890` | |
| 스페이스 | `1YqGodQbNXDxv` | 영숫자이며 Snowflake 형식이 아님 |
| DM 이벤트 | `1234567890123456789` | |
