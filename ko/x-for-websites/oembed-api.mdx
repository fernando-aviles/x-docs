oEmbed API를 사용하면 [트윗](https://developer.x.com/en/docs/twitter-for-websites/embedded-tweets/overview)과 [타임라인](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview)과 같은 임베드용 콘텐츠를 프로그래밍 방식으로 가져올 수 있습니다. 

oEmbed API는 응답으로 HTML 스니펫을 반환하며, [페이지에 X 위젯 JavaScript가 포함되어 있는 경우](https://developer.x.com/web/javascript/loading) 이 스니펫은 자동으로 인식됩니다.

이 API는 대량 작업을 수행할 때 사용을 권장하며, 콘텐츠 임베드에는 강력한 도구인 [publish.x.com](https://publish.x.com/#) 사용을 권장합니다.

<Tabs>
  <Tab title="임베디드 타임라인">
    반환된 HTML 스니펫은 [임베디드 타임라인](https://developer.x.com/en/docs/twitter-for-websites/timelines/overview)으로 자동 인식되며, [페이지에 X의 위젯 JavaScript가 포함되어 있는 경우](https://developer.x.com/web/javascript/loading) 적용됩니다.

    oEmbed 엔드포인트를 사용하면 HTML 응답에 기본으로 함께 제공되는 X의 JavaScript가 해석할 수 있도록 HTML 마크업의 해당 속성을 설정하여 임베디드 타임라인의 최종 표시 형태를 사용자 정의할 수 있습니다. 반환되는 마크업 형식은 X가 새로운 기능을 추가하거나 타임라인 표현 방식을 조정함에 따라 시간이 지나면서 변경될 수 있습니다.

    이 엔드포인트는 타임라인 URL로 지정된 X 타임라인을 [oEmbed](https://oembed.com/) 호환 JSON 형식으로 반환합니다. 사용자 타임라인과 리스트 타임라인이 지원됩니다. 타임라인 마크업은 `cache_age` 속성에 지정된 권장 캐시 수명까지 서버에 캐시해서 사용하도록 설계되었습니다.

    ## Resource URL

    *https://publish.x.com/oembed*

    ## Resource Information

    |                          |      |
    | :----------------------- | :--- |
    | Response formats         | JSON |
    | Requires authentication? | No   |
    | Rate limited             | No   |

    ## Parameters

    | Name            | Description                                                                                                                                                                                                                                                              | Example                                                                           |
    | :-------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------- |
    | **url**         | 임베드할 X 타임라인의 URL                                                                                                                                                                                                                                                         | *   https://x.com/TwitterDev<br /> *https://x.com/TwitterDev/lists/national-parks |
    | limit           | 표시할 항목 수 N을 설정합니다. N은 1 이상 20 이하의 값이어야 합니다.                                                                                                                                                                                                                              | 6                                                                                 |
    | maxwidth        | 위젯의 최대 너비를 설정합니다. 180 이상 1200 이하의 값이어야 합니다.                                                                                                                                                                                                                              | 300                                                                               |
    | maxheight       | 위젯의 최대 높이를 설정합니다. 200보다 커야 합니다.                                                                                                                                                                                                                                          | 400                                                                               |
    | omit&#95;script | 응답에 `script` 요소를 포함하지 않습니다.                                                                                                                                                                                                                                              | 1                                                                                 |
    | lang            | 지원되는 X의 [언어 코드](/ko/en/docs/twitter-for-websites/twitter-for-websites-supported-languages/overview "Twitter 언어 코드")                                                                                                                                                         | es                                                                                |
    | theme           | `dark`로 설정하면 타임라인이 어두운 배경 위에 밝은 텍스트로 표시됩니다.                                                                                                                                                                                                                              | dark                                                                              |
    | chrome          | 공백으로 구분된 토큰을 사용하여 타임라인 표시 구성요소를 제거합니다<br /><br />*   `noheader` - 헤더를 숨깁니다<br />*   `nofooter` - 표시되는 경우 푸터를 숨깁니다<br />*   `noborders` - 위젯 둘레, 트윗 간, 그리고 트윗 내부의 모든 테두리를 제거합니다<br />*   `noscrollbar` - 표시되는 경우 타임라인 스크롤바를 잘라내고 숨깁니다<br />*   `transparent` - 배경색을 제거합니다 | noheader%20nofooter                                                               |
    | aria&#95;polite | 타임라인에 추가되는 트윗에 대해 assertive 수준의 [ARIA 라이브 영역 politeness](https://www.w3.org/TR/wai-aria/states_and_properties#aria-live) 값을 설정합니다.                                                                                                                                       | assertive                                                                         |
    | dnt             | `true`로 설정하면, 사이트에 임베드된 페이지와 타임라인은 [맞춤 추천](https://support.x.com/articles/20169421) 및 [맞춤 광고](https://support.x.com/articles/20170405) 등을 포함한 목적에 사용되지 않습니다.                                                                                                             | true                                                                              |

    ## Example Requests

    ```bash
    curl --request GET --url 'https://publish.x.com/oembed?url=https%3A%2F%2Ftwitter.com%2FInterior%2Fstatus%2F507185938620219395'
    twurl -H publish.x.com "/oembed?url=https://x.com/Interior/status/463440424141459456"
    ```

    ## 예시 응답

    ```json

    {
      "url": "https://x.com/TwitterDev",
      "title": "",
      "html": "<a class=\"twitter-timeline\" href=\"https://x.com/TwitterDev\">Tweets by TwitterDev</a>\n<script async src=\"//platform.x.com/widgets.js\" charset=\"utf-8\"></script>",
      "width": null,
      "height": null,
      "type": "rich",
      "cache_age": "3153600000",
      "provider_name": "X",
      "provider_url": "https://x.com",
      "version": "1.0"
    }
    ```

  <Tab title="임베디드 트윗">
    반환된 HTML 스니펫은 [X의 위젯 JavaScript가 페이지에 포함](https://developer.x.com/web/javascript/loading)되어 있으면 자동으로 [임베디드 트윗](https://developer.x.com/web/embedded-tweets)으로 인식됩니다.

    oEmbed 엔드포인트를 사용하면 HTML 마크업에서 해당 속성을 설정하여 임베디드 트윗의 최종 표시 형태를 사용자 지정할 수 있으며, 이는 기본적으로 HTML 응답과 함께 번들로 제공되는 X의 JavaScript에 의해 해석됩니다. 반환되는 마크업의 형식은 X가 새로운 기능을 추가하거나 트윗 표현 방식을 조정함에 따라 시간이 지남에 따라 변경될 수 있습니다.

    트윗 폴백 마크업은 `cache_age` 속성에 지정된 권장 캐시 수명 동안 서버에 캐시해야 합니다.

    ## 리소스 URL

    *https://publish.x.com/oembed*

    ## 리소스 정보

    |                |      |
    | :------------- | :--- |
    | 응답 형식          | JSON |
    | 인증 필요 여부       | 아니요  |
    | 요청 속도 제한 적용 여부 | 아니요  |

    ## 매개변수

    | 이름                                                                                                                                     | 기본값     | 설명                                                                                                                                                                                                                                                                                                                                |
    | :------------------------------------------------------------------------------------------------------------------------------------- | :------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | `url` 필수  <br />문자열                                                                                                                    |         | 임베드할 트윗의 URL입니다.                                                                                                                                                                                                                                                                                                                  |
    | `maxwidth`  <br />Int `[220..550]`                                                                                                     | `325`   | 정수 픽셀 단위로 렌더링된 트윗의 최대 너비입니다. 허용 범위를 벗어나는 값이 제공되면 각각 지원되는 최소 또는 최대 너비로 반환되며, 조정된 너비 값은 반환되는 `width` 속성에 반영됩니다. X는 oEmbed `maxheight` 매개변수를 지원하지 않는다는 점에 유의하세요. 트윗은 근본적으로 텍스트이므로, 이미지나 비디오처럼 스케일링할 수 없는 예측 불가능한 높이를 가집니다. 또한 oEmbed 응답에는 `height` 값이 포함되지 않습니다. 트윗에 대해 일관된 높이가 필요한 경우 아래의 `hide_thread` 및 `hide_media` 매개변수를 참고하세요. |
    | `hide_media`  <br />Boolean, 문자열 또는 Int                                                                                                | `false` | `true`, `"t"`, 또는 `1`로 설정하면 트윗 내 링크가 사진, 동영상 또는 링크 미리보기로 확장되지 않습니다.                                                                                                                                                                                                                                                               |
    | `hide_thread`  <br />Boolean, 문자열 또는 정수                                                                                                | `false` | `true`, `"t"`, 또는 `1`로 설정하면, 요청한 트윗이 다른 트윗에 대한 답글인 경우 대화 스레드에서 이전 트윗이 축약된 형태로 표시되지 않습니다.                                                                                                                                                                                                                                          |
    | `omit_script`  <br />Boolean, 문자열 또는 Int                                                                                               | `false` | `true`, `"t"`, 또는 `1`로 설정하면 `widgets.js` 로드를 담당하는 `<script>`는 반환되지 않습니다. [Embedded Tweets](https://developer.x.com/web/embedded-tweets)를 포함한 모든 X 위젯에서 사용하기 위해 웹 페이지에 `widgets.js`에 대한 참조를 자체적으로 포함해야 합니다.                                                                                                                        |
    | `align`  <br />열거형(Enum) `{left,right,center,none}`                                                                                    | `none`  | 상위 요소를 기준으로 임베드된 트윗을 페이지에서 왼쪽, 오른쪽, 가운데 중 어디에 배치할지 지정합니다.                                                                                                                                                                                                                                                                         |
    | `lang`  <br />Enum([Language](https://developer.x.com/en/docs/twitter-for-websites/twitter-for-websites-supported-languages/overview)) | `en`    | 요청은 지정된 [임베드된 트윗이 지원하는 X 언어](https://developer.x.com/web/overview/languages)로 된 HTML과 렌더링된 트윗을 반환합니다.                                                                                                                                                                                                                             |
    | `theme`  <br />Enum `{light, dark}`                                                                                                    | `light` | `dark`로 설정하면 트윗이 어두운 배경에 밝은 색 글자로 표시됩니다.                                                                                                                                                                                                                                                                                          |
    | `dnt`  <br />Boolean                                                                                                                   | `false` | `true`로 설정하면 트윗과 귀하의 사이트에 임베드된 해당 페이지는 [맞춤형 추천](https://support.x.com/articles/20169421) 및 [맞춤형 광고](https://support.x.com/articles/20170405)를 포함한 목적으로 사용되지 않습니다.                                                                                                                                                                 |
