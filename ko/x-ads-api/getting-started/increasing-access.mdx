<div id="requesting-additional-app-level-permissions">
  ### 추가 App 수준 권한 요청
</div>

애플리케이션이 아래 나열된 App 수준 권한 중 하나로만 제한되어 있고 추가 엔드포인트에 대한 액세스가 필요한 경우, **Standard Access**를 신청하기 위해 X 담당자에게 문의하세요.

2023년 7월 이전에 Ads API 액세스를 요청한 개발자는 다음과 같은 App 수준 권한 중 일부를 요청했을 수 있으며, 현재는 Standard Access 레벨에 포함되어 있습니다.

- **Analytics**(읽기 전용): 사용자는 [Analytics](https://developer.x.com/en/docs/twitter-ads-api/analytics/overview) 엔드포인트에 [읽기 전용](https://developer.x.com/en/docs/apps/app-permissions) 권한으로 액세스할 수 있습니다. 사용자는 Campaign Management, Creative 또는 Custom Audiences 엔드포인트에는 액세스할 수 없지만, Analytics 엔드포인트의 요청 매개변수에 크리에이티브 엔티티를 전달하여 메트릭을 조회할 수 있습니다. `media_id` 또는 `media_name` 단위의 세분화된 수준으로 데이터를 조회하려면, 해당 사용자 애플리케이션에 Ads API 쓰기 권한이 필요합니다.

- **Campaign Management & Creative**(읽기 및 쓰기): 사용자는 [Campaign Management](https://developer.x.com/en/docs/twitter-ads-api/campaign-management/overview) 및 [Creative](https://developer.x.com/en/docs/twitter-ads-api/creatives/overview) 엔드포인트에 [읽기 및 쓰기](https://developer.x.com/en/docs/apps/app-permissions) 권한으로 액세스할 수 있습니다. 사용자는 또한 Analytics 엔드포인트에도 액세스할 수 있습니다.

- **Custom Audiences**(읽기 및 쓰기): 사용자는 [Custom Audiences](https://developer.x.com/en/docs/twitter-ads-api/audiences/overview) 엔드포인트에 [읽기 및 쓰기](https://developer.x.com/en/docs/apps/app-permissions) 권한으로 액세스할 수 있습니다. 사용자는 또한 Campaign Management, Creative, Analytics 엔드포인트에도 액세스할 수 있습니다.

- **Conversion**(읽기 및 쓰기): 사용자는 [Mobile](https://developer.x.com/en/docs/twitter-ads-api/measurement/mobile-conversions/overview) 및 [Web Conversion](https://developer.x.com/en/docs/twitter-ads-api/measurement/web-conversions/overview) 엔드포인트에 [읽기 및 쓰기](https://developer.x.com/en/docs/apps/app-permissions) 권한으로 액세스할 수 있습니다. 사용자는 다른 Ads API 엔드포인트에 액세스 권한이 있을 수도 있고 없을 수도 있습니다. 

<div id="requesting-an-increase-to-user-oauth-token-limits">
  ### 사용자 OAuth 토큰 한도 증가 요청
</div>

2023년 7월 이전에 Ads API 액세스를 요청한 개발자는 애플리케이션에 사용자 OAuth 토큰 한도가 5개로 설정되어 있을 수 있습니다. 개발자 App의 토큰 한도를 늘려야 하는 경우, X 담당자에게 문의해 주세요.

<Note>**참고:** 어떤 Ads API 엔드포인트에 대해서도 [요청 한도](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting)를 상향 조정해 드리지 않습니다. 요청 한도 내에서 사용하는 방법을 알아보려면 [모범 사례](https://developer.x.com/en/docs/twitter-ads-api/rate-limiting)를 확인하세요.</Note>
