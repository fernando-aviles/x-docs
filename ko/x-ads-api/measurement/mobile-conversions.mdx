<div id="mact-overview">
  ## MACT 개요
</div>

X [모바일 앱 프로모션](https://biz.x.com/mobile-app-promotion) 측정을 통해 광고주는 X에서 진행하는 앱 설치 또는 기타 인앱 전환 유도형 광고 캠페인의 성과를 추적할 수 있습니다. X 모바일 측정 파트너는 광고주가 X에서 프로모션 중인 앱에서 어떤 전환을 추적할지 관리할 수 있도록 지원합니다. 광고주가 추적하려는 이벤트의 유형과 시간 범위를 설정하면, 모바일 측정 파트너는 해당 이벤트들을 모두 X로 전송하고, 전환을 유도한 캠페인과 크리에이티브가 무엇인지 나타내는 기여 데이터를 즉시 전달받게 됩니다.

<div id="conversion-events">
  ### 전환 이벤트
</div>

[전환 이벤트](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-event)를 X에 보고하고 기여도 데이터를 받으려면 파트너는 모바일 앱 ID, 전환 유형, 전환 시점의 타임스탬프, 광고/디바이스 ID의 해시값을 전송해야 합니다. 이 데이터를 제공하면 X 플랫폼에 전환 이벤트가 기록되고, 적절한 경우 기여도 정보가 반환됩니다. 또한 광고주는 구매 금액, 상품 ID, 가입 방식과 같은 전환 이벤트에 대한 추가 메타데이터를 제공할 수도 있습니다.

<div id="post-conversion_event">
  #### POST conversion_event
</div>

모바일 측정용 전환 이벤트를 기록합니다. 응답에는 X 또는 X Audience Platform(TAP) 어트리뷰션이 표시됩니다.

이는 [GET conversion&#95;attribution](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-attribution#get-conversion-attribution) 엔드포인트와 관련이 있습니다.

응답에는 X, TAP, 또는 어트리뷰션 없음 중 하나만 표시됩니다. X 어트리뷰션이 없는 경우 `twitter_attribution` 노드는 항상 포함되며 값은 `null`입니다(아래 예시 응답 참조). TAP 어트리뷰션이 있는 경우 `tpn_attribution` 노드가 포함되며 해당 값으로 채워집니다. 자세한 내용은 [TAP 개요](https://developer.x.com/en/docs/x-ads-api/measurement/overview/twitter-audience-platform)를 참고하십시오.

각 전환 이벤트에 연결된 메타데이터를 설정하기 위해 사용할 수 있는 여러 선택적 매개변수가 있습니다. 이 메타데이터는 어트리뷰션 계산에는 아무런 영향을 미치지 않습니다.

<div id="resource-url">
  ##### 리소스 URL
</div>

`https://ads-api.x.com/12/conversion_event`

| conversion&#95;time  <br />*필수* | 밀리초까지 포함한 ISO-8601 타임스탬프 형식의 전환 이벤트 발생 시각입니다.<br /><br />유형: 문자열<br /><br />예시: `2014-05-22T02:38:28.103Z` |

| non&#95;twitter&#95;engagement&#95;time  <br />*선택* | 전환 이전의 마지막 트위터 외 인게이지먼트 발생 시각입니다.<br /><br />유형: 문자열<br /><br />예시: `2014-05-22T02:38:28.103Z` |

| price&#95;micro  <br />*선택* | 이 이벤트와 연결된 가격을 마이크로 단위로 나타낸 값입니다.<br /><br />유형: int<br /><br />예시: `123450000` |
| user&#95;payment&#95;info  <br />*선택* | 이 이벤트와 연결된 앱에 사용자의 결제 정보가 저장되어 있는지를 나타내는 불리언 값입니다.<br /><br />유형: bool<br /><br />가능한 값: `true` 또는 `false` |
| view&#95;through&#95;window  <br />*선택* | 이 이벤트에 대한 뷰 스루 윈도우(일 단위)입니다.<br /><br />**참고**:<br /><br />`click_window`는 view&#95;through&#95;window 이상이어야 합니다.<br /><br />유형: int<br /><br />기본값: `1`  <br />가능한 값: `0`, `1`, `7`, `14`, `30` |

  #### GET accounts/:account_id/app_event_tags
</div>

현재 계정과 연결된 일부 또는 모든 앱 이벤트 태그의 세부 정보를 가져옵니다.

이 태그들은 모바일 앱 전환 추적에서 전환 유형별로 설정된 전환 측정 기간을 정의합니다.

<div id="resource-url">

</div>

`https://ads-api.x.com/12/accounts/:account_id/app_event_tags`

<div id="parameters">

</div>

| Name | Description |
| :--- | :--- |
| account&#95;id  <br />*required* | 활용할 계정의 식별자입니다. 리소스 경로에 포함되며, [GET accounts](/ko/x-ads-api/campaign-management#accounts)를 제외한 모든 Advertiser API 요청에서 일반적으로 필수 매개변수입니다. 지정된 계정은 인증된 사용자와 연계되어 있어야 합니다.<br /><br />Type: string<br /><br />Example: `18ce54d4x5t` |
| app&#95;event&#95;tag&#95;ids  <br />*optional* | 쉼표로 구분된 식별자 목록을 지정하여 원하는 app event tag로만 응답 범위를 제한합니다. 최대 200개의 ID를 제공할 수 있습니다.<br /><br />Type: string<br /><br />Example: `jhp` |

| sort&#95;by  <br />*optional* | 지원되는 속성을 기준으로 오름차순 또는 내림차순으로 정렬합니다. 자세한 내용은 [Sorting](/ko/x-ads-api/fundamentals/sorting)을 참조하세요.<br /><br />Type: string<br /><br />Example: `created_at-asc` |

<div id="get-conversion_attribution">
  #### GET conversion_attribution
</div>

전환 이벤트를 기록하지 않고도 전환 기여도를 확인하기 위해 X에 쿼리를 보냅니다. 응답에는 X 기여 여부가 표시됩니다.

이는 [POST conversion&#95;event](https://developer.x.com/en/docs/x-ads-api/measurement/api-reference/conversion-event#post-conversion-event) 엔드포인트와 관련이 있습니다.

응답에서는 X, TAP 또는 기여 없음 중 하나가 반환됩니다. X 기여가 없는 경우에도 `twitter_attribution` 노드는 항상 존재하며 값이 `null`이고, 아래 예시 응답에서 볼 수 있듯이 X 기여가 있는 경우 값이 채워집니다. TAP 기여가 선언된 경우 `tpn_attribution` 노드가 존재하며 그에 따라 값이 채워집니다. 자세한 내용은 [TAP 개요](https://developer.x.com/en/docs/twitter-ads-api/measurement/twitter-audience-platform/overview)를 참조하세요.
