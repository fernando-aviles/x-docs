Advertiser API에는 [REST API Rate Limiting in v1.1](https://developer.x.com/content/developer-twitter/en/docs/basics/rate-limits)에 문서화된 것과 같이 REST API v1.1과 유사한 방식의 요청 제한이 적용됩니다. 그러나 REST API v1.1과는 달리, 엔드포인트별 제한을 프로그램을 통해 조회할 수 있는 인덱스는 제공되지 않습니다. 엔드포인트별 요청 한도와 재설정(리셋) 윈도우는 HTTP 응답 헤더를 통해 전달됩니다. Ads API의 모든 요청 제한은 OAuth 1.0a를 사용합니다.

<div id="user-level-and-ad-account-level-limits">
  ## 사용자 레벨 및 광고 계정 레벨 한도
</div>

레이트 리밋에는 사용자 토큰 레벨과 광고 계정 레벨의 두 가지 유형이 있습니다. 일부 엔드포인트는 광고 계정 레벨 레이트 리밋을 사용하도록 활성화되어 있습니다. 사용자 토큰은 Ads API를 인증하고 호출할 때 사용하는 [OAuth access token](/ko/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow)입니다. 각 사용자 토큰은 하나 이상의 광고 계정에 액세스할 수 있습니다.

개발자는 응답 헤더에 광고 계정 레벨 레이트 리밋이 반환되는 경우 이를 사용해야 하며, 광고 계정 한도가 제공되지 않을 때에만 사용자 레벨 한도를 사용해야 합니다.

사용자 레벨 레이트 리밋은 다음 헤더를 통해 나타납니다: **x-rate-limit-limit**, **x-rate-limit-remaining**, **x-rate-limit-reset**

광고 계정 레벨 레이트 리밋이 활성화된 엔드포인트의 경우, 레이트 리밋은 다음 헤더를 통해 나타납니다: **x-account-rate-limit-limit**, **x-account-rate-limit-remaining**, **x-account-rate-limit-reset**.

광고 계정 레벨 레이트 리밋은 하나의 사용자 토큰이 여러 광고 계정에 액세스하는 경우 애플리케이션이 엔터티 데이터(예: 캠페인 또는 라인 아이템 객체)를 동기화할 수 있도록 GET 엔드포인트에만 제공됩니다. 쓰기 작업은 동일한 광고 계정 레벨 레이트 리밋이 적용된다고 보장되지 않습니다.

광고 계정 레벨 레이트 리밋이 적용된 엔드포인트의 경우, 사용자 레벨 레이트 리밋은 애플리케이션 전체를 위한 전역 할당량을 나타내는 높은 값으로 설정됩니다. 광고 계정 레벨 레이트 리밋을 사용할 수 있을 때에는 요청량 제어에 있어 이를 우선적으로 사용해야 합니다.

<div id="best-practices">
  ## 모범 사례
</div>

1. 데이터베이스에 마지막으로 동기화한 시점의 타임스탬프를 저장하고, 가능한 경우 `sort_by=updated_at-desc` 옵션을 사용해 데이터를 요청하여, 마지막 동기화 타임스탬프보다 이전의 데이터에 도달하면 동기화 작업을 중지할 수 있도록 하세요. 이렇게 하면 동일한 데이터를 중복으로 동기화하는 것을 방지할 수 있습니다.

2. 단일 요청으로 여러 엔티티를 요청하세요: 일부 엔드포인트는 쉼표로 구분된 값 목록을 지정해 유사한 데이터를 한 번에 여러 개 가져올 수 있도록 허용합니다. 이를 통해 전체 호출 횟수를 줄이고, rate limit을 더 효율적으로 활용할 수 있습니다.

3. 요청 시 “count” 값을 최대치로 설정하세요: [GET accounts/:account&#95;id/targeting&#95;criteria](/ko/x-ads-api/campaign-management#targeting-criteria)와 같은 일부 엔드포인트는 기본값인 200개 대신 1000개의 오브젝트를 반환하도록 최대 count 값으로 호출할 것을 강력히 권장합니다.

<div id="faqs">
  ## 자주 묻는 질문
</div>

*특정 광고 계정이나 당사 애플리케이션의 rate limit를 늘릴 수 있나요?*

일반적으로는 개별 광고 계정이나 애플리케이션에 대해 rate limit를 상향 조정해 드릴 수 없으며, 이미 가장 큰 규모의 광고 계정도 지원할 수 있도록 설정되어 있습니다. 먼저 이 문서에 나와 있는 모범 사례를 적용해 보시고, 그럼에도 불구하고 rate limit 때문에 확장하거나 비즈니스 목표를 달성하는 데 여전히 제약이 있다면, 사용 사례와 관련 요청 사항에 대한 세부 정보를 모두 포함하여 X Ads API 담당자에게 문의해 주시기 바랍니다.
