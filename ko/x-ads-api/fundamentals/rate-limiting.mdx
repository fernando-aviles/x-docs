Advertiser API는 여기 문서에 설명된 REST API v1.1과 유사한 방식으로 요청 한도가 적용됩니다: [REST API Rate Limiting in v1.1](https://developer.x.com/content/developer-twitter/en/docs/basics/rate-limits). REST API v1.1과는 달리, 엔드포인트별 한도에 대한 프로그래밍 방식의 인덱스는 제공되지 않습니다. 엔드포인트별 요청 한도와 재설정(리셋) 시간 창은 HTTP 응답 헤더를 통해 전달됩니다. Ads API의 모든 요청 한도 관리는 OAuth 1.0a를 통해 이루어집니다.

<div id="user-level-and-ad-account-level-limits">
  ## 사용자 수준 및 광고 계정 수준 제한
</div>

요청 제한(레이트 리밋)에는 사용자 토큰 수준과 광고 계정 수준, 두 가지 유형이 있습니다. 일부 엔드포인트는 광고 계정 수준 요청 제한을 사용하도록 설정되어 있습니다. 사용자 토큰은 Ads API를 인증하고 호출하는 데 사용하는 [OAuth access token](/ko/resources/fundamentals/authentication#obtaining-access-tokens-using-3-legged-oauth-flow)을 의미합니다. 각 사용자 토큰은 하나 이상의 광고 계정에 액세스할 수 있습니다.

개발자는 응답 헤더에 광고 계정 수준 요청 제한이 반환되는 경우 이를 사용하고, 광고 계정 제한이 제공되지 않는 경우에만 사용자 수준 제한을 사용해야 합니다.

사용자 수준 요청 제한은 다음 헤더를 통해 표현됩니다: **x-rate-limit-limit**, **x-rate-limit-remaining**, **x-rate-limit-reset**

광고 계정 수준 요청 제한이 활성화된 엔드포인트의 경우, 요청 제한은 다음 헤더를 통해 표현됩니다: **x-account-rate-limit-limit**, **x-account-rate-limit-remaining**, **x-account-rate-limit-reset**.

광고 계정 수준 요청 제한은 단일 사용자 토큰이 여러 광고 계정에 액세스하는 경우 애플리케이션이 캠페인이나 라인 아이템 객체와 같은 엔터티 데이터(entity data)를 동기화할 수 있도록, GET 엔드포인트에 대해서만 제공됩니다. 쓰기 작업에 동일한 광고 계정 수준 요청 제한이 적용된다고는 보장할 수 없습니다.

광고 계정 수준 요청 제한이 적용된 엔드포인트의 경우, 사용자 수준 요청 제한은 애플리케이션 전체에 대한 전역 쿼터를 나타내는 높은 값으로 설정됩니다. 광고 계정 수준 요청 제한을 사용할 수 있는 경우, 요청량을 제어할 때 광고 계정 수준 요청 제한이 우선 적용되어야 합니다.

<div id="best-practices">
  ## 모범 사례
</div>

1. 데이터베이스에 마지막 동기화 시각의 타임스탬프를 저장하고, 가능한 경우 `sort_by=updated_at-desc` 옵션으로 데이터를 요청해 마지막 동기화 시각보다 오래된 데이터에 도달하면 동기화 프로세스를 중단할 수 있도록 하세요. 이렇게 하면 동일한 데이터를 중복으로 동기화하는 것을 방지할 수 있습니다.

2. 하나의 요청에서 여러 엔터티를 요청하기: 일부 엔드포인트는 값들을 쉼표로 구분한 목록으로 지정해, 유사한 데이터를 여러 개 한 번에 가져올 수 있도록 합니다. 이를 통해 전체 호출 횟수를 줄이고, 요청 한도(rate limit)를 보다 효율적으로 활용할 수 있습니다.

3. 요청 시 가능한 최대 “count” 값을 사용하기: [GET accounts/:account&#95;id/targeting&#95;criteria](/ko/x-ads-api/campaign-management#targeting-criteria)와 같은 일부 엔드포인트는 기본값 200이 아닌 최대 count 값으로 호출해, 1000개의 객체를 반환받도록 설정하는 것을 강력히 권장합니다.

<div id="faqs">
  ## FAQs
</div>

*특정 광고 계정이나 당사 애플리케이션에 대한 레이트 한도를 늘릴 수 있나요?*

일반적으로 레이트 한도는 개별적으로 상향 조정해 드리기 어렵고, 가장 큰 규모의 광고 계정을 지원할 수 있도록 설정되어 있습니다. 첫 단계로 이 문서에 나와 있는 모범 사례를 반드시 구현해 주시기 바라며, 그럼에도 레이트 한도가 여전히 확장이나 비즈니스 목표 달성에 영향을 미친다면, 관련 사용 사례와 요청 내역에 대한 모든 세부 정보를 포함하여 X Ads API 담당자에게 문의해 주시기 바랍니다.
