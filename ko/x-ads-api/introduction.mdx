<div id="connect-to-the-x-ads-platform">
  ## X Ads 플랫폼에 연결
</div>

X Ads API는 개발자가 X의 광고 플랫폼에 연결해 전 세계 X 광고주의 요구를 충족하는 솔루션을 구축할 수 있도록 합니다.

<Button href="/ko/x-ads-api/getting-started">
  시작하기
</Button>

***

<CardGroup cols={2}>
  <Card title="캠페인 관리" icon="list-check" href="/ko/x-ads-api/campaign-management">프로그래밍 방식으로 광고 캠페인을 생성, 일정 설정 및 관리해 X에서 사람들과 소통할 수 있습니다.</Card>
  <Card title="맞춤 잠재고객" href="/ko/x-ads-api/audiences" icon="user-group">X, 웹 또는 모바일에서 사용자가 제공하는 data를 사용해 Tailored Audiences를 생성하고 관리합니다.</Card>
  <Card title="크리에이티브" href="/ko/x-ads-api/creatives" icon="paintbrush">포스트를 작성 및 게시하고, Cards로 포스트 기능을 확장하며, 이미지와 동영상을 관리하고 업로드합니다.</Card>
  <Card title="광고 분석" href="/ko/x-ads-api/analytics" icon="chart-pie">비동기 및 동기 API 엔드포인트를 사용해 다양한 지표 전반에 걸쳐 광고 캠페인의 세부적인 인사이트를 가져옵니다.</Card>
  <Card title="도구 및 라이브러리" href="/ko/x-ads-api/tools-and-libraries" icon="screwdriver-wrench">X에서 구축하고 커뮤니티가 지원하는 클라이언트 라이브러리 모음을 확인해 보세요.</Card>
  <Card title="Postman 컬렉션" href="https://documenter.getpostman.com/view/7379786/SzRw1WTU" icon="code">시각적 클라이언트를 사용해 API를 탐색할 수 있도록 v2 엔드포인트용 Postman 컬렉션을 제공합니다.</Card>
  <Card title="명령줄 도구" href="https://github.com/xdevplatform/xurl" icon="terminal">엔드포인트를 명령줄 도구로 사용하고 싶다면 xurl이 적합합니다.</Card>
</CardGroup>
