페이지네이션 응답 인터페이스

X API에서 페이지네이션이 적용된 API 응답의 구조를 나타냅니다.

<div id="type-parameters">
  ## 타입 매개변수
</div>

| 이름 | 설명 |
| :------ | :------ |
| `T` | 응답에 포함된 항목의 유형 |

<div id="properties">
  ## 속성
</div>

<ResponseField name="data" type="T[]" required>
현재 페이지의 항목 배열

</ResponseField>

<ResponseField name="meta" type="Object">
페이지네이션 메타데이터

<Expandable title="properties">
<ResponseField name="Name" type="Type | 유형 | 설명" required>
</ResponseField>

<ResponseField name="resultCount" type="number | 현재 페이지의 결과 수">
</ResponseField>

<ResponseField name="nextToken" type="string | 다음 페이지를 가져오기 위한 토큰">
</ResponseField>

<ResponseField name="previousToken" type="string | 이전 페이지를 가져오기 위한 토큰">
</ResponseField>
</Expandable>
</ResponseField>

<ResponseField name="includes" type="Record&lt;string, any&gt;">
추가로 포함된 객체(사용자, 트윗 등)

</ResponseField>

<ResponseField name="errors" type="any[]">
응답에 포함된 오류

</ResponseField>
