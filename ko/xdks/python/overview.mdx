Python XDK(X Developer Kit)는 Python을 사용하여 X API v2와 연동하기 위한 공식 클라이언트 라이브러리입니다. 이를 통해 개발자는 X API를 빠르게 사용하기 시작하고, 이를 활용해 애플리케이션을 구축할 수 있습니다. 이 라이브러리는 공식 [OpenAPI 사양](https://api.x.com/2/openapi.json)을 기반으로 생성되었습니다. 저수준 HTTP 세부 사항을 추상화하면서도 필요할 때는 세밀한 제어 기능을 제공합니다.

<div id="key-features">
  ## 주요 기능
</div>

- 🔐 **OAuth 지원**: Bearer Token(app-only) 인증, PKCE가 포함된 OAuth 2.0(사용자 컨텍스트), OAuth 1.0을 완전히 지원합니다.
- 🔄 **페이지네이션**: 대용량 결과를 자동으로 페이지 처리합니다. XDK가 `next_token`을 사용해 여러 번 API를 호출할 필요 없이 페이지네이션을 처리합니다.
- 📡 **스트리밍**: 지속적인 HTTP 연결이 필요한 filtered stream 등의 엔드포인트에 대해 실시간 데이터 스트리밍을 지원합니다.
- 🎯 **광범위한 커버리지**: 검색, 타임라인, filtered stream 등 모든 X API v2 엔드포인트를 지원합니다.
**버전 호환성**: Python 3.8+ (이상). CPython 및 PyPy에서 테스트되었습니다.
