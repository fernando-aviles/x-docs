Python XDK(X Developer Kit)는 Python을 사용하여 X API v2와 상호 작용하기 위한 공식 클라이언트 라이브러리입니다. 이를 통해 개발자는 X API v2를 빠르게 활용해 보고, 이를 기반으로 애플리케이션을 구축할 수 있습니다. 이 라이브러리는 공식 [OpenAPI 사양](https://api.x.com/2/openapi.json)을 기반으로 생성되었습니다. 낮은 수준의 HTTP 세부 사항을 추상화하는 동시에, 필요할 때는 세밀한 제어도 제공합니다.

<div id="key-features">
  ## 주요 기능
</div>

- 🔐 **OAuth Support**: Bearer Token(앱 전용) 인증, PKCE를 사용하는 OAuth 2.0(사용자 컨텍스트), OAuth 1.0을 모두 지원합니다.
- 🔄 **Pagination**: 대용량 결과를 자동으로 페이지 처리합니다. XDK가 `next_token`을 사용해 여러 번 API를 호출할 필요 없이 페이지네이션을 처리합니다.
- 📡 **Streaming**: 지속적인 HTTP 연결이 필요한 filtered stream 등의 엔드포인트에 대해 실시간 데이터 스트리밍을 지원합니다.
- 🎯 **Comprehensive Coverage**: 검색, 타임라인, filtered-stream 등을 포함해 모든 X API v2 엔드포인트를 지원합니다.
**Version Compatibility**: Python 3.8+와 호환됩니다. CPython 및 PyPy에서 테스트되었습니다.
