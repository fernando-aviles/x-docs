<div id="create_replay_job">
  ### `create_replay_job`
</div>

리플레이 작업 생성
지정된 webhook에 연결된 모든 구독에 대해 최대 지난 5일 이내의 활동을 가져오기 위한 리플레이 작업을 생성합니다.

<div id="parameters">
  #### 매개변수
</div>

<ParamField path="path.webhook_id" type="Any">
  웹훅 구성의 고유 식별자입니다.
</ParamField>

<ParamField path="path.from_date" type="str">
  이벤트가 제공되는 시작 시점(포함)에 해당하는 가장 이른 UTC 타임스탬프입니다. 형식: yyyymmddhhmm
</ParamField>

<ParamField path="path.to_date" type="str">
  이벤트가 제공되는 종료 시점(미포함)에 해당하는 가장 늦은 UTC 타임스탬프입니다. 형식: yyyymmddhhmm
</ParamField>
