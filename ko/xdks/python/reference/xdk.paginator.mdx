X API SDK를 위한 커서 기반 페이지네이션 유틸리티입니다.

이 모듈은 모든 API 클라이언트 전반에서 편리한 페이지네이션을 지원하는 Cursor 클래스를 제공합니다.
Cursor는 .pages() 및 .items() 메서드를 사용하여, 타입 안전성을 유지하면서 페이지네이션된 결과를 손쉽게 순회할 수 있도록 해 줍니다.

<div id="xdkpaginatorcursor">
  ### `xdk.paginator.cursor`
</div>

적절한 유형 추론과 검증을 갖춘 커서를 생성합니다.
이 팩터리 함수는 유형 추론을 도와 응답 유형에 대한 올바른
타입 힌트를 제공하고, 정적 분석 시점과 런타임 시점 모두에서 메서드가
페이지네이션을 지원하는지 검증합니다.

  #### 매개변수
</div>

래핑할 API 메서드(페이지네이션을 지원해야 함)
</ParamField>
