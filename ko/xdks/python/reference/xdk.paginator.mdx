X API SDK를 위한 커서 기반 페이지네이션 유틸리티입니다.

이 모듈은 모든 API 클라이언트에서 편리한 페이지네이션을 지원하는 Cursor 클래스를 제공합니다.
Cursor를 사용하면 .pages() 및 .items() 메서드를 통해 적절한 타입 안전성을 유지하면서
페이지네이션된 결과를 쉽게 순회할 수 있습니다.

<div id="xdkpaginatorcursor">
  ### `xdk.paginator.cursor`
</div>

올바른 유형 추론과 검증을 수행하는 커서를 생성합니다.
이 팩토리 함수는 유형 추론을 도와 응답 유형에 대한 정확한
유형 힌트를 받을 수 있도록 하고, 해당 메서드가 정적 분석과
런타임 모두에서 페이지네이션을 지원하는지 검증합니다.

<div id="parameters">
  #### 매개변수
</div>

<ParamField path="path.method" type="PaginatableMethod">
페이지네이션을 지원해야 하는, 래핑할 API 메서드
</ParamField>
