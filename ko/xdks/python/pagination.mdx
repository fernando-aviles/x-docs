X API는 여러 페이지의 결과를 반환하는 엔드포인트(예: 타임라인, 검색 등)에 페이지네이션을 사용합니다. 각 API 호출의 응답에는 `result_count`, `previous_token`, `next_token`이 포함된 `meta` 객체가 포함됩니다. XDK는 `next_token`을 사용해 여러 번의 API 호출을 자동으로 처리하므로, 개발자는 여러 번 호출하지 않고도 조회하려는 data의 양만 지정하면 됩니다.
SDK는 이를 다음과 같이 단순화합니다:

- **내장 이터레이터**: 제너레이터 함수를 사용해 여러 페이지를 연속적으로 가져옵니다.
- **명시적 토큰 처리**: 필요할 때 `pagination_token`을 전달해 유연하게 수동 제어할 수 있습니다.
- **최대 결과 수 준수**: 호출당 `max_results`(API 한도 내, 예: 검색은 최대 100)를 준수합니다.

<div id="automatic-pagination-recommended">
  ## 자동 페이지네이션(권장)
</div>

페이지네이션된 응답에서는 `iterate()` 메서드를 사용하여 모든 결과를 지연 방식으로 가져옵니다.
**예제: 페이지네이션 검색**

```python
from xdk import Client
client = Client(bearer_token="your_bearer_token")
# 자동 페이지네이션으로 검색
all_posts = []
for page in client.posts.search_recent(
    query="python",
    max_results=100,  # 페이지당
    tweet_fields=["created_at", "author_id"]  # 선택 사항 expansions
):
    all_posts.extend(page.data)
    print(f"Fetched {len(page.data)} Posts (total: {len(all_posts)})")
print(f"Total tweets: {len(all_posts)}")
```

* 이터레이터가 `next_token`을 자동으로 처리합니다.
* `next_token`이 더 이상 없으면 중지됩니다.
* HTTP 429 오류를 피하기 위한 rate limit 백오프를 지원합니다.


<div id="manual-pagination">
  ## 수동 페이지네이션
</div>

커스텀 로직(예: 페이지 단위 처리)을 위해 결과를 직접 제어해야 한다면, 아래와 같이 `next_token`을 사용하여 페이지네이션을 수동으로 수행할 수 있습니다.

```python
# 첫 번째 페이지 가져오기 - search_recent는 Iterator를 반환합니다
first_page = next(client.posts.search_recent(
    query="xdk python sdk",
    max_results=100,
    pagination_token=None  # First page
))
print(f"First page: {len(first_page.data) if first_page.data else 0} Posts")
# Extract next_token from meta
next_token = None
if hasattr(first_page, 'meta') and first_page.meta:
    if hasattr(first_page.meta, 'next_token'):
        next_token = first_page.meta.next_token
    elif isinstance(first_page.meta, dict):
        next_token = first_page.meta.get('next_token')
if next_token:
    second_page = next(client.posts.search_recent(
        query="xdk python sdk",
        max_results=100,
        pagination_token=next_token
    ))
    print(f"Second page: {len(second_page.data) if second_page.data else 0} Posts")
```

**팁**:

* 항상 `max_results`를 지정해 최적화하세요(기본값은 엔드포인트마다 다릅니다).
* 디버깅을 위해 `meta.result_count`를 모니터링하세요.
* 매우 큰 쿼리의 경우, 블로킹되는 것을 피하기 위해 비동기 반복을 고려하세요.
  Python XDK를 사용하는 자세한 코드 예시는 [code samples GitHub 저장소](https://github.com/xdevplatform/samples/tree/main/python)에서 확인하세요.
